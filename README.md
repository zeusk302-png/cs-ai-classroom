# 열린 배움 — 비전공자를 위한 컴퓨터공학

**컴퓨터공학을 전공하지 않은 사람도 컴퓨터가 동작하는 원리와 인공지능을 이해할 수 있도록 만드는 무료 오픈소스 교육 프로젝트입니다.**

초등학생·중학생·고등학생부터 성인 학습자까지, 관심이 있다면 누구나 회원가입 없이 접근할 수 있습니다. 학년이나 전공으로 접근을 제한하지 않고 작은 예제와 준비 개념에서 시작해 대학 수준의 이론으로 이어갑니다.

**[강의 사이트 바로가기](https://zeusk302-png.github.io/cs-ai-classroom/)**

## 무엇을 배우나요?

- 공학미분적분학·공학수학·선형대수학·이산수학·확률
- Python·C·C++·C#·Java와 프로그래밍 원리
- 자료구조·알고리즘·컴퓨터시스템·운영체제·네트워크·데이터베이스
- 머신러닝·딥러닝·컴퓨터비전·자연어처리와 응용

63개 과목, 857개 단원, 2,849개 소단원의 목차를 바탕으로 강의를 제작하고 있습니다. 모든 강의가 완성된 상태는 아닙니다. 현재 한국어 본문 집필과 독립 검토를 우선 진행하며, 한국어·영어·중국어 간체·일본어 화면을 제공합니다. 번역이 준비되지 않은 내용에는 한국어 원문 또는 준비 상태를 안내합니다.

각 강의는 개념 설명, 적용 조건, 중간 과정을 보여주는 예제, 직접 해보기, 자기점검과 해설을 담습니다. 공개 대학 강의와 공식 문서를 참고하며 출처를 명시합니다. 구조 검사·내용 검토·코드 실행·학습자 검증은 각각 구분합니다.

## 오픈소스와 기여

이 저장소의 `site/`에는 실제 배포되는 HTML·CSS·JavaScript와 교육 자료가 있습니다. 소스를 읽고 수정하거나 학습에 활용할 수 있습니다. 오류 제보, 설명 개선, 접근성 개선 및 번역 제안은 [Issues](https://github.com/zeusk302-png/cs-ai-classroom/issues)와 Pull Request로 보내 주세요.

로컬 미리보기:

```sh
python -m http.server 8000 --directory site
```

이후 브라우저에서 `http://localhost:8000/`을 엽니다. 기여한 변경은 출처와 검토를 확인한 뒤 강의 제작 과정에도 반영합니다.

## 배포와 검색

`main` 브랜치가 갱신되면 GitHub Actions가 GitHub Pages에 자동 배포합니다. 페이지별 제목·설명·canonical·다국어 hreflang·공유 메타데이터·구조화 데이터를 제공하며, [사이트맵](https://zeusk302-png.github.io/cs-ai-classroom/sitemap.xml)은 강의 갱신 때 함께 생성됩니다. Google Search Console 등록 방법은 [SEO_SETUP.md](SEO_SETUP.md)를 참고해 주세요. 검색엔진의 색인이나 검색 순위를 보장하지 않습니다.
