소단원 5.1

zero-input·zero-state 응답

지금 입력이 0인데도 시스템에서 출력이 나올 수 있을까?

준비 개념과 학습 목표

준비 개념

  • 상태는 과거 입력으로 남은 내부 기억이다.

  • 여기서는 선형 방정식과 정해진 초기조건으로 해가 유일한 모형을 다룬다.

학습 목표

  • 초기 상태와 외부 입력의 기여를 분리한다.

  • 두 부분을 더해 전체 응답을 검산한다.

출력이 처음부터 일정하면 내부 기억의 기여도 없을까요?

시간과 신호를 무차원으로 둔 모형 y″+3y′+2y=2, t≥0에서 y(0)=1, y′(0)=0을 사용합니다. 입력을 없앤 zero-input 해는 2e^(−t)−e^(−2t)이고, 두 초기 상태를 모두 0으로 둔 zero-state 해는 1−2e^(−t)+e^(−2t)입니다. 둘을 더한 전체는 모든 t≥0에서 1입니다.

두 부분은 각각 변하지만 전체에서 서로 상쇄됩니다. 일정한 전체 출력만 관찰하고 내부 기억이 없거나 입력이 없다고 추정할 수 없습니다. 2차 식은 상태 두 개를 지정해야 합니다. 여기서는 선형 상수계수 방정식의 유일한 초기값 해를 분해하며 실제 장치를 측정한 기록이 아닙니다.

먼저 확인할 개념
  • 초기 상태와 입력의 분리

    ZI는 입력만, ZS는 초기 상태만 0으로 둡니다.

  • 두 초기 상태

    2차 방정식의 y와 y′ 초기값을 함께 사용합니다.

입력을 0으로 두는 경우

zero-input 응답은 외부 입력을 0으로 하고 원래 초기 상태는 유지한 해다. 초기 충전 전압이나 저장된 이전 값이 있으면 입력이 없어도 출력이 나올 수 있다. 이름의 zero는 초기 상태까지 0이라는 뜻이 아니다.

미분식 y′+ay =x에서 초기 y(0)=y₀라면 zero-input은 y_ZI =y₀ exp(−at)다. 이 식을 미분하고 좌변에 넣으면 0이며 초기값도 y₀다. a>0이면 감소하고 a<0이면 커질 수 있어 입력 없음이 무조건 정지 또는 안정이라는 뜻도 아니다.

상태를 0으로 두는 경우

zero-state 응답은 원래 외부 입력을 유지하고 초기 상태를 0으로 둔 해다. y′+ay =x,x =B가 t ≥0에서 일정하고 a ≠0이면 y_ZS =(B/a)(1 −exp(−at))다. 초기 0을 만족시키는 지수항도 필요하므로 외부 입력에 의한 응답에 지수항이 없다고 외우면 안 된다.

zero-state는 하나의 임의 particular solution과 동일한 말이 아니다. 초기 0을 만족시키도록 동차해 성분이 보태질 수 있다. a =0이면 적분기여서 일정 입력 B의 응답은 Bt며 B/a 식을 그대로 쓰지 않는다.

선형성으로 전체를 합하기

두 해를 더하면 미분식 좌변의 선형성으로 입력은 0 +x =x, 초기값은 y₀+0 =y₀가 된다. 유일성 조건이 성립하면 이 합이 원래 전체 해다. 이 분리는 초기값만 바뀔 때 입력 부분을, 입력만 바뀔 때 초기 부분을 재사용하는 데 유용하다.

고정된 비영 초기값을 가진 입력 →출력만의 관계는 입력 0에서 출력 0이 아닐 수 있으므로 단순 선형 시스템 정의와 구분한다. 상태와 입력을 함께 변수로 보는 선형 방정식이라는 조건을 적는다. 비선형 y² 항이 있는 식에서는 같은 분해를 무조건 적용하지 않는다.

ZI의 초기 미분도 0이고 ZS의 초기 값과 미분도 0입니다. e^(−t)가 1/2 또는 1/4일 때 표를 계산했습니다. 분해한 두 신호의 합이 원래 초기값과 입력을 만족하는지 함께 검사합니다.

중간 과정을 따라가는 예제

t ≥0에서 y′+2y =4,y(0)=3이다. 두 부분과 전체 해를 구하라.

  1. 입력 0 과 초기 3의 해는 y_ZI =3exp(−2t)다.

  2. 입력 4와 초기 0의 해는 y_ZS =2(1 −exp(−2t))다.

  3. 합은 y =2 +exp(−2t)이며 초기 3이다.

  4. 전체 미분 −2exp(−2t)에 2y를 더하면 4로 원래 식을 만족한다.

전체 2 +exp(−2t)는 초기와 입력의 두 기여를 더한 결과다.

조건을 바꾸어 비교하기

식과 두 초기조건을 모두 검산

위 ZI와 ZS가 지정한 식과 초기 상태를 만족하는지 확인하라.

  1. ZI는 특성근 −1과 −2의 동차해 조합이므로 좌변이 0이다. ZI(0)=2−1=1이며 ZI′(0)=−2+2=0이다.

  2. ZS의 상수 1은 좌변 2를 만든다. 나머지 두 지수는 동차해이므로 입력 2를 유지한다.

  3. ZS(0)=1−2+1=0이며 ZS′(0)=2−2=0이다.

  4. 합 1의 미분은 둘 다 0이고 좌변 2y=2다.

각 부분의 방정식과 초기조건이 맞고 전체는 일정한 1이다.

비교할 점

전체만 맞는지 확인하지 않고 각각의 정의도 대조한다.

속도만 바뀐 초기 상태

입력 2와 y(0)=1을 유지하고 y′(0)=1로 바꾼다. 어느 부분을 재사용하며 전체 해는 무엇인가?

  1. 입력이 같고 zero-state의 초기 상태는 여전히 0이므로 기존 ZS를 재사용한다.

  2. ZI=Ae^(−t)+Be^(−2t)에서 A+B=1, −A−2B=1이므로 A=3,B=−2다.

  3. 합은 1+e^(−t)−e^(−2t)다. 초기 값 1과 미분 1을 만족한다.

ZS는 그대로이고 전체는 1+e^(−t)−e^(−2t)다.

비교할 점

초기 위치가 같아도 초기 속도가 달라지면 전체 출력이 달라진다.

오해와 반례

zero-input 응답은 외부 입력뿐 아니라 초기 상태도 0으로 둔 응답이다.

zero-input은 외부 입력만 0으로 지정하고 원래 초기 상태는 유지한다. 초기 3이면 3exp(−2t)가 남아 0이 아니다. 초기 상태를 0으로 두고 원래 입력을 유지하는 것은 zero-state다. 두 정의를 구별한다.

소단원 5.2

자연·강제응답

입력이 만든 응답에도 시스템 고유의 지수가 섞일 수 있을까?

준비 개념과 학습 목표

준비 개념

  • 동차해는 방정식의 입력 항을 0으로 둔 일반 해다.

  • particular solution은 주어진 입력을 만족하는 특정해 하나다.

  • convention은 이 단원에서 선택해 명시한 용어 정의다. 공진 조건은 입력 모양이 동차 모드와 겹치는 경우를 여기서 뜻한다.

학습 목표

  • 동차해와 특정해를 합쳐 초기값을 맞춘다.

  • 자연/ 강제와 ZI/ZS의 분류 기준을 구분한다.

입력 모양이 동차해와 겹치면 어떤 인자가 추가될까요?

이 소단원은 무차원 시간의 y′+2y=e^(−2t), y(0)=3을 다룹니다. 자연 응답을 동차해 성분, 강제 응답을 선택한 특정해 성분으로 부르는 원래 단원의 관례를 유지합니다. Ce^(−2t)는 좌변에서 사라져 입력을 만들지 못합니다. 특정해로 te^(−2t)를 선택해야 합니다.

전체는 (3+t)e^(−2t)입니다. 이 예제에서는 선택한 특정해가 초기 0을 만족하여 ZS와 일치하지만, 그렇다고 모든 특정해가 언제나 ZS인 것은 아닙니다. 특정해에 동차해를 보태면 분해 표현은 바뀌어도 같은 초기값 문제의 전체 해는 유지됩니다.

먼저 확인할 개념
  • 동차해와 특정해의 관례

    natural/forced 용어를 ZI/ZS와 무조건 동일시하지 않습니다.

  • 초기 0의 입력 기여

    특정해가 초기 상태를 만족하는지 별도로 확인합니다.

방정식의 모드와 특정 입력

y′+ay =x의 동차해는 Kexp(−at)다. 형태의 지수는 시스템 계수 a가 정하고 크기 K는 최종 초기조건을 통해 결정된다. 이 단원에서 자연 응답은 이 동차해 성분, 강제 응답은 선택한 particular solution 성분이라는 convention을 사용한다.

용어는 교재에 따라 입력 기여 전체를 forced response라고 부르기도 한다. 따라서 이 표기에서는 어떤 정의를 사용했는지 먼저 밝힌다. 자연 =zero-input, 강제 =zero-state라고 무조건 같은 것으로 치환하지 않는다.

입력에 맞는 해와 초기 조정

일정 입력 B에서 a ≠0이면 특정해 y_p =B/a가 가능하다. 하지만 이 값이 초기조건을 자동 만족하지는 않는다. 전체 Kexp(−at)+B/a에 y(0)=y₀를 넣어 K =y₀−B/a로 정한다. 자연 성분 계수는 초기값뿐 아니라 선택한 특정해의 초기값에도 달려 있다.

특정해는 유일하지 않다. 어떤 동차해를 더해도 같은 입력 식을 만족한다. 그만큼 전체의 동차 계수를 바꾸면 전체 응답은 같다. 분해 표현의 선택과 물리적으로 유일한 초기값 해를 구분한다.

충격 입력 뒤의 초기값을 충격 전의 값과 같게 둘 수 있을까요?

연속 회로의 기억과 한 표본씩 갱신하는 기억을 어떤 식으로 연결할까?

준비 개념과 학습 목표

준비 개념

  • KVL은 루프 전압 합이 0이라는 규칙이다.

  • recurrence는 이전 값과 입력에서 다음 값을 정하는 점화식이다.

학습 목표

  • RC 회로에서 미분식을 만든다.

  • 점화식의 계수· 입력 시점· 안정 조건을 해석한다.

실제 RC가 안정해도 거친 계산 격자의 숫자는 폭주할 수 있을까요?

RC 시간 상수 τ=1 s의 전압 모형 τy′+y=x에서 각 구간 입력을 4 V로 일정하게 둡니다. 구간 폭 h의 정확 갱신은 y[n+1]=e^(−h/τ)y[n]+(1−e^(−h/τ))x[n]입니다. 전진 오일러 근사는 y[n+1]=(1−h/τ)y[n]+(h/τ)x[n]입니다. 두 식의 계수를 혼용하지 않습니다.

초기 0 V에서 h=3 s를 택하면 정확 식은 4 V에 단조롭게 접근하지만 오일러 값은 12 V, −12 V, 36 V로 바뀝니다. 이는 근사 계산의 불안정이지 이 이상 RC가 실제로 그 전압을 냈다는 측정이 아닙니다. 구간 입력 유지 가정, 시각 간격, 초기 상태를 함께 적습니다.

회로를 입출력 방정식으로 바꾸기

전압원 x(t), 직렬 저항 R, 축전기 C의 출력 y(t)를 축전기 전압으로 두자. x =Ri +y이고 i =C y′이므로 RC y′+y =x다. R,C가 일정한 이상 소자라면 선형 상수계수 모형이며 저장 전압 y가 상태 역할을 한다.

전압원에서 출력까지의 응답을 말하려면 초기 전압도 적는다. 저항 전압을 출력으로 선택하면 x −y라는 다른 출력이 된다. 같은 회로라도 입출력 정의가 다르면 전달 식이 달라질 수 있다.

표본 사이 일정 입력의 정확한 갱신

τ=RC>0, 표본간격 h>0에서 입력이 구간[n h,(n +1)h)동안 x[n]으로 일정하다고 하자. 이 구간 미분식을 풀면 y[n +1]=a y[n]+(1 −a)x[n],a =exp(−h/ τ)다. y[n]은 구간 시작의 축전기 전압이다.

이는 그 구간 일정 입력 모형의 정확한 표본 식이지 임의로 변하는 입력의 정확해가 아니다. a가 0과 1 사이여서 새 출력은 이전 상태와 구간 입력의 가중 평균이다. exp 계수와 단순 Euler 근사의 1 −h/ τ는 서로 다르므로 같은 수라고 외우지 않는다.

점화식의 기억과 안정성

일반 식 y[n +1]=a y[n]+b x[n]에서 입력 0의 상태는 aⁿ y0다. |a |<1이면 기억의 절댓값이 감소하지만 a<0이면 부호가 번갈아 바뀔 수 있다. a =1이면 기억 유지,a>1이면 증가하여 출력이 언제나 수렴한다고 말할 수 없다.

같은 차분식으로 이동 누산· 필터· 금융 모형을 표현할 수 있어도 단위· 구간· 입력 시점의 의미는 다르다. 아래 예제는 정해진 RC 표본 모형의 종이 계산이며 회로· 샘플러· 프로그램을 구현하거나 측정하지 않았다.

힌트 2

③ 시작 전 두 값을 첫 식에 넣습니다. ④ 매 구간 기억 계수는 e^(−h/τ)입니다.

풀이와 답 확인

  1. ① ZI=4e^(−t)−2e^(−2t), ZS=2−4e^(−t)+2e^(−2t)다. 합은 일정한 2이며 원래 식의 좌변은 4다.

  3. ③ y[0]=0−1+2=1, y[1]=0.5×1−0=0.5다.

  4. ④ 기억 계수는 1/2다. 첫 출력은 3 V이고 둘째는 (1/2)×3+(1/2)×4=3.5 V다.

① 전체는 2이지만 ZI와 ZS는 각각 시간에 따라 변한다. ② 전체 (2+t)e^(−3t)와 초기 미분 −5다. ③ 첫 출력 1과 다음 출력 0.5다. ④ 첫 구간 끝 3 V, 다음 구간 끝 3.5 V다.
