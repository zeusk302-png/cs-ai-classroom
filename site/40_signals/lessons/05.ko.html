소단원 5.1

zero-input·zero-state 응답

지금 입력이 0인데도 시스템에서 출력이 나올 수 있을까?

준비 개념과 학습 목표

준비 개념

  • 상태는 과거 입력으로 남은 내부 기억이다.

  • 여기서는 선형 방정식과 정해진 초기조건으로 해가 유일한 모형을 다룬다.

학습 목표

  • 초기 상태와 외부 입력의 기여를 분리한다.

  • 두 부분을 더해 전체 응답을 검산한다.

입력을 0으로 두는 경우

zero-input 응답은 외부 입력을 0으로 하고 원래 초기 상태는 유지한 해다. 초기 충전 전압이나 저장된 이전 값이 있으면 입력이 없어도 출력이 나올 수 있다. 이름의 zero는 초기 상태까지 0이라는 뜻이 아니다.

미분식 y′+ay =x에서 초기 y(0)=y₀라면 zero-input은 y_ZI =y₀ exp(−at)다. 이 식을 미분하고 좌변에 넣으면 0이며 초기값도 y₀다. a>0이면 감소하고 a<0이면 커질 수 있어 입력 없음이 무조건 정지 또는 안정이라는 뜻도 아니다.

상태를 0으로 두는 경우

zero-state 응답은 원래 외부 입력을 유지하고 초기 상태를 0으로 둔 해다. y′+ay =x,x =B가 t ≥0에서 일정하고 a ≠0이면 y_ZS =(B/a)(1 −exp(−at))다. 초기 0을 만족시키는 지수항도 필요하므로 외부 입력에 의한 응답에 지수항이 없다고 외우면 안 된다.

zero-state는 하나의 임의 particular solution과 동일한 말이 아니다. 초기 0을 만족시키도록 동차해 성분이 보태질 수 있다. a =0이면 적분기여서 일정 입력 B의 응답은 Bt며 B/a 식을 그대로 쓰지 않는다.

선형성으로 전체를 합하기

두 해를 더하면 미분식 좌변의 선형성으로 입력은 0 +x =x, 초기값은 y₀+0 =y₀가 된다. 유일성 조건이 성립하면 이 합이 원래 전체 해다. 이 분리는 초기값만 바뀔 때 입력 부분을, 입력만 바뀔 때 초기 부분을 재사용하는 데 유용하다.

고정된 비영 초기값을 가진 입력 →출력만의 관계는 입력 0에서 출력 0이 아닐 수 있으므로 단순 선형 시스템 정의와 구분한다. 상태와 입력을 함께 변수로 보는 선형 방정식이라는 조건을 적는다. 비선형 y² 항이 있는 식에서는 같은 분해를 무조건 적용하지 않는다.

중간 과정을 따라가는 예제

t ≥0에서 y′+2y =4,y(0)=3이다. 두 부분과 전체 해를 구하라.

  1. 입력 0 과 초기 3의 해는 y_ZI =3exp(−2t)다.

  2. 입력 4와 초기 0의 해는 y_ZS =2(1 −exp(−2t))다.

  3. 합은 y =2 +exp(−2t)이며 초기 3이다.

  4. 전체 미분 −2exp(−2t)에 2y를 더하면 4로 원래 식을 만족한다.

전체 2 +exp(−2t)는 초기와 입력의 두 기여를 더한 결과다.

종이와 본문으로 직접 해보기

입력 4는 유지하고 초기값을 1로 바꿔 전체 해를 계산하라. 어떤 부분을 다시 쓰는가?

힌트 보기

zero-state는 입력이 같으므로 그대로다.

풀이 보기

zero-input은 exp(−2t), zero-state는 2(1 −exp(−2t))다. 합은 2 −exp(−2t)이며 초기 1과 원래 식 4를 만족한다.

오해와 반례

zero-input 응답은 외부 입력뿐 아니라 초기 상태도 0으로 둔 응답이다.

zero-input은 외부 입력만 0으로 지정하고 원래 초기 상태는 유지한다. 초기 3이면 3exp(−2t)가 남아 0이 아니다. 초기 상태를 0으로 두고 원래 입력을 유지하는 것은 zero-state다. 두 정의를 구별한다.

소단원 5.2

자연·강제응답

입력이 만든 응답에도 시스템 고유의 지수가 섞일 수 있을까?

준비 개념과 학습 목표

준비 개념

  • 동차해는 방정식의 입력 항을 0으로 둔 일반 해다.

  • particular solution은 주어진 입력을 만족하는 특정해 하나다.

  • convention은 이 단원에서 선택해 명시한 용어 정의다. 공진 조건은 입력 모양이 동차 모드와 겹치는 경우를 여기서 뜻한다.

학습 목표

  • 동차해와 특정해를 합쳐 초기값을 맞춘다.

  • 자연/ 강제와 ZI/ZS의 분류 기준을 구분한다.

방정식의 모드와 특정 입력

y′+ay =x의 동차해는 Kexp(−at)다. 형태의 지수는 시스템 계수 a가 정하고 크기 K는 최종 초기조건을 통해 결정된다. 이 단원에서 자연 응답은 이 동차해 성분, 강제 응답은 선택한 particular solution 성분이라는 convention을 사용한다.

용어는 교재에 따라 입력 기여 전체를 forced response라고 부르기도 한다. 따라서 이 표기에서는 어떤 정의를 사용했는지 먼저 밝힌다. 자연 =zero-input, 강제 =zero-state라고 무조건 같은 것으로 치환하지 않는다.

입력에 맞는 해와 초기 조정

일정 입력 B에서 a ≠0이면 특정해 y_p =B/a가 가능하다. 하지만 이 값이 초기조건을 자동 만족하지는 않는다. 전체 Kexp(−at)+B/a에 y(0)=y₀를 넣어 K =y₀−B/a로 정한다. 자연 성분 계수는 초기값뿐 아니라 선택한 특정해의 초기값에도 달려 있다.

특정해는 유일하지 않다. 어떤 동차해를 더해도 같은 입력 식을 만족한다. 그만큼 전체의 동차 계수를 바꾸면 전체 응답은 같다. 분해 표현의 선택과 물리적으로 유일한 초기값 해를 구분한다.

입력 모양과 공진 조건

입력이 exp(bt)이면 일반적으로 exp(bt)형 특정해를 대입하되 b =−a이면 시스템 동차 모드와 겹친다. 이 경우 단순한 상수 배로는 입력을 만들지 못해 t exp(−at) 같은 형태를 시도한다. “항상 입력과 같은 모양”이라는 규칙에는 예외 조건이 있다.

a>0의 안정한 일정 입력 사례에서는 동차 지수가 사라지고 특정 상수에 접근한다. 그렇다고 모든 입력· 모형에서 forced =정상 상태라고 단정하지 않는다. 입력이 계속 커지거나 시스템이 불안정하면 유한한 끝값이 없을 수 있다.

중간 과정을 따라가는 예제

y′+2y =4,y(0)=0을 자연/ 특정해 방식과 ZI/ZS 방식으로 나누라.

  1. 특정해 y_p =2를 택한다. 동차해 Kexp(−2t)를 더한다.

  2. 초기 0에서 K +2 =0이라 K =−2다. 이 convention의 자연 성분은 −2exp(−2t), 강제 성분은 2다.

  3. ZI는 초기 0· 입력 0이므로 0이다. ZS는 입력 4· 초기 0이므로 전체 2 −2exp(−2t)다.

  4. 두 분해의 합은 모두 같은 전체이며 ZS에도 자연 모드 형태의 지수항이 있다.

전체 2(1 −exp(−2t))는 같지만 두 분류의 성분은 같지 않다.

종이와 본문으로 직접 해보기

y′+y =exp(−t),y(0)=0에서 y =t exp(−t)를 직접 대입하라.

힌트 보기

곱미분으로 y′=(1 −t)exp(−t)를 쓴다.

풀이 보기

y′+y =(1 −t +t)exp(−t)=exp(−t),y0 =0이다. Kexp(−t)만 쓰면 좌변 0이라 입력을 만들지 못한다.

오해와 반례

자연 응답은 언제나 실제 초기값만으로 정해지는 zero-input과 같다.

초기 0인 예제에서도 자연 성분 −2exp(−2t)가 있어 특정 상수 2를 초기에서 상쇄한다. ZI는 0이다. 용어 정의와 분해 조건을 함께 적어야 한다.

소단원 5.3

초기조건의 처리

같은 차분식에 입력도 같으면 언제나 같은 출력일까?

준비 개념과 학습 목표

준비 개념

  • 1차 미분식은 한 초기값을 필요로 한다.

  • 차분식은 시작 전 저장된 표본 값을 필요로 할 수 있다.

학습 목표

  • 시간 기준과 필요한 초기 기억을 명시한다.

  • 식과 초기조건을 각각 검산한다.

식만으로는 남는 자유도

y′+ay =x는 입력이 주어져도 일반 해에 상수가 남는다. 시작 시각 t₀와 y(t₀)를 지정하면 그 상수를 정한다. 더 높은 차수에서는 적절한 미분 초기값들도 필요하며 최고차 계수· 계수의 연속성 같은 해 존재/ 유일성 조건을 확인한다.

y′+y =0에서 exp(−t)와 2exp(−t)는 같은 식을 만족하지만 초기값 1과 2가 다르다. 방정식 대입만 통과했다고 원래 초기값 문제의 답으로 인정하지 않는다.

전환 순간과 적분기의 기억

이상 축전기에서 i =C dv/dt다. 유한하고 보통의 전류만 흐르는 전환에서는 전압이 순간 도약하려면 무한한 짧은 충격 전류가 필요하므로 v(0 ⁺)=v(0 ⁻)를 사용한다. 충격 입력을 허용하는 모형은 별도로 다룬다.

미분식을 적분기로 표현하면 y(t)=y(0)+∫₀ᵗ y′(λ)d λ다. 적분만 적고 y(0)을 없애면 처음 정지라는 다른 문제로 바뀐다. 시각 0 직전· 직후 값을 구별하고 어떤 값을 식의 초기조건으로 사용했는지 명시한다.

이산 시작 인덱스의 함정

y[n]=a y[n −1]+x[n],n ≥0에서 첫 계산은 y[0]=a y[−1]+x[0]이다. y[−1]을 초기값으로 준 것과 y[0]을 초기값으로 준 것은 적용 시점이 다르다. 반면 y[n +1]=a y[n]+x[n] 형식은 y[0]부터 시작한다.

두 표기 사이에 입력 시프트가 숨어 있을 수 있으므로 “첫값”이라는 말 대신 인덱스를 적는다. 차수 2식이라면 y[−1],y[−2] 같은 필요한 과거 값을 함께 지정한다. 초기값을 누락해 임의로 0으로 채우지 않는다.

중간 과정을 따라가는 예제

y[n]=0.5y[n −1]+x[n],n ≥0,y[−1]=4,x[0]=2,x[1]=0,x[2]=0이다. 처음 세 출력을 구하라.

  1. n0에서 y0 =.5·4 +2 =4다. 초기 기억 기여 2와 새 입력 2를 더한다.

  2. n1에서 y1 =.5·4 +0 =2다. n2는 y2 =.5·2 +0 =1이다.

  3. ZI만 보면 y0 =2,y1 =1,y2 =.5다. ZS만 보면 2,1,.5여서 합 4,2,1이다.

  4. 만약 y[−1]을 0으로 누락하면 전체를 2,1,.5로 잘못 계산하게 된다.

초기 인덱스 −1을 반영한 출력은 4,2,1이다.

소단원 5.4

회로·이산 recurrence 모델

연속 회로의 기억과 한 표본씩 갱신하는 기억을 어떤 식으로 연결할까?

준비 개념과 학습 목표

준비 개념

  • KVL은 루프 전압 합이 0이라는 규칙이다.

  • recurrence는 이전 값과 입력에서 다음 값을 정하는 점화식이다.

학습 목표

  • RC 회로에서 미분식을 만든다.

  • 점화식의 계수· 입력 시점· 안정 조건을 해석한다.

회로를 입출력 방정식으로 바꾸기

전압원 x(t), 직렬 저항 R, 축전기 C의 출력 y(t)를 축전기 전압으로 두자. x =Ri +y이고 i =C y′이므로 RC y′+y =x다. R,C가 일정한 이상 소자라면 선형 상수계수 모형이며 저장 전압 y가 상태 역할을 한다.

전압원에서 출력까지의 응답을 말하려면 초기 전압도 적는다. 저항 전압을 출력으로 선택하면 x −y라는 다른 출력이 된다. 같은 회로라도 입출력 정의가 다르면 전달 식이 달라질 수 있다.

표본 사이 일정 입력의 정확한 갱신

τ=RC>0, 표본간격 h>0에서 입력이 구간[n h,(n +1)h)동안 x[n]으로 일정하다고 하자. 이 구간 미분식을 풀면 y[n +1]=a y[n]+(1 −a)x[n],a =exp(−h/ τ)다. y[n]은 구간 시작의 축전기 전압이다.

이는 그 구간 일정 입력 모형의 정확한 표본 식이지 임의로 변하는 입력의 정확해가 아니다. a가 0과 1 사이여서 새 출력은 이전 상태와 구간 입력의 가중 평균이다. exp 계수와 단순 Euler 근사의 1 −h/ τ는 서로 다르므로 같은 수라고 외우지 않는다.

점화식의 기억과 안정성

일반 식 y[n +1]=a y[n]+b x[n]에서 입력 0의 상태는 aⁿ y0다. |a |<1이면 기억의 절댓값이 감소하지만 a<0이면 부호가 번갈아 바뀔 수 있다. a =1이면 기억 유지,a>1이면 증가하여 출력이 언제나 수렴한다고 말할 수 없다.

같은 차분식으로 이동 누산· 필터· 금융 모형을 표현할 수 있어도 단위· 구간· 입력 시점의 의미는 다르다. 아래 예제는 정해진 RC 표본 모형의 종이 계산이며 회로· 샘플러· 프로그램을 구현하거나 측정하지 않았다.

중간 과정을 따라가는 예제

τ=1s,h =ln2 s이고 각 구간 입력 x[n]=4V, 초기 y0 =0이다. 정확 표본 식으로 y1,y2,y3를 구하라.

  1. a =exp(−ln2)=1/2이므로 y[n +1]=.5y[n]+2다.

  2. y1 =.5·0 +2 =2V,y2 =.5·2 +2 =3V,y3 =.5·3 +2 =3.5V다.

  3. 연속해 y(t)=4(1 −exp(−t))에 t =nln2를 넣으면 4(1 −2 ⁻ⁿ)로 같다.

  4. 최종 4V와의 차는 2,1,.5V로 매번 절반이다. h가 초이므로 h/ τ는 무차원이다.

표본 전압 2,3,3.5V는 연속해의 같은 시각과 일치한다.

종이와 본문으로 직접 해보기

다음 구간 n3에서 입력을 0V로 바꾸면 y4는? 이전 입력 4를 계속 쓴 계산과 비교하라.

힌트 보기

갱신 식은 해당 구간의 x3을 사용한다.

풀이 보기

y4 =.5·3.5 +.5·0 =1.75V다. 입력 4를 잘못 유지하면 3.75V다. 상태는 남아 있지만 새 구간 입력은 제거되었다.

오해와 반례

표본간격을 어떻게 바꿔도 a 는 같다.

a =exp(−h/ τ)로 h가 커지면 더 작다. 같은 RC라도 기억을 한 표본에 얼마나 남기는지는 시간 간격에 달려 있다.
