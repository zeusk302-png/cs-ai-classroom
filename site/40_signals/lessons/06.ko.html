소단원 6.1

LTI의 고유함수

같은 진동을 넣었는데 출력도 같은 속도로 진동하는 이유를 적분으로 보일 수 있을까?

준비 개념과 학습 목표

준비 개념

  • j²=−1 인 복소수와 Euler 공식
  • LTI 는 선형·시간불변, h 는 단위 충격에 대한 응답이다.

학습 목표

  • 복소지수 고유응답을 convolution 에서 유도한다.
  • 영원한 입력과 시작된 입력의 차이를 설명한다.

시간 이동이 상수 배수가 되는 함수

연속시간 convolution y(t)=∫h(τ)x(t−τ)dτ를 쓴다. 모든 실수 t 에서 x(t)=e^(st)이면 x(t−τ)=e^(st)e^(−sτ)여서 y(t)=e^(st)∫h(τ)e^(−sτ)dτ다. 적분이 유한할 때 상수 H(s)가 앞에 곱해진다.

출력이 입력의 상수 배수면 그 함수를 고유함수라고 부른다. 상수는 복소수여서 크기뿐 아니라 위상도 바꾼다. 전제는 해당 convolution 과 수렴이며 모든 s 에서 무조건 유한하다고 가정하지 않는다.

수렴 영역을 직접 확인한다

자체 h(t)=2e^(−2t)u(t)에서 u(t)는 t≥0 이면 1, t<0 이면 0 인 계단이다. H(s)=∫0∞2e^(−(2+s)τ)dτ=2/(2+s)는 Re(s)>−2 에서 수렴한다. s=jω는 이 영역 안이다.

s=−2 이면 적분 안이 상수 2 라 무한대, s=−3 이면 증가해 수렴하지 않는다. 분수식이 −2 같은 값으로 계산돼도 s=−3 의 실제 convolution 응답을 뜻하지 않는다. 식과 수렴 영역을 함께 쓴다.

입력 시작과 초기 상태를 구별한다

x=e^(jωt)u(t)는 0 이전에 꺼져 있다. 적분의 유효 범위가 시간에 따라 바뀌므로 영원한 지수와 같은 상수 배수 논증이 성립하지 않는다. 시작 구간의 과도응답이 추가될 수 있다.

시스템 내부의 임의 초기 상태도 별도 자연응답을 만들 수 있다. 여기서는 입력에 대한 convolution 의 영초기상태 응답을 다룬다. 실제 필터·장비를 구동한 관측은 없다.

중간 과정을 따라가는 예제

자체 h=2e^(−2t)u(t)에 영원한 x=e^(j2t)를 넣으면 H 와 출력은?

  1. H(j2)=2/(2+j2)=(1−j)/2 다.
  2. 크기는√2/2, 위상은−π/4 다.
  3. y=((1−j)/2)e^(j2t)로 각주파수 2 는 그대로다.

H=(1−j)/2, y=H e^(j2t).

종이와 본문으로 직접 해보기

영원한 x=e^(−t)와 e^(−3t)의 convolution 존재 여부를 비교하라.

힌트 보기

Re(s)>−2 인지 적분 안의 감소로 확인한다.

풀이 보기

s=−1 은 2/(2−1)=2 여서 y=2e^(−t). s=−3 은 적분 2e^τ가 발산해 해당 응답이 정의되지 않는다.

오해와 반례

분수 H(s)만 계산되면 어떤 s 에서도 고유응답을 얻는다.

s=−3 의 분수값−2 와 발산하는 적분이 반례다. 수렴 영역과 입력의 전체 시간 범위를 확인한다.

답과 이유 보기

2 다.

곱하는 H 는 시간 상수라 지수의 2 가 그대로다.

답과 이유 보기

아니다.

∫0∞2dτ가 무한대다.

u(t)를 곱한 입력도 같은 고유함수인가?

답과 이유 보기

일반적으로 아니다.

시간 이동하면 시작 시점이 함께 바뀐다.

한 단계 더

이산 y[n]=x[n]+.5x[n−1]에 모든 정수 n 의 x[n]=z^n,z≠0 를 넣어 H(z)=1+.5/z 를 유도하라. z=j 이면 1−.5j 이며 유한 두 항이라 수렴 문제는 다르다.

소단원 6.2

주파수응답

주파수마다 진동의 크기가 얼마나 달라지는지 하나의 함수로 표현할 수 있을까?

준비 개념과 학습 목표

준비 개념

  • 영원한 복소지수와 convolution
  • ω는 rad/s, H(jω)는 주파수별 복소 배율이다.

학습 목표

  • 주파수응답을 충격응답에서 구한다.
  • 크기·위상과 cascade/parallel 규칙을 유도한다.

허수축에서의 응답

안정한 절대적분 가능 h 라면 H(jω)=∫h(t)e^(−jωt)dt 가 존재한다. 허수축의 영원한 진동에 대한 배율이며 h 의 Fourier 변환이기도 하다. H 자체는 시간 신호가 아니라 ω의 함수다.

자체 h=2e^(−2t)u(t)는 H=2/(2+jω). DC 인ω0 에서는 1, ω가 커지면 크기가 줄어든다. 여기서 저역통과란 높은 각주파수를 상대적으로 약하게 한다는 뜻이다.

직교형과 극형식을 함께 본다

분모에 켤레를 곱하면 H=(4−j2ω)/(4+ω²). 따라서 |H|=2/√(4+ω²), ω≥0 위상φ=−arctan(ω/2)다. H0 의 위상은 0 이며 음의 주파수는 실수 h 에서 켤레 대칭이다.

크기 1/√2 가 되는ω=2 에서 위상−π/4 다. 이는 진폭 기준이며 제곱한 비율은 1/2 다. 크기 감소와 주파수 변화를 혼동하지 않는다.

두 시스템을 연결하는 계산

앞 시스템 출력이 뒤 입력인 cascade 는 각 지수 배율이 연달아 곱해져 H 전체=H1H2 다. 출력 둘을 더하는 parallel 은 선형성으로 H 전체=H1+H2 다. 서로 다른 연결을 같은 곱으로 쓰지 않는다.

같은 필터 두 개 cascade 에서 |H|², 위상 2φ가 된다. parallel 에서는 복소수 합을 먼저 구한다. 개별 크기 합은 상쇄를 무시하므로 결과 크기와 일반적으로 같지 않다.

중간 과정을 따라가는 예제

필터 H=2/(2+jω)의 ω0/2/4 값과 ω2 에서 같은 필터 cascade 를 구하라.

  1. H0=1,H(j2)=(1−j)/2,H(j4)=(1−2j)/5 다.
  2. 각 크기는 1,1/√2,1/√5 다.
  3. cascade ω2 는((1−j)/2)²=−j/2 로 크기.5,위상−π/2 다.

ω 0/2/4의 크기 1, 1/√2, 1/√5; ω 2의 cascade 응답 −j/2.

종이와 본문으로 직접 해보기

parallel H1=1,H2=−1 의 응답과 두 크기 합을 비교하라.

힌트 보기

복소수를 먼저 더한다.

풀이 보기

H 전체 0,크기 0 이다. 개별 크기 합 2 와 다르며 위상 반대인 경로가 상쇄됐다.

오해와 반례

주파수응답 크기가.5 이면 진동 주파수도 절반이 된다.

영원한 e^(j2t)에−j/2 를 곱해도 각주파수 2 다. 진폭 배율.5 와ω를 구별한다.

소단원 6.3

진폭·위상·지연

위상−π/4 는 몇 초 지연이며 모든 주파수에 같은 지연일까?

준비 개념과 학습 목표

준비 개념

  • 복소수 크기와 위상
  • 각도는 라디안, 시간 지연은 x(t−τ)이다.

학습 목표

  • 위상 지연과 군지연을 구별한다.
  • 선형 위상과 주각의 감김을 해석한다.

진폭과 위상으로 출력 쓰기

입력 A cos(ωt+θ),A≥0 에 실수 충격응답의 H=|H|e^(jφ)를 적용하면 정상 출력은 A|H|cos(ωt+θ+φ)다. φ가 음수면 그 단일 진동에서 뒤로 이동한 것으로 해석할 수 있다.

ω>0 에서 위상 지연 τp=−φ/ω다. 위상은 2π 차이에도 같은 진동이라 단일 진동만으로 전체 주기만큼의 지연을 구별하지 못한다. 주각/연속 위상 선택을 기록한다.

순수 지연은 직선 위상이다

y=x(t−τ)의 지수 배율은 e^(−jωτ),크기 1,연속 위상−ωτ다. 모든ω에 같은τ로 이동하므로 모양을 보존한다. 주각이π를 넘어 뛰어도 실제 지연이 갑자기 반대로 바뀐 것은 아니다.

이득 2 까지 함께 있으면 2e^(−jωτ)다. 위상φ 한 점만 고정하는 것과 여러 주파수에 비례하는 직선은 다르다. 같은−π/4 라도ω2/4 에서는 단일 진동 시간 이동이 다르다.

주파수 묶음의 지연

0 이 아니고 미분 가능한 응답의 연속 위상에서 τg=−dφ/dω를 군지연이라 한다. 좁은 주파수 대역에서 위상을 직선 근사할 때 포락선 이동을 설명한다. 대역이 넓거나 크기 변화가 크면 단일 지연 근사의 한계가 있다.

자체 H=2/(2+jω)의φ=−arctan(ω/2)에서 τg=2/(4+ω²). 이는−φ/ω와 일반적으로 다르다. H=0 인 지점의 위상은 정의되지 않아 그 점에서 무심히 미분하지 않는다.

중간 과정을 따라가는 예제

ω2 에서 H=2/(2+jω)의 진폭 배율/위상 지연/군지연과 순수 지연τ=.5 를 비교하라.

  1. 원 필터 크기 1/√2,φ=−π/4 다.
  2. τp=(π/4)/2=π/8 초,τg=2/8=.25 초다.
  3. 순수 지연은 크기 1,φ=−1rad,τp=τg=.5 초다.

원 필터의 위상 지연은 π/8초, 군지연은 .25초다. 순수 지연에서는 둘 다 .5초다.

종이와 본문으로 직접 해보기

τ1 의 순수 지연에서ω=3π/2 일 때 연속 위상과 주각은? 주각으로만 τp 를 구하면?

힌트 보기

−3π/2 에 2π를 더하면 같은 복소수다.

풀이 보기

연속 위상−3π/2,주각π/2 다. 주각만으로는τp=−1/3 초가 되지만 실제 순수 지연은 1 초라 위상 가지를 확인해야 한다.

오해와 반례

위상 지연과 군지연은 늘 같고 주각의 점프는 지연의 변화다.

원 필터ω2 의π/8 과.25 가 다르다. 순수 지연의 주각 점프는 2π 표현 선택이지 시간 이동의 급변이 아니다.

소단원 6.4

정현파 정상응답

처음 켠 진동의 출력도 곧바로 정상 진폭과 위상을 따를까?

준비 개념과 학습 목표

준비 개념

  • convolution 과 지수 적분
  • 정상응답은 여기서 지속 입력의 진동 부분, 과도응답은 사라지는 추가 부분이다.

학습 목표

  • 실수 정현파의 정상응답을 계산한다.
  • 켜진 입력과 초기조건의 과도항을 분리한다.

양과 음의 주파수를 함께 합친다

cos(ωt)=(e^(jωt)+e^(−jωt))/2 다. 실수 h 라면 두 배율이 켤레라 합은 실수이며 크기/위상 정상식으로 돌아온다. 복소지수 한 개의 실수부를 구하는 방법도 같다.

자체 H=2/(2+jω)에서 x=2cos(2t)는 y 정상=√2cos(2t−π/4)=cos2t+sin2t 다. cos 덧셈식으로 부호와 계수를 확인한다.

켜진 입력을 직접 적분한다

입력 x=2cos(2t)u(t),영초기상태이면 t≥0 에서 y=∫0t2e^(−2τ)·2cos(2(t−τ))dτ다. 복소수로 4e^(j2t)∫0t e^(−(2+j2)τ)dτ의 실수부를 구한다.

결과 y=cos2t+sin2t−e^(−2t)다. t0 에서 1+0−1=0 으로 초기 상태와 맞고, 오랫동안 지속하면 추가항이 0 으로 가며 정상 진동만 남는다. 시작부터 정상식을 쓰면 t0 에서 1 이라는 잘못된 값이다.

초기상태와 안정성을 확인한다

같은 필터 미분식 y′+2y=2x 에서 초기 y0=b 이면 자연응답 b e^(−2t)가 영초기응답에 추가된다. 그래서 t≥0 의 총 출력은 cos2t+sin2t+(b−1)e^(−2t)다.

사라지는 이유는 지수계수−2 다. 불안정한 계수나 공진은 정상응답이 총 응답을 지배한다는 단정을 막는다. 지금의 한 안정 필터 예를 모든 LTI 에 확대하지 않는다.

중간 과정을 따라가는 예제

입력 2cos2t 를 t0 에 켜고 y0=0 인 필터의 총 응답과 t=π/4 값을 구하라.

  1. 총 y=cos2t+sin2t−e^(−2t)다.
  2. tπ/4 에서는 cosπ/2=0,sinπ/2=1 이다.
  3. y=1−e^(−π/2);정상만은 1 이다.

총 1−e^(−π/2),정상 1; 차−e^(−π/2).

종이와 본문으로 직접 해보기

초기 b=3 이면 총 응답과 t0 값은?

힌트 보기

영초기 출력에 3e^(−2t)를 더한다.

풀이 보기

y=cos2t+sin2t+2e^(−2t),t0 은 3 이다. 정상항은 같고 과도항 계수가 바뀐다.

오해와 반례

정상 주파수응답만 알면 켠 직후와 임의 초기상태까지 모두 계산된다.

b0 과 b3 은 같은 H/입력에도 t0 출력 0/3 이다. 시작 시점과 초기 상태의 과도응답을 따로 정해야 한다.

자기점검

영초기 총 응답 t0 은?

답과 이유 보기

0 이다.

1−1=0 이다.

정상 진폭은?

답과 이유 보기

√2 다.

입력 진폭 2와 배율 1/√2의 곱이다.

과도항이 사라지는 근거는?

답과 이유 보기

e^(−2t)→0 이다.

이 필터의 자연응답 지수가 음수다.

한 단계 더

y′+2y=4cos2t 에 총 식을 미분 대입하라. 정상부분의 y′+2y 는 4cos2t 이고 Ce^(−2t)는합 0 이다. 각주파수 0 의 켜진 입력 2u(t)는 2(1−e^(−2t))임도 적분으로 대조하라.
