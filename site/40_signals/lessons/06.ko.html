소단원 6.1

LTI의 고유함수

같은 진동을 넣었는데 출력도 같은 속도로 진동하는 이유를 적분으로 보일 수 있을까?

준비 개념과 학습 목표

준비 개념

  • j²=−1 인 복소수와 Euler 공식

  • LTI 는 선형·시간불변, h 는 단위 충격에 대한 응답이다.

학습 목표

  • 복소지수 고유응답을 convolution 에서 유도한다.

  • 영원한 입력과 시작된 입력의 차이를 설명한다.

출력이 모두 0이어도 입력 지수는 고유함수일 수 있을까요?

무차원 이산 LTI y[n]=x[n]+x[n−1]에서 모든 정수 n에 정의한 입력 x[n]=z^n,z≠0을 사용합니다. 출력은 (1+z^(−1))z^n입니다. z=−1이면 입력은 부호가 번갈아 바뀌지만 출력은 0입니다. 영이 아닌 입력 함수에 대한 고유값이 0인 경우입니다.

시작된 입력 z^n u[n]은 n=0에서 이전 항이 없어 같은 상수 배율이 유지되지 않습니다. 연속시간에서는 무한 적분이 실제로 수렴하는지도 확인합니다. 아래 두 연속 응답은 같은 분수식이어도 지지 구간과 수렴 영역이 달라 다른 시스템입니다.

먼저 확인할 개념
  • 영원한 지수의 이동

    시간 이동이 상수 배수가 되는 조건을 확인합니다.

  • 지연 항의 합성곱

    유한 두 항의 위치와 계수를 직접 합합니다.

시간 이동이 상수 배수가 되는 함수

연속시간 convolution y(t)=∫h(τ)x(t−τ)dτ를 쓴다. 모든 실수 t 에서 x(t)=e^(st)이면 x(t−τ)=e^(st)e^(−sτ)여서 y(t)=e^(st)∫h(τ)e^(−sτ)dτ다. 적분이 유한할 때 상수 H(s)가 앞에 곱해진다.

출력이 입력의 상수 배수면 그 함수를 고유함수라고 부른다. 상수는 복소수여서 크기뿐 아니라 위상도 바꾼다. 전제는 해당 convolution 과 수렴이며 모든 s 에서 무조건 유한하다고 가정하지 않는다.

수렴 영역을 직접 확인한다

자체 h(t)=2e^(−2t)u(t)에서 u(t)는 t≥0 이면 1, t<0 이면 0 인 계단이다. H(s)=∫0∞2e^(−(2+s)τ)dτ=2/(2+s)는 Re(s)>−2 에서 수렴한다. s=jω는 이 영역 안이다.

s=−2 이면 적분 안이 상수 2 라 무한대, s=−3 이면 증가해 수렴하지 않는다. 분수식이 −2 같은 값으로 계산돼도 s=−3 의 실제 convolution 응답을 뜻하지 않는다. 식과 수렴 영역을 함께 쓴다.

입력 시작과 초기 상태를 구별한다

x=e^(jωt)u(t)는 0 이전에 꺼져 있다. 적분의 유효 범위가 시간에 따라 바뀌므로 영원한 지수와 같은 상수 배수 논증이 성립하지 않는다. 시작 구간의 과도응답이 추가될 수 있다.

시스템 내부의 임의 초기 상태도 별도 자연응답을 만들 수 있다. 여기서는 입력에 대한 convolution 의 영초기상태 응답을 다룬다. 실제 필터·장비를 구동한 관측은 없다.

조건을 바꾸어 비교하기

같은 분수식과 다른 적분

무차원 연속 응답 hA(t)=e^t를 t≤0에만, hB(t)=−e^t를 t≥0에만 사용한다. 다른 시간의 값은 0이다. 각 H(s)와 수렴 영역을 구하라.

  1. A는 ∫₋∞⁰e^((1−s)t)dt=1/(1−s)이며 Re(s)<1에 수렴한다.

  2. B는 −∫₀∞e^((1−s)t)dt=1/(1−s)이며 Re(s)>1에 수렴한다.

  3. A는 절대 면적 1로 안정하나 비인과다. B는 인과지만 절대 면적이 무한하여 불안정이다.

  4. s=j는 A의 영역에 포함되어 H_A(j)=(1+j)/2다. B에는 이 고유응답 적분이 수렴하지 않는다.

분수식 1/(1−s)만으로 시간 응답과 주파수응답 존재를 결정할 수 없다.

비교할 점

동일한 대수식에 수렴 영역을 붙여 서로 다른 시간 지지를 식별한다.

유한 지연 항에서의 영 고유값

y=x[n]+x[n−1]에 영원한 x=j^n과 x=(−1)^n을 넣는다. 고유배율을 구하라.

  1. z=j이면 1+1/j=1−j다.

  2. z=−1이면 1−1=0이다.

  3. 유한한 두 항만 더하므로 z≠0인 이 예제에는 무한합 수렴 제한이 없다.

배율은 각각 1−j와 0이다.

비교할 점

고유함수는 비영 함수이고 고유값은 0일 수 있다.

소단원 6.2

주파수응답

주파수마다 진동의 크기가 얼마나 달라지는지 하나의 함수로 표현할 수 있을까?

준비 개념과 학습 목표

준비 개념

  • 영원한 복소지수와 convolution

  • ω는 rad/s, H(jω)는 주파수별 복소 배율이다.

학습 목표

  • 주파수응답을 충격응답에서 구한다.

  • 크기·위상과 cascade/parallel 규칙을 유도한다.

두 경로의 진폭 크기를 더하면 전체 진폭이 될까요?

시간 상수 T=1 s인 저역 응답 L(jω)=1/(1+jωT)와 보완 경로 K(jω)=1−L(jω)를 병렬로 더합니다. ω=1/T에서는 L=(1−j)/2,K=(1+j)/2입니다. 각 크기는 1/√2지만 복소수 합은 1이므로 전체 크기는 1입니다.

보완 경로는 현재 입력에서 저역 출력만 빼는 함수입니다. 각각 따로 약해 보이는 두 경로를 함께 더하면 원래 입력을 복구합니다. 진폭과 위상을 함께 계산하고, 직렬의 곱과 병렬의 합을 구별합니다. 이 계산은 실제 필터 구현이나 오디오 재생 결과가 아닙니다.

먼저 확인할 개념
  • 복소 배율의 합과 곱

    병렬은 복소수를 더하며 개별 크기만 더하지 않습니다.

  • 직렬과 병렬의 응답

    연결 방식이 다르면 전체 연산도 다릅니다.

허수축에서의 응답

안정한 절대적분 가능 h 라면 H(jω)=∫h(t)e^(−jωt)dt 가 존재한다. 허수축의 영원한 진동에 대한 배율이며 h 의 Fourier 변환이기도 하다. H 자체는 시간 신호가 아니라 ω의 함수다.

자체 h=2e^(−2t)u(t)는 H=2/(2+jω). DC 인ω0 에서는 1, ω가 커지면 크기가 줄어든다. 여기서 저역통과란 높은 각주파수를 상대적으로 약하게 한다는 뜻이다.

직교형과 극형식을 함께 본다

분모에 켤레를 곱하면 H=(4−j2ω)/(4+ω²). 따라서 |H|=2/√(4+ω²), ω≥0 위상φ=−arctan(ω/2)다. H0 의 위상은 0 이며 음의 주파수는 실수 h 에서 켤레 대칭이다.

크기 1/√2 가 되는ω=2 에서 위상−π/4 다. 이는 진폭 기준이며 제곱한 비율은 1/2 다. 크기 감소와 주파수 변화를 혼동하지 않는다.

두 시스템을 연결하는 계산

위상−π/4 는 몇 초 지연이며 모든 주파수에 같은 지연일까?

준비 개념과 학습 목표

준비 개념

  • 복소수 크기와 위상

  • 각도는 라디안, 시간 지연은 x(t−τ)이다.

학습 목표

  • 위상 지연과 군지연을 구별한다.

  • 선형 위상과 주각의 감김을 해석한다.

모든 주파수의 진폭을 유지하면 모양도 그대로인가요?

실수 인과 응답 h(t)=−δ(t)+(2/T)e^(−t/T)u(t)는 A(jω)=(1−jωT)/(1+jωT)를 줍니다. T>0이고 |A|=1이지만 연속 위상은 φ=−2arctan(ωT)입니다. 이 위상은 모든 주파수에서 같은 시간 이동을 뜻하는 직선이 아닙니다.

ω>0에서 위상 지연은 2arctan(ωT)/ω이고 군지연은 2T/(1+(ωT)²)입니다. ω=1/T에서는 각각 πT/2와 T로 다릅니다. 여기서 군지연은 좁은 대역의 포락선 근사를 해석하는 값이며 임의 넓은 대역 신호가 이 한 값만큼 정확히 이동한다는 뜻이 아닙니다.

ω>0 에서 위상 지연 τp=−φ/ω다. 위상은 2π 차이에도 같은 진동이라 단일 진동만으로 전체 주기만큼의 지연을 구별하지 못한다. 주각/연속 위상 선택을 기록한다.

처음 켠 진동의 출력도 곧바로 정상 진폭과 위상을 따를까?

준비 개념과 학습 목표

준비 개념

  • convolution 과 지수 적분

  • 정상응답은 여기서 지속 입력의 진동 부분, 과도응답은 사라지는 추가 부분이다.

학습 목표

  • 실수 정현파의 정상응답을 계산한다.

  • 켜진 입력과 초기조건의 과도항을 분리한다.

진동을 끄는 순간 과도응답도 사라질까요?

T=1 s인 V→V 저역 응답 h(t)=(1/T)e^(−t/T)u(t)를 사용합니다. 입력 2 V cos(t/T)를 0에서 켜고 초기 전압을 0 V로 두면 y(t)=1 V[cos(t/T)+sin(t/T)−e^(−t/T)]입니다. 영원한 진동의 출력에는 없는 감쇠 항이 초기 상태를 맞춥니다.

입력을 πT에 끄면 그때의 출력 −(1+e^(−π)) V는 즉시 0이 되지 않습니다. 유한 입력 전환에서는 상태가 연속이고 이후에는 저장된 출력이 지수적으로 감쇠합니다. 같은 주파수응답도 입력의 시작·종료와 초기 상태를 함께 알아야 전체 시간의 출력을 계산할 수 있습니다.

양과 음의 주파수를 함께 합친다

cos(ωt)=(e^(jωt)+e^(−jωt))/2 다. 실수 h 라면 두 배율이 켤레라 합은 실수이며 크기/위상 정상식으로 돌아온다. 복소지수 한 개의 실수부를 구하는 방법도 같다.

자체 H=2/(2+jω)에서 x=2cos(2t)는 y 정상=√2cos(2t−π/4)=cos2t+sin2t 다. cos 덧셈식으로 부호와 계수를 확인한다.

켜진 입력을 직접 적분한다

입력 x=2cos(2t)u(t),영초기상태이면 t≥0 에서 y=∫0t2e^(−2τ)·2cos(2(t−τ))dτ다. 복소수로 4e^(j2t)∫0t e^(−(2+j2)τ)dτ의 실수부를 구한다.

결과 y=cos2t+sin2t−e^(−2t)다. t0 에서 1+0−1=0 으로 초기 상태와 맞고, 오랫동안 지속하면 추가항이 0 으로 가며 정상 진동만 남는다. 시작부터 정상식을 쓰면 t0 에서 1 이라는 잘못된 값이다.
