소단원 2.1

선형성과 중첩

두 소리를 따로 처리해 더한 값은 두 소리를 먼저 더해 처리한 값과 언제 같을까?

준비 개념과 학습 목표

준비 개념

  • 이 단원 기본 신호는 모든 정수 n∈ℤ에서 정의된 실수열 x[n]이다. 합과 상수배는 같은 n에서 계산한다. δ[n]은 n=0에서1, 나머지에서0인 이산 임펄스다.

  • 시스템 T는 허용 입력 신호 하나를 출력 신호 하나로 보내는 함수다. T{x}[n]은 T를 전체 신호에 적용한 뒤 n번째 값을 읽는 표기다.

  • 선형성 검사의 입력 공간은 실수 벡터공간이며 합과 모든 실수 상수배에 닫혀 있어야 한다. 초기 상태나 정의역이 다른 두 실험을 하나의 T로 섞지 않는다.

학습 목표

  • 중첩 등식을 모든 입력·상수의 조건으로 읽는다.

  • 합과 상수배를 연산자 식으로 증명하거나 반례로 부정한다.

  • 선형·아핀·비선형 및 고정 초기 상태의 차이를 설명한다.

작은 입력에서 중첩이 맞으면 포화한 입력에서도 맞을까요?

이 단원에서는 무차원 실수 신호를 사용합니다. 전체 실수열에서 L{x}[n]=3x[n]−2x[n−1]은 선형이지만 F{x}[n]=L{x}[n]+4는 고정 오프셋이 있는 아핀 함수입니다. 또 C{x}[n]=clip(2x[n],−3,3)에서 clip은 −3보다 작으면 −3, 3보다 크면 3으로 제한하는 수학 규칙입니다. 실제 증폭기의 포화 범위를 측정한 모형은 아닙니다.

선형성은 모든 허용 입력과 모든 실수 상수의 중첩을 요구합니다. 작은 입력 두 개에서 C의 출력이 맞았어도 큰 입력의 반례 하나면 전체 선형성은 깨집니다. 초기 상태를 고정한 재귀식과 상태까지 입력으로 바꾸는 재귀식도 서로 다른 함수로 검사합니다.

먼저 확인할 개념
  • 중첩의 모든 입력 조건

    가산성과 동차성을 별 조건으로 검사합니다.

  • 유계 출력과 선형성의 구별

    포화한 비선형 함수도 유계 출력을 줄 수 있습니다.

두 입력과 두 상수를 한 번에 비교하기

T가 선형이라는 정의는 모든 허용 x₁,x₂와 실수 α,β에 대해 T{αx₁+βx₂}=αT{x₁}+βT{x₂}가 모든 n에서 성립한다는 것이다. 가산성과 동차성을 함께 요구한다. 특정 두 신호에서 같다는 관찰은 전체 정의를 증명하지 못하지만 다른 한 사례는 선형성 반례가 된다.

T{x}[n]=2x[n]−x[n−1]에는 같은 자리의 합·상수배를 전개할 수 있다. 2(αx₁[n]+βx₂[n])−(αx₁[n−1]+βx₂[n−1])는 α와β로 묶으면 두 출력의 결합과 같다. 이 항등식은 모든 실수열에서 성립하며 물리 증폭기의 포화·잡음·초기 상태를 실험한 결과는 아니다.

직선 모양과 선형성은 다르다

T{x}[n]=2x[n]+1은 입력 0에도 출력 1을 내므로 선형이 아니다. 상수 오프셋이 있는 아핀 시스템이다. 선형 T는 T{0}=T{0·x}=0을 만족해야 한다. 그러나 T{0}=0만 확인하는 것은 충분하지 않다. 제곱 T{x}[n]=x[n]²도0을0으로 보내지만 2배 입력을 4배 출력으로 보낸다.

시간마다 정해진 계수 a[n]을 곱하는 T{x}[n]=a[n]x[n]은 a가 변해도 선형이다. 따라서 선형성은 시간이 변하지 않는다는 말과 다르다. 또 물리량의 단위가 있는 입력들을 더하려면 같은 종류·단위를 맞추며, 임의로 볼트와 온도를 같은 스칼라로 더하는 모델을 실험 의미로 해석하지 않는다.

초기 상태를 계약에 포함하기

차분식 y[n]=y[n−1]+x[n], n≥0만 적으면 y[−1]을 정하지 않은 채 출력 하나가 결정되지 않는다. 초기 0을 고정하면 y[n]=Σ(k=0..n)x[k]로 입력에 대해 선형이다. 초기 c≠0을 고정하면 y[n]=c+Σx[k]가 되어 입력 0의 출력 c 때문에 선형이 아니다.

초기 상태를 입력 좌표의 일부로 포함해 (x,c)를 함께 상수배하면 다른 확장 모형에서 선형성을 말할 수 있다. 이 경우는 고정 c 시스템과 다른 계약이다. 이후 중첩과 시불변성을 논할 때 시간 영역·허용 신호·초기 조건이 무엇인지 먼저 확인한다.

중간 과정을 따라가는 예제

양방향 신호 x₁=δ[n], x₂=δ[n−1], α=2,β=−1에 T{x}[n]=2x[n]−x[n−1]를 적용해 중첩을 확인하라.

  1. 결합 입력 x=2δ[n]−δ[n−1]는 n=0,1,2에서 각각 2,−1,0이고 그 밖은0이다.

  2. T{x₁}의 n=0,1,2 값은 2,−1,0이며 T{x₂}는 0,2,−1이다.

  3. 결합 출력 2T{x₁}−T{x₂}는 n=0,1,2에서 4,−4,1이다.

  4. 직접 T{x}도 n=0:4−0=4, n=1:−2−2=−4, n=2:0−(−1)=1이고 나머지 0이다. 이 사례의 일치와 앞의 일반 전개 증명을 구별한다.

T{2x₁−x₂}=2T{x₁}−T{x₂}이며 출력의 비영 값은 (4,−4,1)이다.

조건을 바꾸어 비교하기

오프셋을 빼면 어떤 함수를 검사하는가

F{x}=L{x}+4에서 입력 0과 입력 합의 출력을 비교하고 G{x}=F{x}−F{0}를 구하라.

  1. F{0}=4이므로 F는 선형이 아니다.

  2. F{x₁+x₂}=L{x₁}+L{x₂}+4이지만 F{x₁}+F{x₂}=L{x₁}+L{x₂}+8이다.

  3. G{x}=L{x}+4−4=L{x}로 새 함수 G는 선형이다.

F는 아핀이며 오프셋 제거 뒤의 G는 선형이다.

비교할 점

G가 선형이라는 사실로 원 함수 F의 성질을 바꾸어 적지 않는다.

고정 초기 상태와 입력 좌표

n≥0에서 y[n]=0.5y[n−1]+x[n], y[−1]=4를 고정한다. 영 입력 출력과 초기 0의 차이를 구하라.

  1. 영 입력에서는 y[0]=2, y[1]=1, y[2]=0.5이다.

  2. 자유 응답은 4(0.5)^(n+1)이다. 이를 빼면 z[n]=Σ_{k=0}^n(0.5)^(n−k)x[k]이다.

  3. 고정 초기 4의 입력 함수는 아핀이고, 초기 0의 함수 또는 (x,c) 모두를 입력으로 삼는 확장 함수는 선형이다.

고정 c=4의 영 출력은 0이 아니므로 선형이 아니다.

비교할 점

초기 상태를 더하거나 배수로 만드는 것은 고정 상태 계약을 바꾸는 일이다.

종이와 본문으로 직접 해보기

제곱 시스템에서 x₁=x₂=δ[n], α=β=1의 양변을 비교하라. 별도로 초기 c=3 누산기에0 입력을 넣어 선형성 필요조건을 검사하라.

힌트 보기

제곱은 먼저 합하면2²이고 따로 제곱하면1²+1²다. 초기 상태는 고정한다.

풀이 보기

n=0에서 제곱 결합 출력 4와 출력 합 2가 달라 비선형이다. 초기 3 누산기는 입력 0에도 모든 n≥0에서 3을 내므로 고정 초기 상태의 입력-출력 함수는 비선형 아핀이다. 둘 다 종이 반례다.

오해와 반례

T가0을0으로 보내면 선형이며, 그래프가 직선이면 항상 선형이다.

제곱은0을0으로 보내도 중첩4≠2다. 2x+1은 직선이지만0 입력의 출력 1이다. 선형성의 모든 입력·상수 조건을 만족해야 한다.

연습 1 · 값과 상태 예측

힌트 1

힌트 2

소단원 2.2

시불변성

입력 시작을 두 칸 늦추면 출력도 똑같이 두 칸 늦춰질까?

준비 개념과 학습 목표

준비 개념

  • 양방향 신호의 정수 k만큼 지연은 S_kx[n]=x[n−k]다. k>0이면 오른쪽으로 이동하며 입력 n=0의 값이 n=k에서 나타난다.

  • 시불변성은 시간 이동과 시스템 처리가 교환되는 성질 T S_k=S_k T다. 입력을 이동한 출력과 원출력을 이동한 값을 비교한다.

  • 이 정의에는 허용 입력 공간이 정수 이동에 닫혀 있다는 전제가 있다. 고정 시작 시각·유한 창·경계 처리 규칙이 있으면 이동 계약을 별도로 정한다.

학습 목표

  • 두 처리 순서의 지표를 정확히 대입한다.

  • 시불변성과 선형성을 독립적으로 판정한다.

  • 초기화·유한 경계·물리 지연과 신호 이동을 구별한다.

두 칸 이동은 통과하고 한 칸 이동은 실패할 수 있을까요?

전체 양방향 실수열에서 a[n]은 짝수 위치에 2, 홀수 위치에 −1이라고 정하고 T_a{x}[n]=a[n]x[n]로 둡니다. 입력은 S_kx[n]=x[n−k]로 이동합니다. 계수도 옮기는 것은 원 출력 전체를 이동하는 경로에서만 일어납니다.

T_a가 두 칸 이동과 교환해도 시불변이라는 결론은 아직 아닙니다. 시불변성은 모든 정수 이동을 요구합니다. 또 W{x}[n]을 n=0,1,2에서 x[n], 나머지에서 0으로 정의하면 고정 관찰 창 자체가 시간 기준을 만듭니다. 이 창을 입력과 함께 옮기면 원래 W와 다른 함수가 됩니다.

먼저 확인할 개념
  • 시불변성의 두 경로

    입력만 이동한 식과 출력 전체를 이동한 식을 비교합니다.

  • 선형성의 독립 검사

    입력과 독립인 시간 계수는 선형성을 보존합니다.

같은 시간 눈금을 함께 옮기기

T가 시불변이면 모든 허용 x와 정수 k에 대해 T{S_kx}[n]=(T{x})[n−k]가 모든 n에서 같다. 시스템 내부 식의 입력만 먼저 이동하고, 다른 쪽에서는 출력 전체 식의 n을 n−k로 바꾼다. 한쪽의 명시적인 시간 계수를 그대로 남겨 놓고 두 식을 같다고 판단하면 안 된다.

고정 두 표본 평균 T{x}[n]=(x[n]+x[n−1])/2에서 입력 이동 출력은 (x[n−k]+x[n−1−k])/2다. 출력 이동 식도 동일하다. 지연 k의 단위는 표본 칸이며 물리 시간으로 환산하려면 표본 간격 Δt를 따로 정한다. 계산 장치의 명령 처리 시간이나 마감 지연을 이 식으로 측정한 것이 아니다.

시간 계수가 있는 반례

T{x}[n]=n x[n]에서 이동 입력 출력은 n x[n−k]지만 원출력 이동은 (n−k)x[n−k]다. 예를 들어 x[n]=1, k=1,n=2면2와1로 달라 시변이다. 이 시스템은 앞에서 본 것처럼 선형이므로 선형이면 시불변이라는 추론은 틀린다.

반대로 T{x}[n]=x[n]²는 입력 이동과 출력 이동 모두 x[n−k]²여서 시불변이다. 중첩은 실패해 비선형이다. 선형과 시불변을 모두 만족할 때만 LTI라고 부르며 하나씩 검사한다. 계수가 고정이라고 모든 다른 성질이 자동으로 따라오는 것도 아니다.

입력 영역과 시작 규칙의 영향

y[n]=Σ(j=0..n)x[j], n≥0라는 고정 시작 누산기는 같은 양방향 누산 식 Σ(j=−∞..n)x[j]와 다르다. 후자는 수렴하는 입력 영역을 지정해야 한다. 시작점0을 포함한 전자를 모든 정수 이동에 닫힌 시스템으로 취급하면 정의역과 초기 조건을 빠뜨린다.

유한 영상이나 기록을 이동할 때 밖을0으로 채울지 순환시킬지에 따라 결과가 달라진다. 무한 격자의 고정 필터는 시불변이어도 유한 창의 잘라내기와 새 경계 생성은 이동과 교환되지 않을 수 있다. 같은 규칙을 양쪽 경로에서 사용했는지 확인하며 장치의 시간 안정성이나 재현성이라는 다른 뜻과 구별한다.

소단원 2.3

인과·기억·가역성

지연된 기록을 되찾을 수 있다는 말은 미래 입력 없이 실시간으로 복구할 수 있다는 말일까?

준비 개념과 학습 목표

준비 개념

  • 양방향 실수열의 현재 n, 과거 j<n, 미래 j>n을 구별한다. 전체 신호를 미리 아는 오프라인 계산과 현재까지 받은 입력만 쓰는 계산은 다르다.

  • 무기억은 출력 n이 입력의 같은 시각 값만으로 결정됨, 인과는 현재까지 같은 두 입력이 현재 출력도 같게 함, 가역은 출력으로 허용 입력을 유일하게 복원할 수 있음이다.

  • 가역성은 입력 공간에서 단사인지 검사한다. 역함수는 출력의 실제 치역에 정의되며 인과·안정·효율적인 구현이라는 요구는 따로 확인한다.

학습 목표

  • 인과·기억·가역을 각각 정의하고 반례를 만든다.

  • 같은 출력이 나오는 서로 다른 입력으로 비가역성을 보인다.

  • 역함수의 정의역과 실시간 구현 제한을 설명한다.

같은 필터도 허용 입력 공간에 따라 가역성 결론이 달라질까요?

이 소단원에서 T{x}[n]=x[n]+0.5x[n−1]를 전체 양방향 실수열에 정의합니다. 인과이며 과거 한 항을 쓰므로 기억이 있습니다. 그러나 전체 실수열에는 x[n]=(−0.5)^n이라는 비영 신호가 있고 T{x}=0입니다. 음의 인덱스 쪽으로 값이 무한히 커져도 이 첫 입력 집합에서는 허용합니다.

허용 입력을 유계 양방향 실수열로 제한하면 같은 비영 커널 신호는 제외됩니다. 이때 역은 x[n]=Σ_{k=0}^∞(−0.5)^k y[n−k]이고 절대 수렴합니다. 전체 기록의 입력 공간 제한과 유한 기록에서 초기 값 하나를 추가하는 일은 구별합니다. 수학 역을 구했지만 실제 복원 장치나 새 필터 프로그램은 실행하지 않았습니다.

먼저 확인할 개념
  • 단사성과 역의 정의역

    허용 입력과 출력의 실제 치역을 명시합니다.

  • 유계 입력과 무한합

    역의 기하급수 상계를 이용해 수렴을 보입니다.

현재만 쓰는가, 현재까지 쓰는가

무기억 T에서는 x₁[n₀]=x₂[n₀]이면 T{x₁}[n₀]=T{x₂}[n₀]다. 인과 T에서는 모든 j≤n₀의 두 입력이 같을 때 현재 출력도 같아야 한다. 따라서 무기억 시스템은 인과이지만 인과 시스템은 과거를 사용할 수 있어 반드시 무기억은 아니다.

지연 D{x}[n]=x[n−1]은 과거를 쓰므로 기억이 있지만 인과다. 앞당김 A{x}[n]=x[n+1]은 미래를 읽어 일반 양방향 입력 공간에서 비인과다. 인과성을 깨려면 현재까지는 같고 미래 한 항만 다른 두 입력을 골라 현재 출력이 달라짐을 보이면 된다. 여기서 기억은 신호 의존성이며 프로그램이 쓰는 RAM 바이트 수와 같지 않다.

서로 다른 입력을 구별할 수 있는가

가역성의 핵심은 T{x₁}=T{x₂}가 전체 출력에서 같으면 x₁=x₂여야 한다는 단사성이다. 지연 D의 역은 D⁻¹{y}[n]=y[n+1]이며 전체 양방향 기록이 있으면 복원된다. 그러나 이 역은 미래 출력값을 요구해 인과적이지 않다. 원래 시스템의 인과성과 역의 인과성은 별 성질이다.

제곱 T{x}[n]=x[n]²는 x≡1과 x≡−1이 같은 출력 1이므로 전체 실수열에서 비가역이다. 허용 입력을 모든 위치에서 비음수인 열로 제한하면 음수가 아닌 제곱근으로 복원되어 가역이다. 이 제한 공간은 실수 상수배에 닫힌 벡터공간이 아니므로 앞 선형성 정의와 혼동하지 않는다.

초기 정보와 경계가 바꾸는 복원

이산 차분 y[n]=x[n]−x[n−1]은 양방향 공간에서 상수열이 모두 0으로 가므로 비가역이다. 기준 x[−1]을 알려 주고 n≥0 출력들을 받으면 x[n]=y[n]+x[n−1]로 순서대로 복원할 수 있다. 알려진 초기 값은 계약에 더한 정보이지 원래 단사성을 얻은 것은 아니다.

유한 기록에서 끝 지연 값이 잘려 나가면 원래 마지막 입력이 출력 창에 나타나지 않을 수 있다. 길이가 같은 잘라낸 출력과 전체 무한 기록의 가역성은 다르다. 실제 복원에서는 잡음·반올림·허용 신호 범위·미래 자료 도착도 검토하며 수학 역함수의 존재를 장치 복원 검증으로 표시하지 않는다.

소단원 2.4

BIBO 안정성의 정의

입력이 어느 순간에도 작으면 출력도 언제까지나 어떤 한계 안에 남을까?

준비 개념과 학습 목표

준비 개념

  • 신호의 유계성은 어떤 유한 M이 있어 모든 시간의 |x[n]|≤M인 것이다. 몇 표본만 작거나 각 항이 개별적으로 유한하다는 것보다 강한 조건이다.

  • BIBO는 bounded-input bounded-output이다. 허용되는 모든 유계 입력마다 전체 시간에서 유계 출력이 나와야 한다. 하나의 반례 입력으로 부정할 수 있다.

  • 이산 시간에서 ||x||∞=sup_n|x[n]|다. 본문 기본은 양방향 신호이며 고정 시작 누산기 반례는 별도로 n≥0·y[−1]=0을 둔다. 선형성·인과·에너지 유한과 BIBO를 구별한다.

학습 목표

  • BIBO의 전체 시간·모든 유계 입력 조건을 설명한다.

  • 부등식으로 출력 상계를 증명하고 누산기 반례를 만든다.

  • 선형 gain 상계와 비선형 유계성 및 LTI 조건을 구별한다.

임펄스 출력이 작게 남으면 모든 작은 입력도 작게 남을까요?

전체 양방향 열의 유한 필터 H{x}[n]=4x[n]−3x[n−1]+2x[n−2]는 |x[n]|≤M에서 출력 절댓값 ≤9M입니다. 세 계수의 합 3이 아니라 절댓값 합 9가 모든 입력의 상계입니다. 상수 입력에는 일부 상쇄가 있어 최악 입력을 대표하지 못합니다.

별도로 n≥0, y[−1]=0, n<0 입력은 0인 재귀식 y[n]=ρy[n−1]+x[n]을 검사합니다. ρ=−0.8에서는 기하급수 상계가 5M입니다. ρ=−1에서는 임펄스 응답이 ±1로 유계여도 교대 입력이 항마다 같은 방향으로 누적되어 BIBO를 깨뜨립니다. 실제 장치 안정성이나 무한 시간 실행 증거와는 구별합니다.

n x[n]은 선형·인과·무기억이지만 x≡1에 출력 n이어서 BIBO 불안정이다. 반대로 앞당김 y[n]=x[n+1]은 비인과지만 유계 상계 M을 그대로 보존해 BIBO 안정이다. 따라서 안정이 곧 인과·선형·기억 없음이라는 분류는 틀린다. 상태가 초기점으로 돌아가는 내부 안정성이나 물리 장치의 안전성도 별 개념이다.

H의 계수 합 4−3+2=3에서 |y|≤3M라고 모든 입력 상계를 적었다. 고쳐라.
