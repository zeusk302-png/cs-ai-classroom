소단원 10.1

수렴영역

같은 1/(s+2)가 서로 다른 시간 신호를 가리킬 수 있을까?

준비 개념과 학습 목표

준비 개념

  • 복소수 s=σ+jω

  • 지수함수의 적분

  • 단위계단 u(t)

학습 목표

  • 양방향 Laplace 적분을 정의한다.

  • 유리식과 수렴영역을 함께 기록한다.

  • 경계에서 발산하는 이유를 확인한다.

지수 가중으로 양쪽 시간을 적분한다

양방향 변환은 X(s)=∫₋∞^∞ x(t)e^(−st)dt다. s=σ+jω에서 크기를 바꾸는 부분은 e^(−σt)다. 여기서는 이 가중 신호의 절댓값 적분이 유한한 열린 영역을 ROC, 즉 수렴영역으로 사용한다. 시간 t의 단위가 s(초)이면 복소 변수 s는 역초 단위를 가지므로 기호가 같다고 혼동하지 말자.

수렴한 곳에서 얻은 유리식을 다른 s에 대입할 수 있다고 해서 원래 적분도 그곳에서 수렴하는 것은 아니다. 변환 정보는 식과 ROC의 묶음이다. 유리 변환의 극점은 ROC 안에 들어갈 수 없다. 일반 신호의 경계 수렴은 별도 문제이며 이 단원은 지수함수로 된 유리 변환을 다룬다.

같은 식을 만드는 오른쪽과 왼쪽 신호

xR(t)=e^(−2t)u(t)는 t≥0에서만 존재한다. 적분은 ∫₀^∞ e^(−(s+2)t)dt이므로 Re(s)>−2에서 1/(s+2)다. xL(t)=−e^(−2t)u(−t)는 음의 시간에 존재하며 ∫₋∞^0 −e^(−(s+2)t)dt=1/(s+2), Re(s)<−2다.

계산 결과의 식은 같지만 시간 방향과 ROC는 반대다. 왼쪽 신호는 t→−∞에서 크기가 커지므로 σ<−2라는 가중이 필요하다. σ=−2에서는 절댓값이 일정해서 무한 구간 적분이 발산한다. u(0)의 한 점 값은 이 보통 함수 적분의 결과를 바꾸지 않는다.

ROC를 그림에 표시한다

s평면의 가로축을 σ, 세로축을 ω로 그린다. −2에 극점을 표시하고 xR이면 그 오른쪽, xL이면 그 왼쪽 반평면을 칠한다. 다른 단순 극점이 여러 개면 오른쪽·왼쪽 성분의 조건을 교차해 띠 모양 ROC가 생길 수도 있다.

σ=0인 허수축이 ROC 안에 있으면 이 절대수렴 정의에서 일반 Fourier 적분이 존재한다. xR의 ROC에는 허수축이 들어가고 xL에는 들어가지 않는다. Fourier의 분포 해석까지 모두 이 검사로 판정한다고 확장하지 않는다.

중간 과정을 따라가는 예제

xR=e^(−2t)u(t), xL=−e^(−2t)u(−t)의 변환과 ROC를 계산하고 s=0에서 원래 절댓값 적분을 비교하라.

  1. xR의 지수 계수는 −(s+2)다. 양의 무한대로 감쇠하려면 σ+2>0이고 X=1/(s+2)다.

  2. xL은 음의 무한대에서 감쇠해야 한다. σ+2<0이면 적분 경계항이 0이고 X=1/(s+2)다.

  3. s=0에서 xR의 절댓값 적분은 ∫₀^∞ e^(−2t)dt=1/2다.

  4. xL의 ∫₋∞^0 e^(−2t)dt는 발산한다. 유리식의 값 1/2를 이 발산 적분의 값이라고 부를 수 없다.

유리식은 모두 1/(s+2)지만 ROC는 σ>−2와 σ<−2다. s=0의 적분은 오른쪽 신호만 수렴한다.

종이와 본문으로 직접 해보기

분모를 s−2로 바꿔 xR=e^(2t)u(t), xL=−e^(2t)u(−t)를 계산하자. 어느 신호의 ROC가 허수축을 포함하는가?

힌트 보기

양의 시간과 음의 시간의 감쇠 조건을 따로 적는다.

풀이 보기

변환은 1/(s−2)다. xR은 σ>2로 허수축을 제외하고 xL은 σ<2로 허수축을 포함한다. xL의 절댓값 적분은 ∫₋∞^0 e^(2t)dt=1/2다.

오해와 반례

유리식이 유한한 s라면 원래 Laplace 적분도 반드시 수렴한다.

적분의 수렴 조건은 별도로 붙여야 한다. 같은 유리식의 서로 다른 ROC는 서로 다른 신호를 뜻한다.

극점 −2가 ROC에 포함되는가?

답과 이유 보기

아니다.

예제에서 경계의 절댓값 적분이 발산한다.

u(0)의 선택이 이 적분을 바꾸는가?

답과 이유 보기

바꾸지 않는다.

보통 함수의 한 점은 적분값을 바꾸지 않는다.

한 단계 더

0≤t≤1에서만 1이고 나머지에서 0인 신호는 모든 유한 s에서 ∫₀¹ e^(−st)dt가 유한하다. s≠0에서는 (1−e^(−s))/s이며 s=0에서는 직접 적분해 1이다. 겉보기 분모 0과 실제 극점을 구별하자.

소단원 10.2

극점·영점·역변환

극점 그림만 보면 응답의 크기와 시간 방향까지 알 수 있을까?

준비 개념과 학습 목표

준비 개념

  • 다항식의 근

  • 부분분수

  • 양방향 ROC

학습 목표

  • 소거한 유리식에서 극점과 영점을 구한다.

  • 부분분수 계수를 계산한다.

  • ROC에 맞춰 각 항의 시간 방향을 정한다.

극점과 영점은 약분 뒤의 근이다

유리식 H(s)=N(s)/D(s)에서 공통 인자를 소거한 뒤 D의 근이 극점, N의 근이 영점이다. 극점 그림만으로 전체 상수 배율은 결정되지 않는다. 같은 극점·영점에 H와 2H는 같은 그림을 가지지만 출력 크기는 다르다.

여기서는 분자 차수가 분모보다 작은 엄밀히 proper 유리식을 다룬다. 이런 예제의 역변환은 보통 지수함수 항으로 표현할 수 있다. 분자 차수가 같으면 상수항에 대응하는 δ(t) 등도 살펴야 하므로 단순 지수 합만으로 처리하지 않는다.

부분분수는 근이 가리키는 지수로 나누는 과정이다

서로 다른 실수 단순 극점 a,b에 대해 H=A/(s−a)+B/(s−b)로 놓는다. 분모를 곱한 다항식의 계수를 비교하거나 s=a,b를 넣어 A,B를 구한다. 구한 계수를 원래 분자로 다시 합쳐 검산한다.

A/(s−a)의 ROC가 σ>a라면 A e^(at)u(t), σ<a라면 −A e^(at)u(−t)다. 반복 극점은 t e^(at) 같은 항이 필요하다. 표를 적용할 때 분모와 계수만 보지 말고 해당 ROC를 함께 확인한다.

하나의 ROC가 각 항의 방향을 제한한다

아래 H의 극점은 −1과 −3이다. 전체 ROC를 σ>−1로 정하면 두 항 모두 오른쪽 신호다. −3<σ<−1이면 −1 항은 왼쪽, −3 항은 오른쪽이어야 두 조건의 교집합이 그 띠가 된다.

공통 인자의 약분은 외부 입출력 전달함수의 표현을 줄인다. 실제 상태를 가진 구현에서 숨겨진 모드의 안정성까지 약분 하나로 보장하지 않는다. 이 구별은 다음 소단원에서 초기 상태를 가진 자체 예제로 확인한다.

중간 과정을 따라가는 예제

H(s)=(s+4)/((s+1)(s+3)), ROC σ>−1이다. 극점·영점·부분분수와 h(t)를 구하라.

  1. 공통 인자는 없다. 극점은 −1,−3이고 영점은 −4다.

  2. s+4=A(s+3)+B(s+1)이다. s=−1에서 3=2A이므로 A=3/2다. s=−3에서 1=−2B이므로 B=−1/2다.

  3. (3/2)(s+3)−(1/2)(s+1)=s+4로 복원된다.

  4. ROC는 두 극점 오른쪽이므로 h(t)=[(3/2)e^(−t)−(1/2)e^(−3t)]u(t)다.

  5. h의 적분은 3/2−1/6=4/3이며 H(0)=4/(1·3)과 일치한다. 이 h는 t≥0에서 양수다.

극점 −1,−3, 영점 −4; A=3/2, B=−1/2이며 오른쪽 지수 합이다. 배율과 ROC도 함께 기록한다.

종이와 본문으로 직접 해보기

같은 H의 ROC를 −3<σ<−1 또는 σ<−3으로 정하면 h(t)는 어떻게 바뀌는가? 2H의 영점·극점·h는?

힌트 보기

각 부분분수 항마다 왼쪽이면 마이너스가 하나 더 붙는다.

풀이 보기

띠 ROC에서는 h=−(3/2)e^(−t)u(−t)−(1/2)e^(−3t)u(t)다. 왼쪽 ROC에서는 h=−(3/2)e^(−t)u(−t)+(1/2)e^(−3t)u(−t)다. 2H의 극점·영점·ROC는 같고 h만 2배다.

오해와 반례

극점·영점만 같으면 신호의 크기와 시간 방향도 같다.

상수 배율은 그림에 따로 주어야 하고 시간 방향은 ROC로 구분한다. 같은 유리식에 다른 ROC가 가능하다.

한 단계 더

소단원 10.3

인과성과 안정성

미래 입력을 사용하지 않는 시스템이라면 출력이 반드시 유계일까?

준비 개념과 학습 목표

준비 개념

  • LTI와 임펄스 응답

  • 절댓값 적분

  • ROC와 허수축

학습 목표

  • 인과성과 BIBO 안정성을 구별한다.

  • 유리 전달함수의 ROC를 함께 검사한다.

  • 외부 안정성과 숨겨진 상태를 구별한다.

인과성은 시간 순서에 대한 조건이다

연속 시간 LTI에서 y(t)=∫ h(τ)x(t−τ)dτ다. h가 음의 τ에서 0이면 출력은 현재와 과거 입력만 사용한다. 이것이 여기서의 인과성이다. h가 음의 τ에서도 존재하면 x(t−τ)는 미래 입력이 될 수 있다.

엄밀히 proper 유리 전달함수의 인과적인 지수 응답은 ROC가 가장 오른쪽 극점보다 오른쪽이다. ROC 선택 없이 분모만 보고 인과적이라고 부르지 않는다. 실제 장치에서 미래 값을 그대로 요구하는 응답은 실시간 구현 조건과 맞지 않는다.

BIBO는 유계 입력마다 유계 출력을 요구한다

일반적인 보통 함수 h의 LTI 컨볼루션에서 ∫|h(t)|dt가 유한하면 |x(t)|≤M인 입력에 대해 |y(t)|≤M∫|h|다. 이 설정에서 절대 적분 가능성은 BIBO 안정성의 기준이다. 예를 들어 h=e^(−2t)u(t)는 적분이 1/2이므로 모든 유계 입력에 출력 상한 M/2를 준다.

유리 전달함수의 지수 응답에서 허수축이 ROC 안에 들어가야 BIBO 안정이다. 따라서 인과성까지 요구하면 약분된 모든 극점의 실수부가 엄격히 음수여야 한다. 순수 허수축 극점은 이 조건을 만족하지 않는다. h=u(t)인 적분기는 유계 단위계단 입력에 t u(t)를 출력해 불안정하다.

안정한 외부 응답과 내부 상태는 다를 수 있다

비인과적인 ROC로 오른쪽 반평면 극점을 포함하는 유리식을 BIBO 안정하게 만들 수도 있다. 아래 예제는 이를 수학적으로 비교한다. 이것을 미래 정보 없이 실시간 구현할 수 있다고 해석하지 않는다.

외부 전달함수는 초기 상태 0의 입출력 관계를 나타낸다. 자체 모델 z1′=z1, z2′=−2z2+x, y=z2는 외부 H=1/(s+2)지만 z1(0)=1이면 z1=e^t다. 관측되지 않는 내부 상태가 자라므로 이 H의 BIBO 안정성만으로 모든 내부 상태의 안정성을 주장할 수 없다.

중간 과정을 따라가는 예제

H(s)=1/((s−1)(s+2))이다. 인과적인 ROC σ>1과 띠 ROC −2<σ<1의 h 및 BIBO 안정성을 비교하라.

  1. 부분분수는 (1/3)/(s−1)−(1/3)/(s+2)다. 분자 (s+2−s+1)/3=1로 검산한다.

  2. σ>1이면 h=(e^t−e^(−2t))u(t)/3다. 인과적이지만 양의 시간에 성장해서 절댓값 적분이 발산한다.

  3. −2<σ<1이면 h=−e^t u(−t)/3−e^(−2t)u(t)/3다. 음의 시간에도 존재해 비인과적이다.

  4. 띠 응답의 절댓값 적분은 (1/3)∫₋∞^0 e^t dt+(1/3)∫₀^∞ e^(−2t)dt=1/3+1/6=1/2다.

  5. 띠는 허수축 σ=0을 포함하고 인과 ROC는 제외한다. 직접 적분 결과와 일치한다.

인과적인 선택은 BIBO 불안정이고 띠 선택은 비인과적이지만 BIBO 안정이다. 유리식에 ROC를 붙여 판단한다.

종이와 본문으로 직접 해보기

H=1/(s+2)의 ROC를 σ>−2와 σ<−2로 각각 선택하자. 인과성·허수축 포함·절댓값 적분을 비교하라. H=1/s의 인과 응답은 왜 불안정한가?

힌트 보기

왼쪽 응답은 음의 시간 무한대에서 커지는지 검사한다.

풀이 보기

오른쪽 e^(−2t)u(t)는 인과적이며 허수축을 포함하고 적분 1/2로 안정이다. 왼쪽 −e^(−2t)u(−t)는 비인과적이며 허수축을 제외하고 적분이 발산한다. 1/s의 인과 응답 u(t)는 단위계단을 적분해 끝없이 증가하는 출력을 만든다.

오해와 반례

인과적이면 안정하고 안정한 전달함수이면 모든 내부 상태도 안정하다.

인과성은 미래 입력 사용 여부이며 BIBO는 유계 입출력 조건이다. 초기 상태 0의 외부 H와 전체 내부 모드의 안정성도 구별한다.

소단원 10.4

미분방정식 해석

전달함수에 입력만 곱하면 저장된 초기 상태의 영향도 포함될까?

준비 개념과 학습 목표

준비 개념

  • 일차 선형 미분방정식

  • 단방향 변환

  • 부분분수와 초기값

학습 목표

  • 초기 상태 항을 유지해 변환한다.

  • 영입력 응답과 영상태 응답을 더한다.

  • 시간 해를 원래 방정식에 대입한다.

초기값 문제에서는 단방향을 명시한다

여기서는 t=0의 충격을 포함하는 0−부터의 단방향 변환을 사용한다. Y(s)=∫₀₋^∞ y(t)e^(−st)dt이며 일반화된 미분의 변환은 sY(s)−y(0−)다. 원점의 충격과 초기값을 다룰 때 0−와 0+를 섞지 않는다.

아래 입력은 보통 단위계단이며 미분방정식 우변에 원점 충격이 없다. 일차 상태 y는 연속이므로 y(0−)=y(0+)=3으로 설정한다. 과거에 어떻게 이 상태를 만들었는지는 계산에 필요한 초기 정보로 요약한다. 만약 원점에 충격이 있으면 상태 점프를 별도로 계산해야 한다.

전달함수는 초기 상태 0의 입출력 관계다

y′+2y=x를 변환하면 (s+2)Y=X+y(0−)다. 따라서 Y=H X+y(0−)/(s+2), H=1/(s+2)다. HX는 초기 상태 0의 영상태 응답이고 나머지는 입력 0에서 초기 상태가 만드는 영입력 응답이다.

초기 상태가 고정되어 있으면 총 출력은 입력만의 선형 전달함수 관계와 다르다. X=0이어도 출력이 있을 수 있기 때문이다. 미분방정식 계수로 H를 얻는 과정에서 초기항을 0으로 둔 조건을 반드시 기록한다.

역변환 뒤에는 초기값과 방정식을 다시 검사한다

입력이 t≥0에서 1이면 X=1/s다. Y를 부분분수로 나누어 시간 해를 얻는다. y(0+)가 초기값과 같은지, t>0의 y′+2y가 1인지 검사하면 초기항을 빼먹은 오류를 잡을 수 있다.

정상상태 값만 맞아도 과도응답은 틀릴 수 있다. y(0)=3인 문제에서 초기 상태 0으로 푼 .5(1−e^(−2t))는 끝값 .5는 같지만 시작값이 0이다. 끝값 정리는 적용 조건이 있으므로 이 단원에서는 시간 해의 극한을 직접 계산한다.

중간 과정을 따라가는 예제

t≥0에서 y′+2y=1, y(0−)=3이고 원점 충격은 없다. 단방향 변환으로 y(t)를 구하고 응답을 분리하라.

  1. sY−3+2Y=1/s이므로 Y=1/[s(s+2)]+3/(s+2)다.

  2. 1/[s(s+2)]=(1/2)/s−(1/2)/(s+2)다. 따라서 Y=(1/2)/s+(5/2)/(s+2)다.

  3. t≥0에서 y=.5+2.5e^(−2t)다. 영상태는 .5(1−e^(−2t)), 영입력은 3e^(−2t)다.

  4. y(0+)=.5+2.5=3이고 y′=−5e^(−2t)다. y′+2y=−5e^(−2t)+1+5e^(−2t)=1이다.

  5. 초기 기울기는 −5이며 방정식의 1−2·3과 같다. t→∞에서 y→.5다.

총 응답은 .5+2.5e^(−2t), 초기 상태 0의 응답과 초기 상태 응답의 합이다. t≥0의 해로 사용하며 인위적으로 0 이전을 0으로 연장한 미분과 혼동하지 않는다.

종이와 본문으로 직접 해보기

같은 입력에서 초기값을 −1로 바꾸면? 입력을 0으로 하고 초기값 3만 남기면? 각각 초기 기울기를 확인하자.

힌트 보기

상수 특수해 .5와 초기값을 맞추는 지수 계수를 더한다.

풀이 보기

초기값 −1이면 y=.5−1.5e^(−2t)이고 초기 기울기 3=1−2(−1)이다. 입력 0, 초기값 3이면 y=3e^(−2t)이고 초기 기울기 −6=−2·3이다. 두 번째에는 입력의 전달함수 항이 0이어도 출력이 있다.

오해와 반례

Y=HX는 초기 상태가 얼마이든 총 출력 전체를 준다.

그 관계는 영상태 조건에서 성립한다. 초기 상태가 있으면 변환한 미분 항의 초기값을 보존해 별도 응답을 더한다.
