같은 분수 식이 서로 다른 수열을 나타낼 수 있을까?

준비 개념과 학습 목표

학습 목표

두 무한 꼬리를 빼면 원래보다 넓은 곳에서 합이 수렴할까요?

무차원 수열 x₁[n]=(1/2)^n u[n]과 x₂[n]=−(1/2)^n u[n−3]을 더합니다. 각각은 |z|>1/2에서 Z 합이 수렴하지만 x=x₁+x₂는 n=0,1,2에만 [1,1/2,1/4]가 남습니다. 무한 꼬리가 정확히 없어졌습니다.

공통 ROC에서 더한 식은 X=(1−(1/8)z^(−3))/(1−(1/2)z^(−1))입니다. 소거하면 X=1+(1/2)z^(−1)+(1/4)z^(−2)이고 실제 ROC는 모든 유한 z≠0으로 넓어집니다. z=1/2에서 원래 분수는 0/0처럼 보이지만 유한합은 3입니다. 합의 ROC가 교집합을 포함한다는 말과 반드시 그 교집합과 같다는 말은 다릅니다.

  • 합에 포함하는 시간 범위

    0 이전을 포함하는지와 유한합의 항을 확인합니다.

시간 인덱스를 복소수의 거듭제곱으로 바꾼다

정수 n의 수열 x[n]에 대해 양방향 Z 변환은 X(z)=Σ_{n=−∞}^{∞}x[n]z^(−n)이다. z는 복소수이고 보통 먼저 z≠0에서 합을 생각한다. 이 단원의 ROC는 절대수렴하는 z의 집합이다. 원점이나 무한대의 포함 여부는 유한 길이·지연 같은 특수한 경우에 별도로 확인한다.

단위 계단 u[n]은 n≥0에서 1, 그 밖에서 0이다. a≠0일 때 aⁿu[n]의 변환은 Σ_{n=0}∞(a/z)ⁿ이므로 |z|>|a|에서 1/(1−a z⁻¹)이다. 분모가 0이 아닌 곳이라는 조건만으로 원래 무한합의 수렴이 보장되지는 않는다.

같은 식의 다른 방향을 확인한다

좌측 수열 −aⁿu[−n−1]은 n≤−1에만 남는다. k=−n으로 바꾸면 −Σ_{k=1}∞(z/a)ᵏ=−(z/a)/(1−z/a)=z/(z−a)다. |z|<|a|에서 수렴한다. 우측 수열과 대수식은 같지만 지원하는 시간 방향과 ROC가 다르다.

양쪽 수열을 더한 경우에는 공통 수렴영역을 먼저 찾는다. 예를 들어 (1/2)ⁿu[n]−2ⁿu[−n−1]은 1/2<|z|<2에서 수렴한다. 공통 영역에서 합을 더할 수 있고 항이 소거되면 실제 ROC가 넓어질 수 있으므로 교집합이 언제나 최종 ROC와 정확히 같다고 하지 않는다.

단위원 대입은 조건을 갖는다

z=e^(jω)는 |z|=1인 단위원이다. 절대수렴 ROC가 이 원을 포함하면 X(e^(jω))=Σx[n]e^(−jωn)로 DTFT를 얻는다. 단위원에서 대수식을 계산할 수 있다는 것과 정의한 수열의 합이 그곳에서 수렴한다는 것은 다른 질문이다.

예를 들어 a=1/2의 우측 수열은 단위원을 포함하지만 같은 식의 좌측 수열은 포함하지 않는다. 분수 식을 계산하거나 역변환할 때 ROC와 수열 방향을 버리면 다른 신호를 선택할 수 있다. 모든 일반화된 Fourier 표현의 존재를 이 절대수렴 기준 하나로 판단하는 것은 이 단원의 범위를 벗어난다.

오른쪽 지연 항 문제

z^(−2)의 극점·제외

소거 전 두 발산 합을 각각 숫자로 계산해 빼는 방법은 허용하지 않습니다. 수열을 먼저 더해 유한 수열로 만든 뒤 새 변환을 계산합니다.

중간 과정을 따라가는 예제

x_R[n]=(1/2)ⁿu[n]과 x_L[n]=−(1/2)ⁿu[−n−1]의 변환·ROC와 n=−1,0,1의 값을 구하라.

  1. 우측 합은 Σ((1/2)/z)ⁿ이라 X_R=z/(z−1/2), ROC |z|>1/2다.

  2. 좌측 합은 −Σ_{k=1}∞(2z)ᵏ이라 X_L=z/(z−1/2), ROC |z|<1/2다.

  3. x_R의 세 값은 0,1,1/2다. x_L은 −2,0,0이다.

두 대수식은 같지만 ROC와 수열은 다르다. 우측값 (0,1,1/2), 좌측값 (−2,0,0)이다.

조건을 바꾸어 비교하기

두 수열을 먼저 더하기

x₁+x₂의 첫 다섯 표본과 z=1/4의 변환값을 구하라.

  1. n=0,1,2에는 x₂=0이라 1,1/2,1/4다. n≥3은 정확히 상쇄되어 0이다.

  2. 유한합은 1+(1/2)/z+(1/4)/z²다.

  3. z=1/4에서 1+2+4=7이다. 각각의 무한합을 그 점에서 계산한 값은 아니다.

표본은 1,1/2,1/4,0,0이고 X(1/4)=7이다.

비교할 점

새 수열의 변환과 원래 두 발산 변환값의 차를 구별한다.

아주 작은 꼬리가 다시 남으면

x₂를 −(1−ε)(1/2)^n u[n−3]로 바꾸고 ε≠0의 실제 ROC를 구하라.

  1. n≥3에 ε(1/2)^n이 남는다. 첫 세 표본은 그대로다.

  2. 그 꼬리의 공비 크기는 |(1/2)/z|이다. ε가 0이 아니면 크기에 관계없이 |z|>1/2가 필요하다.

  3. z=1/4에서 꼬리 항은 ε2^n으로 커져 절대합이 발산한다.

ε≠0이면 ROC는 |z|>1/2다.

비교할 점

정확한 소거와 작은 오차의 소거는 무한합의 수렴에서 다른 조건이다.

힌트 보기

풀이 보기

x_R은 |1|>1/2이므로 합2다. x_L은 |1|<1/2가 아니므로 원래 합이 발산한다. 대수식에 1을 넣은 2를 x_L의 변환값으로 쓰지 않는다. 별도 수열은 1/2<|z|<2이며 두 극점이 소거되지 않아 이 고리다.

오해와 반례

분수 식만 같으면 시간 수열도 같고 분모만 0이 아니면 모든 점에서 변환을 계산할 수 있다.

같은 z/(z−1/2)라도 우측과 좌측이 다르다. z=1에서 좌측 합은 발산한다. ROC를 변환의 일부로 남긴다.

같은 필터 두 개를 연결하면 감쇠 지수만 두 번 더할까요?

초기 정지의 인과 필터 G=1/(1−(1/2)z^(−1))를 두 개 직렬 연결합니다. 전체 H=G²이고 극점 1/2의 중복도는 2입니다. 임펄스 응답은 convolution 합에서 h[n]=(n+1)(1/2)^n u[n]입니다. 지수만 두 배 더한 2(1/2)^n과 다릅니다.

차분식은 y[n]−y[n−1]+(1/4)y[n−2]=x[n]입니다. h[0]=1,h[1]=1,h[2]=3/4라 초기 두 값이 같아도 이후에는 감쇠합니다. 절대합은 4로 유한하고 DC 배율 H(1)=4와 일치합니다. 응답의 시작 모양 몇 점과 무한 시간의 안정성은 구별합니다.

    감쇠 지수에 다항식이 곱해져도 절대합을 확인합니다.

지연은 z의 역수와 연결된다

양방향 합에서 y[n−1]의 인덱스를 m=n−1로 바꾸면 z⁻¹Y(z)가 된다. 이동된 수열의 ROC는 원점·무한대 예외를 따로 확인한다. 상수계수 차분식의 각 지연에 이 관계를 적용하면 Y와 X에 곱해지는 다항식이 나온다.

Σ a_k y[n−k]=Σ b_k x[n−k]라면 초기 정지의 영 상태 LTI 응답에서 H(z)=Σ b_k z^(−k)/Σ a_k z^(−k)다. H는 임펄스 응답 h의 변환이고 공통 수렴 조건에서 Y=HX다. ROC와 인과성도 붙여 시스템을 정한다. 임의 입력의 X가 0인 지점에서 Y/X를 무조건 나누는 정의는 아니다.

먼저 간단한 메모리 규칙을 푼다

y[n]−(1/2)y[n−1]=x[n]을 인과적 초기 정지로 풀자. 입력 전에 남은 출력은 0이다. 변환하면 (1−(1/2)z⁻¹)Y=X이므로 H=1/(1−(1/2)z⁻¹), ROC |z|>1/2다. 임펄스 입력 δ[n]에 대한 h[n]=(1/2)ⁿu[n]을 차분식에 대입해 확인할 수 있다.

계단 입력 u[n]에는 y[n]=Σ_{k=0}^n(1/2)ᵏ=2−(1/2)ⁿ, n≥0이고 음의 시간에서는 0이다. 처음 값 1,3/2,7/4를 재귀식으로도 얻는다. 입력이 달라지면 출력은 달라지지만 영 상태 시스템함수 자체는 같은 H다.

초기 에너지가 있으면 출력 항이 추가된다

출력의 과거값이 0이 아니면 영 상태 응답에 영 입력 응답이 더해진다. 비영 초기 상태를 고정한 입력→전체 출력 관계는 일반적으로 원점의 입력 0에도 출력이 남아 단순한 선형 영 상태 맵과 다르다. Y=HX만으로 그 초기 응답을 버리지 않는다.

또한 유리식의 상쇄만으로 내부 상태의 모든 안정성이 증명되지는 않는다. H는 선택한 입출력 경로의 영 상태 정보를 나타낸다. 이 단원은 작은 입출력 수열의 분석이며 숨은 상태·실제 장치의 동작을 측정하지 않는다.

임펄스 응답이 크기 1 이하면 모든 입력에서도 안정할까요?

초기 정지의 인과 H=1/(1+z^(−2))를 봅니다. 극점은 ±j로 단위원 위이고 h[2k]=(−1)^k, h[2k+1]=0, k≥0입니다. 모든 h의 값은 크기 1 이하지만 절대합은 무한입니다. 유한한 몇 표본만 보고 안정하다고 정할 수 없습니다.

특히 x[n]=cos(πn/2)u[n]은 h와 같은 수열이며 크기 1의 유계 입력입니다. convolution에서 y[2k]=(k+1)(−1)^k, 홀수 표본은 0이 됩니다. 반면 계단 입력은 1,1,0,0을 반복해 유계입니다. 어떤 한 입력의 출력이 작다는 사실과 모든 유계 입력에 대한 안정성은 다릅니다.

먼저 확인할 개념
  • 극점과 단위원

    단위원의 극점과 절대합의 발산을 함께 확인합니다.

  • 차분식과 입력 응답

    y[n]+y[n−2]=x[n]을 직접 추적합니다.

작은 입력에서 출력도 제한되는지 묻는다

이산 LTI 시스템의 BIBO 안정성은 모든 유계 입력에 출력도 유계인 성질이다. 임펄스 응답이 절대합 가능, 즉 Σ|h[n]|<∞일 때 컨볼루션에서 |y[n]|≤sup|x|×Σ|h|라는 상한을 얻는다. 이 조건은 표준 이산 LTI 입출력 BIBO 안정성의 필요충분조건이다.

ROC를 절대수렴으로 정의하면 h의 단위원 포함은 Σ|h[n]|<∞와 같다. 따라서 H의 ROC가 단위원을 포함하는지를 본다. H의 대수식만 1에 대입하거나 유한 시간 표본 몇 개가 작아진다는 사실만으로 모든 유계 입력의 안정성을 증명하지 않는다.

인과성 조건이 극점 기준을 만든다

인과적 유리 시스템함수의 ROC는 가장 바깥 극점 밖으로 뻗고 무한대도 허용하는 형식이다. 이 경우 단위원을 포함하려면 약분 후 실제 극점이 모두 |p|<1에 있어야 한다. 극점이 단위원 위면 이 절대합 기준에서 제외된다. 인과 유리계라는 조건을 생략하지 않는다.

H=1/(1−a z⁻¹), 인과 h=aⁿu[n]은 |a|<1이면 절대합 1/(1−|a|)이다. a=1에서는 h=u이고 계단 입력의 출력 n+1이 커져 불안정하다. a=2의 인과 h는 임펄스라는 유계 입력에도 2ⁿ으로 커진다.

비인과 안정 반례와 상태 경계를 남긴다

같은 a=2의 식에 ROC |z|<2를 주면 h[n]=−2ⁿu[−n−1]이다. 이 수열은 미래 입력을 참고하는 비인과 응답이지만 절대합 Σ_{k=1}∞2^(−k)=1이고 단위원을 포함하여 BIBO 안정하다. 극점 위치만으로는 인과성 없이 안정성을 판정하지 못한다.

안정한 입출력 H도 실제 구현의 숨은 상태 모드까지 모두 안정함을 인증하지 않는다. 극점·영점 상쇄 뒤 입출력 응답과 내부 상태를 구별한다. 비인과 수열을 앞으로 들어올 입력을 모르는 실시간 장치에서 곧바로 구현할 수 있다는 뜻도 아니다.

양·단방향 변환의 구별

변환 합을 0부터 시작하면 과거의 출력은 어디에 남을까?

준비 개념과 학습 목표

준비 개념

  • 양방향 Z 합

  • 초기값 y[−1]

  • 차분방정식과 지연

학습 목표

  • 합의 시작 인덱스로 두 변환을 구별한다.

  • 단방향 지연의 초기항을 유도한다.

  • 비영 초기 응답을 포함해 차분식을 푼다.

과거 두 값이 남으면 같은 분모의 답도 달라질까요?

n≥0에서 y[n]−y[n−1]+(1/4)y[n−2]=δ[n], y[−1]=2,y[−2]=−4로 정합니다. 단방향 합에서 한 칸 지연은 2+z^(−1)Y_+, 두 칸 지연은 −4+2z^(−1)+z^(−2)Y_+입니다. 분모가 같아도 과거 두 경계항은 분자에 남습니다.

정리하면 (1−z^(−1)+(1/4)z^(−2))Y_+=4−(1/2)z^(−1)입니다. 따라서 n≥0의 해는 y[n]=(4+3n)(1/2)^n입니다. 영 상태 응답 (n+1)(1/2)^n과 영 입력 응답 (3+2n)(1/2)^n의 합입니다. 이 공식은 주어진 앞으로의 해이며 음의 모든 인덱스에서 같은 식과 입력이 성립한다고 임의로 연장하지 않습니다.

먼저 확인할 개념
  • 단방향 지연의 경계항

    두 과거값과 서로 다른 z 지수를 남깁니다.

  • 두 지연 차분식의 응답

    같은 제곱 분모를 영 상태 및 초기 응답에서 비교합니다.

0 이전을 합에서 제외한다

단방향 변환을 X_+(z)=Σ_{n=0}∞x[n]z^(−n)로 정하자. 양방향은 모든 정수 n을 합한다. x[n]=0 for n<0이면 두 값이 같지만 과거 표본이 남으면 다를 수 있다. 단방향은 과거를 모른다는 뜻이 아니라 합에서 따로 제외하는 표기다.

단방향 합 자체만으로는 n<0의 원래 수열을 복원하지 못한다. 차분식에 필요한 y[−1], y[−2] 등은 추가 초기조건으로 제공한다. 단방향 변환의 역변환은 여기서 n≥0 응답을 대상으로 하며 이를 원래 과거값이 모두 0이었다는 주장으로 바꾸지 않는다.

지연을 바꾸면 경계항이 나온다

Σ_{n=0}∞y[n−1]z^(−n)에서 첫 항은 y[−1]이다. 나머지는 z⁻¹Σ_{m=0}∞y[m]z^(−m)라서 Z_+{y[n−1]}=y[−1]+z⁻¹Y_+(z)다. 양방향의 단순 z⁻¹Y와 다르다. 두 칸 지연은 y[−2]+y[−1]z⁻¹+z⁻²Y_+다.

앞당김도 경계항을 낸다. Z_+{y[n+1]}=z(Y_+−y[0])다. 합의 시작을 직접 바꾸면 부호와 z 지수를 확인할 수 있다. 표의 지연 공식을 다른 변환으로 가져오며 초기항을 버리지 않는다.

입력과 초기 응답을 나눈다

n≥0에서 y[n]−a y[n−1]=x[n]이면 (1−a z⁻¹)Y_+=X_++a y[−1]이다. 따라서 Y_+=H X_++a y[−1]H, H=1/(1−a z⁻¹)다. 첫 항은 영 상태, 둘째는 초기값에 따른 영 입력 응답이다. 입력 0인데도 초기항 때문에 출력이 남을 수 있다.

이 식은 주어진 초기조건으로 앞으로 반복하는 인과적 해를 선택한다. 단방향 합의 수렴영역도 확인한다. 음의 시간에서까지 같은 점화식이 영 입력으로 성립한다고 임의로 연장하지 않는다. 과거 초기값과 초기 정지를 구별해야 한다.

꼬리 소거·반복 극점·공진·초기 경계를 함께 확인하기

네 문제를 풀어라. ① x[n]=(1/2)^n(u[n]−u[n−4])의 X(1/2)와 실제 ROC를 구하라. ② 두 동일 인과 G=1/(1−z^(−1)/2)의 직렬 임펄스 응답 h[5]와 계단 끝값을 구하라. ③ H_r=1/(1+r²z^(−2))의 인과 r=1/2에서 절대합과 ω=π/2 배율을 구하라. ④ y[n]−y[n−1]+y[n−2]/4=δ[n], 과거 y[−1]=0,y[−2]=4의 n≥0 출력과 단방향 분자를 구하라.

힌트 1

① 정확히 네 표본만 남습니다. ② h[n]=(n+1)/2^n입니다.

힌트 2

③ 짝수 위치의 절대 공비는 r²입니다. ④ 입력 1과 경계 −y[−2]/4가 상쇄됩니다.

풀이와 답 확인

  1. ① X=1+(1/2)z^(−1)+(1/4)z^(−2)+(1/8)z^(−3)다. X(1/2)=4, 실제 ROC는 유한 z≠0이다.

  2. ② h[5]=6/32=3/16이고 계단 끝값은 절대합과 같은 4다.

  3. ③ 절대합 1/(1−1/4)=4/3이다. 공진 배율도 4/3이며 안정하다.

  4. ④ 단방향 분자는 1+0−4/4−0z^(−1)=0이므로 Y_+=0, 모든 n≥0에서 출력 0이다.

① 값 4와 유한 z≠0이다. ② h[5]=3/16, 계단 끝값 4다. ③ 절대합과 공진 배율 4/3이다. ④ 단방향 분자 0이며 미래 출력은 모두 0이다.
