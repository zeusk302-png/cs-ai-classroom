소단원 3.1

임펄스응답

단 한 칸에 1을 넣었을 때의 반응으로 다른 입력의 결과도 알 수 있을까?

준비 개념과 학습 목표

준비 개념

  • 이산 신호 x[n]는 정수 n마다 값이 있다. 배열값 외에 시작 인덱스와 배열 밖 값의 약속이 필요하다.

  • 단위 샘플 δ[n]는 n=0에서 1, 다른 정수에서 0이다. 연속시간 Dirac 델타의 무한 높이 비유와 구별한다.

  • 선형성 T(ax+bz)=aT(x)+bT(z), 시불변성 T(x[n−k])=y[n−k]를 서로 독립 조건으로 이해한다.

학습 목표

  • h=T(δ)를 정의한다.

  • 이동·배율 임펄스 반응을 LTI 조건에서 유도한다.

  • 비선형/시변 시스템의 반례로 임펄스만의 한계를 확인한다.

임펄스 응답의 첫 칸이 음수 시각이라면 무엇이 달라질까요?

이 소단원의 무차원 LTI 모형은 h[n]=δ[n+1]−2δ[n]+3δ[n−2]입니다. 비영 위치는 −1, 0, 2이며 중간 위치 1의 값 0도 좌표로 보존합니다. 입력 x[n]=2δ[n+1]−δ[n−2]는 위치 −1의 2와 위치 2의 −1을 합한 신호입니다. 배열의 첫 값이 있다고 곧바로 n=0으로 바꾸지 않습니다.

LTI 조건에서는 출력 y[n]=2h[n+1]−h[n−2]입니다. 각 이동 응답의 구간이 겹치면 더하며 겹친 위치에서 상쇄도 가능합니다. h[−1]이 비영이라 미래 입력을 쓰는 비인과 모형입니다. 수학적 신호 처리와 현재 즉시 실행 가능한 물리 장치를 구별하며 실제 필터·소리·센서는 실행하지 않았습니다.

먼저 확인할 개념
  • 이동 임펄스의 응답

    선형 배율과 시불변 이동을 각각 적용합니다.

  • 출력 합의 좌표

    입력 시각과 반응 시각이 합해 출력 위치를 만듭니다.

한 칸 신호를 기본 재료로 삼는다

δ[n−k]는 k에서만 1인 신호다. x[k]δ[n−k]는 k번째 값을 떼어낸 한 칸 신호이고 유한지원 입력은 x[n]=Σk x[k]δ[n−k]로 정확히 재조립된다. 여기서 n은 보고 있는 출력 좌표, k는 합에 쓰는 입력 좌표다.

임펄스응답 h[n]=T{δ}[n]는 하나의 입력에 대한 전체 출력 신호다. h[0] 한 숫자만을 뜻하지 않는다. 시스템은 과거 시각의 값이나 미래 값을 쓸 수 있으므로 h의 인덱스와 값이 모두 필요하다.

선형과 시불변을 각각 쓴다

LTI에서 T{δ[n−k]}=h[n−k]는 시불변성의 결과다. T{x[k]δ[n−k]}=x[k]h[n−k]는 선형성의 배율 조건을 쓴다. 여러 칸의 반응을 더할 수 있는 것은 선형성의 가법성 때문이다. 두 조건을 합쳐야 하나의 h를 재사용할 수 있다.

차분방정식으로 정의된 시스템이라도 임의 고정 초기상태의 자체 반응을 더하면 전체 입출력 관계가 선형이 아닐 수 있다. 여기서는 초기휴지/영초기상태의 LTI 입력 응답을 다룬다. 실제 물리 장치의 초기 저장 에너지나 입력 없이 생기는 출력은 별도로 모형화한다.

한 번의 반응만으로 모든 시스템을 알 수는 없다

T1(x)[n]=x[n], T2(x)[n]=x[n]²는 δ에 둘 다 δ를 반환하지만 2δ에 각각 2δ/4δ를 반환한다. T2는 선형이 아니다. 따라서 h가 같다는 것으로 조건 없이 전체 시스템이 같다고 주장하지 않는다.

T3(x)[n]=(n+1)x[n]은 선형이지만 시변이다. δ에 대한 반응은 δ라서 T1과 같지만 δ[n−2]에 대한 반응은 3δ[n−2]다. 입력 이동에 따라 반응 형태/크기가 달라져 같은 h의 단순 이동만으로 설명하지 못한다.

중간 과정을 따라가는 예제

초기휴지 시스템 y[n]=2x[n]−x[n−1]에서 h와 입력 x=3δ[n]+2δ[n−2]의 출력을 구하라. h 밖의 값은 0이다.

  1. x=δ면 h[n]=2δ[n]−δ[n−1], 즉 h[0]=2, h[1]=−1, 다른 값 0이다.

  2. 지연된 2δ[n−2]의 반응은 2h[n−2]여서 n2에서 4, n3에서 −2다.

  3. 3δ 반응 3h는 n0에서 6, n1에서 −3이다. 합치면 y0..3=[6,−3,4,−2]다.

  4. 원식에서도 n2는 2×2−x1=4, n3는 2×0−x2=−2로 검산한다. 입력의 빈칸과 배열 밖을 0으로 썼다.

h=[2,−1] 시작 0, 출력 [6,−3,4,−2] 시작 0이다.

현재 n=0까지 같은 두 입력 0과 δ[n−1]의 현재 출력을 구하라.

  1. 영 입력 출력은 0이다.

  2. 위치 1 임펄스의 출력은 h[n−1]이므로 n=0에서 h[−1]=1이다.

비교할 점

미리 확보한 전체 기록의 계산은 가능해도 현재까지 받은 정보만으로 같은 함수를 즉시 구현한 검증은 아니다.

같은 δ 응답을 갖는 다른 함수

A{x}[n]=x[n], B{x}[n]=x[n]³, C{x}[n]=(1+n²)x[n]의 δ와 2δ[n−2] 출력을 비교하라.

  1. δ 입력에는 세 함수 모두 δ를 낸다.

  2. 2δ[n−2]에서 A는 위치 2에 2, B는 8을 낸다.

  3. C는 위치 2에서 계수 1+4=5가 곱해져 10을 낸다.

  4. B는 비선형이며 C는 선형이지만 시변이라 하나의 h만으로 모든 입력을 결정하지 못한다.

같은 단위 임펄스 응답에도 위치 2 출력이 2,8,10으로 다르다.

소단원 3.2

convolution 합의 유도

입력의 각 칸이 만든 잔향을 한 시각에서 어떻게 합칠까?

준비 개념과 학습 목표

준비 개념

  • 유한지원 신호는 유한개 인덱스 밖에서 0이다. 합기호의 범위를 먼저 정한다.

  • LTI h[n]는 δ의 반응이고 x[k]δ[n−k]의 반응은 x[k]h[n−k]다.

  • n을 고정하면 h[n−k]는 k축에서 h를 뒤집고 옮긴 표다. 곱셈 x[k]h[k]와 다르다.

학습 목표

  • 임펄스 분해에서 convolution을 유도한다.

음수에서 시작한 입력과 양수에서 시작한 필터의 합은 어디서 시작할까요?

서로 별도의 유한 신호를 x[−2]=2, x[−1]=−1, x[0]=3 및 h[1]=−1, h[2]=4, h[3]=2로 정하고 그 밖은 0으로 둡니다. 출력의 가능한 첫 위치는 −2+1=−1, 마지막은 0+3=3입니다. x 배열을 [2,−1,3]이라고 적을 때 시작 −2를 함께 유지해야 합니다.

y[n]=Σ_k x[k]h[n−k]에서 입력 위치 k와 필터 위치 n−k가 각 범위 안에 있어야 합니다. 여기서는 max(−2,n−3)≤k≤min(0,n−1)입니다. 이 교집합을 먼저 구하면 배열 밖 0과 실제 누락 기록을 섞지 않고 유한합을 계산할 수 있습니다.

  • 배열의 시작과 경계

분해와 반응을 순서대로 잇는다

유한지원 x를 Σk x[k]δ[n−k]로 분해하고 T를 적용한다. 선형 가법성/배율과 시불변성을 써서 y[n]=Σk x[k]h[n−k]=(x*h)[n]를 얻는다. *는 전체 신호를 받아 새 신호를 만드는 연산이지 같은 인덱스 두 숫자를 곱하는 별표가 아니다.

h가 유한지원이면 각 n에서 유한항만 남아 일반 입력에도 합이 정의된다. 둘 다 무한지원이면 합의 존재와 시스템 연산을 극한/무한합과 교환할 조건이 추가로 필요하다. |x|≤M과 Σ|h|<∞면 Σ|x[k]h[n−k]|≤MΣ|h|로 절대수렴을 보장한다.

같은 출력시각의 기여를 모은다

n이 정해지면 입력 k의 기여는 k에서 출발한 반응의 n−k번째 샘플이다. 예를 들어 n=2, k=0이면 h[2], k=1이면 h[1], k=2이면 h[0]다. n−k가 h 범위 밖이면 해당 곱은 0이다. 이 표를 직접 만들면 뒤집기와 이동의 부호를 확인할 수 있다.

k에 대한 함수 h[−k]를 먼저 뒤집고 n칸 옮기면 h[n−k]다. 그림 없이도 각 k에 n−k를 쓰는 것으로 동일한 계산이 된다. 신호가 복소수여도 convolution 자체는 여기서 켤레를 붙이지 않는다. 상관 연산의 일부 정의와 혼동하지 않는다.

경계도 합의 일부다

x가 0..N−1, h가 0..M−1에 있다면 k는 0≤k≤N−1와 0≤n−k≤M−1를 동시에 만족해야 한다. 즉 max(0,n−M+1)≤k≤min(N−1,n)이다. 아래 한계가 위 한계보다 크면 겹치는 항이 없어 합 0이다.

causal이 아닌 신호의 시작이 a,b라면 출력의 가능 구간은 a+b부터 끝 인덱스 합까지다. 배열 첫 칸을 늘 n=0으로 오해하면 시간 이동을 잃는다. 배열과 시작 인덱스를 함께 기록하고, 유한 관측이라는 사실만으로 미관측 값 0이라고 단정하지 않는다.

준비 개념과 학습 목표

준비 개념

  • 여기서는 유한지원 스칼라 신호를 우선 다룬다. 무한 신호는 필요한 절대수렴 조건을 따로 둔다.

  • 교환법칙은 x*h=h*x, 결합법칙은 (x*h)*g=x*(h*g)다. 덧셈과 혼동하지 않는다.

  • δ는 convolution 항등, δ[n−d]는 d칸 지연을 만든다. 신호의 같은 시각 값을 곱하는 항등 1과 다르다.

학습 목표

  • 교환·분배·결합법칙을 유한합으로 증명한다.

  • 연쇄/병렬 LTI의 임펄스응답을 계산한다.

  • 지연/반례/비LTI 적용 한계를 설명한다.

최종 출력은 같아도 중간 신호는 달라질 수 있을까요?

이번 유한 스칼라 LTI 필터는 시작 0의 h=[1,−2], g=[2,1,−1]이며 입력 x=[1,3]입니다. 배열 밖은 0입니다. 직렬은 h*g, 병렬 출력의 합은 h+g를 사용합니다. 두 배열을 더할 때는 같은 좌표를 맞춰 h의 위치 2 값을 0으로 둡니다.

스칼라 유한합에서는 합성곱 교환·결합·분배를 쓸 수 있지만 직렬과 병렬을 같은 연산으로 바꾸지 않습니다. 순서 변경의 최종 출력이 같아도 중간 신호는 다릅니다. 또한 다채널 행렬 계수에는 곱의 순서가 있고, 각 시스템이 선형·시불변이어도 행렬 교환을 별도로 검사해야 합니다.

먼저 확인할 개념
  • 직렬·병렬 합의 성질

    유한합의 재배열과 선형 분배를 사용합니다.

  • 유한합과 좌표

    배열 시작과 영계수 위치를 보존합니다.

합 인덱스를 바꾸면 교환이 보인다

(x*h)[n]=Σk x[k]h[n−k]에서 j=n−k로 치환하면 Σj h[j]x[n−j]=(h*x)[n]다. 유한지원에서는 남은 유한항만 재배열하므로 문제가 없다. 무한 조건부수렴 합에 순서 교환을 무조건 허용하지 않는다.

분배법칙 x*(h+g)=x*h+x*g는 각 항의 x[k](h[n−k]+g[n−k])를 펼쳐 합한다. 입력 배율도 밖으로 나갈 수 있다. x*δ=x이며 x*δ[n−d]=x[n−d]라는 식은 δ가 딱 한 항을 선택해서 얻는다.

결합은 두 합을 다시 묶는 일이다

((x*h)*g)[n]=ΣjΣk x[k]h[j−k]g[n−j]다. 유한합에서 순서를 바꾸고 ℓ=j−k로 놓으면 Σk x[k]Σℓ h[ℓ]g[n−k−ℓ]=x*(h*g)다. 이 증명에서 내부 합은 h*g의 n−k 좌표다.

같은 가정에서 LTI 필터 h 다음 g의 전체 응답은 h*g다. 병렬로 반응을 더하면 h+g다. 필터 순서를 바꾸어도 스칼라 LTI 입출력은 교환법칙으로 같지만 중간 신호·내부상태·포화·반올림까지 같다고 주장하지 않는다. 행렬값 다채널 필터의 행렬곱은 일반적으로 교환되지 않는다.

결과의 다른 특징으로 검산한다

유한 신호 총합은 Σn(x*h)[n]=(Σx)(Σh)다. 각 입력 샘플이 h 전체를 복사해 더하므로 모든 쌍의 곱을 한 번씩 합하는 것이다. 이를 정확 계산의 추가 검산으로 쓸 수 있으나 같은 총합의 다른 신호가 가능해 총합만으로 정답 전체를 보장하지 않는다.

필터를 다항식 H(z)=Σh[n]zⁿ로 표현하면 유한 convolution은 다항식 곱의 계수와 같다. 여기서 z는 계수를 모으는 형식변수이며 Z변환의 음지수 정의와 구별한다. 영계수도 위치 정보를 보존해 써야 한다.

소단원 3.4

유한길이 신호의 경계

배열 밖을 0으로 채운 결과와 반복한 결과는 왜 다를까?

준비 개념과 학습 목표

준비 개념

  • 유한 관측 배열은 신호 전체와 같지 않을 수 있다. 배열 밖 값의 0/반복/반사 정책은 모형의 일부다.

  • 길이 N/M인 0 시작 배열의 full 선형 convolution은 N+M−1칸을 기록한다. 시작 a/b이면 결과 시작 a+b다.

  • 원형 convolution은 mod L로 인덱스를 돌려 합한다. 선형 convolution과 별도 연산이다.

학습 목표

  • 전체 가능 출력 구간을 유도한다.

  • full/same/valid의 절단과 경계조건을 구분한다.

  • 원형 겹침과 패딩 조건을 종이로 확인한다.

같은 길이의 결과라도 앞에 되감긴 항과 중앙 절단은 같을까요?

시작 0, 밖 0인 x=[2,−1,3], h=[1,2]의 전체 선형 출력은 [2,3,1,6]입니다. 이 결과를 3점 주기로 접으면 마지막 6이 위치 0으로 돌아와 [8,3,1]이 됩니다. 반면 전체 출력 첫 세 칸을 남기는 절단은 [2,3,1]입니다.

아래 절단 예제는 남길 좌표를 직접 명시합니다. 라이브러리의 same은 첫 입력 길이와 중앙 정렬의 계약이고 경계 영향을 없애는 보장이 아닙니다. 공개 SciPy 문서에서는 fftconvolve의 full도 선형 합성곱을 반환합니다. 충분한 패딩 없는 수동 L점 DFT 곱이 원형합이라는 사실과 라이브러리가 자동으로 패딩하는 API를 혼동하지 않습니다.

먼저 확인할 개념
  • full·same·valid와 원형 경계

    출력 선택과 입력 확장 규칙을 구별합니다.

  • 합의 좌표 교집합

    양 끝에서 남는 입력 항을 계산합니다.

길이는 끝좌표 합에서 나온다

입력 0..N−1과 필터 0..M−1를 더한 좌표가 출력항의 n=k+ℓ이다. 최소 0, 최대 N+M−2이므로 포함 칸수 N+M−1다. 양끝 입력값이 비영인 스칼라 신호이면 끝 계수 곱도 비영이지만 일부 배열 끝값이 0이면 실제 비영 지원은 더 짧을 수 있다.

음의 시작 인덱스도 같은 논리를 쓴다. x가 a..a+N−1, h가 b..b+M−1면 결과는 a+b..a+b+N+M−2다. 신호값이 같더라도 시작을 누락하면 시각이 달라진 신호를 동일하다고 오해한다.

출력 절단은 입력 밖 약속을 없애지 않는다

full은 밖을 0으로 둔 전체 선형합이다. SciPy의 same은 full 중앙에서 첫 입력 길이 N만 남긴다. valid는 어느 필터 위치에서도 입력의 zero-padding에 의존하지 않는 구간이다. 여기서 N≥M이면 길이 N−M+1이다. 중앙 정렬의 짝수 길이 시 어느 칸을 남길지는 API 계약을 확인한다.

same이 길이가 같다는 뜻이지 경계 편향이 없다는 뜻은 아니다. 예를 들어 0으로 확장한 상수 관측에 3칸 평균을 적용하면 끝에서 작게 나온다. 배열 밖도 같은 상수라고 확장하면 달라진다. 입력 밖 0은 실제 미관측 값이 0이라는 증거가 아니라 정한 약속이다.

원형 합의 되감김을 확인한다

L점 원형합 ycirc[n]=Σk=0..L−1 x[k]h[(n−k) mod L]는 끝을 처음으로 돌린다. L이 선형 결과 길이보다 작으면 뒤쪽 계수가 앞으로 더해지는 시간영역 겹침이 생긴다. FFT를 써서 L점 곱을 역변환해도 그 L의 원형 연산이므로 패딩 조건을 따로 준다.

길이 N/M 배열을 L≥N+M−1로 0 패딩하면 선형 출력의 비영 가능 구간이 한 주기 안에 들어가 원형합과 그 구간이 일치한다. 실수 FFT에는 반올림 오차가 있고 실행 환경도 필요하다. 이 단원에서는 FFT 또는 SciPy를 실행하지 않고 작은 합으로 경계 차이를 계산한다.

원형합은 뒤쪽을 그냥 버리는 연산이 아닙니다. 입력의 시작 좌표가 다르면 선형 출력의 시작도 별도로 기록해야 합니다. 여기 원형 배열의 위치는 0부터 L−1이며 실제 신호가 주기적으로 측정되었다는 증거가 아닙니다. 공개 SciPy v1.18.0의 중앙 선택 규칙을 이 길이에 적용하면 same은 위치 0..2의 [2,3,1], valid는 위치 1..2의 [3,1]입니다. 이는 소스 식으로 추적한 결과이며 설치된 라이브러리를 실행한 기록은 아닙니다.

중간 과정을 따라가는 예제

x=[1,2,3], h=[1,1] 시작 0/밖 0이다. full과 SciPy same/valid의 배열, 3점 원형합을 구하라. same의 여기 중앙 절단은 full 첫 3칸으로 정한다.

  1. full은 [1,3,5,3]이며 길이 3+2−1=4다. n3의 3은 마지막 입력 3과 h1의 곱이다.

  2. 정한 same은 full n0..2의 [1,3,5]다. valid는 필터 전체가 입력 범위와 겹치는 n1..2의 [3,5]다.

  3. 3점 패딩 h=[1,1,0]에서 ycirc0=1×1+2×0+3×1=4다. ycirc1=1×1+2×1+3×0=3다.

  4. ycirc2=1×0+2×1+3×1=5라서 [4,3,5]다. 선형 끝 n3의 3이 mod3로 n0에 돌아가 1+3=4가 되었다.
