소단원 14.1

진폭변조와 스펙트럼 이동

낮은 주파수의 정보를 높은 주파수 주변으로 옮기려면 무엇을 해야 할까?

준비 개념과 학습 목표

준비 개념

  • 정현파와 Hz

  • 복소 지수

  • Fourier 이동

학습 목표

  • 반송파 곱셈을 주파수 이동으로 해석한다.

  • 억압 반송파와 반송파 포함 AM을 구별한다.

  • 복조의 위상·분리 조건을 확인한다.

곱셈이 두 스펙트럼 복사본을 만든다

진폭변조의 출발점은 정보 신호 m(t)에 cos(ω_ct)를 곱하는 것이다. 반송파 주파수는 ω_c rad/s이며 f_c=ω_c/(2π) Hz다. Fourier 변환을 M(ω)=∫m(t)e^(−iωt)dt로 정하면 곱셈의 결과는 (1/2)[M(ω−ω_c)+M(ω+ω_c)]다.

이는 cos를 두 복소 지수의 합으로 전개하여 직접 얻는다. 신호가 적분 가능한 경우의 변환과 무한 정현파를 선 스펙트럼으로 나타내는 분포 표현은 구별한다. 아래 예제는 삼각 항등식으로 성분을 직접 구해 보통 적분이 존재한다고 가정하지 않는다.

반송파를 포함할지 결정한다

s=m(t)cos(ω_ct)는 이중 측파대 억압 반송파 방식이다. s=[1+μm(t)]cos(ω_ct)는 반송파가 포함된 AM으로 일정한 반송파 항이 추가된다. 이 둘의 스펙트럼을 같은 것으로 그리지 않는다.

|μm(t)|<1이면 1+μm(t)가 양수라 포락선이 그 값을 따른다. 부호가 바뀌면 단순 절댓값 포락선이 원래 모양을 유지하지 않는다. μ와 신호 크기의 정의를 명시하고 포락선 검출 조건과 동기 복조 조건을 구별한다.

동기 복조는 위상과 필터를 요구한다

억압 반송파 s에 2cos(ω_ct)를 다시 곱하면 m(t)[1+cos(2ω_ct)]다. 저역통과가 원래 대역을 통과시키고 높은 복사본을 제거하도록 분리되어야 m을 얻는다. 반송파 주파수와 위상도 맞아야 한다.

위상 오차 φ가 있으면 2cos(ω_ct+φ)를 곱한 뒤 원래 저주파 부분은 m(t)cos φ다. 주파수 오차가 있으면 시간에 따라 바뀌는 요인이 생긴다. 이상적인 필터 유도와 실제 수신기 측정 성능을 구별한다.

중간 과정을 따라가는 예제

m(t)=cos(2π×200t), f_c=2000 Hz인 억압 반송파 s의 성분과 위상 오차 φ=π/3의 동기 복조 결과를 구하라.

  1. 곱을 합으로 바꾸면 s=(1/2)cos(2π×2200t)+(1/2)cos(2π×1800t)다. 각 성분의 시간 진폭은 1/2다.

  2. 위상이 맞는 2cos 반송파를 곱하면 저주파 200 Hz 성분과 높은 3800/4200 Hz 성분이 생긴다. 이상적인 저역통과의 통과/차단 경계를 그 사이로 정하면 m이 남는다.

  3. 위상 오차 π/3에서는 저주파 진폭이 cos(π/3)=1/2배다. 같은 필터 뒤 결과는 (1/2)m이다.

측파대는 1800/2200 Hz이고 위상 오차 복조의 저주파 진폭은 절반이다.

종이와 본문으로 직접 해보기

반송파 포함 s=[1+(1/2)cos(2π×200t)]cos(2π×2000t)의 세 성분 진폭과 포락선 범위를 구하라.

힌트 보기

상수 항은 반송파로 남고 두 측파대는 μ/2다.

풀이 보기

2000 Hz 진폭1, 1800/2200 Hz 각각1/4다. 포락선은 1+(1/2)cos라 1/2부터3/2까지이며 음수가 아니다.

오해와 반례

반송파를 곱하면 반드시 원래 정보가 사라진다.

적절한 대역 분리와 동기 복조 조건에서는 복원할 수 있다. 반대로 위상·잡음·필터 조건 없이 완전 복원을 약속하지 않는다.

한 단계 더

정보 대역이 |ω|≤B인 이상적 모델에서 반송파 이동 복사본의 위치를 그려라. 중첩 여부와 복조 뒤 2ω_c 주변 성분을 확인하고 대역 분리 조건을 명시한다. 실제 필터의 전이 대역도 별도의 여유가 필요하다.

소단원 14.2

필터·equalization 입문

왜 왜곡의 역수를 적용하는 것만으로 깨끗한 신호를 되찾지 못할까?

준비 개념과 학습 목표

준비 개념

  • LTI 직렬 연결

  • 주파수 응답

  • 기하급수와 잡음

학습 목표

  • 잡음 위치를 포함한 채널 모델을 쓴다.

  • 역보상 조건과 한계를 구별한다.

  • 유한 FIR 근사의 남은 항을 계산한다.

무엇을 보상하는지 모델에 적는다

Equalization, 등화는 채널이 성분별 크기나 위상을 바꾸거나 이전 표본을 섞은 영향을 보상하려는 처리다. 주파수에서 Y=HX+N처럼 잡음이 채널 뒤에 더해진 모델을 정한다. 보상 W를 직렬 연결하면 WY=WHX+WN이다.

W=1/H를 형식적으로 쓰면 신호 항은 X지만 잡음도 1/H배가 된다. H가 0인 주파수에서는 임의의 입력을 그 출력만으로 복원할 수 없다. 작은 H의 역수는 잡음을 크게 키울 수 있으며 인과성·안정성·지연·구현 길이 조건도 따로 확인한다.

필터 목적을 하나로 단정하지 않는다

저역통과는 높은 주파수 성분을 낮추는 목적이고 역등화는 채널의 선택적 왜곡을 보상하는 목적이다. 모든 잡음이 높은 주파수에만 있다는 가정은 없다. 원하는 정보와 잡음이 겹치면 단순한 주파수 제거가 정보도 줄일 수 있다.

오차 제곱을 줄이는 설계는 잔여 왜곡과 잡음 증가를 함께 고려할 수 있다. 최적이라는 말은 정한 목적과 자료·통계 조건에서만 사용한다. 실제 자료를 추정하지 않은 종이 예제의 계수를 실험 최적값으로 부르지 않는다.

지연된 혼합의 역수를 추적한다

이산 채널 y[n]=x[n]+a x[n−1]에서 H(z)=1+a z^(−1)이다. |a|<1이면 인과 역필터는 Σ(k=0…∞)(−a)^k z^(−k)이며 계수 절댓값의 합이 유한하다. 처음 상태와 과거 표본도 명시해야 한다.

길이 L로 자르면 곱은 1−(−a)^L z^(−L)이다. 역수를 짧은 FIR로 근사한 경우 잔여 echo, 메아리 항이 남는다. a=1의 특정 영점처럼 이 조건이 깨지면 같은 안정한 인과 역필터 결론을 내리지 않는다.

중간 과정을 따라가는 예제

a=1/2, 길이2 보상 W=1−(1/2)z^(−1)을 채널 H=1+(1/2)z^(−1)에 연결하라. 입력 δ[n]의 보상 결과를 구하라.

  1. 곱은 (1+(1/2)z^(−1))(1−(1/2)z^(−1))=1−(1/4)z^(−2)다.

  2. 입력 임펄스에서 출력은 n=0에1, n=2에−1/4이며 다른 곳은0이다. 과거 입력은0으로 정했다.

  3. 길이를3으로 늘려 W=1−(1/2)z^(−1)+(1/4)z^(−2)로 두면 곱은1+(1/8)z^(−3)이다. 남은 항이 작아져도 정확한 역수가 된 것은 아니다.

길이2에는 두 표본 뒤 −1/4, 길이3에는 세 표본 뒤1/8의 잔여 항이 남는다.

종이와 본문으로 직접 해보기

어떤 주파수에서 H=1/10, 입력 성분 X=1, 채널 뒤 잡음 N=1/100이다. 역보상 전과 후를 구하라.

힌트 보기

Y=HX+N을 먼저 구하고 W=10을 곱한다.

풀이 보기

Y=11/100이다. WY=11/10으로 신호1과 잡음1/10이 된다. 잡음 진폭은1/100에서1/10으로 열 배가 됐다.

오해와 반례

채널의 역필터는 잡음까지 원래대로 제거한다.

채널 뒤에 더해진 잡음은 역필터를 통과해 증폭될 수 있다. 신호 항의 보상과 잡음 처리를 구별한다.

답과 이유 보기

한 단계 더

길이 L의 기하 합과 H의 곱을 전개해 중간 항의 상쇄 및 마지막 항을 증명하라. a=1일 때 교대 수열 x[n]=(−1)^n을 양방향 입력으로 두면 y[n]=0임을 확인한다. 유한 시작의 경계 표본과 양방향 수열의 정보 상실을 구별한다.

소단원 14.3

피드백 블록 연결

출력을 되돌려 빼면 언제나 안정한 시스템이 될까?

준비 개념과 학습 목표

준비 개념

  • 전달함수

  • 영 초기상태

  • 극점과 지수 해

학습 목표

  • 직렬·병렬·피드백 식을 구별한다.

  • 부호와 센서 경로를 보존한다.

  • 전달함수 대수와 안정성 판단을 분리한다.

블록의 연결 가정을 명시한다

영 초기상태의 scalar LTI 블록 G₁,G₂가 서로의 동작을 바꾸지 않는 비부하 조건이면 직렬 전달함수는 G₂G₁이다. 같은 입력에 대한 두 출력을 더하는 병렬 연결은 G₁+G₂다. 물리 회로의 부하로 블록 자체가 달라지면 독립 전달함수 곱을 그대로 쓰지 않는다.

전달함수는 영 초기상태의 입력과 출력 관계를 표현한다. 초기 에너지에서 생긴 응답은 따로 다룬다. 다변수 행렬 블록은 곱의 순서가 중요하므로 scalar 교환법칙을 무조건 확대하지 않는다.

피드백을 두 방정식에서 유도한다

음의 피드백에서 오차 E=R−HY, 전진 블록 출력 Y=GE를 정한다. 대입하면 (1+GH)Y=GR이므로 T=Y/R=G/(1+GH)다. H는 출력이 센서를 거쳐 오차 계산으로 돌아오는 경로다.

양의 피드백이라면 E=R+HY라 분모가1−GH로 바뀐다. 블록 그림의 +/−를 식에 남긴다. 직접 전달이 있는 대수 루프는 해당 식이 풀릴 수 있는지도 확인한다. 단순한 분수 조작만으로 실현 가능성이나 내부 안정성을 증명하지 않는다.

극점과 내부 상태도 점검한다

음의 피드백이 오차를 줄이려는 구조여도 모든 G,H에서 안정해지는 것은 아니다. 닫힌 연결의 시간 응답과 극점을 확인한다. 외부 전달함수에서 상쇄된 불안정 모드는 내부 상태에 남을 수 있다.

센서의 지연·동역학을 H에 넣으면 같은 단위 피드백과 다른 분모가 생긴다. 센서가 측정하는 값과 실제 출력의 차이, 잡음의 진입 위치도 정한다. 이론적인 이득과 실제 안정 여유·측정 오차를 구별한다.

중간 과정을 따라가는 예제

G=2/(s+1), H=1인 음의 피드백의 T와 단위 계단에 대한 영 초기상태 출력을 구하라.

  1. T=[2/(s+1)]/[1+2/(s+1)]=2/(s+3)이다.

  2. 단위 계단 R=1/s라 Y=2/[s(s+3)]=(2/3)(1/s−1/(s+3))다.

  3. y(t)=(2/3)(1−e^(−3t)), t≥0다. y(0)=0, y′+3y=2를 직접 확인한다. 최종값은2/3으로 오차가0은 아니다.

닫힌 극점은−3이며 이 단위 계단의 최종 출력은2/3이다.

종이와 본문으로 직접 해보기

G=1/(s−2), H=1인 같은 음의 피드백의 극점과 영 초기 단위 계단 응답을 구하라.

힌트 보기

T를 먼저 계산하고 1/[s(s−1)]을 부분분수로 나눈다.

풀이 보기

T=1/(s−1)라 극점은+1이다. y=e^t−1로 증가한다. 음의 피드백이라는 부호만으로 안정화가 보장되지 않는 반례다.

오해와 반례

음의 피드백을 달면 언제나 안정하고 최종 오차도0이다.

두 주장 모두 별도 조건이 필요하다. 위 안정 예제의 오차는1/3이고 다른 예제는 불안정하다.

자기점검

음의 피드백 분모의 부호는?

답과 이유 보기

1+GH다.

E=R−HY를 대입해 이항했다.

H가 센서이면 T의 분자에 항상 H도 곱하나?

답과 이유 보기

아니다. 이 구조의 실제 출력은 G/(1+GH)다.

센서 출력 HY와 실제 출력 Y를 구별한다.

T의 불안정 극점이 상쇄되면 내부 안정성도 확정인가?

답과 이유 보기

아니다.

관측되지 않는 내부 상태를 별도로 확인해야 한다.

한 단계 더

G=2/(s+1), H=1/(s+1)인 음의 피드백은 T=2(s+1)/[(s+1)²+2]다. 극점−1±i√2를 계산하고 H=1의 극점−3과 비교한다. 실제 센서 지연을 임의로 무시하지 않는다.

소단원 14.4

오디오·센서 신호의 검산

매끈한 그래프가 실제 정보와 단위를 잘 보존했다는 증거일까?

준비 개념과 학습 목표

준비 개념

  • 표본률과 DFT

  • 선형 보정

  • 오차 제곱 평균

학습 목표

  • 자료의 단위·시각·모형을 먼저 기록한다.

  • 합성 신호와 센서 보정의 오류를 구별한다.

  • 처리 전후를 같은 기준으로 비교한다.

오디오는 표본 조건을 함께 기록한다

오디오 배열은 표본률 f_s와 함께 있어야 시간을 해석할 수 있다. N개 관측의 DFT 눈금은 k f_s/N이며 Nyquist보다 위 성분은 음의 주파수로도 해석된다. 실수 신호의 대칭 두 성분을 하나의 양의 성분과 혼동하지 않는다.

이상적 대역 제한과 f_s>2f_max라는 조건에서 표본을 논한다. 이미 접힌 성분을 나중에 디지털 저역통과했다고 원래 주파수를 복원했다고 하지 않는다. 실제 파일의 포화·누락·단위·창·정규화도 별도 확인해야 한다.

센서는 보정과 평활을 구별한다

가상 센서 모델 Y=a+bX+ε에서 Y는 센서 읽기, X는 기준 물리 값이다. b≠0이고 적용 범위가 맞으면 보정은 X̂=(Y−a)/b다. 계수의 추정과 불확도·드리프트·적용 범위는 실제 기준 자료로 별도 확인한다.

평활은 주변 시각을 섞는 처리다. 센서 오프셋을 없애는 보정과 다르며 변화하는 실제 신호에 지연 또는 오차를 만들 수 있다. 중심 평균은 미래 표본을 요구하지만 인과 평균은 과거만 사용한다. 같은 시각의 기준값과 비교하는 규약을 적는다.

같은 기준과 비교 자료로 검산한다

처리 전후의 최대값·평균·에너지·오차를 목적에 맞게 고른다. 잡음이라는 이름만으로 정답 기준이 되지 않으며 실제 음성을 제거한 필터가 청감 품질을 개선했다고 단정할 수 없다. 기준 자료를 필터 선택에 쓴 경우 최종 평가 자료와 역할도 구별한다.

아래는 정확히 정의한 합성 여덟 표본과 가상 센서 네 값이다. 실제 오디오 파일·센서·학생 실험을 실행하지 않았다. 작은 DFT 합과 분수 산술을 별도로 계산해 자체 모델에서의 일치만 확인한다.

중간 과정을 따라가는 예제

f_s=8000 Hz, N=8, x[n]=cos(2πn/8)+(1/5)cos(6πn/8)를 정의한다. 표준 비정규화 DFT에서 ±1000 Hz 성분만 남기는 마스크의 결과와 제거 오차 평균제곱을 구하라.

  1. DFT에서 k=1,7은 각각4이고 k=3,5는 각각4/5다. 다른 눈금은0이다. k7과k5는 각각−1000/−3000 Hz로도 해석한다.

  2. k1/7만 유지하고 역변환에1/8을 쓰면 y[n]=cos(2πn/8)다. 제거 성분은 (1/5)cos(6πn/8)다.

  3. 여덟 점 cos²의 합은4라 제거 제곱합은4/25, 평균제곱은1/50이다. 실제 고품질 오디오 개선 지표가 아니라 정의한 합성 모델의 오차다.

출력은1000 Hz 합성 정현파이며 제거 성분의 평균제곱은1/50이다.

종이와 본문으로 직접 해보기

가상 보정 a=100 counts, b=4 counts/unit에서 Y=[120,124,128,124]를 보정하라. X 기준은[5,6,7,6]이다. 첫 과거값X[−1]=5인 인과 두 점 평균을 같은 시각 기준과 비교하라.

힌트 보기

보정 후 S[n]=(X̂[n]+X̂[n−1])/2를 계산한다.

풀이 보기

보정값은[5,6,7,6] unit이다. 평균은[5,11/2,13/2,13/2]다. 기준과의 오차는[0,−1/2,−1/2,1/2], 평균제곱은3/16이다. 이 무잡음 예제에서는 평활이 오차를 만든다.

오해와 반례

평활한 센서 곡선은 언제나 정확도가 높다.

실제 변화를 늦추거나 왜곡할 수 있다. 보정·잡음·기준 시각을 분리해 같은 조건으로 오차를 확인한다.
