Subtopic 2.1

Linearity and Superposition

When does processing two sounds separately and adding the results equal adding the sounds first and processing the sum?

Preparation and learning goals

Preparation

  • The basic signals in this unit are real sequences x[n] defined for every integer n∈ℤ. Addition and scalar multiplication are computed at the same n. The discrete impulse δ[n] is 1 at n=0 and 0 elsewhere.
  • A system T is a function taking one allowed input signal to one output signal. T{x}[n] means applying T to the entire signal and then reading its value at n.
  • The input space for a linearity test must be a real vector space, closed under addition and multiplication by every real scalar. Do not combine two experiments with different initial states or domains as if they used a single T.

Learning goals

  • Read the superposition equation as a condition on all inputs and scalars.
  • Prove preservation of addition and scalar multiplication through operator expressions, or disprove it with a counterexample.
  • Explain the differences among linear, affine, and nonlinear systems and the role of a fixed initial state.

Comparing two inputs and two scalars at once

T is linear when T{αx₁+βx₂}=αT{x₁}+βT{x₂} holds at every n for all allowed x₁,x₂ and all real α,β. This requires both additivity and homogeneity. Agreement for one particular pair of signals does not prove the full definition, whereas a single failure gives a counterexample to linearity.

For T{x}[n]=2x[n]−x[n−1], expand addition and scalar multiplication at the corresponding indices. Grouping 2(αx₁[n]+βx₂[n])−(αx₁[n−1]+βx₂[n−1]) by α and β gives the same combination of the two outputs. This identity holds for all real sequences; it is not an experimental result about saturation, noise, or initial states of a physical amplifier.

A straight line is different from linearity

T{x}[n]=2x[n]+1 produces output 1 even for input 0, so it is not linear. It is an affine system with a constant offset. A linear T must satisfy T{0}=T{0·x}=0. Checking T{0}=0 alone, however, is insufficient. Squaring, T{x}[n]=x[n]², also maps 0 to 0 but maps twice the input to four times the output.

T{x}[n]=a[n]x[n], with a predetermined coefficient at each time, is linear even if a varies. Thus linearity does not mean time invariance. Also, adding inputs that carry physical units requires matching quantities and units. Do not interpret a model that arbitrarily adds volts and temperature as the same kind of scalar as an experimental statement.

Including initial state in the contract

The difference equation y[n]=y[n−1]+x[n], n≥0, alone does not determine a unique output unless y[−1] is specified. With initial state fixed at 0, y[n]=Σ(k=0..n)x[k] is linear in the input. With a fixed c≠0, y[n]=c+Σx[k], which is not linear because input 0 yields output c.

If the initial state is included as an input coordinate and (x,c) is scaled together, linearity can be discussed in a different, extended model. This is a different contract from a system with fixed c. Before discussing superposition or time invariance, identify the time domain, allowed signals, and initial conditions.

A worked example, step by step

Apply T{x}[n]=2x[n]−x[n−1] to the two-sided signals x₁=δ[n], x₂=δ[n−1], with α=2,β=−1, and check superposition.

  1. The combined input x=2δ[n]−δ[n−1] has values 2,−1,0 at n=0,1,2, respectively, and is 0 elsewhere.
  2. T{x₁} has values 2,−1,0 at n=0,1,2, while T{x₂} has values 0,2,−1.
  3. The combined output 2T{x₁}−T{x₂} has values 4,−4,1 at n=0,1,2.
  4. Direct evaluation of T{x} also gives n=0: 4−0=4; n=1: −2−2=−4; n=2: 0−(−1)=1, and 0 elsewhere. Distinguish agreement in this example from the general expansion proof above.

T{2x₁−x₂}=2T{x₁}−T{x₂}; the nonzero output values are (4,−4,1).

Try it with paper and the lesson

For the squaring system, compare the two sides with x₁=x₂=δ[n] and α=β=1. Separately, feed input 0 into an accumulator with initial c=3 and test a necessary condition for linearity.

Show hint

Squaring after addition gives 2²; squaring separately gives 1²+1². Keep the initial state fixed.

Show solution

At n=0, the squared combined input gives 4 while the sum of outputs gives 2, so the system is nonlinear. The accumulator with initial 3 produces 3 at every n≥0 even for input 0, so its fixed-initial-state input-output map is nonlinear and affine. Both are paper counterexamples.

Misconception and counterexample

If T maps 0 to 0, it is linear; a straight-line graph is always linear.

Squaring maps 0 to 0 but fails superposition: 4≠2. The graph of 2x+1 is a straight line, but its output for input 0 is 1. All input and scalar conditions in the definition of linearity must hold.

Check your understanding

Is T{x}=−3x nonlinear because the coefficient is negative?

Show answer and reasoning

It is linear.

Multiplication by a fixed real coefficient preserves addition and multiplication by every real scalar.

Is T{x}[n]=n x[n] linear?

Show answer and reasoning

It is linear.

n is a predetermined coefficient independent of the input, so superposition can be expanded. Time invariance is a separate test.

Can the sum of outputs from an accumulator with fixed c=2 and one with initial 0 be used directly as evidence of superposition for the same system?

Show answer and reasoning

Not directly.

Different fixed initial states give different input-output functions, and the initial offset also affects the sum.

Explore further

Extension: If additivity T(x+y)=Tx+Ty and real homogeneity T(αx)=αTx hold for all inputs, then T(αx+βy)=T(αx)+T(βy)=αTx+βTy. Conversely, in the superposition definition, taking the scalars as 1,1 or taking β=0 yields these properties, respectively. The result extends to finite linear combinations by induction. Moving the infinite signal decomposition Σ_k x[k]δ[n−k] into or out of T, however, requires additional conditions such as appropriate convergence and continuity of the operator. The definition of finite superposition alone does not justify every interchange of infinite sums.

Subtopic 2.2

Time Invariance

If the input begins two samples later, will the output also shift two samples later in exactly the same way?

Preparation and learning goals

Preparation

  • An integer delay k of a two-sided signal is S_kx[n]=x[n−k]. For k>0 this shifts to the right: the value at input n=0 appears at n=k.
  • Time invariance means time shifting commutes with system processing: T S_k=S_k T. Compare processing a shifted input with shifting the original output.
  • This definition assumes the allowed input space is closed under integer shifts. A fixed starting time, finite window, or boundary rule requires a separately specified shift contract.

Learning goals

  • Substitute indices correctly for both orders of processing.
  • Judge time invariance and linearity independently.
  • Distinguish initialization, finite boundaries, and physical delay from signal shifts.

Moving the same time scale together

If T is time invariant, T{S_kx}[n]=(T{x})[n−k] holds at every n for every allowed x and integer k. On one side, shift only the input in the system expression first; on the other, replace n by n−k in the entire output expression. Do not leave an explicit time coefficient unchanged on the latter side and then declare the expressions equal.

For the fixed two-sample average T{x}[n]=(x[n]+x[n−1])/2, the output from a shifted input is (x[n−k]+x[n−1−k])/2. The shifted-output expression is identical. Delay k is measured in sample positions; converting it to physical time requires a separately specified sample interval Δt. This formula is not a measurement of instruction processing time or deadline delay on a computing device.

A counterexample with a time-dependent coefficient

For T{x}[n]=n x[n], processing the shifted input gives n x[n−k], whereas shifting the original output gives (n−k)x[n−k]. For example, x[n]=1, k=1,n=2 yields 2 versus 1, so the system is time varying. This system is linear, as noted earlier, which disproves the inference that linearity implies time invariance.

Conversely, for T{x}[n]=x[n]², both orders give x[n−k]², so the system is time invariant. It fails superposition and is nonlinear. A system is called LTI only when it is both linear and time invariant; test each property. Fixed coefficients alone do not automatically imply every other property either.

The effects of the input domain and starting rule

The fixed-start accumulator y[n]=Σ(j=0..n)x[j], n≥0, differs from the two-sided accumulation expression Σ(j=−∞..n)x[j]. The latter requires specifying an input domain where the sum converges. Treating the former, which includes a starting point at 0, as a system closed under every integer shift omits its domain and initial conditions.

When shifting a finite image or record, filling the exterior with 0 or wrapping it around can change the result. A fixed filter on an infinite grid may be time invariant, while cropping to a finite window and creating new boundaries may not commute with shifting. Check whether the same rule was used on both paths, and distinguish this property from other meanings such as temporal stability or reproducibility of a device.

A worked example, step by step

Apply T{x}[n]=(x[n]+x[n−1])/2 to the two-sided signal x[0]=1,x[1]=2 and 0 elsewhere. Compare the two paths for an input delay k=2.

  1. The original output is y[0]=(1+0)/2=1/2, y[1]=(2+1)/2=3/2, y[2]=(0+2)/2=1, and 0 elsewhere.
  2. The delayed input z[n]=x[n−2] has z[2]=1,z[3]=2, and 0 elsewhere.
  3. T{z} has values 1/2,3/2,1 at n=2,3,4, and is 0 elsewhere.
  4. S₂y[n]=y[n−2] has the same values at the same positions 2,3,4. The general indexed expression proves time invariance for all x,k; this table is one instance.

Both paths give (1/2,3/2,1) at n=2,3,4.

Try it with paper and the lesson

Apply U{x}[n]=n x[n] to x[n]=1 and write both paths for k=1,n=2. Also compare the shift expressions for V{x}[n]=x[n]².

Show hint

Shifting only the input to U does not change its time coefficient n. Shifting the output changes every occurrence of n in the output expression.

Show solution

U S₁x[2]=2 and S₁Ux[2]=1 differ, so U is time varying. V S_kx[n]=x[n−k]²=S_kVx[n], so V is time invariant but not linear. These are all paper calculations.

Misconception and counterexample

Time invariance means the output does not change over time.

Time invariance concerns commuting the system rule with shifts. The output (1/2,3/2,1) of the fixed averaging filter changes when the input changes, yet the system is time invariant. This differs from having a constant output.

Check your understanding

For delay k=3, x[n−3], to which output position does input position 0 move?

Show answer and reasoning

Position 3.

n−3=0 implies n=3.

Does the time variation of n x[n] also disprove linearity?

Show answer and reasoning

No.

It preserves input addition and scalar multiplication but not time shifts.

If exterior values of a finite window are filled differently on the two paths, is this a time-invariance test?

Show answer and reasoning

It is not a test of the same system.

The input-output contract, including the boundary rule, must be held identical.

Explore further

Extension: Suppose T₁,T₂ are time invariant on the same shift-invariant signal domain and every intermediate output is in the next system’s allowed domain. Then (T₂∘T₁)S_k=T₂(S_kT₁)=S_k(T₂∘T₁), so the series composition is time invariant. Linearity was not used here. A parallel sum of outputs is also time invariant by the two shift identities. However, commutativity—getting the same output after exchanging the order of T₁,T₂—does not follow from time invariance alone. The integer k for discrete shifts and real delay τ for continuous time belong to different index domains; translation in two image coordinates is also defined on a separate domain.

Subtopic 2.3

Causality, Memory, and Invertibility

Does recovering a delayed record mean it can be recovered in real time without future input?

Preparation and learning goals

Preparation

  • For two-sided real sequences, distinguish the present n, past j<n, and future j>n. Offline computation with the entire signal known in advance differs from computation using only input received up to now.
  • Memorylessness means the output at n depends only on the input at that same time. Causality means two inputs that agree up to the present give the same present output. Invertibility means the allowed input can be recovered uniquely from the output.
  • To test invertibility, check injectivity on the input space. The inverse is defined on the actual range of outputs; causality, stability, and efficient implementation must be checked separately.

Learning goals

  • Define causality, memory, and invertibility separately and construct counterexamples.
  • Show noninvertibility through distinct inputs with the same output.
  • Explain the domain of the inverse and limits on real-time implementation.

Using only the present, or using up to the present

For a memoryless T, x₁[n₀]=x₂[n₀] implies T{x₁}[n₀]=T{x₂}[n₀]. For a causal T, when the two inputs agree at every j≤n₀, their present outputs must agree. Therefore a memoryless system is causal, but a causal system may use the past and need not be memoryless.

The delay D{x}[n]=x[n−1] uses the past, so it has memory but is causal. The advance A{x}[n]=x[n+1] reads the future and is noncausal on the general two-sided input space. To disprove causality, choose two inputs that agree through the present but differ in one future term, and show different present outputs. Memory here concerns signal dependence, not the number of RAM bytes used by a program.

Can distinct inputs be distinguished?

The key to invertibility is injectivity: if the entire outputs T{x₁}=T{x₂} agree, then x₁=x₂ must follow. The inverse of delay D is D⁻¹{y}[n]=y[n+1], which recovers the input when the full two-sided output record is available. This inverse, however, requires a future output value and is not causal. Causality of the original system and of its inverse are separate properties.

Squaring, T{x}[n]=x[n]², is noninvertible on all real sequences because x≡1 and x≡−1 give the same output 1. Restricting allowed inputs to sequences nonnegative at every position makes it invertible via the nonnegative square root. This restricted space is not a vector space closed under multiplication by every real scalar; do not confuse it with the earlier definition of linearity.

How initial information and boundaries change recovery

The discrete difference y[n]=x[n]−x[n−1] is noninvertible on the two-sided space because all constant sequences map to 0. If a reference x[−1] is given and outputs for n≥0 are received, x[n]=y[n]+x[n−1] recovers inputs in sequence. The known initial value is information added to the contract, not injectivity gained by the original system.

If the final delayed value is cropped from a finite record, the original last input may not appear in the output window. Invertibility of a cropped output of the same length differs from invertibility with the whole infinite record. Practical recovery must also consider noise, rounding, allowed signal ranges, and arrival of future data; existence of a mathematical inverse is not validation of recovery on a device.

A worked example, step by step

Find and invert the one-sample delay y[n]=x[n−1] of a two-sided signal with x[0]=2,x[1]=−1 and 0 elsewhere. Judge memory, causality, and invertibility separately.

  1. y[0]=x[−1]=0, y[1]=x[0]=2, y[2]=x[1]=−1, and 0 elsewhere.
  2. The present y[n] uses one past input, so the system is causal. Two inputs with the same present value but different past values can have different outputs, so it has memory.
  3. In the full output record, y[n+1]=x[n], giving the unique recovery x[0]=y[1]=2,x[1]=y[2]=−1.
  4. The inverse uses future output y[n+1], so it is noncausal. This is recovery from a paper record containing all values, not an experiment recovering the present immediately on a real device.

The delay is causal, has memory, and is invertible with the two-sided record. Its inverse, the advance, is noncausal.

Try it with paper and the lesson

For M{x}[n]=(x[n]+x[n−1])/2, check whether x[n]=(−1)ⁿ and the zero signal produce the same output. Separately, compare causality, memorylessness, and invertibility of P{x}[n]=x[n]² on all real sequences and on nonnegative sequences.

Show hint

Two neighboring terms of the alternating sequence sum to 0. The sign information lost by squaring depends on the input domain.

Show solution

M maps two distinct two-sided signals to the same 0, so it is noninvertible. P uses only the present and is memoryless and causal, but cannot distinguish ±1 on all real sequences and is noninvertible there. Restricted to nonnegative sequences, it is inverted by √y. The activity is a paper calculation.

Misconception and counterexample

A causal system has no memory, and the inverse of an invertible system is always causal.

Delay is causal but reads the past and has memory. Its inverse, advance, reads the future and is noncausal. Required present/past information and mathematically unique recovery are different conditions.

Check your understanding

Is output x[n]+x[n+1] causal for general two-sided inputs?

Show answer and reasoning

It is noncausal.

Two inputs agreeing through the present but differing only at n+1 produce different present outputs.

If squaring real inputs distinguishes input 0 from input 1, is it invertible?

Show answer and reasoning

That alone is insufficient.

It maps 1 and −1 to the same output, violating the requirement of injectivity for all inputs.

If a mathematical inverse of delay exists, can it always recover a last input lost by cropping to a finite window?

Show answer and reasoning

No.

If the needed output in the full record has disappeared outside the window, additional information is required.

Explore further

Extension: If T is injective, for each y∈T(X) there is exactly one x, so defining I(y)=x gives I∘T=id_X. Conversely, if I∘T=id_X exists, applying I to Tx₁=Tx₂ gives x₁=x₂, proving injectivity. The inverse must be defined on the actual range T(X). The inverse of delay likewise uses a domain containing every integer position. The constant nullspace of differencing and the alternating nullspace of averaging show information loss for these respective operators. Adding initial conditions or positivity constraints changes the allowed input set itself, so injectivity must be tested again on that new set.

Subtopic 2.4

The Definition of BIBO Stability

If the input is small at every instant, must the output remain within some bound for all time?

Preparation and learning goals

Preparation

  • A signal is bounded when there is a finite M such that |x[n]|≤M at every time. This is stronger than a few small samples or each term being individually finite.
  • BIBO means bounded-input bounded-output. Every allowed bounded input must yield an output bounded over the entire time domain. One counterexample input can disprove it.
  • In discrete time, ||x||∞=sup_n|x[n]|. The basic setting is two-sided signals; the fixed-start accumulator counterexample separately uses n≥0 and y[−1]=0. Distinguish BIBO from linearity, causality, and finite energy.

Learning goals

  • Explain the all-time and all-bounded-input conditions in BIBO.
  • Prove an output bound with inequalities and construct an accumulator counterexample.
  • Distinguish a linear gain bound from nonlinear boundedness and conditions for LTI systems.

When small values keep accumulating

For y[n]=3x[n]−2x[n−1], if all |x|≤M, the triangle inequality gives |y[n]|≤3M+2M=5M. This finite bound works regardless of the input’s shape, so the system is BIBO stable. Distinguish calculation of a particular table from an inequality proof for every input and every time.

By contrast, feeding x[k]=1 into the accumulator with fixed initial 0, y[n]=Σ(k=0..n)x[k], n≥0, gives y[n]=n+1. The input bound 1 is fixed, but the output has no finite all-time bound. Even though the calculation terminates and the value is finite for each finite n, BIBO fails. Not observing divergence in a finite-length test does not guarantee a property over infinite time.

Do not conflate other properties

Squaring is nonlinear but BIBO stable, since input bounded by M gives output ≤M². This bound depends on M. A single K satisfying ||Tx||∞≤K||x||∞ for every input size, as in a linear gain bound, is stronger than the general BIBO property of squaring. Check linearity or other assumptions when claiming such a common K.

n x[n] is linear, causal, and memoryless, yet is BIBO unstable because x≡1 gives output n. Conversely, advance y[n]=x[n+1] is noncausal but preserves the bound M and is BIBO stable. Thus stability does not imply causality, linearity, or memorylessness. Internal stability, such as a state returning to its initial point, and safety of a physical device are also different concepts.

Connecting impulse responses to LTI stability

If a discrete LTI system is defined for every bounded input by convolution y[n]=Σ_k h[k]x[n−k], and Σ_k|h[k]|=H<∞, then |y[n]|≤MH. Absolute convergence supports both the definition of the sum and this bound. For h=3δ[n]−2δ[n−1], H=5. The finite filter in this unit directly satisfies these conditions.

For continuous-time integral convolution with an ordinary function h, h∈L¹ also gives the corresponding bound. However, δ is a distribution, not an ordinary function, so do not simply integrate |δ| as though it were an ordinary function. The identity system y=x is stable and has impulse response δ, illustrating why this distinction matters. Detailed derivation of convolution connects to the next unit.

A worked example, step by step

Feed T{x}[n]=3x[n]−2x[n−1] an input satisfying |x[n]|≤2 at every position. Find a general output bound and show whether it can be attained.

  1. Apply the triangle inequality |3x[n]−2x[n−1]|≤3|x[n]|+2|x[n−1]|.
  2. Each input magnitude is ≤2, so the output magnitude at every n is ≤3·2+2·2=10.
  3. Choose an allowed input with x[0]=2,x[−1]=−2 and 0 elsewhere, obtaining y[0]=6+4=10.
  4. The bound 10 is attained within this input class, so it cannot be replaced by a smaller common bound. Checking only this signal’s output would not prove general BIBO stability; the first inequality is the general justification.

The all-time output bound is 10, and an input attains 10 at n=0.

Misconception and counterexample

If each output value is finite, or the system is linear, then it is BIBO stable.

The accumulator’s n+1 is finite at each n but has no finite all-time bound. The linear system n x[n] also gives output n for input 1 and is unstable. Check the order of quantifiers and the entire time domain.

Check your understanding

If |x|≤4 and y=−2x[n−3], what is an all-time bound?

8.

The magnitude is multiplied by 2; shifting does not change the input bound.

Does the BIBO bound M² for y=x² give one linear gain K valid for every M?

Show answer and reasoning

No.

For constant input M>0, the output/input ratio is M, which can grow without bound. BIBO itself still holds.

If the accumulator is tested only at n=0..100 and all values are finite, is infinite-time BIBO proved?

Show answer and reasoning

No.

The output n+1 is bounded in a finite window but has no finite bound as n→∞.

Explore further

Extension: Consider why absolute summability is also necessary for discrete convolution. For real h, choose x[−k]=sign(h[k]), with sign(0)=0, so |x|≤1. The sum at n=0 is Σ_k|h[k]|; if it is infinite, a finite output cannot be defined for this input. Under the standard contract that convolution is defined and yields bounded outputs for every bounded input, h∈ℓ¹ is therefore necessary. Sufficiency is the MH inequality above. For complex h, choose x[−k]=conj(h[k])/|h[k]| when h[k]≠0, and x[−k]=0 when h[k]=0. Do not apply this LTI equivalence to arbitrary nonlinear systems or restricted input sets. Extending it to all continuous-time distribution kernels requires separate measure and distribution theory.
