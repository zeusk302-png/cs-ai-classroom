소단원 5.1

변수·도메인·제약

시간표에서 겹치지 않게 배정한다는 말을 컴퓨터가 검사할 수 있는 규칙으로 어떻게 바꿀까?

준비 개념과 학습 목표

준비 개념

  • 집합은 허용하는 값들의 모음이다.

  • 논리 조건은 참/ 거짓을 판정한다.

  • CSP(constraint satisfaction problem)는 제약만족 문제의 영어 약어다.

학습 목표

  • 문제를 변수· 값 집합· 허용 관계로 작성한다.

  • 부분 배정과 해를 구별한다.

세 구성 요소를 따로 명세하기

CSP는 변수 X_i, 각 변수의 도메인 D_i, 그 값들이 만족해야 할 제약의 모음으로 정의한다. 변수는 결정해야 할 대상, 도메인은 그 대상이 취할 후보 값, 제약은 후보 조합의 허용 여부다. 변수마다 도메인이 같을 필요는 없다.

예를 들어 강의 A,B,C의 시간을 변수로 하고 1,2,3교시를 도메인으로 둔다. 강사가 같은 A,B에는 A ≠B를, 연속 수업이 필요한 B,C에는 C =B +1을 둔다. 교실 수나 순서 등 실제 요구가 빠지면 계산이 맞아도 잘못 모형화한 답을 얻는다.

제약의 범위와 그래프

A ≠3 같은 단항 제약은 A 도메인에서 3을 제거할 수 있다. A ≠B 같은 이항 제약은 두 변수의 값 쌍을 검사한다. A,B,C 모두 다르다는 다항 제약은 세 변수 전체에 대한 규칙이다. 불등호나 표에 있는 허용 튜플로 제약을 표현할 수 있다.

이항 제약 그래프의 정점은 변수이고 간선은 해당 두 변수를 연결하는 규칙이다. 간선 자체가 값을 배정하는 것은 아니다. 다항 제약은 일반 간선 하나로 내용을 완전히 표현하기 어려워 별도 관계나 보조 변수가 필요할 수 있다.

부분 배정, 일관성, 완전한 해

부분 배정은 일부 변수의 값만 결정한 상태다. 이미 정해진 값들 사이에 위반이 없다고 해서 나머지를 항상 채울 수 있는 것은 아니다. 완전한 해는 모든 변수를 도메인 안의 값으로 정하고 모든 제약을 만족한 배정이다.

제약 만족은 일단 허용되는 답을 찾는 문제다. 가장 빠른 시간표를 원한다면 목적 함수까지 추가한 최적화 문제가 된다. CSP가 일반적으로 어렵더라도 특별한 구조· 적은 변수에는 간단한 해법이 가능하므로 모든 CSP가 똑같이 비싸다고 단정하지 않는다.

중간 과정을 따라가는 예제

A,B,C의 도메인은{1,2,3}이고 A ≠B,C =B +1,A ≠3이다. 가능한 완전해를 모두 구하라.

  1. C ≤3이므로 B는 1 또는 2이며 B =3은 불가능하다.

  2. B =1이면 C =2다. A는 B와 다르고 3 아니므로 A =2다. 해(2,1,2)를 얻는다.

  3. B =2이면 C =3다. A는 2 아니고 3 아니므로 1이다. 해(1,2,3)를 얻는다.

  4. A와 C를 다르게하라는 조건은 없으므로 첫 해에서 둘이 2인 것은 허용된다.

순서(A,B,C)의 해는(2,1,2),(1,2,3)두 개다.

종이와 본문으로 직접 해보기

같은 문제에 A ≠C를 추가하면 어떤 해가 남는지 종이에 검사하라.

힌트 보기

새 제약은 기존 해를 다시 검사한다.

풀이 보기

(2,1,2)는 A =C 라 탈락하고(1,2,3)만 남는다. 조건 추가는 해 집합을 넓히지 않으며 이 예에서는 줄인다.

오해와 반례

세 변수가 있으면 자동으로 모두 서로 다른 값이어야한다.

변수 이름이 서로 다른 것과 배정 값이 서로 다른 것은 별개다. A ≠C 조건이 없을 때(2,1,2)는 정당한 해다.

소단원 5.2

백트래킹과 변수선택

한 시간 배정이 막히면 처음부터 모두 지워야 할까, 어느 선택으로 돌아갈까?

준비 개념과 학습 목표

준비 개념

  • 부분 배정은 일부 변수만 정한 상태다.

  • 깊이 우선 탐색은 한 갈래를 먼저 따라간다.

  • MRV(minimum remaining values)는 최소 남은 값, LCV(least constraining value)는 이웃 후보를 가장 덜 제한하는 값이라는 뜻이다.

학습 목표

  • 백트래킹에서 값 복구를 추적한다.

  • MRV와 LCV의 역할을 구별한다.

한 변수를 정하고 실패한 갈래를 되돌리기

백트래킹은 미배정 변수 하나를 고르고 도메인 후보를 하나씩 대입한다. 이미 배정한 변수들과 충돌하면 즉시 그 후보를 버린다. 충돌이 없으면 다음 변수로 내려가며 후속 선택이 모두 막히면 현재 값을 취소하고 다음 후보로 돌아온다.

모든 변수 값을 채워 모든 제약을 만족하면 해다. 유한 도메인의 모든 후보를 빠짐없이 검사한다면 해의 존재를 놓치지 않지만 최악 시간은 지수적일 수 있다. 가지치기는 어떤 값이 불가능하다는 정당한 근거가 있을 때만 한다.

MRV는 변수,LCV는 값을 고른다

MRV는 현재 남은 합법 후보가 가장 적은 변수를 먼저 정한다. 실패할 수 있는 빡빡한 변수를 빨리 보자는 원리다. 동률에는 미배정 이웃과의 제약 수가 많은 변수를 먼저 고르는 등 명시한 보조 규칙을 쓸 수 있다.

LCV는 선택한 변수의 여러 값 중 이웃의 후보를 가장 적게 지우는 값을 먼저 시험한다. MRV가 변수 순서라면 LCV는 값 순서다. 휴리스틱은 탐색 순서를 바꾸는 도구이지 어떤 값도 근거 없이 삭제하는 도구가 아니다. 계산 비용이 들고 항상 빨라지지는 않는다.

복구와 중복 순서를 명세하기

같은 완전 배정은 A를 먼저 정하든 B를 먼저 정하든 같은 대상이다. CSP는 경로 순서보다 최종 값의 조합을 찾으므로 각 깊이에서 한 변수를 선택해 배정 순서 중복을 줄일 수 있다. 중간 부분 배정의 충돌 검사는 완전 배정만 검사하는 것보다 일찍 실패를 발견한다.

전파를 함께 사용하면 현재 값 취소뿐 아니라 그 갈래에서 삭제한 도메인 값도 복원해야 한다. 복원하지 않으면 다른 갈래의 정당한 해가 사라진다. 전파 기록이나 도메인 복사 등의 방법이 필요하며 실제 구현 실행은 이 종이 활동과 별도다.

중간 과정을 따라가는 예제

도메인 A ={1,2},B ={1,2},C ={1}이고 A ≠B,B ≠C다. MRV 후 남은 변수는 B,A 순으로 하고 값은 오름차순으로 시험하라.

  1. C 후보가 1개라 MRV는 C를 골라 1을 배정한다.

  2. B에서 1을 시험하면 B ≠C에 충돌하므로 즉시 버린다.

  3. B =2를 정하면 A =1이 A ≠B를 만족한다.

  4. 모든 변수 배정(A,B,C)=(1,2,1)과 두 제약을 확인한다. 잘못된 B =1 때 C를 바꾸려하지 않고 B 다음 후보를 시험했다.

MRV로 단일 후보 C부터 시작하고 충돌 후 B =2로 돌아가 해(1,2,1)를 찾는다.

종이와 본문으로 직접 해보기

X ={1,2},Y ={1,2},Z ={1}이고 X ≠Y,X ≠Z다. X 값을 LCV로 비교하라.

힌트 보기

X =1/2각각이 이웃 Y,Z의 후보를 몇 개 지우는지 센다.

풀이 보기

X =1은 Y의 1과 Z의 1을 지워 총 2개이고 Z가 빈다. X =2는 Y의 2 한 개만 지워 Z =1을 보존한다. LCV는 2를 먼저 시도한다. 일관성 검사도 X =1의 실패를 알릴 수 있다.

오해와 반례

MRV는 전체 문제에서 원래 도메인이 작은 변수를 한 번 고르면 끝이다.

현재 부분 배정/ 전파에 따라 남은 후보 수가 변한다. 처음 2개였던 변수가 후속 제약으로 1개가 되면 새 MRV 선택에서 더 급해질 수 있다.

소단원 5.3

호일관성과 제약전파

후보 숫자 하나를 지우는 것만으로 멀리 있는 다른 변수의 후보도 줄어들 수 있을까?

준비 개념과 학습 목표

준비 개념

  • 이항 제약은 두 변수의 허용 값 쌍이다.

  • 도메인은 아직 가능한 값의 집합이다.

  • AC3(arc consistency algorithm 3)는 호 일관성을 반복 검사하는 알고리즘의 이름이며, 큐는 먼저 넣은 항목을 먼저 꺼내는 대기 목록이다.

학습 목표

  • 방향 있는 호의 지원 값을 검사한다.

  • 호 일관성이 완전해를 보장하지 않음을 증명한다.

지원 값이 없는 후보를 제거하기

호 Xi →Xj는 Xi의 각 후보 x에 대해 Xj 도메인에 제약을 만족하는 y가 하나라도 있는지 검사한다. 이 y 를 지원 값이라고 한다. 모든 x에 지원이 있으면 그 방향 호가 일관적이다. 지원이 전혀 없는 x는 전체 해에도 쓸 수 없으므로 제거한다.

모든 x에 같은 y 하나가 맞아야 한다는 뜻은 아니다. 각 x별로 다른 지원이 있어도 된다. 호는 방향을 가지므로 Xi →Xj와 Xj →Xi를 모두 검사해야 한다. 단순히 서로 도메인에 공통 숫자가 있는지를 검사하는 것도 아니다. 허용 관계는 부등식 등이 될 수 있다.

삭제의 영향을 다시 전파하기

AC3는 검사할 방향 호들을 큐에 넣는다. Xi →Xj 검사로 Xi의 값이 줄면 Xi 를 지원으로 보던 다른 이웃 Xk →Xi를 다시 등록한다. 도메인이 비면 모순이며, 큐가 빌 때까지 반복하면 이항 네트워크의 호 일관성에 이른다.

forward checking은 새로 배정한 변수의 바로 이웃에서 충돌 값을 제거한다. 호 일관성은 미배정 변수 사이에서도 지원 상실을 연쇄 추적할 수 있다. 둘 다 전체 검색을 대체하는 만능 증명은 아니지만 불가능한 갈래를 미리 줄인다.

국소 지원과 전체 공동 해의 차이

삼각형 A,B,C가 각각{빨강, 파랑}이고 모든 쌍이 서로 다른 색이어야 한다고 하자. 각 호에서 빨강의 지원은 상대 파랑이고 파랑의 지원은 상대 빨강이다. 따라서 모든 방향 호가 일관적이며 삭제할 값이 없다.

그러나 A를 빨강으로 정하면 B,C가 둘 다 파랑으로 강제되고 B ≠C를 어긴다. A가 파랑이어도 대칭적으로 실패한다. 모든 쌍별 지원이 같은 하나의 전체 배정에서 동시에 성립한다는 보장은 없다. 호 일관성 성공 후에도 백트래킹이 필요할 수 있다.

중간 과정을 따라가는 예제

A ={0,1,2},B ={1,2},C ={2,3}, 제약 A<B와 B<C가 있다. C =2를 정한 뒤 제거 과정을 추적하라.

  1. C ={2}로 줄인다. B →C에서 B =2는 2<2를 만족하는 지원이 없으므로 삭제한다. B ={1}이다.

  2. B가 줄어 A →B를 재검사한다. A =1,2는 1보다 작지 않으므로 삭제하고 A ={0}만 남는다.

  3. 반대 호 B →A는 1의 지원 0이 있고 C →B는 2의 지원 1이 있다. 더 삭제할 값이 없다.

  4. 최종 배정 0<1<2 를 직접 확인한다. 바로 이웃 B만 보는 forward checking 후에도 A 전파가 추가로 필요했다.

최종 도메인 A ={0},B ={1},C ={2}다. 연쇄 전파는 추측 없는 삭제다.

종이와 본문으로 직접 해보기

두 색 삼각형의 A →B와 A →C에서 각 A 색의 지원 값을 적고 완전해가 없는 이유를 설명하라.

힌트 보기

각 쌍에는 반대 색이 있지만 B,C도 서로 달라야한다.

풀이 보기

A 빨강은 B 파랑/ C 파랑 각각을 지원으로 가지고 A 파랑도 B 빨강/ C 빨강 지원을 가진다. 따로 보면 문제 없으나 동시 배정에서는 B =C가 되어 마지막 간선이 실패한다.

오해와 반례

호 일관성 후 모든 도메인이 비어 있지 않으면 해가 존재한다.

두 색 삼각형은 모든 호가 일관적이고 도메인도 2개지만 해가 없다. 도메인 공집합은 불가능 증거이나 비어 있지 않음은 일반적으로 가능 증거가 아니다.
