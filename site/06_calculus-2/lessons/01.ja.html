小節 1.1

部分積分と繰り返しの適用

x と eˣ をそれぞれ積分してから掛けると、x eˣ の積分になるだろうか？

準備する概念と学習目標

準備する概念

  • 関数の短い復習：入力 x から出力 f(x) が決まる。導関数 f′(x) は、微小な入力変化に対する出力変化の比の極限である。
  • 原始関数：F′=f なら F は f の原始関数である。連結な区間では、すべての原始関数は F+C の形になる。
  • 基本規則：(x²)′=2x、(eˣ)′=eˣ、(uv)′=u′v+uv′。連続な f の定積分は符号付きの累積量であり、∫ₐᵇf=F(b)−F(a)。

学習目標

  • 積の微分から部分積分の公式を導く。
  • 新しい積分が簡単になる理由を基に u,dv を選ぶ。
  • 部分積分の繰り返しと定積分の境界項を計算し、微分で確かめる。

積を積分する規則を導く

積の微分は (uv)′=u′v+uv′ である。同じ区間で両辺を積分して移項すると、∫uv′dx=uv−∫u′vdx+C となる。du=u′dx、dv=v′dx の記号で ∫u dv=uv−∫v du と短く書ける。dv 全体には dx が含まれ、v は v′ の原始関数である。

この単元では、u,v が区間上で連続な導関数を持つという十分条件を使う。定積分では ∫ₐᵇuv′dx=[uv]ₐᵇ−∫ₐᵇu′vdx である。不定積分の答えには定数 C が必要で、定積分の答えには境界値の差が必要である。

公式だけでなく選択の効果を見る

x eˣ で u=x、dv=eˣdx を選ぶと du=dx、v=eˣ なので、新しい積分は簡単な ∫eˣdx になる。逆に u=eˣ、dv=x dx と選ぶと、新しい積分に x²eˣ が現れ、通常は難しくなる。どちらの選択も公式としては正しいが、解く戦略として同じように役立つわけではない。

多項式は微分するたびに次数が下がるため、指数関数や三角関数との積の積分では、多項式を u に選ぶと有利なことが多い。これは役立つ戦略であり、すべての積分を解く普遍的な法則ではない。例えば ∫e^(x²)dx は、この戦略だけでは初等的な原始関数を得られない。

繰り返しと独立した確認

∫x²eˣdx の最初の部分積分で、x²eˣ−2∫xeˣdx を得る。再び部分積分すると多項式の次数が 0 まで下がり、計算が終わる。積分を終えるまで各行に残りの積分を書けば、係数と符号を見落としにくくなる。

確認は、答えを微分して元の被積分関数を回復することである。式がもっともらしいことや数点で合うことより強い確認になる。特異点がある式では、どの連結な区間で微分・積分ができるかも別に書く必要がある。

途中の過程をたどる例題

実数 x について ∫x²eˣdx と ∫₀¹x²eˣdx を求めよう。

  1. u=x²、dv=eˣdx として I=x²eˣ−2∫xeˣdx。
  2. J=∫xeˣdx で u=x、dv=eˣdx とすると J=xeˣ−eˣ+C。
  3. したがって I=eˣ(x²−2x+2)+C。
  4. 微分すると eˣ(x²−2x+2)+eˣ(2x−2)=x²eˣ。
  5. F(1)=e、F(0)=2 なので、定積分は e−2。

不定積分は eˣ(x²−2x+2)+C、定積分は e−2。e−2>0 は、区間上で x²eˣ≥0 であることとも合う。

紙と本文で試してみよう

紙に ∫x e^(2x)dx の計算を書き、結果を微分しよう。

ヒントを見る

v=e^(2x)/2。指数の内側の 2 のために 1/2 が必要である。

解答を見る

u=x、dv=e^(2x)dx を選ぶと、(x/2)e^(2x)−(1/2)∫e^(2x)dx=e^(2x)(x/2−1/4)+C。微分は e^(2x)(x−1/2)+e^(2x)/2=x e^(2x)。

よくある誤解と反例

∫fgdx=(∫fdx)(∫gdx) である。

f=g=1 を考え、両方の原始関数を x と選ぶと、右辺の積は x·x=x² になる。その導関数は 2x であり、元の被積分関数 1 ではない。積の微分には二項が生じるため、原始関数を単純に掛けることは積分規則ではない。

理解を確かめる

部分積分の負の項はどこから生じるか？

答えと理由を見る

積の微分を積分した式で ∫u′v を反対側に移項する。

(uv)′=u′v+uv′ を積分した結果である。

∫xeˣdx の一つの原始関数は？

答えと理由を見る

eˣ(x−1)。

微分すると eˣ(x−1)+eˣ=xeˣ。

定積分では uv を片方の端点に代入するだけでよいか？

答えと理由を見る

よくない。[uv]ₐᵇ=(uv)(b)−(uv)(a)。

累積量には二つの境界値の差が必要である。

もう一歩先へ

発展：Iₙ=∫xⁿeˣdx に対し、整数 n≥1 なら Iₙ=xⁿeˣ−nIₙ₋₁ を導こう。積分定数は最後に一つにまとめる。この漸化式が n 回後に I₀=eˣ に到達する理由を次数の減少で説明し、最後の積分定数も忘れないこと。

小節 1.2

三角関数の累乗の積分

sin³x を sin x 三つの積と考えると、積分はどう簡単になるだろうか？

準備する概念と学習目標

準備する概念

  • ラジアン：一周は 2π。微分公式 (sin x)′=cos x、(cos x)′=−sin x はラジアンの入力を使う。
  • sin²x は (sin x)² であり、sin(x²) とは異なる関数である。
  • 置換の短い復習：u=g(x) なら du=g′(x)dx。∫f(g(x))g′(x)dx=F(g(x))+C は連鎖律を逆に使う。

学習目標

  • 奇数乗では、置換の微分に合う因子を一つ残す。
  • 偶数乗では半角の恒等式を使う。
  • 置換の符号と三角関数の入力単位を確認する。

恒等式で多項式の積分に変える

sin²x+cos²x=1 は、単位円の座標の平方和が 1 であることから得られる。sin³x=(1−cos²x)sin x と書き換えれば、u=cos x、du=−sin xdx が使える。残した sin x 一つが、ちょうど微分の因子である。

一般に ∫sinᵐx cosⁿx dx で m が奇数なら sin x 一つを残し、残りの sin² を 1−cos² に変える。n が奇数なら cos x 一つを残し、残りの cos² を 1−sin² に変える。ここで m,n は 0 以上の整数である。両方が奇数なら、どちらを残してもよい。

両方が偶数のとき

偶数乗だけなら、無理に一つの因子を残す戦略は適さない。cos 2x=1−2sin²x=2cos²x−1 から sin²x=(1−cos 2x)/2、cos²x=(1+cos 2x)/2 を得る。累乗を低くする代わりに角度が二倍になる。

∫sin²x dx=x/2−sin 2x/4+C である。cos 2x の原始関数は sin 2x/2 なので、外側の 1/2 と合わせて 1/4 になる。積の係数と倍角の係数を一緒に書けば、よくある二倍の誤りを防げる。

定積分の境界と確認

定積分全体を u に変えるなら、境界も u(a),u(b) に変える必要がある。特に u=cos x は x が 0 から π/2 まで動くと 1 から 0 に減少するので、du の負号と境界の逆順を両方処理する。不定積分を求めてから x の境界を代入してもよい。

sin、cos の奇数・偶数の戦略は、tan、sec のすべての累乗にそのまま適用できるわけではない。それらには 1+tan²x=sec²x と (tan x)′=sec²x など、別の組を使う。この節ではまず sin、cos の非負整数乗を完結して扱う。

途中の過程をたどる例題

∫sin³x cos²x dx と ∫₀^(π/2)sin³x cos²x dx を求めよう。

  1. sin³x cos²x=(1−cos²x)cos²x sin x と書く。
  2. u=cos x、du=−sin xdx なら −∫(u²−u⁴)du=−u³/3+u⁵/5+C。
  3. 原始関数は F=−cos³x/3+cos⁵x/5。微分すると cos²x sin x−cos⁴x sin x=sin³x cos²x。
  4. F(π/2)=0、F(0)=−1/3+1/5=−2/15 なので、差は 2/15。

原始関数は −cos³x/3+cos⁵x/5+C、定積分は 2/15。

紙と本文で試してみよう

半角の式で ∫cos²x dx を求め、0 から π までの定積分を計算しよう。

ヒントを見る

cos²x=(1+cos 2x)/2 で、sin 0=sin 2π=0。

解答を見る

原始関数は x/2+sin 2x/4+C。微分は 1/2+cos 2x/2=cos²x。境界値の差は π/2、平均値は (π/2)/π=1/2。

よくある誤解と反例

sin²x の積分は sin³x/3 である。

sin³x/3 の導関数は sin²x cos x なので、cos x が一つ余分に現れる。x の累乗の公式を内側の関数 sin x にそのまま使うことはできず、連鎖律の因子を確認する必要がある。

理解を確かめる

sin⁵x cos²x で有利な置換は？

答えと理由を見る

u=cos x。

sin x を残して sin⁴x=(1−cos²x)² に変えられる。

∫sin²x dx は？

答えと理由を見る

x/2−sin 2x/4+C。

半角の式と cos 2x の積分を使う。

u=cos x で 0→π/2 を変えると、境界は？

答えと理由を見る

1→0。

cos 0=1、cos(π/2)=0 なので、元の境界をそのまま使ってはいけない。

もう一歩先へ

発展：∫sin²x cos²x dx で sin x cos x=sin 2x/2 を使い、被積分関数を (1−cos 4x)/8 に変えよう。結果 x/8−sin 4x/32+C を微分して確認する。連結な区間で、異なる恒等式の経路が定数差まで同じ原始関数を与える理由を説明しよう。

小節 1.3

三角置換

√(a²−x²) を円の座標と考えると、根号を取り除けるだろうか？

準備する概念と学習目標

準備する概念

  • 平方根：z≥0 で √z は非負であり、√(z²)=|z|。
  • 単位円：sin²θ+cos²θ=1、tan θ=sin θ/cos θ。θ はラジアンである。
  • 置換：x=g(θ) なら dx=g′(θ)dθ。区間と逆変換を一緒に定める。

学習目標

  • 三つの標準的な根号形に合う置換を恒等式から導く。
  • 角度の範囲で絶対値の符号と逆置換の枝を決める。
  • 元の変数に戻し、微分と定積分で確認する。

根号形と恒等式を組み合わせる

a>0 のとき、√(a²−x²) には x=a sin θ を選ぶ。a²−x²=a²cos²θ なので √(a²−x²)=a|cos θ| である。θ∈[−π/2,π/2] と定めれば cos θ≥0 となり、x∈[−a,a] と一対一に対応するため、根号を a cos θ と書ける。

√(a²+x²) には x=a tan θ、−π/2<θ<π/2 を使い、a sec θ を得る。この区間で sec θ>0 である。√(x²−a²) は x>a の枝で x=a sec θ、0<θ<π/2 を使い、a tan θ を得る。x<−a の枝は範囲と符号を別に定める必要があり、正の枝の計算をそのまま移してはいけない。

dx も一緒に変わる

x=a sin θ なら dx=a cos θdθ である。根号だけ置換して dx をそのままにすると、別の式を積分することになる。逆変換は sin θ=x/a と選んだ角度範囲から θ=arcsin(x/a) と定める。cos θ=√(a²−x²)/a もこの範囲で得られる。

正の辺の長さだけを使う三角形の図は、x≥0 では便利である。負の x も扱うには、座標や角度の符号、または直接恒等式を使う。三角形に負の辺を入れる比喩は、枝の条件の代わりにはならない。

道具の選択と区間の意味

根号形でも、常に三角置換が最短とは限らない。∫x/√(a²+x²)dx は u=a²+x² の方がずっと簡単である。まず内側の関数の微分が一緒にあるかを調べ、なければ恒等式で根号を簡単にする戦略を考える。

不定積分の微分による確認は、元の被積分関数が定義された開区間で行う。端点で根号の導関数が特異になっても、連続な被積分関数の定積分には端点値を使える。使える区間と、定理の微分条件を区別する。

途中の過程をたどる例題

−2<x<2 で ∫√(4−x²)dx を求め、∫₀²√(4−x²)dx を計算しよう。

  1. x=2sin θ、−π/2<θ<π/2。dx=2cos θdθ で、根号は 2cos θ。
  2. 積分は 4∫cos²θdθ=2θ+sin 2θ+C。
  3. θ=arcsin(x/2)、sin 2θ=2sin θcos θ=x√(4−x²)/2。
  4. F=2arcsin(x/2)+(x/2)√(4−x²)。微分すると 2/√(4−x²)+√(4−x²)/2−x²/(2√(4−x²))=√(4−x²)。
  5. 0→2 は θ:0→π/2。F(2)−F(0)=π であり、半径 2 の円の四分の一の面積 π と一致する。

F=2arcsin(x/2)+(x/2)√(4−x²)+C、定積分は π。微分の確認は開区間で行い、端点への代入は F の連続な延長を使う。

紙と本文で試してみよう

x=3tan θ、−π/2<θ<π/2 で √(9+x²) と dx を θ で書き、x=3 のときに確認しよう。

ヒントを見る

1+tan²θ=sec²θ と (tan θ)′=sec²θ を使う。

解答を見る

根号は 3sec θ、dx=3sec²θdθ。x=3 なら tan θ=1、θ=π/4 で、根号は 3√2。直接計算した √(9+9)=3√2 と一致する。

よくある誤解と反例

√(a²cos²θ)=a cos θ はすべての θ で成り立つ。

a>0 なら正確な値は a|cos θ| である。θ=π では左辺は a、右辺は −a で異なる。cos θ≥0 の範囲を選んだときだけ、絶対値を取り除ける。

理解を確かめる

a>0 のとき、a²−x² に合う置換と実数の範囲は？

答えと理由を見る

x=a sin θ、|x|≤a、θ∈[−π/2,π/2]。

円の恒等式と一対一の sin の範囲で根号の符号を決める。

x=2sin θ なら dx は？

答えと理由を見る

2cos θdθ。

置換関数の導関数を一緒に掛ける必要がある。

∫x/√(1+x²)dx に三角置換は必須か？

答えと理由を見る

必須ではない。u=1+x² で √(1+x²)+C を得る。

du=2x dx で、この原始関数の微分は x/√(1+x²)。

もう一歩先へ

発展：a>0、−a<x<a で ∫dx/√(a²−x²)=arcsin(x/a)+C を直接導こう。x=a sin θ によって、dx と根号の a cos θ が約分される。x=±a では元の被積分関数は定義されないため、原始関数の開区間と、広義積分の端点問題を区別する。

小節 1.4

部分分数分解

一つの複雑な分数を、簡単な分数の和に分けると、積分は簡単になるだろうか？

準備する概念と学習目標

準備する概念

  • 多項式：x²−1=(x−1)(x+1)。展開と因数分解は互いに逆の過程である。
  • 恒等式：特定の x 一つではなく、すべての許された x で等しくなければならない。
  • 原始関数：(ln|x−a|)′=1/(x−a)、x≠a。各連結区間の積分定数は独立でもよい。

学習目標

  • 多項式の除法で真分数にする。
  • 因子の形に合う分子と分母の構造を決める。
  • 通分して係数を比較し、積分して特異点で分かれる区間を示す。

真分数と分解の対象

有理関数 P/Q では、まず約分できるかと、元から除外された入力を確認する。deg P≥deg Q なら多項式の除法で P/Q=H+R/Q、deg R<deg Q とする。H は多項式なので直接積分し、真分数 R/Q を部分分数に分解する。

実係数多項式の分母を一次因子と、実数上でそれ以上因数分解できない二次因子に分ける。分解は分母が 0 でないところで成り立つ恒等式である。通分して分子同士が等しいという多項式の恒等式から、未知の係数を決める。

分母に合うすべての項が必要

異なる一次因子 (x−a)(x−b) には A/(x−a)+B/(x−b) を置く。重複因子 (x−a)ᵐ には A₁/(x−a)+⋯+Aₘ/(x−a)ᵐ と、すべての次数を置く。最高次数の一項だけでは一般の分子を表せない。

既約二次因子 x²+px+q には (Ax+B)/(x²+px+q) のように、分母より低い次数の一般的な一次の分子を置く。重複する二次因子の各累乗にも同様の分子を置く。展開比較や適切な x の代入で係数を解き、再び通分して確認する。

分解後の積分と区間

単純な一次分数は対数に、高い一次因子の累乗はべき乗の積分になる。既約二次分数は、分母の微分に対応する対数部分と、平方完成を使う arctan 部分に分けられる。結果を微分して確認できる。

ln(x−a) とだけ書くと x<a の区間を失う。ln|x−a| は x≠a の各区間で使える。分母の根をまたぐ定積分では、原始関数の境界値公式を無条件に使わず、広義積分の収束を別に確認する必要がある。

途中の過程をたどる例題

x≠1,−2 で ∫(2x+1)/((x−1)(x+2))dx を求めよう。

  1. A/(x−1)+B/(x+2) と置き、通分すると 2x+1=A(x+2)+B(x−1)。
  2. x=1 で 3=3A なので A=1。x=−2 で −3=−3B なので B=1。この代入は通分後の多項式の恒等式に行っている。
  3. 通分の確認：(x+2)+(x−1)=2x+1。
  4. 積分は ln|x−1|+ln|x+2|+C。
  5. 微分すると 1/(x−1)+1/(x+2)=(2x+1)/((x−1)(x+2))。

各区間 (−∞,−2)、(−2,1)、(1,∞) で ln|x−1|+ln|x+2|+C。区間ごとの定数は別に選んでよい。

紙と本文で試してみよう

1/[x(x+1)] を部分分数に分けて積分し、x=1 で分解式の値を確認しよう。

ヒントを見る

1=A(x+1)+Bx で定数項と x の係数を比較する。

解答を見る

A=1、A+B=0 なので B=−1。積分は ln|x|−ln|x+1|+C で、区間は x=0,−1 を避ける。x=1 では元の式が 1/2、分解式が 1−1/2=1/2。微分でも恒等式が回復する。

よくある誤解と反例

重複因子 (x−1)² には A/(x−1)² の一項で常に十分である。

(x+1)/(x−1)²=1/(x−1)+2/(x−1)² なので、単一の定数分子では元の分子の x 項を作れない。A/(x−1) と B/(x−1)² の両方を許す必要がある。

理解を確かめる

分子の次数≥分母の次数なら、まず何をするか？

答えと理由を見る

多項式の除法。

多項式部分と、分子の次数が低い真分数に分ける。

1/[x(x+1)] の係数 A,B は？

答えと理由を見る

A=1、B=−1。

1=A(x+1)+Bx の係数比較で得られる。

∫₋₁¹1/x dx を ln|x| の二つの端点値だけで計算し、0 としてよいか？

答えと理由を見る

できない。

区間内の x=0 は特異点で、両側の広義積分はそれぞれ発散する。対称な主値と通常の広義積分は異なる概念である。

もう一歩先へ

発展：x²/(x²−1)=1+1/(x²−1)=1+(1/2)/(x−1)−(1/2)/(x+1) を導き、x≠±1 で x+(1/2)ln|x−1|−(1/2)ln|x+1|+C を微分しよう。除法をせず始めると、必要な多項式の項を落とす理由を説明する。
