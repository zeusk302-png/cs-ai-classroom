소단원 13.1

공간영역 적분

작은 상자마다 온도를 적으면 전체 평균을 어떻게 구할까?

준비 개념과 학습 목표

준비 개념

  • 이중적분

  • 단면의 경계

  • 한 변수 정적분

학습 목표

  • 작은 부피를 곱한 합으로 삼중적분을 설명한다.

  • 공간영역을 세 겹의 범위로 표현한다.

  • 부피·적분·평균을 구별한다.

작은 상자의 기여를 더한다

상자 하나의 크기는 ΔV=ΔxΔyΔz다. 값 f에 이 부피를 곱하고 전부 더한 극한을 ∭_E f dV로 쓴다. 공간에서 값만 더하면 칸을 더 잘게 나눌 때 결과가 달라지므로 크기가 함께 필요하다. f=1을 적분하면 영역의 부피다.

여기서는 유계이고 경계가 유한 개의 매끄러운 면으로 구성되는 영역과 연속함수를 다룬다. 적분할 값이 음수도 가지면 결과는 부호 있는 기여의 합이다. 온도 적분을 질량으로 읽을 수 없듯 단위와 목적을 함께 적는다.

안쪽 범위는 바깥 좌표에 의존할 수 있다

박스 B=[0,1]×[0,2]×[0,3]에서는 각 범위가 독립이다. 연속함수의 적분은 여섯 순서 중 편한 것을 고를 수 있다. 안쪽 변수만 먼저 적분하고 아직 적분하지 않은 변수는 상수처럼 다룬다.

사면체 E={x,y,z≥0, x+y+z≤2}는 먼저 x0…2, 다음 y0…2−x, 마지막 z0…2−x−y로 쓴다. z상한을2로 바꾸면 경사면 밖도 센다. (1,1,1)은 외곽 박스 안에 있지만 합3이라 E 밖이다. 순서를 바꾸면 새 단면의 경계를 다시 찾아야 한다.

평균의 분모는 영역 부피다

양의 부피 V(E)에 대해 공간 평균은 ∭_E f dV / V(E)다. 부피를 평균의 분모로 쓰는 것은 같은 크기의 작은 공간 조각에 같은 가중치를 준다는 뜻이다. 밀도에 따른 질량 가중 평균은 별도 정의다.

위 박스에서 f=x+2y+z의 평균을 구하려면 적분 후 부피6으로 나눈다. 선형함수와 직사각형 박스의 이 특별한 경우에는 중심(1/2,1,3/2)의 값4와 같다. 임의의 곡면영역·비선형함수까지 중심값이 평균이라고 일반화하지 않는다.

중간 과정을 따라가는 예제

위 박스에서 f=x+2y+z의 적분과 평균, 위 사면체의 부피를 구하라.

  1. z0…3 적분은 3x+6y+9/2다.

  2. y0…2 적분은 6x+12+9=6x+21이다.

  3. x0…1 적분은 3+21=24, 박스 부피6이므로 평균4다.

  4. 사면체에서 z적분의 높이는2−x−y, y0…2−x 적분은(2−x)²/2, x0…2 적분은4/3이다.

박스 적분24/평균4, 사면체 부피4/3이다. 영역의 크기와 함수의 평균은 서로 다른 수치다.

오해와 반례

세 변수의 최대값만 알면 그 박스가 원래 공간영역이다.

사면체에서는 x+y+z≤2도 지켜야 한다. 외곽 박스 부피8은 실제4/3보다 크다. 한 점의 포함 여부와 단면 경계를 먼저 검사한다.

소단원 13.2

원통·구면좌표

둥근 물체를 직사각형 경계로 억지로 자르면 무엇이 어려워질까?

준비 개념과 학습 목표

준비 개념

  • 극좌표

  • 삼중적분

  • 삼각함수와 라디안

학습 목표

  • 원통과 구면의 반지름·각도를 구별한다.

  • 영역과 함수를 모두 새 좌표로 바꾼다.

  • 올바른 체적요소로 적분한다.

원통은 평면 극좌표에 높이를 더한다

원통좌표는 x=r cosθ, y=r sinθ, 높이는z를 그대로 쓴다. r≥0은 z축까지의 거리다. 이때 dV=r dr dθ dz다. x²+y²가 r²가 되는 것뿐 아니라 작은 칸의 부피에도 r이 들어간다.

반지름2, 높이3인 원통 E={x²+y²≤4,0≤z≤3}은 r0…2, θ0…2π, z0…3이다. θ가 이미 한 바퀴를 돌았는데0…4π를 쓰면 같은 내부 공간을 두 번 센다. 축과 시작/끝각의 경계 중복은 부피0이지만 한 바퀴 전체의 추가는 부피가 있는 중복이다.

구면의 두 각을 먼저 약속한다

여기서는 ρ≥0이 원점까지의 거리, θ가 xy평면의 방위각, φ∈[0,π]가 양의z축에서 잰 각이다. x=ρ sinφ cosθ, y=ρ sinφ sinθ, z=ρ cosφ다. dV=ρ² sinφ dρ dφ dθ를 사용한다. 책에 따라 각 기호가 바뀌므로 그림이나 정의를 먼저 확인한다.

반지름2 구의 첫 팔분체 x,y,z≥0에서는 ρ0…2, φ0…π/2, θ0…π/2다. 원통 r와 구면ρ는 같은 반지름이 아니다. 점(0,0,2)는 r0이지만ρ2다. 원점과 축은 좌표각이 유일하지 않으므로 매끄러운 내부와 경계의 퇴화를 구별한다.

함수와 범위를 체적요소와 함께 바꾼다

구면에서 x²+y²+z²는ρ²지만 x²+y²만이면ρ² sin²φ다. 원통에서 구는 r²+z²≤R²라 높이 경계가 r에 의존한다. 적당한 좌표 선택은 영역과 함수 두 조건을 동시에 보고 결정한다.

자체 팔분구에서 f=x²+y²+z²를 적분하면 함수ρ²에 체적요소ρ² sinφ를 곱해ρ⁴ sinφ다. ρ² 하나를 빠뜨리면 같은 물체의 부피나 평균과 맞지 않는 결과가 나온다. 한 좌표에서 계산한 값은 대칭이나 익숙한 부피식으로 별도 확인한다.

중간 과정을 따라가는 예제

반지름2·높이3 원통의 부피와 반지름2 첫 팔분구에서 x²+y²+z²의 적분·평균을 구하라.

  1. 원통 부피는(∫0³dz)(∫0²r dr)(∫0²πdθ)=3·2·2π=12π다.

  2. 팔분구 부피는(8/3)·1·(π/2)=4π/3이다. 전체 구32π/3의1/8과 같다.

  3. 팔분구의 함수 적분은(∫0²ρ⁴dρ)(∫0^(π/2)sinφ dφ)(∫0^(π/2)dθ)=(32/5)·1·π/2=16π/5다.

  4. 평균은(16π/5)/(4π/3)=12/5다.

원통 부피12π, 팔분구 함수 적분16π/5와 평균12/5다.

종이와 본문으로 직접 해보기

원통좌표로 0≤z≤3,0≤r≤z/2,0≤θ≤2π인 원뿔의 부피를 구하라.

힌트 보기

풀이 보기

오해와 반례

좌표만 치환하면 dr dθ dz 또는 dρ dφ dθ를 그대로 쓰면 된다.

작은 각도칸의 실제 크기가 반지름에 따라 달라 r 또는ρ² sinφ가 필요하다. 원통에서 r을 빼면 같은 범위로12π를 우연히 얻을 수도 있지만, 반지름을 바꾸면 틀림이 드러난다.

소단원 13.3

Jacobian과 체적요소

좌표의 한 칸이 기울어지고 늘어나면 실제 부피는 몇 배가 될까?

준비 개념과 학습 목표

준비 개념

  • Jacobian 행렬

  • 행렬식

  • 삼중적분

학습 목표

  • 변환 방향에 맞는 도함수 행렬을 만든다.

  • 행렬식 절댓값으로 부피를 바꾼다.

  • 역변환의 행렬식을 혼동하지 않는다.

각 열은 작은 이동의 방향이다

T(u,v,w)=(x,y,z)를 생각하자. DT의 행은 x,y,z, 열은 u,v,w의 편미분이다. 작은 새 좌표 이동을 기존 좌표의 이동으로 근사한다. 세 열벡터가 만드는 평행육면체의 부피비가 |det DT|다. 부호는 방향이며 보통 부피를 음수로 만들지 않는다.

행렬 전체와 행렬식 하나는 다르다. 행렬식만으로 회전·기울기의 모든 정보를 복원할 수 없지만 이 단원의 스칼라 공간적분에서는 부피비로 사용한다. dV=|det ∂(x,y,z)/∂(u,v,w)| du dv dw로 치환한다.

방향을 적고 역함수와 대조한다

자체 변환 x=2u+v,y=v,z=3w의 행렬은 [[2,1,0],[0,1,0],[0,0,3]]이고 행렬식6이다. 역은 u=(x−y)/2,v=y,w=z/3이므로 역의 행렬식은1/6이다. 새 좌표에서 기존 공간의 적분을 계산할 때 필요한 값은6이다.

새 단위상자0≤u,v,w≤1은 기존 공간에서0≤y≤1, y≤x≤y+2,0≤z≤3인 기울어진 기둥이 된다. 실제 y높이마다 x폭2,z높이3이므로 부피6이다. 부피비를1/6으로 잘못 쓰면 직접 단면 계산과 모순된다.

변환 정리에는 적용 조건이 있다

한 가지 충분한 조건은 내부에서 일대일이고 C¹이며 Jacobian이0이 아닌 변환, 적절한 경계와 연속함수다. 그러면 기존 공간의 f를 f(T(u,v,w))로 바꾸고 새 영역에서 부피비를 곱한다. 이것은 이름만 바꾸는 조작이 아니라 영역의 점 대응과 국소 부피 확대를 같이 쓰는 정리다.

원통·구면은 축에서 좌표가 퇴화하므로 매끄러운 내부 조각에서 정리를 적용하고 적분에 영향을 주지 않는 경계를 별도 다룬다. 절댓값을 붙였다는 것만으로 여러 번 덮는 변환까지 자동으로 허용되지 않는다. 다음 소단원에서 그 반례를 확인한다.

중간 과정을 따라가는 예제

위 선형변환의 단위상자 이미지에서 ∭ x dV를 계산하고 기존 좌표로 검산하라.

  1. 함수 x는2u+v로, 부피요소는6 du dv dw로 바뀐다.

  2. 각 u,v,w가0…1이므로 ∭6(2u+v) du dv dw=6(1+1/2)=9다.

  3. 기존 좌표에서 x를 y…y+2 적분하면 [(y+2)²−y²]/2=2y+2다.

  4. y0…1 적분은3,z0…3 적분으로9를 얻는다.

두 좌표계 모두9다. 부피6과 평균 x=3/2를 곱해도9다.

종이와 본문으로 직접 해보기

T(u,v,w)=(−2u,v,3w)로 바꾸면 단위상자 이미지의 부피와 x적분은?

힌트 보기

det DT=−6이지만 체적요소는6이다. x범위는−2…0이다.

풀이 보기

부피6, x적분=6∫0¹(−2u)du=−6이다. 부피의 양수성과 적분 함수의 음수 기여는 구별한다.

오해와 반례

음의 Jacobian이면 실제 공간의 부피가 음수다.

스칼라 부피는 절댓값을 쓴다. 방향을 갖는 다른 적분 문제는 별도 규약이고, 여기서는 함수가 음수인 경우만 결과 적분이 음수일 수 있다.

소단원 13.4

일반 좌표변환의 검산

변환 결과가 그럴듯해도 같은 점을 두 번 세지 않았는지 어떻게 확인할까?

준비 개념과 학습 목표

준비 개념

  • 변수변환 정리

  • 역함수와 영역

  • 적분 경계

학습 목표

  • 새 영역이 원래 영역을 정확히 덮는지 검사한다.

  • 함수·경계·체적요소 세 부분을 점검한다.

  • 다른 좌표 계산으로 결과를 대조한다.

경계와 역변환을 먼저 적는다

자체 T(u,v,w)=(u,v,(1+u)w)를 단위상자0≤u,v,w≤1에 사용하자. x=u,y=v이므로 기존 영역은0≤x,y≤1,0≤z≤1+x다. 역은 u=x,v=y,w=z/(1+x)이며1+x≥1이라 잘 정의된다.

원래 영역의 모든 점이 새상자의 한 점에 대응하고 같은 기존 점으로 가는 다른 새점은 없다. 꼭짓점만 확인해서 끝내지 말고 임의의 점에 대한 역조건0≤z/(1+x)≤1을 확인한다. 여기서는 기둥 높이가 x에 따라 늘어나는 모형이다.

함수와 작은 체적도 함께 바꾼다

DT=[[1,0,0],[0,1,0],[w,0,1+u]]라 det=1+u다. 따라서 부피는∭(1+u)du dv dw이고 z의 적분은∭(1+u)w·(1+u)du dv dw다. 함수의 z를 바꿨다고 Jacobian까지 자동으로 바뀐 것은 아니다.

검산은 f=1 부피부터 시작하면 쉽다. 새 좌표 부피와 기존 좌표 단면높이 적분이 일치하는지 본 뒤 실제 함수로 넘어간다. 한 경우의 일치는 증명이 아니지만 누락한 확대비나 잘못된 범위를 찾아내는 유용한 점검이다.

절댓값만으로 중복 덮기를 고칠 수 없다

T(u,v,w)=(u²,v,w)를 u−1…1,v와w0…1에 사용하면 u와−u가 같은 점으로 간다. 이미지의 부피는 단위상자1이지만 ∫−1¹|2u|du=2다. 양수 절댓값은 방향을 고칠 뿐 두 번 센 공간을 한 번으로 만들지 않는다.

이 예제에서는 u를0…1로 제한하면 내부에서 일대일이다. u0 경계에서는 Jacobian0이지만 경계는 부피0이고 내부를 적용한 뒤 극한으로 단위부피1을 얻는다. 일반적인 특이점이나 복잡한 중복 문제를 모두 경계라고 무시하지 말고 실제 위치와 크기를 확인한다.

중간 과정을 따라가는 예제

T(u,v,w)=(u,v,(1+u)w)의 단위상자 이미지에서 부피·z적분·평균 z를 두 방식으로 확인하라.

  1. 새좌표 부피는∫0¹(1+u)du=3/2다.

  2. z적분은∫0¹(1+u)²du·∫0¹w dw=(7/3)·1/2=7/6다.

  3. 기존좌표에서 z0…1+x 적분은(1+x)²/2이며 x0…1 적분은7/6, y폭1이다.

  4. 평균 z=(7/6)/(3/2)=7/9다.

부피3/2, z적분7/6, 평균7/9이며 새 좌표와 기존 단면 계산이 일치한다.

종이와 본문으로 직접 해보기

T(u,v,w)=(u²,v,w)의 u범위를−1…1과0…1로 각각 잡아 이미지 부피와 Jacobian 절댓값 적분을 비교하라.

힌트 보기

x는 두 경우 모두0…1이다. ∫0¹2u du=1이며 음수쪽도 같은1을 더한다.

풀이 보기

두 이미지 모두 부피1이다. −1…1에서 절댓값 적분은2로 중복을 세므로 단순 일대일 정리를 적용할 수 없다. 0…1로 제한하면 내부 일대일이고 적분1로 실제 부피와 맞는다.

오해와 반례

변환 뒤 함수만 바꾸고 원래 범위와 미소부피를 써도 된다.

범위·함수·Jacobian을 모두 변경해야 한다. 높이가1+x인 자체 영역을 단위상자라고 세면 부피1로 실제3/2를 놓친다. 중복 여부도 별도 검사한다.
