소단원 4.1

비율·근판정

연속한 두 항의 크기 비율이 결국 절반이면 무한합은 왜 안전할까?

준비 개념과 학습 목표

준비 개념

  • Σa_n 의 수렴은 부분합 S_N=a_1+⋯+a_N 의 유한 극한 존재다. 항의 극한과 다르다.

  • |a_n|은 부호를 제거한 크기이고 절대수렴은 Σ|a_n|의 수렴이다.

  • n!=1·2·⋯·n 이고 (n+1)!=(n+1)n!다.

학습 목표

  • 비율·근판정의 조건과 세 결론을 구별한다.

  • 꼬리를 기하급수로 비교하는 이유를 설명한다.

  • 극한 1 을 수렴 또는 발산 결론으로 바꾸지 않는다.

비율 극한을 실제 꼬리 상계로 바꿔 볼까?

자체 aₙ=n(n+1)/4ⁿ, n≥1에서 연속 비율은 (n+2)/(4n)이다. 극한은 1/4라 절대수렴한다. 더 구체적으로 n≥2에서는 비율이 1/2 이하이므로 a₃부터의 꼬리를 a₃[1+1/2+(1/2)²+…]로 감싼다. a₃=3/16이라 꼬리는 3/8 이하이고 첫 두 항 합 7/8을 더한 전체는 5/4 이하이다. 이 값은 정확한 합이 아니다.

0인 항이 무한히 반복되어 비율을 못 쓰더라도 다른 검사가 가능하다. 자체 zₙ은 홀수에서 0, 짝수에서 2^(−n²)다. n번째 근은 홀수 0, 짝수 2^(−n)이라 모두 0으로 가므로 근판정으로 절대수렴한다. 비율의 나눗셈 불가와 급수 발산은 서로 다른 판단이다.

먼저 확인할 개념
  • 등비의 유한 꼬리

    1/2 공비 상계에서 남은 첫 항과 꼬리 합을 보존한다.

  • 항 필요조건과 부분합

    0인 항과 0으로 가지 않는 항의 판단을 구별한다.

비율은 항의 크기 감소를 비교한다

충분히 큰 n 에서 a_n≠0 이고 ρ=lim |a_(n+1)/a_n|가 존재한다고 하자. ρ<1 이면 절대수렴, ρ>1(∞ 포함)이면 발산, ρ=1 이면 이 판정으로는 결정하지 못한다. 음수 비율을 그대로 넣는 것이 아니라 절댓값을 사용한다. 앞의 유한 개 항이나 0 항은 별도로 기록하고 꼬리에서 조건을 확인할 수 있다.

ρ<1 일 때 ρ<q<1 을 하나 고르면 충분히 큰 n 부터 |a_(n+1)|≤q|a_n|이다. 반복하면 |a_(N+k)|≤|a_N|q^k 이므로 절댓값 꼬리를 유한합 |a_N|/(1−q)가 있는 기하급수로 비교한다. ρ>1 이면 결국 어떤 q>1 로 크기가 늘어나 일반항이 0 으로 가지 못한다.

n 번째 근으로 전체 지수를 꺼내기

r=lim |a_n|^(1/n)이 존재하는 경우에도 r<1 이면 절대수렴, r>1 이면 발산, r=1 이면 불확정이다. 0 항의 n 번째 근은 0 으로 정의되어 비율처럼 0 으로 나누지 않는다. |a_n|=b_n^n 꼴이라면 근은 b_n 이어서 지수 n 을 제거할 수 있다. 여기서는 극한이 존재하는 형태만 다룬다.

r<q<1 이면 결국 |a_n|^(1/n)≤q, 즉 |a_n|≤q^n 이다. r>1 이면 결국 어떤 q>1 에 대해 |a_n|≥q^n 이어서 일반항 필요조건을 위반한다. 극한을 단지 비슷한 비율이라는 그림으로만 판단하지 말고, 결국 성립하는 부등식으로 바꾸는 것이 증명의 핵심이다.

1 과 극한의 존재를 검사하기

Σ1/n 과 Σ1/n²는 비율 극한도 근 극한도 1 이다. 첫째는 발산하고 둘째는 수렴한다. 따라서 1 은 발산 표시가 아니라 다른 판정이 필요한 표시다. 또한 일부 초기 비율이 1 보다 커도 극한이 0 이면 수렴할 수 있다. 판정이 다루는 것은 전체 꼬리의 극한이다.

비율 극한 자체가 없으면 지금 제시한 비율 정리를 사용할 수 없다. 예를 들어 a_n=2^(−n) (n 짝수), 3·2^(−n) (n 홀수)는 연속 비율이 3/2 와 1/6 을 번갈아 극한이 없지만 |a_n|≤3·2^(−n)으로 수렴한다. 한 판정이 실패했다고 급수 자체가 발산하는 것은 아니다.

다음 비율이 1/2 이하라는 증거를 모든 n≥2에 대해 식으로 보였다. 표 세 행만으로 그 범위를 대신하지 않는다.

중간 과정을 따라가는 예제

Σ_(n≥1)3^n/n!와 Σ_(n≥1)((2n+1)/(5n+3))^n 을 판정하고, Σ1/n²에 같은 판정의 경계가 무엇인지 적어라.

  1. 첫 양수 항의 비율은 (3^(n+1)/(n+1)!)/(3^n/n!)=3/(n+1)이다.

  2. 극한 0<1 이므로 절대수렴이다. n=1 의 비율 3/2>1 은 꼬리 결론을 바꾸지 않는다.

  3. 둘째 항의 n 번째 근은 (2n+1)/(5n+3)=(2+1/n)/(5+3/n)→2/5 다.

  4. 2/5<1 이므로 근판정으로 절대수렴한다.

  5. 1/n²의 비율(n/(n+1))²→1 이므로 비율판정은 불확정이다. 실제 수렴 여부는 p 급수 p=2 로 확인한다.

첫 급수 비율 0, 둘째 근 2/5 로 절대수렴. 1/n²는 판정의 불확정과 실제 수렴이 공존한다.

조건을 바꾸어 비교하기

누락한 첫 항의 꼬리

a의 첫 두 항 이후 꼬리 상계를 쓰라.

  1. 미포함 첫 항은 a₃=3/16이다.

  2. 이후 비율이 1/2 이하라 꼬리≤(3/16)/(1−1/2)=3/8이다.

  3. S₂=7/8로 전체≤5/4다.

3/8은 미포함 꼬리 상계다.

비교할 점

a₂를 포함한 꼬리와 a₃부터의 꼬리 경계를 섞지 않는다.

0이 있는 항열의 다른 검사

z의 근과 비율을 구별하라.

  1. 홀수 n에서 근은 0이다.

  2. 짝수 n에서 근은 2^(−n)이다.

  3. 두 경우 모두 0으로 가지만 홀수 분모를 쓰는 비율은 정의되지 않는다.

근판정은 적용되어 절대수렴한다.

비교할 점

비율을 0/0 또는 양수/0으로 계산한 뒤 0이라고 쓰지 않는다.

종이와 본문으로 직접 해보기

Σn²/3^n 의 비율 극한과 Σ((n+2)/(2n+1))^n 의 근 극한을 구하라. Σn!/3^n 도 비교하라.

힌트 보기

비율에서 n²는 ((n+1)/n)²가 되고 팩토리얼은 n+1 인수가 남는다.

풀이 보기

n²/3^n 의 비율은 ((n+1)/n)²/3→1/3 로 절대수렴이다. 두 번째 근은 (n+2)/(2n+1)→1/2 로 절대수렴이다. n!/3^n 의 비율(n+1)/3→∞이므로 발산하며 항도 결국 커진다.

오해와 반례

비율이 1 이면 발산하고, 어느 한 비율이 1 보다 크면 항상 발산한다.

Σ1/n²는 극한 1 이어도 수렴한다. Σ3^n/n!는 초기 비율 3/2 가 1 보다 크지만 결국 3/(n+1)→0 이라 수렴한다. 비율이 정의되는지, 극한이 있는지, 경계 1 인지 세 질문을 별도로 확인해야 한다.

교대급수와 오차

더하고 빼는 항이 작아지면 몇 항만으로 정답의 구간을 잡을 수 있을까?

준비 개념과 학습 목표

준비 개념

  • S_N 은 첫 N 개 항의 합이고 R_N=S−S_N 은 나머지다.

  • b_n>0 인 크기에 (−1)^(n+1)을 곱하면 +,−,+,− 순서다.

  • 비증가는 b_(n+1)≤b_n 이며 엄밀한 감소보다 약한 조건이다.

학습 목표

  • 교대급수 조건의 감소와 0 극한을 모두 확인한다.

  • 두 이웃 부분합 사이 구간과 다음 항 오차를 구한다.

  • 오차≤ε를 만족하는 정수 항 수를 선택한다.

음수로 시작하면 정답 구간의 위아래도 바뀔까?

자체 S=Σₙ₌₁∞(−1)ⁿ/(n+1)은 음수부터 시작한다. 크기 1/(n+1)는 감소하여 0으로 가므로 S는 수렴한다. S₄=−13/60, S₅=−23/60이며 −23/60≤S≤−13/60이다. 여기서 짝수 부분합이 위쪽이다. 부호를 양수 시작의 그림에 억지로 맞추지 않는다.

두 경계의 중앙값 M=−3/10은 수학적 절단 불확실성을 1/12 이하로 제한한다. 별도 가상 산술 기록에서 S₄의 저장오차≤4/1000, S₅의 저장오차≤5/1000만 알고 그 평균을 쓰면 중앙값 저장오차≤9/2000이다. 전체는 1/12+9/2000=527/6000 이하로 감싼다. 이는 실제 장치의 오차 측정이나 보편 부동소수점 보증이 아니라 명시한 입력 계약의 계산이다.

부분합이 번갈아 정답을 둘러싼다

b_n>0, b_(n+1)≤b_n, b_n→0 이면 Σ(−1)^(n+1)b_n 은 수렴한다. 결국 이 조건을 만족하면 앞의 유한 항은 수렴 여부를 바꾸지 않는다. 다만 초기부터 이웃 부분합의 오차 공식을 적용하려면 그 뒤 꼬리 전체가 감소 조건을 만족하는지 확인해야 한다. 부호가 교대한다는 사실만으로는 부족하다.

처음부터 조건이 맞으면 짝수 부분합은 증가하고 홀수 부분합은 감소한다. S_(2k+2)−S_(2k)=b_(2k+1)−b_(2k+2)≥0 이고 홀수 차이는 −b_(2k+2)+b_(2k+3)≤0 이다. k≥1 에서 S_2≤S_(2k)≤S_(2k+1)≤S_1 이므로 두 단조 부분수열은 유계여서 유한 극한을 갖는다. 두 부분합 사이 간격 b_n 은 0 으로 가므로 공통 극한 S 를 갖는다. 양수부터 시작한 예에서는 짝수 합≤S≤홀수 합이다.

다음 항이 오차의 상계다

조건을 만족하는 꼬리에서 S 는 S_N 과 S_(N+1) 사이에 있다. 따라서 |S−S_N|≤b_(N+1)이다. 오차는 b_N 이 아니라 아직 넣지 않은 첫 항의 크기다. 이것은 보통 상계이지 실제 오차와 정확히 같은 값이라는 뜻이 아니다. 음수부터 시작하면 오차의 방향은 바뀌어도 절댓값 상계는 같다.

목표 오차≤ε이면 b_(N+1)≤ε인 정수 N 을 고른다. 이 선택은 충분한 보장이다. 실제 오차가 더 작을 수 있어 필요한 최소 항 수라는 주장은 별도 증명 없이는 하지 않는다. 부동소수점 반올림 오차는 이 수학적 급수 절단 오차에 포함되지 않는다.

일반항 0 과 감소는 서로 다르다

1−1+1−1+⋯는 크기가 비증가이지만 0 으로 가지 않아 수렴하지 않는다. 반대로 부호 교대와 일반항 0 만 갖춘 1−1/2+1/2−1/4+1/3−1/6+⋯는 각 두 항의 합 1/(2k)가 쌓여 짝수 부분합이 발산한다. 짝수 항 뒤에 다음 홀수 항의 크기가 올라가는 일이 반복되어 결국 감소 조건이 없다.

교대급수 판정은 충분조건이다. 조건이 안 맞으면 적용 불가이며 곧바로 발산이라는 일반 결론을 내리지 않는다. 실제 발산을 주장하려면 위처럼 부분합이나 일반항 필요조건의 별도 근거를 제시한다. 종이 활동의 목적은 합을 계산하기 전에 조건부터 확인하는 것이다.

소단원 4.3

절대·조건수렴

부호를 없앴을 때 합이 발산해도 원래 합은 수렴할 수 있을까?

준비 개념과 학습 목표

준비 개념

  • 수렴은 주어진 항 순서의 부분합 극한이 존재한다는 뜻이다.

  • |a_n| 합은 각 항의 크기를 모두 양수로 더한다.

  • p 급수 Σ1/n^p 는 p>1 이면 수렴, p≤1 이면 발산한다.

학습 목표

  • 절대수렴·조건수렴·발산을 구별한다.

  • 절대수렴이 수렴을 함의하는 근거를 설명한다.

  • 부호 없는 급수의 발산만으로 원래 급수의 발산을 결론내리지 않는다.

작은 절대수렴 보정은 조건수렴을 절대수렴으로 바꿀까?

자체 기본 항열 a₂ₖ₋₁=1/k,a₂ₖ=−1/k는 전체 합 0으로 조건수렴한다. 짝수 항에만 1/k²를 더해 c₂ₖ₋₁=1/k,c₂ₖ=−1/k+1/k²로 바꾼다. 완전한 쌍 합은 1/k²다. 짝수 부분합은 P_m=Σₖ₌₁ᵐ1/k², 다음 홀수 잔여는 1/(m+1)로 사라져 전체 합은 P=Σ1/k²로 수렴한다. P의 정확한 닫힌 값은 사용하지 않는다.

크기 합은 k≥2에서 |c₂ₖ₋₁|+|c₂ₖ|=2/k−1/k²≥1/k라 발산한다. 따라서 보정 후에도 조건수렴이다. 일반적으로 절대수렴 보정을 더해도 조건수렴 항열이 절대수렴으로 바뀔 수 없다. 만약 둘의 합이 절대수렴한다면 |aₙ|≤|aₙ+dₙ|+|dₙ|로 원래 항열도 절대수렴하여 모순이 된다. 수렴한 급수의 차에만 이 논리를 사용한다.

먼저 확인할 개념
  • 쌍 끝과 홀수 잔여

    짝수 부분합의 새 누적뿐 아니라 홀수 잔여도 검사한다.

  • 양항 비교와 p 조건

    보정 p=2 수렴과 크기 합의 조화 하계를 따로 적용한다.

두 개의 급수를 따로 검사하기

Σ|a_n|이 수렴하면 Σa_n 을 절대수렴한다고 한다. Σa_n 이 수렴하지만 Σ|a_n|이 발산하면 조건수렴이다. 따라서 조건수렴을 판정하려면 원래 급수의 수렴과 절댓값 급수의 발산이라는 두 근거가 필요하다. 원래 합이 발산하면 절댓값 쪽 결과와 관계없이 조건수렴이라 부르지 않는다.

양수 급수에서는 원래 급수와 절댓값 급수가 같으므로 조건수렴이 없다. 부호가 오가더라도 자동으로 조건수렴은 아니다. Σ(−1)^(n+1)/n²는 크기의 p=2 합이 수렴하므로 절대수렴이다. 교대급수라는 형태와 조건수렴이라는 판정은 서로 다른 분류다.

크기 합이 수렴하면 왜 안전한가

실수 항에 대해 0≤|a_n|+a_n≤2|a_n|이다. Σ|a_n|이 수렴하면 비음수 비교로 Σ(|a_n|+a_n)도 수렴한다. 두 수렴 급수의 차이는 수렴하므로 Σa_n=Σ(|a_n|+a_n)−Σ|a_n|도 수렴한다. 이 논증은 이미 수렴한 합에 대해서만 차 연산을 사용한다.

반대로 Σ|a_n|의 발산은 절대수렴이 아니라는 정보다. 그때 원래 합은 조건수렴 또는 발산일 수 있다. Σ(−1)^(n+1)/n 과 Σ1/n 은 모두 절댓값 합이 조화급수지만 앞의 것은 교대 조건으로 수렴하고 뒤의 것은 발산한다.

계산과 항 순서를 구별하기

Σcos(n)/n²의 경우 cos(n) 부호의 규칙이나 각 값의 근삿값을 알 필요 없이 |cos(n)|≤1 을 써서 |cos(n)/n²|≤1/n²로 절대수렴을 얻는다. 비교는 결국 모든 해당 n 에서 성립해야 하며 몇 항의 측정으로는 충분하지 않다. 원래 합의 정확한 값은 판정과 별개다.

조건수렴에서는 무한 항의 순서를 마음대로 바꾸는 조작을 수렴 급수의 기본 산술처럼 사용해서는 안 된다. 여기서는 원래 순서를 고정한다. 유한 부분합에서 괄호를 다르게 묶는 것과 무한히 항을 재배열하는 것은 다른 작업이다. 실제 부동소수점 덧셈의 순서에 따른 반올림 문제도 수학적 수렴 분류와 구별한다.

종이와 본문으로 직접 해보기

풀이 보기

오해와 반례

같은 비율 1인 양끝에서 로그가 판정을 바꿀까?

자체 F(x)=Σₙ₌₁∞xⁿ/[n ln(n+1)]을 실수 x에서 생각한다. 모든 분모가 양수다. x≠0에서 크기 비율은 |x|n ln(n+1)/[(n+1)ln(n+2)]로 극한 |x|다. 따라서 |x|<1은 절대수렴, |x|>1은 발산이다. x=0은 나눗셈하지 않고 모든 항 0으로 직접 확인한다.

x=1에서는 n≥2의 ln(n+1)≤ln(2n)≤2ln n로 항≥1/[2n ln n]이라 발산한다. x=−1에서는 크기 1/[n ln(n+1)]가 감소하여 0으로 가므로 수렴하지만 같은 크기 급수는 발산하여 조건수렴이다. 전체 범위는 [−1,1)이다. 분모 로그를 제곱한 G(x)는 n≥2에서 크기≤1/[n(ln n)²]로 양끝도 절대수렴해 [−1,1]이 된다.

    n=1부터 ln(n+1)>0인지 먼저 검사한다.

쉬운 탈락 검사부터 시작하기

먼저 모든 항이 정의되는 시작 번호를 확인하고 a_n→0 인지 본다.0 이 아니거나 0 으로 수렴하지 않으면 급수는 발산한다.0 이면 아직 수렴 결론은 없다. 다음은 기하급수·p 급수인지, 부호가 교대하는지, 절댓값 급수의 수렴을 확인할 수 있는지 살핀다.

팩토리얼은 비율에서 단순해지고 n 번째 거듭제곱은 근으로 단순해지는 경우가 많다. 양수 유리식은 높은 차수나 알려진 p 급수와 비교한다. 이 순서는 편리한 전략이지 모든 급수의 결론을 반드시 내는 기계적 알고리즘은 아니다. 복수 방법이 맞으면 조건과 계산을 정확히 적은 더 짧은 경로를 사용할 수 있다.

비교의 방향을 바로 확인하기

0≤a_n≤b_n 이고 Σb_n 이 수렴하면 Σa_n 이 수렴한다. a_n≥b_n≥0 이고 Σb_n 이 발산하면 Σa_n 이 발산한다. 반대 방향에서 작은 급수 발산이나 큰 급수 수렴을 모르는 상태라면 정보가 부족하다. 양수 항의 극한 비교 a_n/b_n→L∈(0,∞)이면 둘의 수렴 여부가 같다. L=0 이나∞에서는 추가 방향 조건이 필요하다.

예를 들어 a_n=1/(n²+3n), b_n=1/n²는 양수이고 a_n≤b_n 이라 수렴한다. c_n=1/(n+3), d_n=1/n 은 c_n≤d_n 이지만 큰 d 의 발산으로 c 를 판정할 수는 없다. 대신 c_n/d_n=n/(n+3)→1>0 이어서 발산한다. 같은 그림처럼 작아 보여도 결론의 논리는 다르다.

끝점은 새 문제다

Σx^n/n 에 비율을 적용하면 x≠0 에서 극한 |x|다. |x|<1 에서는 절대수렴, |x|>1 에서는 발산한다. |x|=1 인 두 끝점은 비율판정으로 불확정이다. x=1 에서는 조화급수라 발산, x=−1 에서는 교대 조화급수의 부호를 바꾼 것이라 조건수렴이다. x=0 은 모든 항 0 이므로 직접 수렴을 확인한다.

앞의 유한 개 항을 다른 유한 값으로 바꾸면 수렴 여부는 바뀌지 않는다. 부분합 극한에 유한 상수를 더하는 것이기 때문이다. 하지만 무한히 많은 항의 수정이나 재배열은 같은 주장이 아니다. 열린 구간의 판정으로 양끝을 자동 포함하거나 일부 값만 관찰해 전체 매개변수 영역을 결정하지 않는다.

절대수렴

양끝의 같은 비율은 같은 결론이 아니라 같은 추가 검사 요구다. 네 번째 행은 열린 구간의 결과이므로 그 자체로 두 끝값을 포함하지 않는다.

중간 과정을 따라가는 예제

F(x)=Σ_(n≥1)x^n/n 의 실수 x 에 대한 수렴 범위를 구하고, G(x)=Σx^n/n²와 양끝의 차이를 설명하라.

  1. x≠0 의 F 항 크기 비율은 |x|n/(n+1)→|x|다. 따라서 −1<x<1 에서 절대수렴, 구간 밖에서 발산한다.

  2. x=0 은 비율 0/0 을 사용하지 않고 모든 항 0 으로 직접 수렴한다.

  3. x=1 은 Σ1/n 발산, x=−1 은 Σ(−1)^n/n 조건수렴이다. F 의 수렴 범위는[−1,1)이다.

  4. G 는 x≠0 의 비율 |x|(n/(n+1))²→|x|로 같은 열린 구간을 얻는다.

  5. G 의 x=1 과−1 에서 절댓값 급수는 둘 다 Σ1/n²로 수렴한다. 따라서 G 의 범위는[−1,1]이며 끝점도 절대수렴이다.

F 는[−1,1)에서 수렴하고 −1 만 조건수렴이다. G 는[−1,1] 전체에서 절대수렴한다. 같은 비율 극한이 끝점의 같은 결론을 뜻하지 않는다.

A는 미포함 a₃와 실제 비율≤1/2를 쓰되 상계와 값은 다르다. B의 중앙 반폭 1/12에 저장 평균 오차 9/2000을 더한다.

힌트 2

C는 쌍 합 1/k²와 홀수 잔여, 크기 조화 하계를 쓴다. D는 +1 로그 발산과 −1 교대·크기 두 검사를 별도로 쓴다.

풀이와 답 확인

  1. A의 첫 두 항 합은 7/8, 꼬리는 3/8 이하, 전체는 5/4 이하다. 정확한 합을 이 상계와 동일하다고 말하지 않는다.

  2. B의 정확한 구간은 [−23/60,−13/60]이다. 중앙 수학적 오차≤1/12, 저장 평균 오차≤9/2000이라 총 상계≤527/6000이다.

  3. C의 모든 부분합은 P=Σ1/k²로 수렴하지만 크기 합은 발산하므로 조건수렴이다. 합 0은 유지되지 않는다.

  4. D의 수렴 범위는 [−1,1)이고 −1은 조건수렴, +1은 발산이다. x=0은 모든 항 0으로 별도 확인한다.

A는 상계, B는 두 오차를 더한 527/6000, C는 조건수렴값 P, D는 [−1,1)이다.
