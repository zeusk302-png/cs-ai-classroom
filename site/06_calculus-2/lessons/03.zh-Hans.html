小节 3.1

数列极限与单调收敛

无限接近，是否意味着满足每一种误差要求？

预备知识与学习目标

预备知识

  • 数列是给每个整数指标指定一个值的函数。本小节使用 n=1,2,… 和 a_n∈ℝ，a_1 是首项。
  • |a_n−L| 是与实数 L 的距离。ε>0 是要求的误差幅度，N 是控制此后全部项的起始指标。
  • 非递减指 a_{n+1}≥a_n，非递增则不等号相反。上界 M 满足全部相关项 a_n≤M，不必本身就是数列中的项。

学习目标

  • 按 ∀ε∃N∀n 的顺序解释数列极限，并具体选择 N。
  • 先检查单调性与方向正确的有界条件，再判断收敛。

极限控制全部大指标

a_n→L∈ℝ 的意思是：每个 ε>0 都有一个整数 N≥1，使所有 n≥N 满足 |a_n−L|<ε。不同 ε 可选不同 N，但同一个 ε 下，N 之后的全部项都必须满足条件。这与观察有限表格不同。

n 不像实数那样连续变化。如果实函数 f(x)→L 且 a_n=f(n)，数列也趋于 L，但反向一般不成立。即使 sin(2πn)=0，实变量函数 sin(2πx) 在无穷远仍没有极限。

通过误差公式选择 N

a_n=(3n+1)/(n+2)=3−5/(n+2)，所以与3的距离为5/(n+2)。选 N=max(1,⌊5/ε⌋+1)，则 n≥N 时 n>5/ε，距离小于 ε。⌊z⌋ 是不超过 z 的最大整数。

改变有限个前面的项，只要足够大指标处的误差公式不变，极限就不变。但若全部项都加上同一个常数，极限也会平移该常数。要区分最初几项与全部项。

单调收敛需要有界

实数非递减数列若有上界，就收敛到有限极限；非递增且有下界也一样。即使只有足够后面的尾部单调，前面的有限项也不影响收敛性。只有单调条件的数列 n 会无限增大，并不收敛。

只有有界条件也不够。(−1)^n 在−1与1之间交替变化，不收敛。而 (−1)^n/n 虽不单调，绝对值1/n→0，所以趋于0。单调有界是充分条件，不是所有收敛数列的必要条件。

逐步推导的例题

检查 a_n=(3n+1)/(n+2), n≥1 的单调性、上界与极限，并找出保证误差<1/100 的一个起始指标 N。

  1. 化为 a_n=3−5/(n+2)，得 a_n<3，且 a_1=4/3。
  2. a_{n+1}−a_n=5/[(n+2)(n+3)]>0，因此非递减，3是上界。
  3. 由单调有界可知收敛，再用 ε–N 定义直接确认误差5/(n+2)→0，故极限为3。
  4. ε=1/100 时，5/(n+2)<1/100 等价于 n>498。因此可取整数 N=499，n=499 的误差5/501<1/100。

极限为3，数列递增且有上界。误差<1/100 从 N=499 开始得到保证，而不是有限小数观察的结论。

用纸笔和正文动手试一试

为 b_n=(−1)^n/n→0 写出 ε–N 选择。再列出 c_1=0,c_{n+1}=(c_n+3)/2 的前三项，验证 c_n=3(1−2^{−(n−1)})。

查看提示

b 与0的距离是1/n。把 n=1 代入 c 的显式公式，再代入下一项递推式。

查看解答

b 可取 N=max(1,⌊1/ε⌋+1)，n≥N 时1/n<ε。c 的前三项为0,3/2,9/4。所给公式满足 c_1=0，且 (3(1−2^{−(n−1)})+3)/2=3(1−2^{−n})，所以下一项也正确。误差3·2^{−(n−1)}→0，故 c_n→3。

常见误解与反例

有界数列就收敛，极限是最后一项。

(−1)^n 有界，但两个子数列的值分别为±1，所以不收敛。无穷数列没有最后一个整数指标，极限也可以不是任何一项实际达到的值。

检查理解

a_n→L 中的 N 可以随 ε 改变吗？

查看答案与理由

可以。

∀ε>0 后面才是 ∃N。所选 N 控制其后的全部项。

只要单调递增，就有限收敛吗？

查看答案与理由

不是。

a_n=n 递增，但没有上界。

非单调数列不能收敛吗？

查看答案与理由

不是。

(−1)^n/n 与0的距离为1/n→0。

进一步探索

深入：非递减且有上界的实数数列，其项集 A 非空并有上界。sup A 是 A 的所有上界中最小的数。实数完备性指任何非空且有上界的实数集合都具有这个最小上界，因此 L=sup A 存在。任给 ε>0，L−ε 不可能是上界，所以某个 N 满足 a_N>L−ε。n≥N 时，由单调性得 L−ε<a_N≤a_n≤L，故 |a_n−L|<ε。这就是单调收敛的完整论证。非递增情况可对 −a_n 应用。不能在仅有有理数的体系中假定同样的完备性。例如从下方逼近 √2 的递增有理数数列，其实数极限不是有理数，因此还要说明在哪个数体系中谈收敛。

小节 3.2

级数与部分和

每一项都接近0，无限累加的和就一定有限吗？

预备知识与学习目标

预备知识

  • 本小节 a_n 是 n≥1 的实数项。S_N=∑_{n=1}^N a_n 是 N 项的有限和，规定 S_0=0。
  • 级数 ∑a_n 的收敛是部分和数列 S_N 存在有限实数极限。这是在研究与 a_n 极限不同的数列。
  • 无穷大不是有限实数和。S_N→+∞ 时称级数发散，并与部分和振荡造成的发散区分。

学习目标

  • 明确写出部分和来定义级数和。
  • 解释项→0的必要性与不充分性，并证明调和级数发散。

以部分和极限定义无限累加

∑_{n=1}^∞a_n=S 的意思是 S_N→S∈ℝ，不是计算器不停相加会在某时停止，也不是直接代入第∞项。准确条件是 ∀ε>0∃N₀∀N≥N₀:|S_N−S|<ε。

例如 a_n=2^{−n} 时，有限和 S_N=1−2^{−N}。N=1,2,3 时为1/2,3/4,7/8，极限1不是只观察这三个值得到的，而由一般部分和公式及误差2^{−N}→0证明。

项很小是必要条件，不是充分条件

级数收敛时，a_N=S_N−S_{N−1}→S−S=0。所以 a_n 不趋于0时级数发散。但 a_n→0 时，仅此判别不提供结论。不能把必要条件倒转为充分条件。

a_n=1/n 趋于0，但调和级数发散。在 k=2^{j−1}+1,…,2^j 的一组中有2^{j−1}项，每项≥1/2^j，所以组和≥1/2。每新增一组就累加相同下界，使部分和无上界。

保留求和顺序与前面的项

添加、删除或改变有限项不改变收敛性，但若收敛，其和会改变相应的有限差值。n=2 与 n=1 开始的和相差首项，忽略起始指标会改变答案。

部分和定义使用固定项序。例如1−1+1−1+…的部分和为1,0,1,0,…，并不收敛。若把相邻两项一组后写成全部和为0，只保留了偶数指标的部分和，遗漏了原来的收敛条件。

逐步推导的例题

求 ∑_{n=1}^∞2^{−n} 的部分和与和，并写出 N=4 的部分和与余项。

  1. S_N=1/2+1/4+…+2^{−N}，减去 (1/2)S_N 后得到 (1/2)S_N=1/2−2^{−(N+1)}。
  2. 因此 S_N=1−2^{−N}。此计算在有限 N 下进行。
  3. 2^{−N}→0，所以部分和极限为1。实际余项 R_N=1−S_N=2^{−N}。
  4. N=4 时 S_4=15/16,R_4=1/16。原级数的项 a_4=1/16 虽在本例与余项相同，但两者定义不同。

和为1，N=4 的部分和为15/16，余项为1/16。

用纸笔和正文动手试一试

求 a_n=2(−1)^{n−1} 的前四个部分和并判断收敛性。用分组解释调和级数 S_{2^k}≥1+k/2。

查看提示

把 a_n 和 S_N 分两行写。首个调和项1后面有 k 个长度按二次幂变化的组。

查看解答

项为2,−2,2,−2，部分和为2,0,2,0。偶数与奇数子数列不同，因此发散。调和级数的首项 n=1 为1，j=1,…,k 每组和≥1/2，所以 S_{2^k}≥1+k/2。k 无限增大，部分和不可能有上界。

常见误解与反例

确认 a_n→0 就证明了级数收敛。

调和级数的项1/n 趋于0，但上述分组下界表明部分和无限增长。项极限不能代替和极限。

检查理解

级数的和是 a_N 的极限吗？

查看答案与理由

不是，是 S_N 的极限。

项与累计和是不同的数列。

a_n 不趋于0时，级数怎样？

查看答案与理由

发散。

若收敛，必有 a_N=S_N−S_{N−1}→0。

删除首项后，收敛性与和都不变吗？

查看答案与理由

只有收敛性不变。

收敛时，和减少被删除的首项。发散级数没有这里所说的有限实数和。

进一步探索

深入：∑a_n 收敛时，任意足够后面的有限尾和也统一很小。S_N→S 时，对 ε>0 选 K，使 j≥K 后 |S_j−S|<ε/2。若 m≥n≥K+1，则 |∑_{k=n}^m a_k|=|S_m−S_{n−1}|≤|S_m−S|+|S_{n−1}−S|<ε。反过来，若每个 ε 都满足此条件，部分和就是 Cauchy 数列：每个 ε>0 都有整数 K，使所有 p,q≥K 满足 |S_p−S_q|<ε。具体地，p>q≥K 时取尾和起始指标 n=q+1、结束指标 m=p；p=q 时差为0，p<q 时交换两指标。因此由实数完备性得到收敛。它控制全部足够后面的尾和，比单项逐个变小的必要条件更强。反向使用实数的 Cauchy 完备性定理，并不是用有限样本证明了该定理本身。

小节 3.3

等比级数与望远镜级数

中间项消去后，无穷和的两端也会全部消失吗？

预备知识与学习目标

预备知识

  • c,r∈ℝ 的等比项 c r^{n−1} 首项为 c，n 从1开始。r=0 时，项序列解释为 c,0,0,…。
  • 先整理有限和，再取 N→∞。不能把两个不收敛的无穷和分别相减。
  • 望远镜求和是将 b_n−b_{n+1} 等相邻差相加，使有限部分和的中间项消去的结构。必须考察最后剩下的项的极限。

学习目标

  • 应用等比收敛条件，包括起始指标和 c=0 例外。
  • 展开有限消去，保留最后的项与准确余项。

等比公式来自有限恒等式

S_N=c+cr+…+cr^{N−1} 减去 rS_N 得 (1−r)S_N=c(1−r^N)。r≠1 时 S_N=c(1−r^N)/(1−r)，r=1 时 S_N=Nc。这是有限和代数，并未预先假定无穷和收敛。

c≠0 且 |r|<1 时 r^N→0，和为 c/(1−r)。|r|≥1 时项不趋于0，级数发散。但 c=0 时全部项为0，与 r 无关，级数都收敛。不能在公式中隐藏 c=0 例外。

实际写出首项与末项

∑_{n=3}^∞4/3^n 的首项是4/27，公比为1/3。若误用 n=1 的首项4/3，会把和算成正确值的9倍。指标平移是需要确保项序列不变的有限代数。

将 b_n−b_{n+1} 从 n=1 加到 N 得 b_1−b_{N+1}。若 b_{N+1}→B∈ℝ，和为 b_1−B，并不保证 B 总为0。例如 b_n=2+1/n 仍留下极限 B=2。

相隔两项时，两端各留下两项

2/[n(n+2)]=1/n−1/(n+2)。从 n=1 加到 N，得1+1/2−1/(N+1)−1/(N+2)，两端各留下两项。N=1 时也有3/2−1/2−1/3=2/3，与首项一致。

望远镜形状本身不保证收敛。b_n=n 时 b_n−b_{n+1}=−1，所以部分和−N→−∞。应计算有限端点项与其极限，而不是说无穷多项全部消失。

逐步推导的例题

求 A=∑_{n=1}^∞3(−1/2)^{n−1}, B=∑_{n=1}^∞2/[n(n+2)] 的和及各 N 项部分和。

  1. A 中 c=3,r=−1/2，有限部分和 A_N=3(1−(−1/2)^N)/(1+1/2)=2(1−(−1/2)^N)。
  2. |r|<1，所以 A=2。带符号余项 A−A_N=2(−1/2)^N，绝对值为2^{1−N}。
  3. 把 B 的项分解为1/n−1/(n+2)，得 B_N=3/2−1/(N+1)−1/(N+2)。
  4. 最后两个倒数趋于0，所以 B=3/2。正余项是1/(N+1)+1/(N+2)，要保留而非直接消掉。

A=2，B=3/2，各部分和与余项由上述有限公式给出。

用纸笔和正文动手试一试

求 ∑_{n=3}^∞4/3^n 的和。再求保证 A 的绝对余项<1/16 的最小整数 N≥1。

查看提示

查看解答

和为 (4/27)/(1−1/3)=2/9。2^{1−N}<1/16 等价于 N>5，所以最小 N=6，误差为1/32。N=5 恰为1/16，不满足严格条件。

常见误解与反例

中间项消去的级数总收敛，尾部误差为0。

b_n=n 的相邻差部分和为−N，发散。即使收敛的 B，在有限 N 时也留下两个倒数之和的正余项。

检查理解

等比级数 c=0,r=2 发散吗？

查看答案与理由

不发散，收敛到0。

这是全部项为0的例外。

r=−1,c=3 的部分和收敛吗？

查看答案与理由

不收敛。

部分和3,0,3,0,…振荡，项也不趋于0。

望远镜和 b_1−b_{N+1} 的最后一项可以直接设为0吗？

查看答案与理由

必须检查实际极限。

进一步探索

深入：0<q<1 时，可直接证明 q^N→0。设 q^{−1}=1+d,d>0，则整数 N≥1 时 (1+d)^N≥1+Nd。N=1 时相等，归纳的下一次乘法会加上 Nd²≥0，因此成立。于是0≤q^N≤1/(1+Nd)。任给 ε>0，选足够大的 N，使右侧小于 ε，便得到极限0。r=0 时从第二项开始为0；−1<r<0 时，由 |r^N|=|r|^N 使用相同论证。因此等比部分和的极限得到与符号无关的依据。先写有限 N 恒等式的顺序，避免将不收敛的无穷和相减。

小节 3.4

积分判别与比较判别

比较较小与较大的级数，哪个方向才能得出结论？

预备知识与学习目标

预备知识

  • 正项或非负项级数的尾部部分和非递减。非负项指每个 a_n≥0，与正负交替的级数不同。
  • 反常积分 ∫_K^∞f 是 ∫_K^Tf 在 T→∞ 时的有限实数极限。不假设面积等于项之和。ln 是自然对数，本单元的 ln x 在 x>0 时定义。
  • 非递增函数 f 满足 x≤y 时 f(x)≥f(y)。可微例子中可通过 f′≤0 检查此条件。

学习目标

  • 说明直接比较的不等号方向与正项条件。
  • 解释积分判别、p级数、尾部界与有限正比值极限比较的适用范围。

比较正项部分和的大小

若从某个整数 K 开始0≤a_n≤b_n，则 ∑b_n 收敛可推出 ∑a_n 收敛。反过来，∑a_n 发散则更大的 ∑b_n 也发散。用于发散的较小级数，或用于收敛的较大级数，其比较方向很重要。

较大项对应的级数发散，并不迫使较小项对应的级数发散。0<1/n²≤1/n，但前者收敛，后者发散。即使有限个前面的项为负，也可用尾部非负比较讨论收敛性，但每项都必须是已定义的有限实数。

积分判别适用于连续、正且非递增的尾部

从整数 K≥1 开始，若 f 在 [K,∞) 上连续、为正且非递增，并满足 f(n)=a_n，则 ∑_{n=K}^∞a_n 与 ∫_K^∞f 同时收敛或同时发散。这并不是和的值等于积分值的定理。可在宽为1的各区间，用项值夹住 f 的最大、最小值。

f=x^{−p},x≥1 在 p>0 时满足上述条件。有限上端点 T>1 时，p≠1 的积分为 (T^{1−p}−1)/(1−p)，p=1 时为 ln T。T→∞ 的积分极限仅在 p>1 时为有限实数，因此 ∑1/n^p 在此时收敛。p≤0 时项不趋于0，需要另用项判别推出发散。

极限比较与余项仍须保留条件

若尾部 a_n,b_n>0 且 a_n/b_n→L,0<L<∞，则足够后面有 (L/2)b_n≤a_n≤(3L/2)b_n，两级数收敛性相同。L=0 时仅由 b 级数发散不能判断 a 级数；L=∞ 时仅由 b 级数收敛同样不能判断。

在积分判别的收敛条件下，对整数 N≥K，R_N=∑_{n=N+1}^∞a_n 满足 ∫_{N+1}^∞f≤R_N≤∫_N^∞f。这里的非递增条件使用非严格不等式。f=1/x² 时有1/(N+1)≤R_N≤1/N，限制了部分和误差；仅此判别并没有算出整个和的准确值。

逐步推导的例题

对 n≥1，用直接比较判断 ∑1/(n²+n) 与 ∑1/(3n+2) 的收敛性。

  1. n≥1 时两种项均为正且有限。比较分母，得1/(n²+n)≤1/n²。
  2. p=2 的级数 ∑1/n² 由 ∫_1^∞x^{−2}=1 和积分判别收敛，因此较小的第一个级数也收敛。
  3. 3n+2≤5n，所以1/(3n+2)≥1/(5n)>0。取倒数时不等号方向反转。
  4. ∑1/(5n) 是调和级数的正常数倍，发散，因此较大的第二个级数也发散。

第一个级数收敛，第二个发散。直接比较不是给出两者准确和的计算。

用纸笔和正文动手试一试

将 ∑(2n+1)/(n³+4) 与1/n² 作极限比较。使用 ∑1/n² 的 S_10 时，写出剩余正误差的界。

查看提示

比值乘以 n²，再除以 n³。尾部积分使用原函数−1/x。

查看解答

比值 n²(2n+1)/(n³+4)=(2+1/n)/(1+4/n³)→2，为有限正极限。两个正项级数同时收敛，所以所给级数收敛。S_10 的余项为1/11≤R_10≤1/10。没有用实际数值程序计算 S_10 或总和。

常见误解与反例

只因项更小，就能通过任意发散级数的比较推出发散。

1/n²≤1/n 是较小级数收敛、较大级数发散的反例。证明收敛应使用收敛上界，证明发散应使用发散下界。

检查理解

积分判别可直接应用于 ∑(−1)^n/n 吗？

查看答案与理由

不能用这里的正项判别直接应用。

项的符号变化，不满足相应的连续正尾部条件。

∫_1^∞1/x²=1，是否说明 ∑1/n² 也等于1？

查看答案与理由

不是。

首项1之后还加上正项。此判别比较的是收敛性。

a_n/b_n→0 且 ∑b_n 发散，是否说明 ∑a_n 发散？

查看答案与理由

不能确定。

b_n=1/n，a_n=1/n² 时后者收敛。但 n≥2 时 a_n=1/(n ln n) 即使比值1/ln n→0，仍然发散。f(x)=1/(x ln x) 在 [2,∞) 连续、为正，且 f′(x)=−(ln x+1)/(x²(ln x)²)<0。∫_2^T f(x)dx=ln ln T−ln ln 2→∞，所以满足积分判别的全部条件并发散。

进一步探索

深入：证明积分判别的两个方向。n≥K 时由非递增性得 ∫_n^{n+1}f≤f(n)，n≥K+1 时 f(n)≤∫_{n−1}^nf。因此 ∫_K^{N+1}f≤∑_{n=K}^Nf(n)≤f(K)+∫_K^Nf。若积分有限，右侧是部分和的上界，非递减部分和由实数单调收敛定理收敛。若级数收敛，左侧整数端点积分有界，每个实数 T 都不超过某个整数端点，所以全部正积分也有界且非递减，具有有限极限。反过来，积分发散时，左侧下界使部分和无限增长。对 N 之后的尾部使用同样比较并令端点趋于无穷，得到两个余项界。连续性是保证每个有限区间可积的充分条件；有限前段另行相加。
