小節 3.1

数列の極限と単調収束

限りなく近づくとは、どのような誤差の要求も満たすという意味だろうか？

準備する概念と学習目標

準備する概念

  • 数列は整数の添字ごとに一つの値を与える関数である。この小単元では n=1,2,…、a_n∈ℝ とし、a_1 を初項とする。
  • |a_n−L| は実数値 L との距離である。ε>0 は要求する誤差の幅、N はそれ以降のすべての項を制御するための開始添字である。
  • 非減少とは a_{n+1}≥a_n、非増加とは逆向きの不等式が成り立つことである。上界 M は対象となるすべての項について a_n≤M を満たす数であり、数列の項そのものである必要はない。

学習目標

  • 数列の極限を ∀ε∃N∀n の順序で説明し、実際に N を選ぶ。
  • 単調性と正しい向きの有界性を確認してから、収束を結論づける。

極限は大きな添字すべてについての条件である

a_n→L∈ℝ とは、すべての ε>0 に対してある整数 N≥1 が存在し、すべての n≥N で |a_n−L|<ε となることである。ε ごとに別の N を選べるが、同じ ε に対してはそれ以降のすべての項が条件を満たさなければならない。有限の表を観察することとは異なる。

n は実数のように連続的に動くわけではない。実数関数が f(x)→L を満たし a_n=f(n) なら数列も L に収束するが、逆は一般には成立しない。sin(2πn)=0 であっても、実数 x に対する sin(2πx) は x→∞ で極限をもたない。

誤差の式から N を求める

a_n=(3n+1)/(n+2)=3−5/(n+2) なので、3 との距離は 5/(n+2) である。N=max(1,⌊5/ε⌋+1) と選ぶと、n≥N では n>5/ε となるので距離は ε より小さい。⌊z⌋ は z 以下の最大の整数である。

初めの有限個の値が変わっても、十分大きな添字での誤差の式が同じなら極限は同じである。しかし、すべての項に同じ定数を加えると極限もその定数だけ移動する。「初めの数項」と「すべての項」を区別する。

単調収束には有界性が必要である

実数の非減少数列が上に有界なら、有限の極限に収束する。非増加数列が下に有界である場合も同様である。ある添字以降だけ単調でも、前の有限個の項は収束するかどうかに影響しない。単調であるだけの数列 n は上に限りなく大きくなり、収束しない。

有界であるだけでも不十分である。(−1)^n は −1 と 1 の間にあるが、交互に変化するので収束しない。一方、(−1)^n/n は単調でなくても絶対値が 1/n→0 なので 0 に収束する。単調かつ有界であることは十分条件であり、すべての収束数列に必要な条件ではない。

途中の過程をたどる例題

a_n=(3n+1)/(n+2)、n≥1 の単調性・上界・極限を確認し、誤差<1/100 となる開始添字 N を一つ求めよ。

  1. a_n=3−5/(n+2) と整理すると a_n<3 であり、a_1=4/3 である。
  2. a_{n+1}−a_n=5/[(n+2)(n+3)]>0 なので非減少であり、3 は上界である。
  3. 単調かつ有界なので収束する。さらに誤差 5/(n+2)→0 を ε–N の定義で直接確認できるので、極限は 3 である。
  4. ε=1/100 のとき、5/(n+2)<1/100 は n>498 と同値である。したがって整数 N=499 を選べ、n=499 の誤差は 5/501<1/100 である。

極限は 3。増加し、上に有界であり、N=499 以降では誤差<1/100 が保証される。有限個の小数値の観察による結論ではない。

紙と本文で試してみよう

b_n=(−1)^n/n が 0 に収束することを示す ε–N の選び方を書け。c_1=0、c_{n+1}=(c_n+3)/2 の最初の三項を書き、c_n=3(1−2^{−(n−1)}) を確認せよ。

ヒントを見る

b の距離は 1/n である。c の閉じた式に n=1 を入れ、次の項を求める式に代入する。

解答を見る

b では N=max(1,⌊1/ε⌋+1) とすると n≥N で 1/n<ε となる。c の最初の三項は 0,3/2,9/4 である。提案した式は c_1=0 を満たし、(3(1−2^{−(n−1)})+3)/2=3(1−2^{−n}) なので次の項も一致する。誤差 3·2^{−(n−1)}→0 より c_n→3 である。

よくある誤解と反例

有界な数列なら収束し、極限は最後の項である。

(−1)^n は有界だが、二つの部分列の値が ±1 と異なるので収束しない。無限数列には最後の整数添字はなく、項がその値に実際に到達しなくても極限は存在しうる。

理解を確かめる

a_n→L の N は ε ごとに異なってもよいか？

答えと理由を見る

よい。

∀ε>0 の後に ∃N がある。選んだ N 以降のすべての項を制御する。

単調増加というだけで有限の値に収束するか？

答えと理由を見る

それだけでは有限の値への収束は保証されない。

a_n=n は増加するが上に有界ではない。

単調でない数列は収束できないのか？

答えと理由を見る

そうではない。

(−1)^n/n の距離は 1/n→0 である。

もう一歩先へ

発展：非減少で上に有界な実数数列の項の集合 A は空でなく、上界をもつ。sup A は A のすべての上界のうち最小の値である。実数の完備性とは、空でなく上に有界な実数の集合がこの最小上界をもつという性質であり、これにより L=sup A が存在する。任意の ε>0 に対して L−ε は上界ではありえないので、ある N で a_N>L−ε となる。n≥N なら単調性より L−ε<a_N≤a_n≤L となり、|a_n−L|<ε である。これが単調収束の完全な論証である。非増加の場合は −a_n に適用する。有理数の体系だけで同じ完備性を仮定することはできない。例えば √2 を下から近似する増加有理数数列の実数としての極限は有理数ではないので、どの数の体系で収束を述べるのかも明示する必要がある。

小節 3.2

級数と部分和

一つ一つの項がほぼ 0 なら、無限に足した和も有限になるだろうか？

準備する概念と学習目標

準備する概念

  • この小単元の a_n は n≥1 の実数の項である。S_N=∑_{n=1}^N a_n は N 個の項の有限和であり、S_0=0 と定める。
  • 級数 ∑a_n が収束するとは、部分和数列 S_N が有限の実数に収束することである。a_n の極限とは別の数列を調べる。
  • 無限大は有限の実数の和ではない。S_N→+∞ なら級数は発散するといい、部分和が振動する発散とも区別する。

学習目標

  • 部分和を明示して級数の和を定義する。
  • 項→0 という必要条件とその不十分さを説明し、調和級数の発散を証明する。

無限の足し算を部分和の極限で定義する

∑_{n=1}^∞a_n=S とは S_N→S∈ℝ という意味である。電卓で足し続ければいつか止まるという意味でも、∞ 番目の項を直接入れるという意味でもない。正確な条件は ∀ε>0 に対して ∃N₀∀N≥N₀:|S_N−S|<ε である。

例えば a_n=2^{−n} なら有限和は S_N=1−2^{−N} である。N=1,2,3 では 1/2,3/4,7/8 となるが、極限が 1 であることはこの三つの値だけの観察ではなく、一般の部分和の式と誤差 2^{−N}→0 によって証明する。

項が小さくなることは必要だが十分ではない

級数が収束するなら a_N=S_N−S_{N−1}→S−S=0 である。したがって a_n が 0 に収束しなければ級数は発散する。しかし a_n→0 のとき、この判定だけでは何も結論できない。必要条件を十分条件に逆転させてはいけない。

a_n=1/n は 0 に近づくが、調和級数は発散する。k=2^{j−1}+1,…,2^j の区間には 2^{j−1} 個の項があり、各項≥1/2^j なので各まとまりの和≥1/2 となる。新しいまとまりごとに同じ量が積み重なるので、部分和には上界がない。

和の順序と初めの部分を保つ

有限個の項の追加・除去・変更は収束するかどうかを変えないが、収束する場合の和はその有限の差だけ変わる。n=2 からの和と n=1 からの和は初項一つだけ異なり、開始添字を無視すると答えが変わる。

部分和の定義では決められた項の順序を使う。例えば 1−1+1−1+… の部分和は 1,0,1,0,… なので収束しない。隣り合う二項ずつをまとめ、すべての和が 0 と書くと、偶数添字の部分和だけが残り、元の収束条件を見落とす。

途中の過程をたどる例題

∑_{n=1}^∞2^{−n} の部分和と和を求め、N=4 の部分和と剰余を書け。

  1. S_N=1/2+1/4+…+2^{−N} であり、(1/2)S_N を引くと (1/2)S_N=1/2−2^{−(N+1)} となる。
  2. したがって S_N=1−2^{−N} である。この計算は有限の N で行った。
  3. 2^{−N}→0 なので部分和の極限は 1 である。実際の剰余は R_N=1−S_N=2^{−N} である。
  4. N=4 なら S_4=15/16、R_4=1/16 となる。元の級数の項 a_4=1/16 と剰余がこの例では等しくても、二つの定義は異なる。

和は 1 であり、N=4 の部分和は 15/16、剰余は 1/16 である。

紙と本文で試してみよう

a_n=2(−1)^{n−1} の最初の四つの部分和を求め、収束するか判定せよ。調和級数の S_{2^k}≥1+k/2 を、項をまとめて説明せよ。

ヒントを見る

a_n 自体と S_N を別々の行に書く。調和級数の初項 1 の後には、二のべきの長さをもつ k 個のまとまりがある。

解答を見る

項は 2,−2,2,−2、部分和は 2,0,2,0 であり、偶数・奇数添字の部分列が異なるので発散する。調和級数では n=1 の 1 と j=1,…,k の各まとまりの和≥1/2 より、S_{2^k}≥1+k/2 となる。k が限りなく大きくなるので、部分和は上に有界ではありえない。

よくある誤解と反例

a_n→0 を確認すれば、級数の収束を証明したことになる。

調和級数の項 1/n は 0 に近づくが、上のまとまりによる下界は部分和が限りなく増大することを示す。項の極限は和の極限の代わりにはならない。

理解を確かめる

級数の和は a_N の極限か？

答えと理由を見る

違う。S_N の極限である。

項と累積した和は別の数列である。

a_n が 0 に近づかないとき、級数はどうなるか？

答えと理由を見る

発散する。

収束するなら a_N=S_N−S_{N−1}→0 でなければならない。

初項を除くと、収束するかどうかも和も、そのまま変わらないか？

答えと理由を見る

収束するかどうかだけが同じである。

収束する場合、和は除いた初項の分だけ減る。発散する級数には、ここでいう有限の実数の和はない。

もう一歩先へ

発展：∑a_n が収束するなら、十分後ろにある項の有限和も一様に小さい。S_N→S のとき、ε>0 に対してある K 以降で |S_j−S|<ε/2 となるようにする。m≥n≥K+1 なら |∑_{k=n}^m a_k|=|S_m−S_{n−1}|≤|S_m−S|+|S_{n−1}−S|<ε である。逆にこの条件がすべての ε に対して成立すれば、部分和はコーシー数列である。これは、すべての ε>0 に対してある整数 K が存在し、すべての p,q≥K で |S_p−S_q|<ε となるという意味である。実際、p≥q≥K なら末尾の和の開始添字 n=q+1 と終了添字 m=p を使い、p=q なら差は 0、p<q なら二つの添字を入れ替える。したがって実数の完備性により収束する。これは十分後ろにあるすべての末尾の和を制御するので、a_n が一項ずつ小さいという必要条件より強い。逆向きの論証は実数のコーシー完備性という定理を使っており、有限個の標本でその定理自体を証明したわけではない。

小節 3.3

等比級数と望遠鏡型級数

途中の項が消えるなら、無限和の両端もすべて消えるだろうか？

準備する概念と学習目標

準備する概念

  • c,r∈ℝ の等比数列の項 c r^{n−1} の初項は c で、n は 1 から始まる。r=0 のときは項の列を c,0,0,… と解釈する。
  • まず有限和を整理してから N→∞ とする。収束しない二つの無限和を別々に引く演算は使えない。
  • 望遠鏡型の和は b_n−b_{n+1} のような隣り合う差を足すことで、有限の部分和の途中の項が消える構造である。最後に残る項の極限を調べる必要がある。

学習目標

  • 開始添字と c=0 の例外を含めて、等比級数の収束条件を適用する。
  • 有限の相殺を展開し、最後の項と正確な剰余を残す。

等比の公式は有限の恒等式から導かれる

S_N=c+cr+…+cr^{N−1} から rS_N を引くと、(1−r)S_N=c(1−r^N) となる。r≠1 なら S_N=c(1−r^N)/(1−r)、r=1 なら S_N=Nc である。これは有限和の代数計算なので、無限和の収束をあらかじめ仮定していない。

c≠0 かつ |r|<1 なら r^N→0 なので、和は c/(1−r) である。|r|≥1 なら項が 0 に近づかず、級数は発散する。ただし c=0 の、すべての項が 0 の級数は r に関係なく収束する。公式の中に c=0 の例外を隠してはいけない。

初項と最後の項を実際に書く

∑_{n=3}^∞4/3^n の初項は 4/27、公比は 1/3 である。n=1 の初項 4/3 と勘違いすると、和を 9 倍大きく計算してしまう。添字の移動は、項の列が同じであることを確認して行う有限の代数操作である。

b_n−b_{n+1} を n=1 から N まで足すと b_1−b_{N+1} になる。b_{N+1}→B∈ℝ なら和は b_1−B であり、B が常に 0 だという保証はない。例えば b_n=2+1/n でも極限 B=2 が残る。

二つ先との差では両端に二項ずつ残る

2/[n(n+2)]=1/n−1/(n+2) である。n=1 から N まで足すと、1+1/2−1/(N+1)−1/(N+2) となり、両端に二項ずつ残る。N=1 でも 3/2−1/2−1/3=2/3 となり、初項に一致する。

望遠鏡型の形だけでは収束しない。b_n=n なら b_n−b_{n+1}=−1 なので、部分和は −N→−∞ となる。「∞ 個の項がすべて消える」という説明の代わりに、有限和の端の項とその極限を計算しなければならない。

途中の過程をたどる例題

A=∑_{n=1}^∞3(−1/2)^{n−1}、B=∑_{n=1}^∞2/[n(n+2)] の和と、それぞれの N 項までの部分和を求めよ。

  1. A の c=3、r=−1/2 を確認する。有限の部分和は A_N=3(1−(−1/2)^N)/(1+1/2)=2(1−(−1/2)^N) である。
  2. |r|<1 なので A=2 となる。符号をもつ剰余 A−A_N=2(−1/2)^N の絶対値は 2^{1−N} である。
  3. B の項を 1/n−1/(n+2) に分解すると、B_N=3/2−1/(N+1)−1/(N+2) を得る。
  4. 最後の二つの逆数が 0 に近づくので B=3/2 である。正の剰余は 1/(N+1)+1/(N+2) であり、消してしまわず残す。

A=2、B=3/2 であり、それぞれの部分和と剰余は上の有限の式で与えられる。

紙と本文で試してみよう

∑_{n=3}^∞4/3^n の和を求めよ。また、A の剰余の絶対値<1/16 を保証する最小の整数 N≥1 を求めよ。

ヒントを見る

解答を見る

和は (4/27)/(1−1/3)=2/9 である。2^{1−N}<1/16 は N>5 なので、最小の N は 6 であり、誤差は 1/32 となる。N=5 ではちょうど 1/16 なので、厳密な不等号の条件を満たさない。

よくある誤解と反例

途中の項が相殺される級数は必ず収束し、末尾の誤差は 0 である。

b_n=n の隣り合う差は部分和が −N となり発散する。収束する B でも有限の N では、二つの逆数からなる正の剰余が残る。

理解を確かめる

等比級数で c=0、r=2 なら発散するか？

答えと理由を見る

しない。和 0 に収束する。

すべての項が 0 という例外である。

r=−1、c=3 の部分和は収束するか？

答えと理由を見る

しない。

3,0,3,0,… と振動し、項も 0 に近づかない。

望遠鏡型の和 b_1−b_{N+1} で、最後の項をそのまま 0 としてよいか？

答えと理由を見る

実際の極限を確認する必要がある。

b_n→2 なら 2 を引き、b_n=n なら発散する。

小節 3.4

積分判定法・比較判定法

小さい級数と大きい級数の比較は、どちらの向きで結論を与えるだろうか？

準備する概念と学習目標

準備する概念

  • 正項または非負項の級数では、ある添字以降の部分和は非減少である。非負項とは各 a_n≥0 であり、符号が交互に変わる級数とは異なる。
  • 広義積分 ∫_K^∞f は ∫_K^Tf の T→∞ における有限の実数の極限である。面積と項の和が等しいとは仮定しない。ln は自然対数であり、この単元の ln x は x>0 で定義する。
  • 非増加関数 f は x≤y なら f(x)≥f(y) となる関数である。微分可能な例では f′≤0 によってこの条件を確認できる。

学習目標

  • 直接比較の不等式の向きと正項の条件を明示する。
  • 積分判定法・p 級数・末尾の境界、および有限で正の極限による比較の適用範囲を説明する。

正の部分和の大きさを比較する

ある整数 K 以降で 0≤a_n≤b_n なら、∑b_n の収束から ∑a_n の収束を結論づけられる。逆に ∑a_n が発散すれば、より大きな ∑b_n も発散する。発散する小さい級数と比較するか、収束する大きい級数と比較するかという向きが重要である。

大きい項の列の発散は、小さい項の列の発散を強制しない。0<1/n²≤1/n だが、前者の級数は収束し、後者は発散する。初めの有限個の項が負でも、それ以降の非負項の比較で収束するかどうかを扱えるが、各項は定義された有限の実数でなければならない。

積分判定法は連続・正・非増加となる末尾に適用する

整数 K≥1 から f が [K,∞) で連続・正・非増加であり、f(n)=a_n なら、∑_{n=K}^∞a_n と ∫_K^∞f はともに収束するか、ともに発散する。和の値が積分値に等しいという定理ではない。幅 1 の各区間で f の最大・最小を項の値で挟んで比較する。

f=x^{−p}、x≥1 では p>0 なら上の条件を満たす。p≠1 の積分は (T^{1−p}−1)/(1−p)、p=1 では ln T である。p>1 のときだけ有限なので、∑1/n^p はそのとき収束する。p≤0 なら項が 0 に近づかないため、別に発散と判定する。

極限比較と剰余では条件を保つ

ある添字以降で a_n,b_n>0、a_n/b_n→L、0<L<∞ なら、十分後ろで (L/2)b_n≤a_n≤(3L/2)b_n となり、二つの級数の収束するかどうかは同じになる。L=0 では b の級数の発散だけで a の級数は判定できず、L=∞ では b の級数の収束についても同様である。

積分判定法の収束条件のもと、整数 N≥K に対する R_N=∑_{n=N+1}^∞a_n は ∫_{N+1}^∞f≤R_N≤∫_N^∞f を満たす。ここでは非増加の条件なので、等号を許す不等式を使う。f=1/x² なら 1/(N+1)≤R_N≤1/N として部分和の誤差を限定できるが、この判定だけで全体の和を正確に求めたわけではない。
