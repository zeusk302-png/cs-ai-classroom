소단원 6.1

의사코드와 흐름도

같은 번호가 두 번 있는 카드 줄에서 찾았다는 말은 어느 위치를 뜻할까?

준비 개념과 학습 목표

준비 개념

  • 유한한 정수 카드열 A의 길이를 n이라 하고 왼쪽부터 위치 0,1,…,n−1을 붙인다. 빈 열은 n=0이며 유효한 항목 위치가 없다.
  • 대입은 상태를 바꾸고 비교는 조건을 판정한다. i←i+1은 현재 위치를 하나 늘리는 명령이며 수학 등식의 해를 찾는 식이 아니다.
  • None은 찾지 못했다는 별도 표지다. 유효 위치 0과 구별하고, 이 단원에서는 비교가 정상 종료하며 카드열이 도중에 변하지 않는다고 가정한다.

학습 목표

  • 입력·허용 출력·정지 조건을 먼저 정한 뒤 의사코드를 쓴다.
  • 순서·조건 분기·반복을 흐름도로 대응시키고 빈 입력을 추적한다.
  • 이해하기 쉬운 문장과 의미가 명확한 실행 규칙의 차이를 설명한다.

찾는 문제의 계약부터 쓰기

문제를 “숫자 찾기”라고만 적으면 답의 형태가 정해지지 않는다. 존재 여부, 임의의 일치 위치, 가장 왼쪽 일치 위치는 서로 다른 계약이다. 여기서는 입력 A와 목표 t에 대해 일치 위치가 있으면 가장 작은 위치를, 없으면 None을 반환한다. 같은 값의 카드가 여러 장이어도 답은 하나로 정해진다.

예를 들어 A=[8,3,8], t=8에서 2는 일치 위치지만 이 계약의 올바른 출력은 0이다. 입력 조건도 함께 적는다. 유한 카드열, 정상 정수 비교, 실행 중 변경 없음이라는 가정을 빼면 같은 절차에 대한 아래 종료·정확성 논증을 그대로 적용할 수 없다.

사람이 읽는 절차에도 뜻이 필요하다

의사코드는 특정 프로그래밍 언어의 문법에 매이지 않고 순서와 조건을 나타내는 기록이다. 그러나 “적당히 찾아라”처럼 다음 행동이 정해지지 않는 말은 충분하지 않다. 아래에서 RETURN은 값을 결과로 내고 전체 절차를 끝내며 WHILE의 본문은 조건이 참인 동안 반복한다.

i<n을 먼저 확인해야 A[i]를 읽을 수 있다. n=0이면 본문을 한 번도 수행하지 않고 None을 낸다. i=n인 마지막 검사 뒤에는 A[n]을 읽지 않는다. 들여쓰기는 어느 명령이 반복과 조건에 속하는지 보여 주므로 단순 장식이 아니다.

FIRST(A,t)
  n ← LENGTH(A)
  i ← 0
  WHILE i < n:
    IF A[i] = t: RETURN i
    i ← i + 1
  RETURN None

흐름도에서 되돌아가는 화살표 읽기

흐름도는 같은 절차를 상자와 화살표로 보여 준다. 아래 텍스트 그림의 물음은 조건 판정이고, 두 결과의 목적지를 각각 적었다. RETURN으로 향한 화살표는 다음 위치로 진행하지 않고 끝난다. 반복 화살표는 i를 증가시킨 뒤 범위를 다시 검사하는 곳으로 돌아간다.

그림을 그렸다는 사실만으로 정확해지는 것은 아니다. A[i]=t의 아니오 경로에서 증가를 빠뜨리면 첫 카드가 다를 때 같은 상태를 계속 방문한다. 읽기 가능한 문장, 명확한 상태 전이, 모든 경로의 처리와 정지는 함께 점검해야 한다.

시작 → n=LENGTH(A), i=0 → [i<n?]
[i<n?] 아니오 → RETURN None → 끝
[i<n?] 예 → [A[i]=t?]
[A[i]=t?] 예 → RETURN i → 끝
[A[i]=t?] 아니오 → i=i+1 → [i<n?]

중간 과정을 따라가는 예제

위 FIRST 절차와 흐름도를 A=[8,3,8], t=8에 적용하라. 카드 값과 위치를 따로 기록하고 반환 이후의 명령을 수행하는지 판단하라.

  1. 길이 n=3, 초기 위치 i=0이다. 유효 위치는 0,1,2이고 첫 카드의 값은 8이다.
  2. 0<3이 참이므로 위치 0의 값을 읽는다. A[0]=8=t가 참이다.
  3. RETURN i가 결과 0을 내고 전체 FIRST 절차를 끝낸다. i=i+1은 수행하지 않고 위치 1,2도 검사하지 않는다.
  4. 출력 0은 카드 값 8과 다르다. 다른 일치 위치 2가 있어도 가장 작은 위치 0이므로 계약을 만족한다. 이 기록은 종이 추적이며 프로그램 실제 출력이 아니다.

가장 왼쪽 일치 위치 0을 반환한다. 첫 항목에서 끝나며 항목과 목표의 같음 비교는 1회다.

종이와 본문으로 직접 해보기

독립적으로 A=[8,3,8],t=3과 같은 A,t=5, 그리고 A=[],t=8을 종이에 추적하라. 각 결과와 항목-목표 같음 비교 횟수를 적고 범위 검사는 그 횟수에 포함하지 마라.

힌트 보기

조건 i<n이 거짓이면 항목을 읽지 않는다. 성공 RETURN 뒤에는 반복으로 돌아가지 않는다.

풀이 보기

t=3은 위치 0의 8과 비교해 실패하고 i=1의 3에서 성공하여 결과 1, 같음 비교 2회다. t=5는 위치 0,1,2에서 모두 실패한 뒤 i=3에서 범위 검사가 거짓이므로 None, 같음 비교 3회다. 빈 열은 처음 0<0이 거짓이므로 None, 같음 비교 0회다. 범위 검사 횟수는 각각 2,4,1회로 별도다. 모두 종이 계산이다.

오해와 반례

의사코드에는 실행 문법이 없으므로 분기 목적지와 입력 조건을 정확히 쓰지 않아도 된다.

같은 위치에서 계속 반복하는 그림과 다음 위치로 진행하는 그림은 결과·종료가 다르다. 의사코드는 문법 선택의 자유가 있지만 의미의 누락을 허용하는 것은 아니다. 예를 들어 A=[8],t=3에서 증가 없는 실패 경로는 종료하지 않는다.

자기점검

A=[8,3,8],t=8에서 2를 반환하면 이 계약에 맞는가?

답과 이유 보기

아니다.

존재하거나 임의로 일치하는 위치를 찾는 계약과 달리 가장 작은 일치 위치 0을 요구한다.

빈 카드열에서 A[0]을 읽어야 None을 정할 수 있는가?

답과 이유 보기

읽지 않는다.

범위 검사 0<0이 먼저 거짓이어서 본문으로 들어가지 않는다.

RETURN1 뒤 i를 증가시켜 나머지도 조사하는가?

답과 이유 보기

조사하지 않는다.

RETURN은 이 절차 전체를 끝내며 이후 명령은 이 호출에서 수행되지 않는다.

한 단계 더

심화: 반복 머리에서 아직 반환하지 않았다면 0≤i≤n이고 모든 j<i에서 A[j]≠t라는 불변식을 둔다. i=0에는 앞 항목이 없어 참이다. i<n이고 A[i]≠t이면 i를 하나 늘려도 새 접두부의 모든 항목이 다르므로 보존된다. 일치로 반환하면 앞 위치 모두 불일치이므로 i가 첫 위치다. i=n으로 나가면 전체가 불일치이므로 None이 맞다. 반복을 계속하는 각 회차의 비음수 정수 n−i는 1씩 감소하므로 종료한다. 정상 비교·유한 n·변경 없음이라는 가정이 필요하며, 이 논증은 종이 절차의 의미에 대한 것으로 실제 언어 구현의 예외·자원 오류를 검증한 것은 아니다.

소단원 6.2

탐색·정렬의 직관

카드를 순서대로 놓으면 찾기 쉬워지는데, 그 순서로 놓는 일은 공짜일까?

준비 개념과 학습 목표

준비 개념

  • 정수 카드열의 오름차순은 모든 이웃에 대해 A[i]≤A[i+1]인 상태이며 같은 값의 중복을 허용한다.
  • 정렬은 입력 카드의 값과 개수를 보존하면서 순서를 바꾸는 문제다. 결과가 오름차순이라는 조건만으로는 부족하다.
  • 이 소단원의 이진 탐색은 오름차순 고정 열에서 임의의 일치 위치 또는 None을 반환한다. 앞 소단원의 첫 위치 탐색과 다른 계약이다.

학습 목표

  • 선형 탐색과 정렬을 전제로 하는 이진 탐색을 종이로 추적한다.
  • 선택 정렬의 최솟값 선택·교환·중복 보존을 설명한다.
  • 정렬 비용과 검색 횟수를 함께 고려하고 알고리즘 계약을 구별한다.

순서가 없으면 버릴 근거가 없다

선형 탐색은 왼쪽부터 목표와 비교하므로 정렬되어 있지 않아도 사용할 수 있다. 이진 탐색은 가운데 값보다 목표가 작으면 오른쪽을 버리고, 크면 왼쪽을 버린다. 버린 구간에 목표가 없다는 결론은 카드가 오름차순이라는 조건에서 나온다.

A=[9,1,5],t=9를 정렬된 것처럼 가운데 위치 1에서 검사하면 값 1보다 9가 크므로 왼쪽 위치 0을 버리게 된다. 목표를 실제로 버린 이 반례는 절반씩 줄이는 동작만 흉내 내면 안 된다는 뜻이다. 순서 조건 확인이나 정렬 비용도 목적에 맞게 고려해야 한다.

경계를 줄이며 찾기

검색 구간을 양 끝 포함 [lo,hi]로 두고 mid=⌊(lo+hi)/2⌋를 정한다. A[mid]와 같으면 mid를 반환하고 작으면 hi=mid−1, 크면 lo=mid+1로 바꾼다. lo>hi이면 빈 구간이므로 None이다. 이 경계 규칙에서는 이미 검사한 mid를 다시 포함하지 않는다.

A=[1,1,3,4],t=3은 lo0/hi3/mid1 값 1에서 오른쪽으로 가서 lo2/hi3/mid2 값 3을 찾는다. t=1은 첫 mid1에서 1을 반환할 수 있다. 첫 일치 위치 0을 요구한다면 이 절차를 그대로 쓰지 말고 같을 때도 왼쪽 후보를 더 찾는 별 계약과 알고리즘이 필요하다.

정렬 결과에 필요한 두 조건

선택 정렬은 왼쪽 빈 자리를 하나씩 확정한다. 위치 i에서 아직 확정하지 않은 i..n−1을 훑어 가장 작은 값을 찾고 A[i]와 교환한다. 여기서는 후보를 i로 시작해 j=i+1..n−1을 순서대로 비교하며 더 작은 값일 때만 후보를 바꾸고, i=0..n−2까지 수행한다.

교환은 두 카드의 자리만 바꾸므로 같은 값의 카드 개수까지 보존한다. 반대로 입력[4,1,3,1]을 결과[1,1,1,1]로 바꾸면 오름차순이지만 4와 3을 없애므로 정렬 해답이 아니다. 같은 값에 이름표가 붙었을 때 상대 순서를 보존하는 안정성은 별 요구사항이며 이 선택 정렬은 일반적으로 안정적이지 않다.

중간 과정을 따라가는 예제

고정 열 A=[4,1,3,1]에 위 선택 정렬을 적용하라. 후보 비교는 엄격한 <이며 같은 값이면 앞 후보를 유지한다. 각 패스의 후보 위치·교환 뒤 열·값 비교 횟수를 적어라.

  1. i=0, 후보 0(값 4). j1 값 1에서 후보 1로 바꾸고 j2 값 3과 j3 값 1에서는 유지한다. 후보 1과 0을 교환하여 [1,4,3,1], 값 비교 3회다.
  2. i=1, 후보 1(값 4). j2 값 3에서 후보 2, j3 값 1에서 후보 3으로 바꾼다. 위치 1과 3을 교환하여 [1,1,3,4], 값 비교 2회다.
  3. i=2, 후보 2(값 3). j3 값 4는 더 작지 않아 후보 2를 유지한다. 같은 위치의 교환은 열을 바꾸지 않으며 비교 1회다. i=3 패스는 필요 없다.
  4. 전체 결과[1,1,3,4]는 오름차순이며 1 두 장·3 한 장·4 한 장을 보존한다. 비교 횟수는 3+2+1=6이다. 실제 정렬 프로그램 실행이 아닌 종이 추적이다.

세 패스 뒤 [1,1,3,4], 값 비교 6회. 오름차순과 입력 다중집합 보존을 모두 만족한다.

종이와 본문으로 직접 해보기

오름차순 A=[1,1,3,4]에 위 이진 탐색으로 t=2를 추적하라. 별도로 선택 정렬의 입력[1,1,3,4]에서도 비교가 6회인지 세어라. 카드 2에 왼쪽 a/오른쪽 b 이름을 붙인 [2a,2b,1]은 선택 정렬 뒤 2a/2b 순서를 유지하는지도 적어라.

힌트 보기

각 탐색의 mid와 lo/hi를 적는다. 선택 정렬은 이미 순서가 맞아도 남은 구간을 모두 훑는다. 이름표는 값 비교에 쓰지 않는다.

풀이 보기

t2: [0,3]의 mid1 값 1<2이므로 lo2; [2,3]의 mid2 값 3>2이므로 hi1; 이제 lo2>hi1로 None이다. 목표와 가운데 값의 비교 방문은 2회다. 이미 정렬된 선택 정렬도 남은 비교 3+2+1=6회이며 후보는 각 i에 머문다. [2a,2b,1]은 첫 패스에서 위치 0과 2를 교환해 [1,2b,2a]가 되고 두 번째 패스는 같은값을 바꾸지 않으므로 상대순서가 뒤집힌다. 모두 종이 추적이다.

오해와 반례

정렬하면 검색이 빨라지므로 검색 한 번에도 정렬부터 하는 것이 항상 빠르다.

정렬 작업과 정렬 여부 확인에 드는 비용을 빼면 안 된다. 한 번의 검색은 선형 탐색으로 끝낼 수 있다. 반복 검색에서도 입력 변경 빈도와 정렬 방법·접근 구조를 고려해야 하며, 시간 단위나 자료구조가 다른 측정값을 비교 횟수와 섞어 결론내리지 않는다.

자기점검

답과 이유 보기

아니다.

A=[1,1,3,4],t1에서 mid1을 바로 반환하면 첫 위치 탐색 계약을 만족하는가?

답과 이유 보기

위 선택 정렬에서 길이 4의 이미 정렬된 입력은 값 비교 0회인가?

답과 이유 보기

6회다.

남은 구간 최솟값을 확인하는 루프는 여전히 3+2+1회 비교한다. 교환이 열을 바꾸는 횟수와 비교 횟수는 다르다.

한 단계 더

심화: 선택 정렬에서 i패스 시작 전에 앞 i개가 오름차순이고 앞의 모든 값이 뒤의 모든 값 이하이며 입력 다중집합을 보존한다는 불변식을 둔다. i=0에는 앞부분 조건이 공허하게 참이다. 뒤 구간 최솟값을 A[i]에 교환하면 기존 접두부보다 작지 않고 남은 값보다 크지 않으므로 i+1개 조건이 성립한다. 교환은 다중집합을 보존하고 n−1패스 후 전체 순서가 맞는다. 내부 비교는 Σ(i=0..n−2)(n−i−1)=n(n−1)/2이며 n=0 또는 n=1에는 빈 합 0이다. 값 쌍의 작음/같음/큼을 한 번에 판정하는 추상 비교를 1로 세고 정렬 뒤 정적 배열을 유지한다고 가정한다. 이 모형에서 검색 q회의 단순 비교 견적은 선형 최악 qn, 위 선택 정렬 후 이진 검색은 n(n−1)/2+q(⌊log₂n⌋+1)의 상한(n≥1)이다. 이진 탐색의 한 방문에서 =와 <를 별도로 구현해 세면 개별 비교 연산 수는 이 방문 상한과 같지 않을 수 있다. 이것은 실제초·최적방법·모든 입력의 우열을 보장하는 식이 아니며 중복·갱신·정렬검사 비용과 메모리접근 가정에 주의한다.

소단원 6.3

정확성과 실행 비용

예제 한 개가 맞고 빠르게 끝나면 모든 카드열에서도 맞고 빠르다고 할 수 있을까?

준비 개념과 학습 목표

준비 개념

  • 첫 위치 탐색 FIRST의 입력은 고정 유한 정수열 A와 목표t이며 결과는 첫 일치 위치 또는 None이다.
  • 불변식은 반복의 정해진 시점마다 유지되는 성질이다. 조건부로 결과가 맞는다는 부분 정확성과 반드시 끝난다는 종료를 함께 확인한다.
  • 비용을 세려면 세는 연산·입력 크기·비용모형을 정한다. 이 소단원은 항목과 목표의 같음 비교를 1로 세며 범위검사·출력·초 단위시간은 별도로 구별한다.

학습 목표

  • 첫 위치 탐색의 초기·보존·종료 논증을 직접 연결한다.
  • 최선·최악 입력과 비교 횟수를 구별하고 O/Ω/Θ를 상한/하한/양측 경계로 읽는다.
  • 반례·시험·증명의 범위와 단위비용모형의 제한을 설명한다.

모든 허용 입력에 맞는다는 뜻

정확하다는 말은 골라 본 몇 사례가 아니라 입력 계약에 들어오는 모든 경우에 올바른 결과를 낸다는 뜻이다. A=[8,3,8],t8에서 0을 내는 절차도, 목표가 8이면 무조건 0을 내는 절차도 이 한 사례는 통과한다. 하지만 A=[3],t8에서 후자는 틀린다. 반례 하나는 보편 정확성을 부정할 수 있지만 통과 사례 하나는 증명이 아니다.

증명은 절차의 의미와 가정에서 결과를 연결한다. 예를 들어 앞 위치가 모두 불일치라는 불변식을 세우고 정상 연산·유한 길이·변경 없음 아래에서 초기와 보존을 확인한다. 실제 구현의 문법·예외·입출력·정수 표현이 다른 계약을 가지면 추가 검토가 필요하다. 종이 증명이 코드 전체의 무결함을 자동 보장하지 않는다.

맞게 반환하는 것과 반드시 끝나는 것

FIRST가 일치를 반환하는 시점에는 앞 모든 항목을 이미 확인해 불일치였으므로 첫 위치가 맞다. 끝까지 갔다면 모든 항목이 불일치이므로 None이 맞다. 그러나 “반환한다면 정답”만 보이면 끝나지 않는 입력이 있는지 알 수 없다.

불일치 회차마다 위치가 1씩 증가하고 남은 카드 수 n−i가 감소한다. 이 값은 반복 머리에서 비음수 정수이며 계속 감소할 수 있는 횟수는 유한하다. 따라서 정상 비교가 각각 종료하는 계약에서는 FIRST도 종료한다. 실패 경로에서 증가가 없는 절차는 반환한 성공 사례가 맞더라도 완전한 해결 절차가 아니다.

성장률 표기의 대상 함수를 정하기

길이 n의 입력에서도 찾는 위치에 따라 같음 비교 횟수가 다르다. 성공 첫 위치 j이면 j+1회이고 없으면 n회다. n≥1의 최선 비교 수 B(n)=1, 최악 W(n)=n이다. O는 어떤 비용함수의 충분히 큰 n에서의 상한, Ω는 하한, Θ는 같은 성장률의 상·하한을 모두 주는 표기다. Ω 자체가 최선 경우라는 뜻은 아니다.

이 모형에서는 W(n)=Θ(n)이고 B(n)=Θ(1)이다. W(n)는 O(n²)도 만족하지만 느슨한 상한이므로 가장 정확한 성장률 설명은 아니다. 전체 연산 시간도 선형 최악이라고 분석하려면, 값·인덱스·주소가 각각 O(1)개의 워드에 들어가고 임의 위치 접근·워드 비교·증가가 단위 비용이라는 계산모형을 정해야 한다. Word-RAM의 워드 폭 w는 길이 n의 주소를 나타낼 수 있게 적어도 log₂n 정도여야 한다. 실제 고정 32/64비트 기계는 표현 가능한 주소 범위가 유한하므로 무제한 n의 점근모형과 구별한다. 길어지는 문자열이나 임의 크기 정수의 비교, 느린 외부 저장 접근을 무조건 상수라고 가정하지 않는다.

중간 과정을 따라가는 예제

A=[6,2,6,9]의 FIRST에서 독립 목표t=6,9,5를 추적하라. 항목-목표 같음 비교만 세고 각 결과가 첫 위치 계약을 만족하는 이유를 적어라.

  1. t6은 i0에서 A[0]=6을 확인해 결과 0이다. 비교 1회이며 더 앞의 위치가 없어 첫 일치다. 위치 2의 6은 검사하지 않는다.
  2. t9는 위치 0의 6,1의 2,2의 6과 불일치한 뒤 위치 3의 9에서 성공한다. 결과 3, 비교 4회이며 앞 세 위치 모두 다르다.
  3. t5는 네 위치 모두 불일치하고 i4에서 4<4가 거짓이라 None이다. 비교 4회이며 이 결과는 전체 불일치에 근거한다.
  4. 같은 n4에서도 비용은 1/4/4회다. 실패 예제의 범위검사는 5회로 같음 비교 4회와 다르다. 최악 비교 W(4)=4가 실제 몇 초인지는 이 기록으로 알 수 없다.

각 (결과, 같음 비교 수)는 (0,1),(3,4),(None,4)다. 성공 위치와 실패 전체 검사의 근거를 따로 확인한다. 모두 종이 계산이다.

종이와 본문으로 직접 해보기

길이 8 카드열에서 첫 일치 위치 5인 입력과 미발견 입력의 같음 비교 수를 계산하라. 별도 절차가 “항목이 목표와 같으면 반환, 다르면 i를 바꾸지 않고 반복”이라면 A=[6],t2에서 종료하는지 상태를 적어라.

힌트 보기

위치는 0부터 시작하므로 위치 5까지 읽은 항목 수와 위치 번호가 같지 않다. 종료량이 실제로 감소하는지도 확인한다.

풀이 보기

첫 일치 위치 5는 0..5까지 6회, 미발견은 8회다. 잘못된 절차는 i0,n1 상태에서 6≠2를 확인하고 다시 i0,n1로 돌아가므로 동일 비교를 무한히 반복한다. n−i=1이 감소하지 않는다. 이 반례는 종이로 확인했으며 무한 반복 프로그램을 실제 실행하지 않았다.

오해와 반례

Ω는 최선 경우이고 Θ는 최선과 최악이 서로 같을 때만 쓰는 기호다.

기호는 먼저 지정한 함수의 경계를 말한다. 예를 들어 최악 비교 W(n)=n 자체가 Ω(n)이자 O(n)이므로 Θ(n)이다. 이 탐색의 최선 B(n)=1과 최악 W(n)=n은 다른 함수이고 서로 같지 않아도 각 함수에 Θ 표기를 쓸 수 있다.

자기점검

FIRST에서 첫 일치 위치 7의 같음 비교는 7회인가?

답과 이유 보기

8회다.

위치 0부터 7까지 총 8개를 비교한다.

W(n)=n에 O(n²)를 쓰면 수학적으로 틀리는가?

답과 이유 보기

아니지만 느슨한 상한이다.

n≥1이면 n≤n²이다. 상한을 만족하는 것과 긴밀한 Θ(n) 설명은 구별한다.

길이가 항상 4인 카드 한 묶음에서 측정한 1/4회로 모든 크기의 성장률을 증명했는가?

답과 이유 보기

아니다.

고정 사례의 횟수와 임의 n에 대한 일반 불변식·반복 횟수 유도는 다른 증거다.

심화: 비음수 비용함수 f에 대해 f∈O(g)는 어떤 C>0,N이 있어 모든 n≥N에서 f(n)≤C g(n), f∈Ω(g)는 어떤 c>0,N이 있어 f(n)≥c g(n)이고 Θ(g)는 둘 다 성립함을 뜻한다(여기 g는 충분히 큰 n에서 양수). W(n)=n에는 c=C=1,N=1을 쓰면 Θ(n)을 바로 보인다.
