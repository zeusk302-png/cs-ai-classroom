小节 6.1

伪代码与流程图

一列卡片中同一个数字出现两次时，“找到了”究竟指哪个位置？

预备知识与学习目标

预备知识

  • 有限整数卡片序列 A 的长度为 n，从左往右将位置编号为 0,1,…,n−1。空序列的 n=0，没有有效元素位置。
  • 赋值会改变状态，比较用于判断条件。i←i+1 是把当前位置加一的指令，不是在求数学等式的解。
  • None 是未找到的独立标记，应与有效位置 0 区分。本单元假设比较正常终止，且卡片序列在过程中不变。

学习目标

  • 先规定输入、允许的输出及停止条件，再写伪代码。
  • 把顺序、条件分支与重复过程对应到流程图，并追踪空输入。
  • 说明易读的句子与含义明确的执行规则之间的区别。

先写清查找问题的约定

只把问题写成“找数字”，答案的形式并没有确定。是否存在、任意一个匹配位置、最左匹配位置，是不同的约定。这里对输入 A 和目标 t，若存在匹配位置，就返回最小的位置；否则返回 None。即使多张卡片的值相同，答案也唯一确定。

例如 A=[8,3,8], t=8 时，2 是匹配位置，但按此约定正确输出为 0。还要写明输入条件。若去掉有限卡片序列、正常整数比较、执行过程中不变的假设，就不能原样使用下面的终止性与正确性论证。

面向人的步骤也必须含义明确

伪代码不受某一编程语言语法的约束，用来记录顺序与条件。但“适当地找一找”这种无法确定下一步动作的话并不足够。下面的 RETURN 将一个值作为结果输出并结束整个过程；WHILE 的循环体在条件为真时重复。

必须先确认 i<n，才能读取 A[i]。n=0 时循环体一次也不执行，直接返回 None。在 i=n 时最后一次条件检查之后，不读取 A[n]。缩进显示哪些指令属于循环或条件，因而不只是装饰。

FIRST(A,t)
  n ← LENGTH(A)
  i ← 0
  WHILE i < n:
    IF A[i] = t: RETURN i
    i ← i + 1
  RETURN None

读懂流程图中返回的箭头

流程图用方框与箭头表示同一个过程。下面文字图中的问句是条件判断，并分别写出两种结果的去向。指向 RETURN 的箭头表示结束，不再进入下一个位置。循环箭头在增加 i 后回到再次检查范围的位置。

画出图并不意味着它就正确。若在 A[i]=t 的“否”路径漏掉递增，第一张卡不匹配时就会不断访问同一状态。应同时检查易读的表达、明确的状态转移、所有路径的处理及终止。

开始 → n=LENGTH(A), i=0 → [i<n?]
[i<n?] 否 → RETURN None → 结束
[i<n?] 是 → [A[i]=t?]
[A[i]=t?] 是 → RETURN i → 结束
[A[i]=t?] 否 → i=i+1 → [i<n?]

逐步推导的例题

把上述 FIRST 过程与流程图应用于 A=[8,3,8], t=8。分别记录卡片值与位置，并判断返回后是否还执行指令。

  1. 长度 n=3，初始位置 i=0。有效位置为 0,1,2，第一张卡的值为 8。
  2. 0<3 为真，因此读取位置 0 的值。A[0]=8=t 为真。
  3. RETURN i 输出结果 0，结束整个 FIRST 过程。不执行 i=i+1，也不检查位置 1,2。
  4. 输出 0 与卡片值 8 不同。即使另有匹配位置 2，最小位置仍为 0，因此满足约定。这是纸上追踪，不是程序的实际输出。

返回最左匹配位置 0。在第一个元素处结束，元素与目标的相等比较共 1 次。

用纸笔和正文动手试一试

分别独立地在纸上追踪 A=[8,3,8],t=3、同一 A 且 t=5，以及 A=[],t=8。写出各结果及元素与目标的相等比较次数，不把范围检查计入该次数。

查看提示

i<n 为假时不读取元素。成功 RETURN 后不再返回循环。

查看解答

t=3 时，先与位置 0 的 8 比较失败，在 i=1 的 3 处成功，结果为 1，相等比较 2 次。t=5 在位置 0,1,2 全部失败，随后 i=3 的范围检查为假，因此返回 None，相等比较 3 次。空序列一开始 0<0 就为假，因此返回 None，相等比较 0 次。范围检查次数分别另计为 2,4,1 次。全部是纸上计算。

常见误解与反例

伪代码没有可执行语法，因此不必准确写出分支去向与输入条件。

不断在同一位置重复的图与进入下一位置的图，结果和终止性不同。伪代码允许自由选择语法，但不允许遗漏语义。例如 A=[8],t=3 时，没有递增的失败路径不会终止。

检查理解

A=[8,3,8],t=8 时返回 2，是否符合此约定？

查看答案与理由

不符合。

与只判断存在或查找任意匹配位置的约定不同，这里要求最小匹配位置 0。

空卡片序列是否必须读取 A[0]，才能确定 None？

查看答案与理由

不读取。

范围检查 0<0 先为假，不进入循环体。

RETURN 1 后，是否增加 i 并继续检查其余元素？

查看答案与理由

不检查。

RETURN 结束整个过程，该次调用不再执行之后的指令。

进一步探索

进阶：在循环头部，若尚未返回，设不变式为 0≤i≤n，且对所有 j<i 都有 A[j]≠t。i=0 时没有前面的元素，因此成立。若 i<n 且 A[i]≠t，把 i 加一后，新前缀的所有元素仍不匹配，故不变式保持。匹配时返回，由于前面的所有位置都不匹配，i 就是第一个匹配位置。若以 i=n 退出，则整个序列均不匹配，None 正确。每个继续循环的轮次中，非负整数 n−i 减少 1，因此终止。需要正常比较、有限 n、过程中不变的假设。这一论证针对纸上过程的语义，未验证实际语言实现中的异常或资源错误。

小节 6.2

查找与排序的直觉

把卡片排好顺序会更容易查找，但排好顺序这件事是免费的吗？

预备知识与学习目标

预备知识

  • 整数卡片序列升序排列，指对每对相邻元素都有 A[i]≤A[i+1]，允许重复值。
  • 排序是保持输入卡片的值与数量不变，只改变顺序的问题。仅要求输出为升序还不够。
  • 本节的二分查找在固定的升序序列上返回任意一个匹配位置或 None，与前一节的首个位置查找约定不同。

学习目标

  • 在纸上追踪线性查找与以排序为前提的二分查找。
  • 说明选择排序中选取最小值、交换与保留重复元素的过程。
  • 同时考虑排序成本与查找次数，并区分算法约定。

没有顺序就没有丢弃的依据

线性查找从左往右与目标比较，因此即使没有排序也可以使用。二分查找在目标小于中间值时丢弃右侧，大于中间值时丢弃左侧。能断言被丢弃的区间没有目标，依据是卡片已经按升序排列。

若把 A=[9,1,5],t=9 当作已排序，在中间位置 1 检查，因 9 大于值 1 就丢弃左侧位置 0。这一实际丢掉目标的反例表明，不能只模仿每次减半的动作。也应根据目的考虑检查顺序条件或排序的成本。

缩小边界进行查找

设搜索区间为包含两端的 [lo,hi]，取 mid=⌊(lo+hi)/2⌋。若目标等于 A[mid]，返回 mid；若较小，则 hi=mid−1；若较大，则 lo=mid+1。lo>hi 时区间为空，返回 None。此边界规则不会再次包含已经检查的 mid。

A=[1,1,3,4],t=3 时，从 lo0/hi3/mid1 的值 1 向右进入 lo2/hi3/mid2 的值 3，找到目标。t=1 时可以在首个 mid1 处返回 1。若要求第一个匹配位置 0，就不能原样使用此过程，而需要在相等时继续寻找左侧候选的另一约定与算法。

排序结果需要满足两个条件

选择排序依次确定左侧的空位。在位置 i，扫描尚未确定的 i..n−1，找出最小值并与 A[i] 交换。这里把候选初始化为 i，按顺序比较 j=i+1..n−1，仅在值更小时更换候选，并对 i=0..n−2 执行。

交换只改变两张卡的位置，所以连相同值的卡片数量也保持不变。相反，若把输入 [4,1,3,1] 改为输出 [1,1,1,1]，虽然升序，却删除了 4 与 3，因而不是排序的答案。相同值带标签时，保持它们的相对顺序称为稳定性，是额外要求；这一选择排序一般不稳定。

逐步推导的例题

对固定序列 A=[4,1,3,1] 应用上述选择排序。候选比较使用严格 <，相等时保留先前候选。记录每一轮的候选位置、交换后的序列与值比较次数。

  1. i=0，候选为位置 0（值 4）。在 j1 的值 1 处改为候选 1，在 j2 的值 3 与 j3 的值 1 处保持不变。交换位置 1 与 0，得到 [1,4,3,1]，值比较 3 次。
  2. i=1，候选为位置 1（值 4）。在 j2 的值 3 处改为候选 2，在 j3 的值 1 处改为候选 3。交换位置 1 与 3，得到 [1,1,3,4]，值比较 2 次。
  3. i=2，候选为位置 2（值 3）。j3 的值 4 不更小，保持候选 2。相同位置的交换不改变序列，比较 1 次。不需要 i=3 这一轮。
  4. 最终结果 [1,1,3,4] 为升序，且保留两张 1、一张 3 与一张 4。比较次数为 3+2+1=6。这是纸上追踪，不是实际执行排序程序。

三轮之后得到 [1,1,3,4]，值比较 6 次。既满足升序，又保留输入多重集。

用纸笔和正文动手试一试

对升序 A=[1,1,3,4]，按上述二分查找追踪 t=2。另计算选择排序对输入 [1,1,3,4] 是否仍比较 6 次。再给值为 2 的卡片分别加左侧 a、右侧 b 标签，判断 [2a,2b,1] 经选择排序后是否保持 2a/2b 的顺序。

查看提示

记录每次查找的 mid 与 lo/hi。即使已经排好顺序，选择排序仍扫描整个剩余区间。标签不参与值比较。

查看解答

t2：[0,3] 的 mid1 值 1<2，所以 lo2；[2,3] 的 mid2 值 3>2，所以 hi1；此时 lo2>hi1，返回 None。访问中间值并与目标比较共 2 次。已排序输入的选择排序仍比较 3+2+1=6 次，候选保持在各 i。对 [2a,2b,1]，第一轮交换位置 0 与 2 后成为 [1,2b,2a]，第二轮不更换相同值，故相对顺序逆转。全部为纸上追踪。

常见误解与反例

排序能使查找更快，所以即使只查找一次，也总是先排序更快。

不能省略排序与检查是否排序的成本。一次查找可以直接用线性查找完成。多次查找也需要考虑输入更新频率、排序方法与访问结构，不能把不同时间单位或数据结构的测量值与比较次数混在一起下结论。

检查理解

仅检查输出为升序，是否足以确认排序正确？

查看答案与理由

不足以。

还必须保留输入的值与重复次数。[1,1,1,1] 丢失了原输入的 3 与 4。

A=[1,1,3,4],t1 时直接返回 mid1，是否满足首个位置查找约定？

查看答案与理由

不满足。

它符合任意匹配位置的约定，但首个位置是 0。应先检查算法允许的输出。

上述选择排序对长度 4 的已排序输入，值比较是否为 0 次？

查看答案与理由

为 6 次。

检查剩余区间最小值的循环仍比较 3+2+1 次。使序列发生变化的交换次数与比较次数不同。

进一步探索

进阶：在选择排序第 i 轮开始前，设不变式为前 i 个元素升序，前部每个值均不大于后部每个值，且输入多重集保持不变。i=0 时前部条件空真。把后部最小值交换到 A[i] 后，它不小于原前缀，又不大于剩余值，故前 i+1 个元素的条件成立。交换保留多重集，n−1 轮后全体顺序正确。内部比较总数为 Σ(i=0..n−2)(n−i−1)=n(n−1)/2，n=0 或 n=1 时为空和 0。假设一次抽象比较可同时判定一对值的小于/等于/大于，并计为 1；排序后保持静态数组。在此模型中，q 次查找的简单比较估算为：线性查找最坏 qn，先做此选择排序再二分查找的上界为 n(n−1)/2+q(⌊log₂n⌋+1)，其中 n≥1。如果在二分查找的一次访问中把 = 与 < 分别实现并计数，则单独比较操作数可能不等于这一访问上界。这不是保证实际秒数、最佳方法或所有输入优劣关系的表达式；还须注意重复值、更新、排序检查成本及内存访问假设。

小节 6.3

正确性与执行成本

一个例题结果正确、很快结束，就能说所有卡片序列都正确且快速吗？

预备知识与学习目标

预备知识

  • 首个位置查找 FIRST 的输入为固定有限整数序列 A 与目标 t，结果为首个匹配位置或 None。
  • 不变式是在循环的指定时刻持续成立的性质。须同时检查“若返回则结果正确”的部分正确性与必定结束的终止性。
  • 计量成本前要确定计数的操作、输入规模与成本模型。本节把元素与目标的相等比较计为 1，另行区分范围检查、输出与以秒计的时间。

学习目标

  • 直接连接首个位置查找的初始化、保持与终止论证。
  • 区分最好、最坏输入及比较次数，把 O/Ω/Θ 理解为上界、下界与双侧界。
  • 说明反例、测试、证明各自的范围，以及单位成本模型的限制。

对所有允许输入正确的含义

正确意味着对输入约定包含的所有情况输出正确结果，而不只是挑选的几个案例。对 A=[8,3,8],t8 返回 0 的过程，与“目标为 8 就无条件返回 0”的过程，都能通过这一个案例。但后者在 A=[3],t8 时错误。一个反例可以否定普遍正确性，一个通过的案例却不是证明。

证明从过程的语义与假设连接到结果。例如，设立前面所有位置均不匹配的不变式，并在正常操作、有限长度、过程中不变的条件下验证初始化与保持。若实际实现的语法、异常、输入输出或整数表示具有不同约定，还须进一步检验。纸上证明不会自动保证整个代码毫无缺陷。

正确返回与必定结束

FIRST 返回匹配位置时，前面所有元素均已检查为不匹配，所以返回的是首个位置。如果到达末尾，则所有元素都不匹配，所以 None 正确。但只证明“若返回则答案正确”，还不能知道是否有输入永远不结束。

每轮不匹配时，位置增加 1，剩余卡片数量 n−i 减少。该值在循环头部为非负整数，能持续减少的次数有限。因此，在每次正常比较均终止的约定下，FIRST 也终止。失败路径没有递增的过程，即使成功返回的案例正确，也不是完整的求解过程。

先确定增长率符号所描述的函数

即使输入长度同为 n，相等比较次数也随匹配位置而不同。成功的首个位置为 j 时比较 j+1 次，未找到时比较 n 次。n≥1 时最好比较数 B(n)=1，最坏 W(n)=n。O 表示某个成本函数在充分大的 n 处的上界，Ω 表示下界，Θ 同时表示同一增长率的上界与下界。Ω 本身并不意味着最好情况。

在此模型中 W(n)=Θ(n)，B(n)=Θ(1)。W(n) 也满足 O(n²)，但这是较松的上界，不是最精确的增长率说明。若还要分析全部操作时间为线性最坏情况，须规定计算模型：值、索引与地址分别占 O(1) 个机器字，随机位置访问、机器字比较及递增为单位成本。Word-RAM 的机器字宽度 w 至少应约为 log₂n，才能表示长度 n 的地址。实际固定 32/64 位机器能表示的地址范围有限，应与 n 无限制的渐近模型区分。不能一概把不断增长的字符串、任意精度整数比较或缓慢的外部存储访问视为常数成本。

逐步推导的例题

对 A=[6,2,6,9] 的 FIRST，分别独立追踪目标 t=6,9,5。只计元素与目标的相等比较，并说明各结果为何满足首个位置约定。

  1. t6 在 i0 确认 A[0]=6，结果为 0。比较 1 次，且没有更前的位置，所以是首个匹配。不检查位置 2 的 6。
  2. t9 与位置 0 的 6、位置 1 的 2、位置 2 的 6 均不匹配，随后在位置 3 的 9 成功。结果为 3，比较 4 次，前面三个位置均不同。
  3. t5 与四个位置都不匹配，i4 时 4<4 为假，返回 None。比较 4 次，结果依据是全体不匹配。
  4. 同为 n4，成本却是 1/4/4 次。失败案例的范围检查为 5 次，与相等比较 4 次不同。最坏比较 W(4)=4 究竟花费多少秒，无法从这项记录知道。

各组（结果，相等比较数）为 (0,1),(3,4),(None,4)。分别检查成功位置与失败时全体检查的依据。全部为纸上计算。

用纸笔和正文动手试一试

计算长度 8 的卡片序列中，首个匹配位置为 5 的输入与未找到的输入各需多少次相等比较。另一个过程若“元素等于目标就返回，不等则保持 i 不变并重复”，写出 A=[6],t2 时的状态，判断它是否终止。

查看提示

位置从 0 开始，因此读取到位置 5 时，已读元素数不等于位置编号。也要确认终止量是否真的减少。

查看解答

首个匹配位置 5 要读取 0..5，共 6 次；未找到则为 8 次。错误过程在 i0,n1 状态检查 6≠2 后回到同一 i0,n1，因此无限重复同一比较。n−i=1 不减少。此反例在纸上确认，未实际运行无限循环程序。

常见误解与反例

Ω 是最好情况，Θ 只能在最好与最坏相同时使用。

这些符号描述先指定的函数的界。例如最坏比较 W(n)=n 本身既是 Ω(n) 又是 O(n)，所以是 Θ(n)。这一查找的最好 B(n)=1 与最坏 W(n)=n 是不同函数；即使二者不相等，也能分别对各函数使用 Θ。

检查理解

FIRST 中首个匹配位置为 7，是否比较 7 次？

查看答案与理由

8 次。

从位置 0 到 7，共比较 8 个元素。

对 W(n)=n 写 O(n²)，在数学上是否错误？

查看答案与理由

不错误，但上界较松。

n≥1 时 n≤n²。满足上界与紧确的 Θ(n) 说明须作区分。

在始终长度为 4 的一组卡片中记录 1/4 次，是否就证明了所有规模的增长率？

查看答案与理由

没有。

固定案例的次数与对任意 n 的一般不变式、循环次数推导，是不同的证据。

进一步探索

进阶：对非负成本函数 f，f∈O(g) 指存在 C>0 与 N，使所有 n≥N 都满足 f(n)≤C g(n)；f∈Ω(g) 指存在 c>0 与 N，使 f(n)≥c g(n)；Θ(g) 指两者都成立，其中 g 在充分大的 n 时为正。对 W(n)=n，取 c=C=1,N=1 即可证明 Θ(n)。对 B(n)=1，用相同常数得 Θ(1)。若另规定输入与目标的分布，在 n≥1 的模型中假设总能成功，且首个匹配位置 J 在 0..n−1 上均匀分布，则平均 E[C]=(1+…+n)/n=(n+1)/2。没有均匀性或总成功条件，就不能原样使用此平均式。所有元素相同的实际输入、混有未找到情况的输入等属于其他分布。算出的平均值、墙钟执行时间与学习者理解程度，属于不同测量。
