소단원 13.1

규칙 기반과 학습 기반

조건문을 쓰는 프로그램과 예시에서 규칙을 고르는 프로그램은 어떻게 다를까?

준비 개념과 학습 목표

준비 개념

  • if 조건

  • 입력과 출력

  • 표의 값 비교

학습 목표

  • 사람이 정한 규칙과 자료로 선택한 매개변수를 구별한다.

  • 작은 후보 집합의 학습 과정을 손으로 계산한다.

  • 어느 방식도 자동으로 옳지 않음을 설명한다.

훈련표에서 같은 답을 내는 두 임계값이 새 입력에서도 같을까?

base의 네 학습 행 (1,0),(4,0),(6,1),(9,1)에 후보 t=6을 추가하자. h_t(x)는 x≥t이면 1이다. t=5와 6은 네 행에서 같은 출력을 내지만 x=5에서는 다르다. 훈련표가 두 모델을 구별할 정보를 주지 않는 것이다.

동률 정책은 구현을 결정하기 위한 규칙이지 새 입력의 참 label을 알아내는 증거가 아니다. 오분류 수뿐 아니라 오류 종류의 비용도 목적에 따라 다르게 정할 수 있다. 아래는 거짓 양성 비용 2, 거짓 음성 비용 5인 자체 비교이며 실제 사람의 손해를 측정한 수치는 아니다.

먼저 확인할 개념
  • 문제와 비용 기준

    무엇을 최소화하는지 먼저 정의한다.

  • 검사한 입력의 범위

    학습표 일치를 모든 새 입력의 정확성으로 확대하지 않는다.

규칙은 누가 정하는가

규칙 기반 프로그램은 사람이 명시한 조건을 실행한다. 예를 들어 점수 x가 5 이상이면 1, 아니면 0을 반환하도록 작성할 수 있다. 입력을 비교하고 출력하는 컴퓨터 동작은 정확하게 정의할 수 있지만 그 규칙이 실제 목표에 적합한지는 별도 문제다.

학습 기반 프로그램은 정해진 모델 종류와 학습 절차 안에서 자료에 맞는 매개변수를 선택한다. 사람은 목표·입력·후보·오차 기준을 설계한다. 컴퓨터가 목표와 가치 판단을 스스로 완전히 정하는 것은 아니다.

작은 후보 중 하나를 고르는 학습

자체 모델 h_t(x)는 x≥t이면 1, 아니면 0이다. t 후보가 3·5·7일 때 각 후보의 학습 표 오분류 수를 세어 가장 적은 후보를 고른다. 이 유한 탐색도 자료에서 매개변수를 고르는 단순 학습의 예다. 딥러닝을 실행하거나 현실을 이해하는 모델이라는 뜻은 아니다.

학습이 끝나면 고정 t를 이용해 새 x의 예측을 구한다. 추론 때도 비교라는 알고리즘을 실행한다. 학습 기반이라 조건문과 계산이 없어지는 것은 아니며 개발자가 모든 개별 입력의 정답을 직접 규칙에 쓰지 않는다는 차이가 있다.

규칙과 학습은 함께 쓸 수 있다

서비스는 입력 형식 검사 같은 명시 규칙과 모델 예측을 결합할 수 있다. 모델 출력만으로 실행 권한을 정하지 않고 필요한 업무 정책은 따로 확인한다. 단순하고 검증하기 쉬운 규칙이 충분한 문제도 있다.

새 데이터가 과거와 다르거나 label이 틀렸으면 학습 결과가 틀릴 수 있다. 규칙도 현실 변화에 맞지 않을 수 있으므로 둘 모두 목표와 평가 자료에 비추어 점검한다. 어느 방식이 더 낫다는 이름만의 결론을 내리지 않는다.

거짓 양성은 label 0을 1로, 거짓 음성은 label 1을 0으로 예측한 것이다. 비용은 2×거짓 양성+5×거짓 음성이다. 학습표 밖에서의 비용은 아직 알 수 없다.

중간 과정을 따라가는 예제

자체 학습 표는 (x,label)=(1,0),(4,0),(6,1),(9,1)이다. 후보 t=3/5/7에서 h_t(x)의 오분류 수를 세어 고르고 새 x=5를 예측하자. 동률이면 작은 t를 고른다는 규칙을 미리 둔다.

  1. t=3의 출력은 0/1/1/1이다. x=4 한 행이 틀려 오분류 1이다.

  2. t=5의 출력은 0/0/1/1이라 오분류 0이다. t=7의 출력은 0/0/0/1이라 x=6이 틀려 오분류 1이다.

  3. 최소인 t=5를 선택한다. 새 x=5는 경계 포함 x≥5라 예측 1이다. 새 입력의 실제 정답을 확인한 것은 아니다.

후보 오분류는 1/0/1, 선택 t=5이며 새 예측은 1이다. 네 학습 행의 일치가 모든 새 입력의 정답을 보장하지 않는다.

조건을 바꾸어 비교하기

동률과 관측하지 않은 입력

t=5/6 중 작은 t를 고르는 정책과 큰 t를 고르는 정책을 비교하라.

  1. 두 후보의 학습 오류는 모두 0이다.

  2. 작은 정책은 5, 큰 정책은 6을 고른다.

  3. x=5의 예측은 각각 1과 0이다. 실제 label은 주어지지 않았다.

동률 정책이 새 예측을 바꾸지만 어느 예측이 정답인지 이 표로 결정하지 못한다.

비교할 점

base에 단순 추가 후보로 식별되지 않은 영역을 드러낸다.

같은 오류 수와 다른 목적

t=3과 7은 오류 수가 각각 1이다. 비용 기준으로 비교하라.

  1. 3은 x=4의 거짓 양성 하나라 비용 2다.

  2. 7은 x=6의 거짓 음성 하나라 비용 5다.

  3. 가중 비용 기준에서는 3이 더 작다. 두 후보 모두 비용 0인 5/6보다는 크다.

오류 수 동률이 비용 동률을 뜻하지 않는다.

비교할 점

분모만 바꾸는 정확도 비교와 오류 비용 비교를 구별한다.

종이와 본문으로 직접 해보기

별도 학습 표에서 x=4의 label만 1로 바꾸면 후보 오류와 선택은? 선택 모델로 새 x=2를 예측하자.

힌트 보기

새 label은 0/1/1/1이고 후보 출력은 그대로다.

풀이 보기

t=3/5/7의 오류는 0/1/2다. t=3을 고르고 x=2는 0으로 예측한다. 변경된 label이 올바른지는 이 계산과 별도로 확인해야 한다.

준비 개념과 학습 목표

준비 개념

  • 학습 후보와 오차

  • 분리된 표

  • 정확도 분모

학습 목표

  • 학습·검증·최종 평가 자료의 역할을 구별한다.

  • 검증 결과의 선택과 고정 모델의 추론을 추적한다.

  • 미래 정답·평가 자료의 누출을 설명한다.

검증표를 보고 모델을 고르는 것과 새 입력을 예측하는 것은 어느 기록에서 갈라질까?

새 예에서는 후보 h5/h6를 학습 자료만으로 준비한 뒤 validation의 (5,0)을 공개한다. h5는 1, h6는 0이므로 h6를 선택한다. 이 label은 선택에 쓰였으므로 이후 독립 최종 평가의 새 정답으로 다시 세지 않는다.

선택 후 test는 (4,0),(6,1) 두 행이고 고정 h6의 정확도는 2/2다. 새 입력 7의 예측은 1이나 정답이 없어 정확도에 추가하지 않는다. 전처리의 학습 평균도 모델에 연결된 고정 정보이며 자료마다 새로 맞추지 않는다.

    평가한 고정 후보와 나중에 수정한 후보를 구별한다.

자료를 쓰는 목적을 구별한다

학습 자료는 매개변수를 맞추는 데 쓰고 검증 자료는 모델 종류나 설정 선택을 돕는다. test 자료는 선택을 마친 모델의 최종 평가에 따로 둔다. 정답을 알고 계산하는 평가와 실제 새 입력의 정답을 아직 모르는 추론은 다르다.

분할 비율은 데이터 크기·목표·시간·사용자 중복에 따라 정한다. 같은 사람이나 거의 같은 기록이 양쪽에 섞이면 새로운 대상 성능을 과대 해석할 수 있다. 미래 자료 예측에서는 시간 순서와 예측 시점에 사용 가능한 정보도 중요하다.

검증 점수를 보고 선택한다

아래 두 후보는 학습 자료만으로 이미 만든 고정 후보다. validation 정확도로 하나를 고른 뒤 test를 공개한다. test 결과를 보고 선택을 다시 바꾸면 원래의 독립 최종 평가 역할을 잃는다. 작은 표의 점수를 전체 모집단의 정확도로 단정하지 않는다.

validation을 반복해서 보고 많은 결정을 내리면 그 자료에도 맞춰질 수 있다. 점수가 높다는 사실만으로 자료 수·대표성·새 환경의 차이가 해결되지는 않는다. 어떤 자료가 어떤 결정에 사용됐는지 기록한다.

전처리도 학습되는 부분이다

평균·표준화·특징 선택처럼 자료에서 값을 고르는 전처리는 학습 자료에서만 fit한다. 검증/test에는 정한 변환을 동일하게 적용한다. 전체 자료 평균을 먼저 구하면 평가 자료의 정보가 선택에 섞인다.

추론 입력에는 예측 시점에 얻을 수 없는 미래 정답을 넣지 않는다. 예를 들어 완료 여부를 예측하는 입력에 나중에 기록된 완료 시각을 넣으면 목적과 정보 시점이 어긋난다. 여기는 가상 표만 쓰고 실제 학생 자료를 모으지 않는다.

중간 과정을 따라가는 예제

이미 학습된 자체 후보 H1/H2의 validation 실제 label은 0/1/1/0이다. 예측은 H1=0/1/0/0, H2=0/1/1/0이다. 검증으로 선택한 뒤 공개한 test label은 1/0/1이고 H2 예측은 1/1/1이다.

  1. H1은 3/4=75%, H2는 4/4=100% validation 정확도다. 미리 정한 기준으로 H2를 선택한다.

  2. 고정 H2의 test는 둘째가 틀려 2/3≈66.7%다. validation 100%와 test 약 66.7%는 다른 표의 결과다.

  3. 새 입력 한 개에서 H2가 0을 냈다면 이는 예측이다. 실제 label을 확인하기 전 정확/오류로 셀 수 없다. test를 보고 H1로 바꾸면 새 선택 과정과 별도 평가가 필요하다.

검증에서 H2를 골랐고 test 정확도는 2/3다. 새 입력의 0은 아직 정답 확인 전 예측이다.

소단원 13.3

통계와 데이터 편향

전체 정답 비율 90%만 보면 모든 입력 조건에서도 잘 작동한다고 말할 수 있을까?

준비 개념과 학습 목표

준비 개념

  • 비율·가중평균

  • 표본과 목표 대상

  • 분류의 정답/오류

학습 목표

  • 집단 크기로 가중한 전체 정확도를 계산한다.

  • 자료 선택·기록·label·환경 차이를 구별한다.

  • 집단별 값과 인과·공정성 판단의 차이를 설명한다.

입력 조건의 비중이 달라지면 두 모델의 전체 점수 순서도 바뀔까?

가상 조건 A/B에서 모델 X의 관측 정확도는 9/10과 6/10, 모델 Y는 각각 8/10이다. 이는 같은 조건별 작은 평가표의 값이다. 평가 대상이 A에 몰렸는지 B에 몰렸는지에 따라 전체 가중 점수는 달라진다.

목표 비중으로 다시 계산한 값은 조건별 성능이 유지된다고 가정한 예상이다. 새 환경에서 실제 유지되는지는 별도 자료로 확인해야 한다. A/B는 실제 사람의 속성 집단이 아니라 가상 입력 조건이며 점수 순서가 공정성이나 오류 원인의 판정을 대신하지 않는다.

먼저 확인할 개념
  • 비율과 분모

    서로 다른 요청 분모의 비율을 구별하여 계산한다.

  • 집계 조건

    서로 겹치지 않는 조건과 유효한 성공/전체 수를 확인한다.

표에 들어온 자료가 무엇을 대표하나

데이터는 현실 전체가 아니라 수집 과정의 결과다. 특정 장치·시간·참여자만 기록하면 목표 사용자의 분포와 다를 수 있다. 응답하지 않은 대상, 드문 사건의 누락, 과거 label의 불평등도 점검한다. 행이 많다는 사실만으로 이런 차이가 없어지지는 않는다.

통계적 편향은 목적에 비추어 체계적인 차이를 뜻할 수 있고 사회적 공정성 문제와 함께 검토해야 하지만 두 개념을 한 숫자로 같게 만들지 않는다. 원인과 영향은 추가 자료가 필요하다. 실제 개인의 집단 속성을 추측해 채우지 않는다.

전체 비율은 자료의 섞인 비중을 반영한다

서로 겹치지 않는 두 집단의 전체 정확도는 맞은 수를 합쳐 전체 수로 나눈다. 집단별 정확도를 단순 평균하는 것은 두 집단에 같은 비중을 준 별도 지표다. 표본이 한 집단에 몰리면 그 집단 성능이 전체 수치를 크게 지배한다.

아래 A/B는 개인정보 집단이 아닌 가상 입력 조건 이름이다. 작은 B에서의 관측 비율은 불확실성도 크다. 전체 점수만으로 모든 집단의 품질이나 차이의 원인을 증명하지 않는다.

지표·자료·의사결정의 경계를 적는다

선택 편향은 수집 대상의 분포, 기록 편향은 무엇을 기록했는지, 자동화 편향은 자동 결과를 무비판적으로 선호하는 판단과 관련된다. label 기준과 오류 비용이 다르면 전체 정확도만으로 필요한 품질을 비교하기 어렵다.

집단별 평가·추가 대표 자료·label 검토·새 환경 시험을 계획한다. 지표를 개선했다고 사회적 공정성과 인과적 차별 여부가 자동 판정된 것은 아니다. 결과의 적용 범위와 남은 한계를 함께 기록한다.

중간 과정을 따라가는 예제

가상 입력 A는 90개 중 86개, B는 10개 중 4개를 맞혔다. 두 집단은 겹치지 않는다. 전체 정확도와 집단별 정확도 및 집단별 단순 평균을 구하자.

  1. 전체는 (86+4)/(90+10)=90/100=90%다. A는 86/90=43/45≈95.6%, B는 4/10=40%다.

  2. 집단별 단순 평균은 (43/45+2/5)/2=61/90≈67.8%다. 전체 90%와 다른 것은 두 집단에 준 비중이 다르기 때문이다.

  3. 전체는 A의 비중 90%·B의 비중 10%로 가중한 결과다. B의 낮은 관측값을 전체 90%가 숨길 수 있지만 이 표만으로 원인이 자료 부족인지 모델 구조인지 label인지 확정하지 못한다.

전체 90%, A 약 95.6%, B 40%, 두 집단 동일 비중 평균 약 67.8%다. 이 가상 관측은 실제 학생·장치·공정성 시험이 아니다.

조건을 바꾸어 비교하기

순위를 바꾸는 비중

A의 비중을 p, B의 비중을 1−p라 할 때 X와 Y가 같은 예상 정확도를 내는 p를 구하라.

  1. X는 0.9p+0.6(1−p)=0.6+0.3p다.

  2. Y는 0.8이다.

  3. 0.3p=0.2이므로 p=2/3이다.

p>2/3이면 X, p<2/3이면 Y가 높고 같은 비중에서만 비교한다.

비교할 점

base의 한 모델 집계에 목적 분포에 따른 모델 순위 변화를 추가한다.

관측하지 않은 조건의 한계

별도 모델은 A에서 9/10만 알려져 있고 B의 성능 q는 미확인이다. 목표 비중이 A 20%, B 80%일 때 예상 점수의 범위를 구하라.

  1. q∈[0,1]이라는 비율의 범위만 사용한다.

  2. 예상 점수는 0.18+0.8q다.

  3. 최솟값은 0.18이고 최댓값은 0.98이다.

범위는 18%부터 98%로 폭이 크다. B에 A의 점수를 복사하여 90%라고 확정하지 않는다.

비교할 점

누락 집단 성능을 추가 근거 없이 채우는 오류를 드러낸다.

종이와 본문으로 직접 해보기

별도 표의 A/B는 각각 10개이며 A는 9개·B는 4개를 맞혔다. 전체 정확도는? 이전 표의 B 성공 수 4를 20으로 늘리면 100%가 되는가?

힌트 보기

새 표는 13/20이다. 이전 B는 총수가 10개라 성공 수 20은 유효한 기록이 아니다.

풀이 보기

별도 표의 전체는 13/20=65%이고 집단 평균도 (90%+40%)/2=65%다. 이전 B 성공20/총10은 불가능한 집계라 오류를 확인해야 하며 그대로 정확도를 계산하지 않는다.

오해와 반례

전체 정확도가 높고 데이터 수가 많으면 표본 선택 문제나 모든 집단의 오류도 해결된다.

A가 많은 표에서 전체 90%여도 B는 40%다. 수집 조건·label·집단 비중·새 환경을 확인하고 숫자만으로 원인이나 공정성을 단정하지 않는다.

연습 1 · 값과 상태 예측

A의 비중이 100%일 때와 B의 비중이 100%일 때 X 및 Y의 예상 점수와 순위는?

힌트 1

각각 표의 한 조건만 남긴다.

힌트 2

풀이와 답 확인

  2. B만 있으면 X는 60%, Y는 80%이므로 Y가 높다.

같은 목표 입력 조건을 명시한 비교다.

X가 한 표에서 이겼으니 언제나 이긴다.

전체 점수는 조건별 비율과 섞인 비중의 함수다.

연습 2 · 오류 찾아 고치기

풀이와 답 확인

  2. A의 목표 비중을 80%로 맞추면 X는 84%, Y는 80%다.

  3. 각 비교의 비중과 조건별 성능 유지 가정을 밝힌다.

같은 목표에서 비교하되 실제 성능 유지와 공정성 판단은 미확인이다.

연습 3 · 직접 만들어 보기

A와 B가 각각 20개인 가상 평가표를 기존 조건별 비율대로 구성하라. 두 모델의 정답 합계를 구하라.

  2. Y의 정답 수는 16+16=32개다. 정확도는 32/40=80%다.

다른 문제에 적용하기

학습 자료 네 행에서 오류가 0인 h5와 h6를 준비했다. validation 자료 (5,0)을 이용해 후보 하나를 선택하고, 고정 후보의 test 자료 (4,0)과 (6,1)를 평가한다. 별도 가상 모델 X와 Y는 셋째 소단원의 조건별 정확도를 유지한다고 가정하며 목표 비중 A 20%, B 80%에서 비교한다. 선택 후보, test 정확도, 새 x=7의 예측과 정답 확인 여부, X와 Y의 목표 예상과 유지 가정, B가 미확인인 별도 모델의 가능한 점수 범위를 한 자료 카드로 작성하라. 실제 학습, 개인정보 수집, 새 평가 실험은 수행하지 않는다.

힌트 1

validation의 label로 h6를 선택하고 test는 이후 고정 모델로 계산한다.

힌트 2

전체는 같은 목표 비중으로 가중한다. 미확인 q는 0부터 1로만 제한한다.

풀이와 답 확인

  1. validation에서 h5는 1로 예측하여 틀리고 h6는 0으로 맞으므로 h6를 선택한다. 이 행은 선택 자료로 기록한다.

  2. 고정한 h6는 test에서 각각 0과 1로 예측하여 2/2다. 새 x=7의 예측은 1이지만 label이 없으므로 정확도에 추가하지 않는다.

  3. 목표 비중 A 20%, B 80%에서 예상 점수는 X가 66%, Y가 80%다. 조건별 관측 비율의 유지와 같은 비중이라는 가정을 카드에 쓴다.

  4. B가 미확인인 모델은 A의 9/10만 주어져 있다. 예상 점수는 0.18+0.8q이고 q∈[0,1]이므로 범위는 18%부터 98%다.

  5. test 두 행, 가상 입력 조건, 합성 비중 계산의 범위를 명시한다. 현실 일반화, 공정성, 원인, 새 장치 평가를 완료했다고 쓰지 않는다.

선택 후보는 h6이고 test는 2/2다. 새 예측 1의 정답은 미확인이다. 목표 예상 점수는 X가 66%, Y가 80%이며, 미확인 모델은 18%부터 98%다.

해결한 뒤 점검할 것

  • 학습 후보와 검증 선택·고정 test의 사용 역할을 구별한다.

  • label 없는 추론을 정답 수에 추가하지 않는다.

  • 모델마다 같은 목표 비중을 적용한다.

  • 관측하지 않은 조건을 임의로 채우지 않는다.

  • 성능 유지 가정과 실제 실험 미수행을 함께 명시한다.
