Subtopic 2.1

Bits and Number Bases

Can the same bits, 1111, mean either 15 or −1?

Preparation and learning goals

Preparation

  • A bit: here, a position that stores one of two abstract states, 0 or 1. It is not identical to a physical voltage.
  • Powers: place values double as in 2⁰=1, 2¹=2, and 2²=4.
  • Notation and value: the value thirteen can have different representations, such as decimal 13 and binary 1101.

Learning goals

  • Convert binary and hexadecimal representations using place values.
  • Specify both the bit width and the interpretation rule.
  • Distinguish the number of representable patterns from the arithmetic range.

Reading place values

For an integer base b≥2, the integer representation dₖ…d₀ means Σdᵢbⁱ, with each digit between 0 and b−1. In binary, b=2, so 1101₂=1×8+1×4+0×2+1=13. The subscript identifies the notation rule, not a different value. We read the leftmost bit as the highest place.

Dividing a nonnegative decimal integer N by 2 gives N=2q+r, where r∈{0,1}. The remainder r is the last bit. Repeating the process on q determines the higher places. We therefore read the remainders in the reverse order of their production. We represent N=0 separately as 0.

Bit width and hexadecimal groups

For a positive integer n, an n-bit sequence has 2ⁿ distinct patterns because each position has two choices. Under an unsigned-integer interpretation, these represent 0 through 2ⁿ−1. This pattern count also applies to codes with other meanings; it does not mean that every code represents an integer.

Hexadecimal digits are 0–9 and A–F, with A=10,…,F=15. Since 16=2⁴, grouping bits in sets of four from the right converts each group to one hexadecimal digit. Adding zeros on the left to complete a group does not change an unsigned value, but changing the width of a signed representation requires a separate extension rule.

Interpretation rules and overflow

The four-bit pattern 1111 means 15 when interpreted as unsigned. In four-bit two’s complement, the highest place has weight −8, giving −8+4+2+1=−1. The same stored pattern can have different values under different data types or sign rules. It might also represent a character, so bits alone do not determine their meaning.

The unsigned four-bit range is 0–15. The sum 15+1=16 does not fit in that width. A fictional machine defined to use arithmetic modulo 16 stores the low four bits, 0000. This does not mean that the mathematical integer 16 equals 0. An actual language’s error and overflow rules must follow that language’s specification.

A worked example, step by step

Represent decimal 45 as an eight-bit unsigned binary value and a hexadecimal value, then convert back.

  1. 45=2×22+1, 22=2×11+0, and 11=2×5+1.
  2. 5=2×2+1, 2=2×1+0, and 1=2×0+1. Reading the remainders in reverse gives 101101.
  3. At eight bits, this is 00101101. The groups 0010/1101 give 2D₁₆.
  4. Check the reverse conversions: 32+8+4+1=45 and 16×2+13=45.

45₁₀=00101101₂=2D₁₆. The leading zeros specify an eight-bit width.

Try it with paper and the lesson

Read the four-bit pattern 1010 as an unsigned integer and as a two’s-complement integer. State the full range under each rule.

Show hint

Compare a highest-place weight of +8 with a weight of −8.

Show solution

Unsigned, it is 8+2=10; in two’s complement, it is −8+2=−6. The ranges are 0–15 and −8–7, respectively. Both have 16 patterns.

Misconception and counterexample

A bit sequence has only one numerical meaning.

The counterexample in which 1010 means either 10 or −6 shows why width, sign, and encoding contracts are necessary. Binary notation alone also does not determine the meaning of a character, color, or instruction.

Check your understanding

How many five-bit patterns are there?

Show answer and reasoning

32.

Multiply the two choices at each position five times: 2⁵.

What is the decimal value of 2D₁₆?

Show answer and reasoning

45.

It is 2×16+13.

If four-bit modular addition stores 0 for 15+1, is 15+1=0 also an integer identity?

Show answer and reasoning

No.

The storage rule preserves the remainder modulo 16; the exact integer sum is 16.

Explore further

Further study: when every position of an unsigned n-bit value is 1, Σᵢ₌₀ⁿ⁻¹2ⁱ=2ⁿ−1. Set S=1+2+…+2ⁿ⁻¹ and prove this by 2S−S=2ⁿ−1. Fixed-width bit sequences correspond one-to-one with the integers from 0 through 2ⁿ−1. Introducing a different interpretation rule does not change the number of patterns.

Subtopic 2.2

Encoding Text, Images, and Sound

What rules let text, images, and sound share the same kind of storage?

Preparation and learning goals

Preparation

  • Encoding: a rule that maps information to a bit or byte representation. Decoding reconstructs it according to that rule.
  • A byte: in this unit, eight bits, giving 256 possible patterns.
  • A sample: a value at a selected point, such as the color at an image position or the amplitude of sound at a particular time.

Learning goals

  • Distinguish characters, code points, bytes, and glyphs.
  • Calculate raw image and PCM sizes with explicit conditions and units.
  • Explain what sampling and quantization each make discrete.

Characters and their visual shapes

Unicode assigns code points to characters, and an encoding such as UTF-8 represents them as byte sequences. A code point and a glyph drawn by a font are different concepts. A unit that a person sees as one character can contain several code points. Character counts, code-point counts, and byte counts therefore do not always agree.

For example, A is U+0041 and occupies one UTF-8 byte, 0x41. The Hangul character 가 is U+AC00 and is represented by the three bytes EA B0 80. These are encoding examples, not a rule that assigns the same length to every character. An invalid byte sequence must be rejected or replaced under a specified error policy. Guessing the encoding can produce a result different from the original text.

Image positions and color values

A raw raster is an array of pixels of width W and height H. With a fixed channel count C and b bits per channel, and no padding, compression, or metadata, the data size is WHCb bits. RGB with eight bits per channel uses 24 bits per pixel. An alpha channel, palette, or row padding changes the conditions of the formula.

Sampling, which sets the spacing of pixel positions, differs from quantization, which divides each channel’s values into a finite set of levels. Even identical RGB numbers do not fully determine physical brightness without a color space, transfer function, and display conditions. An actual file such as PNG includes headers and compression, so its raw size is not its file size.

Sound times and amplitudes

Linear PCM stores amplitudes at selected times as quantized integer codes. Let fₛ be the number of samples per second, T the duration, C the channel count, and b the bits per sample. Counting a complete sample interval with integer fₛT gives fₛTCb bits of raw data. This calculation excludes additional information from the file container and compression.

Time sampling does not directly store changes between sample times; quantization maps amplitudes to a finite set of levels. A higher sample rate and bit depth can help, but the microphone, noise, input range, filtering, and reconstruction assumptions also affect quality. Digital data does not automatically preserve every piece of the original physical information.

A worked example, step by step

Compare the data sizes of the UTF-8 string A가, a raw 2×2 RGB image with eight bits per channel, and one second of mono, 16-bit PCM at 8000 samples per second. Count each representation without headers, padding, or compression.

  1. A uses 41 and 가 uses EA B0 80, for a total of four bytes=32 bits.
  2. The image uses 2×2×3×8=96 bits=12 bytes.
  3. The sound uses 8000×1×1×16=128000 bits=16000 bytes.
  4. To interpret these values, we need the text encoding, image width/height/channel rules, and sound sample rate/channel/integer format, respectively.

The raw sizes are four bytes for the text, 12 bytes for the image, and 16000 bytes for PCM. These are not measurements of actual file sizes or playback quality.

Try it with paper and the lesson

What are the raw sizes if the PCM above has two channels for the same duration and the image changes from RGB to RGBA?

Show hint

Change only the channel counts: 1→2 and 3→4.

Show solution

PCM uses 8000×1×2×16/8=32000 bytes; the image uses 2×2×4×8/8=16 bytes. This assumes uniformly stored channel samples and no additional information.

Misconception and counterexample

One character is one byte, and an uncompressed data size is the actual file size.

A가 is a counterexample: it has two code points but takes four UTF-8 bytes. Even if a raw image has 12 bytes, PNG includes headers, filtering, and compression structures, so the actual file size is a separate quantity.

Check your understanding

Are a Unicode code point and a glyph the same?

Show answer and reasoning

No.

Character identification and visual shape belong to different layers.

What is the raw size of a 2×2 RGB image with eight bits per channel?

Show answer and reasoning

12 bytes.

Four pixels×three channels×one byte.

Does increasing only the PCM bit depth automatically reconstruct rapid changes between sample times?

Show answer and reasoning

No.

Amplitude levels and time intervals between samples are separate choices.

Explore further

Further study: two pieces of data with the same byte count need not mean the same information. Changing the contract to read four bytes as text, an integer, or pixels changes their interpretation. To claim the inverse relationship D(E(x))=x, specify the permitted input set and the encoding and decoding rules together. Distinguish this from the stronger claim of reconstructing a person’s character units or the original analog signal.

Subtopic 2.3

Compression and Representation Error

If a photograph is compressed losslessly, does it retain all the information present when it was captured?

Preparation and learning goals

Preparation

  • Reconstruction: reading a stored representation again under a rule. Specify whether the target is bytes or the original physical signal.
  • Error: the difference between a reconstructed value and a reference value. Absolute value ignores the direction of the difference and measures its magnitude.
  • One-to-one: distinct original data must have distinct codes if the codes alone are to distinguish the originals.

Learning goals

  • Define the reconstruction targets and conditions of lossless and lossy compression.
  • Derive a maximum quantization error under stated assumptions.
  • Explain why not every input can be compressed to a shorter representation.

The compression contract

Lossless compression means that the decoder D and encoder E satisfy D(E(x))=x for every permitted digital input x. Here, the reconstruction target is byte-for-byte identity of the original data. Lossy compression permits some differences and requires a separate error measure and intended use. A smaller file alone does not identify which kind of compression is used.

For example, define our own run-length format that stores a byte value and its repetition count in one byte each. A run is a consecutive group of the same byte value. Counts are 1–255; longer runs are split into pairs whose counts are at most 255. The decoder knows where the complete encoded byte sequence ends, reads it two bytes at a time, and reconstructs the original length by adding the counts. Six repetitions of A shrink to the two bytes (A,6), whereas ABABAB becomes repeated (A,1),(B,1) pairs totaling 12 bytes. This example excludes format-header costs.

Quantization loss and compression loss

Assume rounding to the nearest point of a grid with positive spacing Δ, with inputs staying within the nonsaturating range. Each value’s absolute error is at most Δ/2, since the midpoint between neighboring grid points is the farthest position from the nearest point. The tie-breaking rule decides the result at the boundary but does not change this maximum error.

Compressing already quantized samples losslessly lets us recover those samples, but generally not the exact amplitudes before quantization. Reconstructing values at times not stored by sampling also needs separate assumptions. To reduce error, distinguish the sensor, sampling, and quantization stages as well as the compression method.

Why size guarantees have limits

For a positive integer n, fixed-length n-bit inputs have 2ⁿ possible values. All bit sequences shorter than n, including the empty sequence, total 1+2+…+2ⁿ⁻¹=2ⁿ−1. Even if the decoder knows the code length, there are too few code candidates. Thus no one-to-one code can losslessly shorten every input.

A compressor can assign shorter codes to common patterns and longer or equal-length codes to other inputs. The actual compression ratio depends on the data, format, and metadata. Lossless reconstruction of samples must not be extended into a guarantee of identical color representation or identical sensations on physical devices.

A worked example, step by step

Define a toy quantization grid at 0, 0.25, 0.5, 0.75, and 1. Inputs are in [0,1]; map each to its nearest grid point, choosing the smaller point in a tie. Find reconstructed values and absolute errors for inputs 0.10, 0.38, and 0.90.

  1. 0.10 is 0.10 away from 0 and 0.15 away from 0.25, so it maps to 0.
  2. 0.38 is 0.12 away from 0.5 and 0.13 away from 0.25, so it maps to 0.5.
  3. 0.90 is 0.10 away from 1 and 0.15 away from 0.75, so it maps to 1.
  4. The errors 0.10, 0.12, and 0.10 are all at most Δ/2=0.125. Multiple original values can map to the same grid point.

The reconstructed values are 0, 0.5, and 1, and the largest observed error is 0.12. The theoretical bound for this toy model is 0.125.

Try it with paper and the lesson

Under the same rule, quantize 0.125 and 0.375. Also calculate the run-length data sizes of six copies of A and of ABABAB.

Show hint

A tie selects the smaller grid point; one run uses two bytes for its value and count.

Show solution

0.125→0 and 0.375→0.25, with both errors equal to 0.125. AAAAAA has one run and uses two bytes; ABABAB has six runs and uses 12 bytes. Both originals have six bytes.

Misconception and counterexample

Lossless compression also reconstructs the original signal before quantization exactly, and makes every file smaller.

If 0.10 and 0.11 both quantize to 0, reconstructing that 0 exactly cannot distinguish the two original values. Our run-length format makes ABABAB larger, and a lossless code that shortens every n-bit input contradicts the counting argument.

Check your understanding

What is the defining equation for losslessness?

Show answer and reasoning

D(E(x))=x.

Reconstruction must be exact on the specified permitted set of digital inputs.

What is the maximum absolute error of nearest-point quantization with Δ=0.25 and no saturation?

Show answer and reasoning

0.125.

The midpoint between grid points is farthest from the nearest point, giving Δ/2.

Does recovering samples losslessly determine the physical signal at every continuous-time instant?

Show answer and reasoning

No.

Quantization before storage and reconstruction between samples require separate conditions.

Explore further

Further study: for N samples, where N is a positive integer, define the mean squared error MSE=(1/N)Σ(xᵢ−x̂ᵢ)². For the three example values, it is (0.01+0.0144+0.01)/3=0.0344/3≈0.01147. A small MSE does not guarantee the preservation of every important character or rare error. Set additional criteria for the task, such as maximum error, exact text matching, or user review.
