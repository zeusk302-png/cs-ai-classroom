소단원 15.1

개인정보와 저작권

공개된 사진을 이름만 적으면 누구나 학습 사이트에 다시 올려도 될까?

준비 개념과 학습 목표

준비 개념

  • 자료의 수집과 공유

  • 권한과 목적

  • 출처

학습 목표

  • 필요한 정보와 불필요한 수집을 구별한다.

  • 공개 열람과 재사용 허락을 구별한다.

  • 자료별 권리 조건과 삭제 계획을 기록한다.

서버에서 이름을 지웠는데 내려받은 표와 백업에 남아 있다면 삭제가 끝났을까?

자체 학습 예약 모형은 별명·과목·예약 시각만으로 자리를 관리한다. 학교명·생년월일·집 주소를 더 받으면 어떤 기능에 필요한지 먼저 설명해야 한다. 항목 수를 줄이는 것은 자료 처리 범위를 줄이는 설계지만, 항목 수의 감소율이 위험이나 피해의 감소율은 아니다. 별명도 다른 자료와 연결되면 사람을 구별하는 단서가 될 수 있다.

자료는 입력 화면에서만 존재하지 않는다. 자체 상태를 주 저장소 M, 내보낸 표 E, 백업 B의 세 위치로 나눈다. 삭제 요청 때 M만 지워도 E와 B가 그대로라면 전체 위치 삭제 기준은 실패한다. 보관 기간·접근자·내보내기·복구 절차를 함께 정의하고 실제 삭제 검증은 별도로 수행한다.

공개된 그림도 이용 조건을 확인한다. 아래의 그림 A는 작성자가 직접 만들고 명시적으로 CC BY 4.0으로 제공한 가상 자산이다. 그림 B는 공개 화면에서 찾았으나 이용 허락을 확인하지 않은 자산이다. A의 표시 조건을 갖추었다고 B나 그림 속 제삼자의 다른 권리까지 허락받는 것은 아니다. 특정 국가 법률 준수 판정 대신, 출처·허락·변경·다른 권리를 확인하는 설계 연습으로 제한한다.

먼저 확인할 개념
  • 자료가 남는 위치

    입력 값의 열과 내보낸 파일을 별도 처리 위치로 추적한다.

  • 기록의 범위

    로그에 입력 원문을 복제하면 삭제 대상 위치가 더 생김을 확인한다.

어떤 목적으로 누구의 정보를 다루는가

개인정보를 다루는 설계에서는 이름뿐 아니라 활동 기록·접속 정보와 다른 자료를 결합했을 때 개인과 연결될 가능성도 살핀다. 무엇을 모으고 어디로 보내며 누가 접근하고 언제 지울지 흐름을 적는다.

예를 들어 이어 읽을 단원만 저장하려는 목적에 주소·전화번호·사진이 꼭 필요한지 묻는다. 자료를 적게 모으면 불필요한 처리 범위를 줄일 수 있지만 그 자체로 모든 위험이 없어지거나 법적 의무를 충족하는 것은 아니다. 수집·보유·공유·삭제를 함께 검토한다.

출처 표시와 재사용 권한은 다르다

인터넷에서 볼 수 있다는 사실은 복사·수정·재배포의 모든 허락을 뜻하지 않는다. 저작자·권리자·실제 라이선스·허용 범위·표시 조건을 자료별로 확인한다. 원문을 참고하여 자체 설명을 쓰는 일과 그림 전체를 복사해 배포하는 일을 구별한다.

가상의 CC BY 4.0 그림을 수정해 쓸 때는 제공된 저작자 등 표시 정보·원자료 링크·라이선스 링크·변경 안내를 확인한다. 이름 한 줄만 적고 조건 확인을 끝내지 않는다. CC의 개요는 전체 법률문이 아니며 실제 사용에는 해당 조건과 별도 권리도 확인한다.

서로 다른 권리가 겹칠 수 있다

그림의 저작권 허락이 있어도 사진 속 사람의 개인정보나 다른 권리 문제가 자동 해결되는 것은 아니다. 교육 목적이나 오픈소스 프로젝트라는 이름만으로 제3자 자료의 권리가 바뀌지 않는다.

소스와 자체 저작물의 프로젝트 라이선스와 외부 자료의 라이선스를 구별한다. 자료별 출처와 조건을 보존하고 확인되지 않은 자료는 배포 계획에서 보류한다. 실제 학생 정보나 사진을 실습에 모으지 않고 가상 자료로 흐름을 연습한다.

한 행의 존재/부재를 위치별로 읽는다. 이 모형의 전체 삭제 기준은 모든 위치에서 행이 없어야 한다는 조건이다. 현실 백업의 보관·복구 정책은 별도 정해야 하며 표가 실제 시스템 검증 결과를 뜻하지 않는다.

중간 과정을 따라가는 예제

가상 학습 기록의 후보 필드는 별명·현재 단원·주소·전화번호·사진·생년월일의 6개다. 목적을 별명과 이어 읽을 단원 저장으로 제한하고 120명에게 2개만 저장한다면 필드 값 개수는 어떻게 바뀌는가?

  1. 전체 6개를 저장하면 120×6=720개의 필드 값이다.

  2. 2개만 저장하면 120×2=240개다. 차이는 480개다.

  3. 개수 감소는 처리 범위의 가상 산술이다. 별명과 단원도 결합 상황에 따라 개인과 관련될 수 있어 접근·보유·삭제 검토는 남는다.

720개에서 240개로 줄어 480개를 덜 저장한다. 위험이 정확히 2/3 감소했다고 측정한 것은 아니다.

조건을 바꾸어 비교하기

감소한 입력과 남아 있는 복제

가상 40명에게 기존 5항목 대신 필요한 3항목을 받는다. 모든 사람이 각 항목을 한 번 채운다고 가정한다. 항목 값 수와 감소율, 전체 삭제 결과를 구하라.

  1. 기존은 40×5=200개, 변경은 40×3=120개라 80개 감소한다.

  2. 감소율은 80/200=40%다. 이것은 항목 값 수의 감소율이다.

  3. 위 표에서는 E/B에 행이 남으므로 전체 삭제 기준은 실패한다.

필드 최소화와 모든 복제 위치의 삭제는 서로 다른 기준이다.

비교할 점

base의 수집량 비교에 복제와 복구 경계를 추가한다.

자산 두 개의 조건을 섞지 않는다

A는 저자 민이 CC BY 4.0으로 제공한 자체 그림이고 source-A에 출처가 있다. 색을 바꾸어 교재에 쓴다. B는 공개 게시물 그림이나 이용 허락 미확인이다. 처리 계획은?

  1. A의 제공된 저자·출처·라이선스 링크와 제공된 고지 사항을 보존하고 색 변경을 표시한다.

  2. A에 적용된 조건만으로 B의 재사용을 허락받았다고 할 수 없다. B는 허락을 확인하거나 직접 만든 다른 자산으로 대체한다.

  3. 개인정보·초상 등 다른 권리가 문제되는지 별도 확인한다.

공개 열람, 특정 라이선스 허락, 다른 권리 확인은 서로 다른 근거다.

비교할 점

같은 페이지 안 자산이라도 허락 범위는 자산별로 확인한다.

연습 1 · 값과 상태 예측

위 삭제 상태에서 E를 지우고 나중에 B로부터 M을 복구했다. B에는 여전히 해당 행이 있다. 최종 M/E/B와 전체 삭제 기준은?

힌트 1

복구 원본 B의 행을 그대로 M에 넣는 모형이다.

힌트 2

최종 세 위치 모두를 검사한다.

풀이와 답 확인

  1. M에는 행이 다시 생긴다. E에는 행이 없고 B에는 행이 남는다.

  2. 모든 위치에서 행이 없어야 하는 기준은 F다.

복구 경로가 삭제를 되돌릴 수 있어 보관·복구 절차를 함께 설계한다.

흔한 오답에서 다시 생각하기

버튼 이력 대신 현재 각 위치의 내용과 복구 규칙을 읽는다.

연습 2 · 오류 찾아 고치기

수집 항목 값 수가 40% 줄었으므로 재식별 위험도 정확히 40% 줄었다고 보고했다. 고쳐라.

힌트 1

자료량과 위험의 정의를 분리한다.

힌트 2

남은 값의 연결 가능성과 접근 범위를 생각한다.

풀이와 답 확인

  1. 40%는 고정 모형의 항목 값 수 감소율로만 보고한다.

  2. 남은 별명·과목·시각으로 사람을 구별할 수 있는지, 다른 표와 연결되는지, 누가 접근하는지를 별도 검토한다.

  3. 실제 위험 평가나 개인정보 처리 검증을 수행했다고 하지 않는다.

개수 산술로 위험 감소율을 추정하지 않는다.

민감도·식별성·사용 목적이 서로 다를 수 있어 가정과 근거가 필요하다.

힌트 1

삭제 대상 위치와 책임을 목록으로 만든다.

힌트 2

복구 후 확인도 성공 기준에 넣는다.

풀이와 답 확인

  1. 예약 행의 식별 기준과 M/E/B의 처리 담당 및 보관·처리 시점을 정한다.

  2. 각 위치에서 행의 부재를 확인할 방법과 아직 남는 위치를 보고하는 방법을 정한다.

  3. 복구 시 삭제 요청을 반영해 행을 되살리지 않는 절차를 설계하고 복구 후 같은 기준으로 재확인한다.

설계 계획이며 실제 자료 삭제·백업 복구는 미수행이다.

연습 4 · 선택 심화

선택 심화는 기본 연습 뒤 더 탐구하고 싶을 때 풀어 보세요.

A의 재색칠 그림 옆에 “인터넷 출처”만 적고, 원본 A와 B 모두 우리 서비스의 재배포 금지라고 표시했다. 확인할 문제와 보완 계획을 적어라.

힌트 1

A에 제공된 저자/출처/라이선스와 변경 표시를 확인한다.

힌트 2

B의 허락 상태 및 A의 허용 권리를 제한하는 조건을 구별한다.

풀이와 답 확인

  1. A에는 제공된 적절한 크레딧·라이선스 링크·변경 표시 등을 보완한다. 원본의 제공 고지 사항도 보존한다.

  2. A의 CC BY 4.0 허용 이용을 제한하는 추가 조건이나 기술적 제한을 부과하지 않도록 배포 조건을 확인한다.

접근성과 디지털 격차

페이지 주소가 공개되어 있으면 누구에게나 같은 학습 기회가 생길까?

준비 개념과 학습 목표

준비 개념

  • 웹의 입력과 출력

  • 텍스트와 그림

  • 학습 환경

학습 목표

  • 키보드·대체텍스트·텍스트 자료의 역할을 설명한다.

  • 평균 외 환경별 접근 장벽을 비교한다.

버튼을 마우스로 누를 수 있으면 키보드 사용자도 같은 과제를 끝낼 수 있을까?

자체 신청 화면의 세 조작은 과목 선택→신청 확인→오류 수정이다. 마우스 경로에서만 보이는 그림 버튼이나 키보드로 빠져나갈 수 없는 창이 있으면 동일한 정보와 행동에 도달하지 못할 수 있다. 버튼 이름, 현재 초점, 순서, 오류 설명을 사용자 경로에 연결한다.

아래 표는 실제 시험 결과가 아니라 여섯 개의 합성 기록이다. 과제 완료는 올바른 과목을 신청하고 확인 정보를 이해한 경우로 정한다. 단순 화면 도달이나 버튼 클릭과 구별한다. 같은 사람이 여러 경로를 시험하면 사람 수와 시도 수도 달라진다.

접근성은 특정 한 집단의 부가 기능으로만 취급하지 않는다. 작은 화면, 일시적 손 부상, 소리를 들을 수 없는 환경이나 느린 연결에서도 여러 경로가 도움이 될 수 있다. 자동 검사 도구 하나로 접근성을 결정할 수 없으며 실제 다양한 대상의 관찰과 수동 확인이 필요하다. 이 단원의 종이 경로는 실제 웹 접근성 적합성 평가가 아니다.

사람과 환경이 다르면 장벽도 다르다

접근성은 장애가 있는 사람도 정보를 인지·이해·탐색·조작할 수 있게 설계하는 일과 연결된다. 시각·청각·운동·인지 조건과 사용하는 보조 기술을 고려한다.

작은 화면·느린 연결·소리를 들을 수 없는 장소 같은 상황에서도 장벽이 생긴다. 인터넷 공개와 무료 제공만으로 장치·언어·대역폭·사용 능력의 차이가 모두 사라지는 것은 아니다. 디지털 격차는 접속 가능 여부 외 실제 이용 조건을 포함해 살핀다.

같은 학습 정보를 다른 경로로 제공한다

의미 있는 그림에는 그 정보와 역할에 맞는 대체텍스트를 제공한다. 키보드만으로 기능에 도달하고 조작할 수 있어야 하며 현재 초점도 알 수 있어야 한다. 음성 설명에는 대응하는 텍스트 자료를 제공한다.

긴 코드를 스크린샷으로만 제시하면 읽기·복사·보조 기술 사용이 어려울 수 있다. 선택 가능한 텍스트와 설명·예상 결과를 함께 제공한다. 장식 그림의 처리와 중요한 도식의 설명은 목적이 다르며 파일 이름을 그대로 붙이는 것으로 의미 설명을 대신하지 않는다.

검사는 초기에 여러 방법으로 한다

접근성 검사는 설계 초기부터 반복한다. 자동 도구는 일부 오류를 찾을 수 있지만 실제 기능과 설명의 의미·키보드 흐름을 모두 판정하지 못한다. 사람의 검토와 다양한 이용 환경의 관찰이 필요하다.

가상 환경별 과업 완료 비율을 비교해 특정 환경의 실패가 평균에 가려지는지 살핀다. 한 번의 검사 통과를 전체 지침 적합성이나 모든 학생의 성공으로 확대하지 않는다. 실제 수행하지 않은 사용자·보조 기술 검사는 미수행으로 남긴다.

기술 선택의 영향

더 많은 기록을 모으는 추천 기능은 언제나 더 좋은 선택일까?

학습 목표

  • 대안의 자료·장치·접근 조건을 비교한다.

  • 계획·실제 영향·검증 상태를 구별한다.

전송량을 줄인 설계가 더 나은 추천이나 모든 사용자 이익도 보장할까?

자체 후보 L은 기기에 자료를 두고 텍스트 목록을 보여 주며 후보 R은 서버에 선호 자료를 보내 추천을 받는다. L은 외부 전송을 줄일 수 있지만 공유 기기에 남는 자료를 누가 읽는지 확인해야 한다. R은 추천 기능을 제공하지만 추가 자료의 목적·선택·전송·보관 경계를 설명해야 한다.

아래 비용은 한 과업을 끝낼 때 주고받는 정해진 양이며 실패·재시도·캐시는 없는 모형이다. 데이터 비중과 전송 속도를 고정한 산술은 실제 환경 측정이나 추천 효과의 증거가 아니다. 선택 가능한 자료 제공을 필수 기능과 분리하면 사용자가 거절했을 때의 기본 경로도 설계할 수 있다.

이익과 부담은 같은 수 하나로 사라지지 않는다. 전송량·경로별 완료·남는 자료·재사용 조건을 함께 적고 우선순위를 명시한다. 추천 정확도나 학습 향상을 아직 측정하지 않았다면 그 칸은 미확인이다. 적은 전송량을 그대로 낮은 전력 소비나 전체 사회적 피해의 수치로 바꾸지 않는다.

먼저 확인할 개념
  • 전송의 의존성과 조건

    자료량/속도/재시도 가정을 명시한 뒤 전달 시간을 계산한다.

  • 명시한 요구와 목적

    자료 제공 거절 시 기본 기능을 유지할지 요구로 정한다.

성공 기준에는 영향을 받는 사람도 넣는다

기술 선택은 기능 수나 평균 속도 외에 이용자·운영자·자료 제공자에게 다른 편익과 부담을 만들 수 있다. 쉬운 접근·이해 가능한 설명·개인정보 처리·유지 비용 같은 기준을 목적과 연결한다.

예를 들어 공개 학습 자료를 로그인 없이 읽게 하는 선택과 진행 기록을 서버에 저장하는 선택은 서로 다른 필요를 해결한다. 어떤 기능이 왜 필요한지, 그 기능이 없는 대안이 가능한지 비교한다. 많은 기능을 넣었다는 이유만으로 사회적 책임을 다했다고 결론 내리지 않는다.

대안을 공통 조건으로 비교한다

가상 대안 A는 텍스트 자료를 제공하고 진행 기록을 기기 안에 저장한다. B는 같은 본문과 서버 진행 기록·추천을 제공한다. A는 기기 변경 시 기록 이동이 어렵고 B는 외부 전송·접근·삭제 및 운영 처리가 추가된다.

기기 내 저장도 공유 기기에서 다른 사람이 볼 수 있으며 자동으로 안전한 것은 아니다. 서버 기록도 그 존재만으로 나쁘다고 판정하지 않는다. 목적·자료 최소화·이용자 선택·보유/삭제·실패 처리와 실제 환경을 함께 비교한다.

의도와 실제 영향은 다를 수 있다

설계상 이익은 가설이며 실제 효과를 확인하려면 과업·환경·평가 방법을 정한다. 평균 완료 비율 외 연결 환경이나 입력 방식별 실패를 살피고 불필요한 자료 수집을 추가하지 않는 평가 방법을 계획한다.

추가 기능 도입 뒤 문제가 생기면 되돌림·대체 경로·문의와 수정 흐름을 마련한다. 계획한 측정·실제 측정·원인 분석·수정 후 확인을 구별한다. 이 단원은 가상 대안 비교이며 실제 서비스 변경이나 사람 대상 평가를 수행하지 않았다.

MB는 여기서 1,000,000바이트로 정한다. R에서 선호 제공을 거절하면 별도 기본 경로 L의 전송 계약을 사용한다는 자체 요구다. 추천 이익과 에너지는 이 표의 열에 없으며 실제 측정도 없다.

중간 과정을 따라가는 예제

가상 대안 A의 자료 전송은 학습자당 2 MB, B는 같은 본문에 추가 자료 3 MB를 요구한다. 학습자 100명이 한 번 이용할 때 총량과 차이를 구하라. B의 추천 효과는 측정되지 않았다.

  1. A는 100×2=200 MB다. B는 100×(2+3)=500 MB다.

  2. 차이는 300 MB이며 B/A=2.5다. MB는 여기서 같은 단위로 제공된 가상 전송량이다.

  3. 추천 이익은 미측정이다. 전송량만으로 종합 우열을 정하지 않고 느린 연결의 접근과 추천 목적·자료 처리 대안을 비교한다.

가상 전송량 200/500 MB, 차이 300 MB다. 추천 효과나 실제 통신 비용을 측정한 결과는 아니다.

자료량과 고정 전송 시간

전송 속도가 정확히 0.3 MB/s이며 고정 대기·실패·병렬 전송이 없다. 50과업 모두 L 또는 R을 선택했을 때 총 자료량과 한 과업 시간은?

  1. L은 총 50×1.2=60 MB, 한 과업은 1.2/0.3=4초다.

  2. R은 총 50×3.0=150 MB, 한 과업은 3.0/0.3=10초다.

  3. 차이는 90 MB, 한 과업 시간 차이는 6초다. 실제 완료 시간은 구현·사용자 조작까지 포함해 별도 측정한다.

순수 전송 모형에서 R의 양과 시간은 L의 2.5배다.

T2의 원래 여섯 합성 시도에서 전체/경로별 완료율과 마우스−키보드 차이를 계산하라. 50과업 중 R 20개/L 30개를 선택하면 총 자료량·전송 시간 합·전원 R 대비 감소율은? 학습 향상과 실제 접근성/삭제 준수는 어떤 상태로 보고해야 하나?

힌트 1

항목 수 감소율·현재 세 저장 위치·자산별 허락·실제 수행 상태를 서로 다른 조건으로 읽는다.

힌트 2

완료율의 분모는 전체 6 또는 경로 3이다. 자료량은 각 경로의 과업 수를 곱하고 시간 합은 벽시계와 구별한다.

풀이와 답 확인

  1. 항목 값 수는 200개에서 120개로 80개, 40% 감소한다. 위험 감소율은 아니다. 복구 후 M/B에는 행이 있고 E에는 없어 전체 삭제 기준은 실패한다.

  2. A의 제공된 크레딧·출처·라이선스 링크·고지와 색 변경 표시를 보완한다. B는 허락을 확인하거나 대체하고 다른 권리를 별도로 확인한다.

  3. 원래 전체 완료율은 4/6=2/3, 키보드 1/3, 마우스 1이다. 차이는 2/3, 약 66.67 퍼센트포인트다. 여섯 실제 사람의 결과라고 확대하지 않는다.

  4. 혼합 총량은 96 MB, 전송 시간 합은 320초다. 전원 R의 150 MB보다 54 MB, 36% 감소한다. 시간 합은 동시 실행의 벽시계 종료 시각이 아니다.

  5. 학습 향상·에너지·실제 접근성·삭제/복구·저작권 처리/법률 준수 평가 및 학생 실험은 미수행/미확인으로 남긴다. 합성 자료와 종이 설계 및 지정 산술만 완료했다.

수집량은 40% 감소하지만 복구 후 전체 삭제 기준은 실패한다. 자산별 허락과 제공 조건을 구별한다. 완료율은 전체 2/3, 키보드 1/3, 마우스 1이며 경로 차이는 약 66.67 퍼센트포인트다. 혼합 전송은 96 MB, 시간 합은 320초이고 전원 R 대비 자료량은 36% 감소한다. 다른 효과와 실제 수행은 확인되지 않았다.
