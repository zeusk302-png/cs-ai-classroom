소단원 6.1

선형사상의 정의

모든 입력을 두 배로 하면 출력도 두 배가 되는 규칙은 언제 선형일까?

준비 개념과 학습 목표

준비 개념

  • 여기서 벡터공간은 실수 위의 유한차원 공간이다. 스칼라는 벡터에 곱하는 실수다.

  • 선형결합 au+bv는 두 벡터를 실수 배로 더한 것이다.

  • 0벡터는 덧셈의 기준점이다. 사상은 입력마다 출력을 하나 정하는 함수다.

학습 목표

  • 덧셈·스칼라곱 보존을 전체 변수로 증명한다.

  • 필요조건T(0)=0과 충분조건을 구분한다.

  • 기저의 상으로 행렬을 구성한다.

배수를 보존한다는 검사 하나로 선형성을 결정할 수 있을까?

실수 두 성분을 받는 규칙 F를 새로 정하자. x≠0이면 F(x,y)=(x,y²/x)이고 x=0이면 F(0,y)=(0,0)이다. 모든 실수 c에 대해 F(cx,cy)=cF(x,y)가 성립한다. c=0은 양쪽이 영벡터이며, c≠0이고 x≠0인 경우 둘째 성분은 c²y²/(cx)=cy²/x다. x=0인 경우 양쪽은 계속 영벡터다.

그러나 u=(1,1), v=(1,−1)을 더하면 F(u+v)=F(2,0)=(2,0)인 반면 F(u)+F(v)=(1,1)+(1,1)=(2,2)다. 모든 실수배를 보존해도 덧셈을 보존하지 않으면 선형이 아니다. 기저 두 개의 출력만으로 모든 출력을 구성하는 규칙은 선형성의 두 조건을 먼저 증명했을 때 사용할 수 있다.

같은 주의를 다항식에도 적용한다. P₂는 실수 계수 a+bt+ct² 전체이며 벡터 덧셈과 실수배는 계수별이다. E(p)=(p(0),p′(0))는 (a,b)를 내보낸다. 두 다항식을 더하거나 실수배하면 이 두 계수도 같은 방식으로 변하므로 E는 선형이다. 이것은 실제 측정기가 아니라 정확한 다항식의 정보 요약 모형이다.

먼저 확인할 개념
  • 연산과 실수 스칼라

    입력의 덧셈·배수와 출력의 연산을 명시한다.

  • 선형성의 두 조건

    원점과 한 배수 검사만으로 충분하지 않다.

두 연산을 보존하는 정의

T:V→W가 모든 u,v와 실수a,b에 대해 T(au+bv)=aT(u)+bT(v)를 만족하면 선형사상이다. 합을 먼저 하거나 각각 변환한 뒤 같은 계수로 합하거나 결과가 같다는 뜻이다.

단순히 입력과 출력이 비례하는 한 예만 확인하는 것으로는 충분하지 않다. 덧셈 보존과 모든 실수배 보존을 식으로 증명하거나 반례 하나로 실패를 보일 수 있다. 선형성은 선택한 벡터공간과 스칼라에 대한 성질이다.

원점과 평행이동

a=b=0을 대입하면 T(0)=0이다. T(x,y)=(2x+y,3y)는 원점을 고정하고 식을 전개하면 두 연산을 모두 보존한다. 반면F(x,y)=(x+1,y)는 원점을(1,0)으로 옮겨 선형이 아니다.

T(0)=0은 빠른 실패 검사지만 충분하지 않다. H(x)=x²는0을0으로 보내도 H(2)=4≠2H(1)=2다. 양수 배와 음수 배, 여러 입력을 합하는 규칙을 확인해야 한다.

기저 두 개의 출력이면 모든 출력

표준 기저e1=(1,0),e2=(0,1)에 대해 T(e1)=(2,0),T(e2)=(1,3)이다. 열벡터로 넣은 행렬A=[[2,1],[0,3]]가 입력 좌표를 출력 좌표로 바꾼다.

v=xe1+ye2이므로 T(v)=xT(e1)+yT(e2)다. 행렬의 열은 입력 기저 하나의 출력 좌표다. 행을 넣으면 다른 규칙을 만들 수 있으므로 기저 순서와 열의 의미를 함께 기록한다.

  1. 2u−v=(2,4)−(−1,1)=(3,3)이다. T(3,3)=(9,9)이다.

  3. 2T(u)−T(v)=(8,12)−(−1,3)=(9,9)로 같다. 일반 증명은 변수au+bv를 두 좌표 식에 전개하면 된다.

  1. 기저 출력은 (1,0)과 (0,0)이다. 선형이라고 가정하면 합은 (1,0)이다.

  2. 실제 정의에서는 F(1,1)=(1,1)이다.

기저 출력만의 예측이 실패한다.

비교할 점

기저는 입력 표현을 보장하지만 임의 함수가 그 표현을 보존하는 것은 아니다.

같은 다항식 재료, 다른 사상

p를 E(p)로 보내기와 p를 p²로 보내기의 선형성을 비교하라. 뒤 사상의 공역은 P₄다.

  1. E는 상수와 일차 계수의 선형 요약이다.

  2. p=q=1이면 (p+q)²=4이지만 p²+q²=2다.

E는 선형이고 제곱 사상은 비선형이다.

비교할 점

출력 차수를 P₄까지 허용해 함수 정의를 맞춰도 덧셈 실패는 남는다.

종이와 본문으로 직접 해보기

F(x,y)=(x+1,y),H(x)=x²를 각각 반례 하나로 선형이 아님을 보여라.

힌트 보기

풀이 보기

F(0,0)=(1,0)≠0이다. H(2×1)=4이지만2H(1)=2다. 각각 필요조건과 스칼라곱 보존을 깨는 반례다.

오해와 반례

그래프가 단순하거나0을0으로 보내면 선형이다.

평행이동은 단순한 식이어도0을 옮기고 x²는0을 고정해도 배수 규칙을 깬다. 여기서 affine은 선형 부분에 고정 벡터를 더한 사상이며 그 고정 벡터가0이 아닐 때 선형사상과 다르다.

소단원 6.2

핵·치역과 동형

입력이 사라지는 방향과 도달할 수 있는 출력은 어떻게 찾을까?

준비 개념과 학습 목표

준비 개념

  • 핵 kerT는T(v)=0인 입력들의 집합이다. 치역 imT는 실제T(v)로 얻는 출력 집합이다.

  • 단사=다른 입력이 같은 출력으로 합쳐지지 않음, 전사=공역의 모든 출력에 도달함이다.

  • 동형은 선형인 전단사 사상이다. 차원은 기저 벡터의 개수이고 rank는 치역 차원이다.

학습 목표

  • 핵과 치역의 부분공간 성질을 설명한다.

  • 핵과 단사·치역과 전사를 연결한다.

  • 공역 지정과 유한차원 rank-nullity 조건을 확인한다.

두 요약 숫자가 같다면 원래 다항식도 같을까?

앞의 E:P₂→R²는 a+bt+ct²에서 (a,b)만 남긴다. E(p)=0이면 a=b=0이어서 핵은 {ct²:c∈R}이다. 치역은 아무 (r,s)에 대해 p=r+st를 선택할 수 있으므로 R² 전체다. 입력 차원 3은 핵 차원 1과 치역 차원 2로 나뉜다.

이 요약은 전사지만 단사가 아니다. 예를 들어 2−t+4t²와 2−t−7t²의 출력은 모두 (2,−1)이다. 출력의 이름을 좌표라고 부르더라도 정보가 사라진 사상을 가역 기저변환으로 바꿀 수 없다. 다항식을 일차 이하 공간 P₁로 제한하면 c=0만 허용하므로 같은 E가 동형이 된다.

반대로 J:P₁→P₂를 같은 다항식의 포함 사상으로 정하면 핵은 0이지만 t²에는 도달하지 못한다. 공역을 P₁로 바꾸면 항등 동형이다. 정의역과 공역의 선택은 설명의 장식이 아니라 단사/전사 판정의 일부다.

  • 핵·치역과 공역

    요약의 모호성과 공역 도달 여부를 따로 질문한다.

0으로 보내는 입력도 공간이다

선형T의 핵은0을 포함하고 두 핵 벡터의 선형결합도T의 선형성 때문에0으로 간다. 치역도T(u),T(v)의 선형결합이T(au+bv)이므로 닫혀 있다. 두 집합은 각기 입력/출력 공간의 부분공간이다.

T(x,y,z)=(x+y,z)는 x+y=0,z=0일 때만 출력0이다. 핵은(a,−a,0) 전체이며 한 방향이 사라진다. 이 입력 정보는 출력에서 되찾을 수 없다.

단사와 전사를 다른 질문으로

T(u)=T(v)이면 T(u−v)=0이다. 핵이{0}이면 u=v이므로 단사이고, 반대로 단사이면0의 다른 원상이 없어 핵이{0}이다. 전사는 치역이 지정한 공역과 같은지 묻는 조건이다.

위T는 아무 출력(s,t)에 대해 입력(s,0,t)를 선택하므로 R²로 전사지만 단사는 아니다. 같은 좌표식T(x,y)=(x,0)도 공역을R²로 정하면 전사 아님, x축 공간으로 정하면 전사다. 식만 읽고 공역을 생략하면 잘못 판단한다.

차원과 동형의 조건

유한차원V에 대해 dimV=dimkerT+dimimT이다. 핵의 기저를V의 기저로 확장하면 추가 기저들의 상이 치역을 생성하고 독립임을 보일 수 있다. 추가 상의 선형결합0은 원래 결합이 핵에 있다는 뜻이어서 계수가0이 된다.

전단사 선형사상은 역함수도 선형이다. 같은 유한차원 공간 사이에서는 단사/전사가 서로 연결되지만 서로 다른 차원이면 한 성질만 가능할 수 있다. 핵이0이라는 이유만으로 더 큰 공역 전체에 전사라고 말할 수 없다.

소단원 6.3

합성의 행렬 표현

먼저 늘리고 나중에 회전하는 것과 순서를 바꾸는 것은 같을까?

준비 개념과 학습 목표

준비 개념

  • 열벡터를 사용한다. 행렬AB에서 오른쪽B가 입력에 먼저 작용한다.

  • T:V→W와S:W→U의 합성S∘T는S(T(v))다.

  • 중간 공간W의 출력 기저와 다음 입력 기저가 같아야 그대로 행렬을 곱할 수 있다.

학습 목표

  • 합성의 행렬 순서와 크기를 확인한다.

  • 중간 좌표 기저의 일치 조건을 설명한다.

  • 행렬 곱이 일반적으로 가환하지 않는 반례를 계산한다.

행렬 크기가 맞아도 중간 숫자의 뜻이 다르면 그대로 곱해도 될까?

새 사상 U(x,y)=(x+2y,y)의 표준 행렬을 A=[[1,2],[0,1]]로 두고 V(x,y)=(x,3y)의 표준 행렬을 S=diag(1,3)으로 둔다. U 다음 V는 SA이고 V 다음 U는 AS다. 두 사상은 전단사지만 순서를 바꾸면 같은 결과일 필요는 없다.

중간 기저 C=((1,0),(1,1))의 열 행렬 P=[[1,1],[0,1]]은 C좌표를 표준좌표로 보낸다. V의 입력만 C좌표로 적으면 행렬 B=SP=[[1,1],[0,3]]다. U는 표준 출력이므로 B 앞에 P⁻¹=[[1,−1],[0,1]]을 넣어 입력 뜻을 맞춰야 한다. 전체는 BP⁻¹A=SA다.

숫자 행렬 BA는 크기상 곱해지지만 U의 표준 출력 숫자를 C의 계수로 잘못 읽는다. 각 화살표에 입력 좌표와 출력 좌표의 이름을 붙이면 곱셈의 차원 검사 뒤 필요한 의미 검사를 할 수 있다.

먼저 확인할 개념
  • 합성과 중간 좌표

    오른쪽 사상과 동일한 중간 기저 조건을 확인한다.

  • 기저의 표현 책임

    같은 벡터를 서로 다른 기저의 계수로 표현한다.

오른쪽 사상이 먼저

T의 행렬을A,S의 행렬을B라 하면T(v)의 좌표는A[v]이고 S(T(v))의 좌표는B(A[v])다. 따라서 합성행렬은BA다. 읽는 순서S∘T와 계산 순서T 다음S를 함께 적으면 혼동을 줄일 수 있다.

A가m×n이면 입력 좌표는n개, 출력m개다. B가p×m이면 BA는p×n이다. BA의 j번째 열은A의 j번째 열을B로 변환한 결과이며 합성 사상이 입력 기저j를 보내는 곳이다.

두 순서의 자체 예제

D=diag(2,1)은 가로축을2배로 늘린다. R=[[0,−1],[1,0]]는90도 반시계 회전이다. RDe1=R(2,0)=(0,2),DRe1=D(0,1)=(0,1)로 벌써 다른 결과다.

RD=[[0,−1],[2,0]],DR=[[0,−2],[1,0]]이다. 늘릴 방향이 회전 전후에 다르기 때문이다. 행렬의 크기가 모두 맞는다고 순서가 상관없는 것은 아니다.

중간 기저를 바꾸면 변환을 끼운다

W의 앞 출력 기저를C, 뒤 입력 기저를E라 하고 [w]E=P[w]C이면 합성좌표는BPA[v]다. 같은 벡터의 두 좌표를 변환하는P가 필요하다. P를 빼면 숫자열을 다른 방향의 기저 계수로 오독한다.

단순 BA 규칙은 동일한 중간 좌표계를 사용한다는 조건을 담고 있다. 크기가 같은 행렬P라도 실제 기저 방향을 확인하고, 입력/중간/출력 좌표 이름을 각 화살표에 쓰는 습관이 중요하다.

소단원 6.4

기저변환과 유사행렬

같은 벡터를 다른 기준으로 쓰면 변환 행렬은 어떻게 달라질까?

준비 개념과 학습 목표

준비 개념

  • 기저B의 좌표[v]B는B의 순서대로 벡터를 합하는 계수열이다.

  • 기저벡터를 표준 좌표 열로 넣은P는[v]표준=P[v]B를 만족한다.

  • 유사행렬은 가역P에 대해A새=P⁻¹A옛P로 연결되는 정사각 행렬이다.

학습 목표

  • 좌표 변환P/P⁻¹의 방향을 구분한다.

  • 같은 사상의 유사행렬을 유도·계산한다.

  • 유사성과 일반 입출력 기저 변경의 차이를 확인한다.

출력 숫자가 바뀌면 벡터도 달라진 것일까?

이번 절은 V(x,y)=(x,3y) 하나를 고정하고 양쪽 좌표만 C=((1,0),(1,1))로 바꾼다. 입력 (5,2)의 C좌표는 (3,2)다. 표준 출력은 (5,6)이며 C좌표 출력은 (−1,6)이다. P(−1,6)=(5,6)이므로 음수 첫 계수는 다른 벡터라는 증거가 아니다.

같은 기저를 입력과 출력에 쓰므로 V_C=P⁻¹SP=[[1,−2],[0,3]]이다. 이때 trace는 4, determinant는 3으로 S와 같다. 입력 P와 출력 Q=diag(2,1)를 다르게 쓰면 Q⁻¹SP=[[1/2,1/2],[0,3]]이며 trace 7/2와 determinant 3/2다. 혼합 좌표 행렬은 유사변환의 보존량 약속을 갖지 않는다.

기저 후보의 열이 독립인지도 먼저 확인한다. ((1,0),(2,0))는 (0,1)을 표현하지 못하고 같은 x축 벡터를 여러 계수로 표현한다. 이 열 행렬은 역이 없어 P⁻¹을 쓰는 절차의 선행 조건을 만족하지 않는다.

먼저 확인할 개념
  • 양쪽 기저와 유사변환

    P⁻¹AP의 두 방향을 화살표로 읽는다.

  • 기저의 독립과 생성

    종속한 열에는 유일 좌표와 역행렬이 없다.

벡터를 바꾸는 것이 아니라 숫자를 바꾼다

B=((1,1),(1,−1))이면P=[[1,1],[1,−1]]이다. [v]B=(a,b)는 실제v=(a+b,a−b)를 뜻한다. 역으로a=(x+y)/2,b=(x−y)/2다.

v=(3,1)은B에서(2,1)이다. 좌표열(3,1)과(2,1)이 다르지만 실제 벡터는 같다. 좌표를 바꾸는P를 원래 공간의 물리적 변환이라고 생각하면 무엇이 고정되었는지 놓치기 쉽다.

입력과 출력 모두 기저를 바꾼다

T:V→V의 표준 행렬A를B로 표현한다. 입력B좌표를P로 표준으로 바꾸고 A를 적용한 뒤 P⁻¹로 출력B좌표를 얻으므로A_B=P⁻¹AP다.

A=diag(2,4)이면AP=[[2,2],[4,−4]],P⁻¹=½[[1,1],[1,−1]]로A_B=[[3,−1],[−1,3]]이다. 표준좌표의 대각모양은 바뀌지만 동일한T를 나타낸다.

유사성과 보존되는 정보

유사행렬은 특성다항식·고유값·행렬식·trace를 보존한다. det(λI−P⁻¹AP)=det(P⁻¹(λI−A)P)=det(λI−A)로 확인한다. 예제의 trace6와det8도 두 행렬에서 같다.

일반T:V→W에서 입력기저P와 출력기저Q를 서로 다르게 바꾸면 새 행렬은Q⁻¹AP다. V=W라도P와Q가 같다는 조건 없이는 유사변환이 아니다. 또한 같은 고유값만으로 모든 행렬이 유사하다고 판정할 수 없다.

다른 문제에 적용하기

다항식 요약에서 좌표가 다른 후속 처리까지

실수 다항식 p=2−t+4t²를 E로 요약하고 U 다음 V를 적용한다. E의 입력은 P₂, 요약과 후속 처리의 출력은 R²다. U의 표준 출력 뒤 V의 입력은 C좌표이며 B=SP를 사용한다. 필요한 중간 변환을 넣어 최종 표준 출력과 C출력을 구하라. 이차 계수 4를 출력에서 유일하게 복구할 수 있는지 설명하고 V 다음 U의 결과도 비교하라. 모든 값은 종이 모형이며 실제 센서·프로그램·학생 실험은 수행하지 않는다.

힌트 1

E는 상수와 일차 계수만 남긴다. U의 표준 출력 (x,y)을 C의 계수 (x−y,y)로 바꾼 뒤 B를 적용한다.

힌트 2

최종 C좌표도 표준 출력을 P⁻¹로 변환한다. 이차 항을 바꿔도 요약이 같은지 확인하고 두 사상의 적용 순서를 따로 적는다.

풀이와 답 확인

  1. E(p)=(2,−1)이며 E(p+ct²)도 같다. 입력 차원 3 중 핵 span(t²)의 한 방향이 사라진다.

  2. U(2,−1)=(0,−1)이다. 그 C계수는 (1,−1)이며 B(1,−1)=(0,−3)이다.

  3. 최종 표준 출력 (0,−3)의 C좌표는 (3,−3)이다. P(3,−3)=(0,−3)로 복원된다.

  4. V 먼저면 (2,−3), U 다음이면 (−4,−3)이다. 모든 이차 계수가 같은 요약과 후속 출력을 만들므로 원래 4는 유일하게 복구할 수 없다.

U 다음 V의 표준 출력은 (0,−3), C좌표는 (3,−3)이다. V 다음 U의 표준 출력은 (−4,−3)으로 다르다. 기저 변경은 출력 정보를 보존하지만 E에서 사라진 이차 계수는 복원하지 못한다.

해결한 뒤 점검할 것

  • E의 선형성·핵과 입력 정보 손실을 구별한다.

  • 앞 출력 표준과 뒤 입력 C의 변환 방향을 명시한다.

  • 최종 C계수에서 실제 표준 출력을 복원한다.

  • 합성 순서의 두 결과와 이차 계수의 비유일성을 확인한다.
