소단원 5.1

열공간과 행공간

행렬이 만들 수 있는 출력과 입력을 검사하는 조건은 같은 공간일까?

준비 개념과 학습 목표

준비 개념

  • 실수 m×n 행렬 A는 n개 수를 m개 수로 보낸다.

  • span은 주어진 벡터들의 모든 실수 선형결합이다.

  • 피벗은 소거 후 각 비영 행의 첫 비영 위치다.

학습 목표

  • 열·행공간의 좌표 수를 구별한다.

  • 원래 피벗 열과 소거 후 비영 행으로 기저를 찾는다.

입력 세 개로 출력 네 개를 만든다면 기저 벡터는 몇 성분일까?

새 실수 4×3 행렬 A의 행은 차례로 (1,0,1), (0,1,1), (1,1,2), (2,1,3)이다. 모든 입력과 출력은 정확한 수학값이며 실제 센서 측정이 아니다.

첫 열 u=(1,0,1,2), 둘째 열 v=(0,1,1,1), 셋째 열은 u+v다. 따라서 출력은 (s,t,s+t,2s+t)이며 독립인 출력 방향은 두 개다. 한편 행은 세 성분의 입력을 검사하는 계수다. 행공간은 (a,b,a+b) 형태여서 출력 공간과 놓인 자리부터 다르다.

셋째 행에서 첫째와 둘째 행을 빼고, 넷째 행에서 첫째 행의 두 배와 둘째 행을 빼면 아래 두 행이 0이 된다. 소거 행렬 R의 첫 두 행은 (1,0,1), (0,1,1)이다. 행공간은 보존되지만 열의 출력 성분은 달라졌다. 원래 피벗 열과 소거 행렬의 피벗 열을 구별해야 한다.

먼저 확인할 개념
  • 기저의 생성과 독립

    원래 벡터를 보존하며 중복 열을 제거한다.

  • 입력과 출력의 두 공간

    행공간과 열공간의 성분 수를 구별한다.

출력을 만드는 열

A의 j번째 열을 a_j라 하면 Ax=x₁a₁+…+xₙaₙ이다. 따라서 열공간 C(A)는 모든 가능한 출력 Ax의 집합이며 Rᵐ의 부분공간이다. 열 몇 개만 고르는 집합이 아니라 그들의 모든 선형결합을 포함한다.

행공간 Row(A)는 A의 행들을 길이 n인 벡터로 보아 생성한 Rⁿ의 부분공간이다. 전치 Aᵀ의 열공간과 같지만 C(A)와는 좌표 수부터 다를 수 있다. 각 행과 x의 내적이 출력의 한 성분을 만든다.

기저를 고르는 두 규칙

가역인 기본 행 연산은 기존 행들의 선형결합으로 새 행을 만들고 역연산도 가능하다. 따라서 행공간은 보존된다. 사다리꼴 행렬의 비영 행들은 서로 다른 피벗을 가져 독립이므로 행공간 기저가 된다.

열공간 기저는 소거 과정의 피벗 위치를 보고 원래 A의 해당 열을 뽑는다. 행 연산은 출력 좌표 자체를 바꾸므로 소거한 행렬의 열을 원래 열공간 기저라고 쓰면 안 된다. 두 기저의 개수는 같은 rank r이지만 공간 자체가 같다는 뜻은 아니다.

공간에 속하는지 검사하기

기저를 얻었으면 주어진 벡터가 그 공간에 속하는지도 확인할 수 있어야 한다. 예제의 열공간은 (s,t,s+t)이므로 출력 b=(2,3,5)는 s=2,t=3으로 만들 수 있지만 (2,3,6)은 셋째 좌표가 맞지 않아 만들 수 없다. 차원 2라는 숫자만으로 이 두 벡터를 구분할 수는 없다. 좌표 조건을 보존한 기저가 필요한 이유다.

행공간에서는 (s,2s,t)이므로 (2,4,7)은 속하지만 (2,3,7)은 속하지 않는다. 앞 출력 예제와 입력 예제를 같은 길이 3이라고 혼합하지 않는다. 행공간 기저에 직교하는 입력을 넣으면 모든 행과의 내적이 0이 되는 성질이 다음 영공간의 출발점이다.

입력 세 개로 출력 네 개를 만든다면 기저 벡터는 몇 성분일까?
공간 또는 검사주변 좌표조건과 결과

C(A)

R⁴

u,v의 결합; 차원 2

Row(A)

R³

(1,0,1),(0,1,1)의 결합; 차원 2

C(R)

R⁴

(s,t,0,0); C(A)와 다름

같은 차원 2를 가진 공간을 같은 벡터 집합으로 읽지 않는다. C(R)의 셋째·넷째 성분 0은 원래 출력의 관계를 대신하지 못한다.

중간 과정을 따라가는 예제

A의 행이 (1,2,0),(0,0,1),(1,2,1)일 때 열·행공간의 기저를 구하라.

  1. R₃←R₃−R₁ 후 R₃←R₃−R₂로 마지막 행은 0이 된다. 피벗 열은 1,3이다.

  2. 원래 열 a₁=(1,0,1), a₂=2a₁, a₃=(0,1,1)이므로 열공간 기저는 a₁,a₃이다.

  3. 소거 후 비영 행 (1,2,0),(0,0,1)은 행공간 기저다.

  4. C(A)={(s,t,s+t)}, Row(A)={(s,2s,t)}. 각 기저의 두 벡터는 독립이다.

둘 다 차원 2이지만 각각 z=x+y, y=2x라는 다른 평면이다.

조건을 바꾸어 비교하기

소거한 열의 잘못된 복사

R의 첫 열 (1,0,0,0)을 C(A)의 기저로 사용할 수 있는가?

  1. 원래 출력에서는 셋째 성분이 첫째와 둘째의 합이다.

  2. 후보에서는 0≠1+0이어서 원래 열공간에 속하지 않는다.

사용할 수 없다. 원래 첫 열 u를 선택한다.

비교할 점

피벗 번호는 가져오지만 벡터의 출력 성분은 원래 A에서 가져온다.

도달 가능한 출력과 거의 같은 출력

b=(2,3,5,7)과 c=(2,3,5,8)을 비교하라.

  1. 두 후보 모두 셋째 성분은 2+3=5다.

  2. 넷째 성분은 2×2+3=7이어야 하므로 c는 실패한다.

b는 2u+3v이고 c는 C(A) 밖이다.

비교할 점

한 관계만 통과하는 것으로 모든 출력 관계를 확인했다고 할 수 없다.

종이와 본문으로 직접 해보기

행이 (1,1),(2,2),(0,0)인 3×2 행렬의 두 공간을 쓰고 좌표 수를 표시하라.

힌트 보기

열 두 개가 같은지, 행 두 개가 배수인지 본다.

풀이 보기

열공간=span{(1,2,0)}⊂R³, 행공간=span{(1,1)}⊂R². rank는 각각 1이다.

오해와 반례

행공간과 열공간은 rank가 같으므로 항상 같다.

3×2 예제는 공간이 놓인 R³와 R²부터 다르다. 정사각 행렬도 위 예제처럼 다른 평면일 수 있다. 같은 차원은 같은 벡터 집합을 보장하지 않는다.

소단원 5.2

영공간과 왼쪽 영공간

입력을 바꾸어도 출력이 변하지 않는 방향은 어디에 숨을까?

준비 개념과 학습 목표

준비 개념

  • Ax=0은 동차 연립방정식이다.

  • Aᵀ는 행과 열을 바꾼 전치행렬이다.

  • u·v는 같은 좌표 수의 성분 곱을 더한 내적이다.

학습 목표

  • N(A),N(Aᵀ)의 정의와 좌표 수를 쓴다.

  • 행·열공간과 직교 관계를 대입으로 확인한다.

같은 출력의 숨은 입력 변화와 불가능한 출력의 증명은 어디에 있을까?

새 실수 4×3 행렬 A의 행은 차례로 (1,0,1), (0,1,1), (1,1,2), (2,1,3)이다. 모든 입력과 출력은 정확한 수학값이며 실제 센서 측정이 아니다.

Az=0을 풀면 z₁+z₃=0, z₂+z₃=0이므로 z=t(-1,-1,1)이다. 입력 세 성분의 이 방향을 더해도 출력은 바뀌지 않는다. 왼쪽 영공간은 출력 네 성분에 대한 관계다. y=(-1,-1,1,0)와 w=(-2,-1,0,1)는 각각 셋째와 넷째 행의 중복을 기록한다.

두 벡터는 서로 독립이고 Aᵀ의 영공간 전체를 생성한다. 실제로 Aᵀh=0에서 h₁=-h₃-2h₄, h₂=-h₃-h₄이므로 h=h₃y+h₄w다. 오른쪽 영공간의 입력 모호성과 왼쪽 영공간의 출력 제약은 같은 말이 아니다.

    길이가 다른 영벡터와 직교 관계를 구별한다.

영공간의 두 자리

영공간 N(A)={x∈Rⁿ:Ax=0}는 출력이 0인 입력이다. Ax=b의 해 x₀에 z∈N(A)를 더하면 A(x₀+z)=b이므로 관측 출력만으로는 이 방향의 차이를 구분하지 못한다.

왼쪽 영공간 N(Aᵀ)={y∈Rᵐ:Aᵀy=0}는 yᵀA=0과 같다. 이름의 왼쪽은 행벡터 yᵀ가 A 왼쪽에 곱해지는 데서 왔으며, A 왼편의 열을 고르는 뜻이 아니다.

직교로 찾는 증명

Ax=0의 각 성분은 A의 각 행과 x의 내적이다. 따라서 N(A)는 모든 행에 직교하고, 선형성에 의해 행공간의 모든 벡터에 직교한다. 역으로 모든 행에 직교하면 각 성분이 0이어서 Ax=0이다.

Aᵀy=0을 같은 방식으로 보면 y는 원래 A의 모든 열, 즉 열공간 전체에 직교한다. 실수 표준 내적에서 N(A)=Row(A)⊥, N(Aᵀ)=C(A)⊥다. 직교는 공간 전체에 대한 조건이지 기저 중 한 벡터만 검사하는 조건이 아니다.

기저 하나의 검사를 전체 공간으로 넓히기

모든 벡터에 직교한다는 정의가 무한한 검사처럼 보이지만 기저만 검사해도 충분하다. 기저 r₁,…,rₖ의 임의 조합 r=Σcᵢrᵢ에 대해 x·r=Σcᵢ(x·rᵢ)다. 각 내적이 0이면 모든 조합에 대한 내적도 0이다. 반대로 공간 전체에 직교하면 그 안의 기저 각각에도 직교하므로 양방향이 성립한다.

예제의 왼쪽 영공간 벡터 y=(−1,−1,1)는 임의 출력 (s,t,s+t)에 대해 −s−t+(s+t)=0이다. 특정 열 두 개에서 확인한 결과가 열공간 전체로 확장됨을 이 식이 직접 보여 준다. 반면 y와 직교하지 않는 측정값은 정확한 Ax의 출력일 수 없으며, y는 다음 일관성 검사의 근거가 된다.

소단원 5.3

rank-nullity

입력 자유도는 도달 가능한 출력과 사라지는 방향 사이에 어떻게 나뉠까?

준비 개념과 학습 목표

준비 개념

  • 차원은 기저 벡터의 개수다.

  • rank는 독립인 열의 최대 개수다.

  • nullity는 영공간 차원이다.

학습 목표

  • rank+nullity=n을 자유변수로 설명한다.

  • 네 기본공간 차원을 m,n,r로 계산한다.

측정 행을 하나 더 적으면 입력의 모호성은 반드시 줄어들까?

새 실수 4×3 행렬 A의 행은 차례로 (1,0,1), (0,1,1), (1,1,2), (2,1,3)이다. 모든 입력과 출력은 정확한 수학값이며 실제 센서 측정이 아니다.

현재 m=4,n=3,r=2이므로 열과 행공간 차원은 2, 입력 영공간은 1, 왼쪽 영공간은 2다. 출력 식 네 개가 있어도 독립 조건은 두 개라 입력 세 성분을 모두 식별하지 못한다.

새 출력 행이 기존 행의 조합이면 식 수만 늘고 rank는 그대로다. 반대로 기존 행공간 밖의 행을 더하면 rank가 증가할 수 있다. 여기서는 (0,0,1)을 더하면 세 번째 입력을 직접 정하여 rank가 3이 된다. 행 수 증가와 정보 증가를 분리한다.

먼저 확인할 개념
  • span 밖의 독립 방향 추가

    새 행이 기존 행공간 밖인지 확인한다.

  • rank와 두 nullity

    입력 차원 n과 출력 차원 m을 각각 사용한다.

피벗과 자유변수의 분배

m×n 행렬에 피벗이 r개 있으면 n개 입력 변수 중 r개가 피벗변수이고 n−r개가 자유변수다. Ax=0을 소거하여 자유변수 하나씩 1, 나머지 0을 넣으면 n−r개의 특수해가 생긴다. 모든 해는 그들의 선형결합이고 자유 좌표가 단위벡터이므로 독립이다.

따라서 dim N(A)=n−r이며 dim C(A)=r과 더하면 n이다. 이 rank-nullity 공식의 우변은 행 수 m이 아닌 입력 차원 n이다. 출력 성분 수가 많다고 입력에서 사라지는 방향이 자동으로 줄어들지는 않는다.

네 공간의 차원표

행 연산으로 얻은 비영 행 r개가 행공간 기저이므로 dim Row(A)=r이다. 행 rank와 열 rank가 같다는 사실은 두 공간의 좌표 수가 같다는 사실과 다르다.

Aᵀ의 rank도 r이고 입력 차원은 m이므로 dim N(Aᵀ)=m−r이다. 입력 쪽에서는 r+(n−r)=n, 출력 쪽에서는 r+(m−r)=m이다. 네 차원을 모두 더해 행렬 원소 수 mn이 된다고 기대하지 않는다.

차원 숫자가 말하지 않는 것

같은 rank와 nullity를 가진 행렬도 실제 영공간 방향은 다를 수 있다. 1×2 행렬 (1 0)의 영공간은 (0,t), (0 1)의 영공간은 (t,0)이다. 둘 다 rank 1, nullity 1이지만 첫 행렬은 둘째 입력을 지우고 두 번째는 첫째 입력을 지운다. 차원은 방향의 개수이지 방향 그 자체가 아니다.

측정 중복도 행 수와 rank의 차이로 읽을 수 있다. 4×6 예제에서 왼쪽 영공간 차원 1은 출력 성분 사이에 독립인 선형 제약 하나가 있음을 뜻한다. 정확한 출력 b는 그 제약을 만족한다. 숫자 1만으로 제약의 계수를 알 수는 없으므로 실제 Aᵀy=0을 풀어야 한다.

소단원 5.4

일관성과 해의 구조

연립방정식이 풀리는 조건과 답이 하나인 조건은 어떻게 다른가?

준비 개념과 학습 목표

준비 개념

  • 일관성은 해가 적어도 하나 존재한다는 뜻이다.

  • 왼쪽 영공간 벡터 y는 yᵀA=0을 만족한다.

  • 특수해 xₚ는 Ax=b를 만족하는 한 해다.

학습 목표

  • 존재 조건을 열공간과 왼쪽 영공간으로 말한다.

  • 전체 해를 xₚ+N(A)로 유도한다.

정확한 출력 조건을 통과한 뒤 답을 하나만 골라야 할까?

새 실수 4×3 행렬 A의 행은 차례로 (1,0,1), (0,1,1), (1,1,2), (2,1,3)이다. 모든 입력과 출력은 정확한 수학값이며 실제 센서 측정이 아니다.

b=(2,3,5,7)은 두 왼쪽 검사에 직교하므로 정확한 해가 있다. x₃=t로 놓으면 전체 해는 (2-t,3-t,t)다. 특정 입력 (2,3,0)은 한 해이며 유일한 정답이 아니다.

xₚ+t z₀에서 xₚ는 특수해, z₀=(-1,-1,1)은 영공간 방향이다. 두 해의 차이는 영공간에 속하지만 두 해의 합은 보통 원래 우변의 해가 아니다. 실수 계수의 아핀 결합, 즉 계수 합이 1인 결합은 같은 우변의 해가 된다.

먼저 확인할 개념
  • 출력의 왼쪽 검사

    일관성을 먼저 판단한다.

  • 같은 벡터의 유일 좌표

    기저 좌표의 유일성과 비동차계 해의 유일성을 구별한다.

출력 도달성 검사

Ax=b가 풀린다는 것은 b가 A의 열들의 선형결합이라는 뜻이므로 b∈C(A)와 동치다. 소거에서는 증강행렬 [A|b]에 0=비영 상수라는 행이 생기면 불일관이다.

yᵀA=0인 y가 있으면 해에 왼쪽으로 곱해 yᵀb=0을 얻는다. 따라서 모든 왼쪽 영공간 벡터와 b가 직교해야 한다. 역방향은 C(A)=N(Aᵀ)⊥로부터 따른다. yᵀb≠0인 벡터 하나는 불가능성을 증명하는 증명서다.

존재 후에 유일성 검사

해 xₚ를 하나 찾았을 때 다른 해 x는 A(x−xₚ)=0을 만족한다. 따라서 x=xₚ+z, z∈N(A)다. 반대로 이런 벡터는 A(xₚ+z)=b라서 해다. 이 두 방향으로 전체 해집합이 설명된다.

N(A)={0}이면 존재하는 해는 유일하다. 영공간에 비영 벡터가 있으면 실수 배수를 더해 무한히 많은 해를 만든다. b≠0일 때 해집합은 일반적으로 원점을 지나지 않는 아핀 집합이다. 따라서 모든 Ax=b 해집합을 벡터공간이라 부르지 않는다.

유일한 해와 모든 출력의 해를 분리하기

A=(1,0,0; 0,1,0)인 2×3 행렬을 생각하자. 모든 b=(b₁,b₂)는 x=(b₁,b₂,t)로 풀리지만 t가 자유라 유일하지 않다. 이는 모든 출력에 도달하는 조건인 full row rank와 해가 존재할 때 유일한 조건인 full column rank가 서로 다른 질문임을 보여 준다.

반대로 A의 열이 (1,0,0),(0,1,0)인 3×2 행렬은 x=(b₁,b₂)라는 유일한 해가 있을 수 있지만 b₃=0이어야 한다. (0,0,1)은 풀리지 않는다. 둘 다 동시에 모든 출력에 대해 유일해를 보장하는 경우는 정사각 full rank 행렬이며, 정사각 행렬이 아닌 모델에서는 존재와 유일성을 각각 표로 확인한다.

중간 과정을 따라가는 예제

행이 (1,2,0),(0,0,1),(1,2,1)인 A에서 b=(3,4,7)와 c=(3,4,8)의 해를 판단하라.

풀이와 답 확인

  1. y=(-1,-1,1,0), w=(-2,-1,0,1)와 b의 내적은 모두 0이다. c는 y 검사만 통과하고 w·c=1로 실패한다.

  2. b의 전체 해는 (2-t,3-t,t)이다. x₃=2이면 (0,1,2)를 선택하며 A에 대입하면 b다.

  3. 중복 행 추가에서는 행·열 rank가 2이고 오른쪽 nullity는 1, 왼쪽은 3이다. 새 행 추가에서는 rank가 3이고 오른쪽은 0, 왼쪽은 2다.

  4. 원래 열공간 기저는 u=(1,0,1,2), v=(0,1,1,1)이다. R의 첫 열 (1,0,0,0)은 원래 출력 관계를 위반한다.
