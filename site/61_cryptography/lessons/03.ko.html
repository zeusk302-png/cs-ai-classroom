소단원 3.1

일회용 패드

암호문을 보아도 원래 메시지의 확률이 전혀 바뀌지 않을 수 있을까?

준비 개념과 학습 목표

준비 개념

  • bit는0 또는1이다. XOR ⊕는 두 bit가 다르면1, 같으면0인 자리별 연산이다.

  • X⊕X=0이고 X⊕0=X이므로 같은 마스크를 두 번 XOR하면 복원된다.

  • P(M=m|C=c)는 암호문 c를 관측한 조건의 메시지 확률이며 P(C=c)>0에서 정의한다.

학습 목표

  • OTP의 정확성과 완전비밀을 각기 증명한다.

  • 균등·독립·일회 사용 가정과 재사용/변조의 한계를 계산한다.

키의 각 자리에서 0과 1이 반반이면 완전한 패드인가요?

키 K는 00 또는 11을 각각 확률 1/2로 고르고 메시지와 독립이라고 합시다. 각 자리의 주변 분포는 공정하지만 가능한 키는 두 개뿐이라 네 가지 전체 키가 균등하지 않습니다. 메시지 M이 00 또는 01을 각각 1/2로 선택하면 C=M⊕K는 메시지의 두 비트 XOR 값을 그대로 드러냅니다.

M=00에서는 C가 00/11이고 M=01에서는 C가 01/10입니다. 암호문이 00이면 M=00이라는 사후 확률은 1로 바뀝니다. 키 전달이나 실제 난수 발생기는 실행하지 않고 네 결합 경우를 종이로 셉니다. 각각의 비트가 공정하다는 주장과 전체 비트열의 균등·독립 조건을 분리합니다.

같은 길이의 무작위 마스크

길이 n을 고정하고 메시지 M과 키 K를 n-bit 문자열로 둔다. OTP는 C=M⊕K, 복호는 M=C⊕K다. 키는 모든2ⁿ개 문자열에서 균등하게 고르고 메시지와 독립이어야 한다. 송신자/수신자가 같은 비밀 키를 공유하며 각 키 구간은 한 메시지에만 쓴다. n개의 bit마다 균등이라는 말에 bit끼리 독립까지 포함한 전체 균등 분포가 필요하다.

복호 정확성은 (M⊕K)⊕K=M⊕(K⊕K)=M이다. 이 대수식 자체는 키가 편향되거나 재사용되어도 맞을 수 있다. 따라서 “복호가 맞는다”와 “정보가 새지 않는다”는 별개의 질문이다. 여기의 한 번 관측 모형은 송신 길이를 고정하고 암호문만 보는 공격자를 다루며 실제 키 전달과 저장 경로를 시험하지 않는다.

관측 전후 분포가 그대로다

완전비밀은 모든 허용 메시지 사전분포에서 M과 C가 독립이라는 의미로 설명한다. 즉 양의 확률 암호문 c를 본 뒤 P(M=m|C=c)=P(M=m)다. 이것은 모든 메시지가 관측 뒤 같은 확률이라는 뜻이 아니다. 어떤 메시지가 원래 더 흔했다면 그 사전 정보는 그대로 남고 암호문이 추가 정보를 주지 않는 것이다.

고정 m,c마다 m⊕k=c를 만족하는 키는 정확히 k=m⊕c 하나다. 균등 독립 키에서 P(C=c|M=m)=2^(−n)으로 m과 무관하다. 전체확률로 P(C=c)=Σm P(M=m)2^(−n)=2^(−n)이고 Bayes 식의 분자 P(M=m)2^(−n)을 나누면 사전분포가 그대로다. 확률0 메시지는 별도 조건부식을 억지로 쓰지 않고 결합확률로 해석한다.

한 번의 비밀성과 전체 통신 보장

같은 키로 두 메시지를 암호화하면 C1⊕C2=M1⊕M2다. 키가 사라져 두 메시지의 관계가 공개된다. 각 암호문 하나의 주변분포가 균등이어도 암호문 쌍과 메시지 쌍의 독립성은 따로 깨질 수 있다. “일회용”은 구현 이름이 아니라 비밀 마스크의 사용 조건이다.

OTP는 무결성/송신자 인증을 제공하지 않는다. 공격자가 C를 C⊕Δ로 바꾸면 복호 결과가 M⊕Δ로 바뀐다. 비밀성과 변조 탐지는 서로 다른 목표다. 길이가 다른 메시지를 원래 길이 그대로 암호화하면 암호문 길이가 메시지 길이를 드러내므로 모든 길이를 숨긴 완전비밀이라고 말할 수 없다. 이 단원은 실제 통신·암호 도구·난수 생성기를 실행하지 않는다.

중간 과정을 따라가는 예제

M1=1011, K=0110에서 C1과 복호를 구하라. 같은 K를 M2=0010에도 재사용한 가상 모형에서 C2와 C1⊕C2를 계산하라.

  1. 자리별 XOR로 1011⊕0110=1101이다. C1⊕K=1101⊕0110=1011로 복호한다.

  2. 같은 키를 다시 쓰는 조건 위반 예에서 0010⊕0110=0100이므로 C2=0100이다.

  3. 암호문 둘을 XOR하면1101⊕0100=1001이다. 메시지1011⊕0010도1001로 관계가 노출된다.

  4. M1을 이미 아는 관측자는 K=C1⊕M1=0110을 얻어 C2⊕K=0010을 복원한다. 이 결과는 실제 자료를 공격한 것이 아니라 네 bit의 자체 종이 계산이다.

C1=1101, C2=0100, 두 암호문 XOR=1001이며 키 재사용이 두 메시지 관계를 드러낸다.

결합 분포의 사후 확률

이 모형에서 P(C=00), P(M=00|C=00)을 구하세요.

  1. M00·K00의 결합 확률은 1/4입니다. 다른 세 결합에서는 C00이 나오지 않습니다.

  2. 따라서 P(C00)=1/4입니다.

  3. P(M00,C00)/P(C00)=(1/4)/(1/4)=1입니다.

사전 1/2에서 사후 1로 바뀝니다.

비교할 점

키 각 자리의 공정성만으로 완전비밀 증명을 사용할 수 없습니다.

편향된 독립 한 비트 패드

P(M0)=3/5, P(K0)=3/4이고 독립일 때 C0 관측 뒤 M0 확률을 구하세요.

  1. P(M0,C0)=(3/5)(3/4)=9/20입니다.

  2. P(M1,C0)=(2/5)(1/4)=2/20이므로 P(C0)=11/20입니다.

  3. 사후 확률은 9/11이며 사전 3/5와 다릅니다.

독립성만으로도 부족하며 키 균등성 조건이 필요합니다.

비교할 점

확률을 합하는 분모 없이 분자 9/20을 사후 확률로 쓰지 않습니다.

종이와 본문으로 직접 해보기

힌트 보기

각 메시지에서 C=10을 만드는 키는 한 개다. 변조식의 Δ는 복호에도 그대로 남는다.

풀이 보기

P(C10|M00)=P(C10|M11)=1/4, P(C10)=1/4다. 결합확률3/16을1/4로 나누어 P(M00|C10)=3/4이다. 두 메시지가1/2씩 되는 것은 아니다. 변조1101⊕0001=1100을 키0110으로 복호하면1010으로 마지막 bit가 바뀐다.

오해와 반례

균등한 키를 쓰면 재사용해도 완전비밀이고 변조도 탐지된다.

두 암호문 XOR=두 평문 XOR가 되어 키 재사용은 관계를 드러낸다. C⊕0001의 복호는 M⊕0001이라 오류 탐지도 제공하지 않는다. 키의 균등성 한 조건만으로 일회 사용·무결성·키 보관을 대신할 수 없다.

한 단계 더

균등한 K라도 M과 독립이 아니면 위 증명이 실패할 수 있다. 2-bit M=(B1,B2)를 전체 균등하게 고르고 K=(B2,B1)로 정하면 K 자체도 균등하지만 C=(B1⊕B2,B1⊕B2)다. M00/11일 때 C00, M01/10일 때 C11로 메시지 parity가 노출된다. 전체 균등한 키와 메시지 독립이라는 두 가정을 정확히 분리하라. 실제 random bit를 만들어 이 실험을 실행한 것이 아니라 네 경우를 종이로 열거했다.

키 길이와 한계

짧은 비밀 하나로 모든 긴 메시지의 정보를 완전히 숨길 수 있을까?

준비 개념과 학습 목표

준비 개념

  • 유한 키 집합 𝒦와 메시지 집합 𝓜를 구별한다. |𝒦|는 가능한 키 수다.

  • 정확한 복호는 D(k,E(k,m))=m이다.

  • 이 소단원의 하한은 결정적 유한 Shannon 암호와 균등 키, 모든 허용 메시지의 완전비밀에 관한 것이다.

학습 목표

  • 키 공간 크기 하한의 셈 증명을 설명한다.

  • 메시지 표현 bit 수·허용 메시지 수·계산적 보안을 구분한다.

여덟 비트로 적은 메시지 다섯 종류에는 여덟 비트 비밀이 반드시 필요한가요?

메시지 종류는 A,B,C,D,E 다섯 개뿐이며 각각 8비트 코드로 저장한다고 정합니다. 종류의 인덱스 m=0,…,4에 균등·독립 키 K∈{0,…,4}를 한 번 사용해 C=(m+K) mod5로 암호화하고 m=(C−K) mod5로 복호합니다. 저장용 8비트는 가능한 메시지 수 256을 뜻하지 않습니다.

각 m,c에 알맞은 키가 하나씩 있어 조건부 암호문 확률은 항상 1/5입니다. 따라서 이 제한 공간에서 정확 복호와 완전비밀이 가능합니다. 하지만 8비트 모든 256종류를 같은 다섯 키로 숨길 수 있다는 결론은 나오지 않습니다. 모형의 키 분포를 실제 난수 샘플러 구현으로 검증한 것도 아닙니다.

고정 암호문에서 복호 가능한 수

정확히 복호할 수 있고 완전비밀인 유한 Shannon 암호는 |𝒦|≥|𝓜|가 필요하다. 키를ℓ-bit 전체 공간에서 고르고 메시지는 n-bit 모든 문자열을 허용하면2^ℓ≥2ⁿ에서ℓ≥n이다. 모든 n-bit 메시지라는 조건이 핵심이다. 형식상 n-bit로 기록되지만 실제 가능한 메시지가 몇 개 안 되는 경우와 섞지 않는다.

증명은 고정 암호문 하나를 생각한다. 어떤 k0,m0에서 c=E(k0,m0)를 골랐다면 c가 나올 확률이 양수다. 각 키 k는 이 c를 최대 하나의 메시지 D(k,c)로 복호한다. 그러므로 c를 만들 수 있는 메시지 종류는 키 수보다 많을 수 없다. 모든 메시지가 같은 c 확률을 가져야 하는 완전비밀과 비교한다.

빠진 메시지가 있으면 분포가 다르다

만약 키 수가 메시지 수보다 작다면 S={D(k,c):k∈𝒦} 밖의 메시지 m1이 존재한다. 그 m1이 c를 만들면 정확한 복호가 m1을 돌려줘야 해 m1∈S가 되므로 모순이다. 따라서 m1에서는 c 확률0이고 m0에서는 양수다. 메시지에 따른 암호문 분포가 달라 완전비밀이 아니다. 하한은 필요한 조건이며 키 개수만 충분하다고 모든 알고리즘이 안전한 것은 아니다.

3-bit 전체 메시지8개를2-bit 키4개로 완전히 숨기는 정확한 결정적 암호는 이 조건을 만족할 수 없다. 반면 메시지가{000,001,010,011} 네 개뿐이면 뒤2-bit만 OTP로 숨기고 복호 때 앞0을 붙이는 모형은2-bit 키로 가능하다. 첫bit가 항상0이라는 사전 정보를 암호문이 새로 드러낸 것이 아니므로 원래 허용 공간에서 모순이 없다.

실용 암호와 다르게 약속한 보안

짧은 seed를 결정적 생성기로 긴 마스크로 늘려 XOR하면 seed 수만큼의 출력만 가능하다. n>ℓ이면 전체2ⁿ개의 마스크를 균등하게 만들 수 없어 OTP의 완전비밀 증명을 그대로 적용할 수 없다. 적절한 암호학적 생성기에서는 효율적인 관측자가 진짜 무작위와 구별하기 어렵다는 계산적 목표를 검토한다. 완전비밀 하한을 깨뜨린 것이 아니라 보안 요구를 바꾼 것이다.

OTP의 키는 미리 비밀리에 공유하고 같은 구간을 다시 쓰지 않도록 관리해야 한다. 키 전달·보관·삭제·길이 노출·인증은 이 하한으로 자동 해결되지 않는다. 압축으로 메시지 공간을 줄이는 방법도 모든 입력과 모든 길이의 분포·외부 정보를 포함해 검토해야 한다. “항상 긴 자료를 짧게 압축할 수 있다”는 일반 주장은 비둘기집 원리와 충돌한다.

중간 과정을 따라가는 예제

메시지 공간은3-bit 전체8개, 키 공간은{00,01,10,11} 네 개다. 어떤 도달 가능한 c에 대해 복호값 집합 S={000,010,101,111}라고 가정할 때 완전비밀 하한의 모순을 설명하라.

  1. 키는4개이고 고정 c의 복호 후보는 주어진 네 값이다. 중복 복호가 있으면 S는 더 작아질 수도 있다.

  2. c를 만든 원래 메시지 m0는S 안에 있다. 균등4키 중 해당 키 하나가 c를 만드므로 P(C=c|M=m0)≥1/4이다.

  3. m1=001은S 밖이다. 어떤 키도001을 c로 암호화할 수 없다. 가능하면 정확 복호에서001이S에 들어가야 하기 때문이다.

  4. 따라서001에서 확률0과 m0에서 양수가 달라 완전비밀 조건 실패다. 전체8개 공간에는 적어도8개 키, 즉 전체bit 키 모형에서 최소3bit가 필요하다.

같은 암호문 c의 조건부 확률이 메시지에 따라 양수/0으로 달라 완전비밀이 아니다.

분포 전체의 불확실성

유한 X의 Shannon entropy는 H(X)=−Σx p(x)log₂p(x)로 단위bit다. 각 결과의 놀라움 −log₂p를 분포에 따라 평균한 값이다. 네 결과가 각각1/4이면 H=2bit, 값 하나만 확률1이면 H=0이다. 문자열100bit가 늘 똑같다면 길이100이라고 entropy100인 것은 아니다. 실제 분포를 모르는 한 관측한 문자열 하나로 정확한 entropy를 알아낼 수 없다.

관측자의 정보 Z가 있으면 조건부 entropy H(X|Z)=Σz p(z)H(X|Z=z)로 각 조건분포의 평균을 정의한다. 비밀 seed를 알고 있다면 결정적 출력에 대한 조건분포는 한 값으로 모여 H(G(seed)|seed)=0이다. 여기서 낮은 entropy는 정보 이론적 불확실성의 감소이며 어떤 계산을 얼마나 빨리 수행하는지는 별도 질문이다.

한 단계 더

결정적 Y=G(S)에서 H(Y)≤H(S)를 유한 분포로 증명해 보라. 각 출력 y로 가는 seed 묶음의 확률을 pY(y)라 하면, 그 묶음 내부의 조건분포 p(s|y)가 생긴다. −log₂p(s)=−log₂pY(y)−log₂p(s|y)를 평균하면 H(S)=H(Y)+H(S|Y)다. 조건부 entropy는 비음수이므로 출력 엔트로피의 상한 H(Y)≤H(S)가 나온다. G가 서로 다른 seed를 합치면 잃은 정보 H(S|Y)가 양수일 수 있다. 이는 계산 자원 제한 없이 분포를 보는 정보 이론이며, 큰 실제 PRG의 계산적 구별 가능성을 이 식 하나로 판정하지 않는다.
