소단원 6.1

weight decay·dropout

가중치를 작게 만드는 것과 뉴런을 잠시 가리는 것은 같은 계산일까?

준비 개념과 학습 목표

준비 개념

  • 기울기와 SGD 갱신

  • 활성값은 뉴런이 출력하는 수치, 정규화는 여기서 일반화를 돕기 위한 학습 제약이다.

학습 목표

  • L2 벌점과 SGD 축소를 직접 유도한다.

  • inverted dropout 의 평균 보존과 평가 모드를 구별한다.

같은 평균의 제거 정책은 같은 손실도 만드는가?

활성 h=(1,−1)을 두 독립 마스크로 제거한다고 하자. 유지 확률 q=1/2이며 살아남은 값은 두 배다. 합 Y의 네 값은 0,2,−2,0이고 각 확률은 1/4다. 평균은 0이지만 제곱 손실의 평균은 2다. 하나의 마스크를 공유하면 합은 항상 0이어서 같은 평균에 다른 분산과 다른 손실이 따른다.

평가 모드는 제거 없이 원래 합 0을 사용한다. 독립 마스크의 학습 손실 평균 2를 평가 손실 0과 바로 빼서 새 자료의 일반화 차이라고 부르면 모드의 차이가 섞인다. 평균 보존은 각 활성의 일차 평균에 대한 조건이고 제곱 후처리의 평균까지 보존하지 않는다.

L2와 분리 축소의 차이는 간단한 좌표별 변환에서도 보인다. 자료 기울기 g=(0,0), w=(2,2), η=1/10, λ=1, D=diag(1,1/4)를 고정한다. 결합 벌점을 변환하는 w−ηD(g+λw)는 (9/5,39/20), 벌점을 변환 밖에서 빼는 (1−ηλ)w−ηDg는 (9/5,9/5)다. 이는 자체 고정 D 모형이며 Adam의 실제 이력이나 API 실행 결과가 아니다.

먼저 확인할 개념
  • 제거 마스크와 비선형 평균

    앞 본문의 평균 보존과 제곱 반례를 부호가 반대인 두 활성의 결합에 적용한다.

  • SGD 축소의 적용 조건

    앞 본문의 기본 SGD 동등식을 좌표 변환 D가 있는 두 명시 갱신식과 비교한다.

작은 가중치에 대한 비용

원래 학습 손실 L(w)에 λ||w||²/2, λ≥0 을 더한 목적 F 를 둔다. 미분은 ∇F=∇L+λw 다. 모수 w 와 별도 편향 b 중 무엇에 벌점을 적용하는지도 명시한다. 여기서는 w 만 벌점을 받는다.

기본 SGD 의 w 새=w−η(∇L+λw)=(1−ηλ)w−η∇L 이다. 같은 기울기에 적용한 L2 가 곱셈 축소처럼 보이는 것은 이 갱신식의 결과다. adaptive optimizer 의 좌표별 변환 뒤에도 무조건 같은 것이라 주장하지 않는다.

가리는 동안 살아남은 값을 보정한다

활성 h 에 유지 확률 q=1−p, 0<q≤1 인 Bernoulli 마스크 m 을 곱해 h̃=mh/q 로 둔다. E[m]=q 라 E[h̃]=h 다. 각 활성의 마스크를 독립으로 뽑는 자체 예제이며 같은 마스크를 공유하는 변형은 별도다.

일반 평가 때 마스크를 끄고 원래 h 를 쓴다. 이 규약에서는 평가 시 다시 q 를 곱하지 않는다. 평균 보존은 활성 단위의 말이며 비선형 후처리의 평균이나 전체 네트워크 출력이 항상 완전히 같다는 뜻은 아니다.

일반화 효과는 별도 자료로 확인한다

λ나 p 는 학습 전에 정하거나 검증 자료로 고르는 설정값이다. 너무 큰 벌점이나 지나친 제거는 필요한 신호도 줄일 수 있다. 둘을 동시에 쓰는 경우 효과가 단순히 각각의 퍼센트 합이라고 계산하지 않는다.

학습 중 마스크 때문에 손실이 흔들릴 수 있으므로 같은 평가 모드의 자료 손실도 별도로 기록한다. 정규화 목적 F 와 자료만의 L 을 같은 이름으로 비교하지 않는다. 여기서는 실제 네트워크 훈련·성능 실험을 수행하지 않았다.

오해와 반례

소단원 6.2

early stopping

마지막 학습 결과가 검증 자료에서도 가장 좋을까?

준비 개념과 학습 목표

준비 개념

  • 학습·검증·최종 평가 자료의 역할

  • checkpoint 는 특정 시점 모수의 저장본, patience 는 개선 없는 평가를 기다리는 횟수다.

학습 목표

  • 최저 검증 저장본과 중단 시점을 따로 계산한다.

  • 중단 정책과 최종 평가의 독립성을 설명한다.

중단 장부의 best는 모든 관측의 최솟값인가?

자체 정책의 개선 기준을 B−ℓ>1/50로 정한다. B는 마지막으로 충분히 개선한 손실이며 개선이면 checkpoint를 복사하고 대기 w를 0으로 만든다. 아니면 w를 1 늘리고 w=2에서 멈춘다. 첫 관측은 B와 checkpoint를 초기화한다. 모든 소수는 정확한 유리수로 다루므로 부동소수점 비교 오차는 없다.

손실 순서가 .50,.49,.48,.47일 때 .49와 .48은 기준 B=.50에서 각각 차 .01과 .02다. 엄격 부등식 때문에 둘 다 개선이 아니고 세 번째 관측에서 종료한다. 반환 checkpoint는 첫 번째다. 마지막 관측의 수치 최솟값 .48과 정책상 B=.50을 이름별로 기록해야 한다. .47은 이미 중단한 정책의 관측이 아니다.

재개할 때 모수만 가져오고 B·대기·평가 순서를 초기화하면 같은 정책의 계속 실행이 아니다. 둘째 관측 직후 B=.50,w=1을 복구하면 다음 .48에서 종료하지만, 대기를 0으로 지우면 다음 .48에서 w=1이 되어 더 진행한다. Keras의 restore_best_weights 기본값은 False이므로 자체 반환 규칙을 API 기본값이라고 주장하지 않는다.

먼저 확인할 개념
  • 엄격 개선과 min_delta

    앞 본문에서 제시한 best−현재>min_delta 조건을 등호 경계와 관측 최솟값의 차이에 적용한다.

  • 저장본과 재시작 상태

    앞 본문의 저장·평가 빈도·재시작 상태 조건으로 중단 장부의 복구를 판단한다.

어느 시점이 새 자료에 유리한가

모수 갱신은 학습 자료를 쓰지만 중단과 설정 선택은 별도 검증 자료의 지표를 볼 수 있다. 학습 손실이 계속 줄어도 검증 손실은 다시 늘 수 있다. early stopping 은 그런 곡선에서 학습 길이를 선택하는 방법이다.

검증 손실이 좋아질 때 모수를 복사해 저장한다. 종료 시 최신 모수 대신 가장 좋은 저장본을 반환한다. 기록된 최소값의 모수와 마지막 모수가 다른 경우가 핵심이며 실제 파일을 저장했다고 주장하는 것은 이 종이 예제의 범위 밖이다.

비교 규칙을 먼저 정한다

이 자체 정책은 낮은 손실이 좋고 best−현재>min_delta 이면 개선이다. min_delta=0 이면 엄격히 더 작은 값만 개선이며 동률은 개선이 아니다. 평가할 때마다 개선이면 대기 0, 아니면 1 씩 늘려 patience 에 도달하면 끝낸다.

평가는 매 epoch 끝 한 번이고 epoch 는 학습 자료 한 순회를 뜻한다. batch 마다 평가하는 정책과 대기 숫자가 같은 뜻은 아니다. 저장할 모수·평가 모드·자료 집합·동률 정책과 재시작 상태도 함께 정한다.

선택과 최종 보고를 나눈다

검증 자료로 중단을 골랐으므로 그 최소 검증 값은 선택 과정의 영향을 받는다. 최종 test 자료로 매번 다시 중단을 고르면 독립 평가 역할을 잃는다. 최종 평가는 정해진 모형과 정책으로 별도로 수행한다.

한 작은 표의 상승은 이후 반드시 계속 악화한다는 증명이 아니다. 지표 잡음과 드문 개선에 대한 patience/min_delta 정책의 장단점을 비교한다. 실험 예산으로 멈춘 경우에도 최저 저장본이 있으면 반환할 수 있으나 중단 이유는 구별한다.

소단원 6.3

학습·검증 오차 해석

학습 오차 0 인데 새 자료의 오류가 많다면 숫자 한 개만으로 원인을 알 수 있을까?

준비 개념과 학습 목표

준비 개념

  • 오차율과 평균 손실

  • 누출은 평가 정보를 학습이나 선택에 잘못 사용하는 것, 분포는 자료가 나타나는 방식이다.

학습 목표

  • 같은 지표·평가 모드의 학습/검증 차이를 계산한다.

  • 과적합 징후와 다른 원인·분할 누출을 구별한다.

두 집단 모두 좋은 모형이 전체에서도 좋을까?

쉬운 집단 E와 어려운 집단 H의 오차율을 비교한다. 모형 A는 E에서 1/10, H에서 4/10이고 B는 E에서 2/10, H에서 5/10이다. 집단별로는 A가 10%p씩 낮다. 그러나 A를 E의 10건과 H의 90건, B를 E의 90건과 H의 10건으로 평가하면 오류는 각각 37건과 23건이다. 서로 다른 집단 구성의 전체 오차로 모형 효과를 비교하면 순위가 뒤집힌다.

동일 목표 분포가 E와 H를 각각 절반 포함한다면 표준화 오차는 A의 1/4, B의 7/20이다. 관측 표의 전체 오차 37%/23%와 다른 질문에 답한다. 이 가중 계산은 주어진 집단률을 목표에 적용한 손모형이며 실제 배포의 분포나 인과 효과를 입증하지 않는다.

오차율 0도 손실 0과 같지 않다. 실제 정답이 두 건 모두 첫 분류이고 예측 확률이 각각 (.6,.4)이면 두 건 모두 맞지만 평균 cross-entropy는 −ln(.6)이다. (.9,.1)의 두 건도 오류 0이지만 손실은 −ln(.9)로 더 낮다. 전처리 평균도 학습 자료에서만 구해야 하며 아래 분포 변경과 손실 비교에는 같은 자료·같은 평가 모드라는 조건을 둔다.

먼저 확인할 개념
  • 오차의 분모와 그룹 가중

    앞 본문의 그룹률과 전체률 구별을 서로 다른 평가 구성에서의 순위 반례에 적용한다.

  • 같은 평가 규약과 누출 방지

    앞 본문의 자료 손실·평가 모드·학습에서 추정한 전처리 조건을 확률 손실 및 평균 변환에 적용한다.

비교할 숫자의 뜻을 맞춘다

학습 목적에는 벌점이 들어갈 수 있고 학습 중 dropout 도 작동한다. 검증의 자료 손실과 학습의 전체 목적값을 바로 빼면 서로 다른 양을 비교한다. 같은 loss/집계/평가 모드로 학습 자료를 별도 평가한 값이 비교의 출발점이다.

분류 오차율은 틀린 개수/전체이고 confidence 를 반영한 cross-entropy 와 다르다. 두 모형의 오차율이 같아도 손실은 다를 수 있다. 각 지표의 분모와 전처리·클래스/그룹 구성도 기록한다.

차이에서 가능한 원인을 찾는다

학습이 낮고 검증이 높은 gap 은 학습 자료 적합이 새 자료에 그대로 옮겨지지 않은 징후다. 용량·잡음·분포 변화·누출 없는 분할·표본 크기를 조사한다. 숫자 둘만 보고 유일한 원인을 확정하지 않는다.

둘 다 높으면 학습 미완료·불충분한 표현·레이블 오류·입력 스케일 등의 가능성이 있다. 둘이 비슷하다고 둘 다 좋은 것도 아니다. 깊은 모형의 크기와 일반화는 항상 단조 관계가 아니므로 단순 더 작은 모형만이 답이라고 정하지 않는다.

평가 단위를 독립으로 나눈다

같은 사람의 거의 같은 사진을 학습과 검증에 섞으면 처음 보는 사람에 대한 평가와 다르다. 배포 목표가 새 사람인지 미래 시점인지 정하고 그룹이나 시간 기준 분할을 고려한다. 평균/정규화 기준은 학습 부분에서 추정한다.

한 번 정한 test 를 매번 설정 선택에 쓰지 않는다. 그룹별 오차와 희귀 경우도 읽되 작은 분모의 변동을 실제 확정 성능으로 확대하지 않는다. 여기의 모든 표는 가상 계산이며 실제 전세계 학습자나 네트워크 검증이 아니다.

마스크 결합, 벌점 변환 위치, 엄격 개선 장부, 평가 집단 구성의 네 계약을 이름별로 복원한다. 같은 평균·중단 시점·전체 오차 숫자만으로 학습과 일반화의 같은 의미를 인증하지 않는다.
