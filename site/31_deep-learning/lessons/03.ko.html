소단원 3.1

선형층과 활성화

직선을 여러 번 겹치면 곡선을 만들 수 있을까?

준비 개념과 학습 목표

준비 개념

  • 행벡터 x의 d개 성분과 d×h 행렬을 곱하면 h개 성분을 얻는다.

  • bias는 입력에 상관없이 더하는 상수 벡터다.

  • max(0,z)는 z가 음수면0, 양수면 그대로인 함수다.

학습 목표

  • 각 층의 차원과 bias broadcast를 확인한다.

  • affine 합성과 활성화가 추가하는 표현을 작은 식으로 설명한다.

두 입력을 섞어 세 개의 점수를 만든 뒤, 음수만 지우면 어떤 정보가 바뀔까?

하나의 사례는 특징을 담은 한 행이다. 가중치의 각 열은 그 행에서 새 성분 하나를 계산하는 규칙이다. 같은 규칙을 여러 사례에 쓰면 행 수는 유지되고 특징 수만 바뀐다. bias는 각 사례에 같은 보정값을 더한다.

ReLU는 새 성분을 서로 섞지 않고 각 칸의 음수를 0으로 바꾼다. 층을 통과할 때 표의 수뿐 아니라 행과 열의 의미를 같이 읽어야 한다. 출력 성분은 문제에 따라 회귀값이나 logit이며 숨은 값이 바로 확률은 아니다.

먼저 확인할 개념
  • 행렬곱과 전치

    행과 열의 내적, 곱의 내부 차원, 역방향 전치의 크기를 확인한다.

  • shape와 broadcasting

    사례 축과 특징 축을 구별하고 계산 가능한 shape와 의도한 의미를 따로 확인한다.

선형층이라는 이름의 실제 계산

이 단원은 예제 하나를 행벡터 x∈R^(1×d)로 쓴다. z=xW₁+b₁, W₁∈R^(d×h), b₁∈R^(1×h)이다. bias가0이 아닌 경우 수학적으로는 선형이 아니라 affine 변환이지만 딥러닝에서 관습적으로 선형층이라 부른다.

B개 예제를 행으로 모은 X∈R^(B×d)는 Z=XW₁+1_B b₁를 계산한다. 같은 b₁를 각 행에 더하는 broadcast이고 서로 다른 예제의 값을 더하는 연산은 아니다. 출력은 O=HW₂+1_B b₂, W₂∈R^(h×q), b₂∈R^(1×q)다.

활성화가 없는 합성

H=Z라면 O=X(W₁W₂)+1_B(b₁W₂+b₂)로 접힌다. 차원을 크게 만들거나 여러 affine 층을 겹쳐도 최종 입력 함수는 affine이다. 실제 최적화 과정과 파라미터 표현까지 한 층과 같다는 뜻은 아니다.

φ를 각 성분에 적용해 H=φ(Z)로 만들면 일반적으로 이 접기가 불가능하다. ReLU는 음수 영역을0으로 바꾸므로 입력 영역마다 다른 affine 식을 연결하는 꺾인 함수를 만들 수 있다. 비선형을 넣어도 모든 파라미터가 반드시 비선형 함수를 만드는 것은 아니다. 예를 들어 출력 가중치가 모두0이면 상수다.

미분의 위치와 관례

ReLU는 z>0에서 도함수1, z<0에서0이지만 z=0에서는 양쪽 기울기가 달라 보통 미분이 없다. 구현에서는0에서 보낼 값을 정해야 한다. 이 원고의 선택 코드는0으로 정한다. 이를 수학적 양쪽 도함수가0이라고 설명하지 않는다.

sigmoid σ=1/(1+exp(−z))의 도함수는 σ(1−σ)다. 유한한 실수에서 값은0과1 사이이고 양끝에 접근할수록 기울기는 작아진다. 활성화 값과 분류 확률 해석은 다르다. 숨은 ReLU 값을 확률로 읽거나 음의 출력 logit을 무효라고 판정하지 않는다.

중간 과정을 따라가는 예제

한 입력 x, 숨은 두 성분 z=(x−1,1−x), ReLU 후 h=(max(0,x−1),max(0,1−x)), 출력 o=h₁+h₂의 x=−1,1,3 결과를 구하라.

  1. 행 표기 W₁=(1,−1), b₁=(−1,1), W₂=(1,1)ᵀ, b₂=0이라 차원1→2→1이다.

  2. x=−1이면 z=(−2,2), h=(0,2), o=2다.

  3. x=1이면 z=(0,0), h=(0,0), o=0이다.

  4. x=3이면 z=(2,−2), h=(2,0), o=2다. 합은 모든 실수에서|x−1|이다.

출력2,0,2. ReLU를 제거하면 z₁+z₂=0으로 모든 입력의 출력이0이다.

조건을 바꾸어 비교하기

두 사례가 같은 층을 통과하기

X = [[1,2],[−1,1]], W₁ = [[1,0,1],[0,1,−1]], b₁ = [0,−1,1], W₂ = [[1],[2],[−1]], b₂ = 0이다. 순전파와 활성화 제거 결과를 비교하라.

  1. XW₁은 [[1,2,−1],[−1,1,−2]]다. b₁을 각 행에 더한 Z는 [[1,1,0],[−1,0,−1]]다.

  2. H는 [[1,1,0],[0,0,0]]이므로 O는 [[3],[0]]이다.

  3. 활성화를 제거하면 ZW₂는 [[3],[0]]으로 이 두 입력에서는 우연히 같다.

  4. 새 입력 [0,0]에서는 Z = [0,−1,1], ReLU 출력 −1, 활성화 없는 출력 −3으로 달라진다. 두 입력의 일치로 함수 전체가 같다고 판정하지 않는다.

배치 출력은 [3,0]ᵀ다. 두 관찰의 일치가 ReLU 제거의 일반적 동등성을 뜻하지 않는다.

비교할 점

기존 절댓값 예제에 더해 다차원 shape와 표본의 우연한 일치 경계를 함께 확인한다.

접힐 수 있는 층의 계산과 폭 제한

활성화가 없는 두 층의 W₁ = [[1],[2]], b₁ = [3], W₂ = [[4,−1]], b₂ = [1,2]를 하나로 접어라. 입력은 행벡터 [x₁,x₂]다.

  1. W₁W₂ = [[4,−1],[8,−2]]다.

  2. b₁W₂+b₂ = [12,−3]+[1,2] = [13,−1]이다.

  3. 합성 출력은 [4x₁+8x₂+13, −x₁−2x₂−1]이다. 두 출력의 입력 변화는 하나의 숨은 성분을 통해 연결되어 계수행렬 rank가 1이다.

  4. 따라서 이 폭 1 구조가 임의의 2×2 affine 계수행렬, 예컨대 단위행렬을 모두 표현한다고 말할 수는 없다.

접힌 함수는 affine이며 특정 폭은 표현 가능한 계수행렬을 제한한다.

비교할 점

층 수와 비선형 여부뿐 아니라 좁은 중간 차원의 제한을 비교한다.

종이와 본문으로 직접 해보기

위 네트워크의 x=0,2를 계산하라. d=2,h=3,q=1인 두 affine 층의 가중치와 bias를 모두 세면 학습 파라미터는 몇 개인가?

힌트 보기

각 입력에서 두 ReLU 성분을 먼저 구한다. 가중치는 dh+hq, bias는 h+q다.

풀이 보기

x0은 z(−1,1)→h(0,1)→o1, x2는 z(1,−1)→h(1,0)→o1이다. 파라미터 수2×3+3×1+3+1=13이며 입력의 두 성분은 학습 파라미터가 아니다.

오해와 반례

숨은 층이 많으면 활성화 없이도 복잡한 비선형을 표현한다.

affine 합성은 다시 affine이다. 자체 예제에서 ReLU를 없애면 깊어도 상수0이 된다. 비선형 표현 가능성과 실제 데이터에서 좋은 일반화·학습 성공은 또 다른 주장이다.

힌트 2

  2. W₂ = [1,−1]ᵀ, b₂ = 0으로 정한다.

연습 4 · 선택 심화

선택 심화는 기본 연습 뒤 더 탐구하고 싶을 때 풀어 보세요.

ReLU 입력 z = 0에서 왼쪽과 오른쪽 차분몫을 계산하고 코드의 선택 미분 0과 구별하라.

힌트 1

작은 h > 0에 대해 f(−h),f(h)를 쓴다.

힌트 2

f(−h) = 0, f(h) = h다.

풀이와 답 확인

  1. 왼쪽 차분몫 (f(−h)−f(0))/(−h)은 0이다.

  2. 오른쪽은 (f(h)−f(0))/h = 1이다.

  3. 양쪽이 다르므로 고전 미분이 없다. 역전파의 0 선택은 구현 관례다.

양쪽 미분은 불일치한다. 코드 선택값 0이 미분 존재를 증명하지 않는다.

두 층의 접기와 ReLU의 역할을 어떻게 제한해서 설명하는가?

설명 기준 확인

활성화 없는 affine 합성은 affine으로 접힌다. 활성화는 일반적으로 접기를 깨지만 특정 파라미터는 여전히 선형/상수 함수를 만들 수 있다.

한 단계 더

위 |x−1| 모형은 x<1에서1−x, x>1에서x−1이어서 두 영역에서 기울기가−1과1이다. 하나의 affine 함수 ax+b라면 모든 입력에 같은 기울기 a여야 하므로 전체에서 이를 표현할 수 없다. x1의 미분 불능은 표현 오류가 아니라 목표 함수 자체의 특징이다. 숨은 층 가중치 두 행렬의 곱에서 rank 제약은 별도라서 모든 affine 모형을 좁은 숨은층으로 표현한다는 과장도 피한다.

소단원 3.2

손실함수

맞혔는지 여부가 같은 두 예측에도 다른 학습 신호를 줄 수 있을까?

준비 개념과 학습 목표

준비 개념

  • 회귀의 목표 y는 수치, 분류의 목표는 클래스다. logit은 아직 확률이 아닌 실수 점수다.

  • ln은 자연로그다. ln1=0, ln2>0이다.

  • 평균은 합을 표본 수로 나누는 연산이다. 출력 성분까지 평균하는지 별도로 정한다.

학습 목표

  • 출력 해석에 맞는 회귀·분류 손실을 구성한다.

  • 정규화와 logit 미분·수치 안정성을 확인한다.

두 답의 오차를 줄이고 싶다면, “맞았다” 한 글자 대신 어떤 수를 줄일까?

회귀에서는 목표와 예측의 차이를 잔차로 기록하고 제곱해 부호 상쇄를 막는다. 분류에서는 점수 logit을 확률로 바꿔 정답에 둔 확률을 본다. 같은 함수 이름이어도 어느 축을 평균했는지에 따라 수치와 기울기 크기가 달라진다.

이 단원의 회귀 손실은 1/(2B) 배율이며 q개의 출력은 합한다. 분류는 합이 1인 목표에 대한 자연로그 교차엔트로피다. 결과는 합성 예제의 산술이며 실제 모델 평가나 확률 보정 실험은 아니다.

먼저 확인할 개념
  • 손실과 정상방정식

    잔차 제곱, 양의 상수 배율과 미분 계수의 관계를 복습한다.

  • shape와 broadcasting

    사례 축과 특징 축을 구별하고 계산 가능한 shape와 의도한 의미를 따로 확인한다.

무엇을 평균하는가

회귀 출력 O,Y∈R^(B×q)에 대해 이 원고는 L=(1/(2B))Σ_iΣ_j(O_ij−Y_ij)²를 쓴다. 예제 수 B만 평균하고 q 출력 성분은 합한다. 모든 Bq 성분 평균 MSE와는 상수배가 다르며 gradient도 그만큼 달라진다.

이 정의의 ∂L/∂O=(O−Y)/B다. 1/2는 제곱 미분의2를 없애는 관례이며 정확도를 자동으로 좋게 만드는 장치가 아니다. 목표 단위가 달라 큰 성분이 손실을 지배하면 목적에 맞는 스케일/가중치를 명시해야 한다.

분류 점수에서 음의 로그 확률로

q≥2 상호 배타 클래스에 logit z_j를 주면 p_j=exp(z_j)/Σ_k exp(z_k)다. one-hot 목표 y의 합은1이고 손실 ℓ=−Σ_j y_j ln p_j=lnΣ_k exp(z_k)−Σ_j y_jz_j다. 유한 logit에서는 각 p가0보다 크고1보다 작다.

미분하면 ∂ℓ/∂z_j=p_j−y_j다. argmax만 쓰는 맞음/틀림 점수는 점수가 조금 바뀌어도 같은 값을 가져 이 연속 학습 신호를 대신하지 못한다. softmax는 상호 배타 모델이고 동시에 여러 label이 참인 문제는 별도 출력·손실 계약이 필요하다.

안정적인 계산과 평가의 분리

m=max_j z_j라면 ℓ=m+lnΣ exp(z_j−m)−z_target로 계산한다. 빼는 m은 softmax 확률을 바꾸지 않지만 logsumexp 자체는 m만큼 이동한다. 큰 exp(z)의 overflow 위험을 줄이는 식이며 모든 유한 정밀도 문제를 없앤다는 보장은 아니다.

훈련 손실이 작아도 새 입력의 성능, 확률 보정, 공정한 오류 분포는 별도 평가 대상이다. 같은 argmax라도 p_target이1/2인지3/4인지에 따라 손실이 다르다. 아래는 자체 가상값의 수학 계산이며 실제 분류 실험/검증 데이터 평가를 한 것이 아니다.

같은 분류 결정, 다른 학습 신호

세 클래스 logit A = (ln 2,0,0), B = (ln 8,0,0), 목표는 첫 클래스다. 두 경우의 결정, 확률, 손실과 logit gradient를 비교하라.

  1. A의 확률은 (1/2,1/4,1/4), B는 (4/5,1/10,1/10)이다. 둘 다 첫 클래스가 유일한 최댓값이다.

  2. 손실은 A가 ln 2, B가 ln(5/4)다. 정답 확률이 큰 B의 손실이 작다.

  3. gradient는 A (−1/2,1/4,1/4), B (−1/5,1/10,1/10)이며 각 합은 0이다.

같은 argmax여도 정답 확률과 연속 학습 신호가 다르다.

비교할 점

기존 두 클래스/동점 사례와 달리 두 결정이 모두 유일하게 맞은 상황에서 손실 차이를 보여 준다.

잘못된 shape가 만든 가짜 오차

회귀 예측 O = [[2],[5]]의 shape는 (2,1)인데 목표를 [2,5]의 (2,)로 전달한다. 원소별 뺄셈의 broadcast 결과와 단원 손실을 계산하라.

  1. 부족한 목표 앞축을 1로 보면 (2,1)−(1,2)가 (2,2)로 확장된다.

  2. 잔차는 [[0,−3],[3,0]]이다. 제곱합 18, 이를 2B = 4로 나누면 잘못된 L = 9/2다.

  3. 목표를 [[2],[5]]로 정하면 자기 사례끼리만 비교되어 잔차 0과 L 0이다.

broadcast가 성공했어도 사례 간 교차 비교를 만들었다. shape 계약을 먼저 확인한다.

소단원 3.3

미니배치 역전파 구현

각 층의 모든 파라미터에 대한 미분을 한 번의 역순 계산으로 얻을 수 있을까?

준비 개념과 학습 목표

준비 개념

  • 행렬 곱 AB의 차원과 transpose를 복습한다. Hadamard ⊙는 같은 위치끼리 곱한다.

  • chain rule은 작은 변화가 합성 경로를 통과할 때 국소 미분을 곱하는 규칙이다.

  • 코드는 선택 경로다. 작은 행렬은 종이로 같은 연산을 확인할 수 있다.

학습 목표

  • 행 미니배치의 모든 gradient 차원을 유도한다.

  • 갱신 전 가중치·중간값을 사용하며 평균을 한 번 적용하는 코드를 읽는다.

숨은 성분 둘 중 하나만 켜졌다면, 거꾸로 보낸 오차는 어느 길을 지나갈까?

출력의 작은 변화가 손실을 얼마나 바꾸는지부터 시작해 각 연결의 국소 미분을 곱한다. ReLU의 음수 입력 경로는 0이 되고, 같은 bias를 쓰는 여러 사례의 영향은 더한다. 이때 순전파 때 저장한 값과 가중치를 그대로 사용한다.

아래 계산은 B = 2, d = 1, h = 2, q = 1인 정확 산술이다. 학습률을 적용하기 전에 모든 gradient를 만든다. 표의 결과는 실제 학습이나 GPU 출력이 아니라 독립적으로 계산할 수 있는 기대값이다.

먼저 확인할 개념
  • 연쇄법칙

    손실의 변화가 중간 연산을 통과하는 국소 미분과 공유 변수 기여의 합을 연결한다.

  • 기울기 검사

    같은 고정 목적함수의 함수값 차분과 미분을 비교하되 꺾임과 반올림을 구별한다.

저장한 순전파를 거꾸로 읽기

입력 X, Z=XW₁+b₁, H=ReLU(Z), O=HW₂+b₂와 L=(1/(2B))Σ(O−Y)²를 저장한다. δO=(O−Y)/B를 시작으로 G_W₂=HᵀδO, G_b₂=행 합 δO다. δH=δO W₂ᵀ, δZ=δH⊙1_(Z>0)이다. 0에서는 선택한 값0을 쓴다.

앞층 gradient는 G_W₁=XᵀδZ, G_b₁=행 합 δZ다. W₁ gradient는 d×h, W₂ gradient는 h×q로 원래 파라미터와 같아야 한다. bias는 모든 예제가 공유하므로 역방향에서 예제별 기여를 더한다. δO에 이미1/B가 있으므로 뒤에서 다시 나누지 않는다.

갱신 시점과 구현 계약

모든 gradient는 같은 갱신 전 파라미터에서 평가해야 한다. W₂를 먼저 바꾼 다음 δH를 계산하면 원래 L의 chain rule과 다른 혼합값이 된다. gradient를 먼저 전부 만든 뒤 θ_new=θ−ηG를 동시에 적용한다. 원고의 코드는 새 배열을 만들어 입력 파라미터를 제자리 변경하지 않는다.

선택 NumPy 코드는 X/Y/W₁/W₂가 차원에 맞는2차원 유한 float 배열, b₁/b₂가1차원 길이h/q 배열, B>0, 유한 양의 η라는 계약을 전제로 한다. 타입/shape/비유한값 검사는 호출자 책임이며 모든 잘못된 입력을 처리하는 제품 API가 아니다. loss는 갱신 전 값이고 return의 weights는 갱신 후 값이다. 실행·성능 확인은 아직 없다.

import numpy as np

def mlp_step(X, Y, W1, b1, W2, b2, eta):
    # Contract: finite floating arrays of stated shapes, B>0, eta>0.
    B = X.shape[0]
    Z = X @ W1 + b1
    H = np.maximum(0.0, Z)
    O = H @ W2 + b2
    E = O - Y
    loss = np.sum(E * E) / (2 * B)
    dO = E / B
    gW2 = H.T @ dO
    gb2 = dO.sum(axis=0)
    dZ = (dO @ W2.T) * (Z > 0)  # chosen value 0 at Z=0
    gW1 = X.T @ dZ
    gb1 = dZ.sum(axis=0)
    weights = (W1 - eta*gW1, b1 - eta*gb1,
               W2 - eta*gW2, b2 - eta*gb2)
    gradients = (gW1, gb1, gW2, gb2)
    return loss, weights, gradients

계산 검사를 계획하기

표본 두 개의 손계산은 배치 평균, transpose, bias 합과 갱신 시점 오류를 찾기 좋다. 작은 방향 v에서 [L(θ+εv)−L(θ−εv)]/(2ε)와 G·v를 비교하는 유한차분 검사도 가능하지만 ε가 너무 작으면 상쇄, 너무 크면 근사 오차가 생긴다.

ReLU 경계를 넘는 검사는 미분 불능과 구현 bug를 구별해야 한다. 역전파는 주어진 그래프의 미분 계산이고 경사하강의 수렴·일반화 보장이 아니다. 입력 데이터의 예측 정확도와 GPU 실행 여부도 별도 확인 대상이다.

다른 문제에 적용하기

소단원 3의 두 사례와 이전 파라미터를 쓰되 출력 목적함수를 모든 표본 평균 대신 첫 사례에 3/4, 둘째에 1/4 가중치를 주는 L_w = (1/2)[(3/4)(O₁−Y₁)²+(1/4)(O₂−Y₂)²]로 바꾼다. 순전파, δO, 모든 gradient를 구하고, “표본이 두 개라 마지막에 다시 2로 나눈다”는 변경안을 평가하라. 실제 설치/학습은 필요 없다.

힌트 1

가중치의 합은 1이며 손실 정의가 이미 평균 역할을 정했다.

힌트 2

잔차 (1,−1)에 각각 3/4와 1/4를 곱해 δO를 만든다.

풀이와 답 확인

  1. 기존 순전파 O = (3,4)ᵀ, Y = (2,5)ᵀ와 mask를 유지한다. 손실은 (1/2)(3/4+1/4) = 1/2다.

  2. δO = (3/4,−1/4)ᵀ다.

  3. G_W₂ = [−1/2,3/4]ᵀ, G_b₂ = 1/2다.

  4. δZ 행은 [0,9/4]와 [−1/2,0]이다.

  5. G_W₁ = [−1,−9/4], G_b₁ = [−1/2,9/4]다. 같은 이전 파라미터를 썼다.

  6. 표본 수로 다시 나누면 주어진 L_w의 gradient가 아니라 절반으로 축소된 값이다. 가중치는 실제 비용 선택을 뜻할 수 있으나 새 데이터 성능을 계산하지 않았다.

손실 값은 우연히 기존 1/2와 같지만 gradient는 가중 목표에 따라 다르다. 두 가중치에 의한 평균이 정의에 이미 들어 있으므로 다시 B로 나누지 않는다.

해결한 뒤 점검할 것

  • shape와 기존 ReLU mask를 보존한다.

  • 손실의 표본 가중치를 δO에 한 번만 적용한다.

  • 모든 가중치/bias gradient를 동일 이전 점에서 구한다.

  • 같은 손실 값이 같은 gradient라는 오해를 반박한다.

  • 합성 산술을 실제 학습/일반화 증거로 주장하지 않는다.
