Subtopic 2.1

The Chain Rule

If an input x travels along two branches to the same loss, which path’s influence should we count?

Preparation and learning goals

Preparation

  • A function determines an output from an input. f′(a) is lim(h→0)[f(a+h)−f(a)]/h, the instantaneous slope. The derivative of x² is 2x, and the derivative of a constant is 0.
  • The partial derivative ∂L/∂x varies x while holding the other independent inputs fixed. The column gradient ∇L stacks all partial derivatives.
  • For F:ℝⁿ→ℝᵐ, the Jacobian J_F has shape m×n, with entry (i,j) equal to ∂F_i/∂x_j. Real differentiability in an open neighborhood means a linear approximation F(a+h)=F(a)+J_F(a)h+o(||h||).

Learning goals

  • Distinguish node values from local derivatives in a computational graph.
  • Multiply along paths and add contributions from merging paths in a differentiable composition.
  • Explain shapes, transposes, and the exception at a kink in the vector chain rule.

Passing a small change through successive computations

For the product u=xy, holding y fixed gives ∂u/∂x=y. In the sum v=u+x, each local derivative is 1. The final operation L=v² has derivative 2v. A local derivative refers to the immediately preceding input of that node; the gradient of the entire loss must also connect the influences of later nodes.

Both the path through u and the direct path into v carry the influence of x to L. For L=(xy+x)², ∂L/∂x=2v·y+2v·1=2v(y+1). Counting only one path changes the partial derivative of the actual function. Do not confuse the computed loss L with ∂L/∂x.

The composition theorem and shapes

If F is real differentiable at a, G is real differentiable at F(a), and their composition is defined in a neighborhood, then D(G∘F)(a)=DG(F(a))DF(a). In Jacobian notation, J_(G∘F)=J_G J_F. The weaker condition that partial derivatives merely exist at one point does not automatically justify this theorem. Continuity of all partial derivatives in a neighborhood is a sufficient condition for differentiability.

For the scalar L=G(F(x)), the column gradient is ∇_xL=J_Fᵀ∇_zG, where z=F(x). Multiplying n×m by m×1 gives n×1. Matching shapes is necessary but is not itself a proof that the formula is valid. Check domains too: a division node needs a nonzero denominator, and a log node needs a positive input.

Shared values and the limits of automatic differentiation

If several uses of one variable are temporarily treated as separate independent inputs and then tied back to the same variable, their partial derivatives add. For example, x²=x·x has contributions x+x=2x from its two input slots. If the same bias b is added to every batch item, sum all contributions to b. For a mean loss, include the previously specified averaging factor as well.

ReLU r(z)=max(0,z) has derivative 1 for z>0 and 0 for z<0, but no classical derivative at 0. A software rule that returns a particular value at 0 is not a proof that a derivative exists. Automatic differentiation connects the rules of recorded operations. It does not automatically verify integer selections, disconnected graphs, unsupported operations, or incorrect custom derivative rules.

A worked example, step by step

At real inputs x=2,y=3, find the values and both input partial derivatives for u=xy, v=u+x, L=v². All operations use an exact real-arithmetic model.

  1. Compute the values in order: u=2·3=6, v=6+2=8, L=8²=64.
  2. The last local derivative is dL/dv=2v=16, with ∂v/∂u=1 and derivative 1 for the direct x input slot of v.
  3. The product-path contribution to x is 16·1·y=48, and its direct-path contribution is 16·1=16. Adding gives ∂L/∂x=64.
  4. The influence of y uses only the product path, so ∂L/∂y=16·1·x=32. Differentiating the expanded L=x²(y+1)² also gives (64,32).

L=64, ∇L=(64,32)ᵀ. The equality of the value 64 and the first gradient component 64 is a coincidence at these inputs.

Try it with paper and the lesson

Evaluate the same graph at x=1,y=−1. Separately, on paper find ∂Q/∂b for Q=(x₁+b)²+(x₂+b)², with fixed x₁=1,x₂=2 and shared bias b=1.

Show hint

If v is 0, the last derivative is also 0. Add the influences of both squared terms on the shared b.

Show solution

In the first case, u=−1,v=0,L=0, and both partial derivatives are 0. Q=2²+3²=13 and ∂Q/∂b=2·2+2·3=10. For the mean Q/2, the derivative is 5. No actual batch or program was run.

Misconception and counterexample

Once numbers fill a computational graph, the loss gradient equals those numbers.

At x=1,y=0, L=1 but ∂L/∂x=2. Values and gradients are different. Also, using only 48 in the branched example misses the direct contribution 16 and fails to obtain the correct 64.

Check your understanding

For L=v² at v=−2, is the local derivative 4?

Show answer and reasoning

It is −4.

2v=−4, unlike the function value v²=4.

If J_F is 3×2 and ∇_zG is 3×1, what is the input-gradient shape?

Show answer and reasoning

2×1.

J_Fᵀ is 2×3, so J_Fᵀ∇_zG is 2×1.

If automatic differentiation returns 0 for ReLU at 0, does a classical derivative exist there?

Show answer and reasoning

No.

The left slope 0 and right slope 1 differ, so there is no derivative. The returned value is a separate choice of rule.

Explore further

Further study: examine the chain rule’s remainder. Suppose F(a+h)=F(a)+Ah+r(h), with ||r(h)||/||h||→0, and G(z+k)=G(z)+Bk+s(k), with ||s(k)||/||k||→0. For k=Ah+r(h), ||k||=O(||h||) and k→0. The composition increment is BAh+Br(h)+s(k), and the last two terms are o(||h||) (when k=0, s(0)=0). Thus the linear part is BA. Summation at branches follows by applying this linear approximation to independent slots and then inserting the same increment into shared slots. This proof assumes real differentiability; the existence of only some partial derivatives at one point is not a substitute.

Subtopic 2.2

Forward- and Reverse-Mode Differentiation

Should the change along one input direction and all input gradients of one loss be computed in the same way?

Preparation and learning goals

Preparation

  • A finite DAG is an acyclic computational graph. Each node is a function of preceding node values; values can be evaluated in topological order and influences propagated in reverse order.
  • For F:ℝⁿ→ℝᵐ, J has shape m×n. For an input direction v∈ℝⁿ, Jv is m×1; for output weights c∈ℝᵐ, Jᵀc is n×1.
  • Forward value evaluation and forward-mode differentiation are different. The former computes function values; the latter computes values together with sensitivity in a chosen direction. Here we assume differentiable real operations in an open neighborhood and a fixed finite graph.

Learning goals

  • Distinguish a forward-mode direction seed from a reverse-mode output seed.
  • Accumulate contributions arriving at shared nodes.
  • Explain the purposes, propagation counts, and memory conditions of JVPs and VJPs.

Attaching a directional derivative to each value

Consider the inputs x(ε)=x+εv_x,y(ε)=y+εv_y. Use a dot to denote their directional derivatives: ẋ=v_x,ẏ=v_y. For u=xy, u̇=y ẋ+x ẏ; for v=u+x, v̇=u̇+ẋ. Pass each node’s value and sensitivity in this one direction from front to back.

Finally, for L=v², L̇=2v v̇. This is ∇Lᵀ(v_x,v_y)ᵀ, not both components of the full gradient obtained at once. Using the input standard-basis seeds (1,0) and (0,1) separately gives the two partial derivatives. For a vector-valued F, one likewise obtains Jv for one direction.

Propagating loss influence backward

In reverse mode, seed the scalar loss with L̄=1 and compute the derivatives ∂L/∂node value that it propagates. L=v² gives v̄=2v; v=u+x sends v̄ to ū and adds v̄ directly to x̄. From u=xy, add y ū to x̄ and x ū to ȳ. The shared input x receives the sum of two contributions.

For general output F and a fixed seed c, the reverse result Jᵀc is the gradient of the scalar cᵀF. Seeding every output with 1 gives the gradient of the output sum, not the entire m×n Jacobian. Also distinguish old accumulation buffers across repeated calls from branch accumulation within one graph. The paper rule below starts from 0 and collects this graph’s contributions.

Choosing an appropriate direction

To form the full Jacobian of n inputs and m outputs using basis seeds, the basic comparison is n forward-mode JVPs versus m reverse-mode VJPs. Reverse mode is natural for the gradient of a single-output loss with many parameters. In a model where differentiating each primitive operation costs the same order as the original operation, propagation for one seed has the same order of cost as graph evaluation.

Reverse mode stores or recomputes earlier values needed by local derivatives. Time and memory constants and checkpointing strategies are separate questions; this is not a measured conclusion that it is faster on every device. With a real API, check tangent shapes, dtypes, devices, and operation support. The beta label in the PyTorch tutorial that was read is a statement in the documentation; this unit did not execute that version.

A worked example, step by step

At x=2,y=3, differentiate u=xy,v=u+x,L=v² using forward seed (1,0), then find the full gradient by reverse mode.

  1. The values are u=6,v=8,L=64, and the input direction is ẋ=1,ẏ=0.
  2. In forward mode, u̇=3·1+2·0=3, v̇=3+1=4, and L̇=16·4=64.
  3. In reverse mode, L̄=1 gives v̄=16 and ū=16. Accumulate the product-path 48 with the direct 16 at x, and send 32 to y.
  4. The inner product of reverse result (64,32)ᵀ with direction (1,0) is 64, matching forward mode. A single JVP did not produce the second component 32.

The forward JVP is 64 and the reverse gradient is ∇L=(64,32)ᵀ; their meaning differs from the function value 64.

Try it with paper and the lesson

For F(x,y)=(xy,x+y), at (x,y)=(2,3) use direction d=(1,−1) and output seed c=(2,1) to find Jd and Jᵀc. Separately, find the reverse-mode gradient of f(x)=x·x+x at x=2.

Show hint

The first row of J is (y,x), and the second is (1,1). Do not overwrite contributions from slots that use the same x.

Show solution

J=[[3,2],[1,1]], Jd=(1,0)ᵀ, and Jᵀc=(7,5)ᵀ. Also cᵀJd=2 equals (Jᵀc)ᵀd=2. For f, the value is 6, and the gradient is 5 after adding the two product-slot contributions 2+2 and the direct 1. These are all paper calculations.

Misconception and counterexample

Setting all reverse-mode seeds to 1 gives the full Jacobian.

For F=(xy,x+y), seed (1,1) gives only Jᵀ(1,1)=(4,3)ᵀ. The full J is 2×2; summing the two output gradients does not distinguish its rows.

Check your understanding

What derivative of L does the forward seed (0,1) give?

Show answer and reasoning

∂L/∂y.

All other input directions are 0 and the y direction is 1, so the JVP is that partial derivative.

If two contributions to a shared input are 2 and 3, may the last overwrite the result with 3?

Show answer and reasoning

No. Add them to get 5.

The multivariable chain rule requires a sum over paths arriving at the same input.

Is one reverse pass for a scalar loss necessarily faster on every device?

Show answer and reasoning

There is no such guarantee.

A propagation-count and asymptotic model is different evidence from actual memory, support, devices, and execution time.

Explore further

Further study: the forward rule for a node z=φ(a₁,…,a_k), ż=Σ_j(∂φ/∂a_j)ȧ_j, is the multivariable chain rule. Reverse mode adds z̄∂φ/∂a_j to each ā_j. Use the inductive invariant that contributions from already processed successor nodes have been accumulated in reverse topological order. When a node is processed, contributions from every path to it are passed onward, yielding the exact Jᵀc at the final inputs. If the same value occupies two input slots, add each slot’s term separately. A finite DAG and differentiable operations are conditions of the proof; it does not guarantee a classical derivative at a branch boundary or correctness of user-supplied local rules.

Subtopic 2.3

Gradient Checking

If two gradient numbers are close at one point, is the entire differentiation implementation correct?

Preparation and learning goals

Preparation

  • The centered difference D_hf(a)=[f(a+h)−f(a−h)]/(2h), h>0, approximates a derivative. Both evaluation points must lie in the domain.
  • A coordinate partial-derivative check holds the other coordinates fixed and uses a±h e_j. An independent numerical comparison must use the same loss definition, mean/sum reduction, fixed data, and parameters.
  • Exact real arithmetic and floating-point arithmetic differ. Cancellation when subtracting similar values, rounding, nondifferentiable kinks, and changing randomness or state affect a check’s results.

Learning goals

  • Distinguish finite-difference error from the actual derivative.
  • Specify absolute and relative scales and the conditions at zero or a kink.
  • Explain the local evidence and limitations of passing a gradient check.

Approximating the same derivative by a different route

Comparing graph differentiation with a centered difference of function values, a different computation, can reveal missing path contributions or coefficients. Change only the coordinate being checked by ±h and hold all other conditions fixed. This is a separate approximation obtained from two loss-value evaluations, not a check that simply rereads the library’s returned gradient.

If f is C³ in a neighborhood and the absolute third derivative is bounded by M, the centered-difference truncation error is at most Mh²/6. This term shrinks with h in exact arithmetic. But rounding in actual operations changes the function values themselves, so h cannot be made arbitrarily small without care.

Specify scales together with reproducibility conditions

First record |g−D|; if useful, also use |g−D|/max(|g|,|D|). If both are 0, the relative expression is 0/0, so handle agreement separately. Near-zero values should not be judged by the relative expression alone; specify an absolute tolerance too. Tolerances are choices based on dtype, expected error, and the problem’s scale, not a theorem common to every neural network.

The two loss evaluations and the graph gradient must use the same data, state, and objective. Disabling dropout or augmentation checks only that fixed function, not the entire original stochastic model. If the same random realization is deliberately fixed, record which realization is differentiated. An identical seed number alone does not guarantee perfect reproducibility across every device and operation order.

Passing at one point and encountering a kink

At 0, f(x)=|x| has centered difference 0 for every h>0. Its left and right derivatives are −1 and 1, however, so no classical derivative exists there. Agreement with an automatic-differentiation choice of 0 at this point does not certify a nonexistent derivative. Differences that cross a ReLU boundary require the same caution.

Examining more parameters, points, and h values offers more opportunities to find counterexamples, but a finite check does not become a proof over the entire domain. For example, an incorrect implementation that always returns 12 as the gradient of x³ matches the correct derivative 12 at x=2, but differs from 3 at x=1. Checking the data loss and regularization term separately can also reveal which term’s error is being hidden.

A worked example, step by step

In exact real arithmetic, compare centered differences of f(x)=x³ at a=2 using h=1/10 and 1/100 with the exact derivative 12. Also compare the incorrectly proposed gradient 11.

  1. The exact derivative is f′(2)=3·2²=12. For h=1/10, f(2.1)=9.261 and f(1.9)=6.859.
  2. Divide the difference 2.402 by 2h=0.2 to obtain D=12.01. Its absolute difference from the exact derivative is 0.01=h².
  3. The identity (2+h)³−(2−h)³=24h+2h³ gives D=12+h². For h=1/100, it is 12.0001, with error 0.0001.
  4. Its differences from the incorrect 11 are 1.01 and 1.0001, respectively. Reducing h does not make it converge to 11. These are exact-arithmetic paper calculations, not actual outputs of a floating-point program.

D_0.1=12.01 and D_0.01=12.0001. They converge to the exact derivative 12 and expose the error in 11 at this point.

Try it with paper and the lesson

Expand the centered difference for f(x)=x² at a=3 and any h>0. Also evaluate it for |x| at a=0, and explain whether the two results provide the same kind of evidence for a derivative.

Show hint

(a+h)²−(a−h)²=4ah. For the absolute value, the function values on the two sides are equal.

Show solution

For the square, the centered difference is 6 in exact arithmetic and agrees with derivative 6 for every h. For the absolute value, it is 0, but no derivative exists at 0. Because the differentiability conditions differ, the two numerical agreements cannot be treated as the same certification. No learner activity or code was run.

Misconception and counterexample

If the check’s numbers agree as h is reduced, the whole differentiation implementation is proved correct.

Approximation at one point in exact arithmetic differs from finite-precision rounding. An incorrect implementation that always returns 12 for x³ passes at x=2 but fails at x=1. At 0, |x| has difference 0 but no derivative, so first check the conditions of the test itself.

Check your understanding

Is the centered difference of x³ at x=2,h=0.1 exactly 12?

Show answer and reasoning

It is 12.01.

The exact-arithmetic formula 12+h² retains truncation error 0.01.

If g=D=0, should the relative-error expression compute 0/0?

Show answer and reasoning

Handle agreement separately.

The denominator is 0, so the relative expression is undefined. Specify an absolute scale separately for near-zero values too.

Does checking with dropout disabled verify every path of the original random operation?

Show answer and reasoning

No.

Only derivatives of the fixed function and the path actually used were compared. Other realizations, states, and devices require additional evidence.

Explore further

Further study: in a C³ neighborhood, Taylor’s remainder gives f(a±h)=f(a)±hf′(a)+h²f″(a)/2±h³f‴(ξ_±)/6. Subtract and divide by 2h to obtain error h²[f‴(ξ_+)+f‴(ξ_−)]/12, whose absolute value is at most Mh²/6. In a simple model with an added absolute error ≤η in each function-value evaluation and exact division, the additional difference error is at most η/h. The total bound Mh²/6+η/h shows the tradeoff between small and large h. Actual η depends on inputs, dtypes, and operations; not every error follows this model. A directional difference compares ∇f(a)ᵀd, so one direction cannot rule out errors in every coordinate.
