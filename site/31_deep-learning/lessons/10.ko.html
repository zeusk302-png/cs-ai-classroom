소단원 10.1

seq2seq

입력 문장은 세 단어인데 출력은 네 단어라면 위치를 어떻게 맞출까?

준비 개념과 학습 목표

준비 개념

  • 토큰과 임베딩

  • 순환 상태

  • 조건부확률과 교차엔트로피

학습 목표

  • 입력과 출력의 길이를 별도로 다룬다.

  • teacher forcing의 입력 이동을 작성한다.

  • 훈련과 생성의 조건 차이 및 패딩 손실을 구별한다.

EOS가 없는 접두부를 높은 확률만 보고 완료 문장으로 뽑아도 될까?

앞 본문은 정답을 한 칸 옮겨 훈련했다. 새 자체 분포에서 BOS 다음은 A가 0.6, B가 0.4다. 접두부 A 뒤에는 EOS가 0.2, A가 0.8이고, B 뒤에는 EOS가 0.9, A가 0.1이다. 각 줄은 합이 1인 조건부 분포다. 첫 선택 A의 확률 0.6과 완료 후보 [B,EOS]의 확률 0.36은 서로 다른 길이와 완료 상태를 가리킨다.

두 토큰 안에 종료한 후보만 비교하면 [A,EOS]는 0.12, [B,EOS]는 0.36이다. 탐욕 생성은 첫 A 뒤에도 더 큰 A를 골라 [A,A]에 도달한다. 이 접두부 확률 0.48은 종료 확률이 아니다. 두 토큰 한도에서 EOS가 없으면 최대 길이 도달로 보고하며, 완료 문장의 의미 평가와 분리한다. 세 번째 이후 분포는 주어지지 않아 전체 길이의 최적 문장을 주장할 수 없다.

정답 [B,EOS]의 teacher forcing 입력은 [BOS,B]다. 두 목표 확률 0.4와 0.9로 손실 합은 −ln(0.36)이다. 탐욕 경로의 두 번째 입력 A를 훈련 입력 B와 섞어 EOS 확률 0.9를 적용하면 조건이 다른 값을 이어 붙인다. 아래 분포와 결과는 새 모형의 손추적이며 번역기 실행이 아니다.

먼저 확인할 개념
  • 이전 토큰에 조건부인 출력

    이동한 정답 입력과 자기 출력 입력을 별도 경로로 기록한다.

  • 정렬표와 실제 번역의 구분

    가상 내부 계산만으로 완성 문장의 의미 평가를 주장하지 않는다.

두 순서를 연결하되 길이를 강제하지 않는다

seq2seq는 입력 순서 x1,…,xT를 보고 출력 순서 y1,…,yL을 만드는 학습 문제다. T와 L은 같을 필요가 없다. 인코더는 입력 토큰의 벡터를 처리해 상태나 문맥을 만들고 디코더는 문맥과 이전 출력들을 사용해 다음 토큰의 조건부 분포를 만든다. 번역뿐 아니라 요약처럼 순서가 바뀌거나 길이가 달라지는 문제에도 적용할 수 있다.

자기회귀 모형은 P(y1,…,yL|x)=∏t P(yt|y1,…,y(t−1),x)로 표현한다. 출력 종료 토큰 EOS도 순서의 일부로 다룬다. 단순 RNN 방식은 인코더 마지막 상태 하나를 문맥으로 쓰지만, 모든 seq2seq가 하나의 고정 벡터만 쓰는 것은 아니다. attention은 입력의 여러 상태를 출력 단계마다 참조할 수 있게 한다.

정답을 한 칸 옮겨 넣어 훈련한다

teacher forcing은 정답 출력의 앞부분을 디코더 입력으로 제공한다. 정답이 [A,B,EOS]면 입력은 [BOS,A,B], 예측 목표는 [A,B,EOS]다. BOS는 시작을 알려 주고 EOS는 종료를 알려 준다. 현재 맞혀야 할 정답 토큰을 같은 단계의 입력에 직접 넣는 것과 구별한다.

각 단계에서 목표 토큰에 배정한 확률을 p라 하면 손실은−ln p다. 유효 토큰의 손실을 합하거나 유효 개수로 나누는 규약을 정한다. 여러 길이를 한 배치에 맞추기 위한 PAD는 번역 정답이 아니므로 보통 손실에서 제외한다. EOS는 유효한 목표이며 PAD와 혼동하지 않는다.

생성할 때는 정답 앞부분이 주어지지 않는다

실제 생성은 BOS에서 시작해 모형이 고른 토큰을 다음 입력으로 사용한다. 탐욕 선택은 각 단계의 가장 높은 확률을 고르지만 전체 문장 확률의 최댓값을 보장하지 않는다. EOS 또는 정한 최대 길이 같은 종료 규칙을 명시한다. 정답을 계속 입력한 평가와 실제 자기 출력으로 생성한 평가는 조건이 다르다.

초기 오답이 다음 입력으로 전달되면서 후속 분포도 달라질 수 있다. 손실이 작다는 관찰만으로 새 문장의 의미·사실·문법을 모두 맞췄다고 결론 내리지 않는다. 아래 확률은 실제 번역기의 출력이 아니라 훈련과 생성 규약을 연습하기 위해 주어진 가상 값이다.

중간 과정을 따라가는 예제

정답[A,B,EOS,PAD]에서 앞3개만 유효하다. teacher forcing 입력과 목표를 적고 유효 목표 확률이1/2,1/4,1/2일 때 합 손실과 유효 평균 손실을 구하라.

  1. 정답 유효 부분은[A,B,EOS]이고 훈련 입력은[BOS,A,B], 목표는[A,B,EOS]다.

  2. 패딩까지 길이4로 담으면 입력[BOS,A,B,EOS], 목표[A,B,EOS,PAD]이며 마지막 위치의 손실을 제외한다.

  3. 유효 세 손실은 ln2,ln4,ln2다. 합은 ln16=4ln2다.

  4. 유효 평균은(4/3)ln2≈.9242다. 마지막 PAD 확률은 이 합과 평균에 포함하지 않는다.

입력은 목표를 한 칸 옮긴 형태이며 합4ln2, 평균(4/3)ln2다. 실제 모형 실행이나 번역 성능 결과는 아니다.

조건을 바꾸어 비교하기

탐욕 경로는 종료 후보와 다르다

두 번 탐욕 선택하고, 두 토큰 안의 최선 완료 후보와 비교하라.

  1. BOS에서 A를 고른다. A 뒤에서는 EOS 대신 A를 고른다.

  2. [A,A]는 확률 0.48인 미완료 접두부다. 완료 후보 중에는 [B,EOS]의 0.36이 크다.

탐욕 접두부와 최선 완료 후보는 다른 결과이며 둘 다 전체 무한 길이 최적화 결과가 아니다.

비교할 점

앞 본문의 두 후보 반례에 한도와 미완료 상태를 추가한다.

정답 경로와 다른 완료 경로의 손실

정답 [B,EOS]를 teacher forcing으로 평가한 손실과 별도 [A,EOS] 경로의 손실을 적어라.

  1. 정답 앞부분 경로의 곱은 0.4×0.9=0.36이다.

  2. A 경로에서 EOS를 평가한 곱은 0.6×0.2=0.12다.

합 손실은 각각 −ln(0.36), −ln(0.12)다. EOS 조건부 확률만 서로 교환하지 않는다.

비교할 점

목표 문자열, 접두부와 조건부 확률의 소속을 기록한다.

종이와 본문으로 직접 해보기

같은 유효 손실에서 전체 저장 길이4로 잘못 나누면 평균은? 첫 생성 토큰이 정답A 대신C면 두 번째 입력은 무엇인가? teacher forcing과 비교하라.

풀이 보기

잘못된 평균은 ln2≈.6931로 유효 평균보다25% 낮다. 자기회귀 생성의 둘째 입력은C지만 teacher forcing에서는A다. 이어지는 분포가 같다고 가정하지 않는다.

오해와 반례

teacher forcing은 생성할 때도 정답 토큰을 받을 수 있으므로 초기 실수가 후속 출력에 영향을 주지 않는다.

생성에서는 자기 출력을 입력으로 쓴다. 정답 앞부분을 받은 훈련 조건과 달라서 실수가 누적될 수 있다.

연습 1 · 값과 상태 예측

BOS 확률만 A가 0.3, B가 0.7로 바꾼다. 나머지 분포는 그대로다. 두 번 탐욕 결과와 확률은?

힌트 1

첫 단계에서 B를 고른다.

힌트 2

B 뒤의 더 큰 확률은 EOS의 0.9다.

풀이와 답 확인

  1. 출력은 [B,EOS]다.

  2. 확률은 0.7×0.9=0.63이다.

이번에는 확률 0.63인 완료 출력이다.

흔한 오답에서 다시 생각하기

첫 단계 확률 0.7이 전체 문장 확률이다.

전체 확률에는 해당 접두부에서의 종료 확률도 곱한다.

연습 2 · 오류 찾아 고치기

원래 표에서 [A,EOS]의 확률을 0.6×0.9로 기록했다. 고쳐라.

힌트 1

0.9가 속한 접두부를 찾는다.

힌트 2

현재 경로의 둘째 확률을 적는다.

풀이와 답 확인

  1. 0.9는 B 뒤 EOS에 속한다.

  2. A 뒤 EOS는 0.2여서 전체는 0.12다.

[A,EOS]의 확률은 0.12다.

흔한 오답에서 다시 생각하기

EOS는 같은 토큰이니 어느 줄의 확률이나 쓴다.

같은 EOS도 앞부분에 따라 조건부 분포가 다르다.

연습 4 · 선택 심화

선택 심화는 기본 연습 뒤 더 탐구하고 싶을 때 풀어 보세요.

별도 완료 후보 S는 확률 0.4·토큰 수 2, L은 확률 0.3·토큰 수 4다. EOS를 포함한 토큰 수로 평균 로그 확률을 비교하면 순위는?

힌트 1

평균 로그는 ln P를 길이로 나눈 값이다.

힌트 2

기하평균 0.4^(1/2)와 0.3^(1/4)를 비교한다.

풀이와 답 확인

  1. 기하평균 비교는 네제곱하여 0.16과 0.3으로 바꿀 수 있다.

  2. 총확률은 S가 크지만 평균 로그는 L이 크다.

길이 정규화는 목적을 바꾸어 L을 선호한다. 이는 원래 표에서 생성한 후보가 아닌 별도 비교다.

흔한 오답에서 다시 생각하기

로그를 쓰면 총확률과 평균 로그의 순위가 언제나 같다.

로그의 단조성은 공통 양수 길이로 나누지 않을 때의 총확률 순위에 적용한다.

query·key·value

찾는 조건과 검색 표지와 가져올 내용은 꼭 같은 벡터여야 할까?

준비 개념과 학습 목표

준비 개념

  • 내적

  • softmax

  • 행렬 곱의 크기

학습 목표

  • query/key/value의 역할을 구별한다.

  • 점수에서 가중치와 출력으로 이어 계산한다.

  • 차원·mask·정규화 방향을 확인한다.

제외한 항목의 value만 0으로 바꾸면 올바른 mask가 될까?

새 한 query의 점수는 (ln 2,0,ln 3), 스칼라 value는 (1,5,9)다. dropout 없이 지수 (2,1,3)를 정규화하면 가중치 (1/3,1/6,1/2), 출력 17/3을 얻는다. 셋째 항목을 제외할 때는 지수 합부터 3으로 바꿔 유효 가중치 (2/3,1/3,0)를 만든다. 새 출력은 7/3이다.

원래 softmax 뒤 셋째 value만 0으로 만들면 출력 7/6이다. 유효 가중치 합이 1/2로 남아 결과를 축소했다. 반면 셋째 점수에서 ln M을 빼는 유한 벌점은 M>0일 때 지수 3/M을 남긴다. 그 출력은 (7+27/M)/(3+3/M)이다. M=3이면 출력 4여서 정확 mask의 7/3과 다르다. M이 커지는 극한과 어느 유한 M의 계산을 분리한다.

모든 점수를 같은 유한 −K로 덮으면 softmax는 세 항목을 똑같이 1/3씩 준다. 유효 항목이 없는 수학적 분모 0을 처리한 것이 아니다. 자체 보고 계약에서는 빈 유효 집합을 없음 또는 오류로 따로 표시한다. 아래 계산은 수학적 실수식이며 실제 부동소수점 underflow나 라이브러리 반환값을 주장하지 않는다.

먼저 확인할 개념
  • 점수와 가중치·value의 세 단계

    softmax 분모를 결정한 뒤 value를 가중합한다.

  • 각 query 행의 유효 입력 집합

    입력 제외는 행마다 재정규화하며 열 방향 정규화로 바꾸지 않는다.

관련성을 계산할 표지와 내용을 구별한다

query q는 현재 어떤 내용을 찾는지 표현한다. key ki는 i번째 항목을 비교하기 위한 표지이고 value vi는 해당 항목에서 가져올 내용이다. 점수 ai=a(q,ki)로 관련성을 비교하고 출력은 Σi αivi로 계산한다. key와 value는 같은 항목에 짝지어 있지만 반드시 같은 수치나 차원일 필요는 없다.

scaled dot-product에서는 q와 ki가 같은 길이 d를 가지고 ai=qᵀki/√d다. 반면 vi의 길이는 dv여도 된다. 여러 query를 행으로 놓으면 Q는 n×d, K는 m×d, V는 m×dv이고 QKᵀ는 n×m, 최종 출력은 n×dv다. query마다 key 위치들에 대해 정규화한다.

점수는 확률형 가중치로 바뀐다

유한 점수에 대해 αi=exp(ai)/Σj exp(aj)를 사용한다. αi는 양수이고 합은1이다. 점수 자체는 음수여도 되고 합이1일 필요도 없다. 모든 점수에 같은 상수를 더해도 softmax 결과는 같다. 큰 지수의 수치 문제를 줄이기 위해 최대 점수를 빼는 계산을 사용할 수 있다.

1/√d는 특정 독립·평균0·분산1 가정에서 내적의 분산이 d가 되는 규모를 조절하려는 계수다. 모든 학습된 벡터의 분산을 항상1로 보장하는 정리는 아니다. 가중치를 만든 뒤 value를 더하며 큰 key나 큰 점수를 그대로 답 벡터라고 부르지 않는다.

허용한 항목 안에서 정규화한다

PAD나 보지 말아야 할 위치는 softmax 전에 점수를 제외하는 mask로 처리한다. 수학적으로 제외 항목의 지수를0으로 보고 남은 유효 항목의 지수 합으로 나눈다. 단순히 softmax 뒤 value를0으로 만들면 유효 가중치 합이1이 아닐 수 있다.

모든 key가 mask되어 유효 집합이 비면 이 분모는0이라 별도 정의·처리가 필요하다. 매우 큰 음수로 mask하는 구현과 수학적 정확0은 구별한다. 여기서는 dropout을 적용하지 않은 attention 가중합을 사용하며, 일반 훈련의 추가 변형까지 같은 합 규약으로 단정하지 않는다.

가중합과 정렬

번역할 다음 단어가 달라지면 입력의 어느 위치를 참고하는지도 바뀔까?

준비 개념과 학습 목표

준비 개념

  • attention 가중치

  • 인코더 상태

  • 가중평균과 행렬

학습 목표

  • 단계별 문맥 가중합을 작성한다.

  • 정렬표의 행합과 길이를 확인한다.

  • 가중치 시각화와 의미·인과 설명을 구별한다.

서로 다른 value라도 같은 문맥을 만드는 가중치가 있을까?

앞 본문은 모든 value가 같다는 반례를 썼다. 새 스칼라 value (0,1,2)는 서로 다르지만 가중치 α=(1/5,3/5,1/5)와 β=(3/10,2/5,3/10)는 둘 다 문맥 1을 만든다. 각 가중치는 양수이고 합은 1이어서 점수 ln α 또는 ln β로 softmax를 구성할 수도 있다. 이는 합법 가중치의 대수적 예이며 같은 학습 query가 실제로 두 분포를 만들었다는 실험은 아니다.

차이 β−α=(1/10,−1/5,1/10)는 합도 0이고 value 가중합도 0이다. 문맥 숫자 하나는 세 가중치의 정보를 모두 복원하지 못한다. 반면 value를 (0,0),(1,0),(0,1)로 바꾸면 문맥 (x,y)에서 둘째 가중치는 x, 셋째는 y, 첫째는 1−x−y로 복원된다. 복원 가능 여부에는 value의 배치와 관측 차원이 필요하다.

문맥을 복원했어도 최종 출력에서 정보가 다시 사라질 수 있다. 방금 삼각형 value에서 α의 문맥은 (3/5,1/5), β의 문맥은 (2/5,3/10)으로 다르다. 출력층이 두 성분을 더하면 값은 각각 4/5와 7/10이지만, 별도 출력층이 늘 상수 0을 반환하면 둘을 구별하지 못한다. 여기서 인과 중요도·정답 번역을 확정하지 않고 가중치, 문맥, 출력층 관측의 정보 범위를 구분한다.

먼저 확인할 개념
  • 정렬표와 가중합의 설명 범위

    행 가중치와 문맥 및 최종 예측을 단계별 관측으로 분리한다.

  • value 차원과 가중합

    같은 가중치라도 value 배치가 바뀌면 문맥과 복원 가능성이 달라진다.

출력 단계마다 문맥을 다시 만든다

attention을 쓰는 RNN 인코더·디코더의 한 방식에서는 입력 위치 i의 인코더 상태 hi를 key와 value로, 이전 디코더 상태 s(t−1)을 query로 사용한다. 각 출력 단계에서 αti를 새로 계산하고 ct=Σi αti hi를 디코더에 제공한다. 같은 입력이라도 출력 단계가 바뀌면 문맥이 달라질 수 있다.

이 방식은 마지막 인코더 상태 하나를 계속 사용하는 구조와 다르다. additive attention은 query와 key를 학습 행렬로 공통 숨은 공간에 보내 점수를 만들 수 있어 원래 차원이 달라도 가능하다. 이 단원에서는 점수가 이미 계산된 가중치표로 가중합을 연습하며 실제 학습된 정렬이라고 주장하지 않는다.

정렬표는 출력을 행으로 놓는다

출력 두 단계와 입력 세 위치면 가중치표는2×3이다. 여기서는 행마다 비음수이며 합1인 규약을 쓴다. 입력 위치에 강하게 가중하는 모양을 soft alignment라고 부를 수 있지만 한 위치만 선택하는 필수 규칙은 아니다. 출력과 입력의 길이도 다를 수 있다.

한 입력 위치를 여러 출력 단계가 참고해도 되고 위치 순서를 거꾸로 참고해도 된다. 열합은 일반적으로1이 아니다. 단어를 토큰 여러 개로 나눈 경우 그 위치도 토큰 기준이다. 가중치만으로 단어 대 단어 정답 대응이나 문장 전체 번역 성공을 확인할 수는 없다.

가중치만으로 최종 예측 이유를 확정하지 않는다

가중치의 큰 값은 해당 query에서 가중합을 계산할 때 어떤 value를 많이 사용했는지 보여 준다. value 자체에 주변 입력 정보가 섞여 있을 수 있고 최종 출력층도 문맥을 다르게 사용한다. 그러므로 heatmap 한 장으로 원래 입력의 인과적 중요도나 정답 의미를 확정하지 않는다.

서로 다른 가중치도 같은 가중합을 만들 수 있다. 예를 들어 모든 value가(1,2)이면(.8,.1,.1)과(.1,.8,.1) 둘 다 출력(1,2)다. 이는 모든 attention이 항상 설명 불가능하다는 전칭 증명이 아니라 가중치만으로 설명을 자동 보장할 수 없다는 작은 반례다. 모델·입력·검증 방법에 맞는 추가 분석이 필요하다.

조건을 바꾸어 비교하기

가중치 차이의 두 조건

새 α와 β가 같은 문맥을 만드는 이유를 차이 벡터로 설명하라.

  1. 차이의 합은 1/10−1/5+1/10=0이다.

  2. value 곱은 0−1/5+2/10=0이다.

정규화와 문맥을 동시에 보존하는 0이 아닌 변화가 있다.

비교할 점

모든 value 동일이라는 앞 반례보다 넓은 정보 손실을 보인다.

삼각형 value에서는 복원할 수 있다

value가 (0,0),(1,0),(0,1), 문맥이 (1/4,1/2)다. 합 1 가중치를 복원하라.

  1. 둘째 가중치는 1/4, 셋째는 1/2다.

  2. 첫째는 1−1/4−1/2=1/4다.

가중치는 (1/4,1/4,1/2)로 유일하다.

비교할 점

모든 attention 가중치가 항상 복원 불가능하다는 주장도 피한다.

  1. ① 탐욕은 [A,A]이며 확률 0.48인 미완료 접두부다. 완료 후보 [A,EOS]는 0.12, [B,EOS]는 0.36이다. 정답 입력은 [BOS,B], 합 손실은 −ln(0.36)이다.

  2. ② 정확 제외 출력은 7/3, value만 0으로 바꾼 출력은 7/6이다. 점수에서 ln 9를 뺀 경우 지수 (2,1,1/3)의 출력은 3이다. 유한 벌점은 정확 제외가 아니다.

  3. ③ 스칼라 가족은 (t,1−2t,t), 0≤t≤1/2다. 유한 softmax만 허용하면 0<t<1/2다. 삼각형의 복원 가중치는 (1/4,1/4,1/2)다.

  4. W=(1,0)은 서로 다른 두 삼각형 문맥의 첫 성분 1/4만 읽어 같은 최종 값을 만든다. 같은 최종 관측이 가중치 동일·인과 설명·번역 성공을 보장하지 않는다.

완료 여부와 조건부 경로를 분리한다. 세 mask 출력은 7/3, 7/6, 3으로 다르다. 스칼라 문맥은 가중치 가족을 숨기지만 삼각형 문맥은 가중치를 복원한다. 뒤 출력층은 그 문맥 차이도 지울 수 있다.
