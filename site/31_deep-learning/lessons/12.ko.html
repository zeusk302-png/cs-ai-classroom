소단원 12.1

과적합 소형배치 검사

작은 학습 자료조차 맞히지 못할 때 더 많은 자료를 넣기 전에 무엇을 확인할까?

준비 개념과 학습 목표

준비 개념

  • 평균제곱오차

  • 미분과 SGD

  • 학습과 일반화

학습 목표

  • 고정된 작은 자료로 학습 경로를 진단한다.

  • 예측·손실·기울기·갱신을 각각 확인한다.

  • 진단 성공과 일반화, 표현 불가능한 자료를 구별한다.

작은 고정 자료에서 경로를 분리한다

충분히 표현할 수 있는 작은 학습 자료를 반복해 맞추는 검사는 입력·라벨 연결, 손실, 기울기, 갱신의 문제를 찾는 데 도움이 된다. 전체 자료나 무작위 배치로 바로 학습하면 문제 위치를 구별하기 어렵다. 진단용 작은 자료는 최종 평가 자료에서 고르지 않는다.

먼저 자료와 라벨을 직접 읽고, 모형이 목표를 표현할 수 있는지 확인한다. 진단에서는 강한 정규화나 무작위 증강이 작은 자료를 맞히는 일을 방해할 수 있어 조건을 명시하고 단순화한다. 이것은 최종 모델에서 정규화를 무조건 없애라는 뜻이 아니다.

손실이 어디서 변하는지 추적한다

순전파의 예측과 손실, 미분으로 얻은 기울기, optimizer가 바꾼 파라미터를 따로 확인한다. 손실이 줄지 않는 원인은 라벨 오류, 갱신 누락, 학습률, 수치 문제나 표현 능력 등 여러 가지다. 한 원인으로 곧바로 단정하지 않는다.

유한 차분 기울기 검사는 일부 점에서 analytic 미분과 비교하는 보조 방법이다. 무작위 효과, 비미분 지점과 부동소수점 오차를 고려한다. 검사한 한 점이나 일부 성분의 일치가 모든 입력과 모든 파라미터에서 정확하다는 증명은 아니다.

작은 자료 성공에도 한계가 있다

작은 자료를 암기할 수 있어도 평가 성능은 낮을 수 있다. 입력이 버그로 무의미한 값이 되어도 충분히 큰 모델이 암기할 수 있으므로 성공은 전체 구현 정확성이나 일반화를 보증하지 않는다. 원래 자료와 별도 평가를 다시 확인한다.

또한 동일 입력에 서로 다른 회귀 정답이 있고 입력만으로 하나의 값을 내는 결정적 모델이라면 모든 오차를 0으로 만들 수 없다. 표현 불가능한 과제를 진단 실패로 오해하지 않는다. 아래 계산은 신경망의 가장 단순한 affine, 즉 입력에 가중치를 곱하고 편향을 더하는 층을 종이로 확인하는 예이며 실제 딥러닝 학습을 실행하지 않았다.

중간 과정을 따라가는 예제

고정 두 표본은 (x,y)=(0,1),(1,3)이다. 예측 wx+b와 손실 L=((b−1)²+(w+b−3)²)/2를 쓴다. w=b=0에서 학습률 1/10의 SGD 한 번과 표현 가능한 완전 적합을 구하라.

  1. 처음 예측은 0,0이고 손실은 (1+9)/2=5다. ∂L/∂w=w+b−3=−3, ∂L/∂b=(b−1)+(w+b−3)=−4다.

  2. 동시 갱신하면 w=3/10, b=2/5다. 새 예측은 2/5,7/10이며 잔차는 −3/5,−23/10이다.

  3. 새 손실은 ((3/5)²+(23/10)²)/2=113/40=2.825다. w=2,b=1이면 두 예측 1,3으로 손실이 0이다.

한 번의 갱신은 w=0.3,b=0.4, 손실 2.825다. 이 자료는 affine 층으로 완전 적합 가능하지만 한 번 갱신이 최적값을 바로 주지는 않는다.

종이와 본문으로 직접 해보기

동일 입력 x=0의 두 정답이 0과 1이다. 결정적 예측 p의 평균제곱오차 (p²+(p−1)²)/2를 완전제곱으로 고치고 최솟값을 구하라.

힌트 보기

p²−p+1/2를 (p−1/2)²와 상수로 나눈다.

풀이 보기

손실은 (p−1/2)²+1/4로 p=1/2에서 최소 1/4다. 동일 입력에 하나의 값만 내는 조건에서는 두 잔차를 동시에 0으로 만들 수 없다.

오해와 반례

작은 배치 손실을 0으로 만들면 모든 구현과 평가 성능도 검증됐다.

암기 가능성과 일반화는 다르다. 반대로 모순 라벨이나 부족한 표현 능력 때문에 0이 불가능한 경우도 있어 과제 조건부터 확인한다.

한 단계 더

소단원 12.2

체크포인트와 로그

파라미터만 저장했다면 중단 직전과 같은 학습으로 돌아온 것일까?

준비 개념과 학습 목표

준비 개념

  • 파라미터와 optimizer

  • momentum

  • 검증 지표

학습 목표

  • 추론용 가중치와 재개용 학습 상태를 구별한다.

  • 검증 기준의 best와 마지막 상태를 나눈다.

  • 진행 위치·환경·난수·로그의 연결을 기록한다.

재개에 필요한 상태를 구별한다

체크포인트는 중단 후 다시 사용할 상태 묶음이다. 모델의 파라미터와 등록된 버퍼는 추론에 필요하지만 학습 재개에는 optimizer의 누적 상태, 학습률 스케줄, 진행 위치 같은 정보도 필요할 수 있다. 사용하는 optimizer와 데이터 흐름에 따라 필요한 항목을 확인한다.

자료 순서·난수 상태·사용 환경·정밀도 설정과 증강 조건이 바뀌면 저장한 가중치가 같아도 다음 갱신이 달라질 수 있다. seed를 처음부터 다시 설정한 것과 중단 직전의 난수 상태를 복원한 것은 다르다. 다른 플랫폼/버전에서 완전히 같은 결과를 무조건 보장하지 않는다.

가장 좋은 상태와 마지막 상태를 구별한다

best는 정해진 검증 지표와 동점 규약으로 선택한 상태이고, last는 가장 나중 진행 상태다. 훈련 손실이 계속 내려가도 검증 손실의 best가 last와 같을 필요는 없다. 최종 평가 정답으로 best를 선택하지 않는다.

메모리에서 best를 가리키는 참조만 보관하면 이후 파라미터 변경이 그 내용에도 반영될 수 있다. 필요한 값을 실제 복사하거나 저장하고 파일 식별자·설정·검증 로그를 함께 연결한다. 저장 뒤 복원하여 일치 여부를 확인하는 실제 검사는 별도로 수행해야 한다.

로그의 축과 측정 조건을 적는다

epoch는 자료 전체를 한 차례 보는 진행 단위, optimizer step은 파라미터 갱신 한 번이다. 이 둘과 처리 표본 수는 다른 축이다. 배치 크기나 gradient accumulation, 즉 여러 배치의 기울기를 모아 한 번 갱신하는 규칙을 바꾸면 같은 step 수라도 처리 자료량이 달라질 수 있다. 손실의 평균/합과 정규화, 검증의 학습/평가 모드, 표본 수와 시점을 기록한다.

학습 재개와 추론의 모드를 구별한다. 예를 들어 dropout·batch normalization의 train/eval 설정은 결과에 영향을 주며 eval 설정이 모든 난수나 gradient 계산을 자동 제거하는 것은 아니다. 아래는 가상 상태와 로그의 종이 추적이며 실제 체크포인트 파일을 저장·복원하지 않았다.

중간 과정을 따라가는 예제

자체 momentum 규칙 vnext=(1/2)v+g, θnext=θ−(1/10)vnext를 사용한다. 저장 θ=1,v=2이고 같은 다음 기울기 g=3이다. 완전 상태를 복원한 결과와 θ만 복원해 v=0으로 재시작한 결과를 비교하라.

  1. θ와 v를 복원하면 vnext=1+3=4, θnext=1−4/10=3/5다.

  2. θ만 복원하고 v=0이면 vnext=3, θnext=1−3/10=7/10이다.

  3. 처음 θ와 다음 g가 같아도 optimizer 상태를 빠뜨린 두 결과의 차이는 1/10이다. 이는 지정한 자체 규칙의 예이고 모든 optimizer의 동일 공식은 아니다.

전체 복원 θnext=0.6, 가중치만 복원 θnext=0.7이다. 같은 가중치가 같은 학습 궤적을 자동 보장하지 않는다.

종이와 본문으로 직접 해보기

epoch 1,2,3의 학습 손실이 0.8,0.4,0.2이고 검증 손실이 0.5,0.3,0.4다. 낮은 검증 손실과 더 이른 epoch의 동점 규약으로 best와 last를 고르라.

힌트 보기

학습 손실이 아니라 선택 계약의 검증 손실을 비교한다.

풀이 보기

best는 epoch 2의 검증 0.3, last는 epoch 3이다. 검증 0.4로 악화된 last가 더 좋은 평가 성능인지 최종 평가를 수행하기 전에는 알 수 없다.

오해와 반례

파일 이름을 best라고 적거나 seed 하나를 기록하면 정확한 학습 재개가 확인됐다.

파일 이름은 저장 내용·선택 기준·복원 일치의 증거가 아니다. 필요한 상태와 환경, 실제 복원 검사를 확인해야 한다.

  • 실패 사례와 실행 여부를 재현 기록에 연결한다.

집단과 분모를 함께 보고한다

전체 정확도는 각 집단의 맞힌 수를 더해 전체 표본 수로 나눈 값이다. 집단 정확도를 단순 평균한 값과 표본 수로 가중한 전체 값은 다를 수 있다. 소수 집단의 실패가 큰 집단의 높은 성능에 가려지는지 확인한다.

훈련·검증·최종 평가의 지표를 구별하고 자료 시점·분할·선택한 모델·임계값·지표 규약을 연결한다. 드문 실패를 분류할 때 실제 표본, 라벨 의문과 원인 가설을 나누어 적는다. 표본이 적은 집단의 비율을 안정적인 미래 성능으로 단정하지 않는다.

시간과 자원은 범위를 정해서 비교한다

처리량은 일정 범위에서 처리한 표본 수를 걸린 시간으로 나눈 값이고, 요청 지연은 해당 요청이 완료될 때까지의 시간이다. 배치 크기가 커지면 처리량과 지연이 함께 증가할 수도 있다. 자료 읽기·전처리·전송·순전파 포함 범위를 밝힌다.

장치 초기화 등을 먼저 수행하는 warmup과 본 측정을 나누고 비동기 가속기 작업의 완료를 확인한다. 여러 반복의 원시 시간과 요약을 함께 보며 스레드 수·입력 크기·정밀도·환경을 기록한다. 파라미터 저장 바이트만으로 활성값·기울기·optimizer·임시 버퍼를 포함한 최대 메모리를 추정했다고 말하지 않는다.

성공과 실패, 가정을 같은 표에 남긴다

성능이 좋아진 사례뿐 아니라 실패·제외·미실행도 기록한다. 평균은 개선되지만 한 집단은 악화될 수 있고, 빠르지만 메모리가 부족할 수도 있다. 목표 사용 조건과 비교 지표를 먼저 정해 선택 이유를 설명한다.

아래 시간·정답 수·파라미터 수는 보고 산술을 위한 가상 값이다. 실제 GPU 학습·메모리 계측·벤치마크를 수행한 값으로 공개하지 않는다. 실험이 수행되면 원시 로그와 설정, 모델/자료 버전, 복원 상태를 함께 보존하고 학습자 이해도 검토는 별도 항목으로 둔다.

중간 과정을 따라가는 예제

가상 평가에서 집단 A는 100개 중 90개, B는 10개 중 5개를 맞혔다. 전체 정확도와 집단 정확도 단순 평균을 구하라. 같은 측정 범위에서 배치 64개가 2초, 16개가 1초인 두 조건의 처리량도 비교하라.

  1. 전체는 (90+5)/(100+10)=95/110=19/22로 약 86.36%다. A는 90%, B는 50%다.

  2. 집단의 단순 평균은 (90%+50%)/2=70%다. 실제 표본 수를 가중한 전체 정확도와 같지 않다.

  3. 처리량은 64/2=32개/초와 16/1=16개/초다. 첫 조건이 처리량은 두 배지만 해당 배치 완료 시간 2초는 1초보다 길다. 사용자별 요청 지연은 배치 대기 등 추가 조건이 필요하다.

전체 약 86.36%, 집단 평균 70%다. 두 처리량은 32와 16개/초이며 이 비율만으로 모든 요청의 지연 개선을 말하지 않는다.

시간은 합/5와 정렬 가운데 값을, 저장량은 개수×바이트를 계산한다.

풀이 보기

시간 합은 100ms라 평균 20ms, 정렬 9,10,10,11,60의 중앙값은 10ms다. 파라미터만은 800만 바이트로 십진 MB 기준 8MB다. 이상값을 근거 없이 버리거나 이를 최대 학습 메모리라고 부르지 않는다.

오해와 반례

전체 정확도가 높고 파라미터 파일이 작으면 모든 집단과 장치에 충분하다.

B의 정확도 50%가 전체 평균에 가려질 수 있고 학습 메모리에는 파라미터 외 상태가 있다. 집단별 표본과 실제 자원 조건이 필요하다.
