소단원 7.1

채널·stride·padding

사진의 가로세로와 색 채널은 CNN에서 어떻게 바뀔까?

준비 개념과 학습 목표

준비 개념

  • 텐서 shape는 각 축의 길이다. N은 배치, C는 채널, H·W는 높이·너비다.

  • 작은 창 안의 값과 가중치를 곱해 합하는 연산을 안다.

학습 목표

  • 입력·출력 채널과 공간 축을 구분한다.

  • 출력 크기와 파라미터 수를 계산한다.

  • stride 및 padding의 효과를 설명한다.

출력 모양이 같으면 같은 입력을 보는 층인가?

출력 길이만 확인하면 연결 구조를 놓칠 수 있다. 길이 7의 한 축에서 커널 크기 3, stride 1, 한쪽 padding 1, dilation 1이면 출력 길이는 7이다. dilation을 2로 바꾸고 padding도 2로 바꾸면 출력 길이는 여전히 7이지만 가운데 출력은 연속 세 칸 대신 두 칸 간격의 세 위치를 본다.

입력 채널 4개와 출력 채널 6개, 3×3 커널, bias를 고정한다. groups가 1이면 출력 하나가 입력 네 채널을 모두 보고 파라미터는 6×(4×9+1)=222개다. groups가 2이면 출력 하나는 대응하는 입력 두 채널만 보고 파라미터는 6×(2×9+1)=114개다. 출력의 채널 수와 공간 크기가 같아도 연결은 다르다. groups는 입력과 출력 채널 수 모두를 나누어야 한다.

커널이 차지하는 한 축의 유효 폭은 d(k−1)+1이다. 유효 폭은 양끝을 포함한 입력 칸 수이며, 양끝 인덱스의 차이보다 1 크다. 그 안의 모든 칸을 실제로 사용한다는 뜻은 아니다. 커널 [1,0,−1], 입력 [0,1,2,3,4,5,6]의 가운데 출력은 상호상관 기준으로 dilation 1에서 −2, dilation 2에서 −4다. 뒤집기나 새 가중치 학습 없이 연결 차이를 읽는 자체 계산이다.

먼저 확인할 개념
  • stride와 한쪽 padding

    앞 본문의 출력 길이 식을 dilation까지 확장하며 한쪽 padding이라는 같은 규약을 유지한다.

  • 채널 합과 공유 파라미터

    앞 본문의 groups=1 조건을 groups=2와 비교하며 공간 공유와 채널 연결을 분리한다.

채널별로 더하고 출력별로 분리

일반적인 groups=1 합성곱에서 출력 채널 하나의 필터는 모든 입력 채널을 본다. 입력 채널별 창의 곱합을 더하고 해당 출력 채널의 bias 하나를 더한다. 출력 채널 수만큼 서로 다른 필터를 학습한다.

딥러닝 구현이 합성곱이라 부르는 연산은 대개 커널을 뒤집지 않는 상호상관이다. 이후 학습되는 가중치로 기능을 익히므로 명칭만으로 수학적 뒤집기를 코드에 추가하지 않는다.

창의 이동과 테두리

stride s는 다음 창 시작점의 이동 간격이다. dilation=1, 양쪽 각각 p의 padding, 커널 한 축 크기 k라면 출력 길이는 floor((n+2p−k)/s)+1이다. padding 값은 보통 0이며 테두리 처리의 가정이다.

높이·너비에 같은 식을 각각 적용한다. 남는 끝부분에 창이 완전히 들어가지 않으면 버린다. same 크기는 홀수 k, stride1에서 p=(k−1)/2로 얻지만 stride2가 자동으로 원래 크기를 보존하는 것은 아니다.

파라미터는 공간 크기와 분리

bias를 쓰는 groups=1 층의 파라미터 수는 Cout×(Cin×kh×kw+1)이다. 필터를 모든 위치에 공유하므로 입력 H,W가 바뀌어도 이 수는 그대로다. 활성값 수와 계산량은 출력 공간 크기에 따라 달라진다.

groups나 dilation을 바꾸면 연결 방식이나 유효 창 크기가 바뀐다. 여기 식의 가정을 확인하고 새로운 설정에서는 공식 문서와 조건을 다시 대조한다. 입력 채널 불일치는 공간 padding으로 해결하지 못한다.

  3. 총 4×28=112개다. 한 위치에서 두 입력 채널 기여가 2와 −1, 세 번째가 3, bias0.5라면 출력은 4.5다.

출력 (N,4,4,4), 파라미터 112개이며 배치 수 N과 무관하다.

그룹을 공간 축소로 오해하지 않는다

소단원 7.2

수용영역과 pooling

작은 창을 여러 번 쓰면 원래 사진의 얼마나 넓은 부분을 보게 될까?

준비 개념과 학습 목표

준비 개념

  • 합성곱의 커널 크기와 stride를 안다.

  • 최댓값과 평균은 서로 다른 요약 연산이다.

학습 목표

  • 이론적 수용영역과 유효 영향력을 구분한다.

  • pooling 값을 직접 계산한다.

  • 위치 정보의 손실과 불변성의 한계를 설명한다.

같은 두 종류의 층에서 pooling의 순서는 왜 중요한가?

길이 8에 padding 없는 순차 연산을 비교한다. A는 k=3, s=1 합성곱 뒤 k=2, s=2 pooling으로 길이가 6에서 3으로 줄어든다. B는 pooling 뒤 같은 합성곱으로 길이가 4에서 2로 줄어든다. 최종 크기까지 같다고 가정하기 전에 각 단계 길이를 먼저 써야 한다.

크기와 별도로 입력 수용영역을 추적한다. 초기 r=1,j=1에서 A는 (r,j)=(3,1)→(4,2), B는 (2,2)→(6,2)다. 같은 두 종류의 층을 사용해도 순서를 바꾸면 범위가 달라진다. r은 가능한 영향 범위이고, max의 현재 승자나 영 가중치가 만드는 실제 영향은 더 작을 수 있다.

평균 pooling의 padding도 분모 정책이다. 한 채널의 2×2 입력이 모두 4이고 k=3, s=1, p=1로 pooling하면 각 창에 실제 값 네 개와 padding 다섯 개가 들어간다. padding을 분모에 포함하면 평균은 16/9이고 제외하면 4다. 창 크기만 보고 평균의 분모를 9로 고정하지 말고 count_include_pad와 divisor_override 조건을 확인한다. 여기서는 ceil_mode=False이고 divisor_override는 없다.

먼저 확인할 개념
  • 수용영역과 출력 간격

    앞 본문의 r,j 재귀식을 층 순서가 다른 두 경로에 각각 적용한다.

  • 창의 시작과 테두리

    앞 본문의 공간 크기와 0 padding 규약을 평균의 분모 정책과 분리한다.

입력까지 거슬러 보는 범위

수용영역은 어떤 출력 하나에 영향을 줄 수 있는 원래 입력 위치 범위다. dilation=1인 순차 층에서 초기 r=1,j=1로 두고 커널 k,stride s를 지날 때 r새=r+(k−1)j, j새=js다. j는 인접 출력이 원래 입력에서 얼마나 떨어져 있는지다.

ReLU 같은 점별 연산은 공간 범위를 넓히지 않는다. padding 부근의 이론적 범위에는 인공 0이 들어갈 수 있다. 실제로 큰 영향을 주는 위치는 가중치와 활성 상태에 따라 이론적 범위보다 작을 수 있다.

창 안의 대표값

Max pooling은 창 안 최댓값, average pooling은 평균을 택한다. 기본 pooling 자체에는 학습 가중치가 없고 채널별로 작동한다. 창 크기와 stride를 같게 해야 항상 비겹침이 되는 간단한 설정을 얻는다.

풀링이 작은 위치 이동의 민감도를 줄일 수 있지만 모든 이동에 불변이라는 보장은 없다. 창 경계를 넘으면 대표값이 바뀌고 값의 정확한 위치를 잃는다. 위치가 답인 과제에는 지나친 축소가 불리하다.

범위·해상도·손실의 교환

3×3,stride1 합성곱 뒤 2×2,stride2 pooling, 다시 3×3,stride1 합성곱이면 원래 입력을 보는 범위가 늘고 출력 간격도 커진다. 넓게 보는 것과 고해상도를 유지하는 것은 별개의 목표다.

평균은 여러 값의 합을 사용하고 최대는 큰 값 하나를 보존한다. 평균은 작은 잡음을 완화할 수 있으나 구조에 따라 흐림이 생기며 최대는 이상치에 민감할 수 있다. 과제와 자료를 보고 선택한다.

소단원 7.3

소형 CNN 구현

신경망 코드가 실행되기 전에 층의 크기 오류를 찾을 수 있을까?

준비 개념과 학습 목표

준비 개념

  • NCHW 배치 축과 합성곱·pooling shape 식을 안다.

  • Linear는 마지막 특성 축을 출력 점수로 바꾼다.

학습 목표

  • 작은 모델의 shape를 층별로 추적한다.

  • flatten에서 배치 축을 보존한다.

  • 구조 정의와 학습 성공을 구분한다.

입력 크기 대응과 위치 보존을 동시에 얻을 수 있는가?

앞 모델의 flatten은 2채널의 4×4 공간을 특정 순서로 펼쳐 32개 특징을 만든다. 입력 8×8에는 맞지만 10×10에는 50개가 되어 Linear32와 맞지 않는다. N=1에서 전체 flatten의 길이 32가 우연히 길이를 맞추더라도 명시한 배치 축을 지우므로 N=2에서 같은 계약을 유지하지 못한다.

대안으로 입력 1채널을 출력 2채널로 바꾸는 k=3, p=1, bias가 있는 합성곱 뒤 ReLU, 공간 전체를 채널마다 평균하는 AdaptiveAvgPool2d(1), flatten(start_dim=1), 입력 특징 2개에서 점수 2개를 내는 bias가 있는 Linear를 설계한다. 입력 공간이 양의 정수라면 pooling 뒤 shape는 (N,2,1,1), 펼친 뒤 shape는 (N,2), 최종 출력도 (N,2)다. Conv의 파라미터 20개와 Linear의 6개를 합하여 총 26개다. 이는 새 구조 설계이며 실행·학습·정확도 개선의 증거가 아니다.

전역 평균은 위치를 없앤다. ReLU 뒤 한 채널의 2×2 특징 A=[[4,0],[0,0]]와 B=[[0,0],[0,4]]는 모두 평균 1이다. 다른 채널까지 같은 평균이라면 뒤 Linear는 두 입력을 구별하지 못한다. 이 반례는 특징 지도 수준의 정보 손실이며 임의 원본 사진의 모든 합성곱 출력이 반드시 이 두 지도라는 주장은 아니다. 위치가 정답인 문제에는 평균 요약만으로 충분하지 않을 수 있다.

먼저 확인할 개념
  • 배치를 남기는 flatten

    앞 본문의 start_dim=1 계약과 입력 크기별 특징 32개와 50개를 새 분류기 설계와 비교한다.

  • 요약의 위치 정보 손실

    앞 본문의 같은 최대/평균을 갖는 다른 배열을 채널별 전역 평균의 구별 불가능 사례에 적용한다.

입력 계약부터 고정

아래 자체 모델은 실수 입력 (N,1,8,8)을 받아 두 종류의 분류 점수(N,2)를 낸다. Conv2d1→2,k3,p1 뒤 ReLU, k2,s2 MaxPool, flatten, Linear32→2 순서다. 모든 입력 크기에 자동 대응하는 모델은 아니다.

사진값의 단위와 범위·라벨 의미는 자료 준비에서 정한다. 구조만 정의했다고 가중치가 학습되거나 점수가 확률이 되지 않는다. 이 예는 이론적 크기와 코드 흐름을 설명하며 학습 결과를 보고하지 않는다.

형태가 맞는지 종이로 실행

첫 층은 공간 8×8을 유지하고 채널을 2로 만든다. Pooling은 4×4로 줄이고 flatten(start_dim=1)은 배치를 제외한 2×4×4=32개를 펴므로 Linear의 입력 32와 맞는다.

start_dim=0으로 모두 펴면 서로 다른 학생 사진의 값까지 한 벡터에 섞인다. 입력이 10×10이면 Pooling 뒤 5×5라 50개가 되어 이 모델의 Linear32와 맞지 않는다. shape 검사도 자료 계약의 일부다.

코드와 확인 범위

nn.Module의 __init__에서 층을 등록하고 forward에서 연결한다. 아래 코드는 구조 예시다. 실제 실행은 하지 않았으며 설치 없이 종이 추적 활동만 해도 이 단원 목표를 수행할 수 있다.

추후 실행할 때 입력 shape, 출력 shape, 손실·라벨 계약, 학습·평가 자료 분리를 확인한다. 무작위 초기 점수나 shape가 맞는 결과는 인식 정확도·학습 완료·학생 이해도의 증거가 아니다.

import torch
from torch import nn

class TinyCNN(nn.Module):
    def __init__(self):
        super().__init__()
        self.features = nn.Sequential(
            nn.Conv2d(1, 2, kernel_size=3, padding=1),
            nn.ReLU(),
            nn.MaxPool2d(kernel_size=2, stride=2),
        )
        self.classifier = nn.Linear(32, 2)

    def forward(self, x):
        # 입력 계약: (N, 1, 8, 8). 실행하지 않은 예시 코드.
        z = self.features(x)
        z = torch.flatten(z, start_dim=1)
        return self.classifier(z)

세 CNN 계약을 따로 인증한다

독립 세 설계를 진단하라. ① 입력 채널 4개, 출력 채널 6개, 커널 3×3, bias가 있고 groups=2, dilation=2, stride=1, 한쪽 padding=2다. 입력 공간은 7×7이다. 출력 shape의 배치를 N으로 표시하고 파라미터 수와 한 축의 유효 폭을 구한다. ② 길이 8에서 padding 없는 k=3, s=1 합성곱과 k=2, s=2 pooling의 두 순서 A/B에 대해 최종 길이와 r,j를 구한다. 별도 모든 값이 4인 2×2 입력의 k=3, s=1, p=1 평균 pooling에서 padding 포함/제외 분모를 비교한다. ③ 입력 1채널에서 출력 2채널로 바꾸는 k=3, p=1, bias가 있는 Conv 뒤 ReLU, 각 채널의 공간 전체 평균 1×1, flatten(start_dim=1), 입력 특징 2개에서 점수 3개를 내는 bias가 있는 Linear를 연결한다. 입력은 (2,1,10,6)으로 가정한다. 최종 shape와 파라미터 수를 구하고, 다른 채널의 요약도 같을 때 같은 평균이나 다른 위치를 갖는 특징 A/B의 구별 가능성을 판정한다. 모든 수치는 교육용 손모형이며 실제 CNN 결과가 아니다.

힌트 1

① groups는 한 출력이 보는 채널 수를 정한다. 유효 폭은 d(k−1)+1이다. ② r 갱신에는 이전 j를 쓴다.

힌트 2

③ 공간 평균은 채널을 남긴다. 같은 입력 벡터를 같은 함수로 후처리하면 같은 출력을 낸다.

풀이와 답 확인

  1. ① 공간 길이는 7+4−5+1=7로 출력 shape는 (N,6,7,7)이다. 파라미터는 6×(2×9+1)=114개이며 유효 폭은 5다.

  2. ② A의 최종 길이는 3, r은 4, j는 2다. B의 최종 길이는 2, r은 6, j는 2다. 같은 층 종류의 순서를 바꾸면 범위와 크기가 달라진다.

  3. ② 별도 평균은 실제 합 16을 분모 9 또는 4로 나누어 16/9 또는 4다.

  4. ③ 공간 평균 뒤 shape는 (2,2,1,1), flatten 뒤에는 (2,2), 최종 출력은 (2,3)이다. 전체 파라미터는 20+9=29개다. 같은 채널 평균 벡터를 갖는 A/B는 뒤 Linear로 구별할 수 없다.

출력 크기, 채널 연결, 수용영역과 분모, 축의 의미, 요약 정보를 각각 조건과 함께 인증한다. shape 일치와 파라미터 수는 학습 성공이나 위치 구별 성능의 증거가 아니다.
