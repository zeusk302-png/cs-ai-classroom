소단원 7.1

채널·stride·padding

사진의 가로세로와 색 채널은 CNN에서 어떻게 바뀔까?

준비 개념과 학습 목표

준비 개념

  • 텐서 shape는 각 축의 길이다. N은 배치, C는 채널, H·W는 높이·너비다.
  • 작은 창 안의 값과 가중치를 곱해 합하는 연산을 안다.

학습 목표

  • 입력·출력 채널과 공간 축을 구분한다.
  • 출력 크기와 파라미터 수를 계산한다.
  • stride 및 padding의 효과를 설명한다.

채널별로 더하고 출력별로 분리

일반적인 groups=1 합성곱에서 출력 채널 하나의 필터는 모든 입력 채널을 본다. 입력 채널별 창의 곱합을 더하고 해당 출력 채널의 bias 하나를 더한다. 출력 채널 수만큼 서로 다른 필터를 학습한다.

딥러닝 구현이 합성곱이라 부르는 연산은 대개 커널을 뒤집지 않는 상호상관이다. 이후 학습되는 가중치로 기능을 익히므로 명칭만으로 수학적 뒤집기를 코드에 추가하지 않는다.

창의 이동과 테두리

stride s는 다음 창 시작점의 이동 간격이다. dilation=1, 양쪽 각각 p의 padding, 커널 한 축 크기 k라면 출력 길이는 floor((n+2p−k)/s)+1이다. padding 값은 보통 0이며 테두리 처리의 가정이다.

높이·너비에 같은 식을 각각 적용한다. 남는 끝부분에 창이 완전히 들어가지 않으면 버린다. same 크기는 홀수 k, stride1에서 p=(k−1)/2로 얻지만 stride2가 자동으로 원래 크기를 보존하는 것은 아니다.

파라미터는 공간 크기와 분리

bias를 쓰는 groups=1 층의 파라미터 수는 Cout×(Cin×kh×kw+1)이다. 필터를 모든 위치에 공유하므로 입력 H,W가 바뀌어도 이 수는 그대로다. 활성값 수와 계산량은 출력 공간 크기에 따라 달라진다.

groups나 dilation을 바꾸면 연결 방식이나 유효 창 크기가 바뀐다. 여기 식의 가정을 확인하고 새로운 설정에서는 공식 문서와 조건을 다시 대조한다. 입력 채널 불일치는 공간 padding으로 해결하지 못한다.

중간 과정을 따라가는 예제

입력 (N,3,8,8), Cout=4,k=3,s=2,p=1,dilation=1,groups=1,bias 있음인 층의 shape와 파라미터 수를 구하라.

  1. 각 출력 축은 floor((8+2−3)/2)+1=floor(3.5)+1=4다.
  2. shape는(N,4,4,4)다. 필터 한 개는 3×3×3=27개 가중치와 bias1이다.
  3. 총 4×28=112개다. 한 위치에서 두 입력 채널 기여가 2와 −1, 세 번째가 3, bias0.5라면 출력은 4.5다.

출력 (N,4,4,4), 파라미터 112개이며 배치 수 N과 무관하다.

소단원 7.2

수용영역과 pooling

작은 창을 여러 번 쓰면 원래 사진의 얼마나 넓은 부분을 보게 될까?

준비 개념과 학습 목표

준비 개념

  • 합성곱의 커널 크기와 stride를 안다.
  • 최댓값과 평균은 서로 다른 요약 연산이다.

학습 목표

  • 이론적 수용영역과 유효 영향력을 구분한다.
  • pooling 값을 직접 계산한다.
  • 위치 정보의 손실과 불변성의 한계를 설명한다.

입력까지 거슬러 보는 범위

수용영역은 어떤 출력 하나에 영향을 줄 수 있는 원래 입력 위치 범위다. dilation=1인 순차 층에서 초기 r=1,j=1로 두고 커널 k,stride s를 지날 때 r새=r+(k−1)j, j새=js다. j는 인접 출력이 원래 입력에서 얼마나 떨어져 있는지다.

ReLU 같은 점별 연산은 공간 범위를 넓히지 않는다. padding 부근의 이론적 범위에는 인공 0이 들어갈 수 있다. 실제로 큰 영향을 주는 위치는 가중치와 활성 상태에 따라 이론적 범위보다 작을 수 있다.

창 안의 대표값

Max pooling은 창 안 최댓값, average pooling은 평균을 택한다. 기본 pooling 자체에는 학습 가중치가 없고 채널별로 작동한다. 창 크기와 stride를 같게 해야 항상 비겹침이 되는 간단한 설정을 얻는다.

풀링이 작은 위치 이동의 민감도를 줄일 수 있지만 모든 이동에 불변이라는 보장은 없다. 창 경계를 넘으면 대표값이 바뀌고 값의 정확한 위치를 잃는다. 위치가 답인 과제에는 지나친 축소가 불리하다.

범위·해상도·손실의 교환

3×3,stride1 합성곱 뒤 2×2,stride2 pooling, 다시 3×3,stride1 합성곱이면 원래 입력을 보는 범위가 늘고 출력 간격도 커진다. 넓게 보는 것과 고해상도를 유지하는 것은 별개의 목표다.

평균은 여러 값의 합을 사용하고 최대는 큰 값 하나를 보존한다. 평균은 작은 잡음을 완화할 수 있으나 구조에 따라 흐림이 생기며 최대는 이상치에 민감할 수 있다. 과제와 자료를 보고 선택한다.

중간 과정을 따라가는 예제

위 순차 층의 r,j와 창[[1,4],[2,3]]의 두 pooling 값을 계산하라.

  1. 초기(1,1)에서 합성곱 뒤 r=1+2×1=3,j=1이다.
  2. pooling 뒤 r=3+1×1=4,j=2이고 마지막 합성곱 뒤 r=4+2×2=8,j=2다.
  3. 창의 max는 4, 평균은(1+4+2+3)/4=2.5다.

마지막 출력의 이론적 수용영역은 한 축 8, 출력 간격 2다. 창의 위치는 두 요약값에서 복원되지 않는다.

오해와 반례

[[1,4],[2,3]]와 [[4,1],[3,2]]는 같은 max와 평균이지만 위치가 다르다. 여러 입력이 같은 요약으로 합쳐져 정보가 손실된다.

소단원 7.3

소형 CNN 구현

신경망 코드가 실행되기 전에 층의 크기 오류를 찾을 수 있을까?

준비 개념과 학습 목표

준비 개념

  • NCHW 배치 축과 합성곱·pooling shape 식을 안다.
  • Linear는 마지막 특성 축을 출력 점수로 바꾼다.

학습 목표

  • 작은 모델의 shape를 층별로 추적한다.
  • flatten에서 배치 축을 보존한다.
  • 구조 정의와 학습 성공을 구분한다.

입력 계약부터 고정

아래 자체 모델은 실수 입력 (N,1,8,8)을 받아 두 종류의 분류 점수(N,2)를 낸다. Conv2d1→2,k3,p1 뒤 ReLU, k2,s2 MaxPool, flatten, Linear32→2 순서다. 모든 입력 크기에 자동 대응하는 모델은 아니다.

사진값의 단위와 범위·라벨 의미는 자료 준비에서 정한다. 구조만 정의했다고 가중치가 학습되거나 점수가 확률이 되지 않는다. 이 예는 이론적 크기와 코드 흐름을 설명하며 학습 결과를 보고하지 않는다.

형태가 맞는지 종이로 실행

첫 층은 공간 8×8을 유지하고 채널을 2로 만든다. Pooling은 4×4로 줄이고 flatten(start_dim=1)은 배치를 제외한 2×4×4=32개를 펴므로 Linear의 입력 32와 맞는다.

start_dim=0으로 모두 펴면 서로 다른 학생 사진의 값까지 한 벡터에 섞인다. 입력이 10×10이면 Pooling 뒤 5×5라 50개가 되어 이 모델의 Linear32와 맞지 않는다. shape 검사도 자료 계약의 일부다.

코드와 확인 범위

nn.Module의 __init__에서 층을 등록하고 forward에서 연결한다. 아래 코드는 구조 예시다. 실제 실행은 하지 않았으며 설치 없이 종이 추적 활동만 해도 이 단원 목표를 수행할 수 있다.

추후 실행할 때 입력 shape, 출력 shape, 손실·라벨 계약, 학습·평가 자료 분리를 확인한다. 무작위 초기 점수나 shape가 맞는 결과는 인식 정확도·학습 완료·학생 이해도의 증거가 아니다.

import torch
from torch import nn

class TinyCNN(nn.Module):
    def __init__(self):
        super().__init__()
        self.features = nn.Sequential(
            nn.Conv2d(1, 2, kernel_size=3, padding=1),
            nn.ReLU(),
            nn.MaxPool2d(kernel_size=2, stride=2),
        )
        self.classifier = nn.Linear(32, 2)

    def forward(self, x):
        # 입력 계약: (N, 1, 8, 8). 실행하지 않은 예시 코드.
        z = self.features(x)
        z = torch.flatten(z, start_dim=1)
        return self.classifier(z)

중간 과정을 따라가는 예제

N=3인 입력에서 층별 shape와 bias 포함 총 학습 파라미터 수를 구하라.

  1. 합성곱/ReLU 뒤(3,2,8,8), pooling 뒤(3,2,4,4), flatten 뒤(3,32), Linear 뒤(3,2)다.
  2. Conv는 2×(1×3×3+1)=20개다. Linear는 2×32+2=66개다.
  3. ReLU·pooling·flatten은 이 모델에서 학습 파라미터가 0개라 총 86개다.

최종 shape (3,2), 파라미터 86개다. 점수 수 2는 분류 종류 수이며 배치 3을 바꾸지 않는다.
