소단원 11.1

self-attention과 multi-head

같은 문장의 단어들이 서로의 정보를 다른 방식으로 참고할 수 있을까?

준비 개념과 학습 목표

준비 개념

  • 행렬곱과 shape

  • query·key·value

  • softmax와 가중합

학습 목표

  • self-attention의 Q/K/V 출처를 설명한다.

  • head별 가중합과 출력 투영을 계산한다.

  • 토큰 수와 특징 차원에 따른 행렬 모양을 추적한다.

같은 입력에서 세 역할을 만든다

각 토큰의 벡터를 행으로 쌓은 X가 n×d_model이라 하자. Self-attention은 같은 X로 Q=XW_Q, K=XW_K, V=XW_V를 만든다. 같은 자료에서 나오지만 투영 행렬이 다르므로 세 벡터가 서로 같아야 하는 것은 아니다. Query는 무엇을 찾는지, key는 참고할 위치의 비교 정보, value는 가져올 내용을 나타내는 계산 역할이다.

한 query 행과 모든 key의 내적을 구하고 key 차원 d_k의 제곱근으로 나눈다. 행별 softmax를 적용한 뒤 V와 곱하면 참고 위치의 value를 섞은 결과다. 이 단원에서는 dropout을 적용하지 않는 종이 계산을 사용하므로 각 행의 가중치가 음이 아니고 합이 1이다. Attention 가중치만으로 사람의 설명이나 인과 관계가 증명되지는 않는다.

여러 head는 각각의 투영으로 계산한다

Multi-head는 같은 입력을 여러 투영으로 보아 head별 attention을 계산한다. Head 출력들을 특징 방향으로 이어 붙인 뒤 W_O로 출력 특징을 만든다. Head마다 항상 서로 다른 의미나 특정 문법 관계를 맡도록 보장한 구조는 아니며 그런 해석에는 실제 측정이 필요하다.

가장 흔한 균등 분할 예로 d_model=4, head 수=2, 각 d_k=d_v=2를 쓰자. 토큰 3개이면 각 Q/K/V는 3×2, 점수는 3×3, head 출력은 3×2다. 두 출력 연결은 3×4이고 W_O가 4×4라면 최종 출력도 3×4다. Head 수만큼 토큰 수가 늘어나는 것이 아니다.

가중 평균과 최종 출력은 다르다

하나의 head가 scalar value를 가중합하는 동안에는 결과가 그 value들의 범위 안에 있다. 하지만 연결 뒤의 출력 투영에는 음수 계수도 있을 수 있으므로 최종 출력까지 항상 원래 value의 볼록 평균이라고 단정할 수 없다. 여러 차원의 value도 같은 가중치를 성분별로 적용한다.

아래 예는 이미 투영된 특정 query의 점수와 value를 주는 작은 계산이다. 전체 X와 모든 투영 행렬을 학습한 결과라는 주장은 하지 않는다. 실제 self-attention 구현에서는 입력·투영·마스크·행별 정규화의 shape를 함께 확인해야 하며 이 종이 예로 속도나 품질을 평가하지 않는다.

중간 과정을 따라가는 예제

투영 후 특정 query의 첫 head 점수는 (log 3, 0), scalar value는 (2, 10)이다. 둘째 head 점수는 (0, 0), value는 (−2, 6)이다. d_k=1이고 log는 자연로그다. 두 출력을 연결한 행벡터에 W_O=(1, −1)의 열벡터를 곱하라.

  1. 첫 head의 exp 점수는 (3, 1)이므로 가중치는 (3/4, 1/4)다. 출력은 (3/4)×2+(1/4)×10=4다.

  2. 둘째 head의 가중치는 (1/2, 1/2), 출력은 (−2+6)/2=2다.

  3. 연결 행벡터는 (4, 2)이며 출력 투영은 4×1+2×(−1)=2다.

Head 출력은 4와 2, 연결 뒤 출력은 2다. 출력 투영은 각 head의 단순 평균이 아니다.

종이와 본문으로 직접 해보기

첫 head의 점수는 고정하고 value 순서만 (10, 2)로 바꾸라. 출력과 균등 평균을 비교하고, 토큰 3개·d_model 4·head 2·d_k=d_v 2의 연결 출력 shape도 적어라.

힌트 보기

가중치가 어느 위치에 붙는지 유지한다. Head 출력의 열 수를 합하고 행 수는 보존한다.

풀이 보기

첫 head는 (3/4)×10+(1/4)×2=8이다. 균등 평균은 6이라 다르다. 각 head 3×2를 연결하면 3×4이며 W_O 4×4를 곱해도 3×4다.

오해와 반례

Self-attention이므로 Q, K, V가 반드시 같은 벡터다.

같은 X라도 서로 다른 W_Q/W_K/W_V를 적용하면 값이 다르다. 같은 출처와 같은 값은 다른 조건이다.

자기점검

답과 이유 보기

각 query 행의 key 위치 방향이다.

한 query가 참고하는 위치의 가중치 합을 1로 만든다.

답과 이유 보기

그럴 필요가 없다.

점수의 두 축은 query/key 위치이며 value 특징 차원과 다르다.

d_k=1의 스케일 분모는?

답과 이유 보기

1이다.

sqrt(1)=1이다.

한 단계 더

첫 head의 두 점수를 모두 0으로 바꾸면 원래 value (2, 10)의 출력은 6이다. 점수의 차이와 value의 크기를 각각 바꾸며 어느 변화가 가중치와 어느 변화가 가져올 내용을 바꾸는지 설명하자. 토큰 수를 두 배로 하면 조밀한 self-attention 점수의 원소 수는 네 배다. 실제 메모리 사용은 구현과 저장 중간값에도 의존한다.

소단원 11.2

위치정보와 마스크

단어를 바꿔 놓거나 아직 나오지 않은 답을 가려야 할 때 무엇을 추가할까?

준비 개념과 학습 목표

준비 개념

  • 벡터 덧셈

  • softmax

  • 행·열 위치와 가중합

학습 목표

  • 위치 정보와 토큰 내용의 역할을 구별한다.

  • causal mask와 padding mask를 비교한다.

  • 마스크 적용 후 허용 위치의 정규화를 계산한다.

토큰 내용만으로 위치를 지정하지 않는다

위치 신호나 위치 의존 마스크가 없는 self-attention에 토큰 행을 같은 순열로 재배열하면 출력 행도 대응하여 재배열된다. 이를 순열 등변성이라고 한다. 출력이 무조건 같은 고정 행렬이라는 순열 불변성과 다르다. 순서를 사용하는 문제에는 위치에 관한 정보가 필요하다.

원래 Transformer의 한 방법은 입력 임베딩에 위치 벡터 P를 더하는 것이다. 짝수 d_model일 때 P(p,2i)=sin(p/10000^(2i/d_model)), P(p,2i+1)=cos(p/10000^(2i/d_model))다. p는 0부터의 위치다. 학습 위치 벡터나 다른 위치 표현도 있으므로 이 식이 모든 Transformer의 유일한 규칙은 아니다.

보지 말아야 할 위치를 점수에서 가린다

Causal mask는 현재 query 위치보다 뒤의 key 위치를 가려 미래 답을 엿보지 않도록 한다. 1부터의 행 번호 i에서 j≤i를 허용하고 j>i를 차단한다. 이상적인 덧셈 마스크는 허용 위치 0, 차단 위치 −∞이며 softmax 이전 점수에 더한다. 최소 한 위치가 허용된 행에서 차단 위치의 exp는 0이다.

Padding mask는 길이를 맞추느라 넣은 빈 토큰을 참고하지 않도록 한다. 미래 위치를 가리는 causal mask와 목적이 다르며 함께 적용할 수 있다. 차단 뒤 허용 위치 사이에서 다시 정규화해야 한다. Softmax 후 일부 값을 0으로만 바꾸면 남은 합이 1이 아닐 수 있다. 모든 위치를 가린 행은 표준 softmax로 정의되지 않으므로 구현의 처리와 입력 조건을 따로 확인한다.

마스크는 실수를 숨기는 장식이 아니다

학습할 때 정답 문장 전체가 메모리에 있더라도 다음 토큰을 예측하는 decoder가 미래 정답에 접근하면 과제가 바뀐다. Causal mask와 입력의 한 칸 이동이 함께 필요하다. 추론에서는 이미 생성한 접두부만 사용하며 캐시는 계산을 재사용하는 방법이지 미래 정답을 저장하는 허가가 아니다.

위치 벡터를 더하는 것은 위치를 알리는 방법이고 마스크는 접근을 제한하는 방법이다. 둘 중 하나가 나머지를 자동으로 대신하지 않는다. 아래 예는 내용 점수가 모두 0인 조건을 고정하므로 허용된 위치에서만 균등 가중치가 나온다. 실제 모델 점수는 보통 균등하지 않다.

중간 과정을 따라가는 예제

세 위치의 모든 원래 점수는 0, scalar value는 (2, 4, 12)다. 각 행 i가 key 1부터 i까지만 허용하는 causal mask를 적용하여 출력 세 개를 구하라.

  1. 첫 행은 위치 1만 허용하므로 가중치 (1, 0, 0), 출력 2다.

  2. 둘째 행은 위치 1·2를 허용하여 가중치 (1/2, 1/2, 0), 출력 (2+4)/2=3이다.

  3. 셋째 행은 모두 허용하여 가중치 (1/3, 1/3, 1/3), 출력 (2+4+12)/3=6이다.

출력은 (2, 3, 6)이다. Causal mask 없이 모든 위치를 허용하면 세 행 모두 6이다.

종이와 본문으로 직접 해보기

위치 3이 padding이면 앞 예의 셋째 query에서 padding key를 추가 차단했을 때 출력을 구하라. d_model=4의 정현파 위치 벡터 P(0)와 P(1)도 식으로 적어라. 여기서는 셋째 query의 계산 자체는 관찰하되 padding 출력의 사용 여부는 별도다.

힌트 보기

허용 key는 1·2뿐이다. i=0의 분모는 1, i=1의 분모는 100이다.

풀이 보기

셋째 query 출력은 (2+4)/2=3이다. P(0)=(0, 1, 0, 1), P(1)=(sin 1, cos 1, sin 0.01, cos 0.01)이다. 각도는 라디안이며 d_model=4에서 10000^(2/4)=100이다.

오해와 반례

위치 인코딩을 더했으므로 미래 정답 접근도 자동으로 막힌다.

위치 표시는 접근 제한이 아니다. 위치 벡터가 있어도 점수 계산에서 미래 key를 허용하면 그 정보를 섞을 수 있으므로 causal mask가 별도로 필요하다.

답과 이유 보기

볼 수 없다.

3>2이므로 차단한다.

모든 위치를 차단한 행을 보통 softmax의 균등 결과로 해석해도 되는가?

답과 이유 보기

안 된다.

−∞만 있는 행의 정규화는 정의되지 않아 별도 처리가 필요하다.

한 단계 더

Softmax (1/3, 1/3, 1/3) 뒤 셋째 값만 0으로 만들면 합은 2/3이다. 차단된 위치를 점수 단계에서 제외한 (1/2, 1/2, 0)과 비교하자. 별도 종이 예에서 위치 벡터 P0=(0,0), P1=(1,0), A=(2,0), B=(0,2)를 더하면 A,B 순서는 (2,0),(1,2), B,A 순서는 (0,2),(3,0)가 된다. 이 임의 위치 벡터는 정현파 식과 구별한다.

  • 학습 병렬 계산과 순차 생성을 구별한다.

Encoder는 입력 안의 관계를 계산한다

원래 Transformer encoder는 입력 위치끼리 self-attention을 하고 각 위치에 같은 feed-forward network를 적용한다. Padding 같은 제한을 제외하면 양쪽 입력 문맥을 참고할 수 있다. FFN을 위치마다 적용한다는 말은 전체 모델이 위치 사이의 관계를 전혀 쓰지 않는다는 뜻이 아니다. 앞 attention이 이미 위치 정보를 섞었다.

잔차 덧셈을 하려면 두 항의 위치 수와 특징 차원이 맞아야 한다. 원래 구조의 각 sublayer 출력에는 잔차 후 LayerNorm을 적용하지만 여러 현대 구조는 순서가 다를 수 있다. 특정 교재의 원래 구조를 모든 모델의 고정 규칙으로 일반화하지 않는다.

Decoder는 접두부와 encoder 표현을 나누어 참고한다

원래 decoder에는 causal self-attention, encoder 출력에 대한 cross attention, 위치별 FFN이 있다. Self-attention의 Q/K/V는 decoder 쪽에서 나오고 cross attention의 Q는 decoder, K/V는 encoder 출력에서 나온다. 서로 다른 수의 입력·출력 위치를 연결하므로 cross 점수는 일반적으로 정사각 행렬이 아니다.

입력 길이가 3, decoder 위치가 4이면 encoder 점수는 3×3, decoder self 점수는 4×4, cross 점수는 4×3이다. Cross attention은 입력 원문의 유효 위치를 참고하며 decoder 미래 목표 위치를 읽는 장치가 아니다. 입력 padding mask와 decoder causal mask를 각 계산에 맞게 적용한다.

정답을 아는 학습과 모르는 생성

학습에서 목표가 t1,t2,t3,EOS이면 decoder 입력을 BOS,t1,t2,t3으로 이동시켜 같은 네 위치의 출력이 각각 다음 목표를 예측하게 한다. 두 번째 위치는 BOS와 t1을 참고하고 t2를 목표로 삼는다. 그 위치가 decoder 입력의 미래 t2를 참고하면 정답 누출이다.

Causal mask가 있으면 정답 접두부를 주는 teacher forcing 학습의 위치 계산을 병렬 처리할 수 있다. 실제 생성은 새 토큰을 고른 뒤 그 토큰을 다음 접두부에 넣어 이어 간다. Encoder-only와 decoder-only 구조도 있으며 decoder-only에 항상 encoder cross attention이 있다고 가정하지 않는다. 구조 비교는 실제 모델의 품질을 측정한 결과가 아니다.

중간 과정을 따라가는 예제

입력 3개, decoder 입력 BOS,t1,t2,t3의 4개, 목표 t1,t2,t3,EOS다. 세 점수 행렬 shape와 causal self-attention 허용 칸 수를 구한다. 한 cross query의 가중치 (1/4,1/2,1/4), encoder scalar value (2,6,10)의 출력도 구하라.

  1. Encoder self 점수는 3×3, decoder self는 4×4, cross는 4×3이다.

  2. Causal 허용 칸은 1+2+3+4=10개다. 전체 16개 중 뒤쪽 6개를 차단한다.

  3. Cross 출력은 (1/4)×2+(1/2)×6+(1/4)×10=6이다.

Shape는 3×3, 4×4, 4×3이고 causal 허용은 10칸, cross 가중합은 6이다. 이 가중합은 vocabulary의 다음 토큰 확률 자체가 아니다.
