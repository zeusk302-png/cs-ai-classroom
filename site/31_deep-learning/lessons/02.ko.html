소단원 2.1

연쇄법칙

입력 x가 두 갈래로 흘러 같은 손실에 도달하면 어느 길의 영향을 세어야 할까?

준비 개념과 학습 목표

준비 개념

  • 함수는 입력에서 출력을 정한다. f′(a)는 lim(h→0)[f(a+h)−f(a)]/h이며 순간 기울기다. x²의 미분은 2x이고, 상수의 미분은 0이다.
  • 편미분 ∂L/∂x는 다른 독립 입력을 고정하고 x만 바꾸는 미분이다. 열벡터 기울기 ∇L은 모든 편미분을 쌓은 것이다.
  • F:ℝⁿ→ℝᵐ의 Jacobian J_F는 m×n이며 (i,j)칸은 ∂F_i/∂x_j다. 열린 근방에서 실미분 가능하다는 것은 F(a+h)=F(a)+J_F(a)h+o(||h||)라는 선형 근사를 뜻한다.

학습 목표

  • 계산그래프의 값과 국소 미분을 구별한다.
  • 미분 가능한 합성에서 경로를 따라 곱하고 합류 경로를 더한다.
  • 벡터 연쇄법칙의 형상·전치와 꺾임의 예외를 설명한다.

작은 변화가 연속된 계산을 통과하기

곱 u=xy에서 y를 고정하면 ∂u/∂x=y다. 합 v=u+x에서는 각각의 국소 미분이 1이다. 마지막 L=v²의 미분은 2v다. 국소 미분은 그 노드의 바로 앞 입력에 대한 값이고, 손실 전체의 입력 기울기는 뒤 노드의 영향까지 연결해야 한다.

x가 u를 거치는 길과 v에 직접 들어가는 길은 모두 L에 영향을 준다. L=(xy+x)²에서 ∂L/∂x=2v·y+2v·1=2v(y+1)이다. 한 길만 세면 실제 함수의 편미분이 달라진다. 계산한 L 자체와 ∂L/∂x를 같은 숫자라고 생각하지 않는다.

합성의 정리와 형상

F가 a에서 실미분 가능하고 G가 F(a)에서 실미분 가능하며 근방 합성이 정의되면 D(G∘F)(a)=DG(F(a))DF(a)다. Jacobian으로 J_(G∘F)=J_G J_F다. 편미분들이 한 점에서 존재하기만 한다는 약한 조건으로 이 정리를 자동 적용하지 않는다. 근방에서 모든 편미분 연속은 미분 가능성의 충분조건이다.

스칼라 L=G(F(x))에서 열벡터 ∇_xL=J_Fᵀ∇_zG, z=F(x)다. n×m과 m×1을 곱해 n×1을 얻는다. 형상 일치는 필요하지만 수식의 정당성 증명 자체는 아니다. 나눗셈 노드는 분모가 0이 아니어야 하고 log 노드는 양수 입력이라는 정의역도 점검한다.

공유 값과 자동미분의 경계

한 변수의 여러 사용을 서로 독립 변수처럼 임시로 나눈 뒤 다시 같은 변수로 묶으면 각 사용의 편미분이 합쳐진다. 예를 들어 x²=x·x는 두 입력 슬롯의 미분 x+x=2x다. 배치 각 항에 같은 편향 b를 더하면 b에 대한 모든 항의 기여를 합한다. 평균 손실이면 먼저 정한 평균 계수도 함께 곱한다.

ReLU r(z)=max(0,z)는 z>0에서 1, z<0에서 0으로 미분되지만 0에서 고전 미분이 없다. 소프트웨어가 0에서 특정 값을 반환하는 규칙은 미분 존재 증명이 아니다. 자동미분은 기록된 연산의 규칙을 연결한다. 정수 선택·끊긴 그래프·지원하지 않는 연산이나 잘못된 자체 미분 규칙까지 저절로 검증하지 않는다.

중간 과정을 따라가는 예제

실수 x=2,y=3에서 u=xy, v=u+x, L=v²의 값과 두 입력 편미분을 구하라. 모든 연산은 정확 실수 산술 모형이다.

  1. u=2·3=6, v=6+2=8, L=8²=64로 순서대로 값을 구한다.
  2. 마지막 국소 미분 dL/dv=2v=16이며 ∂v/∂u=1, 직접 슬롯 ∂v/∂x=1이다.
  3. x의 곱 경로 기여는16·1·y=48, 직접 경로 기여는16·1=16이다. 합하면 ∂L/∂x=64다.
  4. y는 곱 경로만 있으므로 ∂L/∂y=16·1·x=32다. 직접 전개 L=x²(y+1)²를 미분해도 (64,32)를 얻는다.

L=64, ∇L=(64,32)ᵀ. 값64와 첫 기울기64의 일치는 이 입력의 우연이다.

종이와 본문으로 직접 해보기

같은 그래프를 x=1,y=−1에서 계산하라. 별도로 고정 x₁=1,x₂=2와 공유 편향 b=1인 Q=(x₁+b)²+(x₂+b)²의 ∂Q/∂b를 종이에 구하라.

힌트 보기

v가0이면 마지막 미분도0이다. 공유 b에는 두 제곱항의 영향을 더한다.

풀이 보기

첫 경우 u=−1,v=0,L=0, 두 편미분 모두0이다. Q는2²+3²=13, ∂Q/∂b=2·2+2·3=10이다. 두 항 평균 Q/2를 쓰면5다. 실제 배치나 프로그램 실행은 없다.

오해와 반례

계산그래프에 숫자만 채우면 손실의 기울기도 그 숫자와 같다.

x=1,y=0이면 L=1인데 ∂L/∂x=2다. 값과 기울기는 별개다. 또한 x가 갈라지는 예제에서48만 쓰면 직접 경로16을 놓쳐 올바른64를 얻지 못한다.

자기점검

L=v²에서 v=−2이면 국소 미분은4인가?

답과 이유 보기

−4다.

2v=−4이며 함수값 v²=4와 다르다.

J_F가3×2이고 ∇_zG가3×1이면 입력 기울기의 형상은?

답과 이유 보기

2×1이다.

J_Fᵀ는2×3이므로 J_Fᵀ∇_zG가2×1이다.

ReLU의0에서 자동미분이0을 반환하면 고전 미분이 존재하는가?

답과 이유 보기

그렇지 않다.

왼쪽 기울기0과 오른쪽1이 달라 미분이 없다. 반환 규칙은 별 선택이다.

한 단계 더

심화: 연쇄법칙의 나머지를 확인하자. F(a+h)=F(a)+Ah+r(h), ||r(h)||/||h||→0이고 G(z+k)=G(z)+Bk+s(k), ||s(k)||/||k||→0라 하자. k=Ah+r(h)는 ||k||=O(||h||)이고 k→0다. 합성 증분은 BAh+Br(h)+s(k)이며 뒤 두 항은 o(||h||)다(k=0에서는 s(0)=0). 따라서 선형 부분은 BA다. 분기 합산도 이 선형 근사를 각 독립 슬롯에 적용한 뒤 공유 슬롯의 같은 증분을 넣으면 나온다. 이 증명은 실미분 가능성을 전제로 하며 한 점의 일부 편미분만으로 대체하지 않는다.

소단원 2.2

순방향·역방향 미분

입력 방향 하나의 변화와 손실 하나의 모든 입력 기울기는 같은 방식으로 계산해야 할까?

준비 개념과 학습 목표

준비 개념

  • 유한 DAG는 순환 없는 계산그래프다. 각 노드는 앞 노드 값의 함수이며 위상 순서로 값을 계산하고 역순으로 영향을 전파할 수 있다.
  • F:ℝⁿ→ℝᵐ의 J는 m×n이다. 입력 방향 v∈ℝⁿ에 대한 Jv는 m×1이고 출력 가중 c∈ℝᵐ에 대한 Jᵀc는 n×1이다.
  • 순방향 값 계산과 순방향 미분은 다르다. 전자는 함수값을 구하고 후자는 값과 함께 선택한 방향의 민감도를 구한다. 여기서는 열린 근방의 미분 가능한 실수 연산·고정 유한 그래프를 가정한다.

학습 목표

  • 순방향 미분의 방향 씨앗과 역방향의 출력 씨앗을 구별한다.
  • 공유 노드에 돌아오는 기여를 누적한다.
  • JVP/VJP의 목적·횟수·메모리 조건을 설명한다.

값 옆에 방향 미분을 붙이기

입력 x(ε)=x+εv_x,y(ε)=y+εv_y를 생각한다. 점 위의 방향 미분을 점으로 표시해 ẋ=v_x,ẏ=v_y라 쓰자. u=xy이면 u̇=y ẋ+x ẏ, v=u+x이면 v̇=u̇+ẋ다. 각 노드의 값과 이 한 방향 민감도를 앞에서 뒤로 전달한다.

마지막 L=v²이면 L̇=2v v̇다. 이는 ∇Lᵀ(v_x,v_y)ᵀ이고 전체 기울기 두 성분을 한 번에 얻었다는 뜻은 아니다. 입력 표준기저 (1,0),(0,1)를 각각 씨앗으로 쓰면 두 편미분을 얻는다. 벡터 출력을 갖는 F에서도 한 방향의 Jv를 얻는다.

손실의 영향을 뒤로 되돌리기

역방향에서는 스칼라 손실의 씨앗 L̄=1을 두고 L̄가 전달하는 ∂L/∂노드값을 구한다. L=v²에서 v̄=2v, v=u+x에서 ū에 v̄를 보내고 x̄에 직접 v̄를 더한다. u=xy에서는 x̄에 y ū, ȳ에 x ū를 더한다. 공유 입력 x에는 두 기여가 합쳐진다.

일반 출력 F의 씨앗 c를 고정하면 역방향 결과 Jᵀc는 스칼라 cᵀF의 기울기다. 모든 출력에 1을 넣는 것은 출력 합의 기울기이며 전체 m×n Jacobian 자체가 아니다. 반복 호출 사이의 오래된 누적 버퍼와 한 그래프 안의 분기 합산도 구별해야 한다. 초기값 0에서 이번 기여를 모으는 것이 아래 종이 규칙이다.

어느 방향이 알맞은가

n개 입력·m개 출력의 전체 Jacobian을 기저 씨앗으로 만들 때 순방향은 n개 JVP, 역방향은 m개 VJP가 기본 비교다. 출력 하나인 손실에서 많은 매개변수 기울기를 구하는 경우 역방향이 자연스럽다. 단위 연산별 미분 비용이 원연산과 같은 차수라는 모형에서 씨앗 하나의 전파는 그래프 연산 비용과 같은 차수다.

역방향은 국소 미분에 필요한 앞선 값을 보관하거나 재계산한다. 시간·메모리의 상수와 체크포인트 전략은 별 문제이고 모든 장치에서 더 빠르다는 실측 결론이 아니다. 실제 API에서는 tangent 형상·자료형·장치 및 연산 지원을 확인한다. 읽은 PyTorch 튜토리얼의 beta 표시는 문서의 설명이며 이 단원은 해당 버전을 실행하지 않았다.

중간 과정을 따라가는 예제

x=2,y=3에서 u=xy,v=u+x,L=v²를 순방향 씨앗 (1,0)으로 미분하고 역방향으로 전체 기울기를 구하라.

  1. 값은 u=6, v=8, L=64이며 입력 방향은 ẋ=1, ẏ=0이다.
  2. 순방향 u̇=3·1+2·0=3, v̇=3+1=4, L̇=16·4=64다.
  3. 역방향 L̄=1에서 v̄=16, ū=16이다. x의 직접 기여 16에 곱 경로 48을 누적하고 y에는 32를 보낸다.
  4. 역방향 결과 (64,32)ᵀ와 방향 (1,0)의 내적64가 순방향 결과와 일치한다. 하나의 JVP만으로 둘째 성분32를 구한 것은 아니다.

순방향 JVP=64, 역방향 ∇L=(64,32)ᵀ이며 값64와 의미가 다르다.

종이와 본문으로 직접 해보기

F(x,y)=(xy,x+y)에서 (x,y)=(2,3), 방향 d=(1,−1), 출력 씨앗 c=(2,1)을 두고 Jd와 Jᵀc를 구하라. 별도로 f(x)=x·x+x의 x=2 역방향 기울기를 구하라.

힌트 보기

J의 첫 행은 (y,x), 둘째는 (1,1)이다. 같은 x를 사용하는 슬롯의 기여를 덮어쓰지 않는다.

풀이 보기

J=[[3,2],[1,1]], Jd=(1,0)ᵀ, Jᵀc=(7,5)ᵀ다. cᵀJd=2와 (Jᵀc)ᵀd=2도 같다. f는 값6, 두 곱 슬롯2+2와 직접1을 합해 기울기5다. 모두 종이 계산이다.

오해와 반례

역방향 씨앗을 모두1로 두면 전체 Jacobian이 나온다.

F=(xy,x+y)의 씨앗 (1,1)은 Jᵀ(1,1)=(4,3)ᵀ만 낸다. 전체 J는2×2이고 두 출력 편미분의 합은 각 행을 구별하지 못한다.

자기점검

순방향 씨앗 (0,1)은 L의 어떤 값인가?

답과 이유 보기

소단원 2.3

기울기 검사

두 기울기 숫자가 한 점에서 비슷하면 미분 구현 전체가 맞는 걸까?

준비 개념과 학습 목표

준비 개념

  • 중심차분 D_hf(a)=[f(a+h)−f(a−h)]/(2h), h>0은 미분의 근삿값이다. 두 평가점이 정의역 안에 있어야 한다.
  • 좌표 편미분 검사는 다른 좌표를 고정하고 a±h e_j를 쓴다. 독립 수치 비교는 같은 손실 정의·축약 평균/합·고정 자료·매개변수를 사용한다.
  • 실수 정확 산술과 부동소수는 다르다. 두 비슷한 값을 빼는 소거와 반올림, 미분 불가능한 꺾임, 바뀌는 난수·상태는 검사 결과에 영향을 준다.

학습 목표

  • 유한차분 오차를 실제 미분과 구별한다.
  • 절대·상대 척도와0/꺾임 조건을 명시한다.
  • 기울기 검사 통과의 국소적 증거와 한계를 설명한다.

다른 길로 같은 미분을 근사하기

그래프 미분과 다른 계산인 함수값 중심차분을 비교하면 경로 합산이나 계수 누락을 발견할 수 있다. 검사할 좌표만 ±h만큼 바꾸고 나머지 조건을 고정한다. 이는 라이브러리에서 반환한 기울기를 그대로 다시 읽는 검사가 아니라 손실값 두 평가로 얻는 별 근삿값이다.

f가 근방에서 C³이고 세 번째 도함수의 절댓값이 M 이하이면 중심차분의 절단 오차는 Mh²/6 이하로 제한된다. h가 작아지는 만큼 정확 산술에서는 이 항이 작아진다. 그러나 실제 연산의 반올림으로 함수값 자체가 변하면 h를 무작정 작게 정할 수 없다.

척도와 재현 조건을 함께 쓰기

차이 |g−D|를 먼저 기록하고 필요하면 |g−D|/max(|g|,|D|)를 쓴다. 둘 다 0이면 이 상대식은0/0이므로 별도로 일치 처리한다. 거의0인 값은 상대식만으로 평가하지 않고 명시한 절대 허용량도 함께 본다. 허용량은 자료형·오차 예상·문제 척도에 따른 선택이지 모든 신경망의 공통 정리가 아니다.

두 손실 평가와 그래프 기울기는 같은 자료·상태·목적함수를 사용해야 한다. dropout이나 증강을 끄면 그 고정 함수만 검사한 것이며 원래 확률 모형 전체를 검사한 것이 아니다. 같은 난수 실현을 의도적으로 고정하는 경우도 어떤 실현의 미분인지 기록한다. 씨앗 숫자만 같다고 모든 장치·연산 순서의 완전 재현이 보장되지는 않는다.

한 점의 통과와 꺾임

f(x)=|x|의0에서 중심차분은 모든 h>0에 대해0이다. 하지만 좌우 미분이−1과1이어서 고전 미분은 없다. 이 점에서 자동미분 선택값0과 일치해도 존재하지 않는 미분을 인증한 것은 아니다. ReLU 경계를 가로지르는 차분도 같은 주의를 요구한다.

여러 매개변수·점·h를 조사하면 더 많은 반례 기회를 얻지만 유한 검사가 전체 정의역의 증명으로 바뀌지는 않는다. 예를 들어 x³의 잘못된 기울기를 항상12라고 구현하면 x=2에서만 정확 미분12와 맞고 x=1에서는3과 다르다. 데이터 손실과 정규화 항을 분리해 검토하는 것도 어느 항의 오류가 가려지는지 확인하는 방법이다.
