소단원 9.1

RNN과 BPTT

같은 숫자를 다른 순서로 읽으면 기억의 마지막 값도 같을까?

준비 개념과 학습 목표

준비 개념

  • 합성함수와 연쇄법칙

  • 벡터와 행렬 곱

학습 목표

  • 순환 상태의 시간별 갱신을 계산한다.

  • 공유 매개변수의 전체 경로 미분과 절단을 구별한다.

한 시점의 결과를 다음 시점에 전달하기

RNN은 순서 t의 입력 xₜ와 이전 은닉 상태 hₜ₋₁로 새 상태를 만든다. 열벡터 약속에서는 hₜ=φ(Wxₜ+Uhₜ₋₁+b)처럼 쓴다. 입력과 상태 차원이 달라도 각각의 행렬 곱이 같은 상태 차원으로 나오면 더할 수 있다.

같은 W,U,b를 매 시점 재사용한다. 시간 단계 수만큼 서로 다른 가중치를 만드는 방식이 아니다. 초기 상태와 시퀀스 경계를 정해야 하며 독립적인 새 문장을 이전 문장의 상태와 무조건 이어 붙이지 않는다. 출력층은 필요에 따라 매 시점이나 마지막 유효 상태에 연결한다.

시간을 펼친 뒤 경로를 따라 미분하기

시간 순환을 1,2,3 시점의 계산 그래프로 펼치면 일반적인 연쇄법칙을 적용할 수 있다. 이것이 BPTT다. 같은 매개변수가 여러 시점에 등장하므로 그 매개변수의 변화가 손실에 도달하는 모든 경로의 기여를 더한다. 순방향 계산의 기억과 역방향 미분 경로를 구별한다.

계산을 단순하게 보기 위해 아래에는 hₜ=a hₜ₋₁+xₜ라는 스칼라 선형 모형을 쓴다. 활성화 φ는 항등함수이고 출력은 마지막 상태 자체다. 이는 tanh RNN의 학습 결과가 아니라 공유 매개변수 a의 미분을 정확히 볼 수 있는 교육용 특수 모형이다.

긴 경로의 곱과 절단

선형 모형에서 과거 입력의 영향은 a의 반복 곱을 포함한다. |a|<1이면 긴 거리를 거치며 작아지고 |a|>1이면 커질 수 있다. 일반 RNN에서는 활성화 도함수와 행렬 Jacobian도 함께 곱해지므로 스칼라 a 하나의 조건을 그대로 모든 네트워크에 적용하지 않는다.

절단 BPTT는 일부 이전 상태의 미분 경로를 끊어 계산 부담을 줄이는 근사다. 상태 값을 다음 구간에 전달하면서 미분 연결만 끊을 수도 있다. 따라서 상태 초기화와 미분 경로 절단은 같은 동작이 아니다. 큰 기울기 클리핑 역시 과거의 사라진 정보까지 복구하는 방법은 아니다.

중간 과정을 따라가는 예제

h₀=0, 입력 (1,2,−1), a=1/2인 자체 선형 순환계에서 L=h₃²/2와 dL/da를 구하라.

  1. h₁=1, h₂=(1/2)×1+2=5/2, h₃=(1/2)×(5/2)−1=1/4이다.

  2. 상징적으로 h₂=a+2, h₃=a²+2a−1이다. 따라서 dh₃/da=2a+2=3이다.

  3. L=(1/4)²/2=1/32이고 dL/da=h₃×dh₃/da=3/4이다.

  4. h₂의 미분 연결을 끊고 마지막 단계만 미분하면 dh₃/da=h₂=5/2로 간주하여 dL/da=5/8이 된다. 이것은 전체 BPTT의 3/4와 다르다.

상태는 1,5/2,1/4, 손실은 1/32, 전체 기울기는 3/4다. 마지막 단계만의 근사는 5/8이다.

종이와 본문으로 직접 해보기

같은 입력에서 a=1로 바꾸어 상태·손실·전체 기울기를 계산하라. 입력을 (2,1,−1)로 뒤바꾸면 a=1/2의 마지막 상태는?

힌트 보기

h₃=a²+2a−1의 도함수와, 새 순서의 상태를 각각 계산한다.

풀이 보기

a=1이면 상태1,3,2, L=2, dh₃/da=4이므로 기울기는8이다. 새 순서는 h₁=2,h₂=2,h₃=0으로 마지막 값이 이전1/4와 다르다.

오해와 반례

같은 매개변수를 쓰므로 한 시점의 기울기만 계산하면 전체 기울기다.

공유된 매개변수는 이전 상태 생성에도 참여한다. 예제의 마지막 단계만 미분한5/8은 전체3/4와 다르다. 공유는 기여를 생략하는 조건이 아니라 여러 등장 위치의 기여를 더하는 이유다.

자기점검

같은 길이3 입력을 읽으면 U를3개 별개로 학습하나?

답과 이유 보기

기본 RNN에서는 하나의 U를 공유한다.

같은 갱신 규칙을 매 시점 적용한다.

h₂값 전달과 h₂의 미분 연결 절단은 모순인가?

답과 이유 보기

아니다.

순방향 값은 유지하면서 역방향 경로만 끊을 수 있다.

예제의 a=1/2에서 마지막 상태의 x₁에 대한 도함수는?

답과 이유 보기

a²=1/4이다.

x₁에서 h₃까지 두 번의 상태 전달을 거친다.

한 단계 더

선형 상태 전달10번의 계수는 a=1/2일 때1/1024, a=2일 때1024이다. 이 숫자는 영향의 반복 곱을 보여 주며 실제 RNN 학습의 성공률을 뜻하지 않는다. 손실을 시점별 합으로 바꾸면 각 시점 출력에서 오는 경로도 포함해야 한다.

소단원 9.2

LSTM·GRU

새 정보가 들어올 때 이전 기억을 모두 덮어써야 할까?

준비 개념과 학습 목표

준비 개념

  • sigmoid와 tanh의 범위

  • 성분별 곱

학습 목표

  • 셀 상태와 은닉 상태를 구별하여 LSTM을 계산한다.

  • GRU의 reset과 update 역할 및 식의 약속을 설명한다.

기억을 남길 양과 보일 양

LSTM에는 셀 상태 c와 은닉 상태 h가 따로 있다. 여기서는 cₜ=fₜ⊙cₜ₋₁+iₜ⊙gₜ, hₜ=oₜ⊙tanh(cₜ)를 사용한다. f는 이전 셀을 남기는 비율, i는 후보 g를 더하는 비율, o는 현재 셀을 밖으로 드러내는 비율이다. ⊙는 대응 성분끼리의 곱이다.

게이트는 현재 입력과 이전 은닉 상태의 학습 가능한 식에서 계산하며 보통 sigmoid를 거친다. 후보 g는 tanh를 거친다. 유한 실수 입력의 sigmoid 값은0과1 사이이며 정확한0/1은 이상적 경계 설명이다. 본문의 분수 게이트 값은 주어진 값이고 실제 학습해 얻은 값이라고 주장하지 않는다.

GRU는 한 상태를 섞는다

GRU에는 reset 게이트 r와 update 게이트 z가 있다. 이 절은 hₜ=zₜ⊙hₜ₋₁+(1−zₜ)⊙gₜ라는 약속을 쓴다. z가1에 가까우면 이전 상태를 더 남기고0에 가까우면 후보를 더 반영한다. 다른 자료가 z를 새 후보의 비율로 정의한다면 식도 반대로 읽어야 한다.

reset은 후보를 만들 때 과거 상태가 들어가는 경로를 조절한다. reset이 작아도 최종 혼합의 z hₜ₋₁ 경로가 남아 있으므로 전체 상태를 반드시0으로 만드는 것은 아니다. 후보에서 reset을 행렬 곱 전후 어느 위치에 넣는지는 구현마다 차이가 있어 라이브러리 식을 확인한다.

기억 통로의 이득과 한계

LSTM의 셀에는 이전 셀과 새 후보를 더하는 통로가 있다. 게이트가 적절하면 긴 관계를 학습하기 쉬워질 수 있지만 모든 기억을 무한히 보존하거나 모든 기울기 문제를 제거한다는 보증은 아니다. 실제 능력은 학습 데이터와 손실, 파라미터 및 조건에 달려 있다.

c와 h를 모두 저장하는 LSTM과 하나의 h를 쓰는 GRU를 비교하되 무엇이 항상 더 정확하다고 정하지 않는다. 단계별 게이트·후보·상태를 기록하면 계산을 검산할 수 있다. 초기 상태와 길이 처리도 여전히 필요하며 아래 활동은 모델 훈련 없이 수행한다.

중간 과정을 따라가는 예제

자체 스칼라 LSTM에서 이전 c=.8, f=.75,i=.5,g=.4,o=.5가 주어졌다. GRU에서는 이전 h=.8,z=.75,g=−.4가 주어졌다. 각각 갱신하라.

  1. LSTM의 이전 기억 기여는 .75×.8=.6, 후보 기여는 .5×.4=.2이다. c=.8이 된다.

  2. h=.5×tanh(.8)이다. 셀 c=.8과 밖으로 보이는 h는 다른 값이다.

  3. GRU의 이전 기여는 .75×.8=.6, 후보 기여는 .25×(−.4)=−.1이다. 새 h=.5이다.

  4. 게이트가 어느 항에 곱해지는지 표시했다. 후보는 이미 주어져 있으므로 후보 네트워크와 reset의 별도 계산은 하지 않았다.

LSTM c=.8,h=.5tanh(.8), GRU h=.5이다. 두 모델의 서로 다른 상태를 같은 뜻으로 혼동하지 않는다.

종이와 본문으로 직접 해보기

LSTM의 f만.25로 바꾸고, GRU의 z만.25로 바꾸어 각각 계산하라. 다른 주어진 값은 유지한다.

힌트 보기

이전 상태에 대한 기여와 새 후보 기여를 두 항으로 분리한다.

풀이 보기

LSTM c=.25×.8+.5×.4=.4이고 h=.5tanh(.4)이다. GRU h=.25×.8+.75×(−.4)=−.1이다. 이 약속에서는 작은 z가 후보 비율을 높인다.

오해와 반례

GRU reset이0에 가까우면 최종 상태도 반드시0에 가까워진다.

reset은 후보 안의 과거 경로를 줄인다. 이전 h=.8,z=.75이고 후보가0이라고 해도 최종 h=.6이다. 최종 혼합의 이전 상태 경로를 따로 확인해야 한다.

자기점검

LSTM의 c와 h는 항상 같은가?

답과 이유 보기

아니다.

h는 o⊙tanh(c)이고 셀과 출력 상태는 별개다.

이 절의 GRU 식에서 z가1에 가까우면 무엇을 남기나?

답과 이유 보기

이전 h를 더 남긴다.

z가 이전 상태 항의 계수이다.

유한 sigmoid 입력으로 정확한 gate0이나1을 수학적으로 얻나?

답과 이유 보기

아니다.

이상적 경계와 유한 입력의 열린 범위(0,1)를 구별한다.

한 단계 더

이상적으로 LSTM f=1,i=0이면 c가 그대로 전달된다. 그러나 f=.9,i=0으로10번 반복하면 이전 기억은 .9¹⁰배가 된다. 이 직접 셀 통로의 계수와, 게이트가 이전 상태에 의존하는 전체 미분은 구별하라. 이론적 경계는 학습 성공 증명이 아니다.

소단원 9.3

마스킹과 가변길이

빈칸을 붙인 입력을 실제 문장의 일부처럼 읽으면 무엇이 달라질까?

준비 개념과 학습 목표

준비 개념

  • 배치와 시퀀스 길이

  • 가중합과 평균

학습 목표

  • 유효 위치 마스크를 만들고 올바른 분모로 평균한다.

  • 손실 제외와 순환 상태의 패딩 처리 차이를 설명한다.

같은 크기의 배열과 다른 실제 길이

길이3과 길이1의 시퀀스를 같은 배치에 넣으려면 짧은 쪽 뒤에 패딩을 붙일 수 있다. 배열의 폭3과 실제 길이1을 따로 저장한다. 0은 진짜 입력값일 수도 있으므로 모든0을 무효라고 정하지 말고 길이 또는 전용 토큰 계약으로 유효 위치를 판별한다.

시점 t를1부터 센다면 mᵢₜ는 t≤길이ᵢ일 때1, 그 밖은0이다. 토큰 단위 손실의 합은 Σmᵢₜℓᵢₜ이고 유효 토큰 평균의 분모는 Σmᵢₜ이다. 분모가0이면 나눌 수 없으므로 배치 제외 등 명시적인 정책을 정한다.

손실을 지우는 것과 상태를 멈추는 것

패딩 위치의 손실을0으로 만들어도 RNN의 상태 갱신이 저절로 멈추지는 않는다. hₜ=.5hₜ₋₁+xₜ에서 패딩 입력0을 읽으면 상태는 절반으로 바뀐다. 마지막 배열 위치를 무조건 대표 상태로 택하면 짧은 시퀀스의 실제 마지막 상태와 달라진다.

방법은 길이를 사용해 마지막 유효 상태를 선택하거나, 패딩 단계에서 이전 상태를 유지하는 갱신 마스크를 쓰거나, 라이브러리의 packed sequence처럼 실제 길이를 반영하는 방식이다. 이 절의 순방향 한 층 모형에 한정하여 설명한다. 양방향 구조와 다른 모듈의 패딩 영향은 별도로 확인한다.

평균 약속과 API 조건까지 기록하기

모든 유효 토큰을 한꺼번에 평균하면 긴 시퀀스가 더 많은 토큰을 제공한다. 먼저 시퀀스별 평균을 내고 그 평균을 다시 평균하면 시퀀스마다 같은 비중을 가진다. 두 방식 중 목표에 맞는 것을 정하고 보고하며 결과가 항상 같다고 가정하지 않는다.

PyTorch의 pack_padded_sequence는 입력 차원과 길이를 받아 패딩 시퀀스를 묶는다. 길이가 실제보다 짧으면 유효 입력도 잘릴 수 있다. CrossEntropyLoss의 ignore_index는 정수 클래스 목표에 적용하는 손실 제외 옵션이며 순환 상태를 자동으로 동결하지 않는다. 설치와 API 실행은 본 활동의 필수가 아니다.

중간 과정을 따라가는 예제

자체 A=(2,4,6), 길이3과 B=(8,0,0), 길이1을 배치로 둔다. 주어진 위치별 손실은 A=(1,2,3),B=(4,100,100)이다. 마스크 평균을 구하고 h₀=0,hₜ=.5hₜ₋₁+xₜ의 B 마지막 상태를 비교하라.

  1. 길이에 따른 마스크는 A=(1,1,1),B=(1,0,0)이다. 유효 토큰 수는4이다.

  2. 유효 손실 합은1+2+3+4=10이므로 토큰 평균은10/4=2.5이다. 마스크 합10을 배열 전체6개로 나누는10/6과는 다르다.

  3. B를 패딩까지 단순 갱신하면 h는8,4,2이다. 실제 마지막 유효 상태는 첫 시점의8이고 배열 끝의2가 아니다.

  4. 패딩 단계에서 h를 유지하는 마스크를 적용하면 B 상태는8,8,8이다. 손실 마스크만 둔 경우의8,4,2와 구별한다.

유효 토큰 평균2.5, B의 실제 마지막 유효 상태8이다. 패딩 입력0이 순환 연산의 항등 입력은 아니다.

종이와 본문으로 직접 해보기

같은 손실에서 시퀀스별 평균을 먼저 계산한 뒤 두 시퀀스의 평균을 구하라. A의 실제 길이를 잘못2로 주면 어떤 값이 제외되는가?

힌트 보기

A는3개, B는1개 유효 손실을 가진다. 길이를2로 줄이면 A의 세 번째 입력과 손실을 생각한다.

풀이 보기

A 평균은6/3=2, B 평균은4/1=4라 시퀀스 평균은3이다. 토큰 평균2.5와 다르다. A 길이를2라고 하면 실제 입력6과 손실3을 잘못 제외한다. 손실 합1+2+4=7, 토큰 수3으로 평균7/3을 얻게 된다.

오해와 반례

패딩 손실을 무시했으므로 패딩이 모든 출력에 주는 영향도 제거됐다.

B의 손실을 제외해도 순환 상태는8→4→2로 달라질 수 있다. 목표 손실의 제외, 상태 갱신, 마지막 상태 선택은 각각 확인한다. 0을 실제 데이터로 포함하는 경우에는 길이 기준의 마스크가 그0을 보존해야 한다.

한 단계 더

A에 실제 입력0이 있어도 길이 안에 있으면 유효하다. 패딩 추가 전후 동일한 유효 토큰 평균과 대표 상태를 얻는지 종이 표로 확인하라. 실제 라이브러리 검증을 할 때는 배치 순서·길이·정렬 옵션과 원래 식별자 대응도 기록하되, 이 원고에서는 실행을 수행하지 않았다.
