소단원 1.1

알파벳·문자열·언어

아무 문자도 없는 문자열 하나와 문자열이 하나도 없는 집합은 같은 것일까?

준비 개념과 학습 목표

준비 개념

  • 집합은 원소의 포함 여부를 정하며 중복을 세지 않는다. ∅는 원소가 하나도 없는 집합이다.

  • 문자열은 기호를 순서대로 나열한 유한열이다. 같은 기호 수라도 01과 10은 순서가 달라 서로 다른 문자열이다.

  • w∈L은 w가 집합 L의 원소라는 뜻, L⊆K는 L의 모든 원소가 K에도 속한다는 뜻이다.

학습 목표

  • Σ, 문자열,ε,Σ*, 언어 L의 서로 다른 수준을 구별한다.

  • 길이·이어붙이기·언어 연산을 작은 집합에서 계산한다.

  • 형식언어의 기호와 실제 문자/바이트 인코딩을 구별한다.

1. 먼저 기호와 길이를 정한다

이 단원에서 알파벳 Σ는 유한하고 비어 있지 않은 입력 기호 집합으로 선언한다. Σ={0,1}이면 0과 1은 숫자 계산값이 아니라 읽는 기호다. 문자열은 Σ의 기호를 순서대로 나열한 유한열이고 길이|w|는 기호 개수다. 입력 기호가 아닌 문자가 끼면 그 문자열은 Σ 위의 입력이 아니다.

빈 문자열 ε는 기호 0개를 가진 유일한 열이며 |ε|=0이다. ε라는 표기는 “아무 기호도 없음”을 나타내며 이 단원의 입력 기호로 읽지 않는다. 실제 UTF-8의 바이트 수·화면의 글자 수·토큰 수는 별도 인코딩 문제다. 선택한 알파벳 기호 하나를 프로그램이 여러 바이트로 표현할 수도 있다.

2. 가능한 모든 입력과 선택한 언어

Σⁿ은 길이 n인 모든 문자열의 집합이다. Σ⁰={ε},Σ*는 n≥0의 Σⁿ을 모두 합친 집합으로 모든 유한 문자열을 포함한다. 알파벳이 유한해도 문자열 길이에 고정 상한이 없으므로 Σ*는 무한하다. 언어 L은 Σ*의 부분집합이다.

L={w∈{0,1}*:w의 1의 개수가 짝수}는 규칙으로 정의한 무한 언어다.0개의 1도 짝수이므로 ε와 0과 00이 포함되고 1과 1011은 포함되지 않는다. 언어 자체는 집합이고 그 집합을 설명하는 문법·기계·프로그램은 표현 방식이다. 모든 언어가 모든 종류의 유한 기계로 인식되는 것은 아니다.

3. 문자열과 언어의 이어붙이기

문자열 uv는 u 다음에 v를 이어붙인 것이다. 길이는|uv|=|u|+|v|이고 uε=εu=u다. 보통 uv≠vu이며 u=0, v=1이면 01≠10이다. 언어의 이어붙이기 LK={uv:u∈L, v∈K}는 가능한 모든 쌍을 만들고 결과 문자열을 집합으로 모은다.

∅와 {ε}는 다르다. ∅에는 고를 문자열이 없어 L∅=∅이고 L{ε}=L이다. 언어의 반복 L*=⋃(n≥0)Lⁿ은 0번 이어붙인 경우 {ε}도 포함하므로 ∅*={ε}다. 원소가 문자열인지 언어인지 먼저 구별하면 “빈 것”이라는 말에 가려진 차이를 정확히 볼 수 있다.

중간 과정을 따라가는 예제

Σ={0,1}, A={ε,0}, B={1,01}에서 AB와 BA 및 각 집합의 원소 수를 계산한다.

  1. AB의 쌍별 결과는 ε·1=1, ε·01=01,0·1=01,0·01=001이다.

  2. 01이 두 번 나오지만 집합에서 중복을 제거해 AB={1,01,001}이다.

  3. BA의 결과는 1·ε=1,1·0=10,01·ε=01,01·0=010이다.

  4. BA={1,10,01,010}으로 AB와 다르다.

|AB|=3,|BA|=4. |A||B|=4는 가능한 쌍 수이지 언제나 결과의 서로 다른 문자열 수는 아니다.

종이와 본문으로 직접 해보기

종이에 ∅,{ε},{0}를 세 상자로 구별하라. 각 원소 수와 문자열 길이를 적고 C={0}에 대해 C∅, C{ε},∅*를 계산하라.

힌트 보기

원소 수와 원소인 문자열의 길이를 별도 줄에 쓴다. ∅에는 길이를 잴 문자열이 아예 없다.

풀이 보기

∅의 원소 수 0, {ε}의 원소 수 1이고 그 문자열 길이 0, {0}의 원소 수 1이고 문자열 길이 1이다. C∅=∅, C{ε}={0},∅*={ε}다. 반복 0회 결과는 빈 문자열 하나이며 문자열이 없는 집합이 아니다.

오해와 반례

알파벳이 두 기호뿐이면 만들 수 있는 문자열과 언어도 항상 유한하다.

0,00,000,…는 길이가 서로 달라 무한히 많다. 각 문자열은 유한하지만 그 전체 집합은 무한할 수 있다. 알파벳 크기와 문자열 길이의 상한을 혼동하지 않는다.

자기점검

ε와 ∅의 차이는?

답과 이유 보기

ε는 길이 0 문자열,∅는 원소 0개 집합이다.

서로 다른 수준의 대상이고 {ε}도 ∅와 다르다.

Σ={0,1}의 길이 2 문자열을 모두 적어라.

답과 이유 보기

00,01,10,11.

두 위치에 각 두 기호를 고르므로 2²=4개다.

짝수 개 1 언어에 1011이 포함되는가?

답과 이유 보기

포함되지 않는다.

1이 3개이며 길이 4라는 사실은 1의 짝수성 조건과 다르다.

한 단계 더

심화: Σ={0,1}에서 길이 n 문자열은 2ⁿ개다. 길이 0에서 1개, 마지막 위치에 두 기호를 붙이면 이전 개수의 2배임을 귀납으로 보이라. 길이 0부터 3까지는 1+2+4+8=15개다. 알파벳 ∅를 허용하는 다른 관례에서는 Σ*={ε}가 됨을 구별하되 본문은 비어 있지 않은 알파벳을 사용한다.

소단원 1.2

생성과 인식

올바른 문자열을 만들어 내는 규칙과 주어진 문자열이 올바른지 검사하는 기계는 어떻게 같은 언어를 설명할까?

준비 개념과 학습 목표

준비 개념

  • 터미널은 최종 문자열에 들어갈 입력 기호다. 비터미널은 생성 과정에서 바꿀 수 있는 표식이며 최종 입력 기호와 다르다.

  • 문법의 규칙 X→α는 비터미널 X 하나를 오른쪽 열α로 바꾸는 방식이다. 시작 표식에서 유한 번 바꾸어 터미널 문자열을 얻는 과정을 유도라 한다.

  • 상태기계는 입력을 차례로 읽으면서 현재 상태를 전이 규칙으로 바꾼다. 유한 자동기계는 상태 수가 유한하고 입력 전체를 읽은 끝 상태로 수락 여부를 정한다.

학습 목표

  • 생성 문법과 입력 인식기의 역할·언어를 각각 정의한다.

  • 짝수 1 언어의 두 상태·문법을 같은 문자열로 추적한다.

  • 유한자동기계의 종료와 일반 인식/결정의 차이를 설명한다.

1. 문법은 완성 문자열을 만든다

문법 G의 터미널 Σ={0,1}, 비터미널 {E, O}, 시작 E를 쓰자. 규칙은 E→0E|1O|ε, O→0O|1E다. |는 대안의 구분이며 실제 입력 기호가 아니다. 시작 E에서 규칙을 유한 번 적용해 비터미널 없이 끝난 문자열들의 집합이 생성 언어 L(G)다. E나 O가 남아 있는 중간형은 완성 문자열이 아니다.

여기서 E는 지금까지 만든 1의 개수가 짝수라는 상태를, O는 홀수라는 상태를 나타내도록 설계했다.0을 만들면 표식이 같고 1을 만들면 표식이 바뀐다. E에만 ε로 끝내는 규칙이 있어 짝수 상태에서만 완성할 수 있다. 이 직관이 모든 생성 결과의 정확성을 보장하는지는 다음 소단원에서 양방향으로 증명한다.

2. 인식기는 주어진 입력을 읽는다

두 상태 DFA의 구성은 Q={E, O}, 알파벳 Σ={0,1}, 시작 E, 수락 집합 F={E}이고 δ(E,0)=E,δ(O,0)=O,δ(E,1)=O,δ(O,1)=E다. δ는 상태·기호 쌍마다 정확히 다음 상태 하나를 정한다. 입력을 다 읽은 뒤 E이면 수락, O이면 거부한다. 중간에 E를 지났다는 것만으로 전체 입력을 수락하지 않는다.

빈 문자열에서는 아무 전이도 하지 않아 시작 E가 끝 상태다. 따라서 ε를 수락한다. 이 DFA가 인식하는 언어 L(M)은 수락한 모든 입력 문자열의 집합이다. 유한 길이 n 입력을 n번 읽고 판정하므로 언제나 종료한다. 문자열 길이의 상한이 없다는 말은 한 입력을 무한히 읽는다는 뜻이 아니다.

여기의 DFA는 모든 상태·입력 기호 쌍에서 다음 상태 하나가 정의된 완전한 결정적 기계다. NFA는 같은 기호에서 가능한 다음 상태가 여러 개 또는0개일 수 있고, ε 전이가 허용된 모형에서는 입력을 소비하지 않고 이동할 수도 있다. NFA는 전체 입력을 소비해 수락 상태에 끝나는 유한 경로가 하나라도 있으면 수락한다. 한 경로의 실패를 전체 NFA의 거부로 해석하지 않는다. 이 예제의 한 상태씩 추적하는 표는 DFA에 대한 것이다.

3. 생성과 인식의 능력 범위

G가 생성한 집합과 M이 수락한 집합이 모두 짝수 1 언어라는 것을 보이면 같은 언어의 두 표현이다. 문법·기계의 겉모양이 같아서가 아니라 두 집합이 일치하기 때문에 같은 언어라고 한다. 여기의 오른쪽에 상태 하나만 남기는 문법은 유한 상태 인식과 연결되는 간단한 경우다. 모든 문맥자유 문법을 DFA로 바꿀 수 있다는 결론은 아니다.

일반 계산모형에서는 인식기가 언어의 원소를 언젠가 수락하되 비원소에서 끝나지 않을 수도 있다. 결정기는 모든 입력에서 끝나 수락/거부를 판정한다. 이번 DFA는 종료하는 인식기이자 결정기다. 생성이라는 문법 관점, 문자열들을 출력하는 열거 프로그램, 주어진 입력의 인식은 구별하며 일반 동치·한계는 뒤 계산가능성 단원에서 다룬다.

중간 과정을 따라가는 예제

문자열 0110을 위 문법으로 생성하고 DFA로 인식하라. ε와 111도 DFA에서 비교한다.

  1. 생성: E⇒0E⇒01O⇒011E⇒0110E⇒0110이다. 마지막 E→ε로 터미널 문자열만 남는다.

  2. 인식: E에서 0을 읽어 E,1을 읽어 O,1을 읽어 E,0을 읽어 E다.

  3. 0110의 1은 두 개이고 끝 E가 수락 상태이므로 수락한다.

  4. ε는 시작 E 그대로 수락한다.111은 E→O→E→O로 끝나 거부한다.

0110과 ε는 생성/수락 언어에 속한다.111은 홀수 1 입력이라 DFA에서 거부되며 이 문법의 완성 문자열도 아니다.

종이와 본문으로 직접 해보기

101과 010을 두 상태 카드로 인식하라.101을 문법으로 생성하고,010에서 비터미널을 모두 없앨 수 없는 이유를 설명하라.

힌트 보기

기호 1마다 E/O 카드를 뒤집고 0에서는 그대로 둔다. ε로 끝내는 규칙은 E에만 있다.

풀이 보기

101: E→O→O→E로 수락. E⇒1O⇒10O⇒101E⇒101이다.010: E→E→O→O로 거부. 생성 과정은 E⇒0E⇒01O⇒010O까지이고 O→ε 규칙이 없어 그 문자열 그대로 끝낼 수 없다. 다른 규칙은 추가 입력을 만들어 010 자체와 달라진다.

오해와 반례

문법에서 ε가 있으니 ε를 문자 하나로 입력해 처리해야 한다.

E→ε는 E를 없애는 규칙이다. 입력 알파벳 {0,1}에 ε는 없으며 DFA의 빈 입력에서는 전이를 0번 한다. 빈 문자열을 처리하는 방법과 입력 기호 ε를 새로 넣은 별도 언어는 다르다.

자기점검

E⇒01O는 이미 완성된 입력 문자열을 생성한 것인가?

답과 이유 보기

아니다. O가 남아 있다.

최종 생성 언어에는 터미널만 있는 유도 결과를 넣는다.

입력 1101의 상태와 판정은?

답과 이유 보기

E→O→E→E→O, 거부다.

1이 3개이고 모든 입력을 읽은 뒤 O에 있다.

일반 인식기가 비원소에서 끝나지 않을 수 있으면 항상 결정기인가?

결정기는 모든 입력에서 종료하여 membership을 판정해야 한다.

심화: 생성 규칙 E→0E, E→1O 등에서 터미널을 만드는 한 단계는 DFA의 같은 기호 전이와 대응한다. 모든 기호를 만든 뒤 E→ε로 끝낼 수 있다는 조건은 DFA의 끝 상태가 E라는 조건이다. 이 대응을 입력 길이에 대한 귀납으로 확장하여 L(G)=L(M)을 증명한다.

소단원 1.3

증명과 반례의 작성

몇 개 문자열에서 맞는 기계를 만들었으면 무한히 많은 입력에서도 맞는다고 말할 수 있을까?

준비 개념과 학습 목표

준비 개념

  • 전칭 명제는 모든 해당 대상에 대해 성립한다는 주장이다. 반례 하나는 그 주장을 거짓으로 만들 수 있지만 예제 여러 개가 참이라고 증명되지는 않는다.

  • 언어 동치 L=K는 L⊆K와 K⊆L 두 방향을 요구한다. 생성 결과가 올바르기만 하면 목표 문자열을 빠뜨릴 수도 있다.

  • 귀납은 기저와 한 단계 보존으로 모든 유한 길이의 입력에 관한 성질을 증명한다. 불변식은 처리한 접두열에 대해 유지하는 상태의 의미다.

  • 이 소단원의 대상은 Σ={0,1}, Q={E,O}, 시작E, 수락{E}인 DFA다.0은 상태를 유지하고1은 E/O를 바꾼다. 모든 상태·기호의 전이가 정의되어 있다. 비교 문법은 터미널{0,1}, 비터미널{E,O}, 시작E, 규칙 E→0E|1O|ε 및 O→0O|1E다. |는 규칙 대안 표시이며 입력 기호가 아니다.

학습 목표

  • 인식기 상태 의미를 모든 접두열의 불변식으로 증명한다.

  • 생성 언어의 건전성·완전성을 구별한다.

  • 정확한 주장·전제·반례를 함께 제시한다.

1. 무엇을 증명하는지 양방향으로 적는다

목표 L은 이진열 중 1의 개수가 짝수인 언어다. 기계가 L을 인식한다는 주장은 모든 w∈{0,1}*에 대해 “M이 w를 수락한다 iff w∈L”이다. L에 속한 입력을 수락한다는 한 방향뿐 아니라 L 밖 입력을 수락하지 않는다는 방향도 필요하다.

문법에는 생성한 것은 모두 목표 안이라는 건전성 L(G)⊆L과 목표의 모든 문자열을 생성할 수 있다는 완전성 L⊆L(G)이 있다. ε만 생성하는 문법은 짝수 1 조건을 어기는 문자열을 만들지 않아 건전하지만 11이나 0을 빠뜨려 완전하지 않다. 같은 말로 “잘못된 출력 없음”과 “필요한 모든 경우 가능”을 구별한다.

2. 모든 접두열을 포괄하는 귀납

짝수/홀수 DFA에서 불변식은 읽은 접두열 u의 1의 개수가 짝수 iff 현재 E, 홀수 iff 현재 O다. 기저 u=ε에서 1의 개수 0이 짝수이고 시작 E이므로 참이다. 이 성질이 길이 k의 임의 접두열에서 참이라고 가정한다.

다음 기호 0은 1의 개수의 홀짝을 유지하고 δ도 상태를 유지한다. 다음 기호 1은 개수에 1을 더해 홀짝을 뒤집고 δ도 E/O를 뒤집는다. 따라서 k+1에도 참이다. 모든 유한 길이에 성립하므로 입력 끝에서 수락 상태 E iff 짝수 1이라는 결론을 얻는다. 이 귀납은 시험한 몇 가지 길이에만 한정되지 않는다.

3. 문법의 두 포함과 정확한 반례

생성 규칙의 매 단계에서 만든 터미널 접두열과 남은 E/O는 같은 홀짝 관계를 가진다. 오직 E만 ε로 종료하므로 모든 완성 결과는 짝수 1이다. 반대로 임의의 짝수 1 문자열을 왼쪽부터 보고 각 기호에 맞는 규칙을 고르면 접두열을 그대로 만들며 끝 E에 도달해 ε로 없앨 수 있다. 이것으로 두 포함을 증명한다.

반례는 어떤 명제를 깨는지 밝혀야 한다. “짝수 1이면 길이도 짝수”는 0에서 1의 개수 0이 짝수지만 길이 1이 홀수라 거짓이다. 잘못된 문법 S→0S|11S|ε는 1을 붙이는 횟수가 2개씩이라 건전하지만 101을 생성하지 못한다.101은 1이 2개인데 이 문법의 1은 인접한 11묶음으로만 나타나기 때문이다.

중간 과정을 따라가는 예제

“1의 개수가 짝수인 언어 L은 길이가 짝수인 언어 K와 같다”는 주장을 검토하라. Σ={0,1}이며 빈 문자열도 허용한다.

  1. ε는 1의 개수 0·길이 0으로 둘 다 속한다.11도 두 언어에 속하지만 이 두 예제가 동치를 증명하지 않는다.

  2. 0은 1의 개수 0으로 L에 속하고 길이 1로 K에는 없다. 따라서 L⊆K가 거짓이다.

  3. 01은 길이 2로 K에 속하지만 1의 개수 1로 L에는 없다. 따라서 K⊆L도 거짓이다.

  4. 반례의 알파벳·개수·길이를 각각 확인했고 두 포함 방향을 따로 판정했다.

L≠K이며 서로 어느 쪽도 다른 쪽의 부분집합이 아니다. 같지 않음을 보이는 데는 한 반례만으로도 충분하지만 여기서는 두 방향의 차이를 보였다.

종이와 본문으로 직접 해보기

잘못된 문법 S→0S|11S|ε가 11과 0011을 생성하는 과정을 적고,101을 못 만드는 이유를 적는다. 이 문법이 L에 대해 건전한지 완전한지도 판정한다.

힌트 보기

규칙은 문자열 앞에 0 또는 11을 차례로 붙이고 마지막에 S를 없앤다. 만들어진 1은 항상 길이 2짜리 연속 묶음에 포함된다.

풀이 보기

11: S⇒11S⇒11.0011: S⇒0S⇒00S⇒0011S⇒0011. 생성 단계마다 1을 0개 또는 2개 추가하므로 완성 문자열의 1의 개수는 짝수라 건전하다.101은 1사이에 0이 있어 0/11의 연속 묶음으로 분해할 수 없고 생성되지 않아 완전하지 않다. 목표 L에는 101이 포함된다.

오해와 반례

길이 8까지 모든 입력에서 맞았다면 무한 언어를 정확히 인식한다는 증명이다.

“길이 8 이하이면서 1의 개수 짝수”만 수락하는 다른 검사기는 그 범위에서 똑같지만 길이 9인 000000000을 거부한다. 표본 전수검사는 그 유한 범위를 확인하며 일반 증명에는 길이와 무관한 불변식·귀납 등 근거가 필요하다.

심화: 같은 입력 알파벳을 쓰며 모든 상태·기호 전이가 정의된 두 완전 DFA의 언어가 같은지 확인할 때 상태쌍을 추적하는 곱 기계를 생각하라. 시작쌍에서 도달 가능한 상태쌍 중 한쪽만 수락인 쌍이 있으면 거기까지 읽은 문자열이 반례다. 모든 도달쌍의 수락 여부가 일치하면 언어 동치를 증명할 수 있다. 유한 도달 상태 전체를 체계적으로 검사하는 것과 임의 길이 표본만 시험하는 것의 차이를 설명하라. 전이가 생략된 도표는 먼저 비수락 막힘 상태로 보완한다. NFA의 한 경로 상태쌍만으로 이 판정을 그대로 적용할 수는 없다. 도달 상태쌍은 최대 |Q₁|×|Q₂|개여서 방문한 쌍을 반복 탐색하지 않으면 종료한다.
