소단원 1.1

알파벳·문자열·언어

아무 문자도 없는 문자열 하나와 문자열이 하나도 없는 집합은 같은 것일까?

준비 개념과 학습 목표

준비 개념

  • 집합은 원소의 포함 여부를 정하며 중복을 세지 않는다. ∅는 원소가 하나도 없는 집합이다.

  • 문자열은 기호를 순서대로 나열한 유한열이다. 같은 기호 수라도 01과 10은 순서가 달라 서로 다른 문자열이다.

  • w∈L은 w가 집합 L의 원소라는 뜻, L⊆K는 L의 모든 원소가 K에도 속한다는 뜻이다.

학습 목표

  • Σ, 문자열,ε,Σ*, 언어 L의 서로 다른 수준을 구별한다.

  • 길이·이어붙이기·언어 연산을 작은 집합에서 계산한다.

  • 형식언어의 기호와 실제 문자/바이트 인코딩을 구별한다.

기호 하나를 두 비트로 표시하면 원래 언어의 판정도 그대로 보존될까?

새 입력 알파벳은 Σ={a,b}다. 화면의 두 이름은 각각 한 기호를 가리키며 기호열 aba의 길이는 3이다. 비트열로 저장할 때 인코딩 c(a)=0, c(b)=00을 선택하고 기호 순서대로 이어 붙이자. aba의 비트열은 0000이고 aaaa의 비트열도 0000이다. 원래 기호열의 길이는 각각 3과 4지만 저장 비트 수는 모두 4다. 각 기호의 코드가 서로 다르다는 사실만으로 전체 문자열의 원상이 유일해지지는 않는다.

빈 기호열의 인코딩은 빈 비트열이다. Σ의 각 기호는 비어 있지 않은 코드이므로 빈 비트열의 원상은 ε 하나다. 반면 길이 2인 비트열 00은 aa와 b에서 모두 나온다. 원래 언어가 두 원상을 서로 다르게 판정하면 원시 비트열만 받은 결정적 검사기는 둘의 판정을 동시에 보존할 수 없다. 이때 오류는 자동기계의 상태 수 이전에 입력 표현이 정보를 잃은 데서 생긴다.

별도 코드 d(a)=0, d(b)=10은 어느 코드도 다른 코드의 접두열이 아닌 접두 자유 코드다. 왼쪽에서 0을 만나면 a 한 기호를, 1을 만나면 다음 0까지 확인해 b 한 기호를 읽는다. 남은 마지막 1이나 11 같은 조각은 완전한 기호의 코드가 아니므로 거절해야 한다. d(aba)=0100이고 d(aaaa)=0000으로 구별된다. 모든 이진열이 이 코드의 유효 입력인 것은 아니다.

다른 집합 계산에서는 U={a,ab}, V={ε,b}를 쓴다. 네 쌍의 결과는 a, ab, ab, abb이므로 UV={a,ab,abb}의 크기는 3이다. 곱집합 U×V의 네 원소와 언어 이어붙이기의 서로 다른 결과 수를 구별한다. 개별 문자열은 같은 접미열을 소거할 수 있지만 언어의 곱은 선택한 분할을 잃어 같은 소거 규칙을 갖지 않을 수 있다.

  • 입력 전제와 반례

    두 다른 기호열이 같은 비트열로 바뀌는 반례가 어떤 주장에 해당하는지 적는다.

1. 먼저 기호와 길이를 정한다

이 단원에서 알파벳 Σ는 유한하고 비어 있지 않은 입력 기호 집합으로 선언한다. Σ={0,1}이면 0과 1은 숫자 계산값이 아니라 읽는 기호다. 문자열은 Σ의 기호를 순서대로 나열한 유한열이고 길이|w|는 기호 개수다. 입력 기호가 아닌 문자가 끼면 그 문자열은 Σ 위의 입력이 아니다.

빈 문자열 ε는 기호 0개를 가진 유일한 열이며 |ε|=0이다. ε라는 표기는 “아무 기호도 없음”을 나타내며 이 단원의 입력 기호로 읽지 않는다. 실제 UTF-8의 바이트 수·화면의 글자 수·토큰 수는 별도 인코딩 문제다. 선택한 알파벳 기호 하나를 프로그램이 여러 바이트로 표현할 수도 있다.

2. 가능한 모든 입력과 선택한 언어

Σⁿ은 길이 n인 모든 문자열의 집합이다. Σ⁰={ε},Σ*는 n≥0의 Σⁿ을 모두 합친 집합으로 모든 유한 문자열을 포함한다. 알파벳이 유한해도 문자열 길이에 고정 상한이 없으므로 Σ*는 무한하다. 언어 L은 Σ*의 부분집합이다.

L={w∈{0,1}*:w의 1의 개수가 짝수}는 규칙으로 정의한 무한 언어다.0개의 1도 짝수이므로 ε와 0과 00이 포함되고 1과 1011은 포함되지 않는다. 언어 자체는 집합이고 그 집합을 설명하는 문법·기계·프로그램은 표현 방식이다. 모든 언어가 모든 종류의 유한 기계로 인식되는 것은 아니다.

3. 문자열과 언어의 이어붙이기

문자열 uv는 u 다음에 v를 이어붙인 것이다. 길이는|uv|=|u|+|v|이고 uε=εu=u다. 보통 uv≠vu이며 u=0, v=1이면 01≠10이다. 언어의 이어붙이기 LK={uv:u∈L, v∈K}는 가능한 모든 쌍을 만들고 결과 문자열을 집합으로 모은다.

∅와 {ε}는 다르다. ∅에는 고를 문자열이 없어 L∅=∅이고 L{ε}=L이다. 언어의 반복 L*=⋃(n≥0)Lⁿ은 0번 이어붙인 경우 {ε}도 포함하므로 ∅*={ε}다. 원소가 문자열인지 언어인지 먼저 구별하면 “빈 것”이라는 말에 가려진 차이를 정확히 볼 수 있다.

표의 문자열 길이는 선언된 알파벳 기호 수다. 비트 0과 기호 a를 동일한 입력 수준으로 바꾸지 않으며 유효 코드 여부와 원래 언어의 membership을 두 단계로 구별한다.

중간 과정을 따라가는 예제

Σ={0,1}, A={ε,0}, B={1,01}에서 AB와 BA 및 각 집합의 원소 수를 계산한다.

  1. AB의 쌍별 결과는 ε·1=1, ε·01=01,0·1=01,0·01=001이다.

  2. 01이 두 번 나오지만 집합에서 중복을 제거해 AB={1,01,001}이다.

  3. BA의 결과는 1·ε=1,1·0=10,01·ε=01,01·0=010이다.

  4. BA={1,10,01,010}으로 AB와 다르다.

|AB|=3,|BA|=4. |A||B|=4는 가능한 쌍 수이지 언제나 결과의 서로 다른 문자열 수는 아니다.

조건을 바꾸어 비교하기

기호별 코드는 달라도 문자열 전체 코드가 충돌하는 저장

c로 저장한 00과 0000의 두 원상씩을 적어라.

  1. c(aa)=00이고 c(b)=00이다.

  2. c(aba)=0·00·0=0000이고 c(aaaa)=0·0·0·0=0000이다.

기호별 코드의 상이함만으로 문자열 인코딩의 단사성을 증명하지 못한다.

비교할 점

기본의 기호 길이·바이트 구별에 복원 비유일성이라는 새 조건을 더한다.

언어에서 소거가 실패하는 경우

X={ε,a}, Y={ε}, K={a}*에서 XK와 YK를 구하고 X=Y 여부를 판정하라.

  1. XK=a*∪aa*=a*다.

  2. YK=a*다. 하지만 a는 X에만 속해 X≠Y다.

XK=YK여도 X=Y가 따라오지 않는다.

같은 접미 문자열을 붙인 두 문자열의 소거와 집합에 여러 길이가 섞인 언어의 소거는 다르다.

종이와 본문으로 직접 해보기

종이에 ∅,{ε},{0}를 세 상자로 구별하라. 각 원소 수와 문자열 길이를 적고 C={0}에 대해 C∅, C{ε},∅*를 계산하라.

힌트 보기

원소 수와 원소인 문자열의 길이를 별도 줄에 쓴다. ∅에는 길이를 잴 문자열이 아예 없다.

풀이 보기

∅의 원소 수 0, {ε}의 원소 수 1이고 그 문자열 길이 0, {0}의 원소 수 1이고 문자열 길이 1이다. C∅=∅, C{ε}={0},∅*={ε}다. 반복 0회 결과는 빈 문자열 하나이며 문자열이 없는 집합이 아니다.

오해와 반례

알파벳이 두 기호뿐이면 만들 수 있는 문자열과 언어도 항상 유한하다.

0,00,000,…는 길이가 서로 달라 무한히 많다. 각 문자열은 유한하지만 그 전체 집합은 무한할 수 있다. 알파벳 크기와 문자열 길이의 상한을 혼동하지 않는다.

연습 1 · 값과 상태 예측

U={a,ab}, V={ε,b}에서 VU의 결과와 UV와의 차이를 구하라.

힌트 1

V의 ε 또는 b를 U의 a 또는 ab 앞에 붙인다.

힌트 2

결과 문자열 자체를 비교하고 중복은 한 번만 센다.

풀이와 답 확인

  1. εa=a, εab=ab, ba=ba, bab=bab이다.

  2. VU={a,ab,ba,bab}이고 UV={a,ab,abb}다.

VU에는 4개, UV에는 3개 원소가 있으며 서로 다른 집합이다.

흔한 오답에서 다시 생각하기

U와 V의 원소 수가 같으므로 UV=VU다.

쌍 수는 순서에 무관해도 결과의 기호 순서는 바뀐다.

c(a)와 c(b)가 다르니 c가 모든 문자열에서 단사라는 주장을 고쳐라.

힌트 1

코드가 한 기호의 코드인지 여러 기호의 결합인지 본다.

힌트 2

같은 비트열 00의 서로 다른 원상을 찾아라.

풀이와 답 확인

  1. a≠b이며 코드 0≠00이라는 것은 기호 한 개의 비교다.

  2. aa≠b인데 c(aa)=c(b)=00이므로 문자열 전체의 단사성은 실패한다.

기호별 상이함과 모든 이어붙임의 유일 복원은 다른 조건이다.

연습 3 · 직접 만들어 보기

d 코드의 0100을 복원하고 01과 11을 처리하는 정책을 구성하라.

힌트 1

0은 a이고 10은 b다.

힌트 2

선택한 코드를 끝까지 소비해야 한다.

풀이와 답 확인

  1. 0100은 0|10|0으로 나뉘어 aba다.

  2. 01은 a를 읽은 뒤 마지막 1이 남으므로 미완성 코드다.

  3. 11은 처음 1 뒤 기대한 0이 없어 유효 코드가 아니다.

0100은 aba로 유일하게 복원하고 01과 11은 입력 형식 오류로 거절한다.

마지막 1을 버리면 항상 복원된다.

남은 비트를 버리면 입력 전체를 보존하지 않는다.

연습 4 · 선택 심화

선택 심화는 기본 연습 뒤 더 탐구하고 싶을 때 풀어 보세요.

d로 유효하게 저장한 기호열의 기호 수가 n이고 b의 수가 k라면 비트 길이를 구하라. 같은 비트 길이가 같은 기호열을 뜻하는지도 판단하라.

힌트 1

a는 1비트, b는 2비트다.

힌트 2

서로 다른 기호 순서도 비교한다.

풀이와 답 확인

  2. ab와 ba는 모두 비트 길이 3이지만 코드 010과 100이 다르다.

길이는 n+k지만 길이만으로 문자열을 식별하지 못한다.

생성과 인식

올바른 문자열을 만들어 내는 규칙과 주어진 문자열이 올바른지 검사하는 기계는 어떻게 같은 언어를 설명할까?

준비 개념과 학습 목표

준비 개념

  • 터미널은 최종 문자열에 들어갈 입력 기호다. 비터미널은 생성 과정에서 바꿀 수 있는 표식이며 최종 입력 기호와 다르다.

  • 문법의 규칙 X→α는 비터미널 X 하나를 오른쪽 열α로 바꾸는 방식이다. 시작 표식에서 유한 번 바꾸어 터미널 문자열을 얻는 과정을 유도라 한다.

  • 상태기계는 입력을 차례로 읽으면서 현재 상태를 전이 규칙으로 바꾼다. 유한 자동기계는 상태 수가 유한하고 입력 전체를 읽은 끝 상태로 수락 여부를 정한다.

학습 목표

  • 생성 문법과 입력 인식기의 역할·언어를 각각 정의한다.

  • 짝수 1 언어의 두 상태·문법을 같은 문자열로 추적한다.

  • 유한자동기계의 종료와 일반 인식/결정의 차이를 설명한다.

짝수 개 a라는 조건에 b를 실제로 본 적 있다는 조건을 더하면?

새 목표 언어 K={w∈{a,b}*: a의 수가 짝수이고 b가 한 번 이상 있다}를 정한다. ε와 aa는 짝수 조건을 만족하지만 b가 없어 K에 없다. b는 a의 수가 0이고 b가 있으므로 K에 있다. ab는 b가 있어도 a가 한 개라 K에 없다. 서로 다른 두 조건의 접속사를 AND로 고정해야 한다.

상태 E0,O0,E1,O1에서 E/O는 읽은 a의 수의 짝수/홀수, 0/1은 b를 아직 안 봄/이미 봄이다. a를 읽으면 E/O만 바꾸고 b를 읽으면 홀짝은 유지하면서 뒤 비트를 1로 바꾼다. 시작은 E0이고 수락 상태는 E1 하나다. 1 비트는 b 이후 다시 0으로 돌아가지 않는다. 상태 이름을 숫자의 덧셈 결과로 해석하지 않고 두 의미의 조합으로 읽는다.

같은 언어를 생성하는 오른쪽 선형 문법의 비터미널도 E0,O0,E1,O1이며 시작은 E0이다. 규칙은 E0→aO0|bE1, O0→aE0|bO1, E1→aO1|bE1|ε, O1→aE1|bO1이다. 터미널은 a와 b뿐이며 E1만 없애는 규칙이 있다. E0를 ε로 없애면 b가 없는 입력까지 생성하는 다른 문법이 된다.

aba의 인식 경로는 E0→O0→O1→E1이고 생성은 E0⇒aO0⇒abO1⇒abaE1⇒aba다. 같은 네 상태의 전이·생성 대응은 유한 입력 전체에 적용한다. 한 생성 경로를 무한히 계속할 수 있어도 생성 언어는 터미널만 남긴 유한 유도 결과로 정의한다. 어떤 후보 경로가 끝나지 않았다는 사실 하나는 해당 문자열의 비생성을 증명하지 않는다.

먼저 확인할 개념
  • 유한 유도와 전체 입력 수락

    중간 비터미널과 완성 문자열, 시작 상태와 끝 상태를 구별한다.

  • 두 포함과 접두열 불변식

    a의 홀짝과 b의 관찰 여부를 모든 접두열에서 보존한다.

1. 문법은 완성 문자열을 만든다

문법 G의 터미널 Σ={0,1}, 비터미널 {E, O}, 시작 E를 쓰자. 규칙은 E→0E|1O|ε, O→0O|1E다. |는 대안의 구분이며 실제 입력 기호가 아니다. 시작 E에서 규칙을 유한 번 적용해 비터미널 없이 끝난 문자열들의 집합이 생성 언어 L(G)다. E나 O가 남아 있는 중간형은 완성 문자열이 아니다.

여기서 E는 지금까지 만든 1의 개수가 짝수라는 상태를, O는 홀수라는 상태를 나타내도록 설계했다.0을 만들면 표식이 같고 1을 만들면 표식이 바뀐다. E에만 ε로 끝내는 규칙이 있어 짝수 상태에서만 완성할 수 있다. 이 직관이 모든 생성 결과의 정확성을 보장하는지는 다음 소단원에서 양방향으로 증명한다.

2. 인식기는 주어진 입력을 읽는다

두 상태 DFA의 구성은 Q={E, O}, 알파벳 Σ={0,1}, 시작 E, 수락 집합 F={E}이고 δ(E,0)=E,δ(O,0)=O,δ(E,1)=O,δ(O,1)=E다. δ는 상태·기호 쌍마다 정확히 다음 상태 하나를 정한다. 입력을 다 읽은 뒤 E이면 수락, O이면 거부한다. 중간에 E를 지났다는 것만으로 전체 입력을 수락하지 않는다.

빈 문자열에서는 아무 전이도 하지 않아 시작 E가 끝 상태다. 따라서 ε를 수락한다. 이 DFA가 인식하는 언어 L(M)은 수락한 모든 입력 문자열의 집합이다. 유한 길이 n 입력을 n번 읽고 판정하므로 언제나 종료한다. 문자열 길이의 상한이 없다는 말은 한 입력을 무한히 읽는다는 뜻이 아니다.

여기의 DFA는 모든 상태·입력 기호 쌍에서 다음 상태 하나가 정의된 완전한 결정적 기계다. NFA는 같은 기호에서 가능한 다음 상태가 여러 개 또는0개일 수 있고, ε 전이가 허용된 모형에서는 입력을 소비하지 않고 이동할 수도 있다. NFA는 전체 입력을 소비해 수락 상태에 끝나는 유한 경로가 하나라도 있으면 수락한다. 한 경로의 실패를 전체 NFA의 거부로 해석하지 않는다. 이 예제의 한 상태씩 추적하는 표는 DFA에 대한 것이다.

3. 생성과 인식의 능력 범위

G가 생성한 집합과 M이 수락한 집합이 모두 짝수 1 언어라는 것을 보이면 같은 언어의 두 표현이다. 문법·기계의 겉모양이 같아서가 아니라 두 집합이 일치하기 때문에 같은 언어라고 한다. 여기의 오른쪽에 상태 하나만 남기는 문법은 유한 상태 인식과 연결되는 간단한 경우다. 모든 문맥자유 문법을 DFA로 바꿀 수 있다는 결론은 아니다.

일반 계산모형에서는 인식기가 언어의 원소를 언젠가 수락하되 비원소에서 끝나지 않을 수도 있다. 결정기는 모든 입력에서 끝나 수락/거부를 판정한다. 이번 DFA는 종료하는 인식기이자 결정기다. 생성이라는 문법 관점, 문자열들을 출력하는 열거 프로그램, 주어진 입력의 인식은 구별하며 일반 동치·한계는 뒤 계산가능성 단원에서 다룬다.

잘못된 출력이 없는 문법이 목표의 모든 문자열을 만드는가?

K는 a가 짝수 개이고 b가 한 번 이상인 언어다. 제한 문법 R→bT, T→bT|aaT|ε는 먼저 b를 만들고 나중에 b 또는 aa 묶음을 붙인다. 모든 완성 결과에는 b가 있고 a를 짝수 개씩만 추가하므로 K에 대한 건전성은 성립한다. 그러나 aba는 K에 속하면서 첫 기호가 a이므로 이 문법에서 생성되지 않는다. 하나의 포함으로 다른 포함을 대신하지 않는다.

다른 넓은 문법 R→aR|bT, T→aT|bT|ε는 첫 b 앞과 뒤에 임의의 a를 허용하고 그 뒤에 임의 기호를 허용한다. 생성 언어는 b가 한 번 이상 있는 모든 문자열이다. K의 각 문자열은 첫 b를 경계로 이 규칙을 고를 수 있어 완전하지만 ab까지 생성하므로 건전하지 않다. 두 오류는 필요한 수정과 반례의 방향이 서로 다르다.

올바른 네 상태의 불변식은 모든 읽은 접두열 u에 대해 첫 성분이 a의 수의 홀짝, 둘째 성분이 b의 존재 여부라는 것이다. 빈 접두열에서 E0가 맞는다. 다음 a는 첫 성분만 뒤집고 다음 b는 첫 성분을 보존하면서 둘째 성분을 1로 만든다. 따라서 모든 길이에 유지되며 끝 E1 iff u∈K다. 생성의 매 터미널 추가가 같은 전이를 따라가고 E1에서만 종료하므로 건전성이 성립한다. 임의의 K 문자열을 왼쪽부터 따라가면 끝 E1에서 종료할 수 있어 완전성도 성립한다.

조건을 OR로 바꾼 H={w: a가 짝수 개이거나 b가 한 번 이상 있음}은 다른 언어다. K⊆H지만 ε는 H에만 속한다. 목표가 K인지 H인지 먼저 고정하지 않으면 예제에서 둘 다 맞은 b와 aba가 조건 선택을 검증해 주지 못한다. 유한 길이 m까지 일치하는 제한 검사기도 그보다 긴 문자열 b^(m+1)을 거부하도록 설계할 수 있어 표본 전수 확인만으로 무한 범위 동치를 증명하지 못한다.

1. 무엇을 증명하는지 양방향으로 적는다

목표 L은 이진열 중 1의 개수가 짝수인 언어다. 기계가 L을 인식한다는 주장은 모든 w∈{0,1}*에 대해 “M이 w를 수락한다 iff w∈L”이다. L에 속한 입력을 수락한다는 한 방향뿐 아니라 L 밖 입력을 수락하지 않는다는 방향도 필요하다.

문법에는 생성한 것은 모두 목표 안이라는 건전성 L(G)⊆L과 목표의 모든 문자열을 생성할 수 있다는 완전성 L⊆L(G)이 있다. ε만 생성하는 문법은 짝수 1 조건을 어기는 문자열을 만들지 않아 건전하지만 11이나 0을 빠뜨려 완전하지 않다. 같은 말로 “잘못된 출력 없음”과 “필요한 모든 경우 가능”을 구별한다.

2. 모든 접두열을 포괄하는 귀납

짝수/홀수 DFA에서 불변식은 읽은 접두열 u의 1의 개수가 짝수 iff 현재 E, 홀수 iff 현재 O다. 기저 u=ε에서 1의 개수 0이 짝수이고 시작 E이므로 참이다. 이 성질이 길이 k의 임의 접두열에서 참이라고 가정한다.

다음 기호 0은 1의 개수의 홀짝을 유지하고 δ도 상태를 유지한다. 다음 기호 1은 개수에 1을 더해 홀짝을 뒤집고 δ도 E/O를 뒤집는다. 따라서 k+1에도 참이다. 모든 유한 길이에 성립하므로 입력 끝에서 수락 상태 E iff 짝수 1이라는 결론을 얻는다. 이 귀납은 시험한 몇 가지 길이에만 한정되지 않는다.

3. 문법의 두 포함과 정확한 반례

생성 규칙의 매 단계에서 만든 터미널 접두열과 남은 E/O는 같은 홀짝 관계를 가진다. 오직 E만 ε로 종료하므로 모든 완성 결과는 짝수 1이다. 반대로 임의의 짝수 1 문자열을 왼쪽부터 보고 각 기호에 맞는 규칙을 고르면 접두열을 그대로 만들며 끝 E에 도달해 ε로 없앨 수 있다. 이것으로 두 포함을 증명한다.

풀이와 답 확인

  2. a는 두 조건 모두 거짓이라 두 언어 밖이다.

  3. b는 두 조건 모두 참이라 두 언어 안이다.

  4. ab는 홀짝 거짓·b 존재 참이라 K 밖, H 안이다.

인코딩·관찰 상태·양방향 정확성의 종합 감사

목표 K는 {a,b} 위에서 a가 짝수 개이고 b가 한 번 이상 있는 언어다. ① c(a)=0, c(b)=00으로 저장한 aba와 aaaa가 같은 비트열인지 계산하고 원시 비트열만의 결정적 검사기가 두 K 판정을 보존할 수 있는지 논증하라. ② d(a)=0, d(b)=10으로 바꾸어 두 비트열을 복원하고 네 상태 모형으로 K를 판정하라. ③ 제한 문법 R→bT, T→bT|aaT|ε와 넓은 문법 R→aR|bT, T→aT|bT|ε의 건전성·완전성을 비교하고 각각 반례를 적어라.

힌트 1

① 같은 저장 입력에 서로 다른 원래 판정이 요구되는지 본다. ② 인코딩을 끝까지 복원한 뒤 a의 홀짝과 b 관찰 비트를 따로 추적한다.

힌트 2

③ 생성 결과가 목표 안인지와 목표를 모두 생성하는지를 다른 포함으로 쓴다. 첫 기호 제한과 ab의 a 개수를 확인한다.

풀이와 답 확인

  1. ① c(aba)=0000이고 c(aaaa)=0000이다. aba는 a가 두 개이고 b가 있어 K 안이며 aaaa는 b가 없어 K 밖이다. 결정적 검사기는 같은 비트열에 같은 결과를 내므로 원래 두 판정을 모두 보존하지 못한다.

  2. ② d(aba)=0100을 0|10|0으로 복원하면 aba다. d(aaaa)=0000은 aaaa다. aba는 E0→O0→O1→E1로 수락하고 aaaa는 E0→O0→E0→O0→E0로 거부한다.

  3. ③ 제한 문법은 b가 있고 a를 짝수 개씩 추가해 건전하지만 aba를 누락해 불완전하다. 넓은 문법은 첫 b를 경계로 모든 K 문자열을 생성해 완전하지만 ab도 생성하므로 불건전하다.

  4. 네 상태 문법의 모든 전이는 두 접두 정보와 대응하고 E1만 종료한다. 임의 K 입력을 같은 규칙으로 따라가 끝낼 수 있으므로 두 포함을 모두 증명한다. 실제 인코더·자동기계·문법 도구·학생 실험은 수행하지 않았다.

정보를 잃은 c는 K 판정을 원시 비트열로 전달하지 못한다. 접두 자유 d와 네 상태·E1 종료 모형은 유효 코드 복원과 K의 두 조건을 보존한다. 제한 문법의 누락 aba와 넓은 문법의 과잉 ab는 서로 반대 포함의 실패다.
