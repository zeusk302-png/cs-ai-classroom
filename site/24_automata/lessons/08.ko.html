소단원 8.1

정규형과 변환

같은 문장을 만드는 규칙을 짧은 조각으로 다시 쓸 수 있을까?

준비 개념과 학습 목표

준비 개념

  • 비단말은 치환할 기호, 터미널은 최종 문자다.

  • ε는 길이 0인 문자열이다.

학습 목표

  • CNF의 허용 규칙과 시작 기호 예외를 설명한다.

  • 생성 언어를 보존하며 짧은 문법을 변환한다.

같은 nullable 기호가 두 번 나오면 새 규칙도 네 개일까?

새 문법 G는 S→AA | b, A→a | ε다. 완성 언어는 {ε,a,aa,b}다. 오른쪽 AA의 두 A는 같은 이름이지만 서로 다른 발생 위치다. 첫째만 지우거나 둘째만 지우는 선택은 모두 같은 오른쪽 A를 만들므로 네 삭제 선택이 네 고유 규칙을 뜻하지 않는다.

새 시작 S0를 도입해 ε를 따로 보존한다. nullable 제거 뒤에는 S0와 S가 각각 AA,A,b를 갖고 S0에는 ε도 둔다. A→a만 남긴 뒤 단위 규칙 S0→A와 S→A를 복사 방식으로 없앤다. 도달하지 않는 S를 제거한 최종 문법 H는 S0→AA | a | b | ε, A→a다. S0는 오른쪽에 없고 ε는 S0에만 있다.

H에서 비어 있지 않은 출력 aa는 이진 규칙 한 번과 terminal 규칙 두 번으로 만든다. a와 b는 각각 terminal 규칙 한 번이다. ε는 별도의 시작 예외 한 번이다. 길이 n≥1인 임의 CNF 유도 트리의 binary 규칙은 n−1회, terminal 규칙은 n회이므로 전체 규칙 적용 수는 2n−1회다. 이는 왼쪽·오른쪽 독립 자식의 처리 순서가 만든 유도열 개수를 세는 식이 아니다.

단위 규칙에 순환이 있어도 이를 반복 삭제하는 것으로 처리하지 않는다. 별도 J의 S→A, A→B, B→A | a에서는 S,A,B 모두 단위 경로로 B에 도달한다. 따라서 각각 a 규칙을 복사하면 언어 {a}를 유지한다. 무한 A↔B 경로는 terminal 문장이 아니다.

먼저 확인할 개념
  • nullable와 단위 규칙 제거

    기본 변환의 위치별 삭제와 도달 규칙 복사를 새 반복 A에 적용한다.

  • CNF로 처리할 입력 계약

    형식 변환이 빈 입력과 길이 1 초기화를 바꾸는 지점을 확인한다.

형식을 제한하는 이유

Chomsky 정규형(CNF)은 비단말 A에서 두 비단말 BC로 가는 규칙 A→BC 또는 한 터미널 a로 가는 A→a를 사용한다. 시작 기호는 어느 규칙의 오른쪽에도 나타나지 않게 하고, 빈 문자열이 언어에 있으면 시작 기호에서만 ε를 허용하는 관례를 사용한다.

규칙 형식을 제한하면 비어 있지 않은 문자열의 유도 트리가 이진 분기 형태가 된다. 언어가 정규언어로 바뀐다는 뜻은 아니다. 정규형은 문법을 쓰는 양식이고 정규언어는 유한 오토마타가 인식하는 언어 부류다.

언어를 잃지 않고 규칙 정리하기

기존 시작 기호가 오른쪽에 있으면 새 시작 기호를 만들고 기존 시작으로 이어 준다. ε를 만들 수 있는 nullable 비단말을 찾아 그 비단말이 없어지는 경우의 규칙도 추가한 뒤 시작 예외 외의 ε 규칙을 제거한다. 빈 문자열이 원래 가능했는지는 별도로 보존한다.

A→B 같은 단위 규칙은 A가 단위 경로로 도달하는 비단말의 비단위 규칙을 직접 복사하여 제거한다. 단위 규칙을 삭제만 하면 생성 문자열이 사라질 수 있다. ε 제거가 단위 규칙을 새로 만들 수 있어 처리 순서에도 주의한다.

터미널을 묶고 긴 규칙을 나누기

두 기호 이상이 있는 오른쪽의 터미널은 보조 비단말로 바꾼다. aB라면 X→a와 A→XB로 바꿀 수 있다. 세 비단말 ABC는 새 C1을 도입해 A0→AC1, C1→BC처럼 두 개씩 나눈다.

새 보조 기호가 기존 기호와 겹치지 않도록 한다. 변환 후 규칙마다 형식을 검사하고 이전 문법의 짧은 문자열을 양쪽에서 유도해 본다. 몇 개 예제를 비교한 것만으로 언어 전체의 동치 증명이 끝난 것은 아니며, 각 변환의 언어 보존 근거가 필요하다.

네 행을 세는 문제가 아니라 두 발생 위치의 유지·삭제 선택을 세는 문제다. AA의 삭제 결과에는 세 고유 오른쪽이 있고, ε는 시작에서만 남긴다. H의 규칙 수는 S0의 네 대안과 A의 한 대안을 합한 5개다.

중간 과정을 따라가는 예제

문법 S→aSb | ab는 n≥1인 a^n b^n을 만든다. 빈 문자열을 만들지 않는 이 문법을 새 시작 S0를 가진 CNF로 바꾸고 aabb를 유도하라.

  1. X→a, Y→b를 도입하고 S→XSY | XY로 터미널 혼합을 없앤다.

  2. 긴 규칙을 S→XC, C→SY로 나눈다.

  3. 새 시작 S0→S를 도입한 뒤 단위 규칙을 제거하여 S0→XC | XY로 S의 비단위 규칙을 복사한다.

  4. 최종 규칙은 S0→XC | XY, S→XC | XY, C→SY, X→a, Y→b다.

  5. S0⇒XC⇒XSY⇒XXYY⇒aaYY⇒aabY⇒aabb로 유도한다.

모든 규칙이 두 비단말 또는 한 터미널이고 S0는 오른쪽에 없다. 이 문법은 ε를 생성하지 않는다.

조건을 바꾸어 비교하기

발생 선택과 고유 규칙 수를 나눈다

G에서 AA의 nullable 삭제 선택과 최종 H의 언어를 설명하라.

  1. 유지/첫 삭제/둘째 삭제/둘 다 삭제의 결과는 AA,A,A,ε다. 중복 A를 합치면 세 오른쪽이다.

  2. H의 AA는 aa만, terminal 대안은 a와 b, 시작 ε는 빈 열을 만든다. 원래 G의 두 A도 각각 a 또는 ε라 같은 네 출력을 만든다.

삭제 선택은 4개, 고유 오른쪽은 3개, 전체 언어의 문자열은 4개다.

비교할 점

규칙 수와 문자열 수, 발생 위치 선택 수는 각각 다른 장부다.

단위 순환의 언어를 규칙 복사로 보존한다

J의 단위 규칙을 제거하라. S→A를 그냥 삭제한 경우도 비교하라.

  1. 단위 도달의 자기 쌍도 포함해 S,A,B가 a를 생성하는 B에 도달함을 확인한다.

  2. 새 규칙은 S→a, A→a, B→a다. 반면 S→A만 삭제하면 시작 S의 규칙이 없어 언어는 공집합이다.

복사 변환은 {a}를 유지하며 단순 삭제는 a를 잃는다.

비교할 점

순환이 있다는 이유로 모든 도달 규칙을 지워도 된다는 결론은 틀리다.

종이와 본문으로 직접 해보기

같은 CNF로 ab를 유도하고 aaa 또는 abb를 만들 수 없는 이유를 적어라.

힌트 보기

S0→XY를 기본 경우로 보며 XC·SY의 쌍이 a와 b를 하나씩 더한다.

풀이 보기

S0⇒XY⇒aY⇒ab다. 반복은 a와 b를 같은 수만큼 늘리며 a가 먼저, b가 뒤라 aaa와 abb는 생성되지 않는다.

오해와 반례

CNF로 쓰면 그 언어는 정규언어다.

위 문법은 a^n b^n을 생성하는 문맥자유 문법이며 유한 오토마타로 같은 수를 끝없이 기억할 수 있는 정규언어가 아니다. 형식 이름의 정규와 언어 부류를 구분한다.

자기점검

A→aB는 CNF 규칙인가?

답과 이유 보기

아니다.

터미널과 비단말이 섞인 두 기호다.

ε를 원래 생성하지 않는 문법에 S0→ε를 추가해도 되는가?

답과 이유 보기

안 된다.

생성 언어에 새 문자열을 추가한다.

A→B를 그냥 지우면 언어가 보존되는가?

답과 이유 보기

보장되지 않는다.

B의 비단위 규칙에 대한 도달 가능성을 A에 복사해야 한다.

스스로 풀어보기

먼저 답과 이유를 적고, 필요한 만큼 힌트를 한 단계씩 열어 보세요.

연습 1 · 값과 상태 예측

H에서 aa와 ε의 규칙 적용 수를 각각 구하라.

힌트 1

aa는 S0→AA를 쓴다.

힌트 2

빈 출력은 시작 예외다.

풀이와 답 확인

  1. aa는 binary 한 번과 A→a 두 번으로 총 3회다.

  2. ε는 S0→ε 한 번으로 끝난다.

aa는 3회, ε는 1회다.

흔한 오답에서 다시 생각하기

길이 0을 2n−1에 대입해 −1회다.

비어 있지 않은 입력이라는 유도 횟수 식의 조건을 유지한다.

연습 2 · 오류 찾아 고치기

G의 A→ε를 지우고 S→AA | b만 남겼다. 무엇을 잃는가?

힌트 1

남은 A는 a만 만든다.

힌트 2

원래 두 A 중 일부 또는 모두를 비울 수 있었다.

풀이와 답 확인

  1. 새 문법은 aa와 b만 만든다.

  2. 원래 a와 ε를 만들던 삭제 대안을 보충하지 않았으므로 두 문자열을 잃었다.

nullable 제거는 규칙 삭제와 삭제 발생 대안 추가를 함께 해야 한다.

흔한 오답에서 다시 생각하기

빈 규칙은 글자를 만들지 않아 언어에 영향이 없다.

나중 문장에서 어느 발생을 비울 수 있는지가 출력 길이를 바꾼다.

연습 3 · 직접 만들어 보기

H에서 단어 b를 제거하고 ε,a,aa만 만드는 CNF를 구성하라.

힌트 1

S0의 대안별 출력을 본다.

힌트 2

비시작 ε를 새로 넣지 않는다.

풀이와 답 확인

  1. S0→b만 삭제하고 S0→AA | a | ε, A→a를 남긴다.

  2. 각 남은 규칙은 ε,a,aa 중 하나만 생성하며 세 문자열 각각의 유도가 있다.

새 문법은 요구 언어를 두 방향으로 정확히 생성한다.

흔한 오답에서 다시 생각하기

A→ε를 다시 추가해 짧은 출력도 만든다.

이미 시작 예외와 a 대안이 있으므로 비시작 ε 추가는 CNF 계약을 깨뜨린다.

연습 4 · 선택 심화

선택 심화는 기본 연습 뒤 더 탐구하고 싶을 때 풀어 보세요.

길이 n≥1인 CNF 트리에서 binary 규칙 수와 terminal 규칙 수를 증명하라.

힌트 1

terminal 규칙이 만드는 문자 잎은 n개다.

힌트 2

모든 내부 분기가 두 자식을 갖는 binary 골격의 간선 수를 센다.

풀이와 답 확인

  1. binary 노드를 I개라 하면 골격 노드는 I+n개, 간선은 I+n−1개다. 각 binary 노드가 두 간선을 내므로 2I=I+n−1이다.

  2. 따라서 I=n−1이며 각 문자 잎에 terminal 규칙 한 번을 더해 전체 적용 수는 2n−1이다.

n=1에서는 binary 0회와 terminal 1회다. ε 시작 예외는 별도로 처리한다.

흔한 오답에서 다시 생각하기

CNF면 모든 문자열 길이가 짝수다.

binary는 비단말을 분기하고 최종 잎 수는 임의의 양의 n일 수 있다.

내 말로 설명하기

CNF 변환은 파스 트리 모양도 그대로 보존하는가?

설명 기준 확인

새 보조 기호와 규칙이 구조를 바꾼다. 요구 보존 대상은 생성 언어이며 원래 트리와 같은 모양이라는 주장은 별도다.

네 삭제 선택이 항상 서로 다른 네 규칙인가?

설명 기준 확인

같은 기호의 반복 발생처럼 결과가 중복될 수 있다. 고유 오른쪽을 집합으로 합친다.

한 단계 더

원래 문법에 S→ε도 있다고 하자. 새 시작에 ε를 보존하고 nullable S가 사라지는 경우를 어떻게 추가해야 하는지 추적해 보자. 시작 기호 오른쪽 금지 조건도 함께 점검한다.

소단원 8.2

닫힘 성질과 펌핑

서로 간단한 두 조건을 동시에 요구하면 왜 더 어려운 언어가 될까?

준비 개념과 학습 목표

준비 개념

  • 언어는 문자열 집합이며 교집합은 두 조건을 동시에 만족한다.

  • a^n은 a를 n번 이어 붙인 문자열이다.

학습 목표

  • CFL의 닫힘과 예외를 구분한다.

  • 펌핑 정리의 양화 순서로 비문맥자유 증명을 쓴다.

정규 필터로 짝수만 남기는 일과 두 스택 조건을 합치는 일은 같을까?

L={aⁿbⁿ | n≥0}와 정규 언어 R={a의 개수가 짝수인 모든 a/b 열}을 비교한다. L∩R은 {a²ᵏb²ᵏ | k≥0}이며 E→aaEbb | ε로 생성한다. regular 필터는 유한 parity 상태만 요구하므로 원래 스택과 유한 상태의 곱으로 처리할 수 있다.

곱 상태는 PDA 제어 상태와 DFA 제어 상태의 쌍이다. PDA가 문자 하나를 소비할 때 DFA도 같은 문자를 읽고, PDA가 ε 이동을 할 때 DFA 상태는 유지한다. 입력 전체 뒤 PDA 승인 조건과 DFA 승인 상태를 모두 요구한다. 스택이 두 개가 되는 것이 아니며 두 임의 NPDA를 같은 방식으로 곱으로 결합해 두 CFL의 일반 교집합을 해결한 것으로 확대하지 않는다.

새 반례 C={aⁿbⁿc²ⁿ | n≥1}를 보자. U={aⁿbⁿcᵐ | n,m≥1}, V={aᵐbⁿc²ⁿ | m,n≥1}는 각각 CFG로 만들 수 있지만 U∩V=C다. V의 뒤 블록은 B→bBcc | bcc로 생성한다. 두 조건을 동시에 만족시키는 C가 비CFL임은 모든 허용 pumping 분해에 대한 논증이 필요하다.

pumping 길이를 p라 가정하고 s=aᵖbᵖc²ᵖ를 고른다. |vxy|≤p인 연속 구간은 a와 c를 동시에 포함할 수 없다. 마지막 a부터 첫 c까지도 p+2글자가 필요하다. 따라서 i=0으로 v와 y를 삭제하면 최대 두 종류의 개수만 바뀌며, 적어도 한 종류는 줄어든다. 변하지 않는 a 또는 b의 개수가 p이면 목표 관계는 다른 a/b의 개수도 p, c의 개수도 2p로 강제한다. c의 개수가 2p로 유지되어도 목표 n=p가 강제된다. 어느 종류를 줄여도 목표 관계를 만족하지 못한다.

  • 문법의 언어 보존 조건

어떤 조합을 유지할 수 있는가

문맥자유언어(CFL)는 합집합·연결·Kleene 별에 대해 닫혀 있다. 새 시작 기호에서 각 문법 시작으로 분기하거나 차례로 연결하는 구성이 가능하기 때문이다. 단, 서로 다른 문법의 비단말 이름은 겹치지 않게 바꾼다.

두 CFL의 교집합은 항상 CFL이 아니다. CFL과 정규언어의 교집합은 CFL인데, 유한 제어와 하나의 스택을 함께 사용하면 되기 때문이다. 모든 교집합이 실패한다는 말과 항상 성공한다는 말은 둘 다 틀리다. 일반 CFL은 여집합에 대해서도 닫혀 있지 않다.

반복 가능한 두 조각

CFL 펌핑 정리는 어떤 길이 p가 존재하여, 길이 p 이상인 언어의 모든 s를 s=uvxyz로 나눌 방법이 있고 |vy|≥1, |vxy|≤p이며 모든 i≥0에 대해 uv^i xy^i z가 언어 안에 있다는 필요조건이다. v와 y는 같은 횟수로 반복한다. 둘 중 하나는 비어도 둘 다 비면 안 된다.

비문맥자유 증명에서는 언어가 CFL이라고 가정하고 그 p에 의존하는 s를 고른 뒤 허용되는 모든 분해를 고려한다. 자신이 고른 한 분해만 실패했다고 결론내릴 수 없다. 반대로 펌핑이 가능해 보인다는 사실만으로 문법이 존재한다고 결론내리는 역방향도 허용되지 않는다.

동시에 세 수 맞추기의 한계

L={a^n b^n c^n : n≥1}에서 s=a^p b^p c^p를 택한다. 길이 p 이하인 연속 부분 vxy는 a 블록과 c 블록을 동시에 걸칠 수 없다. 사이에 b가 p개 있어 두 끝의 문자까지 포함하려면 p보다 길어지기 때문이다.

따라서 반복 조각 v·y가 제거하는 문자는 많아야 두 종류다. i=0으로 지우면 |vy|≥1이므로 적어도 한 종류 수가 감소하지만 적어도 한 종류 수는 p로 남아 세 수가 같지 않다. 삭제 뒤 블록 순서는 그대로이므로 수 불일치만으로도 언어 밖임을 보인다.

중간 과정을 따라가는 예제

L1={a^n b^n c^m : n,m≥1}, L2={a^m b^n c^n : n,m≥1}의 교집합을 구하고 CFL 교집합 닫힘의 반례임을 설명하라.

  1. L1은 앞 a·b 수를 문법 A→aAb | ab로 맞추고 c를 C→cC | c로 붙여 CFL이다.

  2. L2는 a를 D→aD | a로 만들고 뒤 b·c 수를 E→bEc | bc로 맞춰 CFL이다.

  3. 교집합에서는 a=b이고 b=c여야 해서 a^n b^n c^n만 남는다.

  4. 위 펌핑 증명의 모든 분해에 대해 i=0이 세 수를 깨므로 교집합 언어는 CFL이 아니다.

두 입력 언어는 CFL이지만 그 교집합은 CFL이 아니다. 이는 항상 닫힘이 성립한다는 주장을 반박한다.

연습 1 · 값과 상태 예측

곱 PDA가 ε 이동할 때 parity DFA 상태도 바꿔야 하는가? 문자 a와 b의 소비도 비교하라.

힌트 1

DFA는 실제 소비 문자만 읽는다.

힌트 2

a만 홀짝을 바꾼다.

풀이와 답 확인

  1. PDA의 ε 이동에서는 parity 상태를 그대로 둔다.

  2. a 소비는 짝↔홀을 바꾸고 b 소비는 같은 parity를 유지한다.

ε 이동은 필터에 새 문자를 전달하지 않는다.

흔한 오답에서 다시 생각하기

PDA 전이 횟수마다 parity를 뒤집는다.

유한 필터가 세는 것은 입력 a의 개수이지 스택 작업 횟수가 아니다.

연습 2 · 오류 찾아 고치기

C의 pumping 증명에서 v=a,y=b인 한 분해만 실패시켰다. 무엇이 부족한가?

힌트 1

문자 s는 p가 주어진 뒤 선택한다.

힌트 2

분해 선택은 증명자가 고정할 수 없다.

풀이와 답 확인

  1. 모든 |vy|≥1, |vxy|≤p 허용 분해를 다뤄야 한다.

  2. 종류 세 개를 덮지 못하는 구간 길이와 삭제 뒤 남은 종류가 강제하는 n=p를 사용하면 어떤 분해에도 i=0이 실패한다.

한 분해를 나열하는 대신 모든 분해를 포괄하는 범위 논증이 필요하다.

흔한 오답에서 다시 생각하기

실패 분해가 하나라도 있으면 pumping 필요조건이 깨진다.

정리는 성공 가능한 분해가 하나 존재한다는 주장이다. 이를 반박하려면 모든 분해를 막아야 한다.

연습 3 · 직접 만들어 보기

L에서 n이 홀수인 부분만 만드는 CFG를 설계하고 처음 두 출력을 구하라.

힌트 1

기본 ab에서 시작한다.

힌트 2

풀이와 답 확인

  1. O→aaObb | ab로 정한다. k번 반복이면 a^(2k+1)b^(2k+1)이다.

  2. 반대로 모든 양의 홀수 n은 2k+1로 쓸 수 있어 해당 반복 횟수로 생성한다. 처음 두 출력은 ab와 aaabbb다.

연습 4 · 선택 심화

선택 심화는 기본 연습 뒤 더 탐구하고 싶을 때 풀어 보세요.

p=2 예시의 s=aabbcccc에서 세 종류를 모두 담는 가장 짧은 연속 구간 길이를 구하고 일반 p와 연결하라.

힌트 1

마지막 a부터 첫 c까지 적는다.

힌트 2

전체 증명은 p=2에서 끝내지 않는다.

풀이와 답 확인

  1. 최단 구간은 abbc이며 길이는 4다. 이는 p=2를 초과한다.

  2. 일반 p에서 마지막 a부터 첫 c까지의 구간 abᵖc는 길이가 p+2다. 이 길이는 항상 p보다 커서 |vxy|≤p인 구간이 세 종류를 함께 포함할 수 없다.

세 종류를 함께 pump하는 분해가 없다는 일반 범위 근거다.

흔한 오답에서 다시 생각하기

전체 입력이 길므로 길이가 2인 구간도 세 종류를 담을 수 있다.

전체 길이와 제한된 연속 창 길이를 구별한다.

내 말로 설명하기

교집합 반례는 모든 두 CFL 교집합이 실패한다는 뜻인가?

설명 기준 확인

아니다. L∩L=L이며 정규 필터 교집합은 특히 CFL로 남는다.

여집합 일반 닫힘을 가정하면 왜 모순인가?

설명 기준 확인

합집합 닫힘과 De Morgan으로 모든 두 CFL의 교집합도 닫히게 되어 U,V의 반례와 충돌한다.

한 단계 더

합집합 닫힘과 De Morgan 법칙을 이용해, 만약 CFL이 여집합에도 닫혀 있다고 가정하면 교집합도 닫혀야 함을 써 보자. 위 반례와 모순이므로 여집합 일반 닫힘도 실패한다.

  • 시작 기호 판정·복잡도·빈 문자열 예외를 설명한다.

전체 칸이 차 있어도 시작 기호가 없으면 승인할까?

새 CNF K는 S0→AX | XB, X→AB, A→a, B→b다. S0는 오른쪽에 없다. 이 문법의 언어는 {aab,abb}다. X는 ab를 생성하지만 시작 S0는 반드시 A를 앞에 붙이거나 B를 뒤에 붙인다. 따라서 ab의 전체 CYK 칸은 {X}여도 시작 기호가 없어 거부한다.

T[i,j]는 1기반 포함 구간을 생성하는 모든 비단말의 집합이다. abb의 길이 1 칸은 {A},{B},{B}이고 길이 2는 {X},∅다. 길이 3은 a|bb의 분할이 실패하지만 ab|b의 X/B로 S0를 얻는다. 한 실패 분할만 보거나 집합 하나를 임의로 고르면 승인 증거를 잃는다.

별도 CNF J는 S0→AB | CD | ε, A→a, B→b, C→a, D→b다. ab의 초기 칸은 {A,C},{B,D}이고 전체 집합은 {S0} 하나지만 적용 규칙은 AB와 CD 두 가지다. membership 집합의 원소 수는 파스 트리 수가 아니다. 두 backpointer를 따로 보존하면 두 트리를 복원할 수 있다.

길이 n의 비어 있지 않은 입력에는 n(n+1)/2개의 포함 구간 칸이 있다. 모든 길이 2 이상 칸의 split 후보 수는 Σ_{ℓ=2}ⁿ(n−ℓ+1)(ℓ−1)=n(n−1)(n+1)/6이다. 이 수는 규칙 검사 횟수나 실제 실행 시간이 아니다. 문법이 고정일 때의 O(n³) 점화 계산과, 문법 크기도 바뀔 때의 추가 비용을 구별한다. ε는 시작의 ε 대안을 따로 검사한다.

    단위 규칙 없는 K와 J의 빈 입력을 서로 다른 계약으로 확인한다.

표의 한 칸이 뜻하는 것

길이 n인 입력 w에서 T[i,j]는 i번째부터 j번째까지 부분문자열을 유도할 수 있는 비단말들의 집합이다. 길이 1 칸은 해당 문자로 가는 A→a 규칙의 A를 모두 넣는다. 여러 A가 가능하면 하나를 선택하지 않고 모두 보존한다.

이 단원의 알고리즘은 비어 있지 않은 입력과 CNF 문법을 사용한다. ε 입력은 표에 길이 0 칸을 억지로 만들지 않고 시작 기호가 ε를 허용하는지 별도로 확인한다. A→B 같은 단위 규칙을 그대로 둔 문법에는 이 기본 점화식을 그대로 적용하면 누락이 생길 수 있다.

구간을 모든 위치에서 둘로 나누기

길이가 2 이상인 [i,j]를 k=i,…,j−1에서 [i,k]와 [k+1,j]로 나눈다. B가 왼쪽 집합, C가 오른쪽 집합에 있고 A→BC 규칙이 있으면 A를 T[i,j]에 추가한다. 가능한 모든 k와 규칙의 결과를 합친다.

길이 1부터 긴 순서로 채우면 필요한 작은 칸이 먼저 계산되어 있다. 이것이 재귀적으로 같은 부분문자열을 여러 번 계산하는 낭비를 줄인다. 어느 한 분할만 실패해도 다른 분할에서 성공할 수 있어 전부 확인해야 한다.

전체 판정과 비용

시작 기호 S0가 T[1,n]에 있을 때만 입력은 문법 언어에 속한다. 다른 비단말이 전체 문자열을 만들 수 있다는 사실은 S0의 유도와 다르다. 표를 채우며 어떤 규칙·분할로 들어갔는지 기록하면 유도 트리도 되짚을 수 있다.

구간 수는 O(n²), 구간마다 분할 위치가 O(n)개다. 문법을 고정하면 기본 구현 시간 O(n³), 공간 O(n²)로 표현한다. 문법 크기도 변하면 규칙 검색 비용이 별도로 포함되며 이 표 판정은 언어 전체의 동치나 문법 비모호성을 판정하는 알고리즘이 아니다.

K와 J의 표를 합치지 않는다. J에는 a를 만드는 두 비단말과 b를 만드는 두 비단말이 있지만 K에는 각각 하나다. 각 칸의 집합과 그 원소를 넣은 규칙·분할 증거를 따로 기록한다.

중간 과정을 따라가는 예제

CNF S0→AB | AC, C→SB, S→AB | AC, A→a, B→b에서 입력 aabb를 판정하라. S0는 오른쪽에 없다.

  1. 길이 1: T[1,1]={A}, T[2,2]={A}, T[3,3]={B}, T[4,4]={B}.

  2. 길이 2: aa와 bb는 ∅, 가운데 ab는 AB 규칙으로 {S0,S}다.

  3. 길이 3: aab의 두 분할에는 해당 규칙이 없어 ∅다. abb는 ab|b에서 SB 규칙으로 {C}다.

  4. 길이 4: a|abb에서 A와 C를 얻어 AC 규칙의 S0,S를 넣는다. 나머지 분할에는 결과가 없다.

  5. T[1,4]={S0,S}이며 S0가 있으므로 수용한다. 유도는 S0⇒AC⇒ASB⇒AABB⇒aaBB⇒aabB⇒aabb다.

aabb는 소속한다. 가운데 ab의 S를 재사용해 abb의 C를 만든 것이 핵심이다.

조건을 바꾸어 비교하기

첫 실패 분할 뒤의 성공 분할을 보존한다

K에서 abb의 두 split과 aab의 두 split을 비교하라.

  1. abb의 a|bb는 오른쪽 빈 집합으로 실패한다. ab|b는 X와 B로 S0→XB를 써 성공한다.

  2. aab의 a|ab는 A와 X로 S0→AX를 써 성공하고 aa|b는 왼쪽 빈 집합으로 실패한다.

두 입력 모두 승인하지만 성공 split은 서로 다르다.

비교할 점

항상 첫 split만 선택하거나 마지막 split만 선택하면 하나를 놓친다.

집합 한 원소와 두 파스 트리를 분리한다

J의 ab 소속과 파스 트리 수를 계산하고 빈 입력도 판정하라.

  1. 왼쪽 집합 {A,C}와 오른쪽 집합 {B,D}에서 AB와 CD가 각각 S0를 만든다. 집합에서 S0는 중복되지 않는다.

  2. 트리는 S0의 자식 A/B 또는 C/D로 두 개다. 빈 입력은 S0→ε가 있어 별도 승인한다.

ab는 승인하며 파스 트리는 2개다. ε도 시작 예외로 승인한다.

비교할 점

동적 계획에서 membership을 집합으로 합치는 것과 트리 증거를 지우는 것을 구별한다.

종이와 본문으로 직접 해보기

같은 문법에서 abb와 ab를 각각 판정하라. 전체 칸에 C만 있는 경우를 주의하라.

힌트 보기

abb의 전체 칸은 위 길이 3 결과이고 ab는 AB 규칙을 본다.

풀이 보기

abb 전체 칸 {C}에는 S0가 없어 거부한다. ab 전체 칸 {S0,S}에는 S0가 있어 수용한다. 부분문자열에서 가능한 C는 시작 기호를 대신하지 않는다.

오해와 반례

전체 칸이 비어 있지 않으면 입력을 수용한다.

abb는 C로 유도할 수 있어 전체 칸이 비지 않지만 S0로는 생성되지 않는다. 시작 기호 포함 여부가 필요하다.

새 보고서에서 G의 S→AA | b, A→a | ε를 H의 S0→AA | a | b | ε, A→a로 변환한 언어와 aa의 규칙 횟수를 확인하라. 별도 K의 S0→AX | XB, X→AB, A→a, B→b로 abb와 ab를 판정하라. 마지막으로 두 CFL U={aⁿbⁿcᵐ:n,m≥1}, V={aᵐbⁿc²ⁿ:m,n≥1}의 교집합과, 짝수 필터 L∩R의 언어 부류를 구별하라. K에는 ε 대안이 없다는 조건을 유지하라.

힌트 1

nullable의 두 발생 위치 삭제 결과를 합치고 CYK에서는 시작 기호를 찾는다.

힌트 2

U와 V의 수 관계를 함께 쓰되 regular parity 필터와 같은 종류의 곱이라고 확대하지 않는다.

풀이와 답 확인

  1. G와 H의 언어는 {ε,a,aa,b}다. AA의 네 삭제 선택에서 고유 결과는 AA, A, ε의 세 가지다. H의 aa는 이진 규칙 1회와 terminal 규칙 2회로 만들므로 전체 규칙 적용 수는 3회다.

  2. K의 abb에서 길이 1인 칸은 {A},{B},{B}이고 길이 2인 칸은 {X},∅다. 전체 칸은 {S0}로 승인한다. ab의 전체 칸 {X}에는 S0가 없어 거부한다. K의 빈 입력도 시작 ε 대안이 없어 거부한다.

  3. U∩V는 {aⁿbⁿc²ⁿ:n≥1}다. 모든 제한 pumping 분해에서 i=0의 삭제가 수 관계를 깨뜨리므로 이 언어는 비CFL이다. 반면 L∩R={a²ᵏb²ᵏ:k≥0}는 E→aaEbb | ε로 생성하는 CFL이며 ε를 포함한다.

H의 네 출력과 aa의 규칙 적용 수 3회를 보존한다. K는 제시된 입력 중 abb만 승인하고 ab와 빈 입력은 거부한다. 두 임의 CFL의 교집합 반례와 CFL∩regular의 닫힘은 서로 다른 보장이다.

해결한 뒤 점검할 것

  • 삭제 선택은 4개, 고유 오른쪽은 3개, 출력 문자열은 4개임을 구별하고 aa의 규칙 적용 수 3회를 확인한다.

  • K의 모든 split과 전체 시작 기호, K/H의 빈 입력 차이를 정확히 기록한다.

  • 교집합 수 관계와 임의 p의 모든 분해 반박을 쓰고 짝수 문법의 양방향 생성을 확인한다.

G의 AA에서 발생 위치를 삭제하는 네 선택은 AA, A, A, ε를 만든다. 중복을 합치면 고유 오른쪽은 3개다. H의 언어는 {ε,a,aa,b}이며 전체 규칙 수는 5개임을 손으로 확인했다. 단위 순환 J에서는 S, A, B가 모두 a를 만드는 B에 도달한다. 규칙 복사로 언어 {a}를 유지하는 경우와 시작 단위 규칙만 삭제해 공집합이 되는 경우를 대조했다. 양의 길이 n인 CNF 트리의 이진 규칙 수 n−1과 terminal 규칙 수 n을 간선 장부로 유도해 전체 적용 수 2n−1을 확인했다. parity 필터의 짝수 문법과 홀수 문법은 생성 방향과 역방향을 함께 확인했다. C의 임의 p에 대해 길이가 p 이하인 창은 a와 c를 함께 담을 수 없다. 따라서 i=0의 삭제는 최소 한 종류를 유지하고 최소 한 종류를 줄여 목표 수 관계를 깨뜨림을 논증했다. K의 aab와 abb는 각각 두 split을 모두 확인했으며 ab의 전체 칸 {X}에는 S0가 없어 거부함을 확인했다. J의 ab는 두 backpointer를 갖고 빈 입력은 시작 ε 대안으로 승인한다. 길이가 3인 입력은 구간 칸 6개와 split 후보 4개를 갖고, 길이가 4인 입력은 구간 칸 10개와 split 후보 10개를 갖는다. 일반 split 합 n(n−1)(n+1)/6은 유한합으로 유도했다. 단원 전이에서도 빈 입력의 K 거부와 H 승인, 네 출력과 aa의 규칙 적용 수 3회, 두 종류 교집합의 언어 부류를 대조했다.
