소단원 2.1

상태·전이·수용

긴 0·1 카드 줄에서 1이 짝수 번 나왔는지, 카드 수를 모두 기억하지 않고 판정할 수 있을까?

준비 개념과 학습 목표

준비 개념

  • 집합은 원소들의 모음이다. q∈Q는 q가 상태 집합 Q의 원소라는 뜻이며, F⊆Q는 수용 상태를 Q에서 골랐다는 뜻이다.

  • 알파벳 Σ는 사용할 기호의 유한 집합이다. Σ={0,1}에서 문자열은 010처럼 기호를 순서대로 나열한 유한 줄이며, Σ*는 가능한 모든 유한 문자열의 집합이다.

  • ε는 길이 0인 빈 문자열이다. ∅는 원소가 하나도 없는 집합이며, {ε}는 빈 문자열 한 개를 원소로 가진 집합이다. 0개는 짝수다.

  • 함수는 각 입력에 출력 하나를 정한다. 상태와 기호를 함께 입력하는 전이함수에서는 가능한 모든 상태·기호 쌍에 다음 상태가 정확히 하나 있어야 한다.

학습 목표

  • DFA의 다섯 구성 요소와 전이표의 전체함수 조건을 설명한다.

  • 기호 하나의 전이와 문자열 전체의 확장 전이를 구분한다.

  • 빈 문자열과 중간 수용 상태를 포함한 추적에서 최종 수용·거부를 결정한다.

작은 기억으로 긴 입력을 요약하기

1의 개수가 짝수인지 홀수인지 알려면 정확한 개수 대신 두 가지 경우만 기억하면 된다. 아직 아무 기호도 읽지 않았을 때 1은 0개이므로 E에서 시작한다. 0은 개수의 짝홀을 바꾸지 않고, 1은 E와 O를 서로 바꾼다. 이 두 상태는 읽은 부분의 정보를 요약하며, 실제 컴퓨터의 메모리 주소나 전압을 뜻하지 않는다.

이 예제는 M=(Q,Σ,δ,q₀,F), Q={E,O}, Σ={0,1}, q₀=E, F={E}로 정의한다. δ(E,0)=E, δ(E,1)=O, δ(O,0)=O, δ(O,1)=E이다. 네 쌍을 모두 적었으므로 빈칸이 없는 전이표다. 각 쌍에 두 다음 상태를 지정하면 결정성이 깨지고, 다음 상태를 생략하면 여기서 채택한 전체 DFA 정의를 충족하지 않는다.

상태 | 기호 0 | 기호 1
E    | E      | O
O    | O      | E

기호 하나와 문자열 전체의 전이

일반적인 결정적 유한 오토마타(DFA)는 유한한 비어 있지 않은 상태 집합 Q, 유한 알파벳 Σ, 전체함수 δ:Q×Σ→Q, 시작 상태 q₀∈Q, 수용 상태 집합 F⊆Q로 이루어진다. F는 비어 있어도 되고 Q 전체여도 된다. DFA에는 ε를 소비하는 전이가 없다. 빈 입력은 전이를 한 번도 하지 않는 경우이지, 별도의 빈 문자열 기호를 읽는 경우가 아니다.

확장 전이 δ*:Q×Σ*→Q는 δ*(q,ε)=q와 δ*(q,xa)=δ(δ*(q,x),a)로 정의한다. x는 이미 읽은 문자열이고 a∈Σ는 마지막 기호다. δ*는 유한 전이표를 반복 적용해 길이가 서로 다른 입력까지 다룬다. 입력에 2처럼 Σ 밖의 기호가 있으면 이 DFA의 문자열 입력 계약을 벗어난다. 실제 프로그램에서 이를 오류로 처리할지, 알파벳을 넓혀 거부 상태로 보낼지는 추가 명세다.

마지막 상태가 판정을 결정한다

w∈Σ*를 전부 읽은 뒤 δ*(q₀,w)∈F이면 수용하고, 그렇지 않으면 거부한다. 따라서 인식 언어는 L(M)={w∈Σ*:δ*(q₀,w)∈F}다. 입력 길이가 유한하고 δ가 전체함수이므로 모든 정상 입력에 최종 상태와 둘 중 하나의 판정이 존재한다. 수용 상태를 중간에 지나갔다고 입력 전체가 수용되는 것은 아니다. 이 기계는 1을 읽으면 거부 상태 O에 있지만, 다음 1을 읽으면 E로 돌아와 11을 수용한다.

예제의 불변식은 읽은 접두부 x에 대해 상태 E일 필요충분조건이 x의 1 개수가 짝수라는 것이다. ε에서 성립하고, 0을 붙이면 개수와 상태가 그대로이며, 1을 붙이면 개수의 짝홀과 상태가 함께 뒤집힌다. 이 귀납 논증은 O의 의미도 함께 유지한다. 최종 상태 E와 언어의 짝수 조건이 동치이므로 원하는 문자열을 놓치지도, 원하지 않는 문자열을 받아들이지도 않는다.

중간 과정을 따라가는 예제

위의 두 상태 DFA에 정상 입력 1011을 넣는다. 전체 상태열과 판정을 구하고, 마지막에 0을 더 붙인 10110과 비교하라.

  1. 아무것도 읽기 전 접두부 ε: 상태 E, 1 개수 0이다. 첫 기호 1을 읽으면 δ(E,1)=O, 개수 1이다.

  2. 두 번째 기호 0을 읽으면 δ(O,0)=O다. 접두부 10의 1 개수는 여전히 1이다.

  3. 세 번째 기호 1을 읽으면 E, 네 번째 기호 1을 읽으면 O다. 접두부 101과 1011의 개수는 각각 2와 3이다.

  4. 1011의 전체 상태열은 E→O→O→E→O이며 마지막 O∉F이므로 거부한다. 0을 더 읽어도 O→O라서 10110도 거부한다.

1011과 10110 모두 거부한다. 중간의 E는 그때까지의 접두부만 수용한다는 뜻이며 전체 입력의 판정을 미리 확정하지 않는다.

종이와 본문으로 직접 해보기

전이표를 종이에 옮겨 ε, 1, 11, 0101을 각각 E에서 시작해 추적하라. 수용되는 문자열만 모은 집합을 적고, 각 입력의 전이 횟수도 적어라.

힌트 보기

입력마다 시작 상태를 다시 E로 설정한다. ε는 화살표를 따라가지 않는다. 0은 현재 상태를 유지하고 1은 바꾼다.

풀이 보기

ε는 E로 끝나 0회 전이 후 수용한다. 1은 E→O로 1회 후 거부한다. 11은 E→O→E로 2회 후 수용한다. 0101은 E→E→O→O→E로 4회 후 수용한다. 제시된 입력 가운데 수용된 문자열의 집합은 {ε,11,0101}이다. 이것은 언어 L(M)의 일부이지 모든 수용 문자열을 열거한 것은 아니다.

오해와 반례

수용 상태는 멈추는 곳이므로 도달하는 순간 입력 읽기를 종료한다.

이 DFA의 E는 수용 상태이면서 1에 의해 O로 이동한다. 시작부터 E에서 멈추면 1도 잘못 수용한다. 일반 DFA의 수용 판정은 입력 끝에서 하며, 수용 상태에도 모든 기호의 전이가 필요하다. 구현의 조기 종료를 도입하려면 남은 입력이 판정을 바꾸지 않는다는 별도의 정당화가 필요하다.

자기점검

이 DFA는 ε를 수용하는가? ε와 ∅는 같은 대상인가?

답과 이유 보기

ε를 수용한다. ε와 ∅는 다르다.

δ*(E,ε)=E∈F이다. ε는 문자열이고 ∅는 빈 집합이다. 이 기계의 언어는 ε를 포함하므로 공집합도 아니다.

입력 1110의 최종 상태와 판정은?

답과 이유 보기

최종 O, 거부.

상태열 E→O→E→O→O이며 1이 세 번 나온다. 0은 짝홀을 바꾸지 않는다.

δ(O,0)을 생략한 표를 그대로 전체 DFA라고 할 수 있는가?

답과 이유 보기

아니다. 누락된 쌍을 정의해야 한다.

O∈Q와 0∈Σ이므로 (O,0)은 함수의 정의역에 속한다. 화살표 생략을 함정 상태로 해석하는 관례를 쓰려면 그 상태와 생략 전이 및 그 상태의 모든 전이를 명시해야 한다.

한 단계 더

같은 완전 DFA에서 수용 집합을 F에서 Q\F로 바꾸면 Σ* 안에서 여집합 언어를 얻는다. 각 정상 입력에 하나의 최종 상태가 있고, 그 상태가 F 또는 Q\F 중 정확히 하나에 속하기 때문이다. 위 표에서는 F={O}로 바꾸면 1 개수가 홀수인 문자열만 수용하고 ε는 거부한다. Σ를 바꾸지 않아야 여집합의 전체 범위가 일치한다. Σ 밖의 기호에 대한 실제 오류 처리는 이 정리의 수용·거부와 구별한다.

소단원 2.2

언어에서 DFA 구성

마지막 두 카드가 01인지 검사할 때, 지금까지 나온 모든 카드를 기억해야 할까?

준비 개념과 학습 목표

준비 개념

  • 접두부는 문자열 앞부분, 접미부는 뒷부분이다. 1101의 길이 2 접미부는 01이며 길이 0 접미부는 ε다. 부분 문자열은 연속한 중간 부분도 포함한다.

  • 언어 L⊆Σ*는 조건을 만족하는 문자열들의 집합이다. 이 소단원의 L은 Σ={0,1}에서 마지막 두 기호가 01인 문자열들의 집합이다. 길이 0이나 1인 문자열은 조건을 충족하지 않는다.

  • DFA는 유한 상태 Q, 알파벳 Σ, 모든 상태·기호 쌍의 다음 상태 δ, 시작 상태 q₀, 수용 집합 F를 갖는다. 정상 입력을 끝까지 읽고 마지막 상태가 F에 속할 때만 수용한다.

  • 귀납법은 빈 입력에서 성립함을 보이고, 성립하는 접두부에 기호 하나를 붙여도 성립함을 보여 모든 유한 길이로 확장하는 방법이다.

학습 목표

  • 목표 언어의 조건과 상태가 기억할 정보를 먼저 명시한다.

  • 겹치는 접미부를 고려해 빈칸 없는 전이표를 구성한다.

  • 각 상태의 의미를 귀납적으로 보존해 수용과 언어 소속의 양방향을 증명한다.

목표 조건에서 기억할 정보를 고르기

검사 조건은 문자열 어딘가에 01이 있는지가 아니라 끝이 01인지다. 지나간 전체 입력을 저장하는 대신, 앞으로 기호가 붙었을 때 끝부분이 어떻게 바뀔지 결정하는 정보를 남긴다. 후보 패턴 01의 접두부는 ε, 0, 01이다. 이미 읽은 문자열의 접미부이기도 한 후보 가운데 가장 긴 것을 기억하면 다음 기호를 처리할 수 있다.

상태 q₀는 가장 긴 후보가 ε인 경우, q₁은 0인 경우, q₂는 01인 경우를 뜻한다. 같은 뜻을 분할해서 쓰면 q₁은 마지막 기호가 0인 모든 문자열, q₂는 끝이 01인 모든 문자열, q₀는 ε 또는 마지막 기호가 1이면서 끝이 01은 아닌 모든 문자열이다. 이 세 경우는 겹치지 않고 모든 이진 문자열을 덮는다. 빈 입력은 q₀에 속하고 수용 조건은 q₂에만 해당한다.

모든 전이를 상태의 뜻에서 도출하기

Q={q₀,q₁,q₂}, Σ={0,1}, 시작 q₀, F={q₂}로 정한다. 어느 상태에서든 0을 붙이면 마지막 기호가 0이므로 q₁로 간다. q₁에서 1을 붙이면 이전 마지막 0과 새 1이 함께 01을 만들어 q₂로 간다. q₀에서 1을 붙이면 끝이 01이 아니므로 q₀다. q₂의 마지막 기호는 1이므로 거기에 1을 붙여도 끝이 01이 아니어서 q₀다.

따라서 전이표는 아래와 같다. 특히 q₁에서 0을 읽을 때 q₀로 돌아가면 안 된다. 00의 마지막 0은 다음 1과 짝을 만들 수 있어 q₁을 유지해야 한다. q₂는 수용 상태지만 다음 입력 0이나 1을 만나면 각각 q₁이나 q₀로 이동한다. 상태 이름에 붙은 번호는 처리한 기호의 총개수가 아니다.

상태 | 기호 0 | 기호 1
q₀   | q₁     | q₀
q₁   | q₁     | q₂
q₂   | q₁     | q₀

성공 사례를 넘어 모든 입력을 증명하기

불변식은 각 접두부 x를 다 읽은 상태가 위 세 의미 중 x가 속하는 경우와 정확히 대응한다는 것이다. ε는 q₀로 시작한다. 귀납 단계에서 새 기호가 0이면 이전 상태와 무관하게 q₁의 의미가 맞는다. 새 기호가 1이고 이전 상태가 q₁이면 직전 기호가 0이어서 q₂의 의미가 맞는다. 나머지 q₀·q₂에서 1을 읽으면 이전 입력은 ε이거나 마지막이 1이므로 결과는 q₀의 의미에 맞는다. 이로써 표의 여섯 전이를 모두 확인했다.

이 불변식에서 최종 상태 q₂일 필요충분조건이 입력의 끝이 01이라는 결론이 나온다. 수용된 입력은 반드시 L에 속하고, L에 속하는 모든 입력은 반드시 수용된다. 한쪽 포함만 보이면 틀린 기계도 통과할 수 있다. 예를 들어 모든 문자열을 수용하는 기계는 L의 모든 원소를 수용하지만 11까지 받아들이므로 L을 정확히 인식하지 않는다. 유한한 테스트 몇 개와 모든 입력에 대한 귀납 증명도 서로 다른 근거다.

중간 과정을 따라가는 예제

위의 전체 전이표로 입력 11001을 추적하고, 한 기호를 더 붙인 110011과 비교하라. 각 상태의 접미부 의미를 확인하라.

  1. ε에서 q₀로 시작한다. 첫 기호 1을 읽으면 q₀이고, 두 번째 1도 q₀를 유지한다. 1과 11 모두 끝이 01이 아니다.

  2. 세 번째 기호 0을 읽으면 q₁이다. 접두부 110의 마지막 0을 기억한다.

  3. 네 번째 0을 읽어도 q₁이다. 1100의 마지막 0은 이후의 1과 새 패턴을 만들 수 있다. 다섯 번째 1을 읽으면 q₂다.

  4. 11001은 q₀→q₀→q₀→q₁→q₁→q₂로 수용된다. 1을 더 읽은 110011은 q₂→q₀로 끝나 거부된다.

11001은 끝이 01이어서 수용, 110011은 끝이 11이어서 거부한다. 110011 안에 01이 등장했다는 사실은 이 언어의 조건을 충족하지 않는다.

종이와 본문으로 직접 해보기

각각 새로 시작해 ε, 01, 001, 010을 추적하라. 이어 q₁의 0 전이를 q₀로 잘못 바꾼 표에서 001의 판정이 어떻게 달라지는지 적어라.

힌트 보기

연속한 0 가운데 마지막 0이 다음 1과 연결될 수 있다. 바른 표와 잘못된 표를 각각 q₀에서 시작해 비교한다.

풀이 보기

바른 표에서 ε는 q₀로 거부, 01은 q₀→q₁→q₂로 수용, 001은 q₀→q₁→q₁→q₂로 수용, 010은 q₀→q₁→q₂→q₁로 거부한다. 잘못된 표에서 001은 q₀→q₁→q₀→q₀로 거부된다. 실제로 끝이 01인 입력을 놓치므로 언어의 모든 원소를 수용한다는 방향이 깨진다.

오해와 반례

상태는 지금까지 패턴을 몇 글자 맞혔는지만 세면 되고, 실패하면 무조건 시작 상태로 돌아가면 된다.

끝부분이 새로운 시작 후보와 겹칠 수 있다. 00에서 두 번째 0은 01의 첫 기호 후보이므로 q₁을 유지해야 한다. 무조건 q₀로 돌리면 001을 놓친다. 또한 한때 패턴 전체를 맞힌 q₂에서 이후 기호를 무시하면 010을 잘못 수용한다. 상태 의미에는 다음 입력에 필요한 접미부 정보와 최종 판정 조건이 함께 들어가야 한다.

자기점검

이 기계에서 q₀에 있는 접두부는 반드시 빈 문자열인가?

답과 이유 보기

아니다. 1, 11, 011도 q₀에 있다.

q₀는 ε 또는 마지막이 1이면서 끝이 01은 아닌 경우다. 많은 서로 다른 접두부가 같은 미래 판정 정보를 가질 수 있다.

입력 10101의 최종 상태는?

답과 이유 보기

q₂, 수용.

q₀→q₀→q₁→q₂→q₁→q₂다. 마지막 01이 조건을 충족하며, 중간 q₂ 이후에도 입력을 계속 읽는다.

L의 모든 원소를 수용한다는 사실만으로 L을 인식했다고 결론내릴 수 있는가?

답과 이유 보기

아니다. L 밖의 원소를 거부한다는 방향도 필요하다.

인식은 L(M)=L이라는 집합의 동등성이다. 모든 문자열을 수용하면 L⊆L(M)은 성립하지만 11처럼 L 밖의 입력까지 수용한다.

한 단계 더

세 상태를 더 줄일 수 없다는 것을 접미부로 구별해 보자. 접두부 ε, 0, 01이 각각 q₀,q₁,q₂에 도달한다. ε와 0에는 공통 후속 문자열 1을 붙이면 1은 거부, 01은 수용이라 서로 다른 상태가 필요하다. ε와 01은 후속 ε만으로 거부/수용이 달라지고, 0과 01도 후속 ε만으로 달라진다. 만약 어떤 두 접두부가 같은 상태라면 결정적 전이를 통해 같은 후속 입력에 같은 최종 판정을 해야 하므로 이 차이를 만들 수 없다. 따라서 이 언어를 인식하는 모든 DFA에는 적어도 세 도달 가능한 상태가 필요하고, 구성한 기계는 그 하한을 달성한다. 이는 앞서 정의한 동일 Σ와 전체 입력 판정에 대한 주장이다.

소단원 2.3

실행 추적과 불변식

아주 긴 이진수가 3의 배수인지, 그 큰 수를 계산해 저장하지 않고 판정할 수 있을까?

준비 개념과 학습 목표

준비 개념

  • 이진 문자열의 수값 V는 V(ε)=0, V(xb)=2V(x)+b로 정의한다. b는 기호 0 또는 1의 숫자값이다. 예를 들어 V(110)=2(2·1+1)+0=6이다.

  • 정수의 3으로 나눈 나머지는 0,1,2 중 하나다. u≡v (mod 3)는 u−v가 3의 배수라는 뜻이다. 나머지가 0이면 3의 배수다. 0도 3의 배수다.

  • DFA는 유한 상태와 모든 상태·기호 쌍의 다음 상태를 정한다. 시작 상태에서 입력 전체를 읽은 마지막 상태가 수용 집합에 속하면 수용한다. 입력 ε는 전이를 수행하지 않는다.

  • 불변식은 처리 도중 계속 참인 명제이고, 종료 근거는 아직 읽지 않은 기호 수처럼 매번 줄어드는 비음수 정수로 만들 수 있다. 참인지 확인할 접두부와 처리 위치를 함께 적는다.

학습 목표

  • 이진수의 나머지를 요약하는 전체 DFA를 정의하고 추적한다.

  • 접두부의 수값과 상태의 나머지가 일치한다는 불변식을 귀납 증명한다.

  • 유한 입력의 종료, 시간·메모리 모형, 테스트와 증명의 차이를 구분한다.

큰 정수 대신 작은 나머지를 저장하기

목표 언어를 L₃={w∈{0,1}*: V(w)≡0 (mod 3)}로 정한다. 여기서는 선행 0을 허용하고 ε의 값도 0으로 정의하므로 ε와 0, 00을 모두 수용한다. 이것은 문자열에 부여한 명시적 수학 규약이다. 실제 숫자 입력 형식에서 빈 입력 금지나 선행 0 금지를 원하면 그 문법 조건을 별도로 결합해야 한다.

Q={r₀,r₁,r₂}, Σ={0,1}, 시작 r₀, F={r₀}로 한다. rⱼ는 읽은 접두부의 나머지가 j라는 의미이며 δ(rⱼ,b)=r_h, h=(2j+b) mod 3로 정의한다. 나머지 연산은 상태 자체가 아니라 다음 상태의 정수 인덱스에 적용한다. 표로 쓰면 r₀에서 0/1은 r₀/r₁, r₁에서는 r₂/r₀, r₂에서는 r₁/r₂다. 예를 들어 나머지 2에서 0을 붙이면 2·2=4의 나머지 1이므로 r₁이다. 큰 수 전체는 상태에 보관하지 않는다.

상태 | 기호 0 | 기호 1
r₀   | r₀     | r₁
r₁   | r₂     | r₀
r₂   | r₁     | r₂

모든 접두부에 대한 불변식을 증명하기

입력 w의 앞 k개 기호를 xₖ, 현재 상태를 sₖ라고 하자. 불변식은 0≤k≤|w|이고 sₖ=rⱼ에서 j가 V(xₖ)의 3으로 나눈 나머지라는 것이다. k=0이면 x₀=ε, V(x₀)=0, s₀=r₀이므로 참이다. 다음 기호 b가 있다면 V(xₖ)=3t+j인 어떤 비음수 정수 t가 존재하고, V(xₖb)=6t+2j+b다. 그 나머지는 (2j+b) mod 3이므로 표의 다음 상태가 정확히 맞는다.

이 논증은 수용 상태 r₀만을 대상으로 하지 않고 r₁과 r₂까지 함께 포함한다. 따라서 모든 유한 접두부에 대해 귀납적으로 유지된다. 끝에서 sₙ=r₀일 필요충분조건이 V(w)의 나머지 0이라는 결론을 얻어 수용의 건전성(수용하면 목표 조건을 만족)과 완전성(목표 조건을 만족하면 수용)을 함께 얻는다. 유한 상태로 임의로 큰 정수를 직접 저장하는 것이 아니라 판정에 충분한 동치류를 저장한 것이다.

추적, 종료와 비용은 서로 다른 주장이다

유한 입력 길이를 n이라 하고, 매 단계 정확히 한 기호를 소비한다고 가정한다. 남은 길이 n−k는 처음 비음수이고 한 단계마다 1 줄어들어 n번 전이 후 0이 된다. 전체함수 δ가 있으므로 정상 입력에서 다음 상태를 못 찾아 멈추는 경우도 없다. ε이면 n=0이므로 시작 상태에서 즉시 최종 판정한다. 무한 스트림에 대해 끝의 수용 판정을 내리는 문제는 이 유한 문자열 명세와 다르다.

고정된 세 상태 전이표의 조회와 다음 입력 기호 접근을 각각 상수 비용으로 보는 모형에서는 n번 전이와 마지막 판정으로 O(n+1) 시간이 든다. 상태를 보관하는 메모리는 O(1)이고 전이표도 고정 크기다. 전체 입력을 메모리에 보존하면 입력 저장 공간 O(n)이 별도로 들며, 길이 제한 없는 입력의 위치 k를 이진 정수로 보관하면 O(log(n+1)) 비트가 필요할 수 있다. 스트림 종료 신호를 이용하면 위치 카운터 없이 현재 상태만으로 판정할 수도 있다. 이것은 수학적 비용 모형이며 실제 장치 시간이나 메모리 측정값이 아니다.

중간 과정을 따라가는 예제

위의 나머지 DFA로 이진 문자열 1101을 처리한다. 각 접두부의 상태와 수값을 비교하고 마지막 판정을 구하라.

  1. ε의 값은 0이고 상태 r₀다. 첫 1을 읽으면 (2·0+1) mod 3=1이므로 r₁이며 V(1)=1이다.

  2. 두 번째 1을 읽으면 (2·1+1) mod 3=0이므로 r₀다. V(11)=3이라 나머지가 맞는다.

  3. 세 번째 0을 읽으면 r₀를 유지한다. V(110)=6이며 나머지는 0이다. 아직 입력이 남았으므로 최종 수용을 선언하지 않는다.

  4. 네 번째 1을 읽으면 r₁이다. V(1101)=2·6+1=13, 나머지 1이고 전체 상태열은 r₀→r₁→r₀→r₀→r₁이다.

1101은 13을 나타내므로 거부한다. 앞부분 11과 110은 각각 3과 6이라 수용되지만 남은 기호 때문에 전체 판정은 달라진다.

종이와 본문으로 직접 해보기

00110을 종이에 추적하라. 각 접두부의 수값, 나머지, 상태를 나란히 적어 불변식을 확인한다. ε와 000도 별도로 판정하고, ε를 거부해야 하는 입력 정책을 이 표만으로 만족하는지 답하라.

힌트 보기

맨 앞 0은 V를 0에 유지한다. 이후에는 새 값=2×이전 값+새 비트, 새 나머지=(2×이전 나머지+새 비트) mod 3을 각각 적용한다.

풀이 보기

접두부 ε,0,00,001,0011,00110의 값은 0,0,0,1,3,6이며 나머지는 0,0,0,1,0,0이다. 상태도 r₀,r₀,r₀,r₁,r₀,r₀이므로 5번 전이 후 수용한다. ε는 0번 전이 후, 000은 3번 전이 후 각각 r₀로 수용된다. ε 거부 정책은 이 표의 정의와 다르다. 새 비수용 시작 상태 p를 추가하고 δ(p,0)=r₀, δ(p,1)=r₁로 두면 비어 있지 않은 정상 입력부터 기존 나머지 표를 이용할 수 있다. p를 수용하지 않아 ε만 제외한다.

오해와 반례

몇 개의 입력에서 나머지가 맞았으므로 모든 길이의 입력에서도 올바르고, 실제 프로그램 성능도 입증됐다.

유한 테스트는 시험하지 않은 긴 입력을 보장하지 않는다. 모든 입력의 정확성은 빈 입력의 기초와 일반 접두부에서 한 기호를 붙이는 귀납 단계로 증명했다. 잘못된 r₂의 0 전이를 r₀로 바꾸면 ε,0,1,11은 여전히 맞아도 100은 잘못 수용된다. 올바른 표에서는 100의 상태열 r₀→r₁→r₂→r₁이며 값 4는 3의 배수가 아니다. 또한 이 논증은 추상 표에 대한 것이고 실제 코드, 입력 처리, 하드웨어 및 시간 측정의 검증을 대신하지 않는다.

자기점검

현재 상태 r₂에서 다음 기호 1을 읽으면 어디로 가는가?

답과 이유 보기

r₂.

(2·2+1) mod 3=5 mod 3=2다. 같은 상태를 유지해도 입력 한 기호는 소비하므로 진행이 멈춘 것이 아니다.

1010의 최종 상태와 전이 횟수는?

답과 이유 보기

r₁, 거부, 4번 전이.

상태열 r₀→r₁→r₂→r₂→r₁이며 수값 10의 나머지는 1이다. 길이 4인 입력은 초기 상태까지 합쳐 상태 관측 5개를 갖지만 전이는 4번이다.

현재 상태가 세 종류이므로 전체 입력 저장 공간과 위치 카운터까지 모두 항상 상수 크기인가?

답과 이유 보기

아니다. 현재 상태의 공간과 별도 입력·위치 저장을 구분해야 한다.

고정 상태와 표는 O(1)이다. 길이 n 입력을 저장하면 O(n) 기호 공간이 추가되고, 위치 정수를 보관하는 비트 모형에서는 O(log(n+1)) 비트가 추가될 수 있다. 스트리밍 구현은 입력 전체 저장을 피할 수 있다.

한 단계 더

일반화하면 밑 B≥2의 숫자 기호 {0,…,B−1}와 양의 정수 m에 대해 나머지 상태 r₀,…,rₘ₋₁, 전이 δ(rⱼ,b)=r_h, h=(Bj+b) mod m을 구성할 수 있다. V(ε)=0, V(xb)=B·V(x)+b라는 정의와 같은 귀납 논증이 성립한다. 이 구성은 m개 상태로 충분하다는 상한이며 항상 최소 m개가 필요하다는 뜻은 아니다. 실제로 B=2,m=4의 네 나머지 상태에서는 비수용 r₁과 r₃를 하나의 상태 u로 합칠 수 있다. 두 상태는 기호 0에서 모두 r₂, 기호 1에서 모두 r₃로 가므로 합친 뒤에도 같은 다음 상태를 갖는다. 축약 표는 r₀의 0/1→r₀/u, u의 0/1→r₂/u, r₂의 0/1→r₀/u이고 시작·유일 수용 상태는 r₀다. 따라서 ε와 선행 0을 허용하는 동일 언어를 세 상태로 인식하여 네 상태가 항상 최소라는 주장을 반박한다. 반면 본문의 B=2,m=3 기계는 세 상태가 서로 구별된다. r₀와 다른 두 상태는 후속 ε의 수용 여부로 구별되고, r₁과 r₂는 후속 1에서 각각 r₀ 수용과 r₂ 거부로 구별된다. ε,1,10이 세 상태에 도달하므로 같은 언어를 인식하는 DFA에 세 상태가 필요하다. 실제 숫자 표현의 부호·공백·접두사 등은 별도 알파벳과 문법 명세가 없으면 포함하지 않는다.
