결정기·인식기

정답인 경우를 알아보는 것과 모든 경우에 답을 끝내는 것은 무엇이 다를까?

준비 개념과 학습 목표

준비 개념

  • 튜링기계의 수락·거부·무한 실행

  • 언어와 문자열

학습 목표

  • 인식기와 결정기의 정지 조건을 구별한다.

  • 한 기계의 무한 실행과 언어 비결정성을 구분한다.

  • 공정하게 열거하는 시뮬레이션을 추적한다.

같은 인식기를 공정하게 돌려도 출력 라운드는 같을까?

입력 목록을 w₁=ε, w₂=a, w₃=aa, w₄=aaa,…로 고정한다. 새 인식기 R은 ε에서 정지 거부하고 a는 네 번째 대상 전이에 수락하며 aa는 첫 번째 대상 전이에 수락한다. 길이가 3 이상인 모든 단항 입력에서는 계속 실행한다. 모든 단계 수는 이 자체 종이 계약의 대상 전이 수이며 실제 프로그램 시간은 아니다.

기본의 재시작 방식 A는 라운드 t에서 첫 t개 입력을 매번 초기 구성부터 최대 t 전이까지 모의한다. 새 방식 B는 라운드 t에 t번째 입력을 추가하고 지금까지의 각 비정지 실행을 한 전이씩 이어서 진행한다. 거부 또는 수락한 실행은 더 진행하지 않으며 이미 출력한 문자열도 다시 출력하지 않는다. B에서는 i번째 입력이 라운드 i에 첫 전이를 받으므로 양의 k번째 전이의 수락은 라운드 i+k−1에 발견된다. A는 라운드 max(i,k)에 처음 발견한다. 일반 인식기에 적용할 때에는 추가한 초기 구성도 검사하며 초기 수락이면 두 방식 모두 라운드 i에 바로 출력한다.

두 방식 모두 각 고정 입력에 충분한 유한 전이 수를 언젠가 배분한다. 출력 순서는 입력 목록의 순서일 필요가 없다. 늦게 시작한 짧은 수락이 일찍 시작한 긴 수락보다 먼저 출력될 수 있다. B에서 작업을 저장하는 것이 A보다 항상 더 이른 출력 라운드를 준다는 주장도 맞지 않는다. 비교 단위인 라운드와 라운드 안 대상 전이 수를 따로 기록해야 한다.

열거 출력에서 중복을 없애면 출력 집합은 그대로다. 그러나 이미 나온 문자열보다 작은 문자열이 나중에 나오지 않는다는 보장은 생기지 않는다. 임의 열거기의 미출력은 일반 거부 증거가 아니다. 뒤 연습의 엄격한 shortlex 순서는 길이가 먼저, 같은 길이에서는 사전순인 추가 계약이며 보통 열거기에 자동으로 있는 성질이 아니다.

    기본의 매 라운드 재시작 규칙과 새 구성 유지 규칙을 비교한다.

  • 두 인식기의 공정한 진행

    한 실행의 종료를 기다리지 않고 각 실행에 유한 단계를 배분하는 원리를 사용한다.

수락 집합과 정지 조건

인식기는 언어에 속한 모든 입력을 언젠가 수락하며, 언어 밖 입력을 수락하지 않는다. 밖 입력에서는 정지 거부하거나 영원히 실행할 수 있다. 결정기, 또는 판정기는 여기에 모든 입력에서 유한 시간 안에 정지한다는 조건을 추가한다.

영원히 실행한다는 것은 정지 거부 상태에 들어간 사건과 다르다. 관찰 중 아직 수락하지 않았다는 사실만으로 앞으로도 수락하지 않을 것이라 결론낼 수 없다. 결정기는 언어 밖 입력도 정지해서 거부해야 한다.

좋지 않은 기계가 언어의 한계는 아니다

같은 언어를 인식하는 기계가 여러 개 있을 수 있다. 어떤 인식기가 밖 입력에서 무한 실행한다고 그 언어 자체가 결정 불가능한 것은 아니다. 별도의 모든 입력에서 멈추는 결정기가 존재할 수 있다.

예를 들어 단항 문자열의 길이가 짝수인 언어는 길이를 끝까지 세고 짝홀을 확인하면 결정할 수 있다. 굳이 홀수 입력에서 계속 기다리는 인식기를 만들었더라도 더 좋은 결정기의 존재를 지우지 못한다. 비결정성은 한 프로그램의 실패가 아니라 모든 결정기 후보에 대한 주장이다.

무한 기다림을 피하며 열거하기

열거기는 입력을 받아 답하기보다 언어의 문자열들을 출력한다. 인식기로 열거기를 만들 때 첫 문자열 실행이 끝날 때까지 기다리고 다음으로 가면 밖 입력의 무한 실행에 막힐 수 있다. 여러 입력에 유한 단계씩 돌아가며 시간을 배분한다.

아래는 라운드 t마다 첫 t개 문자열을 각각 처음부터 최대 t단계까지 시뮬레이션하고 새로 확인한 수락 문자열을 출력하는 방식이다. 이미 출력한 문자열은 중복 출력하지 않는다고 약속한다. 문자열이 목록의 i번째이고 수락까지 k단계가 걸리면 t≥max(i,k)인 라운드에는 확인된다. 실제 시간 효율이 좋은 방법이라는 뜻은 아니다.

공정성 계약 실패

행의 라운드는 대상 전이 수와 다르다. A는 매번 처음부터 실행하므로 같은 전이를 다시 모의할 수 있다. B는 직전 구성을 보존한다. 표의 출력 라운드는 위 정의에서만 정확하며 실제 벽시계 속도 비교가 아니다.

중간 과정을 따라가는 예제

언어는 {aⁿ | n≥0이고 n은 짝수}다. R은 길이가 짝수면 유한 시간에 수락하고 홀수면 무한 실행한다. D는 길이를 세어 짝수 수락/홀수 거부한다. ε, aa, aaa의 결과를 비교하라.

  1. ε의 길이는0으로 짝수이므로 R과 D 모두 수락한다.

  2. aa의 길이2도 둘 다 수락한다.

  3. aaa의 길이3에서 R은 무한 실행하고 D는 정지 거부한다. 둘의 수락 집합은 같은 짝수 길이 언어다.

R은 인식기이며 결정기는 아니다. D는 모든 입력의 길이를 유한하게 읽고 판정하므로 같은 언어의 결정기다.

  1. A의 a는 목록 위치 2를 포함하고 네 전이를 허용한 라운드 4에 발견된다. aa는 위치 3을 처음 포함한 라운드 3에서 발견된다.

  2. B의 a는 라운드 2,3,4,5에 각각 첫째부터 넷째 전이를 받아 라운드 5에 수락한다. aa는 라운드 3의 첫 전이에 수락한다.

  3. A의 라운드 3,4,5 새 출력은 aa,a,없음이고 B는 aa,없음,a다.

두 방식 모두 aa를 먼저 출력한다. a의 최초 출력은 A에서 라운드 4, B에서 라운드 5다.

비교할 점

구성을 저장한다는 사실만으로 라운드 번호가 작아지지는 않는다. 각 라운드의 배분 규칙을 확인한다.

관찰 장부의 종류를 구별한다

정지 여부와 관계없이 예약 상한만 계산한다. A는 라운드 r에 r개 실행마다 최대 r 전이까지, B는 최대 r개 실행에 한 전이씩 예약한다. 라운드 1–4의 누적 상한을 구하라.

  1. A의 각 라운드 상한은 차례로 1, 4, 9, 16번의 대상 전이여서 합은 30번이다.

  2. B의 각 라운드 상한은 차례로 1, 2, 3, 4번의 대상 전이여서 합은 10번이다.

  3. 일찍 정지한 실행은 덜 모의하므로 이 수치는 실제 사용량이 아닌 예약 상한이다. 초기화·저장·출력 오버헤드도 제외한다.

동일 네 라운드의 대상 전이 예약 상한은 A가 30, B가 10이다. 실제 실행 속도나 전체 시간의 측정은 아니다.

비교할 점

출력 라운드가 이르다는 것과 같은 라운드까지 예약한 전이 수가 작다는 것은 다른 비교다.

종이와 본문으로 직접 해보기

별도 인식기의 입력 목록은 ε,a,aa,aaa,…다. ε는 무한 실행, a는2단계 수락, aa는1단계 수락, aaa는3단계 수락이라고 주어진다. 앞서 정의한 라운드1~4에서 새로 출력할 문자열을 구하라.

힌트 보기

길이 순서의 목록 위치도 충분히 포함돼야 한다. 같은 문자열은 한 번만 출력한다.

풀이 보기

라운드1은 ε만1단계 보므로 출력 없다. 라운드2는 ε,a를2단계씩 보아 a 출력. 라운드3은 aa도 포함되어 aa 출력. aaa는 목록4번째여서 라운드4에 처음 포함되고3단계 수락을 확인하므로 aaa 출력한다. ε 때문에 전체가 막히지 않는다.

오해와 반례

어떤 인식기가 멈추지 않으면 그 언어는 결정 불가능하다.

R은 aaa에서 멈추지 않지만 D가 같은 언어를 결정한다. 또 ε의 무한 실행을 순차적으로 기다리면 뒤의 수락 문자열이 출력되지 않는 문제는 열거 방법의 문제다.

  2. i번째 입력의 수락 전이가 양의 k이면 라운드 i+k−1까지 진행된다. 초기 수락이면 라운드 i에 출력된다. 각 라운드의 실행 수와 작업 수가 유한하고 다른 실행의 종료를 기다리지 않는다.

네 단계 뒤 수락하는 기계를 세 단계만 보고 거부해도 될까?

새 유한 코드 카탈로그를 사용한다. 코드 0의 A는 모든 이진 입력에서 정확히 네 번째 대상 전이에 수락하고 코드 1의 R은 두 번째 전이에 정지 거부한다. 코드 10의 C는 모든 입력에서 계속 실행한다. 그 밖의 코드는 카탈로그 형식 오류다. 이는 실제 표준 튜링기계 전이 코드가 아니라 수락 시점을 명시한 고수준 교육 모형이다.

쌍 부호 E(c,w)=1^{|c|}0cw를 쓰고 처음 0 앞의 1 개수로 코드 길이를 복원한다. 길이만 맞아도 코드가 카탈로그에 없으면 거부한다. 예를 들어 110111은 코드 11과 입력 1로 유일하게 해독되지만 코드 11은 유효한 기계 설명이 아니다. 유일 해독과 설명 유효성은 다른 검사다.

별도 판정기 B_T는 음이 아닌 정수 T가 주어진 유한 예산 문제를 다룬다. 먼저 형식을 검사하고 대상 기계의 초기 상태를 확인한 뒤 최대 T번 전이를 모의한다. 매 전이 직후의 상태까지 확인하여 그 안에 수락하면 수락한다. 정지 거부하거나 예산 안 수락이 없으면 거부한다. 초기 수락 상태인 일반 대상도 허용한다면 T=0에서 이미 수락할 수 있다. 카탈로그 A/R/C는 초기 비정지 상태다.

B_T는 모든 유한 입력에서 정지하지만 그 언어는 T 전이 안 수락하는 쌍이다. 대상이 예산 뒤 수락할지 묻는 원래 무제한 문제와 다르다. 예산 초과를 영원한 무수락으로 해석하지 않는다. 보편 시뮬레이션도 대상의 결과를 보존하는 것이며 미래 전체를 한 번에 판정하는 것이 아니다. 완전한 결정적 구성의 반복을 확인한 특수 경우에는 계속 반복됨을 증명할 수 있지만 헤드 위치나 테이프만의 반복은 그 증거가 아니다.

설명을 데이터로 다루기

유한 상태와 전이 규칙을 유한 문자열로 기록하면 기계 설명을 데이터로 읽을 수 있다. 보편기계는 기계 설명과 입력을 받아 그 기계의 계산을 단계별로 시뮬레이션한다. 설명을 읽는 기계의 상태 집합이 시뮬레이션 대상마다 새로 바뀌는 것은 아니다.

표현에는 상태·기호·전이의 경계와 형식 검사 규칙이 필요하다. 표의 글자들이 있다고 모두 올바른 기계 설명은 아니다. 아래는 실제 표준 부호화가 아니라 기계 코드 문자열과 입력 문자열을 구분하는 작은 자체 형식이다.

단순 연결 대신 경계 보존

두 문자열을 그냥 연결하면 code=10/input=011과 code=100/input=11을 구별하기 어렵다. 이 절은 code의 비트 길이 n을 먼저 단항 1ⁿ0으로 쓰고 code와 입력을 잇는다. 첫0으로 길이를 읽은 다음 n비트를 기계 코드로 떼고 나머지를 입력으로 해석한다.

외부에는 이미 기계 코드의 유효성을 판단할 수 있는 규칙이 주어졌다고 가정한다. 길이 접두부가 없거나 선언 길이만큼 코드 비트가 남아 있지 않으면 형식 오류로 거부한다. 실제 계산 모델의 특정 전이표를 이 짧은 숫자 코드에 숨겨 구현했다고 주장하지 않는다.

보편 시뮬레이션은 미래 예측이 아니다

시뮬레이터는 대상이 수락하면 수락, 정지 거부하면 거부, 끝없이 실행하면 계속 실행하도록 만들 수 있다. 따라서 기계가 주어진 입력을 수락하는 쌍의 언어를 인식할 수 있다. 영원히 실행하는 경우를 즉시 알아내 거부한다는 단계는 여기서 허용하지 않는다.

유한 시간 제한을 넣어 시험하는 기계는 별도의 유한 단계 문제를 결정할 수 있다. 그러나 제한을 넘겼다는 이유로 영원히 수락하지 않는다고 결론내리면 원래 수락 문제와 다른 언어를 판단하게 된다. 보편기계라는 이름이 모든 질문에 유한 시간 답한다는 뜻은 아니다.

유한 도달성의 증거와 두 인식기의 공정 실행을 어떻게 연결할까?

새 DFA M은 전체 문자열 길이가 짝수일 때 수락한다. 상태 m₀,m₁이고 시작·수락 상태는 m₀이며 0과 1을 읽을 때 모두 상태를 뒤집는다. 새 DFA N은 0의 개수가 짝수일 때 수락한다. 상태 n₀,n₁이고 시작·수락은 n₀이며 0에서 뒤집고 1에서 유지한다. 둘의 상태 수가 같아도 언어는 다를 수 있다.

동치 검사는 쌍 (mᵢ,nⱼ)의 동시 전이를 만든 뒤 한쪽만 수락하는 쌍에 도달하는지 확인한다. 시작 쌍 (m₀,n₀)는 둘 다 수락하므로 빈 문자열은 차이의 증인이 아니다. 입력 1의 쌍 (m₁,n₀)는 M 거부/N 수락이어서 짧은 반례다. 전체 쌍은 네 개라 이미 방문한 쌍을 다시 확장하지 않는 유한 탐색이 끝난다.

이는 같은 입력을 두 기계에 공급해야 하는 동기 곱이다. M과 N의 각자 도달 상태를 따로 모아 임의로 짝짓는 것만으로 반례 문자열을 보증하지는 못한다. 각 도달 쌍에는 그 쌍을 만든 같은 입력의 증인을 함께 저장한다. 일반 TM의 상태 이름 쌍만 저장하면 서로 다른 테이프·헤드 구성을 잃으므로 이 유한 DFA 증명을 그대로 옮길 수 없다.

한편 L과 여집합의 올바른 인식기가 주어진 경우에는 같은 입력에서 한 전이씩 공정하게 진행한다. L 쪽 수락은 전체 수락, 여집합 쪽 수락은 전체 거부다. 입력은 정확히 한쪽에 속하므로 그쪽 수락이 언젠가 나온다. 두 임의 인식기가 있다는 사실만으로 이 정지 논증이 성립하지는 않는다. 두 언어가 전체 영역을 덮는지와 겹치지 않는지가 핵심 전제다. 일반 인식기의 초기 구성도 검사하여 이미 수락한 쪽이 있으면 바로 해당 답을 반환한다. 비정지 실행만 전이를 받으며 정지 거부한 실행은 건너뛴다.

같은 언어를 다른 기계로 표현하기

언어의 성질은 어떤 기계가 그것을 나타내든 수락 집합으로 결정된다. 언어가 비었는지, 특정 문자열이 있는지는 언어를 묻는다. 반면 설명에 상태가 몇 개인지, 특정 이름의 상태가 있는지는 기계 기술을 묻는다.

사용되지 않는 상태를 추가하면 기계의 기술이 바뀌어도 수락 언어는 그대로일 수 있다. 반대로 전이 하나를 바꾸면 같은 상태 수에서도 언어가 달라질 수 있다. 그러므로 상태 수만 보고 두 기계의 언어가 같다고 결론내리지 않는다.

유한 상태에서는 도달성으로 공집합 검사

DFA에서는 시작 상태에서 전이를 따라 도달할 수 있는 수락 상태가 있는지 유한 탐색으로 확인한다. 있으면 어떤 입력이 수락되므로 언어는 비어 있지 않다. 없으면 언어가 비었다. 모든 상태가 수락이 아니어도 일부 수락 상태에 도달하면 비공집합이다.

입력 길이는 무한히 많지만 상태는 유한해서 이미 표시한 상태를 반복 탐색할 필요가 없다. 이 절은 전이함수가 모든 상태·기호에 정의된 DFA를 다룬다. 같은 방법이 일반 튜링기계의 무한한 테이프 구성에도 유한 상태 이름만으로 적용된다고 생각하면 안 된다.

언어와 여집합의 두 인식기가 있다면

L의 인식기와 여집합의 인식기가 둘 다 있다면 같은 입력에서 둘을 한 단계씩 번갈아 진행한다. L 쪽이 수락하면 결정기는 수락, 여집합 쪽이 수락하면 결정기는 거부한다. 입력은 둘 중 정확히 한 언어에 속하므로 그쪽 인식기가 언젠가 수락하고 결정도 끝난다.

첫 인식기가 끝날 때까지 기다렸다가 두번째를 실행하는 것은 공정한 진행이 아니다. 밖 입력에서 첫 기계가 무한 실행할 수 있다. 또한 거부와수락을 단순히 뒤집어 여집합 인식기를 얻는 방법도 무한 실행을 해결하지 못한다.

쌍 ij는 mᵢ와 nⱼ를 줄여 쓴 표기다. 전이 열의 같은 문자 하나를 양쪽에 모두 공급한다. 아래 단계 수는 대상 인식기 전이 배분만 센 값이며 실제 시뮬레이터 비용은 제외한다.

중간 과정을 따라가는 예제

알파벳 {0,1}의 DFA는 상태 p/q/r/u, 시작 p, 수락 {r}다. p는 0→q/1→p, q는 0→q/1→r, r은 두 기호 모두 r, u는 두 기호 모두 u로 간다. 도달 상태를 구해 공집합인지 판정하라. u를 지운 기계와 상태 수·언어를 비교하라.

  1. 처음{p}를 표시한다. p의 전이로q를 추가해{p,q}다.

  2. q에서1을 읽으면r이 추가돼{p,q,r}다. r의 두 전이는r이고 더 새 상태는 없다. u는 도달하지 않는다.

  3. 수락r이 도달하며 문자열01로 실제p→q→r이다. 언어는비공집합이다.

  4. 도달불가u를지우면상태수4→3이지만 시작에서 가능한 계산은 같아서언어는같다.

도달 집합은 {p,q,r}이고 언어는 비공집합이다. u를 제거하면 기계 상태 수는 달라지지만 수락 언어는 같다.

조건을 바꾸어 비교하기

반례 문자열을 쌍과 함께 보존한다

M/N이 같은 언어인지 쌍 탐색으로 판정하고 ε,0,1,01의 결과를 비교하라.

  1. ε의 쌍 00에서는 둘 다 수락한다. 0의 쌍 11에서는 둘 다 거부한다.

  2. 1의 쌍 10은 M 거부/N 수락이라 언어 차이의 증인이다. 01의 쌍 01은 M 수락/N 거부다.

  3. 시작부터 0과 1을 확장하면 쌍 11과 10을 발견하므로 이 단계에서 이미 반례 1을 얻는다. 빈 문자열에 차이가 없으므로 길이 1은 최단이다.

두 언어는 다르며 최단 반례 중 하나는 1이다. 쌍 01의 반례 01은 더 길다.

비교할 점

상태 수 2라는 외형이나 모든 개별 상태 도달만으로 언어 동치를 판정하지 않는다.

정지 거부만으로도 답할 수 있는가?

같은 입력 w에서 L 인식기는 첫 전이에 거부하고 여집합 인식기는 두 번째 전이에 수락한다. L 먼저 한 전이, 여집합 한 전이 순서로 진행할 때 전체 결정 시점을 구하라. 정지 실행은 이후 건너뛴다.

  1. 라운드 1에서 L의 정지 거부를 확인한다. 보편 구성은 이 사건만으로 전체 거부를 반환하지 않고 여집합 수락을 기다린다.

  2. 여집합은 라운드 1과 2에 자신의 두 전이를 받는다. L은 이미 정지했으므로 라운드 2에서는 건너뛴다.

  3. 여집합의 수락에 따라 라운드 2에서 전체 거부한다. 실제 배분 전이는 L 한 번과 여집합 두 번으로 총 3번이다.

라운드 2·총 3번의 대상 전이 배분에서 거부한다. 두 실행이 계속 비정지인 표의 4번 상한과 다르다.

비교할 점

거부가 발생한 실행을 계속 전이시킨다고 가정하거나 라운드 수를 실제 배분 수 두 배로 무조건 바꾸지 않는다.

다른 문제에 적용하기

출력 순서·유한 예산·언어 증거의 보고서를 감사한다

첫째 모형의 시간 배분 규칙만 유지하고 인식기를 바꾼 별도 사례다. 여기서는 목록 네 번째 입력 w가 자신의 두 번째 전이에 수락한다고 새로 주어진다. 원래 R의 길이 3 이상 무한 실행 조건을 이 사례에 적용하지 않는다. A와 B의 최초 발견 라운드를 비교하라. 둘째 모형에서 부호 100을 B₃와 B₄에 주고 대상 A의 원래 수락 여부까지 구별하라. 마지막으로 두 DFA M/N에 10을 주어 쌍을 추적하고 차이의 증인을 쓰라. 별도 입력 z에서는 올바른 L 인식기가 계속 실행하고 여집합 인식기가 자신의 세 번째 전이에 수락한다. L 먼저 한 단계씩 진행할 때 결정 라운드와 총 대상 전이 배분 수를 구하라.

힌트 1

구성 유지 방식 B는 입력이 목록에 들어온 라운드에 첫 전이를 받는다. 예산 판정과 대상의 원래 결과는 별도로 적는다.

힌트 2

M은 모든 문자에서, N은 0에서만 뒤집는다. 두 인식기의 상보 계약에서는 수락한 쪽이 전체 답을 정한다.

풀이와 답 확인

  1. w의 목록 위치는 4, 수락 전이는 2다. A는 max(4,2)=4라 라운드 4에, B는 4+2−1=5라 라운드 5에 발견한다.

  2. 100은 코드 0과 빈 입력이다. B₃는 예산 안 수락이 없어 거부하고 B₄는 네 번째 전이 수락을 보아 수락한다. 대상 A는 원래 네 전이 뒤 수락한다.

  3. 10의 쌍은 00→10→01이다. M은 길이 2로 수락하고 N은 0의 홀수 개수로 거부하므로 10은 언어 차이의 증인이다.

  4. z에서는 매 라운드 L과 여집합이 각 한 전이씩 진행한다. 라운드 3의 둘째 배분에서 여집합이 수락하므로 전체 거부하며 대상 전이 배분은 3+3=6번이다.

w의 발견은 A에서 라운드 4, B에서 라운드 5다. B₃의 거부는 대상 A의 영원한 무수락을 뜻하지 않으며 B₄는 수락한다. 입력 10은 M/N의 불일치 증인이다. 상보 인식기의 z 판정은 라운드 3에서 거부이며 대상 전이 배분은 총 6번이다.
