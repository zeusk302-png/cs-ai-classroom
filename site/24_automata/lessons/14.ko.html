소단원 14.1

공간 복잡도 입문

많은 경우를 오래 검사해도 모든 경우를 동시에 저장해야 할까?

준비 개념과 학습 목표

준비 개념

  • 튜링 기계

  • 최악 시간 복잡도

  • 이진수

학습 목표

  • 최대 동시 저장 공간과 누적 실행 시간을 구별한다.

  • 입력 공간과 보조 공간의 규약을 명시한다.

  • 순차 열거에서 공간 재사용을 설명한다.

시간은 누적되고 공간은 재사용된다

시간 복잡도는 입력 길이에 따른 실행 단계 수를 다룬다. 공간 복잡도는 계산 중 필요한 최대 저장 규모를 다룬다. 하나의 저장 칸을 천 번 덮어쓴다고 동시에 천 칸을 사용한 것은 아니다. 길이가 같은 모든 입력의 최악 경우를 기준으로 상한을 설명한다.

무엇을 공간으로 세는지는 모델에 따라 명시한다. MIT 슬라이드는 입력이 놓인 테이프까지 포함한 도달 칸 수를 설명한다. 프로그램 분석에서 읽기 전용 입력을 제외한 보조 공간을 따로 셀 수도 있다. 입력 포함 O(n)과 보조 O(log n)은 서로 다른 계산 규약일 수 있다.

괄호 하나의 종류는 개수로 검사한다

한 종류의 괄호 문자열을 왼쪽부터 읽어 여는 괄호면 개수를 1 늘리고 닫는 괄호면 1 줄인다. 음수가 되면 즉시 거절하고 끝에서 0이면 받아들인다. 저장하는 개수는 최악에 0부터 n까지다.

이진 개수에는 ⌈log₂(n+1)⌉비트가 필요하다. 고정 크기 제어 정보와 필요한 위치 정보도 포함하여 보조 공간을 O(log(n+1))로 설명한다. 입력을 같은 테이프에 저장하는 모델이면 그 입력 n칸도 포함한다. 여러 괄호 종류의 올바른 중첩을 단순 개수 하나로 검사할 수는 없다.

완전 탐색도 공간을 아껴 순서대로 한다

변수 k개의 모든 진리값 배정은 2ᵏ개다. 배정 하나를 k비트로 저장하고 식을 평가한 뒤 다음 배정으로 덮어쓸 수 있다. 전체 배정을 동시에 저장하지 않아도 된다.

식의 길이와 평가 저장 공간까지 포함해 분석해야 한다. 다항 공간이 다항 시간을 자동 뜻하지는 않는다. PSPACE는 다항 공간으로 결정하는 언어들의 집합이다. 결정 계산의 종료와 공간 제한을 함께 요구하며, 실행 중 발견한 작은 사례가 전체 입력의 복잡도 증명은 아니다.

중간 과정을 따라가는 예제

길이 8의 문자열 (()(()))를 개수 방식으로 검사하라. 이 문자열에서 최대 개수와 길이 8의 임의 입력을 위한 개수 비트 폭을 구하라.

  1. 문자마다 갱신한 개수는 1,2,1,2,3,2,1,0이다. 음수가 없고 끝이 0이라 받아들인다.

  2. 이번 입력의 최대 개수는 3이다. 그러나 길이 8의 입력 ((((((((에서는 개수가 8까지 올라간다.

  3. 0부터 8까지 9개 값을 표현해야 하므로 ⌈log₂9⌉=4비트다. 이번 입력만 보고 항상 2비트면 충분하다고 정하면 안 된다.

이번 입력은 올바르고 최대 개수 3이다. 길이 8 전체 입력을 처리할 카운터는 4비트가 필요하다.

종이와 본문으로 직접 해보기

변수 4개의 진리값을 전부 보관하는 비트 수와 배정 하나씩 순차 검사할 때 배정 저장 비트 수를 비교하라. 식 평가 공간은 별도라고 가정한다.

힌트 보기

배정은 16개이고 각 배정은 4비트다.

풀이 보기

전부 저장하면 16×4=64비트다. 순차 배정 자체는 4비트를 재사용한다. 실제 총 공간에는 식·평가 상태·종료 처리가 추가되며 시간은 여전히 여러 배정을 검사한다.

오해와 반례

작은 공간을 쓰면 항상 빨리 끝난다.

공간을 재사용하면서 매우 많은 경우를 순차 검사할 수 있다. 배정 2ᵏ개를 검사하는 예는 저장 공간과 누적 시간이 다른 이유를 보여 준다.

소단원 14.2

무작위 계산의 개요

정답일 가능성이 높다는 말과 정답 경로가 하나 있다는 말은 같을까?

준비 개념과 학습 목표

준비 개념

  • 확률과 독립성

  • 비결정성

  • 다수결

학습 목표

  • 무작위 경로와 비결정적 존재를 구별한다.

  • 독립 반복의 오류 확률을 계산한다.

  • 정확성 확률과 실행 시간의 조건을 명시한다.

동전을 던지는 계산에는 확률이 있다

확률적 계산은 무작위 비트에 따라 경로를 선택한다. 독립인 공정한 동전 k번의 특정 결과열은 확률 2⁻ᵏ다. 여러 수락 경로의 확률을 합하여 입력 하나의 수락 확률을 구한다.

비결정적 계산의 수락은 수락 경로가 존재한다는 조건이다. 경로가 존재해도 그 경로를 무작위로 고를 확률은 매우 작을 수 있다. 변수 n개의 정답 배정이 하나뿐이면 공정한 무작위 배정이 그것을 고를 확률은 2⁻ⁿ이다. 이를 높은 확률의 효율적 해결과 동일시하지 않는다.

오류 조건은 각 입력에 적용한다

양쪽 오류의 확률적 결정 알고리즘은 예 입력에서 수락 확률이 높고 아니오 입력에서 거절 확률이 높아야 한다. 흔히 오류 상한 1/3처럼 1/2보다 작은 고정 상수를 사용한다. 전체 자료의 평균 정확도만 높다는 조건과 다르다.

BPP에서는 다항 시간과 각 입력의 제한된 오류 확률을 요구한다. 아래 정답 확률 3/4 사례는 반복 계산을 설명하는 가상 가정이다. 임의 문제의 실제 알고리즘을 구성한 것이 아니다. 항상 정답이지만 실행 시간이 무작위인 방식과 오류를 허용하는 방식도 구별한다.

독립 반복은 같은 오류를 복사하는 일이 아니다

각 실행의 정답 확률이 3/4이고 결과들이 독립이라고 가정하자. 세 번의 다수결은 틀린 실행이 두 번 이상일 때 실패한다. 실패 확률은 3×(1/4)²×(3/4)+(1/4)³=5/32다.

동일한 난수 결과를 그대로 재사용해 세 출력이 항상 같다면 다수결 오류는 1/4에서 줄지 않는다. 반복 증폭에는 독립성과 실행당 오류 상한 같은 조건이 필요하다. 반복 횟수를 늘려도 오류를 정확히 0으로 만든다고 주장하지 않는다.

중간 과정을 따라가는 예제

입력 하나에서 독립 실행 각각의 정답 확률이 3/4다. 세 번 다수결의 정답·오류 확률을 구하라.

  1. 정확히 두 번 틀릴 확률은 위치 3가지에 (1/4)²(3/4)를 곱하여 9/64다.

  2. 세 번 모두 틀릴 확률은 (1/4)³=1/64다. 다수결 오류는 합 10/64=5/32다.

  3. 다수결 정답 확률은 1−5/32=27/32이며 한 번의 3/4보다 높다.

독립 가정 아래 정답 27/32, 오류 5/32다. 실제 모델 실행으로 측정한 정확도가 아니다.

종이와 본문으로 직접 해보기

첫 실행의 난수와 출력을 복사해 세 표를 동일하게 만들면 오류 확률은 무엇인가? 정답 배정이 하나인 변수 4개 식에서 임의 배정의 성공 확률도 구하라.

힌트 보기

복사한 표는 독립 시행이 아니다. 4비트 배정은 16개다.

풀이 보기

복사 다수결의 오류는 여전히 1/4다. 정답 배정 하나를 고를 확률은 1/16이다. 정답 경로 존재만으로 3/4 같은 성공 보장은 생기지 않는다.

오해와 반례

NP는 정답 경로가 있으니 무작위로 골라도 높은 확률로 정답이다.

존재와 확률 크기는 다르다. 가능한 배정 중 정답 하나라면 무작위 성공 확률은 입력 크기에 따라 매우 작아질 수 있다.

소단원 14.3

언어 분류·환원·한계 분석

한 문제를 다른 문제로 바꿀 때 어느 방향이 한계를 전달할까?

준비 개념과 학습 목표

준비 개념

  • 정규/문맥자유 언어

  • 결정과 인식

  • 함수와 동치

학습 목표

  • 계산 모형과 자원 분류를 구별한다.

  • 환원의 종료·양방향 동치를 확인한다.

  • 결정불가능성과 느린 알고리즘을 구별한다.

무엇을 묻는 분류인지 구별한다

정규·문맥자유 분류는 어떤 언어를 특정 문법이나 자동자로 표현할 수 있는지 다룬다. 결정가능은 모든 입력에서 종료하여 예/아니오를 맞힐 수 있는지 다룬다. 인식가능은 예 입력의 수락을 보장하지만 아니오 입력에서 영원히 실행할 수 있다.

P·NP·PSPACE 같은 분류는 결정가능한 문제의 자원과 계산 조건을 더 구별한다. 빠르지 않음과 결정불가능은 다르다. 2ⁿ개 경우를 전부 검사해 종료하는 알고리즘은 느릴 수 있지만 그 자체로 결정가능성을 보여 준다.

변환은 모든 입력에서 끝나야 한다

A≤mB라는 계산가능 many-one 환원은 모든 입력에서 종료하는 f를 만들고 x∈A와 f(x)∈B가 동치임을 요구한다. B의 판정기 뒤에 변환 f를 붙이면 A의 판정기를 만들 수 있다.

따라서 A가 결정불가능하고 A≤mB라면 B도 결정불가능하다. A가 쉽고 A≤mB라는 사실만으로 B가 쉽다고 결론 내릴 수 없다. 다항 시간의 어려움을 전달하려면 변환도 다항 시간이라는 추가 자원 조건을 확인해야 한다.

수락과 단순 종료를 혼동하지 않는다

ATM은 기계 M이 입력 w를 수락하는지를 묻고 HALTTM은 M이 w에서 종료하는지를 묻는다. M이 거절하고 종료하는 경우 때문에 쌍을 그대로 옮기면 두 조건이 동치가 아니다.

새 기계 N은 자기 입력을 무시하고 고정된 M(w)를 실행한다. M이 수락하면 N은 종료하고, M이 거절하면 N은 계속 반복한다. M이 계속 실행하면 N도 계속 실행한다. N의 설명을 만드는 변환은 M(w)의 완료를 기다리지 않고 코드만 생성하여 끝난다. 잘못된 인코딩은 알려진 무한 반복 기계의 쌍으로 보내 아니오를 보존한다.

중간 과정을 따라가는 예제

ATM의 쌍 (M,w)를 HALTTM의 쌍 (N,빈 입력)으로 바꾼다. M(w)의 수락·거절 종료·무한 실행 세 경우에서 N의 종료 여부를 확인하라.

  1. M이 수락하면 N도 종료한다. 원문제 예와 대상 문제 예가 일치한다.

  2. M이 거절하고 종료하면 N은 그 뒤 무한 반복한다. 원문제 아니오와 대상 문제 아니오가 일치한다.

  3. M이 무한 실행하면 N은 기다리며 무한 실행한다. 잘못된 원인코딩도 무한 반복 기계로 보내 아니오를 보존한다.

  4. 변환은 M의 코드를 실행해 결과를 결정하지 않고 감싼 N의 설명을 만드는 유한 작업이다. 따라서 환원 자체는 모든 입력에서 끝난다.

수락하는 경우에만 N이 종료하므로 ATM≤mHALTTM이다. ATM의 결정불가능성이 이 방향으로 HALTTM에 전달된다.

오해와 반례

환원 화살표는 양쪽 문제의 난도가 같다는 뜻이다.

한 방향은 변환을 통해 대상 해법으로 원문제를 푸는 관계다. 반대 방향은 별도로 증명해야 하며 자원 제한 없는 계산가능 환원과 다항 시간 환원을 혼동하지 않는다.

한 단계 더

정규 언어의 간단한 DFA, 괄호 언어의 중첩 구조, ATM의 인식과 결정 한계를 세 질문으로 비교하라. 유한 입력에서 프로그램이 잘 동작한 관찰을 모든 입력의 종료·자원 상한 증명으로 대체하지 않는다. 보완언어까지 인식가능한 경우 결정가능성을 얻는 조건도 원문과 연결해 설명하라.
