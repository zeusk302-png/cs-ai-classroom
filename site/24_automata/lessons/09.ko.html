소단원 9.1

테이프·상태·계산

읽은 글자를 다시 고치고 뒤로 돌아갈 수 있으면 무엇이 달라질까?

준비 개념과 학습 목표

준비 개념

  • 상태는 현재 행동 규칙을 선택하는 유한한 기억이다.

  • 입력 문자열은 유한 길이이며 빈 문자열도 입력이다.

학습 목표

  • 상태·테이프 내용·헤드 위치로 한 계산 상태를 표현한다.

  • 정지 수락·정지 거부·무한 실행과 판정기를 구별한다.

같은 테이프라도 다음 행동이 다르면 무엇을 빠뜨린 걸까?

새 자체 기계 B는 이진 입력의 각 비트를 뒤집고 시작 칸으로 돌아가 수락한다. 칸 0은 왼쪽 표지 ▷이고 칸 1부터 입력, 뒤는 □다. 초기 구성은 상태 flip와 헤드 1이다. flip에서 0은 1을 쓰고 R로 flip, 1은 0을 쓰고 R로 flip, □는 그대로 쓰고 L로 back이다. back에서 0 또는 1은 그대로 쓰고 L로 back, ▷는 그대로 쓰고 R로 accept한다. 이 밖의 비정지 상태·기호 조합은 읽은 기호를 유지하고 R로 reject한다. accept와 reject에서는 더 전이하지 않는다.

전이의 읽기·쓰기는 이동 전 칸에서 일어난다. 입력 01의 첫 전이는 칸 1을 1로 고친 뒤 칸 2로 간다. 칸 2의 기존 1까지 동시에 뒤집은 것이 아니다. 테이프 ▷10□…가 같아도 flip·헤드 2는 0을 1로 고치지만 back·헤드 2는 0을 유지하고 왼쪽으로 간다. 따라서 상태와 헤드 위치를 테이프와 함께 보존한다.

이진 입력 길이가 n이면 비트 뒤집기를 n번, 빈칸에서 방향 전환을 한 번, 왼쪽 복귀를 n번, 표지에서 수락을 한 번 실행해 총 전이 수는 2n+2다. 빈 입력도 방향 전환과 수락이 필요해 전이 수는 2다. 이는 아래 자체 기계의 정확한 전이 수이며 다른 기계나 실제 프로그램의 실행 시간으로 일반화하지 않는다.

정지하지 않음을 규칙으로 증명하는 방법도 구별한다. 별도 C는 q에서 □를 유지하고 R로 r, r에서 □를 유지하고 L로 q이며 빈 입력 칸 1에서 시작한다. 두 전이 뒤 상태 q·헤드 1·전체 테이프가 처음과 같아 결정적 반복을 증명한다. 또 다른 D가 □에서도 계속 R로 q를 유지하면 헤드가 매번 달라 완전한 구성은 반복되지 않지만 정지 상태가 없어 역시 계속 실행한다. 구성 반복은 충분한 증거이지 모든 무한 실행의 필요조건이 아니다.

먼저 확인할 개념
  • 테이프·상태·헤드의 기본 구성

    같은 테이프만으로 전이를 결정할 수 없다는 기본 계약을 비트 뒤집기에 적용한다.

  • 구성 부호화에서의 헤드 표시

    내용과 위치를 함께 보존해야 하는 이유를 단일 기계의 상태 표에서 먼저 확인한다.

유한 제어와 늘릴 수 있는 기록

튜링기계는 유한한 상태 집합, 유한한 테이프 기호 집합, 읽고 쓰는 헤드와 전이 규칙을 가진 수학 모형이다. 테이프 기호는 입력 기호와 빈칸 □, 보조 표시를 포함한다. 한 전이는 상태와 읽은 기호를 보고 기호를 쓰고 헤드를 한 칸 이동하고 새 상태로 바꾼다.

여기서는 왼쪽 끝 표지 ▷가 있는 오른쪽 무한 테이프를 사용한다. 입력은 표지 다음 칸부터 놓고 그 뒤는 빈칸이다. 무한 테이프는 시작부터 무한한 내용을 읽었다는 뜻이 아니다. 유한 시간에는 유한한 칸만 방문하며 필요에 따라 더 멀리 이동할 수 있다는 이상화다.

계산의 스냅샷

한 순간의 구성은 상태, 테이프 내용, 헤드 위치를 함께 기록한다. 테이프만 같아도 헤드나 상태가 다르면 다음 행동이 달라질 수 있다. 전이 순서는 현재 칸을 읽기→같은 칸에 쓰기→이동하기로 약속한다.

아래 자체 기계는 1만 있는 입력을 오른쪽으로 훑고 빈칸에 1을 하나 더 쓴 뒤 왼쪽 끝으로 돌아간다. scan에서 1을 읽으면 1을 쓰고 R, 빈칸이면 1을 쓰고 L로 back에 들어간다. scan에서 0이면 0을 쓰고 R로 reject한다. back에서 1은 그대로 쓰고 L, ▷는 그대로 쓰고 R로 accept한다. 예제 경로 밖의 비정지 상태·기호 조합은 해당 기호를 유지하고 R로 reject하도록 정한다.

언어 수락과 함수 출력

accept와 reject는 정지 상태다. 일반 튜링기계는 정지 상태에 도달하지 않고 영원히 움직일 수도 있다. 언어를 인식하는 기계는 그 언어의 입력을 수락하지만 언어 밖에서는 정지 거부 또는 무한 실행이 가능하다. 판정기는 모든 입력에서 반드시 정지해 예/아니오를 준다.

이 예제는 입력 알파벳 {0,1}에서 1만 있는 문자열인지 판정하며 수락 시 테이프에 1을 하나 추가하는 작업도 한다. 입력에 0이 있으면 첫 0에서 거부하므로 모든 유한 입력에서 정지한다. 한 입력이 빨리 끝났다는 관찰만으로 다른 기계도 판정기라고 결론 내리면 안 된다.

중간 과정을 따라가는 예제

입력 11의 테이프 칸은 0=▷,1=1,2=1,3=□이다. 시작 상태 scan, 헤드 1이다. 위 규칙으로 수락까지의 전이와 최종 비빈 부분을 추적하라.

  1. 1회: 칸1의 1을 유지하고 scan·헤드2다. 2회: 칸2의 1을 유지하고 scan·헤드3다.

  2. 3회: 칸3의 □를 1로 바꾸고 back·헤드2다. 이제 테이프는 ▷111□…이다.

  3. 4회: back·헤드1, 5회: back·헤드0이다. 쓰는 1은 그대로다.

  4. 6회: ▷를 유지하고 accept·헤드1로 이동하며 정지한다.

6전이 후 ▷111□…이며 수락했다. 입력 길이 n의 1만 있는 입력은 n회 스캔+1회 추가+n회 복귀+1회 수락=2n+2전이다. 총 전이 수를 센다.

연습 3 · 직접 만들어 보기

빈 입력에 대한 작업 준비를 마쳐 칸 1에 보조 기호 X를 한 개 놓고 칸 2 이후는 □인 초기 구성에서 시작한다. 상태 이름은 q 하나만 사용해 헤드가 칸 1과 칸 2를 번갈아 방문하고 두 전이 뒤 전체 구성이 복구되는 결정적 규칙을 구성하라. 준비 단계는 이번 두 전이의 횟수에 포함하지 않는다.

힌트 1

내용도 두 단계 뒤 복구해야 한다.

힌트 2

칸 1과 칸 2의 읽은 기호를 서로 다르게 만들 수 있다.

풀이와 답 확인

  1. 먼저 초기 구성의 칸 1을 X, 칸 2 이후를 □로 정한 별도 작업 테이프 구성을 사용한다. δ(q,X)=(q,X,R), δ(q,□)=(q,□,L)로 정한다.

  2. q·헤드 1에서 X를 읽어 헤드 2, 그곳의 □를 읽어 헤드 1로 돌아온다. 두 단계 뒤 전체 구성은 초기와 같다.

초기 작업 표시 X가 있다는 명시적 계약에서 q 하나로 두 단계 반복을 구성했다. 빈 입력을 그대로 시작할 경우에는 X 초기화 단계가 별도로 필요하다.

흔한 오답에서 다시 생각하기

동일 상태 q와 동일 기호 □에서 R/L을 번갈아 지정한다.

두 테이프를 한 줄로 옮기면서 새로 쓴 값을 다시 읽어도 될까?

새 두 테이프 기계 M의 한 전이는 두 현재 기호를 먼저 함께 읽고 규칙 하나를 선택한다. 테이프 1의 칸 2가 1, 테이프 2의 칸 2가 0일 때 상태 q의 규칙은 δ(q,1,0)=(p,0,1,R,L)이다. 두 기존 칸에 각각 0과 1을 쓰고 헤드는 각각 칸 3과 칸 1로 옮긴다. 다른 읽기 쌍의 규칙을 나중에 선택하는 것이 아니다.

단일 테이프 부호화에서는 #로 구간을 나누고 각 구간의 한 기호에 점 표시를 붙인다. 예시 초기 부호는 #0·1□#1·0□#이고 상태 q를 유한 제어에 둔다. 첫 스캔에서 읽은 쌍 (1,0)을 저장하고 규칙을 확정한다. 갱신 뒤 부호는 #00·□#·11□#이며 상태 p다. 점 표시된 빈칸도 헤드가 놓인 실제 원래 칸이므로 삭제하지 않는다.

두 테이프 모형의 동시 읽기 계약을 순차 두 규칙 선택으로 바꾸면 오류가 난다. 첫 테이프를 0으로 고친 뒤 다시 쌍 (0,0)을 읽어 다른 규칙을 적용하면 원래 한 전이의 모의가 아니다. 올바른 구현도 물리적으로는 순차 스캔하지만 시작 시 읽은 쌍과 선택한 한 규칙을 고정해 두 구간을 갱신한다.

구간 끝의 점 표시가 R로 넘어가면 □를 추가하고 뒤 구간을 오른쪽으로 밀어 구분을 보존한다. 실제 공간을 고정 길이로 제한하지 않는다. 정지 보존을 위해 각 모의 전이는 유한 스캔과 유한 이동으로 끝나야 하며, 여러 단계를 훑기만 하고 원래 한 전이를 완수하지 않는 시뮬레이터는 동치 증거가 아니다. k는 기계 정의에서 고정된 유한 수라 읽은 k기호의 조합을 유한 제어에 저장할 수 있다.

한 상태와 여러 헤드

고정된 k개 테이프의 튜링기계는 각 테이프에 헤드를 두고 한 전이에서 k개의 현재 기호를 읽는다. 하나의 상태와 그 기호 목록에 따라 각 칸에 쓰고 각 헤드를 이동한다. 첫 테이프에는 입력, 나머지에는 처음에 빈칸을 놓는 모형을 생각한다.

k는 기계 정의에서 정해진 유한한 수다. 유한 기호 집합의 k개 조합을 전이표로 다룰 수 있다. 여러 헤드 동시 이동은 이 모형의 전이 단위이지 현실 컴퓨터의 스레드 실행을 측정한 결과가 아니다.

한 줄에 여러 테이프 넣기

단일 테이프에 각 테이프의 사용 구간을 구분자 #로 나누어 저장한다. 각 구간에서 원래 헤드가 놓인 기호는 점 표시한 기호로 바꾸고 원래 기계의 상태도 추적한다. 점 표시는 별도의 유한 테이프 기호이므로 헤드를 추가한 것이 아니다.

원래 한 전이를 흉내낼 때 각 구간을 훑어 표시된 기호들을 유한 제어에 모은 뒤, 다시 훑으며 규칙에 맞게 쓰고 표시를 옮긴다. 구간 끝 너머로 이동해야 하면 빈칸을 추가하고 뒤 구간을 밀어 공간을 확보한다. 모든 모의 전이 시점의 내용과 표시가 원래 구성을 정확히 표현한다는 불변식이 근거다.

이 시뮬레이션은 원래 수락과 거부를 같은 방식으로 정지하도록 보존한다. 각 원래 단계에 유한한 모의 단계가 필요하므로 원래 판정기는 변환 후에도 모든 입력에서 정지한다. 반대 방향은 단일 테이프 기계를 여러 테이프 중 하나만 사용하는 기계로 보면 된다.

서로 다른 계산 모형의 동치 증명과 알고리즘의 뜻을 정하는 논제는 같은 종류의 주장일까?

준비 개념과 학습 목표

준비 개념

  • 알고리즘은 유한하게 기술된 기계적인 절차다.

  • 인식과 모든 입력에서 정지하는 판정을 구별한다.

학습 목표

  • 형식 모형의 동치 정리와 논제를 구별한다.

  • 기계적 절차의 입력·정지·부호화 조건을 설명한다.

문자열로 저장했다고 원래 두 입력을 항상 복원할 수 있을까?

이진 문자열 두 개 x,y를 새 부호 E(x,y)=1^|x|0xy로 저장한다. 첫 0 이전의 1 개수를 ℓ로 세고, 0 뒤의 처음 ℓ문자를 x, 나머지를 y로 해독한다. x와 y에 0이 있어도 이미 헤더를 끝내는 첫 0을 찾았으므로 데이터의 0과 혼동하지 않는다. 헤더 뒤 문자가 ℓ개 미만이면 잘못된 부호로 정지 거부한다. 첫 0이 없으면 헤더 자체가 끝나지 않은 유한 부호이므로 역시 거부한다.

E(1,01)=10101, E(10,1)=110101로 단순 연결 101의 충돌을 없앤다. E(ε,01)=001, E(1,ε)=101이며 E(ε,ε)=0이다. 빈 문자열도 두 객체가 없다는 뜻이 아니다. 두 빈 문자열이라는 한 쌍을 명시적으로 복원한다. 부호화가 단사임은 해독의 첫 0·길이 ℓ·유일한 절단으로 두 구성 성분을 복원하는 데서 따른다.

효과적인 고수준 절차는 각 유한 부호를 검증하고 각 연산을 유한하게 구현할 수 있어야 한다. 새로운 검사 J는 E(x,y)를 해독하고 x,y가 정확히 같으면 수락한다. 유한 문자 비교가 끝나므로 잘못된 부호도 포함한 모든 유한 이진 입력에서 정지한다. 부호 검사 없이 유효한 입력에서만 정지했다고 모든 입력의 판정기라 말하지 않는다.

별도 자연수 짝수 검사에서는 이진 정수 n에 대해 k=0,1,2,…를 순서대로 시험하고 2k=n인 경우에만 수락하는 절차 A와, 0≤k≤n을 시험하고 실패하면 거부하는 절차 B를 비교한다. A는 n=3에서 끝나지 않지만 B는 네 후보 뒤 거부한다. n=4에서는 둘 다 k=2의 세 번째 후보에서 수락한다. 이는 알려진 유한 범위를 이용한 특수 문제의 판정기 구성이며 Church–Turing 논제를 증명하거나 모든 무한 탐색의 범위를 제공한 것이 아니다. 논제는 직관적 효과적 절차와 형식 계산 모형의 연결이지 속도 보증이 아니다.

직관적 절차와 형식 모형 연결

Church–Turing 논제는 기계적으로 효과적으로 계산할 수 있는 절차를 튜링기계 계산으로 표현할 수 있다는 연결이다. 튜링기계 쪽은 상태와 전이로 수학적으로 정의되지만 효과적인 절차라는 직관적 말 자체가 이미 하나의 형식 정의로 주어진 것은 아니다.

그래서 두 엄밀한 모형 사이의 동치처럼 같은 방식으로 증명하는 정리와 구별해 논제라고 부른다. 람다 계산이나 다른 충분한 계산 모형이 같은 계산 능력으로 귀결된다는 증명은 이 연결을 뒷받침한다. 여러 테이프가 한 테이프와 동치라는 앞 절 정리가 곧 논제 전체의 증명이라는 뜻은 아니다.

고수준 절차에도 조건이 있다

튜링기계를 기술할 때 모든 칸 전이를 쓰는 대신 유한 자료를 읽고 비교·덧셈·반복하는 고수준 절차를 쓰기도 한다. 그 연산들을 기호와 유한 단계로 구현할 수 있어야 한다. 어떤 답을 아는 초능력 상자를 한 줄에 넣으면 알고리즘 설명이 되지 않는다.

입력을 문자열로 부호화하는 규칙도 필요하다. 두 문자열 x,y를 구분자 없이 붙이면 경계를 잃을 수 있다. 구분자 #가 입력 알파벳에 없는 경우 x#y처럼 저장하면 두 문자열을 복원할 수 있다. 일반 입력에 #가 있으면 이스케이프나 길이 표기 등 다른 유일한 복원 규칙을 정해야 한다.

가능하다는 말과 빠르다는 말

계산 가능한 절차가 존재한다는 말은 현실의 메모리·시간 안에 언제나 빨리 끝난다는 말이 아니다. 모형에서는 필요한 만큼 유한하게 늘릴 수 있는 작업 공간을 가정하지만 실제 장비에는 한계가 있다. 논제만으로 특정 시간 복잡도나 모든 수학 문제의 풀이 가능성이 따라오지 않는다.

완료되는 탐색과 답이 있을 때만 완료되는 탐색도 구별한다. 자연수 후보를 끝없이 시험해 답을 찾으면 예라고 하는 절차는 답이 없을 때 언제 끝나는지 보장하지 못한다. 후보를 유한 범위로 제한할 근거가 있으면 그 범위 전체를 확인한 뒤 아니오로 정지할 수 있다.

A는 짝수의 인식 절차지만 n=3에서 판정하지 못한다. B는 모든 자연수 부호에서 정지하는 특수 판정 절차다.

논제는 효과적인 계산 절차와 형식 모형을 연결한다. 예제의 후보 수 n+1은 이진 입력 길이에 대해 커질 수 있고, 일반 문제에서 알고리즘 존재나 빠른 실행은 각각 별도의 문제다.

연습 1 · 값과 상태 예측

E(01,ε)와 E(ε,1)를 만들고 J의 판정을 구하라.

힌트 1

첫 x의 길이는 2다.

힌트 2

J는 두 문자열의 값과 길이를 비교한다.

풀이와 답 확인

  1. E(01,ε)는 헤더 110 뒤에 자료 01을 붙인 부호 11001이다. E(ε,1)은 헤더 0 뒤에 자료 1을 붙인 부호 01이다.

  2. 첫 쌍의 문자열 01과 ε는 다르다. 둘째 쌍의 문자열 ε와 1도 다르므로 J는 두 부호를 모두 거부한다.

첫 부호는 11001이고 둘째 부호는 01이다. J는 두 부호를 모두 거부한다.

흔한 오답에서 다시 생각하기

빈 y이면 입력 자체가 ε다.

두 성분을 복원하는 헤더가 있으므로 빈 성분도 부호 안에서 표현된다.

연습 2 · 오류 찾아 고치기

학생은 1101을 (1,ε)로 해독하고, 111은 헤더 끝을 찾을 때까지 무한히 읽는다. 유한 문자열 입력 계약으로 고쳐라.

힌트 1

헤더 110이 요구하는 첫 문자열 길이는 2다.

힌트 2

입력 끝의 □를 헤더 데이터로 쓰지 않는다.

풀이와 답 확인

  1. 1101은 헤더가 길이 2를 요구하지만 뒤 자료 길이는 1이므로 거부한다. 쌍 (1,ε)의 올바른 부호는 101이다.

  2. 111은 유한 입력 안에 헤더 종료 기호 0이 없으므로 거부한다. 뒤의 □를 만난 검사 단계에서 종료할 수 있다.

헤더 부족과 종료표지 부재 모두 유한 시간 거부로 처리한다.

흔한 오답에서 다시 생각하기

뒤의 무한 □를 계속 읽으면 언젠가 0이 나온다.

유한 입력 뒤 빈칸은 입력 0이 아니며 유효 부호를 기다리는 무한 탐색으로 바꾸면 판정 계약이 깨진다.

연습 3 · 직접 만들어 보기

J가 수락하는 길이 5의 부호를 구성할 수 있는지 먼저 검사하라. 가능하면 정확한 쌍을 제시하고, 불가능하면 길이 조건의 모순을 증명한 뒤 길이 4로 수정한 예를 구성하라.

힌트 1

같은 x와 y를 고른다.

힌트 2

E의 길이는 |x|+1+|x|+|y|다.

풀이와 답 확인

  1. x=y=1을 고르면 부호 길이는 1+1+1+1=4다. 두 같은 문자열의 길이를 m이라 하면 수락 부호의 전체 길이는 3m+1이다.

  2. 3m+1=5를 만족하는 정수 m은 없으므로 길이 5의 요구는 불가능하다. 수정 길이 4에서는 쌍 (1,1)의 부호 1011을 구성하며 J가 이를 수락한다.

길이 5의 수락 부호는 없다. 불가능성을 증명하고 수정 길이 4의 부호 1011을 구성했다.

흔한 오답에서 다시 생각하기

10101은 길이가 5이므로 J가 수락한다.

10101은 (1,01)이라 길이가 다른 두 문자열이며 J가 거부한다. 요구의 불가능성을 숨기지 않는다.

연습 4 · 선택 심화

선택 심화는 기본 연습 뒤 더 탐구하고 싶을 때 풀어 보세요.

E가 서로 다른 쌍을 같은 부호로 만들지 않음을 증명하고, 입력 검증을 포함한 J의 정지를 설명하라.

힌트 1

첫 0의 위치는 헤더 길이를 유일하게 정한다.

힌트 2

뒤의 고정 길이와 나머지는 하나의 분할이다.

풀이와 답 확인

  2. J는 유한 헤더 스캔·길이 검사·두 유한 문자열 비교를 실행하고 수락/거부한다. 헤더 끝 부재와 자료 부족도 입력 끝에서 거부한다.

유일 해독이 단사 부호를 보이며 유효/무효 모든 유한 입력에서 정지한다.

흔한 오답에서 다시 생각하기

두 문자열을 연결하는 어떤 규칙도 단사다.

B의 입력 10을 수락까지 추적해 출력·전이 수·최종 헤드를 구하세요. 별도 M의 초기 부호 #0·1□#1·0□#와 규칙 δ(q,1,0)=(p,0,1,R,L)에 따른 다음 경계 부호를 구하세요. 마지막으로 J에 부호 1011과 10101을 주었을 때 각각 해독한 쌍과 판정을 쓰고, 길이 5의 수락 부호가 존재하는지 설명하세요. 모든 수치는 자체 종이 모형이며 실제 튜링기계 프로그램 실행 결과가 아닙니다.

힌트 1

B는 두 비트를 뒤집은 후 빈칸에서 방향을 바꾸고 표지로 돌아간다. M은 먼저 읽은 두 기호로 한 규칙을 고정한다.

힌트 2

E의 헤더 뒤 처음 ℓ문자가 x이고 나머지가 y다. J가 수락하면 두 문자열 길이가 m으로 같으므로 전체 부호 길이는 3m+1이다.

풀이와 답 확인

  1. B는 첫 두 전이 뒤 테이프 ▷01□…와 상태 flip·헤드 3이 된다. 이후 back·헤드 2, back·헤드 1, back·헤드 0, accept·헤드 1을 차례로 거친다. 출력은 01이고 총 전이 수는 6이다.

  2. M의 다음 경계 부호는 #00·□#·11□#이고 상태는 p다. 첫 원래 헤드는 칸 3, 둘째는 칸 1에 있으므로 다음 읽기 쌍은 (□,1)이다. 쓰기 후 다른 규칙을 선택하지 않는다.

  3. 부호 1011에서 첫 0 앞에 있는 1은 한 개다. 뒤 자료 11을 x=1과 y=1로 나누므로 J가 수락한다. 부호 10101은 x=1과 y=01로 나누므로 J가 거부한다.

  4. 수락 부호의 길이는 3m+1이다. 3m+1=5를 만족하는 자연수 m이 없으므로 길이 5의 수락 부호는 존재하지 않는다. 수정 길이 4의 부호 1011은 유효한 예다.

B의 출력은 01이고 총 6전이 뒤 헤드가 칸 1에 있는 상태에서 수락한다. M은 상태 p와 부호 #00·□#·11□#로 옮겨 다음 쌍 (□,1)을 읽는다. J는 1011을 쌍 (1,1)로 해독해 수락하고 10101을 쌍 (1,01)로 해독해 거부한다. 길이 5의 수락 부호는 불가능하다.

  • M의 두 읽기 기호·한 규칙·두 표시 및 표시된 빈칸을 보존한다.

  • 두 부호의 유일한 해독과 길이 5의 불가능성을 증명하고 특수 정지 논증을 일반 논제나 속도 보증으로 확대하지 않는다.
