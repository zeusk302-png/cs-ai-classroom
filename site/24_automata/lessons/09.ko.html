소단원 9.1

테이프·상태·계산

읽은 글자를 다시 고치고 뒤로 돌아갈 수 있으면 무엇이 달라질까?

준비 개념과 학습 목표

준비 개념

  • 상태는 현재 행동 규칙을 선택하는 유한한 기억이다.
  • 입력 문자열은 유한 길이이며 빈 문자열도 입력이다.

학습 목표

  • 상태·테이프 내용·헤드 위치로 한 계산 상태를 표현한다.
  • 정지 수락·정지 거부·무한 실행과 판정기를 구별한다.

유한 제어와 늘릴 수 있는 기록

튜링기계는 유한한 상태 집합, 유한한 테이프 기호 집합, 읽고 쓰는 헤드와 전이 규칙을 가진 수학 모형이다. 테이프 기호는 입력 기호와 빈칸 □, 보조 표시를 포함한다. 한 전이는 상태와 읽은 기호를 보고 기호를 쓰고 헤드를 한 칸 이동하고 새 상태로 바꾼다.

여기서는 왼쪽 끝 표지 ▷가 있는 오른쪽 무한 테이프를 사용한다. 입력은 표지 다음 칸부터 놓고 그 뒤는 빈칸이다. 무한 테이프는 시작부터 무한한 내용을 읽었다는 뜻이 아니다. 유한 시간에는 유한한 칸만 방문하며 필요에 따라 더 멀리 이동할 수 있다는 이상화다.

계산의 스냅샷

한 순간의 구성은 상태, 테이프 내용, 헤드 위치를 함께 기록한다. 테이프만 같아도 헤드나 상태가 다르면 다음 행동이 달라질 수 있다. 전이 순서는 현재 칸을 읽기→같은 칸에 쓰기→이동하기로 약속한다.

아래 자체 기계는 1만 있는 입력을 오른쪽으로 훑고 빈칸에 1을 하나 더 쓴 뒤 왼쪽 끝으로 돌아간다. scan에서 1을 읽으면 1을 쓰고 R, 빈칸이면 1을 쓰고 L로 back에 들어간다. scan에서 0이면 0을 쓰고 R로 reject한다. back에서 1은 그대로 쓰고 L, ▷는 그대로 쓰고 R로 accept한다. 예제 경로 밖의 비정지 상태·기호 조합은 해당 기호를 유지하고 R로 reject하도록 정한다.

언어 수락과 함수 출력

accept와 reject는 정지 상태다. 일반 튜링기계는 정지 상태에 도달하지 않고 영원히 움직일 수도 있다. 언어를 인식하는 기계는 그 언어의 입력을 수락하지만 언어 밖에서는 정지 거부 또는 무한 실행이 가능하다. 판정기는 모든 입력에서 반드시 정지해 예/아니오를 준다.

이 예제는 입력 알파벳 {0,1}에서 1만 있는 문자열인지 판정하며 수락 시 테이프에 1을 하나 추가하는 작업도 한다. 입력에 0이 있으면 첫 0에서 거부하므로 모든 유한 입력에서 정지한다. 한 입력이 빨리 끝났다는 관찰만으로 다른 기계도 판정기라고 결론 내리면 안 된다.

중간 과정을 따라가는 예제

입력 11의 테이프 칸은 0=▷,1=1,2=1,3=□이다. 시작 상태 scan, 헤드 1이다. 위 규칙으로 수락까지의 전이와 최종 비빈 부분을 추적하라.

  1. 1회: 칸1의 1을 유지하고 scan·헤드2다. 2회: 칸2의 1을 유지하고 scan·헤드3다.
  2. 3회: 칸3의 □를 1로 바꾸고 back·헤드2다. 이제 테이프는 ▷111□…이다.
  3. 4회: back·헤드1, 5회: back·헤드0이다. 쓰는 1은 그대로다.
  4. 6회: ▷를 유지하고 accept·헤드1로 이동하며 정지한다.

6전이 후 ▷111□…이며 수락했다. 입력 길이 n의 1만 있는 입력은 n회 스캔+1회 추가+n회 복귀+1회 수락=2n+2전이다. 총 전이 수를 센다.

종이와 본문으로 직접 해보기

빈 입력과 입력 101을 각각 추적하라. 빈 입력의 초기 헤드는 ▷ 다음 빈칸이다.

힌트 보기

빈 입력도 먼저 빈칸에 1을 쓴다. 101은 두 번째 칸의 0을 만난다.

풀이 보기

빈 입력은 1회에 1을 쓰고 back·헤드0, 2회에 accept·헤드1로 끝난다. 101은 첫 1에서 오른쪽으로, 두 번째 0에서 reject로 이동해 2전이 후 거부하며 입력 내용은 유지한다.

오해와 반례

테이프가 무한하면 한 번에 무한한 자료를 처리한다.

한 전이는 한 칸만 읽고 쓴다. 입력 11 처리에도 6전이가 든다. 무한히 이어갈 수 있는 작업 공간과 무한 시간 작업을 한 번에 끝내는 능력은 다르다.

자기점검

같은 테이프 내용이면 다음 행동도 항상 같은가?

답과 이유 보기

아니다.

상태와 헤드 위치도 전이를 결정한다.

무한 실행은 정지 거부 상태에 도달한 것인가?

답과 이유 보기

아니다.

언어 밖 입력일 수 있지만 정지 거부라는 사건은 일어나지 않았다.

1이 세 개인 입력의 전이 수는?

답과 이유 보기

8회다.

2×3+2이며 추가 뒤 돌아가는 경로까지 포함한다.

한 단계 더

오른쪽으로 계속 이동하는 별도 기계를 생각하라. □에서도 □를 쓰고 R로 같은 상태를 유지하면 유한 입력 뒤에도 정지하지 않는다. 몇 단계 관찰로 영원한 실행을 실험적으로 확인한 것이 아니라, 어느 상태에도 정지 전이가 없다는 규칙으로 설명한다.

소단원 9.2

다중테이프와 동치

테이프가 여러 개면 풀 수 있는 문제도 반드시 늘어날까?

준비 개념과 학습 목표

준비 개념

  • 테이프의 기호·헤드 위치·상태를 함께 기록한다.
  • 한 전이를 다른 모형의 여러 전이로 흉내낼 수 있다.

학습 목표

  • 고정된 여러 테이프의 한 전이를 설명한다.
  • 단일 테이프 부호화와 시뮬레이션의 정지 보존을 설명한다.

한 상태와 여러 헤드

고정된 k개 테이프의 튜링기계는 각 테이프에 헤드를 두고 한 전이에서 k개의 현재 기호를 읽는다. 하나의 상태와 그 기호 목록에 따라 각 칸에 쓰고 각 헤드를 이동한다. 첫 테이프에는 입력, 나머지에는 처음에 빈칸을 놓는 모형을 생각한다.

k는 기계 정의에서 정해진 유한한 수다. 유한 기호 집합의 k개 조합을 전이표로 다룰 수 있다. 여러 헤드 동시 이동은 이 모형의 전이 단위이지 현실 컴퓨터의 스레드 실행을 측정한 결과가 아니다.

한 줄에 여러 테이프 넣기

단일 테이프에 각 테이프의 사용 구간을 구분자 #로 나누어 저장한다. 각 구간에서 원래 헤드가 놓인 기호는 점 표시한 기호로 바꾸고 원래 기계의 상태도 추적한다. 점 표시는 별도의 유한 테이프 기호이므로 헤드를 추가한 것이 아니다.

원래 한 전이를 흉내낼 때 각 구간을 훑어 표시된 기호들을 유한 제어에 모은 뒤, 다시 훑으며 규칙에 맞게 쓰고 표시를 옮긴다. 구간 끝 너머로 이동해야 하면 빈칸을 추가하고 뒤 구간을 밀어 공간을 확보한다. 모든 모의 전이 시점의 내용과 표시가 원래 구성을 정확히 표현한다는 불변식이 근거다.

같은 계산 가능성과 다른 비용

이 시뮬레이션은 원래 수락과 거부를 같은 방식으로 정지하도록 보존한다. 각 원래 단계에 유한한 모의 단계가 필요하므로 원래 판정기는 변환 후에도 모든 입력에서 정지한다. 반대 방향은 단일 테이프 기계를 여러 테이프 중 하나만 사용하는 기계로 보면 된다.

따라서 단일/다중 테이프는 인식 가능한 언어와 판정 가능한 언어에서 동치다. 한 원래 단계를 모의할 때 스캔과 구간 확장이 필요하므로 전이 수까지 같다는 주장은 아니다. 계산 가능성의 동치만으로 모든 알고리즘의 실행 시간을 같다고 결론 내리지 않는다.

중간 과정을 따라가는 예제

자체 두 테이프 복사 기계는 상태 copy에서 입력 테이프의 0/1과 작업 테이프 □를 읽으면 입력은 유지하고 작업에 같은 기호를 쓰며 두 헤드를 R로 옮긴다. 입력과 작업이 둘 다 □이면 그대로 쓰고 두 헤드를 R로 옮겨 accept한다. 입력 101, 두 헤드 모두 첫 칸, 작업은 모두 빈칸일 때 추적하라.

  1. 첫 전이에서 작업 첫 칸에 1을 쓴다. 입력/작업 헤드는 둘 다 칸2다.
  2. 둘째 전이에서 작업 칸2에 0을 쓰고 두 헤드는 칸3이다. 셋째에서 1을 쓰고 칸4다.
  3. 넷째에 두 빈칸을 읽고 두 헤드를 칸5로 옮겨 accept한다. 입력과 작업 비빈 문자열은 모두 101이다.
  4. 단일 테이프 부호화에서는 각 구간에 내용뿐 아니라 칸5의 빈칸에 놓인 헤드 표시도 유지해야 같은 최종 구성을 표현한다.

복사 기계는 4전이 후 정지 수락한다. 이는 두 테이프 기계의 전이 수이며 단일 테이프 모의 전이 수로 환산한 값은 아니다.

종이와 본문으로 직접 해보기

입력 10을 복사할 때 두 번째 전이 직후 두 테이프의 내용과 헤드 위치를 쓰라. #구간 사이에 점 표시로 부호화하라.

힌트 보기

두 번째 문자도 복사한 뒤 두 헤드는 셋째 칸의 빈칸에 있다.

풀이 보기

입력과 작업 모두 10□…이며 헤드는 각각 칸3이다. 유한 구간의 예시 표기는 #10·□#10·□#이다. ·□는 점 표시된 빈칸 기호 하나를 뜻한다. 다음 세 번째 원래 전이에서 accept하고 헤드는 칸4로 옮긴다.

오해와 반례

동치라면 다중 테이프의 4단계는 단일 테이프에서도 정확히 4단계다.

동치는 같은 입력의 수락·거부 및 계산 가능성에 관한 것이다. 점 표시를 찾는 스캔과 갱신은 여러 단계여서 이 시뮬레이션의 비용은 같지 않다.

자기점검

헤드 표시를 빼고 내용만 저장해도 충분한가?

답과 이유 보기

충분하지 않다.

각 원래 헤드가 읽을 칸을 복원할 수 없다.

한 테이프가 다른 여러 테이프를 흉내낼 수 있다는 방향만으로 동치 증명이 완결되는가?

답과 이유 보기

양방향이 필요하다.

다른 방향은 여러 테이프 기계가 하나만 사용하여 단일 테이프 기계를 모의한다.

위 복사 규칙으로 빈 입력은 몇 원래 전이인가?

한 단계 더

부호화 구간 마지막의 표시된 빈칸에서 계속 R로 이동하는 원래 기계를 생각하라. 구간을 늘리고 뒤 구간을 밀어야 한다. 입력 길이가 고정되어도 실행 중 사용 구간은 늘 수 있으므로 처음 입력만 저장하는 배열로 시뮬레이션을 끝냈다고 주장할 수 없다.

소단원 9.3

Church–Turing 논제

서로 다른 계산 모형의 동치 증명과 알고리즘의 뜻을 정하는 논제는 같은 종류의 주장일까?

준비 개념과 학습 목표

준비 개념

  • 알고리즘은 유한하게 기술된 기계적인 절차다.
  • 인식과 모든 입력에서 정지하는 판정을 구별한다.

학습 목표

  • 형식 모형의 동치 정리와 논제를 구별한다.
  • 기계적 절차의 입력·정지·부호화 조건을 설명한다.

직관적 절차와 형식 모형 연결

Church–Turing 논제는 기계적으로 효과적으로 계산할 수 있는 절차를 튜링기계 계산으로 표현할 수 있다는 연결이다. 튜링기계 쪽은 상태와 전이로 수학적으로 정의되지만 효과적인 절차라는 직관적 말 자체가 이미 하나의 형식 정의로 주어진 것은 아니다.

그래서 두 엄밀한 모형 사이의 동치처럼 같은 방식으로 증명하는 정리와 구별해 논제라고 부른다. 람다 계산이나 다른 충분한 계산 모형이 같은 계산 능력으로 귀결된다는 증명은 이 연결을 뒷받침한다. 여러 테이프가 한 테이프와 동치라는 앞 절 정리가 곧 논제 전체의 증명이라는 뜻은 아니다.

고수준 절차에도 조건이 있다

튜링기계를 기술할 때 모든 칸 전이를 쓰는 대신 유한 자료를 읽고 비교·덧셈·반복하는 고수준 절차를 쓰기도 한다. 그 연산들을 기호와 유한 단계로 구현할 수 있어야 한다. 어떤 답을 아는 초능력 상자를 한 줄에 넣으면 알고리즘 설명이 되지 않는다.

입력을 문자열로 부호화하는 규칙도 필요하다. 두 문자열 x,y를 구분자 없이 붙이면 경계를 잃을 수 있다. 구분자 #가 입력 알파벳에 없는 경우 x#y처럼 저장하면 두 문자열을 복원할 수 있다. 일반 입력에 #가 있으면 이스케이프나 길이 표기 등 다른 유일한 복원 규칙을 정해야 한다.

가능하다는 말과 빠르다는 말

계산 가능한 절차가 존재한다는 말은 현실의 메모리·시간 안에 언제나 빨리 끝난다는 말이 아니다. 모형에서는 필요한 만큼 유한하게 늘릴 수 있는 작업 공간을 가정하지만 실제 장비에는 한계가 있다. 논제만으로 특정 시간 복잡도나 모든 수학 문제의 풀이 가능성이 따라오지 않는다.

완료되는 탐색과 답이 있을 때만 완료되는 탐색도 구별한다. 자연수 후보를 끝없이 시험해 답을 찾으면 예라고 하는 절차는 답이 없을 때 언제 끝나는지 보장하지 못한다. 후보를 유한 범위로 제한할 근거가 있으면 그 범위 전체를 확인한 뒤 아니오로 정지할 수 있다.

중간 과정을 따라가는 예제

입력은 0 이상의 정수 n의 유한 이진 부호화다. 자연수 x에 대해 x²=n인 해가 있는지 판정하는 자체 절차를 만들자. 후보 0부터 n까지 순서대로 시험하고 일치하면 예, 모두 불일치하면 아니오로 정지한다. n=9와 n=10을 추적하고 유한 범위의 근거를 설명하라.

  1. n=9에서 x=0,1,2,3의 제곱은 0,1,4,9다. 네 번째 시험에서 예라고 정지한다.
  2. n=10에서 0부터 10까지 11개를 시험한다. 제곱 0,1,4,9,16,25,36,49,64,81,100 중 10이 없어 아니오다.
  3. n=0의 해는 0이다. n≥1에서 x≥1이면 x²≥x이므로 x²=n인 후보는 x≤n이어야 한다. 따라서 범위 밖에 놓친 자연수 해가 없다.
  4. 읽기·유한 정수 연산·카운터 증가를 기호로 구현할 수 있고 후보도 유한 개다. 별도의 유한 범위 근거가 판정기의 정지를 보장한다.

9는 네 번 시험 후 예, 10은 열한 번 시험 후 아니오다. 이 계산은 한 특수 문제의 고수준 판정 절차이지 모든 방정식을 푸는 일반 방법이 아니다.

종이와 본문으로 직접 해보기

0 입력의 시험 수를 구하고, (x,y)=(1,01)과 (10,1)을 단순 연결/구분자 연결로 각각 비교하라.

빈 후보 목록이 아니다. 두 쌍의 단순 연결은 같은 세 문자다.

풀이 보기

n=0은 후보 x=0 한 번에서 0²=0으로 예다. 단순 연결은 둘 다 101이라 모호하다. #가 원래 알파벳에 없다면 1#01과 10#1은 달라 원래 쌍을 복원할 수 있다.

오해와 반례

Church–Turing 논제는 모든 문제에 빠른 알고리즘이 있다는 정리다.

논제는 효과적인 계산 절차와 형식 모형을 연결한다. 예제의 후보 수 n+1은 이진 입력 길이에 대해 커질 수 있고, 일반 문제에서 알고리즘 존재나 빠른 실행은 각각 별도의 문제다.

한 단계 더

위 절차의 최악 후보 수 n+1과 이진 부호화 길이를 비교하라. 양수 n의 길이 b이면 2^(b−1)≤n<2^b다. 10은 이진 1010의 네 자리지만 이 절차는 11후보를 시험한다. 더 좋은 제곱근 탐색이 가능할 수 있다는 사실과 지금 작성한 절차의 비용을 구별하라.
