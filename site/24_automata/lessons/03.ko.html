소단원 3.1

NFA와 ε 전이

같은 글자를 보고 두 갈래로 갈 수 있다면 어느 갈래가 정답일까?

준비 개념과 학습 목표

준비 개념

  • 유한 집합 Q와 멱집합 P(Q): {p,q}의 부분집합은 ∅,{p},{q},{p,q}다.
  • 문자열 ab는 a 다음 b를 읽는다. ε는 길이 0인 문자열이며 ∅는 문자열을 하나도 포함하지 않는 집합이다.
  • DFA는 현재 상태 하나와 다음 입력으로 상태를 정한다. 입력을 모두 읽은 뒤 수락 여부를 판단한다.

학습 목표

  • NFA의 존재적 수락 조건을 모든 경로 수락과 구분한다.
  • ε 폐쇄를 입력 소비 없이 계산하고 문자 전이 앞뒤에 적용한다.

선택지를 가진 유한 기계

ε-NFA를 M=(Q,Σ,δ,q0,F)로 둔다. Q는 유한 상태 집합, Σ는 유한 입력 알파벳, q0∈Q는 시작 상태, F⊆Q는 수락 상태 집합이다. δ:Q×(Σ∪{ε})→P(Q)는 가능한 다음 상태들의 집합을 돌려준다. 전이가 없는 경우 값은 ∅이며, ε는 여기서 입력 문자가 아니라 입력을 소비하지 않는 전이 표시다.

문자열 w의 모든 문자를 순서대로 소비한 유한 경로 중 하나라도 F에서 끝나면 수락한다. 어떤 선택이 실패해도 다른 성공 경로가 있으면 수락한다. 확률을 정해 무작위로 한 길을 택하는 기계가 아니라 가능한 길의 존재를 정의한 모델이다. 수락 상태에 중간에 들렀더라도 남은 입력을 읽지 못하면 그 길로는 전체 문자열을 수락하지 못한다.

ε 전이와 폐쇄

E(S)는 S의 각 상태에서 ε 전이를 0번 이상 따라 도달하는 모든 상태의 집합이다. 0번도 허용하므로 S⊆E(S)이고 E(∅)=∅다. q0가 수락 상태가 아니어도 E({q0})에 수락 상태가 있으면 ε를 수락한다. ε 간선으로 한 바퀴 도는 것은 문자 수를 늘리지 않는다.

종이 계산에서는 S에서 시작해 새 ε 도착 상태를 계속 추가한다. 이미 넣은 상태를 다시 처리하지 않으면 ε 순환이 있어도 유한 Q 때문에 멈춘다. 예를 들어 p→εq, q→εp, q→εr이면 E({p})={p,q,r}이다. 폐쇄는 상태 목록의 고정점이며 가능한 ε 경로를 무한히 열거하는 일이 아니다.

문자를 하나 읽는 정확한 규칙

처음 가능한 상태들은 S0=E({q0})이다. 이미 ε 폐쇄된 Si에서 다음 문자 a를 읽으면 Si+1=E(⋃[q∈Si]δ(q,a))로 계산한다. 합집합은 갈래 중 하나라도 도달하는 상태를 보존하고, 뒤의 E는 문자를 읽은 직후 가능한 무료 이동을 보존한다. 입력 끝에서 Sn∩F≠∅인지 검사한다.

가능한 상태 집합은 동시에 여러 장소에 실제 사람이 있다는 뜻이 아니다. 하나의 입력 접두사를 설명하는 경로들의 끝점을 묶은 정보다. 길이 n 입력의 단계는 n번이고 ε 이동은 각 단계의 폐쇄에 포함된다. 이 단원은 수락 언어를 다루며 토큰의 최장 일치나 정규식 엔진의 탐욕적 정책은 별도 선택 규칙이다.

중간 과정을 따라가는 예제

Σ={a,b}, Q={s,p,q,f}, 시작 s, 수락 F={f}. s→εp와 s→εq, p→a p, p→b f, q→b q, q→a f만 있고 나머지 전이는 없다. abb와 bbba의 가능한 상태 집합을 모두 구하라.

  1. 시작 폐쇄 E({s})={s,p,q}다. p와 q에는 ε 간선이 없으며 s도 0번 이동으로 포함된다.
  2. abb에서 a를 읽으면 p의 a 전이로 p, q의 a 전이로 f를 얻어 {p,f}다. 다음 b는 p에서 f로 가므로 {f}다.
  3. 마지막 b는 f에서 갈 수 없어 ∅다. 앞선 단계의 f는 남은 b를 소비하지 못하므로 abb는 거절된다.
  4. bbba는 {s,p,q}→{f,q}→{q}→{q}→{f}다. 끝에 f가 남으므로 수락한다. 이 기계의 언어는 a*b 또는 b*a이며 ε 자체는 수락하지 않는다.

abb는 거절, bbba는 수락이다. 모든 입력 뒤의 가능한 끝 상태로 판정한다.

종이와 본문으로 직접 해보기

같은 기계에서 ε, a, b, aab, ba, abab를 판정하고, f→εs를 추가하면 ε 자체가 수락되는지도 따져보라.

힌트 보기

각 문자열마다 시작 폐쇄를 새로 놓는다. ε를 수락하려면 시작 폐쇄가 f를 포함해야 한다. f에서 돌아가는 간선만으로 시작에서 f로 가는 길이 새로 생기는지는 별도 문제다.

풀이 보기

원래 ε는 {s,p,q}이므로 거절. a는 {p,f}, b는 {f,q}, aab는 {p,f}→{p}→{f}라 수락한다. ba는 {f,q}→{f}라 수락하고 abab는 a,b 뒤 {f}, 다음 a에서 ∅라 거절한다. f→εs를 더하면 비어 있지 않은 입력의 조합 언어는 달라질 수 있지만 E({s})에는 여전히 f가 없어 ε는 거절이다.

오해와 반례

어떤 경로가 실패하면 NFA는 문자열을 거절한다.

a 입력에서는 p에서 끝나는 실패 경로와 q→a f의 성공 경로가 함께 있다. 성공 경로 하나가 있으므로 수락한다. 반대로 abb는 b 뒤 f에 왔다는 사실만으로 수락하지 않고 마지막 b까지 처리해야 한다.

자기점검

ε 전이는 문자 하나를 소비하는가?

답과 이유 보기

소비하지 않는다.

ε의 길이는 0이며 입력 위치를 유지한 상태 이동이다.

E({p})에는 p 자체가 포함되는가?

답과 이유 보기

포함된다.

ε 이동 0번도 도달로 센다.

마지막 가능한 상태가 {p,f}, F={f}이면?

답과 이유 보기

수락한다.

교집합이 {f}로 비어 있지 않아 성공 경로가 존재한다.

한 단계 더

폐쇄의 고정점 성질 E(E(S))=E(S)를 증명하라. 두 번 폐쇄에서 얻은 상태는 S에서 첫 ε 경로와 다음 ε 경로를 이어 도달하므로 이미 E(S)에 들어간다. 반대 포함은 0번 이동으로 성립한다. 이 성질이 문자 전후마다 ε 경로의 세부 길이를 저장하지 않아도 되는 이유다.

소단원 3.2

부분집합 구성

여러 상태가 가능한 상황을 하나의 결정적 상태로 이름 붙일 수 있을까?

준비 개념과 학습 목표

준비 개념

  • 앞 소단원의 E(S)와 문자 전이 합집합을 복습한다.
  • 집합 {p,f} 하나와 두 상태 p,f의 이름을 구별한다. DFA의 상태 이름은 집합일 수도 있다.
  • 집합 크기 n의 멱집합에는 2^n개 부분집합이 있으며 ∅도 포함된다.

학습 목표

  • ε-NFA의 부분집합 DFA 시작·전이·수락 상태를 구성한다.
  • 도달 상태 탐색과 전체 멱집합, 최소화를 서로 구분한다.

가능한 끝점 집합을 상태로

부분집합 DFA의 상태 공간은 P(Q), 시작 상태는 E({q0})다. 집합 상태 S에서 문자 a의 전이는 Δ(S,a)=E(⋃[q∈S]δ(q,a))다. 집합 S가 수락 상태가 될 조건은 S∩F≠∅다. 모든 원소가 수락 상태일 필요는 없으며 선택 하나만 성공하면 되는 NFA 정의를 그대로 옮긴 것이다.

전체 P(Q)로 정의할 때 일부 S는 ε 폐쇄되지 않을 수 있지만 시작에서 도달하는 상태들은 항상 폐쇄되어 있다. 따라서 표시한 공식은 시작에서의 실행과 언어 동치를 보장한다. 실제 구성을 도달 상태만으로 하면 모든 생성 상태가 폐쇄되므로 전이 전의 E(S)를 따로 다시 계산할 필요가 없다.

빠뜨리지 않는 작업 목록

시작 집합을 목록에 넣고 아직 처리하지 않은 집합 하나를 꺼낸다. 모든 a∈Σ에 대해 합집합 뒤 폐쇄를 계산하고, 처음 보는 집합이면 목록에 넣는다. 모든 도달 집합의 모든 문자 전이를 채우면 종료한다. 유한 Q의 부분집합 수가 유한하기 때문에 종료는 보장되지만 많은 부분집합이 생길 수 있다.

∅도 한 상태다. 합집합에 원소가 없고 E(∅)=∅이므로 모든 문자에서 ∅로 자기 전이한다. 도달하지 않는 ∅를 굳이 도달 목록에 넣을 필요는 없지만, 도달했는데 표에서 지우면 완전 DFA의 전이 정의가 빈칸이 된다. 여기서는 δ가 모든 상태·문자에서 정의된 완전 DFA를 쓴다.

왜 같은 언어인가

길이 0 접두사의 NFA 가능한 끝점은 E({q0})로 DFA 시작 상태와 같다. 길이 k에서 같다고 가정하면 다음 문자 전이 합집합과 ε 폐쇄가 바로 길이 k+1 NFA의 끝점을 계산하므로 다음 DFA 상태와도 같다. 문자열 길이에 대한 귀납으로 모든 입력 접두사에서 이 불변식이 성립한다.

입력 끝에서 NFA의 성공 경로 존재는 끝점 집합과 F의 교집합이 비어 있지 않은 것과 동치다. 이것이 DFA 수락 상태 정의이므로 양쪽이 같은 문자열을 수락한다. 동치는 상태 수, 내부 경로, 처리시간이 같다는 뜻이 아니다. 도달 상태 삭제와 동치 상태 병합에 의한 최소화도 서로 다른 작업이다.

중간 과정을 따라가는 예제

첫 소단원의 기계 s→εp,q; p→a p,p→b f; q→b q,q→a f; F={f}를 완전 DFA로 바꾸라. 문자 열은 a,b 순이다.

  1. A={s,p,q}에서 a→B={p,f}, b→C={q,f}다. B와 C는 f를 포함해 수락이다.
  2. B에서 a→D={p}, b→E={f}. C에서 a→E, b→H={q}다.
  3. D에서 a→D,b→E; H에서 a→E,b→H; E에서 a,b 모두 Z=∅; Z에서 a,b 모두 Z다.
  4. 총 도달 상태는 A,B,C,D,E,H,Z의 7개다. 원래 4상태의 전체 멱집합 상한은 16이지만 나머지 9개는 시작에서 도달하지 않는다. 수락은 B,C,E다.

전이표 A:(B,C), B:(D,E), C:(E,H), D:(D,E), E:(Z,Z), H:(E,H), Z:(Z,Z). 수락 B,C,E.

종이와 본문으로 직접 해보기

완성한 표로 aab와 abb를 추적하라. 그리고 A에서 두 문자 이상 읽은 뒤 s가 들어 있는 집합에 도달할 수 있는가?

힌트 보기

표의 문자 열을 한 번씩 따라가며 마지막 상태의 수락 표시를 본다. s로 들어오는 간선이 원래 기계에 있는지도 검사한다.

풀이 보기

aab는 A→B→D→E라 수락, abb는 A→B→E→Z라 거절이다. s로 들어오는 문자·ε 간선이 없으므로 한 문자라도 읽은 뒤 s는 끝점 집합에서 사라져 돌아오지 않는다. A 외에 s를 포함하는 도달 집합이 없는 이유를 설명한다.

오해와 반례

NFA 상태가 4개면 만든 DFA는 반드시 16개 상태다.

16은 전체 부분집합 상한이다. 이 예제의 도달 부분은 7개이며 어떤 NFA는 더 적다. 더 나아가 같은 미래 수락 행동을 가진 도달 상태를 최소화에서 병합할 수 있어 도달 구성과 최소 상태 수가 같다는 보장도 없다.

자기점검

부분집합 {p,f}를 수락으로 표시할 조건은?

답과 이유 보기

F와의 교집합이 비어 있지 않다.

F={f}이면 f가 포함되어 존재적 수락 조건을 만족한다.

∅ 상태에서 a를 읽으면?

답과 이유 보기

다시 ∅다.

어떤 원래 상태의 전이도 합칠 수 없다.

도달하지 않는 부분집합을 생략해도 언어가 유지되는가?

답과 이유 보기

유지된다.

시작에서 실행되는 어떤 입력 경로도 그 상태에 들어가지 않는다.

한 단계 더

DFA의 구별 가능한 상태를 살펴보라. 이 예제에서 B와 D는 빈 접미사 ε로 구별된다. B는 수락, D는 비수락이다. D와 H는 접미사 b로 구별된다. D는 E로 수락하지만 H는 H에 남아 거절한다. 이런 접미사 비교는 도달 상태 구성과 다른 최소화 관점이며, 표의 모양이 달라도 미래 언어가 같으면 병합 가능하다.

소단원 3.3

DFA·NFA의 표현력

NFA가 선택을 허용하면 DFA로는 풀지 못하는 문자열 문제까지 풀 수 있을까?

준비 개념과 학습 목표

준비 개념

  • 동일 언어는 모든 유한 입력 문자열에 대해 수락/거절이 일치하는 뜻이다.
  • DFA 전이 하나를 NFA의 한 원소 집합 전이로 바꾸는 방법을 준비한다.
  • 부분집합 구성은 유한 상태라는 사실에 의존한다. 입력 문자열 길이는 제한하지 않는다.

학습 목표

  • DFA와 ε-NFA의 언어 동치를 양쪽 포함으로 증명한다.
  • 언어 표현력·상태 수·구현 비용을 구별하고 유한 기억의 한계를 설명한다.

양쪽 변환이 주는 결론

DFA D=(Q,Σ,δ,q0,F)를 NFA로 보면 δN(q,a)={δ(q,a)}이고 ε 전이는 없게 한다. 모든 단계의 가능한 상태 집합은 한 원소이므로 같은 언어를 수락한다. 따라서 DFA로 표현하는 모든 언어는 NFA로도 표현된다.

반대쪽은 부분집합 구성으로 모든 ε-NFA에 유한 DFA를 만들 수 있다. 그러므로 DFA, NFA, ε-NFA가 수락하는 언어 종류는 모두 같다. 이를 정규언어라고 한다. 비결정성은 유한 상태 모델에서 언어 종류를 더하지 않지만, 언어의 조건을 작게 기술하고 조합하는 데 도움을 준다.

작은 기술과 큰 결정화

Σ={0,1}에서 끝에서 n번째 문자가 1인 언어를 생각하자. n은 기계를 설계할 때 고정한 양의 정수다. NFA는 접두사를 읽으며 시작 상태에 머물다가 1을 보았을 때 그 위치가 끝에서 n번째라고 선택하고 이후 정확히 n−1문자를 세는 n+1상태 기계를 만들 수 있다.

그 선택이 맞는 경로 하나라도 입력 끝에 맞춰 수락하면 된다. DFA는 최근 n개 비트를 구분해야 하며 적어도 2^n개 구별 가능한 상태가 필요하다. 그래서 같은 정규언어라도 작은 NFA와 훨씬 큰 DFA가 있을 수 있다. 이것은 수락 언어의 종류가 다르다는 주장이 아니라 표현 크기의 차이다.

모든 문제를 해결한다는 뜻은 아니다

유한 상태 기계의 동치는 임의 깊이 괄호 짝맞춤이나 {a^k b^k | k≥0}까지 정규언어라는 뜻이 아니다. 임의의 k를 저장해야 하는 조건은 유한 상태만으로 구분할 수 없는 접두사들을 만든다. 길이 상한을 미리 고정하면 별도의 유한 언어가 되어 기계로 표현할 수 있으므로 무한 길이 조건을 명시해야 한다.

수학적 NFA를 시뮬레이션할 때는 가능한 상태 집합을 유지할 수도 있고, 선택 경로를 하나씩 탐색할 수도 있다. 서로 다른 구현은 수행 비용이 다르며 경로 재탐색 방식은 느려질 수 있다. 언어 동치만으로 프로그램의 속도·메모리·보안 특성을 결론내리지 않는다. 여기서는 이론 모형만 종이로 다룬다.

중간 과정을 따라가는 예제

n=2, 즉 끝에서 두 번째 비트가 1인 언어의 NFA를 만들고 110과 101을 추적하라. 시작 u는 0,1 자기 전이, u에서 1로 v도 이동, v는 0,1 모두 f로 이동, 수락 f의 이후 전이는 없다.

  1. 시작 집합 {u}. 110의 첫 1은 {u,v}, 다음 1은 u의 {u,v}와 v의 {f}를 합쳐 {u,v,f}다.
  2. 마지막 0은 u→u와 v→f가 남아 {u,f}다. f가 있어 110을 수락하며 끝에서 둘째 1과 일치한다.
  3. 101은 첫 1 뒤 {u,v}, 0 뒤 {u,f}, 마지막 1 뒤 {u,v}다. f가 없어 거절하며 끝에서 둘째 0과 일치한다.
  4. 도달 집합은 {u},{u,v},{u,f},{u,v,f}의 네 가지다. NFA는 3상태지만 최근 두 비트를 구별하는 DFA는 네 가지 미래 행동이 필요하다.

110은 수락, 101은 거절. 같은 언어를 서로 다른 상태 수로 기술한다.

종이와 본문으로 직접 해보기

n=2 NFA에서 ε,1,10,11,01을 판정하라. 그리고 길이 2 접두사 00,01,10,11이 서로 다른 DFA 상태여야 하는 이유를 찾아라.

힌트 보기

길이가 2보다 짧으면 끝에서 둘째 문자가 없다. 두 접두사의 첫 비트가 다르면 접미사 ε, 둘째 비트가 다르면 접미사 0을 사용한다.

풀이 보기

ε와 1은 거절, 10과 11은 수락, 01은 거절이다. 길이 2 접두사 둘의 첫 비트가 다르면 빈 접미사로 현재 수락이 달라진다. 첫 비트가 같고 둘째가 다르면 0을 뒤에 붙여 원래 둘째가 끝에서 둘째가 되므로 수락이 달라진다. 따라서 네 접두사 모두 미래 구별이 필요하다.

오해와 반례

NFA는 DFA보다 더 많은 종류의 언어를 수락한다.

부분집합 구성으로 모든 NFA의 언어에 DFA가 존재한다. 차이는 크기와 설계 편의다. 예를 들어 끝에서 둘째 1 언어는 NFA 3상태와 DFA 4상태로 표현되며 어느 쪽도 {a^k b^k | k≥0}의 임의 카운트를 유한 기억으로 처리하지 못한다.

한 단계 더

일반 n에서 2^n 상태 하한을 증명하라. 서로 다른 길이 n 비트열 x,y의 다른 위치 i(왼쪽부터 1)를 택하고 0^(i−1)을 붙인다. 길이는 n+i−1이고 끝에서 n번째 위치가 원래 i가 되어 x,y의 수락이 갈린다. 따라서 모든 2^n 접두사는 서로 다른 미래 언어를 갖는다. 또한 a^0,a^1,…의 접두사를 같은 DFA 상태에 합치면 a^i와 a^j(i<j)에 b^i를 붙였을 때 하나만 같은 개수로 맞으므로 {a^k b^k}는 유한 DFA로 표현할 수 없다.
