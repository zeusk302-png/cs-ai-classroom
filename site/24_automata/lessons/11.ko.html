소단원 11.1

대각선 논법

목록의 모든 줄과 적어도 한 칸씩 다른 새 줄을 만들 수 있을까?

준비 개념과 학습 목표

준비 개념

  • 반증법
  • 집합의 원소 여부
  • 유한 문자열 인코딩

학습 목표

  • 대각선 반전이 각 행과 다른 이유를 설명한다.
  • 유한 표의 예시와 무한 목록의 증명을 구분한다.
  • 모든 언어의 목록과 모든 기계의 목록을 구별한다.

모든 줄을 담았다는 가정에 도전한다

자연수 순서로 무한한 0/1열을 나열하여 모든 가능한 열을 담았다고 가정하자. i번째 줄의 i번째 값을 읽고 반대로 바꾼 값을 새 열의 i번째 칸에 넣는다. 새 열은 각 i번째 줄과 그 줄의 i번째 칸에서 다르다. 따라서 어느 줄과도 같지 않아 모든 열을 담았다는 가정이 모순이다.

이 논증은 새 열이 목록 전체와 한꺼번에 모든 칸에서 다르다고 말하지 않는다. 각 줄마다 하나의 다른 칸을 지정하면 충분하다. 유한 표에서는 같은 반전을 연습할 수 있지만 유한한 몇 줄만 비교한 계산이 무한 집합의 증명을 대신하지는 않는다.

유한 프로그램과 무한한 답의 배열은 다르다

유한 알파벳의 유한 문자열은 길이 순서와 같은 길이의 사전 순서로 셀 수 있다. 프로그램이나 튜링기계 설명을 이런 문자열로 인코딩하므로 가능한 기계 설명은 가산이다. 모든 설명이 유효할 필요는 없고 유효하지 않은 설명은 검사하여 제외하거나 일정한 기계로 대응시킬 수 있다.

각 언어는 모든 입력 문자열에 대해 속하면1, 아니면0인 무한 열로 생각할 수 있다. 가능한 모든 언어는 위 대각선 논법으로 가산 목록에 전부 들어가지 않는다. 기계는 가산인데 언어는 그렇지 않으므로 모든 언어를 인식하는 기계가 존재할 수는 없다. 이것은 구체적으로 어떤 언어가 어려운지 찾는 증명과는 별개의 존재 논증이다.

기계를 나열해도 답 표가 자동으로 계산되지는 않는다

기계 설명 목록을 만들 수 있어도 각 기계가 모든 입력에서 수락하는지 알려 주는 표를 끝까지 계산할 수 있다는 뜻은 아니다. 실제 시뮬레이션은 무한히 실행될 수 있다. 대각선을 뒤집는 수학적 정의와 그 값을 항상 유한 시간에 내는 프로그램의 존재를 구별한다.

다음 소단원은 모든 기계·입력의 정지 여부를 항상 맞게 답한다는 더 구체적인 가정을 놓고 모순을 만든다. 자기 설명을 입력으로 사용한다는 것은 기계가 자기 소스 코드를 마법처럼 알아낸다는 뜻이 아니라 인코딩 문자열을 보통의 입력으로 받는다는 뜻이다.

중간 과정을 따라가는 예제

네 줄의 처음 네 칸이 r1=0011,r2=1100,r3=1010,r4=0110이다. 대각선을 뒤집어 네 칸의 새 줄을 만들고 각 줄과 다른 위치를 표시하라.

  1. 대각선은 r1첫칸0,r2둘째칸1,r3셋째칸1,r4넷째칸0으로0110이다.
  2. 반전하면1001이다.
  3. r1과첫칸1대0, r2와둘째0대1, r3와셋째0대1, r4와넷째1대0에서 다르다.

새 앞부분1001은 제시한 네 앞부분 어느 것과도 같지 않다. 무한한 모든 열의 목록이라고 가정하면 같은 방법이 각 행에 적용되어 모순이 된다.

종이와 본문으로 직접 해보기

풀이 보기

소단원 11.2

정지 문제

프로그램을 오래 실행하는 대신 언제 끝날지 언제나 맞게 알려 주는 검사기는 가능할까?

준비 개념과 학습 목표

준비 개념

  • 튜링기계 인코딩
  • 반증법
  • 대각선 반전

학습 목표

  • 정지와 수락을 구별한다.
  • 항상 정확하고 종료하는 판정기를 가정해 모순을 만든다.
  • 인식 가능성과 시간 제한 검사의 한계를 설명한다.

정지에는 수락과 거절이 모두 들어간다

HALT는 튜링기계 M과 입력 w의 인코딩쌍에서 M이 w에서 결국 멈추는지를 묻는 언어다. 멈추며 수락해도, 멈추며 거절해도 HALT의 예다. 수락 여부를 묻는 A_TM과 구별한다. 정지 판정기는 모든 입력에서 스스로 종료하며 예·아니오를 정확히 답해야 한다.

시뮬레이션으로 M이 멈추는 경우에는 그 사실을 발견할 수 있다. 멈추지 않는 경우에는 기다리기만 해서 유한 시간에 아니오를 확정하지 못한다. 이를 통해 정지 언어는 인식 가능하지만 판정 가능과 같지는 않다는 차이를 생각할 수 있다. 유효하지 않은 인코딩은 검사해 아니오로 처리하도록 규칙을 정한다.

검사기의 답과 반대로 행동하는 기계

모든 기계·입력에 맞는 정지 판정기 H가 있다고 가정한다. 새 기계 D는 입력 문자열 x가 유효한 기계 설명이면 H(x,x)를 호출한다. H가 정지한다고 답하면 D는 끝없이 실행하고, H가 멈추지 않는다고 답하면 D는 즉시 정지한다. 유효하지 않은 설명이면 즉시 정지하도록 정한다.

H가 항상 종료한다는 가정 덕분에 D의 분기가 실제로 수행된다. 이제 D 자신의 유한 설명d를 D의 입력으로 준다. H(d,d)의 어느 답도 D의 행동과 맞지 않는다. 따라서 그런 완전한 정지 판정기 H는 존재하지 않는다. D를 만드는 단계는 가정한 H를 이용한 논리 구성이지 실제 완전 검사기를 구현한 결과가 아니다.

일반 불가능성과 개별 증명을 구별한다

정지 문제의 판정 불가능성은 모든 프로그램과 입력에 적용되는 완전한 절차의 부재다. 특정 반복문이 카운터를 줄여 끝남을 증명하거나 명백한 무한 반복을 판정하는 개별 작업을 금지하지 않는다. 제한된 프로그램 집합이나 유한 상태 모델에서는 다른 판정 절차가 가능할 수 있다.

T단계까지 멈추지 않았다는 관찰은 T+1단계에 멈추는 기계를 배제하지 못한다. 시간 제한 검사기가 모름을 반환하거나 특정 범위만 보장하면 유용할 수 있다. 그러나 항상 정확한 예·아니오와 모든 입력 종료를 약속하는 정지 판정기의 계약과 같다고 부르지 않는다.

중간 과정을 따라가는 예제

가정한 H가 D의 자기 입력d에 YES 또는 NO를 답하는 두 경우를 모두 추적하여 모순을 설명하라.

  1. YES는D(d)가정지한다는 주장이다. 그러나D는그답을받고무한반복하므로정지하지않는다.
  2. NO는D(d)가정지하지않는다는 주장이다. 그러나D는그답을받고즉시정지한다.
  3. 모든 경우에서정확성 가정과행동이충돌한다.

항상 종료하며 모든 인코딩쌍에 정확한 H는 존재하지 않는다. 특정 입력이 어려워 시간이 부족했다는 경험적 결론이 아니다.

종이와 본문으로 직접 해보기

기계R은 즉시 거절하고 기계L은 무한히 반복한다. 둘을 같은 입력w로 실행하면 HALT와 A_TM에 대한 참·거짓은? 100단계 제한이L과101단계 후 정지하는기계S를 구별할 수 있는가?

힌트 보기

풀이 보기

오해와 반례

정지 문제를 못 푼다는 것은 어떤 프로그램이 끝나는지도 절대 증명할 수 없다는 뜻이다.

예컨대 n≥0에서 n을1씩 줄여0에서 끝나는 반복은 감소량과 하한으로 종료를 증명할 수 있다. 불가능한 것은 모든 튜링기계·입력을 항상 맞게 답하는 완전한 절차다.

100단계 미정지는영원한미정지인가?

한 단계 더

HALT의인식기는M(w)를시뮬레이션하다정지하면YES를낸다. 만약보완언어의인식기도있다면두기계를번갈아한단계씩실행해어느쪽이YES를내는지알수있다. 모든유효입력은둘중하나에속하므로이절차는판정기가된다. 정지판정불가능성과모순이므로보완언어는인식가능하지않다. 한쪽전체실행뒤다른쪽실행은무한대기때문에같은구성이아니다.

매핑 환원과 Rice 정리

새 문제를 푸는 도구가 있으면 이미 불가능한 문제까지 풀게 되는가?

준비 개념과 학습 목표

준비 개념

  • 판정과인식
  • 언어L(M)
  • 정지문제

학습 목표

  • Rice정리의언어의미와비자명조건을확인한다.

입력을전환해같은예·아니오를묻는다

A≤mB는모든입력x에서종료하는계산가능함수f가있어x∈A와f(x)∈B가동치라는뜻이다. f를계산한뒤B판정기를호출하면A도판정할수있다. 따라서A가판정불가능하고A≤mB를보이면B도판정불가능하다. B≤mA만보인것으로B의판정불가능성을결론내릴수는없다.

매핑환원은예뿐아니라아니오도보존하고하나의입력을다른문제의입력으로바꾼다. 변환기가원래정지여부를먼저판정한다면필요한계산가능변환을구성한것이아니다. 이단원의환원은시간복잡도를제한하지않으며다항시간환원과조건을섞지않는다.

실행하지않고새기계의설명을만든다

NONEMPTY={⟨N⟩|L(N)≠∅}라하자. ⟨M,w⟩에서기계N의설명을만든다. N은어떤입력z에서도M(w)를시뮬레이션하고M이멈추면z를수락한다. M이멈추지않으면N도계속시뮬레이션한다. M의유한설명과w를N에삽입하는작업은항상종료한다.

M(w)가정지하면N은모든z를수락해L(N)=Σ*다. 정지하지않으면아무z도수락하지않아L(N)=∅다. 따라서HALT≤mNONEMPTY이며NONEMPTY가판정불가능하다. 새설명을출력하는변환과그새기계를나중에실행하는단계를분리하는것이핵심이다.

Rice정리는언어의내용에대한비자명성질이다

Rice정리의언어형은튜링기계가인식하는언어의비자명한성질을기계설명에서판정하는문제가판정불가능하다고말한다. 같은언어를인식하는다른기계라도성질값이같아야하고, 성질을만족하는인식가능언어와만족하지않는언어가모두있어야한다. 예컨대언어의공집합여부·유한성·특정문자열의포함여부는이조건을점검할수있다.

상태가몇개인지처럼설명의형식만보는문제에는이정리를그대로적용하지않는다. 모든입력에서정지한다는기계성질도인식언어만으로결정되지않아언어형Rice의직접대상이아니다. 같은공집합을인식하면서한기계는항상거절정지하고다른기계는항상반복할수있다. Rice는그런문제가판정가능하다고말하는것도아니며별도논증이필요하다는뜻이다.

중간 과정을 따라가는 예제

위환원에서M1은w에서즉시거절정지하고M2는w에서무한반복한다고하자. 각생성기계N1/N2의언어와NONEMPTY답을구하고환원의방향을설명하라.

  1. M1은수락하지않아도정지한다. N1은시뮬레이션종료뒤모든z를수락하므로Σ*다.
  2. M2는끝나지않아N2가아무z도수락하지못하므로∅다.
  3. HALT의참/거짓이NONEMPTY의참/거짓으로보존되어HALT≤mNONEMPTY다.

N1은비공집합YES, N2는NO다. NONEMPTY판정기가있으면정지여부까지판정할수있다는모순이성립한다.

종이와 본문으로 직접 해보기

성질①L(N)에문자열01이포함됨,②N의상태수가10개이상,③L(N)의모든문자열길이가0이상임에Rice언어형을적용할수있는지검사하라.

힌트 보기

같은언어의기계에서값이같은지와YES/NO언어가모두있는지나눈다.

풀이 보기

①은언어성질이고{01}는YES,∅는NO라적용가능하다.②는기계형식이며같은언어에사용하지않는상태를추가해바뀔수있으므로직접적용하지않는다.③은모든언어에서참인자명성질이라적용하지않는다.

오해와 반례

Rice정리는프로그램에대한모든질문이판정불가능하며환원은어느방향으로해도충분하다는뜻이다.

형식검사와자명언어성질은정리범위에서제외된다. 이미불가능한A를새문제B로바꾸는A≤mB가필요하다. 새문제를어려운문제로보내는역방향은같은결론을주지않는다.

한 단계 더

Rice의일반구성을살펴보자. 비자명성질P에서P(∅)=거짓이면P를만족하는인식기K를하나고른다. N은M(w)가정지한뒤K(z)를실행한다. 언어는정지시L(K),미정지시∅라P판정기로HALT를푼다. P(∅)=참이면비자명한보완성질에같은논증을적용한다. K(z)는거절하거나반복할수있으며N이모든입력에서정지해야한다는요구는없다.
