소단원 7.1

스택과 전이

순서대로 쌓은 기억을 마지막 것부터 꺼내면 무엇을 검사할 수 있을까?

준비 개념과 학습 목표

준비 개념

  • 유한 오토마타는 유한한 상태로 이동한다.

  • 스택은 마지막에 넣은 기호를 먼저 꺼내는 기억이다.

학습 목표

  • 상태/남은 입력/스택 구성을 추적한다.

  • 입력 끝과 수용 조건을 함께 확인한다.

유한 상태에 기억 더하기

PDA는 유한 상태와 한 개의 이론적 무제한 스택을 가진다. 현재 상태·남은 입력·스택 전체를 구성(configuration)으로 기록하면 처리 과정을 재현할 수 있다. 스택 알파벳은 입력 알파벳과 달라도 된다.

이 단원은 스택 최상단을 문자열의 왼쪽에 쓰고 바닥 기호 Z를 오른쪽에 둔다. AA Z는 A가 두 개 쌓였다는 뜻이다. 실제 컴퓨터의 유한 메모리를 무제한이라고 주장하는 것이 아니라 인식 모형을 정의한다.

기호 하나를 치환하기

전이(q,a,X)→(r,γ)는 입력 a를 하나 소비하고 최상단 X를 γ로 바꾸며 상태 r로 이동한다. γ의 왼쪽 기호가 새 최상단이다. γ=ε면 pop, γ=AX면 X를 보존하고 A를 쌓는 효과다.

입력 칸a=ε인 전이는 입력을 소비하지 않는다. 최상단 치환과 입력 소비는 별개이며 ε를 실제 입력 문자로 세지 않는다. 스택 문자열을 실제 push 명령으로 만들 때는 오른쪽 기호부터 넣어 왼쪽이 맨 위가 되도록 한다.

수용 조건을 고정하기

아래 기계는 입력 끝 표시$를 포함한 확장 입력을 모두 소비하고 최종 상태 f에 도달하면 수용한다. 바닥 Z는 남아 있다. 최종 상태 수용과 빈 스택 수용은 다른 규약이며 각 기계의 조건을 섞지 않는다.

a의 개수를 A로 기억하다가 b마다 하나 꺼내면 a^n b^n을 비교할 수 있다. b를 읽기 시작한 뒤 a를 다시 허용하면 순서 조건을 잃으므로 push 상태 p와 pop 상태 r를 분리한다. 없는 전이는 경로를 멈춘다.

  1. 초기(p,aabb$,Z). a 두 개를 읽어(p,abb$,AZ)→(p,bb$,AAZ)다.

  2. 첫 b는(p,bb$,AAZ)→(r,b$,AZ),둘째 b는(r,b$,AZ)→(r,$,Z)다.

  3. $,Z 전이로(f,ε,Z)에 도달한다. 입력을 모두 소비하고 최종 상태 f이므로 수용한다.

aabb$ 수용. 최대 A깊이는 2이며 바닥 Z까지 세면 스택 기호 최대 3 개다.

오해와 반례

최종 상태에 한 번 도착하면 남은 입력과 관계없이 수용이다.

정의는 전체 입력 소비를 요구한다. f에서 더 읽는 전이가 없으므로 $ 뒤 기호가 남는 문자열은 이 확장 입력 언어에 속하지 않는다.

소단원 7.2

CFG·PDA 대응

문법의 아직 해야 할 일을 스택에 쌓아 둘 수 있을까?

준비 개념과 학습 목표

준비 개념

  • CFG 생산규칙은 비단말 하나를 기호 문자열로 바꾼다.

  • 유도는 시작 기호에서 단말 문자열을 만드는 과정이다.

학습 목표

  • CFG 생산규칙을 스택 치환으로 연결한다.

  • 생성/검사의 대응과 비결정적 선택을 구별한다.

해야 할 일을 순서대로

CFG의 미완성 비단말은 앞으로 생성할 부분을 나타낸다. PDA 스택을 아직 읽어야 할 기호 목록으로 해석하면 비단말을 생산규칙 오른쪽 문자열로 치환하고 단말은 입력과 맞춰 제거한다.

일반 변환은 생산규칙마다 선택지를 두므로 NPDA다. 기호가 같은 경우만 단말을 소비한다. 시작 스택SZ이며 S가 최상단이다. 모든 입력을 소비하고 스택이 비면 수용하는 규약을 여기서 사용한다. 앞 소단원의 최종 상태/$ 규약과 구별한다.

확장과 매칭의 두 전이

규칙 A→X1…Xk마다 (q,ε,A)→(q,X1…Xk)를 둔다. 실제 push 동작으로 구현한다면 Xk부터 역순으로 넣는다. A→ε는 비단말을 꺼내며 입력을 읽지 않는다.

각 단말 a에 (q,a,a)→(q,ε)를 둬 일치할 때만 입력과 스택 단말을 함께 제거한다. 바닥 Z는 (q,ε,Z)→(q,ε)로 제거한다. 너무 이른 바닥 제거도 입력이 남아 있으면 수용이 되지 않는다.

양방향 대응의 의미

주어진 문법의 성공 유도는 그 규칙을 선택하고 단말을 매칭하는 수용 경로로 옮길 수 있다. 거꾸로 성공 경로에서 비단말 확장 사건을 읽으면 입력 문자열의 유도가 된다. 실패 경로가 있어도 성공 경로 하나가 있으면 NPDA 수용이다.

일반적으로 NPDA가 인식하는 언어와 CFG가 생성하는 언어는 정확히 같다. PDA→CFG 역변환은 스택 기호를 넣고 꺼내는 상태 사이 구간을 비단말로 기술하는 별도 구성이다. 여기서는 정리를 소개하며 모든 기계의 역변환 증명을 짧은 예제 하나로 대체했다고 하지 않는다.

중간 과정을 따라가는 예제

S→aSb|ε,스택 왼쪽 최상단, 시작SZ인 위 NPDA에서 aabb를 수용하는 경로를 쓰고 문법 유도와 연결한다.

  1. S⇒aSb⇒aaSbb⇒aabb가 문법 유도다. 스택SZ를aSbZ로 ε치환한 뒤 입력 a를 맞춰 SbZ로 만든다.

  2. 다시 S를aSb로 바꾸어 aSbbZ,두 번째a를 소비하여 SbbZ다. S→ε를 선택하여 bbZ가 된다.

  3. 남은 입력bb를 차례로 매칭해 bZ→Z,바닥을 ε제거하여 입력/스택 모두 빈 상태가 된다.

문법은 두 번 aSb 확장 후 ε를 선택한다. NPDA는 같은 확장 사건과 네 단말 매칭으로 aabb를 수용한다.

종이와 본문으로 직접 해보기

같은 문법에서 ab와 abb를 검사한다. 처음부터 S→ε를 고른 ab 경로가 실패한다고 전체 기계가 ab를 거부하는가?

힌트 보기

ab는 한 번 확장하고 S를 지운다. abb는 생성되는 a/b 수 불변식을 확인한다.

풀이 보기

ab:SZ→aSbZ→SbZ→bZ→Z→ε이며 단말a,b를 소비한다. abb는 a/b 수가 다르므로 어떤 성공 유도도 없다. 처음 ε를 고른 ab 경로는 남은 입력 때문에 실패하지만 다른 수용 경로가 있어 전체는 수용이다.

오해와 반례

스택에 aSb를 만들려면 a,S,b 순으로 push한다.

단순 push에서 a를 먼저 넣으면 b가 맨 위가 된다. b,S,a 순으로 넣어 a부터 읽도록 해야 한다. 문자열 치환 표기와 명령 수행 순서를 구별한다.

생산규칙 확장은 ε 입력 전이다.

한 단계 더

문법 S→(S)S|ε로 ()()의 유도를 만들고 스택 치환을 적는다. 연속 부분을 위해 뒤S가 남는다는 점을 확인한다. 일반 CFG→NPDA의 선택지가 있다고 모든 해당 언어가 비결정성이 필수인 것은 아님도 다음 소단원과 연결한다.

소단원 7.3

결정적·비결정적 PDA

문자열의 중간을 모르면 언제부터 스택을 꺼내야 할까?

준비 개념과 학습 목표

준비 개념

  • DPDA는 각 구성에서 가능한 다음 행동이 최대 하나다.

  • NPDA는 선택 경로 중 하나라도 전체 입력 수용이면 수용한다.

학습 목표

  • ε선택과 입력 소비 선택의 충돌을 설명한다.

  • 결정적 구현 하나의 실패와 언어 불가능 증명을 구별한다.

선택 하나라는 정확한 조건

표준 ε-PDA에서 상태q·최상단 X·입력 a의 전이 결과가 둘 이상이면 결정적이지 않다. 또 같은 q,X에 ε전이가 가능하면 입력을 읽는 전이가 경쟁해서는 안 된다. 입력 칸마다 한 화살표뿐이어도 이 충돌로 NPDA가 될 수 있다.

결정성은 성공 사례의 경로가 우연히 하나였다는 뜻이 아니라 가능한 모든 구성에서 규칙이 충돌하지 않는다는 구조 조건이다. 없는 전이는 멈춤이며 ε순환은 입력 소비 없이 계속될 수 있다. 결정적이라는 말만으로 항상 종료함을 보장하지 않는다.

가운데 표지를 사용하기

0/1 문자열w에 대해 w#w의 역순을 검사하면 #가 push와pop 단계의 경계를 알려 준다. #전에는 입력 기호를 쌓고 #뒤에는 같은 최상단일 때만 꺼낸다. $끝에서 바닥 Z이면 최종 상태로 간다.

#가 없는 ww의 역순을 NPDA로 검사하려면 중간을 ε전이로 추측할 수 있다. push를 계속할지 pop상태로 갈지 선택하며 틀린 분기는 실패한다. 한 개의 성공 추측이면 수용한다. 짝수 길이와 기호 일치 조건을 모두 확인한다.

언어의 힘과 구성 선택

유한 오토마타에서는 NFA와 DFA의 언어 범위가 같지만 한 스택 PDA에서는 DPDA 언어가 NPDA 언어의 진부분집합이다. CFG의 일반 변환이 NPDA를 만드는 사실과 모든 CFG 언어에 DPDA가 존재한다는 주장은 다르다.

a^n b^n은 CFG 규칙 선택 변환으로 NPDA를 만들어도 앞 소단원의 단계 기계로 결정적으로 검사할 수 있다. 특정 비결정적 그림만 보고 그 언어는 DPDA로 불가능하다고 단정하지 않는다. 아래 유한 추적은 중간 추측의 역할을 보여 주며 진부분집합 정리의 완전한 증명은 아니다.

자체 표지 기계에서 입력01#10$를 검사한다. push상태 p에서0/1을 각각스택에 쌓고#에 pop상태 r로 간다. r에서는 같은0/1만 pop, $,Z에서f다.

  1. 초기Z,0읽어0Z,1읽어10Z다. #를 읽을 때스택10Z를 보존하고r로 간다.

  2. r에서1읽어0Z,0읽어Z다. 마지막$에서f로 가서 전체 소비했다.

  3. 01#01$이면#뒤 첫0에 최상단1이라 전이가 없어서 실패한다. 중간 표지가 있어 언제 pop을 시작할지 경쟁이 없다.

01#10$는 수용,01#01$는 거부다. #와$는0/1과 구별되는 확장 입력 기호다.

종이와 본문으로 직접 해보기

표지 없는0110의 NPDA에서 읽은 기호를push하다 ε로pop상태에 전환한다고 하자. 한 기호 뒤와 두 기호 뒤에 전환한 경로를 각각 추적한다. 이 활동은 전체 입력 소비 후 바닥 Z를 ε로 제거하여 빈 스택이면 수용하는 규약이다. p에서는 push와 r로의 ε전환이 경쟁하고 r에서는 입력과 최상단이 같을 때만 pop한다.

힌트 보기

성공하려면 남은 입력이 쌓인 기호의 역순이어야 한다. 전환 자체는 입력을 소비하지 않는다.

풀이 보기

한 기호 0 뒤 stack0Z/남은110에서pop을 시작하면 첫1이0과 달라 실패한다. 두 기호 01 뒤 stack10Z/남은10이면1과0을 차례로pop하여Z가 되어 성공한다. 같은 입력에 실패/성공 분기가 공존한다.

오해와 반례

전이표의 각 입력 칸에 한 행동이면 언제나 DPDA다.

같은 q,X에 ε전이와0입력 전이가 각각 하나 있어도 실제 입력이 0이면 둘이 경쟁한다. ε기호를 실제 입력으로 생각하면 이 충돌을 놓친다.
