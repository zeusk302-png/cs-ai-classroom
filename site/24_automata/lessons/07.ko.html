소단원 7.1

스택과 전이

순서대로 쌓은 기억을 마지막 것부터 꺼내면 무엇을 검사할 수 있을까?

준비 개념과 학습 목표

준비 개념

  • 유한 오토마타는 유한한 상태로 이동한다.

  • 스택은 마지막에 넣은 기호를 먼저 꺼내는 기억이다.

학습 목표

  • 상태/남은 입력/스택 구성을 추적한다.

  • 입력 끝과 수용 조건을 함께 확인한다.

스택의 왼쪽과 실제 push 순서를 바꾸면 같은 기계를 구현할까?

새 기계 M은 입력 alphabet {0,1,#,$}를 사용한다. #는 중간 구분자이고 $는 마지막 입력 기호다. 시작 상태 p, 비교 상태 r, 승인 상태 f와 바닥 Z를 둔다. 스택은 왼쪽이 top인 문자열이다. p에서 bit a를 읽으면 기존 top X를 aX로 바꾸며, #에서는 X를 유지하고 r로 간다. r에서는 입력 bit와 top bit가 같을 때만 둘을 함께 소비한다. r에서 $와 Z가 만나면 $를 소비하고 f로 간다. f에는 출구가 없다.

M의 승인 입력은 w#wᴿ$ 꼴이며 w는 임의의 유한 이진 열이고 wᴿ은 w의 역순이다. bit를 읽을 때마다 가장 최근 bit를 왼쪽에 쌓으므로 비교 상태에서는 최근 bit부터 확인한다. #와 $는 bit가 아니며 서로 다른 역할을 맡는다. 빈 w의 입력은 #$다.

전이 δ(p,0,1)=(p,01)은 top 1을 제거한 뒤 문자열 01로 교체한다. 오른쪽이 top인 실제 저장 구조에 push 함수를 여러 번 호출한다면 1을 먼저, 0을 나중에 넣어야 결과의 top이 0이다. 전이의 교체 문자열을 왼쪽부터 push하면 역순이 되어 의미가 달라진다.

이 단원의 승인은 입력 전체 소비와 최종 상태 f를 동시에 요구한다. 0#0$1은 f를 방문하지만 입력 1이 남으므로 거부한다. 바닥만 남았다는 사실도 #를 읽고 비교 단계에 도달했다는 조건을 대신하지 못한다. ε 이동은 입력을 소비하지 않는 이동이며 실제 입력 문자 #와 혼동하지 않는다.

먼저 확인할 개념
  • 교체 문자열과 스택 top

    기본 전이의 X를 제거하고 γ로 교체하는 뜻을 bit 순서에 적용한다.

  • 표식이 있는 역순 비교

    기본 구분자 기계의 소비 단계와 비교 단계를 새 오류 입력에 적용한다.

유한 상태에 기억 더하기

PDA는 유한 상태와 한 개의 이론적 무제한 스택을 가진다. 현재 상태·남은 입력·스택 전체를 구성(configuration)으로 기록하면 처리 과정을 재현할 수 있다. 스택 알파벳은 입력 알파벳과 달라도 된다.

이 단원은 스택 최상단을 문자열의 왼쪽에 쓰고 바닥 기호 Z를 오른쪽에 둔다. AA Z는 A가 두 개 쌓였다는 뜻이다. 실제 컴퓨터의 유한 메모리를 무제한이라고 주장하는 것이 아니라 인식 모형을 정의한다.

기호 하나를 치환하기

전이(q,a,X)→(r,γ)는 입력 a를 하나 소비하고 최상단 X를 γ로 바꾸며 상태 r로 이동한다. γ의 왼쪽 기호가 새 최상단이다. γ=ε면 pop, γ=AX면 X를 보존하고 A를 쌓는 효과다.

입력 칸a=ε인 전이는 입력을 소비하지 않는다. 최상단 치환과 입력 소비는 별개이며 ε를 실제 입력 문자로 세지 않는다. 스택 문자열을 실제 push 명령으로 만들 때는 오른쪽 기호부터 넣어 왼쪽이 맨 위가 되도록 한다.

수용 조건을 고정하기

아래 기계는 입력 끝 표시$를 포함한 확장 입력을 모두 소비하고 최종 상태 f에 도달하면 수용한다. 바닥 Z는 남아 있다. 최종 상태 수용과 빈 스택 수용은 다른 규약이며 각 기계의 조건을 섞지 않는다.

a의 개수를 A로 기억하다가 b마다 하나 꺼내면 a^n b^n을 비교할 수 있다. b를 읽기 시작한 뒤 a를 다시 허용하면 순서 조건을 잃으므로 push 상태 p와 pop 상태 r를 분리한다. 없는 전이는 경로를 멈춘다.

각 행은 새 기계 M의 전이 한 번 뒤다. bit를 쌓을 때와 비교할 때 모두 입력을 한 기호씩 소비한다. 표의 스택 길이는 바닥 Z를 포함하며 최대 길이는 3이다. # 전이는 스택 길이를 바꾸지 않는다.

중간 과정을 따라가는 예제

n≥0의 a^n b^n$를 인식하는 자체 기계: p에서 a,X→p,AX(X=A 또는Z), p에서 b,A→r,ε; r에서 b,A→r,ε; p 또는r에서 $,Z→f,Z. 다른 전이는 없다. 입력 aabb$를 추적한다.

  1. 초기(p,aabb$,Z). a 두 개를 읽어(p,abb$,AZ)→(p,bb$,AAZ)다.

  2. 첫 b는(p,bb$,AAZ)→(r,b$,AZ),둘째 b는(r,b$,AZ)→(r,$,Z)다.

  3. $,Z 전이로(f,ε,Z)에 도달한다. 입력을 모두 소비하고 최종 상태 f이므로 수용한다.

aabb$ 수용. 최대 A깊이는 2이며 바닥 Z까지 세면 스택 기호 최대 3 개다.

조건을 바꾸어 비교하기

최종 상태 방문과 승인을 분리한다

M에서 0#0$와 0#0$1의 경로를 비교하라.

  1. 두 입력 모두 0을 쌓고 # 뒤의 0을 pop한 다음 $를 읽어 f에 도달한다. 이때 스택은 Z다.

  2. 첫 입력은 남은 입력이 ε이지만 둘째는 1이다. f에 출구가 없으므로 둘째에는 전체 입력을 소비한 승인 경로가 없다.

0#0$만 승인한다.

비교할 점

승인 상태의 이름만 보고 뒤의 입력을 버리는 검사는 언어를 바꾼다.

교체 문자열의 push 순서를 검사한다

top이 1인 스택 1Z에서 교체 01을 실제 push 두 번으로 구현하라. 잘못된 순서도 비교하라.

  1. 기존 1을 pop하면 Z다. 1을 push한 뒤 0을 push하면 논리 표기는 01Z다.

  2. 0을 먼저 push하고 1을 나중에 push하면 10Z가 된다. 다음 입력 0을 비교할 때 올바른 결과는 일치하지만 잘못된 결과는 불일치다.

실제 push 순서는 1 다음 0이다.

비교할 점

교체 γ의 논리 문자열 순서와 연속 push의 호출 순서는 서로 반대다.

종이와 본문으로 직접 해보기

같은 기계로 ab$,aab$,aba$,$를 추적하고 수용/거부를 설명한다.

힌트 보기

$를 만날 때 최상단Z여야 하고 r에는 a 전이가 없다.

풀이 보기

ab$는AZ→Z→f로 수용. aab$는 마지막에(r,$,AZ)로 $,A 전이가 없어 거부. aba$는(r,a$,Z)에서 a 전이가 없어 거부. $는(p,$,Z)→(f,ε,Z)로 n 0을 수용한다.

오해와 반례

최종 상태에 한 번 도착하면 남은 입력과 관계없이 수용이다.

정의는 전체 입력 소비를 요구한다. f에서 더 읽는 전이가 없으므로 $ 뒤 기호가 남는 문자열은 이 확장 입력 언어에 속하지 않는다.

스스로 풀어보기

먼저 답과 이유를 적고, 필요한 만큼 힌트를 한 단계씩 열어 보세요.

연습 1 · 값과 상태 예측

M에서 10#01$의 전이 수와 바닥을 포함한 최대 스택 길이를 구하라.

힌트 1

모든 전이는 입력 기호 하나를 소비한다.

힌트 2

w의 길이는 2이며 Z도 한 칸이다.

풀이와 답 확인

  1. 입력 길이는 bit 네 개와 표식 두 개로 6이다. 경로는 Z→1Z→01Z→01Z→1Z→Z→Z다.

  2. 두 번째 bit 뒤 스택 길이가 3으로 가장 크다. 모든 비교가 일치한다.

승인하며 전이 수는 6회, 최대 스택 길이는 3이다.

흔한 오답에서 다시 생각하기

#와 $가 스택을 쌓으므로 최대 길이는 5다.

두 표식은 bit push 규칙을 사용하지 않는다.

연습 2 · 오류 찾아 고치기

0#0$1을 f 방문만으로 승인한 검사기를 교정하라.

힌트 1

마지막 남은 입력도 기록한다.

힌트 2

새 전이를 추가하지 않고 승인 조건을 고친다.

풀이와 답 확인

  1. f 방문 시 남은 입력이 1임을 기록한다.

  2. 판정은 f에 도달하고 남은 입력이 ε일 때만 승인하도록 한다. 따라서 이 입력은 거부한다.

최종 상태와 전체 소비 조건을 함께 검사한다.

흔한 오답에서 다시 생각하기

끝에 남은 문자는 이미 승인한 뒤이므로 무시한다.

PDA는 입력의 임의 접두부를 승인하는 것이 아니라 주어진 전체 문자열을 판정한다.

연습 3 · 직접 만들어 보기

M의 # 전이를 상태 p에서 r로 가되 stack X를 그대로 유지하는 δ 표기로 작성하고 #$를 추적하라.

힌트 1

X는 0,1,Z 중 하나다.

힌트 2

빈 w에서는 시작 스택이 Z다.

풀이와 답 확인

  1. 각 X∈{0,1,Z}에 δ(p,#,X)=(r,X)를 둔다.

  2. #$에서 첫 이동 뒤 r/$/Z이며 마지막 $ 이동 뒤 f/ε/Z다.

#$는 전이 2회로 승인한다.

흔한 오답에서 다시 생각하기

빈 w는 bit가 없어 #도 읽을 수 없다.

# 전이는 bit 대신 현재 top을 유지하며 바닥 Z에서도 정의된다.

연습 4 · 선택 심화

선택 심화는 기본 연습 뒤 더 탐구하고 싶을 때 풀어 보세요.

M의 각 승인 입력에서 |w|=n일 때 전이 수와 최대 스택 길이를 일반식으로 논증하라.

힌트 1

두 표식도 입력 길이에 포함한다.

힌트 2

모든 p bit 이동은 한 칸 증가하고 모든 r bit 이동은 한 칸 감소한다.

풀이와 답 확인

  1. 앞 n개 bit, # 한 개, 뒤 n개 bit, $ 한 개를 소비하므로 전체 전이는 2n+2회다.

  2. 스택은 Z의 길이 1에서 n번 증가해 n+1이 된 뒤 감소한다. 표식은 스택을 유지한다.

전이 수는 2n+2회이며 바닥을 포함한 최대 길이는 n+1이다. n=0에서도 두 식이 맞다.

흔한 오답에서 다시 생각하기

출력 없는 이동도 항상 n번 있으므로 전이는 3n+2회다.

새 M에는 ε 이동이 없다. 다른 PDA의 규칙을 섞어 세지 않는다.

내 말로 설명하기

M에서 #를 두 번 읽으면 어떻게 되는가?

설명 기준 확인

첫 # 뒤의 r에는 # 소비 전이가 없으므로 두 번째 #에서 막힌다.

표식이 끝났다면 남은 Z는 오류인가?

설명 기준 확인

이 기계는 Z를 유지한 최종 상태 승인이다. 빈 스택 승인을 사용하는 별도 기계와 구별한다.

한 단계 더

올바른 괄호 언어를 위한 스택 규칙을 제안한다. 여는 괄호에 push, 닫는 괄호에 대응 pop하며 빈 바닥에서 닫는 괄호는 거부한다. 최종 깊이0만으로는 부족함을 )(의 먼저 닫히는 사건으로 설명한다.

준비 개념과 학습 목표

준비 개념

  • CFG 생산규칙은 비단말 하나를 기호 문자열로 바꾼다.

  • 유도는 시작 기호에서 단말 문자열을 만드는 과정이다.

학습 목표

  • CFG 생산규칙을 스택 치환으로 연결한다.

  • 생성/검사의 대응과 비결정적 선택을 구별한다.

a 하나가 b 두 개를 예약하면 스택 길이와 입력 길이는 어떻게 달라질까?

새 CFG G는 S→aSbb | ε이며 목표 언어는 {aⁿb²ⁿ | n≥0}다. 매 재귀 규칙은 왼쪽 a 하나와 나중의 b 두 개를 함께 예약한다. n번 전개하고 S를 지우면 aⁿb²ⁿ이 되고, 이외의 규칙이 없어 다른 완성 형태는 만들지 못한다.

새 NPDA N은 상태 q 하나, 시작 스택 SZ, 입력 alphabet {a,b}, 전체 소비 뒤 빈 스택 승인이다. top S에서는 ε 이동으로 aSbb 또는 ε로 교체할 수 있다. top a와 입력 a가 같으면 소비하며 pop하고 b도 같다. Z는 ε 이동으로 제거할 수 있다. 여기에 #나 $를 추가하지 않는다. 종료 표식이 있는 M의 계약을 N에 그대로 옮기면 다른 입력 언어가 된다.

왼쪽 top에서 aSbb를 저장하려면 실제 push 호출은 b,b,S,a 순서다. S 전개는 입력을 소비하지 않으며 terminal 일치만 입력 위치를 진행한다. 어떤 갈래가 S를 너무 일찍 지워 막히더라도 다른 갈래가 전체 소비와 빈 스택에 도달하면 NPDA는 승인한다.

경로의 ε 이동은 문법 규칙의 적용을 기록한다. terminal 일치 이동은 이미 예약한 글자를 실제 입력과 대조한다. 이 둘을 같은 횟수로 세면 입력 길이와 전이 수를 혼동한다. 아래 최대 길이 계산은 한 번 전개한 뒤 선두 a를 곧바로 소비하는 이 구성의 승인 경로에 관한 것이다.

먼저 확인할 개념
  • 문법 전개와 terminal 일치

    기본 S→aSb의 예약을 새 두 b 예약으로 바꾸어 추적한다.

  • ε 이동과 스택 교체

    입력 위치가 고정된 전개와 실제 terminal 소비를 구별한다.

해야 할 일을 순서대로

CFG의 미완성 비단말은 앞으로 생성할 부분을 나타낸다. PDA 스택을 아직 읽어야 할 기호 목록으로 해석하면 비단말을 생산규칙 오른쪽 문자열로 치환하고 단말은 입력과 맞춰 제거한다.

일반 변환은 생산규칙마다 선택지를 두므로 NPDA다. 기호가 같은 경우만 단말을 소비한다. 시작 스택SZ이며 S가 최상단이다. 모든 입력을 소비하고 스택이 비면 수용하는 규약을 여기서 사용한다. 앞 소단원의 최종 상태/$ 규약과 구별한다.

확장과 매칭의 두 전이

규칙 A→X1…Xk마다 (q,ε,A)→(q,X1…Xk)를 둔다. 실제 push 동작으로 구현한다면 Xk부터 역순으로 넣는다. A→ε는 비단말을 꺼내며 입력을 읽지 않는다.

각 단말 a에 (q,a,a)→(q,ε)를 둬 일치할 때만 입력과 스택 단말을 함께 제거한다. 바닥 Z는 (q,ε,Z)→(q,ε)로 제거한다. 너무 이른 바닥 제거도 입력이 남아 있으면 수용이 되지 않는다.

양방향 대응의 의미

주어진 문법의 성공 유도는 그 규칙을 선택하고 단말을 매칭하는 수용 경로로 옮길 수 있다. 거꾸로 성공 경로에서 비단말 확장 사건을 읽으면 입력 문자열의 유도가 된다. 실패 경로가 있어도 성공 경로 하나가 있으면 NPDA 수용이다.

일반적으로 NPDA가 인식하는 언어와 CFG가 생성하는 언어는 정확히 같다. PDA→CFG 역변환은 스택 기호를 넣고 꺼내는 상태 사이 구간을 비단말로 기술하는 별도 구성이다. 여기서는 정리를 소개하며 모든 기계의 역변환 증명을 짧은 예제 하나로 대체했다고 하지 않는다.

중간 과정을 따라가는 예제

S→aSb|ε,스택 왼쪽 최상단, 시작SZ인 위 NPDA에서 aabb를 수용하는 경로를 쓰고 문법 유도와 연결한다.

  1. S⇒aSb⇒aaSbb⇒aabb가 문법 유도다. 스택SZ를aSbZ로 ε치환한 뒤 입력 a를 맞춰 SbZ로 만든다.

  2. 다시 S를aSb로 바꾸어 aSbbZ,두 번째a를 소비하여 SbbZ다. S→ε를 선택하여 bbZ가 된다.

  3. 남은 입력bb를 차례로 매칭해 bZ→Z,바닥을 ε제거하여 입력/스택 모두 빈 상태가 된다.

문법은 두 번 aSb 확장 후 ε를 선택한다. NPDA는 같은 확장 사건과 네 단말 매칭으로 aabb를 수용한다.

조건을 바꾸어 비교하기

정확한 b 개수와 과잉 입력을 비교한다

N에서 aabbbb와 aabbbbb를 같은 두 재귀 전개로 추적하라.

  1. 두 재귀 뒤 S를 지우면 bbbbZ가 남고 입력은 각각 bbbb와 bbbbb다.

  2. 네 b를 소비하고 Z를 제거하면 첫 입력은 ε이지만 둘째에는 b가 남는다. 더 많은 재귀 전개는 추가 a를 요구하므로 현재 입력과 맞지 않는다.

aabbbb는 승인하고 aabbbbb는 거부한다.

비교할 점

스택이 빈 갈래를 찾았다는 사실만으로 남은 입력을 승인하지 않는다.

이른 실패 갈래를 전체 거부로 오해하지 않는다

입력 abb에서 처음 S→ε를 고른 갈래와 S→aSbb를 고른 갈래를 비교하라.

  1. 처음 S를 지우는 갈래는 Z를 제거해도 입력 abb가 남아 승인하지 못한다.

  2. 재귀 한 번 뒤 a를 소비하고 S를 지운 다음 b 두 개와 Z를 제거하면 전체 입력과 스택이 함께 빈다.

실패 갈래가 있지만 승인 갈래가 있으므로 abb는 승인한다.

비교할 점

NPDA의 승인은 모든 갈래 성공이 아닌 한 승인 경로의 존재다.

종이와 본문으로 직접 해보기

같은 문법에서 ab와 abb를 검사한다. 처음부터 S→ε를 고른 ab 경로가 실패한다고 전체 기계가 ab를 거부하는가?

힌트 보기

ab는 한 번 확장하고 S를 지운다. abb는 생성되는 a/b 수 불변식을 확인한다.

풀이 보기

ab:SZ→aSbZ→SbZ→bZ→Z→ε이며 단말a,b를 소비한다. abb는 a/b 수가 다르므로 어떤 성공 유도도 없다. 처음 ε를 고른 ab 경로는 남은 입력 때문에 실패하지만 다른 수용 경로가 있어 전체는 수용이다.

오해와 반례

스택에 aSb를 만들려면 a,S,b 순으로 push한다.

단순 push에서 a를 먼저 넣으면 b가 맨 위가 된다. b,S,a 순으로 넣어 a부터 읽도록 해야 한다. 문자열 치환 표기와 명령 수행 순서를 구별한다.

연습 1 · 값과 상태 예측

힌트 1

힌트 2

terminal 검사 세 번과 바닥 제거 한 번도 PDA 전이다.

연습 2 · 오류 찾아 고치기

힌트 2

  2. S를 pop한 뒤 b,b,S,a 순서로 push하면 top부터 aSbb가 된다.

호출 순서를 뒤집어 a가 top이 되게 한다.

같은 네 기호를 넣었으므로 순서는 무관하다.

힌트 2

  2. δ(q,a,a)={(q,ε)}, δ(q,b,b)={(q,ε)}를 둔다. 바닥 제거는 별도 δ(q,ε,Z)={(q,ε)}다.

연습 4 · 선택 심화

선택 심화는 기본 연습 뒤 더 탐구하고 싶을 때 풀어 보세요.

N의 aⁿb²ⁿ 승인 경로에서 전체 전이 수와 최대 스택 길이를 n=0과 n≥1로 나누어 구하라.

힌트 1

힌트 2

k번째 재귀 직후는 aSb²ᵏZ다.

풀이와 답 확인

  1. 문법 전개 n회와 종료 1회, terminal 소비 3n회, Z 제거 1회로 전체 전이는 4n+2회다.

  2. n≥1이면 마지막 재귀 직후 aSb²ⁿZ의 길이 2n+3이 최대다. n=0은 재귀가 없어 시작 SZ의 길이 2가 최대다.

흔한 오답에서 다시 생각하기

n=0을 2n+3에 대입하면 최대 길이는 3이다.

그 식은 실제 재귀 전개가 존재할 때 얻은 식이다. 빈 입력에서는 aSbb가 한 번도 나타나지 않는다.

한 단계 더

소단원 7.3

결정적·비결정적 PDA

문자열의 중간을 모르면 언제부터 스택을 꺼내야 할까?

준비 개념과 학습 목표

준비 개념

  • DPDA는 각 구성에서 가능한 다음 행동이 최대 하나다.

  • NPDA는 선택 경로 중 하나라도 전체 입력 수용이면 수용한다.

학습 목표

  • ε선택과 입력 소비 선택의 충돌을 설명한다.

  • 결정적 구현 하나의 실패와 언어 불가능 증명을 구별한다.

다음 이동이 하나뿐이면 반드시 판정이 끝날까?

표준 ε 전이 PDA에서 결정성은 두 조건을 함께 요구한다. 같은 상태·top·입력 기호에 서로 다른 결과가 있으면 안 되고, 같은 상태·top에 ε 전이가 있으면 어떤 입력 소비 전이도 함께 두지 않는다. 두 규칙의 입력 표기가 ε와 0으로 다르다는 이유만으로 충돌이 사라지지 않는다.

새 U는 상태 p, top Z에 δ(p,ε,Z)=(p,Z)와 δ(p,0,Z)=(r,Z)를 모두 둔다. 입력 0에서 ε 이동과 0 소비가 동시에 가능하므로 U는 결정적이지 않다. 소비 전이를 삭제한 V는 다음 이동이 하나뿐이지만 p/Z의 ε 자기 반복 때문에 어떤 입력에서도 판정을 끝내지 않는다. 결정성과 종료는 서로 다른 성질이다.

M은 #로 비교 시점을 정해 ε 이동 없이 bit를 저장하거나 비교한다. 표식 없는 역순 비교 NPDA W는 push 상태에서 언제 compare 상태로 넘어갈지 ε로 추측할 수 있다. 0110에서는 앞 두 bit를 읽은 뒤 전환한 갈래가 성공하지만 앞 한 bit 뒤의 갈래는 실패한다. 이 특정 W가 비결정적이라는 관찰만으로 모든 기계의 불가능성을 증명하지 않는다.

일반 이론에서는 DPDA 언어가 NPDA 언어의 진부분집합이다. 그러나 문법에서 기계로 기계적으로 만든 N이 비결정적이라는 사실은 그 언어에 결정적 기계가 없다는 뜻이 아니다. aⁿb²ⁿ의 경우 앞의 a마다 표식 두 개를 push하고 첫 b부터 pop하며 마지막 $에서 바닥을 검사하는 별도 결정적 설계를 만들 수 있다. 이 $ 버전은 원래 N의 입력 언어에 종료 표식을 추가한 별도 계약이다.

선택 하나라는 정확한 조건

표준 ε-PDA에서 상태q·최상단 X·입력 a의 전이 결과가 둘 이상이면 결정적이지 않다. 또 같은 q,X에 ε전이가 가능하면 입력을 읽는 전이가 경쟁해서는 안 된다. 입력 칸마다 한 화살표뿐이어도 이 충돌로 NPDA가 될 수 있다.

결정성은 성공 사례의 경로가 우연히 하나였다는 뜻이 아니라 가능한 모든 구성에서 규칙이 충돌하지 않는다는 구조 조건이다. 없는 전이는 멈춤이며 ε순환은 입력 소비 없이 계속될 수 있다. 결정적이라는 말만으로 항상 종료함을 보장하지 않는다.

가운데 표지를 사용하기

0/1 문자열w에 대해 w#w의 역순을 검사하면 #가 push와pop 단계의 경계를 알려 준다. #전에는 입력 기호를 쌓고 #뒤에는 같은 최상단일 때만 꺼낸다. $끝에서 바닥 Z이면 최종 상태로 간다.

#가 없는 ww의 역순을 NPDA로 검사하려면 중간을 ε전이로 추측할 수 있다. push를 계속할지 pop상태로 갈지 선택하며 틀린 분기는 실패한다. 한 개의 성공 추측이면 수용한다. 짝수 길이와 기호 일치 조건을 모두 확인한다.

언어의 힘과 구성 선택

유한 오토마타에서는 NFA와 DFA의 언어 범위가 같지만 한 스택 PDA에서는 DPDA 언어가 NPDA 언어의 진부분집합이다. CFG의 일반 변환이 NPDA를 만드는 사실과 모든 CFG 언어에 DPDA가 존재한다는 주장은 다르다.

a^n b^n은 CFG 규칙 선택 변환으로 NPDA를 만들어도 앞 소단원의 단계 기계로 결정적으로 검사할 수 있다. 특정 비결정적 그림만 보고 그 언어는 DPDA로 불가능하다고 단정하지 않는다. 아래 유한 추적은 중간 추측의 역할을 보여 주며 진부분집합 정리의 완전한 증명은 아니다.

시점 추측 불필요

W는 bit마다 push하거나 ε로 비교 상태로 전환하며 비교 상태에서는 일치 bit만 pop한다. 전체 소비 뒤 Z를 제거하는 승인 갈래를 사용한다. 표의 두 갈래는 전체 탐색의 일부이며 하나의 성공 갈래가 승인 증거다.

중간 과정을 따라가는 예제

자체 표지 기계에서 입력01#10$를 검사한다. push상태 p에서0/1을 각각스택에 쌓고#에 pop상태 r로 간다. r에서는 같은0/1만 pop, $,Z에서f다.

  1. 초기Z,0읽어0Z,1읽어10Z다. #를 읽을 때스택10Z를 보존하고r로 간다.

  2. r에서1읽어0Z,0읽어Z다. 마지막$에서f로 가서 전체 소비했다.

  3. 01#01$이면#뒤 첫0에 최상단1이라 전이가 없어서 실패한다. 중간 표지가 있어 언제 pop을 시작할지 경쟁이 없다.

01#10$는 수용,01#01$는 거부다. #와$는0/1과 구별되는 확장 입력 기호다.

입력 표기가 다른 두 규칙도 동시에 가능하다

  1. U는 입력을 그대로 둔 ε 자기 이동과 0을 소비한 r 이동을 모두 허용한다.

  2. V는 소비 이동을 삭제해 ε 이동 하나만 남지만 상태·스택·입력이 매번 그대로여서 무한 반복한다.

U는 비결정적이며 V는 결정적이지만 종료하지 않는다.

중간 시점 추측을 경로 증거로 검사한다

W에서 0110의 전환 위치를 앞 1 bit와 앞 2 bit로 나누어 비교하라.

  1. 앞 한 bit 뒤 스택은 0Z이고 남은 입력은 110이다. 비교 첫 입력 1이 top 0과 달라 막힌다.

  2. 앞 두 bit 뒤 스택은 10Z이고 남은 입력은 10이다. 일치 두 번으로 Z가 남고 입력이 빈 뒤 Z를 제거한다.

두 번째 갈래는 승인 증거지만 첫 번째 갈래는 실패한다.

종이와 본문으로 직접 해보기

문법 기반 N이 비결정적이라는 사실로 aⁿb²ⁿ$에 DPDA가 없다고 결론 내렸다. 무엇이 부족하며 어떤 증거가 반박하는가?

힌트 1

한 구성의 성질과 모든 가능한 구성의 불가능성을 구별한다.

힌트 2

바로 앞 연습의 ε 없는 설계를 사용한다.

풀이와 답 확인

  1. N의 비결정성은 특정 CFG 변환이 선택을 남긴다는 뜻이다. 모든 인식 기계를 배제하는 논증이 아니다.

  2. 앞 설계는 각 구성의 가능한 소비 이동이 하나 이하이고 ε 경쟁이 없으며 정확히 aⁿb²ⁿ$를 승인한다. 이 설계 자체가 불가능성 주장의 반례다.

특정 NPDA의 선택이 있다는 사실만으로 해당 언어의 결정적 인식 불가능성을 증명하지 못한다.

흔한 오답에서 다시 생각하기

DPDA와 NPDA의 표현력이 다르므로 모든 CFG 변환 결과가 반드시 DPDA 불가능 언어다.

진부분집합 정리는 일부 언어가 빠진다는 주장이다. 개별 언어의 소속은 별도의 증거가 필요하다.

서로 다른 계약의 세 기계를 비교하라. M의 입력은 10#01$1이다. 문법 S→aSbb | ε를 옮긴 N의 입력은 aabbbb이며 시작 스택은 SZ다. N은 전체 소비 뒤 빈 스택 승인이고, M은 전체 소비 뒤 최종 상태 승인이다. 마지막으로 U의 p/Z에는 ε 자기 이동과 0 소비 이동이 함께 있다. M의 최종 상태 방문이 승인인지, N의 전이 수와 바닥 포함 최대 스택 길이, U의 결정성을 각각 근거와 함께 설명하라.

힌트 1

M의 $ 뒤 남은 입력과 N의 마지막 재귀 직후 스택을 직접 적는다.

힌트 2

N에서는 규칙 전개·terminal 소비·바닥 제거를 따로 세고 U에서는 입력 0의 가능한 이동을 동시에 본다.

풀이와 답 확인

  1. M은 10을 저장해 01과 비교한 뒤 $를 읽어 f에 도달하지만 입력 1이 남는다. 따라서 전체 소비 조건을 만족하지 않아 거부한다.

  2. N은 재귀 전개 2회와 S 종료 1회, terminal 소비 6회, Z 제거 1회로 전이 10회다. 둘째 재귀 직후 스택 aSbbbbZ의 길이는 7이며 이것이 최대다. 전체 입력을 소비하고 빈 스택에 도달하므로 승인한다.

  3. U는 같은 p/Z와 남은 입력 0에서 ε 이동과 0 소비가 모두 가능하므로 비결정적이다. ε 이동만 남겨도 종료를 보장하지 못한다.

M은 최종 상태를 방문해도 거부한다. N은 전이 10회, 최대 스택 길이 7로 승인한다. U는 ε와 소비 전이가 경쟁하므로 비결정적이다. 세 판단은 각각 승인 계약, 전이의 종류별 장부, 실제 enabled 이동을 사용한다.

해결한 뒤 점검할 것

  • M에서 남은 입력 1을 명시하고 전체 소비 조건과 최종 상태 방문을 구별한다.

  • N의 3+6+1 전이 장부와 aSbbbbZ의 일곱 기호를 확인한다.

  • U의 입력 0에서 두 이동이 동시에 가능함을 밝히고 결정성과 종료를 구별한다.
