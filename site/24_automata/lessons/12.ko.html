소단원 12.1

자원 한계와 계산모형

결국 답을 낼 수 있다는 말과 입력이 커져도 적은 자원으로 답을 낸다는 말은 같을까?

준비 개념과 학습 목표

준비 개념

  • 알고리즘의 종료

  • 입력 길이와 이진 표현

  • 큰 O와 반복문

학습 목표

  • 시간·공간의 측정 기준과 최악 입력을 정한다.

  • 입력의 숫자 값과 표현 길이를 구별한다.

  • 모형의 기본 연산·비트 수와 실제 측정을 구별한다.

값 31을 입력받아 31번 반복하는 절차는 입력 길이에 선형일까?

입력 크기는 값 자체가 아니라 선택한 인코딩의 길이다. 양의 정수 N을 앞자리 0 없이 이진 문자열로 쓰면 n = ⌊log₂N⌋ + 1이다. 값 31은 11111로 다섯 칸에 들어가지만, 1을 31개 이어 붙이는 단항 인코딩은 31칸이다. 같은 값의 반복 횟수를 다른 입력 길이에 대해 평가해야 한다.

N = 2ᵏ − 1인 입력군을 생각하자. 이진 길이는 k인데 N번 반복하는 절차는 2ᵏ − 1번의 반복 본문을 실행한다. 이것은 k에 대해 다항 횟수가 아니다. 단항 길이를 n으로 잡으면 같은 본문 횟수는 n이다. 부호·앞자리·구분 기호가 있는 실제 형식에서는 그 비용도 명세해야 한다.

시간은 실행 전체의 전이를 세지만 보조 공간은 동시에 살아 있는 작업 칸의 최대 수다. 읽기 전용 입력을 제외하는 약속 아래, 0부터 N까지의 카운터 하나에는 이진 입력 길이 n만큼의 비트가 충분하다. 이미 지난 카운터 값까지 모두 저장하는 별도 절차는 공간 계약이 달라진다.

반복 한 번을 튜링기계 한 전이라고 가정하지 않는다. 이진 카운터 갱신은 자리 올림으로 여러 칸을 건드릴 수 있고 한 본문에도 추가 연산이 있다. 여기서는 반복 횟수의 하한과 작업 비트 수를 비교한다. 표준 단일·다중 테이프의 다항 시간 분류가 일치해도 정확한 시간식까지 같다는 뜻은 아니다.

먼저 확인할 개념
  • 최악 시간·작업 공간·비트 비용

    재사용 작업 칸과 누적 전이 수, 입력 값과 인코딩 길이의 차이를 기본 정의와 연결한다.

  • 다항 검증의 입력 길이 기준

    증인 검사가 다항이라는 말도 실제 입력 길이에 대한 비용임을 확인한다.

답을 낼 수 있는지에서 자원을 묻는 단계로

결정 가능성은 모든 입력에서 종료하고 맞는 예/아니오를 내는 알고리즘의 존재를 묻는다. 복잡도는 그런 계산에 시간과 저장 공간이 얼마나 필요한지를 묻는다. 아주 오래 걸리는 종료 계산도 결정 가능할 수 있다.

입력 문자열 길이를 n으로 정하고 같은 길이의 모든 입력 가운데 최악의 연산 수 T(n)을 센다. 특정 쉬운 입력 하나의 값이나 평균을 최악 한계와 혼동하지 않는다. 공간은 동시에 필요한 저장량이며 이미 쓴 공간을 재사용할 수 있다.

무엇을 한 번의 계산으로 세는가

Turing machine에서는 한 전이가 기본 단계다. 여러 테이프를 한 테이프로 모사하면 단계 수가 늘 수 있다. 적절한 표준 결정 모형들 사이의 다항 모사에서는 P라는 분류가 유지되지만 모든 모형의 정확한 시간식이 같은 것은 아니다.

정수 하나를 저장한다고 무조건 한 비트만 쓰는 것도 아니다. 0부터 n까지 세는 카운터에는 ceil(log₂(n + 1))비트가 필요하다. 임의 길이 큰 정수의 곱셈을 항상 단위 비용이라고 가정하면 비트 비용을 숨길 수 있다. 아래 비교 예제는 원소 비교 횟수만 세며 전체 Turing machine 전이 수라고 부르지 않는다.

공간을 셀 때 관례를 공개한다

읽기 전용 입력을 제외한 보조 공간을 세는 모형과 입력까지 담는 테이프 전체 공간을 세는 관례가 있다. 여기서 원소 쌍 비교의 카운터 공간은 보조 공간이다. 전체 입력 저장량을 포함하려면 입력의 표현 길이를 더해야 한다.

입력이 큰 숫자 N을 이진수로 표현했다면 길이는 대략 log₂N이다. N번 반복하는 알고리즘은 숫자 값에 선형이어도 표현 길이에 다항일 필요가 없다. 또 많은 경우를 하나씩 탐색하면 시간이 커지면서 작업 공간은 재사용할 수 있다. 다항 공간과 다항 시간이 같은 말은 아니다.

첫 두 행은 유한 수치이며 네 번째 행은 임의 양의 정수 k에 대한 입력군이다. 반복 횟수는 실제 전체 시간 측정값이 아니다. 공간은 읽기 전용 입력을 제외한 카운터의 표현 비트만 비교한다.

중간 과정을 따라가는 예제

길이 n인 배열의 모든 서로 다른 위치 쌍 i < j를 한 번씩 비교한다. 입력은 읽기 전용이고 i와 j는 0부터 n까지 표현하는 고정 비트 카운터다. n = 8에서 비교 수와 두 카운터의 비트 수를 구하라.

  1. 위치 쌍 수는 (n − 1) + (n − 2) + … + 1 = n(n − 1)/2다. n = 8이면 28회다.

  2. 0부터 8까지 9개 값을 표현하려면 카운터 하나에 ceil(log₂9) = 4비트다. 두 카운터는 8비트다.

  3. 이 모형에서 비교 횟수는 Θ(n²), 카운터 보조 공간은 Θ(log n)비트다. 루프 제어·원소 저장·다른 변수와 실제 비교 연산의 비트 비용은 따로 계산해야 한다.

28회 비교와 두 카운터 8비트다. 연산 수와 동시에 저장할 비트 수는 서로 다른 양이다.

조건을 바꾸어 비교하기

같은 값의 두 입력 계약

값 31과 32에 대해 이진 길이와 단항 길이, 반복 본문 횟수를 각각 비교하라.

  1. 31의 이진 표현은 11111로 길이 5이고, 32는 100000으로 길이 6이다.

  2. 단항 길이는 각각 31과 32이며 본문 횟수도 각각 31과 32다.

  3. 인접한 두 값만으로 일반 시간 분류를 판정하지 않는다. N = 2ᵏ − 1인 전체 입력군에서 이진 길이 k와 2ᵏ − 1회를 비교한다.

이진 인코딩에서 값에 선형인 반복은 입력 길이에 지수적일 수 있다.

비교할 점

한 유한 입력의 31회 실행을 일반 다항 시간 증명으로 사용하지 않는다.

두 인덱스를 재사용하는 쌍 검사

항목 10개에서 i<j인 모든 쌍을 차례로 검사한다. 인덱스는 0..9이고 두 인덱스만 저장하며 쌍 결과는 보관하지 않는다. 검사 횟수와 인덱스 공간은?

  1. 쌍의 수는 9+8+…+1 = 45다.

  2. 각 인덱스는 값 0..9를 나타내므로 4비트가 필요하다. 두 인덱스의 표현은 8비트다.

  3. 45개의 쌍을 동시에 저장하지 않는다. 제어 상태나 비교 대상 값 등 다른 공간은 이 두 인덱스 비교에서 제외한다.

쌍 검사 45회와 인덱스 표현 8비트는 서로 다른 지표다.

비교할 점

일반 항목 수 n에 대해 쌍은 n(n−1)/2개, 두 인덱스는 O(log n)비트지만 이것만으로 전체 비교 비용이나 전체 공간을 확정하지 않는다.

종이와 본문으로 직접 해보기

n = 16이면 같은 비교 수와 두 카운터 비트 수는? 별도로 N = 2¹⁰을 이진수로 입력받고 N번 도는 반복은 입력 길이 몇 비트에 몇 회인가?

힌트 보기

16·15/2와 ceil(log₂17)을 계산한다. 2¹⁰은 1 뒤에 0이 10개다.

풀이 보기

비교는 120회이고 두 카운터는 5비트씩 총 10비트다. N = 1024의 이진 입력은 11비트이며 반복은 1024회다. 2^k의 길이는 k + 1, 반복 수는 2^k여서 이 계열에서 입력 길이에 지수적으로 커진다.

오해와 반례

입력에 선형인 반복이고 저장 변수도 두 개뿐이니 모든 계산모형에서 시간 O(n), 공간 O(1)비트다.

어떤 입력 길이와 기본 연산을 쓰는지 필요하다. 큰 정수 값 N에 선형인 반복이 이진 길이에 선형은 아니다. 변수 개수 두 개도 그 값 범위가 커지면 저장 비트 수는 늘 수 있다.

연습 1 · 값과 상태 예측

N = 63의 이진 입력 길이와 0..63을 표현하는 카운터 비트 수, N번 반복의 본문 횟수를 구하라.

힌트 1

63 = 2⁶ − 1이다.

힌트 2

상태 0..63에는 서로 다른 64개 값이 있다.

풀이와 답 확인

  1. 이진 표현 111111의 길이는 6이다.

  2. 64개 상태는 6비트로 표현하며 본문은 63번 실행한다.

입력 길이와 카운터 표현은 각각 6비트이고 본문 횟수는 63회다.

흔한 오답에서 다시 생각하기

63번 반복하므로 동시에 63개의 카운터 칸이 필요하다.

한 현재 값을 갱신하는 절차와 과거 값을 보관하는 절차를 구분한다.

연습 2 · 오류 찾아 고치기

이진 입력 N을 받아 N번 반복하므로 T(n)=n이라는 설명을 고쳐라.

힌트 1

그 설명은 n을 입력 길이 대신 값으로 썼다.

힌트 2

N = 2ᵏ − 1에서 실제 이진 길이는 k다.

풀이와 답 확인

  1. 길이 k인 지정 입력군에서 반복 횟수는 2ᵏ − 1이다.

  2. 반복마다 적어도 한 전이를 쓴다면 전체 시간도 적어도 그만큼이다. 갱신 비용까지 넣으면 더 커질 수 있다.

값에 선형인 횟수는 이진 입력 길이에 선형이라는 뜻이 아니다.

흔한 오답에서 다시 생각하기

카운터 갱신을 한 연산으로 정했으니 어떤 기계에서도 전체 전이가 N이다.

단위 비용 모형과 실제 테이프의 비트 연산을 구분한다. 반복 횟수 하한만으로도 이 입력군의 다항 시간 주장은 반박된다.

연습 3 · 직접 만들어 보기

현재 카운터만 저장하는 절차와 과거 값 0..N을 모두 같은 n비트 슬롯에 저장하는 절차를 구성하고 공간을 비교하라. n은 N의 양의 이진 길이다.

힌트 1

첫 절차에서는 이전 슬롯을 덮어쓴다.

힌트 2

두 번째 절차는 N+1개의 슬롯을 보존한다.

풀이와 답 확인

  1. 첫 절차의 카운터 표현은 n비트이며 매 단계 같은 슬롯을 갱신한다.

  2. 두 번째 절차는 n(N+1)비트의 값 슬롯을 보존한다. 배열 제어 메타데이터는 별도다.

현재 값만 저장하면 n비트, 지정 과거 값 슬롯은 n(N+1)비트다.

흔한 오답에서 다시 생각하기

공간은 총 갱신 횟수이므로 두 절차가 같다.

공간은 동시에 보존한 칸의 최대 수다. 덮어쓰기와 이력 보존은 서로 다른 계약이다.

연습 4 · 선택 심화

선택 심화는 기본 연습 뒤 더 탐구하고 싶을 때 풀어 보세요.

양의 항목 수 n에서 모든 i<j 쌍을 검사하는 절차를 다중 테이프에서 O(n²)시간이라고 가정한다. 단일 테이프 모의가 O(T²)라면 어떤 상계를 얻으며 두 모델의 정확 시간식도 같은가?

힌트 1

T(n)=O(n²)를 모의 상계에 넣는다.

힌트 2

상계와 정확 횟수는 다르다.

풀이와 답 확인

  1. 모의 상계는 O((n²)²)=O(n⁴)다.

준비 개념

학습 목표

짧은 정점 목록을 확인하면 최적 목록을 찾은 것일까?

새 그래프의 정점은 a,b,c,d,e이고 간선은 ab, ac, ad, ae, bc다. 정점 덮개란 모든 간선의 적어도 한 끝점을 포함하는 정점 집합이다. 질문은 크기가 k 이하인 덮개가 존재하는가이다. k=2에서 목록 [a,b]를 받으면 다섯 간선을 각각 확인하여 YES 증인임을 검증할 수 있다.

그래프 입력은 모든 정점의 ID 목록과 간선 목록을 명시적으로 포함한다고 약속한다. 증인은 정점 ID 목록으로 인코딩한다. 입력 정점 목록에 없는 ID, 중복 ID 또는 k를 넘는 증인 길이를 거절하는 검증 계약을 먼저 정한다. 이후 각 간선이 증인 목록의 어느 정점을 끝점으로 가지는지 검사한다. 리스트를 직접 비교하는 단순 절차도 이 명시 입력과 증인 길이에 대해 다항 비용이다. 해시 조회를 무조건 한 단계라고 가정할 필요가 없다.

YES 입력에는 적어도 한 유효 증인이 있어야 하고, NO 입력에는 허용 길이의 모든 증인이 거절되어야 한다. [a]가 bc를 덮지 못해 거절됐다는 사실은 그래프의 k=2 질문이 NO라는 뜻이 아니다. 그 질문에는 [a,b]와 [a,c]라는 다른 성공 증인이 있다.

비결정적 계산의 존재하는 수락 갈래와 모든 갈래의 시간 한계도 별도 조건이다. 실패 갈래 하나나 무작위로 찾지 못한 실행은 NO 인증이 아니다. P의 결정기를 증인을 무시하는 검증기로 바꾸면 P⊆NP를 보일 수 있지만, NP라는 사실만으로 다항 결정기나 지수 하한을 얻지 않는다.

한 입력에 예 또는 아니오를 묻는다

P는 결정적 알고리즘으로 입력 길이에 다항인 시간 안에 판정할 수 있는 결정 문제들의 모임이다. 다항시간은 n^c 같은 한계에 고정 지수 c를 쓰는 말이며 n마다 지수가 늘어나는 식은 포함하지 않는다.

NP는 예인 입력에 다항 길이의 증명서가 존재하고 결정적 검증기가 입력 길이에 다항인 시간으로 확인하는 결정 문제들의 모임이다. 예인 입력에는 적어도 하나의 통과 증명서가 있고, 아니오인 입력에는 어떤 허용 증명서도 통과하면 안 된다.

후보를 주면 확인할 수 있다

SAT는 논리식의 변수에 참·거짓을 넣어 전체 식을 참으로 만드는 배정이 존재하는지 묻는다. 배정은 증명서가 된다. 식을 주어진 배정으로 계산하면 각 연산을 처리할 수 있어 식과 배정 길이에 다항인 검증을 한다.

후보 하나를 거절해도 식이 만족 불가능하다고 결론 내리지 않는다. 다른 후보가 통과할 수 있다. 모든 2^k 배정을 훑는 결정적 탐색은 종료하지만 변수 수 k에 지수 단계가 될 수 있다. 이 탐색 하나가 느리다는 사실만으로 더 빠른 알고리즘의 부재를 증명하지 않는다.

포함 관계와 미해결 질문을 구별한다

P의 판정기를 검증기로 쓰면 증명서를 무시하고 결정하면 되므로 P ⊆ NP다. 따라서 NP는 non-polynomial의 약자가 아니다. 비결정적 다항시간이라는 이름은 여러 계산 가지 가운데 수락 가지가 존재하는지를 나타내며 난수 성공 확률과 다른 정의다.

P = NP인지에 관해서는 이 자료가 해결을 주장하지 않는다. 또한 다항시간이라도 지수와 상수가 커서 실제로 느릴 수 있다. NP에 속한다는 증명과 현실 난이도 측정, NP 완전성의 증명은 각각 다른 작업이다.

중간 과정을 따라가는 예제

자체 식 φ = (p ∨ q) ∧ (¬p ∨ r) ∧ (¬q ∨ ¬r)에 배정 (p,q,r) = (1,0,1)과 (1,1,1)을 검증하라. 1은 참, 0은 거짓이다.

  1. (1,0,1)은 첫 절 1 ∨ 0 = 1, 둘째 절 0 ∨ 1 = 1, 셋째 절 1 ∨ 0 = 1이어서 통과한다.

  2. (1,1,1)은 첫·둘째 절이 1이지만 셋째 절 0 ∨ 0 = 0이라 거절된다.

  3. 첫 배정이 통과하므로 이 식은 만족 가능하다. 두 번째 배정의 실패는 이 입력이 아니오라는 증명이 아니다.

첫 증명서는 통과, 둘째 증명서는 실패다. 이 식은 예인 SAT 입력이다.

힌트 보기

풀이 보기

NP는 빠르게 풀 수 없는 문제들의 집합이므로 P와 겹치지 않는다.

  3. 중복 검사는 O(n²)번, 간선 검사는 O(mn)번의 ID 비교 상계를 갖는다. ID 비트 비교 비용도 입력 길이에 대해 다항이다.

문제 A를 문제 B로 바꾸어 풀었다면 쉬워진 것은 어느 쪽일까?

준비 개념과 학습 목표

준비 개념

  • 함수의 입력과 출력

  • 그래프·clique·다항시간

학습 목표

  • A ≤p B에서 빠른 풀이와 난해성의 전달 방향을 구별한다.

  • 같은 그래프의 보수 변환으로 작은 환원을 구성한다.

덮개를 독립집합으로 바꾸면 어려움은 어느 방향으로 전달될까?

새 그래프 G의 모든 정점 집합을 V라 하자. S가 정점 덮개이면 I=V\S 안에는 간선의 두 끝점이 동시에 남을 수 없으므로 I는 독립집합이다. 반대로 I 안에 간선이 없다면 모든 간선은 V\I와 적어도 한 끝점을 공유하므로 그 여집합은 덮개다. 두 방향이 환원의 핵심이다.

0≤k≤n인 입력에서 크기 k 이하 덮개가 존재하는가는 크기 n−k 이상 독립집합이 존재하는가와 동치다. 그래프는 그대로 두고 문턱만 바꾸므로 명시 인코딩에서 다항 변환이다. 최소 덮개와 최대 독립집합을 실제 구했다고 주장하는 것은 아니다. YES/NO 입력의 소속 동치가 모든 적법 입력에서 성립해야 한다.

독립집합을 완전부분그래프로 바꾸려면 그래프의 여그래프를 만든다. 정점은 보존하고 서로 다른 두 정점 사이의 간선 존재를 반전한다. 독립집합 안의 모든 서로 다른 쌍은 G에 간선이 없으므로 여그래프에는 모두 간선이 있다. 루프를 추가하거나 방향·평행 간선 정보를 섞지 않는 단순 무방향 그래프 계약이다.

A≤pB는 B의 결정기를 호출해 A를 풀 수 있다는 방향이다. B가 P이면 A도 P지만, A가 쉽다는 사실만으로 B가 쉬워지지는 않는다. 어려움을 B에 전달하려면 이미 어려운 A에서 B로 가는 환원이 필요하다. B가 NP-hard라는 증명과 B의 NP 소속은 별도이며 둘을 갖추어야 NP-complete다.

먼저 확인할 개념
  • 다항 환원의 iff와 전달 방향

    모든 입력에서 소속 동치를 보이는 변환과 쉽고 어려움이 전달되는 방향을 확인한다.

  • NP 소속의 증인 검증

    NP-hard와 NP-complete 사이에 추가해야 할 검증 조건을 연결한다.

풀이를 운반하는 변환 함수

다항시간 many-one 환원 A ≤p B는 입력 x를 다항시간 함수 f로 바꿔 x ∈ A와 f(x) ∈ B가 동치가 되게 한다. 원래 예 입력은 새 문제의 예로, 원래 아니오 입력은 새 문제의 아니오로 보내야 한다. 하나의 출력 인스턴스로 질문하는 형태이며 여러 번 호출하는 다른 환원과 구별한다.

B의 빠른 결정 알고리즘이 있으면 f(x)를 만들고 B를 판정해 A를 풀 수 있다. f의 다항시간 생성은 출력 길이도 다항 한계에 묶는다. B가 출력 길이에 다항시간이면 두 과정의 합성도 원 입력 길이에 다항이다.

어려움을 증명할 때 방향을 확인한다

A ≤p B는 B가 A를 풀어 주는 수단이라는 뜻이다. A가 어렵다고 알려져 있고 이 환원을 증명하면 B에도 그 어려움을 전달할 수 있다. 반대로 쉬운 A를 B로 바꿀 수 있다는 이유만으로 B가 쉽다고 결론 내리지 않는다.

NP 난해는 모든 NP 문제가 그 문제로 다항시간 환원된다는 뜻이고, NP 완전은 여기에 그 문제 자체가 NP에 속함을 더한다. 몇 개의 작은 입력을 변환한 결과만으로 모든 입력에서의 환원 정리를 증명하거나 NP 완전이라고 선언할 수 없다.

보수 그래프로 관계를 직접 증명한다

단순 무방향 그래프 G의 independent set은 선택한 정점 사이에 간선이 하나도 없는 집합이다. 보수 그래프 Ḡ는 같은 정점에 서로 다른 두 정점을 두고, G에 간선이 없을 때만 간선을 만든다. 자기 자신과 잇는 간선은 만들지 않는다.

A가 크기 k 이상 independent set의 존재, B가 크기 k 이상 clique의 존재를 묻는 문제라면 f(G,k) = (Ḡ,k)로 정한다. 선택 집합 S의 모든 정점 쌍이 G에서 비간선인 것과 Ḡ에서 모두 간선인 것이 동치다. 따라서 예·아니오가 모두 보존된다. 모든 정점 쌍을 확인하는 구성은 V²에 비례하는 다항 작업이다.

중간 과정을 따라가는 예제

자체 G의 정점은 {a,b,c,d}, 간선은 {ab,bc,cd}다. k = 2인 independent set 질문을 보수 그래프의 clique 질문으로 변환하라.

  1. 가능한 서로 다른 무순서 쌍은 ab, ac, ad, bc, bd, cd 여섯 개다. 원래 세 간선을 제외하면 보수 간선은 ac, ad, bd다.

  2. 원래 G의 {a,c}는 간선이 없는 크기 2 집합이다. 보수에서는 ac 간선이 있어 크기 2 clique다. {a,b}는 원래 간선 때문에 실패하고 보수에는 ab가 없어 역시 실패한다.

  3. 이 입력은 양쪽 모두 예다. 모든 집합에 대한 정점 쌍 동치가 있으므로 단순 성공 예시를 넘어 환원의 이유를 설명할 수 있다.

f(G,2) = (Ḡ,2), 보수 간선 {ac,ad,bd}다. 크기 2 질문의 답은 양쪽 모두 예다.

같은 정점에서 두 동치 검사

앞 그래프의 k=2 덮개 [a,b]를 독립집합과 여그래프 완전부분그래프로 옮겨라.

  1. 선택되지 않은 정점은 c,d,e이고 원래 그래프에 cd,ce,de 간선이 없다.

  2. 여그래프에는 cd,ce,de가 모두 있으므로 세 정점은 완전부분그래프다.

덮개 {a,b}, 독립집합 {c,d,e}, 여그래프의 크기 3 완전부분그래프가 서로 대응한다.

선택된 {a,b} 자체를 여그래프의 세 정점 증인으로 넘기지 않는다.

쉬운 문제에서 환원했다고 모두 쉬운가

임의 결정가능 문제 B가 알려진 YES 입력 y와 NO 입력 z를 가진다. 빈 언어 A를 모든 입력에서 z로 보내는 상수 변환은 무엇을 보여 주는가?

  1. 빈 언어에서는 모든 x가 A에 속하지 않는다.

  2. 상수 출력 z는 B의 NO 입력이므로 x∈A iff f(x)∈B가 항상 성립한다.

  3. A는 즉시 거절하는 쉬운 문제지만 B 전체 입력의 결정 비용에 관한 결론은 없다.

A≤pB라는 쉬운 원본의 환원만으로 B∈P를 증명하지 못한다.

이 상수 환원은 어려움 증명이 아니라 잘못된 방향 일반화를 반박하는 예다.

종이와 본문으로 직접 해보기

같은 그래프에서 k = 3이면 네 개의 정점 삼중집합을 검사하라. 모든 그래프에 A ≤p B가 있고 B를 빠르게 판정한다면 어느 문제의 빠른 판정기를 얻는가?

힌트 보기

abc, abd, acd, bcd를 쓴다. 원래 그래프의 간선을 포함하면 independent set이 아니며 보수에는 그 간선이 없다.

풀이 보기

abc에는 ab·bc, abd에는 ab, acd에는 cd, bcd에는 bc·cd가 있어 independent set이 아니다. 보수의 각 삼중집합도 그 쌍에서 clique가 아니므로 k = 3은 양쪽 모두 아니오다. 변환 후 B 판정기를 실행하면 A의 빠른 판정기를 얻는다.

오해와 반례

쉬운 A를 B로 환원했으니 B도 쉽다는 결론이 나온다.

A ≤p B와 B의 빠른 풀이에서 A의 빠른 풀이를 얻는다. A의 빠른 풀이만으로 임의 B 입력을 되돌릴 방법은 주어지지 않았다. 난해성 전달은 알려진 어려운 문제에서 새 목표 문제로 향하는 환원이 필요하다.

  2. a를 제외한 네 정점 b,c,d,e에는 bc가 있어 네 개 전체가 독립집합은 아니다.

  3. 따라서 여그래프에도 크기 4 완전부분그래프가 없다.

세 질문 모두 NO다.

문턱 k=1을 그대로 크기 1 완전부분그래프로 바꾼다.

덮개에서 독립집합으로 갈 때 문턱은 n−k다. 여그래프 변환에서는 그 문턱을 유지한다.

연습 2 · 오류 찾아 고치기

A≤pB와 A∈P를 보고 B∈P라 한 주장, B가 NP-hard여서 B∈NP라 한 주장을 각각 고쳐라.

힌트 1

A의 절차는 B의 절차를 쓰는 방향이다.

힌트 2

검증기 존재는 어려움의 환원과 별도다.

풀이와 답 확인

  1. B∈P이면 A∈P라는 결론이 맞다. A∈P만으로는 B∈P가 나오지 않는다.

  2. B의 NP 소속을 별도로 보여야 NP-hard에서 NP-complete로 갈 수 있다.

환원 방향과 소속 증명 두 조건을 구분한다.

연습 3 · 직접 만들어 보기

k가 음수이거나 n보다 큰 입력도 받는 덮개 문제를 전체 문자열 결정 문제로 정리하라. 적법 그래프에서 음수 k는 NO, k≥n은 YES라고 정의하고 독립집합 입력으로 총 변환을 구성하라.

힌트 1

통상 0≤k≤n 범위에서는 문턱 n−k다.

힌트 2

범위를 벗어난 경우에는 고정 YES/NO 사례를 출력할 수 있다.

풀이와 답 확인

  1. 그래프 인코딩이 불법이면 규약에 따라 NO로 두고 고정 독립집합 NO 입력을 출력한다.

  2. k<0도 고정 NO 입력을 출력한다. 예를 들어 정점 한 개의 그래프에 문턱 2를 준다.

  3. k≥n은 고정 YES 입력을 출력한다. 정점 한 개의 그래프에 문턱 1을 준다.

  4. 나머지는 원래 G와 문턱 n−k를 출력한다. 인코딩 검사와 비교·복사·출력은 다항이다.

법외 입력 규칙까지 포함한 총 다항 변환을 만들 수 있다.

다항 many-one 함수는 모든 문자열에서 종료해야 한다. 적법 입력만의 부분 절차로 전체 환원을 증명하지 않는다.

연습 4 · 선택 심화

선택 심화는 기본 연습 뒤 더 탐구하고 싶을 때 풀어 보세요.

A≤pB의 출력 길이가 O(n²)이고 B≤pC 변환이 길이 m 입력에서 O(m³)시간이다. 합성의 다항성과 B∈NP가 아직 없는 상황의 완전성 주장을 감사하라.

힌트 1

두 번째 변환의 m에 첫 출력 길이를 넣는다.

힌트 2

변환 비용의 다항성과 문제의 NP 소속은 다르다.

풀이와 답 확인

  1. 두 번째 단계는 O((n²)³)=O(n⁶)시간이고 첫 다항 단계와 더해 여전히 다항이다.

  2. 소속 iff를 두 번 연결하면 A≤pC다.

  3. 모든 NP 언어가 B로 환원된다는 증거가 있어도 B∈NP를 아직 증명하지 않았다면 NP-hard까지만 말한다.

합성은 다항 환원을 보존하지만 누락된 NP 소속을 대신하지 않는다.

입력 길이·증인·환원 계약을 함께 감사한다

정점 a,b,c,d,e와 간선 ab,ac,ad,ae,bc인 그래프의 k=2 덮개 요청을 독립집합·여그래프 완전부분그래프 요청으로 옮기고 성공 증인을 제시하라. [a]가 거절됐다는 이유로 요청을 NO로 보고한 검증기를 고쳐라. 별도 이진 값 N=31의 N회 반복을 입력 길이 31의 선형 알고리즘이라고 부른 보고를 고치고, 환원 대상에 다항 결정기가 생기면 어떤 원본을 풀 수 있는지 방향을 적으라.

힌트 1

정점 수는 5이고 문턱은 5−2다. 성공 덮개의 여집합에서 원래 간선 존재를 확인한다.

힌트 2

31의 이진 길이는 5다. 실패 증인 하나와 모든 증인의 실패를 구별한다.

풀이와 답 확인

  1. 덮개 {a,b}는 모든 간선을 덮는다. 여집합 {c,d,e}는 크기 3 독립집합이고 여그래프의 세 간선 cd,ce,de가 있는 완전부분그래프다.

  2. [a]는 bc를 덮지 못해 실패하지만 [a,b]라는 성공 증인이 있으므로 k=2 요청은 YES다.

  3. 이진 N=31의 입력 길이는 5이고 본문 횟수는 31이다. 일반 입력군 N=2ᵏ−1에서는 길이 k에 지수 횟수이므로 값 기준 선형을 길이 기준 선형으로 보고하지 않는다.

  4. 덮개≤p독립집합≤p완전부분그래프 방향을 합성했다. 마지막 문제의 다항 결정기가 있다면 변환하여 원래 덮개 문제도 다항 결정할 수 있다. 쉬운 원본만으로 마지막 문제의 쉬움을 주장하지 않는다.

크기 2 덮개 {a,b}, 크기 3 독립집합 {c,d,e}, 여그래프의 크기 3 완전부분그래프가 대응하고 요청은 YES다. 이진 값 31의 입력 길이는 5이며 반복 본문은 31회다. 대상 결정기의 쉬움은 들어오는 환원을 통해 원본에 전달된다.

  • 실패 증인과 NO 입력의 전칭 조건을 구별한다.

  • 환원 방향·NP 소속·NP-hard를 서로 대체하지 않고 실제 프로그램/학생 미수행을 유지한다.
