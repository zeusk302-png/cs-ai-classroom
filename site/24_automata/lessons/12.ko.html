소단원 12.1

자원 한계와 계산모형

결국 답을 낼 수 있다는 말과 입력이 커져도 적은 자원으로 답을 낸다는 말은 같을까?

준비 개념과 학습 목표

준비 개념

  • 알고리즘의 종료

  • 입력 길이와 이진 표현

  • 큰 O와 반복문

학습 목표

  • 시간·공간의 측정 기준과 최악 입력을 정한다.

  • 입력의 숫자 값과 표현 길이를 구별한다.

  • 모형의 기본 연산·비트 수와 실제 측정을 구별한다.

답을 낼 수 있는지에서 자원을 묻는 단계로

결정 가능성은 모든 입력에서 종료하고 맞는 예/아니오를 내는 알고리즘의 존재를 묻는다. 복잡도는 그런 계산에 시간과 저장 공간이 얼마나 필요한지를 묻는다. 아주 오래 걸리는 종료 계산도 결정 가능할 수 있다.

입력 문자열 길이를 n으로 정하고 같은 길이의 모든 입력 가운데 최악의 연산 수 T(n)을 센다. 특정 쉬운 입력 하나의 값이나 평균을 최악 한계와 혼동하지 않는다. 공간은 동시에 필요한 저장량이며 이미 쓴 공간을 재사용할 수 있다.

무엇을 한 번의 계산으로 세는가

Turing machine에서는 한 전이가 기본 단계다. 여러 테이프를 한 테이프로 모사하면 단계 수가 늘 수 있다. 적절한 표준 결정 모형들 사이의 다항 모사에서는 P라는 분류가 유지되지만 모든 모형의 정확한 시간식이 같은 것은 아니다.

정수 하나를 저장한다고 무조건 한 비트만 쓰는 것도 아니다. 0부터 n까지 세는 카운터에는 ceil(log₂(n + 1))비트가 필요하다. 임의 길이 큰 정수의 곱셈을 항상 단위 비용이라고 가정하면 비트 비용을 숨길 수 있다. 아래 비교 예제는 원소 비교 횟수만 세며 전체 Turing machine 전이 수라고 부르지 않는다.

공간을 셀 때 관례를 공개한다

읽기 전용 입력을 제외한 보조 공간을 세는 모형과 입력까지 담는 테이프 전체 공간을 세는 관례가 있다. 여기서 원소 쌍 비교의 카운터 공간은 보조 공간이다. 전체 입력 저장량을 포함하려면 입력의 표현 길이를 더해야 한다.

입력이 큰 숫자 N을 이진수로 표현했다면 길이는 대략 log₂N이다. N번 반복하는 알고리즘은 숫자 값에 선형이어도 표현 길이에 다항일 필요가 없다. 또 많은 경우를 하나씩 탐색하면 시간이 커지면서 작업 공간은 재사용할 수 있다. 다항 공간과 다항 시간이 같은 말은 아니다.

중간 과정을 따라가는 예제

길이 n인 배열의 모든 서로 다른 위치 쌍 i < j를 한 번씩 비교한다. 입력은 읽기 전용이고 i와 j는 0부터 n까지 표현하는 고정 비트 카운터다. n = 8에서 비교 수와 두 카운터의 비트 수를 구하라.

  1. 위치 쌍 수는 (n − 1) + (n − 2) + … + 1 = n(n − 1)/2다. n = 8이면 28회다.

  2. 0부터 8까지 9개 값을 표현하려면 카운터 하나에 ceil(log₂9) = 4비트다. 두 카운터는 8비트다.

  3. 이 모형에서 비교 횟수는 Θ(n²), 카운터 보조 공간은 Θ(log n)비트다. 루프 제어·원소 저장·다른 변수와 실제 비교 연산의 비트 비용은 따로 계산해야 한다.

28회 비교와 두 카운터 8비트다. 연산 수와 동시에 저장할 비트 수는 서로 다른 양이다.

종이와 본문으로 직접 해보기

n = 16이면 같은 비교 수와 두 카운터 비트 수는? 별도로 N = 2¹⁰을 이진수로 입력받고 N번 도는 반복은 입력 길이 몇 비트에 몇 회인가?

힌트 보기

16·15/2와 ceil(log₂17)을 계산한다. 2¹⁰은 1 뒤에 0이 10개다.

풀이 보기

비교는 120회이고 두 카운터는 5비트씩 총 10비트다. N = 1024의 이진 입력은 11비트이며 반복은 1024회다. 2^k의 길이는 k + 1, 반복 수는 2^k여서 이 계열에서 입력 길이에 지수적으로 커진다.

오해와 반례

입력에 선형인 반복이고 저장 변수도 두 개뿐이니 모든 계산모형에서 시간 O(n), 공간 O(1)비트다.

어떤 입력 길이와 기본 연산을 쓰는지 필요하다. 큰 정수 값 N에 선형인 반복이 이진 길이에 선형은 아니다. 변수 개수 두 개도 그 값 범위가 커지면 저장 비트 수는 늘 수 있다.

소단원 12.2

P·NP와 검증

누군가 해답 후보를 주었을 때 빠르게 확인하는 일과 해답을 직접 찾는 일은 같을까?

준비 개념과 학습 목표

준비 개념

  • 결정 문제와 입력 길이

  • 참·거짓과 논리식

  • 다항시간

학습 목표

  • P와 다항시간 검증의 NP 정의를 설명한다.

  • 짧은 증명서의 존재 조건과 거절 조건을 구별한다.

  • NP가 비다항시간이라는 오해를 반례로 바로잡는다.

한 입력에 예 또는 아니오를 묻는다

P는 결정적 알고리즘으로 입력 길이에 다항인 시간 안에 판정할 수 있는 결정 문제들의 모임이다. 다항시간은 n^c 같은 한계에 고정 지수 c를 쓰는 말이며 n마다 지수가 늘어나는 식은 포함하지 않는다.

NP는 예인 입력에 다항 길이의 증명서가 존재하고 결정적 검증기가 입력 길이에 다항인 시간으로 확인하는 결정 문제들의 모임이다. 예인 입력에는 적어도 하나의 통과 증명서가 있고, 아니오인 입력에는 어떤 허용 증명서도 통과하면 안 된다.

후보를 주면 확인할 수 있다

SAT는 논리식의 변수에 참·거짓을 넣어 전체 식을 참으로 만드는 배정이 존재하는지 묻는다. 배정은 증명서가 된다. 식을 주어진 배정으로 계산하면 각 연산을 처리할 수 있어 식과 배정 길이에 다항인 검증을 한다.

후보 하나를 거절해도 식이 만족 불가능하다고 결론 내리지 않는다. 다른 후보가 통과할 수 있다. 모든 2^k 배정을 훑는 결정적 탐색은 종료하지만 변수 수 k에 지수 단계가 될 수 있다. 이 탐색 하나가 느리다는 사실만으로 더 빠른 알고리즘의 부재를 증명하지 않는다.

포함 관계와 미해결 질문을 구별한다

P의 판정기를 검증기로 쓰면 증명서를 무시하고 결정하면 되므로 P ⊆ NP다. 따라서 NP는 non-polynomial의 약자가 아니다. 비결정적 다항시간이라는 이름은 여러 계산 가지 가운데 수락 가지가 존재하는지를 나타내며 난수 성공 확률과 다른 정의다.

P = NP인지에 관해서는 이 자료가 해결을 주장하지 않는다. 또한 다항시간이라도 지수와 상수가 커서 실제로 느릴 수 있다. NP에 속한다는 증명과 현실 난이도 측정, NP 완전성의 증명은 각각 다른 작업이다.

중간 과정을 따라가는 예제

자체 식 φ = (p ∨ q) ∧ (¬p ∨ r) ∧ (¬q ∨ ¬r)에 배정 (p,q,r) = (1,0,1)과 (1,1,1)을 검증하라. 1은 참, 0은 거짓이다.

  1. (1,0,1)은 첫 절 1 ∨ 0 = 1, 둘째 절 0 ∨ 1 = 1, 셋째 절 1 ∨ 0 = 1이어서 통과한다.

  2. (1,1,1)은 첫·둘째 절이 1이지만 셋째 절 0 ∨ 0 = 0이라 거절된다.

  3. 첫 배정이 통과하므로 이 식은 만족 가능하다. 두 번째 배정의 실패는 이 입력이 아니오라는 증명이 아니다.

첫 증명서는 통과, 둘째 증명서는 실패다. 이 식은 예인 SAT 입력이다.

종이와 본문으로 직접 해보기

세 변수의 여덟 배정을 써서 위 식의 모든 만족 배정을 찾아라. ψ = p ∧ ¬p에서는 두 배정 가운데 통과하는 것이 있는가?

힌트 보기

첫 절은 p = q = 0을 제외한다. 둘째 절은 p = 1, r = 0을 제외한다. 셋째 절은 q = r = 1을 제외한다.

풀이 보기

φ의 만족 배정은 (0,1,0)과 (1,0,1) 두 개다. ψ는 p = 0에서 첫 항, p = 1에서 둘째 항이 거짓이라 어떤 배정도 통과하지 않는다. 여덟 경우의 종이 열거는 일반 SAT 전체의 다항시간 알고리즘 증명이 아니다.

오해와 반례

NP는 빠르게 풀 수 없는 문제들의 집합이므로 P와 겹치지 않는다.

P ⊆ NP다. 빠른 결정 알고리즘이 있으면 그 결정으로 검증할 수 있다. NP는 짧은 예 증명서와 다항 검증의 존재를 요구하며 모든 NP 문제의 비다항 하한을 주장하지 않는다.

소단원 12.3

다항시간 환원

문제 A를 문제 B로 바꾸어 풀었다면 쉬워진 것은 어느 쪽일까?

준비 개념과 학습 목표

준비 개념

  • 결정 문제의 예·아니오

  • 함수의 입력과 출력

  • 그래프·clique·다항시간

학습 목표

  • 환원 함수의 시간과 양방향 정답 보존을 확인한다.

  • A ≤p B에서 빠른 풀이와 난해성의 전달 방향을 구별한다.

  • 같은 그래프의 보수 변환으로 작은 환원을 구성한다.

풀이를 운반하는 변환 함수

다항시간 many-one 환원 A ≤p B는 입력 x를 다항시간 함수 f로 바꿔 x ∈ A와 f(x) ∈ B가 동치가 되게 한다. 원래 예 입력은 새 문제의 예로, 원래 아니오 입력은 새 문제의 아니오로 보내야 한다. 하나의 출력 인스턴스로 질문하는 형태이며 여러 번 호출하는 다른 환원과 구별한다.

B의 빠른 결정 알고리즘이 있으면 f(x)를 만들고 B를 판정해 A를 풀 수 있다. f의 다항시간 생성은 출력 길이도 다항 한계에 묶는다. B가 출력 길이에 다항시간이면 두 과정의 합성도 원 입력 길이에 다항이다.

어려움을 증명할 때 방향을 확인한다

A ≤p B는 B가 A를 풀어 주는 수단이라는 뜻이다. A가 어렵다고 알려져 있고 이 환원을 증명하면 B에도 그 어려움을 전달할 수 있다. 반대로 쉬운 A를 B로 바꿀 수 있다는 이유만으로 B가 쉽다고 결론 내리지 않는다.

NP 난해는 모든 NP 문제가 그 문제로 다항시간 환원된다는 뜻이고, NP 완전은 여기에 그 문제 자체가 NP에 속함을 더한다. 몇 개의 작은 입력을 변환한 결과만으로 모든 입력에서의 환원 정리를 증명하거나 NP 완전이라고 선언할 수 없다.

보수 그래프로 관계를 직접 증명한다

단순 무방향 그래프 G의 independent set은 선택한 정점 사이에 간선이 하나도 없는 집합이다. 보수 그래프 Ḡ는 같은 정점에 서로 다른 두 정점을 두고, G에 간선이 없을 때만 간선을 만든다. 자기 자신과 잇는 간선은 만들지 않는다.

A가 크기 k 이상 independent set의 존재, B가 크기 k 이상 clique의 존재를 묻는 문제라면 f(G,k) = (Ḡ,k)로 정한다. 선택 집합 S의 모든 정점 쌍이 G에서 비간선인 것과 Ḡ에서 모두 간선인 것이 동치다. 따라서 예·아니오가 모두 보존된다. 모든 정점 쌍을 확인하는 구성은 V²에 비례하는 다항 작업이다.

중간 과정을 따라가는 예제

자체 G의 정점은 {a,b,c,d}, 간선은 {ab,bc,cd}다. k = 2인 independent set 질문을 보수 그래프의 clique 질문으로 변환하라.

  1. 가능한 서로 다른 무순서 쌍은 ab, ac, ad, bc, bd, cd 여섯 개다. 원래 세 간선을 제외하면 보수 간선은 ac, ad, bd다.

  2. 원래 G의 {a,c}는 간선이 없는 크기 2 집합이다. 보수에서는 ac 간선이 있어 크기 2 clique다. {a,b}는 원래 간선 때문에 실패하고 보수에는 ab가 없어 역시 실패한다.

  3. 이 입력은 양쪽 모두 예다. 모든 집합에 대한 정점 쌍 동치가 있으므로 단순 성공 예시를 넘어 환원의 이유를 설명할 수 있다.

f(G,2) = (Ḡ,2), 보수 간선 {ac,ad,bd}다. 크기 2 질문의 답은 양쪽 모두 예다.

종이와 본문으로 직접 해보기

같은 그래프에서 k = 3이면 네 개의 정점 삼중집합을 검사하라. 모든 그래프에 A ≤p B가 있고 B를 빠르게 판정한다면 어느 문제의 빠른 판정기를 얻는가?

힌트 보기

abc, abd, acd, bcd를 쓴다. 원래 그래프의 간선을 포함하면 independent set이 아니며 보수에는 그 간선이 없다.

풀이 보기

abc에는 ab·bc, abd에는 ab, acd에는 cd, bcd에는 bc·cd가 있어 independent set이 아니다. 보수의 각 삼중집합도 그 쌍에서 clique가 아니므로 k = 3은 양쪽 모두 아니오다. 변환 후 B 판정기를 실행하면 A의 빠른 판정기를 얻는다.

오해와 반례

쉬운 A를 B로 환원했으니 B도 쉽다는 결론이 나온다.

A ≤p B와 B의 빠른 풀이에서 A의 빠른 풀이를 얻는다. A의 빠른 풀이만으로 임의 B 입력을 되돌릴 방법은 주어지지 않았다. 난해성 전달은 알려진 어려운 문제에서 새 목표 문제로 향하는 환원이 필요하다.

자기점검

예 입력만 보존하고 아니오 입력을 예로 바꿔도 환원인가?

답과 이유 보기

아니다.

x ∈ A iff f(x) ∈ B라는 양방향 동치가 필요하다.

보수 그래프에서 자기 자신을 잇는 간선을 넣는가?

답과 이유 보기

넣지 않는다.

단순 그래프의 서로 다른 정점 쌍만 뒤집는다.

NP 난해성과 NP 완전성은 같은 조건인가?

답과 이유 보기

아니다.

NP 완전에는 문제 자체가 NP에 속하는 조건도 필요하다.

한 단계 더

위 보수 변환은 두 결정 문제의 관계를 보여 준다. 이것만으로 어느 쪽의 모든 일반 입력을 다항시간에 풀었다고 말하지 않는다. NP 완전 문제를 공부할 때는 검증기의 다항 한계, 출발 문제의 알려진 난해성, 변환 구성의 다항 한계, 예·아니오 동치를 별도로 적는다.
