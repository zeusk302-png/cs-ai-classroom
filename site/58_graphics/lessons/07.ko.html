소단원 7.1

vertex·fragment 단계

삼각형 꼭짓점 색 세 개로 내부의 색을 어떻게 만들까?

준비 개념과 학습 목표

준비 개념

  • 삼각형과 벡터
  • 동차좌표
  • shader는 GPU의 지정 단계에서 실행하는 프로그램이다. 래스터화는 도형이 덮는 표본을 만들며 uniform은 여러 처리에 공통으로 제공하는 값이다.

학습 목표

  • 정점 처리와 래스터화 뒤 fragment 처리를 구별한다.
  • 입력·uniform·보간값을 추적한다.

vertex shader는 정점 데이터를 처리한다

vertex shader는 들어오는 정점 위치와 관련 속성을 처리하여 gl_Position 같은 출력과 다음 단계에 전달할 속성을 만든다. 모델·뷰·투영 변환으로 clip 공간 위치를 만든 뒤 파이프라인이 clipping과 perspective divide 등을 수행한다. shader가 화면 픽셀을 직접 하나씩 배치하는 것은 아니다.

동차좌표 (x,y,z,w)에서 w가 0이 아닌 유효 점의 정규화 좌표는 (x/w,y/w,z/w)다. 실제 clipping 범위를 먼저 만족해야 화면 처리로 이어진다. 이 단원은 정점/fragment 핵심 단계에 집중하고 tessellation·geometry 등의 선택 단계는 생략한다.

래스터화와 fragment의 역할

래스터화는 삼각형이 덮는 위치에 fragment 후보와 보간 속성을 만든다. fragment shader는 색·깊이 등 값을 계산할 수 있으나 그 fragment의 x,y 위치를 마음대로 이동시키지 않는다. 이후 깊이 검사와 blending 등으로 최종 저장이 결정될 수 있다.

fragment를 최종 픽셀과 일대일로 동일시하면 안 된다. 겹친 삼각형, 다중 샘플, helper invocation과 버려지는 fragment 등이 있다. 따라서 정점 세 개면 fragment도 세 번이라는 결론이나 화면 픽셀 수가 실제 shader 호출 수라는 결론을 이 그림에서 얻지 않는다.

속성과 uniform 및 보간

정점마다 다른 색은 정점 속성으로 주고 여러 정점에 공통인 변환 행렬은 uniform으로 제공할 수 있다. GLSL의 기본 smooth는 perspective-correct 보간이고 flat은 보간하지 않는다. 표본의 정점 가중치를 적용하는 단순 계산은 모든 clip w가 같은 경우로 한정한다.

이 예제는 같은 w와 가중치 (1/4,1/4,1/2)를 지정한다. 세 색이 빨강·초록·파랑이면 각 성분의 가중 합으로 내부 색을 계산한다. 다른 w에서는 단순 화면 가중 합을 그대로 smooth 결과라고 쓰지 않는다.

중간 과정을 따라가는 예제

clip 점 (1,−1,0,2)의 정규화 좌표와 같은 w인 세 정점 색 R=(1,0,0),G=(0,1,0),B=(0,0,1)의 가중치 1/4,1/4,1/2 색을 구하라.

  1. w=2로 x,y,z를 나누어 (0.5,−0.5,0)을 얻는다. clip 범위도 이 점은 만족한다.
  2. 빨강 성분은 1/4×1+1/4×0+1/2×0=1/4다.
  3. 초록은 1/4, 파랑은 1/2이므로 색은 (0.25,0.25,0.5)다.

정규화 좌표 (0.5,−0.5,0), 보간색 (0.25,0.25,0.5)다.

소단원 7.2

법선과 보간

단위 법선을 보간하면 결과도 단위 길이일까?

준비 개념과 학습 목표

준비 개념

  • 내적과 벡터 길이
  • 역행렬과 전치

학습 목표

  • 보간 뒤 재정규화의 필요성을 계산한다.
  • 비균등 크기변환의 법선 변환을 설명한다.

법선은 표면 방향의 정보다

법선은 표면에 수직인 방향이다. 조명에서 각도의 코사인을 얻으려면 법선과 광원 방향을 단위 길이로 만든다. 실제 다각형의 면 법선과 꼭짓점에 지정한 smooth shading 법선은 다를 수 있으며 둥근 외형을 근사하는 선택이다.

법선 방향을 바꾸는 것과 삼각형 자체의 기하를 바꾸는 것은 다르다. 위치는 같아도 법선을 공유하거나 나눠 지정하면 매끄러운 경계와 날카로운 경계를 다르게 표현할 수 있다. 법선은 이동 위치가 아니라 방향 정보이므로 translation을 더하지 않는다.

보간 후 길이는 다시 확인한다

세 단위 법선 (1,0,0),(0,1,0),(0,0,1)을 같은 w와 동일 가중치 1/3으로 보간하면 (1/3,1/3,1/3)이다. 길이는 √(3/9)=1/√3으로 1이 아니다. 0이 아닌 결과를 길이로 나누면 (1/√3,1/√3,1/√3)이다.

광원 방향 (0,0,1)과 내적은 보간값을 그대로 쓰면 1/3, 단위화하면 1/√3이다. 서로 반대 법선을 섞어 0벡터가 나오면 길이로 나눌 수 없으므로 모델의 경계 법선·퇴화 입력 처리도 검토한다.

비균등 스케일은 역전치로 변환한다

같은 좌표 공간에서 계산하려면 접선은 변환행렬 A로, 법선은 가역인 선형 3×3 부분의 (A⁻¹)ᵀ로 옮긴 뒤 정규화한다. 이렇게 하면 변환된 접선과의 수직 관계가 유지된다. 세계 공간 계산이면 모델의 선형 부분을, 뷰 공간이면 해당 선형 부분을 쓴다.

A=diag(2,1,1)에서 접선 (1,−1,0)은 (2,−1,0)이 된다. 옛 법선 (1,1,0)을 A로 그대로 옮기면 (2,1,0)으로 내적 3이라 수직을 잃는다. 역전치로 옮긴 (1/2,1,0)은 내적 1−1=0이다. 스케일 0인 특이행렬에는 이 역행렬 공식을 적용하지 않는다.

중간 과정을 따라가는 예제

동일 가중치 보간 법선의 길이와 단위화 후 z 성분을 구하고 A 예제의 두 법선과 접선 내적을 비교하라.

  1. 보간 (1/3,1/3,1/3)의 길이는 1/√3이다.
  2. 길이로 나누면 각 성분 1/√3이며 광원 z 방향 내적도 1/√3다.
  3. 잘못된 A 법선은 (2,1,0)·(2,−1,0)=4−1=3, 역전치 법선은 (1/2,1,0)·(2,−1,0)=1−1=0이다.

재정규화 z=1/√3, 수직 유지 내적 0은 역전치 변환에서 얻는다.

오해와 반례

정점 법선이 단위 벡터면 보간값도 항상 단위이고 위치행렬 그대로 법선을 바꾸면 된다.

동일 가중치 세 법선은 길이 1/√3이고 비균등 스케일은 수직을 깨므로 각 조건에 맞는 재정규화/역전치가 필요하다.

소단원 7.3

Lambert·Phong 모델

정면을 보는 밝기와 반짝임은 같은 계산일까?

준비 개념과 학습 목표

준비 개념

  • 단위 벡터 내적
  • 거듭제곱
  • BRDF는 표면의 입사·반사 방향별 빛의 분포를 기술하는 함수다. 선형 색 수치는 빛의 세기에 비례하며 clamping은 표시 범위를 넘은 값을 경계로 자르는 정책이다.

학습 목표

  • 확산항과 시선 의존 반사항을 구별한다.
  • 방향과 앞면 조건을 명시하여 조명을 계산한다.

Lambert 확산항은 방향의 내적이다

점에서 광원으로 향하는 단위 벡터 l과 바깥쪽 단위 법선 n을 둔다. 확산항은 k_d max(n·l,0)I_l로 계산한다. 광원이 반대쪽이면 내적을 0으로 잘라 음의 밝기를 막는다. 같은 위치·법선·광원일 때 확산항은 관찰자의 방향 v와 무관하다.

여기서는 흰빛 한 광원과 한 채널의 선형 수치만 센다. 거리 감쇠·그림자·색 공간 변환을 생략했다. Lambert BRDF의 물리적 정규화까지 포함하는 방정식이 아니라 입문 조명 계수를 k_d에 둔 경험적 계산이다.

Phong 반사항은 시선 방향에 의존한다

점에서 카메라로 향하는 단위 v를 둔다. l이 점에서 광원으로 향하므로 들어오는 방향은 −l이다. 반사 방향 r=reflect(−l,n)=2(n·l)n−l을 얻고 앞면에 빛이 있을 때 k_s max(r·v,0)^p I_l을 더한다. p는 양의 지수이며 커질수록 일반적으로 하이라이트가 좁아진다.

이 모형에서는 n·l≤0이면 specular도 0으로 두어 뒷면 광원 하이라이트를 막는다. GLSL reflect의 입력 n은 단위여야 한다. Phong 조명 모형과 법선을 보간한 뒤 fragment에서 조명을 계산하는 Phong shading은 서로 다른 이름의 개념이다.

ambient와 합 및 모형의 한계

작은 ambient항 I_a를 더해 I=I_a+I_diffuse+I_specular라고 정한다. ambient는 실제 다중 반사와 에너지 보존을 정확히 푸는 것이 아닌 근사다. 계수가 커지면 합이 1을 넘을 수 있어 최종 표시에서는 clamping/tone mapping 등 별도 정책이 필요하다.

Gouraud shading은 정점에서 계산한 색을 보간하며 fragment에서 법선을 재정규화하여 계산하는 방법과 결과가 다를 수 있다. 작은 하이라이트가 정점 사이에 있으면 정점 값만으로 놓칠 수 있다. 실제 시각 결과나 GPU 성능은 여기서 실험하지 않았다.

중간 과정을 따라가는 예제

n=(0,0,1), l=(0.6,0,0.8), v=(0,0,1), I_l=1, I_a=0.1, k_d=0.5,k_s=0.25,p=2일 때 한 채널 I는?

  1. l의 길이는 √(0.36+0.64)=1이고 n·l=0.8이다. 확산은 0.5×0.8=0.4다.
  2. r=1.6n−l=(−0.6,0,0.8), r·v=0.8이다.
  3. 반사항은 0.25×0.8²=0.16, 합은 0.1+0.4+0.16=0.66이다.

I=0.66이다. 선형 스칼라 계산이며 화면 sRGB 값 측정이 아니다.

오해와 반례

Phong 반사항과 Lambert 확산항은 모두 시선과 무관하고 물리적으로 완벽하다.

확산항은 이 조건에서 시선 무관하지만 반사는 r·v에 따른다. ambient와 Phong은 경험적 근사이며 그림자·간접광 등을 생략했다.
