소단원 7.1

vertex·fragment 단계

삼각형 꼭짓점 색 세 개로 내부의 색을 어떻게 만들까?

준비 개념과 학습 목표

준비 개념

  • 삼각형과 벡터

  • 동차좌표

  • shader는 GPU의 지정 단계에서 실행하는 프로그램이다. 래스터화는 도형이 덮는 표본을 만들며 uniform은 여러 처리에 공통으로 제공하는 값이다.

학습 목표

  • 정점 처리와 래스터화 뒤 fragment 처리를 구별한다.

  • 입력·uniform·보간값을 추적한다.

제곱을 정점에서 계산하고 보내면 보간 뒤 제곱과 같을까?

한 삼각형의 정점 A/B/C가 스칼라 q를 각각 0, 1, 1로 갖고 clip w는 각각 1, 2, 2라고 정한다. 유효한 내부 표본의 화면 가중치는 (1/2,1/4,1/4)다. smooth 보간의 분모는 (1/2)/1+(1/4)/2+(1/4)/2=3/4이고 정규화한 속성 가중치는 (2/3,1/6,1/6)이다. noperspective는 화면 가중치를 그대로 사용한다. 이 표본과 수학 값만 계산하며 실제 정점·fragment 호출 횟수는 알 수 없다.

목표는 표본에서 보간한 q를 제곱하는 것이다. q를 smooth로 보내면 fragment의 q는 1/3이고 목표 값은 1/9다. 정점에서 q²를 먼저 계산해 smooth로 보내면 정점 값이 여전히 (0,1,1)이어서 표본 값은 1/3이다. 단계가 달라도 같은 제곱 기호를 썼다는 사실은 같은 함수 계산을 보장하지 않는다.

flat은 이 삼각형의 모든 fragment에 선택된 provoking vertex의 값 하나를 전달한다. 이 자체 사례에서 그 정점은 B라고 명시한다. 따라서 flat q는 1이다. flat을 단순히 더 빠른 smooth라고 바꾸면 원하는 값이 달라진다. 반면 q에 공통인 선형 식 2q+1을 적용하는 일은 정규화된 보간과 교환할 수 있다. 이 구별은 정점 수를 세어 실제 성능 개선을 인증하는 규칙이 아니다.

먼저 확인할 개념
  • 단계별 입력과 보간 규약

    정점 속성·uniform과 fragment 계산의 위치를 먼저 나눈다.

  • 정점 색 보간과 fragment 조명

    비선형 조명 계산의 단계를 바꾸면 값이 달라질 수 있다는 앞 본문과 연결한다.

vertex shader는 정점 데이터를 처리한다

vertex shader는 들어오는 정점 위치와 관련 속성을 처리하여 gl_Position 같은 출력과 다음 단계에 전달할 속성을 만든다. 모델·뷰·투영 변환으로 clip 공간 위치를 만든 뒤 파이프라인이 clipping과 perspective divide 등을 수행한다. shader가 화면 픽셀을 직접 하나씩 배치하는 것은 아니다.

동차좌표 (x,y,z,w)에서 w가 0이 아닌 유효 점의 정규화 좌표는 (x/w,y/w,z/w)다. 실제 clipping 범위를 먼저 만족해야 화면 처리로 이어진다. 이 단원은 정점/fragment 핵심 단계에 집중하고 tessellation·geometry 등의 선택 단계는 생략한다.

래스터화와 fragment의 역할

래스터화는 삼각형이 덮는 위치에 fragment 후보와 보간 속성을 만든다. fragment shader는 색·깊이 등 값을 계산할 수 있으나 그 fragment의 x,y 위치를 마음대로 이동시키지 않는다. 이후 깊이 검사와 blending 등으로 최종 저장이 결정될 수 있다.

fragment를 최종 픽셀과 일대일로 동일시하면 안 된다. 겹친 삼각형, 다중 샘플, helper invocation과 버려지는 fragment 등이 있다. 따라서 정점 세 개면 fragment도 세 번이라는 결론이나 화면 픽셀 수가 실제 shader 호출 수라는 결론을 이 그림에서 얻지 않는다.

속성과 uniform 및 보간

정점마다 다른 색은 정점 속성으로 주고 여러 정점에 공통인 변환 행렬은 uniform으로 제공할 수 있다. GLSL의 기본 smooth는 perspective-correct 보간이고 flat은 보간하지 않는다. 표본의 정점 가중치를 적용하는 단순 계산은 모든 clip w가 같은 경우로 한정한다.

이 예제는 같은 w와 가중치 (1/4,1/4,1/2)를 지정한다. 세 색이 빨강·초록·파랑이면 각 성분의 가중 합으로 내부 색을 계산한다. 다른 w에서는 단순 화면 가중 합을 그대로 smooth 결과라고 쓰지 않는다.

제곱을 정점에서 계산하고 보내면 보간 뒤 제곱과 같을까?
전달·계산 정책표본에서 얻은 값쓴 가중치 또는 연산

smooth q를 보내고 제곱

q = 1/3, 결과 = 1/9

속성 가중치 (2/3,1/6,1/6)

smooth q²를 보냄

결과 = 1/3

정점에서 이미 제곱한 값

noperspective q 뒤 제곱

q = 1/2, 결과 = 1/4

화면 가중치 (1/2,1/4,1/4)

B를 선택한 flat q 뒤 제곱

q = 1, 결과 = 1

보간하지 않음

각 행은 같은 화면 표본의 서로 다른 계약이다. q와 q²의 두 값은 다른 단계에서 계산한 것이며, flat 행은 B라는 정점 선택 조건까지 포함한다. 화면 가중치와 smooth의 속성 가중치를 섞지 않는다.

중간 과정을 따라가는 예제

clip 점 (1,−1,0,2)의 정규화 좌표와 같은 w인 세 정점 색 R=(1,0,0),G=(0,1,0),B=(0,0,1)의 가중치 1/4,1/4,1/2 색을 구하라.

  1. w=2로 x,y,z를 나누어 (0.5,−0.5,0)을 얻는다. clip 범위도 이 점은 만족한다.

  2. 빨강 성분은 1/4×1+1/4×0+1/2×0=1/4다.

  3. 초록은 1/4, 파랑은 1/2이므로 색은 (0.25,0.25,0.5)다.

정규화 좌표 (0.5,−0.5,0), 보간색 (0.25,0.25,0.5)다.

조건을 바꾸어 비교하기

똑같은 정점 값이 다른 중간 계산을 숨긴다

위 q와 w에서 정점 제곱 전달과 fragment 제곱을 비교하라.

  1. smooth q의 분자는 0+1/8+1/8=1/4이고 분모는 3/4라 q는 1/3이다. 이를 제곱하면 1/9다.

  2. 정점 q²도 (0,1,1)이지만 이를 보간한 결과 1/3은 제곱 이후 보간의 결과다.

두 결과는 1/9와 1/3이다. 정점 데이터가 같아 보이는 것만으로 목표 연산의 순서를 생략할 수 없다.

비교할 점

앞 본문의 선형 RGB 합과 달리 제곱은 보간과 교환하지 않는다.

공통 선형 식은 같은 결과를 준다

같은 표본에서 정점별 2q+1을 smooth로 보내거나 보간 후 2q+1을 적용한다.

  1. 정점 출력은 (1,3,3)이고 보간 값은 2/3+1/2+1/2=5/3이다.

  2. 먼저 q=1/3을 보간하면 2/3+1=5/3이다. 가중치 합이 1인 것이 상수항 보존의 근거다.

두 방식 모두 5/3이다. 동일한 공통 식을 썼다는 조건이 필요하다.

비교할 점

모든 단계 이동이 틀린 것은 아니며 선형성과 상수항을 직접 증명한다.

종이와 본문으로 직접 해보기

정점마다 위치 3float+법선 3float이며 float는 4byte라고 정한다. 삼각형 3정점의 원시 속성 데이터 크기와 4×4 uniform 행렬 크기를 따로 계산하라.

힌트 보기

속성 float 수를 먼저 세고 실제 GPU 정렬/버퍼 padding과 구별한다.

풀이 보기

정점당 6×4=24byte, 3정점 72byte다. 행렬은 16×4=64byte의 원시 수치다. 실제 buffer 배치나 호출 수 측정은 아니다.

오해와 반례

fragment shader는 반드시 모든 화면 픽셀에 한 번씩 호출된다.

삼각형이 덮는 부분·깊이·샘플·helper 등이 달라 실제 호출 수를 화면 해상도만으로 단정할 수 없다.

연습 1 · 값과 상태 예측

별도 비교에서 w를 모두 2로 바꾸고 화면 가중치와 q는 유지한다. smooth q 뒤 제곱, 정점 q² 전달, B의 flat 결과를 각각 구하라.

힌트 1

같은 w이면 정규화된 가중치는 화면 가중치와 같다.

힌트 2

먼저 q와 q²의 표본 값을 따로 적는다.

풀이와 답 확인

  1. smooth q는 1/2라 fragment 제곱은 1/4다. 정점 q²의 보간은 1/2다.

  2. B를 선택한 flat q는 1이어서 제곱도 1이다.

fragment 제곱은 1/4, 정점 제곱 전달은 1/2, flat 제곱은 1이다.

흔한 오답에서 다시 생각하기

같은 w이면 모든 연산의 단계 차이가 사라진다.

같은 w는 보간 가중치를 단순하게 만들 뿐 비선형 제곱의 순서를 바꾸지 않는다.

연습 2 · 오류 찾아 고치기

원래 w=(1,2,2)에서 구현 보고가 smooth q=1/2, 목표 제곱=1/4라고 적었다. 어느 조건을 놓쳤으며 어떻게 고칠까?

힌트 1

1/2는 noperspective의 q다.

힌트 2

각 화면 가중치를 해당 w로 나눈 뒤 전체 합으로 정규화한다.

풀이와 답 확인

  1. 분모 3/4와 분자 1/4를 다시 계산해 smooth q=1/3을 얻는다.

  2. 목표는 fragment에서 제곱하므로 결과를 1/9로 고친다.

다른 w의 smooth 규약을 누락했다. 목표 제곱은 1/9다.

흔한 오답에서 다시 생각하기

보간된 q를 w 하나로 다시 나누면 된다.

표본에 속한 w 하나를 임의로 택하는 방식은 정점별 보정과 분모를 대체하지 않는다.

연습 3 · 직접 만들어 보기

목표가 원래 표본의 smooth q²가 아니라 (smooth q)²임을 문서화하고 두 단계의 데이터 계약을 구성하라. 그림이나 GPU 실행은 요구하지 않는다.

힌트 1

vertex 출력에 담는 값을 정확히 이름 붙인다.

힌트 2

fragment 입력이 이미 제곱되었는지 확인한다.

풀이와 답 확인

  1. vertex는 q를 smooth 출력으로 전달하고 위치는 별도의 clip 위치 출력에 둔다.

  2. fragment는 보간된 q를 받아 한 번 제곱한다. q²를 정점 출력으로 바꾸는 변경은 별도 의미 변경으로 취급한다.

데이터 전달은 q이고 목표 연산은 fragment의 q*q다. 원래 표본에서는 1/9다.

흔한 오답에서 다시 생각하기

fragment 출력 값을 바꾸면 그 표본의 화면 x,y도 이동한다.

색 등의 출력 데이터 계산과 래스터화된 fragment 위치는 다른 계약이다.

연습 4 · 선택 심화

선택 심화는 기본 연습 뒤 더 탐구하고 싶을 때 풀어 보세요.

정점마다 다른 계수 a_i로 a_i q_i를 보내는 것과 a와 q를 각각 smooth 보간하여 곱하는 것이 항상 같을까? 위 가중치에서 a=(1,0,0), q=(0,1,1)을 반례로 써라.

힌트 1

정점별 곱은 모두 0이다.

힌트 2

보간한 a와 q는 각각 2/3과 1/3이다.

풀이와 답 확인

  1. 곱을 먼저 만든 세 값은 (0,0,0)이므로 보간 결과는 0이다.

  2. 분리 보간 뒤 곱은 (2/3)(1/3)=2/9다. 공통 계수의 선형 식과 조건이 다르다.

두 결과는 0과 2/9다. 정점마다 다른 두 입력의 곱은 일반적으로 교환하지 않는다.

흔한 오답에서 다시 생각하기

곱셈도 각 성분에 수행하므로 선형 식이다.

하나의 고정 계수에 대한 선형성은 두 입력이 함께 변하는 곱의 선형성을 뜻하지 않는다.

정점에서 미리 정규화하면 fragment 재정규화만으로 원래 법선장이 복원될까?

자체 목표 법선장은 객체 공간의 두 끝 법선 n_A=(1,0,0), n_B=(0,1,0)을 절반씩 보간한 뒤 상수 normal matrix를 적용하고 마지막에 정규화한 것이다. 표본의 두 끝은 동일한 clip w를 갖는 변의 중점이라고 정한다. A=diag(2,1,1)이고 normal matrix Q=(A⁻¹)ᵀ=diag(1/2,1,1)다. 보간한 n은 (1/2,1/2,0), Qn은 (1/4,1/2,0)이라 목표 단위 방향은 (1/√5,2/√5,0)이다.

Q를 정점에서 적용하되 정규화하지 않고 보내면 두 출력은 (1/2,0,0), (0,1,0)이다. 이들을 보간해도 (1/4,1/2,0)이므로 마지막 정규화는 같은 결과를 준다. 그러나 각 정점 출력을 먼저 정규화하면 둘 다 다시 좌표축 단위 벡터가 된다. 중점 보간 뒤의 단위 방향은 (1/√2,1/√2,0)으로 목표와 다르다. fragment에서 normalize를 호출한다는 사실만으로 앞에서 잃은 상대 길이를 복원하지 못한다.

이 보간 법선장의 중점에서 옛 방향 (1/2,1/2,0)에 수직인 시험 접선 t=(1,−1,0)을 함께 둔다. 변환 뒤 접선 At=(2,−1,0)과 목표 법선의 내적은 0이지만 먼저 정규화한 정책의 내적은 1/√2다. 이는 선택한 중점 방향의 수직 관계를 검사하는 수학 사례이며 두 끝 shading 법선이 실제 한 평면의 면 법선이라는 가정은 아니다. 공통 공간·가역 행렬·영벡터 경계를 먼저 적는다.

법선은 표면 방향의 정보다

법선은 표면에 수직인 방향이다. 조명에서 각도의 코사인을 얻으려면 법선과 광원 방향을 단위 길이로 만든다. 실제 다각형의 면 법선과 꼭짓점에 지정한 smooth shading 법선은 다를 수 있으며 둥근 외형을 근사하는 선택이다.

법선 방향을 바꾸는 것과 삼각형 자체의 기하를 바꾸는 것은 다르다. 위치는 같아도 법선을 공유하거나 나눠 지정하면 매끄러운 경계와 날카로운 경계를 다르게 표현할 수 있다. 법선은 이동 위치가 아니라 방향 정보이므로 translation을 더하지 않는다.

보간 후 길이는 다시 확인한다

세 단위 법선 (1,0,0),(0,1,0),(0,0,1)을 같은 w와 동일 가중치 1/3으로 보간하면 (1/3,1/3,1/3)이다. 길이는 √(3/9)=1/√3으로 1이 아니다. 0이 아닌 결과를 길이로 나누면 (1/√3,1/√3,1/√3)이다.

광원 방향 (0,0,1)과 내적은 보간값을 그대로 쓰면 1/3, 단위화하면 1/√3이다. 서로 반대 법선을 섞어 0벡터가 나오면 길이로 나눌 수 없으므로 모델의 경계 법선·퇴화 입력 처리도 검토한다.

비균등 스케일은 역전치로 변환한다

같은 좌표 공간에서 계산하려면 접선은 변환행렬 A로, 법선은 가역인 선형 3×3 부분의 (A⁻¹)ᵀ로 옮긴 뒤 정규화한다. 이렇게 하면 변환된 접선과의 수직 관계가 유지된다. 세계 공간 계산이면 모델의 선형 부분을, 뷰 공간이면 해당 선형 부분을 쓴다.

A=diag(2,1,1)에서 접선 (1,−1,0)은 (2,−1,0)이 된다. 옛 법선 (1,1,0)을 A로 그대로 옮기면 (2,1,0)으로 내적 3이라 수직을 잃는다. 역전치로 옮긴 (1/2,1,0)은 내적 1−1=0이다. 스케일 0인 특이행렬에는 이 역행렬 공식을 적용하지 않는다.

중간 과정을 따라가는 예제

동일 가중치 보간 법선의 길이와 단위화 후 z 성분을 구하고 A 예제의 두 법선과 접선 내적을 비교하라.

  1. 보간 (1/3,1/3,1/3)의 길이는 1/√3이다.

  2. 길이로 나누면 각 성분 1/√3이며 광원 z 방향 내적도 1/√3다.

  3. 잘못된 A 법선은 (2,1,0)·(2,−1,0)=4−1=3, 역전치 법선은 (1/2,1,0)·(2,−1,0)=1−1=0이다.

재정규화 z=1/√3, 수직 유지 내적 0은 역전치 변환에서 얻는다.

조건을 바꾸어 비교하기

선형 변환은 보간과 교환한다

Q가 모든 정점에서 같은 행렬일 때 위 두 법선을 먼저 보간하거나 먼저 Q로 바꿔 비교하라.

  1. Q((n_A+n_B)/2)=Q(1/2,1/2,0)=(1/4,1/2,0)이다.

  2. (Qn_A+Qn_B)/2=((1/2,0,0)+(0,1,0))/2도 같은 벡터다.

중간 벡터와 마지막 단위 방향이 같다. 각 정점의 Q가 달라지는 경우까지 이 증명을 확대하지 않는다.

끝점의 정상 방향이 중점 오류를 가린다

Q 뒤 정점별 정규화를 넣은 정책은 끝점에서 방향이 맞다. 중점에서도 같은가?

  1. 각 끝점은 축 방향이라 정규화해도 방향이 같지만 변환 길이 1/2와 1의 차이가 사라진다.

  2. 중점 방향은 (1/√2,1/√2,0)이다. 목표 방향과 다르며 At와 내적은 (2−1)/√2다.

끝점 비교만으로는 중점의 방향 보존을 인증하지 못한다.

연습 1 · 값과 상태 예측

같은 중점에서 광원 방향 l=(0,1,0)을 둔다. 목표 정책과 정점별 선행 정규화 정책의 Lambert 방향 계수를 비교하라.

힌트 1

두 최종 법선의 y 성분을 읽는다.

힌트 2

계수는 max(n·l,0)이고 두 방향 모두 y가 양수다.

풀이와 답 확인

  1. 목표의 계수는 2/√5로 약 0.8944다.

  2. 선행 정규화 정책은 1/√2로 약 0.7071이다.

각 계수는 2/√5와 1/√2다. 실제 화면 밝기를 측정한 값은 아니다.

연습 2 · 오류 찾아 고치기

구현이 법선을 Q가 아니라 위치의 선형 부분 A로 바꾼 뒤 정규화했다. 위 중점 벡터와 At의 수직 검사를 사용해 고쳐라.

힌트 1

A(1/2,1/2,0)=(1,1/2,0)이다.

힌트 2

길이로 나누는 일은 0이 아닌 내적을 0으로 만들지 않는다.

풀이와 답 확인

  1. 잘못된 단위 방향은 (2/√5,1/√5,0)이고 At와 내적은 3/√5다.

  2. Q로 바꾸어 목표 방향 (1/√5,2/√5,0)을 만들면 내적이 0이다.

법선은 이 가역 변환에서 역전치로 옮긴다. 잘못된 내적 3/√5는 정규화만으로 해결되지 않는다.

연습 3 · 직접 만들어 보기

상수 Q를 vertex에서 계산해 전송하면서 위 목표 법선장을 유지하는 계약을 작성하라. 입력 보간 벡터가 0이면 광원 내적을 계산하지 않고 별도 오류 표식을 반환하는 정책을 추가한다.

힌트 1

Q를 적용한 벡터의 크기를 전송 중에 보존한다.

힌트 2

풀이와 답 확인

  1. vertex는 Qn을 정규화하지 않고 같은 보간 규약으로 전송한다. fragment는 보간된 Qn의 길이를 검사한다.

  2. 0이 아니면 마지막에 정규화하고 같은 공간의 l과 내적한다. 0이면 지정한 오류 표식으로 끝내어 임의 방향을 정상 결과로 만들지 않는다.

상수 선형 변환 뒤 상대 길이를 보존하고 영벡터의 별도 정책을 명시한다.

0벡터도 단위 길이 1로 나누면 된다.

길이가 0인 벡터에는 방향이 없고 x/length(x)의 분모가 0이다.

연습 4 · 선택 심화

선택 심화는 기본 연습 뒤 더 탐구하고 싶을 때 풀어 보세요.

별도 A=sI에서 s>0일 때 정점별 선행 정규화가 이 두 단위 법선의 목표 중점 방향을 바꾸는가? s=0에서도 같은 공식을 쓸 수 있는가?

힌트 1

s>0이면 Q=(1/s)I이고 모든 정점의 변환 길이가 같다.

힌트 2

s=0이면 역행렬의 존재부터 검사한다.

풀이와 답 확인

  1. 양의 균등 배율은 공통 인자 1/s만 제거하므로 목표와 선행 정규화 모두 중점 단위 방향 (1/√2,1/√2,0)이다.

  2. s=0은 특이행렬이라 Q 공식을 계산할 수 없다. 원래 입력의 단위 길이 조건도 이 비교의 전제다.

이 양의 균등 배율 사례는 동일하지만 0 배율에는 역전치 공식이 없다.

  • BRDF는 표면의 입사·반사 방향별 빛의 분포를 기술하는 함수다. 선형 색 수치는 빛의 세기에 비례하며 clamping은 표시 범위를 넘은 값을 경계로 자르는 정책이다.

학습 목표

  • 확산항과 시선 의존 반사항을 구별한다.

  • 방향과 앞면 조건을 명시하여 조명을 계산한다.

정점에서 계산한 하이라이트를 보간하면 중간의 강한 반짝임도 잡을까?

독립된 방향광 사례에서 같은 w인 두 끝 shading 법선 n_+=(3/5,0,4/5), n_−=(−3/5,0,4/5)을 둔다. l과 v는 모두 (0,0,1)로 고정한다. ambient는 1/10, k_d는 1/2, k_s는 1/4, 지수 p는 4, 광원 세기는 1이다. 거리·그림자·색 변환은 생략하며 모든 수치는 한 채널의 선형 경험적 모델이다.

각 끝에서 n·l=4/5이고 반사 방향의 z 성분은 2(4/5)²−1=7/25다. 끝점 밝기는 1/10+2/5+(1/4)(7/25)^4=0.50153664다. 두 값이 같으므로 Gouraud처럼 끝점 조명 값을 중점으로 보간하면 같은 수치다. 법선을 먼저 보간해 중점 (0,0,4/5)을 정규화하면 n=(0,0,1)이다. fragment 조명은 1/10+1/2+1/4=0.85로 더 크다. 정점에서 보이지 않은 최대값을 선형 색 보간이 만들어 내지는 못한다.

앞면 조건과 표시 변환도 연산 순서다. 이 단원의 자체 정책은 n·l≤0이면 확산과 specular를 모두 0으로 둔다. reflect의 내적이 양수라는 이유만으로 뒷면 광원을 더하지 않는다. 여러 빛의 선형 기여를 더한 뒤 표시 함수 F(x)=x/(1+x)를 적용하는 별도 정책도, 각 빛에 F를 먼저 적용해 더하는 정책과 다르다. F는 여기서 정한 교육 함수이며 특정 화면의 tone mapping 결과가 아니다.

Lambert 확산항은 방향의 내적이다

점에서 광원으로 향하는 단위 벡터 l과 바깥쪽 단위 법선 n을 둔다. 확산항은 k_d max(n·l,0)I_l로 계산한다. 광원이 반대쪽이면 내적을 0으로 잘라 음의 밝기를 막는다. 같은 위치·법선·광원일 때 확산항은 관찰자의 방향 v와 무관하다.

여기서는 흰빛 한 광원과 한 채널의 선형 수치만 센다. 거리 감쇠·그림자·색 공간 변환을 생략했다. Lambert BRDF의 물리적 정규화까지 포함하는 방정식이 아니라 입문 조명 계수를 k_d에 둔 경험적 계산이다.

Phong 반사항은 시선 방향에 의존한다

점에서 카메라로 향하는 단위 v를 둔다. l이 점에서 광원으로 향하므로 들어오는 방향은 −l이다. 반사 방향 r=reflect(−l,n)=2(n·l)n−l을 얻고 앞면에 빛이 있을 때 k_s max(r·v,0)^p I_l을 더한다. p는 양의 지수이며 커질수록 일반적으로 하이라이트가 좁아진다.

이 모형에서는 n·l≤0이면 specular도 0으로 두어 뒷면 광원 하이라이트를 막는다. GLSL reflect의 입력 n은 단위여야 한다. Phong 조명 모형과 법선을 보간한 뒤 fragment에서 조명을 계산하는 Phong shading은 서로 다른 이름의 개념이다.

ambient와 합 및 모형의 한계

작은 ambient항 I_a를 더해 I=I_a+I_diffuse+I_specular라고 정한다. ambient는 실제 다중 반사와 에너지 보존을 정확히 푸는 것이 아닌 근사다. 계수가 커지면 합이 1을 넘을 수 있어 최종 표시에서는 clamping/tone mapping 등 별도 정책이 필요하다.

Gouraud shading은 정점에서 계산한 색을 보간하며 fragment에서 법선을 재정규화하여 계산하는 방법과 결과가 다를 수 있다. 작은 하이라이트가 정점 사이에 있으면 정점 값만으로 놓칠 수 있다. 실제 시각 결과나 GPU 성능은 여기서 실험하지 않았다.

중간 과정을 따라가는 예제

n=(0,0,1), l=(0.6,0,0.8), v=(0,0,1), I_l=1, I_a=0.1, k_d=0.5,k_s=0.25,p=2일 때 한 채널 I는?

  1. l의 길이는 √(0.36+0.64)=1이고 n·l=0.8이다. 확산은 0.5×0.8=0.4다.

  2. r=1.6n−l=(−0.6,0,0.8), r·v=0.8이다.

  3. 반사항은 0.25×0.8²=0.16, 합은 0.1+0.4+0.16=0.66이다.

I=0.66이다. 선형 스칼라 계산이며 화면 sRGB 값 측정이 아니다.

다른 문제에 적용하기

세 독립 사례의 단계 이동 제안을 감사하라. ① q=(0,1,1), w=(1,2,2), 화면 가중치 (1/2,1/4,1/4)에서 목표는 smooth 보간한 q의 제곱이다. 제안은 vertex에서 q²를 보내는 것이다. 둘의 값과 공통 선형 식 2q+1의 비교를 적어라. ② 변의 같은 w인 중점에서 n_A=(1,0,0), n_B=(0,1,0), Q=diag(1/2,1,1)이다. 목표는 보간→Q→정규화이며 제안은 Q→정점별 정규화→보간→정규화다. 각 방향과 l=(0,1,0)의 확산 계수를 구하라. ③ 별도 방향광 l=v=(0,0,1), 법선 n_±=(±3/5,0,4/5), ambient=1/10, k_d=1/2, k_s=1/4, p=4, 광원 세기 1이다. 정점 조명 색 보간과 중점 법선 조명 값을 비교하라. 모든 좌표·방향은 해당 사례의 공통 공간에 있다. GPU 실행과 화면·성능·학생 관찰은 요구하지 않는다.

힌트 1

① 정규화한 속성 가중치와 연산 위치를 분리한다. ② Q가 만든 두 길이를 먼저 지우면 무엇이 사라지는지 본다.

힌트 2

③ 끝점 반사 내적은 7/25이고 중점 법선을 단위화하면 +z다. 조명 색과 법선은 서로 다른 전달 데이터다.

풀이와 답 확인

  1. ① 분모는 3/4라 q=1/3이다. 목표 제곱은 1/9지만 정점 제곱 전달은 1/3이다. 공통 선형 식은 어느 순서든 5/3이라 제곱 반례를 모든 식으로 일반화하지 않는다.

  2. ② 목표는 (1/√5,2/√5,0), 제안은 (1/√2,1/√2,0)이다. 광원 내적의 양수 계수는 각각 2/√5와 1/√2다. Q→보간→마지막 정규화라면 목표와 같지만 정점별 정규화는 상대 길이를 지운다.

  3. ③ 끝점 반사 기여는 0.00153664이고 색 보간은 0.50153664다. 중점 법선을 단위화한 조명은 0.85다. 원래 두 정점 색의 보간만으로는 이 최대를 만들 수 없다.

제곱 이동은 목표 1/9를 1/3으로 바꾼다. 공통 선형 식은 5/3으로 동일하다. 정점별 선행 법선 정규화는 방향과 확산 계수를 바꾼다. 정점 조명 색 보간은 0.50153664이고 중점 법선 조명은 0.85다. 각 변경의 등가성과 실제 실행 성능을 별도 주장으로 기록한다.

해결한 뒤 점검할 것

  • 화면 가중치와 smooth 속성 가중치를 구별하고 제곱의 두 값 및 선형 식의 공통 값 5/3을 계산한다.

  • 두 법선 방향과 광원 계수를 이름별로 적고 상수 Q 이동과 정점별 정규화를 구별한다.

  • 세 조명 항과 두 중점 값을 재계산하며 반사 내적·법선 재정규화 조건을 보존한다.

  • 원고의 손모형과 실제 shader/GPU/화면/성능/학생 미수행을 구별한다.
