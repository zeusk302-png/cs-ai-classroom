소단원 6.1

UV와 texture sampling

같은 삼각형에 그림의 어느 부분을 붙일지 어떻게 알려 줄까?

준비 개념과 학습 목표

준비 개념

  • UV는 표면이 텍스처의 어느 좌표를 사용할지 나타내는 두 값이다.

  • texel은 텍스처의 한 자료 칸이며 화면 픽셀과 다르다.

  • 배열 인덱스는 여기서 0부터 시작한다.

학습 목표

  • 표면 위치와 UV를 구별한다.

  • 정규화 좌표를 texel 중심에 연결한다.

  • 경계 처리와 샘플링 규칙을 명시한다.

반복되는 그림의 이음새에서 좌표를 먼저 감싸면 보간도 같을까?

앞 본문의 texel 중심을 사용해 새 가로 네 칸짜리 선형 스칼라 자료 [0,4,8,20]을 둔다. 세로는 한 칸이며 u만 계산한다. 각 중심은 1/8,3/8,5/8,7/8이다. 선형 샘플링은 x=4u−1/2, i=floor(x), a=x−i로 두 이웃 i와 i+1을 (1−a),a로 섞는다. repeat이면 두 인덱스를 각각 4로 나눈 나머지로, clamp-to-edge이면 각각 0..3 범위의 끝 인덱스로 제한한다. 실제 유한 정밀도나 하드웨어의 동률 선택을 모사하지 않는 명시 계산이다.

u=0은 첫 칸 중심이 아니라 마지막과 첫 중심 사이 경계다. repeat에서는 x=−1/2이므로 마지막 값 20과 첫 값 0이 반씩 섞여 10이다. clamp에서는 두 이웃을 첫 칸으로 제한해 0이다. u=1에서도 repeat 값은 10이지만 clamp 값은 20이다. 따라서 범위 안/밖이라는 판정만으로 읽은 값이 결정되지 않는다. 주소 정책과 이웃 선택을 함께 기록한다.

별도 투영 없는 표면 선분의 끝 UV는 0.9와 1.1이며 중간 가중치는 각각 1/2다. 먼저 연속 UV를 보간하면 중간 u=1이고 반복 샘플 값은 10이다. 끝 UV를 먼저 각각 0.9와 0.1로 감싼 뒤 보간하면 중간 u=0.5이고 값은 (4+8)/2=6이다. 정점 UV의 감싸기와 샘플러의 반복 주소 처리는 순서가 다르다. 같은 끝의 반복 주소를 갖더라도 그 사이를 어느 경로로 잇는지는 자료에 남겨야 한다.

먼저 확인할 개념
  • 중심과 경계 및 주소 정책

    중심 식과 repeat/clamp를 이웃 인덱스 계산에 적용한다.

  • 이웃 보간의 가중 합

    경계에서도 두 값과 가중치를 별도로 추적한다.

기하와 그림 좌표를 따로 전달하기

삼각형 정점은 3차원 위치와 UV를 각각 가진다. 같은 기하라도 UV를 바꾸면 붙는 그림 영역이나 방향이 달라질 수 있다. 래스터화 과정은 정점에서 받은 UV를 표면 안쪽으로 보간하고 sampler가 그 위치의 자료를 읽는다. UV만 바꾸었다고 삼각형의 기하 위치가 움직이는 것은 아니다.

이 절은 아래쪽이 v=0인 2차원 좌표 관례를 쓴다. 이미지 파일 행 방향과 도구 관례가 다를 수 있어 상하 뒤집힘을 확인해야 한다. 투영 화면의 임의 선형 가중치를 무조건 UV에 적용하지 않고, 여기서는 자체 표면의 지정 가중치 또는 투영이 없는 모형만 계산한다.

texel의 모서리와 중심 구분하기

W×H 텍스처에서 texel(i,j)의 중심은 ((i+0.5)/W,(j+0.5)/H)다. 예제는 경계에서 떨어진 좌표와 nearest 규칙을 쓰므로 중심에 정확히 놓으면 그 칸을 읽는다. 화면 픽셀 수와 텍스처 칸 수가 달라도 같은 0~1 좌표를 사용할 수 있다.

자체4×2 텍스처의 i=2,j=1 중심은 u=2.5/4=0.625,v=1.5/2=0.75다. u=0.5는 두 가운데 열 중심 사이이며 texel 중심이라고 외우면 안 된다. 정확히 경계나 같은 거리일 때의 선택은 규칙을 확인해야 하므로 아래 nearest 문제는 그런 동률을 피한다.

범위 밖 좌표의 정책도 필요하다

repeat는 패턴을 반복하고 clamp-to-edge는 가장자리 쪽으로 제한한다. 자체 u=1.25는 repeat이면0.25 쪽, clamp이면 오른쪽 끝 쪽을 읽는다. UV가 1보다 크다는 이유만으로 배열 오류라고 단정하지 않고 sampler의 주소 정책을 먼저 본다.

텍스처는 그림 색뿐 아니라 표면 자료를 담을 수 있다. 따라서 읽은 숫자의 의미·색 공간·필터링 조건도 자료 종류에 맞춰 정한다. 아래 값은 단순 기호 격자이며 실제 OpenGL 업로드·shader 실행을 수행한 것은 아니다.

조건을 바꾸어 비교하기

반복 경계와 가장자리 제한을 비교한다

u=0과 u=1에서 두 정책의 값을 계산하라.

  1. u=0에서 x=−1/2이므로 원래 이웃 인덱스는 −1과 0이며 가중치는 각각 1/2다. repeat 인덱스는 3과 0, 자료 값은 20과 0으로 결과 10이다. clamp에서는 두 인덱스가 모두 0이 되어 결과도 0이다.

  2. u=1에서 x=7/2이므로 원래 이웃 인덱스는 3과 4이며 가중치는 각각 1/2다. repeat 인덱스는 3과 0으로 결과 10이다. clamp 인덱스는 모두 3으로 결과 20이다.

repeat의 양 끝 값은 같고 clamp의 양 끝 값은 다르다.

비교할 점

좌표 범위보다 주소 정책이 경계 이웃을 결정한다.

같은 끝 주소라도 선분 내부가 달라진다

끝 UV 0.9와 1.1의 중간을 두 처리 순서로 비교하라.

  1. 원래 두 UV의 평균은 1이다. repeat 샘플은 경계의 값 10이다.

  2. 각 끝을 먼저 0..1로 감싸면 0.9와 0.1이다. 그 평균 0.5에서 x=1.5라 값 4와 8을 반씩 섞어 6이다.

정점 좌표를 먼저 감싸면 같은 표면의 내부 샘플을 10에서 6으로 바꾼다.

비교할 점

연습 1 · 값과 상태 예측

u=−1/8과 u=9/8에서 repeat 및 clamp 값을 구하라.

힌트 1

두 위치는 범위 밖이지만 반복 후 texel 중심이다.

힌트 2

x=4u−1/2와 floor를 먼저 계산한다.

풀이와 답 확인

  1. u=−1/8은 x=−1이며 repeat 인덱스 3의 값 20, clamp 인덱스 0의 값 0이다.

  2. u=9/8은 x=4이며 repeat 인덱스 0의 값 0, clamp 인덱스 3의 값 20이다.

u=−1/8에서 repeat 값은 20, clamp 값은 0이다. u=9/8에서 repeat 값은 0, clamp 값은 20이다.

흔한 오답에서 다시 생각하기

범위 밖이면 두 정책 모두 같은 오류 값이다.

이 명시 주소 정책은 범위 밖 이웃을 합법적인 자료 인덱스로 바꾼다.

연습 2 · 오류 찾아 고치기

repeat 좌표를 u−trunc(u)로 구해 u=−1/8을 −1/8로 남겼다. 0≤r<1 계약을 만족하게 고쳐라.

힌트 1

trunc는 0 방향 절단이다.

힌트 2

floor(−1/8)=−1이다.

풀이와 답 확인

  1. r=u−floor(u)로 쓰면 r=−1/8−(−1)=7/8이다.

  2. 이 중심은 마지막 값 20을 읽는다. 음수 좌표를 직접 배열 인덱스로 쓰지 않는다.

정한 repeat 대표 좌표는 7/8이다.

흔한 오답에서 다시 생각하기

소수 부분이라는 말은 언제나 trunc를 뜻한다.

음수에서도 0..1 대표를 원하면 어떤 정수 제거 규칙인지 명시해야 한다.

연습 3 · 직접 만들어 보기

0.9에서 반복 경계를 한 번 지나 0.1 주소에 도달하는 표면 선분의 연속 UV 표현을 구성하라. 중간 결과도 적어라.

힌트 1

두 번째 끝 주소에 정수 1을 더할 수 있다.

힌트 2

표면 보간 뒤 sampler에서 repeat한다.

풀이와 답 확인

  1. 끝 UV를 0.9와 1.1로 저장해 연속적인 증가 경로를 보존한다.

  2. 중간은 u=1로 반복 샘플 값 10이다. 0.9에서 0.1로 바로 보간한 값 6과 다르다.

기하 위치는 유지하고 UV 경로와 주소 처리를 분리한다.

정수 차이는 끝 주소에서 사라져도 중간 보간에는 영향을 준다.

연습 4 · 선택 심화

선택 심화는 기본 연습 뒤 더 탐구하고 싶을 때 풀어 보세요.

위 단일 축 계산을 두 축으로 확장한다. U/V 모두 repeat인 W×H 자료의 정수 UV 이동 (k,l)이 bilinear 샘플 값을 유지하는 이유를 설명하라. 두 축의 k,l은 정수다.

힌트 1

x의 변화는 Wk이고 y의 변화는 Hl이다.

힌트 2

floor 이후의 분수 비율과 나머지 인덱스를 각각 비교한다.

풀이와 답 확인

  1. 가로 이웃 인덱스에는 Wk가 더해지고 세로 이웃 인덱스에는 Hl이 더해진다. 각각 modulo W와 modulo H를 적용하면 이전 인덱스를 유지한다.

  2. 각 축의 분수 비율도 그대로여서 네 값과 네 가중치가 같다. 이는 정확 산술·동일 자료·동일 repeat 정책 조건이다.

전역 정수 이동은 유지하지만 정점마다 서로 다른 정수 이동의 내부 보간은 별도다.

흔한 오답에서 다시 생각하기

정점별 정수 이동도 항상 같은 내부 샘플을 만든다.

선분 반례처럼 위치별 정수 선택은 보간 전에 서로 달라질 수 있다.

준비 개념과 학습 목표

준비 개념

  • 축소에서는 화면 한 픽셀이 여러 texel 영역을 대표할 수 있다.

  • 보간은 이웃 값을 가중 평균하는 방식이다.

  • 아래 예제는 선형 자료 값이며 감 마· 압축· 하드웨어 오버 헤드를 제외한다.

  • filtering은 자료를 고르거나 섞어 읽는 규칙이다. footprint는 한 화면 픽셀이 대응하는 텍스처의 범위다.

학습 목표

  • 축소 필터와 확대 필터의 조건을 설명한다.

정사각형 체인의 약 4/3배를 모든 텍스처에 적용해도 될까?

새 저장 모형은 8×2의 선형 스칼라 텍스처다. 각 축을 절반으로 줄이되 1보다 작게 만들지 않아 레벨 크기는 8×2,4×1,2×1,1×1이다. 첫 감소는 2×2 평균, 세로가 1이 된 뒤에는 가로 이웃 두 값의 평균으로 정한다. 각 칸은 4바이트이며 압축·행 패딩·정렬·메타데이터는 없다. 두 원래 행을 모두 [0,0,0,0,1,1,1,1]로 두면 다음 레벨들은 [0,0,1,1], [0,1], [1/2]다.

전체 칸 수는 16+4+2+1=23으로 기본 16의 23/16배다. 두 축이 계속 절반이 되는 정사각형의 기하급수 합과 다르다. 약 4/3을 무조건 적용하면 전체 92바이트의 정확 저장 모형을 얻지 못한다. 이 바이트 계산은 실제 GPU 메모리 측정이 아니다.

별도 atlas 모형은 가로 네 칸 [0,0,1,1]이며 왼쪽 두 칸과 오른쪽 두 칸이 다른 그림이다. 같은 전역 텍스처의 선형 샘플에서 u=3/8은 기본 레벨의 왼쪽 마지막 중심이라 값 0이다. 가로 두 칸 평균 레벨 [0,1]에서는 중심이 1/4과 3/4다. 같은 u=3/8에서 두 값이 3/4과 1/4로 섞여 1/4가 된다. 기본 레벨만 이웃 그림을 피하도록 좌표를 잡아도 다른 레벨의 이웃은 다르다. 레벨별 여유 칸/그림별 축소 생성/별도 저장 등 추가 계약을 확인해야 한다.

한 점을 찍는 대신 이웃을 섞기

nearest는 가까운 texel을 고르고 bilinear는 2차원 이웃 네 값의 가중 합을 구한다. 자체 네 값의 왼쪽 아래0,오른쪽 아래1,왼쪽 위1,오른쪽 위0을 중심 사이 비율a,b로 섞으면 (1−a)(1−b)·0+a(1−b)·1+(1−a)b·1+ab·0이다. 가중치 합은1이다.

이웃 사이 a=0.25,b=0.5이면 네 가중치는0.375/0.125/0.375/0.125이고 결과0.5다. 보간은 새로운 원본 세부 묘사를 만들어 내는 장치가 아니다. 확대된 낮은 해상도 그림을 부드럽게 할 수 있어도 잃은 정보가 복원되었다고 단정하지 않는다.

축소할 때 대표 범위에 맞는 레벨 쓰기

mipmap은 한 축씩 줄인 여러 해상도를 준비하는 방식이다. 자체4×4 자료를2×2로 만들 때 각2×2블록을 평균하고 다시1×1로 평균한다고 정한다. 이는 선형 스칼라 자료의 교육 모형이며 모든 색 공간·필터가 이 단순 평균과 같지는 않다.

화면에서 한 픽셀이 넓은 원본 범위를 덮을 때 맞는 축소 레벨을 사용하면 과도한 미세 무늬 선택을 줄일 수 있다. 레벨 선택은 텍스처의 화면상 변화율·footprint와 관계가 있으므로 거리가 같아도 기울기나 UV배율이 다르면 달라질 수 있다. 실제 aliasing을 완전히 제거했다는 실험 결과는 아니다.

레벨 사이에서도 보간하기

각 레벨에서 bilinear로 읽은 값이0.2와0.6이고 다음 레벨 비율λ=0.25면 레벨 간 값은0.75×0.2+0.25×0.6=0.3이다. 이 두 레벨 선형 보간과 각 레벨의2차원 보간을 조합하는 방식이 흔히 trilinear라고 불린다. 한 레벨의 bilinear만 사용한 것과 다르다.

4×4/2×2/1×1의 texel 합은16+4+1=21이다. 기본 레벨16보다5개 추가이며 큰 정사각형 전체 체인은 약4/3배에 가까워진다. 작은4×4의 정확 비율은21/16이다. mipmap은 주로 축소에 쓰며 OpenGL의 확대 필터에 mipmap 옵션을 지정하면 유효한 확대 설정이 아니다.

중간 과정을 따라가는 예제

0/1 바둑판 4×4에서 각 2×2 블록 평균으로 2×2와 1×1 레벨을 만든다. 모든 레벨을 한 칸 4바이트로 저장하면 총 바이트는?

  1. 각 2×2 블록은 0 두 개·1 두 개라 평균(0 +0 +1 +1)/4 =0.5다.

  2. 2×2의 네 값은 모두 0.5이고 1×1도 평균 0.5다.

  3. 총 칸 16 +4 +1 =21, ×4 =84 바이트다. 기본 64바이트 대비 20바이트 추가다.

축소 레벨들은 0.5이며 체인 84B, 기본 64B 대비21/16=1.3125 배다.

두 축의 감소가 끝나는 시점이 다르다

8×2 체인의 칸 수·바이트·기본 대비 비율을 구하라.

  1. 첫 두 레벨은 16칸과 4칸이다. 세로 1 뒤에도 2칸과 1칸이 필요하다.

  2. 합계 23칸에 4바이트를 곱하면 92바이트다. 기본 64바이트에 추가 28바이트다.

  3. 정확 비율은 23/16=1.4375이고 약 4/3이라는 정사각형 극한과 다르다.

비교할 점

정확한 유한 직사각형과 정사각형 극한을 비교한다.

기본 레벨의 안전한 중심도 다음 레벨에서는 섞인다

atlas [0,0,1,1]의 u=3/8을 기본/다음 레벨에서 읽고 레벨 사이 비율 λ=1/2를 적용하라.

  1. 기본 레벨의 x=4×3/8−1/2=1로 값 0이다.

  2. 다음 레벨 [0,1]에서는 x=2×3/8−1/2=1/4로 값 1/4다.

  3. 두 레벨을 반씩 섞으면 0/2+(1/4)/2=1/8이다.

기본 중심의 값 0이 레벨 혼합에서는 1/8이 된다.

풀이 보기

0.5×0.2 +0.5×0.6 =0.4다. 합은 64 +16 +4 +1 =85개이며 기본 64 대비85/64=1.328125다. 실제 GPU 할당 비용은 제외한다.

오해와 반례

bilinear만 켜면 모든 축소 aliasing이 사라지고 원래 세부도 복원된다.

작은 이웃 보간만으로 넓은 원본 footprint 전체를 대표하지 못할 수 있다. 또한 평균 0.5로 축소한 0/1바둑판에서 원래 순서를 다시 알 수 없으므로 정보 복원을 보장하지 않는다.

  • 단위 벡터의 길이는 1이다.

  • 내적 조명 비교에서는 두 벡터의 좌표계를 같게 둔다.

  • tangent 공간은 표면에 붙인 국소 좌표계이고 world 공간은 장면 전체의 공통 좌표계다. T/B/N은 접선·종접선·법선 축이다.

학습 목표

  • RGB 저장 값을 법선 벡터로 해석한다.

  • tangent 법선과 world 법선을 구별한다.

  • 조명 변화와 기하 변경의 한계를 설명한다.

두 법선의 평균을 정규화한 조명은 두 조명의 평균과 같을까?

앞 본문의 2RGB−1 해석을 두 샘플에 적용한다. tangent 단위 법선 n+=(3/5,0,4/5)와 n−=(−3/5,0,4/5)의 저장 RGB는 각각 (4/5,1/2,9/10)과 (1/5,1/2,9/10)이다. 선형 자료로 반씩 필터링하면 RGB 평균은 (1/2,1/2,9/10), 해석 벡터는 (0,0,4/5)다. 해석 변환은 affine이므로 평균과 교환되지만 정규화는 길이로 나누는 비선형 연산이라 별도로 수행한다.

이 평균 벡터를 정규화하면 (0,0,1)이다. tangent 빛 L=(0,0,1)에서 두 원래 Lambert 계수는 각각 4/5여서 조명의 평균은 4/5다. 필터링 뒤 정규화한 법선의 Lambert 계수는 1이다. 둘은 서로 다른 목표다. 법선을 보간해 다시 단위 방향으로 만드는 과정이 원래 여러 미세면의 조명 평균을 항상 재현한다는 뜻은 아니다. 별도 재질 모델·거칠기·빛의 다른 항은 제외한다.

기본 직교 단위 기저 T=(0,0,−1), B=(0,1,0), N=(1,0,0)를 유지한다. n=(0,3/5,4/5)는 world에서 (4/5,3/5,0)다. 거울 UV에 대응하는 별도 기저는 T와 N을 유지하고 B만 (0,−1,0)으로 둔다. 같은 tangent 성분은 world (4/5,−3/5,0)가 된다. 이 두 직교 기저의 손잡이 방향은 다르므로 항상 cross(N,T)만 사용해 같은 B라고 가정하지 않는다. 파일의 축 부호·기저의 handedness를 함께 명시한다.

반대 방향 법선 (1,0,0)과 (−1,0,0)을 반씩 필터링하면 해석 벡터는 0이다. 본 보강은 이 경우 명시한 fallback N을 사용하는 계약을 둔다. 이 선택은 예외 처리 정책이며 원래 미세 방향을 복원한 결과가 아니다. 실제 shader·유한 정밀도·영에 가까운 값의 임계 선택·소자 실행은 수행하지 않는다.

색처럼 보이는 숫자에 방향 담기

normal map은 표면의 작은 법선 방향을 자료로 저장한다. 자체 RGB 각 성분 0~1을 n_raw=2RGB−1로 바꾸어 −1~1 벡터를 얻고 길이가 0이 아니면 정규화한다. 일반 색 사진을 그대로 법선으로 해석하면 같은 의미가 아니다.

예제 RGB(0.8,0.5,0.9)는 (0.6,0,0.8)을 만든다. 길이 √(0.36+0.64)=1이어서 그대로 단위 벡터다. 실제 자료는 필터링 뒤 길이가 달라질 수 있어 정규화 조건이 필요하다. RGB(0.5,0.5,0.5)의 영벡터는 정규화할 수 없어 별도 정책이 필요하다.

표면에 붙은 좌표계를 변환하기

tangent 공간의 세 축은 T/B/N이다. 자체 직교 단위 기저 T=(0,0,−1),B=(0,1,0),N=(1,0,0)를 열로 둔 TBN은 tangent 법선을 world로 바꾼다. (x,y,z)는 xT+yB+zN이므로 (0.6,0,0.8)은 (0.8,0,−0.6)이 된다.

world 방향 빛과 내적을 구할 때 tangent 성분을 그대로 쓰면 좌표계를 혼합한다. 반대로 빛도 tangent로 옮겨 같은 공간에서 계산할 수 있다. 실제 기저 계산·UV 이음새·손잡이 방향·축 부호는 자료 관례와 맞춰야 한다. 이 절은 주어진 직교 기저의 수동 변환만 다룬다.

바뀌는 것과 그대로인 것

자체 Lambert 계수는 단위 법선 n과 표면에서 빛으로 향하는 단위 L에 대해 max(0,n·L)이다. world L=(1,0,0)이라면 바뀐 법선과 내적은 0.8이다. 평평한 기하 법선 N=(1,0,0)은 1이어서 같은 위치의 조명 계수가 달라진다. 이것은 색 공간·전체 조명·거리 감쇠를 제외한 비교다.

normal mapping만으로 정점 위치나 윤곽이 바뀌지는 않는다. 벽돌 홈처럼 보이는 조명 효과가 있어도 실제 기하 홈의 가림·그림자·충돌까지 만든 것은 아니다. 표면을 옆에서 볼 때 평평한 윤곽이 남는 반례를 생각하라. displacement나 parallax 등 다른 방법은 각자 별도 조건을 갖는다.

조건을 바꾸어 비교하기

해석 평균과 정규화의 순서를 구별한다

두 저장 RGB의 평균부터 Lz 계수까지 계산하고 원래 조명 평균과 비교하라.

  1. RGB 평균은 (1/2,1/2,9/10)이고 2RGB−1은 (0,0,4/5)다.

  2. 길이 4/5로 나누면 (0,0,1)이므로 Lambert는 1이다.

  3. 각 원래 방향의 계수는 4/5여서 평균도 4/5다.

법선 평균 뒤 정규화의 계수 1과 원래 조명 평균 4/5는 다르다.

비교할 점

필터링으로 방향을 대표하는 것과 여러 면의 에너지를 평균하는 목표를 비교한다.

거울 기저는 녹색 성분의 방향을 바꾼다

n=(0,3/5,4/5)와 world L=(0,1,0)를 원래/거울 기저에서 비교하라.

  1. 원래 world 법선은 0T+(3/5)B+(4/5)N=(4/5,3/5,0)이고 Lambert는 3/5다.

  2. B 부호만 반전한 기저에서는 world 법선 (4/5,−3/5,0), 내적 −3/5를 clamp해 0이다.

자료 RGB가 같아도 기저 관례가 바뀌면 조명이 3/5에서 0으로 바뀐다.

비교할 점

색 숫자만 대조하지 않고 그 숫자가 가리키는 축을 함께 대조한다.

연습 1 · 값과 상태 예측

위 n+/n−를 반씩 섞은 법선을 기본 TBN으로 world에 옮긴 뒤 world L=(1,0,0)과 비교하라. 먼저 각 법선의 world 조명을 평균한 결과도 구하라.

힌트 1

필터 뒤 tangent 단위 법선은 (0,0,1)이다.

힌트 2

기본 TBN에서 N은 world의 +x다.

풀이와 답 확인

  1. 필터 뒤 world 법선은 (1,0,0)이므로 계수 1이다.

  2. 원래 두 world 법선은 (4/5,0,−3/5)와 (4/5,0,3/5)이고 계수는 각각 4/5다. 조명 평균은 4/5다.

같은 공간으로 옮겨도 두 목표의 1 대 4/5 차이는 남는다.

흔한 오답에서 다시 생각하기

좌표계를 같게 하면 모든 평균과 비선형 연산이 교환된다.

공간 일치는 내적의 조건이며 정규화의 비선형성을 제거하지 않는다.

연습 2 · 오류 찾아 고치기

거울 기저에서도 B=cross(N,T)로 원래 B를 재생성하고 같은 RGB의 world 계수가 3/5라고 했다. 명시 기저 계약으로 고쳐라.

힌트 1

거울 기저의 B는 −y로 주어졌다.

힌트 2

world L은 +y이며 음의 내적은 0으로 제한한다.

풀이와 답 확인

  1. cross(N,T)는 이 T/N에서 +y지만 거울 기저가 요구하는 B는 −y다. 필요한 손잡이 방향 정보가 빠졌다.

  2. 주어진 B를 사용하면 n의 world y 성분은 −3/5, Lambert는 0이다.

명시 handedness 또는 제공된 B를 보존해야 한다.

흔한 오답에서 다시 생각하기

세 축이 직교이면 손잡이 방향은 언제나 같다.

직교 단위 기저라도 determinant의 부호가 다를 수 있다.

연습 3 · 직접 만들어 보기

기본 TBN의 tangent 공간에서 반대 법선 (1,0,0)과 (−1,0,0)의 저장 RGB 및 반반 필터 결과를 적어라. 해석 벡터의 길이가 0이면 기본 world N=(1,0,0)을 쓰는 정책을 구성하라. world 빛은 L=(1,0,0)이다.

힌트 1

두 저장 RGB는 x 성분만 1과 0으로 다르다.

힌트 2

0으로 나누기 전에 fallback 분기를 둔다.

풀이와 답 확인

  1. RGB는 (1,1/2,1/2)와 (0,1/2,1/2), 평균은 (1/2,1/2,1/2)라 해석 결과가 0이다.

  2. 영벡터에서는 정규화하지 않고 명시 world N을 선택한다. 계수는 1이지만 원래 두 world 법선은 ∓z여서 각각 계수 0이다.

fallback의 계수 1은 원래 조명 평균 0을 복원한 것이 아니라 새 정책이다.

흔한 오답에서 다시 생각하기

평균 법선이 0이면 밝기 0 또는 1 중 하나가 수학적으로 유일하다.

방향이 없으므로 정규화와 조명 의미를 별도 정책 없이 확정하지 않는다.

연습 4 · 선택 심화

선택 심화는 기본 연습 뒤 더 탐구하고 싶을 때 풀어 보세요.

T=(2,0,0),B=(0,1,0),N=(0,0,1)을 열로 둔 별도 행렬에서 transpose가 inverse라는 주장을 시험하라. 벡터 (1,0,0)를 world로 옮긴 뒤 transpose로 되돌린다. 이 행렬을 위 직교 단위 TBN 계약에 승인하지 않는다.

힌트 1

첫 축의 길이는 2다.

힌트 2

앞/뒤 변환에서 각각 x에 2가 곱해진다.

풀이와 답 확인

  1. world 결과는 (2,0,0)이고 transpose로 다시 계산하면 (4,0,0)이다. 원래 (1,0,0)이 아니다.

  2. 축의 직교성만으로는 부족하며 길이 1까지 필요하다. 올바른 inverse는 이 행렬에서 x를 1/2로 바꾼다.

단위 직교 조건을 검사하지 않고 transpose를 역변환으로 쓰지 않는다.

흔한 오답에서 다시 생각하기

세 축이 서로 수직이면 길이와 무관하게 transpose=inverse다.

QᵀQ의 첫 대각 성분이 4이므로 항등행렬이 아니다.

서로 독립인 세 사례를 감사하라. ① 한 축 자료 [0,4,8,20]과 T1 sampler에서 끝 UV 0.9/1.1을 반씩 보간한 결과를, 먼저 각 끝을 repeat한 뒤 보간한 결과와 비교한다. 기하 위치는 고정이다. ② 8×2 자료의 두 행이 모두 [0,0,0,0,1,1,1,1]이고 T2의 축별 최소 1 평균 체인과 칸당 4바이트 저장을 쓴다. 레벨별 값·전체 바이트·기본 대비 추가량을 적는다. 별도 atlas [0,0,1,1]의 u=3/8에서 기본과 레벨 1을 반씩 섞는 값도 구한다. ③ 기본 TBN에서 n+/n−의 반반 RGB 평균 뒤 정규화하여 world L=(1,0,0)의 계수를 구하고, 원래 두 조명 계수 평균과 비교한다. 별도 거울 B에서 n=(0,3/5,4/5)와 world L=(0,1,0)의 결과도 적는다. 실제 sampler/shader/GPU/학생 실행은 하지 않는다.

힌트 1

① 연속 u=1과 미리 감싼 평균 u=1/2를 구별한다. ② 세로가 1이어도 가로 감소는 계속된다. atlas는 레벨별 중심을 새로 계산한다.

힌트 2

③ RGB 해석, 길이 검사, 정규화, TBN 변환, 같은 공간 내적의 순서를 적는다. 두 조명 평균은 별도 목표다.

풀이와 답 확인

  1. ① 연속 UV의 중간은 u=1이며 repeat 샘플 값은 10이다. 먼저 감싼 두 끝은 0.9와 0.1, 그 중간은 u=1/2로 샘플 값 6이다. UV 경로만 바뀌고 기하 위치는 유지된다.

  2. ② 레벨 자료는 두 원래 행, [0,0,1,1], [0,1], [1/2]다. 전체 16+4+2+1=23칸, 92바이트이며 기본 64바이트에서 28바이트 추가다. atlas의 기본 샘플 0과 레벨 1의 1/4를 반씩 섞으면 1/8이다.

  3. ③ 해석 평균은 tangent (0,0,4/5)라 정규화 후 (0,0,1), world (1,0,0) 및 계수 1이다. 원래 두 world 계수는 각각 4/5라 평균 4/5다. 별도 거울 법선은 world (4/5,−3/5,0)여서 +y 빛 계수 0이다.

연속 UV 보간의 샘플 값은 10이고 정점별 repeat를 먼저 적용한 값은 6이다. 직사각형 체인의 전체 저장량은 92바이트, 기본 대비 추가량은 28바이트다. atlas의 두 레벨 혼합 값은 1/8이다. 법선 혼합 뒤 정규화의 계수는 1이며 원래 두 조명 계수의 평균 4/5와 다르다. 별도 거울 기저에서 +y 빛의 계수는 0이다.

해결한 뒤 점검할 것

  • 두 UV 처리 순서의 중간 좌표·이웃·값을 각각 재계산하고 위치와 그림 좌표를 구별한다.

  • 축별 감소와 레벨 자료·전체/추가 바이트를 계산하며 atlas의 다른 레벨 이웃을 확인한다.

  • 법선 평균의 길이와 TBN의 단위 직교/손잡이 조건을 적고 두 조명 목표를 분리한다.

  • 각 사례의 자료/빛/좌표계를 독립 초기 조건으로 사용하고 실제 GPU·성능·기하 변화·학생 검증은 미수행으로 둔다.
