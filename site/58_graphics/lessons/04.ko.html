소단원 4.1

edge function

삼각형이 화면의 어느 작은 점을 덮는지 세 번의 계산으로 판단할 수 있을까?

준비 개념과 학습 목표

준비 개념

  • 2차원 점은 (x,y)로 표현한다.

  • 행렬식 ux·vy−uy·vx는 방향 있는 면적을 나타낸다.

  • 이 예의 y축은 위쪽이며 화면 API의 좌표 규약과 다를 수 있다.

학습 목표

  • 방향 있는 변과 점의 위치를 edge function의 부호로 판단한다.

  • 삼각형 방향과 내부 조건을 함께 확인한다.

  • 샘플 검사와 공통 경계의 소유 규칙을 구별한다.

변의 어느 쪽에 있는가

방향 있는 변 U→V와 점 P에 대해 E(U,V,P)=(Vx−Ux)(Py−Uy)−(Vy−Uy)(Px−Ux)로 정의하자. y축이 위쪽인 이 좌표에서는 양수가 왼쪽, 음수가 오른쪽, 0이 변을 포함한 직선 위라는 뜻이다. E는 거리 자체가 아니다. 변의 길이가 달라지면 같은 수직 거리라도 값의 크기가 달라진다.

A,B,C가 반시계 방향인 비퇴화 삼각형이면 내부 점은 세 방향 변 A→B, B→C, C→A의 왼쪽에 있다. 따라서 세 E가 모두 양수이면 엄밀한 내부다. 모두 0 이상이면 경계를 포함한 기하학적 삼각형에 속한다. 정점 순서를 거꾸로 하면 부호와 검사 방향도 바뀐다.

격자의 점을 검사하는 래스터화

래스터화는 연속적인 삼각형을 화면의 샘플 위치에서 검사하는 과정이다. 단순 모델은 정수 i,j의 픽셀마다 중심 (i+0.5,j+0.5)을 하나의 샘플로 사용한다. 삼각형의 최소·최대 x,y로 만든 경계 상자는 검사할 후보를 줄여 주지만 상자 안의 모든 점이 삼각형 안에 있는 것은 아니다.

이 단원에서는 투영과 클리핑을 마친 2차원 삼각형을 입력으로 놓고 단일 샘플 모델을 사용한다. 샘플 하나가 내부라는 사실은 픽셀 면적 전체가 삼각형에 덮였다는 뜻이 아니다. 여러 샘플을 사용하는 안티앨리어싱은 덮임을 더 자세히 추정하는 별도 확장이며 실제 GPU의 작업 수를 이 종이 모델과 동일시하지 않는다.

경계와 퇴화 삼각형

같은 변을 공유하는 두 삼각형이 경계 샘플을 모두 포함하면 두 번 처리하고, 모두 제외하면 틈이 생긴다. 실제 래스터화는 일관된 한쪽 포함 규칙을 사용한다. Direct3D의 top-left 규칙과 OpenGL의 공통 변에 있는 샘플은 정확히 한 삼각형만 생성한다는 요구가 이 문제를 다룬다.

이 예의 E≥0은 경계를 포함하는 기하학 검사이며 공통 변을 가진 전체 메시의 최종 픽셀 소유 알고리즘은 아니다. 특정 API의 좌표와 경계 규칙을 추가해야 한다. D=E(A,B,C)=0이면 세 점이 한 직선에 있거나 겹친 퇴화 삼각형이다. 면적이 0인 입력을 보통 삼각형의 보간 분모로 사용하지 않는다.

중간 과정을 따라가는 예제

y 위쪽 좌표에서 A=(0,0), B=(4,0), C=(0,4)다. P=(1,1), Q=(3,2), R=(2,2)의 기하학적 포함을 E 함수로 판정하라. 공통 경계의 최종 소유 규칙은 아직 적용하지 않는다.

  1. D=E(A,B,C)=4·4−0=16>0이므로 반시계 방향이며 모든 E≥0 검사를 쓴다.

  2. 세 식은 EAB=4y, EBC=16−4x−4y, ECA=4x다. 예를 들어 B→C=(-4,4)를 점 P−B와 행렬식으로 계산하면 가운데 식을 얻는다.

  3. P에서는 EAB=4, EBC=8, ECA=4다. 모두 양수여서 엄밀한 내부다.

  4. Q에서는 8, −4, 12다. 하나가 음수이므로 경계 상자 안이어도 삼각형 밖이다.

  5. R에서는 8, 0, 8이다. BC 위의 기하학적 경계다. 메시에서 어느 삼각형이 이 샘플을 맡을지는 별도 규칙으로 결정한다.

P는 내부, Q는 외부, R은 BC 경계다. D=16은 면적 8의 두 배이며 거리 값이 아니다.

종이와 본문으로 직접 해보기

샘플 H=(0.5,0.5), J=(3.5,0.5), K=(3.5,1.5)의 세 E 값을 구하고 내부·경계·외부를 나누라. 정점 C와 B를 교환하면 내부 H의 부호가 어떻게 바뀌는지도 설명하라.

힌트 보기

EAB=4y, EBC=16−4(x+y), ECA=4x를 사용하라. 정점 교환 뒤에는 새 방향의 세 변으로 계산한다.

풀이 보기

H는 (2,12,2)라 내부다. J는 (2,0,14)라 경계다. K는 (6,−4,14)라 외부다. A,C,B 순서에서 H의 새 변 AC,CB,BA 값은 (−2,−12,−2)이며 D=−16이다. 이때 내부 조건도 부호를 바꾸어 E≤0을 사용해야 한다.

오해와 반례

경계 상자 안의 픽셀은 전부 삼각형에 속하고 E의 크기는 실제 거리다.

Q와 K는 상자 안이지만 비스듬한 BC 밖에 있다. E는 행렬식이며 방향과 변의 길이에 영향받는다. 부호는 쪽을 알려 주지만 거리로 읽으려면 변 길이로 나누는 등의 별도 정의가 필요하다.

자기점검

D=16인 삼각형의 면적은?

답과 이유 보기

8

행렬식 D는 방향 있는 면적의 두 배이므로 |D|/2다.

모든 E≥0이면 공유 변의 샘플 중복도 해결되는가?

답과 이유 보기

해결되지 않는다

경계를 포함하는 기하학 검사만으로는 두 이웃이 같은 점을 처리할 수 있어 한쪽 소유 규칙이 필요하다.

D=0을 보간 분모로 써도 되는가?

답과 이유 보기

안 된다

삼각형이 퇴화해 0으로 나누며 비퇴화 삼각형의 좌표 공식을 적용할 수 없다.

한 단계 더

심화: E(U,V,(x+1,y))−E(U,V,(x,y))=−(Vy−Uy), y를 1 올렸을 때의 차이는 Vx−Ux다. 한 행에서 값을 조금씩 갱신할 수 있다는 뜻이다. 위 삼각형의 세 식으로 차이를 검산하고, 실제 구현에서는 부동소수점 오차와 일관된 경계 처리를 함께 검토해야 함을 설명해 보자.

소단원 4.2

무게중심좌표

한 점을 세 꼭짓점의 혼합 비율로 쓰면 색과 위치를 함께 계산할 수 있을까?

준비 개념과 학습 목표

준비 개념

  • edge function의 부호와 삼각형의 방향을 이해한다.

  • 가중합은 각 값에 비율을 곱해 더하는 계산이다.

  • 삼각형이 퇴화하지 않아야 면적비를 정의할 수 있다.

학습 목표

  • 각 정점의 반대편 변을 이용해 무게중심좌표를 계산한다.

  • 좌표합과 점의 재구성으로 결과를 검산한다.

  • 내부 보간과 외부 외삽을 구별한다.

면적비를 정점의 가중치로 바꾸기

D=E(A,B,C)≠0인 삼각형에서 λA=E(B,C,P)/D, λB=E(C,A,P)/D, λC=E(A,B,P)/D로 둔다. 각 정점의 가중치에는 그 정점 반대편 변을 사용한다. 모든 식은 동일한 정점 순서와 방향 있는 행렬식 규약을 따른다. 단순히 가까운 정점까지의 거리의 역수로 정한 비율은 이 정의와 다르다.

λA+λB+λC=1이고 P=λA A+λB B+λC C다. 비퇴화 삼각형에서 이 두 관계가 위치를 유일하게 나타낸다. 점이 내부 또는 경계에 있으면 각 λ는 0 이상 1 이하다. 외부 점에도 좌표를 계산할 수 있지만 일부가 음수여서 내부의 혼합과 다른 외삽이 된다.

위치와 수치 속성의 보간

평면에서 선형적으로 바꿀 수 있는 정점 속성 aA,aB,aC는 a(P)=λA aA+λB aB+λC aC로 보간한다. A에서 가중치가 (1,0,0)이므로 A의 속성이 그대로 나온다. BC 위에서는 λA=0이어서 B와 C의 속성만 사용한다. 내부에서는 가중치가 음수가 아니고 합이 1이므로 스칼라 결과가 꼭짓점 값의 최솟값과 최댓값 사이에 있다.

이 계산은 적용할 속성과 좌표 공간을 명시해야 한다. 여기서는 2차원 위치에 대해 선형인 가상의 스칼라 신호를 다루며 실제 색의 감마 변환이나 원근 투영한 3차원 속성을 자동 해결한다고 하지 않는다. 색 벡터라면 각 성분에 가중합을 적용하지만 올바른 색 공간도 따로 정해야 한다.

검산과 실패 조건

가중치 합만 1이라고 정답은 아니다. (1,0,0)은 합이 1이지만 모든 P를 A로 재구성한다. 따라서 좌표합, 재구성 위치, 내부 부호를 함께 확인한다. 정점의 반대편 변을 잘못 대응하면 합은 맞아도 엉뚱한 위치나 속성이 나올 수 있다.

D=0이면 분모가 0이므로 일반 공식이 정의되지 않는다. 매우 작은 D에서는 부동소수점 오차가 커질 수 있고 화면에서 거의 선처럼 보이는 삼각형의 처리 정책도 필요하다. 종이 예에서는 정수 행렬식과 정확한 분수를 사용하므로 GPU의 유한 정밀도 동작을 측정한 것으로 해석하지 않는다.

중간 과정을 따라가는 예제

A=(0,0), B=(4,0), C=(0,4), P=(1,1)이다. 가상의 스칼라 속성은 A에서20, B에서40, C에서80이다. 무게중심좌표와 P의 보간 값을 계산하라.

  1. D=16이며 P에서 반대편 변 EBC=8, ECA=4, EAB=4다.

  2. λA=8/16=1/2, λB=4/16=1/4, λC=4/16=1/4로 대응한다.

  3. 합은 1/2+1/4+1/4=1이다. 위치 재구성은 (1/2)(0,0)+(1/4)(4,0)+(1/4)(0,4)=(1,1)이다.

  4. 속성은 (1/2)20+(1/4)40+(1/4)80=10+10+20=40이다.

  5. 20≤40≤80이므로 내부 가중합의 범위 조건도 만족한다. 단순 세 값 평균 140/3은 이 점의 가중치와 다르다.

P의 좌표는 (1/2,1/4,1/4), 위치는 (1,1)로 재구성되며 속성은40이다.

종이와 본문으로 직접 해보기

R=(2,2)와 Q=(3,2)의 무게중심좌표, 같은 속성의 가중합을 계산하라. Q의 결과가 꼭짓점 범위 안이면 내부라고 결론 내릴 수 있는지도 판단하라.

힌트 보기

λA=1−x/4−y/4, λB=x/4, λC=y/4다. 내부 판단은 속성 결과가 아니라 좌표 부호를 사용한다.

풀이 보기

R은 (0,1/2,1/2)이고 속성60이다. Q는 (−1/4,3/4,1/2)이고 속성−5+30+40=65다. Q는 음수 λA 때문에 외부다. 속성65가 20과80 사이에 있다는 것은 내부의 충분조건이 아니다.

오해와 반례

무게중심좌표는 항상 세 값이 모두 양수이고 속성을 같은 비율로 평균내는 것이다.

내부·경계에서는 음수가 없지만 외부에서는 음수가 가능하다. 비율은 위치로 결정되며 중심점 등 특별한 위치에서만 모두1/3이다. 경계에서는 0인 가중치가 있을 수 있다.

자기점검

A 정점의 좌표는?

답과 이유 보기

(1,0,0)

A를 λA A+λB B+λC C로 재구성하며 반대편 면적은 전체 면적과 같고 나머지는0이다.

Q의 속성65가 범위 안인데 왜 외부인가?

답과 이유 보기

λA가−1/4이기 때문이다

속성 한 값의 범위만으로 기하학적 포함을 결정할 수 없다.

λ합1만 확인하면 충분한가?

답과 이유 보기

충분하지 않다

한 단계 더

소단원 4.3

보간과 visibility

점이 삼각형 안에 있다는 사실만으로 그 삼각형의 색을 화면에 써도 될까?

준비 개념과 학습 목표

준비 개념

  • 무게중심좌표의 합과 가중합을 계산한다.

  • 동차 좌표의 w로 나누면 화면 위치를 얻는다.

  • coverage는 덮임이고 visibility는 그 점에서 실제 보이는 표면의 결정이다.

학습 목표

  • 화면 가중치와 clip w를 사용해 원근 보정 속성을 계산한다.

  • 표면 속성과 window depth의 보간 규칙을 구별한다.

  • 불투명 샘플의 깊이 검사와 동률·투명성 조건을 설명한다.

화면에서 반이 표면에서 반은 아니다

원근 투영에서 동차 좌표를 w로 나누면 가까운 부분과 먼 부분의 화면 크기가 달라진다. 따라서 화면의 λ로 표면 속성을 그냥 평균내면 의도한 3차원 선형 보간과 어긋날 수 있다. clip wA,wB,wC가 알려졌을 때 보정 속성은 a=(Σλi ai/wi)/(Σλi/wi)다.

이 예에서는 클리핑을 마친 유효 삼각형, 각 wi>0, 내부의 λ≥0을 사용하므로 분모가 양수다. w=0인 점을 그대로 나누거나 시점 뒤의 삼각형을 클리핑 없이 적용하지 않는다. 모든 w가 같으면 공통 나눗셈이 약분되어 보통 가중합으로 돌아간다. 속성이 화면 선형 보간을 의도한 경우에는 별도 noperspective 규칙을 선택할 수 있다.

깊이와 속성을 같은 이름으로 처리하지 않기

화면 공간에서 사용하는 깊이는 카메라에서의 실제 거리와 항상 같은 수가 아니다. OpenGL의 기본 삼각형 래스터화에서 window depth는 z=Σλi zi로 선형 보간하며 일반 속성의 w 보정 식과 구별한다. 이미 투영과 viewport 변환을 거친 깊이에 다시 같은 보정을 적용하면 다른 값을 만든다. 원고에서는 표면 속성 a, clip w, 검사할 depth d를 별도 기호로 쓴다.

깊이 버퍼는 각 샘플에서 지금까지 통과한 깊이와 색을 기억한다. 이 종이 모델은 불투명 표면, 더 작은 d가 가까움, 엄격한 비교 d<stored, 성공 시 깊이와 색을 함께 덮어쓰기로 정의한다. 실제 API에서는 역방향 깊이, 비교 함수, 쓰기 마스크와 깊이 형식 등이 달라질 수 있으므로 모델 조건을 먼저 확인한다.

덮임 검사 뒤의 가려짐 검사

한 샘플을 덮는 삼각형이 여러 개라면 coverage 검사를 통과한 후보끼리 깊이를 비교한다. 깊이가 모두 다른 불투명 후보에서는 주어진 최소 깊이가 마지막 색을 결정한다. 깊이가 같은 후보에서는 엄격한 < 비교로 나중 후보가 실패하므로 먼저 기록한 색이 남는다. 동률까지 항상 순서 무관하다고 일반화하지 않는다.

투명 표면은 뒤의 색도 기여하므로 가장 가까운 하나를 덮어쓰는 모델만으로 해결되지 않는다. 블렌딩과 그 순서, 깊이 읽기·쓰기 정책이 필요하다. 또한 여러 샘플과 GPU 정밀도에서의 결과는 이 계산의 실행 결과가 아니다. 아래 활동은 숫자와 조건을 종이로 추적한 것이다.

중간 과정을 따라가는 예제

한 내부 샘플의 화면 λ=(1/2,1/4,1/4), clip w=(1,2,2), 표면 속성 a=(0,8,8)이다. 원근 보정 값을 계산하라. 별도로 같은 샘플을 덮는 불투명 후보 P,Q,R의 depth는0.6,0.4,0.5이며 순서 P→Q→R, 초기 stored=∞, 비교는 <다.

  1. 속성 분자는 (1/2)0/1+(1/4)8/2+(1/4)8/2=0+1+1=2다.

  2. 분모는 (1/2)/1+(1/4)/2+(1/4)/2=1/2+1/8+1/8=3/4다.

  3. 보정 속성은 2/(3/4)=8/3이다. 보정 없는 가중합은4로 서로 다르다.

  4. 깊이 P의0.6<∞이므로 stored=0.6, 색P다. Q의0.4<0.6이므로 stored=0.4, 색Q로 바뀐다.

  5. R의0.5<0.4는 거짓이므로 갱신하지 않는다. 최종 stored=0.4, 색Q다. 속성의 보정 계산과 깊이 후보 비교는 서로 다른 작업이다.

원근 보정 속성은8/3이고 단순 화면 가중합4와 다르다. 가시성 모델의 최종 색은Q, depth는0.4다.

종이와 본문으로 직접 해보기

같은 λ에서 w를 모두2로 바꾸고 속성(0,8,8)은 유지할 때 보정 값을 구하라. 깊이 순서를 R→P→Q로 바꾸면 최종 결과는? 마지막에 depth0.4인 다른 색S를 추가하면?

힌트 보기

같은 w는 분자·분모에서 약분된다. 엄격한 <는 같은 깊이에서 실패한다.

풀이 보기

분자는 (1/2)0/2+(1/4)8/2+(1/4)8/2=2, 분모는1/2이므로 속성4다. R0.5가 기록되고 P0.6은 실패, Q0.4가 교체하므로 최종Q0.4다. S0.4는0.4<0.4가 거짓이라 Q를 바꾸지 않는다. S를 Q보다 먼저 처리했다면 동률에서 S가 남을 수 있다.

오해와 반례

모든 수치는 원근 보정 식으로 처리하면 되고 깊이 버퍼는 투명 표면도 순서 없이 해결한다.

window depth와 일반 표면 속성의 보간 규칙은 구별한다. 불투명 후보의 서로 다른 깊이에서 최소값을 고르는 조건과 동률·투명 블렌딩 조건도 다르다. 투명 색은 여러 표면의 기여를 합치는 별도 과정이 필요하다.
