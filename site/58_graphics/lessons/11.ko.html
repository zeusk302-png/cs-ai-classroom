소단원 11.1

표본추정

모든 방향의 빛을 계산하지 않고 몇 방향만 보면 무엇을 알 수 있을까?

준비 개념과 학습 목표

준비 개념

  • 평균과확률

  • 함수값과적분

학습 목표

  • 적분과표본평균관계를설명한다

  • 확률가중치와지지조건을검사한다

  • 불편성과한표본정확성을구별한다

많은 값을 평균으로 살핀다

적분은 영역 전체의 함수 기여를 합치는 계산이다. Monte Carlo는 정한 확률분포로 표본을 선택해 가중한 평균으로 추정한다. [0,1]의 독립 균등 표본에서는 I=∫₀¹f(x)dx를 f값의 평균으로 추정할 수 있다. 구간 폭이 1이 아니면 폭 또는 확률밀도가 가중치에 들어간다.

f(x)=x의 실제 적분은 손으로 I=[x²/2]₀¹=.5라고 계산할 수 있다. 가상 선택 위치 .1,.4,.7,.8의 평균도 .5지만 표본이 항상 같은 정답을 낸다는 뜻은 아니다. 미리 정한 목록은 무작위 생성을 실행한 증거도 아니다.

많이뽑은만큼나눈다

일반 밀도 p(x)로 선택하면 한 표본 기여는 f(x)/p(x)이고 N개 평균을 쓴다. f가 0이 아닌 영역에서 p가 0이면 그 기여를 선택할 수 없어 일반적인 불편 추정 조건을 어긴다. 자주 뽑은 방향의 큰 값을 가중치 없이 더하면 편향될 수 있다.

유한 범주에서는 밀도 대신 PMF를 쓴다. 합 F=f(A)+f(B)를 구하려면 범주 i를 확률 p(i)로 뽑아 f(i)/p(i)를 쓴다. 기댓값은 Σp(i)f(i)/p(i)=Σf(i)로 원하는 합이다. 확률 합 1과 필요한 범주의 양수 조건을 먼저 확인한다.

평균으로맞음과매번맞음

불편 추정량은 반복 표본 선택 전체의 기댓값이 목표와 같다는 성질이다. 유한한 한 번의 추정값이 정답과 다르더라도 즉시 알고리즘 오류라고 하지 않는다. 우연히 정답인 한 사례만으로 분포 설계가 옳다고 결론 내리지도 않는다.

많은 표본의 수렴에는 분포·독립성·적분 가능성 등의 조건을 확인한다. 계산 비용과 분산도 중요하다. 이 단원은 렌더러나 새 무작위 표본 생성을 실행하지 않고 주어진 목록과 정의된 확률을 종이에서 분석한다.

중간 과정을 따라가는 예제

두 범주 기여 f(A)=2, f(B)=6의 합 8을 추정한다. p(A)=.25, p(B)=.75일 때 각 가중값과 선택 목록 A,B,B,B의 평균은?

  1. A의 가중값은 2/.25=8, B는 6/.75=8이다. 확률 합은 1이다.

  2. 목록의 가중값은 8,8,8,8이고 평균은 32/4=8이다.

  3. 기댓값도 .25×8+.75×8=8이다. 이 특별한 분포에서는 두 가중값이 같다.

목록 추정값과 목표 합은 모두 8이다. 자체 두 값 모형에서 기여에 비례한 확률이 가중값을 같게 만들었다.

풀이 보기

한 단계 더

균등 두 범주에서 확률로 나누지 않으면 한 표본 기댓값은 .5×2+.5×6=4다. 목표 합 8이 아니라 평균 4를 구하는 다른 문제가 된다. 원래 목표가 평균이면 추정식도 달라져야 하므로 원하는 합·적분·평균을 먼저 명시하라.

소단원 11.2

직접·간접조명

광원이안보이는벽도다른벽에서온빛으로밝아질수있을까?

준비 개념과 학습 목표

준비 개념

  • 빛의반사

  • 곱셈과경로

학습 목표

  • 카메라경로와실제빛의이동을구별한다

  • 직접/간접항과가시성을판정한다

  • 중복기여와종료가중치를검사한다

어떤경로에서빛이오는가

카메라가 처음 보는 표면 A에 광원에서 바로 오는 기여는 직접 조명이고, 다른 표면 B에서 반사되어 A로 오는 기여는 간접 조명의 한 예다. 광원을 직접 보는 방출항도 별도로 있다. 실제 빛의 이동과 카메라에서 역으로 경로를 구성하는 계산 방향을 구별한다.

path tracing은 카메라 광선의 교점에서 방향을 표본으로 정하고 다음 교점을 찾으며 경로를 연장한다. 광원 쪽 가시성과 재질·방향·확률 가중치는 각 경로 기여에 관여한다. 반사 횟수만 세고 거리·방향·가림을 빼면 실제 장면 빛을 정확히 계산한 것이 아니다.

표본확률과기여를함께관리한다

광원을 직접 표본화해 연결하는 next event estimation은 직접항을 효율적으로 추정하는 방법이다. BSDF 방향 추적도 광원을 만날 수 있어 중복 기여를 어떻게 처리할지 정해야 한다. 여기서는 두 기여 집합이 겹치지 않는다고 먼저 정한 유한항 모형을 쓴다.

아래 숫자는 기하·확률 보정 등을 이미 묶어 정한 가상 경로 계수다. 단순 재질 반사율의 곱을 완전한 rendering equation으로 읽지 않는다. 광원 radiance 10의 두 항을 합할 뿐 장면 전체의 광원 power나 에너지 예산을 측정하는 것은 아니다.

가림과종료는결과를바꾼다

경로에 막힌 구간이 있으면 현재 모형의 visibility가 0이 되어 그 항이 사라진다. 직접항이 0이어도 모든 간접항이 0인 것은 아니다. 다른 표면을 경유하는 열린 경로를 별도로 확인한다.

반사 깊이를 고정해 자르면 남은 항이 존재하는 장면에서 편향이 생길 수 있다. Russian roulette는 일부 경로를 종료하되 살아남은 기여를 생존 확률로 나누어 조건에 맞는 기댓값을 보존한다. 특정 실행의 값을 동일하게 보존하거나 분산을 항상 낮추는 방법은 아니다.

중간 과정을 따라가는 예제

자체 유한항 모형에서 카메라→A→광원 직접항의 합성 계수는 .5, 카메라→A→B→광원 간접항은 .5×.25이고 광원값은 10이다. 두 항의 visibility는 1, 집합은 중복되지 않는다. 합과 B→광원만 막힌 별도 상황을 계산하라.

  1. 직접항은 .5×10=5, 간접항은 .5×.25×10=1.25다.

  2. 합은 5+1.25=6.25다. 두 항으로 정한 문제의 전수 계산이다.

  3. B→광원의 visibility가 0이면 간접항은 0이고 직접항 5는 그대로다.

열린 두 항은 6.25, 간접 경로 가림 상황은 5다. 물리 장면 전체의 무한 경로 적분이나 렌더링 측정은 아니다.

종이와 본문으로 직접 해보기

직접 A→광원만 가리고 간접 경로는 열리면 합은? 별도로 남은 기여 C=2를 생존 확률 q=.5로 roulette하면 종료·생존값과 기댓값은?

힌트 보기

직접 가림과 간접 가림은 다르다. 생존값은 C/q다.

풀이 보기

직접 0+간접 1.25=1.25다. roulette의 종료값은 0, 생존값은 4이고 기댓값 .5×0+.5×4=2로 원래 C와 같다.

오해와 반례

광원 직접 연결과 방향 추적에서 같은 기여를 둘 다 더하면 더 정확하다.

직접항 5를 중복하면 총 11.25가 되어 모형값 6.25를 어긴다. 기여 집합 분리나 적절한 결합 가중 방법이 필요하다.

분산·노이즈·수렴

표본을두배로늘리면노이즈도항상절반으로줄까?

준비 개념과 학습 목표

준비 개념

  • 기댓값과평균

  • 제곱과제곱근

학습 목표

  • 분산과표준오차를구별한다

  • 독립표본평균의표본수효과를계산한다

  • 편향과유한표본의함정을설명한다

반복실행값의흩어짐

분산은 값과 기댓값의 차이를 제곱하여 평균한 값이다. Var(X)=E[X²]−E[X]²로도 계산할 수 있다. 표준편차는 분산의 제곱근이며 원래 값과 같은 단위다. 렌더링의 입자 같은 노이즈는 유한 표본 기여가 흩어지는 현상과 관련된다.

동일 분포의 독립 표본 N개 평균은 분산 σ²/N, 표준오차 σ/√N을 갖는다. 독립성·유한 분산 가정이 필요하고 상관 표본이나 다른 추정량에 그대로 대입하지 않는다. 반복 표본 전체의 성질이며 한 그림의 모든 픽셀이 단조롭게 좋아진다는 보장은 아니다.

표본을늘리는비용

표준오차를 절반으로 만들려면 N을 네 배로 늘려야 한다. 표본 두 배는 1/√2배로 줄이는 관계다. 표본당 비용이 같다면 네 배 표본은 네 배 비용이므로 더 효율적인 표본분포 설계가 필요할 수 있다.

올바른 확률 가중치를 갖춘 importance sampling은 기여와 비슷한 분포를 선택해 분산을 줄일 수 있다. 그러나 PDF 평가·표본 생성 비용과 어려운 기여·델타 등의 조건이 남는다. 특정 모형의 분산 0을 모든 장면에 일반화하지 않는다.

오차의종류를나눈다

불편 추정량에서는 MSE가 분산과 같지만 편향 추정량에서는 MSE=분산+편향²다. 고정 깊이로 남은 조명항을 없애는 편향은 같은 잘못된 계산을 많이 반복한다고 자동 사라지지 않는다. 노이즈 제거로 매끈한 그림도 정확성을 보장하지 않는다.

표본분산 s²=Σ(xi−평균)²/(N−1)은 N≥2의 유한 표본으로 모분산을 추정한다. 큰 기여가 드문 분포에서 짧은 목록이 모두 같으면 표본분산 0이어도 실제 분산은 양수일 수 있다. 실측 범위와 통계 추정을 구별한다.

중간 과정을 따라가는 예제

같은 확률 .5/.5로 기여 X=4 또는 12를 갖는 모형에서 평균·분산·N=4/N=16 독립 표본 평균의 표준오차를 구하라.

  1. E[X]=.5×4+.5×12=8, E[X²]=.5×16+.5×144=80이다.

  2. Var(X)=80−64=16이므로 σ=4다.

  3. N=4 평균의 분산은 4, 표준오차는 2다. N=16에서는 분산 1, 표준오차 1이다.

표본 수를 4→16으로 네 배 늘리면 표준오차는 2→1로 절반이다. 확률 모형 계산이며 실행 오차 측정은 아니다.

종이와 본문으로 직접 해보기

주어진 목록 4,4,12,12의 표본평균과 s²는? N=64의 이론 표준오차는?

힌트 보기

평균 8에서 차이는 각각 ±4이고 표본분산 분모는 N−1이다.

풀이 보기

평균 8, 편차 제곱합 4×16=64, s²=64/3≈21.333이다. 모분산 16과 다를 수 있다. N=64의 이론 표준오차는 4/8=.5다.

오해와 반례

표본을 두 배로 늘리면 표준오차가 절반이고 표본분산 0이면 모분산도 0이다.

독립 동분포·유한 분산에서 두 배는 1/√2배다. 짧은 목록 4,4의 표본분산은 0일 수 있지만 이 분포의 모분산 16은 남는다.

자기점검

N=4→N=16에서 평균 분산은 몇 배인가?

답과 이유 보기

1/4.

16/N의 분모가 네 배이며 표준오차는 그 제곱근인 1/2배다.

편향 2·분산 1인 추정량의 MSE는?

답과 이유 보기

5.

1+2²=5다.

같은 분포라도 표본들이 완전히 같이 움직이면 σ²/N 공식은 항상 맞는가?

답과 이유 보기

아니다.

상관에 따른 공분산 항을 확인해야 한다.

한 단계 더

가상 추정 A의 한 표본 분산 16·비용 1, B의 분산 8·비용 3을 가정한다. 비용 12에서 A의 12개 평균 분산은 16/12=4/3, B의 4개 평균 분산은 8/4=2다. B의 개별 분산이 작아도 같은 예산에서는 A가 더 작다. 독립 표본과 고정 비용을 명시한 비교이며 실제 렌더러 벤치마크는 아니다.
