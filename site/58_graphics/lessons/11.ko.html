음수 항이 섞이면 기여에 비례한 확률을 그대로 만들 수 있을까?

앞 본문의 유한 범주 합을 부호가 있는 차이 장부로 확장한다. f(A) = 1, f(B) = 3, f(C) = −2이며 목표는 합 F = 2다. 음수는 두 계산의 차이 같은 대수적 기여를 나타내고 음수인 물리 radiance를 가정하지 않는다. 모든 값은 공통 가상 단위다. 범주 확률은 p(A) = 1/4, p(B) = 1/2, p(C) = 1/4로 정한다.

한 번 뽑은 범주의 값 f/p는 A에서 4, B에서 6, C에서 −8이다. 기댓값은 1+3−2 = 2다. 제곱의 기댓값은 4+18+16 = 38이므로 분산은 38−2² = 34다. 음수를 선택할 수 없도록 p(C)를 0으로 만들면 목표의 음수 항을 잃는다. 확률 정규화와 지원 범위 조건을 각각 검사한다.

절댓값의 합 6으로 나눈 별도 확률은 1/6, 1/2, 1/3이다. 새 가중값은 6, 6, −6이며 기댓값은 여전히 2, 분산은 36−4 = 32다. 양수 항만 있는 앞 예제와 달리 부호가 남으므로 상수 가중값이 되지 않는다. 아래 선택 목록은 미리 지정한 목록이며 실제 난수 생성 기록이 아니다.

    범주 확률로 나눈 값의 기댓값이 목표 합이 되는 앞 논증을 읽는다.

  • 분산과 기댓값

    제곱의 기댓값에서 평균 제곱을 빼는 계산을 준비한다.

많은 값을 평균으로 살핀다

적분은 영역 전체의 함수 기여를 합치는 계산이다. Monte Carlo는 정한 확률분포로 표본을 선택해 가중한 평균으로 추정한다. [0,1]의 독립 균등 표본에서는 I=∫₀¹f(x)dx를 f값의 평균으로 추정할 수 있다. 구간 폭이 1이 아니면 폭 또는 확률밀도가 가중치에 들어간다.

f(x)=x의 실제 적분은 손으로 I=[x²/2]₀¹=.5라고 계산할 수 있다. 가상 선택 위치 .1,.4,.7,.8의 평균도 .5지만 표본이 항상 같은 정답을 낸다는 뜻은 아니다. 미리 정한 목록은 무작위 생성을 실행한 증거도 아니다.

많이뽑은만큼나눈다

일반 밀도 p(x)로 선택하면 한 표본 기여는 f(x)/p(x)이고 N개 평균을 쓴다. f가 0이 아닌 영역에서 p가 0이면 그 기여를 선택할 수 없어 일반적인 불편 추정 조건을 어긴다. 자주 뽑은 방향의 큰 값을 가중치 없이 더하면 편향될 수 있다.

유한 범주에서는 밀도 대신 PMF를 쓴다. 합 F=f(A)+f(B)를 구하려면 범주 i를 확률 p(i)로 뽑아 f(i)/p(i)를 쓴다. 기댓값은 Σp(i)f(i)/p(i)=Σf(i)로 원하는 합이다. 확률 합 1과 필요한 범주의 양수 조건을 먼저 확인한다.

평균으로맞음과매번맞음

불편 추정량은 반복 표본 선택 전체의 기댓값이 목표와 같다는 성질이다. 유한한 한 번의 추정값이 정답과 다르더라도 즉시 알고리즘 오류라고 하지 않는다. 우연히 정답인 한 사례만으로 분포 설계가 옳다고 결론 내리지도 않는다.

많은 표본의 수렴에는 분포·독립성·적분 가능성 등의 조건을 확인한다. 계산 비용과 분산도 중요하다. 이 단원은 렌더러나 새 무작위 표본 생성을 실행하지 않고 주어진 목록과 정의된 확률을 종이에서 분석한다.

중간 과정을 따라가는 예제

두 범주 기여 f(A)=2, f(B)=6의 합 8을 추정한다. p(A)=.25, p(B)=.75일 때 각 가중값과 선택 목록 A,B,B,B의 평균은?

  1. A의 가중값은 2/.25=8, B는 6/.75=8이다. 확률 합은 1이다.

  2. 목록의 가중값은 8,8,8,8이고 평균은 32/4=8이다.

  3. 기댓값도 .25×8+.75×8=8이다. 이 특별한 분포에서는 두 가중값이 같다.

목록 추정값과 목표 합은 모두 8이다. 자체 두 값 모형에서 기여에 비례한 확률이 가중값을 같게 만들었다.

조건을 바꾸어 비교하기

같은 목표에서 분산이 달라진다

원래 확률과 절댓값 확률의 기댓값·분산을 비교하라.

  1. 원래 가중값의 기댓값은 2, 제곱 기댓값은 38이므로 분산은 34다.

  2. 절댓값 확률에서는 모든 가중값의 제곱이 36이다. 기댓값은 2이므로 분산은 32다.

두 추정량은 같은 합 2를 불편 추정하지만 분산은 각각 34와 32다.

비교할 점

이 자체 범주 모형의 비교이며 실제 장면의 효율 측정은 아니다.

목록 하나의 일치가 분포를 증명하지 않는다

원래 확률의 가중값으로 고정 목록 A,B,C,B와 A,A,B,C를 각각 평균하라.

  1. 첫 목록은 (4+6−8+6)/4 = 2다.

  2. 둘째 목록은 (4+4+6−8)/4 = 1.5다. 두 목록은 독립적인 지정 사례다.

첫 목록은 목표 2와 같고 둘째는 1.5다. 둘째 결과만으로 불편성을 부정할 수 없다.

비교할 점

한 목록의 평균과 모든 선택에 대한 기댓값은 다르다.

종이와 본문으로 직접 해보기

힌트 보기

선택 확률을 바꾸면 분모도 바뀐다. 목록 평균은 기댓값과 다를 수 있다.

풀이 보기

A는 4, B는 12이고 목록 평균은 (4+4+4+12)/4=6이다. 기댓값 .5×4+.5×12=8과 다르다. f(x)=x의 네 .2 목록 평균은 .2로 실제 적분 .5와 다르다.

오해와 반례

불편 추정이면 표본 한 개도 항상 정확하다.

균등 두 범주의 값 4나 12는 목표 8과 다르다. 불편성은 분포에 대한 기댓값이지 한 번의 값 보장이 아니다.

연습 1 · 값과 상태 예측

세 범주를 각각 확률 1/3으로 뽑는 별도 추정량의 가중값·기댓값·분산을 예측하라.

힌트 1

각 f를 1/3으로 나눈다.

힌트 2

제곱 기댓값을 구한 뒤 2²를 뺀다.

풀이와 답 확인

  1. 가중값은 A에서 3, B에서 9, C에서 −6이다. 기댓값은 (3+9−6)/3 = 2다.

  2. 제곱 기댓값은 (9+81+36)/3 = 42이므로 분산은 38이다.

균등 확률에서도 목표 합 2를 보존하지만 분산은 38이다.

흔한 오답에서 다시 생각하기

균등이면 원래 가중값 4, 6, −8을 유지한다.

확률을 바꾸면 f/p의 분모도 함께 바꿔야 한다.

연습 2 · 오류 찾아 고치기

음수 범주를 제거하여 p(A) = 1/4, p(B) = 3/4, p(C) = 0으로 만들었다. A/B 가중값과 기대 결과를 검사하라.

힌트 1

두 남은 가중값은 각각 1/(1/4), 3/(3/4)다.

힌트 2

삭제된 f(C)는 0이 아니다.

풀이와 답 확인

  1. A와 B의 가중값은 모두 4라서 기대 결과는 4다.

  2. 목표 합 2에 대한 편향은 +2다. C의 확률 0에서 f/p를 계산하지 말고 지원 범위 실패를 기록한다.

정규화는 맞지만 목표 합을 불편 추정하지 못한다.

흔한 오답에서 다시 생각하기

선택할 수 없는 음수는 실제 합에도 없다.

원래 목표의 항을 삭제하면 다른 합을 계산한다.

연습 3 · 직접 만들어 보기

절댓값에 비례한 세 확률을 구성하고 정규화·지원 범위·가중값의 부호를 확인하라.

힌트 1

절댓값 합은 1+3+2 = 6이다.

힌트 2

확률은 비음수이고 f의 부호는 가중값에 남는다.

풀이와 답 확인

  1. 확률 1/6, 1/2, 1/3은 합 1이고 모두 양수다.

  2. 가중값 6, 6, −6의 기댓값은 1+3−2 = 2다.

절댓값으로 확률을 만들되 가중값에서 음수를 지우지 않는다.

흔한 오답에서 다시 생각하기

f/F를 확률로 써서 1/2, 3/2, −1을 고른다.

음수 확률과 1을 넘는 범주 확률은 PMF가 아니다.

연습 4 · 선택 심화

선택 심화는 기본 연습 뒤 더 탐구하고 싶을 때 풀어 보세요.

세 확률이 모두 양수일 때 이 부호 혼합의 f/p가 항상 목표 2가 되어 분산 0일 수 있는가?

힌트 1

양수 확률로 나누어도 C의 가중값은 음수다.

힌트 2

분산 0이면 양수 확률의 모든 가중값이 기댓값과 같다.

풀이와 답 확인

  1. C에서는 −2/p(C) < 0이므로 목표 양수 2와 같을 수 없다.

  2. 이 단일 범주 f/p 추정 방식에서는 모든 지원 범주에 같은 값 2를 줄 수 없으므로 분산 0이 불가능하다.

주어진 부호 혼합과 단일 범주 방식에서는 분산 0을 만들 수 없다. 다른 추정 방식까지 금지한 주장은 아니다.

흔한 오답에서 다시 생각하기

절댓값 확률이면 항상 분산 0이다.

가중값의 크기는 같아도 부호가 달라 값 자체는 같지 않다.

내 말로 설명하기

가중값이 음수면 확률도 음수인가?

설명 기준 확인

아니다. 확률은 양수이고 기여 f의 음수 부호가 가중값에 남는다.

고정 목록이 목표와 같으면 난수 검증인가?

설명 기준 확인

아니다. 지정 목록의 손계산과 무작위 선택·통계 관찰은 구별한다.

두 번 종료를 결정했다면 어느 생존 확률로 나눌까?

앞 본문의 직접·간접 항을 겹치지 않는 자체 두 항 장부로 둔다. 이미 누적한 직접항 D = 2와 아직 계산하지 않은 간접항 C = 3의 목표 합은 5다. 실제 기하 계산이 아니라 가시성·재질·다른 확률 보정을 이미 포함한 상수 모형이다. C를 계산하려면 독립적인 생존 결정 두 개를 모두 통과해야 하며 각각의 확률은 1/2다.

전체 생존 확률은 1/4다. 중도 종료하면 남은 기여는 0, 두 번 모두 생존하면 C/(1/2×1/2) = 12다. 이미 누적한 D는 모든 결과에 남으므로 최종 값은 확률 3/4로 2, 확률 1/4로 14다. 기댓값은 5이고 분산은 27이다. 종료 결과에서도 누적한 D를 버리지 않는다.

두 번째 확률만 나누면 생존한 C를 6으로 잘못 쓴다. 최종 값 2 또는 8의 기댓값은 3.5로 목표 5보다 1.5 작다. 반면 고정 깊이로 C를 항상 생략하면 값 2만 남아 편향 −3이다. 분산이 0이라는 사실은 목표 합의 정확성을 뜻하지 않는다. 생존 결정이 이력에 의존하는 별도 사례에서는 그 이력의 조건부 확률을 사용한다.

먼저 확인할 개념
  • 직접·간접 항과 종료 보정

    누적한 항과 아직 계산하지 않은 항을 앞 경로 예제에서 구별한다.

  • 확률 가중치

    실제 선택 확률에 맞는 분모가 필요한 이유를 먼저 읽는다.

어떤경로에서빛이오는가

카메라가 처음 보는 표면 A에 광원에서 바로 오는 기여는 직접 조명이고, 다른 표면 B에서 반사되어 A로 오는 기여는 간접 조명의 한 예다. 광원을 직접 보는 방출항도 별도로 있다. 실제 빛의 이동과 카메라에서 역으로 경로를 구성하는 계산 방향을 구별한다.

path tracing은 카메라 광선의 교점에서 방향을 표본으로 정하고 다음 교점을 찾으며 경로를 연장한다. 광원 쪽 가시성과 재질·방향·확률 가중치는 각 경로 기여에 관여한다. 반사 횟수만 세고 거리·방향·가림을 빼면 실제 장면 빛을 정확히 계산한 것이 아니다.

표본확률과기여를함께관리한다

광원을 직접 표본화해 연결하는 next event estimation은 직접항을 효율적으로 추정하는 방법이다. BSDF 방향 추적도 광원을 만날 수 있어 중복 기여를 어떻게 처리할지 정해야 한다. 여기서는 두 기여 집합이 겹치지 않는다고 먼저 정한 유한항 모형을 쓴다.

아래 숫자는 기하·확률 보정 등을 이미 묶어 정한 가상 경로 계수다. 단순 재질 반사율의 곱을 완전한 rendering equation으로 읽지 않는다. 광원 radiance 10의 두 항을 합할 뿐 장면 전체의 광원 power나 에너지 예산을 측정하는 것은 아니다.

가림과종료는결과를바꾼다

경로에 막힌 구간이 있으면 현재 모형의 visibility가 0이 되어 그 항이 사라진다. 직접항이 0이어도 모든 간접항이 0인 것은 아니다. 다른 표면을 경유하는 열린 경로를 별도로 확인한다.

반사 깊이를 고정해 자르면 남은 항이 존재하는 장면에서 편향이 생길 수 있다. Russian roulette는 일부 경로를 종료하되 살아남은 기여를 생존 확률로 나누어 조건에 맞는 기댓값을 보존한다. 특정 실행의 값을 동일하게 보존하거나 분산을 항상 낮추는 방법은 아니다.

중간 과정을 따라가는 예제

자체 유한항 모형에서 카메라→A→광원 직접항의 합성 계수는 .5, 카메라→A→B→광원 간접항은 .5×.25이고 광원값은 10이다. 두 항의 visibility는 1, 집합은 중복되지 않는다. 합과 B→광원만 막힌 별도 상황을 계산하라.

  1. 직접항은 .5×10=5, 간접항은 .5×.25×10=1.25다.

  2. 합은 5+1.25=6.25다. 두 항으로 정한 문제의 전수 계산이다.

  3. B→광원의 visibility가 0이면 간접항은 0이고 직접항 5는 그대로다.

열린 두 항은 6.25, 간접 경로 가림 상황은 5다. 물리 장면 전체의 무한 경로 적분이나 렌더링 측정은 아니다.

조건을 바꾸어 비교하기

누적항을 모든 결과에 남긴다

표의 최종 값으로 기댓값·분산을 구하라.

  1. 기댓값은 (3/4)×2+(1/4)×14 = 5다.

  2. 제곱 기댓값은 (3/4)×4+(1/4)×196 = 52다. 분산은 52−25 = 27이다.

누적 직접항을 보존한 roulette는 목표 5를 불편 추정하며 분산은 27이다.

비교할 점

기댓값 보존은 각각의 실행 결과가 5라는 뜻이 아니다.

이력마다 다른 생존 확률

별도 장부의 두 이력 H1/H2는 각각 확률 1/2다. 남은 기여는 H1에서 1, H2에서 3이며 생존 확률은 각각 1과 1/2다. 보정한 반환의 분포와 기댓값은?

  1. H1에서는 항상 1을 반환하여 전체 확률 1/2를 갖는다. H2에서는 전체 확률 1/4로 0, 1/4로 6을 반환한다.

  2. 기댓값은 (1/2)×1+(1/4)×6 = 2이며 원래 이력 평균 (1+3)/2와 같다.

해당 이력의 확률로 나누면 원래 평균 2를 보존한다. 이 사례에는 앞 장부의 D를 더하지 않는다.

비교할 점

다른 이력의 평균 생존율을 모든 경우의 분모로 쓰지 않는다.

오해와 반례

광원 직접 연결과 방향 추적에서 같은 기여를 둘 다 더하면 더 정확하다.

좋아 보이는 첫 표본에서 멈추면 단순 평균도 불편할까?

별도 분포 Z는 확률 1/2로 0, 확률 1/2로 4다. 목표 평균은 2이고 모분산은 4다. 고정된 독립 표본 두 개의 평균은 기댓값 2, 분산 2다. 이번에는 첫 표본이 4이면 즉시 그 값으로 종료하고, 첫 표본이 0이면 독립 표본 하나를 더 얻어 두 값의 평균을 보고하는 규칙을 비교한다.

조기 중단 규칙은 첫 4에서 확률 1/2로 결과 4, 첫 0 뒤 둘째 0에서 확률 1/4로 결과 0, 첫 0 뒤 둘째 4에서 확률 1/4로 결과 2다. 기대 보고값은 2.5이며 편향은 +0.5다. 제곱 기댓값은 9, 분산은 9−2.5² = 11/4, 목표 2에 대한 MSE는 3이다. 관측값에 따라 표본 수가 달라진 평균에 고정 N의 불편성 공식을 그대로 적용하지 않는다.

같은 표본을 네 번 복사한 평균은 원래 Z라서 분산 4다. 네 독립 표본 평균의 분산 1과 다르다. 아래 비용 장부는 독립 표본·고정 비용의 자체 모형이며 실제 renderer 시간은 아니다. A의 표본 분산 4와 비용 1, B의 표본 분산 2와 비용 3을 가정하면 예산 12에서 평균 분산은 A가 1/3, B가 1/2다.

반복실행값의흩어짐

분산은 값과 기댓값의 차이를 제곱하여 평균한 값이다. Var(X)=E[X²]−E[X]²로도 계산할 수 있다. 표준편차는 분산의 제곱근이며 원래 값과 같은 단위다. 렌더링의 입자 같은 노이즈는 유한 표본 기여가 흩어지는 현상과 관련된다.

동일 분포의 독립 표본 N개 평균은 분산 σ²/N, 표준오차 σ/√N을 갖는다. 독립성·유한 분산 가정이 필요하고 상관 표본이나 다른 추정량에 그대로 대입하지 않는다. 반복 표본 전체의 성질이며 한 그림의 모든 픽셀이 단조롭게 좋아진다는 보장은 아니다.

표본을늘리는비용

표준오차를 절반으로 만들려면 N을 네 배로 늘려야 한다. 표본 두 배는 1/√2배로 줄이는 관계다. 표본당 비용이 같다면 네 배 표본은 네 배 비용이므로 더 효율적인 표본분포 설계가 필요할 수 있다.

올바른 확률 가중치를 갖춘 importance sampling은 기여와 비슷한 분포를 선택해 분산을 줄일 수 있다. 그러나 PDF 평가·표본 생성 비용과 어려운 기여·델타 등의 조건이 남는다. 특정 모형의 분산 0을 모든 장면에 일반화하지 않는다.

오차의종류를나눈다

불편 추정량에서는 MSE가 분산과 같지만 편향 추정량에서는 MSE=분산+편향²다. 고정 깊이로 남은 조명항을 없애는 편향은 같은 잘못된 계산을 많이 반복한다고 자동 사라지지 않는다. 노이즈 제거로 매끈한 그림도 정확성을 보장하지 않는다.

표본분산 s²=Σ(xi−평균)²/(N−1)은 N≥2의 유한 표본으로 모분산을 추정한다. 큰 기여가 드문 분포에서 짧은 목록이 모두 같으면 표본분산 0이어도 실제 분산은 양수일 수 있다. 실측 범위와 통계 추정을 구별한다.

중간 과정을 따라가는 예제

같은 확률 .5/.5로 기여 X=4 또는 12를 갖는 모형에서 평균·분산·N=4/N=16 독립 표본 평균의 표준오차를 구하라.

  1. E[X]=.5×4+.5×12=8, E[X²]=.5×16+.5×144=80이다.

  2. Var(X)=80−64=16이므로 σ=4다.

  3. N=4 평균의 분산은 4, 표준오차는 2다. N=16에서는 분산 1, 표준오차 1이다.

첫 부호 모형의 목표는 1, 분산은 8이다. 둘째 경로 모형의 목표는 3, roulette 분산은 12이며 고정 생략은 편향 −2와 MSE 4를 갖는다. 셋째 모형의 목표는 2이며 관측값 의존 중단은 기댓값 2.5와 MSE 3, 고정 두 표본 평균은 기댓값 2와 MSE 2다. 세 목표와 조건을 서로 섞지 않는다.

해결한 뒤 점검할 것

  • 모든 필요한 범주의 양수 확률과 PMF 합 1을 검사하며 기여 부호를 유지한다.

  • 누적 직접항을 종료 결과에 보존하고 실제 생존 확률로 미래 기여를 보정한다.

  • 표본 수가 관측값에 의존하면 보고값 분포를 다시 계산하며 MSE에 편향 제곱을 포함한다.

  • 모든 숫자는 자체 손모형으로 기록하고 실제 난수·렌더러·GPU·시간 측정·학생 관찰을 수행한 것으로 확대하지 않는다.
