소단원 8.1

Bezier와 spline

곡선을 끌어 올리는 손잡이가 꼭 곡선 위에 있어야 할까?

준비 개념과 학습 목표

준비 개념

  • 좌표별 선형 보간

  • 미분은 변화율

  • 매개변수 t

학습 목표

  • de Casteljau 로 곡선의 한 점을 구한다.

  • 끝점·접선과 구간 연결 조건을 설명한다.

여러 보간으로 하나의 점을 만든다

L(A, B, t)=(1−t)A+tB 는 선분 위 보간이다. 0≤t≤1 이고 같은 t 로 이웃 제어점을 보간한 뒤 결과를 다시 보간하면 Bézier 곡선의 점을 얻는다. 제어점은 곡선을 조절하는 점이며 모든 제어점을 그대로 지나가는 자료점과 다르다.

세 제어점 P0/P1/P2 의 이차 곡선은 B(t)=(1−t)²P0+2t(1−t)P1+t²P2 다. 두 일차 보간 Q0/Q1 뒤 L(Q0, Q1, t)가 같은 식이 되는지 전개할 수 있다. 좌표별로 계산하므로 2D 와 3D 에서 보간 원리는 같다.

끝의 위치와 움직임을 읽는다

t=0 이면 P0, t=1 이면 P2 다. 이차 곡선의 도함수 B′(t)=2[(1−t)(P1−P0)+t(P2−P1)]이므로 끝 접선은 제어 다각형의 끝 변 방향이다. 접선 벡터가 0 이면 이 식만으로 방향을 정할 수 없다는 조건도 본다.

가중치가 음수가 아니고 합 1 인 구간에서는 점이 제어점의 convex hull 안에 있다. convex hull 은 제어점들을 감싸는 가장 작은 볼록 영역이다. t 를 구간 밖으로 보내면 가중치의 성질과 이 포함 보장을 같은 방식으로 적용할 수 없다.

낮은 차수의 조각을 연결한다

spline 은 여러 구간의 다항 곡선을 연결하는 접근이다. 높은 차수의 하나를 무작정 늘리는 대신 구간 경계의 위치와 접선을 정한다. P2=R0 이면 위치 연속 C0 이며, 각 조각의 같은 매개변수 길이에서 끝 도함수까지 같으면 C1 이다.

접선 방향만 같고 크기가 다르면 시각적 방향 연결 G1 과 C1 은 다르다. 구간의 실제 매개변수 길이가 다르면 도함수에 그 길이의 환산이 필요하다. 일반 B-spline 의 basis/knot 규칙을 임의의 모든 Bézier 연결과 같다고 단정하지 않는다.

Q0=L(P0,P1,t); Q1=L(P1,P2,t)
B=L(Q0,Q1,t)

중간 과정을 따라가는 예제

자체 P0=(0,0), P1=(2,4), P2=(4,0), t=1/2 이다. de Casteljau 와 이차식으로 B 를 구하고 끝 도함수를 계산하라.

  1. Q0=(1,2), Q1=(3,2)다.

  2. 두 Q 의 중점은 B=(2,2)다.

  3. 이차식 가중치 1/4,1/2,1/4 를 적용해 x0+1+1=2, y0+2+0=2 로 같다.

  4. B′(0)=2(2,4)=(4,8), B′(1)=2(2,−4)=(4,−8)이다. P1=(2,4)는 이 곡선의 중간점(2,2)와 다르다.

B(1/2)=(2,2), 끝 도함수(4,8)/(4,−8)이다.

한 단계 더

세 번의 보간으로 cubic Bézier 를 계산하는 삼각표를 그린다. 한 t 에서 분할한 두 조각의 제어점을 표의 양쪽 가장자리에서 읽는다. rational 곡선의 가중치와 분모는 별도이며 polynomial Bézier 에 원의 정확 표현을 무조건 요구하지 않는다.

소단원 8.2

삼각메시·half-edge

좌표 네 개와 삼각형 두 개에서 이웃 면을 바로 찾으려면?

준비 개념과 학습 목표

준비 개념

  • 정점·변·면

  • 방향 있는 선분

  • 연결 자료구조

학습 목표

  • 좌표와 연결 관계를 구별한다.

  • next 와 twin 의 역할과 경계 규약을 추적한다.

위치와 연결을 따로 저장한다

삼각메시는 정점 좌표와 세 정점 인덱스로 된 면 목록을 가진다. 좌표가 가까워도 별도 인덱스로 저장됐다면 자동으로 연결된 정점이 아니다. 반대로 같은 정점을 여러 면이 공유하면 위치 수정이 관련 면에 영향을 준다.

polygon soup 는 면 목록의 단순 표현이고 halfedge 는 인접 관계를 따라 이동하기 쉽게 더 많은 연결을 둔다. 어떤 표현이 항상 빠르거나 작다고 단정하지 않고 렌더링과 기하 편집의 접근 요구를 비교한다.

변의 두 방향과 면의 다음 변을 연결한다

halfedge h 의 origin 은 출발 정점, next 는 같은 면의 다음 방향 변, twin 은 반대 방향의 같은 무방향 변이다. h A→B 의 twin 은 B→A 다. twin(twin(h))=h 이며 next 를 면의 시작까지 따르면 면의 경계를 돈다.

본 자체 모형은 일관된 방향의 orientable manifold 삼각메시이며 경계 halfedge 의 twin 은 null 로 둔다. CMU 의 가상 경계면 방식은 경계에도 twin 을 만들 수 있으므로 두 표현을 혼합하지 않는다. 한 변에 세 면이 붙는 비다양체 자료를 여기의 한 twin 으로 모두 나타낼 수는 없다.

그림을 바꾸면 연결도 바꾼다

halfedge 는 좌표를 저장하는 것만이 아니라 어떤 면과 변에 속하는지 알려준다. 면을 나누거나 대각선을 뒤집으면 next/twin 뿐 아니라 face/edge/vertex 의 시작 참조도 재검토한다. 그림이 그럴듯해도 끊긴 순환이 남을 수 있다.

한 정점의 이웃을 twin→next 로 순회하는 규약도 origin 표현과 경계 처리에 의존한다. null 을 그냥 따라가면 안 된다. 여기서는 면 순회와 공유변 이동을 먼저 검산하고 경계 정점 전체 순회는 별도 처리 조건을 계획한다.

F0: h0=A→B, h1=B→C, h2=C→A
F1: h3=C→B, h4=B→D, h5=D→C

중간 과정을 따라가는 예제

자체 두 면 F0=(A, B, C), F1=(C, B, D)이다. h0→h1→h2→h0, h3→h4→h5→h3 가 next 다. 공유변 BC 의 twin 쌍과 F0 순회 origin, V/E/F 와면 halfedge 수를 구하라. 외곽 twin=null 모형이다.

  1. F0 의 origin 순회는 A, B, C 뒤 A 로 돌아온다. 면 하나의 세 단계다.

  2. h1 B→C 와 h3 C→B 가 twin 쌍이다. h1.twin.next=h4 B→D 다.

  3. 정점 A/B/C/D 는 4, 무방향변 AB/BC/CA/BD/DC 는 5, 실제면은 2 다.

  4. 실제면 halfedge 는 3×2=6 이고 경계 4 개는 null twin 이다. 가상 경계 halfedge 를추가한 표현에서는총 10 으로달라진다.

twin 쌍 h1/h3, V4/E5/F2, 실제면 halfedge6 이다. 2E=10 을 null 경계모형의 6 과혼동하지않는다.

종이와 본문으로 직접 해보기

F1 을 잘못(B, C, D)로 등록하면 BC 가 어떤 방향으로 두 번나오나? h1.next 를 h1 로 잘못 설정하면 F0 순회가 어떻게 끝나나?

힌트 보기

각 면의 연속쌍과 시작으로 되돌아오는 조건을 표시한다.

풀이 보기

BC 가 B→C 로 두 번 나와 반대 twin 짝이 되지 않는다. h0→h1 뒤 h1 만 반복되어 h0 로 복귀하지 못하므로 정상 3 면 순회가 아니다.

오해와 반례

halfedge 의 next 는 항상 인접 면으로 넘어가는 포인터다.

h1.next=h2 는 같은 F0 안 이동이다. 인접 F1 으로 넘으려면 공유변의 twin h3 를 사용한다. next 와 twin 을교환하면 순회규약이깨진다.

세 면이 한 변을 공유해도 이 모형인가?

한 단계 더

정점 C 를 움직여도 F0/F1 인덱스연결은그대로일 수 있다. 같은 위치의 서로 다른 정점을 합치는 welding 은 별도 연결 변경이며 허용 오차·모서리 속성/UV 차이를 확인한다. pointer 순환 검사와 실제 GPU 영상 검증은 다른 관측이다.

소단원 8.3

분할과 기하처리

삼각형 수를 네 배로 만들면 자동으로 더 정확한 표면일까?

준비 개념과 학습 목표

준비 개념

  • 평균과 가중합

  • 삼각형 연결

  • 경계와 내부 정점

학습 목표

  • 연결 분할과 위치 평활화를 구별한다.

  • 명시된 subdivision 가중치와 비용 증가를 계산한다.

더 많은 표본을 배치한다

분할은 큰 면을 작은 면으로 나누는 작업이다. 삼각형 변중점을 연결하면 한 면이 네 면이 된다. 좌표를 단순히 같은 평면 위에서 나눴다면 더 많은 면을 얻어도 원래 평면 형상은 변하지 않는다. 존재하지 않은 곡면의 세부를 측정한 것은 아니다.

upsampling 은 표본수를 늘리고 downsampling 은 줄이며 remeshing 은 표본분포를 바꾼다. 목표는 위치오차만이 아니라 법선·삼각형 품질·특징 보존과 작업 비용일 수 있다. 면수 하나만으로 정확도나 렌더링 속도를 판단하지 않는다.

위치 규칙을 명시한다

Loop subdivision 은 삼각메시를 나누면서 이웃 좌표의 가중합으로 위치를 정한다. 내부변 AB 의 두 맞은편 정점 C/D 에 대해 새점은 3/8(A+B)+1/8(C+D)다. 이는 중점 1/2(A+B)와 다를 수 있으며 경계변 규칙으로 그대로 적용하지 않는다.

이 강의 자료의 old interior vertex 규칙은 이웃 수 n=3 이면 β=3/16, 그 외 β=3/(8n), 새 P=(1−nβ)P+βΣ이웃이다. 다른 Loop 가중치 variant 와 경계/crease 정책도 있으므로 사용한 규약을 먼저 적는다. 모든 새 좌표는 같은 옛 단계 자료에서 계산한 뒤 함께 교체한다.

상세를 늘리고 줄일 때 잃는 것을 확인한다

반복분할은 면수를 4 배씩 늘려 저장과 처리 비용을 키운다. 반대로 edge collapse 는 변끝을 합쳐 면을 줄이지만 작은특징이나 연결위상·삼각형 방향을 망칠 수 있다. 단순한 개수 목표 외에 허용 오차와 유효성 조건을 둔다.

이웃 평균으로 정점을 이동하는 평활화는 잡음을 줄이기도 하지만 부피를 줄이거나 날카로운 모서리를 둥글게 만들 수 있다. Laplacian 처럼 이름이 붙었다고 원래 측정 형상의 모든 특징을 보존하는 것은 아니다. 경계 고정·법선 방향 제한 등의 조건을 실제 알고리즘별로 검토한다.

newEdge = (3/8)*(A+B)+(1/8)*(C+D)  # 내부변만

중간 과정을 따라가는 예제

자체 비퇴화 내부변 A=(0,0), B=(4,0)의 맞은편 정점은 C=(2,5), D=(2,−1)이다. C와 D는 AB의 서로 반대쪽에 있어 두 삼각형은 퇴화하지 않는다. Loop 새점과 중점을 비교한다. 별도 old interior P=(0,0), n=3 이웃 (2,0),(0,2),(−2,0)에 위 규칙을 적용한다.

  1. A+B=(4,0), C+D=(4,4)다.

  2. 새변점은(1.5,0)+(.5,.5)=(2,.5)이며중점(2,0)과 다르다.

  3. n3 의β=3/16, old 가중치 1−9/16=7/16 이다.

  4. 이웃합(0,2)이므로 old P 새값=(0,3/8)이다. 같은 옛 자료에서 두 종류를 계산한다.

내부변점(2,.5), 중점(2,0), old 정점(0,.375)이다. 경계에는 별도 규칙이 필요하다.

종이와 본문으로 직접 해보기

처음 실제 삼각면 2 개에서 균일 4 분할을 3 회하면 면수는? n6 의 old 가중치와 각 이웃 가중치 합은? 옛 P 가(1,2), 모든 6 이웃도(1,2)라면 새 P 는?

힌트 보기

2×4³과β=3/(8×6)을 적용한다. 동일 좌표의 가중치 합 1 을 본다.

풀이 보기

면수 128 이다.β=1/16, old=1−6/16=5/8 이고 합 5/8+6/16=1 이다. 새 P=(1,2)로 같다. 퇴화된 좌표 예시는 가중합 검산이며 유효한 6 삼각형을 구성했다는 주장은 아니다.

오해와 반례

면만 많아지면 원형상의 세부와 날카로운 모서리를 모두 되찾는다.

평면 삼각형 중점 분할은 원래 평면에 점만 늘린다. 이웃 평균은 날카로운 특징을 없앨 수도 있으므로 표본수와 정보의 새로운 측정은 다르다.

한 단계 더

같은 단계에서 새 P 를 먼저 원 배열에 써 뒤 점의 계산에 사용하면 순서에 따라 결과가 달라질 수 있다. 옛/새 배열을 분리하고 면 방향·경계·crease·UV 를 검토한다. 위치 근사와 법선 근사의 평가를 별도로 계획하며 실제 mesh 프로그램을 수행했다고 쓰지 않는다.
