小節 1.1

定義域・値域とグラフ

二乗する計算機に −2 と 2 を入れて同じ答えが出ても、関数と呼べるだろうか？

準備する概念と学習目標

準備する概念

  • 四則演算：(−2)²=4 のように負の数を二乗するときは括弧を使う。
  • 座標：(x,y) は横方向の入力 x と縦方向の出力 y を表す。
  • 集合：[a,b] は両端を含み、(a,b) は両端を含まない。

学習目標

  • 各入力に出力が一つだけ対応するという関数の条件を確認する。
  • 定義域・終域・値域を区別し、値域を両方向から示す。
  • 表とグラフから分かることの限界を説明する。

各入力に出力を一つ対応させる

関数 f:A→B は、A のすべての要素 x に B の要素 f(x) をちょうど一つ割り当てる規則である。A が定義域、B が終域である。異なる入力が同じ出力を持ってもよい。出力が重なることと、一つの入力に二つの出力があることは別である。

値域 f(A)={f(x):x∈A} は、実際に到達する出力の集合である。f:ℝ→ℝ, f(x)=x² の終域は ℝ だが、値域は [0,∞) である。関数を指定するときは、式だけでなく入力と出力の集合も指定する。

式から使える入力を調べる

実数値関数の自然な定義域は、その式を実数値として計算できるすべての入力である。分母は 0 であってはならず、偶数乗根の中は 0 以上でなければならない。条件が複数あれば、すべてを同時に満たす必要がある。距離を扱う場面なら、代数的には使える負の数もモデルの定義域から除く場合がある。

g(x)=√(x−1) の自然な定義域は [1,∞) である。出力は負にならず、任意の y≥0 に対して x=y²+1 を入れると g(x)=y となる。したがって、値域は [0,∞) と示せた。不等式だけで出力の上限・下限を求めるのは、値域を示す議論の半分である。

グラフはすべての順序対の集合

グラフは {(x,f(x)):x∈A} である。一つの垂直線が異なる二点と交わるなら、その x に二つの出力があるので関数ではない。円 x²+y²=1 は、x=0 で y=1 と −1 があるため、y を x の関数として定めない。

定義域が {0,1,2} なら、グラフは三点だけである。点を線で結ぶと、途中の入力も存在するという仮定を追加することになる。有限個の値を載せた表だけでは、表にない入力の関数値を確定できない。

途中の過程をたどる例題

f:[−2,3]→ℝ, f(x)=(x−1)² の値域と f(−2), f(1), f(3) を求めよう。

  1. f(−2)=9, f(1)=0, f(3)=4 である。
  2. −2≤x≤3 なら −3≤x−1≤2 なので、0≤(x−1)²≤9 である。
  3. すべての 0≤y≤9 に対して x=1−√y を選ぶと、−2≤x≤1 であり、f(x)=y となる。

定義域は [−2,3]、値域は [0,9]。最大値は左端で、最小値は区間内部の x=1 で得られる。

紙と本文で試してみよう

紙に h(x)=1/(x−2) の定義域と値域を書き、(0,h(0)), (1,h(1)), (3,h(3)) を描こう。

ヒントを見る

分母が 0 になる入力と、逆に x=2+1/y を作れない出力を探そう。

解答を見る

x≠2 であり、h(0)=−1/2, h(1)=−1, h(3)=1。出力 0 は不可能で、y≠0 なら x=2+1/y で到達するため、値域は ℝ∖{0}。三点だけでグラフ全体を確定したわけではない。

よくある誤解と反例

関数なら、異なる入力からは異なる出力が出る。

f(x)=x² では f(−1)=f(1)=1 だが、各入力の出力は一つなので関数である。異なる入力の出力も異なるという条件は、単射性という追加の条件である。

理解を確かめる

f:ℝ→ℝ, f(x)=x² の終域と値域は？

答えと理由を見る

終域は ℝ、値域は [0,∞)。

終域は指定した集合で、値域は実際の二乗値の集合である。

√(5−x) の自然な定義域は？

答えと理由を見る

(−∞,5]。

5−x≥0 が必要であり、それで十分である。

関係 {(1,2),(1,3)} は関数か？

答えと理由を見る

関数ではない。

入力 1 に異なる二つの出力がある。

もう一歩先へ

発展：どの関数でも、値域を改めて終域に指定すれば全射になる。しかし、この指定だけで単射にはならない。x²:ℝ→[0,∞) を例に、二つの性質を比較しよう。

小節 1.2

合成関数・逆関数

温度をセンサーの数値に変換してから温度に戻すには、何が必要だろうか？

準備する概念と学習目標

準備する概念

  • 式への代入：x の代わりに式全体を括弧で囲んで入れる。
  • 一次方程式：y=3x+2 を x=(y−2)/3 と解く。
  • 関数の定義域と値域：出力を次の関数の入力に使えるか確認する。

学習目標

  • 合成の順序と定義域を計算する。
  • 単射・全射の条件を使い、逆関数の存在を説明する。
  • 両方向の合成で逆関数を確認する。

二つの規則をつなぐ

g の後に f を適用する関数は (f∘g)(x)=f(g(x)) である。合成で実際に使える定義域は {x∈Dom(g):g(x)∈Dom(f)}。g の終域全体が f の定義域に含まれていれば、g のすべての入力で合成できる。そうでなくても、使える入力だけに制限して合成できる。

一般に、合成の順序を入れ替えると別の関数になる。f(x)=x², g(x)=x+1 なら、f(g(x))=(x+1)² だが g(f(x))=x²+1 である。x=1 でそれぞれ 4 と 2 になるため、二つは異なる関数である。

復元には情報の損失がないことが必要

f が単射であるとは、f(x₁)=f(x₂) なら x₁=x₂ であることをいう。同じ出力から元の入力を一つに定める逆関数には、この条件が必要である。f:A→B が両方向の逆関数 f⁻¹:B→A を持つには、B のすべての要素にも到達しなければならないので、全射性も必要になる。

終域ではなく値域 f(A) を逆関数の定義域にすれば、単射性だけで十分である。x² は ℝ 全体では符号の情報を失うが、定義域を [0,∞) に制限すれば平方根で復元できる。どの水平線もグラフと異なる二点で交わらないという検査は、単射性を図で表したものである。

逆関数の式と確認

y=f(x) を x について解き、使える範囲も書いたうえで入力と出力の役割を交換する。f⁻¹(f(x))=x は x∈A で、f(f⁻¹(y))=y は y∈f(A) で確認する必要がある。一方の合成が特定の点で合うだけでは、十分な確認にも証明にもならない。

f⁻¹ は 1/f という逆数ではない。逆関数は入力へ戻す規則で、逆数は出力の乗法逆元である。例えば f(x)=2x の f⁻¹(y)=y/2 と 1/f(x)=1/(2x) はまったく異なる。

途中の過程をたどる例題

温度 T≥−5 をセンサー値 s=g(T)=3T+15 に変換し、画面には h(s)=√s を表示する。画面表示の関数と T の復元式を求めよう。

  1. T≥−5 なら s≥0 なので √s を計算できる。画面表示は w=(h∘g)(T)=√(3T+15) で、値域は w≥0。
  2. w²=3T+15 から T=(w²−15)/3 と求まる。w≥0 を保つ。
  3. T=7 なら s=36, w=6。復元すると (36−15)/3=7。
  4. 一般の T に復元式を適用すると ((√(3T+15))²−15)/3=T。w≥0 では √(3((w²−15)/3)+15)=√w²=w。

画面表示は w=√(3T+15), T≥−5。逆関数は T=(w²−15)/3, w≥0。範囲の制限が復元の鍵である。

紙と本文で試してみよう

f(x)=√x, g(x)=x−4 について、f∘g と g∘f の式・定義域を求め、x=9 で比較しよう。

ヒントを見る

まず内側の関数の定義域を書き、次に外側の関数の入力条件を書く。

解答を見る

f∘g=√(x−4), 定義域は [4,∞), x=9 では √5。g∘f=√x−4, 定義域は [0,∞), x=9 では −1。式も定義域も異なる。

よくある誤解と反例

y=x² から x=±√y と求まるので、±√y が逆関数である。

±√y は y>0 で一つの入力に異なる二つの出力を与えるため、非負の y 全体に対する一つの逆関数にはならない。x≥0 に制限すれば √y、x≤0 に制限すれば −√y がそれぞれ逆関数になる。二つを合わせて一つの逆関数とは指定できない。

理解を確かめる

f∘g で先に適用するのは？

答えと理由を見る

g。

括弧の中 f(g(x)) の g(x) を先に求める。

f(x)=4x−7, 定義域 ℝ の逆関数は？

答えと理由を見る

f⁻¹(y)=(y+7)/4。

4 は 0 ではないので、すべての出力から x を一意に解ける。

x²:[0,∞)→ℝ は ℝ 全体に対する両方向の逆関数を持つか？

答えと理由を見る

持たない。値域 [0,∞) に対しては持つ。

元の関数は負の出力に到達しないので、全射性がない。

もう一歩先へ

発展：g:A→B と f:B→C がどちらも全単射なら、(f∘g)⁻¹=g⁻¹∘f⁻¹ である。つなぐ中間の集合 B を同じ集合として指定する必要があり、そのとき合成と二つの逆関数が定義域全体で成り立つ。g⁻¹(f⁻¹(f(g(x))))=x を示し、各中間値が該当する定義域に入る理由を説明しよう。

小節 1.3

多項式・有理関数・超越関数

毎回 2 ずつ増える数と、毎回 2 倍になる数は、同じ種類の関数だろうか？

準備する概念と学習目標

準備する概念

  • 累乗：2³=8、x² は x を二つ掛け合わせる、つまり x×x である。
  • 分数：分母が 0 なら割り算できない。
  • 対数の短い復習：log₂8=3 は 2³=8 という意味である。

学習目標

  • 多項式関数・有理関数・代数関数・超越関数の関係を説明する。
  • 関数の種類ごとに実数の定義域の制約を調べる。
  • 多項式の約分では、除外した入力は復活しないと説明する。

多項式関数と有理関数

多項式関数は有限和 aₙxⁿ+⋯+a₁x+a₀ で、指数は 0 以上の整数である。aₙ≠0 のとき n が次数になる。ゼロ多項式の次数は、この単元では定義しない。すべての実数入力で計算できる。x⁻¹ と √x は多項式ではない。

有理関数は二つの多項式の比 P(x)/Q(x) であり、Q はゼロ多項式であってはならない。自然な定義域から Q(x)=0 となる入力を除く。多項式関数はすべて分母を 1 として書けるので、有理関数でもある。分類は互いに重ならない箱ではない。

代数関数と超越関数

代数関数は、x と y の間で非零の多項式関係 P(x,y)=0 を満たす関数である。√x は y²−x=0 を満たすが、実数の定義域は x≥0 で、y≥0 の枝を選ぶ。多項式関数・有理関数より広い分類である。

このような多項式関係では定義されない関数を超越関数といい、指数関数・対数関数・三角関数が基本例である。aˣ は a>0, a≠1 で、すべての実数 x に対して定義される。logₐx は x>0 で定義される。sin x・cos x は実数全体、tan x は cos x≠0 となるところで定義される。このコースでは三角関数の入力にラジアンを使う。

名前より規則と定義域

x² と 2ˣ は x=2 でどちらも 4 だが、x=3 では 9 と 8 になる。多項式では整数の指数が固定され、指数関数では正の底が固定されて指数が変わる。数点での一致は、同じ関数であることを意味しない。

(x²−1)/(x−1)=x+1 は x≠1 でだけ成り立つ。元の式は x=1 では計算できない。約分後の式にその入力を新たに認めると、延長された別の関数を作ることになる。極限の単元では、穴のある点の近くでの振る舞いと、その点での実際の値がなぜ異なる情報なのかを学ぶ。

途中の過程をたどる例題

r(x)=(x²−9)/(x−3) の自然な定義域と r(2), r(4) を求め、p(x)=x+3 と同じ関数か判定しよう。

  1. 分母が 0 になる x=3 を除くので、Dom(r)=ℝ∖{3}。
  2. x²−9=(x−3)(x+3) なので、x≠3 では r(x)=x+3。
  3. r(2)=(4−9)/(2−3)=5, r(4)=(16−9)/(4−3)=7。
  4. p(3)=6 は定義されるが r(3) は定義されない。同じ関数であるには定義域も同じでなければならないため、全体としては別の関数である。

定義域は ℝ∖{3}、値は 5 と 7。グラフは y=x+3 から点 (3,6) を除いたものである。

紙と本文で試してみよう

x²+1, (x+1)/(x²−4), √(x+2), log₂(x−1) を分類し、自然な定義域を書こう。

ヒントを見る

最初の二つは多項式・有理関数かを調べ、後の二つは平方根と対数の入力条件をそれぞれ調べる。

解答を見る

x²+1 は多項式関数・有理関数・代数関数で、定義域は ℝ。分数は有理関数・代数関数で、ℝ∖{−2,2}。√(x+2) は代数関数で、[−2,∞)。log₂(x−1) は超越関数で、(1,∞)。

よくある誤解と反例

超越関数の値は常に無理数になる。

この分類は関数の関係式についてのものである。2ˣ は超越関数だが、2⁰=1 と 2³=8 は整数である。√x は代数関数だが √2 は無理数である。一つの入力での値から関数の種類は決まらない。

理解を確かめる

x³−2x+1 の次数と定義域は？

答えと理由を見る

3、ℝ。

係数が非零の項の最大の指数は 3 で、割り算や根号による制約はない。

1/(x²+1) の実数の定義域は？

答えと理由を見る

ℝ。

x²+1≥1 なので、分母は 0 にならない。

ln(x²) はすべての実数 x で定義されるか？

答えと理由を見る

x≠0 でだけ定義される。

対数の入力は正でなければならず、x²>0 は x≠0 と同じ条件である。

もう一歩先へ

発展：y=√x と y=−√x はどちらも y²=x を満たす。多項式関係が自動的に一つの関数を指定するわけではないと示し、枝の選択と定義域の選択が必要な理由を説明しよう。

小節 1.4

単位と関数モデルの仮定

距離に 5 を入れて料金が 17 になる計算には、どの単位を決めれば意味があるだろうか？

準備する概念と学習目標

準備する概念

  • 比例：1 km あたり 3 なら、2 km あたりでは 6 である。
  • 単位換算：1 km=1000 m、1 時間=60 分。
  • 一次式：b+ax の b は初期値、a は入力 1 単位あたりの変化量である。

学習目標

  • 係数の単位を推定し、式の両辺の次元を調べる。
  • 状況の仮定に基づいて定義域を制限する。
  • モデルの予測・測定の事実・外挿を区別する。

数値に伴う意味

物理量は数値と単位を合わせて持つ。距離 d の単位が km、料金 C の単位が千ウォンなら、C(d)=2+3d の 2 の単位は千ウォン、3 の単位は千ウォン/km である。足し合わせる項は同じ次元でなければならない。

数値で書いた式は単位の選び方に依存する。距離を m で表す数値 m を使うと、d=m/1000 なので C=2+0.003m となる。係数が変わっても、同じ現実の料金を予測する。単位を省くと、数値だけは正しく見える誤りが生まれる。

モデルを成り立たせる仮定

ここでは基本料金と距離あたりの料金が一定であり、距離の丸め・割増・上限・時間料金がないと仮定する。連続した実数の距離 d≥0 に式を使うが、実際の装置では 100 m ごとに料金を上げることもある。その場合には階段関数のモデルが必要になる。

モデルは目的のために選んだ規則である。測定した二点を通る直線を作れることは、すべての距離で実際の料金が直線に従う証拠ではない。データを観察した区間の外で式を使う外挿には、新たな検証が必要である。

次元の確認と検証の役割

長さ d と時間 t を d+t と足す式は、通常は次元が合わない。速度 v を掛けた vt は長さになるため、d+vt は可能である。指数・対数などの関数の入力は、通常は無次元の比にする。減衰モデル e^(−t/τ) では、t と τ は同じ時間単位でなければならない。

次元が合っても、現実に合うモデルとは限らない。距離料金の式 2+3d と 2+4d はどちらも次元上は使えるが、料金データと比較して選ぶ必要がある。計算の確認・単位の確認・現実での検証は、それぞれ異なる問いに答える。

途中の過程をたどる例題

架空の移動サービスが 0–10 km で C(d)=2+3d（千ウォン）に従うと仮定する。1500 m 移動した料金と、20 分で移動した場合の平均速度を求めよう。

  1. 1500 m=1.5 km であり、モデルの区間 0–10 km に入る。
  2. C(1.5)=2+3×1.5=6.5 千ウォン=6500 ウォン。
  3. 20 分=1/3 時間なので、平均速度=1.5/(1/3)=4.5 km/時。
  4. m 単位の式では 2+0.003×1500=6.5 千ウォンとなり、最初の計算と一致する。時間は与えられた料金モデルの入力ではないため、速度を料金式に入れない。

料金は 6500 ウォン、平均速度は 4.5 km/時。この値は架空のモデルでの計算結果であり、実際のサービス料金を観察した値ではない。

紙と本文で試してみよう

紙に s(t)=5+2t と書こう。s の単位は m、t の単位は秒である。二つの係数の単位を書き、t=4 秒での位置を求める。時間を分単位の u に変えて式を書き直そう。

ヒントを見る

t の秒単位の数値は 60u であり、初期位置は変わらない。

解答を見る

5 の単位は m、2 の単位は m/秒。s(4)=13 m。t=60u なので s=5+120u で、120 の単位は m/分。u=1/15 分を入れると 5+8=13 m。

よくある誤解と反例

単位が合い、測定した二点に合えば、モデルは完全に証明される。

s(t)=5 m+(2 m/秒)t と s(t)=5 m+(2 m/秒)t+k t(t−1秒) は、k の単位を m/秒² にすれば、どちらも単位が合い、t=0 秒、1 秒での値も一致する。後の式の t−1秒 のように、引き算でも両項に同じ単位を使う必要がある。k≠0 を選べば、他の時刻の予測は異なるため、二点だけではモデルを確定できない。

理解を確かめる

C(d)=2+3d で C の単位がウォン、d の単位が m なら、3 の単位は？

答えと理由を見る

ウォン/m。

距離と掛け合わせて料金の単位にする必要がある。

6 km を 30 分で移動した平均速度は？

答えと理由を見る

12 km/時。

30 分=0.5 時間であり、6/0.5=12 である。

0–10 km でだけ確認した式に 100 km を入れると、検証済みの予測になるか？

答えと理由を見る

ならない。外挿である。

式は計算できるが、適用区間の外での仮定を確認していない。

もう一歩先へ

発展：基本料金は 2 千ウォン、最初の 2 km までは追加料金なし、それを超えると 1 km あたり 3 千ウォンという架空の規則を、C(d)=2（0≤d≤2）、C(d)=2+3(d−2)（d>2）と書こう。d=2 で二つの式の境界値がともに 2 になることを確認し、実際に料金を丸める場合、この連続モデルをどう変えるか話し合おう。
