小節 3.1

連続関数の演算

式を足したり割ったりして新しい関数を作ると、連続性も必ず引き継がれるだろうか？

準備する概念と学習目標

準備する概念

  • 関数 f の定義域は、入力を許す集合である。分数の分母が 0 の場合や、実数の平方根の中身が負の場合は許さない。
  • x→a の極限は、a の近くの入力に対する出力が近づく値である。f(a) はその点に実際に定義された値なので、両者を区別する。
  • 点 a で連続とは、f(a) が定義され、有限の極限が存在し、その極限が f(a) と等しいことをいう。区間の端点では、定義域の内側から近づく一方向について調べる。

学習目標

  • 和・積・商・合成の連続性を、定義域と条件を確認して判断する。
  • 分母が 0 になる点で定理を機械的に適用しない。
  • 区分的に定義された関数の接合点で、極限と実際の値を別々に一致させる。

連続性を保つ演算

実数値関数 f と g が a で連続なら、f+g、f−g、fg、および定数倍も a で連続である。商 f/g には g(a)≠0 という条件が加わる。近くで計算が定義されるか、a で定義されるかを先に確認する。この規則は有限個の演算についてのもので、任意の無限和の連続性まで自動的に保証しない。

多項式はすべての実数で連続である。多項式の商は、分母が 0 でない定義域で連続である。約分して簡単な式になっても、元の定義域から除かれた点が自動的に追加されるわけではない。一点を追加するには、その値の定義と極限を別に確認する。

合成では外側の関数の入力も確認する

g が a で連続で、f が g(a) で連続なら、f∘g、すなわち f(g(x)) は a で連続である。外側の関数 f が許す入力を通る必要がある。√(x+4) は x≥−4 で実数として定義され、その定義域で連続であり、−4 では右からの連続性で判断する。x<−4 に実数値があるとは仮定しない。

ある関数がどこかで連続だというだけでは、すべての合成が連続とはいえない。外側の関数が内側の関数の実際の到達値で連続かを調べる。また、定義域の共通部分を忘れると、連続な式を組み合わせても、その式が許さない入力を答えに含めてしまう。

接合点の値を別に合わせる

x<1 では 2x+3、x≥1 では kx+1 とする関数を考える。左側極限は 5、右側極限と f(1) は k+1 である。連続になるには k=4 が必要で、このとき三つの値はすべて 5 である。左右の部分がそれぞれ多項式だというだけでは、接合点での連続性は結論できない。

連続性は、グラフがなめらかであることと同じではない。|x| は 0 での値と左右の極限がすべて 0 なので連続だが、左右の傾きは異なる。微分可能性は、後でより強い条件として扱う。小さな図や数点の表より、定義と適用条件を優先する。

途中の過程をたどる例題

h(x)=(x²+1)/(x−2) の実数での定義域と、x=3 での連続性および値を求めよ。x=2 にも同じ代入規則を使えるか説明せよ。

  1. 分母 x−2 が 0 になる 2 を除くので、定義域は ℝ\{2} である。
  2. 分子と分母は多項式であり、3 で連続である。分母の値は 1 で、0 ではない。
  3. 商の連続性により lim(x→3)h(x)=h(3)=(9+1)/1=10 である。
  4. x=2 では元の関数値が定義されておらず、分子の値は 5 である。分母が 0 なので商の定理を適用したり、h(2)=10 として延長したりはできない。

定義域 ℝ\{2} のすべての点で連続であり、h(3)=10 である。2 は元の定義域に含まれず、別に扱う必要がある。

紙と本文で試してみよう

紙の上で、x<1 のとき 2x+3、x≥1 のとき kx+1 とする関数の連続条件を求めよ。別に、√(x+4) の実数での定義域と、左端点への接近方向を書け。

ヒントを見る

接合点の左側極限・右側極限・実際の値を、三つの欄に分けて書く。

解答を見る

左側は 5、右側と実際の値は k+1 なので k=4 である。平方根の定義域は [−4,∞) であり、−4 には右側から近づき、値 0 と極限 0 を比較する。すべて紙上の解答であり、数値コードやグラフツールは実行していない。

よくある誤解と反例

二つの連続関数の商は、分母の値に関係なくすべての実数で連続である。

1/x は分子と分母が多項式でも、x=0 では定義されない。商の定義域と g(a)≠0 の条件を必ず保つ。

理解を確かめる

多項式 x²−7 はどの実数で連続か？

答えと理由を見る

すべての実数。

定数と x の有限個の積・差からなり、定義域に分母や平方根による制限がない。

√(x+4) は実数値関数として x=−5 で連続か？

答えと理由を見る

その入力は定義域の外である。

平方根の中身 −1 に実数値を定めていないので、実数値関数としての連続性を主張しない。

接合点で左右の極限が等しければ、実際の値は何でもよいか？

答えと理由を見る

よくない。実際の値もその極限と等しくなければならない。

f(a) の定義と極限との一致は、連続性の別の条件である。

もう一歩先へ

発展：u(x)=1/(x−2) の a=3 での連続性を ε–δ で直接確認せよ。ε>0 に対し δ=min(1/2,ε/2) を選ぶ。|x−3|<δ なら |x−2|≥1−|x−3|>1/2 なので、|u(x)−1|=|x−3|/|x−2|<2δ≤ε である。x=3 自体も差が 0 なので条件を満たす。この議論は分母を 0 から離す役割を示すもので、すべての商の前提を省略してよいという証明ではない。x=2 には同じ中心値や分母の下界を使えない。

小節 3.2

中間値の定理

片側の値が負で、もう片側の値が正なら、その間に 0 が必ずあるだろうか？

準備する概念と学習目標

準備する概念

  • 閉有界区間 [a,b] は、有限の a≤b の間のすべての実数と両端点を含む。
  • f(c)=0 の解を根または零点という。解が存在するという主張と、その正確な数値を計算したという主張は異なる。
  • 連続性は区間全体で必要である。端点では区間の内側からの片側連続性も含む。

学習目標

  • 連続性と目標値の位置を確認してから中間値の定理を適用する。
  • 存在・一意性・数値近似を、それぞれ異なる根拠で区別する。
  • 符号が変わらなくても根があり得ることと、不連続なら符号変化だけでは不十分なことを示す。

値を飛び越えないという定理

実数値関数 f が [a,b] で連続なら、f(a) と f(b) の間にある実数 y ごとに、f(c)=y となる c∈[a,b] が存在する。y が両端の値の間に厳密にあれば、c を (a,b) 内に取れる。y が端点の値と等しければ、その端点が解である。端点の値が増加する順に並ぶ必要はなく、間の範囲を小さい値から解釈する。

連続性は両端の二点だけを確認する条件ではない。途中で値を飛び越えると目標値を欠くことがある。例えば x<0 で −1、x≥0 で 1 を与える関数は、[−1,1] の端点の値が反対符号でも 0 を取らない。符号の検査を定理の連続条件の代わりに使わない。

存在と一意性を分ける

f(a)<0<f(b) なら、0 が端点の値の間にあるので、少なくとも一つの根が存在する。定理は根の個数を一つに固定せず、解を閉じた形の式で与えるわけでもない。連続な関数でも上下に変化し、同じ高さを何度も通ることがある。

端点の値が同符号だから根がない、という逆の結論も成り立たない。(x−3/2)² は [1,2] の両端で 1/4 だが、x=3/2 で 0 である。この場合、符号変化の判定は根の存在を保証できないだけで、根の不在を証明したわけではない。一意性には狭義単調増加などの追加の議論が必要である。

区間を縮める紙上の手順

連続性と反対符号を保ちながら中点 m を調べられる。値が正確に 0 なら解を得て、そうでなければ符号が異なる端点と m を新しい区間にする。正確な実数演算のモデルでは長さが半分になるが、有限回の手順が必ず正確な根を出力するわけではない。

n 回縮めた長さは初期の長さ/2ⁿ である。根を含む区間の中点を近似値にすれば、誤差はその長さの半分以下となる。根が引き続き含まれるという不変条件と、正確な符号判定が前提である。実際の浮動小数点の丸めや関数評価の失敗は、この紙上の分析では試験していない。

途中の過程をたどる例題

f(x)=x³+x−3 の根が [1,2] 内に存在することを示し、中点 3/2、次の 5/4 を正確な分数で調べて、区間を二回縮めよ。

  1. f は多項式なので [1,2] で連続である。f(1)=−1、f(2)=7 なので、中間値の定理により根 c∈(1,2) が存在する。
  2. 最初の中点 3/2 では f=27/8+12/8−24/8=15/8>0 である。f(1)<0 の端点 1 と f(3/2)>0 の端点 3/2 の間の [1,3/2] に縮める。
  3. 次の中点 5/4 では f=125/64+80/64−192/64=13/64>0 である。新しい区間は [1,5/4] で、長さは 1/4 である。
  4. 区間の中点 9/8 を近似値とすれば、含まれる根との距離≤1/8 である。これは解の正確な値を求めたものではなく、すべての分数計算は紙上で行った。

根は (1,5/4) 内に存在する。二回縮めた区間の長さは 1/4、中点による近似値 9/8 の誤差上限は 1/8 である。一意性は以下の別の証明で扱う。

紙と本文で試してみよう

同じ f で、目標 f(c)=1 の解の存在を [1,2] の端点の値から判断せよ。別に (x−3/2)² の両端の値と根を比較し、符号変化のない状況を説明せよ。

ヒントを見る

目標値が両端の値の間にあるかを先に確認する。存在保証に使えない検査と、不在の証明を混同しない。

解答を見る

−1<1<7 で f は連続なので、(1,2) 内に f(c)=1 の解が存在する。平方の関数は両端の値が同じ正数 1/4 だが、3/2 で値 0 となる根を持つ。目標 1 に対する解の正確な値を計算したわけではない。

よくある誤解と反例

中間値の定理で根を見つけたので、その根は一意で、数値も正確に計算できた。

定理は少なくとも一つの存在を保証する。例題の分数区間は誤差上限を与えるが、正確な根の値ではなく、一意性は追加で証明しなければならない。

理解を確かめる

連続な f で f(a)=0 なら、端点も根か？

答えと理由を見る

そうである。

解を開区間だけに強制的に制限せず、端点の実際の値が目標 0 と等しい。

不連続な階段関数の端点の値 −1、1 だけで、値 0 の根を保証できるか？

答えと理由を見る

できない。

区間全体の連続性がなく、階段関数は実際に 0 を飛び越える。

初期の長さが 2 の区間を正確に三回半分にすると、長さはいくらか？

答えと理由を見る

1/4 である。

2/2³=1/4 であり、中点の誤差上限はさらに半分の 1/8 である。

もう一歩先へ

発展：f(x)=x³+x−3 がすべての実数で狭義単調増加であることを、微分なしで示せ。x<y なら f(y)−f(x)=(y−x)(y²+xy+x²+1)>0 である。第二因子は (x+y/2)²+3y²/4+1≥1 で、第一因子は正である。異なる二つの入力が同じ出力 0 を取れないので、先ほど存在を示した根は一意である。また、反対符号の区間の縮小について帰納法を用いると、根の包含と長さ 2⁻ⁿ が保たれる。正確な符号判定・連続性・初期の包含という前提と、実際の数値プログラムを実行していない範囲を維持する。

小節 3.3

最大値・最小値の定理

最大の値と最小の値は、どんな連続関数にも必ずあるだろうか？

準備する概念と学習目標

準備する概念

  • 最大値 M は、ある許容入力 c で f(c)=M と実際に達成され、すべての x に対し f(x)≤M となる値である。最小値にも、逆の不等式と達成が必要である。
  • 上界はすべての値を上から抑える数で、達成されない場合もある。最小の上界を上限（supremum）、最大の下界を下限（infimum）という。
  • 実数の閉有界区間 [a,b] は端点を含み、長さが有限である。関数値と、その値を得る入力の位置は異なる答えである。

学習目標

  • 最大値・最小値の定理の連続性・閉区間・有界性の条件を確認する。
  • 最大値・最小値と達成点、上限・下限を区別する。
  • 平方完成で簡単な大域的最大値・最小値を証明し、開区間の反例と比較する。

存在を保証する条件

実数値関数が、空でない閉有界区間 [a,b] で連続なら、最大値と最小値をそれぞれ区間内で達成する。単に値が有界だという結論より強い。この定理は、達成位置が端点か内部か、何か所あるか、正確な値はいくらかまでは教えない。

例題ではまだ微分を使わず、平方完成と区間の比較で値を直接求める。一般の定理全体の証明には、実数の完備性とコンパクト性などの解析学の道具が必要であり、ここで一つの例題によって定理まで証明したとは主張しない。位置と値の計算は、定理による存在保証の後にも必要な別の作業である。

大域的な値と達成点

p(x)=5−(x−1)² では、平方≥0 なので p(x)≤5 である。x=1 が定義域に含まれれば、実際に値 5 を達成する。区間 [−1,4] では |x−1|≤3 なので平方≤9、したがって p(x)≥−4 であり、x=4 で −4 を達成する。

最大値 5 と達成点 1 を入れ替えて書かない。最小値は −4、達成点は 4 である。この関数と区間では、不等式の等号条件から、それぞれの達成点が一意であることも確認できる。一般の連続関数では、定数関数のように、すべての位置が最大値と最小値を同時に達成する場合もある。

条件が欠ける例を読む

開区間 (−1,4) の同じ p は、内部の 1 で最大値 5 を取るが、最小値はない。−4 より大きい値だけを取り、4 に近づくほど −4 に近づくからである。下限 −4 があっても、その入力 4 は許されない。一方、開区間なら必ず最大値も最小値もないという結論は、先ほどの最大値 5 が反証する。

閉区間だけでも不十分である。[0,1] で h(0)=2、0<x≤1 では h(x)=x と定義すると、最大値 2 はあるが最小値はない。正の値をいくらでも小さくできるが、0 を達成しない。0 で不連続なので定理の条件を満たさない。条件は十分条件であり、条件の不成立だけで最大値・最小値の不在が証明されるわけではない。

途中の過程をたどる例題

閉区間 [−1,4] で p(x)=5−(x−1)² の最大値・最小値と達成点を、微分なしで求めよ。

  1. 多項式 p は、この閉有界区間で連続なので、最大値と最小値の両方が存在する。
  2. (x−1)²≥0 なので p(x)≤5 である。x=1 は区間内で p(1)=5 なので、最大値 5 を達成する。
  3. 区間内では −2≤x−1≤3 なので |x−1|≤3、平方≤9 である。したがって p(x)≥−4 である。
  4. p(4)=−4、p(−1)=1 を比較し、平方が 9 になる許容される等号点が 4 だけであることを確認する。最小値 −4 の達成点は 4 である。

最大値 5 は x=1 で、最小値 −4 は x=4 で達成される。二つの値と位置をそれぞれ区別し、区間内のすべての入力についての不等式で検証した。

紙と本文で試してみよう

同じ p の定義域を開区間 (−1,4) に変える。最大値と最小値の達成の有無、および下限を紙上で判断せよ。[−1,4] の定数関数 7 には達成点が何個あるか？

ヒントを見る

入力 4 を関数値の表に入れない。定数関数はすべての許容点で同じ値を取る。

解答を見る

開区間の p の最大値 5 は 1 で達成されるが、最小値はない。下限 −4 には x→4− で近づくだけで、達成されない。定数関数 7 の最大値も最小値も 7 で、区間のすべての点で達成される。図や数値ツールは実行していない。

よくある誤解と反例

値が有界なら、最大値と最小値を必ず達成する。

開区間 (−1,4) の p は −4<p≤5 と有界だが、最小値 −4 を持たない。近づく境界値と、定義域内で達成する値を区別する。

理解を確かめる

定理は最大値の達成点が必ず内部にあると述べているか？

答えと理由を見る

述べていない。端点の場合もある。

例えば [0,1] で連続な f(x)=x は、端点 1 で最大値 1 を達成する。一般の定理は最大値や最小値の位置を内部に限定しない。

連続関数 x を ℝ 全体で考えると、最大値はあるか？

答えと理由を見る

ない。

どの入力よりも 1 大きい入力でさらに大きい値を取り、定義域が有界でない。

連続性・閉区間・有界性の条件の一つが欠けると、最大値と最小値の両方が必ずなくなるか？

答えと理由を見る

そうではない。

開区間の p も最大値 5 を持つ。十分条件を使えないことと、最大値・最小値の不在は異なる。

もう一歩先へ

発展：開区間で p(x)>−4 となることを |x−1|<3 から示し、正の整数 n に対し x_n=4−1/n を取り、n→∞ のとき p(x_n)=5−(3−1/n)²→−4 となることを計算せよ。したがって −4 は下界であり、どのさらに大きい数も下界になれないので、下限である。−4 自体は達成されないため最小値はない。閉区間の例題の最大値・最小値の証明は、平方の範囲だけを使う。一般の最大値・最小値の定理や、実際の最適化プログラムの性能を、この一例によって証明するものではない。

小節 3.4

不連続の種類と反例

一点の値だけを直せば、途切れた関数はどれも連続にできるだろうか？

準備する概念と学習目標

準備する概念

  • a の左側極限・右側極限は、それぞれ x<a と x>a の近い入力を対象とする。この単元で分類する点は、両側に入力がある内点である。
  • 有限の実数の極限と、±∞ への発散を区別する。無限大は、ここで連続性に必要な実数の関数値ではない。
  • 一点に定義した値を変更しても、その点を除く周囲の出力値は変わらない。

学習目標

  • 除去可能・跳躍・無限不連続を、左右の極限と実際の値で分類する。
  • 一点の再定義で解決する場合と、解決しない場合を区別する。
  • 振動の反例によって、三つの分類がすべての不連続を尽くさないことを説明する。

穴は一つの値で埋められる

ある内点 a で有限の両側極限 L が存在するのに、関数値がないか L と異なる場合を、除去可能な不連続と呼ぶ。その点だけ f(a)=L とすれば連続な延長になる。極限の計算と、現在の定義域・現在の値は異なる項目である。

r(x)=(x²−9)/(x−3) は x≠3 でのみ定義された式で、そこで x+3 と等しい。x→3 の極限 6 を求められても、約分だけで r(3) を定義することにはならない。値 5 を追加してもまだ不連続であり、6 を追加して初めて連続になる。

異なる片側の値と無限発散

有限の左側極限と右側極限が異なれば、跳躍不連続である。例えば x<0 で −2、x≥0 で 3 を与えると、左側は −2、右側は 3 である。f(0) をどの実数に変えても、二つの周囲の極限に同時に合わせられない。

1/(x−3) は、3 の左側で −∞、右側で +∞ に発散する。この無限不連続も、有限な一点の値の変更では解決しない。元の関数が 3 で定義されていない事実と、周囲での発散の形を別に書く。数値が大きい数個の標本だけでは、無限発散を証明したことにならない。

三分類の外にある振動と比喩の限界

x≠0 で sin(1/x) は 0 の近くで振動し続ける。有限の跳躍に対応する両側の値も、一定方向の無限発散も、有限の除去可能な極限もない。したがって、このよくある三種類がすべての不連続を分類するという主張は誤りである。以下では関数値の極限が異なる二つの接近数列によって、この振動を確認する。

鉛筆でグラフを描くという直感は導入の比喩だが、小さな画面や有限個の標本だけで連続性を確定できない。関数の定義域、値・極限・条件が成立しない理由を式で確認する。また |x| は 0 で連続なので、とがった形だけを見て不連続と呼んではいけない。この単元では実際のグラフやセンサーデータを試験していない。

途中の過程をたどる例題

x≠3 では (x²−9)/(x−3)、x=3 では k と定義する F_k の、3 での連続性を調べよ。k=5 と k=6 を比較せよ。

  1. 周囲の x≠3 では (x−3)(x+3)/(x−3)=x+3 と約分できる。元の分母が 0 になる点で、約分して直接代入しているのではない。
  2. したがって左右の極限はともに 6 であり、有限の両側極限も 6 である。
  3. 実際の値は F_k(3)=k なので、連続条件は k=6 である。k=5 は極限 6 と一致しない。
  4. k=5 の場合は 3 で除去可能な不連続であり、その一点だけを 6 に変えれば連続になる。跳躍や無限発散の例とは理由が異なる。

k=6 なら連続、k=5 なら除去可能な不連続である。極限 6 は周囲の式から、実際の値は別の区分的定義から読み取る。

紙と本文で試してみよう

x<2 では x+1、x>2 では 5−x、x=2 では k とする関数の連続条件を求めよ。別に、右側の式だけを 6−x に変えた場合、k 一つで連続性を直せるか？

ヒントを見る

実際の値より先に、二つの周囲の極限を計算し、それらが等しいか確認する。

解答を見る

最初の関数は左側 3、右側 3 なので、k=3 なら連続である。変更した関数は左側 3、右側 4 で跳躍し、どの k でも連続にはできない。すべて紙上の計算で、数値実行はしていない。

よくある誤解と反例

不連続はどれも、一点の値を適切に変えれば直る。

有限の両側極限がある除去可能な種類では可能である。異なる左右の極限、無限発散、sin(1/x) の振動では、一点の変更で周囲の挙動を変えることはできない。

理解を確かめる

両側極限 4 と実際の値 4 がすべて等しければ、不連続か？

答えと理由を見る

その点では連続である。

定義された値と有限の極限の一致という三つの条件を満たす。

有限の左側極限 1、右側極限 2 がある点は除去可能か？

答えと理由を見る

そうではない。跳躍不連続である。

一つの実際の値が、異なる両側の極限と同時に等しくなることはできない。

±∞ を実際の関数値として代入すれば、実数値関数の連続性になるか？

答えと理由を見る

ならない。

この単元は実数値関数の連続性と有限の極限を扱い、無限大は許される実数値ではない。

もう一歩先へ

発展：x_n=1/(π/2+2πn)、y_n=1/(3π/2+2πn) とし、n を非負整数として n→∞ とすると、両方とも正の値で 0 に近づく。しかし sin(1/x_n)=1、sin(1/y_n)=−1 なので、共通の有限な右側極限は存在し得ない。値は [−1,1] に有界なので、無限発散でもない。0 での値を何に定めても、この周囲の数列の出力は変わらない。これは数列による極限判定を用いた紙上の議論であり、三角関数コード・グラフ・数値標本を実行した証拠ではない。
