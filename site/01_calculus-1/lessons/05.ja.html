小節 5.1

積・商の微分

二つの量が同時に変わるとき、変化率も二つの変化率を掛ければよいのだろうか？

準備する概念と学習目標

準備する概念

  • 点 a で微分可能とは、実際の関数値を使った差分商が有限の実数に収束することをいう。微分可能ならその点で連続である。
  • 正の整数 n について (xⁿ)′=nxⁿ⁻¹ であり、定数の導関数は 0 である。和の導関数は各導関数の和である。
  • 積 fg と商 f/g は合成とは異なる。商では元の分母が 0 になる入力を除く。

学習目標

  • 積と商の微分法を、成立条件とともに適用する。
  • 展開して結果を照合し、約分後も元の定義域を保つ。

両方が変化する積

f と g が共通の開区間で定義され、a で微分可能なら、(fg)′(a)=f′(a)g(a)+f(a)g′(a) である。一方が変化する効果と、他方が変化する効果を足す。関数値と導関数を使う位置を先に示すと、二つの導関数を無条件に掛ける誤りを減らせる。

元の f と g がともに微分可能であることは十分条件である。fg が微分可能ならそれぞれも微分可能、という逆向きの主張ではない。f=g=|x| では各関数は 0 で微分不可能だが、積は x² なので微分可能である。

分母も変化する商

同じ条件に加えて g(a)≠0 なら、(f/g)′(a)=[f′(a)g(a)−f(a)g′(a)]/g(a)² である。g の連続性により、a の近くでも分母が 0 にならない小さな区間を選べる。分子の引き算の順序を逆にすると符号が変わる。

分母を微分して新しい分母にする f′/g′ は一般的な規則ではない。特に g が 0 でない定数なら g′=0 だが、f/g は微分できる。結果は f′/g であり、導関数が 0 の分母で割る必要はない。

式の形を変えても穴は残る

P(x)=(x²+2)(x−3) はすべての実数で定義される。一方、H(x)=(x²+2)/(x−3) は x=3 を除く。計算式を整理することと、新たに関数値を定義することを区別する。

例えば (x²−1)/(x−1)=x+1 は x≠1 のときだけ成立する。元の関数は 1 で値をもたないので、その点の導関数もない。値 2 を別に補った新しい関数は区間全体で x+1 と等しく、そのとき初めて 1 で導関数 1 が得られる。

途中の過程をたどる例題

P=(x²+2)(x−3) と H=(x²+2)/(x−3) の導関数と、x=1 における導関数の値を求めよう。定義域も書こう。

  1. f=x²+2, f′=2x, g=x−3, g′=1 と役割を分ける。P はすべての実数、H は x≠3 で定義される。
  2. P′=2x(x−3)+(x²+2)=3x²−6x+2 である。P を x³−3x²+2x−6 に展開しても同じ結果になる。
  3. H′=[2x(x−3)−(x²+2)]/(x−3)²=(x²−6x−2)/(x−3)² である。分母の二乗と引き算の順序を保つ。
  4. x=1 では P′(1)=3−6+2=−1, H′(1)=(1−6−2)/4=−7/4 である。いずれも元の定義域内の点なので評価できる。

P′=3x²−6x+2, P′(1)=−1。H′=(x²−6x−2)/(x−3)² (x≠3), H′(1)=−7/4。

紙と本文で試してみよう

a=1 で u=3, v=−2, u′=4, v′=5 となる微分可能な関数について、積と商の導関数を求めよう。別に R=x/(x+2) の R′ と R′(0) を求めよう。

ヒントを見る

u′v と uv′ をそれぞれ書き、積では和、商では差を使う。v² と R の元の分母の条件も書こう。

解答を見る

積は 4(−2)+3·5=7、商は [4(−2)−3·5]/(−2)²=−23/4 である。例えば u=4x−1, v=5x−7 は指定された点の条件を実際に満たす。R′=[(x+2)−x]/(x+2)²=2/(x+2)² (x≠−2), R′(0)=1/2 である。すべて紙上の計算である。

よくある誤解と反例

積は導関数どうしを掛け、商は導関数どうしを割ればよい。

x·x=x² の導関数は 2x だが、1·1=1 はそれとは異なる。x/2 の導関数は 1/2 なのに、1/0 は定義されない。入力における実際の関数値を含む規則が必要である。

理解を確かめる

商の微分法の分母は g′² だろうか？

答えと理由を見る

g² である。

元の関数の分母の値を二乗し、g(a)≠0 が必要になる。

約分した (x²−1)/(x−1) を、1 でそのまま微分できるだろうか？

答えと理由を見る

元の関数としてはできない。

1 は定義域の外である。その点の値を別に補えば、新しい関数についての問いになる。

fg が 0 で微分可能なら、f と g もそれぞれ微分可能だろうか？

答えと理由を見る

必ずしもそうではない。

f=g=|x| の積 x² は 0 で微分可能である。

もう一歩先へ

発展：Δf=f(a+h)−f(a), Δg=g(a+h)−g(a) と書くと、積の差分商は (Δf/h)g(a+h)+f(a)(Δg/h) となる。h→0 で微分可能性と連続性を使うと、二つの項の極限は f′(a)g(a), f(a)g′(a) になる。商は直接引き算をして [(Δf/h)g(a)−f(a)(Δg/h)]/[g(a+h)g(a)] と整理できる。g(a+h)→g(a)≠0 なので分母の極限は g(a)² となり、商の微分法が得られる。約分で h=0 を代入せず、共通の定義域内にある十分小さい h だけを使う。

小節 5.2

合成と連鎖律

入力が変わって二つの関数の層を通るとき、外側の関数の変化率はどこで計算するのだろうか？

準備する概念と学習目標

準備する概念

  • 合成 f∘g は、x を g(x) に変えた後で f に入れる関数である。g の出力が f の定義域に属する必要がある。
  • f′(u) は入力 u における外側の変化率、g′(x) は最初の入力 x に対する内側の変化率である。
  • ある点で微分可能であっても、関数値と導関数の値が同じになるわけではない。

学習目標

  • 内側・外側の関数と、各導関数を評価する位置を区別する。
  • 内側の変化率が 0 の場合も扱い、規則の十分条件を逆向きに使わない。

評価する位置を見失わない規則

g が a で、f が g(a) で微分可能であり、合成が a の近くで定義されるなら、(f∘g)′(a)=f′(g(a))g′(a) である。外側の導関数に入れるのは内側の関数値 g(a) であり、g′(a) ではない。内側と外側の段階の入力を、紙に分けて書こう。

h(x)=(2x²−1)³ では g(x)=2x²−1, f(u)=u³ である。f′(u)=3u², g′(x)=4x なので h′=3(2x²−1)²·4x となる。外側を微分して元の内側の式を残し、内側の導関数を掛ける。

複数の層とほかの規則の組合せ

H(x)=((x+2)²+3)³ は x→v=x+2→u=v²+3→u³ の三つの層をもつ。変化率は 3u²·2v·1 とつながる。外側の導関数を内側の導関数で評価する 3(2v)² は別の計算である。

積と合成が同時に現れるなら、先に構造を分ける。x(2x²−1)³ の導関数は (2x²−1)³+x·12x(2x²−1)² である。積の最初の効果と内側の変化の効果のどちらも省かない。

内側が止まる点と条件の向き

g′(a)=0 でも外側の導関数が存在すれば、合成の導関数は 0 である。これは g が近くの全域で定数という意味ではない。g=x² は 0 で g′=0 だが、近くでは値が変わる。

逆に、合成が微分可能だから外側の関数も対応する値で微分可能とは結論できない。f(u)=|u|, g(x)=x² では合成は x² だが、f は 0 で微分不可能である。この例の合成の導関数は直接求める必要があり、微分不可能な f に規則を適用して 0 を掛けた、と説明してはいけない。

途中の過程をたどる例題

h=(2x²−1)³ と H=((x+2)²+3)³ の導関数、および h′(1), H′(0) を求めよう。

  1. h の内側 g=2x²−1 は g′=4x、外側 f(u)=u³ は f′(u)=3u² である。両方の多項式はすべての実数で微分可能である。
  2. h′=3(2x²−1)²·4x=12x(2x²−1)² である。x=1 では g(1)=1 なので h′(1)=12 となる。
  3. H では v=x+2, u=v²+3 である。H′=3u²·2v·1=6(x+2)((x+2)²+3)² となる。
  4. x=0 では v=2,u=7 なので H′(0)=3·49·4=588 である。途中の関数値 2/7 と途中の導関数の値 1/4 を区別する。

h′=12x(2x²−1)², h′(1)=12。H′=6(x+2)((x+2)²+3)², H′(0)=588。

紙と本文で試してみよう

G=(3x−2)⁴ の G′ と G′(1) を求めよう。続いて f(u)=u², g(x)=x² の合成について、0 で規則を確認しよう。

ヒントを見る

最初の関数の内側の導関数は 3 である。二つ目は合成を先に整理した x⁴ と照合する。

解答を見る

G′=4(3x−2)³·3=12(3x−2)³ であり、G′(1)=12 である。二つ目の合成は x⁴ なので導関数は 4x³ である。規則でも f′(g(x))g′(x)=2x²·2x=4x³ となり、0 では 0 になる。内側の関数が 0 の周囲で一定である必要はない。

よくある誤解と反例

dy/dx=(dy/du)(du/dx) は、いつでも数のように du を約分して証明できる。

ここで導関数の記号は演算と評価する位置を表す。Δg=0 なら変化量で割る非形式的な証明は進められない。微分可能性の条件の下で余りを使う証明は、この場合も扱う。

理解を確かめる

連鎖律では外側の導関数を g′(a) で評価するのだろうか？

答えと理由を見る

g(a) で評価する。

外側の関数が実際に受け取る入力は、内側の関数値である。

g′(a)=0 なら、合成の導関数を得るために 0 で割る必要があるだろうか？

答えと理由を見る

ない。

二つの微分可能性の条件の下で、f′(g(a)) と 0 の積から結果を得る。

|x²| の微分可能性は、|u| が 0 で微分可能であることを示すだろうか？

答えと理由を見る

示さない。

合成は x² だが、外側の |u| の左右の差分商は −1 と 1 である。

もう一歩先へ

発展：b=g(a), Δg=g(a+h)−g(a) とする。外側の微分可能性は f(b+k)−f(b)=f′(b)k+ε(k)k, ε(k)→0 と表せ、ε(0)=0 と定める。合成の差分商は [f′(b)+ε(Δg)](Δg/h) である。g の連続性から Δg→0 となり、Δg/h→g′(a) は有界なので ε(Δg)Δg/h→0 となる。Δg=0 となる h でも式はそのまま成立し、0 で割らない。したがって f′(b)g′(a) を得る。この証明は両方の関数の実際の微分可能性と近くで合成が定義されることを前提とし、外側の折れ曲がりに架空の導関数を与えて使うものではない。

小節 5.3

高階導関数

導関数をもう一度微分することは、最初の導関数を二乗することと同じだろうか？

準備する概念と学習目標

準備する概念

  • 導関数 f′ は、可能な各入力にその点の変化率を対応させる新しい関数である。
  • f″(a) は a の近くで定義された f′ の差分商の極限であり、(f′(a))² とは異なる演算である。
  • 仮想の位置モデルで時間の単位が秒、位置の単位が m なら、速度は m/s、加速度は m/s² である。

学習目標

  • 高階導関数を順に計算し、累乗と区別する。
  • 高階微分の存在条件と、位置・速度・加速度の単位を一緒に確認する。

新しい関数の変化率

f″ は f′ の導関数、f‴ は f″ の導関数である。f⁽ⁿ⁾ の括弧付き n は n 回微分する記号であり、fⁿ の関数値の累乗とは異なる。d²f/dx² も二回微分する記号で、分子と分母をそれぞれ数として二乗した分数ではない。

f″(a) を問う前に、f′ が a の近くで定義され、その関数が a で微分可能かを確認する。f′(a) という一つの値だけを知っても二階導関数を決めることはできない。一回微分可能であるだけでは次の微分が自動的に存在しない。

多項式では次数が下がる

正の整数次数の単項式を微分するたびに、指数は一つ下がる。例えば x⁴ の導関数は 4x³,12x²,24x,24,0 の順になる。最後の定数をもう一度微分すると 0 となり、その後も 0 である。

多項式の反復規則をほかの関数に無条件で移してはいけない。x|x| は 0 での差分商が |h| なので一階導関数 0 をもち、一階導関数全体は 2|x| である。この導関数の 0 での左右の差分商は −2 と 2 なので、二階導関数は存在しない。一階導関数が連続であることと、二回微分可能であることは異なる。

速度の変化を読む

独自の位置モデル s(t)=t³−3t²+2t で、数値 t は秒単位の時間、数値 s は m 単位の座標である。物理単位をすべて書けば各項の係数は 1 m/s³, −3 m/s², 2 m/s である。実際の観測資料に当てはめた式という主張ではない。

v(t)=3t²−6t+2 m/s, a(t)=6t−6 m/s² である。t=1 では v=−1,a=0 になる。その瞬間の加速度が 0 でも速度は 0 ではなく、全時間で速度が一定という意味でもない。負の速度は向きの情報を含み、速さは |v| である。

途中の過程をたどる例題

f=x⁴−2x³+x−5 を五回まで微分しよう。f′(1), f″(1), f‴(1) を求め、f″(1) と (f′(1))² を比べよう。

  1. 定数倍・和・累乗の規則から f′=4x³−6x²+1 となる。−5 の微分は 0、x の微分は 1 である。
  2. もう一度微分して f″=12x²−12x, f‴=24x−12 となる。それぞれ直前の関数全体を微分する。
  3. f⁽⁴⁾=24, f⁽⁵⁾=0 である。微分の階数が増えたという意味で、f を四回・五回掛けたという意味ではない。
  4. x=1 では f′=−1, f″=0, f‴=12 である。(f′(1))²=1 なので f″(1)=0 とは異なる。

f′=4x³−6x²+1, f″=12x²−12x, f‴=24x−12, f⁽⁴⁾=24, f⁽⁵⁾=0。点 1 での値は −1/0/12 で、一階導関数の二乗は 1 である。

紙と本文で試してみよう

r=x³−4x の最初の四つの導関数を求め、r′(0), r″(0) を比べよう。別に s=t³−3t²+2t で t=1 の速度・速さ・加速度を求めよう。

ヒントを見る

r″ は r′ をもう一度微分する。位置座標の単位と時間を書き、速さは絶対値で求める。

解答を見る

r′=3x²−4, r″=6x, r‴=6, r⁽⁴⁾=0 である。r′(0)=−4, r″(0)=0 であり、二乗 16 とは異なる。仮想の位置モデルで t=1 の速度は −1 m/s、速さは 1 m/s、加速度は 0 m/s² である。実際の運動の測定ではない。

よくある誤解と反例

一回微分可能な関数は、望むだけ何回でも微分できる。

f=x|x| はすべての点で一回微分可能で、f′=2|x| も連続である。しかし f″(0) は左側 −2/右側 2 で存在しない。次の段階の定義を直接確認する必要がある。

理解を確かめる

f⁽³⁾ は f³ と同じだろうか？

答えと理由を見る

異なる。

前者は三階導関数、後者は関数値の三乗である。

ある瞬間の加速度が 0 なら、その瞬間の速度も 0 だろうか？

答えと理由を見る

そうではない。

独自のモデルの t=1 では a=0 だが v=−1 である。

次数 4 の多項式の五階導関数は何だろうか？

答えと理由を見る

すべての実数で 0 である。

四回微分すると定数になり、もう一度微分すると 0 になる。

もう一歩先へ

発展：整数 n≥1 について、xⁿ の k 階導関数 (0≤k≤n) は n!/(n−k)!·xⁿ⁻ᵏ である。k=0 は元の関数であり、k<n でもう一度微分すると係数に n−k が掛かり、次の k+1 の式になる。k=n では定数 n!、その後は 0 となるので帰納法が完了する。これは有限の多項式に対する厳密な公式で、非整数指数の定義域や任意の関数の高階微分の存在を代わりに証明するものではない。C¹ は一階導関数まで存在して連続であるという意味、C² は二階導関数まで存在して連続であるという、より強い条件である。x|x| は C¹ だが C² ではない独自の反例である。

小節 5.4

区分的に定義された関数の微分

各区間の式が滑らかでも、つなぎ目の一点で微分可能なのだろうか？

準備する概念と学習目標

準備する概念

  • 接合点の実際の関数値は、どの枝の条件に等号を含めたかで定まる。
  • 連続とは左右の関数値の極限が実際の値と等しいこと、微分可能とは左右の差分商が同じ有限値に収束することである。
  • 周囲の枝から求めた導関数の値と、接合点の定義から求めた差分商を混同しない。

学習目標

  • 接合点でまず連続の条件を定め、左右の差分商を求める。
  • 一階微分と高階微分で、それぞれ接合を確認する。

値をつないでから傾きをつなぐ

F(x) を x<2 では ax+b、x≥2 では x²+1 とする。実際の F(2)=5 である。連続には左側極限 2a+b が 5 である必要がある。この条件がなければ、枝の式の傾きだけを比べて微分可能とはいえない。

連続の条件を満たすと左側の差分商は a、右側は [(2+h)²+1−5]/h=4+h になる。したがって左右の有限極限が等しいためには a=4, b=−3 である。右側の式の条件に等号があっても、右側の傾きだけで答えてはいけない。

枝の導関数だけが等しい場合の落とし穴

J(x)=x (x≠0), J(0)=1 は 0 の左右の周囲で枝の導関数が 1 である。しかし実際の値 J(0)=1 を使う差分商は (h−1)/h=1−1/h で、有限の数に収束しない。まず値の不一致を確認する必要がある。

|x−1| は連続だが、接合点 1 の左側差分商 −1 と右側差分商 +1 が異なる。したがって連続の確認を微分の確認の代わりにはできない。元の定義域の端点での片側微分は、ここで扱う内点での両側微分と別に示す。

一度つながっても二度目もつながるとは限らない

a=4,b=−3 とした F の一階導関数は、x<2 で 4、x>2 で 2x、x=2 で 4 である。左右の値が 4 でつながり、一階導関数は連続になる。

その一階導関数をもう一度微分すると、2 での左側差分商は 0、右側は [2(2+h)−4]/h=2 である。したがって F″(2) は存在しない。各区間で任意の階数まで微分可能でも、接合点の高階微分には別の制約がある。

途中の過程をたどる例題

F(x)=ax+b (x<2), x²+1 (x≥2) が 2 で微分可能となるように a,b を定め、F′(2) と F″(2) の存在を確認しよう。

  1. F(2)=5 である。微分可能なら連続なので、まず 2a+b=5 が必要である。
  2. h<0 なら連続の条件の下で [a(2+h)+b−5]/h=a である。h>0 なら差分商は 4+h なので右側極限は 4 である。
  3. 左右の極限を等しくして a=4,b=−3 を得る。このとき左右の差分商の極限は 4 なので F′(2)=4 である。
  4. F′ は左側で 4、点 2 で 4、右側で 2x である。F′ の差分商は左側 0/右側 2 なので、F″(2) は存在しない。

a=4,b=−3, F′(2)=4。F は 2 で一回微分可能で、一階導関数は連続だが、二階導関数はない。

紙と本文で試してみよう

G(x)=cx+d (x<1), x³ (x≥1) を 1 で微分可能にする c,d を求めよう。このとき G″(1) も存在するか、差分商で判断しよう。

ヒントを見る

G(1)=1 と連続の条件 c+d=1 から始める。一階導関数の点 1 の値も書き、二つ目の差分商に入れる。

解答を見る

連続には c+d=1 が必要で、左側の最初の差分商は c、右側の 3+3h+h² の極限は 3 なので c=3,d=−2 である。G′(1)=3 で、左の枝は 3、右の枝は 3x² である。G′ の差分商は左側 0/右側 6+3h なので G″(1) は存在しない。すべて紙上の計算である。

よくある誤解と反例

左右の枝をそれぞれ微分した式の値が等しければ、接合点も常に微分可能である。

実際の接合値と連続性を先に確認する必要がある。J(x)=x (x≠0), J(0)=1 では周囲の枝の導関数はどちらも 1 だが、接合点の差分商は 1−1/h なので微分不可能である。

理解を確かめる

F(2)=5 なのに左側極限が 4 なら、左右の傾きだけを等しくしてもよいだろうか？

答えと理由を見る

よくない。

微分可能性に必要な連続性がすでに成立しない。

F′(2)=4 で一階導関数が連続なら、F″(2) も自動的に存在するだろうか？

答えと理由を見る

存在するとは限らない。

この単元の F′ の左右の差分商は 0 と 2 である。

右側の枝の条件に等号があれば、微分も右側だけを調べるのだろうか？

答えと理由を見る

内点では両側を調べる。

等号は実際の値の定義に関わり、導関数の両側極限の条件とは異なる。

もう一歩先へ

発展：接合点 a に両側から近づけ、実際の F(a) が定義されているとする。差分商の左側・右側極限が同じ有限値 L なら、任意の ε>0 に対して左側の誤差を ε 未満にする δ₋ と右側の δ₊ を選ぶ。δ=min(δ₋,δ₊) とすれば、0<|h|<δ のどちらの符号でも全体の差分商の誤差が ε 未満なので F′(a)=L である。逆に、全体の極限が L なら各片側の極限も L である。したがって同じ有限の片側差分商極限をもつことは、その点で通常の導関数が存在するための必要十分条件である。F″ を調べるときは、この議論を F ではなく、実際の接合値まで定義された F′ にもう一度適用する。
