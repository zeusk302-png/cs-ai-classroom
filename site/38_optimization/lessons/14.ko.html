소단원 14.1

회귀·분류·자원배분 모델

같은 최소화 기호로 자료를 맞추고 두 작업에 자원을 나누는 문제를 적을 수 있을까?

준비 개념과 학습 목표

준비 개념

  • 목적함수와 제약

  • 평균 제곱 오차

  • 벡터 내적

학습 목표

  • 결정 변수·자료·단위를 구별한다.

  • 회귀와 분류 목적의 차이를 설명한다.

  • 연속 자원 배분과 정수 결정을 구별한다.

문제를 식으로 옮기는 순서

먼저 바꿀 수 있는 결정 변수, 이미 정한 자료와 허용 범위를 적는다. 다음 목적의 단위와 최소화/최대화를 정한다. 회귀에서는 고정 자료 A,b에 대해 ||Aw−b||² 같은 오차를 줄이고 필요하면 λ||w||², λ≥0을 더한다. 이것은 관측 자료에 대한 적합이며 새 자료의 예측 성능을 자동 증명하지 않는다.

분류의 한 모형은 고정 특징 zᵢ와 표지 yᵢ∈{−1,+1}에 대해 평균 log(1+exp(−yᵢzᵢᵀw))에 비음수 제곱 정규화를 더한다. 점수 zᵀw와 분류 규칙을 별도로 적는다. 선형 점수의 이 손실은 볼록하지만 이 사실을 임의 신경망의 전체 파라미터 문제로 확장하지 않는다.

자원을 나누는 제약

두 작업의 할당을 x₁,x₂라 하면 음수 할당 금지 x₁,x₂≥0과 예산 x₁+x₂=B를 적을 수 있다. 원하는 목표와의 제곱 거리를 줄이는 모형은 한 가지 선택이며 실제 사용자 만족을 관측한 것은 아니다.

아래에서는 자원을 분할 가능한 연속량으로 둔다. 사람이 몇 명인지처럼 정수여야 한다면 그 조건을 추가해야 하며 연속해를 반올림하는 것만으로 최적성과 예산 충족이 보장되지 않는다. 자료의 단위가 바뀌면 비용과 목표의 계수도 함께 확인한다.

해가 답하는 질문을 제한한다

모형의 최솟값은 작성한 목적과 제약 안에서의 답이다. 실제 목적을 잘못 적거나 중요한 제한을 빼면 계산이 정확해도 현실에 적절하지 않을 수 있다. 데이터 분할, 비용 가중치와 실행 가능한 범위는 사용 목적에 맞게 따로 정한다.

모형 보고에는 자료·단위·제약·목적·선택 이유를 남긴다. 계산한 해, 새 자료 평가, 실제 운영 성과를 구별한다. 이 단원은 설치 없이 식과 손계산으로 모형을 확인하며 실제 solver나 분류기를 훈련하지 않는다.

중간 과정을 따라가는 예제

연속량 x₁+x₂=4, x₁,x₂≥0에서 f=(x₁−3)²+(x₂−2)²를 최소화하라.

  1. x₂ = 4 − x₁를 대입하면 0 ≤ x₁ ≤ 4이고 f = (x₁ − 3)² + (2 − x₁)²다.

  2. 완전제곱으로 f = 2(x₁ − 5/2)² + 1/2가 된다.

  3. x₁ = 5/2, x₂ = 3/2는 예산과 비음수 조건을 만족하며 제곱 항을 0으로 만든다.

연속 최적 할당은 (5/2, 3/2), 목적값은 1/2다. 목표 (3, 2)는 총량 5라서 예산 4를 만족하지 않는다.

종이와 본문으로 직접 해보기

같은 모형에서 두 할당이 정수여야 한다면 (2,2)와 (3,1)의 목적값을 구하고 연속해와 비교하라.

힌트 보기

완전제곱 식에서 정수 x₁의 5/2까지 거리를 비교한다.

풀이 보기

두 경우 모두 목적값은 1이다. 허용 정수 x₁ = 0, 1, 2, 3, 4의 목적값은 각각 13, 5, 1, 1, 5다. 5/2에 가장 가까운 2와 3이 정수 최적해이며 연속 최적값 1/2보다 크다.

오해와 반례

최적화 프로그램이 답을 내면 현실 목표도 반드시 달성했다.

해는 정한 모형을 해결한다. 위 연속해는 정수 사람 배치로 그대로 사용할 수 없고 목표(3,2)도 예산 때문에 불가능하다.

소단원 14.2

모형의 볼록성 확인

제곱이 들어간 식은 어느 방향으로 최적화해도 볼록 문제일까?

준비 개념과 학습 목표

준비 개념

  • 볼록함수와 볼록집합

  • 아핀함수

  • 2차 미분

학습 목표

  • 목적과 제약의 방향을 함께 점검한다.

  • 표현과 볼록집합의 차이를 설명한다.

  • DCP의 충분 판정과 unknown을 구별한다.

목적만 검사하지 않는다

표준 볼록 최소화 모형은 볼록 목적 f₀, 볼록 함수의 부등식 fᵢ≤0와 아핀 등식 Ax=b를 사용한다. 이 조건이면 허용 집합도 볼록하다. 최대화 모형은 오목 목적을 사용한다. 제곱이 볼록이라고 제곱을 최대화하는 문제까지 같은 규칙으로 인증되는 것은 아니다.

최소제곱의 Hessian은 2AᵀA이고 vᵀ(2AᵀA)v = 2||Av||² ≥ 0이다. 따라서 고정 A와 b의 제곱 오차는 볼록하다. 모든 고유값이 반드시 양수라는 뜻은 아니므로 최적 계수의 유일성에는 별도 조건이 필요하다.

같은 집합도 표현이 다를 수 있다

x²≤1의 집합은 [−1,1]이고 볼록 부등식 x²−1≤0 형태다. x²=1의 집합은 두 점 {−1,1}이며 그 중간0을 포함하지 않아 볼록하지 않다. 등호와 부등호 하나가 다른 문제를 만든다.

어떤 비아핀 등식이 우연히 볼록집합을 표현할 수도 있다. 그렇더라도 표준 모형 형식이나 자동 도구의 인증을 바로 얻지는 못한다. 허용 집합이 같은 아핀 표현으로 바꿀 수 있는지 확인하고 변환의 동치 조건을 기록한다.

자동 규칙의 한계를 읽는다

DCP는 함수의 곡률·단조성·입력의 부호와 합성 구조를 점검하는 충분한 규칙이다. unknown은 이 표현을 규칙으로 인증하지 못했다는 뜻이며 비볼록이라는 수학적 증명이 아니다. 식을 동치로 재표현하면 인증 결과가 달라질 수 있다.

반대로 DCP 인증을 통과해도 자료가 틀렸거나 제약이 모순일 수 있다. 볼록성, 해의 존재, 수치 solver 성공은 각각 검사한다. 아래 곡률은 수학 식으로 검토하며 실제 is_dcp 호출 결과를 기록하지 않는다.

중간 과정을 따라가는 예제

한 변수 f(w) = (w − 2)² + (w + 1)²를 0 ≤ w ≤ 2에서 최소화하는 모형과 같은 함수의 최대화 모형을 비교하라.

  1. 전개하면 f = 2w² − 2w + 5 = 2(w − 1/2)² + 9/2이고 f″ = 4 ≥ 0이다.

  2. 구간은 아핀 부등식으로 표현되는 볼록집합이므로 최소화는 볼록 모형이다. w = 1/2에서 최솟값은 9/2다.

  3. 같은 볼록 함수를 최대화하는 모형은 볼록 최적화의 오목 목적 조건에 맞지 않는다. 여기서는 볼록 함수의 구간 내 값이 양 끝값의 최댓값 이하이므로 끝점을 비교한다. f(0) = 5, f(2) = 9여서 최댓값은 9다.

최소화는 볼록 모형이고 최적 w = 1/2, 값은 9/2다. 최대화의 답 w = 2, 값 9는 이 작은 식을 별도로 분석한 결과다.

종이와 본문으로 직접 해보기

x²=1의 두 허용점의 중간이 허용되는지 확인하고 x²≤1과 비교하라.

힌트 보기

중간점은 (−1+1)/2=0이다.

풀이 보기

중간점의 0² = 0은 1과 달라 등식의 집합은 볼록하지 않다. 부등식에서는 0 ≤ 1이고 전체 구간 [−1, 1]이 허용된다.

오해와 반례

자동 곡률 판정이 unknown이면 그 함수는 반드시 비볼록이다.

충분한 합성 규칙의 실패는 비볼록성의 증명이 아니다. 정의·미분으로 조사하고 동치 표현과 도구의 조건을 별도로 확인한다.

소단원 14.3

해 상태·잔차·쌍대 gap

목적값이 작다는 출력만으로 제약을 만족한 최적해라고 할 수 있을까?

준비 개념과 학습 목표

준비 개념

  • 라그랑주 함수

  • 허용해와 하한

  • 절댓값

학습 목표

  • solver 상태의 의미를 구별한다.

  • 원래 제약의 잔차를 계산한다.

  • 허용한 원·쌍대 쌍의 gap을 해석한다.

출력의 상태부터 읽는다

해 상태에는 optimal, infeasible, unbounded와 낮은 정확도를 알리는 inaccurate 계열이 있다. infeasible은 허용해가 없다는 판정, 최소화 unbounded는 목적을 아래로 제한할 수 없다는 판정이다. 도구 오류나 시간 제한을 곧바로 모형 infeasible로 바꾸어 쓰지 않는다.

실제 도구는 상태별 변수값 처리와 지원 범위가 다르므로 사용 버전 문서를 확인한다. optimal도 수치 허용오차 아래의 결과이므로 원래 식에 다시 대입한다. 아래는 solver가 낸 로그가 아니라 우리가 만든 후보의 검사다.

잔차와 단위를 기록한다

등식 Ax=b의 잔차는 Ax−b이고 부등식 fᵢ(x)≤0의 위반량은 max(fᵢ(x),0)로 잡을 수 있다. 한 수로 보고할 때 사용한 norm·단위·절대/상대 허용오차를 명시한다. 자료의 크기가 다른 문제에 같은 절대 임계값을 무조건 적용하지 않는다.

미분 가능한 제약 문제에서는 정지성·승수 부호·상보성도 대조한다. 제약이 있는 최적점의 원래 목적 기울기는 0이 아닐 수 있다. 작은 잔차 몇 개만으로 비볼록 전역 최적성이나 모델의 현실 적합성을 확정하지 않는다.

하한과 상한을 한 쌍으로 쓴다

원래 최소화 모형의 허용점 x는 상한 f(x)를 준다. 쌍대 허용 승수의 쌍대함수 g는 하한을 준다. 그래서 g≤p*≤f(x)이고 gap=f(x)−g가 최적값과의 차이를 위에서 제한한다. 원래 점의 허용성과 쌍대 조건을 모두 확인해야 이 인증을 쓸 수 있다.

원문 조건이 정확히 충족된 수학적 쌍과 수치 근사 잔차는 구별한다. 부호가 잘못된 승수나 허용하지 않은 원래 점에 gap 공식을 넣어 음수가 나왔다면 최적성을 증명한 것이 아니다. 강한 쌍대성은 gap을 임의로 작게 만들 수 있는 보장에 추가로 필요할 수 있다.

중간 과정을 따라가는 예제

min f(x) = (x − 2)²/2, 제약 x ≥ 3을 보자. λ ≥ 0에서 L = f + λ(3 − x)이고 g(λ) = λ − λ²/2다. 후보 x = 16/5, λ = 1의 위반·정지성·상보성·gap을 구하라.

  1. x = 3.2 ≥ 3이므로 원 제약 위반은 0이다. λ = 1 ≥ 0이므로 쌍대 부호도 맞으며 g도 유한하다. ∂L/∂x = x − 2 − λ = 1/5다.

  2. 상보성의 절댓값은 |λ(3 − x)| = 1/5다. f(16/5) = (6/5)²/2 = 18/25, g(1) = 1/2다.

  3. gap = 18/25 − 1/2 = 11/50 = 0.22다. x* = 3의 최적값 1/2와 실제 목적 차이도 11/50이며 gap은 0이 아니다.

위반이 0이어도 정지성과 상보성의 절댓값은 각각 1/5다. 허용한 쌍의 gap 11/50은 목적 오차의 상한이다.

종이와 본문으로 직접 해보기

x=3, λ=1 및 x=29/10, λ=1의 목적값과 위반량을 비교하라. 두 경우 모두 gap으로 인증되는가?

힌트 보기

목적값보다 먼저 x≥3을 검사한다.

풀이 보기

x = 3은 f = 1/2, 위반 0, 정지성 0, 상보성 0, gap 0이어서 최적이다. x = 2.9는 f = 81/200이지만 위반 1/10이 있다. f − g = −19/200을 최적성 gap 인증으로 쓸 수 없다.

오해와 반례

출력 목적값이 인증한 최적값보다 작으면 더 좋은 허용해다.

제약 위반일 수 있다. 위 x = 2.9의 목적값 0.405는 0.5보다 작지만 허용되지 않으므로 원 문제의 더 좋은 해가 아니다.

답과 이유 보기

한 단계 더

g는 L을 x에 대해 최소화해서 얻는다. L = (x − (2 + λ))²/2 + λ − λ²/2이므로 x = 2 + λ에서 g = λ − λ²/2 = 1/2 − (λ − 1)²/2다. 따라서 λ = 1은 쌍대 최댓값 1/2를 주고 원래 허용점 x = 3과 gap은 0이다. L의 최소화는 원래 x ≥ 3 제약을 강제하는 문제가 아니다. 임의 승수에 따른 L의 최소점이 원래 모형에서도 허용된다고 가정하지 않는다.

소단원 14.4

비볼록 문제의 결과 해석 한계

기울기가0인 점을 찾았다는 말과 가장 낮은 점을 찾았다는 말은 같을까?

준비 개념과 학습 목표

준비 개념

  • 도함수와 2차 미분

  • 국소/전역 최적성

  • 실험의 재현 조건

학습 목표

  • 정지점과 국소/전역 최솟값을 구별한다.

  • 초기값 비교가 주는 증거의 한계를 설명한다.

  • 수치 결과와 수학 인증을 구별한다.

정지점은 분류가 필요하다

제약 없는 미분 가능 함수에서 ∇f=0은 국소 최적점의 필요한 조건일 수 있지만 극댓값이나 안장점도 해당한다. 볼록 문제의 국소 최적성은 전역으로 이어지지만 이 논리를 비볼록 문제에 그대로 적용하지 않는다.

여러 초기값에서 낮은 목적값을 얻으면 비교한 실행의 좋은 후보를 고를 수 있다. 시험하지 않은 영역의 더 좋은 해가 없다는 증명은 아니다. 제약 허용성·수렴 조건·실제 목적을 먼저 맞춰 비교한다.

작은 식에서도 멈추는 점이 다르다

아래 f(x) = (x² − 1)²는 항상 0 이상이고 x = −1, +1에서 0이다. 하지만 x = 0에서도 도함수가 0이다. 평평한 기울기를 찾는 종료 규칙만 사용하면 중심 부근의 국소 극댓값을 종료 후보로 받아들일 수 있다. x = 0은 이 함수의 전역 극댓값이 아니며 |x|가 커지면 함수값은 무한히 증가한다.

이 식의 전역 최솟값0은 부등식 f≥0과 그 값을 달성한 점으로 증명한다. 실제 optimizer가 그 점을 찾았다고 주장하는 것은 별도 실행 증거가 필요하다. 손으로 구성한 경로를 라이브러리의 수렴 실험으로 바꾸어 쓰지 않는다.

보고서를 증거별로 적는다

자료와 전처리·목적·제약·초기값·난수·학습률·정지 조건·도구 버전을 기록한다. 목적값, 제약 위반, 정지성, 계산 예산과 별도 평가 지표를 구분한다. 실행 횟수 중 최선만 남기면 실패와 변동을 숨길 수 있다.

학습 문제에서는 훈련 손실의 최소화와 일반화도 다른 주장이다. 실제 실행을 하지 않았다면 기대 계산과 이론 분석으로 표시한다. 설치 없는 활동도 가치가 있지만 실제 학습자 이해·속도·모델 훈련 완료로 기록하지 않는다.

중간 과정을 따라가는 예제

f(x)=(x²−1)²에서 x=0과 x=±1을 미분으로 분류하고 전역 최솟값을 설명하라.

  1. f′ = 4x(x² − 1), f″ = 12x² − 4다. 세 점 모두 f′ = 0이다.

  2. x = 0은 f = 1, f″ = −4이므로 엄격한 국소 극댓값이다. x = ±1은 f = 0, f″ = 8이므로 엄격한 국소 최솟값이다.

  3. f가 제곱이므로 모든 x에서 f ≥ 0이고 ±1에서 0을 달성한다. 따라서 두 점은 전역 최솟값이다.

기울기가 0인 x = 0은 최솟값이 아니다. 전역 최적값 0은 x = −1, +1에서 달성한다.

종이와 본문으로 직접 해보기

기울기 하강 x새 = x − ηf′(x), η = 1/10을 정확한 손계산으로 한 단계 적용하라. 시작 x = 0과 x = 1/2의 결과를 비교하라.

힌트 보기

시작점 각각의 기울기를 구한 뒤 갱신한다.

풀이 보기

x = 0은 기울기가 0이므로 새 점도 0이고 목적값은 1이다. x = 1/2의 기울기는 −3/2라 새 점은 13/20이다. 새 목적값은 (169/400 − 1)² = 53361/160000 = 0.33350625이며 시작 목적값 9/16 = 0.5625보다 작다. 한 단계 감소가 전역 수렴을 증명하지 않는다.

오해와 반례

여러 초기값에서 가장 낮은 목적을 찾으면 전역 최적성이 증명된다.

유한한 후보 비교는 시험한 후보 중의 순위만 준다. 전역 인증에는 이 예의 제곱 하한 같은 별도 수학적 근거가 필요하다.
