소단원 4.1

Jensen 부등식

평균 입력의 비용과 비용의 평균 중 무엇이 더 작을까?

준비 개념과 학습 목표

준비 개념

  • 볼록 집합은 두 점 사이의 모든 선분을 포함한다.

  • 가중 평균은 비음수 가중치의 합을 1 로 두고 값들을 더한다.

  • 그래프가 현 아래라는 조건을 이 단원에서 볼록이라고 부른다.

학습 목표

  • 볼록 함수의 정의와 유한 가중 Jensen 부등식을 연결한다.

  • 정의역·가중치·기대값의 조건과 등호 여부를 확인한다.

평균이 같으면 평균 비용도 같고 Jensen의 등호 조건도 같을까?

정확한 유한 분포 X는 −2, 0, 2를 각각 1/4, 1/2, 1/4의 확률로 갖는다. 평균은 0이지만 제곱 비용의 평균은 2다. 평균 입력 비용 0과 비용 평균 2의 차이는 분산 2다. 평균 입력만 저장한 기록은 그 차이를 복원하지 못한다. 항상 0인 다른 변수 Y도 평균은 0이나 제곱 비용 평균은 0이다.

같은 X에 비용 f(x)=(x+1)²를 쓰면 평균 입력 비용은 1, 비용 평균은 3이다. 차이는 여전히 2다. 이차 비용의 기준점을 바꿔도 분산 항은 남는다. 반면 직선 비용 3x+2의 두 비용은 모두 2다. 입력이 변동한다는 사실만으로 모든 볼록 비용에서 엄격한 Jensen을 주장할 수 없다.

절댓값 비용에도 직선 구간이 있다. 입력 1과 3을 반씩 섞으면 평균 입력의 절댓값과 절댓값의 평균은 둘 다 2다. 같은 두 입력의 제곱 비용은 4와 5여서 차이가 1이다. 가중치가 0인 입력은 등호 판정에서 제외한다. 비음수 가중치와 합 1은 분포와 볼록결합의 공통 계약이며 음수 계수의 외삽은 이 계약 밖이다.

  • 비음수 가중합과 affine 합성

    기준점을 옮긴 이차 비용과 직선 비용을 구별한다.

평균 비용을 아래에서 비교한다

실수값 함수 f 의 정의역 C 가 볼록이고 x,y∈C,0≤λ≤1 일 때 f((1−λ)x+λy)≤(1−λ)f(x)+λf(y)이면 볼록 함수다. x²는 대표 예이고 직선 함수도 등호로 이 조건을 만족한다. 아래로 굽는 함수는 반대 부등식인 오목 함수다.

두 점 부등식을 반복하면 유한 점 xᵢ∈C 와 pᵢ≥0,Σpᵢ=1 에 대해 f(Σpᵢxᵢ)≤Σpᵢf(xᵢ)가 된다. 왼쪽은 입력을 먼저 평균하고 한 번 평가, 오른쪽은 각 입력을 평가한 뒤 평균한다. 두 연산이 교환된다는 등식이 아니라 방향이 있는 부등식이다.

확률의 평균과 조건을 연결한다

유한한 값을 갖는 확률변수 X 에서 pᵢ는 값별 확률이다. 그러면 f(E X)≤E f(X)로 읽을 수 있다. 각 값과 평균이 정의역에 있어야 하고 비교하는 기대값이 정의되어야 한다. 무한 분포의 적분판은 추가 적분가능성·정의역 조건을 확인해야 하며 여기 계산은 모두 유한 분포다.

f=x²에서는 E X²−(E X)²=E[(X−E X)²]≥0 을 직접 전개할 수 있다. 이 차이는 분산이다. 확률 평균 아래의 등호는 X 가 거의 확실히 한 값인 경우에 성립한다. 일반 볼록 함수는 직선 구간이 있어서 서로 다른 값이어도 등호가 가능하므로 모든 볼록 함수에 같은 등호 조건을 강요하지 않는다.

엄격함과 사용 한계를 구별한다

엄밀히 볼록이면 서로 다른 두 점과 0<λ<1 에서 엄격한 부등식이다. 유한 Jensen 에서도 양의 가중치를 가진 값들이 모두 같지 않으면 엄격해진다. 가중치 0 인 값은 평균에 참여하지 않으므로 등호 판단에서 제외한다.

볼록성은 모든 정의역 점과 허용 비율에 대한 조건이다. 유한한 몇 숫자에 부등식이 맞는 것은 증명이 아니다. 음의 가중치나 합이 1 이 아닌 합, 정의역 밖 평균에 원래 Jensen 을 적용할 수 없다. 실제 모델의 손실이 볼록인지부터 확인하며 단순 그림의 인상으로 전역 판정을 내리지 않는다.

각 좌표의 곡률이 양수인데 혼합 방향에서 왜 내려갈까?

실수 a를 고정하고 R²에서 fₐ(x,y)=x²+2axy+y²를 둔다. Hessian은 2[[1,a],[a,1]]이다. 두 대각은 a와 무관하게 2지만 방향 (1,−1)의 이차형식은 4(1−a), 방향 (1,1)의 값은 4(1+a)다. 좌표축 검사만으로 혼합 곡률을 놓칠 수 있다.

함수 자체를 (1+a)(x+y)²/2+(1−a)(x−y)²/2로 쓰면 |a|≤1에서 볼록임을 전체 방향으로 인증한다. |a|<1이면 두 계수가 양수여서 유일 최소는 원점이다. a=1이면 (x+y)²가 되어 최소점은 직선 y=−x 전체다. a=−1이면 최소점은 y=x 전체다. 볼록성과 유일 최소는 같은 주장이 아니다.

a>1에서는 (1,−1) 방향, a<−1에서는 (1,1) 방향이 음의 곡률을 준다. 이 함수는 그 방향으로 무한히 내려갈 수 있다. 한편 x⁴+y⁴는 엄밀 볼록인데 원점 Hessian이 영행렬이다. 모든 위치의 양의 정부호는 충분한 판정이며 엄밀 볼록에 필요한 조건으로 뒤집지 않는다.

접선은 전체 그래프의 아래에 있다

열린 볼록 정의역에서 미분가능한 f 는 모든 x,y 에 대해 f(y)≥f(x)+∇f(x)ᵀ(y−x)이면 그리고 그때만 볼록이다. 오른쪽은 x 에서의 일차 근사다. 한 점의 접선 부등식만 확인한 것은 전체 정의역 판정이 아니다. 경계점 미분이나 비열린 정의역은 별도 형식의 조건을 써야 한다.

볼록성 정의에서 y 방향의 아주 짧은 선분을 보고 극한을 취하면 일차 부등식을 얻는다. 반대로 두 끝점 x,y 사이 z 에서의 접선 부등식을 각각 쓰고 가중합하면 ∇f(z)의 두 방향 항이 상쇄되어 원래 볼록 부등식이 나온다. 이는 미분가능성을 조건으로 사용한다.

곡률은 모든 방향으로 검사한다

열린 볼록 정의역에서 f 가 두 번 연속 미분가능하면 모든 위치에서 Hessian 이 양의 준정부호인 것과 볼록성이 동치다. 선 x+tv 로 제한하면 이계미분이 vᵀH(x+tv)v 여서 한 변수의 굽음 판정과 이어진다. 한 위치의 양의 행렬만으로 모든 위치를 판정하지 않는다.

대각 성분이 양수라는 것만으로 양의 준정부호가 아니다. [[2,4],[4,2]]에서 v=(1,−1)이면 vᵀHv=−4 다. 방향 혼합항을 포함해야 한다. 대칭 행렬의 고유값이나 완전제곱 전개, 적절한 주행렬 조건 등으로 모든 방향을 검사한다.

엄밀 볼록과 미분 불가능의 경우

모든 위치에서 Hessian 이 양의 정부호이면 엄밀 볼록의 충분조건이다. 하지만 엄밀 볼록이면 모든 위치의 Hessian 이 반드시 양의 정부호라는 역은 거짓이다. f=x⁴는 엄밀 볼록이지만 0 에서 이계미분이 0 이다. 충분한 판정 실패는 성질의 부재를 뜻하지 않는다.

|x|는 0 에서 미분이 없어 위 일차/이차 미분 판정을 바로 쓸 수 없지만 삼각부등식으로 볼록성을 증명할 수 있다. 볼록함수의 정지점이 전역최소라는 결론도 미분가능한 곳의 ∇f=0 과 전체 볼록성 조건을 함께 쓴다. 무제약 결론을 제약 경계에 그대로 적용하지 않는다.

준비 개념

  • 합성 h(g(x))는 안쪽 함수를 계산한 값을 바깥 함수에 넣는 것이다.

  • 점별 최대는 같은 입력에서 여러 출력 중 큰 것을 고른다.

  • perspective 의 t 는 양수 변수이며 x/t 를 만든다.

두 처리율을 반씩 섞을 때 규모도 다르면 올바른 가중치는 무엇일까?

작업량 x와 양의 처리 시간 t의 비용 g(x,t)=x²/t를 정확한 실수 모형으로 둔다. 후보 A=(2,1)의 비용은 4, B=(2,3)의 비용은 4/3이다. 두 후보를 좌표별 반씩 섞으면 M=(2,2), 비용은 2다. 끝 비용 평균 8/3보다 2/3 작다.

perspective 증명에서 처리율은 A의 2와 B의 2/3이다. 혼합 시간 T=2에 대한 새 가중치는 1/4와 3/4라 가중 처리율은 1이다. 두 처리율을 원래 1/2로 평균한 4/3은 M의 처리율이 아니다. 처리 시간으로 정규화한 가중치와 원래 후보의 비율을 나누어 기록해야 한다.

합성 규칙도 출력 범위에 의존한다. h(u)=(u−2)²와 g₀(x)=x²는 각각 볼록이지만 전체 R에서 합성 (x²−2)²는 볼록이 아니다. 양끝 ±√2의 값 0보다 중점 값 4가 크다. 그러나 볼록 정의역 [√2,∞)에서는 g₀의 출력이 [2,∞)이고 h가 그 범위에서 비감소라 합성은 볼록이다. 두 반직선을 합친 비볼록 정의역으로 바꾸지 않는다.

기본 블록의 안전한 조합

볼록 함수들의 비음수 가중합은 공통 정의역이 볼록일 때 볼록이다. αf 에서 α≥0 조건을 보존한다. 볼록 f 의 affine 입력 합성 f(Ax+b)도 원래 정의역의 역상에서 볼록이다. 이차식(2x−1)²는 x²에 affine 입력을 넣은 예다.

유한 개 볼록 함수의 점별 최대 maxᵢfᵢ(x)도 공통 정의역에서 볼록이다. 각 i 의 선분 부등식을 최대값의 가중합으로 위에서 묶으면 증명된다. 최대가 바뀌는 경계에 모서리가 생겨 미분이 없어도 볼록성은 유지될 수 있다.

볼록끼리 합성해도 단조성을 봐야 한다

바깥 h 가 볼록·비감소이고 안쪽 g 가 볼록이면 적절한 정의역 조건에서 h∘g 가 볼록이다. 바깥 h 가 볼록·비증가이고 g 가 오목인 경우도 가능하다. 안쪽이 affine 이면 별도의 단조조건 없이 볼록 h 를 합성할 수 있다. 다변수 바깥 함수에는 좌표별 조건을 점검한다.

바깥 (u−1)²와 안쪽 x²는 각각 볼록이지만 h 는 u≥0 전체에서 비감소가 아니다. 합성(x²−1)²에서 양 끝±1 은 0, 중간 0 은 1 이라 볼록 부등식에 실패한다. 함수별 성질 외에 출력 범위에서의 단조성과 합성 정의역을 확인해야 한다.

양수 규모로 perspective 를 만든다

볼록 f 의 perspective 는 g(x,t)=t f(x/t), t>0,x/t∈dom f 다. 전체 (x,t)에 대한 함수로 볼록이다. f(u)=u²이면 g=x²/t 이며 t 를 고정했을 때만 볼록이라는 약한 주장보다 두 변수 공동 볼록성이 강한 내용이다. t=0 을 이 공식에 직접 대입하지 않는다.

두 후보의 혼합에서 T=(1−λ)t₁+λt₂>0 이고 x 혼합/T 는 x₁/t₁,x₂/t₂의 새 가중평균이다. 가중치는 (1−λ)t₁/T,λt₂/T 로 비음수·합 1 이다. f 의 볼록성을 적용하고 T 를 곱하면 perspective 의 선분 부등식을 얻는다. 단순히 나눗셈이니까 볼록이라는 설명을 대신할 수 있다.

epigraph와 로그볼록성

그래프의 위쪽 전체와 로그로 본 그래프는 같은 성질을 말할까?

준비 개념과 학습 목표

준비 개념

  • epigraph 는 그래프 위쪽의 점들을 포함하는 집합이다.

  • 양수 함수의 자연로그를 취하면 곱의 관계를 합의 관계로 바꿀 수 있다.

  • 함수값·입력의 로그·함수값의 로그는 서로 다른 조작이다.

학습 목표

  • 함수 볼록성과 epigraph 집합의 볼록성 동치를 설명한다.

  • 로그볼록의 양수·볼록 정의역 조건과 일반 볼록의 차이를 검사한다.

모든 sublevel set이 볼록이면 함수도 볼록이라고 말할 수 있을까?

실수 함수 q(x)=x³는 엄밀히 증가하므로 높이 s 이하의 집합은 (−∞, ∛s]라는 반직선이다. 모든 sublevel set은 볼록이다. 그러나 입력 −2와 0의 중점 −1에서 함수값 −1이 끝값 평균 −4보다 크다. 따라서 q 자체는 볼록이 아니다. 집합의 등고 수준 검사와 함수의 선분 값 검사는 다른 관찰이다.

q의 epigraph 경계점 (−2,−8),(0,0)을 반씩 섞으면 (−1,−4)다. 이 점은 q(−1)=−1보다 높이가 낮아 epigraph 밖이다. epigraph 볼록성은 함수 볼록성과 동치지만 sublevel set의 볼록성만으로는 그 역을 만들 수 없다. 그래프의 중점과 epigraph의 포함 여부도 따로 검사한다.

양수 r(x)=1+x²는 일반 볼록이나 로그볼록이 아니다. 입력 1과 3에서 값은 2와 10, 중점 2에서 값은 5다. 일반 볼록 부등식 5≤6은 통과하지만 로그볼록 부등식 5≤√20은 실패한다. 제곱 비교는 양수 전제 아래 25>20으로 정확히 판정한다. f=e^(3x+1)는 함수값의 로그가 affine라 로그볼록과 로그오목 모두다. 입력을 log x로 바꾸는 별도 조작과 혼동하지 않는다.

곡선 대신 위쪽 집합을 본다

epi f={(x,s):x∈dom f,f(x)≤s}다. s 는 함수값 이상인 보조 좌표다. 함수 f 가 볼록이면 두 epigraph 점의 가중평균도 f 의 선분 부등식에 따라 epigraph 에 남는다. 반대로 그래프 위 경계점(x,f(x)),(y,f(y))의 혼합을 epi 조건에 넣으면 원래 볼록 부등식을 얻는다.

그래프 자체 {(x,f(x))}와 epigraph 는 다르다. f=x²의 그래프 두 점(−1,1),(1,1)의 중간(0,1)은 그래프 위쪽이지만 그래프 점은 아니다. 그래프 집합이 볼록하지 않아도 epigraph 는 볼록일 수 있다. sublevel set 이 볼록이라는 사실만으로 함수가 볼록이라는 역도 일반적으로 성립하지 않는다.

양수 함수값에 로그를 취한다

볼록 정의역에서 f(x)>0 인 함수가 로그볼록이면 h(x)=log f(x)가 볼록이다. 따라서 f((1−λ)x+λy)≤f(x)^(1−λ)f(y)^λ다. 로그의 증가성과 양수 값 조건을 사용해 두 형식을 연결한다. 여기서는 0 이 있는 함수의 확장 정의를 쓰지 않으며 0 의 로그를 유한수로 계산하지 않는다.

로그볼록 함수는 f=exp(h)이고 지수는 볼록·증가이므로 일반 볼록이기도 하다. 역은 거짓이다. f=1+x²는 양수이고 볼록이지만 log f 의 이계미분은 2(1−x²)/(1+x²)²라 |x|>1 에서 음수이다. 로그볼록 판정을 함수의 볼록과 동일하게 취급하지 않는다.

미분 판정과 기하 조건을 연결한다

양수 두 번 연속 미분가능 f 와 열린 볼록 정의역에서 H(log f)=Hf/f−(∇f∇fᵀ)/f²다. 따라서 로그볼록은 fHf−∇f∇fᵀ가 양의 준정부호인지 검사할 수 있다.1 변수에서는 f f″−(f′)²≥0 이다. 모든 위치에서의 조건이고 f>0 전제를 잃지 않는다.

exp(x²)는 log=x²라 로그볼록이고, exp(x)는 log=x 가 affine 이라 로그볼록/로그오목을 둘 다 만족한다. 함수값의 로그를 볼록 판정한다고 입력 x 를 log x 로 바꾸는 것은 아니다. epigraph 에서 t 와 perspective 의 양수 t 처럼 같은 글자의 역할도 문맥별로 별도 정의한다.

  4. ④ q의 모든 sublevel은 반직선이지만 (−2,−8),(0,0)의 epigraph 중점 (−1,−4)는 q(−1)=−1보다 아래라 포함되지 않는다. r의 중점 값 5는 산술 평균 6 이하이나 제곱 25가 기하 평균의 제곱 20보다 커 로그볼록 조건에 실패한다.

평균 자료와 비용, 전체 방향과 최소점 유일성, 후보 비율과 처리율 비율, sublevel·epigraph·두 함수 판정을 각각 구별한다.

해결한 뒤 점검할 것

  • 확률 조건과 두 비용 4/6 및 차이 2를 이름별 계산한다.

  • 양끝 a=±1을 포함한 범위와 a=1의 최소점 직선을 설명한다.

  • 시간 양수와 새 가중치 합 1, 비용 2≤8/3을 확인한다.

  • q의 역이 실패하는 반례와 r의 5≤6/25>20을 분리하며 실제 솔버·학생 실험을 주장하지 않는다.
