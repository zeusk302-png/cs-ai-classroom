교환 뒤 두 값의 합이 같다면 정말 교환에 성공했을까?

상태는 각 변수에 지금 저장된 값의 모음이다. 시작값은 바뀌지 않는 수학적 이름 X,Y로 기록한다. 교환의 정확한 사후조건은 x=Y 그리고 y=X다. 합 x+y=X+Y만 요구하면 x=X,y=Y인 아무 일도 하지 않는 명령도 통과하므로 목표를 충분히 표현하지 못한다.

이 단원의 삼중항은 부분 정확성으로 읽는다. 사전조건에서 시작하여 정상 종료한다면 사후조건이 맞다는 뜻이며 종료 증명은 별도다. 예를 들어 while true: skip은 어떤 사후조건을 붙여도 정상 종료 반례가 없지만 계산을 끝내 주지는 않는다. 다른 대학 자료가 종료까지 포함하는 삼중항을 사용하면 규약을 먼저 맞춘다.

대입은 상태를 차례로 바꾼다. x←y; y←x는 둘 다 시작 Y가 된다. 임시 t로 옛 x를 먼저 보존해야 한다. 여기의 x,y,t는 서로 다른 수학적 변수이고 정확한 정수 산술을 사용한다. 실제 메모리 별칭이나 저장 실패까지 증명했다고 확대하지 않는다.

계약은 상태를 말한다

사전조건 P는 시작할 때 허용하는 상태이고 사후조건 Q는 작업을 끝냈을 때 만족해야 하는 상태다. {P} S {Q}는 명령 S에 대한 계약 표기다. 예를 들어 입력 n이 음수가 아닌 정수이고 결과 r이 1부터 n까지의 합이라는 약속을 적을 수 있다.

이 단원에서는 먼저 부분 정확성 규약으로 읽는다. P에서 시작한 실행이 정상 종료한다면 Q라는 뜻이다. 종료도 보이면 전체 정확성이다. 자료마다 호어 삼중항(Hoare triple) 자체에 종료까지 포함하는 규약이 있으므로 어느 규약인지 확인한다. 아래 수학 모형은 정수 산술이 정확하고 오버플로(overflow)·입출력 실패가 없다고 둔다.

대입 전후의 시간을 나눈다

x←x+3은 새 x에 옛 x+3을 저장한다. x=x+3이라는 동시에 참인 방정식이 아니다. 시작 값을 X라는 변경하지 않는 수학적 이름으로 적으면 시작 x=X에서 종료 x=X+3을 약속할 수 있다.

사후조건을 만드는 사전조건은 대입 오른쪽 식을 넣어 찾을 수 있다. x←x+3 뒤 x≥5를 원하면 시작 때 x+3≥5, 즉 x≥2가 충분하다. 실행 모형의 표현 범위나 오류 가능성은 별도 가정이며 수학적 식만으로 실제 기계의 안전을 보증하지 않는다.

계약 밖 입력과 약한 약속

사전조건이 거짓인 입력에 대해서는 이 계약이 성공을 약속하지 않는다. 이것은 구현이 반드시 실패한다는 뜻도 아니다. 입력 검사를 제공할지, 호출자가 조건을 보장할지 API 정책을 별도로 정한다.

사후조건이 r≥0뿐이면 음수가 아닌 잘못된 합도 통과할 수 있다. 사용자가 원한 결과를 충분히 표현해야 한다. 테스트 몇 개의 통과는 계약을 모든 허용 입력에서 증명한 것이 아니며 증명도 전제를 벗어난 하드웨어/서비스 동작까지 확인한 것은 아니다.

합만 보존

두 번째 행의 둘째 상태 칸은 세 대입을 모두 마친 상태다. 합 보존과 각 변수의 시작값 대응을 별도로 검사한다.

중간 과정을 따라가는 예제

수학적 정수 x에 x←x+3을 수행한다. 사후조건 x≥5를 보장하는 시작 조건을 찾고 x=2와 x=1을 추적하라.

  1. 사후조건의 x를 대입 오른쪽으로 바꾸면 x+3≥5다.

  2. 이를 풀면 시작 x≥2다.

  3. x=2이면 새 값5로 조건을 만족한다. x=1이면 새 값4라 사후조건을 만족하지 않는다.

이 정수 대입 모형의 조건은 x≥2다. 경계 2는 허용하고 1은 계약 밖이다.

조건을 바꾸어 비교하기

순차 대입의 역방향 조건

x←x+2; y←x−1 뒤 y≥8을 얻는 가장 약한 정수 사전조건을 구하라.

  1. 마지막 대입 전에는 x−1≥8, 즉 x≥9가 필요하다.

  2. 앞 대입 전의 x에는 x+2≥9, 즉 x≥7이 필요하다.

  3. 시작 x=7이면 새 x=9,y=8이고 x=6이면 y=7이다.

정확한 정수 모형에서는 x≥7이다. 시작 y는 덮어쓰므로 조건에 필요 없다.

비교할 점

두 대입이 모두 처음 x를 읽는다고 계산하지 않는다.

약한 교환 계약의 반례

합 보존만으로 교환 계약을 대체할 수 있는가?

  1. X=2,Y=5에서 skip은 합 7을 보존한다.

  2. 하지만 종료 x=2는 Y=5가 아니다.

  3. 정확한 사후조건에 두 시작값 대응을 함께 넣는다.

필요한 성질 하나가 전체 목표를 표현하지 못할 수 있다.

아직 읽지 않은 배열 값이 있어도 지금까지의 합을 설명할 수 있을까?

길이 N인 고정 정수 배열 A를 앞에서부터 읽는다. i←0,s←0; while i<N: s←s+A[i]; i←i+1이다. 조건 검사 경계의 불변식은 0≤i≤N 그리고 s가 A[0]부터 A[i−1]까지의 합이라는 두 절이다. i=0의 빈 합은 0이다. 배열과 N은 반복 중 바꾸지 않는다.

몸체 전의 인덱스를 j라 쓰면 첫 대입 뒤 s는 j까지의 합이다. 아직 i=j이므로 경계 불변식의 합 식은 중간에 깨질 수 있다. 두 번째 대입 뒤 i=j+1이 되면 같은 식이 다시 맞는다. 불변식을 확인하는 지점을 바꾸면 중간 명제도 새로 적어야 한다.

종료에서 i≥N과 불변식의 i≤N을 합쳐 i=N을 얻는다. i의 범위를 빼면 안전한 A[i] 접근과 종료 결론을 설명할 수 없다. s≥0도 음수 원소를 허용한 계약에서는 보존되지 않는다. 합이 맞다는 조건은 정렬이나 특정 부호를 요구하지 않는다.

정해진 관찰 지점의 명제

불변식 I는 while의 조건을 검사하는 시점마다 참이어야 하는 명제다. 몸체의 모든 중간 줄에서 참일 필요는 없고 한 번 몸체를 마치면 다시 참이어야 한다. 처음 조건 검사 전에도 성립해야 한다.

자체 프로그램은 n≥0인 정수에 i←0, s←0으로 시작하고 while i<n: i←i+1; s←s+i를 반복한다. 불변식은 0≤i≤n 그리고 s=Σₖ₌₁ⁱk다. i=0일 때 빈 합은 0으로 정한다. n은 실행 중 바꾸지 않는다.

초기화와 한 번의 보존

초기에 i=0, s=0이라 범위 조건과 빈 합 식이 성립한다. 몸체 전 I와 i<n을 가정하면 새 i는 옛 i+1이고 새 s는 옛 합에 옛 i+1을 더한 값이다. 따라서 새 i까지의 합이 되어 I가 복원된다.

i를 먼저 증가시킨 직후 아직 s를 더하지 않은 중간에는 s가 새 i까지의 합이 아니다. 이를 실패로 오해하지 않는다. 반대로 s에 옛 i를 더한 뒤 i를 증가시키는 다른 몸체는 마지막에도 이 불변식을 유지하지 못한다. 대입 순서가 증명에 영향을 준다.

종료 조건과 결합한다

종료했다면 i<n이 거짓이므로 i≥n이다. 불변식의 i≤n과 함께 i=n이고 s=Σₖ₌₁ⁿk라는 사후조건이 나온다. 불변식만으로 종료 여부를 아직 증명하지는 않았다.

I를 s≥0만으로 두면 초기화와 보존은 쉬워도 정확한 합을 도출할 수 없다. I를 s=Σ₁ⁿk로 처음부터 두면 n>0일 때 초기화가 실패한다. 목표를 향한 진행 상태와 범위를 함께 적는 것이 유용하다.

두 번째 수가 다시 커지는 반복도 끝난다고 증명할 수 있을까?

자연수 변형량은 몸체마다 엄격히 줄고 항상 비음수여야 한다. 몸체 자체도 종료해야 한다. 배열 합에서는 V=N−i이고 조건이 참이면 V≥1, 몸체 뒤 V가 1 줄어든다. 불변식은 무엇이 유지되는지, 변형량은 왜 영원히 반복할 수 없는지 설명한다.

새 상태는 비음수 정수 p,q와 고정 B=3이며 0≤q≤B다. 둘 중 하나가 양수인 동안 q>0이면 q를 1 줄이고, q=0이면 p를 1 줄인 뒤 q를 B로 되돌린다. 두 번째 분기에서는 조건 때문에 p>0이다. 쌍 (p,q)를 사전식 순서로 보면 먼저 p가 줄 때 q가 커져도 전체는 감소한다.

유한 상한 B가 있으면 하나의 자연수 V=(B+1)p+q로도 설명할 수 있다. q 분기에서는 1 감소하고 재설정 분기에서도 (B+1)(p−1)+B=(B+1)p−1로 1 감소한다. 실제 실행 시간과 이 추상 전이 횟수는 같은 측정값이 아니다. 정확한 실수 x를 반씩 줄이는 경우에는 이런 자연수 논증을 그대로 쓸 수 없다.

감소가 멈출 수밖에 없는 집합

자연수 값의 변형량 V를 정하고 매 반복에서 V가 엄격히 감소함을 보인다. 비음수 정수는 0 아래로 내려갈 수 없으므로 무한히 엄격 감소하는 반복은 불가능하다. 이 논증은 몸체 자체가 유한 시간에 종료한다는 전제도 사용한다.

값이 실수라면 단순 감소와 하한만으로 충분하지 않다. 양수 x를 x/2로 바꾸면 1,1/2,1/4,…는 계속 양수다. while x>0을 정확한 실수 모형에서 반복하면 끝나지 않는다. 실제 부동소수점의 반올림과 언더플로(underflow, 표현 범위보다 작은 값이 되는 현상) 행동은 이 수학 모형과 구별한다.

합산 루프의 남은 횟수

앞 프로그램의 V=n−i를 사용한다. 불변식 0≤i≤n에서 V≥0인 정수이고 조건 i<n에서 V≥1이다. 한 몸체 뒤 i가 1 증가하므로 Vnew=Vold−1이다. 몸체는 두 정확한 정수 대입이라 이 모형에서 종료한다.

초기 V=n이므로 몸체는 정확히 n회 실행하고 i=n에서 끝난다. 이 종료 증명과 앞의 부분 정확성을 합하면 합산 프로그램은 모든 허용 n≥0에서 전체 정확하다. 실제 입력 크기가 무제한이라 모든 자원 제한도 해결됐다는 뜻은 아니다.

두 작은 구간의 합을 더할 때 가운데 원소를 두 번 넣지 않았을까?

고정 정수 배열 A의 반 열린 구간 [l,r)을 합하는 F(l,r)을 정한다. 계약은 0≤l≤r≤N이다. l=r이면 0을 반환하고 r=l+1이면 A[l]을 반환한다. 길이가 2 이상이면 m=l+⌊(r−l)/2⌋를 두고 F(l,m)+F(m,r)을 반환한다.

구간 길이 d=r−l를 귀납 척도로 쓴다. d≥2에서는 l<m<r라 두 자식 길이가 양수이고 d보다 작다. 작은 두 입력의 계약과 반환값을 가정한 뒤, 겹치지 않고 전체를 덮는 두 구간의 합을 결합한다. 배열은 읽기 전용이다. 반환 뒤 더하는 연산도 증명에 포함한다.

종료는 작은 구간으로 줄어드는 호출과 두 기저를 확인하여 얻는다. F(l,m+1)+F(m,r)처럼 겹친 구간의 올바른 부분 합을 결합한다고 가정하면 A[m]을 두 번 센다. 그러나 이 겹친 규칙을 재귀 전체에 적용하면 d=2에서 왼쪽 길이가 그대로 2여서 같은 호출을 반복하고 반환값 자체가 없다. 결합식의 조건부 감사, 호출 종료, 실제 스택과 정수 범위는 서로 다른 주장이다.

함수 계약과 기저 사례

자체 함수 S는 n≥0인 정수를 받아 1부터 n까지의 합을 반환한다. 규칙은 n=0이면 0 반환, n>0이면 n+S(n−1) 반환이다. 산술은 정확하고 각 호출의 기본 연산은 종료하는 수학 모형으로 둔다.

기저 사례 S(0)=0은 빈 합과 같다. n>0에서 호출 n−1도 비음수 정수라 같은 함수의 사전조건을 충족한다. 호출 입력이 더 작은 자연수라는 사실이 종료와 귀납 증명을 연결한다.

작은 입력의 결과를 사용한다

강한 귀납법으로 n보다 작은 모든 허용 입력에서 반환값이 맞다고 가정한다. 특히 S(n−1)=Σₖ₌₁ⁿ⁻¹k다. 현재 함수는 여기에 n을 더해 Σₖ₌₁ⁿk를 반환한다. 큰 입력의 정답을 먼저 가정하는 것이 아니다.

이 합산 함수는 바로 이전 값만 필요하므로 보통의 귀납법으로도 충분하다. 여러 더 작은 입력을 호출하는 알고리즘에는 강한 귀납법이 편할 수 있다. 재귀 호출의 계약뿐 아니라 반환 뒤 결합 연산이 올바른지도 증명한다.

종료와 실행 환경을 구별한다

n을 자연수 변형량으로 보면 재귀 호출마다 1 감소하고 0에서는 더 호출하지 않는다. 따라서 이 모형에서 무한 호출은 없다. n=3이면 호출 입력 3→2→1→0, 반환 결과 0→1→3→6이다.

실제 언어는 호출 스택·정수 표현·실행 시간에 제한이 있다. 수학적 종료 증명이 임의로 큰 n의 실제 실행 성공을 보증하지 않는다. 음수 입력은 이 계약 밖이고, n−1 대신 n+1로 호출하는 오류는 감소 증명과 입력0 도달을 깨뜨린다.

  3. S(2)=2+1=3, S(3)=3+3=6으로 반환한다.

  4. 1+2+3=6과 일치하며 실제 실행 로그가 아닌 규칙 추적이다.

겹친 구간의 두 가지 오류

겹친 분할 F(l,m+1)+F(m,r)의 결합식만 감사하는 것과 이 규칙을 모든 재귀 호출에 적용하는 것을 구별하라.

  1. 길이 3에서 두 자식 반환값을 원래의 올바른 F로 계산한다고 가정하여 결합식만 감사한다. A=[4,−2,7]이면 부분 합 2와 5를 합한 7은 원 합 9와 다르다. 중간 −2를 두 번 넣은 조건부 결합 오류다.

  3. 따라서 7은 이 잘못된 재귀 전체를 실행한 결과가 아니다. 결합식의 중복 오류와 호출 감소 실패를 각각 점검한다.

길이 N의 읽기 전용 정수 배열을 반복 접두 합과 반 열린 구간 재귀 합으로 각각 계산한다. A=[4,−2,7]의 경계와 반환 트리를 적고 같은 합 계약을 증명하라. 빈 배열·음수 원소·합만 보존하는 약한 교환 계약·겹치는 재귀 분할의 문제도 설명하라. 별도로 B=3의 재설정 규칙을 시작 (p,q)=(2,1)에 적용하여 종료 척도와 몸체 횟수를 구하라. 수학적 증명과 실제 실행·시간·학생 실험을 구분하라.

힌트 1

반복은 조건 검사 경계에 불변식을 적고 종료 조건과 결합한다. 재귀는 두 자식 구간의 감소·서로 겹치지 않음·전체 덮음을 확인한다.

힌트 2

재설정에서 q는 커지지만 V=4p+q를 계산한다. 각 몸체가 끝난다는 전제도 적는다.

풀이와 답 확인

  1. 반복 경계는 (0,0),(1,4),(2,2),(3,9)다. 불변식은 0≤i≤N과 시작 배열의 앞 i개 원소 합이며 V=N−i로 종료를 보인다.

  2. 재귀 F(0,3)는 F(0,1)=4와 F(1,3)=−2+7=5를 합해 9다. 호출은 5개다. 빈 구간은 한 호출로 0을 반환한다.

  3. 교환에는 시작값 대응 x=Y,y=X가 필요하다. 합 보존만으로는 아무 일도 하지 않는 명령을 배제하지 못한다.

  4. 겹친 분할은 중간 원소를 두 번 세며 길이 2에서는 부모와 같은 자식 호출을 만들어 종료도 깨뜨린다.

  5. 재설정 모형의 시작 V=4·2+1=9다. 두 분기에서 매번 1 감소하고 비음수 범위를 보존하므로 9회 뒤 (0,0)이다.

  6. 모든 결론은 정확한 정수·고정 배열·유한 기본 연산의 모형 안이다. 실제 코드 실행·오버플로·스택·성능·학생 실험은 수행되지 않았다.

두 합 모형은 같은 계약에서 9를 반환하고 빈 배열은 0이다. 반복의 불변식과 종료, 재귀의 작은 구간과 비중복 결합은 각각 증명해야 한다. 재설정의 V=4p+q는 시작 9에서 0까지 9회 감소한다.
