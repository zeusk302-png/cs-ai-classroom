소단원 12.1

사전·사후조건

답이 맞는지 말하려면 어떤 입력에서 무엇을 약속하는지 먼저 정해야 하지 않을까?

준비 개념과 학습 목표

준비 개념

  • 명제와 함의

  • 변수의 값과 대입

  • 정수와 함수

학습 목표

  • 사전조건과 사후조건을 상태에 대한 명제로 적는다.

  • 초기값과 현재 값을 구별한다.

  • 부분 정확성과 전체 정확성 및 실행 모형을 설명한다.

계약은 상태를 말한다

사전조건 P는 시작할 때 허용하는 상태이고 사후조건 Q는 작업을 끝냈을 때 만족해야 하는 상태다. {P} S {Q}는 명령 S에 대한 계약 표기다. 예를 들어 입력 n이 음수가 아닌 정수이고 결과 r이 1부터 n까지의 합이라는 약속을 적을 수 있다.

이 단원에서는 먼저 부분 정확성 규약으로 읽는다. P에서 시작한 실행이 정상 종료한다면 Q라는 뜻이다. 종료도 보이면 전체 정확성이다. 자료마다 호어 삼중항(Hoare triple) 자체에 종료까지 포함하는 규약이 있으므로 어느 규약인지 확인한다. 아래 수학 모형은 정수 산술이 정확하고 오버플로(overflow)·입출력 실패가 없다고 둔다.

대입 전후의 시간을 나눈다

x←x+3은 새 x에 옛 x+3을 저장한다. x=x+3이라는 동시에 참인 방정식이 아니다. 시작 값을 X라는 변경하지 않는 수학적 이름으로 적으면 시작 x=X에서 종료 x=X+3을 약속할 수 있다.

사후조건을 만드는 사전조건은 대입 오른쪽 식을 넣어 찾을 수 있다. x←x+3 뒤 x≥5를 원하면 시작 때 x+3≥5, 즉 x≥2가 충분하다. 실행 모형의 표현 범위나 오류 가능성은 별도 가정이며 수학적 식만으로 실제 기계의 안전을 보증하지 않는다.

계약 밖 입력과 약한 약속

사전조건이 거짓인 입력에 대해서는 이 계약이 성공을 약속하지 않는다. 이것은 구현이 반드시 실패한다는 뜻도 아니다. 입력 검사를 제공할지, 호출자가 조건을 보장할지 API 정책을 별도로 정한다.

사후조건이 r≥0뿐이면 음수가 아닌 잘못된 합도 통과할 수 있다. 사용자가 원한 결과를 충분히 표현해야 한다. 테스트 몇 개의 통과는 계약을 모든 허용 입력에서 증명한 것이 아니며 증명도 전제를 벗어난 하드웨어/서비스 동작까지 확인한 것은 아니다.

중간 과정을 따라가는 예제

수학적 정수 x에 x←x+3을 수행한다. 사후조건 x≥5를 보장하는 시작 조건을 찾고 x=2와 x=1을 추적하라.

  1. 사후조건의 x를 대입 오른쪽으로 바꾸면 x+3≥5다.

  2. 이를 풀면 시작 x≥2다.

  3. x=2이면 새 값5로 조건을 만족한다. x=1이면 새 값4라 사후조건을 만족하지 않는다.

이 정수 대입 모형의 조건은 x≥2다. 경계 2는 허용하고 1은 계약 밖이다.

종이와 본문으로 직접 해보기

초기 x=X, y=Y에서 t←x; x←y; y←t의 사후조건을 적어라. X=2, Y=5로도 추적하라.

힌트 보기

X와 Y는 프로그램이 바꾸지 않는 시작값 이름이다.

풀이 보기

t=X, x=Y, y=X이므로 사후조건 x=Y 그리고 y=X이다. 수치 추적은 t=2, x=5, y=2로 두 값을 교환한다.

오해와 반례

사전조건이 거짓이면 그 프로그램은 반드시 종료하지 않는다.

계약의 보장 범위를 벗어났다는 뜻이지 실제 행동을 단정하는 뜻이 아니다. 범위 밖 입력 정책은 별도로 명시한다.

자기점검

부분 정확성은 종료를 보장하는가?

답과 이유 보기

그 자체로는 아니다.

종료한다면 결과가 맞는다는 조건부 보장이다.

x←x+3에서 오른쪽 x는 어느 값인가?

답과 이유 보기

대입 전의 값이다.

대입은 상태를 바꾸는 명령이다.

합 계산의 사후조건 r≥0만으로 정확한 합을 약속하는가?

답과 이유 보기

아니다.

여러 잘못된 양수 결과도 허용한다.

순차 명령 S;T를 증명할 때 S의 사후조건이 T의 사전조건을 충족하는지 연결한다. 교환 예제의 x←y 뒤 x=Y, t=X, y=Y가 유지되어 마지막 대입을 설명할 수 있다. 다음 소단원은 이 연결을 반복 실행에도 적용한다.

소단원 12.2

반복문 불변식

반복 횟수가 아직 정해지지 않았어도 지금까지 계산한 합을 한 식으로 설명할 수 있을까?

준비 개념과 학습 목표

준비 개념

  • 사전·사후조건

  • 수학적 귀납법

  • 유한 합과 빈 합

학습 목표

  • 반복 경계의 불변식을 적는다.

  • 초기화와 보존 및 종료 후 결과를 따로 증명한다.

  • 불변식이 너무 약하거나 강한 경우를 판별한다.

정해진 관찰 지점의 명제

불변식 I는 while의 조건을 검사하는 시점마다 참이어야 하는 명제다. 몸체의 모든 중간 줄에서 참일 필요는 없고 한 번 몸체를 마치면 다시 참이어야 한다. 처음 조건 검사 전에도 성립해야 한다.

자체 프로그램은 n≥0인 정수에 i←0, s←0으로 시작하고 while i<n: i←i+1; s←s+i를 반복한다. 불변식은 0≤i≤n 그리고 s=Σₖ₌₁ⁱk다. i=0일 때 빈 합은 0으로 정한다. n은 실행 중 바꾸지 않는다.

초기화와 한 번의 보존

초기에 i=0, s=0이라 범위 조건과 빈 합 식이 성립한다. 몸체 전 I와 i<n을 가정하면 새 i는 옛 i+1이고 새 s는 옛 합에 옛 i+1을 더한 값이다. 따라서 새 i까지의 합이 되어 I가 복원된다.

i를 먼저 증가시킨 직후 아직 s를 더하지 않은 중간에는 s가 새 i까지의 합이 아니다. 이를 실패로 오해하지 않는다. 반대로 s에 옛 i를 더한 뒤 i를 증가시키는 다른 몸체는 마지막에도 이 불변식을 유지하지 못한다. 대입 순서가 증명에 영향을 준다.

종료 조건과 결합한다

종료했다면 i<n이 거짓이므로 i≥n이다. 불변식의 i≤n과 함께 i=n이고 s=Σₖ₌₁ⁿk라는 사후조건이 나온다. 불변식만으로 종료 여부를 아직 증명하지는 않았다.

I를 s≥0만으로 두면 초기화와 보존은 쉬워도 정확한 합을 도출할 수 없다. I를 s=Σ₁ⁿk로 처음부터 두면 n>0일 때 초기화가 실패한다. 목표를 향한 진행 상태와 범위를 함께 적는 것이 유용하다.

중간 과정을 따라가는 예제

n=3에서 위 프로그램의 반복 경계 (i,s)를 추적하고 불변식을 확인하라.

  1. 초기 경계는 (0,0)이며 빈 합0이다.

  2. 첫 몸체 뒤 (1,1), 둘째 뒤 (2,3), 셋째 뒤 (3,6)이다.

  3. 각 s는 i까지의 합이고 0≤i≤3이다. i=3에서 조건이 거짓이라 s=6으로 종료한다.

경계 상태는 (0,0)→(1,1)→(2,3)→(3,6)이다.

종이와 본문으로 직접 해보기

n=0이면 몸체를 몇 번 실행하고 어떤 결과를 얻는가? s←s+i; i←i+1로 순서를 바꾸면 n=1에서 무엇이 달라지는가?

힌트 보기

첫 조건 검사 전에 참인 빈 합과, 각 대입이 읽는 옛 값을 확인한다.

풀이 보기

n=0은 처음부터 조건이 거짓이라 몸체 0회, 합 0이다. 바꾼 몸체는 n=1에서 s=0+0=0, i=1이 되어 결과 0으로 틀린다. 원래 프로그램은 결과 1이다.

오해와 반례

불변식은 몸체의 모든 줄 직후에 항상 같아야 한다.

관찰 지점을 명시해야 한다. 여기서는 조건 검사 경계에서 유지한다. 중간 대입 뒤 일시적으로 깨져도 몸체 끝에 복원될 수 있다.

자기점검

초기 i=0의 합은?

답과 이유 보기

빈 합0이다.

초기 불변식의 s=0과 맞는다.

종료 후 i=n을 얻는 두 조건은?

답과 이유 보기

i≤n과 i≥n이다.

첫째는 불변식, 둘째는 거짓인 조건 i<n에서 나온다.

s≥0만으로 합이 맞는다고 증명할 수 있는가?

답과 이유 보기

없다.

정확한 합과 i의 관계를 표현하지 않는다.

한 단계 더

Σₖ₌₁ⁱk=i(i+1)/2를 이전 귀납법으로 증명했다면 불변식을 그 닫힌식으로 써도 된다. 보존은 i(i+1)/2+(i+1)=(i+1)(i+2)/2다. 다음 소단원에서는 계속 반복될 수 없다는 별도 증명을 붙인다.

소단원 12.3

종료성과 변형량

값이 계속 작아지는 것만으로 반복이 반드시 끝난다고 말할 수 있을까?

준비 개념과 학습 목표

준비 개념

  • 자연수의 정렬성

  • 부분 정확성

  • 반복문 불변식

학습 목표

  • 변형량의 비음수 정수 조건과 엄격 감소를 확인한다.

  • 불변식과 종료 증명의 역할을 구별한다.

  • 실수 감소와 갱신 없는 반복의 반례를 설명한다.

감소가 멈출 수밖에 없는 집합

자연수 값의 변형량 V를 정하고 매 반복에서 V가 엄격히 감소함을 보인다. 비음수 정수는 0 아래로 내려갈 수 없으므로 무한히 엄격 감소하는 반복은 불가능하다. 이 논증은 몸체 자체가 유한 시간에 종료한다는 전제도 사용한다.

값이 실수라면 단순 감소와 하한만으로 충분하지 않다. 양수 x를 x/2로 바꾸면 1,1/2,1/4,…는 계속 양수다. while x>0을 정확한 실수 모형에서 반복하면 끝나지 않는다. 실제 부동소수점의 반올림과 언더플로(underflow, 표현 범위보다 작은 값이 되는 현상) 행동은 이 수학 모형과 구별한다.

합산 루프의 남은 횟수

앞 프로그램의 V=n−i를 사용한다. 불변식 0≤i≤n에서 V≥0인 정수이고 조건 i<n에서 V≥1이다. 한 몸체 뒤 i가 1 증가하므로 Vnew=Vold−1이다. 몸체는 두 정확한 정수 대입이라 이 모형에서 종료한다.

초기 V=n이므로 몸체는 정확히 n회 실행하고 i=n에서 끝난다. 이 종료 증명과 앞의 부분 정확성을 합하면 합산 프로그램은 모든 허용 n≥0에서 전체 정확하다. 실제 입력 크기가 무제한이라 모든 자원 제한도 해결됐다는 뜻은 아니다.

무엇이 감소하는지 다시 확인한다

s를 갱신해도 i를 바꾸지 않는 루프는 같은 조건을 계속 검사한다. n>0, i=0이면 n−i는 감소하지 않고 종료 논증이 실패한다. 불변식 true가 유지되어도 종료하지 않을 수 있다.

반복마다 0보다 큰 어떤 실수만큼 줄인다는 설명 역시 감소의 최소 크기와 상태 집합을 확인해야 한다. 복잡한 알고리즘은 자연수 쌍의 사전식 순서 같은 다른 정렬된 척도를 사용할 수 있지만 그 순서와 감소를 별도로 증명해야 한다.

중간 과정을 따라가는 예제

합산 프로그램의 n=4에서 V=n−i를 계산하고 총 몸체 횟수를 구하라.

  1. 초기 i=0이므로 V=4다.

  2. 몸체마다 i가 1 증가하여 V는 4→3→2→1→0이다.

  3. V=0이면 i=n이고 조건 i<n이 거짓이다. 몸체 4회 후 종료한다.

비음수 정수 변형량이 매번 1 감소하므로 4회 후 종료한다.

종이와 본문으로 직접 해보기

정확한 실수 모형의 x=1; while x>0: x←x/2에서 k회 뒤 x를 적고 종료 여부를 설명하라.

힌트 보기

유한 k에서 2의 거듭제곱 역수는 여전히 양수다.

풀이 보기

x=2⁻ᵏ>0이다. 모든 유한 k에서 조건이 참이라 종료하지 않는다. 감소하고 하한0이 있어도 자연수 감소 논증과 같지 않다.

오해와 반례

불변식을 증명했으면 종료도 자동 증명된다.

불변식은 유지되는 성질이다. 종료는 별도의 정렬된 변형량 감소 등으로 증명해야 한다. true 불변식은 무한 루프에서도 유지된다.

자기점검

V=n−i가 정수인 이유는?

답과 이유 보기

n과 i가 정수다.

상태 모형과 불변식의 범위 가정을 쓴다.

조건 i<n이면 V의 최소 값은?

답과 이유 보기

1이다.

양의 정수이므로0보다 큰 최소 값은1이다.

V가 그대로인 몸체로 엄격 감소 증명을 할 수 있는가?

답과 이유 보기

없다.

Vnew<Vold가 성립하지 않는다.

소단원 12.4

재귀 프로그램의 정확성

작은 문제의 답이 맞다고 가정하는 것은 순환 논증일까, 귀납법일까?

준비 개념과 학습 목표

준비 개념

  • 수학적 귀납법

  • 함수 호출과 반환

  • 종료 척도

학습 목표

  • 기저 사례와 작은 입력의 계약을 확인한다.

  • 귀납 가정으로 반환값을 증명한다.

  • 재귀 종료와 실제 호출 자원 한계를 나눈다.

함수 계약과 기저 사례

자체 함수 S는 n≥0인 정수를 받아 1부터 n까지의 합을 반환한다. 규칙은 n=0이면 0 반환, n>0이면 n+S(n−1) 반환이다. 산술은 정확하고 각 호출의 기본 연산은 종료하는 수학 모형으로 둔다.

기저 사례 S(0)=0은 빈 합과 같다. n>0에서 호출 n−1도 비음수 정수라 같은 함수의 사전조건을 충족한다. 호출 입력이 더 작은 자연수라는 사실이 종료와 귀납 증명을 연결한다.

작은 입력의 결과를 사용한다

강한 귀납법으로 n보다 작은 모든 허용 입력에서 반환값이 맞다고 가정한다. 특히 S(n−1)=Σₖ₌₁ⁿ⁻¹k다. 현재 함수는 여기에 n을 더해 Σₖ₌₁ⁿk를 반환한다. 큰 입력의 정답을 먼저 가정하는 것이 아니다.

이 합산 함수는 바로 이전 값만 필요하므로 보통의 귀납법으로도 충분하다. 여러 더 작은 입력을 호출하는 알고리즘에는 강한 귀납법이 편할 수 있다. 재귀 호출의 계약뿐 아니라 반환 뒤 결합 연산이 올바른지도 증명한다.

종료와 실행 환경을 구별한다

n을 자연수 변형량으로 보면 재귀 호출마다 1 감소하고 0에서는 더 호출하지 않는다. 따라서 이 모형에서 무한 호출은 없다. n=3이면 호출 입력 3→2→1→0, 반환 결과 0→1→3→6이다.

실제 언어는 호출 스택·정수 표현·실행 시간에 제한이 있다. 수학적 종료 증명이 임의로 큰 n의 실제 실행 성공을 보증하지 않는다. 음수 입력은 이 계약 밖이고, n−1 대신 n+1로 호출하는 오류는 감소 증명과 입력0 도달을 깨뜨린다.

중간 과정을 따라가는 예제

S(3)의 호출과 반환을 분리해 추적하고 결과가 합과 같은지 확인하라.

  1. 호출은 S(3)→S(2)→S(1)→S(0) 순서다.

  2. 기저 S(0)=0 후 S(1)=1+0=1이다.

  3. S(2)=2+1=3, S(3)=3+3=6으로 반환한다.

  4. 1+2+3=6과 일치하며 실제 실행 로그가 아닌 규칙 추적이다.

네 호출의 입력 3/2/1/0과 반환 0/1/3/6을 얻는다.

종이와 본문으로 직접 해보기

같은 규칙에서 S(0)은 호출을 몇 번 만들고 S(4)의 최종 반환값은 얼마인가? 최초 호출도 호출 수에 포함한다.

힌트 보기

기저에서도 최초 함수 호출은 하나다. S(4)=4+S(3)다.

풀이 보기

S(0)은 최초 호출 1개이며 추가 재귀 호출 0개다. S(4)는 호출 입력 4/3/2/1/0의 5개, 반환값 4+6=10이다.

오해와 반례

재귀 함수 자신을 호출한다는 것만으로 정확하다.

입력 계약·기저·작은 입력으로의 감소·결과 결합을 모두 증명해야 한다. n+1 호출 같은 오류는 함수 이름이 같아도 종료하지 않는다.

한 단계 더

합산 반복문과 재귀 함수는 같은 합 계약을 만족하지만 저장 상태가 다르다. 반복문은 i,s를 유지하고 이 단순 재귀는 반환 결합을 위한 호출 상태를 유지한다. 꼬리 재귀로 누적 합을 인자로 넘길 경우 새 인자의 사전조건이 반복 불변식과 대응할 수 있다. 실제 언어의 꼬리 호출 최적화를 여기서 보장하지 않는다.
