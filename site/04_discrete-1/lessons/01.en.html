Subtopic 1.1

Propositions and connectives

Is “It is raining or I have an umbrella” false when both parts are true?

Preparation and learning goals

Preparation

  • True and false: mark a statement whose facts are fixed with T or F.
  • Parentheses: show which parts are grouped together first.
  • Quick review: distinguish questions and commands from statements that assert facts.

Learning goals

  • Distinguish propositions from open sentences whose variables have not yet been specified.
  • Explain the truth conditions for negation, conjunction, disjunction, implication, and the biconditional.
  • Remove ambiguity in everyday language using symbols and parentheses.

A proposition is a unit of assertion

In classical propositional logic, a proposition is an assertion with exactly one of the truth values true or false. “7 is odd” is true; “7 is even” is false. “Open the window” is a command, so it is not a proposition in this sense.

“x>3” is an open sentence until x is specified or a quantifier is used over a specified range of x. Substituting x=5 makes it true; substituting x=1 makes it false. Not knowing a proposition’s truth value does not make it cease to be a proposition. Distinguish an unverified fact from an expression whose truth value has not been determined because its variables remain unspecified.

Define each connective precisely

The negation ¬p is false when p is true and true when p is false. The conjunction p∧q is true only when both are true. The inclusive disjunction p∨q is true when at least one is true. To require exactly one true part, use the exclusive disjunction p⊕q.

The implication p→q is false only when p is true and q is false. It forbids a case that satisfies p while violating q. The biconditional p↔q is true when the two truth values agree. Distinguish p↔q being true in a single situation from two formulas being equivalent in every situation.

Logical implication and everyday causation

Writing “If it is raining, I have an umbrella” as p→q makes p=T,q=F the only violation. When it is not raining, having an umbrella and not having one both leave this condition unviolated, so the implication is true in both cases. This condition does not claim that rain causes an umbrella.

Everyday “or” sometimes asks for only one choice, so its context matters. In mathematics, ∨ is fixed as inclusive. Use parentheses such as p∧(q∨r) to specify how a complicated formula is grouped. Do not leave a long unparenthesized expression to the reader’s guesses.

A worked example, step by step

Let p mean “It is raining” and q mean “I have an umbrella.” In a situation with p=T,q=F, evaluate ¬p, p∧q, p∨q, p→q, and p↔q.

  1. Since p=T, ¬p=F.
  2. p∧q=F because the two parts are not both true.
  3. p∨q=T because at least p is true.
  4. p→q=F because this is T→F.
  5. p↔q=F because the truth values differ.

In order: F,F,T,F,F. Violating the umbrella condition corresponds to the condition that makes p→q false.

Try it with paper and the lesson

For p=T,q=T, calculate p∨q and p⊕q. State which operation represents “activate at least one of the two features” and which represents “activate exactly one.”

Show hint

“At least” allows both; “exactly one” excludes both being active.

Show solution

p∨q=T and p⊕q=F. At least one uses ∨; exactly one uses ⊕. When only one feature is true, in T,F or F,T, both operations return T.

Misconception and counterexample

If the premise is false, p→q is false.

When p=F, p→q is true regardless of q. For example, a blue card with an odd number does not violate “If this card is red, its number is even.” A false premise alone does not let you infer that the conclusion q is true.

Check your understanding

Is “Do your homework today” a proposition in this unit?

Show answer and reasoning

No.

The command itself does not assert something true or false.

For p=F,q=T, what are p∨q and p∧q?

Show answer and reasoning

T and F.

Disjunction needs at least one true part; conjunction requires both.

For p=T,q=T, is mathematical p∨q false?

Show answer and reasoning

It is true.

∨ is inclusive disjunction, which differs from exclusive choice.

Explore further

Go further: “exactly one is true” can be written (p∨q)∧¬(p∧q). Calculate all four cases to check that T,T is excluded while T,F and F,T remain. Later this connects to XOR in Boolean circuits; this unit deals only with pure truth values.

Subtopic 1.2

Truth tables and tautologies

Can checking all four possible cases tell us whether a complicated rule always holds?

Preparation and learning goals

Preparation

  • Connectives: know the truth conditions for ¬,∧,∨,→.
  • Reading a table: one row represents one truth-value assignment.
  • Quick counting review: each variable has two choices, T and F.

Learning goals

  • List all 2ⁿ truth-value assignments without omissions.
  • Classify formulas as tautologies, contradictions, or contingencies.
  • Check logical equivalence by agreement on every row.

List every possible case

Assuming n propositional variables can each independently take T or F, there are 2ⁿ assignments. Two variables p,q give the four rows T,T; T,F; F,T; F,F. Three variables give eight rows. Omitting a row can hide an error that occurs only on that row.

Compute a compound formula from smaller parenthesized parts and record intermediate columns. For (p→q)∧p, first compute the p→q column, then conjoin it with p. If rules restrict the relationships between variables in a particular situation, state those restrictions. A pure propositional-logic check starts with all possible assignments.

Always true, or only sometimes true?

A tautology is true on every assignment; a contradiction is false on every assignment. The formula p∨¬p is a tautology, and p∧¬p is a contradiction. A formula that is true on some rows and false on others is a contingency. “Contingent” here does not mean random.

The variable p alone can take either truth value, so it is contingent. The concrete fact “2+2=4” being true differs from a variable formula being true by its logical form alone. Tautology requires a condition covering every truth-value assignment, rather than evidence from individual observations.

Matching result columns and valid arguments

Formulas A and B are logically equivalent when they have the same truth value on every assignment; write A≡B. This is equivalent to A↔B being a tautology. Matching on a particular row does not establish equivalence.

If ((p→q)∧p)→q is a tautology, it guarantees the inference “when p→q and p are both true, q is true.” A row with a false premise is not a counterexample to that inference. This separates an argument’s validity, which assumes its premises, from the actual truth of a particular conclusion.

A worked example, step by step

Build a truth table for ((p→q)∧p)→q and determine whether it is a tautology.

  1. Use row order (p,q)=(T,T),(T,F),(F,T),(F,F).
  2. The p→q column is T,F,T,T.
  3. The (p→q)∧p column is T,F,F,F.
  4. The final implication column is T→T, F→F, F→T, F→F, giving T,T,T,T.

Every row is T, so the formula is a tautology. This verifies the form of modus ponens.

Try it with paper and the lesson

Write the four rows for p→q and ¬p∨q side by side, then decide whether they are equivalent.

Show hint

Compute ¬p first. Check whether both output columns, in the stated row order, are T,F,T,T.

Show solution

p→q gives T,F,T,T. The ¬p column is F,F,T,T; disjoining it with q gives T,F,T,T. All four rows agree, so p→q≡¬p∨q.

Misconception and counterexample

A formula is a tautology if it is true in many examples.

p∨q is true on T,T; T,F; F,T, but false on F,F, so it is contingent. You need all rows or an equivalence derivation that covers every case. Checking only part of a table is insufficient.

Check your understanding

How many rows are in a truth table with three propositional variables?

Show answer and reasoning

8.

There are two choices per variable, giving 2³.

How is p∧¬p classified?

Show answer and reasoning

A contradiction.

If p=T, ¬p=F; if p=F, p itself is false. The conjunction is always F.

If A and B agree on one row, are they logically equivalent?

Show answer and reasoning

That alone does not tell us.

Equivalence requires matching results on every possible assignment.

Explore further

Go further: 20 variables require 2²⁰=1,048,576 rows. Truth tables are complete, but their size grows. Explain why equivalence laws and structural proofs are useful. This unit does not run a SAT search program or measure its performance.

Subtopic 1.3

Necessary and sufficient conditions

In “Every square is a rectangle,” which condition is necessary and which is sufficient?

Preparation and learning goals

Preparation

  • Implication: p→q is false only for p=T,q=F.
  • Set inclusion: A⊆B means every element of A also belongs to B.
  • Counterexample: find one concrete case that defeats a general claim.

Learning goals

  • Explain why p is sufficient for q and q is necessary for p in a universally valid p→q.
  • Distinguish converse, inverse, and contrapositive, and check contrapositive equivalence.
  • Give counterexamples to reasoning that wrongly treats a necessary condition as sufficient.

Sufficient gets you there; necessary cannot be missing

If p→q always holds, p is a sufficient condition for q: establishing p guarantees q. In the same relationship, q is a necessary condition for p: p cannot hold without q. Being necessary does not mean that q alone guarantees p.

If n is a multiple of 4, then n is even. Being a multiple of 4 is sufficient for being even, and being even is necessary for being a multiple of 4. The number 6 is even but not a multiple of 4, so the necessary condition alone is insufficient. Specify the range n∈ℤ.

Write the converse, inverse, and contrapositive

For p→q, the converse is q→p, the inverse is ¬p→¬q, and the contrapositive is ¬q→¬p. The original and its contrapositive are equivalent. A true ¬q with a false ¬p means q=F,p=T, exactly the only case in which the original implication is false.

The converse and inverse are equivalent to each other, but generally not to the original. The converse “even → multiple of 4” is false at n=6. Its inverse “not a multiple of 4 → odd” is also false at n=6. The contrapositive “odd → not a multiple of 4” is true over the stated integer domain.

Both directions and translating sentences

Saying p is necessary and sufficient for q means p→q and q→p both hold. Express this as p↔q. For example, by definition, an integer n is even if and only if there exists an integer k with n=2k.

“If p, then q” and “q is necessary for p” have the same direction p→q. “p holds only if q” also means p→q. After translating a sentence, check that a case satisfying p but not q is forbidden. This checks the direction. Formal logic alone does not establish actual causal relationships.

A worked example, step by step

For an integer n, let p mean “n is a multiple of 4” and q mean “n is even.” Explain the original statement, converse, inverse, and contrapositive, and their truth.

  1. Original p→q: if n=4k, then n=2(2k); since 2k is an integer, the statement is true.
  2. Converse q→p: n=6 is even but not a multiple of 4, so this is false.
  3. Inverse ¬p→¬q: n=6 is not a multiple of 4 but is not odd, so this is false.
  4. Contrapositive ¬q→¬p: if an odd n were a multiple of 4, the original statement would make it even, a contradiction. Therefore this is true.

Being a multiple of 4 is sufficient for being even; being even is necessary for being a multiple of 4. These conditions are not necessary and sufficient for each other.

Try it with paper and the lesson

Write the contrapositive of “Every square is a rectangle,” then draw a counterexample to its converse. Use nondegenerate quadrilaterals in the Euclidean plane.

Show hint

A square requires four right angles and equal side lengths. A rectangle requires four right angles.

Show solution

Contrapositive: if a quadrilateral is not a rectangle, it is not a square. Converse: “Every rectangle is a square” is false. A rectangle of width 3 and height 2 has four right angles but unequal adjacent side lengths, so it is a counterexample.

Misconception and counterexample

If p→q and q are true, then p is true.

At n=6, “multiple of 4 → even” is true and q, being even, is true, but p is false. This is the fallacy of affirming the consequent. Other routes may establish q; the converse implication requires a separate justification.

Check your understanding

In a universally valid p→q, what kind of condition is q for p?

Show answer and reasoning

A necessary condition.

Whenever p holds, q must also hold.

What is the contrapositive of p→q?

Show answer and reasoning

¬q→¬p.

Reverse the order and negate both conditions.

For real x, is the converse of “x>2 implies x>0” true?

Show answer and reasoning

No. x=1 is a counterexample.

1>0 is true, but 1>2 is false.

Explore further

Go further: in a universe U, let P be the set satisfying p and Q the set satisfying q. Then ∀x∈U,p(x)→q(x) is equivalent to P⊆Q. If P=Q, the conditions are necessary and sufficient for each other. Explain why implication and set inclusion have the same direction by considering one element.

Subtopic 1.4

Equivalence transformations and counterexamples

If we shorten a complicated approval condition, will it make the same decision in every case?

Preparation and learning goals

Preparation

  • Truth tables: formulas are equivalent when their final results agree on every row.
  • Quick distributive-law review: numbers satisfy a(b+c)=ab+ac, but each logical operation needs its own verified law.
  • Implication transformation: p→q≡¬p∨q.

Learning goals

  • Derive formulas using De Morgan’s laws, distributivity, and double negation.
  • Refute an equivalence claim with one counterexample.
  • Distinguish equivalence, one-way implication, and factual verification.

Equivalence laws hold on every assignment

De Morgan’s laws are ¬(p∧q)≡¬p∨¬q and ¬(p∨q)≡¬p∧¬q. To negate both being true, at least one must be false. To negate at least one being true, both must be false. Double negation is ¬¬p≡p.

Distributivity gives p∧(q∨r)≡(p∧q)∨(p∧r) and p∨(q∧r)≡(p∨q)∧(p∨r). Check all eight T,F assignments, or split into the two possible values of p. The resemblance to numerical multiplication and addition is not a proof: the definitions of ∨ and ∧ provide the justification.

Replace small parts and record the reason

Replacing a subformula by an equivalent formula preserves the truth value of the entire formula. Record the law used on each line. Transform (p→q)∧p into (¬p∨q)∧p, then (¬p∧p)∨(q∧p), then F∨(q∧p), then p∧q. Requiring both premises is therefore equivalent to requiring both p and q.

It is wrong to obtain p∧q from p→q alone. For p=F,q=F, the implication is T but the conjunction is F. Dropping an assumption included in the starting formula changes the formula.

Counterexamples and restricted situations

An equivalence claim says the formulas agree on every assignment. A single differing row refutes it. For p=T,q=F, ¬(p∧q) is T while ¬p∧¬q is F, so they are not equivalent. Switching ∧ and ∨ in De Morgan’s law is essential.

General equivalence A≡B allows replacement in any situation. If they agree only under a factual assumption H, check whether H→(A↔B) is a tautology. Valid logical form does not replace verifying whether the original statements are factual. When applying these laws to program conditions, side effects or evaluation order require analysis beyond pure propositional logic.

A worked example, step by step

Let A mean “review passed” and B mean “exception authorized.” Simplify the approval condition ¬(¬A∧¬B) and check all four cases.

  1. By De Morgan’s law, ¬(¬A∧¬B)≡¬¬A∨¬¬B.
  2. By double negation, this becomes A∨B.
  3. For (A,B)=(T,T),(T,F),(F,T),(F,F), the ¬A∧¬B column is F,F,F,T.
  4. Negating that column gives T,T,T,F, matching A∨B.

Approval is A∨B: at least one of review passed or exception authorized is required. Both being true is also allowed.

Try it with paper and the lesson

Prove the absorption law p∧(p∨q)≡p by considering p=T and p=F. Also check p∨(p∧q).

Show hint

When p=T, p∨q is always T. When p=F, the outermost ∧ makes the first formula F.

Show solution

For p=T, the first formula is T∧T=T=p, and the second is T∨(T∧q)=T=p. For p=F, the first is F∧(F∨q)=F=p, and the second is F∨(F∧q)=F=p. These cases cover both values of q, so both laws hold.

Misconception and counterexample

Replacing p→q by q→p preserves its meaning.

For p=T,q=F, p→q=F but q→p=T. The original and contrapositive ¬q→¬p are equivalent; the converse is not generally equivalent. Reversing familiar words is different from applying an equivalence law.

Check your understanding

What is an equivalent formula for ¬(p∨q)?

Show answer and reasoning

¬p∧¬q.

For neither part to be true, both must be false.

What is an equivalent formula for (p→q)∧p?

Show answer and reasoning

p∧q.

Eliminate implication, distribute, then remove the contradictory term.

If two formulas differ on one row, do you need more rows before concluding non-equivalence?

Show answer and reasoning

That single row establishes non-equivalence.

Equivalence requires agreement on every row, so one failure is a sufficient counterexample.

Explore further

Go further: A≡B means A↔B is a tautology. A→B being a tautology does not require the converse B→A to be one. Set A=p∧q and B=p. Use cases to show the first direction is always true, then show the converse is false for p=T,q=F.
