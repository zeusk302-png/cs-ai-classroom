소단원 8.1

수열·집합의 재귀 정의

첫 항과 다음 항을 만드는 규칙만으로 전체 대상을 정할 수 있을까?

준비 개념과 학습 목표

준비 개념

  • 자연수와 수열

  • 집합의 원소

학습 목표

  • 수열의 초기값과 적용 범위를 정한다.

  • 생성 집합의 최소성 조건을 설명한다.

생성된 모든 수가 짝수라는 사실만으로 모든 짝수가 생성될까?

새 집합 R은 기본 원소 0을 갖고 x가 이미 R에 있으면 x+4 또는 x+6을 추가한다. 유한 번 생성한 원소만 포함하는 최소 집합이다. 규칙에 없던 원소를 임의로 넣거나 음수에서 역방향으로 적용하지 않는다.

매 단계 짝수를 보존하므로 R의 모든 원소는 비음수 짝수다. 그러나 2는 생성되지 않는다. 첫 비기본 단계부터 최소 4이고 이후 증가하기 때문이다. 성질을 보존한다는 증명은 생성 집합의 한쪽 포함만 주며 같은 집합이라는 결론에는 반대쪽 포함도 필요하다.

정확히 R={0}∪{짝수 n:n≥4}임을 보이자. 4와 6은 직접 생성한다. n≥8인 짝수에서는 n−4가 4 이상인 더 작은 짝수여서 이미 구성한 값에 4를 더한다. 매 구성은 유한하지만 원소가 무한히 많다는 사실과 모순되지 않는다.

먼저 확인할 개념
  • 포함의 두 방향

    불변 성질과 정확한 생성 범위의 동치를 나눈다.

  • 여러 기초와 과거 범위

    4/6 기초와 n−4의 허용 영역을 확인한다.

이전 항에서 다음 항 만들기

재귀 수열은 시작 항과 이미 정한 항을 이용하는 규칙으로 값을 정한다. a_0=2, a_(n+1)=3a_n+1(n≥0)처럼 지표 시작과 규칙 범위를 함께 써야 한다. 첫 항을 빼면 같은 점화식을 만족하는 서로 다른 수열이 생긴다.

두 앞 항을 이용하는 Fibonacci형 규칙에는 두 초기값이 필요하다. 단순히 재귀라는 이름만으로 어떤 시작값과 입력이 정의되는지 결정되지 않는다. 아래는 한 앞 항만 쓰는 자체 수열이다.

기본 원소와 생성 규칙으로 집합 정하기

집합 S는 0을 포함하고 n∈S이면 n+3∈S라는 규칙으로 생성한다고 하자. 이 규칙을 유한 번 적용해서 만들 수 있는 원소만 포함하는 최소 집합을 뜻한다. 0,3,6,…이며 음수나 1을 임의로 더하지 않는다.

기본 원소 포함과 닫힘만 말하면 자연수 전체도 조건을 만족한다. 생성된 원소만 허용한다는 최소성 또는 배제 절이 집합을 정확히 정한다. 집합 원소와 수열의 지표/순서를 같은 것으로 취급하지 말자.

구성으로 포함을, 성질로 제외를 보이기

9가 S에 있음을 보이려면 0→3→6→9의 유한 구성을 제시한다. 4를 못 찾았다는 것만으로 제외를 증명하지 않고 모든 구성 원소가 3의 배수라는 불변 성질을 귀납으로 보인다.

유한 단계로 생성된 대상의 집합은 무한히 많을 수 있다. 각 원소의 유한 구성과 집합 전체가 유한이라는 주장은 다르다. 점화식 몇 값을 계산하는 것은 전체 일반식의 증명과도 다르다.

조건을 바꾸어 비교하기

정확한 집합의 양방향 증명

R={0}∪{짝수 n≥4}를 증명하라.

  1. 기본 0과 두 증가 규칙은 비음수 짝수를 보존한다. 비기본 구성의 첫 값은 4 또는 6이어서 2를 만들지 않는다.

  2. 역방향에서 0은 기본이고 4와 6은 한 단계로 만든다.

  3. 짝수 n≥8에서 4≤n−4<n이다. 더 작은 짝수 구성에 4를 더한다.

불변식/최소 증가와 강한 귀납으로 두 포함을 모두 확보한다.

비교할 점

짝수라는 필요조건을 충분조건으로 바꾸지 않는다.

값과 이력의 다른 유일성

12를 두 경로로 만들고 마지막 규칙이 값만으로 유일한지 보라.

  1. 0→6→12는 두 증가다.

  2. 0→4→8→12는 세 증가다.

  3. 같은 정수 12지만 마지막 이전 값 6과 8 및 이력 길이가 다르다.

생성 원소는 12 하나지만 구성 이력은 여러 개다. 이력 길이를 정수의 함수로 쓰려면 별도 규칙이 필요하다.

문자열·트리의 구성

글자 묶음과 가지가 갈라진 그림을 같은 방식으로 정의할 수 있을까?

준비 개념과 학습 목표

준비 개념

  • 문자와 빈 문자열

  • 노드와 자식

학습 목표

  • 기본/생성 사례로 유한 대상을 구성한다.

  • 문자열 길이와 트리 크기를 재귀 계산한다.

모양은 다르지만 잎 글자와 전체 크기가 같을 수 있을까?

새 유한 순서 트리는 leaf(c), c∈{a,b}, 또는 node(U,V)로 만든다. 왼쪽과 오른쪽은 구별된다. flat(leaf(c))=c, flat(node(U,V))=flat(U)++flat(V)로 잎을 왼쪽부터 읽는 문자열을 정한다.

두 위치에 동일한 작은 트리를 넣어도 각 구성 위치를 센다. 같은 포인터 객체를 공유하는 구현의 실제 메모리 개수는 이 함수의 대상이 아니다. 크기 N은 잎에서 1이고 부모에서 1과 두 자식 크기다. 문자열 길이 ℓ과 높이 h도 별도 함수이며 h(leaf)=0,h(node)=1+max(h(U),h(V))로 여기의 간선 높이를 정한다.

T=node(leaf(a),node(leaf(b),leaf(a)))는 문자열 aba, 크기 5, 높이 2다. 반대 결합 T′=node(node(leaf(a),leaf(b)),leaf(a))도 같은 aba/5/2이지만 다른 구성 대상이다. 문자열 결과나 숫자 한 개로 원 구조를 복원할 수 있다는 보장은 없다.

먼저 확인할 개념
  • 함수의 충돌

    서로 다른 입력 트리가 같은 flatten 결과를 낼 수 있다.

  • 함수 합성의 영역

    트리에서 문자열로, 문자열에서 길이로 이어지는 두 함수의 정의역과 공역을 연결한다.

빈 문자열에서 한 글자 붙이기

알파벳 {a,b}의 문자열은 빈 문자열 ε를 기본으로 하고 이미 만든 s 앞에 문자 c∈{a,b}를 붙인 cons(c,s)로 생성한다. 모든 문자열은 유한 번 생성한 것으로 제한한다. 길이는 len(ε)=0, len(cons(c,s))=1+len(s)다.

앞에 붙이는 규칙이므로 ab를 만들 때 ε→b→ab 순서다. 마지막 글자부터 구성한 과정과 화면에 보이는 글자 순서를 구별하자. ε는 길이가 0인 문자열이며 한 글자 공백과 같지 않다.

잎과 두 자식 노드로 트리 만들기

이 단원은 leaf를 기본으로 하고 node(L,R)를 생성자로 가진 유한 순서 있는 full binary tree를 쓴다. 모든 내부 노드는 정확히 두 자식이다. 한 자식 트리나 무한 순환 그래프는 이 자료형에 포함되지 않는다.

노드 총수 N(leaf)=1, N(node(L,R))=1+N(L)+N(R)다. 잎 수와 높이는 다른 함수다. 같은 모양의 자식 두 개가 있어도 각 위치의 구성 성분을 따로 세며 공유 포인터 그래프 메모리 개수를 계산하는 것이 아니다.

구성 문법과 그림의 의미 연결하기

node(leaf,node(leaf,leaf))는 왼쪽 잎과 오른쪽 내부 노드를 가진 트리다. 괄호와 왼쪽/오른쪽 위치가 구성 경계를 보여 준다. 그림을 문자열로 적을 때 이 정보를 생략하면 다른 트리를 구별하기 어렵다.

계산 함수는 기본과 각 생성 사례를 빠짐없이 따라야 한다. 자식 크기를 먼저 구해서 부모 크기를 계산하는 흐름은 나중에 구조적 귀납의 가정과 결론에도 그대로 연결된다.

구조적 귀납증명

작은 자식의 성질을 부모로 올리면 모든 유한 트리에 대해 증명할 수 있을까?

준비 개념과 학습 목표

준비 개념

  • 재귀 생성자

  • 보통 귀납법

학습 목표

  • 모든 기본/생성 사례를 증명한다.

  • 두 자식 각각의 귀납 가정을 사용한다.

거울을 두 번 비추면 돌아온다는 말을 모든 유한 트리에 증명하려면?

거울 함수 M은 M(leaf(c))=leaf(c), M(node(U,V))=node(M(V),M(U))다. 단지 root의 자식만 교환하는 것이 아니라 각 자식 안에도 재귀적으로 거울을 적용한다. 목표는 M(M(T))=T다.

잎에서 두 번은 그대로다. 부모에서는 두 자식 각각에 M(M(U))=U와 M(M(V))=V를 가정한다. 정의를 두 번 펼치면 node(M(M(U)),M(M(V)))라 두 가정을 모두 사용한다. 부모 목표를 미리 가정하거나 평평한 문자열이 같으니 트리가 같다고 결론내리지 않는다.

연결과 뒤집기의 순서도 중요하다. rev(s++t)=rev(t)++rev(s)이며 양쪽 순서를 뒤집는다. 모든 T에서 flat(M(T))=rev(flat(T))를 보이려면 양 자식의 귀납가정과 이 문자열 연결 규칙을 함께 사용한다. 작은 예제가 맞는 것과 일반 증명은 분리한다.

먼저 확인할 개념
  • 함의의 가정/결론

    자식 가정으로 부모를 보이고 부모를 가정하지 않는다.

  • 두 절을 함께 사용

    각 구성 성분에 필요한 가정 둘을 유지한다.

구성 규칙을 증명의 사례로 바꾸기

구조적 귀납은 재귀 자료형의 모든 대상에 성질 P가 성립함을 보인다. 모든 기본 대상에서 P를 보이고 각 생성자에서는 구성 성분들이 P를 만족한다고 가정해 새 대상도 P를 만족함을 증명한다.

full binary tree의 node(L,R)에는 P(L)와 P(R) 두 가정이 필요하다. 부모 P(node(L,R))를 처음부터 가정하면 결론을 가정한 순환 논증이다. 유한 구성만 허용했기 때문에 기초에서 생성 사례를 반복하여 모든 대상을 덮는다.

잎 수와 내부 노드의 관계 세우기

잎 수를 L(T), 내부 노드 수를 I(T)라 하자. 명제 L(T)=I(T)+1을 보인다. leaf에서는 L=1/I=0이고 node의 잎 수는 양 자식 잎의 합, 내부 수는 새 root 1에 양 자식 내부의 합이다.

자식의 크기가 같을 필요는 없다. 서로 다른 모양/깊이의 L/R에 각각 가정을 적용한다. 노드 수 몇 예가 맞았다는 관찰은 이 일반 증명의 대체가 아니다.

증명 범위를 자료형에 묶기

한 자식 내부 노드를 허용하면 위 식이 달라질 수 있다. 잎 하나에 부모 하나만 붙인 트리는 L=1/I=1로 L=I+1이 실패한다. 따라서 정확히 두 자식이라는 조건이 증명의 핵심이다.

전체 노드 N=L+I를 합하면 N=2I+1이라 전체 크기는 홀수다. 일반식에서 새로운 성질을 얻을 수 있지만 leaf/full binary/유한이라는 가정을 이어서 보존해야 한다.

내부 자식도 재귀 거울

두 번째 행은 자식 위치를 두 번 바꾸고 함수도 두 번 적용한다. 평평한 잎 문자열은 트리 자체와 다른 객체다.

중간 과정을 따라가는 예제

leaf와 node(L,R) 두 사례로 모든 유한 full binary tree의 잎 수=내부 노드 수+1을 증명하라.

  1. 기본 leaf: L=1,I=0이므로 1=0+1이다.

  2. 귀납 가정 L(L)=I(L)+1, L(R)=I(R)+1을 두자. 부모 잎 수는 I(L)+I(R)+2다.

  3. 부모 내부 수는 1+I(L)+I(R)다. 따라서 부모 잎 수는 부모 내부 수+1이고 모든 유한 구성에 성립한다.

기본과 유일한 node 생성 사례를 모두 확인하여 전체 자료형에 등식이 성립한다.

조건을 바꾸어 비교하기

두 번 거울의 일반 증명

모든 유한 순서 트리에서 M(M(T))=T를 보이라.

  1. 잎에서는 두 번 정의를 적용하여 leaf(c)다.

  2. 부모에서는 U와 V의 두 번 거울 등식을 각각 가정한다.

  3. M(M(node(U,V)))=node(M(M(U)),M(M(V)))다.

  4. 두 가정으로 node(U,V)를 얻는다.

모든 기본 잎과 유일한 부모 생성자를 덮어 원 목표가 성립한다.

비교할 점

잎 레이블의 개수가 많아도 모든 c에 기본을 확인한다.

왼쪽부터 읽기와 역순

T에서 M(T)의 flat을 구하고 일반 증명의 부모 단계를 써라.

  1. T의 flat=aba, M(T)=node(node(leaf(a),leaf(b)),leaf(a))라 역시 aba다.

  2. 일반 부모의 flat(M(node(U,V)))=flat(M(V))++flat(M(U))다.

  3. 가정으로 rev(flat(V))++rev(flat(U))=rev(flat(U)++flat(V))다.

이 예의 대칭 문자열 aba는 구조 동일성 증거가 아니다. 일반 단계는 역순 연결 법칙을 사용한다.

기본값만 있으면 어떤 자기 호출 규칙도 하나의 함수를 정할까?

준비 개념과 학습 목표

준비 개념

  • 유한 감소

학습 목표

  • 잘못된 순환이나 겹치는 규칙을 반례로 설명한다.

계산이 멈추는 것과 모든 규칙이 같은 답을 요구하는 것은 같을까?

새 요구 f(0)=0, f(n)=f(n−2)+1(n≥2)에서 정의역은 비음수 정수다. 입력은 감소하지만 1의 값이 없다. f(1)=q인 임의 정수 q에 따라 홀수 값이 달라지므로 기존 요구만으로 전체 함수를 유일하게 정하지 않는다. 종료에 필요한 도달 기초와 수학 해의 유일성을 함께 확인한다.

생성 집합 R의 구성이 항상 유한이어도 정수 x의 함수 d(x)를 “생성에 쓴 증가 횟수”로 정하면 충돌할 수 있다. d(0)=0, d(x+4)=d(x)+1, d(x+6)=d(x)+1을 모두 동등하게 요구하면 12에 2와 3을 동시에 요구한다. 이력별 함수와 정수 원소별 함수는 다르다.

최소 증가 횟수는 별도 정의다. m(x)=min{R의 x 구성 이력 길이}로 정하면 각 x에 유한 구성이 존재하고 길이는 비음수 정수라 최솟값이 있다. 그러나 모든 증가 간선에서 반드시 1 늘어난다는 등식은 더 이상 요구하지 않는다. 예컨대 8→12의 +4 간선은 m(8)=2, m(12)=2여서 그 등식을 깨뜨린다.

먼저 확인할 개념
  • 함수의 유일한 출력

    같은 정수에 동등 규칙이 두 값을 요구하는 충돌을 찾는다.

  • 비공집합 정수의 최소

더 작은 입력으로 반드시 돌아가기

자연수의 구조적 재귀는 0 기본값과 n+1에서 n 같은 더 작은 구성 성분으로 값을 정한다. 이미 정의된 값에서 다음 값을 만들므로 각 유한 입력을 계산하고 값을 유일하게 정할 수 있다.

f(0)=0, f(n)=f(n+1)(n>0)은 기본값이 있어도 양수 입력에서 더 큰 값만 찾는다. 계산은 0으로 돌아가지 않고, 양수에서 서로 다른 상수를 주는 여러 수학 함수도 식을 만족한다. 기본값 하나만으로 종료나 유일성이 보장되지 않는다.

겹치는 사례가 다른 값을 요구하는지 보기

규칙별 적용 영역이 겹치면 그 영역에서 값이 같아야 하나의 함수다. f(n)=0 if n이 2의 배수, f(n)=1 if n이 3의 배수라는 동등한 두 요구는 n=6에서 충돌한다. 순서 있는 if/else 코드로 우선순위를 주면 다른 명세다.

같은 자료를 여러 방식으로 구성하는 모호한 문법에서도 재귀 함수 결과가 구성 방법에 의존할 수 있다. 자료 자체의 함수인지 구성 이력의 함수인지 정하고 모든 표현에서 같은 값이 되는지 검토해야 한다.

다른 문제에 적용하기

R은 0/+4/+6의 최소 생성 집합이다. 2/10/12/14의 소속과 최소 이력 길이를 판정하고 12의 서로 다른 길이 이력을 적어 d의 간선 등식 충돌을 설명하라. T=node(leaf(a),node(leaf(b),leaf(a)))에서 N/flat/M(T)/M(M(T))를 구한다. 모든 유한 트리의 거울 크기 보존과 두 번 거울 등식을 각각 증명하고, 같은 flat을 원 구조 복원 증거로 쓸 수 있는지 반례를 제시하라. f의 −2 규칙에서 누락 기초를 보완하고 실제 코드/학생/메모리 실험 미수행을 구분하라.

힌트 1

짝수 불변식은 2를 넣는 충분조건이 아니다. 최소 길이는 더 짧은 가능성을 배제한다.

힌트 2

거울은 각 자식 내부에도 적용한다. 부모를 가정하지 말고 두 자식의 가정을 쓴다.

풀이와 답 확인

  1. 2는 미소속, 10/12/14는 소속이며 최소 길이 각각 2/2/3이다. 12의 6+6 길이 2와 4+4+4 길이 3은 d(12)의 동등 요구를 충돌시킨다.

  2. T의 N=5, flat=aba다. M(T)=node(node(leaf(a),leaf(b)),leaf(a))이며 한 번 더 거울은 T다.

  3. 잎에서 N과 두 번 등식을 확인하고 부모에서 양 자식의 가정으로 1+N(V)+N(U)=1+N(U)+N(V), node(M(M(U)),M(M(V)))=node(U,V)를 각각 얻는다.

  4. T와 M(T)는 같은 aba/5지만 왼쪽 자식이 잎/부모여서 서로 다른 트리다. flat/크기는 원 구조 복원을 보장하지 않는다.

  5. f(1)=q를 명시하면 홀수 값 q+(n−1)/2, 짝수 값 n/2로 정해진다. 다른 q는 다른 전체 함수다. 이는 수학 검산이며 컴파일/실제 포인터/재귀 성능/학생 수행 증거는 없다.

2는 생성 집합 밖이고 10,12,14는 집합 안이다. 이 세 원소의 최소 이력 길이는 각각 2,2,3이며 d의 요구는 12에서 충돌한다. T의 크기는 5이고 flat은 aba다. 거울은 다른 트리를 만들지만 두 번 적용하면 T로 돌아온다. 크기 보존과 두 번 거울의 일반 증명은 각각 양 자식의 가정을 사용한다. f는 누락된 기초 f(1)를 명시해야 전체 함수를 유일하게 정한다.

해결한 뒤 점검할 것

  • 값/최소값/구성 이력의 유일성을 분리한다.

  • 두 자식 가정으로 일반 증명을 완성한다.

  • 수학 명세와 실제 구현/학생 미수행을 구별한다.
