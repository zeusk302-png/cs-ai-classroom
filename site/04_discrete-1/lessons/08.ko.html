소단원 8.1

수열·집합의 재귀 정의

첫 항과 다음 항을 만드는 규칙만으로 전체 대상을 정할 수 있을까?

준비 개념과 학습 목표

준비 개념

  • 자연수와 수열

  • 집합의 원소

학습 목표

  • 수열의 초기값과 적용 범위를 정한다.

  • 생성 집합의 최소성 조건을 설명한다.

이전 항에서 다음 항 만들기

재귀 수열은 시작 항과 이미 정한 항을 이용하는 규칙으로 값을 정한다. a_0=2, a_(n+1)=3a_n+1(n≥0)처럼 지표 시작과 규칙 범위를 함께 써야 한다. 첫 항을 빼면 같은 점화식을 만족하는 서로 다른 수열이 생긴다.

두 앞 항을 이용하는 Fibonacci형 규칙에는 두 초기값이 필요하다. 단순히 재귀라는 이름만으로 어떤 시작값과 입력이 정의되는지 결정되지 않는다. 아래는 한 앞 항만 쓰는 자체 수열이다.

기본 원소와 생성 규칙으로 집합 정하기

집합 S는 0을 포함하고 n∈S이면 n+3∈S라는 규칙으로 생성한다고 하자. 이 규칙을 유한 번 적용해서 만들 수 있는 원소만 포함하는 최소 집합을 뜻한다. 0,3,6,…이며 음수나 1을 임의로 더하지 않는다.

기본 원소 포함과 닫힘만 말하면 자연수 전체도 조건을 만족한다. 생성된 원소만 허용한다는 최소성 또는 배제 절이 집합을 정확히 정한다. 집합 원소와 수열의 지표/순서를 같은 것으로 취급하지 말자.

구성으로 포함을, 성질로 제외를 보이기

9가 S에 있음을 보이려면 0→3→6→9의 유한 구성을 제시한다. 4를 못 찾았다는 것만으로 제외를 증명하지 않고 모든 구성 원소가 3의 배수라는 불변 성질을 귀납으로 보인다.

유한 단계로 생성된 대상의 집합은 무한히 많을 수 있다. 각 원소의 유한 구성과 집합 전체가 유한이라는 주장은 다르다. 점화식 몇 값을 계산하는 것은 전체 일반식의 증명과도 다르다.

중간 과정을 따라가는 예제

a_0=2, a_(n+1)=3a_n+1의 a_1,a_2,a_3을 구하고 S의 9 구성과 4 제외의 근거를 적어라.

  1. a_1=3×2+1=7, a_2=3×7+1=22, a_3=3×22+1=67이다.

  2. S에서 0에 +3을 세 번 적용해 9를 만든다.

  3. 기본 0은 3의 배수이고 3의 배수에 3을 더하면 다시 배수다. 모든 구성 원소는 배수이므로 4는 S에 없다.

수열은 2,7,22,67로 시작한다. 9∈S이고 4∉S다. 세 항 계산을 모든 항 증명으로 확대하지 않았다.

더 큰 집합도 두 조건을 만족할 수 있다. 최소 생성 집합 또는 유한 구성만 허용한다는 범위가 필요하다.

소단원 8.2

문자열·트리의 구성

글자 묶음과 가지가 갈라진 그림을 같은 방식으로 정의할 수 있을까?

준비 개념과 학습 목표

준비 개념

  • 문자와 빈 문자열

  • 노드와 자식

학습 목표

  • 기본/생성 사례로 유한 대상을 구성한다.

  • 문자열 길이와 트리 크기를 재귀 계산한다.

빈 문자열에서 한 글자 붙이기

알파벳 {a,b}의 문자열은 빈 문자열 ε를 기본으로 하고 이미 만든 s 앞에 문자 c∈{a,b}를 붙인 cons(c,s)로 생성한다. 모든 문자열은 유한 번 생성한 것으로 제한한다. 길이는 len(ε)=0, len(cons(c,s))=1+len(s)다.

앞에 붙이는 규칙이므로 ab를 만들 때 ε→b→ab 순서다. 마지막 글자부터 구성한 과정과 화면에 보이는 글자 순서를 구별하자. ε는 길이가 0인 문자열이며 한 글자 공백과 같지 않다.

잎과 두 자식 노드로 트리 만들기

이 단원은 leaf를 기본으로 하고 node(L,R)를 생성자로 가진 유한 순서 있는 full binary tree를 쓴다. 모든 내부 노드는 정확히 두 자식이다. 한 자식 트리나 무한 순환 그래프는 이 자료형에 포함되지 않는다.

노드 총수 N(leaf)=1, N(node(L,R))=1+N(L)+N(R)다. 잎 수와 높이는 다른 함수다. 같은 모양의 자식 두 개가 있어도 각 위치의 구성 성분을 따로 세며 공유 포인터 그래프 메모리 개수를 계산하는 것이 아니다.

구성 문법과 그림의 의미 연결하기

node(leaf,node(leaf,leaf))는 왼쪽 잎과 오른쪽 내부 노드를 가진 트리다. 괄호와 왼쪽/오른쪽 위치가 구성 경계를 보여 준다. 그림을 문자열로 적을 때 이 정보를 생략하면 다른 트리를 구별하기 어렵다.

계산 함수는 기본과 각 생성 사례를 빠짐없이 따라야 한다. 자식 크기를 먼저 구해서 부모 크기를 계산하는 흐름은 나중에 구조적 귀납의 가정과 결론에도 그대로 연결된다.

중간 과정을 따라가는 예제

문자열 ab의 구성과 길이, 트리 T=node(leaf,node(leaf,leaf))의 전체 노드/잎/내부 노드 수를 구하라.

  1. ab=cons(a,cons(b,ε))이고 길이 1+(1+0)=2다.

  2. 오른쪽 작은 node는 1+1+1=3노드, 전체 T는 1+1+3=5노드다.

  3. 잎은 3개, 내부 노드는 2개다. 전체 5=3+2로 검산한다.

ab 길이 2, T 전체 5/잎 3/내부 2다. 구성 위치의 수이며 실제 객체 메모리 측정이 아니다.

힌트 보기

풀이 보기

전체 노드 수에서는 잎도 한 노드다. N(leaf)=1이며 잎 수·높이의 기본값과 구별한다.

소단원 8.3

구조적 귀납증명

작은 자식의 성질을 부모로 올리면 모든 유한 트리에 대해 증명할 수 있을까?

준비 개념과 학습 목표

준비 개념

  • 재귀 생성자

  • 보통 귀납법

학습 목표

  • 모든 기본/생성 사례를 증명한다.

  • 두 자식 각각의 귀납 가정을 사용한다.

구성 규칙을 증명의 사례로 바꾸기

구조적 귀납은 재귀 자료형의 모든 대상에 성질 P가 성립함을 보인다. 모든 기본 대상에서 P를 보이고 각 생성자에서는 구성 성분들이 P를 만족한다고 가정해 새 대상도 P를 만족함을 증명한다.

full binary tree의 node(L,R)에는 P(L)와 P(R) 두 가정이 필요하다. 부모 P(node(L,R))를 처음부터 가정하면 결론을 가정한 순환 논증이다. 유한 구성만 허용했기 때문에 기초에서 생성 사례를 반복하여 모든 대상을 덮는다.

잎 수와 내부 노드의 관계 세우기

잎 수를 L(T), 내부 노드 수를 I(T)라 하자. 명제 L(T)=I(T)+1을 보인다. leaf에서는 L=1/I=0이고 node의 잎 수는 양 자식 잎의 합, 내부 수는 새 root 1에 양 자식 내부의 합이다.

자식의 크기가 같을 필요는 없다. 서로 다른 모양/깊이의 L/R에 각각 가정을 적용한다. 노드 수 몇 예가 맞았다는 관찰은 이 일반 증명의 대체가 아니다.

증명 범위를 자료형에 묶기

한 자식 내부 노드를 허용하면 위 식이 달라질 수 있다. 잎 하나에 부모 하나만 붙인 트리는 L=1/I=1로 L=I+1이 실패한다. 따라서 정확히 두 자식이라는 조건이 증명의 핵심이다.

전체 노드 N=L+I를 합하면 N=2I+1이라 전체 크기는 홀수다. 일반식에서 새로운 성질을 얻을 수 있지만 leaf/full binary/유한이라는 가정을 이어서 보존해야 한다.

중간 과정을 따라가는 예제

leaf와 node(L,R) 두 사례로 모든 유한 full binary tree의 잎 수=내부 노드 수+1을 증명하라.

  1. 기본 leaf: L=1,I=0이므로 1=0+1이다.

  2. 귀납 가정 L(L)=I(L)+1, L(R)=I(R)+1을 두자. 부모 잎 수는 I(L)+I(R)+2다.

  3. 부모 내부 수는 1+I(L)+I(R)다. 따라서 부모 잎 수는 부모 내부 수+1이고 모든 유한 구성에 성립한다.

기본과 유일한 node 생성 사례를 모두 확인하여 전체 자료형에 등식이 성립한다.

소단원 8.4

재귀 정의의 정당성

기본값만 있으면 어떤 자기 호출 규칙도 하나의 함수를 정할까?

준비 개념과 학습 목표

준비 개념

  • 함수의 유일한 값

  • 유한 감소

학습 목표

  • 기본/감소/일관성/범위 조건을 확인한다.

  • 잘못된 순환이나 겹치는 규칙을 반례로 설명한다.

더 작은 입력으로 반드시 돌아가기

자연수의 구조적 재귀는 0 기본값과 n+1에서 n 같은 더 작은 구성 성분으로 값을 정한다. 이미 정의된 값에서 다음 값을 만들므로 각 유한 입력을 계산하고 값을 유일하게 정할 수 있다.

f(0)=0, f(n)=f(n+1)(n>0)은 기본값이 있어도 양수 입력에서 더 큰 값만 찾는다. 계산은 0으로 돌아가지 않고, 양수에서 서로 다른 상수를 주는 여러 수학 함수도 식을 만족한다. 기본값 하나만으로 종료나 유일성이 보장되지 않는다.

겹치는 사례가 다른 값을 요구하는지 보기

규칙별 적용 영역이 겹치면 그 영역에서 값이 같아야 하나의 함수다. f(n)=0 if n이 2의 배수, f(n)=1 if n이 3의 배수라는 동등한 두 요구는 n=6에서 충돌한다. 순서 있는 if/else 코드로 우선순위를 주면 다른 명세다.

같은 자료를 여러 방식으로 구성하는 모호한 문법에서도 재귀 함수 결과가 구성 방법에 의존할 수 있다. 자료 자체의 함수인지 구성 이력의 함수인지 정하고 모든 표현에서 같은 값이 되는지 검토해야 한다.

정의와 구현의 증거 구별하기

유한 순서 트리는 leaf/node 구성 자체를 구별하므로 자식별 재귀가 명확하다. 문자열 연결을 생성자로 쓰면 ε=ε++ε처럼 같은 문자열에 여러 생성 이력이 생길 수 있어 연산 횟수 정의가 충돌할 수 있다.

적절한 재귀 정의를 주었다고 구현의 stack 한계·시간/메모리·공유 순환이 검증된 것은 아니다. 수학적 유일성/종료와 실행 환경을 나누어 기록한다. 아래는 함수값 요구를 손으로 대조한다.

중간 과정을 따라가는 예제

함수 g(0)=1, g(n+1)=2g(n)의 g(3)을 구하라. 별도 h(0)=0,h(n)=h(n+1)(n>0)이 유일한 함수를 정하지 않는 이유를 서로 다른 두 함수로 보여라.

  1. g(1)=2,g(2)=4,g(3)=8이다. 입력을 3→2→1→0으로 줄여 계산한다.

  2. h_A는 모든 n에서 0으로, h_B는 0에서 0/모든 양수에서 7로 정하자.

  3. 두 함수 모두 h(0)=0이고 양수 n에서는 h(n)=h(n+1)이다. 값이 다르므로 조건만으로 h를 유일하게 정하지 않는다.

g(3)=8이고 h의 조건에는 적어도 두 해가 있다. h(1)을 앞으로 호출하는 구현의 종료를 증명한 것은 아니다.

종이와 본문으로 직접 해보기

문자열 ε에 값 f(ε)=0, 연결 규칙 f(s++t)=1+f(s)+f(t)를 동시에 주면 어떤 충돌이 있는가?

힌트 보기

s=t=ε로 놓고 ε++ε=ε를 쓴다.

풀이 보기

왼쪽 f(ε)=0이어야 하지만 연결 규칙은 1+0+0=1을 요구한다. 따라서 이 문자열 함수 정의는 일관되지 않다.

오해와 반례

초기값이 한 개 있으면 재귀 규칙은 언제나 유일하고 종료한다.

범위·잘-founded 감소·겹치는 구성의 일관성 등을 따로 확인해야 한다. h 반례는 기본값이 있어도 유일성이 없음을 보인다.
