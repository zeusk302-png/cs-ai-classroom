소단원 5.1

단사·전사·전단사

서로 다른 학생이 같은 사물함을 배정받아도 함수일까?

준비 개념과 학습 목표

준비 개념

  • f:A→B는 A의 모든 입력마다 B 안의 출력 하나를 지정한다.

  • 치역 f(A)는 실제 나온 출력들의 집합이며 공역 B와 다를 수 있다.

  • ∀는 모든 대상, ∃는 적어도 한 대상이 있다는 뜻이다.

학습 목표

  • 세 대응 성질을 정확한 양화 조건으로 판정한다.

  • 실패를 보이는 충돌 입력이나 빠진 출력을 찾는다.

함수 조건과 단사 조건

함수는 입력 하나에 출력 하나를 요구한다. 서로 다른 두 입력이 같은 출력을 갖는 것은 허용된다. 여기에 다른 입력끼리 출력이 겹치지 않는 조건을 더하면 단사(injective)다. 수식은 모든 x₁,x₂∈A에 대해 f(x₁)=f(x₂)라면 x₁=x₂다. 공역의 출력 하나에는 원상이 최대 하나 있다는 표현과 같다.

단사가 아님을 증명하려면 x₁≠x₂인데 f(x₁)=f(x₂)인 실제 한 쌍을 제시한다. 출력 하나가 아무 입력에도 연결되지 않아도 단사는 가능하다. 최대 하나와 정확히 하나를 구별한다. 유한 표에서 출력 중복을 찾을 수 있지만 무한 정의역은 몇 개만 검사하여 단사를 증명할 수 없다.

빠진 출력과 전사 조건

전사(surjective)는 모든 y∈B에 대해 f(x)=y인 x∈A가 적어도 하나 있다는 뜻이다. 즉 치역 f(A)=B다. 여러 입력이 같은 y로 갈 수도 있다. 전사가 아님을 보이려면 공역에 속하지만 어떤 입력에서도 나오지 않는 y를 찾는다.

공역을 바꾸면 같은 계산식도 전사 여부가 달라진다. x²를 ℝ→ℝ로 보면 −1이 안 나와 전사가 아니다. ℝ→[0,∞)로 보면 y≥0마다 x=√y를 선택할 수 있어 전사다. 이때 ±1의 출력 충돌은 그대로라 단사는 아니다. 계산식만 적고 집합을 생략하면 성질을 판정할 수 없다.

두 조건을 함께 보기

전단사(bijective)는 단사이면서 전사다. 모든 공역 원소마다 원상이 정확히 하나 있으므로 출력을 보고 입력을 유일하게 되찾는다. 단사와 전사는 서로의 부정이 아니다. 둘 다 참, 하나만 참, 둘 다 거짓인 경우를 따로 생각한다.

빈 정의역에서도 함수는 의미가 있다. ∅→B에는 빈 대응 함수 하나가 있고 입력 충돌이 없어 단사다. 이 함수가 전사인 것은 B도 빈 집합일 때뿐이다. A가 비어 있지 않고 공역이 ∅이면 출력 하나를 지정할 수 없어 함수 자체가 없다. 빈 경우는 대응 그림에서 놓치기 쉽다.

중간 과정을 따라가는 예제

A={1,2,3},B={a,b,c,d}에서 f=(a,b,b), g=(a,b,c)를 출력 순서 표로 정의한다. 또 h:{1,2,3,4}→B를 (b,c,d,a)로 정의한다. 세 성질을 판정하라.

  1. f는 2와 3의 출력 b가 같으므로 단사가 아니다. c,d가 치역에서 빠지므로 전사도 아니다.

  2. g는 서로 다른 출력 a,b,c를 갖으므로 단사다. 하지만 d가 빠져 전사가 아니다.

  3. h의 네 출력은 모두 다르며 B의 모든 원소를 포함한다. 단사와 전사를 모두 만족한다.

  4. f와 g도 각 입력에 출력 하나가 있으므로 함수다. 단사가 아닌 것과 함수가 아닌 것을 혼동하지 않는다.

f는 둘 다 아니고 g는 단사만, h는 전단사다.

종이와 본문으로 직접 해보기

A={1,2,3,4},B={a,b,c}에서 q=(a,b,c,c)를 판정하고 q를 단사로 만들려면 같은 두 집합으로 가능한지 설명하라.

힌트 보기

출력 c의 원상을 먼저 찾고, 서로 다른 네 출력이 세 칸에 들어갈 수 있는지 생각한다.

풀이 보기

q는 모든 a,b,c가 나와 전사다. 3과 4가 충돌하여 단사가 아니다. 같은 집합 사이에서 단사 함수는 없다. 네 입력에 서로 다른 세 개 이하 출력만 배정할 수 있어 적어도 둘이 겹친다.

오해와 반례

입력 하나마다 출력 하나이면 단사다.

f의 입력 2와 3은 각각 출력 하나씩을 가지지만 같은 b로 간다. 함수 조건은 한 입력의 유일성이고 단사는 서로 다른 입력 사이의 충돌 금지다.

자기점검

∅→{a}의 빈 함수는 단사인가?

답과 이유 보기

그렇다.

충돌할 두 입력이 없어 모든 입력 쌍에 관한 조건이 참이다.

x²:[0,∞)→[0,∞)는 전단사인가?

답과 이유 보기

그렇다.

제곱은 비음수 영역에서 서로 다른 값을 구분하고 y의 원상 √y가 항상 있다.

전사이면 원상이 유일한가?

답과 이유 보기

아니다.

q의 c에는 3,4라는 두 원상이 있다. 전사는 존재만 보장한다.

한 단계 더

실수 함수 f(x)=2x+1의 전단사를 정의로 증명하자. 2u+1=2v+1이면 2u=2v이므로 u=v다. 임의의 y∈ℝ에 대해 x=(y−1)/2∈ℝ이고 f(x)=y다. 첫 논증이 단사, 둘째가 전사다. 같은 식을 ℤ→ℤ로 바꾸면 짝수 출력에 원상이 없으므로 전사 논증의 x가 정의역에 들어가는지 다시 확인해야 한다.

소단원 5.2

합성과 역함수

두 변환을 차례로 적용한 결과를 거꾸로 되돌리려면 어느 변환부터 취소해야 할까?

준비 개념과 학습 목표

준비 개념

  • 앞 함수의 출력이 뒤 함수의 입력 집합에 들어가야 한다.

  • id_A(x)=x는 A에서 A로 가는 항등함수다.

  • 역함수와 수의 역수 1/f(x)는 다른 개념이다.

학습 목표

  • 합성 순서를 식과 집합에 맞춰 계산한다.

  • 양쪽 항등식을 확인하여 역함수를 검증한다.

합성은 오른쪽부터 적용하기

f:A→B,g:B→C라면 g∘f:A→C를 (g∘f)(x)=g(f(x))로 정의한다. 먼저 f로 A에서 B로 옮기고, 그 결과에 g를 적용한다. 합성 기호의 오른쪽 함수가 먼저라는 규칙을 단계 표로 확인하면 혼동이 줄어든다. f∘g는 집합이 맞지 않아 정의하지 못할 수도 있다.

둘 다 실수 함수여도 순서가 바뀌면 대개 결과가 다르다. f(x)=2x+1,g(x)=x²이면 g∘f=(2x+1)²이고 f∘g=2x²+1이다. 반면 합성은 가능한 집합 연결에서 결합법칙 h∘(g∘f)=(h∘g)∘f를 만족한다. 양쪽 모두 x를 f,g,h 순서로 처리하므로 괄호만 다르다.

역은 공역의 모든 값을 되돌리기

f:A→B의 역함수 r:B→A는 r∘f=id_A와 f∘r=id_B를 둘 다 만족해야 한다. 전단사 f이면 y마다 유일한 원상 x를 r(y)로 정할 수 있어 이 두 조건을 만족한다. 반대로 r이 있으면 같은 출력에 r을 적용해 단사를 얻고, 모든 y에 대해 x=r(y)를 택해 전사를 얻는다.

f(x)=x²를 ℝ→[0,∞)로 두면 원상 ±√y가 겹쳐 역함수가 없다. 정의역을 [0,∞)로 제한하면 역 √y가 생긴다. 한쪽만 되돌리는 함수는 양쪽 역과 다르다. 예를 들어 f(x)=x²,r(y)=√y에서 f(r(y))=y지만 r(f(−2))=2≠−2다.

합성과 성질 연결하기

두 단사 함수의 합성은 단사다. g(f(u))=g(f(v))에서 먼저 g의 단사로 f(u)=f(v), 다음 f의 단사로 u=v를 얻는다. 두 전사 함수의 합성은 전사다. 임의의 최종 출력 z에 g의 원상 y를 찾고, 그 y의 f 원상 x를 찾아 연결한다.

합성이 전단사라고 두 함수가 각각 전단사라는 역추론은 안 된다. A={1},B={a,b},C={0},f(1)=a,g(a)=g(b)=0이면 합성은 유일 입력과 출력의 전단사다. 하지만 f는 b를 빠뜨려 전사가 아니며 g는 충돌하여 단사가 아니다. 합성의 단사는 f의 단사를, 합성의 전사는 g의 전사를 보장하는 방향만 일반적으로 남는다.

중간 과정을 따라가는 예제

f,g:ℝ→ℝ에서 f(x)=2x+1,g(x)=x²를 x=1에 합성하라. f의 역을 구하고 양쪽 합성으로 확인하라.

  1. g(f(1))=g(3)=9이고 f(g(1))=f(1)=3이다. 두 합성은 다르다.

  2. y=2x+1을 x에 대해 풀면 x=(y−1)/2다. r(y)=(y−1)/2는 모든 실수에서 정의된다.

  3. r(f(x))=(2x+1−1)/2=x다.

  4. f(r(y))=2*(y−1)/2+1=y다. 모든 실수 x,y에서 성립하므로 r=f⁻¹이다.

두 순서의 값은 9와 3이며 f⁻¹(y)=(y−1)/2다. 역은 양쪽 식으로 검사했다.

종이와 본문으로 직접 해보기

f:{1,2,3}→{a,b,c}를 (b,c,a)로 정의한다. 역 표를 만들고 역을 두 번 취하면 무엇이 되는지 확인하라.

힌트 보기

출력 a,b,c의 원상을 각각 찾고 정의역과 공역도 교환한다.

풀이 보기

f⁻¹:{a,b,c}→{1,2,3}의 출력 순서는 (3,1,2)다. 예를 들어 f⁻¹(f(1))=f⁻¹(b)=1이고 f(f⁻¹(a))=f(3)=a다. 모든 세 원소에서 같으며 역의 역은 원래 f다.

오해와 반례

합성의 역은 같은 순서로 두 역을 적용한다.

전단사 f,g에 대해 (g∘f)⁻¹=f⁻¹∘g⁻¹이다. 마지막 g를 먼저 취소하고 그 다음 f를 취소한다. f=2x+1,g=x+3이면 전체는 2x+4이고 역은 (y−4)/2다. 잘못된 g⁻¹∘f⁻¹는 (y−1)/2−3=(y−7)/2다.

자기점검

g∘f에서 먼저 실행되는 함수는?

답과 이유 보기

f.

정의식 g(f(x))의 내부 f가 먼저 값을 만든다.

f⁻¹는 1/f인가?

답과 이유 보기

아니다.

f(x)=2x+1의 역은 (y−1)/2이고 역수 식은 1/(2x+1)이다.

합성이 단사이면 뒤 함수 g도 전체 B에서 단사인가?

답과 이유 보기

반드시 아니다.

A={1}, B={a,b}, g(a)=g(b)인 반례에서 f가 b를 사용하지 않는다.

한 단계 더

양쪽 역의 유일성을 증명하자. r과 s가 모두 f의 양쪽 역이면 r=r∘id_B=r∘(f∘s)=(r∘f)∘s=id_A∘s=s다. 각 항등함수의 집합 첨자는 실제 합성 가능한 방향을 확인해 준다. 전단사가 아닌 경우에도 역상 f⁻¹(T)는 다음 소단원에서 정의할 수 있다. 역상 집합 기호가 있다고 역함수가 있다고 결론 내리지 않는다.

소단원 5.3

상과 역상

출력 조건을 만족하는 입력들을 찾으려면 역함수가 꼭 필요할까?

준비 개념과 학습 목표

준비 개념

  • 집합은 같은 원소를 중복하여 세지 않는다.

  • S⊆A,T⊆B처럼 어느 쪽 집합의 부분집합인지 먼저 정한다.

  • 역함수 f⁻¹(y)와 역상 f⁻¹(T)는 기호가 겹치지만 역할이 다르다.

학습 목표

  • 상과 역상을 원소 조건으로 계산한다.

  • 집합 연산에 대한 보존과 실패 반례를 설명한다.

입력 집합을 앞으로 보내기

f:A→B와 S⊆A에 대해 상 f(S)={f(x):x∈S}다. S의 각 입력에 함수를 적용하여 나온 값만 모은다. 서로 다른 입력이 같은 출력을 만들면 상에는 그 값을 한 번만 넣는다. 전체 상 f(A)가 치역이며 공역 B와 같다는 보장은 없다.

S⊆U이면 f(S)⊆f(U)다. f(S∪U)=f(S)∪f(U)도 성립한다. 어떤 출력이 합집합 입력에서 나왔다는 것은 S 또는 U의 입력에서 나왔다는 뜻이기 때문이다. 하지만 교집합의 상은 대개 f(S∩U)⊆f(S)∩f(U)만 보장된다. 동일 출력이 S와 U의 서로 다른 입력에서 나올 수 있다.

출력 조건을 뒤로 가져오기

T⊆B의 역상 f⁻¹(T)={x∈A:f(x)∈T}는 출력이 T 안에 있는 모든 입력을 모은 집합이다. 이 정의는 f가 단사나 전사가 아니어도 가능하다. 어떤 출력에 입력이 없으면 그 부분의 역상은 빈 집합이고 여러 입력이 있으면 모두 포함한다.

역상은 합집합·교집합을 정확히 보존한다. 예를 들어 x∈f⁻¹(T∩V)⇔f(x)∈T이고 f(x)∈V⇔x∈f⁻¹(T)∩f⁻¹(V)다. 여집합도 f⁻¹(B∖T)=A∖f⁻¹(T)로 보존된다. 여집합의 전체 기준 A와 B를 생략하면 어느 원소를 제외하는지 모호해진다.

되돌릴 때 추가되거나 빠지는 것

항상 S⊆f⁻¹(f(S))다. S에서 나온 출력과 충돌하는 다른 입력이 추가될 수 있어서 등호가 아닐 수 있다. f가 단사라면 추가 충돌이 없어 모든 S에 대해 등호다. 입력 집합을 되찾는 데 필요한 조건을 이렇게 확인한다.

반대로 f(f⁻¹(T))=T∩f(A)다. 원래 T에서 실제로 도달 가능한 출력만 남는다. T에 공역의 도달 불가능한 원소가 있으면 빠진다. f가 전사라면 f(A)=B이므로 모든 T⊆B에 대해 T가 그대로 복원된다. 이 두 방향의 차이는 단사와 전사의 역할 차이를 보여준다.

중간 과정을 따라가는 예제

A={−2,−1,0,1,2}, B={0,1,4,9}, f(x)=x²에서 S={−2,1}, T={1,9}의 상·역상과 두 되돌림을 구하라.

  1. S의 출력은 4와 1이므로 f(S)={1,4}다.

  2. T의 출력 조건 x²∈{1,9}를 A에서 검사한다. −1,1만 1을 만들고 ±3은 A에 없어서 f⁻¹(T)={−1,1}이다.

  3. f⁻¹(f(S))는 출력 1 또는 4를 만드는 입력 {−2,−1,1,2}다. 원래 S보다 두 입력이 더 있다.

  4. f(f⁻¹(T))={1}이고 f(A)={0,1,4}이므로 T∩f(A)={1}과 같다. 9는 원상이 없다.

상 {1,4}, 역상 {−1,1}, 되돌린 입력 {−2,−1,1,2}, 되돌린 출력 {1}이다.

종이와 본문으로 직접 해보기

같은 f에서 S={−1},U={1}의 교집합 상과 두 상의 교집합을 비교하라. T={1,9},V={4,9}의 역상 교집합도 계산하라.

힌트 보기

서로 다른 부호는 같은 제곱을 만들 수 있다. 9의 원상은 A에서 없다.

풀이 보기

S∩U=∅라 f(S∩U)=∅지만 f(S)=f(U)={1}이므로 두 상의 교집합은 {1}이다. T∩V={9}의 역상은 ∅다. f⁻¹(T)={−1,1},f⁻¹(V)={−2,2}의 교집합도 ∅로 정확히 일치한다.

오해와 반례

역상을 계산하려면 먼저 역함수를 구해야 한다.

제곱 함수는 이 A에서 단사가 아니라 역함수가 없지만 f⁻¹({1})={−1,1}은 잘 정의된다. 역상은 출력 조건을 만족하는 입력 집합이며 출력 하나를 입력 하나로 돌리는 역함수가 아니다.

답과 이유 보기

앞으로 보낼 입력도, 만족시킬 출력 조건도 없다.

답과 이유 보기

함수의 모든 입력은 정의상 B 안의 출력 하나를 가진다.

상은 교집합을 항상 정확히 보존하는가?

답과 이유 보기

아니다.

{−1}과 {1}의 상은 같아도 입력 교집합은 비어 있다.

한 단계 더

역상에서 합성의 순서를 확인해 보자. f:A→B,g:B→C,T⊆C이면 (g∘f)⁻¹(T)=f⁻¹(g⁻¹(T))다. x가 왼쪽 집합에 속함은 g(f(x))∈T, 즉 f(x)∈g⁻¹(T), 즉 x∈f⁻¹(g⁻¹(T))와 같다. 양쪽의 모든 원소 조건이 같으므로 집합이 같다. f나 g가 전단사일 필요 없다. 이는 역함수 공식과 닮았지만 집합 조건의 역상 연산에 대한 별도 항등식이다.

소단원 5.4

유한집합과 기수

입력과 출력의 개수만 알아도 가능한 대응을 얼마나 제한할 수 있을까?

준비 개념과 학습 목표

준비 개념

  • |A|는 집합 A의 원소 수다. 유한 집합에서는 직접 세는 자연수다.

  • n!=n(n−1)…1이며 0!=1로 둔다.

  • 각 독립 선택의 경우 수는 곱셈 원리로 곱한다.

학습 목표

  • 유한 크기로 단사·전사 가능성을 판정한다.

  • 함수 수를 세고 무한 집합의 반례를 구별한다.

빈 칸과 겹친 칸을 세기

유한 A,B의 크기를 n,m이라 하자. 단사라면 서로 다른 n개 입력에 서로 다른 출력 n개가 필요하여 n≤m이다. 전사라면 모든 m개 출력에 적어도 하나 입력이 필요하여 n≥m이다. m>0일 때 각각의 크기 조건을 만족하면 실제 단사 또는 전사를 구성할 수 있다.

공역이 빈 경우는 별도로 적는다. n>0,m=0이면 함수가 없다. n=0,m=0이면 빈 함수 하나가 전단사다. n=0,m>0이면 빈 함수는 단사지만 전사가 아니다. 전사 존재를 n≥m이라는 부등식만으로 말하면 비어 있는 공역 예외를 놓칠 수 있다.

함수 수를 선택으로 계산하기

m>0이면 n개 입력마다 m개 중 하나를 독립적으로 선택하므로 전체 함수는 m^n개다. 단사는 이미 사용한 출력에 다시 갈 수 없어 n≤m일 때 m(m−1)…(m−n+1)개다. n=m이면 단사 수는 n!이고 자동으로 전사가 되어 전단사 수도 n!이다.

같은 유한 크기에서 단사인데 전사가 아니면 n개 서로 다른 출력이 n칸 중 일부를 빠뜨린다는 모순이다. 전사인데 단사가 아니면 중복 때문에 서로 다른 출력 수가 n보다 작아지는 모순이다. 전체 함수 m^n을 세는 방법은 중복 출력을 허용하므로 전단사 계수 n!와 다르다. 빈 함수의 0^0은 여기의 함수 계수 문맥에서는 1로 약속한다.

유한 조건을 떼면 달라지는 결론

기수가 같다는 일반 정의는 두 집합 사이에 전단사가 있다는 것이다. 유한 집합에서는 직접 센 개수의 같음과 일치한다. 자연수 N={0,1,…}와 짝수 집합 E={0,2,…}는 n↦2n이라는 전단사로 같은 기수를 갖는다. 무한 집합의 진부분집합도 원래 집합과 같은 기수를 가질 수 있다.

N→N의 n↦n+1은 단사지만 0을 빠뜨려 전사가 아니다. n↦⌊n/2⌋는 모든 k의 원상 2k가 있어 전사지만 0과 1처럼 충돌하여 단사가 아니다. 따라서 같은 크기에서 단사와 전사가 동치라는 유한 정리를 무한 집합에 적용할 수 없다. 특정 대응의 성질과 다른 전단사가 존재한다는 집합 크기는 구별한다.

중간 과정을 따라가는 예제

세 입력 {1,2,3}을 두 출력 {a,b}에 보내는 전체 함수와 전사를 세라. 두 입력을 세 출력에 보내는 단사 수도 구하라.

  1. 각 입력에 두 선택이 있으므로 전체 함수 수는 2³=8이다.

  2. 전사가 아닌 함수는 모두 a로 보내는 것과 모두 b로 보내는 것 두 개다. 공역이 두 원소이므로 하나를 빠뜨리면 상수 함수다.

  3. 전사는 8−2=6개다. 세 입력에서 두 출력으로 가는 단사는 3>2여서 없다.

  4. 두 입력에서 세 출력으로 가는 단사는 첫 선택 3개, 둘째 선택 2개라 3*2=6개다. 전체 함수는 3²=9개이며 전사는 없다.

3→2의 전체8·전사6·단사0, 2→3의 단사6·전체9·전사0이다.

오해와 반례

동일한 크기의 집합 사이에서 단사면 언제나 전사다.

유한 집합에 필요한 조건이다. N→N의 n+1은 같은 무한 집합 사이의 단사지만 0을 출력하지 않는다. N의 원소 하나를 빠뜨린다는 이유로 집합 자체의 기수가 달라지는 것도 아니다.

답과 이유 보기

서로 다른 n은 다른 짝수를 만들고 모든 짝수 2k에 원상 k가 있다.

한 단계 더
