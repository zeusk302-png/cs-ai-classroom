小节 1.1

命题与联结词

“正在下雨或者有雨伞”在两部分都为真时，会是假的吗？

预备知识与学习目标

预备知识

  • 真与假：对于事实已经确定的陈述，用 T 或 F 标记。
  • 括号：表示哪些部分先组合在一起。
  • 简短复习：区分问题、命令和断言事实的句子。

学习目标

  • 区分命题与变量尚未确定的开放句。
  • 解释否定、合取、析取、蕴含和双条件的真值条件。
  • 用符号和括号消除日常语言中的歧义。

命题是进行判断的单位

在经典命题逻辑中，命题是恰好具有真、假两种真值之一的断言。“7 是奇数”为真，“7 是偶数”为假。“打开窗户”是命令，因此不是这里所说的命题。

“x>3”在确定 x 或对 x 的范围加上量化条件之前，是开放句。代入 x=5 得到真，代入 x=1 得到假。我们不知道某个命题的真值，并不意味着它不是命题。要区分“事实尚未核实”和“变量尚未确定，因而还未给出真值”。

精确定义联结词

p 的否定 ¬p 在 p 为真时为假，在 p 为假时为真。p∧q 只有两者都为真才为真。p∨q 是包含性的析取：至少一个为真就为真。如果要求恰好一个为真，使用异或 p⊕q。

p→q 只在 p 为真、q 为假时为假。它排除了“满足 p 却违反 q”的情形。p↔q 在两者真值相同时为真。要区分“某一次赋值下 p↔q 为真”和“两逻辑公式在所有情形下都等价”。

逻辑蕴含与生活中的因果

把“如果下雨，就有雨伞”写为 p→q，只有 p=T,q=F 才违反这个条件。不下雨时，不管有没有雨伞，都没有违反该条件，所以两种情况都把蕴含判为真。这并不是在断言雨是雨伞的原因。

自然语言中的“或者”有时表示只能选一项，需要查看语境。在数学中，∨ 固定表示包含性的析取。对于复杂公式，用 p∧(q∨r) 这样的括号明确组合范围，不要让读者猜测没有括号的长句如何分组。

逐步推导的例题

令 p=“正在下雨”，q=“有雨伞”。在 p=T,q=F 的情况下，计算 ¬p、p∧q、p∨q、p→q、p↔q。

  1. p=T，所以 ¬p=F。
  2. p∧q 的两部分并非都真，所以为 F。
  3. p∨q 中至少 p 为真，所以为 T。
  4. p→q 是 T→F，所以为 F。
  5. p↔q 的两边真值不同，所以为 F。

依次为 F,F,T,F,F。违反雨伞条件的情形，正好对应 p→q 为假的条件。

用纸笔和正文动手试一试

在 p=T,q=T 时计算 p∨q 和 p⊕q，分别写出哪个运算适合“两个功能中至少启用一个”和“恰好启用一个”。

查看提示

“至少”允许两个都启用，“恰好一个”排除两个都启用。

查看解答

p∨q=T，p⊕q=F。至少一个用 ∨，恰好一个用 ⊕。只有一个功能为真的 T,F 或 F,T 情况下，两种运算都是 T。

常见误解与反例

前提为假时，p→q 为假。

p=F 时，无论 q 的值是什么，p→q 都为真。例如，蓝色的奇数卡片并不违反“如果卡片是红色，编号就是偶数”的规则。仅凭前提为假，不能推断结论 q 为真。

检查理解

“今天把作业做完！”这个命令在本单元中是命题吗？

查看答案与理由

不是。

命令本身没有断言一个真或假的事实。

p=F,q=T 时，p∨q 与 p∧q 分别是什么？

查看答案与理由

T 与 F。

析取只需要至少一个为真，合取需要两个都为真。

p=T,q=T 时，数学中的 p∨q 为假吗？

查看答案与理由

为真。

∨ 是包含性的析取，与排他的选择不同。

进一步探索

进阶：恰好一个为真的条件可写成 (p∨q)∧¬(p∧q)。亲自计算四种情况，检查是否排除了 T,T，只保留 T,F 和 F,T。以后可将它与布尔电路中的 XOR 联系起来，本单元只讨论纯粹的真值。

小节 1.2

真值表与重言式

检查全部四种可能情况，就能知道复杂规则是否总成立吗？

预备知识与学习目标

预备知识

  • 联结词：知道 ¬、∧、∨、→ 的真值条件。
  • 读表：每一行表示一种真值赋值。
  • 计数简短复习：每个变量都可以选择 T 或 F。

学习目标

  • 无遗漏地列出 2ⁿ 种真值赋值。
  • 判断公式是重言式、矛盾式还是偶然式。
  • 通过每一行结果一致来确认逻辑等价。

列出所有情况，不遗漏

假设 n 个命题变量可以分别独立取 T 或 F，则有 2ⁿ 种赋值。p,q 两个变量对应 T,T；T,F；F,T；F,F 四行。三个变量对应八行。漏掉一行，就可能漏掉只在那一行出现的错误。

从括号中的小部分开始计算复合公式，并写出中间列。例如，对 (p→q)∧p，先计算 p→q，再与 p 作合取。如果具体场景中的规则限制了变量之间的关系，需要明确写出限制；纯命题逻辑检查默认考虑全部可能赋值。

总为真，还是有时为真？

在所有赋值下都为真的公式叫重言式，在所有赋值下都为假的公式叫矛盾式。p∨¬p 是重言式，p∧¬p 是矛盾式。在某些行真、某些行假的公式叫偶然式。这里的“偶然”并不表示随机。

变量 p 本身可以取两种真值，因此是偶然式。具体事实“2+2=4”为真，与变量公式仅凭逻辑形式就总为真，是不同的事情。重言性要求覆盖所有真值赋值，强于若干个别观察中的成立。

相同的结果列与有效推理

如果公式 A,B 在每一种赋值下真值都相同，它们逻辑等价，记作 A≡B。这等价于 A↔B 是重言式。仅仅在某一行结果相同，不能得出等价结论。

如果 ((p→q)∧p)→q 是重言式，就保证“p→q 与 p 都为真时，q 也为真”的推理。某个前提为假的行不是违反该推理的例子。这可以区分“假设前提为真时的推理有效性”和“某个具体结论在现实中是否为真”。

逐步推导的例题

为 ((p→q)∧p)→q 建立真值表，判断它是否为重言式。

  1. 行顺序为 (p,q)=(T,T),(T,F),(F,T),(F,F)。
  2. p→q 一列为 T,F,T,T。
  3. (p→q)∧p 一列为 T,F,F,F。
  4. 最后一列分别为 T→T、F→F、F→T、F→F，因此为 T,T,T,T。

所有行都是 T，因此是重言式。这验证了肯定前件规则（modus ponens）的逻辑形式。

用纸笔和正文动手试一试

并排写出 p→q 与 ¬p∨q 的四行结果，判断它们是否等价。

查看提示

先求 ¬p。按已给出的行顺序，检查两列输出是否都为 T,F,T,T。

查看解答

p→q 为 T,F,T,T。¬p 为 F,F,T,T，与 q 作析取后为 T,F,T,T。四行全部一致，所以 p→q≡¬p∨q。

常见误解与反例

很多例子中为真，就是重言式。

p∨q 在 T,T；T,F；F,T 三行都为真，但在 F,F 时为假，因此是偶然式。需要检查全部行，或者给出覆盖全部情况的等价推导；仅检查表的一部分还不够。

检查理解

含三个命题变量的真值表有多少行？

查看答案与理由

8。

每个变量有两个选择，因此为 2³。

p∧¬p 属于哪一类？

查看答案与理由

矛盾式。

p=T 时 ¬p=F，p=F 时 p 本身为 F，所以合取总为 F。

A 与 B 在一行中相同，就逻辑等价吗？

查看答案与理由

仅凭这一点无法确定。

等价要求全部可能赋值下的结果都一致。

进一步探索

进阶：20 个变量需要 2²⁰=1,048,576 行。真值表是完备的方法，但规模会增长。解释为什么要使用等价律和结构化证明。本单元没有运行 SAT 搜索程序，也没有测量性能。

小节 1.3

必要条件与充分条件

“正方形一定是长方形”这句话中，哪个条件必要，哪个条件充分？

预备知识与学习目标

预备知识

  • 蕴含：p→q 只在 p=T,q=F 时为假。
  • 集合包含：A⊆B 表示 A 的每个元素也在 B 中。
  • 反例：找到一个推翻一般断言的具体情况。

学习目标

  • 解释在总成立的 p→q 中，p 为 q 的充分条件，q 为 p 的必要条件。
  • 区分逆命题、否命题与逆否命题，并确认逆否等价。
  • 为把必要条件误当充分条件的推理提供反例。

充分能保证结果，必要不能缺少

如果 p→q 总成立，p 就是 q 的充分条件：只要确保 p，就能保证 q。在同一关系中，q 是 p 的必要条件：p 要成立，就不能缺少 q。必要并不意味着仅靠 q 就能保证 p。

如果 n 是 4 的倍数，n 就是偶数。“4 的倍数”足以保证“偶数”，“偶数”是成为“4 的倍数”所必需的条件。6 是偶数，却不是 4 的倍数，说明仅有必要条件还不充分。这里明确范围为 n∈ℤ。

写出逆命题、否命题与逆否命题

p→q 的逆命题为 q→p，否命题为 ¬p→¬q，逆否命题为 ¬q→¬p。原命题与逆否命题等价。¬q 为真且 ¬p 为假，对应 q=F,p=T，正好是原蕴含为假的唯一情况。

逆命题与否命题相互等价，但一般不与原命题等价。“4 的倍数→偶数”的逆命题“偶数→4 的倍数”在 n=6 时为假。否命题“不是 4 的倍数→奇数”在 n=6 时也为假。逆否命题“奇数→不是 4 的倍数”在指定的整数范围中为真。

充要条件与句子翻译

p 是 q 的充要条件，表示 p→q 与 q→p 都成立，写为 p↔q。例如，根据定义，整数 n 为偶数，当且仅当存在整数 k 使 n=2k。

“如果 p，就 q”与“p 要成立，q 是必要的”都是同一方向 p→q。“p 只有在 q 时才成立”也表示 p→q。写出公式后，检查是否禁止“满足 p 但不满足 q”的情况，就能确认方向。实际因果关系不能仅靠这种形式逻辑来判断。

逐步推导的例题

对整数 n，令 p=“n 是 4 的倍数”，q=“n 是偶数”。写出原命题、逆命题、否命题与逆否命题，并解释真伪。

  1. 原命题 p→q：n=4k 时，n=2(2k)，而 2k 是整数，因此为真。
  2. 逆命题 q→p：n=6 是偶数，却不是 4 的倍数，因此为假。
  3. 否命题 ¬p→¬q：n=6 不是 4 的倍数，但也不是奇数，因此为假。
  4. 逆否命题 ¬q→¬p：假设奇数 n 是 4 的倍数，由原命题它应当是偶数，产生矛盾，因此为真。

“4 的倍数”是“偶数”的充分条件，“偶数”是“4 的倍数”的必要条件。两者并不是充要条件。

用纸笔和正文动手试一试

写出“正方形一定是长方形”的逆否命题，再画出逆命题的反例。讨论对象限定为欧氏平面中的非退化四边形。

查看提示

正方形同时要求四个直角与各边等长。长方形要求四个直角。

查看解答

逆否命题：不是长方形，就不是正方形。逆命题“长方形一定是正方形”为假。长 3、宽 2 的长方形有四个直角，但相邻边长不同，是反例。

常见误解与反例

p→q 与 q 都为真，就能得出 p 为真。

n=6 时，“4 的倍数→偶数”为真，q 即“偶数”也为真，但 p 为假。这是肯定后件的错误。可能有其他途径使 q 成立，因此逆向蕴含需要单独论证。

检查理解

在总成立的 p→q 中，q 是 p 的什么条件？

查看答案与理由

必要条件。

p 成立时，q 也必须成立。

p→q 的逆否命题是什么？

查看答案与理由

¬q→¬p。

交换顺序，并同时否定两个条件。

对实数 x，“x>2 就有 x>0”的逆命题为真吗？

查看答案与理由

为假。x=1 是反例。

1>0 为真，但 1>2 为假。

进一步探索

进阶：在论域 U 中，把满足 p 的对象组成集合 P，满足 q 的对象组成集合 Q，则 ∀x∈U,p(x)→q(x) 等价于 P⊆Q。P=Q 时，两条件互为充要条件。以单个元素为线索，解释蕴含方向与集合包含方向为何一致。

小节 1.4

等价变换与反例

把复杂的批准条件简化后，所有情况中的决定还会一样吗？

预备知识与学习目标

预备知识

  • 真值表：每一行最终结果都一致，才是等价。
  • 分配律简短复习：数的运算中 a(b+c)=ab+ac，但逻辑运算需要分别确认自己的定律。
  • 蕴含变换：p→q≡¬p∨q。

学习目标

  • 利用德摩根律、分配律与双重否定推导逻辑公式。
  • 用一个反例反驳等价断言。
  • 区分等价、单向蕴含与事实判断。

等价律对全部赋值成立

¬(p∧q)≡¬p∨¬q、¬(p∨q)≡¬p∧¬q 是德摩根律。否定“两者都真”，需要至少一个为假；否定“至少一个为真”，需要两者都假。¬¬p≡p 是双重否定。

p∧(q∨r)≡(p∧q)∨(p∧r)、p∨(q∧r)≡(p∨q)∧(p∨r) 是分配律。可以把各变量取 T,F，检查八种情况；也可以按 p 的值分两种情况证明。即使形式类似数的乘法与加法，依据仍是 ∨ 与 ∧ 各自的定义。

逐步替换小部分并写明依据

把逻辑公式中的子公式替换为等价公式，会保留整个公式的真值。推导时每一行写明所用定律。(p→q)∧p 可依次变为 (¬p∨q)∧p、(¬p∧p)∨(q∧p)、F∨(q∧p)、p∧q。因此同时要求两个前提，等价于同时要求 p 与 q。

仅凭 p→q 得出 p∧q 是错误的。p=F,q=F 时，蕴含为 T，合取为 F。在推导中删掉起始公式包含的条件，就会改变公式。

反例与受限情形

等价断言要求每一种赋值下都一致。只要有一行不同，就被反驳。p=T,q=F 时，¬(p∧q) 为 T，¬p∧¬q 为 F，所以它们不等价。德摩根律中交换 ∧ 与 ∨ 是必不可少的。

如果一般性等价 A≡B 成立，任何情形中都可以替换。如果只在特定事实假设 H 下相同，需要检查 H→(A↔B) 是否为重言式。逻辑形式的有效性不能替代核实原句是否符合事实。应用到程序条件时，如果存在副作用或求值顺序问题，还需要超出纯命题逻辑的分析。

逐步推导的例题

令批准条件中的 A=“审核通过”，B=“例外已获许可”。简化 ¬(¬A∧¬B)，并核对四种情况。

  1. 由德摩根律，¬(¬A∧¬B)≡¬¬A∨¬¬B。
  2. 由双重否定，得到 A∨B。
  3. (A,B)=(T,T),(T,F),(F,T),(F,F) 时，¬A∧¬B 一列为 F,F,F,T。
  4. 取否定后为 T,T,T,F，与 A∨B 一列一致。

批准条件为 A∨B，即“审核通过”与“例外获许可”中至少一个成立。也允许两者都真。

用纸笔和正文动手试一试

分别考虑 p=T 与 p=F，证明吸收律 p∧(p∨q)≡p，并检查 p∨(p∧q)。

查看提示

p=T 时 p∨q 总为 T；p=F 时，第一个公式最外层的 ∧ 使结果为 F。

查看解答

p=T 时，第一个公式为 T∧T=T=p，第二个为 T∨(T∧q)=T=p。p=F 时，第一个为 F∧(F∨q)=F=p，第二个为 F∨(F∧q)=F=p。这覆盖 q 的两种值，所以两个定律都成立。

常见误解与反例

把 p→q 换成 q→p，含义也一样。

代入 p=T,q=F，得到 p→q=F，却有 q→p=T。原式与逆否式 ¬q→¬p 等价，但逆命题一般不等价。交换熟悉语句的顺序，与使用等价律不是同一回事。

检查理解

¬(p∨q) 的等价式是什么？

查看答案与理由

¬p∧¬q。

没有任何一个为真，就需要两个都假。

(p→q)∧p 的等价式是什么？

查看答案与理由

p∧q。

消去蕴含，使用分配律，再消去矛盾项即可得到。

两个公式在一行不同，还必须检查更多行才能判定不等价吗？

查看答案与理由

这一行就足以判定不等价。

等价要求每一行都一致，所以一次不一致就是足够的反例。

进一步探索

进阶：A≡B 表示 A↔B 是重言式。即使 A→B 是重言式，也不要求逆向 B→A 是重言式。令 A=p∧q,B=p，分情况说明第一个方向总为真，再用 p=T,q=F 说明逆向为假。
