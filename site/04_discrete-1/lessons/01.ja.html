小節 1.1

命題と論理結合子

「雨が降っている、または傘がある」は、両方が真なら偽になるだろうか？

準備する概念と学習目標

準備する概念

  • 真と偽：事実が定まっている文を T または F で表す。
  • 括弧：どの部分を先に組み合わせるかを示す。
  • 短い復習：質問や命令と、事実を主張する文を区別する。

学習目標

  • 命題と、変数の値がまだ定まっていない開いた文を区別する。
  • 否定・論理積・論理和・含意・双条件が真になる条件を説明する。
  • 記号と括弧を使い、日常の言葉の曖昧さを取り除く。

命題は判断の単位

古典命題論理では、命題は真または偽のちょうど一つの真理値を持つ主張である。「7 は奇数である」は真、「7 は偶数である」は偽である。「窓を開けなさい」は命令なので、この意味での命題ではない。

「x>3」は、x を定めるか、x の範囲に対する量化条件を付ける前は開いた文である。x=5 を代入すれば真、x=1 なら偽になる。ある命題の真理値を私たちが知らなくても、それは命題でなくなるわけではない。事実が未確認であることと、変数が未指定で真理値がまだ定まっていないことを区別する。

結合子の意味を正確に定める

p の否定 ¬p は、p が真なら偽、偽なら真である。p∧q は両方が真のときだけ真になる。p∨q は少なくとも一つが真なら真となる包含的な論理和である。ちょうど一つだけ真という条件には、排他的論理和 p⊕q を使う。

p→q は、p が真で q が偽のときだけ偽である。p を満たしながら q に反する場合を禁止する条件である。p↔q は両者の真理値が同じときに真になる。一つの状況で p↔q が真であることと、二つの論理式がすべての状況で同値であることを区別する。

論理的含意と日常の因果

「雨が降っているなら傘がある」を p→q と書くと、p=T,q=F だけが条件への違反である。雨が降っていないときは、傘があってもなくても条件に違反しないため、どちらも真とする。これは雨が傘の原因であるという主張ではない。

自然言語の「または」は、一つだけ選ぶ意味の場合もあるので文脈を確認する。数学では ∨ を包含的に定める。複雑な式は p∧(q∨r) のように括弧を使い、結合する範囲を明示する。括弧のない長い文を、読み手の推測に任せない。

途中の過程をたどる例題

p=「雨が降っている」、q=「傘がある」とし、p=T,q=F の状況を考える。¬p、p∧q、p∨q、p→q、p↔q を評価しよう。

  1. p=T なので ¬p=F。
  2. p∧q は両方が真ではないので F。
  3. p∨q は少なくとも p が真なので T。
  4. p→q は T→F なので F。
  5. p↔q は真理値が異なるので F。

順に F,F,T,F,F。傘についての条件への違反は、p→q が偽となる条件に一致する。

紙と本文で試してみよう

p=T,q=T のとき p∨q と p⊕q を計算し、「二つの機能のうち少なくとも一つを有効にする」と「ちょうど一つを有効にする」に、それぞれどちらの演算が合うか書こう。

ヒントを見る

「少なくとも」は両方を許し、「ちょうど一つ」は両方を除く。

解答を見る

p∨q=T、p⊕q=F。少なくとも一つは ∨、ちょうど一つは ⊕。一つの機能だけが真である T,F または F,T では、どちらも T になる。

よくある誤解と反例

前提が偽なら p→q は偽である。

p=F のとき、p→q は q の値に関係なく真である。例えば「このカードが赤なら番号は偶数である」という規則に、青い奇数のカードは違反しない。前提が偽という事実だけから、結論 q が真だとは推論できない。

理解を確かめる

「今日、宿題をしなさい」は、この単元では命題か？

答えと理由を見る

命題ではない。

命令そのものは真・偽の事実を主張していない。

p=F,q=T なら p∨q と p∧q は？

答えと理由を見る

T と F。

論理和は少なくとも一つが真なら真、論理積は両方が真でなければならない。

p=T,q=T で数学の p∨q は偽か？

答えと理由を見る

真である。

∨ は包含的な論理和で、排他的な選択とは異なる。

もう一歩先へ

発展：ちょうど一つが真という条件は (p∨q)∧¬(p∧q) と書ける。四つの場合を自分で計算し、T,T を除いて T,F と F,T だけが残るか確かめよう。後でブール回路の XOR につながるが、この単元では純粋な真理値だけを扱う。

小節 1.2

真理値表と恒真式

四つの可能な場合をすべて確認すれば、複雑な規則がいつも成立するか分かるだろうか？

準備する概念と学習目標

準備する概念

  • 結合子：¬、∧、∨、→ が真になる条件を知っている。
  • 表の読み方：一行は一つの真理値の割当てを表す。
  • 場合の数の短い復習：各変数には T,F の二つの選択がある。

学習目標

  • 2ⁿ 個の真理値の割当てを漏れなく書く。
  • 恒真式・恒偽式・偶然式を判定する。
  • すべての行の一致から論理的同値を確かめる。

漏れなく場合を列挙する

n 個の命題変数が、それぞれ独立に T,F を取れると仮定すると、割当ては 2ⁿ 個ある。p,q の二変数なら T,T；T,F；F,T；F,F の四行である。三変数なら八行になる。一行を落とすと、その行だけで生じる誤りを見逃す可能性がある。

複合式は括弧の中の小さな部分から計算し、中間列を作る。例えば (p→q)∧p では p→q を計算した後、p と論理積を取る。状況の規則が変数間の関係を制限する場合は、その制限を明示する。純粋な命題論理の確認では、すべての可能な割当てを基本とする。

常に真か、ときどき真か

恒真式はすべての割当てで真になる式、恒偽式はすべての割当てで偽になる式である。p∨¬p は恒真式、p∧¬p は恒偽式である。一部の行で真、他の行で偽になる式を偶然式と呼ぶ。ここで「偶然」は無作為という意味ではない。

変数 p 自体は二つの真理値を取れるため偶然式である。具体的な事実「2+2=4」が真であることと、変数の式が論理形式だけで常に真であることは異なる。恒真性は、個別の観測よりも強い、すべての真理値の割当てに関する条件である。

同じ結果の列と論証

二つの式 A,B がすべての割当てで同じ真理値を持つとき、論理的に同値であり A≡B と書く。これは A↔B が恒真式であることと同じである。特定の行で結果が同じというだけでは、同値とは結論できない。

((p→q)∧p)→q が恒真式なら、「p→q と p がともに真の場合、q も真」という推論を保証する。前提の一つが偽の行は、その推論への反例ではない。これにより、前提が真と仮定した論証の妥当性と、個別の結論が実際に真であることを区別できる。

途中の過程をたどる例題

((p→q)∧p)→q の真理値表を作り、恒真式か判定しよう。

  1. 行の順序を (p,q)=(T,T),(T,F),(F,T),(F,F) とする。
  2. p→q の列は T,F,T,T。
  3. (p→q)∧p の列は T,F,F,F。
  4. 最後の含意の列は T→T、F→F、F→T、F→F なので T,T,T,T になる。

すべての行が T なので恒真式である。前件肯定（modus ponens）の形式を確認した。

紙と本文で試してみよう

p→q と ¬p∨q の四行の結果を並べて書き、同値か判定しよう。

ヒントを見る

まず ¬p を求める。示した行順で、両方の出力列が T,F,T,T になるか確かめる。

解答を見る

p→q は T,F,T,T。¬p の列 F,F,T,T と q の論理和を取ると T,F,T,T。四行とも同じなので p→q≡¬p∨q である。

よくある誤解と反例

多くの例で真なら恒真式である。

p∨q は T,T；T,F；F,T の三行では真だが、F,F では偽なので偶然式である。すべての行を確認するか、すべての場合を覆う同値変形が必要であり、表の一部だけでは十分ではない。

理解を確かめる

命題変数が三つの真理値表は何行か？

答えと理由を見る

8。

各変数に二つの選択があるので 2³ になる。

p∧¬p はどの分類か？

答えと理由を見る

恒偽式。

p が T なら ¬p が F、p が F なら p 自体が F なので、論理積は常に F。

A と B が一行で同じなら論理的に同値か？

答えと理由を見る

それだけでは分からない。

同値にはすべての可能な割当てで結果が一致する必要がある。

もう一歩先へ

小節 1.3

必要条件・十分条件

「正方形なら長方形である」では、どの条件が必要で、どの条件が十分だろうか？

準備する概念と学習目標

準備する概念

  • 含意：p→q は p=T,q=F のときだけ偽になる。
  • 集合の包含：A⊆B は A のすべての要素が B にも属することを意味する。
  • 反例：一般的な主張を破る一つの具体例を探す。

学習目標

  • 常に成り立つ p→q で、p が q の十分条件、q が p の必要条件だと説明する。
  • 逆・裏・対偶を区別し、対偶との同値を確認する。
  • 必要条件を十分条件として誤用する推論に反例を挙げる。

十分なら保証でき、必要なら欠かせない

p→q が常に成り立つとき、p は q の十分条件である。p を確保すれば q が保証されるという意味である。同じ関係で、q は p の必要条件である。p が成り立つためには q が欠かせないという意味であり、q だけで p が保証されるわけではない。

n が 4 の倍数なら偶数である。「4 の倍数」は「偶数」であるために十分で、「偶数」は「4 の倍数」であるために必要である。6 は偶数だが 4 の倍数ではないので、必要条件だけでは十分でない。ここでは範囲を n∈ℤ と明示する。

逆・裏・対偶を書いてみる

p→q の逆は q→p、裏は ¬p→¬q、対偶は ¬q→¬p である。元の命題と対偶は同値である。¬q が真で ¬p が偽の場合は q=F,p=T であり、元の含意が偽になる唯一の場合と同じだからである。

逆と裏は互いに同値だが、一般には元の命題と同値ではない。「4 の倍数→偶数」の逆「偶数→4 の倍数」は n=6 で偽である。裏の「4 の倍数でない→奇数」も n=6 で偽である。対偶「奇数→4 の倍数でない」は、指定した整数の範囲で真である。

必要十分と文の翻訳

p が q の必要十分条件とは、p→q と q→p がともに成り立つことであり、p↔q と表す。例えば整数 n が偶数であることと、n=2k となる整数 k が存在することは、定義により必要十分である。

「p なら q」と「p のためには q が必要」は同じ方向の p→q である。「p は q のときだけ成り立つ」も p→q である。文を書いた後、p を満たすのに q を満たさない例が禁止されるか確認すると、方向を検査できる。実際の因果関係は、この形式的論理だけで判断できない。

途中の過程をたどる例題

整数 n に対して p=「n は 4 の倍数」、q=「n は偶数」とする。元の命題・逆・裏・対偶と、それぞれの真偽を説明しよう。

  1. 元の命題 p→q：n=4k なら n=2(2k) で、2k は整数なので真。
  2. 逆 q→p：n=6 は偶数だが 4 の倍数ではないので偽。
  3. 裏 ¬p→¬q：n=6 は 4 の倍数ではないが奇数でもないので偽。
  4. 対偶 ¬q→¬p：奇数 n が 4 の倍数だと仮定すると、元の命題から偶数になるため矛盾する。したがって真。

4 の倍数であることは偶数であるための十分条件、偶数であることは 4 の倍数であるための必要条件である。両者は必要十分ではない。

紙と本文で試してみよう

「正方形なら長方形である」の対偶を書き、逆の反例を図にしよう。対象はユークリッド平面の退化していない四角形とする。

ヒントを見る

正方形は四つの直角と等しい辺の長さを両方要求する。長方形は四つの直角を要求する。

解答を見る

対偶：長方形でなければ正方形ではない。逆の「長方形なら正方形である」は偽。横 3、縦 2 の長方形は四つの直角を持つが隣り合う辺の長さが異なり、反例になる。

よくある誤解と反例

p→q と q が真なら p も真である。

n=6 では「4 の倍数→偶数」が真で、偶数という q も真だが、p は偽である。これは後件肯定の誤りである。q を成立させる別の経路があり得るため、逆向きの含意には別の根拠が必要である。

理解を確かめる

常に成り立つ p→q で、q は p のどの条件か？

答えと理由を見る

必要条件。

p が成り立てば q も必ず成り立たなければならない。

p→q の対偶は？

答えと理由を見る

¬q→¬p。

順序を入れ替え、両方の条件を否定する。

実数 x について「x>2 なら x>0」の逆は真か？

答えと理由を見る

偽である。x=1 が反例。

1>0 は真だが 1>2 は偽である。

もう一歩先へ

発展：全体集合 U で p を満たす集合を P、q を満たす集合を Q とすると、∀x∈U,p(x)→q(x) は P⊆Q と同じである。P=Q なら必要十分となる。一つの要素を基準に、含意と集合の包含の方向が同じ理由を説明しよう。

小節 1.4

同値変形と反例

複雑な承認条件を短くしても、すべての場合で同じ判断になるだろうか？

準備する概念と学習目標

準備する概念

  • 真理値表：すべての行の最終結果が一致すれば同値である。
  • 分配法則の短い復習：数では a(b+c)=ab+ac だが、論理演算はそれぞれの法則を確かめる。
  • 含意の変換：p→q≡¬p∨q。

学習目標

  • ド・モルガンの法則・分配法則・二重否定で論理式を導く。
  • 一つの反例で同値の主張を反駁する。
  • 同値、一方向の含意、事実の判断を区別する。

同値の法則はすべての割当てで成立する

¬(p∧q)≡¬p∨¬q、¬(p∨q)≡¬p∧¬q がド・モルガンの法則である。両方が真であることを否定するには、少なくとも一つが偽でなければならない。一つ以上が真であることを否定するには、両方が偽でなければならない。¬¬p≡p は二重否定である。

p∧(q∨r)≡(p∧q)∨(p∧r)、p∨(q∧r)≡(p∨q)∧(p∨r) は分配法則である。各変数に T,F を割り当てて八つの場合を確認するか、p の値で二つの場合に分けて示せる。数の乗法・加法に似ていても、根拠は ∨ と ∧ それぞれの定義である。

小さい部分を変え、根拠を書く

論理式の中の部分式を同値な式に置き換えると、全体の真理値も保たれる。各行に使った法則を書いて導く。(p→q)∧p は (¬p∨q)∧p、(¬p∧p)∨(q∧p)、F∨(q∧p)、p∧q と変形できる。したがって、二つの前提を同時に要求することは、p と q を同時に要求することと同じである。

p→q だけから p∧q を得るのは誤りである。p=F,q=F なら含意は T だが論理積は F になる。出発した式に含まれる仮定を途中で消せば、別の式になる。

反例と限定された状況

同値の主張はすべての割当てで一致するという主張である。一行でも異なれば反駁できる。p=T,q=F では ¬(p∧q) と ¬p∧¬q が T と F になるので同値ではない。ド・モルガンの法則で ∧ と ∨ を交換することは必須である。

一般的な同値 A≡B があれば、どの状況でも置換できる。特定の事実の仮定 H の下だけで一致するなら、H→(A↔B) が恒真式か確認する必要がある。論理形式の妥当性は、元の文が実際の事実であることの確認を代わりにはしない。プログラムの条件に使う場合も、副作用や評価順序があれば、純粋な命題論理とは別の検討が必要である。

途中の過程をたどる例題

承認条件の A=「審査に合格」、B=「例外が許可された」として、¬(¬A∧¬B) を簡単に変形し、四つの場合を確認しよう。

  1. ド・モルガンの法則から ¬(¬A∧¬B)≡¬¬A∨¬¬B。
  2. 二重否定から A∨B。
  3. (A,B)=(T,T),(T,F),(F,T),(F,F) で ¬A∧¬B の列は F,F,F,T。
  4. その否定は T,T,T,F であり、A∨B の列と同じ。

承認は A∨B、つまり審査合格または例外許可の少なくとも一つが成立すればよい。両方が真でも許される。

紙と本文で試してみよう

吸収法則 p∧(p∨q)≡p を p=T と p=F に分けて証明し、p∨(p∧q) も確認しよう。

ヒントを見る

p=T なら p∨q は常に T、p=F なら最も外側の ∧ で最初の式は F になる。

解答を見る

p=T のとき、最初の式は T∧T=T=p、二番目は T∨(T∧q)=T=p。p=F のとき、最初は F∧(F∨q)=F=p、二番目は F∨(F∧q)=F=p。q の両方の値を含むため、二つの法則が成り立つ。

よくある誤解と反例

p→q を q→p に変えても意味は同じである。

p=T,q=F を入れると p→q=F だが q→p=T である。元の式と対偶 ¬q→¬p は同値だが、逆は一般には同値でない。慣れた言葉の順序を入れ替えることと、同値の法則を使うことは違う。

理解を確かめる

¬(p∨q) の同値な式は？

答えと理由を見る

¬p∧¬q。

どちらも真でないためには、両方が偽でなければならない。

(p→q)∧p の同値な式は？

答えと理由を見る

p∧q。

含意の除去、分配、恒偽の項の除去によって得られる。

二つの式が一行で異なる場合、非同値を結論するにはさらに行の確認が必要か？

答えと理由を見る

その一行で非同値を結論できる。

同値には全行での一致が必要なので、一つの不一致が十分な反例になる。

もう一歩先へ

発展：A≡B は A↔B が恒真式であることを意味する。A→B が恒真式でも、逆の B→A が恒真式とは限らない。A=p∧q、B=p とし、最初の方向が常に真と場合分けで示し、逆が p=T,q=F で偽になることを示そう。
