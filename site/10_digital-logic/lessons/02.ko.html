소단원 2.1

기본 게이트와 진리표

둘 중 하나라도 눌리면 켜지는 장치와 정확히 하나만 눌려야 켜지는 장치는 어떻게 다를까?

준비 개념과 학습 목표

준비 개념

  • 부울 값: 0과 1 두 추상값이며 여기서는 입력이 이 둘 중 하나라고 가정한다.

  • 함수: 입력 조합마다 출력 하나를 정하는 규칙이다.

  • 표: 모든 입력 조합을 빠짐없이 한 번씩 적어 비교한다.

학습 목표

  • AND·OR·NOT·XOR·NAND·NOR의 출력을 계산한다.

  • 진리표가 전체 입력에 대한 기능 명세임을 설명한다.

  • 논리값과 물리 신호·전파 시간을 구분한다.

세 입력의 XOR는 정확히 한 명의 요청만 승인할까?

세 요청 A, B, C 중 정확히 하나가 1일 때만 승인하는 자체 기능 E를 설계한다. 입력은 모두 안정된 유효 부울 값이며 동시 요청도 허용한다. 일반 정수로 센 요청 수 A+B+C가 1인지 검사한다는 말과, 부울 식의 + 기호를 구별하자. 여기서 부울 +는 포함 OR다.

E=A′B′C+A′BC′+AB′C′는 정확히 한 요청이 켜진 세 행을 고른다. 세 입력의 XOR인 P=(A⊕B)⊕C는 1의 개수가 홀수이면 켜진다. 따라서 세 요청이 모두 켜진 111에서는 P가 1이지만 E는 0이다. 두 입력에서 맞았던 배타적 해석을 세 입력으로 그대로 옮기면 요구가 바뀐다.

먼저 확인할 개념
  • 코드의 구별 조건

    허용되는 입력과 의미를 먼저 명세한다.

  • 안정된 논리의 범위

    전압과 변화 중의 미정 신호를 부울 입력으로 몰래 확장하지 않는다.

기호와 기본 규칙

부울 함수 f:{0,1}ⁿ→{0,1}는 n개의 입력으로 출력 하나를 정한다. 이 단원에서 AB는 AND, A+B는 포함 OR, A′는 NOT이다. 곱과 합 기호를 쓰지만 일반 정수 산술과 다르므로 1+1=1이다. 괄호와 보수 범위를 명시한다.

AND는 둘 다 1일 때, OR는 적어도 하나가 1일 때 1이다. NOT은 0/1을 뒤집는다. XOR A⊕B는 두 값이 다를 때 1이다. NAND=(AB)′, NOR=(A+B)′로 정의한다. 입력이 1인 개수에 따른 동작을 말로 확인하고 표로 고정한다.

진리표를 빠짐없이 만들기

두 입력의 순서를 AB=00,01,10,11로 고정하자. AND 출력은 0,0,0,1; OR는 0,1,1,1; XOR는 0,1,1,0; NAND는 1,1,1,0; NOR는 1,0,0,0이다. NOT은 입력 0→1,1→0이다. 모든 행을 보면 11에서 OR와 XOR가 다름을 바로 확인한다.

각 입력이 다른 입력의 제약 없이 0 또는 1을 자유롭게 가질 수 있는 n입력의 조합은 2ⁿ개다. 여기서 자유로운 입력 조합은 확률적 독립이라는 뜻이 아니다. 세 입력이면 000부터 111까지 여덟 행을 쓴다. 행 순서를 바꿔도 함수는 같지만 비교할 때는 같은 입력끼리 정렬해야 한다. 실제로 불가능한 입력 조합을 제외하려면 그 제약을 명세해야 하며 임의로 행을 지우지 않는다.

게이트라는 구현 층

게이트는 이런 논리 연산을 구현하는 부품이나 회로 블록의 추상화다. 여기서는 안정된 유효 입력이 주어진 뒤 출력이 안정된 때의 기능을 다룬다. 진리표에는 실제 전압, 팬아웃, 전파 지연, 전원 조건이 들어 있지 않다.

전압이 미정 구간이거나 변하는 동안에는 즉시 0/1 기능 표만 적용해 실제 파형을 보장할 수 없다. 시뮬레이터의 X나 Z도 이 두 값의 부울 함수와 같은 입력 집합이 아니다. 이번 활동은 종이 논리 계산이며 FPGA나 게이트 회로 실행이 아니다.

중간 과정을 따라가는 예제

가상 알림 F=(A+B)C에서 A는 버튼1, B는 버튼2, C는 허용 신호다. 입력은 안정된 부울 값이다. ABC=000부터 111까지 F의 진리표를 만든다.

  1. C=0인 000,010,100,110에서는 마지막 AND 때문에 모두 0이다.

  2. C=1인 001에서는 A+B=0이므로 0이다.

  3. 011,101,111에서는 C=1이고 A+B=1이므로 1이다.

  4. 입력 000,001,010,011,100,101,110,111의 출력은 0,0,0,1,0,1,0,1이다.

허용 신호가 있고 적어도 한 버튼이 눌린 세 행에서만 1이다.

세 요청이 함께 들어온 경우

ABC=111에서 E와 P 및 포함 OR의 값을 비교하라.

  1. E의 세 곱항에는 각각 두 보수가 있어 모두 0이다.

  2. P는 1⊕1=0 뒤 0⊕1=1이다.

  3. 포함 OR인 A+B+C도 1이다.

소단원 2.2

부울 항등식·쌍대성

계산식을 줄이면서 모든 입력의 답을 그대로 유지할 수 있을까?

준비 개념과 학습 목표

준비 개념

  • 부울 연산: +는 OR, 곱은 AND, ′는 NOT이며 1+1=1이다.

  • 항등식: 허용 입력의 모든 조합에서 양쪽 값이 같은 등식이다.

  • 보수: A′는 A와 반대이며 (A′)′=A다.

학습 목표

  • 항등·멱등·보수·흡수·분배 법칙을 적용한다.

  • 쌍대와 함수의 보수를 구분한다.

  • 축약의 모든 입력 보존 근거를 제시한다.

괄호 전체의 쌍대와 출력의 보수를 바꾸면 같은 식이 될까?

자체 식 F=(A+B′)C를 비교한다. 쌍대 D는 OR와 AND를 교환하되 변수와 변수의 보수는 유지하므로 D=AB′+C다. 출력 보수 H는 F 전체를 뒤집으므로 H=(A′B)+C′다. 변수 B′ 하나를 보고 둘을 같은 절차라고 생각하면 틀린다.

쌍대는 식의 괄호 구조를 보존한 문장 변환이다. 항등식의 쌍대도 항등식이지만 한 함수의 쌍대가 그 함수나 보수와 같은 것은 아니다. 보수에서는 드모르간을 각 괄호에 적용하고 변수까지 뒤집는다. F와 H는 모든 행에서 반대여야 하며 D에는 그 요구가 없다.

  • 전체 진리표의 비교

    반례가 전칭 등가를 깨는 방식을 사용한다.

  • 같은 패턴과 다른 규약

    출력 반전과 문장 변환의 의미를 각각 고정한다.

항등식의 근거

부울 항등은 A+0=A,A·1=A, A+1=1,A·0=0이다. 멱등은 A+A=A,AA=A이고 보수는 A+A′=1,AA′=0이다. 교환·결합 법칙으로 항을 재배열할 수 있다. 이것은 0/1에 대한 등식이며 정수 산술의 A+A=2A를 가져오지 않는다.

흡수 A+AB=A는 A=0이면 양쪽 0, A=1이면 양쪽 1이므로 성립한다. 분배 A(B+C)=AB+AC뿐 아니라 A+BC=(A+B)(A+C)도 성립한다. 뒤 식은 A=1이면 양쪽 1, A=0이면 양쪽 BC가 된다는 경우 분할로 증명할 수 있다.

쌍대는 문장의 변환

쌍대는 식 전체에서 +와 곱, 0과 1을 서로 교환하고 변수와 보수는 그대로 두는 변환이다. A+0=A의 쌍대는 A·1=A다. 부울대수의 공리 체계가 이 교환에 대칭이므로 항등식에서 얻은 쌍대도 항등식이다. 적절한 괄호 구조를 유지한다.

쌍대가 원래 함수와 항상 같은 것은 아니다. A+B의 쌍대 AB는 입력 01에서 1과 0으로 다르다. 또한 쌍대와 보수도 다르다. 보수는 출력 자체를 뒤집는 (A+B)′이며 드모르간으로 A′B′가 된다. 변수를 그대로 두는 AB와 혼동하지 않는다.

보수 범위를 유지하며 축약

드모르간 법칙 (A+B)′=A′B′, (AB)′=A′+B′는 연산을 바꾸며 각 입력에도 반전을 적용한다. 전체 보수를 각 변수에만 붙이고 원래 연산을 남기는 방식은 틀리다. AB=01에서 (A+B)′=0이지만 A′+B′=1이다.

식 축약은 중간 등식을 한 줄씩 쓰고 적용한 법칙을 적는다. 한 입력의 대입만 맞는 것은 항등식의 증명이 아니다. 작은 식은 모든 2ⁿ개 조합을 대조하면 완전한 기능 등가 증명이 된다. 시간 지연이나 전력까지 같다는 결론은 이 증명에 포함되지 않는다.

소단원 2.3

합의 곱·곱의 합

출력이 1인 행을 모으는 방법과 0인 행을 배제하는 방법이 같은 함수를 만들까?

준비 개념과 학습 목표

준비 개념

  • 리터럴: 변수 A 또는 그 보수 A′ 하나다.

  • 곱/합: 이 단원에서는 AND/OR이며 일반 수의 곱셈/덧셈이 아니다.

  • 입력 순서: ABC를 이진 정수 4A+2B+C로 색인한다.

학습 목표

  • 최소항과 최대항의 행 선택 원리를 설명한다.

  • 진리표로 정규 SOP/POS를 구성한다.

  • 정규 표현과 최소 표현의 차이를 구분한다.

입력 순서만 바꾸면 최소항의 번호를 그대로 써도 될까?

새 함수 J는 ABC 순서의 000, 010, 101, 111에서만 1이다. 색인은 4A+2B+C로 정하므로 J=Σm(0,2,5,7)이다. 정규식의 네 항을 B의 두 값으로 묶으면 J=A′C′+AC가 되어 A와 C가 같을 때만 1이다. B는 모든 값에서 영향이 없다.

같은 물리 입력에 CAB 순서로 이름을 쓰면 색인 가중치는 4C+2A+B다. 기존 네 행은 CAB=000, 001, 110, 111이므로 새 번호는 0,1,6,7이다. 함수가 바뀐 것이 아니라 표 좌표가 바뀐 것이다. 새 순서에 옛 번호를 복사하면 다른 함수를 선택한다.

먼저 확인할 개념
  • 입력과 출력의 전체 표

    출력 1행과 0행을 별도 모은다.

  • 보수와 묶음 항등식

    B+B′=1로 두 최소항의 공통 부분을 남긴다.

1행을 고르는 최소항

곱의 합 SOP는 여러 리터럴 곱을 OR로 합친 표현이다. 정규 SOP에서는 각 곱에 모든 입력 변수가 한 번씩 나타난다. 입력 101만 1로 만드는 최소항은 AB′C다. 1인 자리는 그대로, 0인 자리는 보수로 넣어 모든 리터럴이 그 행에서만 1이 되도록 한다.

출력 1인 모든 행의 최소항을 합치면 그 행들만 출력 1이 된다. 따라서 전수 입력을 정의한 부울 함수는 정규 SOP로 표현할 수 있다. 아무 행도 1이 아니면 빈 OR를 0으로 정한다. 정규식이 반드시 게이트 수가 가장 작은 식은 아니다.

0행을 배제하는 최대항

합의 곱 POS는 여러 리터럴 합을 AND로 곱한 표현이다. 정규 POS에서는 각 합에 모든 변수가 한 번씩 나타난다. 입력 101에서만 0이 되는 최대항은 A′+B+C′다. 각 리터럴을 그 행에서 0이 되게 하므로 SOP와 보수 선택이 반대다.

출력 0인 행의 최대항을 모두 곱하면 해당 행에서는 그중 하나가 0이고, 나머지 모든 행에서는 모두 1이다. 그래서 같은 진리표를 얻는다. 0행이 없으면 빈 AND를 1로 정한다. 최대항과 최소항은 식 길이의 크고 작음이 아니라 한 행을 고르는 역할의 용어다.

논리식과 회로 변환

식이 같은 두 회로는 부품과 응답 시간까지 같을까?

준비 개념과 학습 목표

준비 개념

  • 조합 회로: 여기서는 피드백 없는 유한 게이트 연결이며 안정 출력은 현재 입력의 함수다.

  • 중간 신호: 게이트마다 출력 이름을 붙여 연결 순서대로 계산한다.

  • 기능 등가: 모든 유효 안정 입력에서 두 회로의 최종 출력이 같다.

학습 목표

  • 식에서 게이트 연결을 만들고 회로에서 식을 복원한다.

  • NAND만으로 AND·OR·NOT를 구성한다.

  • 기능 등가와 지연/전압/글리치 검증의 차이를 설명한다.

선택 신호를 반전하는 게이트도 연결 수와 시간에 포함했을까?

새 두 입력 선택 기능 M=S′A+SB는 S=0이면 A, S=1이면 B를 출력한다. 허용 부품을 2입력 NAND로만 제한하면 nS=NAND(S,S), u=NAND(nS,A), v=NAND(S,B), M=NAND(u,v)로 구성한다. nS를 무료 신호로 세지 않으며 총 네 게이트다.

기능 증명은 안정 입력의 두 선택 경우 또는 여덟 행 비교다. 별도의 가상 시간 모형에서 모든 NAND의 전파 상한을 2 ns라고 두면 S의 반전 경로는 세 단계로 6 ns, A와 B의 경로는 두 단계로 4 ns다. 이는 안정된 입력과 유효 부하를 가정한 보수적 상한이며 실제 측정이나 최솟값은 아니다. S가 변할 때 두 데이터가 같아도 중간 출력의 흔들림이 배제되지는 않는다.

먼저 확인할 개념
  • 드모르간과 출력 반전

    두 반전 곱항의 마지막 NAND로 원래 OR를 만든다.

  • 안정 시각과 직렬 상한

    가장 긴 경로를 세고 상한 전에 논리값을 단정하지 않는다.

식과 유향 연결

F=(A+B)C를 만들려면 OR 출력 u=A+B를 만들고 AND(u,C)를 연결한다. 회로에서 식을 읽을 때도 각 중간 신호를 정의하고 출력부터 대입한다. 같은 이름의 신호를 공유하는 팬아웃과 게이트 출력을 서로 직접 연결하는 일은 다르므로 연결 규칙을 명시한다.

여기서는 순환이 없는 회로를 앞에서 뒤로 계산한다. 출력이 자기 입력으로 돌아오는 피드백은 상태나 안정성 문제를 만들어 이 조합 모형으로 다루지 않는다. 실제 부품은 허용 팬아웃·전원·입력 범위 조건이 필요하나 종이 기능 변환에서는 추상 게이트로 한정한다.

반전을 이용한 NAND 변환

NAND(A,B)=(AB)′다. 두 입력을 A로 묶으면 NAND(A,A)=A′라 NOT을 만들 수 있다. AND는 NAND 결과를 다시 자기 자신과 NAND하여 이중 반전을 취하면 AB다. OR는 NAND(A′,B′)=(A′B′)′=A+B다.

따라서 AND·OR·NOT로 표현된 유한 부울 식을 NAND 회로로 치환할 수 있다. 이는 임의의 부울 기능을 만들 수 있다는 범용성이지 단일 NAND가 모든 함수를 계산한다는 뜻은 아니다. 연결 수·깊이·입력 공유에 따라 필요한 부품 수가 달라진다.

기능과 물리 시간은 다른 증거

F=AB+AC와 G=A(B+C)는 부울 분배법칙으로 같다. 모두 2입력 게이트만 허용하고 공유·보수 게이트 없이 세면 F는 AND 두 개와 OR 한 개, G는 OR 한 개와 AND 한 개다. 이 추상 게이트 수는 트랜지스터 수·면적·전력의 실측과 다르다.

입력이 변하면 각 경로의 전파 지연이 달라 잠깐 다른 출력이 나타날 수 있다. 같은 진리표는 안정 출력의 기능 등가를 증명할 뿐 전파 시간과 glitch의 동일성을 증명하지 않는다. 실제 지연값·부하·배선·소자 모델 없이 더 빠르다고 결론내리지 않는다.

힌트 1

풀이와 답 확인

한 단계 더

심화: 논리적으로 F=A′B+AC에 중복 항 BC를 더해도 합의 정리로 값은 같다. B=C=1을 안정되게 유지하고 A만 한 번 변화한다고 하자. 변화 전에 회로와 BC 경로의 출력이 이미 안정됐다는 조건에서, 기존 두 경로의 역할이 바뀌며 출력이 잠깐 흔들릴 수 있다. BC 경로는 이 변화 동안 1을 유지하므로 안정된 제어 입력이 출력을 유지하는 게이트 모형에서는 이 특정 static-1 hazard를 막는 데 도움을 준다. 이는 임의의 여러 입력 동시 변화나 실제 모든 glitch 제거의 인증은 아니며 지연·부하·전압 조건은 별도 확인 대상이다.

다른 문제에 적용하기

세 요청 ABC와 선택 입력 S가 모두 자유로운 안정 부울 값이다. S=0이면 정확히 하나의 요청인 E를, S=1이면 A와 C의 같음 함수 J를 출력하는 Y를 설계하라. E와 홀수 패리티의 차이를 밝히고 J의 ABC 및 CAB 최소항 번호를 적어라. Y의 선택식을 쓰고 입력 순서 SABC에서 출력 1인 번호를 전부 구하라. E와 J가 유효하게 계산되어 외부 입력으로 주어지는 선택 단계만 네 NAND로 구성한다. 그 단계의 상한이 각각 2 ns이고 S, E, J가 5 ns부터 안정된다면 출력 보장 시각을 구하라. E와 J 계산 시간을 이미 포함했다고 주장하지 않는다. 실제 회로·학생 수행은 미수행이다.

힌트 1

E의 1행은 001, 010, 100이며 J의 1행은 000, 010, 101, 111이다. S를 최고 비트로 둔다.

힌트 2

선택 단계에서는 A와 B 자리에 E와 J를 넣는다. 반전 경로의 세 게이트를 포함하며 앞단 계산의 종료 시각은 별도다.

풀이와 답 확인

  1. E는 111에서 0이고 홀수 패리티는 1이다. J의 ABC 번호는 0,2,5,7이며 CAB 번호는 0,1,6,7이다.

  2. Y=S′E+SJ다. S=0일 때 SABC 번호 1,2,4가 1이다. S=1일 때 번호 8,10,13,15가 1이다.

  3. 전체 1행 번호는 1,2,4,8,10,13,15이며 나머지 아홉 행은 0이다.

  4. nS=NAND(S,S), u=NAND(nS,E), v=NAND(S,J), Y=NAND(u,v)로 네 게이트다.

  5. 선택 단계의 긴 경로 상한은 6 ns다. 세 입력이 5 ns부터 안정되어 유지되면 11 ns부터 보장한다. E와 J의 계산 지연을 별도 합산하려면 해당 명세가 추가로 필요하다.

정확히 하나와 패리티는 111에서 다르다. J의 좌표별 번호는 ABC에서 0,2,5,7, CAB에서 0,1,6,7이다. Y의 일곱 1행 번호는 1,2,4,8,10,13,15다. 네 NAND 선택 단계는 주어진 안정 조건 아래 11 ns부터 보장하며 전체 앞단 회로의 측정 결과는 아니다.
