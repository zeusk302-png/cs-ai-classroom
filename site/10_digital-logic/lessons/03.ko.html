소단원 3.1

Karnaugh map

진리표의 줄을 바꾸면 없앨 수 있는 입력이 더 잘 보일까?

준비 개념과 학습 목표

준비 개념

  • 불 값은 0 또는 1이다. AB 는 AND, A+B 는 OR, ¬A 는 NOT 을 뜻하며 보통 정수 곱셈/덧셈과 달리 1+1=1이다.

  • 리터럴은 A 또는 ¬A 처럼 변수 하나의 조건이다. minterm 은 모든 입력을 하나씩 포함해 특정 진리표 행 하나에서만 1인 곱 항이다.

  • 세 입력 ABC 의 행 번호는 m=4A+2B+C 다. Gray 순서 00,01,11,10에서는 이웃한 번호가 한 비트만 다르다.

학습 목표

  • Gray 배열에서 인접 셀을 찾는다.

  • 묶음에서 변하는 변수를 제거한다.

  • 최소라는 말에 비용 기준을 붙인다.

네 모서리와 가운데 묶음이 겹치면 두 번 켜진 출력이 될까?

네 입력 ABCD의 자체 함수 F는 행 번호 m=8A+4B+2C+D 중 {0,2,3,6,7,8,10}에서만 1이다. 행 AB와 열 CD를 각각 00,01,11,10 순서로 놓는다. 맨 위와 아래 행, 맨 왼쪽과 오른쪽 열도 인접하며 두 방향의 경계를 함께 감을 수 있다. 이 표는 안정된 부울 입력의 전체 함수다.

네 모서리 {0,2,8,10}는 B=0, D=0만 고정되어 B′D′다. 위쪽 두 행의 오른쪽 두 열 {2,3,6,7}는 A=0, C=1만 고정되어 A′C다. 두 묶음이 행 2에서 겹쳐도 OR는 1+1=1이므로 F=B′D′+A′C다. 중복 덮기는 허용되지만 지정 0을 덮는 것은 허용되지 않는다.

먼저 확인할 개념

    행 번호와 고정 입력의 곱항을 먼저 연결한다.

  • 부울 합과 일반 덧셈

    겹친 셀에서 OR의 멱등성을 사용한다.

진리표를 다시 놓기

Karnaugh map 은 진리표의 값을 Gray 순서의 격자에 배치한다. 여기서는 행 A=0,1, 열 BC=00,01,11,10으로 고정한다. 좌우 끝 열도 인접하므로 00과 10은 B 만 다르다. 셀 위치를 바꿔 보일 뿐 함수값을 변경하는 작업은 아니다.

SOP, 즉 곱의 합에서는 1인 셀들을 1,2,4,…개의 직사각형 묶음으로 덮는다. 가로와 세로 크기는 각각 2의 거듭제곱이어야 하며 경계 감기도 허용한다. 대각선 두 셀이나 길이 3인 줄은 한 리터럴 제거 묶음이 아니다. 묶음은 겹쳐도 된다.

변하는 조건을 지우는 근거

같은 조건 P 에 대해 PB+P¬B=P(B+¬B)=P 다. 묶음에서 B 가 0과 1 모두를 취하면 B 를 검사할 필요가 없다는 뜻이다. k 변수가 독립적으로 모두 바뀌는 2^k 개 셀은 나머지 고정 변수의 곱으로 표현한다. 0셀까지 덮으면 반드시 1이어야 하지 않는 행을 1로 바꿔 함수가 달라진다.

prime implicant 는 더 큰 허용 묶음에 포함되지 않는 묶음이다. 모든 prime 을 선택할 필요는 없으며 전체 1셀을 덮는 항을 골라야 한다. 여기서는 두 단계 SOP 의 항 수를 우선, 같은 항 수면 리터럴 수를 비교하는 비용 기준을 정한다. 이는 모든 gate library 에서 가장 작은 물리 회로를 찾는 기준은 아니다.

네 모서리를 함께 보기

1행 번호가 0,2,4,6인 함수를 위 배치에 쓰면 두 행 모두 열 순서대로 1,0,0,1이다. 양 끝 열과 두 행의 네 셀을 감아 묶으면 A 와 B 는 모두 바뀌고 C=0만 고정된다. 따라서 F=¬C 다. 격자의 네 모서리를 종이에서 멀다고 제외하면 더 큰 묶음을 놓친다.

최소화 주장은 직접 확인할 수 있다. 이 함수는 0과 1을 모두 출력하므로 상수식은 불가능하고 적어도 하나의 리터럴이 필요하다. ¬C 한 리터럴이 정확히 함수를 표현하므로 지정한 SOP 비용에서 최소다. 일반 복잡한 표에서 눈에 띄는 큰 묶음만 선택했다고 전역 최소가 증명되는 것은 아니다.

중간 과정을 따라가는 예제

F 의 1행은 {0,2,4,6},나머지는 0이다. 행 A,열 BC=00,01,11,10 map 에서 최소 SOP 를 구한다.

  1. 행 번호 0,1,3,2와 4,5,7,6을 각 셀에 대응한다.

  2. 두 행의 출력은 각각 1,0,0,1이다. 좌우 경계는 Gray 인접이다.

  3. 네 모서리 2×2 감기 묶음에서 A,B 는 변하고 C=0은 고정이므로 항은 ¬C 다.

  4. 모든 1을 덮고 0을 덮지 않는다. 비상수 함수라 0리터럴은 불가능하므로 1리터럴의 ¬C 가 최소다.

F=¬C 이며 여덟 입력 모두 원래 표와 같다.

조건을 바꾸어 비교하기

겹친 두 묶음의 전수 범위

F=B′D′+A′C가 정확히 지정 일곱 행을 켜는 이유를 설명하라.

  1. B′D′는 A와 C가 자유라 0,2,8,10을 켠다.

  2. A′C는 B와 D가 자유라 2,3,6,7을 켠다.

  3. OR의 행 집합은 두 모음의 합집합이며 2는 한 번만 센다.

전체 1행은 {0,2,3,6,7,8,10}으로 일곱 개다.

비교할 점

겹친 한 행을 일반 덧셈으로 2라고 표시하지 않는다.

작다는 말에 하한을 붙인다

항 수 우선, 같은 항 수에서 리터럴 수를 비교하는 두 단계 SOP 기준으로 이 식의 최소성을 보이라.

  1. m0와 m7을 한 곱항으로 함께 덮으려면 다른 B,C,D를 모두 지워 A′가 필요하지만 m1도 켜서 실패한다. 적어도 두 항이 필요하다.

  2. 한 리터럴 곱항은 네 입력의 여덟 행을 켠다. 함수의 1행은 일곱 개라 지정 0을 덮게 되어 어떤 한 리터럴 항도 허용되지 않는다.

  3. 선택한 두 항은 각각 두 리터럴이며 하한인 두 항·네 리터럴을 달성한다.

지정된 SOP 기준에서 최소다. 실제 셀 면적이나 지연의 전역 최소라는 뜻은 아니다.

어떤 입력에서는 결과가 정해져 있지 않다면 그 칸을 어떻게 사용할까?

준비 개념과 학습 목표

준비 개념

  • 명세는 허용 입력과 반드시 지켜야 할 출력을 함께 정한다. care 입력에서는 0/1을 정확히 지켜야 하고 output don’t-care 입력에서는 어느 출력도 허용된다.

  • input don’t-care 표시는 특정 출력 행에서 입력 변수 값이 결과에 영향을 주지 않는다는 뜻일 수 있다. 출력 미지정과 같은 X 문자라도 용도를 먼저 구분한다.

  • ABC 의 행 번호는 4A+2B+C 다. SOP 는 곱 항을 OR 한 식이며 리터럴은 변수 또는 그 부정 하나다.

학습 목표

  • output don’t-care 를 안전하게 사용한다.

  • care 입력의 동등성 조건을 검사한다.

  • 불가능 입력과 실제 미지정 전압을 구분한다.

미사용 입력 한 행에 안전 출력을 요구하면 기존 최소식은 남을까?

세 입력 ABC의 새 명세를 O={2,6}, D={3,7}, Z={0,1,4,5}로 정한다. O는 반드시 1, Z는 반드시 0이며 D는 어느 출력도 허용한다. B는 2,3,6,7에서 1이므로 명세를 만족한다. BC′도 2,6에서만 1이라 같은 명세를 만족하지만 두 전함수는 D에서 다르다.

버전 v2는 오류 입력 m3에서 반드시 0을 요구한다. 따라서 m3은 D에서 Z로 이동하고 D에는 m7만 남는다. B는 이제 실패하지만 BC′는 계속 유효하다. 실제 상위 장치의 입력 보장이나 안전성을 시험한 것은 아니며 이 예제는 명세의 허용 값 집합을 직접 좁힌 수학 모형이다.

  • 논리 해석의 유효 범위

    미정 전압을 설계 자유도로 바꾸지 않는다.

X 는 명세의 자유도

출력 don’t-care 집합 D 에서는 구현이 0이나 1을 선택할 수 있다. 필수 1 집합 O 와 필수 0 집합 Z 와 D 는 서로 겹치지 않고 전체 입력을 나눈다. 구현 g 는 O 에서 1,Z 에서 0이어야 한다. D 에서 같은 값을 낼 필요는 없다. X 가 실제회로에서 세 번째 불 논리값이라는 뜻이 아니다.

예를 들어 상위 시스템이 특정 코드만 준다는 보장에 따라 미사용 코드를 D 로 둘 수 있다. 그 보장을 누가 유지하는지 명시해야 한다. 오류 입력에 반드시 안전 출력 0을 내야 한다면 그것은 D 가 아니라 Z 다. 시뮬레이터의 unknown X 나 유효 전압 범위 밖 신호를 don’t-care 설계 허가와 동일시하지 않는다.

선택적으로 포함하는 묶음

SOP 묶음에는 O 와 필요한 D 를 포함할 수 있으나 Z 는 포함할 수 없다. 모든 O 는 덮어야 하고 D 를 모두 덮을 의무는 없다. D 를 1로 활용하면 큰 묶음이 생길 수 있고 사용하지 않아도 된다. 목적은 care 동작을 유지하는 비용 개선이다.

명세 O={1,3},D={5,7},Z={0,2,4,6}에서는 C=1인 네 셀을 하나의 묶음으로 쓰면 g=C 다. D 를 모두 0으로 고정했다면 지정한 전함수는 ¬A C 가 된다. 두 결과는 care 입력에서 일치하되 D 의 5,7에서는 서로 다르다.

최소화 뒤의 검증 범위

g=C 는 비상수 care 요구를 만족하므로 0리터럴 상수식은 불가능하고 1리터럴 식이 최소다. 그러나 원래 D 가 나중에 특정값을 요구하는 care 로 바뀌면 검증을 다시 해야 한다. 입력 영역과 출력 요구를 버전별로 기록한다.

  1. 행 A=0,1 및 열 BC=00,01,11,10에 O 를 1,D 를 X,Z 를 0으로 적는다.

  2. C=1인 1,3,5,7을 묶으면 A,B 가 자유롭고 C 만 고정되어 C 를 얻는다.

  4. 상수 0은 O 를,상수 1은 Z 를 위반하므로 한 리터럴 C 가 최소다. D 가 0을 요구하는 새 명세에서는 이 식이 틀린다.

g=C 는 원래 care 여섯 행을 만족한다. D 에서의 출력 1은 허용한 선택이다.

다단 논리와 공유

두 출력이 같은 중간 계산을 쓰면 게이트를 함께 쓸 수 있을까?

준비 개념과 학습 목표

준비 개념

  • 다단 논리는 중간 결과를 다음 gate 가 사용하는 여러 단계 구조다. 불 함수의 동등성은 모든 지정 입력의 최종 0/1이 같다는 뜻이다.

  • fanout 은 한 출력 신호가 연결되는 입력 부하의 개수다. 공유된 중간 값은 부하와 배선 조건을 바꿀 수 있다.

  • 분배법칙 AB+AC=A(B+C)는 불 대수의 항등식이다. AND/OR 를 각각 2입력 gate 로 구현한다고 정하면 인수분해의 비용을 셀 수 있다.

학습 목표

  • SOP 를 인수분해해 다단 구조로 바꾼다.

  • 여러 출력의 공통 중간값을 공유한다.

  • 최종 논리 동등성과 전이 중 glitch 를 구별한다.

세 출력을 공유하면 두 출력 때의 부하 가정을 유지해도 될까?

안정된 다섯 입력 ABCDE에 대해 X=D+E, F=AX, G=BX, H=CX를 자체 설계한다. 2입력 AND와 OR만 세고 부정·배선 비용은 제외한다. 독립 후보 I는 OR 세 개와 AND 세 개로 6단위이고 공유 후보 S는 OR 하나와 AND 세 개로 4단위다. X의 fanout은 3이다.

두 함수가 같은 최종 출력을 만든다는 논증은 각각 공통 식 D+E를 대입하면 된다. 그러나 OR 지연이 부하에 따라 달라지는 가상 표에서는 비용 절감이 지연 절감이 아닐 수 있다. 공유 노드를 서로 다른 이름으로 세 번 써도 실제로 한 노드면 한 번만 면적을 세고 세 입력 부하를 함께 본다.

식과 연결 구조

F=AB+AC 를 그대로 구현하면 AND 두 개와 OR 한 개,총 3개 2입력 gate 가 필요하다. F=A(B+C)는 OR 하나와 AND 하나,총 2개다. 두 식은 A=0일 때 0이고 A=1일 때 B+C 이므로 모든 여덟 입력에서 같다. gate 개수는 선택한 library 와 구현 구조의 비용이며 물리 면적을 직접 측정한 수치는 아니다.

다단 구조에서 중간 노드 U=B+C 는 F 로 들어간다. 모든 입력이 안정되고 각 gate 가 정해진 값을 낸 뒤의 동작을 비교한다. 부정 입력을 만드는 NOT 비용이나 입력수 제한이 달라지면 비용 비교도 달라지므로 gate 목록을 먼저 정한다.

출력 사이의 공유

F=A(B+C),G=D(B+C)를 각각 독립적으로 만들면 OR 두 개와 AND 두 개다. U=B+C 를 한 번 만들고 F=AU,G=DU 로 공유하면 OR 하나와 AND 두 개,총 3개다. U 의 fanout 은 1에서 2로 늘어난다. 논리 공유는 값을 복제하는 별도의 메모리 연산이 아니라 두 gate 입력에 같은 신호를 연결하는 구조다.

공유로 생긴부하가 지연을 늘리거나 buffer 를 필요로 하면 gate 수 이득과 실제 성능은 달라질 수 있다. 출력 F 와 G 의 정확성은 네 입력 16개에 대해 각각 확인해야 한다. 한 출력만 확인했다고 다른 출력의 연결 실수까지 배제되는 것은 아니다.

안정 값과 시간 파형

동등한 불 함수라도 입력 전이 중 같은 파형을 만들 필요는 없다. 예를 들어 H=AB+¬A C 에서 B=C=1이면 안정 출력은 항상 1이다. A 전이 때 두 항의 경로 지연이 다르면 둘 다 잠깐 0이 되는 static-1 hazard 가 생길 수 있다. 실제 발생 여부는 gate 와 배선 지연에 의존한다.

논리적으로 중복인 BC 를 추가한 H=AB+¬A C+BC 는 B=C=1일 때 그 항이 1로 유지되어 해당 단일 A 전이에 대한 보호를 제공한다. 최소 리터럴만을 목표로 없애면 이 보호가 사라질 수 있다. 여러 입력 동시 변화·실제 gate 세부 조건까지 전부 glitch-free 라고 확장하지 않는다. 이 보호 설명은 B,C 가 1로 안정되어 있고 BC 경로가 이미 1을 낸 뒤 A 만 변하는 두 단계 SOP gate 모형을 전제로 한다.

면적·지연의 비교

게이트 하나를 줄이면 면적과 지연을 함께 줄인 것일까?

준비 개념과 학습 목표

준비 개념

  • 면적 비용은 사용한 셀 비용의 합으로 모형화할 수 있다. 실제 면적은 공정·셀 library·배선·buffer·배치에 따라 달라진다.

  • 경로 지연은 입력에서 출력까지 직렬 gate 지연의 합이고 critical path 는 그중 최대다. 병렬 gate 들의 지연을 모두 더하지 않는다.

  • ns 는 10^−9초다. 여기서는 2입력 AND/OR 각각 면적 1단위, fanout 1 지연 1ns 라는 가상 비용을 사용하며 실측이라고 부르지 않는다.

학습 목표

  • 면적과 critical path 를 다른 식으로 계산한다.

  • fanout 조건에 따른 공유 tradeoff 를 비교한다.

  • 제약식에 맞는 후보를 선택하고 보장 범위를 설명한다.

입력이 늦게 도착하면 더 얕은 회로도 더 늦을까?

가상 AND 게이트의 최대 지연을 각각 1 ns로 고정한다. 네 입력을 AND하는 체인은 u=AB, v=uC, Y=vD이며 트리는 u=AB, v=CD, Y=uv다. 모든 입력이 시각 0에 안정되면 체인은 3 ns, 트리는 2 ns다. 그러나 D만 4 ns에 도착하면 체인은 5 ns, 트리는 6 ns가 된다.

gate의 안정 도착 상계는 max(입력 도착 상계)+gate 최대 지연으로 계산한다. 이는 부울 출력의 실제 전이 시각이나 glitch 폭을 측정한 결과가 아니다. 앞의 세 출력 후보에도 각 셀과 부하의 명시된 가상 지연을 넣어야 면적·지연 제약을 판단할 수 있다.

비교할 후보와 비용표

후보 I 는 F=A(B+C),G=D(B+C)를 독립 구현하고 후보 S 는 U=B+C 를 공유한다. 두 후보는 안정 진리값이 같다. 비용표에서 모든 gate 의 면적은 1단위이고 배선·buffer 면적은 0으로 가정한다. I 의 4개 gate 면적은 4, S 의 3개 gate 면적은 3이다.

지연은 입력 도착 0부터 계산한다. I 의 각 OR 은 fanout 1이라 1ns, 뒤 AND 도 1ns 이므로 B/C 에서 출력까지 2ns 다. A/D 에서 출력까지는 1ns 다. critical path 는 2ns 이지 전체 4개 gate 의 4ns 가 아니다.

공유 부하의 가상 반례

S 의 공유 OR 은 fanout 2이므로 이 예제만의 비용표에서 지연을 2ns 로 정한다. 뒤 AND 는 1ns 이므로 B/C 경로는 3ns, A/D 경로는 1ns 다. 그러므로 S 는 면적 3으로 작지만 최대 지연 3ns 로 느리다. OR fanout 2의 2ns 는 공식 부품 수치가 아닌 가정이다.

만약 부하 증가를 무시해 OR 지연을 1ns 로 두면 S 도 2ns 가 된다. 같은 논리 구조도 시간 모형에 따라 결론이 다르다. 실제 합성 결과와 지연 인증에는 library 조건·입력 slew·배선·출력 load·전압·온도 등이 필요하다. 현재 계산은 이러한 장치 시험을 수행한 것이 아니다.

목표를 정한 뒤 선택하기

최대 지연 ≤2.5ns 가 필수면 지정 모형의 I 만 통과한다. 면적 ≤3.5단위가 필수면 S 만 통과한다. 두 제약을 동시에 요구하면 두 후보 모두 실패하므로 새 후보나 목표 변경이 필요하다. 하나의 지표로 다른 조건 통과를 선언하지 않는다.

Pareto 비지배 후보는 어떤 다른 후보가 면적과 지연 모두 작거나 같으며 적어도 하나 엄격히 작게 만들 수 없는 후보다. 여기서 I=(4,2),S=(3,3)는 서로를 지배하지 않는다. 최소화된 식이라는 말을 조건 없는 최적 실측 회로라는 말로 바꾸지 않는다.
