소단원 9.1

상태·전이·출력

같은 버튼을 눌렀는데 왜 이전 입력에 따라 결과가 달라질까?

준비 개념과 학습 목표

준비 개념

  • 순차회로와 clock

  • 표의 행 읽기

학습 목표

  • 기억을 상태로 압축하기 설명

짝홀 기억을 그대로 쓰면 세 번째 1을 알아볼 수 있을까?

기억할 정보는 요구하는 미래 출력에 따라 달라진다. 이번 가상 장치는 입력으로 받은 1의 개수가 3의 배수인지, 매 입력을 처리한 직후 알려 준다. 초기에는 0개이므로 참이다. 짝홀만 기억하면 0개와 2개를 모두 짝수로 묶지만, 뒤에 1을 붙였을 때 각각 1개와 3개가 되어 출력이 달라진다. 따라서 이 요구에는 짝홀 요약이 충분하지 않다.

상태 R₀, R₁, R₂는 받은 1의 개수를 3으로 나눈 나머지다. 입력 0은 상태를 유지하고, 입력 1은 R₀→R₁→R₂→R₀로 순환한다. Moore 출력은 현재 R₀에서만 1이다. 아래 관찰은 한 번의 입력을 한 번의 edge에서 처리한 직후 출력이며, 초기 출력 1은 입력열의 결과에 포함하지 않는다. 실제 스위치나 clock 회로를 실행한 사례가 아니다.

먼저 확인할 개념
  • 미래에 필요한 이력 요약

    입력 기록 자체와 출력에 충분한 기억을 구별한다.

  • 옛 상태에서 next 계산

    한 edge에서 입력을 한 번만 적용한다.

기억을 상태로 압축하기

유한상태기계 FSM은 유한한 상태 집합 S, 입력 집합 X, 다음 상태 함수 δ, 출력 규칙 및 초기 상태로 동작을 표현한다. 상태는 미래 출력에 필요한 과거 정보의 요약이다. 전체 입력 기록을 그대로 저장할 필요는 없다. 이 소단원은 한 clock마다 안정된 입력 한 비트를 받아 움직이는 결정적 동기식 모델이며 전이 계산과 상태 저장을 구분한다.

현재 상태와 다음 상태

clock 직전 상태를 s_k, 그 주기에 샘플할 입력을 x_k라 하면 다음 상태는 s_(k+1)=δ(s_k,x_k)다. 표의 다음 상태가 즉시 현재 상태가 된다고 계산하면 한 입력을 여러 번 처리할 수 있다. reset은 명시한 초기 상태에서 시작하게 한다. 실제 버튼은 바운스나 비동기 변화가 있어 종이 FSM과 별도로 debounce·동기화 설계가 필요하다.

짝수와 홀수의 기억

1을 받은 횟수의 짝홀만 기억하는 기계는 E와 O 두 상태면 충분하다.0은 현재 상태 유지,1은 E↔O로 이동한다. 출력 y=1은 현재까지 받은1의 개수가 홀수일 때라고 정의하면 O의 출력이1이고 E가0이다. 여기서는 각 입력을 처리한 직후 상태의 출력을 기록한다. 출력 시점의 정의를 바꾸면 표에 초기 출력도 따로 적어야 한다.

  1. 두 이력의 1 개수는 0과 2로 모두 짝수다.

  2. 입력 1 뒤 개수는 1과 3이므로 새 요구의 출력은 각각 0과 1이다.

비교할 점

세 상태가 서로 구별되는 이유

R₀,R₁,R₂ 중 두 상태를 합쳐도 모든 미래 출력이 보존될까?

  1. R₀는 현재 출력 1이고 다른 둘은 0이라 바로 구별된다.

  2. R₁과 R₂에 입력 1을 붙이면 R₂와 R₀로 가므로 직후 출력 0과 1로 구별된다.

도달 가능한 세 상태는 모두 서로 구별되므로 이 출력 규칙에는 세 상태가 필요하다.

소단원 9.2

Moore·Mealy 비교

현재 입력이 바뀌는 순간 출력도 바뀌게 할 것인가?

준비 개념과 학습 목표

준비 개념

  • 이진 입력과 출력

  • 순차회로와 clock

  • 표의 행 읽기

학습 목표

  • 두 출력 함수 설명

  • 연속된1의 검출 적용

  • 비교하려면 시간 기준부터 확인

입력이 달라졌다는 알림을 어느 순간 읽는가?

새 Mealy 장치는 직전 입력 q를 저장하고 현재 샘플 x가 q와 다르면 y=q XOR x를 낸다. 다음 상태는 q_next=x이고 초기 q=0이다. 입력을 읽어 전이 출력을 계산할 때는 옛 q를 사용한다. 입력 1,1,0,0,1에서는 변화가 첫째·셋째·다섯째 사건에서 생긴다.

이를 Moore 장치로 옮기면 상태 (q,c)에 마지막 입력과 방금 변화 여부를 함께 저장할 수 있다. next=(x,q XOR x)이고 현재 출력은 c다. 초기 (0,0)이며 입력 처리 직후 c를 읽으면 Mealy의 같은 사건 출력과 일치한다. edge 직전 c는 앞 사건의 값이다. 이 시간 기준의 차이를 실제 회로 전파 지연이나 보편적인 속도 우열로 발표하지 않는다.

먼저 확인할 개념
  • 출력의 의존성과 관측 시점

    g(s)와 g(s,x)를 같은 사건 기준으로 비교한다.

  • XOR 비교의 역할

    두 비트가 다를 때 1을 만드는 조건을 사용한다.

두 출력 함수

Moore의 출력은 g(s), Mealy의 출력은 g(s,x)다. 다음 상태는 둘 다 δ(s,x)로 계산할 수 있다. Moore는 원 안에 상태 출력을 적고 Mealy는 전이 화살표에 입력/출력을 적는다. 이름은 상태 개수나 좋고 나쁨의 평가가 아니라 출력의 의존성을 뜻한다.

연속된1의 검출

직전 비트가1인지 기억해 새 비트도1이면 검출하는 Mealy 기계를 만든다. 상태 A는 직전이1이 아님, B는 직전이1이다. A에서0→A/0,1→B/0;B에서0→A/0,1→B/1이다. 첫 시작 A는 직전1이 없다는 뜻이다.1이 연속 세 개면 겹치는 두 쌍을 모두 검출한다.

비교하려면 시간 기준부터

Moore는 A=직전0/시작, B=직전1이나 검출 상태 아님, C=방금11 검출로 만들어 A0→A,A1→B,B0→A,B1→C,C0→A,C1→C로 할 수 있다. 출력 C만1이다. 이 Moore 출력을 입력 처리 직후 상태에서 읽으면 앞의 Mealy 전이 출력과 같은 검출열이다. clock 직전의 Moore 출력과 같은 주기의 Mealy 출력을 비교하면 한 clock 차이가 보인다. 실제 조합 Mealy 출력은 입력 변동에 반응하므로 등록 출력과 timing 조건도 고려한다.

두 요청이 동시에 오면 그림의 어느 화살표를 따라야 할까?

가상 중재기는 F=비어 있음, A=A 요청을 보유, B=B 요청을 보유인 세 상태를 가진다. 매 사건의 입력은 cancel, rA, rB 세 비트다. F에서는 cancel을 최우선으로 처리해 F를 유지한다. cancel=0일 때 rA가 있으면 A, 그렇지 않고 rB가 있으면 B, 둘 다 없으면 F다. A 또는 B에서는 cancel=1이면 F로 가고 나머지는 현재 보유 상태를 유지한다.

출력은 현재 상태가 가리키는 보유자다. 이는 처리 직전 출력 열이며, 다음 상태의 출력이 필요하면 전이 뒤 상태를 읽는다. 그림을 조건 묶음으로 줄이더라도 조건은 겹치지 않으면서 허용한 입력 전체를 덮어야 한다. 이번 계약은 두 요청이 동시에 오는 입력도 허용한다. 실제 사용자 권한이나 서버 잠금의 안전성이 검증된 사례는 아니다.

먼저 확인할 개념
  • 배타적 완전 전이

    그림의 조건 묶음을 모든 입력 행으로 펼친다.

  • AND·NOT 조건

    우선순위를 서로 겹치지 않는 조건으로 쓴다.

그림과 표는 같은 함수

상태도에서 원은 상태이고 화살표는 입력에 따른 전이다. 결정적 완전 FSM은 각 상태와 각 가능한 입력에 대해 정확히 하나의 다음 상태를 정한다. 같은 입력에 화살표가 둘이면 모호하고 하나도 없으면 정의가 빠졌다. 머무는 경우도 자기 루프 또는 표의 같은 상태 값으로 명시한다.

모든 행을 확인

E/O 짝홀 Moore 기계를 한 비트 입력 표로 쓰면 E,0→E,출력0;E,1→O,출력0;O,0→O,출력1;O,1→E,출력1이다. 여기 표 출력은 현재 상태의 출력이며 다음 상태 출력이 아니다. 처리 직후 출력이 필요하면 다음 상태를 찾은 뒤 그 상태의 g값을 읽는다. 표의 열 제목만으로도 시간 혼동을 줄일 수 있다.

작은 표와 큰 표

상태3개와 입력2비트면 입력 조합4개씩이어서 전이 행은12개다. 입력이 무엇이든 유지하는 동작은 그림에서 넓은 조건으로 압축할 수 있지만 조건들은 중복 없이 전부 덮어야 한다. 사용하지 않는 encoding의 복구 정책은 상징 상태표와 구현 진리표를 연결할 때 추가한다. 불가능하다는 가정은 왜 불가능한지 근거가 있어야 한다.

그림은 모호하고 불완전하다. 우선 규칙을 배타적 조건으로 고친다.

초기 F에서 (cancel,rA,rB)가 011,001,111,001인 네 사건을 처리하라.

직후 상태는 B,F이고 각 사건 직전 출력은 B,B다.

흔한 오답에서 다시 생각하기

둘째 사건의 현재 출력은 F다.

F는 둘째 사건의 next 상태이며 현재 출력은 옛 B에서 읽는다.

연습 2 · 오류 찾아 고치기

환경이 rA와 rB가 동시에 1인 입력을 금지한다고 해서 cancel 입력까지 지워도 되는가?

힌트 1

환경 계약이 금지한 조합만 적는다.

힌트 2

cancel은 요청의 동시성과 다른 비트다.

풀이와 답 확인

  1. rA AND rB=0 제한은 cancel=1인 행을 금지하지 않는다.

  2. cancel의 우선 복귀를 모든 허용 요청 조합에서 보존한다.

불가능 입력을 생략하려면 정확한 환경 제한이 있어야 한다.

흔한 오답에서 다시 생각하기

연습 3 · 직접 만들어 보기

F의 네 next 조건을 배타적이고 완전하게 쓰라.

힌트 1

힌트 2

나머지에서 rA 우선 조건과 NOT rA를 쓴다.

풀이와 답 확인

  2. A 조건은 NOT cancel AND rA이고 B 조건은 NOT cancel AND NOT rA AND rB다.

세 도착 상태 조건은 겹치지 않고 모든 8입력을 덮는다. F의 두 사유를 나누면 네 조건 묶음이다.

소단원 9.4

상태 encoding과 최소화

이름이 다른 두 상태가 정말 서로 다른 기억일까?

준비 개념과 학습 목표

준비 개념

  • 이진 입력과 출력

  • 순차회로와 clock

  • 표의 행 읽기

학습 목표

  • 이름을 비트로 바꾸기 설명

  • 출력만 같아서는 부족 적용

  • 반복 분할과 도달성 확인

한 단계 앞까지 같으면 두 기억을 합쳐도 될까?

새 완전 Moore 기계는 A,B,C,D,Z 다섯 상태를 가지며 초기 B다. Z만 현재 출력 1이고 나머지는 0이다. 입력 1은 어느 상태에서든 A로 간다. 입력 0은 B→D→A→C→Z→Z로 이어진다. B에서 0을 차례로 받아 모든 상태에 도달하므로 단순히 도달 불가 상태를 지울 수 없다.

현재 출력으로 먼저 나누면 {A,B,C,D}와 {Z}다. 같은 입력이 어디의 묶음으로 가는지 반복해 나눈다. C는 0 뒤 Z라 첫 분할에서 구별되지만 A와 B는 첫 분할에서도 아직 같아 보인다. 입력 00을 붙이면 A는 Z, B는 A에 있어 출력이 달라진다. 분할은 한 번의 검사로 끝나는 절차가 아니다. encoding 변경과 상태 병합, 전체 논리의 물리 비용은 각각 다른 작업이다.

먼저 확인할 개념
  • 모든 미래 출력의 등가

    현재 출력 및 다음 묶음을 안정될 때까지 나눈다.

  • 상태 수와 구현 비용

    논리적 최소 상태와 실제 지연·전력을 구별한다.

이름을 비트로 바꾸기

상태 K개에 최소 ceil(log2 K)개의 이진 비트가 필요하다.5개는3비트에 들어가고8가지 encoding 중3개가 남는다. one-hot은 상태마다 비트 하나를 두어5비트를 쓰지만 일부 논리식을 간단히 할 수 있다. 비트 수가 적다는 사실만으로 실제 회로 지연·면적이 더 좋다고 확정할 수는 없다.

출력만 같아서는 부족

이 단원은 결정적 완전 Moore 기계의 등가를 다룬다. 두 상태가 동등하려면 어떤 미래 입력열에서도 같은 출력열을 내야 한다. 먼저 현재 출력이 같은 상태를 묶고, 각 입력의 다음 상태가 같은 묶음으로 가는지 반복 분할한다. 현재 출력0이어도 입력1 후 하나는 출력1 상태로, 다른 하나는 출력0 상태로 가면 구별된다.

반복 분할과 도달성

초기 상태에서 도달할 수 없는 상태를 제거하는 것과 도달 가능한 등가 상태를 합치는 것은 다른 단계다. 병합 뒤에도 초기 상태·출력·모든 입력의 전이가 보존되어야 한다. Mealy를 최소화할 때는 각 입력에서의 전이 출력도 함께 비교한다. 이진 encoding을 바꾸는 작업은 상태 수를 줄이지 않고 단지 같은 기계에 다른 비트 이름을 붙인다.

중간 과정을 따라가는 예제

초기 A인 Moore 기계다. A,B 출력0;C 출력1. A0→A,A1→C,B0→A,B1→C,C0→B,C1→C이다. 도달성과 병합 가능성, 비트 수를 구하라.

  1. A에서1로 C, 이어0으로 B이므로 세 상태 모두 도달 가능하다.

  2. 출력 묶음 {A,B},{C}에서 A와 B의0은 모두 {A,B},1은 모두 {C}로 가므로 동등하다.

  3. D={A,B}로 합치면 D0→D,D1→C,C0→D,C1→C다. 원래3상태2비트, 병합2상태1비트이다.

도달 가능한 A와 B를 합쳐 출력 동작을 보존하고2비트에서1비트로 줄인다.

조건을 바꾸어 비교하기

현재와 한 단계 비교의 한계

A와 B의 현재 출력 및 입력 0/1 뒤 출력이 같다. 그래도 등가인가?

  1. 둘의 현재 출력은 0이고 입력 한 개 뒤도 0이다.

  2. 입력 00 뒤 A는 Z 출력 1, B는 A 출력 0이다.

길이 2의 입력 00이 구별하므로 병합하면 안 된다.

비교할 점

현재와 한 단계의 같음은 모든 미래 이력의 같음보다 약하다.

반복 분할의 종료

현재 출력 묶음부터 위 기계를 분할하고 최소 상태 수를 구하라.

  1. 첫 분할은 {A,B,D},{C},{Z}다. 다음 분할에서는 A가 C로 가므로 {A},{B,D},{C},{Z}가 된다.

  2. 그다음 B는 {D}, D는 {A} 방향이라 {B}와 {D}도 나뉜다. 모든 단일 상태 묶음은 안정적이다.

최소 상태는 5개이고 이진 저장의 최소 폭은 3 bit다.

비교할 점

동일 출력 네 상태를 한 상태로 합치면 필요한 지연 기억을 잃는다.

종이와 본문으로 직접 해보기

풀이 보기

A1은 C 출력1, B1은 B 출력0이므로 입력1로 구별된다. 출력이 현재 같아도 병합할 수 없다.

오해와 반례

상태 두 개의 현재 출력이 같으면 언제나 합칠 수 있다.

모든 미래 입력의 결과가 같아야 한다. 활동의 입력1은 현재 출력이 같은 두 상태를 구별하는 반례다.

다른 문제에 적용하기

세 가상 설계를 감사하라. ① 받은 1의 개수가 3의 배수인지 직후 알려 주는 기계에 1,0,1,1,0,1을 넣고 짝홀 두 상태로 충분하다는 주장을 검사하라. ② 변화 알림에서 초기 q=0인 1,1,0의 Mealy 전이 출력과 Moore 직전/직후 출력을 구별하라. ③ 중재기의 F에서 011,001,111,001을 처리한 직후 상태를 쓰고 현재 출력과 혼동한 보고를 고쳐라. 마지막으로 원래 다섯 상태 기계의 A/B를 합치는 보고에 구별 입력을 주고 D0→Z로 바꾼 경우의 최종 최소 상태를 구하라. 실제 clock·중재 서버·학생 시험은 수행하지 않는다.

힌트 1

각 장치의 상태가 무엇을 기억하고 출력이 언제 관찰되는지 먼저 명시한다.

힌트 2

조건을 모든 허용 입력으로 펼치고, 병합 후보에는 같은 미래 입력을 붙여 출력이 다른지 검사한다.

풀이와 답 확인

  1. ① 직후 상태는 R₁,R₁,R₂,R₀,R₀,R₁이고 출력은 0,0,0,1,1,0이다. 0개와 2개 이력은 같은 짝홀이나 입력 1 뒤 출력이 다르다.

  2. ② Mealy 전이 출력과 Moore 직후 c는 1,0,1이다. Moore 직전 c는 0,1,0으로 앞 사건의 값이다.

  3. ③ 직후 상태는 A,A,F,B다. 직전 출력은 없음,A,A,없음이다. 두 요청 동시 입력은 cancel이 없을 때 A 우선이며 cancel이 최우선이다.

  4. 원래 A/B는 입력 00 뒤 출력 1/0이라 병합할 수 없다. D0→Z로 바꾸면 먼저 C/D, 이어 A/B가 합쳐져 세 묶음 {A,B},{C,D},{Z}가 된다.

  5. 상태 수와 encoding 폭은 각각 원래 5개/3 bit, 바뀐 계약의 최소 3개/2 bit다. 실제 물리 우열과 안전성은 미확인이다.

출력 계약에 충분한 기억·옛 상태·관측 시점·배타적 완전 조건·모든 미래 입력의 등가를 각각 확인해야 한다. 주어진 계산은 위 상태열과 출력열이며, 변형 기계만 세 상태로 줄어든다.

해결한 뒤 점검할 것

  • 세 장치의 초기 상태와 현재/next 및 전/후 출력 열을 분리한다.

  • 누락과 조건 겹침을 허용 입력에서 확인한다.

  • 구별 입력 00 및 변형 기계의 두 번 병합을 제시한다.

  • 논리 모형 계산과 실제 회로·서버·학생 검증 미수행을 구별한다.
