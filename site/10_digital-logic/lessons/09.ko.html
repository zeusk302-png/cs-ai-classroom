소단원 9.1

상태·전이·출력

같은 버튼을 눌렀는데 왜 이전 입력에 따라 결과가 달라질까?

준비 개념과 학습 목표

준비 개념

  • 이진 입력과 출력
  • 순차회로와 clock
  • 표의 행 읽기

학습 목표

  • 기억을 상태로 압축하기 설명
  • 현재 상태와 다음 상태 적용
  • 짝수와 홀수의 기억 확인

기억을 상태로 압축하기

유한상태기계 FSM은 유한한 상태 집합 S, 입력 집합 X, 다음 상태 함수 δ, 출력 규칙 및 초기 상태로 동작을 표현한다. 상태는 미래 출력에 필요한 과거 정보의 요약이다. 전체 입력 기록을 그대로 저장할 필요는 없다. 이 소단원은 한 clock마다 안정된 입력 한 비트를 받아 움직이는 결정적 동기식 모델이며 전이 계산과 상태 저장을 구분한다.

현재 상태와 다음 상태

clock 직전 상태를 s_k, 그 주기에 샘플할 입력을 x_k라 하면 다음 상태는 s_(k+1)=δ(s_k,x_k)다. 표의 다음 상태가 즉시 현재 상태가 된다고 계산하면 한 입력을 여러 번 처리할 수 있다. reset은 명시한 초기 상태에서 시작하게 한다. 실제 버튼은 바운스나 비동기 변화가 있어 종이 FSM과 별도로 debounce·동기화 설계가 필요하다.

짝수와 홀수의 기억

1을 받은 횟수의 짝홀만 기억하는 기계는 E와 O 두 상태면 충분하다.0은 현재 상태 유지,1은 E↔O로 이동한다. 출력 y=1은 현재까지 받은1의 개수가 홀수일 때라고 정의하면 O의 출력이1이고 E가0이다. 여기서는 각 입력을 처리한 직후 상태의 출력을 기록한다. 출력 시점의 정의를 바꾸면 표에 초기 출력도 따로 적어야 한다.

중간 과정을 따라가는 예제

E에서 시작하여 입력1,0,1,1을 처리한다. 각 처리 직후 상태와 출력을 적어라.

  1. 초기 E,y=0이다.
  2. 1 후 O,1;0 후 O,1이다.
  3. 다음1 후 E,0; 마지막1 후 O,1이다.

상태 O,O,E,O; 출력1,1,0,1.

힌트 보기

풀이 보기

기존 O에서0 후 O,출력1;1 후 E,출력0이다. 전체1의 횟수4개는 짝수다.

오해와 반례

입력 비트만 알면 다음 상태를 결정할 수 있다.

같은1도 E에서는 O, O에서는 E를 만든다. 현재 상태가 함께 필요하다.

소단원 9.2

Moore·Mealy 비교

현재 입력이 바뀌는 순간 출력도 바뀌게 할 것인가?

준비 개념과 학습 목표

준비 개념

  • 이진 입력과 출력
  • 순차회로와 clock
  • 표의 행 읽기

학습 목표

  • 두 출력 함수 설명
  • 연속된1의 검출 적용
  • 비교하려면 시간 기준부터 확인

두 출력 함수

Moore의 출력은 g(s), Mealy의 출력은 g(s,x)다. 다음 상태는 둘 다 δ(s,x)로 계산할 수 있다. Moore는 원 안에 상태 출력을 적고 Mealy는 전이 화살표에 입력/출력을 적는다. 이름은 상태 개수나 좋고 나쁨의 평가가 아니라 출력의 의존성을 뜻한다.

연속된1의 검출

직전 비트가1인지 기억해 새 비트도1이면 검출하는 Mealy 기계를 만든다. 상태 A는 직전이1이 아님, B는 직전이1이다. A에서0→A/0,1→B/0;B에서0→A/0,1→B/1이다. 첫 시작 A는 직전1이 없다는 뜻이다.1이 연속 세 개면 겹치는 두 쌍을 모두 검출한다.

비교하려면 시간 기준부터

Moore는 A=직전0/시작, B=직전1이나 검출 상태 아님, C=방금11 검출로 만들어 A0→A,A1→B,B0→A,B1→C,C0→A,C1→C로 할 수 있다. 출력 C만1이다. 이 Moore 출력을 입력 처리 직후 상태에서 읽으면 앞의 Mealy 전이 출력과 같은 검출열이다. clock 직전의 Moore 출력과 같은 주기의 Mealy 출력을 비교하면 한 clock 차이가 보인다. 실제 조합 Mealy 출력은 입력 변동에 반응하므로 등록 출력과 timing 조건도 고려한다.

중간 과정을 따라가는 예제

입력1,1,1,0에서 Mealy 전이 출력과 Moore의 처리 직후 출력을 비교하라.

  1. Mealy 상태 A→B→B→B→A, 출력0,1,1,0이다.
  2. Moore 상태 A→B→C→C→A이고 직후 출력0,1,1,0이다.
  3. Moore의 초기 출력0은 입력 처리 전 값이라 이4개에 포함하지 않았다.

정의한 관측 시점에서는 둘 다0,1,1,0이며 상태 수는2와3이다.

종이와 본문으로 직접 해보기

입력1,0,1,1에 대한 두 출력열을 쓰라.

힌트 보기

0 입력은 직전1의 기억을 지운다.

풀이 보기

Mealy 출력0,0,0,1; Moore 직후 상태 B,A,B,C로 출력0,0,0,1이다.

오해와 반례

Mealy는 언제나 상태가 더 적고 Moore보다 빠르다.

이 예에는 상태가 적지만 일반적 우열은 아니다. 요구 출력·등록 여부·관측 시점·경로 지연을 정해 비교해야 한다.

소단원 9.3

상태도·상태표

화살표가 빠진 그림을 회로로 만들면 어떤 일이 생길까?

준비 개념과 학습 목표

준비 개념

  • 이진 입력과 출력
  • 순차회로와 clock
  • 표의 행 읽기

학습 목표

  • 그림과 표는 같은 함수 설명
  • 모든 행을 확인 적용
  • 작은 표와 큰 표 확인

그림과 표는 같은 함수

상태도에서 원은 상태이고 화살표는 입력에 따른 전이다. 결정적 완전 FSM은 각 상태와 각 가능한 입력에 대해 정확히 하나의 다음 상태를 정한다. 같은 입력에 화살표가 둘이면 모호하고 하나도 없으면 정의가 빠졌다. 머무는 경우도 자기 루프 또는 표의 같은 상태 값으로 명시한다.

모든 행을 확인

E/O 짝홀 Moore 기계를 한 비트 입력 표로 쓰면 E,0→E,출력0;E,1→O,출력0;O,0→O,출력1;O,1→E,출력1이다. 여기 표 출력은 현재 상태의 출력이며 다음 상태 출력이 아니다. 처리 직후 출력이 필요하면 다음 상태를 찾은 뒤 그 상태의 g값을 읽는다. 표의 열 제목만으로도 시간 혼동을 줄일 수 있다.

작은 표와 큰 표

상태3개와 입력2비트면 입력 조합4개씩이어서 전이 행은12개다. 입력이 무엇이든 유지하는 동작은 그림에서 넓은 조건으로 압축할 수 있지만 조건들은 중복 없이 전부 덮어야 한다. 사용하지 않는 encoding의 복구 정책은 상징 상태표와 구현 진리표를 연결할 때 추가한다. 불가능하다는 가정은 왜 불가능한지 근거가 있어야 한다.

중간 과정을 따라가는 예제

상태 P,Q,R와 입력 한 비트가 있다. P0→P,P1→Q,Q0→R,Q1→Q,R1→P만 주어졌다. 빠진 행과 초기 P에서1,0,1의 상태를 찾으라.

  1. 3×2=6행 중 R0가 없다.
  2. P에서1 후 Q,0 후 R,1 후 P다.
  3. 주어진 추적은 빠진 R0를 방문하지 않아서 그 행의 완전성을 증명하지 못한다.

빠진 전이는 R0. 상태 Q,R,P이나 표 전체는 아직 불완전하다.

종이와 본문으로 직접 해보기

R0→R을 추가하면 P에서1,0,0,1의 상태열은?

힌트 보기

풀이 보기

Q,R,R,P이다. 전이가6개가 되어 각 상태/입력 조합을 하나씩 덮는다.

오해와 반례

한 입력열이 잘 동작하면 상태도 전체가 완전하다.

방문하지 않은 상태/입력 조합은 누락될 수 있다. 예제 추적과 전체 행 검사는 별개다.

소단원 9.4

상태 encoding과 최소화

이름이 다른 두 상태가 정말 서로 다른 기억일까?

준비 개념과 학습 목표

준비 개념

  • 이진 입력과 출력
  • 순차회로와 clock
  • 표의 행 읽기

학습 목표

  • 이름을 비트로 바꾸기 설명
  • 출력만 같아서는 부족 적용
  • 반복 분할과 도달성 확인

이름을 비트로 바꾸기

상태 K개에 최소 ceil(log2 K)개의 이진 비트가 필요하다.5개는3비트에 들어가고8가지 encoding 중3개가 남는다. one-hot은 상태마다 비트 하나를 두어5비트를 쓰지만 일부 논리식을 간단히 할 수 있다. 비트 수가 적다는 사실만으로 실제 회로 지연·면적이 더 좋다고 확정할 수는 없다.

출력만 같아서는 부족

이 단원은 결정적 완전 Moore 기계의 등가를 다룬다. 두 상태가 동등하려면 어떤 미래 입력열에서도 같은 출력열을 내야 한다. 먼저 현재 출력이 같은 상태를 묶고, 각 입력의 다음 상태가 같은 묶음으로 가는지 반복 분할한다. 현재 출력0이어도 입력1 후 하나는 출력1 상태로, 다른 하나는 출력0 상태로 가면 구별된다.

반복 분할과 도달성

초기 상태에서 도달할 수 없는 상태를 제거하는 것과 도달 가능한 등가 상태를 합치는 것은 다른 단계다. 병합 뒤에도 초기 상태·출력·모든 입력의 전이가 보존되어야 한다. Mealy를 최소화할 때는 각 입력에서의 전이 출력도 함께 비교한다. 이진 encoding을 바꾸는 작업은 상태 수를 줄이지 않고 단지 같은 기계에 다른 비트 이름을 붙인다.

중간 과정을 따라가는 예제

초기 A인 Moore 기계다. A,B 출력0;C 출력1. A0→A,A1→C,B0→A,B1→C,C0→B,C1→C이다. 도달성과 병합 가능성, 비트 수를 구하라.

  1. A에서1로 C, 이어0으로 B이므로 세 상태 모두 도달 가능하다.
  2. 출력 묶음 {A,B},{C}에서 A와 B의0은 모두 {A,B},1은 모두 {C}로 가므로 동등하다.
  3. D={A,B}로 합치면 D0→D,D1→C,C0→D,C1→C다. 원래3상태2비트, 병합2상태1비트이다.

도달 가능한 A와 B를 합쳐 출력 동작을 보존하고2비트에서1비트로 줄인다.

풀이 보기

A1은 C 출력1, B1은 B 출력0이므로 입력1로 구별된다. 출력이 현재 같아도 병합할 수 없다.

오해와 반례

상태 두 개의 현재 출력이 같으면 언제나 합칠 수 있다.

모든 미래 입력의 결과가 같아야 한다. 활동의 입력1은 현재 출력이 같은 두 상태를 구별하는 반례다.
