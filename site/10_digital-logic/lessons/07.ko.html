소단원 7.1

latch·flip-flop

문을 열어 둔 동안 계속 바뀌는 값과 순간 사진 한 장을 찍는 값은 어떻게 다를까?

준비 개념과 학습 목표

준비 개념

  • D 는 저장할 입력, Q 는 저장 소자의 출력이다.

  • 상승 에지는 클록이 0 에서 1 로 바뀌는 시점이다.

학습 목표

  • level-sensitive latch 와 edge-triggered flip-flop 의 관측 시점을 구별한다.

  • 같은 D 사건 열에서 서로 다른 저장 결과를 추적한다.

저장소자를 두 개 직렬로 놓으면 언제나 한 번에 한 칸만 이동할까?

먼저 지연 0의 이상적인 active-high latch 두 개 L1,L2를 직렬로 연결한다. 둘 다 G=1이면 D 변화가 L1과 L2에 모두 전달된다. 이는 레지스터 두 단계처럼 한 edge에 한 단계씩 이동하는 구조가 아니다. 같은 이름의 저장소자라도 열린 구간이 겹치는지가 정보 이동 규칙을 바꾼다.

새 모형에서는 L1이 [0,4) ns, L2가 [5,9) ns에 열린다. L1이 닫힌 뒤에만 L2가 열리므로 D가 3 ns에 1이 되면 L1은 1을 저장하고 L2는 5 ns에 그 저장값을 받는다. 6 ns에 D가 0으로 돌아와도 L1은 닫혀 있어 L2에는 1이 남는다. 이 표는 지연 0의 기능 모형이다. 실제 latch의 닫힘 주변 setup/hold와 배선·gate 지연 및 위상 겹침을 추가로 검사해야 하며, 간격 1 ns만으로 실제 소자의 타이밍이 인증된 것은 아니다.

먼저 확인할 개념
  • 멀티플렉서의 자료 선택

    2:1 MUX의 선택 신호로 자료와 feedback을 고르는 기능을 연결하고 실제 저장 소자의 열림·닫힘 조건을 별도로 검토한다.

  • 지연 계약의 전제

    이상적 기능 표를 실제 소자의 닫힘 타이밍 보장으로 확대하지 않는다.

레벨이 열어 주는 문

active-high D latch 는 G =1 인 동안 투명하다. D 변화가 전파 지연 뒤 Q 로 전달되며 G =0 이면 이전 값을 유지한다. 투명이라는 말은 회로 지연이 정확히 0 이라는 뜻이 아니다. G 가 닫히는 순간에도 D 가 안정해야 하므로 setup/hold 조건이 있다.

G =0 에서 D 가 바뀌어도 저장된 값은 유지된다. 따라서 현재 D 만으로 Q 를 정할 수 없고 이전 저장 상태가 필요하다. 이것이 현재 입력만 다루는 조합 논리와 다른 점이다. 아래 종이 모형의 그림은 안정한 논리 값만 표시하며 실제 지연은 생략한다.

에지가 찍는 사진

양의 에지 D flip-flop 은 지정한 상승 에지에서 D 를 샘플링하고 다음 상승 에지까지 유지한다. 클록이 1 인 시간 전체에 D 를 계속 통과시키는 소자가 아니다. 출력은 에지 직후 즉시 변하기보다 clock-to-Q 최소/ 최대 지연 규약을 따른다.

서로 반대 위상에 열리는 master/slave latch 두 개로 양의 에지 소자를 만들 수 있다. low 동안 master 가 입력을 따라가고 high 로 바뀌며 master 가 닫히면 slave 가 그 값을 출력한다. 이 구조 설명과 실제 라이브러리의 다른 구현· 지연 값은 구별한다.

저장된 값과 시간 조건을 함께 본다

두 저장소자 모두 안정 조건 아래 한 비트를 저장하지만 언제 바뀔 수 있는지가 다르다. latch 를 무조건 flip-flop 과 교체하면 투명 구간의 동작이 사라져 다른 회로가 된다. latch 기반 설계도 가능하지만 위상·time borrowing·race 를 별도로 설계해야 한다.

이 단원은 충분히 안정한 입력과 이상적인 논리 값을 가정한다. D 변화가 샘플 시점 근처에 오면 결과를 0/1 로 단정할 수 없으며 뒤 소단원에서 그 보장 조건을 계산한다. 단순 파형 추적의 성공을 장비 검증이나 실물 무오류 보장으로 확대하지 않는다.

중간 과정을 따라가는 예제

시간 단위는 ns 다. 처음 D =0,Q =0, D 는 3 에 1/5 에 0/8 에 1 로 바뀐다. latch G 는[2,7)에서만 1 이다. flip-flop 상승 에지는 2/7/12 이며 D 는 각 에지 ±.5 동안 안정하다. 전파 지연을 생략한 안정 값을 비교하라.

  1. latch 는 2 에 열린 뒤 D0 을 따르고 3 에 1,5 에 0 을 따라간다.

  2. 7 에 닫힐 때 0 을 저장하므로 8 의 D1 은 통과하지 않는다.

  3. flip-flop 은 2 에서 D0,7 에서 D0 을 샘플링해 0 을 유지한다.

  4. 12 에서 D1 을 샘플링해 1 을 유지한다.

latch 는 3~5 에 1 이었다가 0 을 저장하며, flip-flop 은 12 에 처음 1 을 저장한다.

직렬 배치가 단계 수를 보장하지 않는다

표의 두 구조가 9 ns 이후 저장하는 값과 positive-edge FF 두 개의 비교를 구하라. FF edge는 0,10,20 ns이고 D는 0 ns 전부터 0이며 3 ns부터 6 ns까지 1이다. 이상적 기능 모형이다.

  1. 서로 다른 위상은 중간에 L1이 저장한 1을 L2로 보낸다. 같은 위상은 D의 0 복귀까지 전달한다.

  2. FF는 edge 0과 10에서 D=0을 샘플한다. 두 FF 모두 이 펄스를 보지 못하고 0을 유지한다.

두 latch 구조의 결과는 각각 1과 0이며, 두 FF의 결과는 0과 0이다.

비교할 점

두 latch가 물리적으로 두 칸이라는 사실만으로 edge-triggered 두 단계와 같지 않다.

겹침을 만드는 위상 변경

L1을 [0,7), L2를 [5,9) ns로 바꾸고 같은 D 변화 3/6 ns를 넣는다. 이상적 최종값은?

  1. 5 ns에 L2가 열려 L1의 1을 받는다.

  2. 6 ns에는 둘 다 열려 D=0이 L1과 L2로 전달되고 이후 두 소자는 0을 저장한다.

최종 L1=L2=0이다. [5,7) ns의 겹침이 새 입력을 통과시켰다.

연습 1 · 값과 상태 예측

원래 서로 다른 위상에서 D가 6 ns에만 0→1로 변한다. 9 ns 뒤 L1/L2는?

힌트 2

L2는 현재 D가 아니라 L1을 입력으로 받는다.

풀이와 답 확인

  2. L2는 5–9 ns에 이 0을 받아 저장한다.

L1=L2=0이다.

L2가 열렸으므로 외부 D=1을 직접 받는다.

연습 2 · 오류 찾아 고치기

두 같은 위상 latch에서 D가 바뀌어도 L2는 다음 clock까지 기다린다는 설명을 고쳐라.

힌트 1

latch의 열린 조건을 확인한다.

힌트 2

edge 샘플 규칙을 latch에 옮겼는지 본다.

풀이와 답 확인

  1. 같은 열린 구간에서는 L1과 L2의 데이터 경로가 모두 통한다.

  2. 지연 0 모형에서는 D 변화가 두 소자에 즉시 전달된다고 바꾼다. 실제 망은 경로 지연을 거친다.

latch의 투명성으로 설명하고 다음 edge의 대기를 삭제한다.

저장소자이므로 항상 edge에서만 변한다.

저장소자에는 수준 민감형과 edge 민감형이 모두 있다.

힌트 1

힌트 2

풀이와 답 확인

동기식 설계

두 레지스터가 같은 에지에서 바뀌면 두 번째가 첫 번째의 새 값을 즉시 받을까?

준비 개념

  • 레지스터는 여러 비트를 함께 저장하는 소자다.

  • 조합 논리는 저장된 현재 값에서 다음 입력을 계산한다.

학습 목표

  • 현재 상태와 다음 상태의 계산을 분리한다.

  • 동기식 경로의 setup/hold 두 조건을 확인한다.

여러 저장값을 갱신하는데 위에서부터 차례대로 계산해도 될까?

새 3-bit 상태 Q=(q0,q1,q2)의 다음 상태를 (q2,q0,q1)로 정한다. 모든 FF는 같은 edge 직전의 옛 상태를 읽고 함께 갱신한다. 초기 100은 010,001,100으로 순환한다. q0부터 변수에 덮어쓰는 소프트웨어 계산은 옛 q0를 잃어 이 망을 잘못 모사할 수 있다. 다음 상태를 별도 임시 묶음으로 만든 뒤 한 번에 교체하면 계약을 보존한다.

기능이 맞아도 clock 주기는 모든 경로를 덮어야 한다. 새 가상 경로의 CQmax=2 ns, setup=2 ns이고 logicmax는 8,5,11 ns다. 최소 주기는 max(12,9,15)=15 ns다. CQmin=.5 ns, logicmin은 1,2,.2 ns, hold=.6 ns라면 최소 hold 여유는 .5+.2−.6=.1 ns다. 이 값은 분포나 평균이 아닌 명세의 상하계이며 실제 장치 측정값이 아니다.

먼저 확인할 개념
  • 멀티플렉서와 enable의 자료 선택

    2:1 MUX에서 e=0은 현재값, e=1은 다음값을 선택하는 식으로 연결한다. MUX 자체가 상태를 저장하는 것은 아니다.

  • 경로마다 다른 최소와 최대

    최장 setup 경로와 최단 hold 경로를 따로 검사한다.

모든 다음 상태는 현재 상태에서 계산한다

단일 클록 동기식 설계는 레지스터와 조합 논리를 연결한다. 에지 직전의 현재 상태로 조합 논리가 계산한 다음 상태를 에지에서 함께 저장한다. 한 레지스터가 업데이트된 값을 같은 에지의 다른 레지스터가 순차 실행처럼 바로 읽는 모형이 아니다.

예를 들어 A_next =NOT A, B_next =A 면 두 next 를 이전 A 로 계산한다. 소프트웨어에서 A 를 먼저 수정한 뒤 B =A 를 실행하는 문장과는 결과가 다르다. 구현 언어의 할당 규칙을 배우기 전에도 현재/ 다음 표를 나누면 하드웨어 병렬 갱신을 설명할 수 있다.

에지 사이에 조합 논리가 안정한다

source 레지스터의 clock-to-Q 최대 지연, 경로의 최대 지연, target setup 을 합친 시간은 다음 에지까지 확보되어야 한다. 같은 에지가 도착하고 skew/uncertainty 를 제외한 모형에서 T ≥tCQ,max +tlogic,max +tsetup 이다. 모든 경로 중 가장 긴 합이 클록 주기의 하한을 정한다.

동시에 가장 빠른 경로도 확인한다. source clock-to-Q 최소지연 +logic 최소 지연이 target hold 이상이어야 새 값이 너무 빨리 도착하지 않는다. 주기를 늘려도 같은 에지 직후 빠른 경로는 그대로여서 hold 문제는 해결되지 않을 수 있다. 최대/ 최소 지연을 혼용하지 않는다.

동기식도 주변 조건이 있다

단순 단일 클록 규약에서는 조합 논리만으로 순환 경로를 만들지 않고 모든 되먹임이 저장 소자를 거치게 한다. 임의의 논리 게이트로 클록을 끊으면 글리치/ 새 에지가 생길 수 있다. 실제 clock gating 은 전용 규약/ 셀과 검증을 따로 사용한다.

외부 입력은 같은 클록을 저절로 따르지 않는다. 버튼이나 다른 클록 영역 신호는 비동기일 수 있어 동기화/ 프로토콜이 필요하다. 이 소단원의 표는 이미 timing 조건을 만족하는 안정 입력과 이상적 공통 에지를 가정하며 모든 전기적 문제를 없앤다고 하지 않는다.

소단원 7.3

setup·hold와 clock skew

도착 클록이 1ns 늦으면 데이터를 받아들일 시간은 늘까 줄까?

준비 개념과 학습 목표

준비 개념

  • setup 은 target 에지 전 안정 시간, hold 는 에지 뒤 안정 시간이다.

  • clock skew 는 레지스터마다 클록이 도착하는 시각 차이다.

학습 목표

  • skew 의 부호를 정의하고 setup/hold 부등식을 유도한다.

  • 같은 skew 가 두 조건에 반대 효과를 주는 이유를 계산한다.

한 방향에 유리한 clock skew가 반대 방향에도 유리할까?

δ를 목적지 B clock 시각에서 출발지 A clock 시각을 뺀 값으로 정의한다. A→B의 setup 조건은 T+δ≥CQmax+logicmax+setup이며, hold 조건은 CQmin+logicmin≥δ+hold다. 같은 clock 이름을 써도 물리 도착이 달라지면 양쪽 여유가 반대로 변한다. 가상 A→B에서 T=12 ns이고 최대 합은 9 ns, 최소 합은 2 ns, hold는 1 ns이면 허용 범위는 −3≤δ≤1 ns다.

B→A 방향에서는 skew가 −δ다. 이 경로의 최대 합은 11 ns, 최소 합은 1.5 ns, hold는 .8 ns이면 −1≤−δ≤.7이므로 −.7≤δ≤1이다. 두 방향을 동시에 만족하는 범위는 [−.7, 1] ns다. setup 불확실성 .4 ns와 hold 불확실성 .2 ns를 각각 불리한 쪽에 더하면 A→B는 [−2.6, .8] ns이고 B→A는 δ∈[−.5, .6] ns다. 교집합은 [−.5, .6] ns로 줄어든다. 두 불확실성은 선언한 독립 보수 예산이며 실제 공정 통계 추정이 아니다.

먼저 확인할 개념
  • 두 경로의 합과 교집합

    각 경로 명세의 상하계를 별도로 보존한다.

  • setup와 hold의 두 검사

    주기와 현재 edge 뒤 보호 구간의 서로 다른 조건을 연결한다.

시각 축에 에지를 놓는다

source 의 이번 에지 0, target 의 이번 에지 δ, target 다음 에지 T +δ라 정한다. δ=target −source 이므로 양수는 target 클록이 늦다는 뜻이다. 이름만 보고 부호를 외우지 말고 실제 두 에지를 먼저 그린다. 지터/uncertainty 는 여기 모형에서 제외한다.

이번 source 가 보낸 데이터의 최대 도착은 tCQ,max +tlogic,max 다. 다음 target 에지의 setup 마감 T +δ−setup 까지 도착해야 하므로 최대 합 +setup ≤T +δ다. target 이 늦으면 다음 에지까지 시간은 늘어난다.

같은 에지의 hold 는 반대다

이번 source 에서 출발한 새 데이터는 이번 target 이 샘플 한 옛 값을 hold 동안 깨뜨리지 않아야 한다. 최초 도착 tCQ,min +tlogic,min 은 δ+hold 이상이어야 한다. target 이 늦으면 옛 값을 더 늦게까지 유지해야 하여 빠른 경로에는 불리하다.

setup slack =T +δ−setup −tCQ,max −tlogic,max, hold slack =tCQ,min +tlogic,min −δ−hold 로 정한다. 양수는 여유,0 은 이상적 경계, 음수는 이 모형에서 조건 위반이다. sign 이 반대인 두 slack 을 동시에 검사한다.

지연 수정도 두 조건을 건드린다

빠른 경로에 buffer 를 추가하면 최소 도착이 늦어져 hold 를 고칠 수 있다. 하지만 최대 지연도 늘면 setup 여유가 줄어든다. 어느 하나만 맞추는 것이 아니라 변경 후 모든 관련 경로를 재확인해야 한다.

소단원 7.4

timing violation의 파형

입력이 에지 가까이 바뀌면 출력은 반드시 반대 값으로 보일까?

준비 개념과 학습 목표

준비 개념

  • 논리 0/1 은 유효한 전압 범위를 추상화한 값이다.

  • X 는 이 표에서 결과를 보장할 수 없다는 표시이며 세 번째 물리 논리 값이 아니다.

학습 목표

  • setup/hold 의 안정 창을 파형에 표시한다.

  • 위반과 실제 관측 실패·metastability 의 차이를 설명한다.

변화 시각을 정확히 모를 때 0이나 1을 반드시 저장한다고 말할 수 있을까?

새 FF의 edge는 20 ns,setup=2 ns,hold=1 ns라서 입력은 [18,21] ns 동안 유효하게 안정해야 한다. 초기 D=0이고 단 한 번 0→1로 변하는 시각이 a라고 하자. a<18이면 새 값 1을 보장하고 a>21이면 옛 값 0을 보장한다. a가 [18,21] 안이면 출력 validity 명세를 적용하지 못한다. 경계까지 금지하는 보수 계약으로 정의하여 등호의 해석을 명시한다.

변화 시각 범위 [16,17] ns는 모든 경우 1을 보장하지만 [17,19] ns는 일부 경우가 금지 창에 들어가므로 전체 출력값을 보장하지 못한다. [22,23] ns는 모든 경우 0이다. 창 위반은 반드시 0을 잘못 저장했다거나 항상 metastability가 관찰된다는 뜻이 아니다. 비동기 입력에 기다리는 시간을 더 주면 실제 소자의 불안정 지속 가능성을 줄일 수 있지만 유한 시간 절대 성공을 증명하지 않는다. 여기서는 소자 매개변수나 MTBF 값을 측정하지 않는다.

먼저 확인할 개념
  • 조건을 잃으면 보장도 잃는다

    불확정 구간을 임의의 실제 파형으로 단정하지 않는다.

  • 목적지 edge의 주변 창

    clock 도착과 setup/hold를 함께 읽는다.

금지 창을 그림으로 만든다

상승 에지 10ns, setup2/hold1 이면 D 는 8 부터 11 까지 안정해야 한다. 입력이 그 안에서 변하면 dynamic discipline 을 위반한다. 이 창은 에지 이전 구간만 있는 것이 아니므로 10 직후의 변화도 hold 위반일 수 있다.

안정 조건이 맞으면 clock-to-Q 지연 규약으로 출력 파형의 보장 영역을 표시한다. 예를 들어 최소.5/ 최대 2ns 면 Q 는 10.5 이전까지 옛 값을 유지하고 12 까지 샘플 한 새 값으로 안정한다. 사이 구간에는 전이가 가능하며 정확한 변화 시각은 이 범위만으로 모른다.

위반하면 보장 영역이 사라진다

setup/hold 위반은 정상 소자 규약으로 정한 샘플 값이나 안정 시각의 보장을 적용할 수 없다는 뜻이다. 옛값이나 새 값을 얻을 수 있고 유효하지 않은 전압이 일시적으로 나타날 수도 있다. 반드시 매번 실패하거나 항상 반대 값이 된다고 단정하지 않는다.

metastability 는 저장 회로가 불안정한 중간 상태 근처에 머물러 유효한 0/1 로 해결되기까지 시간이 늘어나는 현상이다. 디지털 파형의 X 는 그 정확한 전압/ 지속 시간 측정이 아니다. 시뮬레이터가 X 를 표시하거나 실물 계측이 깨끗하게 보이는 것만으로 모든 위반의 안전성을 증명하지 못한다.

그림과 실물 증거를 구별한다

파형 검토는 D 변화· 클록에지· 안정 창·Q 보장 영역을 한 축에 놓고 어느 조건이 깨졌는지 확인한다. 수정에는 전처리 지연/ 주기/hold buffer 나 비동기 입력 동기화처럼 원인에 맞는 방법이 필요하다. setup 와 hold 의 차이를 무시하고 클록만 느리게 하면 해결되지 않을 수 있다.

비동기 입력에는 충분한 해결 시간을 허용하는 동기화가 실패 확률을 낮출 수 있지만 모든 입력에 유한 시간 내 무오류를 보장하는 마법 소자는 아니다. 실제 실험에는 반복 조건/ 관측 범위가 필요하다. 여기서는 종이 사건 표만 추적하고 장비 파형·MTBF 실측· 시뮬레이터 실행은 하지 않았다.

  2. edge 20 ns 뒤 CQmin=.5 ns가 지나기 전, 즉 20.5 ns 전까지 옛 Q=0이며 22 ns부터 새 Q=1이다.

20.5 ns 전에는 0이고, 22 ns부터는 1이다. 그 사이의 정확한 전이 시각은 알 수 없다.

비교할 점

CQ 상계는 입력 변화 17 ns부터가 아니라 FF의 active edge부터 센다.

분포를 선언해야 확률을 계산할 수 있다

매 10 ns 주기에서 한 instantaneous 입력 변화의 위상이 [0,10) ns 균등이라고 가정한다. setup 2/hold 1의 금지 창에 들어갈 확률과 두 번째 FF의 절대 보장 주장을 검토하라.

  1. 금지 창 총길이 3 ns를 주기 10 ns로 나누어 3/10을 얻는다.

  2. 이 확률은 창 위반의 모형 확률이다. 소자의 실제 실패 확률 및 불안정 지속 분포가 아니다.

위반 확률은 30%다. 두 FF를 썼다고 실제 실패 확률 0을 증명할 수 없다.

비교할 점

균등 가정이 없으면 시각 길이 비율만으로 확률을 정하지 못한다.

다른 문제에 적용하기

이상적 3-bit 회전 레지스터는 Q=(q0, q1, q2), next=(q2, q0, q1)이고 초기 상태는 100이다. enable이 1, 0, 1일 때의 상태를 구하라. 물리 구현의 가상 A→B/B→A 경로에서 T=12 ns이고, 최대 합은 각각 9 ns와 11 ns, 최소 합은 각각 2 ns와 1.5 ns, hold는 각각 1 ns와 .8 ns다. δ=tB−tA이고 setup 불확실성 .4 ns와 hold 불확실성 .2 ns를 모두 포함해 허용 δ 범위를 구하라. δ=.8 ns를 택한 제안의 실패 조건을 찾으라. 별도 외부 FF에서 edge는 20 ns, setup은 2 ns, hold는 1 ns이고 입력 변화 범위는 [17, 19] ns다. 모든 입력값 보장 및 실제 실패확률을 발표할 수 있는지 판단하라. 같은 열린 위상 latch 두 개로 레지스터를 대체해도 edge 회전 계약을 유지한다는 주장도 검토하라. 모든 값은 자체 가상 모형이며 회로·장비·학생 시험은 하지 않는다.

힌트 1

기능 상태는 같은 옛값 묶음에서 만들고 e=0에서는 유지한다. 양방향 skew 식의 부호는 서로 반대다.

힌트 2

전체 경로 범위는 교집합이며 입력 시각 범위의 모든 경우를 검사한다. 계약 위반 가능성을 측정된 실패 확률로 바꾸지 않는다.

풀이와 답 확인

  1. 기능 상태는 100→010→010→001이다. 각 next는 edge 직전 같은 옛 상태에서 계산한다.

  2. A→B의 setup 조건은 δ≥9+.4−12=−2.6 ns이고, hold 조건은 δ≤2−1−.2=.8 ns다.

  3. B→A의 두 조건은 −δ≥11+.4−12=−.6 ns와 −δ≤1.5−.8−.2=.5 ns다. 따라서 δ∈[−.5, .6] ns이며 전체 교집합도 [−.5, .6] ns다.

  4. δ=.8 ns에서는 B→A setup 여유가 12−.8−11−.4=−.2 ns로 부족하다.

  5. 외부 변화 범위 [17,19] ns는 금지 창 [18,21] ns와 일부 겹친다. 새 값 1을 모든 경우 보장할 수 없고, 실제 오류값이나 실패확률도 주어진 자료만으로 정할 수 없다.

  6. 같은 열린 위상의 두 latch는 동시에 투명해 D 변화가 연속 통과할 수 있다. edge 직전의 옛 상태를 한 단계씩 갱신하는 FF 계약과 같지 않다. 이상적 기능과 물리 조건을 각각 검증해야 한다.

회전 상태는 100, 010, 010, 001이다. 보수 허용 skew는 [−.5, .6] ns이며 .8 ns는 반대 방향의 setup 조건을 .2 ns 위반한다. 외부 입력 범위 전체 보장과 실제 실패확률은 미확인이다. 같은 위상 latch로의 대체는 edge 회전 계약을 자동 보존하지 않는다.
