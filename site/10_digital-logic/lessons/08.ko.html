소단원 8.1

enable·reset과 레지스터

같은 입력을 계속 두어도 기억한 값은 언제 바뀔까?

준비 개념과 학습 목표

준비 개념

  • 0 과 1

  • 멀티플렉서

  • 클록 에지

학습 목표

  • 저장과 출력 구동을 구별한다.

  • 정해진 우선순위의 다음 상태를 추적한다.

enable로 저장을 멈추는 것과 clock 선을 AND하는 것은 같은 동작일까?

새 2-bit 레지스터에서 상승 edge에만 갱신하며 synchronous reset이 enable보다 우선한다. next는 r=1이면 00, 아니면 e=1일 때 D, 나머지는 Q다. e=0도 clock 자체를 없애지 않는다. 실제 clock을 그대로 FF에 연결하고 자료 쪽 MUX가 Q를 선택하면 enable이 clock high 구간에서 변해도 그 순간 새 상승 edge는 없다.

반대로 G=CLK AND e를 clock으로 쓰는 단순 모형은 CLK가 이미 1인 동안 e가 0→1이면 G도 0→1이 된다. 원래 clock에 없던 상승 사건으로 자료를 저장할 수 있다. 이 비교는 논리 사건 모형이며 실제 clock gating cell의 내부 latch·타이밍·전력 효과를 측정한 것이 아니다. synchronous reset은 원래 edge 주변에 샘플되어야 한다. enable 조건 안에 reset 검사를 잘못 넣으면 e=0인 때 reset도 무시하는 다른 계약이 된다.

  • 자료 선택 MUX

    현재값과 새 자료를 선택하는 2:1 식을 실제 본문에서 연결한다.

  • edge와 투명 구간

    edge 사건과 열린 구간의 자료 통과를 구별한다.

레지스터는 에지에서 값을 기억한다

이 단원은 양의 에지에서 값을 저장하는 D 레지스터를 쓴다. D 입력과 Q 상태를 구별하고 클록이 1 로 유지되는 동안 입력을 바꾸는 것을 새 저장 사건으로 세지 않는다.

레벨에 따라 열린 D latch 는 다른 동작이다. 실제 에지 주변에는 setup/hold 조건이 있어야 하며 이상 모델의 상태 표만으로 실제 칩의 안정성을 증명하지 않는다.

enable 은 저장을 허용하는 조건이다

enable=1 이면 새 데이터를 저장하고 0 이면 기존 Q 를 유지하도록 다음 상태 MUX 를 만들 수 있다. enable 이 0 이어도 밖에서 Q 를 읽을 수 있는지와 출력선 구동 여부는 별도 기능이다.

레지스터 여러 비트는 같은 규칙으로 함께 저장한다. 허용신호를 클록에 아무 게이트나 붙여 구현하는 것과 데이터 경로의 선택 규칙은 동일한 안전성 주장이 아니다.

reset 의 시점과 우선순위를 명시한다

여기서는 동기식 active-high reset 을 enable 보다 우선한다. 양의 에지에서 reset=1 이면 0, 아니고 enable=1 이면 D, 둘 다 아니면 Q 를 저장한다.

reset 신호가 에지 사이에 잠깐 1 이었다가 사라지면 이 동기식 모델의 Q 는 바뀌지 않는다. 에지와 관계없이 반응하는 비동기식 reset 은 다른 계약이므로 부품이나 HDL 규칙을 따로 확인한다.

없는 clock edge를 새로 만들기

원래 CLK는 10 ns에 상승하고 15 ns에 하강한다. e는 10 ns에 0, 12 ns에 1로 변한다. D=11이고 Q=00이다. reset은 0이다. 자료 MUX와 G=CLK AND e의 결과를 비교하라.

  1. 자료 MUX 구조는 10 ns에서 e=0이라 Q=00을 유지한다. 12 ns에는 원래 상승 edge가 없다.

  2. 단순 AND 구조의 G는 10 ns에서 0이고 12 ns에 상승한다. 이상적 FF는 그 새 사건에서 D=11을 저장한다.

15 ns 전 기능 결과는 자료 MUX에서 00, 단순 AND clock에서 11이다.

실제 전용 gating cell과 단순 AND를 같은 계약으로 부르지 않는다.

  1. 잘못된 구조는 e=0이라 아무 저장도 하지 않고 Q=10을 유지한다.

shift register·counter

비트를 옆 칸으로 보내는 것과 숫자를 하나 올리는 것은 어떻게 다를까?

준비 개념과 학습 목표

준비 개념

  • 이진수

  • 레지스터

  • 나머지

학습 목표

  • 동시 에지의 이전 상태 기준 이동을 추적한다.

  • 이진 카운터의 wrap 와 모듈로 조건을 구별한다.

3-bit 상태가 있으면 반드시 여덟 상태를 모두 순환할까?

새 상태 (q2,q1,q0)의 다음값을 (q1,q0,q2 XOR q0)로 정한다. enable이 1인 edge만 이 규칙으로 이동하며 모든 우변은 같은 옛 상태에서 읽는다. 초기 100은 001,011,111,110,101,010을 거쳐 100으로 돌아온다. 일곱 비영 상태를 방문하지만 000은 000으로 남는다. 이것은 선택한 작은 feedback shift 모형의 성질이며 어떤 폭이나 tap도 같은 길이를 준다는 정리는 아니다.

상태 저장 폭의 가능 상태 수 8과 실제 도달 순환 길이 7은 다르다. 이름에 counter가 붙어도 자연수 0,1,2 순서로 증가하는 것은 아니다. 또 shift로 버린 옛 비트는 새 상태만으로 항상 복원되지 않는다. 외부 직렬 입력을 사용하는 단순 shift에서는 입력 및 버린 비트 기록을 추가하면 한 단계의 원래 상태를 재구성할 수 있다.

먼저 확인할 개념
  • XOR와 2의 보수 회로

    한 비트 XOR의 조건을 연결하며 여기서 정수 덧셈과 구별한다.

  • 동시에 읽는 옛 상태

    여러 저장 bit를 한 edge에서 같은 옛 묶음으로 갱신한다.

shift 는 저장 칸 사이의 이동이다

4 비트 Q=[q3,q2,q1,q0]에서 오른쪽 shift 를 Qnext=[s,q3,q2,q1]로 정의하자. s 는 직렬 입력이고 이전 q0 는 밀려 나가는 비트다. 왼쪽/오른쪽 이름보다 이 연결식을 먼저 적는다.

같은 에지의 각 칸은 이전 상태를 보고 새 값을 저장한다. 종이에 한 칸씩 순서대로 바꾸며 이미 바꾼 값을 옆 칸에 넣으면 다른 동작이 된다.

counter 는 상태값을 연산한다

3 비트 unsigned 이진 카운터에서 Qnext=(Q+1) mod 8 이면 0 부터 7 까지 돌고 다시 0 이 된다. shift 의 비트 복사 규칙과 다른 산술 다음 상태다.

0 부터 5 까지 도는 mod 6 카운터는 Q=5 이면 0 으로 가는 규칙과 유효하지 않은 6/7 에서의 복구 정책을 정해야 한다. 비트 수가 3 이라는 이유로 모든 8 상태를 정상 순서에 넣는 것은 아니다.

같은 주소를 읽으며 쓰면 옛값을 읽을까, 새값을 읽을까?

새 가상 메모리는 8개 word에 word당 12 bit를 저장한다. address는 word 번호 0–7이며 주소 선은 3개다. 자료 저장량은 96 bit, 즉 12 byte지만, 실제 파일에서 각 word를 16-bit container에 넣으면 16 byte가 필요하다. 자료를 빈틈없이 이어 붙인 packed 표현과 구현 포장·port·제어 비용은 서로 다르다. 주소 3은 이 계약에서 네 번째 word이며 byte 주소 3이라는 뜻이 아니다.

이제 read 출력도 상승 edge에서 저장하는 계약을 선언한다. 같은 edge의 write는 그 직전 자료 묶음을 바꾸는 next 작업이고 read-first 출력은 옛 M[read_address]를 읽는다. write-first라는 다른 계약은 같은 주소일 때 write 자료를 출력에 bypass한다. 이 둘은 자체 정의한 비교 모형이며 모든 SRAM/FPGA RAM의 보편 규칙은 아니다. 한 주소에 두 write port가 충돌할 때도 우선순위나 거절 계약을 별도로 정해야 한다.

먼저 확인할 개념
  • 주소 decoder와 자료 MUX

    word 선택과 read 자료 선택의 방향을 구별한다.

  • edge의 옛값 읽기

    동일 edge에서 기존 자료 읽기와 next 갱신을 구별한다.

주소는 저장 위치를 고른다

k 비트 주소는 0 부터 2^k−1 까지 위치를 고른다. 각 위치에 N 비트를 저장하면 정보 용량은 2^k×N 비트다. 주소 폭과 데이터 폭은 서로 다른 축이다.

이 단원은 워드 주소 모형을 쓴다. 한 주소가 여러 바이트 워드를 가리키는 것과 바이트 주소의 연속 범위를 섞으면 용량·오프셋 계산이 틀린다.

쓰기에는 주소·값·허용 조건이 필요하다

교육용 동기 쓰기에서 양의 에지에 WE=1 이면 WA 가 고른 위치에 WD 를 저장한다. 세 신호 모두 필요한 setup/hold 동안 유효해야 한다.

읽기는 부품에 따라 조합 읽기나 클록 기준 읽기 등 규약이 다르다. 여기서는 읽기 주소가 안정된 뒤 전파 지연 후 값이 나오는 조합 읽기를 선택한다. 모든 RAM 의 규칙이라고 일반화하지 않는다.

같은 위치의 충돌과 출력 구동을 정한다

같은 위치에서 동시에 읽고 쓰면 이 예는 쓰기 전에는 이전 값, 쓰기 후 전파 지연이 지나면 새 값을 읽는다. 다른 메모리는 old/new/no-change 등 계약이 다를 수 있다.

여러 출력을 한 선에 묶을 때 누가 구동하는지도 필요하다. 출력 enable 은 데이터를 저장하라는 WE 와 다르므로 disabled 값을 곧바로 저장된 0 으로 해석하지 않는다.

  1. read-first는 옛 자료 7을 출력한다.

  2. write-first는 같다는 주소 조건에서 11을 bypass한다. 두 저장 자료는 모두 11이다.

출력은 각각 7과 11이지만 edge 뒤 저장 자료는 둘 다 11이다.

두 write port의 충돌 계약

초기 M[1]=4이고 port A는 주소 1에 6을, port B는 주소 1에 10을 쓴다. A 우선 계약과 충돌 시 둘 다 거절하는 계약을 비교하라.

  1. A 우선이면 한 next M[1]=6을 선택한다.

  2. 둘 다 거절이면 M[1]=4를 유지하고 충돌 flag를 낸다.

최종 자료는 각각 6과 4다. 다른 주소일 때 둘 다 쓰는 규칙은 이 충돌 결과를 정하지 않는다.

소단원 8.4

상태 저장의 비용

비트 수를 줄이기만 하면 상태를 기억하는 회로는 언제나 좋아질까?

준비 개념과 학습 목표

준비 개념

  • 상태 수

  • log2

  • 전파 지연

학습 목표

  • 정보 비트 최소와 실제 구현 비용을 구별한다.

  • setup/hold 및 주소 회로 비용을 따로 평가한다.

가장 적은 상태 bit가 항상 가장 싼 구현일까?

새 장치는 다섯 상태를 구별한다. 이진 저장에는 최소 3 bit가 필요하며, 8개 인코딩 중 3개가 미사용이다. one-hot 저장에는 5 bit가 필요하고, 유효 자료는 정확히 한 bit가 1인 다섯 가지다. 나머지 27개는 무효다. 유효 이력에서만 상태가 나온다는 가정으로 무효 상태의 복구가 자동 해결되지는 않는다. 여기서는 무효 상태를 다음 edge에 초기 상태로 복구하는 계약을 별도로 선언한다.

실제 제조 비용 대신 가상 비용 C=저장 bit당 2점+선언한 조합논리 점수를 쓴다. 이진 설계의 조합논리 비용이 14점이면 총 20점이고, one-hot의 논리 비용이 3점이면 총 13점이다. 저장 bit가 적은 쪽이 이 지정 모형의 전체 비용에서는 더 크다. FF bit의 clock 입력 수는 각각 3개와 5개지만, 실제 전력 비교에는 부하·전압·빈도·cell·활동률이 필요하다. 이 점수표를 면적·전력·실측 속도로 발표하지 않는다.

먼저 확인할 개념
  • bit 표현과 부호 규약

    가능 인코딩 수와 자료 의미를 구별한다.

  • 물리 경로의 별도 검사

    기능 인코딩과 실제 타이밍 인증은 다른 조건이다.

정보량은 최소 칸 수를 알려 준다

구별할 상태 S 개는 적어도 ceil(log2 S)비트가 필요하다. 모든 비트 조합이 유효 상태일 필요는 없다.

이 최소는 정보 표현의 한계다. one-hot 처럼 상태마다 한 비트를 쓰는 설계는 칸이 많아도 다음 상태 판별이 단순해질 수 있다. 적은 비트가 언제나 작고 빠른 전체 회로라는 뜻은 아니다.

저장 셀 밖의 회로도 비용이다

레지스터에는 클록·enable·reset 과 연결이 있고 메모리 배열에는 주소 해독·읽기 선택·출력 회로가 있다. 저장 용량만 비교하면 총면적·전력·접근 지연을 놓친다.

SRAM 과 DRAM 은 셀 구조·읽기/쓰기·유지 조건이 다르다. DRAM 의 전하 유지는 refresh 가 필요하고 SRAM 도 전원을 끊으면 정보를 보존하는 비휘발성 저장소가 아니다.

상태 경계가 사용 가능 시간을 줄인다

단일 클록·skew 무시 모델에서 주기는 출발 레지스터의 최대 전파 지연+조합 최대 지연+수신 setup 이상이어야 한다.

hold 는 출발 최소 지연+조합 최소 지연이 수신 hold 이상인지 별도로 검사한다. 두 조건은 각각 늦고 빠른 도착에 관한 것이므로 클록 주기 하나로 모두 해결하지 않는다.

다른 문제에 적용하기

가상 상태·메모리 장치의 계약 보고

초기 2-bit Q=10에서 reset 우선 규칙의 r/e/D가 0/1/01, 1/0/11, 0/0/11인 세 edge 뒤 상태를 기록하라. feedback 상태 100의 e=1, 0, 1, 1도 추적하라. 초기 M[3]=5인 8 word×12 bit 메모리에서 read3/write3=9와 다음 read3/write없음의 read-first 및 write-first 출력과 저장 자료를 비교하라. 자료 packed byte 수와 16-bit container 포장량을 구하라. 다섯 상태 이진/one-hot의 위 가상 비용과 무효 인코딩 수를 적고 실제 전력 우열을 발표할 수 있는지 판단하라. clock AND를 자료 enable과 동일시하거나 read-first를 write 실패로 보는 설명을 고쳐라. 모든 사례는 가상 모형이며 실제 회로·메모리·학생 시험은 하지 않는다.

힌트 1

세 종류의 상태는 각각의 옛값과 우선순위를 먼저 적는다. enable=0인 edge도 발생한다.

힌트 2

메모리의 출력과 저장 word를 분리하고 자료 bit·포장량·가상 점수·실제 전력을 따로 쓴다.

풀이와 답 확인

  1. 레지스터는 10→01→00→00이다. reset이 enable보다 우선한다. feedback은 100→001→001→011→111이다.

  2. read-first 출력은 5와 9이고 write-first는 9와 9다. 첫 edge 뒤 M[3]=9이며 다음에도 9를 유지한다.

  3. 자료량 96 bit는 12 byte다. 지정한 16-bit container 포장은 16 byte다. 주소 3은 word 번호다.

  4. 다섯 상태 이진의 무효 수는 3이고 비용은 20점이다. one-hot의 무효 수는 27이고 비용은 13점이다. 실제 전력 우열은 미확인이다.

  5. 단순 AND는 CLK가 1인 동안 enable 상승으로 새 clock 상승을 만들 수 있다. 자료 MUX의 enable은 원래 edge에서 자료를 선택한다. read-first는 옛 출력 계약이며 write 실패를 뜻하지 않는다.

세 레지스터 갱신의 최종값은 00이고 feedback 최종값은 111이다. read-first의 5/9 및 write-first의 9/9를 저장 자료 9와 구별한다. packed 자료는 12 byte이고 포장은 16 byte다. 이진 비용은 20점, one-hot 비용은 13점이며 실제 전력·물리 안전성은 미확인이다.
