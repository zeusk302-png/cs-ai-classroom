소단원 8.1

enable·reset과 레지스터

같은 입력을 계속 두어도 기억한 값은 언제 바뀔까?

준비 개념과 학습 목표

준비 개념

  • 0 과 1
  • 멀티플렉서
  • 클록 에지

학습 목표

  • 저장과 출력 구동을 구별한다.
  • 정해진 우선순위의 다음 상태를 추적한다.

레지스터는 에지에서 값을 기억한다

이 단원은 양의 에지에서 값을 저장하는 D 레지스터를 쓴다. D 입력과 Q 상태를 구별하고 클록이 1 로 유지되는 동안 입력을 바꾸는 것을 새 저장 사건으로 세지 않는다.

레벨에 따라 열린 D latch 는 다른 동작이다. 실제 에지 주변에는 setup/hold 조건이 있어야 하며 이상 모델의 상태 표만으로 실제 칩의 안정성을 증명하지 않는다.

enable 은 저장을 허용하는 조건이다

enable=1 이면 새 데이터를 저장하고 0 이면 기존 Q 를 유지하도록 다음 상태 MUX 를 만들 수 있다. enable 이 0 이어도 밖에서 Q 를 읽을 수 있는지와 출력선 구동 여부는 별도 기능이다.

레지스터 여러 비트는 같은 규칙으로 함께 저장한다. 허용신호를 클록에 아무 게이트나 붙여 구현하는 것과 데이터 경로의 선택 규칙은 동일한 안전성 주장이 아니다.

reset 의 시점과 우선순위를 명시한다

여기서는 동기식 active-high reset 을 enable 보다 우선한다. 양의 에지에서 reset=1 이면 0, 아니고 enable=1 이면 D, 둘 다 아니면 Q 를 저장한다.

reset 신호가 에지 사이에 잠깐 1 이었다가 사라지면 이 동기식 모델의 Q 는 바뀌지 않는다. 에지와 관계없이 반응하는 비동기식 reset 은 다른 계약이므로 부품이나 HDL 규칙을 따로 확인한다.

중간 과정을 따라가는 예제

4 비트 Q 초기값은 1010 이다. 네 양의 에지에서 (reset,enable,D)는(0,0,0011),(0,1,0011),(1,1,1111),(0,0,1001)이다. 모든 신호는 필요한 시간 동안 안정되고 reset 우선 동기식 규칙을 쓴다.

  1. 첫 에지는 enable 0 이라 1010 을 유지한다.
  2. 두 번째는 enable 1 이라 0011 을 저장한다. 세 번째는 reset 1 이 우선하여 D 1111 대신 0000 이다.
  3. 네 번째는 enable 0 으로 0000 을 유지한다. 에지 뒤 경과 지연은 이 이상 상태 표에서 제외했다.

에지 후 Q 는 1010→0011→0000→0000 이다.

풀이 보기

첫 에지에서 1010 이 유지되는 반례다. 유지와 0 저장은 다른 다음 상태다.

소단원 8.2

shift register·counter

비트를 옆 칸으로 보내는 것과 숫자를 하나 올리는 것은 어떻게 다를까?

준비 개념과 학습 목표

준비 개념

  • 이진수
  • 레지스터
  • 나머지

학습 목표

  • 동시 에지의 이전 상태 기준 이동을 추적한다.
  • 이진 카운터의 wrap 와 모듈로 조건을 구별한다.

shift 는 저장 칸 사이의 이동이다

4 비트 Q=[q3,q2,q1,q0]에서 오른쪽 shift 를 Qnext=[s,q3,q2,q1]로 정의하자. s 는 직렬 입력이고 이전 q0 는 밀려 나가는 비트다. 왼쪽/오른쪽 이름보다 이 연결식을 먼저 적는다.

같은 에지의 각 칸은 이전 상태를 보고 새 값을 저장한다. 종이에 한 칸씩 순서대로 바꾸며 이미 바꾼 값을 옆 칸에 넣으면 다른 동작이 된다.

counter 는 상태값을 연산한다

3 비트 unsigned 이진 카운터에서 Qnext=(Q+1) mod 8 이면 0 부터 7 까지 돌고 다시 0 이 된다. shift 의 비트 복사 규칙과 다른 산술 다음 상태다.

0 부터 5 까지 도는 mod 6 카운터는 Q=5 이면 0 으로 가는 규칙과 유효하지 않은 6/7 에서의 복구 정책을 정해야 한다. 비트 수가 3 이라는 이유로 모든 8 상태를 정상 순서에 넣는 것은 아니다.

연결과 시간 조건을 함께 확인한다

shift register 는 직렬 정보를 시간마다 옮기거나 디지털 지연을 만드는 데 쓸 수 있다. counter 는 사건이나 주기를 세는 상태로 쓸 수 있다. 기능이 달라도 저장소와 다음 상태 논리가 필요하다.

직접 연결한 두 레지스터도 hold 검사를 면제받지 않는다. 새 출력이 너무 빨리 도착하면 수신자가 이전 값을 유지해야 하는 시간이 깨질 수 있으며 클록을 느리게 하는 것만으로 해결되지 않는다.

중간 과정을 따라가는 예제

오른쪽 shift Qnext=[s,q3,q2,q1], 초기 1010, 세 직렬 입력 s=1,0,1 을 쓴다. 별도 3 비트 카운터는 초기 6 에서 증가 세 번을 한다. enable 은 항상 1 이고 reset 은 없다.

  1. 첫 shift 는[1,1,0,1]=1101, 이전 q0=0 이 나간다.
  2. 다음은 [0,1,1,0]=0110, 나가는 비트는 1 이다. 세 번째는 [1,0,1,1]=1011, 나가는 비트는 0 이다.
  3. 카운터는 6→7→0→1 이다. 비트가 밀려 나가는 것과 숫자 wrap 을 따로 센다.

shift 상태는 1101/0110/1011, 직렬 출력은 0/1/0 이다. 카운터 최종값은 1 이다.

종이와 본문으로 직접 해보기

mod 6 카운터를 5 이면 0, 0..4 이면 +1, 잘못된 6/7 이면 0 으로 정의했다. 초기 4 에서 세 에지 뒤 값은?

힌트 보기

입력 상태가 5 인지 먼저 검사한다.

풀이 보기

4→5→0→1 이다. 초기 7 이면 첫 에지에 0 으로 복구한다.

오해와 반례

한 에지에서 shift 의 각 칸을 앞부터 갱신해도 같다.

새 q3 를 즉시 q2 에 복사하면 원래 q3 가 아닌 입력 s 가 여러 칸에 퍼질 수 있다. 모두 이전 Q 를 기준으로 계산한다.

소단원 8.3

주소와 메모리 인터페이스

주소선이 네 개면 저장되는 데이터도 네 비트일까?

준비 개념과 학습 목표

준비 개념

  • 이진 주소
  • 배열
  • 읽기와 쓰기

학습 목표

  • 주소 폭·데이터 폭·총용량을 구별한다.
  • 읽기 지연과 같은 주소의 동시 접근 규칙을 명시한다.

주소는 저장 위치를 고른다

k 비트 주소는 0 부터 2^k−1 까지 위치를 고른다. 각 위치에 N 비트를 저장하면 정보 용량은 2^k×N 비트다. 주소 폭과 데이터 폭은 서로 다른 축이다.

이 단원은 워드 주소 모형을 쓴다. 한 주소가 여러 바이트 워드를 가리키는 것과 바이트 주소의 연속 범위를 섞으면 용량·오프셋 계산이 틀린다.

쓰기에는 주소·값·허용 조건이 필요하다

교육용 동기 쓰기에서 양의 에지에 WE=1 이면 WA 가 고른 위치에 WD 를 저장한다. 세 신호 모두 필요한 setup/hold 동안 유효해야 한다.

읽기는 부품에 따라 조합 읽기나 클록 기준 읽기 등 규약이 다르다. 여기서는 읽기 주소가 안정된 뒤 전파 지연 후 값이 나오는 조합 읽기를 선택한다. 모든 RAM 의 규칙이라고 일반화하지 않는다.

같은 위치의 충돌과 출력 구동을 정한다

같은 위치에서 동시에 읽고 쓰면 이 예는 쓰기 전에는 이전 값, 쓰기 후 전파 지연이 지나면 새 값을 읽는다. 다른 메모리는 old/new/no-change 등 계약이 다를 수 있다.

여러 출력을 한 선에 묶을 때 누가 구동하는지도 필요하다. 출력 enable 은 데이터를 저장하라는 WE 와 다르므로 disabled 값을 곧바로 저장된 0 으로 해석하지 않는다.

중간 과정을 따라가는 예제

4 비트 워드 주소와 16 비트 데이터인 교육용 메모리다. 초기 위치 3 의 값은 9 다. RA=3 을 안정되게 둔 뒤 WA=3, WD=12, WE=1 인 양의 에지가 온다. 읽기는 위에서 정한 조합 규칙이다.

  1. 위치는 2^4=16 개이고 용량은 16×16=256 비트=32 바이트다. 주소는 0..15 다.
  2. 쓰기 전에 안정된 읽기 출력은 9 다. 유효 에지에서 위치 3 에 12 를 저장한다.
  3. 쓰기 후 읽기 전파 지연이 지나면 RA=3 의 출력은 12 다. 에지 순간 아무 지연 없이 새 값이 보인다고 가정하지 않는다.

용량은 32 바이트이며 같은 주소의 읽기는 정한 규약에서 9→지연 후 12 다.

종이와 본문으로 직접 해보기

힌트 보기

주소 조합은 두 배가 되고 쓰기는 허용 조건을 확인한다.

풀이 보기

오해와 반례

주소선 수가 늘면 한 위치의 데이터 폭도 자동으로 늘어난다.

4→5 비트 주소의 예는 위치 수만 16→32 가 되고 워드 폭은 16 비트 그대로다.

소단원 8.4

상태 저장의 비용

비트 수를 줄이기만 하면 상태를 기억하는 회로는 언제나 좋아질까?

준비 개념과 학습 목표

준비 개념

  • 상태 수
  • log2
  • 전파 지연

학습 목표

  • 정보 비트 최소와 실제 구현 비용을 구별한다.
  • setup/hold 및 주소 회로 비용을 따로 평가한다.

정보량은 최소 칸 수를 알려 준다

구별할 상태 S 개는 적어도 ceil(log2 S)비트가 필요하다. 모든 비트 조합이 유효 상태일 필요는 없다.

이 최소는 정보 표현의 한계다. one-hot 처럼 상태마다 한 비트를 쓰는 설계는 칸이 많아도 다음 상태 판별이 단순해질 수 있다. 적은 비트가 언제나 작고 빠른 전체 회로라는 뜻은 아니다.

저장 셀 밖의 회로도 비용이다

레지스터에는 클록·enable·reset 과 연결이 있고 메모리 배열에는 주소 해독·읽기 선택·출력 회로가 있다. 저장 용량만 비교하면 총면적·전력·접근 지연을 놓친다.

SRAM 과 DRAM 은 셀 구조·읽기/쓰기·유지 조건이 다르다. DRAM 의 전하 유지는 refresh 가 필요하고 SRAM 도 전원을 끊으면 정보를 보존하는 비휘발성 저장소가 아니다.

상태 경계가 사용 가능 시간을 줄인다

단일 클록·skew 무시 모델에서 주기는 출발 레지스터의 최대 전파 지연+조합 최대 지연+수신 setup 이상이어야 한다.

hold 는 출발 최소 지연+조합 최소 지연이 수신 hold 이상인지 별도로 검사한다. 두 조건은 각각 늦고 빠른 도착에 관한 것이므로 클록 주기 하나로 모두 해결하지 않는다.

중간 과정을 따라가는 예제

상태 10 개를 표현한다. 자체 경로의 레지스터 최대 전파 지연 2 ns, 조합 최대 5 ns, setup 1 ns 다. 최소 지연은 레지스터 0.2 ns+조합 0.1 ns 이며 수신 hold 는 0.5 ns 다. skew 와 기타 여유는 제외한다.

  1. 2^3=8<10≤16=2^4 이므로 최소 4 비트다. one-hot 10 비트는 최소보다 크지만 논리 비용은 별도다.
  2. 주기는 2+5+1=8 ns 이상이다. 대응 이상 주파수 한계는 1/(8 ns)=125 MHz 다.
  3. 최소 도착 0.2+0.1=0.3 ns 는 hold 0.5 보다 0.2 ns 짧다. 주기를 8→16 ns 로 늘려도 이 같은 에지의 최소 도착은 변하지 않는다.

최소 정보 비트는 4, setup 모델 주기는 8 ns/125 MHz 다. hold 는 따로 실패하므로 이 회로를 전체 타이밍 통과로 판정하면 안 된다.

오해와 반례

저장 정보 비트가 같으면 면적·전력·속도도 같다.

주소·포트·클록·셀 기술과 다음 상태 논리의 비용이 다를 수 있다. 정보량 계산만으로 그 차이를 지우지 않는다.
