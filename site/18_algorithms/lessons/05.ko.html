소단원 5.1

상태·전이·기저조건

계단마다 통행료가 있을 때 마지막 한 걸음만 보고 가장 싼 길을 고를 수 있을까?

준비 개념과 학습 목표

준비 개념

  • 상태는 앞으로 필요한 정보를 요약하는 문제의 이름이다. 비용은 지나온 칸들의 통행료 합이다.
  • 0번에서 출발하여 번호가 커지는 방향으로 1칸 또는 2칸 이동한다. 도착 칸 i의 비용 c[i]를 내며 0번 비용은 0이다.

학습 목표

  • 상태의 의미를 문장으로 쓰고 전이와 초기값을 유도한다.
  • 불가능한 상태를 구별하고 귀납으로 정확성을 설명한다.

마지막 이동을 모두 비교한다

D[i]를 0에서 i까지 도달하는 최소 누적 비용이라 정하자. i에 오는 마지막 이동은 i−1 또는 i−2에서 시작한다. 앞부분이 같은 출발점까지의 최소 비용보다 비싸다면 그것을 더 싼 앞부분으로 바꿀 수 있어 전체도 싸진다. 따라서 두 이전 답에 도착 비용을 더해 작은 것을 고른다. 이는 모든 경로를 직접 적는 대신 같은 목적지의 답을 재사용하는 설계다.

이 경우 목적지 번호만으로 미래의 선택과 비용이 결정된다. 하지만 한번만 쓸 수 있는 무료 쿠폰이 있다면 i만 같아도 쿠폰을 이미 사용한 경로와 아직 가진 경로가 다르다. 이때 D[i,사용 여부] 같은 추가 정보가 필요하다. 작은 상태를 고르는 일보다 충분한 상태를 고르는 일이 먼저다.

경계에서 식의 뜻을 지킨다

D[0]=0이며 D[1]=c[1]이다. i≥2에서는 D[i]=c[i]+min(D[i−1],D[i−2])이다. 음수 인덱스를 참조하지 않도록 1번을 따로 두었다. 비용이 음수여도 번호가 증가하여 순환이 없으므로 이 모형의 전이는 성립한다. 음수 비용이 있다는 이유만으로 이 DAG 문제를 포기할 필요는 없다.

통행 금지 칸은 D[i]=∞로 두고 그 칸을 통과할 수 없다고 해석한다. 가능한 마지막 이동이 하나도 없으면 ∞다. 실제 구현에서 ∞를 큰 정수로 대체했다면 무조건 더하는 것이 오버플로를 일으킬 수 있으므로 먼저 도달 가능성을 검사해야 한다. 본문은 수학적 ∞를 사용한다.

D[0] = 0
D[1] = c[1]  # 1번이 허용된 경우
for i = 2 .. n:
    D[i] = c[i] + min(D[i-1], D[i-2])  # 금지 칸은 infinity

계산 순서와 증명의 순서를 맞춘다

0과 1의 답이 정확하다고 하고 i 이전의 답이 정확하다고 가정하자. 모든 i 도착 경로는 두 마지막 이동 중 하나이며 각 후보에서 가장 싼 앞부분은 이미 계산했다. 후보의 최솟값은 가능한 모든 경로보다 비싸지 않으며 실제 후보 경로로 얻을 수 있다. 이 두 방향이 함께 최소라는 결론을 준다.

상태 n+1개에 각 두 후보를 비교하므로 단위 비용 산술 모형에서 시간 O(n), 전체 표 공간 O(n)이다. 큰 정수 비용의 덧셈·비교 자체가 얼마나 걸리는지는 별도 비트 복잡도 문제다. 의존 번호가 줄어드는 것은 종료를 보장한다. 아무 재귀 식이나 저장하면 종료하는 것은 아니다.

중간 과정을 따라가는 예제

c[1..5]=(4,2,7,1,3)에서 0→5의 최소 비용을 계산하라.

  1. D0=0, D1=4다.
  2. D2=2+min(4,0)=2이고 D3=7+min(2,4)=9다.
  3. D4=1+min(9,2)=3, D5=3+min(3,9)=6이다.
  4. 최소 경로 0→2→4→5의 비용은 2+1+3=6으로 표와 일치한다.

최소 비용 6이다. 경로는 번호가 증가하며 모든 이동 차이가 1 또는 2다.

종이와 본문으로 직접 해보기

같은 비용에서 2번 칸을 금지하고 D0부터 D5까지 다시 채워라.

힌트 보기

금지 칸을 0으로 두지 말고 ∞로 두어라. 1→3으로 우회할 수 있다.

풀이 보기

D=(0,4,∞,11,12,14)다. 3은 7+min(∞,4)=11, 4는 1+min(11,∞)=12, 5는 3+min(12,11)=14다. 경로 0→1→3→5는 4+7+3=14다.

오해와 반례

DP는 방문한 위치 번호 하나만 저장하면 언제나 충분하다.

쿠폰 유무, 남은 용량, 직전에 고른 색처럼 미래에 영향을 주는 정보가 다르면 같은 번호도 다른 상태다. 이 계단 문제에서는 별도 자원이 없고 비용이 도착 칸만으로 정해져 i가 충분하다.

자기점검

D0가 0인 이유는?

답과 이유 보기

이동하지 않아 통행료를 내지 않는다.

아무 경로도 없다는 ∞와 빈 경로의 비용 0은 다르다.

D4 계산 전 필요한 값은?

답과 이유 보기

D3과 D2다.

마지막 이동 거리가 1 또는 2뿐이다.

비용이 음수이면 이 전이가 반드시 실패하는가?

답과 이유 보기

아니다.

번호가 증가하는 유한 DAG여서 비용을 무한히 줄이는 순환은 없다.

한 단계 더

쿠폰을 최대 한 번 쓸 수 있다면 D[i,0]은 미사용, D[i,1]은 사용 완료로 정의해 보자. 미사용 상태에서 일반 통행료를 내는 이동은 0→0이며 쿠폰을 쓰면 0→1에 비용 0을 더한다. 이미 사용한 상태에서는 1→1에 통행료를 더한다. 출발 D[0,0]=0, D[0,1]=∞로 두어 불가능한 이력을 만들지 않는다.

소단원 5.2

메모이제이션과 테이블

동일한 답을 여러 번 물어보는 재귀를 어떻게 한 번의 계산으로 바꿀까?

준비 개념과 학습 목표

준비 개념

  • F0=0, F1=1, Fk=F(k−1)+F(k−2)인 피보나치 수를 사용한다.
  • 재귀 호출 스택은 아직 끝나지 않은 함수의 정보를 보관한다. 캐시는 이미 계산한 답을 기억한다.

학습 목표

  • 하향식 저장과 상향식 순서의 차이를 추적한다.
  • 0이라는 유효한 답과 아직 미계산을 구별한다.

반복되는 질문에 이름표를 붙인다

F5를 곧바로 재귀로 풀면 F4와 F3를 부르고 F4도 다시 F3를 부른다. 호출 나무의 가지 수는 커져도 서로 다른 질문은 F0부터 F5까지 여섯 개뿐이다. 메모이제이션은 질문 k를 열쇠로 이미 계산한 Fk를 저장하여 다음 질문에는 그 답을 바로 반환하는 하향식 방법이다.

캐시 안에 k가 있는지를 먼저 검사하고 없을 때만 계산하여 저장한다. 답이 0인지로 캐시 존재를 검사하면 F0=0을 미계산으로 오인한다. 배열에서는 별도 visited 표시나 존재 여부를 나타내는 선택값을 사용할 수 있다. 계산 도중과 계산 완료를 구별하면 순환 의존 탐지도 가능하다.

표를 먼저 채우는 방법

상향식은 F0,F1을 정한 뒤 k=2부터 n까지 표를 채운다. 어떤 칸을 계산할 때 필요한 앞 두 칸이 이미 채워져 있다는 루프 불변식이 핵심이다. 하향식은 시작 질문에서 필요해진 상태만 찾아갈 수 있고 상향식은 지정한 표 영역을 모두 계산하는 경우가 많다. 그래서 드문 상태만 필요한 문제에서는 하향식의 장점이 있다.

피보나치는 양쪽 모두 n까지의 상태가 필요해 단위 산술 모형에서 O(n)이다. 하향식은 캐시뿐 아니라 깊이 O(n)의 호출 스택도 고려해야 한다. 상향식은 호출 스택 없이 전체 표 O(n)을 쓰며, 앞 두 값을 남기는 별도 설계를 하면 O(1)개의 수만 저장한다. 수의 자릿수 증가까지 O(1)비트라고 말하는 것은 아니다.

memo = {}
fib(k):
    if k in memo: return memo[k]
    if k == 0: value = 0
    else if k == 1: value = 1
    else: value = fib(k-1) + fib(k-2)
    memo[k] = value
    return value

저장은 잘못된 식을 고쳐 주지 않는다

상태 A가 B를 기다리고 B가 A를 기다리면 완료된 값을 캐시에 넣기도 전에 다시 A가 필요하다. 메모이제이션만으로 순환이 해결되지 않는다. 단계 수를 상태에 추가하거나 다른 순환 해결 알고리즘을 써야 한다. 먼저 의존 관계와 종료 근거를 검사한다.

O(상태 수×평균 상태당 일)이라는 계산은 캐시 조회가 상수 시간이라는 가정 아래 사용한다. 후보 수가 상태마다 다르면 전체 후보 검사 수를 더하는 것이 더 정확하다. 원소 복사·문자열 키 생성·큰 수 산술 비용도 문제에 따라 포함해야 한다.

중간 과정을 따라가는 예제

fib(5)에서 왼쪽 fib(k−1)를 먼저 부르고 F0/F1도 캐시에 저장한다. 새로 계산되는 상태와 캐시 적중을 추적하라.

  1. 새 상태 호출 순서는 5→4→3→2→1이다. F1=1을 저장한 뒤 F0=0을 새로 계산한다.
  2. F2=1을 저장한다. F3 계산의 두 번째 자식 F1은 캐시 적중이라 재계산하지 않고 F3=2다.
  3. F4의 F2와 F5의 F3도 각각 적중한다. F4=3, F5=5다.
  4. 서로 다른 새 상태는 6개, 총 호출은 9번, 그중 이미 저장된 상태 조회는 3번이다. 상향식 표는 0,1,1,2,3,5다.

같은 점화식의 F5=5를 얻는다. 호출 9번은 명시한 평가 순서·기저값 저장 정책의 종이 추적이다.

종이와 본문으로 직접 해보기

같은 규칙으로 fib(4)의 총 호출 수와 적중 수를 적고 상향식 표와 비교하라.

힌트 보기

4→3→2→1, 다음 0을 계산하고 돌아오는 두 가지를 추적한다.

풀이 보기

새 상태는 4,3,2,1,0의 5개다. F3의 F1과 F4의 F2가 두 적중이므로 총 7번 호출이다. 표 F0..F4=0,1,1,2,3과 동일하다.

오해와 반례

메모이제이션을 넣으면 모든 재귀가 종료하고 모든 상태를 O(1)에 푼다.

재귀가 감소하지 않으면 캐시에 완료값을 넣기 전 무한히 이어질 수 있다. 후보 100개를 비교하는 한 상태는 조회는 빨라도 계산에는 100후보의 일이 필요하다. 저장은 중복 계산을 줄일 뿐 정의·종료·후보 수를 대신 증명하지 않는다.

자기점검

F0=0을 미계산 표시로 쓰면 어떤 문제가 생기는가?

답과 이유 보기

값과 존재 여부를 분리해야 한다.

답과 이유 보기

의존 값이 먼저 완성되는 순서다.

피보나치에서는 작은 인덱스가 앞선다.

하향식의 공간에서 캐시만 세면 충분한가?

답과 이유 보기

아니다.

미완료 호출을 저장한 스택도 차지한다.

한 단계 더

표에 모든 상태를 저장한 경우와 두 값만 남긴 경우를 나란히 써 보자. 같은 F10=55라도 과거 F4를 즉시 다시 보여 주려면 전체 표가 편하다. 공간을 절약한다는 선택은 이후 필요한 질의가 무엇인지와 함께 결정한다. 성능 차이는 실제 실행 환경에서 따로 측정해야 한다.

소단원 5.3

해 복원과 공간 절약

최대 가치가 9라는 답만으로 어떤 물건을 챙길지 알 수 있을까?

준비 개념과 학습 목표

준비 개념

  • 각 물건을 최대 한 번 고르는 0/1 배낭이다. 무게는 양의 정수, 용량 W는 음이 아닌 정수다.
  • V[i,w]는 앞 i개 물건으로 무게 합 w 이하에서 얻을 수 있는 최대 가치다. 아무것도 안 고를 수 있어 V[0,w]=0이다.

학습 목표

  • 최적값과 선택 경로를 분리하고 동률 규칙을 정한다.
  • 공간 압축에서 갱신 방향과 복원 가능성을 검토한다.

선택 정보를 남긴다

i번째 물건의 무게 a, 가치 b라면 안 고르는 후보 V[i−1,w]와 고르는 후보 b+V[i−1,w−a]를 비교한다. w<a라면 두 번째 후보는 허용하지 않는다. 어느 후보를 골랐는지 표시하면 (n,W)에서 뒤로 이동해 실제 선택을 복원할 수 있다. 동률 때는 안 고르기로 약속하면 결과가 일관되지만 유일한 최적 집합이라는 뜻은 아니다.

복원에서 안 골랐다면 i만 1 줄인다. 골랐다면 i를 줄이고 w에서도 무게를 뺀다. 매번 i가 줄어 결국 0에 도달한다. 표만 있고 별도 선택 표시가 없더라도 두 후보 값을 다시 비교할 수 있지만 동률 규칙을 동일하게 적용해야 한다.

한 행으로 줄이면 시간이 섞일 수 있다

각 행은 바로 이전 행만 필요해 가치 계산만 목적이라면 길이 W+1의 배열로 압축할 수 있다. 0/1 배낭은 물건 하나를 처리할 때 w를 W부터 a까지 내려가며 업데이트한다. 그러면 dp[w−a]는 아직 이번 물건으로 갱신되지 않은 이전 행 값이므로 한 번만 고른다는 조건을 지킨다.

반대로 작은 w부터 올리면 같은 물건으로 방금 좋아진 dp[w−a]를 다시 이용해 물건을 여러 번 고르는 의미가 된다. 방향은 코딩 취향이 아니라 시간 층을 보존하는 조건이다. 1행 가치만 남기고 모든 과거 선택도 O(W) 공간에서 즉시 복원된다고 주장하면 안 된다. 전체 표·결정 표를 보존하거나 재계산 등을 설계해야 한다.

dp[0..W] = 0
for each item (a,b):
    for w = W down to a:
        dp[w] = max(dp[w], b + dp[w-a])

빠르다는 말의 입력 크기

n(W+1) 상태에 두 후보를 비교하므로 시간 O(n(W+1)), 전체 가치 표 공간 O((n+1)(W+1)), 한 행 가치 공간 O(W+1)이다. W≥1인 일반 표기에서는 각각 O(nW), O(nW), O(W)로 줄여 쓸 수 있지만 W=0도 허용한 이 단원에서는 +1 경계를 명시한다. 이는 무게와 용량을 정수 격자로 두는 설계다. 용량 W의 숫자를 이진수로 쓰는 길이는 W≥1에서 약 log2W여서 O(nW)는 입력 비트 수에 대한 다항 시간과 다르며 의사다항이라고 부른다. 덧셈·비교를 단위 작업으로 세는 분석이며 큰 가치 수의 비트 산술 비용은 별도다.

작은 W에는 표가 실용적일 수 있지만 W가 매우 큰 입력에서는 표 자체가 비싸다. 단순히 DP라는 이름만으로 모든 어려운 최적화가 빠르게 해결되는 것은 아니다. 복원과 공간 절약 또한 계산 목표가 최대값만인지 선택 집합까지인지에 따라 평가한다.

중간 과정을 따라가는 예제

A=(무게2,가치3), B=(3,4), C=(4,6), W=6에서 표를 만들고 최적 집합을 복원하라.

  1. 용량 0..6의 초기 행은 0,0,0,0,0,0,0이다. A행은 0,0,3,3,3,3,3이다.
  2. B행은 0,0,3,4,4,7,7이다. 용량5에서 B+A는 4+3=7이다.
  3. C행은 0,0,3,4,6,7,9다. 용량6은 max(7,6+V[2,2]=9)이므로 C를 고른다.
  4. (3,6)→(2,2)에서 B는 무게가 커 못 고르며 (1,2)에서 A를 고른다. 무게 4+2=6, 가치 6+3=9다.

A와 C를 고른 최대 가치9다. B+C는 무게7로 불가능하며 단순 가치합10을 답으로 쓰면 안 된다.

종이와 본문으로 직접 해보기

물건 하나 (무게2,가치3), 용량4에서 한 행을 오름차순과 내림차순으로 각각 갱신하라.

힌트 보기

오름차순에서 dp4가 읽는 dp2가 이번 물건을 이미 포함하는지 확인한다.

풀이 보기

초기 모두0. 오름차순은 dp2=3, dp3=3, dp4=3+dp2=6으로 같은 물건을 두 번 포함한다. 내림차순은 dp4=3, dp3=3, dp2=3이라 0/1 조건의 정답3을 지킨다.

오해와 반례

정답 가치와 한 행 배열이 있으면 어떤 과거 선택도 추가 작업 없이 복원된다.

압축 배열은 이전 행을 덮어쓴다. 선택 표시를 남기지 않으면 해당 값이 어느 물건 처리 단계에서 나왔는지 사라질 수 있다. 전체 결정표나 재계산은 별도 비용이다. 또한 동률이면 서로 다른 집합이 같은 최적값을 가질 수 있다.

한 단계 더

동률 시 선택하지 않는 규칙 대신 더 적은 물건 수를 선호하려면 상태의 값에 (가치,개수)를 함께 저장하고 가치는 크게, 동률 개수는 작게 비교할 수 있다. 그러나 최대 가치라는 원래 목표와 추가 동률 목표를 문서에 구분한다. 모든 최적해를 출력하는 일은 출력 수 자체가 매우 클 수 있다.
