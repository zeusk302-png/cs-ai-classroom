이 본문은 집필 초안입니다. 독립 내용 검토 완료. 학습자 실험과 본문 번역은 아직 수행하지 않았습니다. 언어 메뉴는 해당 언어의 과목 안내로 이동합니다.
소단원 1.1

입력·출력·전제조건

숫자 카드의 최댓값을 찾으라고 할 때 카드가 한 장도 없다면 무엇을 답해야 할까?

준비 개념과 학습 목표

준비 개념

  • 변수는 현재 값을 담는 이름이다. m←a는 a의 값을 m에 저장한다는 뜻이며 수학적 등식과 다르다.

  • 유한 배열 A는 순서가 있는 값들의 목록이다. 길이 n인 배열의 위치를 여기서는 0부터 n−1까지 센다.

  • 명제는 참 또는 거짓인 문장이다. 전제조건은 작업을 시작할 때 참이어야 하는 명제, 사후조건은 올바르게 끝난 뒤 참이어야 하는 명제다.

학습 목표

  • 같은 입력에서도 출력의 종류가 다를 수 있음을 명세로 구별한다.

  • 최댓값 명세의 존재·상한 조건과 빈 입력 정책을 적는다.

  • 알고리즘의 수학적 가정과 실제 구현의 값 범위를 구별한다.

1. 절차보다 먼저 문제를 적는다

알고리즘은 허용된 입력에서 원하는 결과를 만드는 계산 절차다. 컴퓨터 언어로 옮기기 전에도 종이에 실행할 수 있다. 입력의 형식만으로 문제는 충분히 정해지지 않는다. 정렬에서는 원래 원소를 보존하면서 순서만 바꾸어야 하고, 최댓값에서는 값 하나를 반환할지 그 위치를 반환할지 정해야 한다.

최댓값을 반환하는 이번 문제의 입력은 길이 n≥1인 유한 정수 배열 A다. 출력 m은 어떤 위치 j에서 A[j]=m인 값이어야 하며 모든 0≤k<n에 대해 A[k]≤m이어야 한다. 상한 조건만 적으면 실제 배열에 없는 큰 수를 반환해도 통과하므로 존재 조건이 꼭 필요하다.

2. 전제와 실패 정책도 결과의 일부다

배열은 계산 도중 다른 주체가 바꾸지 않고, 모든 원소의 비교가 정의되어 있다고 가정한다. 정수의 일반 순서를 쓴다. 부동소수점 NaN처럼 비교가 전순서처럼 동작하지 않는 값을 허용하려면 별도 정책과 증명이 필요하다. n=0은 이 명세의 전제 밖이다. 빈 입력까지 받는 API라면 없음이라는 표시나 명시적 오류를 반환하도록 명세를 확장할 수 있다.

여기서는 실제 기계 정수의 덧셈을 사용하지 않는다. 값 비교와 복사만 하므로 합산 오버플로 문제는 없지만 구현에서는 길이·인덱스·메모리 접근의 유효성을 여전히 확인해야 한다. 수학적 알고리즘이 정확하다는 주장과 특정 언어 구현이 안전하다는 주장은 연결되지만 동일하지 않다.

3. 명세와 후보 절차를 대조한다

첫 원소를 후보 m으로 정한 뒤 남은 원소가 m보다 클 때만 후보를 바꾼다. 후보는 늘 이미 읽은 원소 중 하나이므로 출력의 존재 조건을 지킬 수 있다. 모든 원소를 읽었을 때 상한 조건도 만족하는지는 다음 소단원의 불변식으로 증명한다. 아래 표기는 예상 동작을 설명하는 의사코드이며 실행 결과가 아니다.

m←0으로 시작하는 다른 후보는 양수 예제에서 좋아 보여도 [−8,−3]에서 0을 반환한다. 입력 중 0이 없고 0은 최댓값 −3도 아니다. 이렇게 명세의 두 조건을 따로 검사하면 잘못된 초기화의 원인을 찾을 수 있다.

전제: n = 길이(A), n ≥ 1
m ← A[0]
i ← 1
while i < n:
    if A[i] > m: m ← A[i]
    i ← i + 1
return m

중간 과정을 따라가는 예제

A=[−4,7,7,2]의 최댓값 값을 반환한다. 입력은 읽기 전용이고 같은 값이 여러 번 나와도 출력은 값 하나다.

  1. n=4이고 첫 원소 −4를 m에 저장한다. 아직 위치 1,2,3이 남아 있다.

  2. A[1]=7>−4이므로 m=7이다.

  3. A[2]=7은 현재 후보와 같아 갱신하지 않는다. A[3]=2도 더 크지 않다.

  4. 출력 7은 A[1]과 A[2]에서 실제 나타나며 모든 원소 −4,7,7,2가 7 이하이다.

m=7. 위치를 반환하는 명세였다면 동률일 때 첫 위치 또는 마지막 위치 정책을 추가해야 한다.

종이와 본문으로 직접 해보기

A=[−5,−2,−9]에서 m←0 후보와 m←A[0] 후보를 종이에 추적하라. 빈 배열도 받는 새로운 명세를 한 문장으로 적어라.

힌트 보기

각 원소와 후보를 비교한 뒤 후보를 적고, 마지막 후보가 입력 원소 중 하나인지 검사한다. 빈 배열에서는 어떤 j도 존재하지 않는다.

풀이 보기

0 후보는 세 값 모두 0보다 작으므로 0 그대로 끝나 존재 조건을 어긴다. 첫 원소 후보는 −5→−2→−2로 끝나 −2를 반환한다. 확장 명세의 한 예는 “빈 배열이면 없음, 아니면 입력 원소 중 모든 원소 이상인 값 반환”이다. 없음은 정수 0과 구별되는 표시다.

오해와 반례

큰 수를 반환하면 모든 원소 이상이므로 최댓값 명세를 만족한다.

[2,5]에서 100은 상한이지만 최댓값은 아니다. 출력이 입력 원소 중 하나라는 존재 조건도 만족해야 한다. 위치 출력·값 출력·빈 입력 정책은 사용자에게 보이는 계약이므로 구현자가 몰래 바꾸면 안 된다.

자기점검

전제조건 n≥1과 사후조건 m=A[j]는 언제 검사하는 조건인가?

답과 이유 보기

전제는 시작 때, 사후의 존재 조건은 올바른 종료 뒤다.

전제가 보장한 입력에서 절차가 어떤 결과를 만들어야 하는지 나누어 적는다.

A=[3,3]의 값 최댓값과 최댓값이 있는 위치 집합은?

답과 이유 보기

값은 3, 위치 집합은 {0,1}이다.

동일 입력이라도 요청한 출력 자료의 의미가 다르다.

음수 입력도 허용하면서 후보를 0으로 초기화해도 되는가?

답과 이유 보기

안 된다. [−1]에서 0을 반환한다.

0이 입력에 없고 실제 최댓값 −1보다 크므로 명세를 어긴다.

한 단계 더

심화: 최댓값의 첫 위치 j를 반환하도록 절차를 바꿔 보라. j←0 뒤 A[i]>A[j]일 때만 j←i로 갱신하면 동률에서 앞 위치가 남는다. ≥로 바꾸면 마지막 위치를 선택한다. 두 절차는 값 명세에서는 모두 정확하지만 첫 위치 명세에서는 서로 다르다.

소단원 1.2

루프 불변식과 귀납

아직 모든 카드를 보지 않았는데도 현재 후보가 올바르다고 말할 수 있는 범위는 어디까지일까?

준비 개념과 학습 목표

준비 개념

  • 반복문은 조건이 참인 동안 본문을 반복한다. 조건 검사는 본문 전과 각 반복 뒤에 이루어진다.

  • A[0:i]는 위치 0부터 i−1까지의 앞부분이다. i는 포함하지 않으므로 원소 수는 i다.

  • 수학적 귀납은 첫 경우가 성립하고 한 경우에서 다음 경우로 성립이 이어지면 모든 해당 자연수 경우가 성립한다는 증명 방법이다.

학습 목표

  • 불변식이 참이어야 하는 지점을 지정한다.

  • 초기 성립·보존·종료 시 사후조건 연결을 증명한다.

  • 불변식과 종료를 보장하는 감소량을 구별한다.

1. 불변식은 변수가 아니라 관계다

이 소단원에서 분석할 절차는 아래에 다시 적었다. A는 변경되지 않는 길이 n≥1의 유한 정수 배열이고 0부터 인덱스를 센다. m←v는 후보 값을 저장하는 대입이다. 정수 비교·배열 접근·대입은 모형에서 유효하고 종료하는 기본 연산이다.

루프 불변식은 정한 반복 경계마다 참인 상태 관계다. m의 값은 바뀌어도 “m은 이미 읽은 앞부분의 최댓값”이라는 문장은 계속 참일 수 있다. 반복 중 모든 명령 직후에 참일 필요는 없다. 여기서는 while 조건을 검사하기 직전에 참이라고 지정한다.

최댓값 절차의 불변식 I는 1≤i≤n, m∈{A[0],…,A[i−1]}, 그리고 모든 0≤k<i에 대해 A[k]≤m이다. 배열 A가 변하지 않는다는 전제도 계속 사용한다. 범위 조건은 증명의 장식이 아니다. i<n일 때 다음 접근 A[i]가 유효하고 종료 때 i=n임을 결론내리는 데 필요하다.

전제: n = 길이(A), n ≥ 1
m ← A[0]
i ← 1
while i < n:
    if A[i] > m: m ← A[i]
    i ← i + 1
return m

2. 초기 성립과 한 단계 보존

초기 m=A[0],i=1에서 앞부분은 첫 원소 하나이므로 m은 그 원소이고 모든 앞부분 값 이상이다. n≥1 때문에 1≤i≤n도 성립한다. 이것이 귀납의 기저다.

I가 참이고 i<n이라고 가정하자. A[i]>m이면 새 후보는 A[i]이고 이전 모든 값도 그보다 작거나 같다. 그렇지 않으면 이전 후보 m이 A[i]까지 포함하여 모든 값 이상이다. 두 경우 모두 새 후보가 확장된 앞부분의 원소라는 사실도 유지된다. 마지막 i←i+1 뒤 새 i는 n 이하이므로 조건 검사 경계에서 I가 다시 참이다.

3. 종료 시 연결과 별도의 진행 증명

종료했다면 조건 i<n이 거짓이고 I에서 i≤n이므로 i=n이다. 불변식의 앞부분이 전체 배열이 되어 최댓값 사후조건을 얻는다. 이 단계는 “종료하면 정답”이라는 부분정확성을 증명한다.

실제로 종료하는지는 감소량 V=n−i로 보인다. V는 조건 검사 지점에서 0 이상의 정수이고 본문에 들어갈 때 양수다. 각 반복 후 정확히 1 감소하므로 무한히 반복할 수 없다. 예를 들어 A=[4,−1]에서 i 증가를 빼면 i=1,m=4와 불변식은 유지되지만 n−i=1이 줄지 않고 같은 상태를 반복한다. 불변식만으로 종료가 자동 따라오지는 않는다.

조건 검사 직전 I:
1 ≤ i ≤ n
m은 A[0:i]의 원소
모든 k ∈ {0,…,i−1}에 대해 A[k] ≤ m
진행량 V = n−i

중간 과정을 따라가는 예제

A=[4,−1,6,2]에 아래에 제시한 최댓값 절차를 적용하고 매 조건 검사 직전의 (i,m,V)를 적는다.

  1. 초기 (1,4,3): 앞부분 [4]의 최댓값은 4다.

  2. −1과 비교하고 i를 늘린 뒤 (2,4,2): 앞부분 [4,−1]의 최댓값은 4다.

  3. 6과 비교한 뒤 (3,6,1): 앞부분 [4,−1,6]의 최댓값은 6이다.

  4. 2와 비교한 뒤 (4,6,0): 전체 앞부분이 배열 전체이며 i<4가 거짓이다.

세 번 반복 뒤 6을 반환한다. 각 상태가 불변식을 만족하고 진행량은 3→2→1→0이다.

종이와 본문으로 직접 해보기

0으로 시작하여 A의 값을 차례로 더하는 절차의 불변식을 만들라. s←0,i←0에서 시작하고 while i<n 안에서 s←s+A[i],i←i+1을 수행한다. A=[2,−3,5]를 추적하라.

힌트 보기

합은 빈 앞부분에서도 정의할 수 있다. 0≤i≤n과 s=앞 i개 합을 함께 적는다. 덧셈은 이번 활동에서 수학적 정수 연산이다.

풀이 보기

불변식은 0≤i≤n, s=Σ(k=0..i−1)A[k]다. 빈 합은 0으로 정의하므로 초기 성립한다. 다음 원소를 더하고 i를 늘리면 같은 관계가 보존된다. (i,s)는 (0,0)→(1,2)→(2,−1)→(3,4)이고 종료에서 전체 합 4를 얻는다. 실제 고정폭 정수 구현에는 오버플로 조건을 추가해야 한다.

오해와 반례

불변식은 반복하는 동안 값이 한 번도 변하지 않는 변수다.

예제에서 m은 4에서 6으로 변한다. 변하지 않는 것은 “처리한 앞부분의 최댓값”이라는 관계다. 또 불변식 i≥0처럼 참이지만 너무 약한 관계만 고르면 원하는 결과를 도출할 만큼 강하지 않을 수 있다.

자기점검

최댓값 불변식은 본문의 후보 갱신 직후에도 같은 i로 반드시 참이어야 하는가?

답과 이유 보기

그럴 필요 없다. 정한 경계인 조건 검사 직전에 성립해야 한다.

새 원소를 후보로 바꾸고 i를 늘리기 전에는 m이 이전 앞부분의 원소가 아닐 수 있다.

n=1일 때 m=A[0],i=1에서 반복이 없어도 증명은 성립하는가?

답과 이유 보기

성립한다. 초기 불변식과 거짓 반복 조건이 바로 사후조건을 준다.

초기 성립과 종료 연결이 0회 반복을 포함한다.

i 증가를 삭제해도 불변식만 참이면 완전정확한가?

답과 이유 보기

아니다. n>1이면 종료하지 않을 수 있다.

부분정확성에 별도의 감소량 증명이 더해져야 한다.

한 단계 더

심화: 최댓값의 첫 위치를 반환하는 불변식에 “j<i, A[j]가 앞부분 최대, 같은 최대값을 가진 앞부분 위치 중 j가 최소”를 추가하라. A[i]>A[j]일 때만 바꾸는 분기에서 최소 위치가 유지되는 이유를 동률·엄격한 증가 두 경우로 증명한다.

소단원 1.3

정확성·종료성·복잡도

정답을 찾는 절차라도 끝나지 않거나 너무 오래 걸리면 같은 해결책이라고 할 수 있을까?

준비 개념과 학습 목표

준비 개념

  • 부분정확성은 전제를 만족한 실행이 종료하면 사후조건을 만족한다는 뜻이다. 완전정확성은 이에 종료 보장까지 더한다.

  • 입력 크기 n은 여기서는 배열 원소 수다. 시간 비용은 정한 기본 연산의 횟수로 측정할 수 있다.

  • Θ(n)은 충분히 큰 n에서 비용이 양의 상수배 n 사이에 놓인다는 뜻이다. 상수는 n에 따라 달라지지 않는다.

학습 목표

  • 정확성·종료성·비용 주장을 각각 필요한 근거와 연결한다.

  • 비교 횟수와 실제 시간을 구별하고 비용 모델을 적는다.

  • 최댓값의 선형 비용과 비교 모델의 하한을 설명한다.

1. 세 가지 질문에는 세 가지 근거가 필요하다

이 소단원에서 분석할 절차는 아래에 다시 적었다. A는 변경되지 않는 길이 n≥1의 유한 정수 배열이고 0부터 인덱스를 센다. m←v는 후보 값을 저장하는 대입이다. 정수 비교·배열 접근·대입은 모형에서 유효하고 종료하는 기본 연산이다.

최댓값 절차의 사후조건은 출력이 입력에 나타나고 모든 입력 이상이라는 명제다. 불변식의 초기 성립·보존과 종료 조건을 연결하면 부분정확성을 얻는다. n−i가 0 이상의 정수로 감소한다는 증명을 더하면 모든 허용 입력에서 종료하므로 완전정확성이 된다.

시험 입력은 구현의 결함을 찾는 데 유용하지만 모든 입력의 정확성 증명을 대신하지 않는다. 특히 전제가 달라지면 증명을 다시 봐야 한다. 동시 변경 배열, 비교 불가능한 값, 유효하지 않은 인덱스를 같은 정수 배열 모델로 취급할 수 없다.

전제: n = 길이(A), n ≥ 1
m ← A[0]
i ← 1
while i < n:
    if A[i] > m: m ← A[i]
    i ← i + 1
return m

2. 비용 모델에서 정확히 세기

배열 한 원소 읽기·정수 한 단어 비교·인덱스 갱신을 상수 비용으로 가정한다. 최댓값 절차는 n−1번 A[i]>m을 비교하고, while 조건은 n번 검사한다. 후보의 실제 갱신은 0부터 n−1번까지지만 비교 수는 입력 순서와 관계없이 같다. 따라서 총 기본 연산 수는 Θ(n), 입력 배열을 제외한 추가 공간은 몇 개 변수이므로 Θ(1) 단어다.

이것은 n초라는 뜻이 아니다. 실제 시간은 CPU, 캐시, 언어, 데이터 배치와 비교 대상 크기에 영향을 받는다. 한 정수가 여러 단어를 차지하거나 문자열 비교가 길이에 따라 달라지면 비교 한 번을 상수 시간으로 놓을 수 없다. 추가 공간 Θ(1) 단어와 정확한 비트 수도 구별해야 한다. n을 나타내는 인덱스에는 적어도 로그 규모의 비트가 필요하다.

3. 더 빠를 수 있는 범위와 하한

서로 다른 n개 값 중 최대를 비교만으로 찾는 모델에서는 최대가 아닌 각 원소가 적어도 한 번 비교에서 패배해야 후보에서 제거된다. 비교 한 번은 패배자를 최대 한 개 새로 만들므로 n−1번 이상 필요하다. 선형 탐색은 이 하한과 같은 비교 수를 사용한다.

이 하한은 비교 기반으로 정확한 최대를 구하고 입력에 대한 별도 정보가 없다는 조건에 따른다. 이미 오름차순 정렬되었다는 전제가 있으면 마지막 값을 읽는 것으로 충분하다. 마지막 원소를 반환하는 상수 비용 절차는 정렬 전제에서 정확하지만 임의 배열에서는 [9,1] 반례로 틀린다. 효율성 비교는 같은 문제와 같은 전제를 대상으로 해야 한다.

중간 과정을 따라가는 예제

A=[8,3,5,1,7]에서 이 소단원에 제시한 최댓값 절차의 원소 비교·조건 검사·후보 갱신 수를 센다. 실시간 초 단위 측정은 하지 않는다.

  1. 초기 후보 8 뒤 남은 원소 3,5,1,7과 네 번 비교한다.

  2. 모든 비교는 더 큼이 거짓이므로 후보 갱신은 0번이다.

  3. 조건 i<5는 i=1,2,3,4에서 참, i=5에서 거짓으로 총 5번 검사한다.

  4. 같은 길이의 [1,3,5,7,8]에서는 비교 4번과 조건 검사 5번은 같고 후보 갱신만 4번이다.

첫 배열은 비교 4, 조건 검사 5, 후보 갱신 0. 비용의 정확한 계수는 지정한 연산 종류에 달라지지만 이 모델의 전체 성장률은 선형이다.

종이와 본문으로 직접 해보기

n=1,2,4,8일 때 비교 수 n−1과 조건 검사 수 n을 표로 적어라. 이어 while true: skip 절차가 사후조건 “끝나면 출력은 0”에 대해 부분정확하더라도 해결책으로 부족한 이유를 설명하라.

힌트 보기

끝나지 않는 실행에서는 “종료하면”이라는 함의의 전건이 성립하지 않는다. 이는 출력 0을 실제 받았다는 말이 아니다.

풀이 보기

(n,비교,조건)은 (1,0,1),(2,1,2),(4,3,4),(8,7,8)이다. 무한 반복은 종료하지 않으므로 종료 시 조건을 어기는 사례가 없어 부분정확성 주장이 공허하게 참일 수 있다. 요구한 결과를 실제 얻기 위해 완전정확성의 종료 증명이 필요하다.

오해와 반례

시간 복잡도 Θ(n)이면 입력 100개에서 언제나 100초가 걸린다.

Θ 표기는 충분히 큰 입력에서 기본 연산 수의 성장률을 비교한다. 초 단위 시간과 계수는 정하지 않는다. 두 Θ(n) 구현도 상수와 실제 하드웨어 동작이 다를 수 있으며, 단순 시험 시간만으로 모든 n의 점근적 비용을 증명할 수 없다.

자기점검

불변식은 검증했지만 종료를 증명하지 못했다. 어떤 정확성 주장만 가능한가?

답과 이유 보기

종료 시 사후조건을 연결했다면 부분정확성이다.

완전정확성에는 모든 전제 만족 입력에서 종료한다는 추가 근거가 필요하다.

n=10인 최댓값 탐색의 원소 비교와 while 조건 검사 수는?

답과 이유 보기

비교 9번, 조건 검사 10번이다.

마지막 거짓 조건 검사도 세지만 첫 원소는 다른 후보와 비교하지 않는다.

정렬 배열의 마지막 값 읽기와 임의 배열의 선형 탐색을 같은 전제의 성능 경쟁으로 볼 수 있는가?

답과 이유 보기

그럴 수 없다. 첫 절차에는 정렬이라는 추가 전제가 있다.

[9,1]에서 마지막 값은 최대가 아니므로 문제의 허용 입력이 다르다.
