소단원 2.1

상한·하한·타이트한 경계

n²보다 느리지 않다는 말만으로 정확한 성장률을 알 수 있을까?

준비 개념과 학습 목표

준비 개념

  • 입력 크기 n: 이 단원에서는 양의 정수인 항목 수다. 같은 n에도 실제 배열 값이 달라 비용이 다를 수 있다.
  • 상수: n과 무관하게 고정한 수다. 증명에서 n이 커질 때마다 c를 새로 바꾸면 하나의 점근 경계가 아니다.
  • 비용 함수: 선택한 연산 수나 비용의 합이다. 초/클록 같은 실측 단위와 동일하지 않다.

학습 목표

  • O·Ω·Θ의 정량 조건을 쓴다.
  • 최악·최선 비용 함수와 경계의 종류를 구별한다.
  • 자체 비용식의 양쪽 경계를 고정된 상수들로 증명한다.

무엇의 비용을 세는가

알고리즘 분석은 입력 x의 비용 C(x)를 먼저 정의한다. 같은 크기 n 입력들 중 최악 W(n)=max C(x), 최선 B(n)=min C(x)를 정할 수 있다. 여기서는 유한 입력 집합 또는 실제 최대/최소가 존재하는 경우를 가정한다. 평균은 그 집합의 분포를 별도로 정해야 한다. 최악 함수도 상한과 하한 둘 다 갖는다. O를 최악, Ω를 최선의 별명으로 쓰지 않는다.

단위 비용 모형에서는 정해진 기본 연산 하나를 1로 센다. 길어지는 큰 정수의 곱셈이나 긴 문자열 비교까지 무조건 1로 세려면 별도 가정이 필요하다. 아래 비용식은 이미 지정한 단위의 수학 함수이며 실제 CPU 속도나 캐시 영향까지 포함한 실측이 아니다. 무엇을 세는지 바꾸면 비용식과 경계도 다시 평가한다.

모든 충분히 큰 n에 적용하는 부등식

결국 양수인 기준 함수 g와 비음수 비용 f에 대해 f∈O(g)는 어떤 c>0,n₀≥1이 존재하여 모든 정수 n≥n₀에서 0≤f(n)≤c g(n)인 것이다. f∈Ω(g)는 어떤 c>0,n₀부터 0≤c g(n)≤f(n)이다. f∈Θ(g)는 어떤 c₁,c₂>0,n₀부터 0≤c₁g(n)≤f(n)≤c₂g(n)인 것이다. 같은 n₀는 양쪽에 필요한 시작점의 최대를 택하면 된다.

O는 상한의 집합이므로 f=n은 O(n)인 동시에 O(n²)다. 뒤의 표현도 참이지만 느슨하다. Θ는 양쪽의 같은 성장 척도를 말한다. 유한한 앞부분의 비용은 n₀로 제외할 수 있으나 입력을 무시하고 틀린 답을 빨리 반환하는 절차는 올바른 알고리즘이 되지 않는다. 비용 증명은 명세·정확성 증명의 대체물이 아니다.

작은 입력과 상수의 한계

f(n)=3n²+2n+7을 생각하자. n≥1에서 n≤n²이고1≤n²이므로3n²≤f(n)≤12n²다. c₁=3,c₂=12,n₀=1로 Θ(n²)를 직접 증명한다. 이 결론은 n마다 c를 고른 것이 아니라 동일 상수로 모든 양의 n을 덮는 것이다. 12는 최적 상한 상수일 필요가 없다.

점근적으로 더 낮은 차수여도 작은 n에서 비용이 더 클 수 있다. A(n)=100n, B(n)=n²라는 가상 비용에서는 n<100에서 A>B, n=100에서 같고 n>100에서 A<B다. 따라서 O(n)이라는 표기만으로 모든 현실 입력에서 빠름을 증명할 수 없다. 로그의 밑처럼 일정한 인자는 Θ 안에서는 흡수되지만 실제 비용 비교에는 영향을 준다.

중간 과정을 따라가는 예제

f(n)=3n²+2n+7, 양의 정수 n, 비용 단위는 가상 기본 연산이다. f의 Θ(n²) 경계를 제시하고 n=4의 값이 그 사이에 있음을 확인하라.

  1. n≥1에서2n≤2n²이고7≤7n²이므로 f≤(3+2+7)n²=12n²다.
  2. 2n+7≥0이므로 f≥3n²다. 따라서 동일 n₀=1에서 c₁=3,c₂=12를 쓸 수 있다.
  3. n=4이면 f=3×16+8+7=63이다. 하한48, 상한192가 되어 48≤63≤192다.
  4. 양쪽 부등식으로 Θ(n²)를 얻는다. 상한만으로 Θ(n²)라고 부를 수는 없고, 이 함수는 느슨한 O(n³)에도 속한다.

f∈Θ(n²), c₁=3,c₂=12,n₀=1이다. n=4의 비용 63은 48~192 범위에 있다.

힌트 보기

9≤9n으로 위를 묶고5n을 아래에 남긴다. 최악/최선 이름과 Ω 정의를 분리한다.

풀이 보기

5n≤g≤14n이므로 Θ(n), 상수 5/14와 시작점 1이다. W(n)=n도 Ω(n)이며 c=1이다. Ω가 최선 입력만 뜻하는 것은 아니다.

오해와 반례

O(n²)이면 반드시 Θ(n²)이며 Ω는 최선 비용이다.

f=n은 O(n²)이지만 Θ(n²)가 아니다. 어떤 양수c에 대해서도 n>1/c면 n<c n²여서 필요한 n² 하한이 깨진다. 최악 함수 n도 Ω(n)으로 아래를 묶을 수 있다.

답과 이유 보기

아니다.

c는 모든 충분히 큰 n에서 같은 고정 상수여야 한다.

한 단계 더

심화: 양수 계수의 다항식 f(n)=a_d n^d+…+a₀, d≥0, a_d>0, 나머지 계수 비음수라면 n≥1에서 a_d n^d≤f(n)≤(Σa_i)n^d다. 따라서 Θ(n^d)다. 음수 계수가 있을 때는 이 간단한 하한 논증을 그대로 쓰지 말고, 하위 항의 절댓값 합이 큰 n에서 선도 항의 일정 비율 이하임을 따로 보여야 한다. 또한 n의 의미가 정수의 값인지 입력 비트 길이인지를 바꾸면 같은 식의 해석이 달라진다.

소단원 2.2

재귀 트리와 마스터 정리

작은 문제 두 개로 나누면 전체 작업도 절반이 될까?

준비 개념과 학습 목표

준비 개념

  • 점화식: 큰 입력의 비용을 작은 입력의 비용과 결합 비용으로 나타낸 식이다. 처음 비용을 주는 기저 조건도 필요하다.
  • 로그: log_b n은 b를 몇 번 곱해야 n이 되는지를 말한다. b>1이고 n=b^k이면 값은 k다.
  • 재귀 트리: 각 호출을 노드로 놓고 그 호출에서 하위 호출을 제외한 비용을 적은 그림이다. 자식 호출 비용을 부모에 다시 넣어 중복 합산하지 않는다.

학습 목표

  • 재귀 층·잎의 비용을 합한다.
  • 마스터 기본형의 세 경우와 전제를 확인한다.
  • 정리가 적용되지 않는 점화식도 직접 합으로 푼다.

기저와 크기의 조건부터 쓰기

정확한 종이 예제로 T(1)=1, T(n)=2T(n/2)+n, n=2^k,k≥0을 정의한다. 기저보다 큰 크기만 재귀하고 각 호출은 더 작은 양의 크기로 줄어든다. 이 비용은 두 자식 비용과 해당 호출의 자체 n비용을 합한 것이다. n=0은 정의하지 않았으므로 빈 입력을 다루려면 별도 기저를 추가한다.

깊이 i에는 2^i개 호출, 각각 크기 n/2^i가 있다. i=0..k−1의 자체 비용 합은 층마다 n이고, 깊이 k의 잎은 n개이며 비용 1씩이다. 따라서 내부 k층 비용 nk와 잎 n을 합해 T(n)=n log₂n+n이다. 호출 수는2n−1이지만 각 호출의 비용이 다르므로 호출 수만으로 전체 비용 n log n을 대신할 수 없다.

기본형 세 경우를 정확히 적용하기

마스터 정리의 여기서 쓰는 기본형은 T(n)=aT(n/b)+f(n), 고정 a≥1,b>1, T(1)=Θ(1), 결국 양수인 비음수 결합 비용 f와 q=log_b a를 사용한다. 호출 트리라면 a는 양의 정수다. 크기 계산은 먼저 b가 정수인 n=b^k 경로에서 설명하며 일반 크기의 반올림·작은 기저 처리는 별도 적절한 조건이 필요하다. 불균등한 자식 크기에 이 식을 그대로 쓰지 않는다.

경우1: 어떤 ε>0에 대해 f=O(n^(q−ε))이면 T=Θ(n^q)다. 경우2: f=Θ(n^q)이면 T=Θ(n^q log n)다. 경우3: 어떤 ε>0에 대해 f=Ω(n^(q+ε))이고 어떤 고정 0<c<1에 대해 충분히 큰 n에서 a f(n/b)≤c f(n)이면 T=Θ(f(n))다. 마지막 부등식을 정규 조건이라 부른다. 단순히 f가 더 크다는 말로 다항 간격이나 정규 조건을 빼지 않는다. 여기의 기본형 경우2는 추가 로그 인자가 붙은 일반화 판본이 아니다.

층별 합이 조건의 이유를 보여 준다

T(n)=2T(n/2)+n²에서는 q=1이고 f=n²이다. ε=1의 간격을 가지며2(n/2)²=n²/2≤(1/2)f(n)이므로 경우3의 정규 조건을 만족한다. 층 합 n²+n²/2+…와 잎 비용은 Θ(n²)다. T(n)=4T(n/2)+n이면 q=2, f=n=O(n^(2−1))라 경우1로 Θ(n²)가 된다.

T(n)=2T(n/2)+n log₂n, T1=1은 위 기본형 세 경우 사이의 틈에 있다. f/n=log n이므로 경우 2의 같은 Θ(n)도 아니고 경우3의 다항 간격도 없다. 직접 n=2^k의 내부 층 비용 n(k−i)을 합하면 n k(k+1)/2, 잎 n이 더해져 Θ(n(log n)²)다. 정리가 적용되지 않는다는 사실은 점화식에 해가 없다는 뜻이 아니다. 다른 일반화 마스터 정리나 직접 합으로 접근할 수 있다.

중간 과정을 따라가는 예제

T1=1,T(n)=2T(n/2)+n,n=8인 정확한 종이 비용을 트리와 점화식으로 확인하라. 시간 단위는 추상 비용이다.

  1. 크기는8→4→2→1이므로 깊이 k=3이다. 내부 깊이0에서1노드×8=8이다.
  2. 깊이1은2노드×4=8, 깊이2는4노드×2=8이다. 내부 비용은24다.
  3. 잎 깊이3의8노드×T1=8을 더해 총32다. 수식8 log₂8+8=24+8=32와 같다.
  4. 다른 방향으로 T2=2×1+2=4,T4=2×4+4=12,T8=2×12+8=32다. a2/b2/q1/fn은 경우2라 Θ(n log n)이다.

정확한 T8=32다. 점근식은 성장률이며32를 실제 밀리초로 바꾸는 단위 정의는 없다.

종이와 본문으로 직접 해보기

U1=1,U(n)=2U(n/2)+n²에서 n=4의 정확값과 정규 조건을 구하라. V(n)=V(n−1)+1에는 같은 마스터 기본형을 바로 적용할 수 있나?

힌트 보기

U2를 먼저 구한다. 자식의 f를2배한 값과 부모f의 비율을 확인한다.

풀이 보기

U2=2+4=6,U4=12+16=28이다. 2f(n/2)=f(n)/2로 c=1/2다. V는 고정비율 n/b가 아니라 n−1이어서 이 기본형을 바로 적용하지 못한다. V1=1이면 직접 반복 합으로 Vn=n이다.

오해와 반례

f가 n^q보다 조금 크기만 하면 정규 조건 없이 T=Θ(f)다.

f=n log n,q=1에서는 다항 간격이 없고,2T(n/2)+f의 실제 해는 Θ(n(log n)²)다. 경우3을 쓰려면 ε의 다항 간격과 정규 조건 모두 필요하다.

자기점검

T1=1이 n log₂n 공식의 내부 비용만으로 표현되나?

소단원 2.3

분할상환·확률 분석 기초

평균적으로 싸다는 말에 반드시 주사위나 무작위 입력이 필요할까?

준비 개념과 학습 목표

준비 개념

  • 연산열: 자료 구조에 차례로 수행한 명령들의 목록이다. 한 연산의 비용과 전체 m개 비용의 합은 다른 질문이다.
  • 기댓값: 유한 경우 j마다 확률 p_j와 비용 c_j를 정했을 때 Σp_j c_j다. p_j≥0이며 합은1이어야 한다.
  • 기하합:1+2+…+2^k=2^(k+1)−1이다. 양의 정수 연산 수 m의 앞부분 비용을 묶는 데 쓸 수 있다.

학습 목표

  • 분할상환 비용과 입력 분포의 기댓값을 구별한다.
  • 확장 배열의 연산열 합을 경계짓는다.
  • 성공 탐색의 위치 분포를 명시하고 평균을 계산한다.

분포 없이 연산열 전체를 묶기

분할상환 분석은 지정한 초기 상태에서 모든 허용 연산열의 총 비용을 묶어 연산당 비용을 배분하는 방법이다. 한 번의 비싼 연산을 주변의 싼 연산이 충분히 보상한다는 논증이며 입력을 무작위로 뽑을 필요가 없다. 전체 m개에 O(m)이라도 그중 한 번은 Θ(m)일 수 있다. 최악 한 호출과 분할상환 한 호출의 경계를 섞지 않는다.

자체 append 배열을 정의한다. 처음 길이0/용량1, 양의 정수 용량이 가득 차면2배 새 배열을 확보해 모든 기존 항목을 복사하고 새 배열을 현재 배열로 재결합한 뒤 새 항목을 쓴다. 복사 하나/새 항목 쓰기 하나의 비용을 각각1로 센다. 할당은 모두 성공하고 할당·해제·초기화·검사 비용은 이번 정확 비용에서 제외하며 항목은 고정 크기다. 이 정의는 실제 Python/C 구현의 측정이 아니다.

복사 비용은 전체 합으로 갚기

m≥1개 append의 새 항목 쓰기는 m이다. 복사는 확장 때의 이전 용량1,2,4,…,2^k를 더하며 마지막 복사2^k는 m번째 이전 길이이므로2^k<m이다. 복사가 있는 경우 합2^(k+1)−1<2m이므로 총 비용<3m이다. m1처럼 복사가 없으면 총1<3이다. m0은 총0이며 엄격한0<0을 주장하지 않는다. 상한과 쓰기 m의 하한으로 총 Θ(m), 연산당 분할상환 Θ(1)이다.

새 항목 9개이면 쓰기9에 복사1+2+4+8=15가 붙어24다. 아홉 번째 한 호출만 보면 복사8+쓰기1=9로 비싸다. 하지만9개 전체 평균24/9=8/3이고 이는 이 구체적 연산열의 산술 평균이다. 어느 입력 분포도 쓰지 않았다. 임의 삭제/축소를 허용한다면 정책과 증명을 다시 정해야 하며 증가만 하는 이 경계를 그대로 확대하지 않는다.

평균 입력에는 분포를 명시한다

확률 분석의 예제로 길이 n≥1의 배열에서 목표가 정확히 한 번 존재하고 위치 J가1..n 중 균등하다고 정한다. 왼쪽부터 검사해 처음 일치에서 정지하며 비교만1로 센다. 비용 C=J이므로 E[C]=(1+…+n)/n=(n+1)/2다. 최악 n, 최선1과 다른 함수이며 성공 존재/균등 위치 조건이 핵심이다. 실제 입력이 균등이라는 경험적 주장은 하지 않는다.

이 알고리즘은 결정적이고 무작위성은 입력 위치 분포에 있다. 무작위 알고리즘은 고정 입력에서도 내부 난수 선택에 대한 기댓값을 정의할 수 있으므로 두 평균의 대상도 구별한다. 예를 들어 항상 마지막에 목표가 있으면 평균도 n이다. 없을 확률을 추가하면 실패 탐색 비용 n을 가중해 다시 계산해야 한다. 분할상환과 확률을 함께 사용하는 해싱도 있지만 각각 필요한 초기 상태·연산열·확률 가정을 따로 써야 한다.

중간 과정을 따라가는 예제

정의한 doubling 배열에9개를 append한다. 비용표와 전체 합을 구하고, 별도로 n=5 성공 탐색의 균등 위치 평균을 구하라. 두 사례는 서로 다른 모형이다.

  1. 1번째 비용1,2번째 복사1+쓰기1=2,3번째 복사2+쓰기1=3,4번째1이다. 누적은1,3,6,7이다.
  2. 5번째는 복사4+쓰기1=5,6~8번째는 각1이다. 누적12,13,14,15다.
  3. 9번째는 복사8+쓰기1=9라 총24, 평균24/9=8/3이다. 전체24<27=3m이지만9번째는 상수1의 비용이 아니다.
  4. 성공 탐색 n5의 비용은1,2,3,4,5이고 각 확률1/5다. E=15/5=3, 최악5다.24/9와3은 다른 자료 구조·분모·가정의 평균이다.

append 비용표1,2,3,1,5,1,1,1,9/전체24/평균8/3이다. 균등 성공 탐색 n5 평균3, 최악5다.

종이와 본문으로 직접 해보기

배열 append8개의 총비용과 가장 비싼 호출은? 별도 n5 탐색에서 목표가 없을 확률1/2, 존재할 때 위치는 균등이라면 기대 비교 수는?

힌트 보기

확장은 기존 용량1/2/4만 복사한다. 탐색의 성공 평균3과 실패 비용5를 가중한다.

풀이 보기

append 쓰기8+복사7=15이며5번째 호출 비용5가 최대다. 탐색 E=(1/2)×3+(1/2)×5=4다. 같은 5칸 배열이라도 분포가 달라 평균이 바뀐다.

오해와 반례

분할상환 O(1)은 무작위로 선택한 각 호출이 언제나 O(1)이라는 뜻이다.

이 배열의9번째 호출은 비용9이고 큰2의 거듭제곱 경계의 확장 비용은 계속 커진다. 보장은 지정한 초기 상태에서 전체 연산열의 합에 대한 것이며 확률과 개별 최악 비용을 뜻하지 않는다.

한 단계 더

심화: 비음수 잠재량 Φ=max(0,2s−c)를 길이 s/용량 c에 붙이고 실제 비용+Φ새−Φ옛을 분할상환 비용으로 정의하자. 초기 Φ=0이다. 확장 없는 쓰기는 Φ가 최대2 늘어 비용≤3이다. 가득 찬 c에서 확장은 실제 비용 c+1, 옛 Φ=c, 새 길이 c+1/용량2c의 Φ=2이므로 배분 비용3이다. 배분 비용을 합하면 Σ(실제 비용+Φ새−Φ옛)=실제 총비용+Φ최종−Φ초기다. 중간 잠재량은 소거되고 초기 Φ=0, 최종 Φ≥0이므로 실제 총비용≤3m−Φ최종≤3m이다. 정확 기하합의 엄격<3m과 양립하는 더 느슨한 경계다. 이 방법도 확률 없는 모든 증가 연산열의 증명이며 제외한 할당 비용을 실제 상수라고 주장하지 않는다.
