소단원 10.1

고차 상수계수식

세 번 미분이 들어간 식의 해에는 왜 세 개의 초기 정보가 필요할까?

준비 개념과 학습 목표

준비 개념

  • 상수계수2차ODE
  • 특성방정식
  • 선형독립

학습 목표

  • 고차 선형식을 특성다항식으로 바꾼다.
  • 중근과복소근의해를세어기저를구성한다.
  • 초기조건과원식대입을교차확인한다.

차수는 필요한 독립해의 수를 정한다

n차동차상수계수식 a_n y^(n)+…+a_1 y′+a_0 y=0에서 a_n≠0이다. y=e^(rx)를대입하면지수함수가공통인자로남아 a_n r^n+…+a_1 r+a_0=0을얻는다. 이다항식은미분작용을숫자r의거듭제곱으로바꿔읽는도구다.

일반해에는n개의선형독립해가필요하다. n차식에는중복도를포함해복소근n개가있지만같은근의같은지수함수를반복나열하면독립해가늘지않는다. 초기값문제에서는같은점의y,y′,…,y^(n−1)를지정해상수를결정한다. 선형식이정규화되고계수가연속인구간에서존재·유일성정리를적용한다.

중근과 복소근을 빠뜨리지 않기

실근r이k중근이면 e^(rx),x e^(rx),…,x^(k−1)e^(rx)를사용한다. 실수계수에서복소근α±iβ가각각k중근이면 x^j e^(αx)cos(βx),x^j e^(αx)sin(βx),j=0,…,k−1을사용한다. 켤레한쌍은2k개의실수독립해를준다.

예를들어r(r²+4)=0은0,±2i로3개해1,cos2x,sin2x를준다. r²(r−1)=0은0이2중근이라1,x,e^x를준다. 같은상수함수를두번쓰면초기기울기를자유롭게맞출수없다. 다항식인수분해와해개수확인이서로검산이된다.

초기조건을 맞추고 원식에도 되돌려 넣기

초기조건은상수결정에쓰지만맞춘점하나만으로미분방정식전체를만족한다고증명되지않는다. 선택한기저가원식의해인지미분해확인하고,그선형결합이초기자료도맞는지따로확인한다.

비제차식우변이0이아니면동차기저만으로일반해가되지않는다. 한특수해를더해야한다. 또계수가x에따라변하면같은특성다항식을기계적으로사용할수없다. 고차라는이유만으로상수계수법의적용조건이사라지지않는다.

중간 과정을 따라가는 예제

y‴+4y′=0,y(0)=2,y′(0)=6,y″(0)=−4를 풀라.

  1. 특성다항식r³+4r=r(r²+4)이므로 y=C0+C1cos2x+C2sin2x다.
  2. y′(0)=2C2=6이므로C2=3. y″(0)=−4C1=−4라C1=1.
  3. y(0)=C0+1=2라C0=1이다.
  4. y′=−2sin2x+6cos2x,y‴=8sin2x−24cos2x이므로y‴+4y′=0이다.

y=1+cos2x+3sin2x로원식과초기조건을모두만족한다.

종이와 본문으로 직접 해보기

y‴−y″=0의일반해를구하라. 같은점을기준으로y(0)=1,y′(0)=2,y″(0)=3이면?

힌트 보기

r²(r−1)과0의중복도를확인하라.

풀이 보기

일반해C0+C1x+C2e^x. C2=3,C1+3=2라C1=−1,C0+3=1라C0=−2. 해는−2−x+3e^x다.

오해와 반례

n차식의서로다른특성근만세면모든해를얻는다.

r²(r−1)에서는서로다른근이2개지만차수3이다. 중근0에서x를추가해야3개의독립해를얻는다.

소단원 10.2

Cauchy-Euler 방정식

계수가 x와 x²이면 지수함수 대신 어떤 모양이 미분 후 정리되기 쉬울까?

준비 개념과 학습 목표

준비 개념

  • 거듭제곱미분
  • 로그
  • 2차특성근

학습 목표

  • y=x^r로보조방정식을유도한다.
  • 양의구간에서로그변환을확인한다.
  • 0의특이점과해의구간을명시한다.

미분 차수와 x의 거듭제곱이 맞물린다

ax²y″+bxy′+cy=0,a≠0를Cauchy-Euler식이라고한다. 이소단원에서는x>0에서풀이한다. y=x^r를대입하면 ar(r−1)+br+c=0이다. y″항의r(r−1)을r²로잘못쓰지않는것이핵심이다.

양의구간에서는임의실수r의x^r가정의된다. 서로다른실근r1,r2에는x^r1,x^r2를쓰고,중근r에는x^r,x^r ln x를쓴다. 복소근α±iβ에는x^α cos(βlnx),x^α sin(βlnx)가실수기저다. 상수계수식의해에서변수x대신lnx가들어간다고읽을수있다.

t=ln x 변환으로 조건을 이해하기

Y(t)=y(e^t)로놓으면 xy′=Y′,x²y″=Y″−Y′이다. 따라서 aY″+(b−a)Y′+cY=0으로상수계수식이된다. 보조다항식은 ar²+(b−a)r+c라앞의식과같다.

이변환은x>0에서t가실수전체를움직일때가능하다. x=0은lnx를정의할수없고원식의최고차계수도0이다. 음의구간은t=ln|x|로따로다룰수있지만양·음구간의상수를자동연결할수없다. 실수지수의음수밑을무조건x^r라고쓰는것도피한다.

초기점과 특이점의 차이

양의점x0에서원식을ax²로나누면정규화계수들이연속이므로초기값두개로유일해를정한다. x=0에서는이정리의전제가없다. 어떤특별한해가0까지이어진다고해도모든해가같은방식으로연장된다는뜻은아니다.

계수의x거듭제곱이맞지않으면같은방법이적용되지않는다. x²y″+y′+y=0의y′계수는x가아니므로위변환후상수계수식이되지않는다. 식의형태확인→구간확인→보조방정식→초기조건→원식검산순서로풀이한다.

중간 과정을 따라가는 예제

x²y″−2xy′+2y=0,x>0,y(1)=3,y′(1)=4를 풀라.

  1. r(r−1)−2r+2=r²−3r+2=(r−1)(r−2)다.
  2. y=C1x+C2x². 초기조건C1+C2=3,C1+2C2=4를푼다.
  3. C2=1,C1=2라y=2x+x²다.
  4. y′=2+2x,y″=2를대입하면2x²−2x(2+2x)+2(2x+x²)=0이다.

y=2x+x²다. 양의구간에서일반해를구하고초기조건을적용했다.

종이와 본문으로 직접 해보기

x²y″−xy′+y=0,x>0에서중근기저를구하고y(1)=1,y′(1)=3을맞춰라.

힌트 보기

보조식(r−1)²이며두번째기저는x ln x다.

풀이 보기

y=x(C1+C2lnx),y′=C1+C2lnx+C2. C1=1,C2=2라y=x(1+2lnx)다. y″=2/x이고원식2x−x(3+2lnx)+x(1+2lnx)=0이다.

오해와 반례

Cauchy-Euler식도r²항을그대로특성식에쓰면된다.

x²y″는x^r에r(r−1)을곱한다. 자체식에서r²−2r+2로쓰면잘못된근을얻고원식대입에서도실패한다.

소단원 10.3

상미분방정식의 멱급수해

미지 함수 전체 대신 계수 목록을 차례로 구하면 해를 표현할 수 있을까?

준비 개념과 학습 목표

준비 개념

  • 멱급수와수렴
  • 항별미분
  • 계수비교

학습 목표

  • 급수의미분지수를맞춘다.
  • 초기조건에서자유계수를정한다.
  • 유한절단과정확한급수를구별한다.

함수의 후보를 계수로 표현하기

중심0의해를y=Σ(n≥0)a_n x^n으로찾는다. 수렴반경안에서는항별미분을정당화할수있고 y′=Σ(n≥0)(n+1)a_(n+1)x^n,y″=Σ(n≥0)(n+2)(n+1)a_(n+2)x^n이다. 같은x^n의계수를맞춰점화식을얻는다.

형식적으로계수를구한것과그급수가실제로수렴해미분방정식을만족한다는것은다른확인이다. 정규화계수가중심주변에서해석적이면보통점의멱급수해이론을사용한다. 처음몇항만찾아놓고모든x에서정확하다고주장하지않는다.

y″+2xy′+2y=0에서 직접 점화식 만들기

y″의x^n계수는(n+2)(n+1)a_(n+2)다. xy′의계수는n a_n이고n=0에서는0이다. 따라서 (n+2)(n+1)a_(n+2)+(2n+2)a_n=0이라 a_(n+2)=−2a_n/(n+2)다.

초기y(0)=a0,y′(0)=a1로두자유계수를정한다. a0=1,a1=0이면홀수계수는0,짝수는1,−1,1/2,−1/6,…이다. 즉Σ(j≥0)(−1)^j x^(2j)/j!=e^(−x²)이며모든실수x에서수렴한다. 원식을직접미분해서도같은해인지확인할수있다.

절단 다항식의 잔차는 정확성 검사의 출발점

4차절단p4=1−x²+x⁴/2는급수의처음항들이지만일반적으로정확해가아니다. p4″+2xp4′+2p4=5x⁴로남는항이있다. 작은x에서그럴듯해보여도정확잔차0과는다르다.

잔차가작으면근사의일관성을확인하는단서지만해오차의엄밀한상한을자동제공하지않는다. 초기값·구간·안정성에대한추가분석이필요하다. 전개중심을x0로바꾸면x−x0의거듭제곱을쓰고초기미분과계수를다시연결한다.

중간 과정을 따라가는 예제

y″+2xy′+2y=0,y(0)=1,y′(0)=0의급수계수a0…a6을구하고해를검산하라.

  1. a0=1,a1=0. 점화식a_(n+2)=−2a_n/(n+2)을쓴다.
  2. a2=−1,a3=0,a4=1/2,a5=0,a6=−1/6이다.
  3. 급수1−x²+x⁴/2−x⁶/6+…=e^(−x²)다.
  4. y′=−2xy,y″=(4x²−2)y이므로y″+2xy′+2y=0. 초기1/0도맞는다.

계수는[1,0,−1,0,1/2,0,−1/6],정확해는e^(−x²)다.

종이와 본문으로 직접 해보기

p4=1−x²+x⁴/2를원식에넣어잔차를구하라. x=1/2의p4값과잔차는?

힌트 보기

p4′=−2x+2x³,p4″=−2+6x²다.

풀이 보기

잔차5x⁴,x=1/2에서5/16이다. p4값1−1/4+1/32=25/32다. 정확해는e^(−1/4)이며같다고단정하지않는다.

오해와 반례

급수 처음몇항이맞으면유한다항식이ODE의정확해다.

p4의잔차5x⁴가0이아니므로반례다. 무한급수의정확성과절단근사의정확성을구별해야한다.

소단원 10.4

특이점과 해법의 한계

최고차 미분의 계수가0이면 해도 반드시 사라질까?

준비 개념과 학습 목표

준비 개념

  • 정규형ODE
  • 해석함수
  • 구간과특이점

학습 목표

  • 보통점과특이점을정규화후구별한다.
  • 정칙특이점의조건을검사한다.
  • 방법실패와해부재를구별한다.

먼저 최고차 계수로 나눈 식을 확인한다

P(x)y″+Q(x)y′+R(x)y=0를다룬다. 중심x0주변에서p=Q/P,q=R/P가해석적으로정의되면보통점의급수법이적용된다. 다항계수이고P(x0)≠0이면이조건을만족한다. 최고차계수가0인경우에는원식의공통인자제거가원점조건을어떻게바꾸는지도따로본다.

예를들어x²y″+xy′−y=0은x≠0에서 p=1/x,q=−1/x²이다. 0에서정규형계수가특이하지만양의구간해는x와1/x가있다. 따라서정규형의특이점이란말은해가아예없다는뜻이아니다. x해는0까지연장되고1/x해는그렇지않다.

정칙특이점은 보통급수보다 넓은 후보를 요구한다

해석계수이론에서x0특이점이정칙인지보려면 (x−x0)p,(x−x0)²q가x0로해석적연장되는지확인한다. 유리함수계수예에서는극의차수로검사할수있다. 위식은 xp=1,x²q=−1이므로정칙특이점이다.

이상황에서는y=x^rΣa_n x^n 같은Frobenius후보가유용하다. r이분수나음수면보통정수멱급수보다넓은함수를포함한다. 첫계수a0≠0의최저차항에서r을결정한다. 이입문단원은모든근차이/중근경우의로그해까지기계적으로구하는완전절차를요구하지않는다.

정리 전제가 깨지면 새 분석이 필요하다

x²y″+y′+y=0에서는p=1/x²,q=1/x²라xp=1/x로0에서해석적연장되지않는다. 이점은정칙특이점이아니다. 이분류는특정Frobenius보장정리를곧바로쓰지말라는뜻이지모든해부재를증명한것은아니다.

특이점에서초기값의자유도도변한다. xy″−y′=0은x>0에서y=A+Bx²다. 0까지매끄럽게연장되는해모두y′(0)=0을가져서y(0)=1,y′(0)=1은불가능하고y(0)=1,y′(0)=0은B를정하지못한다. 보통점의유일성정리전제와실제반례를함께확인한다.

중간 과정을 따라가는 예제

①x²y″+xy′−y=0,②x²y″+y′+y=0의0을분류하고①의양의구간해를구하라.

  1. ①p=1/x,q=−1/x²로0은특이점. xp=1,x²q=−1이해석적이므로정칙특이점이다.
  2. ①거듭제곱보조식r(r−1)+r−1=r²−1이라근±1이다. 해C1x+C2/x다.
  3. ②p=1/x²,q=1/x². xp=1/x가0에서발산해정칙특이점이아니다.
  4. ①의x해와1/x해의0부근거동은서로다르므로특이점분류만으로모든해의연장을같게판정하지않는다.

①정칙특이점·해C1x+C2/x,②정칙아닌특이점이다.

종이와 본문으로 직접 해보기

xy″−y′=0의y=A+Bx²를대입하고0의초기값1/0에서해를두개찾아라. 초기값1/1은?

힌트 보기

y′=2Bx,y″=2B다. 0에서모든B의기울기는0이다.

풀이 보기

잔차2Bx−2Bx=0. y=1과y=1+x²는같은초기1/0을만족한다. 초기1/1인0까지C²해는없다. 원식0대입도−y′(0)=0을요구한다.

오해와 반례

특이점이면모든해가발산하고존재하지않는다.

①의y=x는0까지매끄럽게연장된다. 반면1/x는발산한다. 구체해·구간·초기조건에따라별도로판정한다.
