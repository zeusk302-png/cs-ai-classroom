소단원 11.1

정의와 존재영역

같은 적분도 시간에 곱하는 지수의 감쇠율에 따라 수렴할 수 있을까?

준비 개념과 학습 목표

준비 개념

  • 이상적분
  • 지수함수
  • 복소수의 실수부

학습 목표

  • 단측 Laplace 변환의 적분과 변수를 구별한다.
  • 적분이 실제 수렴하는 영역을 식과 함께 적는다.
  • 조각연속·지수차수 조건을 충분조건으로 설명한다.

시간 함수에서 새 함수로

이 단원은 t≥0의 보통 함수를 대상으로 하는 단측 변환 F(s)=∫_0^∞ e^(−st)f(t)dt를 다룬다. t는 적분하는 시간 변수이고 s는 새 함수의 입력이다. 적분 기호의 ∞는 유한 상한 T까지 적분한 뒤 T→∞ 극한을 취한다는 뜻이다.

s가 실수이고 양수이면 먼 시간의 값을 작게 가중한다. s=σ+iω이면 |e^(−st)|=e^(−σt)이므로 절대수렴의 감쇠는 실수부 σ가 결정한다. 복소 계산에 익숙하지 않으면 먼저 실수 s로 계산하고 Re(s) 조건을 읽어도 된다.

존재를 보장하는 조건

매 유한 구간에서 조각연속이고 충분히 큰 t에서 |f(t)|≤Me^(at)을 만족한다고 하자. M>0과 실수 a는 고정 상수다. 이를 지수차수 조건이라 한다. Re(s)>a이면 가중한 절댓값을 Me^(−(Re(s)−a)t)로 상계할 수 있어 꼬리 적분이 수렴한다.

이는 충분조건이다. 조건을 확인하지 못했다고 변환이 없다고 결론 내릴 수는 없다. 경계 Re(s)=a는 이 부등식만으로 보장하지 않는다. 실제 적분으로 정확한 존재영역을 따져야 한다. 국소 적분 가능성도 필요해 t=0 부근의 특이점을 무시하지 않는다.

유리식의 값과 적분의 값을 구별하기

f(t)=e^(2t)이면 F(s)=1/(s−2), Re(s)>2다. s=1에서 유리식은 −1이지만 원래 적분의 integrand는 e^t여서 발산한다. 적분 정의의 존재영역과 유리식 자체가 값을 갖는 범위는 다르다. 해석적 연장은 이 단원 밖의 별도 개념이다.

e^(t²)은 어떤 고정 실수 s에서도 t²−st가 결국 양의 이차식처럼 커져 적분이 발산한다. 연속이라는 조건만으로 먼 시간의 성장을 제어할 수 없다. 반면 e^(−2t)은 s가 조금 음수여도 감쇠가 남아 존재영역이 Re(s)>−2다.

중간 과정을 따라가는 예제

f(t)=e^(2t)의 변환을 정의에서 구하고 실수 s=3,2,1을 비교하라.

  1. 유한 상한 T에서 적분은 ∫_0^T e^(−(s−2)t)dt다. s≠2이면 [1−e^(−(s−2)T)]/(s−2)다.
  2. s=3에서는 1−e^(−T)→1이므로 F(3)=1이다.
  3. s=2에서는 integrand가 1이라 적분 T→∞로 발산한다.
  4. s=1에서는 e^T−1이 커져 발산한다. 따라서 실수 영역은 s>2이며 복소 절대수렴 영역은 Re(s)>2다.

F(s)=1/(s−2), Re(s)>2다. s=2와 1의 원래 적분에는 유한 값이 없다.

종이와 본문으로 직접 해보기

f(t)=e^(−2t)의 변환과 실수 s=−1,−2에서의 존재 여부를 구하라. f(t)=1/t를 t>0에서 쓰면 지수 감쇠만으로 충분한가?

힌트 보기

첫 식의 integrand는 e^(−(s+2)t)다. 둘째는 0 근처의 적분을 확인한다.

풀이 보기

F(s)=1/(s+2), Re(s)>−2다. s=−1에서는 1이고 s=−2에서는 발산한다. 1/t는 0 근처의 적분이 발산하므로 먼 시간의 감쇠만으로 변환을 보장하지 못한다.

오해와 반례

유리식 1/(s−2)가 계산되면 s=1도 변환값 −1이다.

s=1의 원래 적분은 발산한다. 식을 얻었을 때 적분의 존재영역도 함께 기록해야 한다.

자기점검

t와 s는 같은 시간 변수인가?

답과 이유 보기

아니다.

t를 적분해 s의 함수 F를 만든다.

지수차수 a이면 경계 Re(s)=a도 자동 보장되는가?

답과 이유 보기

아니다.

꼬리 감쇠 보장은 엄격한 부등식 Re(s)>a에서 얻는다.

모든 연속 함수가 변환되는가?

답과 이유 보기

아니다.

e^(t²)은 너무 빠르게 커진다.

한 단계 더

f(t)=1을 t=1 한 점에서만 100으로 바꾸어도 변환은 바뀌지 않는다. 보통 적분은 유한 개 점의 값을 바꿔도 같다. 따라서 보통 함수의 역변환에서 연속성 가정을 빼고 각 점의 값까지 유일하게 복원한다고 주장하면 안 된다.

소단원 11.2

기본 변환쌍

시간의 상수·직선·진동은 새 변수의 어떤 식으로 나타날까?

준비 개념과 학습 목표

준비 개념

  • 부분적분
  • 삼각함수
  • 팩토리얼

학습 목표

  • 기본 함수의 변환쌍과 존재영역을 연결한다.
  • 다항식의 차수와 s의 거듭제곱을 구별한다.
  • sin과 cos의 분자를 구별한다.

기본표를 적분과 연결하기

t≥0에서 1↔1/s, t↔1/s², t²↔2/s³이다. 이들의 절대수렴 영역은 Re(s)>0이다. 비음수 정수 n에 대해 t^n↔n!/s^(n+1)이며 n=0은 0!=1로 첫 쌍과 맞는다.

부분적분으로 L[t^n]=(n/s)L[t^(n−1)]을 얻는다. 경계 t^n e^(−st)는 Re(s)>0에서 0으로 사라진다. 거듭제곱의 계수 n!을 빠뜨리지 않도록 t²와 t³의 표를 직접 확인한다.

지수와 진동의 분자

실수 a에 대해 e^(at)↔1/(s−a), Re(s)>a다. 양의 a는 성장을, 음의 a는 감쇠를 뜻한다. e^(−3t)의 분모는 s+3이며 s−3이 아니다.

실수 ω>0이면 sin(ωt)↔ω/(s²+ω²), cos(ωt)↔s/(s²+ω²), Re(s)>0이다. 사인에는 ω, 코사인에는 s가 분자다. ω=0의 사인은 영함수라 별도로 읽는다. 여기서는 실제 회로나 진동계의 계측값을 주지 않는다.

함수의 곱을 표의 곱으로 바꾸지 않기

L[t²]=2/s³인데 L[t]²=1/s⁴다. 일반적으로 시간 함수의 곱은 변환의 곱으로 가지 않는다. 다항식을 더한 경우에는 선형성으로 항별 변환을 더할 수 있다. 함수의 합과 곱을 구별한다.

표의 역방향은 해당 변환을 갖는 함수를 찾는 데 쓴다. 예를 들어 6/s⁴의 역변환은 t³이다. 연속이며 적절한 지수차수를 갖는 함수 범위에서는 변환의 유일성이 역방향의 근거가 된다. 한 점의 임의 값을 표가 복원해 주는 것은 아니다.

중간 과정을 따라가는 예제

f(t)=2+3t+4t²와 g(t)=5sin(2t)−2cos(2t)의 변환을 구하라.

  1. 상수 2는 2/s, 3t는 3/s², 4t²는 4×2/s³=8/s³이다.
  2. 따라서 F(s)=2/s+3/s²+8/s³이다.
  3. 5sin(2t)는 10/(s²+4), −2cos(2t)는 −2s/(s²+4)다.
  4. G(s)=(10−2s)/(s²+4)이며 두 식 모두 Re(s)>0에서 계산한다.

F(s)=2/s+3/s²+8/s³, G(s)=(10−2s)/(s²+4), 공통 영역 Re(s)>0이다.

종이와 본문으로 직접 해보기

6/s⁴+2/(s+3)의 역변환을 구하라. 실수 s=2에서 위 F(s)의 값을 계산하라.

힌트 보기

3!=6이고 e^(−3t)의 분모는 s+3이다.

풀이 보기

역변환은 t³+2e^(−3t)이고 원래 변환의 공통 절대수렴 영역은 Re(s)>0이다. F(2)=1+3/4+1=11/4다.

오해와 반례

sin(ωt)와 cos(ωt)는 분모가 같으니 변환도 같다.

분자가 각각 ω와 s다. ω=2, s=1이면 2/5와 1/5로 다르다.

자기점검

t³의 변환은?

답과 이유 보기

6/s⁴다.

3!=6, 분모 차수는 4다.

e^(−3t)의 분모는?

답과 이유 보기

s+3이다.

a=−3을 s−a에 넣는다.

L[t²]=L[t]²인가?

답과 이유 보기

아니다.

2/s³과 1/s⁴은 서로 다른 함수다.

한 단계 더

t^n의 부분적분 재귀를 n=1,2,3에서 전개하고 실수 s=2에 대입해 각각 1/4,1/4,3/8을 구하라. n이 늘어도 같은 수치가 우연히 나올 수 있으므로 한 점의 값과 함수 전체를 구별하라.

소단원 11.3

선형성·이동·미분

지수 가중, 시작 시간 지연, 시간 미분은 각각 같은 규칙으로 변환될까?

준비 개념과 학습 목표

준비 개념

  • 기본 변환쌍
  • 부분적분
  • 단위계단함수

학습 목표

  • 지수 가중과 시간 지연을 구별한다.
  • 미분 변환에서 초기값을 포함한다.
  • 조건과 존재영역을 함께 이동시킨다.

합과 지수 가중

변환이 함께 존재하는 영역에서 L[αf+βg]=αF+βG다. 합의 실제 존재영역이 상쇄 때문에 더 넓어질 수는 있지만 공통 영역에서는 언제나 이 계산이 유효하다.

e^(at)f(t)의 변환은 F(s−a)다. 원래 Re(s)>c에서 존재했다면 이 규칙은 Re(s)>c+a에서 적용된다. 단순히 앞에 e^(as)를 곱하는 규칙이 아니다. 이는 시간 함수에 지수 가중을 주는 s축 이동이다.

시작을 늦추는 시간 이동

a≥0에서 u(t−a)는 t<a에 0, t≥a에 1인 계단함수다. f(t−a)u(t−a)의 변환은 e^(−as)F(s)다. 지연 이후의 함수도 t−a로 읽어야 한다. 한 점 t=a에서 계단값을 다르게 정의해도 보통 적분은 같다.

u(t−2)(t−2)는 시각 2에서 시작한 직선이고 e^(−2s)/s²로 변환된다. 반면 u(t−2)t는 시각 2부터 이미 값 2인 직선으로, e^(−2s)(1/s²+2/s)다. 계단을 곱하는 것과 함수 자체를 이동하는 것은 다르다.

미분에는 초기값이 남는다

이 단원은 t≥0에서 연속이고 충분히 매끄러운 보통 함수의 미분을 다룬다. f와 f′의 변환이 존재하고 경계 e^(−st)f(t)→0인 영역에서 부분적분으로 L[f′]=sF(s)−f(0+)를 얻는다. 초기값을 빼는 항이 0쪽 경계에서 나온다.

f가 두 번 미분 가능하고 필요한 수렴 조건이 있으면 L[f″]=s²F−sf(0+)−f′(0+)다. 점프를 갖는 함수의 일반화 미분과 델타는 이 단원의 보통 미분 규칙과 따로 다룬다. 단측의 보통 미분과 전체 인과 확장의 일반화 미분을 혼동하지 않는다.

중간 과정을 따라가는 예제

f(t)=t e^(−2t)의 변환과 f′의 변환, h(t)=(t−3)u(t−3)의 변환을 구하라.

  1. t의 변환 1/s²에서 a=−2를 이동해 F(s)=1/(s+2)², Re(s)>−2다.
  2. f(0+)=0이므로 L[f′]=s/(s+2)²다.
  3. 직접 f′=e^(−2t)−2t e^(−2t)의 변환은 1/(s+2)−2/(s+2)²=s/(s+2)²로 같다.
  4. 시간 지연된 h는 e^(−3s)/s², Re(s)>0이다. 지수 가중의 분모 이동과 시간 지연의 지수 인자는 다르다.

F=1/(s+2)², L[f′]=s/(s+2)², L[h]=e^(−3s)/s²이다.

종이와 본문으로 직접 해보기

g(t)=e^t는 g(0+)=1이다. 미분 규칙으로 L[g′]를 계산하라. k(t)=t u(t−2)의 변환도 구하라.

힌트 보기

s/(s−1)에서 초기값 1을 뺀다. t=(t−2)+2를 계단과 함께 사용한다.

풀이 보기

L[g′]=s/(s−1)−1=1/(s−1), Re(s)>1이다. k의 변환은 e^(−2s)(1/s²+2/s), Re(s)>0이다.

오해와 반례

미분은 항상 s를 곱하기만 하면 된다.

보통 단측 미분에는 초기값 −f(0+)가 있다. e^t에서 이를 빼지 않으면 직접 변환과 맞지 않는다.

자기점검

e^(at)f(t)의 변환은?

답과 이유 보기

F(s−a)다.

적분의 지수를 합치면 e^(−(s−a)t)가 된다.

지연 a의 인자는 e^(as)인가?

답과 이유 보기

소단원 11.4

부분분수와 역변환

복잡한 분수를 이미 아는 변환쌍의 합으로 바꿀 수 있을까?

준비 개념과 학습 목표

준비 개념

  • 다항식의 인수분해
  • 부분분수
  • 기본 변환쌍

학습 목표

  • 서로 다른 일차 인수의 계수를 정한다.
  • 중복 인수와 이차 인수에 필요한 형태를 고른다.
  • 역변환 뒤 원식과 초기값을 확인한다.

분모를 나누되 분자를 복원하기

진유리식은 분자의 차수가 분모보다 작은 유리식이다. 그보다 큰 경우에는 다항식 나눗셈을 먼저 해야 한다. 이 소단원은 진유리식을 보통 함수의 변환쌍으로 읽는다. 다항식 부분이 나오면 델타 같은 일반화 함수가 필요할 수 있어 여기서 무리하게 역변환하지 않는다.

서로 다른 일차 인수 (s+a)(s+b)에는 A/(s+a)+B/(s+b)를 놓고 양변에 공통 분모를 곱한다. 몇 s값으로 계수를 구하더라도 마지막에 분자가 모든 s에 대해 복원되는지 확인한다. 분모의 근에서 변환이 존재한다는 뜻으로 대입한 것은 아니고 다항식 항등식의 계수를 정하는 과정이다.

중복 인수와 이차 인수

(s+a)² 같은 중복 인수에는 A/(s+a)+B/(s+a)²를 함께 둔다. 첫 항만으로는 모든 분자를 표현할 수 없다. 1/(s+a)²의 역변환은 t e^(−at)다. 반복 차수 k에는 1부터 k까지 각 거듭제곱 항을 준비한다.

실수 범위에서 인수분해되지 않는 이차식에는 일차 분자 As+B를 둔다. (s+a)²+ω² 형태로 완전제곱한 뒤 분자를 s+a와 상수로 나누면 e^(−at)cos(ωt) 및 e^(−at)sin(ωt) 쌍을 사용할 수 있다. 사인의 분자 ω도 함께 맞춘다.

확인할 식과 영역

역변환을 얻으면 다시 변환해 원래 분수를 복원한다. 미분방정식에서 얻은 분수라면 시간 함수의 초기값과 방정식도 직접 확인한다. 형식상 분해가 맞는 것과 적분의 존재영역까지 맞는 것을 함께 점검한다.

유한 개 점을 바꿔도 변환이 같으므로 보통 적분만으로 임의 함수의 모든 점값을 복원하지는 못한다. 여기서는 t≥0에서 연속인 지수·다항식·삼각함수 조합으로 역변환을 찾는다. 실제 계산 프로그램이나 시스템 응답을 실행하지 않았다.

중간 과정을 따라가는 예제

F(s)=(3s+5)/[(s+1)(s+2)]의 부분분수와 역변환을 구하라.

  1. A/(s+1)+B/(s+2)를 놓으면 3s+5=A(s+2)+B(s+1)이다.
  2. s 계수에서 A+B=3, 상수에서 2A+B=5여서 A=2,B=1이다.
  3. F=2/(s+1)+1/(s+2)이므로 f(t)=2e^(−t)+e^(−2t)다.
  4. 분자를 복원하면 2(s+2)+(s+1)=3s+5다. 이 함수의 절대수렴 영역은 Re(s)>−1이며 f(0+)=3이다.

f(t)=2e^(−t)+e^(−2t), Re(s)>−1이다.

종이와 본문으로 직접 해보기

(s+5)/(s+2)²의 역변환과 (2s+7)/[(s+1)²+9]의 역변환을 구하라.

힌트 보기

첫 분자는 (s+2)+3, 둘째는 2(s+1)+5로 나눈다.

풀이 보기

첫 식은 e^(−2t)+3t e^(−2t), Re(s)>−2다. 둘째는 2e^(−t)cos(3t)+(5/3)e^(−t)sin(3t), Re(s)>−1이다.

오해와 반례

분모가 (s+2)²이어도 A/(s+2) 하나만 있으면 된다.

공통 분모를 곱하면 A(s+2)만 생겨 모든 일차 분자를 맞추지 못한다. B/(s+2)² 항도 있어야 한다.
