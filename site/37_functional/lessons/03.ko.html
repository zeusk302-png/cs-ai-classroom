소단원 3.1

리스트·트리 재귀

큰 구조를 같은 종류의 작은 구조로 나누면 어떤 계산을 되풀이할 수 있을까?

준비 개념과 학습 목표

준비 개념

  • 유한 정수 리스트는 Nil 또는 Cons(x,xs)로 만든다. Nil은 빈 리스트이고 Cons는 정수 x와 더 짧은 리스트 xs를 연결한다. [2,5]는 Cons(2,Cons(5,Nil))이다.

  • 이 단원의 이진 트리는 Empty 또는 Node(v,l,r)이며 v는 정수, l/r은 같은 종류의 하위 트리다. 유한·비순환·공유 없는 구문트리를 가정한다. Empty는 노드가 없고 노드 수는 0이다.

  • 재귀 호출은 같은 함수를 다시 부르는 일이다. 호출은 끝나면 값을 돌려주며 대기한 바깥 계산이 그 값을 이어 사용한다. 이론의 덧셈은 수학적 정수라 오버플로가 없다.

학습 목표

  • 생성자마다 기저식과 재귀식을 쓰고 반환 순서를 추적한다.

  • 진짜 작은 하위 구조와 순환 참조를 구별하여 적용 범위를 명시한다.

노드 수와 합계가 맞으면 방문 순서도 맞았을까?

앞 본문의 유한·비순환·공유 없는 Empty/Node 트리를 그대로 쓴다. 새 중위 목록 F는 F(Empty)=[], F(Node(v,l,r))=F(l)++[v]++F(r)다. ++는 왼쪽 목록 뒤에 오른쪽 목록을 이어 붙이고 ::는 앞에 원소 하나를 붙인다. t=Node(2,Node(−3,Empty,Empty),Node(5,Empty,Empty))를 고정한다. 이 트리는 정렬 검색 트리 계약을 요구하지 않는다.

자식의 반환을 받는 순서와 결과 목록 안의 위치를 구별하자. F(t)는 [−3,2,5]다. 별도 G는 G(Empty)=[], G(Node(v,l,r))=[v]++G(l)++G(r)로 정의하며 루트를 먼저 둔다. G(t)는 [2,−3,5]다. 두 목록 모두 길이 3이고 정수 합 4여서 이 두 검사만으로 중위 순서를 확인할 수 없다. 값에 중복이 있으면 값 목록만으로 객체의 정체성까지 복원할 수도 없다.

최댓값은 빈 구조에서 정수 0을 돌려주는 규칙으로 만들지 않는다. 새 M(Empty)=None이고 Node에서는 자기 값 v와 자식의 Some 값들만 모아 최댓값 Some m을 만든다. 모든 값이 음수여도 실제 노드에서 고른 최대가 남는다. None은 값 없음이고 Some 0은 실제 최대가 0이라는 다른 결과다. 각 사례는 새 초기 구조에서 독립적으로 시작하며 목록 연결의 실제 시간이나 할당량은 측정하지 않는다.

자료의 생성 규칙에서 함수의 경우를 얻는다

리스트 합을 S(Nil)=0, S(Cons(x,xs))=x+S(xs)로 정의한다. 빈 경우에는 더 부르지 않고 0을 반환한다. 비어 있지 않은 경우에는 head를 보존한 뒤 tail의 합을 구한다. 분기 두 개는 리스트 생성자 두 개에 대응하며, 임의의 정수 값이 음수여도 이 정의는 같다.

S([2,5])는 2+S([5])이고 이어 2+(5+S([]))가 된다. 빈 경우 0을 반환하면 5+0, 그 뒤 2+5로 값이 전달된다. 더 작은 문제를 요청하는 순서와 값을 돌려받아 결합하는 순서를 구별해야 한다. 입력 목록을 바꿀 필요는 없으며 이 모형은 외부 효과가 없는 계산이다.

하위 트리 두 개의 답을 결합한다

노드 수 C(Empty)=0, C(Node(v,l,r))=1+C(l)+C(r)로 정한다. v의 숫자 크기는 개수가 아니므로 100이 들어 있는 한 노드도 개수 1이다. 이 정의는 값 합 T(Empty)=0, T(Node(v,l,r))=v+T(l)+T(r)와 다르다. 원하는 관찰량을 먼저 정해야 한다.

Node(4,Node(2,Empty,Empty),Node(7,Empty,Empty))는 자식 둘 각각 개수 1을 반환하므로 개수 3, 값 합 13이다. 순차 구현은 왼쪽 답 뒤 오른쪽 답을 구할 수 있지만 이 순수 정수 식의 결과는 그 순서와 무관하다. 실제 언어에서 예외·입출력·부동소수 반올림이 있으면 같은 순서 독립성을 자동으로 주장하지 않는다.

구조가 작아진다는 조건을 확인한다

Cons의 tail 길이는 부모 길이보다 1 작다. Node의 각 하위 트리 크기는 부모의 1+크기(l)+크기(r)보다 작다. 유한 자연수 크기는 무한히 엄격 감소할 수 없어서 각 호출 경로가 기저 경우에 도착한다. 노드가 공유되지 않는 조건에서 트리의 각 노드 방문 비용은 정수 연산을 상수 비용으로 센 모형에서 O(n)이다. 큰 정수 연산 비용이나 실제 런타임 공간까지 측정한 결과는 아니다.

순환 참조가 있는 heap graph에서 child가 자기 자신이면 작은 하위 트리 조건이 거짓이다. 또 무한 lazy 리스트에는 유한 길이 변량을 적용할 수 없다. 실제 Python 구현의 유한 리스트도 깊으면 재귀 한도를 넘을 수 있다. 수학적 유한 종료와 제한된 실행 스택의 성공을 구별한다. 공유 그래프를 펼쳐 세는 값과 서로 다른 객체 개수도 다르므로 이 단원은 공유 없는 구문트리로 고정한다.

중간 과정을 따라가는 예제

소단원 3.2

structural induction

앞의 몇 가지 트리에서 맞은 규칙을, 모든 유한 트리에 대해 어떻게 증명할까?

준비 개념과 학습 목표

준비 개념

  • 귀납은 무한히 많은 대상을 하나씩 열거하는 대신 생성 규칙에 따라 기저와 확장 단계를 증명하는 방식이다. 여기서는 유한·비순환·공유 없는 트리 Empty 또는 Node(v,l,r)를 쓴다.

  • 술어 P(t)는 트리 t에 대해 참·거짓인 주장이다. 귀납가정 IH는 특정한 더 작은 자식에 P가 이미 성립한다고 놓는 조건이지, 부모의 결론을 미리 가정하는 일이 아니다.

  • 크기 C(Empty)=0,C(Node(v,l,r))=1+C(l)+C(r)다. H(Empty)=0,H(Node(v,l,r))=1+max(H(l),H(r))는 빈 트리에서부터 세는 높이다.

학습 목표

  • 생성자별 증명 의무와 각 재귀 자식의 귀납가정을 구분한다.

  • 높이≤노드 수를 구조귀납으로 증명하고 모든 경우의 누락을 찾는다.

거울 트리의 목록은 왜 원래 목록의 역순일까?

앞 본문의 mirror는 Empty를 유지하고 Node(v,l,r)를 Node(v,mirror(r),mirror(l))로 바꾼다. 새 목표는 F(mirror(t))=rev(F(t))다. rev([])=[], rev(x::xs)=rev(xs)++[x]이며 목록의 구조값 동등성을 쓴다. 값이 같은지뿐 아니라 모든 위치가 같은지를 증명한다.

연결된 목록을 뒤집는 보조 성질 rev(xs++ys)=rev(ys)++rev(xs)가 필요하다. xs에 대한 구조귀납에서 ys는 임의의 유한 목록으로 남긴다. 빈 xs는 두 변이 rev(ys)다. x::tail에서는 tail의 귀납가정과 연결 결합법칙으로 rev(ys)++rev(tail)++[x]를 얻는다. 연결 결합법칙 자체도 첫 목록의 Nil/Cons 경우로 보일 수 있으며 ++의 교환법칙은 사용하지 않는다.

트리 기저에서는 F와 rev가 모두 []다. Node에서는 두 자식의 귀납가정을 각각 써서 F(mirror(r))++[v]++F(mirror(l))를 rev(F(r))++[v]++rev(F(l))로 바꾼다. 보조 성질을 두 연결 경계에 적용하면 이것이 rev(F(l)++[v]++F(r))임을 얻는다. 오른쪽 가정을 생략하거나 ++가 교환 가능하다고 가정하면 이 단계가 성립하지 않는다. 일반 증명과 아래 작은 손계산을 구별한다.

먼저 확인할 개념
  • 모든 생성자와 두 자식의 귀납가정

    Node 단계에 두 독립 가정이 필요하다.

  • 자식 반환을 결합하는 재귀

    앞 본문의 개수·합처럼 두 자식 반환을 결합한다. 중위 목록 F의 연결 순서는 이 보강에서 새로 정의했다.

모든 생성자 경우를 증명한다

구조귀납 원리는 P(Empty)를 보이고, 임의의 정수 v와 유한 트리 l,r에 P(l)와 P(r)를 가정하여 P(Node(v,l,r))를 보이면 모든 해당 트리 t에 P(t)가 성립한다는 것이다. 이 가정은 자료가 유한 번의 생성자로 만들어진다는 조건에 의존한다. 임의의 순환 heap graph까지 포함하는 원리가 아니다.

자식이 둘이면 귀납가정도 두 자식에 대해 필요하다. 왼쪽만 확인한 뒤 오른쪽을 건너뛰면 오른쪽이 큰 트리일 때 증명이 없다. 재귀 프로그램의 분기가 자료 생성자에 대응하는 것처럼, 증명도 모든 생성자와 모든 재귀 필드에 대응해야 한다.

높이와 노드 수의 관계를 증명한다

P(t)를 H(t)≤C(t)로 놓자. Empty에서는 0≤0이다. Node에서는 IH로 H(l)≤C(l),H(r)≤C(r)를 쓸 수 있으므로 max(H(l),H(r))≤max(C(l),C(r))≤C(l)+C(r)이다. 두 크기는 비음수 자연수이므로 마지막 부등식이 성립한다. 1을 더하면 H(Node)≤C(Node)가 나온다.

이 증명은 노드가 저장한 숫자 v가 양수인지에 의존하지 않는다. v가 −100인 경우도 동일하다. 그러나 높이를 간선 수로 정의하여 Empty 높이를 −1로 놓는 관례라면 기저식과 명제가 달라진다. 정의를 고정한 다음 증명해야 서로 다른 관례의 수치를 섞지 않는다.

관찰과 증명의 범위를 구별한다

높이 1,2인 예를 여러 개 검사하는 것은 오류를 찾는 좋은 활동이지만 모든 유한 높이의 트리를 증명하지는 못한다. 구조귀납은 임의의 자식과 임의의 생성 단계에 대해 논증하므로 크기에 상한을 미리 두지 않는다. 다만 실제 프로그램이 처리할 수 있는 메모리 크기까지 무제한이라는 결론은 아니다.

목록 연결에도 같은 원리를 쓸 수 있다. append(Nil,ys)=ys, append(Cons(x,xs),ys)=Cons(x,append(xs,ys))일 때 len(append(xs,ys))=len(xs)+len(ys)를 xs에 대해 증명한다. ys는 임의의 유한 목록으로 고정하고, 기저와 tail의 IH를 사용한다. 더 강한 결론이 필요하면 양화한 변수를 일찍 특정 값으로 제한하지 않는다.

귀납 단계의 각 변환
단계표현사용한 근거

정의 펼침

F(mirror(r))++[v]++F(mirror(l))

mirror와 F의 정의

자식 교체

rev(F(r))++[v]++rev(F(l))

오른쪽·왼쪽 IH

원래 목록 반전

rev(F(l)++[v]++F(r))

행을 위에서 아래로 읽으면 부모 결론을 미리 가정하지 않고 두 자식의 명제만 사용한다. [v]의 반전은 [v]다.

중간 과정을 따라가는 예제

H(t)≤C(t)의 증명 틀을 작성한 뒤 t=Node(0,Empty,Node(−4,Empty,Empty))에서 수치를 대조하라.

  1. Empty의 기저 의무 H=0≤C=0을 쓴다.

  2. 임의 l,r에서 IH_l:H(l)≤C(l), IH_r:H(r)≤C(r)를 적고, max(H(l),H(r))≤C(l)+C(r)를 얻는다.

  3. 부모에 1을 더해 1+max(H(l),H(r))≤1+C(l)+C(r)로 증명 단계를 닫는다.

  4. 예제의 오른쪽 자식은 H=1,C=1이고 왼쪽은 0,0이다. 부모는 H=2,C=2라 증명과 맞는다. 값 0과 −4는 노드 개수와 무관하다.

생성자 두 경우와 두 귀납가정으로 모든 해당 트리의 높이≤노드 수를 증명한다. 예제 수치는 H=2,C=2다.

조건을 바꾸어 비교하기

비대칭 구조의 비교

u=Node(−4,Empty,Node(−7,Empty,Empty))에서 F(mirror(u))와 rev(F(u))를 구하라.

  1. F(u)=[−4,−7]이다.

  2. mirror(u)는 왼쪽에 값 −7의 노드가 있고 오른쪽은 Empty다.

  3. 그 중위 목록은 [−7,−4]이며 원래 목록의 반전도 같다.

두 값은 [−7,−4]로 같다.

비교할 점

이 예제는 정리를 대조하지만 모든 유한 트리에 대한 귀납을 대신하지 않는다.

부모 결론을 가정한 잘못된 증명

Node 단계에서 처음부터 F(mirror(Node(v,l,r)))=rev(F(Node(v,l,r)))를 가정한 뒤 같은 식을 결론으로 쓴다. 고쳐라.

  1. 처음 가정은 바로 증명할 부모 명제라 순환이다.

  2. 가정을 F(mirror(l))=rev(F(l)), F(mirror(r))=rev(F(r))로 제한한다.

  3. 정의·두 자식 IH·목록 보조 성질을 차례로 써서 부모 식을 유도한다.

부모 명제를 가정하지 않고 더 작은 자식 명제만 사용한다.

비교할 점

그림에서 그럴듯해 보이는 주장도 논증의 방향을 검사해야 한다.

종이와 본문으로 직접 해보기

len(append(xs,ys))=len(xs)+len(ys)를 Nil/Cons 두 경우로 증명하라. xs=[1,2],ys=[3]에서 계산도 확인하라.

힌트 보기

len(Nil)=0,len(Cons(x,xs))=1+len(xs)다. Cons 단계에서 tail에 대한 같은 명제를 한 번 쓴다.

풀이 보기

Nil에서는 len(ys)=0+len(ys)다. Cons에서는 1+len(append(xs,ys))=1+(len(xs)+len(ys))=len(Cons(x,xs))+len(ys)로 IH와 정수 덧셈을 쓴다. 예제 연결은 [1,2,3]이며 3=2+1이다. ys=[]인 경우도 이 증명에 포함된다.

오해와 반례

부모에 P가 성립한다고 가정한 뒤 자식에서도 맞음을 보이면 구조귀납이다.

여기서 필요한 방향은 더 작은 자식의 P를 가정하여 부모의 P를 증명하는 것이다. 결론 자체를 가정하면 순환 논증이다. Empty 기저를 빠뜨리면 모든 생성의 출발도 보이지 않는다.

소단원 3.3

종료와 불변조건

답이 변하지 않는다는 식과, 언젠가 멈춘다는 식은 같은 역할일까?

준비 개념과 학습 목표

준비 개념

  • 자연수 변량은 매 진행 단계에서 엄격히 감소하며 항상 0 이상인 정수다. 무한 감소열이 없다는 자연수의 성질로 종료를 논증한다. 불변조건은 단계가 바뀌어도 유지되는 관계다.

  • 이 단원의 sum은 유한 정수 목록의 수학적 합이고 []의 합은 0이다. 정수 덧셈의 결합법칙 (a+x)+b=a+(x+b)와 항등원0을 사용한다. 부동소수 덧셈으로 같은 순서 변경을 자동 정당화하지 않는다.

  • 누산기(accumulator)는 이미 처리한 값의 요약을 인자로 전달한다. A(xs,a)는 남은 xs를 모두 더하여 a+sum(xs)를 반환해야 하는 보조함수다. 초기 호출은 A(original,0)이다.

학습 목표

  • 불변조건 보존과 종료 변량을 서로 다른 의무로 설명한다.

  • 누산기 보조함수의 강화된 명세를 모든 초기 a에 대해 증명한다.

합계와 길이 불변식만으로 반전이 맞다고 할 수 있을까?

앞 본문의 합 누산기 A와 같은 모양으로 목록 누산기 R를 만든다. R([],a)=a, R(x::xs,a)=R(xs,x::a)다. 모든 유한 목록 xs와 임의의 유한 목록 a에 R(xs,a)=rev(xs)++a라는 강화 명세가 목표다. 공개 반전은 R(original,[])로 시작한다. 임의 a는 덧셈의 숫자 누산기가 아니라 이미 만들어 둔 목록이다.

호출 경계의 관계는 rev(xs)++a=rev(original)이다. 처음에는 rev(original)++[]라 참이다. 한 단계 뒤 rev(tail)++(x::a)=rev(x::tail)++a이므로 보존된다. []에서 a=rev(original)이 되어 반환의 정당성을 얻는다. 종료는 별도로 len(xs)가 자연수이며 각 단계 1 감소한다는 식에서 얻는다.

변형 B는 B(x::xs,a)=B(xs,a++[x])이고 빈 경우는 a를 반환한다. 길이가 감소하고 len(xs)+len(a), sum(xs)+sum(a)가 보존되어도 반전은 아니다. a=[]에서 원래 순서를 그대로 모으기 때문이다. 순서 계약에는 실제 순서 관계가 필요하다. 아래 모든 비교는 새 초기 목록/누산기에서 시작한다. 수학적 종료를 언어의 깊은 재귀 성공이나 꼬리 호출 최적화로 확대하지 않는다.

먼저 확인할 개념
  • 강화 누산기 명세와 별도 변량

    초기 빈 누산기에만 맞춘 가정으로 다음 호출을 증명할 수 없다.

  • 임의 매개변수를 남기는 귀납

    xs에 귀납하되 변경되는 a는 임의 목록으로 양화한다.

누산기는 보조함수의 명세를 바꾼다

A([],a)=a, A(x::xs,a)=A(xs,a+x)로 정의한다. 이 보조함수는 항상 원래 목록의 합만 반환한다는 명제가 아니다. 남은 목록과 임의의 초기 정수 a에 대해 a+sum(xs)를 반환하는 더 강한 명세가 필요하다. a=0인 첫 호출에만 맞춘 귀납가정은 다음 호출의 a+x에 사용할 수 없다.

외부 입력 original을 고정하면 호출 경계의 불변조건은 a+sum(xs)=sum(original)이다. 초기 xs=original,a=0에서 참이다. x::tail에서 (a+x)+sum(tail)=a+(x+sum(tail))=a+sum(x::tail)이므로 다음 경계도 같은 값이다. 종료 xs=[]에서 a+0=a라 반환값이 원래 합과 같다.

종료는 남은 길이로 따로 보인다

매 재귀 호출이 진짜 tail을 사용하면 변량 len(xs)는 자연수이고 비어 있지 않은 경우에 1 감소한다. 초기 유한 길이 n에서 n번 진행 뒤 []가 된다. 불변조건은 결과가 맞다는 논증이고, 이 길이 감소는 계산이 끝난다는 논증이다. 둘을 합쳐 유한 수학적 모형에서 전체 정확성을 주장할 수 있다.

만약 같은 xs를 다음 호출에 그대로 넘기면 a를 적절히 고정하여 합 관계를 유지할 수 있어도 변량이 감소하지 않아 끝나지 않을 수 있다. 반대로 매번 tail로 줄이되 a+x 대신 a−x를 쓰면 종료는 하되 정답을 놓친다. 종료와 정당성은 서로 대체하지 않는다.

언어 실행의 제한을 계약에 추가한다

마지막 행동이 보조함수의 반환인 tail recursion은 남은 덧셈 대기가 없는 모양이다. 어떤 언어 구현은 이를 반복처럼 실행하지만 Python은 꼬리 재귀를 자동으로 일정 스택 공간으로 바꿔준다는 보장을 하지 않는다. 이 예제의 작은 정상 입력은 실행하되 모든 유한 길이에 실제 성공했다는 주장은 하지 않는다.

실제 프로그램에서는 스택·메모리·외부 예외·입력 안정성을 확인한다. 입력을 다른 실행 흐름이 바꾸면 고정 original과 남은 suffix라는 불변식 자체가 깨질 수 있다. 부동소수로 1e16,−1e16,1을 더할 때 괄호의 위치가 결과를 바꿀 수 있으므로 정수 증명을 그대로 복사하지 않는다. 여기서는 변형 실패 경로와 무한 호출을 실행하여 증명의 근거로 쓰지 않는다.

def total(xs):
    if not xs:
        return 0
    return xs[0] + total(xs[1:])

def count(t):
    if t is None:
        return 0
    v, left, right = t
    return 1 + count(left) + count(right)

def height(t):
    if t is None:
        return 0
    v, left, right = t
    return 1 + max(height(left), height(right))

def acc(xs, a):
    if not xs:
        return a
    return acc(xs[1:], a + xs[0])

tree = (4, (2, None, None), (7, None, None))
print(total([2, 5, -1]), count(tree), height(tree))
print(acc([2, 5, -1], 0), acc([4, -3], 10))

거울 트리의 결과를 다시 반전한다

각 단계는 순수 구조값 모형이다. t=Node(2,Node(−3,Empty,Empty),Node(5,Empty,Empty))다. (1) mirror(t)의 중위 목록 F와 개수·합·최대를 구하라. (2) 그 목록을 original로 삼아 R(original,[])의 모든 경계를 적고 반환을 예측하라. (3) 별도 새 초기 상태에서 같은 목록을 B(original,[])로 처리하면 개수·합 검사는 무엇을 놓치는가? (4) F(mirror(t))=rev(F(t))의 일반 증명에 필요한 자식 가정과 목록 보조 성질, R의 종료 근거를 적어라.

힌트 2

개수·합·최대와 순서 관계는 별도다. 귀납가정은 두 자식, 종료 변량은 남은 목록 길이다.

풀이와 답 확인

  1. 거울의 중위 목록은 [5,2,−3], 개수는 3, 합은 4, 최대는 Some 5다.

  2. R 경계는 ([5,2,−3],[])→([2,−3],[5])→([−3],[2,5])→([],[−3,2,5])다. rev(xs)++a는 [−3,2,5]로 유지되고 남은 길이는 3,2,1,0이다.

  3. B는 [5,2,−3]를 반환한다. 정상 R와 둘 다 길이 3·합 4·최대 5지만 순서가 다르다. 각 대안은 독립 초기 상태에서 시작한다.

  4. 일반 트리 증명은 Empty 기저, 왼쪽·오른쪽 IH, rev(xs++ys)=rev(ys)++rev(xs) 및 연결 결합법칙을 쓴다. R는 임의 a의 강화 명세와 자연수 len(xs) 감소로 정당성과 종료를 따로 보인다.
