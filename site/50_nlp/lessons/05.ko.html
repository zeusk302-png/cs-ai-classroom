소단원 5.1

문서표현과 분류

문장 전체의 분야를 정하는 일과 각 이름의 위치를 찾는 일은 같을까?

준비 개념과 학습 목표

준비 개념

  • 문서 분류는 문서 하나를 지정한 범주로 보내는 과제다.

  • 특징 벡터는 문서를 수치 목록으로 바꾼 표현이다.

  • 가중합 점수와 확률은 서로 다른 값이다.

  • IDF는 여러 문서에 흔한 단어의 비중을 조절하는 역문서빈도, TF-IDF는 문서 안 빈도와 그 비중을 결합하는 특징이다. n-gram은 연속 n개 토큰 묶음이다.

학습 목표

  • 어휘 순서를 고정해 횟수 벡터를 만든다.

  • 주어진 선형 점수와 일반화 조건을 해석한다.

어휘 순서만 바꿨는데 분류가 뒤집히면 무엇을 함께 바꿔야 할까?

앞 본문은 고정 어휘의 계수와 가중치를 같은 순서로 곱했다. 새 종이 모형의 어휘 순서는 [찬성,반대], 문서 계수는 x=(1,2), 가중치는 w=(3,−1), 절편은 b=−1이다. 점수 z=wᵀx+b가 0 이상이면 승인, 음수이면 거절한다. 점수는 보정된 확률이라고 가정하지 않는다.

원래 점수는 3−2−1=0이므로 승인이다. 새 어휘 [반대,찬성]에서는 계수 x′=(2,1)과 가중치 w′=(−1,3)를 함께 교환해야 같은 점수를 얻는다. 계수만 교환하고 이전 w를 쓰면 점수는 6−1−1=4다. 두 경우가 이번 문서에서 같은 승인이라도 점수 계약이 같다는 뜻은 아니다.

좌표 단위도 판본의 일부다. D=diag(2,1)로 계수를 x′=Dx로 바꿀 때 가중치를 w′=D⁻ᵀw로 바꾸면 내적과 절편을 포함한 점수가 보존된다. 여기서는 x′=(2,2), w′=(3/2,−1)로 점수 0을 얻는다. 가중치를 그대로 쓰면 점수는 3이다. 새 IDF나 다른 정규화는 단순 이름 변경으로 처리하지 않는다.

별도 L1 정규화 모형은 비영 x를 x/(x₁+x₂)로 바꾸되 w,b를 그대로 쓴다. 원래 문서의 점수는 3(1/3)−2/3−1=−2/3이므로 거절이다. 공통 양수 배수 문서는 같은 정규화 계수를 갖지만 절편이 있는 원시 계수 점수는 배수와 함께 선형으로만 변하지 않는다. 빈 계수 (0,0)는 정규화 분모가 0이므로 별도 거절/대체 규약이 필요하다.

먼저 확인할 개념
  • 계수·가중치·절편의 점수

    어휘 좌표와 절편을 보존하는 변경인지 직접 내적으로 확인한다.

  • 평가 계약의 명시

    같은 최종 라벨만으로 전처리와 점수 계약이 동일하다고 판단하지 않는다.

원고를 숫자 표현으로 바꾸기

자체 어휘를 [쉽다, 어렵다, 수학]으로 정하고 문서에서 각 토큰이 나온 횟수를 벡터에 넣는다. [2,0,1]은 쉽다 두 번, 어렵다 0번, 수학 1번이다. 같은 단어 순서를 모든 문서에서 유지해야 내적의 같은 성분이 같은 특징을 뜻한다.

이 bag-of-words 표현은 토큰 순서를 잃는다. 순서만 다른 두 문서는 같은 횟수 벡터가 될 수 있다. 부정어 범위· 문맥을 알아야 하는 과제를 모든 단어 횟수만으로 해결한다고 단정하지 않는다. n-gram이나 문맥 표현은 다른 정보를 추가하는 후속 방식이다.

점수에 결정 규칙을 붙이기

주어진 가중치 w와 절편 b로 z =wᵀx +b를 계산한다. 자체 규칙은 z ≥0이면 쉬움, 음수면 어려움으로 분류한다. 점수는 실수 전체를 가질 수 있으므로 z 3.5를 확률 3.5라고 부르면 안 된다. sigmoid를 적용한 확률 해석은 별도 모형과 학습 조건이 필요하다.

이 예제의 w =[2, −3,.5],b =−1은 우리가 정한 숫자다. 실제 자료로 학습하거나 검증한 분류기가 아니다. 주어진 규칙의 종이 예측과 새 학생 문서에서의 정확도 관측을 구분한다.

분류 목표와 자료 분리

하나의 범주만 붙이는 one-of와 여러 범주를 붙이는 multi-label은 출력 규칙이 다르다. 어떤 범주가 정답인지와 라벨 지침을 먼저 적는다. 문서 전체 라벨이 맞아도 그 안의 모든 이름 위치나 유형을 찾았다는 뜻은 아니다.

실제 학습에서는 어휘·IDF· 모형 선택에 평가 자료의 정보를 미리 섞지 않는다. 훈련 문서를 암기한 높은 성능은 새 문서의 일반화 증거가 아니다. 시간· 작성자별 중복을 고려해 자료를 분리하고 다수 클래스 기준선과 비교하는 평가 계획을 세운다.

중간 과정을 따라가는 예제

어휘 [쉽다, 어렵다, 수학],w =[2, −3,.5],b =−1,z ≥0이면 쉬움이다. 문서 벡터 A[2,0,1],B[0,1,2]의 점수와 라벨을 구하라.

  1. A는 2·2 +(−3)·0 +.5·1 −1 =3.5다.

  2. B는 2·0 +(−3)·1 +.5·2 −1 =−3이다.

  3. 결정 규칙에 따라 A 쉬움,B 어려움이다. 점수 3.5와 −3은 확률이 아니다.

  4. 이는 주어진 벡터/ 가중치의 계산 결과다. 학습 데이터가 없으므로 모델 학습 성공이나 실제 정확도라고 보고하지 않는다.

A 3.5 →쉬움,B −3 →어려움이다.

조건을 바꾸어 비교하기

같은 라벨이 숨기는 다른 점수

어휘 순서 변경에서 계수만 바꾼 경우와 가중치도 바꾼 경우를 계산하라.

  1. 계수만 교환하면 3×2−1×1−1=4다.

  2. 가중치도 교환하면 −1×2+3×1−1=0이다.

  3. 둘 다 승인이나 두 점수는 다르다.

두 점수는 각각 4와 0이며 라벨은 모두 승인이다.

비교할 점

한 문서의 최종 라벨 일치는 좌표 호환성 검사가 아니다.

정규화는 새로운 입력 계약이다

원시 x=(1,2)와 L1 정규화 입력의 판정을 비교하라.

  1. 원시 점수는 0이다.

  2. 정규화 계수는 (1/3,2/3)이다.

  3. 정규화 점수는 −2/3이다.

원시는 승인, 정규화는 거절이다.

비교할 점

정규화 후 같은 가중치를 사용하는 변경은 여기서 판정을 바꾼다.

종이와 본문으로 직접 해보기

문서 C[0,0,2]와 D[1,1,0]를 판정하고 z =0의 처리도 적어라.

힌트 보기

곱한 성분을 더한 뒤 절편 −1과 명시한 등호 규칙을 적용한다.

풀이 보기

C는 0 +0 +1 −1 =0이라 쉬움이다. D는 2 −3 −1 =−2라 어려움이다. 등호 규칙을 바꾸면 C 라벨도 달라진다.

오해와 반례

문서 횟수 벡터가 같으면 원문 의미도 반드시 같다.

단어 순서를 바꿔도 횟수는 같을 수 있다. 공백으로 토큰화한 “Alice helps Bob”과 “Bob helps Alice”는 Alice/helps/Bob의 횟수가 각각 1로 같지만, 도움의 방향은 반대다. 한국어의 조사나 어미까지 포함하는 토큰화에서는 같은 벡터인지 별도로 확인해야 한다.

연습 1 · 값과 상태 예측

별도 문서 y=(0,1)에 어휘 순서 교환을 적용하라. 입력만 바꾼 경우와 두 표를 함께 바꾼 경우의 판정은?

힌트 1

원래 점수도 계산한다.

힌트 2

교환 뒤 입력은 (1,0)이다.

풀이와 답 확인

  1. 원래 점수는 −2로 거절이다.

  2. 입력만 교환하면 점수 2로 승인이다.

  3. 가중치도 교환하면 점수 −2로 거절을 유지한다.

입력만 교환하면 승인으로 뒤집히며 두 표의 교환은 거절을 보존한다.

흔한 오답에서 다시 생각하기

앞 문서의 라벨이 같았으므로 모든 문서도 호환된다.

y의 점수 2 대 −2가 전체 호환성 주장의 반례다.

연습 2 · 오류 찾아 고치기

정규화가 공통 양수 배수를 제거하므로 원시 분류도 공통 배수에 불변이라는 주장을 반박하라. 별도 비음수 실수 계수 x/2도 허용하는 입력 모형에서 x와 x/2를 비교한다.

힌트 1

절편은 한 번만 더한다.

힌트 2

원래 x의 점수 0과 x/2=(1/2,1)의 점수를 비교한다.

풀이와 답 확인

  1. x의 점수는 0으로 승인이다.

  2. x/2=(1/2,1)의 원시 점수는 3/2−1−1=−1/2로 거절이다.

  3. 정규화 입력은 둘 다 (1/3,2/3)이며 점수는 −2/3이다. 별도 2x의 원시 점수는 1이다.

원시 분류는 x의 승인에서 x/2의 거절로 바뀐다. 정규화 점수는 모두 −2/3이다.

흔한 오답에서 다시 생각하기

x/2의 점수는 원래 점수 0의 절반인 0이다.

절편은 한 번만 더한다. z(x/2)=z(x)/2+b/2=−1/2이며 원시 점수의 배수 불변성을 주장할 수 없다.

연습 3 · 직접 만들어 보기

가역 D로 입력을 바꿀 때 모든 문서 점수를 보존하는 가중치와 저장 계약을 구성하라.

힌트 1

변환한 내적을 원래 내적과 같게 만든다.

힌트 2

어휘·단위·절편의 판본을 함께 기록한다.

풀이와 답 확인

  1. x′=Dx와 w′=D⁻ᵀw이면 w′ᵀx′=wᵀx다.

  2. 절편 b를 유지하면 전체 점수도 같다.

  3. 어휘 순서·변환 D·가중치·절편 및 미정의 입력 정책을 한 계약으로 묶는다.

역전치 가중치와 같은 절편은 모든 입력 점수를 보존한다.

흔한 오답에서 다시 생각하기

singular D에도 역전치 공식을 적용한다.

역행렬이 없는 경우에는 이 증명을 사용할 수 없다. 잃은 좌표 정보의 복원 조건이 별도로 필요하다.

연습 4 · 선택 심화

선택 심화는 기본 연습 뒤 더 탐구하고 싶을 때 풀어 보세요.

빈 계수 (0,0)를 정규화할 때 0/0을 자동으로 영벡터로 바꾸는 정책과 요청 거절 정책을 비교하라.

힌트 1

수학적 정규화가 정의되는지 먼저 판단한다.

힌트 2

대체 뒤 점수와 원래 정의역을 구별한다.

풀이와 답 확인

  1. L1 정규화는 분모 0으로 미정의다.

  2. 영벡터 대체를 별도로 선언하면 점수는 b=−1로 거절이다.

  3. 입력 자체 거절은 분류 라벨 반환과 다른 결과이며 두 정책을 보고서에서 분리한다.

대체 점수 −1은 정책의 결과이며 0/0의 계산값이 아니다.

분류한 문서와 입력 검증에서 제외한 문서는 평가 대상 규약에 따라 다르게 집계된다.

소단원 5.2

개체명인식

서울이라는 글자만 보면 도시인지 단체 이름의 일부인지 확정할 수 있을까?

준비 개념과 학습 목표

준비 개념

  • NER는 텍스트에서 이름 언급의 범위와 유형을 찾는 과제다.

  • PER/ORG/LOC는 이 모형의 사람/ 조직/ 장소 유형이다.

  • span은 시작과 끝으로 정한 연속 토큰 구간이다.

  • offset은 원문에서 시작·끝 문자 위치, entity linking은 이름 언급을 특정 실체 ID에 연결하는 과제다.

학습 목표

  • 토큰 경계와 엔티티 유형을 함께 지정한다.

  • 문맥· 주석 지침과 실체 연결을 구별한다.

같은 글자로 보이는 원문의 span 번호도 같을까?

앞 본문은 토큰 번호의 반열린 span을 사용했다. 새 설정은 원문 판본과 Unicode 코드 포인트 번호를 먼저 고정한다. 원문 R은 A, e, 결합 악센트 U+0301, 공백, B라는 다섯 코드 포인트의 문자열이다. NFC로 정규화한 N은 A, é U+00E9, 공백, B라는 네 코드 포인트다. 표시 모양이 비슷해도 위치 표는 다르다.

R에서 악센트가 붙은 이름의 span은 [1,3)이고 B의 span은 [4,5)다. N에서는 각각 [1,2), [3,4)다. N의 B 위치 [3,4)를 R에 그대로 사용하면 공백을 가리킨다. 정규화된 이름 문자열만 저장하면 원문의 정확한 span 복원이 자동으로 되지 않는다.

현재 한 사례의 경계 대응은 R의 경계 0→N의 0, 1→1, 3→2, 4→3, 5→4다. R의 경계 2는 결합 묶음 내부이므로 이 NFC 결과에 같은 문자 구분 경계로 대응하지 않는다. 임의 구간을 모두 가역 대응한다고 가정하지 않는다. 원문 판본·위치 단위·전처리·대응표를 함께 저장하고 허용 경계만 변환한다.

독립 한국어 원문 서울대학에서 토크나이저가 전체를 한 토큰 [0,4)로 묶는다고 하자. 단일 토큰 BIO는 서울만의 원문 [0,2)를 표현할 수 없다. B-LOC를 붙이면 현재 토큰 전체 [0,4)를 표시한다. 토큰을 서울/대학으로 나누거나 문자 span을 별도로 보유해야 경계를 표현할 수 있다. 문자열·토큰 경계 문제와 어느 실제 장소를 뜻하는지의 연결 문제도 다르다.

먼저 확인할 개념
  • 원문 경계와 개체 유형

    같은 표시 이름이어도 원문 위치와 토큰 경계를 함께 확인한다.

  • BIO의 토큰 단위 span

    한 토큰 내부의 부분 경계를 BIO가 표현할 수 있는지 따진다.

범위와 유형을 함께 찾기

문서 전체를 분야 하나로 분류하는 것과 달리 NER는 어느 토큰부터 어디까지가 이름인지, 그 이름이 어떤 유형인지 찾는다. 여러 단어 이름은 한 엔티티일 수 있다. 대부분의 일반 단어는 엔티티가 아닐 수 있으므로 이름이 아닌 구간도 구별한다.

자체 토큰열 [민수, 는, 서울, 대학, 에, 갔다]는 토큰화 규칙을 이미 정한 교육 자료다. “서울 대학”은 이 예제의 가상 조직명 전체라고 주석한다. 현실의 대학 이름이나 모든 한국어 분절 기준을 자동 결정한 사례가 아니다.

문맥과 주석 지침의 책임

서울에 도착했다의 서울은 장소일 수 있지만 “서울”이라는 스포츠 팀을 별도로 정한 글에서는 조직일 수 있다. 같은 문자열만 보고 항상 LOC로 붙이는 사전 규칙은 문맥을 놓친다. 말뭉치가 정한 유형과 경계 지침을 읽고 모호한 사례를 기록한다.

표기· 약칭· 조사가 붙은 언어에서는 토큰화와 원문 문자 offset을 연결해야 한다. 여기서는 조사 토큰을 이름 범위에서 제외한다. 다른 자료가 조사 포함 정책을 쓰면 결과를 같은 평가라고 섞지 않는다.

이름 언급과 실세계 식별을 나누기

PER라고 표시했다고 그 사람이 누구인지 고유 ID까지 확인한 것은 아니다. 이름 언급을 찾는 NER와 지식 베이스의 실체에 연결하는 entity linking은 서로 다른 과제다. 동명이인 두 명은 같은 문자열과 유형을 가질 수 있다.

학습 자료의 사람 이름을 대량 수집했다고 실제 개인 정보 처리· 자동 식별이 검증되었다고 표시하지 않는다. 기본 활동은 가상 문장의 종이 라벨이다. 실제 자료에는 동의· 품질· 언어별 지침과 별도 평가 계획이 필요하다.

소단원 5.3

BIO 라벨과 span 평가

거의 모든 단어 라벨이 맞아도 엔티티 점수가 낮을 수 있을까?

준비 개념과 학습 목표

준비 개념

  • BIO에서 B는 새 span 시작,I는 같은 유형의 계속,O는 외부다.

  • 이 단원은 겹치지 않는 연속 span과 BIO2 규칙을 쓴다.

  • TP/FP/FN은 정확히 맞춘/ 잘못 예측한/ 놓친 span 수다.

  • P는 정밀도, R은 재현율, micro는 여러 문장의 TP/FP/FN을 먼저 합해 계산하는 평가 방식이다. invalid는 정한 라벨 규칙에 어긋난 상태다.

학습 목표

  • BIO를 범위 목록으로 변환한다.

  • 경계· 유형 정확 일치의 P/R/F1을 계산한다.

큰 문서에서 잘한 모델과 작은 문서에서 잘한 모델 중 누가 우세할까?

새 평가 모형은 문서 ID까지 포함한 정확 span을 비교한다. 문서 D1의 정답 개체는 9개, D2는 1개다. 중복 정답은 없고 두 모델은 정답 외 예측을 하지 않는다. A는 D1에서 9개를 모두 찾고 D2에서는 아무것도 찾지 않는다. B는 D1에서 5개, D2에서 1개를 찾는다. 실제 코퍼스 결과가 아닌 집계 반례다.

A의 전체 TP/FP/FN은 9/0/1이므로 micro F1은 18/19다. B는 6/0/4이므로 micro F1은 12/16=3/4다. 문서별 F1의 같은 비중 평균을 여기서 문서 macro F1이라 정의하면 A는 (1+0)/2=1/2, B는 (5/7+1)/2=6/7이다. micro에서는 A, 문서 macro에서는 B가 우세하다.

D2에서 A는 예측 개수 0이므로 precision은 정의되지 않는다. 다만 정답 개수 1이 있어 F1의 직접 식 2TP/(2TP+FP+FN)은 0으로 정의된다. 이 직접 식과 precision의 미정의를 구별한다. 정답도 예측도 없는 별도 문서는 F1 직접 식의 분모도 0이므로 현재 평균에 추가하려면 처리 정책을 먼저 정해야 한다.

독립 중복 사례에서는 정답 span 하나와 같은 예측 span 두 줄을 둔다. 집합 규약은 예측을 중복 제거하여 TP=1, FP=0, FN=0으로 F1=1이다. 줄별 일대일 대응 규약은 한 줄만 TP이고 나머지가 FP라 TP=1, FP=1, FN=0으로 F1=2/3이다. 문서 검증 실패로 제외한 출력과 빈 정상 출력도 같은 결과로 숨기지 않는다.

먼저 확인할 개념
  • 정확 span과 합계 기반 F1

    문서별 평균과 전체 TP/FP/FN 합계를 다른 평가 목표로 구별한다.

  • 정답 경계와 개체 유형

    문서 ID·구간·유형을 모두 포함해 일대일 정확 대응을 정의한다.

연속 라벨을 구간으로 읽기

B-PER는 한 사람 언급을 새로 시작하고 이어진 I-PER는 같은 언급의 일부다. O를 만나거나 다른 B가 나오면 이전 범위가 끝난다. 같은 유형 B-PER 두 개가 연속해도 두 언급이다. IO로 B를 없애면 그 구분을 잃을 수 있다.

이 BIO2 모형에서 문장 처음 I-ORG나 O 뒤 I-ORG는 올바른 시작 규칙을 어긴다. 거절할지 B로 복구할지 평가 전에 정책을 정한다. 여기서는 invalid로 기록하고 조용히 정답으로 바꾸지 않는다.

엔티티 전체를 정답 단위로 보기

평가의 정확 일치는 시작· 끝· 유형이 모두 같아야 한다. 정답 ORG[2,4)와 예측 ORG[2,3)은 겹치지만 정확 일치가 아니다. 예측은 FP 하나, 놓친 정답은 FN 하나로 세며 부분 겹침 점수를 이 기준에 섞지 않는다.

토큰 대부분이 O인 자료에서 모두 O로 예측하면 토큰 정확도가 높을 수 있어도 이름을 하나도 찾지 못한다. 토큰 정확도와 span F1은 서로 다른 질문에 답한다. 문장 ID도 범위에 포함해 다른 문장의 같은 인덱스를 같은 언급으로 혼동하지 않는다.

정밀도와 재현율을 나누기

P =TP/(TP +FP)는 예측 중 정확한 비율,R =TP/(TP +FN)는 정답 중 찾은 비율이다. F1 =2TP/(2TP +FP +FN)는 두 비율의 조화 평균이다. 단순히 P와 R을 산술 평균하지 않는다. 여러 문장은 TP/FP/FN을 합하는 micro와 문장별 평균 등의 정책을 구별한다.

분모 0의 경우 어떤 값을 보고할지 정해야 한다. 예측이 전혀 없다고 자동 P1로 표시하지 않는다. 평가 규칙· 잘못된 BIO 처리· 중복 span 처리· 토큰화 지침을 함께 적는다. 아래 숫자는 자체 span 집합 계산이며 실제 모델을 평가한 결과가 아니다.

풀이와 답 확인

  1. TP는 1이다.

  2. 남은 예측은 FP=1이고 FN=0이다.

  3. precision은 1/2, recall은 1, F1은 2/3이다.

평가의 실제 참여 개수와 합계·평균·중복 대응 규약을 분리한다.

풀이와 답 확인

  1. 원시 점수와 두 표 교환 점수는 각각 0으로 승인이다. 입력만 교환한 점수는 4로 승인이다. L1 정규화 점수는 −2/3으로 거절이다. y의 입력만 교환은 점수 2로 승인이나 두 표 교환은 점수 −2로 거절을 유지한다.

  2. N의 B 구간 [3,4)는 R의 [4,5)에 대응한다. N 번호를 원문에 직접 사용하면 공백을 표시한다. 서울대학 한 토큰의 B-LOC는 전체 [0,4)를 가리키므로 서울만의 [0,2)를 표현하지 못한다.

  3. A의 micro F1은 18/19, 문서 macro는 1/2다. B의 micro는 3/4, 문서 macro는 6/7이다. micro는 A, 문서 macro는 B가 우세하다.

  4. 중복을 제거한 집합은 F1=1이고 줄별 일대일 대응은 F1=2/3이다. O/I-ORG는 strict 검증 실패지만 명시한 복구 뒤에는 O/B-ORG로 F1=1이다. 복구 점수와 원래 검증 실패를 별도 보존한다.

좌표 교환의 호환성은 y의 점수 2 대 −2로 구별된다. 원문 B 구간은 [4,5)이며 한 토큰의 부분 서울 경계는 표현하지 못한다. micro에서는 A, 문서 macro에서는 B가 우세하다. 중복 규약의 F1은 1과 2/3이며 복구 뒤 점수 1은 원래 BIO2의 유효성을 뜻하지 않는다.

해결한 뒤 점검할 것

  • 어휘·가중치·절편·정규화의 같은 판본과 미정의 입력을 구별한다.

  • 원문 판본·코드 포인트 단위·허용 경계 대응·토큰 표현 한계를 보존한다.

  • 전체 대상과 참여/제외·micro/문서 macro·중복/복구 규약을 명시한다.

  • 종이 계산을 실제 분류/NER 성능이나 학생 시험으로 확대하지 않는다.

    실제 104–148행의 정규화 형식·NFD/NFC 합성·문자 순서 변경과 호환 형식의 정보 손실 경계를 읽었다. 원문 R/N 및 허용 경계 대응은 자체 사례이며 그림 픽셀 검토를 주장하지 않는다.

기본 세 소단원 전체와 실제 세 primary 관련 범위를 읽었다. 원시 점수 0, 좌표 함께 교환 0, 입력만 교환 4와 별도 y의 2 대 −2, 역전치 짝 보존, 원시 x/2의 −1/2와 2x의 1 및 정규화 −2/3을 손대조했다. R의 길이 5와 N의 길이 4, 두 이름 구간과 B의 경계 대응, 결합 내부 경계의 한계를 확인했다. 한 토큰과 두 토큰 BIO의 원문 구간을 대조했다. A/B의 micro 18/19와 3/4, 문서 macro 1/2와 6/7, 문서 복제/빈 값 대체의 2/3와 17/21, 중복 규약의 1 대 2/3 및 복구 뒤 1을 손계산했다. 저장본 전체·모든 12과제/전이와 여섯 선수 HTML/의미 앵커를 재독하고 검증했다.
