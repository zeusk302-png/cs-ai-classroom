소단원 4.1

분포가설

사전을 주지 않고 어떤 단어가 나오는 주변만 보여 주어도 의미를 짐작할 수 있을까?

준비 개념과 학습 목표

준비 개념

  • 벡터 (2,1,1)은 순서가 정해진 세 특성의 값을 담는다. 좌표 이름이 달라지면 같은 숫자도 뜻이 달라진다.
  • 내적 v·w 는 같은 위치 성분의 곱을 더한 값이다. 길이 ‖v‖는 성분 제곱 합의 제곱근이다.
  • 말뭉치는 선택해 모은 언어 자료다. 한 자료의 자주 나오는 표현이 전 세계 언어 사용을 대표하지는 않는다.

학습 목표

  • 문맥을 정하고 계수 벡터를 구성한다.
  • 코사인으로 문맥 패턴을 비교하고 의미 해석의 한계를 말한다.

주변에서 얻는 단서

낯선 단어가 먹다·접시·요리 주변에 자주 나오면 음식과 관련이 있다고 추측할 수 있다. 비슷한 문맥에 나오는 단어의 의미도 비슷한 경향이 있다는 생각을 분포가설이라 한다. 이것은 문맥의 통계가 유용한 단서라는 주장이지 같은 주변이면 사전 의미가 완전히 같다는 논리적 정리가 아니다.

문맥의 정의를 먼저 정한다. 여기서는 목표 단어 근처에 나타난 먹다·자다·놀다 세 단어를 좌표로 세는 가상 표를 쓴다. 실제 연구에서는 좌우 몇 토큰, 문서 전체, 문법 의존 관계 등 다른 정의를 쓸 수 있다. 거리·방향·문장 경계를 바꾸면 얻는 정보도 달라진다.

벡터로 패턴 비교하기

어휘별 행과 문맥별 열을 만들고 셀에 동시 등장 횟수를 적으면 문맥 계수 행렬이다. 원시 횟수는 자주 나온 단어일수록 커지기 쉬우므로 큰 내적만으로 의미가 가까움을 단정하기 어렵다. 여러 단어의 패턴을 같은 좌표 체계에서 비교해야 한다.

0 이 아닌 두 벡터의 코사인은 cos(v,w)=(v·w)/(‖v‖‖w‖)다. 양수 상수를 곱해 길이만 늘려도 코사인은 같다. 비음수 계수에서는 0 부터 1, 부호를 가진 일반 표현에서는 −1 부터 1 이다. 영벡터는 분모가 0 이므로 이 식으로 유사도를 정할 수 없다.

비슷함의 뜻을 제한하기

동의어, 같은 종류, 같은 사건에 관련된 단어는 서로 다른 관계다. 빵과 식사는 관련이 있고 고양이와 개는 같은 큰 범주이지만 서로 동의어가 아니다. 뜨겁다와 차갑다는 모두 물·날씨·온도 주변에 나올 수 있다. 문맥의 높은 유사도가 반대 의미를 자동으로 구별하지 않는다.

한 단어에 한 벡터를 주는 정적 표현은 여러 뜻을 섞을 수 있다. 한국어 눈의 신체 의미와 날씨 의미가 하나로 합쳐지면 이웃 단어가 뒤섞인다. 자료의 장르·시기·언어와 어휘 빈도를 기록하고 과제에 맞는 평가를 해야 한다. 2 차원 그림의 근접만으로 원래 고차원 거리나 의미를 증명하지 않는다.

중간 과정을 따라가는 예제

좌표를 (먹다,자다,놀다)로 고정하자. 가상 계수 cat=(2,1,1), dog=(4,2,2), spoon=(3,0,0)의 내적과 코사인을 비교하라.

  1. cat·dog=8+2+2=12 이고 ‖cat‖=√6, ‖dog‖=√24=2√6 이다.
  2. cos(cat,dog)=12/(√6·2√6)=1 이다. dog 의 빈도가 두 배라도 방향은 같다.
  3. cat·spoon=6 이고 ‖spoon‖=3 이므로 cos(cat,spoon)=6/(3√6)=2/√6≈0.816 이다.
  4. 이 표에서 cat 과 dog 가 더 비슷하다. 세 좌표를 학습용으로 골랐으므로 현실 의미나 실제 말뭉치 측정의 결론은 아니다.

가상 표의 cat–dog 코사인 1, cat–spoon 약 0.816. 빈도와 방향 정보를 구별했다.

종이와 본문으로 직접 해보기

종이에 bird=(1,1,0), fish=(2,0,0), empty=(0,0,0)를 추가하라. cat 과 각각의 코사인을 구하고 empty 를 순위에 넣을 수 있는지 설명하라.

힌트 보기

bird 의 길이는 √2, fish 는 2 다. 영벡터에서는 나누기를 하기 전에 멈춘다.

풀이 보기

cat·bird=3 이므로 3/√12=√3/2≈0.866 이다. cat·fish=4 이므로 4/(2√6)=2/√6≈0.816 이다. empty 는 코사인 미정의다. 프로그램에서 대체 점수를 정한다면 그것은 별도 정책이며 식의 계산값이라고 부르지 않는다.

오해와 반례

코사인 1 이면 두 단어의 의미가 완전히 같다.

위 가상 cat 과 dog 는 서로 다른 단어인데 동일 방향을 가진다. 정보가 세 좌표로 압축되면 구별이 사라질 수 있다. 같은 계수 벡터가 같은 모든 문장 의미를 보장하지 않는다.

답과 이유 보기

행렬에 들어가는 관측 사건 자체가 달라진다.

한 단계 더

단위 벡터 u=v/‖v‖, z=w/‖w‖에서는 ‖u−z‖²=2−2cos(v,w)다. 제곱을 펼치면 ‖u‖²+‖z‖²−2u·z=1+1−2cos 가 나온다. 따라서 같은 자료에서 정규화한 벡터의 유클리드 거리와 코사인 순위는 반대 방향으로 일치한다. 정규화하지 않은 원시 벡터 거리에는 이 식을 적용할 수 없다. 의미 평가의 타당성까지 이 대수식이 보장하지는 않는다.

소단원 4.2

word2vec와 negative sampling

단어 벡터를 사람이 직접 적는 대신 주변 단어 예측으로 배울 수 있을까?

준비 개념과 학습 목표

준비 개념

  • σ(z)=1/(1+e^(−z))는 0 과 1 사이이며 σ(0)=1/2, σ(−z)=1−σ(z)다.
  • 미분으로 손실의 증가 방향을 찾고 작은 양수 학습률 η만큼 반대 방향으로 움직인다.
  • 관측된 중심–문맥 쌍과 확률 분포에서 뽑은 잡음 쌍은 생성 과정이 다르다.

학습 목표

  • skip-gram 의 두 벡터 표와 내적 점수를 설명한다.
  • 관측 쌍과 잡음 쌍의 손실·기울기를 계산하고 softmax 와 구별한다.

주변 예측으로 학습하기

word2vec 는 단어 벡터를 학습하는 방법들의 묶음이다. 여기서는 중심 단어에서 주변 단어를 예측하는 skip-gram 을 다룬다. 각 단어의 중심 역할 벡터 v 와 문맥 역할 벡터 u 를 따로 두고 쌍의 점수를 z=uᵀv 로 계산한다. 두 역할이 있다고 두 단어 뜻이 독립적으로 확정되는 것은 아니다.

전체 softmax 는 p(c|w)=exp(u_cᵀv_w)/Σ_j exp(u_jᵀv_w)로 어휘 전체에 대한 확률 합을 1 로 만든다. 어휘가 크면 분모의 많은 점수가 비용이 된다. 계산을 줄이려는 다른 목적이 negative sampling 이다. 중심 벡터만 추출할지 두 표를 조합할지도 표현 사용 단계의 선택이다.

관측 쌍 대 잡음 쌍

관측 쌍 한 개와 잡음 문맥 k 개를 뽑았을 때 최소화할 손실을 L=−logσ(z_positive)−Σ_i logσ(−z_negative,i)로 둔다. 관측 쌍은 점수를 높이고 잡음 쌍은 낮추도록 만든다. 여기서 negative 는 반대말이 아니라 잡음 생성 과정의 라벨이다. 우연히 의미 있는 문맥이 잡음으로 뽑힐 수도 있다.

잡음 분포와 k 를 명시해야 실험을 재현할 수 있다. 원 논문은 빈도의 3/4 승을 합으로 나누어 정규화한 분포가 자기 실험에서 유용했다고 보고했다. 모든 언어·자료에 고정 최적값이라는 뜻은 아니다. σ(u_cᵀv_w)는 관측/잡음 구별 점수이지 어휘 전체에서 합이 1 인 p(c|w)는 아니다.

기울기와 비용의 의미

중심 v 의 미분은 ∇_v L=(σ(z_positive)−1)u_positive+Σ_i σ(z_negative,i)u_negative,i 다. 첫 항의 계수는 음수이므로 하강 갱신은 관측 문맥 방향으로 v 를 당긴다. 잡음 항은 양수이므로 그 방향에서 밀어낸다. 여러 방향이 섞이면 개별 점수의 변화는 함께 계산해야 한다.

실제 학습에서는 문맥 벡터도 갱신하고 많은 쌍을 반복한다. 다음 예는 기울기 원리를 분리하려고 문맥 벡터를 고정한 한 번의 종이 계산이다. 손실 감소나 근접한 벡터가 현실 언어 이해·공정한 의사결정을 검증한 결과는 아니다. 학습 프로그램은 실행하지 않았다.

중간 과정을 따라가는 예제

v=(1,0), 관측 u_p=(0,1), 잡음 u_n=(−1,0), k=1 에서 중심 벡터만 학습률 η=0.2 로 한 번 갱신하라.

  1. z_p=0, z_n=−1 이다. σ(0)=0.5, σ(−1)=1/(1+e)≈0.26894 다.
  2. 손실은 −log(1/2)−logσ(1)=log2+log(1+e^(−1))≈1.00641 이다. 로그는 자연로그다.
  3. ∇_v L=(−0.5)(0,1)+0.26894(−1,0)=(−0.26894,−0.5)다.
  4. v_new=v−0.2∇=(1+0.2/(1+e),0.1)≈(1.05379,0.1)이다.
  5. 고정한 문맥과 다시 내적하면 관측 점수 0.1, 잡음 점수 약 −1.05379 다. 이 한 번에서는 원하는 두 방향으로 움직였다.

중심 벡터 약 (1.05379,0.1). 관측 점수가 커지고 잡음 점수는 작아졌다. 전체 학습의 성능은 판단하지 않았다.

종이와 본문으로 직접 해보기

v=(0,0), u_p=(1,0), u_n=(0,1), η=0.4, k=1 로 바꾸어 손실·기울기·새 점수를 종이에 구하라.

힌트 보기

두 점수 모두 0 이므로 σ=1/2 다. v−η∇에서 부호를 확인한다.

풀이 보기

초기 L=2log2, ∇=(−1/2,1/2), 새 v=(0.2,−0.2)이다. 관측 점수 0.2 와 잡음 −0.2 로 두 손실이 모두 log(1+e^(−0.2))가 되어 합 2log(1+e^(−0.2))<2log2 다. 문맥 표는 고정한 조건이다.

오해와 반례

negative sampling 의 σ 점수는 다음 단어 확률이며 negative 는 반대말이다.

어휘 세 문맥 점수가 모두 0 이면 σ 점수 합은 1.5 다. 정규화된 세 범주의 확률 합 1 과 다르다. 잡음은 지정 분포에서 뽑았다는 뜻이며 의미가 반대라는 정답 라벨이 아니다.

자기점검

답과 이유 보기

학습 목적은 단어 쌍의 방향 있는 역할을 내적으로 연결한다.

답과 이유 보기

관측 점수만 높여도 손실이 줄어 다른 쌍과의 비교를 제어하지 못한다.

잡음 k 를 늘리면 무조건 더 좋은가?

답과 이유 보기

아니다.

목적의 항과 계산량이 달라지며 실제 과제·자료 검증이 필요하다.

한 단계 더

좌표의 해석은 유일하지 않다. 임의의 직교 행렬 Q 에 대해 v_new=Qv, u_new=Qu 로 두 표를 같이 돌리면 u_newᵀv_new=uᵀQᵀQv=uᵀv 이므로 모든 쌍 점수와 손실이 같다. 따라서 특정 좌표 하나가 언제나 특정 뜻을 담당한다고 단정할 수 없다. 두 표를 서로 다른 변환으로 바꾸면 이 동일성은 일반적으로 깨진다.

소단원 4.3

표현편향과 유사도

벡터의 거리가 가까워졌다는 사실만으로 더 공정한 시스템이 되었다고 말할 수 있을까?

준비 개념과 학습 목표

준비 개념

  • 단위 벡터는 길이가 1 이다. 0 이 아닌 벡터를 길이로 나누어 만들 수 있다.
  • 선택한 단위 방향 g 에 대한 평행 성분은 (w·g)g 이며 수직 잔차는 w−(w·g)g 다.
  • 자료·표현·최종 의사결정은 서로 다른 단계다. 한 단계의 수치가 다음 단계 전체의 적절성을 대신하지 않는다.

학습 목표

  • 유사도에서 생길 수 있는 편향과 평가 선택을 설명한다.
  • 방향 투영 지표와 제거의 효과·한계를 가상 벡터로 계산한다.

자료에서 표현으로 이어지는 경향

훈련 자료의 반복된 연관은 표현의 이웃 관계에도 남을 수 있다. 특정 집단이 특정 역할과 함께 과도하게 등장하거나 다른 언어·세대 자료가 적으면 검색과 분류에서 그 패턴이 재사용될 수 있다. 근접성은 관측 연관을 나타내며 능력이나 적합성의 자연적 사실을 증명하지 않는다.

편향을 측정하려면 어떤 집단·과제·피해·단어 집합을 다루는지 먼저 정한다. 논문의 특정 영어 성별 방향은 연구 설정의 하나다. 모든 사람을 두 집단으로 나눌 수 있다거나 같은 축이 모든 문화에서 맞는다고 가정하지 않는다. 이 소단원의 A/B 는 실제 사람을 가리키지 않는 가상 표식이다.

선택한 축의 지표 만들기

단위 방향 g 와 평가할 비영 단어 벡터 집합 N 을 고르고 B=(1/|N|)Σ_w |cos(w,g)|를 계산하자. 값이 크면 선택한 축과 정렬된 정도가 크다. 절댓값 때문에 양·음 방향을 모두 센다. N 이 비어 있거나 영벡터가 있으면 정의를 새로 정하기 전에는 계산할 수 없다.

g 를 바꾸거나 N 을 고르면 지표도 달라진다. 따라서 지표를 공정성의 보편적 합격 점수로 읽지 않는다. 표본 수·선정 근거·누락된 집단과 실제 시스템에서 쓰는 의사결정 기준을 함께 공개해야 한다. 방향 투영이 작아도 다른 방향이나 이웃 관계에 연관이 남을 수 있다.

축 제거와 손실되는 정보

평행 성분을 빼면 w_perp=w−(w·g)g 이고 w_perp·g=0 이다. 잔차가 비영이면 다시 정규화할 수 있다. 이 대수적 효과는 선택 축에 대한 정렬 제거만 보장한다. 단어의 유용한 구별을 함께 지울 수도 있고, g 와 평행한 벡터는 잔차가 0 이어서 코사인이 미정의가 된다.

최종 서비스 평가에는 실제 과제 오류·집단별 결과·자료의 대표성과 당사자 관점이 필요하다. 지표 한 개를 낮춘 것만으로 채용·추천 등의 결정을 정당화하지 않는다. 이 원고는 가상 벡터의 종이 활동이며 사람 자료 수집·공정성 실험·실제 사용자 시험을 수행하지 않았다.

중간 과정을 따라가는 예제

가상 단위 방향 g=(1,0), 평가 벡터 w_A=(3/5,4/5), w_B=(0,1)를 사용한다. B, 두 벡터 유사도, 축 제거 후 유사도를 구하라.

  1. 두 벡터 길이는 모두 1 이다. 축과 코사인은 각각 3/5,0 이므로 B=(3/5+0)/2=3/10=0.3 이다.
  2. 원래 두 벡터 코사인은 w_A·w_B=4/5=0.8 이다.
  3. w_A 에서 (3/5)g 를 빼면 (0,4/5), w_B 는 (0,1)이다. 둘 다 잔차가 비영이다.
  4. 정규화하면 두 잔차 모두 (0,1)이다. 선택 축 지표는 0 이고 두 벡터 코사인은 1 이다.
  5. 지표는 줄었지만 A/B 의 원래 차이가 사라졌다. 다른 과제에 유용했을 구별이 보존되었다고 말할 근거는 없다.

B:0.3→0, A/B 코사인:0.8→1. 선택한 축을 제거했고 동시에 두 표현을 합쳐 버렸다.

종이와 본문으로 직접 해보기

w_C=(−3/5,4/5), w_D=(1,0)를 종이에 추가하라. C 의 축 지표 기여·잔차, D 의 잔차를 구하고 어떤 후속 계산이 막히는지 설명하라.

힌트 보기

절댓값 지표는 C 의 음수 정렬도 센다. D 에서는 평행 성분이 전체 벡터다.

풀이 보기

C 의 |cos|는 3/5 이고 잔차는 (0,4/5), 정규화는 (0,1)이다. D 의 잔차는 (0,0)이므로 단위 벡터와 코사인을 만들 수 없다. 임의 대체 벡터를 넣는 것은 추가 정책이며 투영 공식의 결과라고 숨기지 않는다.

오해와 반례

축 지표가 0 이면 모든 간접 편향도 사라진다.

0 은 선택한 방향과의 내적만 검사한 결과다. 위 예는 두 표현의 구별까지 없앴으며, 실제 다차원에서는 다른 방향·문맥·하류 모델이 여전히 집단 연관을 담을 수 있다. 단일 수치로 전체 공정성을 인증할 수 없다.

한 단계 더

수직 잔차와 평행 성분은 내적 0 이므로 ‖w‖²=(w·g)²+‖w_perp‖²다. A 에서는 1=9/25+16/25 다. 이 항등식은 축을 제거할 때 얼마나 벡터 길이를 잃는지 설명한다. 손실된 길이의 비율과 실제 사람에게 미친 피해 감소율은 서로 다른 양이며 36%의 제곱 길이 제거를 36%의 공정성 개선이라고 부르지 않는다.
