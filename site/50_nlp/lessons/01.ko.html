소단원 1.1

언어의 구조와 모호성

같은 문장을 사람이 이해하는 단위와 컴퓨터가 세는 단위는 같을까?

준비 개념과 학습 목표

준비 개념

  • 문자열은 순서가 있는 문자 표현이다. 같은 요소라도 순서가 바뀌면 다른 문자열이다.
  • 토큰의 개수와 서로 다른 토큰의 집합 크기는 다르다. [가,가,나]는 길이 3, 서로 다른 요소는 2개다.
  • 확률은 모형의 불확실성을 나타낸다. 높은 확률의 해석이 모든 문맥에서 참이라는 뜻은 아니다.

학습 목표

  • 문자·어절·형태소·모델 토큰을 구별한다.
  • 모호성이 어휘·구조·문맥에서 생기는 이유를 설명한다.
  • 말뭉치와 주석을 자료 생성 조건까지 포함해 읽는다.

토큰은 정해진 분석 규칙의 결과다

텍스트를 작은 단위의 순서로 바꾸는 토큰화는 함수 T:문자열→토큰열로 생각할 수 있다. 공백 분리, 문자 분리, 형태소 분석, 학습된 부분 단어 분리는 서로 다른 T다. 한국어 어절은 공백으로 나뉜 단위이고 형태소는 의미나 문법 기능의 분석 단위다. 토큰이 항상 사전의 단어라는 정의는 없다.

자체 문장 학생이 책을 읽었다.를 공백으로 나누면 [학생이,책을,읽었다.]의 3개다. 이 문자열은 미리 조합된 한글 음절·공백·마침표를 각각 하나의 Unicode 코드 포인트로 세면 11개이고 공백을 제외하면 9개다. 종이용 분석 규칙 [학생,이,책,을,읽,었,다,.]는 8개를 준다. 마지막 것은 실제 분석기 실행 결과나 유일한 언어학적 분석이 아니다.

형태가 같아도 의미와 범위는 달라진다

배를 보았다는 문장만으로 배가 과일인지 탈것인지 신체 부위인지 결정하기 어렵다. 문맥은 후보를 줄이지만 문맥이 부족할 때는 불확실성을 남겨야 한다. 작은 강아지의 집에서는 작은 것이 강아지인지 집인지 해석 범위를 논의할 수 있다. 토큰을 더 잘게 자르는 것만으로 이런 결정을 모두 해결하지 못한다.

모든 학생이 한 권을 읽었다도 각 학생에게 책 하나가 존재한다는 ∀학생 ∃책과 모든 학생에게 공통 책 하나가 존재한다는 ∃책 ∀학생을 구별해야 한다. 두 학생과 두 책만 있고 각자가 정확히 하나를 읽으면 선택은 2²=4가지다. 둘이 같은 책을 읽는 2가지는 공통 책 조건을 만족하지만 서로 다른 책을 읽는 나머지 2가지는 만족하지 않는다. 따라서 문장 해석은 단순 단어 목록보다 많은 구조를 필요로 한다.

말뭉치와 주석의 생성 조건

말뭉치는 텍스트와 출처·시기·장르 등 메타데이터를 모은 자료다. 주석은 품사, 문장 경계, 감정 등 특정 작업의 규칙에 따라 붙인 표지다. 온라인 리뷰만 모은 말뭉치가 모든 일상 언어의 대표 표본이라는 보장은 없다. 쓰지 않은 사람, 삭제된 글, 플랫폼 규칙이 관측 분포를 바꾼다.

주석 지침에 중립/혼합 감정의 처리와 부족한 문맥의 보류 규칙을 적는다. 두 주석자가 4문항 중 3개에서 같은 표지를 쓰면 단순 일치율은 3/4이다. 이 값은 우연 일치, 클래스 불균형, 정답 타당성을 보정하지 않는다. 주석 표지는 작업 규칙에 대한 관측이며 사람의 실제 의도를 완전히 측정한 사실과 같지 않다.

중간 과정을 따라가는 예제

미리 조합된 한글로 쓴 학생이 책을 읽었다.를 공백 단위와 코드 포인트 단위로 세고, 학생이책을읽었다.와 비교하라.

  1. 첫 문자열의 공백 두 곳을 경계로 잡으면 3개다. 마침표는 마지막 어절에 남긴다.
  2. 코드 포인트를 학생이 3, 공백 1, 책을 2, 공백 1, 읽었다 3, 마침표 1로 더하면 11이다.
  3. 공백이 없는 두 번째 문자열은 공백 분리 결과 1개, 코드 포인트는 9개다. 규칙을 바꿨으므로 길이도 달라진다.

각각 공백 토큰 3/1개, 코드 포인트 11/9개다. 사람의 의미 추론 능력과 선택한 토큰화 규칙을 구별한다.

종이와 본문으로 직접 해보기

두 학생 민/준, 두 책 A/B를 놓고 각자가 정확히 한 권을 읽는 네 경우를 쓰라. 공통 책이 존재하는 경우를 표시하라.

힌트 보기

민의 선택 2가지마다 준의 선택 2가지를 붙인다. 공통 책은 두 선택이 같아야 한다.

풀이 보기

(A,A),(A,B),(B,A),(B,B) 네 경우다. 모든 경우에 각 학생이 한 책을 읽지만 공통 책이 있는 것은 (A,A),(B,B)의 두 경우다. 양화사의 순서가 조건을 바꾼다.

오해와 반례

토큰 수를 알면 문장의 의미와 정답 표지도 결정된다.

배라는 한 토큰도 여러 의미를 갖는다. 같은 토큰 수의 문장이 상반된 감정을 표현할 수도 있다. 토큰화는 표현을 만드는 단계이고 의미/주석 결정에는 문맥과 작업 지침이 필요하다.

자기점검

공백 분리와 형태소 분리의 토큰 수는 반드시 같은가?

답과 이유 보기

아니다.

공백 경계와 문법적 분석 경계가 다르다. 조사와 어미를 나누면 수가 달라질 수 있다.

두 학생이 서로 다른 책을 한 권씩 읽었을 때 ∃책 ∀학생 조건은 참인가?

답과 이유 보기

거짓이다.

각자에게 책이 있다는 사실은 공통 책이 있다는 사실을 보장하지 않는다.

주석자 일치율 3/4이면 표지가 실제 의도의 75%를 정확히 측정했다고 말할 수 있는가?

답과 이유 보기

말할 수 없다.

일치율은 두 주석자의 선택 비교이며 외부 정답, 표본 대표성, 우연 일치를 별도로 검토해야 한다.

한 단계 더

Unicode의 사용자 눈에 보이는 한 글자와 코드 포인트 하나는 항상 같지 않다. 조합 문자, 결합 부호를 포함하면 달라진다. 원자료를 보존하고 정규화 형식과 토큰화 규칙·버전을 함께 기록하라. 토큰열의 순서와 빈도를 버리고 어휘 집합만 남기면 어떤 의미 정보가 사라지는지도 비교하라.

소단원 1.2

데이터 수집·라이선스

인터넷에서 읽을 수 있는 글이면 학습 자료로 복사해도 될까?

준비 개념과 학습 목표

준비 개념

  • 미니복습: 접근할 수 있다는 사실과 특정 행위에 대한 권한은 별개다.
  • 자료의 출처, 버전, 이용 조건은 서로 다른 기록 항목이다.
  • 개인 정보와 저작권의 검토는 같은 질문이 아니다.

학습 목표

  • 자료별 이용 조건을 원문과 함께 기록한다.
  • 수집·학습·공개·재배포 행위를 구별한다.
  • 불명확한 조건을 임의 허용으로 바꾸지 않는 종이 점검표를 만든다.

먼저 무엇을 하려는지 적는다

데이터 수집은 파일을 얻는 일만이 아니다. 접근 방법, 수집 범위, 보관 기간, 분석 목적, 원문 공개 여부를 정해야 한다. 읽기, 복사, 수정, 학습 입력으로 사용, 원문 예시 게시, 데이터 재배포, 모델 공개는 서로 다른 행위다. 하나의 허용 표시가 다른 모든 행위의 조건을 자동 확정하지 않는다.

자료별 manifest에는 출처 URL, 내려받은 버전/시점, 파일 식별값, 권리자·기여자 표시, 라이선스 원문 URL, 제외된 부분, 변경 이력, 개인 정보 검토 결과를 둔다. 출처가 끊겼거나 이용 조건이 불명확하면 확인 대기 상태로 둔다. 자동 수집이 기술적으로 가능하다는 이유만으로 라이선스를 추정하지 않는다.

공식 자료의 조건을 구체적으로 읽는다

실제로 열람한 Universal Dependencies English EWT 소개는 CC BY-SA 4.0을 표시한다. 이는 모든 인터넷 텍스트의 조건이 아니라 그 자료에 표시된 조건이다. CC 원문은 공개 시 필요한 출처·라이선스·변경 표시와, Adapted Material을 공개하는 경우의 ShareAlike를 구별한다. 원문에 공급된 저작권 고지와 면책 고지도 해당 조건에 따라 보존해야 한다.

BY-SA에는 비상업적 이용만 허용한다는 NC 요소가 없다. 그러나 상업적 사용 가능성만으로 다른 조건을 없앨 수는 없다. 개인 정보·초상/퍼블리시티 등의 다른 권리가 이 라이선스로 모두 허용되는 것도 아니다. 자료 이용 조건에서 모든 학습 모델 가중치가 법적으로 Adapted Material인지까지 일반적으로 단정하지 않는다. 데이터·코드·가중치는 각각 표시된 조건과 실제 행위를 대조한다.

조건을 충족하는 후보와 보류 자료

종이 사례 D1은 직접 쓴 문장으로, 작성자가 필요한 권리를 보유하고 외부 문구·개인 정보가 없다고 명시한다. D2는 EWT이며 공식 표시를 확인하고 이용 계획별 의무를 점검하는 후보다. D3은 라이선스 표시가 없는 공개 게시글, D4는 목적이 불명확한 사적 대화다. D3/D4는 이 사례에서 확인 대기다. D1/D2가 후보라는 말은 실제 법적 검토를 모두 통과했다는 인증이 아니다.

자료의 대표성과 권리 상태도 별개다. 조건이 명확한 자료가 목표 언어·장르·시기를 충분히 대표하는지 다시 살핀다. 원문은 제한된 저장소에 보존하고 변환 자료에 출처 ID를 유지한다. 익명화라는 이름만 붙였다고 재식별 가능성이 사라졌다고 주장하지 않는다. 이 단원은 가상 기록을 읽는 활동이며 실제 대화나 개인 자료를 수집하지 않는다.

중간 과정을 따라가는 예제

D1 자체 창작/외부 권리 없음, D2 EWT 공식 BY-SA 표시, D3 공개 글/조건 불명, D4 사적 대화/목적 불명인 네 기록을 분류하라.

  1. 각 기록의 접근 가능 여부와 이용 조건 확인 여부를 따로 적는다.
  2. D1의 명시 가정과 D2의 공식 표시를 근거로 검토 후보 2개를 둔다. D2에는 행위별 출처·변경·공유 조건 및 다른 권리 점검이 남는다.
  3. D3은 공개 여부만 알며 D4는 접근했더라도 목적과 동의 범위가 불명이다. 두 기록 모두 확인 대기로 둔다.

검토 후보 D1/D2, 확인 대기 D3/D4다. 후보라는 분류를 무조건적 사용 허가로 해석하지 않는다.

종이와 본문으로 직접 해보기

D2를 수정한 말뭉치의 일부를 공개한다는 가상 계획에 manifest 필수 항목 다섯 가지 이상을 쓰고, 자료를 학습에만 쓴 경우와 질문이 다른 이유를 설명하라.

오해와 반례

공개 글이거나 출처 링크만 붙이면 모든 자료를 원하는 방식으로 재배포할 수 있다.

공개 접근은 이용 허락 전체를 뜻하지 않는다. 출처 표시는 중요한 조건이지만 수정·공유 방식이나 다른 권리 문제가 남을 수 있다. D3처럼 라이선스가 불명인 자료에 작성자가 임의로 CC 표시를 붙이는 것도 해결이 아니다.

소단원 1.3

중복과 분할누수

테스트 문장을 이미 외웠다면 높은 점수는 새로운 문장 이해를 보여 줄까?

준비 개념과 학습 목표

준비 개념

  • 집합의 교집합은 양쪽에 함께 있는 요소다. 훈련 ID와 테스트 ID가 달라도 원문 출처가 같을 수 있다.
  • 훈련은 값을 추정하는 단계, 검증은 선택하는 단계, 테스트는 고정된 선택을 평가하는 단계다.
  • 고정 규칙으로 변환하는 것과 자료에서 통계·어휘를 학습하는 것은 구별한다.

학습 목표

  • 원문·유사 문서·출처 그룹의 중복을 구분한다.
  • 배포 대상에 맞춰 그룹·시간 분리를 설계한다.
  • 어휘 학습과 목표 정보의 누수를 찾아낸다.

무엇이 새로운 사례인가

행 ID가 다른 복사본은 새로운 독립 사례가 아니다. 같은 문서의 수정본, 같은 대화의 메시지, 같은 작성자의 글은 관련되어 있을 수 있다. 정확히 같은 문자열은 직접 비교할 수 있고 해시는 후보 탐지에 유용하지만 충돌 가능성을 고려해 최종 원문 비교를 할 수 있다. 가까운 문장은 판정 규칙과 임계값을 기록해야 한다.

원자료를 유지한 채 고정 규칙으로 정규화한 복사본을 만들고 중복 그룹을 정할 수 있다. 정말 좋아요!와 정말 좋아요를 마침표/느낌표 제거 규칙으로 같은 그룹에 넣는 것은 한 선택이다. 좋지 않다에서 부정 표현을 지우면 의미가 달라지므로 중복 편의를 위해 무조건 제거하지 않는다. 전체 자료에서 어휘 빈도를 학습하는 것은 고정 규칙의 비교와 다르다.

분할은 평가 질문에 따라 정한다

A의 복사본 a1/a2, B의 유사본 b1/b2, C의 c1, D의 d1 여섯 행을 생각하자. a1,b1,c1을 훈련, a2,b2,d1을 테스트에 두면 행 ID 교집합은 비어도 그룹 A/B가 양쪽에 있다. 훈련 원문을 외워 맞추는 가상 규칙이 테스트 셋 중 2개를 맞추면 2/3의 점수를 얻지만 새로운 출처 성능이라는 해석은 약하다.

새 문서 출처 일반화를 묻는 종이 분할은 A/B 네 행을 훈련, C 한 행을 검증, D 한 행을 테스트에 둘 수 있다. 실제로는 클래스 분포와 표본 크기, 각 그룹의 생성 조건도 검토한다. 새로운 작성자에 대한 질문에는 작성자 그룹 분리가 필요할 수 있다. 같은 작성자의 미래 글이 대상이면 시간 순서 분리가 핵심이며 모든 작성자를 반드시 제외한다는 규칙으로 대체할 수 없다. 미래 내용·사후 표지는 예측 시점에 없어야 한다.

표현을 배우는 단계에도 경계가 있다

귀납적 새 문서 평가에서는 토큰 어휘, 빈도 임계값, TF-IDF 통계, 선택 특징처럼 학습되는 전처리 값을 훈련 자료에서만 fit한다. 검증/테스트에는 그 고정 값을 적용한다. 각 교차검증 fold마다 다시 fit해야 한다. 전처리 Pipeline은 이런 순서를 돕지만 출처 중복이나 사후 목표 정보가 입력에 들어가는 문제를 자동 제거하지 않는다.

검증 점수로 모델·규칙을 선택한 뒤 테스트를 고정해 마지막 평가에 쓴다. 테스트를 반복해서 보고 수정하면 선택 정보가 새어 들어간다. 시간 자료에서는 예측 시점, 표지 관측 지연, 학습 창과 간격을 기록한다. 사전학습 모델이나 공개 토크나이저를 가져왔다고 외부 학습 자료와 평가 말뭉치 사이의 중복이 없다고 증명된 것도 아니다. 공개 결과의 이러한 한계를 함께 적는다. TimeSeriesSplit로 fold 간 같은 시간 길이의 지표를 비교하려면 문서가 정한 고정 시간 간격 조건도 확인한다. 불규칙한 글 작성 시각에는 행 수로 나눈 fold가 같은 시간 길이가 아니므로 평가 시간 구간을 별도로 정할 수 있다.

중간 과정을 따라가는 예제

여섯 행 a1,a2(A),b1,b2(B),c1(C),d1(D)에서 훈련={a1,b1,c1}, 테스트={a2,b2,d1}의 출처 교집합을 계산하라.

  1. 훈련 출처 집합은 {A,B,C}, 테스트 출처 집합은 {A,B,D}다.
  2. 교집합은 {A,B}로 2개다. 행 ID 교집합이 비었다는 검사만으로 이 문제를 잡지 못한다.
  3. 테스트 세 행 중 a2,b2만 암기 규칙으로 맞춘다고 가정하면 2/3이다. 실제 모델을 훈련한 결과가 아닌 가상 비율이다.

출처 중복 2개, 가상 암기 점수 2/3이다. 출처가 새로운 D에 대해서는 이 비율로 성공을 보장하지 못한다.

종이와 본문으로 직접 해보기

P가 1월 1일/2일에 쓴 두 글과 Q가 1월 3일에 쓴 글이 있다. 새로운 작성자 Q 평가와 P의 2월 미래 글 평가의 분할 기준을 각각 적어라. 어휘는 언제 학습하는가?

힌트 보기

누가 새로운가와 언제 예측하는가를 따로 정한다. 평가 대상 문장으로 어휘를 맞추지 않는다.

풀이 보기

새 작성자 평가에서는 P 두 글을 훈련에, Q 글을 평가에 두고 작성자 교집합을 막는다. P의 미래 글 평가에서는 2월 이전 정보로 학습하고 2월 글은 시간 순서대로 남길 수 있다. 같은 작성자가 등장해도 평가 질문과 일치할 수 있다. 두 경우 모두 어휘·통계는 훈련 부분에서만 추정한다.

오해와 반례

행 ID가 다르고 토크나이저를 Pipeline에 넣었으면 누수가 없다.

a1/a2의 복사 관계는 서로 다른 ID에도 남고, 사후 감정 표지를 텍스트에 붙인 입력은 Pipeline 안에서도 목표 누수다. 분할 단위와 예측 시점에 이용 가능한 정보까지 검토해야 한다.

자기점검

훈련 출처 {A,B,C}, 테스트 출처 {D,E}의 교집합은?

답과 이유 보기

공집합이다.

동일한 출처 ID가 양쪽에 없다. 다른 종류의 누수가 없다는 증명까지 되는 것은 아니다.

전체 말뭉치로 TF-IDF 통계를 먼저 fit한 뒤 무작위 분할하면 귀납적 평가에 적합한가?

답과 이유 보기

부적합하다.

평가 문서의 통계가 훈련 표현 결정에 들어간다. 분할한 훈련 자료에서 fit해야 한다.

미래 글을 예측하는 목표에 임의 셔플만 하면 충분한가?

답과 이유 보기

충분하지 않다.

미래 관측이 과거 학습에 들어가거나 표지 지연이 누수로 이어질 수 있다. 예측 시점과 시간 경계를 보존해야 한다.

한 단계 더

유사 문서를 간선으로 연결해 연결 성분별로 분할하면 A~B,B~C를 통해 A/C도 같은 그룹이 된다. 모든 쌍이 서로 비슷하다는 뜻은 아니다. 엄격한 그룹 기준과 시간 제약을 함께 적용할 때 데이터가 부족해질 수 있으므로 제외 수, 클래스별 표본 수, 평가 목적을 보고하라. 고정 규칙·학습 전처리·외부 사전학습의 경계를 따로 남겨야 재현할 수 있다.
