5. 과목의 범위와 선수 학습

  • 미적분 I → II → 공학수학 I → II. 선형대수·확률통계·다변수 미분 → ML → DL → 비전·NLP.
  • Python 입문 → C의 메모리·구조체 → 자료구조 → 알고리즘. C++는 중급 객체지향·자원 수명 담당.
  • 디지털논리 + C → 컴퓨터구조 → 컴퓨터시스템. C → 시스템프로그래밍. 두 시스템 과목 → OS·네트워크.

8. 여러 에이전트의 검토와 채택한 수정

국내 대학 조사, 해외 대학 조사, 독립 학습량·선수 검토를 각각 맡긴 뒤 편성안을 다시 보내 교차 의견을 받았습니다. 의견이 달랐던 선수 순서는 아래처럼 최종 결정했습니다.

검토 쟁점문제반영한 결정
시스템 선수 순서국내·해외 조사 에이전트가 OS 이전 시스템 실습 부족을 지적했다.시스템프로그래밍을 2-2로 이동하고 공학수학 II를 3-1, 언어론을 3-2로 이동했다. OS는 두 시스템 과목 수료 후 시작한다.
시스템 두 과목 동시 이수독립 과목의 중복과 동시수강 의존을 확인해야 한다.컴퓨터시스템은 표현·ABI·링킹·캐시, 시스템프로그래밍은 Unix API·프로세스·IPC·소켓이다. 후자는 C만 강제 선수로 두고 컴퓨터시스템 동시 이수를 명시한다.
자료구조와 C++같은 학기에 자료구조가 아직 배우지 않은 STL을 요구할 위험이 있다.자료구조는 이전 학기의 C 포인터·구조체·동적 할당으로 시작하고 C++ 비교는 후반에 둔다.
수학의 폭미적분 II 이름만으로 AI 수학을 확보할 수 없다.다변수·편미분·gradient·Jacobian·연쇄법칙을 명시한다. 공학수학 I·II는 ODE/변환/PDE로 분리한다.
수치해석의 늦은 배치ML 이전 수치 안정성과 최적화가 부족할 수 있다.ML 시작 부분에 수치오차·벡터미분·경사하강·조건수 입문을 포함한다. 수치해석은 해법·수렴 비교의 심화로 둔다.
언어 5개언어 문법 반복으로 공통 핵심을 밀어낼 수 있다.모두 독립 한 학기 과목으로 제공한다. 공통은 Python/C/C++, Java/C#은 선택이며 기본 예시 경로에서는 모두 수강한다. C#은 2-2부터 가능하나 예시에서는 응용 학기에 둔다.
파일구조와 DB저장·인덱스의 설명이 중복될 수 있다.DB는 관계모델·SQL·트랜잭션, 파일구조는 디스크·레코드·외부정렬·페이지 인덱스와 I/O 비용이다. DB를 먼저 두는 것은 본 과정의 독립 설계다.
프로젝트 부하과목 수와 학점만으로 구현 부담을 판단할 수 없다.대형 프로젝트는 학기당 최대 2개. 2-1 자료구조, 3-1 OS, 3-2 SE·ML, 4-1 DL·캡스톤, 4-2 캡스톤·선택 최대1개로 제한한다.
공통·심화의 경계모든 심화 분야를 개인 필수로 합치면 4년 경로가 과부하가 된다.공통 33과목과 선택 30과목을 구분하고 선택 슬롯 5개를 제공한다. 선택 트랙은 관심별 예시이지 별도 학위나 대학 공식 트랙이 아니다.
통합 실습모든 이론·실습을 별도 과목으로 세면 과목 수가 과장된다.C·자료구조·OS는 각 4학점 상당, 나머지는 목적에 맞는 통합 실습 시간을 별도로 표시한다. 캡스톤 I·II는 독립 학기 과목이다.

기계 검증: 과목 수·학점 합계·선수 DAG·동시 이수·사용자 요구 과목·다섯 선택 경로의 선수 순서·학기당 대형 프로젝트 상한·시간 산술을 확인했습니다. 오류 0개. 이 검사는 강의내용이나 실제 실행의 검증이 아닙니다.

9. 한계와 다음 설계 단계

  • 학점 상당과 모든 시간은 공개 자율학습을 설계하는 자체 기준이다. 대학 학점 인정, 학위, 인증을 뜻하지 않는다.
  • 미적분 II의 급수·다변수·벡터미적분 범위와 공학수학 II의 범위는 실제 15주 세부 편성에서 재검토해야 한다. 벡터미적분·복소함수는 입문 범위로 제한했다.
  • 학습시간은 초보자 대상 실행·문제풀이·과제 수행을 측정한 값이 아니다. 실제 자료 집필 뒤 표본 학습자 리허설로 조정해야 한다.
  • 1~3학년은 주당 56~57시간의 강도 높은 전일제 모형이다. 시험·마감 집중 주에는 평균보다 부담이 커질 수 있다. 주차별 과제 제출과 평가 일정을 분산해야 한다.
  • 컴퓨터시스템과 시스템프로그래밍의 동시 이수는 자동으로 선수 문제를 해결하지 않는다. C·Unix·빌드 기본기를 먼저 다루고, 링킹·주소 변환 등을 요구하는 실습은 대응 이론 주차 뒤에 배치해야 한다.
  • 선택 심화 30개를 모두 이수하는 일정이 아니다. 전체 공개 과목은 71개, 한 개인의 기본 이수는 46개다.
  • 범위 점검은 CS2023 지식영역 수준이다. 세부 Knowledge Unit/학습성과 전체 준수 감사는 아직 하지 않았다. GIT·SPD의 심화는 선택 경로에 있다.
  • 하드웨어 실습은 향후 시뮬레이터 경로와 실제 장비 경로를 구분해야 한다. 장비 없는 학습자의 결과를 실물 검증으로 표시하지 않는다.
  • 외국 대학 unit을 국내 학점으로 환산하지 않았다. 국내 대학도 학번·전공 유형에 따라 졸업요건이 다르다.
  • 현재 완료 범위는 교과목 할당·선수 관계·예상 학습량·산출물 설계다. 주차별 강의 본문·전체 코드·문제·해설은 작성하지 않았다.
  1. 과목별 15주 학습목표·주차·진도·시험·과제 일정을 설계한다.
  2. 각 단원의 설명·유도·예제·실습·문제·해설을 집필한다.
  3. 코드·계산·예상출력을 검증하고 학습자 표본으로 시간과 난이도를 조정한다.
  4. 그 결과를 과목별 공개 웹 강의에 반영한다.
