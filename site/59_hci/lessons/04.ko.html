소단원 4.1

작업흐름

대출 버튼을 누르면 책 빌리기라는 목표를 이미 달성한 것일까?

준비 개념과 학습 목표

준비 개념

  • 목표는 얻고 싶은 결과이고 과업은 그 결과를 향해 하는 행동이다.

  • 조건이 달라지면 절차가 갈라지거나 되돌아갈 수 있다.

  • 이 단원의 도서관 절차와 시간은 만든 종이 사례이며 실제 관찰 자료가 아니다.

학습 목표

  • 사용자 목표·단계·조건·완료 표시를 구별한다.

  • 한 사람의 과업과 역할 사이의 작업흐름을 연결한다.

  • 정상 경로뿐 아니라 실패·재시도·중단을 분석한다.

단계 시간을 모두 더해야 할 때와 겹쳐도 되는 때는 어떻게 나누는가?

앞 본문은 정상 경로와 재시도·도움 요청 경로를 나누었다. 새 가상 예약은 자료 식별에 4초가 걸린 뒤 이용 자격 확인 6초와 재고 확인 8초를 동시에 시작할 수 있다. 두 확인은 서로 독립이고 같은 요청과 자료에 대한 결과를 제공한다. 두 결과가 모두 승인일 때만 예약 커밋 3초를 수행하고 사용자 확인 2초를 받으면 이 모형의 목표가 완료된다.

모든 구간은 주어진 고정 기간이며 준비·통신·자원 충돌 비용은 이 모형에서 없다. 순차 설계의 총 경과는 4+6+8+3+2=23초다. 병렬 설계에서는 두 확인이 식별 종료 시점에 같이 시작하므로 4+max(6,8)+3+2=17초다. 두 확인의 작업 시간 합은 14초로 유지되지만 겹친 경과 구간은 8초다. 실제 도서관 성능이나 배치된 시스템을 측정하지 않았다.

빠르게 끝나는 것만으로 정상 경로가 되지는 않는다. 자격 확인이 거절이면 커밋을 생략하고 실패 안내를 해야 한다. 도움 요청은 직원에게 책임을 넘긴 상태이지 예약 완료가 아니다. 인계 시 요청 ID·자료 ID·확인 결과와 그 결과가 적용되는 판본을 보존해야 같은 대상을 이어서 처리할 수 있다. 자체 규칙은 현재 판본과 확인 판본이 다르면 다시 확인하는 것이다.

먼저 확인할 개념
  • 정상·재시도·도움 경로의 구분

    앞 본문의 경로별 시간과 실제 목표 완료 조건을 새 병렬 확인과 거절·인계 경로에 적용한다.

  • 시작·끝·도움의 사전 기준

    앞 본문의 측정 시작과 종료 및 도움 처리 조건을 작업 시간 합과 경과시간 구분에 연결한다.

끝내고 싶은 일부터 정하기

도서관에서 사용자가 원하는 결과는 특정 책을 사용할 수 있는 상태로 빌리는 것이다. 버튼 누르기는 그 목표의 일부 행동일 뿐이다. 시작 조건을 책과 회원증을 가진 상태, 종료 조건을 대출 승인과 반납일을 확인하고 책을 가져갈 수 있는 상태로 정하면 분석의 경계를 공유할 수 있다.

화면에 성공이라는 글자가 떴어도 대출 기록이 없어 책을 가져갈 수 없다면 목표를 달성한 것이 아니다. 반대로 화면에서 하던 일은 끝났지만 안내를 따라 창구에서 책을 받는 단계가 남을 수 있다. 화면 안의 클릭 수만 세지 말고 사용자의 실제 결과에 필요한 온라인·오프라인 행동을 함께 적자.

단계와 계획을 함께 기록하기

목표를 회원 확인, 책 확인, 대출 확정, 결과 확인으로 나눈 뒤 각 단계의 입력·행동·출력·오류 조건을 쓴다. 계층적 과업 분석에서 하위 과업을 나열하는 것만으로 순서가 정해지지는 않는다. 이 예의 계획은 회원 확인이 유효할 때 책 확인으로 가고, 스캔 실패이면 한 번 다시 시도하며, 다시 실패하면 창구 도움으로 이동하는 것이다.

한 사람의 목표와 행동에 초점을 맞춘 과업 분석과 여러 역할의 정보 전달에 초점을 맞춘 작업흐름 분석은 연결되지만 같은 관점은 아니다. 사용자가 도움을 요청하고 직원이 회원 정보를 확인하며 시스템이 기록을 반환하는 인계에서는 누가 기다리고 어떤 정보가 전달되는지도 적는다. 버튼 하나의 작업으로 인계 전체를 숨기지 않는다.

현재 절차와 제안 절차의 근거

실제 분석에서는 관찰·인터뷰·기존 기록으로 현재 절차를 찾고, 관찰한 사실과 설계자가 제안한 단계를 구별한다. 인터뷰에서 한다고 말한 행동과 실제 수행 행동이 다를 수 있어 한 종류의 자료만으로 모든 경로를 확정하지 않는다. 이 강의의 사례는 절차 분석 방법을 배우기 위한 가상 입력이다.

시간표에서 순차 수행을 가정하면 경로 시간은 방문한 단계의 합이다. 병렬 처리나 다른 사용자의 대기, 시스템 지연이 들어가면 합산 방식도 달라진다. 자주 쓰는 경로와 위험한 예외 경로를 별도로 확인하되 단계 수가 적다는 이유만으로 언제나 더 좋은 설계라고 판단하지 않는다. 잘못된 대출을 막는 확인 단계의 목적도 살펴야 한다.

책임 이전만으로 목표 완료를 세지 않음

시간을 더하기 전에 선행 조건과 겹칠 수 있는 구간을 표시한다. 마지막 두 행은 정상 시간식에 끼워 넣을 숫자 대신 다른 종료 상태를 나타낸다.

중간 과정을 따라가는 예제

종이 절차는 회원 확인8초→책 확인4초→대출 확정3초→결과 확인5초다. 책 확인이 첫 시도에 실패하면 재시도6초를 추가하고 성공 후 확정으로 간다. 다른 대기·병렬 작업은 없다. 정상과 재시도 경로, 목표 완료 시점을 구하라.

  1. 목표 완료는 결과 확인까지 끝낸 뒤 대출 승인과 반납일을 알 때다. 확정 버튼 누른 시점과 구별한다.

  2. 정상 경로는 네 단계를 모두 방문하므로8+4+3+5=20초다.

  3. 재시도 경로도 책 확인4초를 이미 사용했다. 실패를 무시해4초를 빼지 않는다.

  4. 재시도6초를 더한 경로는8+4+6+3+5=26초다. 추가 비용은26−20=6초다.

  5. 각 시간은 주어진 단순 순차 모형의 값이다. 실제 사용자 속도·도서관 대기·네트워크 측정 결과가 아니다.

정상20초, 재시도26초다. 결과 확인을 마쳐야 이 모형에서 목표가 완료된다.

조건을 바꾸어 비교하기

동시 확인의 끝은 늦은 확인이다

두 확인이 식별 종료 뒤 동시에 시작한다. 모두 승인된다. 확인 결과를 받는 시각과 전체 정상 경과를 구하라.

  1. 식별은 시작 후 4초에 끝난다. 자격 결과는 10초에, 재고 결과는 12초에 준비된다.

  2. 두 결과가 필요한 커밋은 12초에 시작하여 15초에 끝난다. 사용자 확인은 17초에 끝난다.

  3. 순차 경로 23초와 비교하면 자체 기간 조건에서 경과가 6초 줄었다.

확인 결과가 모두 준비되는 시각은 12초이고 목표 완료 시각은 17초다.

비교할 점

확인 작업량 14초와 겹친 경과 8초를 같은 지표로 쓰지 않는다.

옛 확인을 인계하면 정상 승인이 되는가

직원에게 넘긴 요청 R의 자료는 B이고 자격 확인 판본은 3이다. 현재 판본은 4다. 자체 규칙은 판본 불일치 시 재확인이다. R과 B를 받았다는 이유만으로 바로 커밋해도 될까?

  1. 요청과 자료의 대응은 보존됐지만 확인 결과의 적용 시점은 달라졌다.

  2. 확인 판본 3과 현재 판본 4를 비교하여 불일치를 발견한다.

  3. 직원이 재확인하고 필요한 두 승인 조건을 충족한 뒤 커밋하는 경로를 계획한다.

바로 커밋하지 않는다. 같은 R과 B의 현재 판본에 대해 재확인이 필요하다.

비교할 점

인계의 정보 보존과 정보가 지금도 유효하다는 조건은 다르다.

종이와 본문으로 직접 해보기

재시도도 실패하면 확정·결과 확인으로 가지 않고 도움 요청2초와 직원 처리15초를 거친다. 이 예외 경로 시간과 직원에게 전달할 최소 업무 정보를 쓰라. 업무 정보는 회원 확인의 상태와 책 식별자로 제한한다.

힌트 보기

공통 앞부분8+4+6 뒤에서 실패 분기를 따라가라. 실행하지 않은 확정3초와 결과5초를 더하지 않는다.

풀이 보기

8+4+6+2+15=35초다. 인계 정보는 회원 확인 상태와 해당 책 식별자다. 확정·결과 확인8초를 자동 추가하지 않는다. 직원 처리 결과가 대출 완료인지 별도로 확인해야 하므로 시간이 끝났다는 사실만으로 목표 성공을 확정하지 않는다.

오해와 반례

화면 단계가 적고 버튼 누르기까지 빨라지면 전체 작업흐름도 성공한다.

대출 확정이 빨라도 기록 실패나 책 수령·도움 인계가 남을 수 있다. 같은 네 단계의 정상20초와 재시도26초도 조건이 달라진 결과다. 목표 완료와 예외 경로, 정보 전달을 확인해야 한다.

연습 1 · 값과 상태 예측

식별 4초 뒤 두 확인이 동시에 시작하고 모두 승인된다. 자격 확인만 6초에서 9초로 바뀐다. 나머지는 같다. 전체 정상 경과와 기존 17초 대비 차이를 구하라.

힌트 1

겹친 구간에는 두 기간 중 큰 값을 쓴다.

힌트 2

커밋과 사용자 확인은 두 승인 뒤에 이어진다.

풀이와 답 확인

  1. 확인 구간은 max(9,8)=9초다.

  2. 총 경과는 4+9+3+2=18초여서 기존보다 1초 길다.

정상 경과는 18초이고 증가량은 1초다.

흔한 오답에서 다시 생각하기

확인 하나가 3초 늘었으므로 전체도 반드시 3초 늘어난다.

기존에는 재고 확인 8초가 끝을 결정했다. 겹친 구간의 끝이 바뀌는 정도를 계산해야 한다.

연습 2 · 오류 찾아 고치기

작업 표가 “자격 확인 거절 후 직원에게 전달했으므로 예약 완료 1건”이라고 적었다. 결과와 다음 책임을 구별해 고쳐라.

힌트 1

목표 완료에는 두 승인과 커밋·사용자 확인이 필요하다.

힌트 2

인계한 상태와 최종 처리 결과를 따로 기록한다.

소단원 4.2

시나리오와 persona의 한계

가상의 학생 한 명을 자세히 소개하면 모든 학생을 이해한 셈일까?

준비 개념과 학습 목표

준비 개념

  • 시나리오는 목표와 맥락 속에서 일어나는 구체 상황이다.

  • persona는 관련 행동·목표·제약의 패턴을 표현하는 설계 도구다.

  • 아래 카드들은 가상 자료이며 실제 인터뷰나 학생 연구를 실시하지 않았다.

학습 목표

  • 사용자 이름보다 행동·목표·맥락에 근거해 시나리오를 쓴다.

  • 가정 기반 persona와 연구 기반 persona의 근거 수준을 구별한다.

  • 작은 사례 분류를 모집단 비율이나 개인의 고정 속성으로 일반화하지 않는다.

각 속성이 반반이면 모든 조합을 관찰한 것인가?

앞 본문은 목표·기기·입력 조건을 사람의 고정 성격으로 묶지 않았다. 새 가상 네 과업 카드 A와 B는 복습 목표 R과 키보드 입력 K이고, C와 D는 새 개념 학습 목표 L과 포인터 입력 P다. 각 카드는 서로 다른 세션의 기록 단위이며 실제 사람을 조사하지 않았다. 목표만 세면 R과 L은 각각 두 장, 입력만 세면 K와 P도 각각 두 장이다.

그러나 목표와 입력을 함께 보면 관찰된 조합은 R·K 두 장과 L·P 두 장뿐이다. R·P와 L·K는 관찰 카드가 없다. 속성별 개수가 같다는 사실로 조합별 사용성이 확인됐다고 말할 수 없다. 빈 칸은 불가능하거나 실패가 없다는 뜻이 아니라 이 목록에서 미관찰이라는 뜻이다.

같은 사람도 다른 날 다른 과업을 할 수 있다. 자체 카드 E와 F는 같은 가명 사람 U의 두 세션이며 E는 R·K, F는 L·P다. 사람 수의 분모는 한 명이고 세션 수의 분모는 두 개다. 두 카드를 서로 다른 사람 둘로 세거나 U를 언제나 복습만 하는 고정 persona로 쓰면 분석 단위와 맥락을 바꿔 버린다. persona는 근거와 미확인 항목을 가진 계획 도구이며 실제 집단 비율을 알려 주는 통계 표가 아니다.

먼저 확인할 개념
  • 목표·입력 맥락과 persona의 반례

    앞 본문의 기기와 목표가 교차하는 카드 및 미확인 맥락을 새 목표·입력의 조합 표로 확장한다.

  • 평가 대상과 성공 분모

    앞 본문의 대상·도움·분모 사전 선언을 사람과 세션의 서로 다른 분석 단위에 적용한다.

구체 상황에는 시작 이유와 제약이 있다

학습 자료를 찾는다는 말만으로는 무엇을 설계해야 하는지 부족하다. 시험 전 짧은 휴식 시간에 휴대전화로 이미 공부한 식을 다시 확인한다는 상황과 처음 배우는 개념을 큰 화면에서 차근차근 읽는 상황은 정보량과 탐색 요구가 다르다. 시나리오에는 행위자, 계기, 목표, 사용 환경, 제약과 성공 결과를 넣는다.

시나리오는 특정 버튼이나 메뉴 위치를 먼저 강제하지 않아도 된다. 저장해 둔 개념의 설명을 다시 찾는 것이 목표이며 반드시 하트 버튼을 누른다는 것은 해결안의 선택이다. 현재 과업을 관찰한 기록인지 미래 설계 제안인지 표시해야 이야기의 자연스러움이 실제 근거처럼 보이는 일을 막을 수 있다.

persona의 근거와 사용 범위

persona를 만들 때 설계 판단과 관련 있는 행동·목표·제약의 패턴을 요약한다. 사진·나이·취미를 많이 넣었다고 더 정확한 모델이 되는 것은 아니다. 이름은 기억을 돕는 표지이며 같은 나이의 모든 사람이 같은 학습 방식을 갖는다는 근거가 아니다. 한 사람이 상황에 따라 짧게 복습하거나 깊게 공부할 수도 있다.

새 연구 없이 팀의 기존 지식과 추측으로 만든 proto-persona는 가정을 드러내는 도구다. 실제 관찰·인터뷰로 만든 질적 persona도 전 사용자의 빠짐없는 분류나 모집단 비율 추정은 아니다. 연구 기반 여부, 자료의 시점·맥락·누락을 기록하고 추가 확인이 필요한 속성을 따로 둔다.

분류보다 반례와 누락을 보기

가상의 카드 일부가 짧은 복습을 원한다고 해서 모든 학생에게 짧은 글만 제공해야 한다는 결론은 나오지 않는다. 긴 설명이 필요한 상황과 키보드·스크린리더 등 접근 방식의 제약이 별도로 있을 수 있다. 목표 패턴과 접근 방식을 같은 하나의 고정 분류로 합치면 중요한 조합을 빠뜨릴 수 있다.

설계 아이디어를 persona에 맞췄다는 사실도 사용자 검증을 대신하지 않는다. persona는 대화를 돕는 요약이므로 맞지 않는 관찰이 나오면 갱신해야 한다. 이 강의에서는 가상 카드의 조건을 분류하고 빠진 질문을 찾는 종이 활동만 수행하며 실제 연구 기반 persona를 완성했다고 표시하지 않는다.

가상 카드6개에서 A/B/C는 쉬는 시간에 짧게 복습, D/E는 처음 배우는 긴 설명 읽기, F는 목표가 기록되지 않았고 키보드만 사용한다. A와 D도 키보드만 사용한다. 목표 패턴과 접근 방식의 분류를 분리하고 비율 해석의 한계를 쓰라.

  1. 목표가 알려진 복습 카드는 A/B/C의3개, 긴 설명 카드는 D/E의2개다. F의 목표는 unknown으로 남긴다.

  2. 접근 방식에서 키보드만 사용은 A/D/F의3개다. 목표 분류를 기준으로 F를 복습 또는 긴 설명에 억지로 넣지 않는다.

  3. 복습이면서 키보드만 사용은 A, 긴 설명이면서 키보드만 사용은 D다. 두 축은 다른 조건이므로 함께 기록할 수 있다.

  4. 가상 카드 안에서는 복습3/6, 긴 설명2/6, 목표 미상1/6이다. 이것은 실제 전 세계 학생의 비율 추정이 아니다.

  5. 복습과 긴 설명은 이 카드의 특정 상황이다. 같은 사람이 다른 상황에서도 반드시 같은 목표를 갖는다고 결론 내리지 않는다.

  1. 고유 사람은 U 한 명이며 세션은 두 개다.

  2. U는 제공된 두 맥락에서 다른 목표와 입력을 사용했다.

  3. 단일 고정 목표로 요약하면 실제 카드 하나의 맥락을 잃는다.

사람은 한 명, 세션은 두 개다. U에게 언제나 하나의 목표만 있다고 단정하지 않는다.

소단원 4.3

문제·요구·성공기준

빠르고 쉬운 검색이라는 요구를 어떤 결과로 확인할 수 있을까?

준비 개념과 학습 목표

준비 개념

  • 문제는 현재 목표 달성을 막는 현상이다.

  • 요구는 제공해야 할 능력이나 조건이고 해결안은 그 구현 선택이다.

  • 성공 기준은 대상·과업·조건·판정·분모를 정한 확인 규칙이다.

학습 목표

  • 문제→요구→확인 기준의 추적 관계를 만든다.

  • 기능 결과와 사용자 과업 결과를 별도로 평가한다.

  • 작은 가상 표의 성공률·시간 분모를 엄밀하게 계산한다.

전체 기준을 통과해도 특정 입력 맥락의 요구는 실패할 수 있을까?

앞 본문은 기능 이름보다 사용자 문제·요구·성공 기준을 먼저 연결했다. 새 과업은 키보드 K 또는 포인터 P로 원하는 자료와 반납 기한을 정확하게 확인하는 것이다. 시작은 과업 지시를 읽은 직후, 끝은 두 정보의 정확한 보고다. 자체 기준은 시도 여덟 개 중 도움 없이 정확하게 60초 이내에 끝난 시도가 다섯 개 이상이고, K와 P 각각에서도 그런 시도가 한 개 이상인 것이다. 잘못된 결과·도움 사용·시간 초과는 해당 성공 분자에 넣지 않는다.

두 후보는 서로 다른 가상 기록이며 실제 사용자 비교 실험이 아니다. A의 여덟 시도는 K 네 개 중 세 개 성공, P 네 개 중 두 개 성공이다. B는 K 네 개 모두 성공, P 네 개 중 한 개 성공이다. 둘 다 전체 성공은 5/8이지만 맥락별 성과는 다르다. 이 기준에서는 둘 다 통과한다. 전체 비율이 같은 것과 맥락별 값이 같은 것은 다른 주장이다.

별도 후보 C는 K 여섯 개 중 다섯 개 성공, P 두 개는 모두 실패했다. 전체 5/8을 만족하지만 P의 성공 한 개 이상 조건을 위반한다. 숫자를 본 뒤 P 조건을 삭제하고 C를 통과시키면 원래 요구에 대한 평가가 아니라 기준을 바꾼 새 평가다. 요구 ID와 기준 판본·조건·시도 결과를 같이 남겨야 무엇을 충족했는지 추적할 수 있다.

먼저 확인할 개념
  • 정확·무도움·시간을 함께 만족하는 성공

    앞 본문의 복합 조건과 전체 시도 분모를 새 입력 맥락별 최소 조건 및 기준 판본에 연결한다.

  • 입력 조건을 고정 persona로 묶지 않기

    앞 본문의 목표·입력 교차 맥락을 실제 평가 표의 맥락별 결과 구분으로 연결한다.

문제와 해결안을 분리하기

이전에 읽은 개념을 다시 찾지 못해 학습을 이어 가지 못한다는 가상 문제를 보자. 요구는 학습자가 해당 개념의 설명으로 다시 접근할 수 있어야 한다는 능력이다. 검색창 확대, 최근 읽은 목록, 주소 저장은 여러 해결안이다. 하나의 아이디어를 사용자 요구 그 자체라고 쓰면 다른 유효한 해결안을 비교하기 어렵다.

문제의 근거에는 실제 기록인지 가정인지, 누구의 어떤 맥락인지 붙인다. 요구에는 관련 문제ID를 연결하고 해결안·확인 항목에도 그 ID를 이어 둔다. 버튼이 구현되었다는 개발 완료와 학습자가 필요한 설명에 도달했다는 과업 성공은 별도로 확인한다.

확인 가능한 기준을 미리 정하기

예를 들어 처음 이용하는 대상10명이 동일한 자료에서 지정한 개념의 올바른 설명에120초 이내, 진행자의 도움 없이 도달하는 사례가8개 이상이라는 기준을 만들 수 있다. 시간의 시작과 끝, 올바른 도달의 판정, 도움의 범위, 중단과 실패의 처리, 대상 모집 조건을 미리 적어야 결과를 보고 유리하게 바꾸는 일을 막을 수 있다.

8/10이나120초는 이 교육 예에서 만든 기준이지 HCI 전체의 공인 합격선은 아니다. 오류 예방·접근성·만족 등 다른 요구도 각 확인 조건을 정한다. 빠른 경로 하나를 성공했다고 다른 기기나 언어에서의 접근, 전체 사용자 집단의 성과를 자동 보증하지 않는다.

성공률과 시간 통계의 분모

제한 시간과 도움 조건 없이 올바르게 도달한 비율,120초 이내 도달한 비율, 성공자만의 시간 중앙값은 서로 다른 질문에 답한다. 실패자를 시간 통계에서 제외하면 성공자의 속도를 설명할 수는 있지만 모든 시도의 경험을 대표하는 통계가 되지는 않는다. 실패자를 임의의 0초나 무한 초로 넣어 보통 평균을 계산해서도 안 된다.

성공 기준의 결합 조건을 만족한 시도 수를 전체 지정 시도 수로 나눈다. 중단이 있을 경우에도 사전에 정한 분모 정책을 따라야 한다. 작은 가상 표의 산술 통과는 실제 사용자의 시험이 아니며 모집단 일반화나 인과 효과를 증명하지 않는다. 자료를 새로 모았다면 표본과 시험 환경을 함께 기록한다.

중간 과정을 따라가는 예제

종이 표의10시도는 올바른 무도움 도달8개, 실패2개다. 성공8개의 시간은50/60/80/90/110/125/140/160초, 실패는120초에서 중단했다. 기준은10개 중8개 이상이 올바른 설명에 무도움으로120초 이내 도달이다. 성공률, 성공자 시간 중앙값, 결합 기준을 판정하라.

  1. 시간 제한을 무시한 올바른 무도움 도달은8/10=80%다. 그러나125/140/160초는 제한120초를 넘는다.

  2. 120초 이내 올바른 무도움 도달은50/60/80/90/110의5개다. 결합 비율은5/10=50%다.

  3. 성공 시간은 이미 오름차순이며8개라 가운데4번째90과5번째110을 평균내 중앙값100초다. 이는 성공8개만의 시간 통계다.

  4. 기준은 결합 성공8개 이상인데 실제 결합 성공은5개이므로 종이 표에서 기준 미달이다.80%와 중앙값 100초만으로 통과라고 판단하면 틀린다.

  5. 실패2개는 중단 시각120초지만 성공 도달 시간120초가 아니다. 실패자도 전체 시도 분모10에 남긴다.

시간 제한 없는 성공80%, 성공자 중앙값100초, 기준의 결합 성공50%이므로8/10 기준은 미달이다.

같은 전체 비율의 다른 맥락 결과

A와 B는 각각 K 네 시도와 P 네 시도를 포함한다. A의 성공 수는 K 세 개·P 두 개, B는 K 네 개·P 한 개다. 전체 및 맥락 기준의 판정을 구하라.

  1. 두 후보 모두 성공 수는 다섯 개로 전체 5/8=62.5%다.

  2. A는 K와 P 모두 성공 한 개 이상이고 B도 각각 네 개와 한 개로 만족한다.

  3. 두 후보는 자체 기준을 통과하지만 P의 성공 비율은 A가 50%, B가 25%다. 이 가상 여덟 시도를 모집단 성능으로 일반화하지 않는다.

둘 다 기준 통과이며 P 기록 비율은 A 50%, B 25%다.
