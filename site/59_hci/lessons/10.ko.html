소단원 10.1

heuristic evaluation

전문가가 발견한 문제를 실제 학생도 겪었다고 말해도 될까?

준비 개념과 학습 목표

준비 개념

  • 사용자 과업과 인터페이스

  • 관찰과 추론의 구별

학습 목표

  • 평가 원칙과 구체적인 화면 증거 연결하기

  • 독립 발견·문제 통합·실제 관찰 구별하기

같은 원칙에 연결된 두 화면 문제는 하나의 문제일까요?

앞 본문은 독립 발견 뒤 같은 문제 ID를 통합했다. 이번 자체 기록에서는 A가 P1·P2·Q, B가 P1·R, C가 Q·S를 발견했다. P1은 저장 화면의 성공 안내 누락, P2는 업로드 화면의 실패 안내 누락이다. 두 문제는 같은 상태 가시성 원칙에 연결되지만 화면·원인·영향이 서로 다르다고 이 과제에서 확인했다. 다른 평가자의 P1과 Q는 각각 동일한 문제라고 확인했다.

원기록의 출처를 남기면서 같은 문제끼리 묶는다. 평가자 이름·기기·과업·화면 위치·관찰한 사실·예상 영향·원인 가설을 구별한다. B가 기록한 재클릭 예상은 행동 가설이며 실제 재클릭 사건은 아직 없다. 원칙 이름과 발견 횟수가 같다고 문제의 정체성이나 사용자 발생률이 같아지는 것은 아니다.

독립 발견을 마친 뒤 동료 기록을 보며 수정안을 논의할 수 있다. 별도 사례에서 C가 자기 평가 전에 A의 목록을 읽었다면 그 기록도 남기되 독립 발견 조건을 충족한 자료로 표시하지 않는다. 아직 근거가 모자란 후보 T는 확인 대기로 분리한다. 확인 대기와 확인된 문제를 한 수로 섞거나 후보를 자동 삭제하지 않는다. 실제 화면·전문가·학생 평가는 수행하지 않았다.

먼저 확인할 개념
  • 독립 발견과 문제 ID 통합

    같은 원칙과 같은 문제를 구별하며 원기록 출처를 남기는 표를 추가한다.

  • 문제 근거와 개선 기준

    발견 횟수에 사용자 빈도나 심각도 의미를 붙이지 않도록 연결한다.

원칙으로 질문 만들기

heuristic evaluation은 전문가가 사용성 원칙을 기준으로 인터페이스의 잠재적인 문제를 찾는 평가다. Nielsen의 원칙은 현재 상태를 알 수 있는지, 익숙한 표현인지, 실수를 취소할 수 있는지 등을 물을 출발점이 된다. 원칙 번호만 적으면 어떤 사용자가 어디서 막히는지 알 수 없으므로 과업·화면 위치·관찰 가능한 동작을 함께 기록한다.

예를 들어 저장 버튼을 눌렀는데 아무 안내도 없다는 화면 사실과, 사용자가 저장 여부를 몰라 다시 누를 것이라는 가설은 구별한다. 앞의 사실은 화면 점검으로 확인할 수 있지만 뒤의 행동은 실제 사용자 관찰이 필요하다. 전문가의 판단만으로 학생 실험을 완료했다고 하지 않는다.

독립 발견 뒤 통합하기

평가자들은 대상 사용자, 수행 과업, 화면과 기기 범위를 먼저 맞춘 뒤 서로의 발견 목록을 보지 않고 점검한다. 처음부터 동료의 목록을 보면 같은 문제만 찾는 방향으로 생각이 끌릴 수 있다. 각자의 기록을 남긴 뒤 함께 비교하는 순서가 중요하다.

같은 장소·원인·영향을 가리키는 중복은 하나의 문제 ID로 합치되 서로 다른 증거와 의견을 보존한다. 같은 원칙을 위반한다는 이유만으로 서로 다른 화면 문제를 합치지는 않는다. 문제 수는 평가자끼리의 경쟁 점수도, 실제 사용자 실패율도 아니다.

발견에서 검증으로 이어가기

원칙 위반이 반드시 같은 수정으로 해결되는 것은 아니다. 작은 화면에서 메뉴를 접는 선택에는 공간과 발견 가능성 사이의 절충이 있을 수 있다. 실제 과업의 중요도와 사용자 맥락을 보고 대안을 제안한다.

아래 P·Q·R은 자체 교육 사례 ID이며 실제 사이트 감사 기록이 아니다. 목록의 합집합은 중복을 제거한 잠재 문제 수만 알려 준다. 사용자에게 그 문제가 얼마나 자주 발생하는지 판단하려면 별도 관찰 기회와 분모가 필요하다.

P1·P2·Q·R·S의 다섯 ID

원기록 일곱 건과 다른 수

행의 평가자별 기록 수를 더한 뒤 문제 ID별로 다시 묶는다. 같은 원칙이라는 열은 같은 문제라는 열을 대신하지 않는다. 기록 자체의 사실과 예상 사용자 행동을 따로 표시한다.

중간 과정을 따라가는 예제

교육 사례에서 평가자 A는 {P: 저장 결과 안내 없음,Q: 취소 경로 없음}, B는 {P,R: 날짜 표현 불일치}를 기록했다. 두 P가 같은 문제임을 확인했다. 기록 수와 고유 문제 수는?

  1. A 2건과 B 2건을 더하면 원기록 4건이다.

  2. 합집합 {P,Q,R}은 3개, 교집합 {P}는 1개다.

  3. P의 두 기록을 같은 ID로 묶되 각 평가자의 화면 근거를 남긴다.

원기록 4건, 고유 문제 3개, 공통 발견 1개. 사용자 발생률은 계산할 수 없다.

조건을 바꾸어 비교하기

원칙 이름으로 합치면 사라지는 문제

첫 기록표의 원기록 수와 고유 문제 수를 구하라. P1과 P2까지 합쳤을 때 생기는 차이도 설명하라.

  1. 평가자별 3+2+2를 더하면 원기록은 일곱 건이다.

  2. 동일 문제를 묶은 ID는 P1·P2·Q·R·S라 다섯 개다. P1/P2까지 합치면 네 개로 잘못 줄인다.

원기록은 일곱 건, 확인된 고유 문제는 다섯 개다. 같은 원칙만으로 합치면 다른 화면 문제 하나를 숨긴다.

비교할 점

원기록 일곱 건은 사용자 실패 일곱 번의 뜻이 아니다.

동료 목록을 먼저 본 평가자의 기록

별도 초기 평가에서 C만 자기 발견 전에 A의 목록을 읽었다. 같은 일곱 기록이 나와도 기록과 독립 조건을 어떻게 보고할까?

  1. 일곱 원기록과 다섯 문제 ID의 집계는 그대로 남긴다.

  2. A/B는 명시된 독립 조건을 만족하고 C는 사전 노출로 독립 조건을 충족하지 않았다고 기록한다.

문제 수는 그대로지만 세 명의 독립 발견 결과라고 보고하지 않는다.

비교할 점

같은 출력 목록만으로 자료를 만든 절차가 같다고 판단할 수 없다.

종이와 본문으로 직접 해보기

C가 {Q,S: 키보드 초점 없음}을 추가하면 기록 수와 고유 문제 수는? P와 S가 같은 원칙에 연결된다는 이유로 합쳐도 될까?

힌트 보기

원기록의 덧셈과 ID 합집합을 따로 구하자.

풀이 보기

원기록은 6건, 합집합 {P,Q,R,S}은 4개다. P와 S는 장소·원인·영향이 다른 문제라면 그대로 구별한다.

오해와 반례

전문가 발견 4건은 학생 실패 4회를 뜻한다.

전문가 목록은 잠재 문제 기록이다. 실제 학생 수와 수행 기회도 없으므로 실패 횟수나 발생률로 바꿀 수 없다.

스스로 풀어보기

먼저 답과 이유를 적고, 필요한 만큼 힌트를 한 단계씩 열어 보세요.

연습 1 · 값과 상태 예측

첫 독립 기록표에서 정확히 두 평가자가 보고한 문제와 한 평가자만 보고한 문제를 나누어라.

힌트 1

문제별 평가자 집합을 적는다.

힌트 2

P1/P2의 뒤 숫자는 다른 문제 ID다.

풀이와 답 확인

  1. P1은 A/B, Q는 A/C가 기록해 각각 두 평가자가 보고했다.

  2. P2는 A, R은 B, S는 C만 기록했다.

두 평가자의 문제는 P1·Q 두 개, 한 평가자의 문제는 P2·R·S 세 개다.

흔한 오답에서 다시 생각하기

P1과 P2를 합치면 상태 가시성 문제가 세 평가자에게 발견됐다.

원칙 범주와 문제 ID를 섞었고 C는 P1/P2를 보고하지 않았다.

연습 2 · 오류 찾아 고치기

B의 메모에는 저장 성공 표시가 없다는 화면 사실과 그래서 사용자가 세 번 재클릭할 것이라는 예상만 있다. 보고서가 실제 재클릭 세 회를 적었다. 고쳐라.

힌트 1

실제 관찰된 동작과 예상 동작을 나눈다.

힌트 2

예상 횟수에도 실제 사용자 분모는 없다.

풀이와 답 확인

  1. 화면 사실과 재클릭 가능성 가설을 각각 기록한다.

  2. 사용자의 실제 재클릭 횟수는 미관찰로 남기고 이후 같은 과업의 관찰 계획을 적는다.

세 번의 재클릭은 관찰 사실이 아니다. 현재 증거로 사용자 횟수나 발생률을 계산하지 않는다.

흔한 오답에서 다시 생각하기

전문가가 확신하면 예상 행동도 실제 관찰이다.

판단의 확신은 수행 기록을 만들지 않는다.

연습 3 · 직접 만들어 보기

확인된 다섯 문제와 미확인 후보 T를 함께 관리할 기록을 설계하라. T는 화면 근거가 아직 없다.

힌트 1

상태와 ID를 따로 둔다.

힌트 2

누가 무엇을 보았는지도 보존한다.

풀이와 답 확인

  1. 확인된 P1·P2·Q·R·S에는 출처와 화면·과업 근거를 연결한다.

  2. T에는 확인 대기 상태와 필요한 근거를 적는다. 확인된 문제 다섯 개와 후보 한 개로 나누어 보고한다.

확인된 문제는 다섯 개, 대기 후보는 한 개다. T의 필요 증거를 남기고 실제 평가 완료로 쓰지 않는다.

흔한 오답에서 다시 생각하기

화면 근거가 없으니 T를 지워 확인 완료라고 하자.

미확인 범위를 숨기면 확인 완료의 의미가 달라진다.

연습 4 · 선택 심화

선택 심화는 기본 연습 뒤 더 탐구하고 싶을 때 풀어 보세요.

별도 후속 보고에서 P2를 두 문제 P2a/P2b로 나눌 만큼 서로 다른 원인이 확인됐다. 나머지 ID는 같다. 고유 문제 수와 이전 기록 연결을 설명하라.

힌트 1

옛 ID 한 개를 새 ID 두 개로 바꾼다.

힌트 2

옛 기록을 새 발견 두 회로 바꾸지 않는다.

풀이와 답 확인

  1. 다섯 ID 중 P2 하나를 두 ID로 바꿔 고유 문제 수는 여섯 개다.

  2. 옛 P2 기록과 분할 근거를 두 새 ID에 연결한다. 원래 일곱 평가 기록을 새 실제 관찰 여덟 건으로 바꾸지 않는다.

고유 문제는 여섯 개이며 원기록은 일곱 건이다. 분류 판본과 연결 근거를 보존한다.

흔한 오답에서 다시 생각하기

문제 수가 하나 늘었으니 사용자의 실패도 하나 늘었다.

분류의 변화는 사용자 사건 발생의 변화가 아니다.

설명 기준 확인

아니다. 화면·원인·영향의 정체성을 먼저 확인한다.

동료 기록을 본 뒤 협의는 항상 금지인가?

설명 기준 확인

목표에 도착한 뒤 제공된 안내가 앞선 성공을 바꿀까요?

앞 본문의 도움 없는 성공과 도움 포함 도착을 사건 순서로 세분한다. 아래는 네 가상 세션이며 각 세션은 20초에 끝나거나 목표 도착 시 끝난다. A는 3초에 중립적 발화 요청을 받고 10초에 도착했다. A에게는 도착 뒤 12초의 별도 회고에서 정답 위치를 알려 주었다. B는 5초에 정답 경로 안내를 받고 9초에 도착했다. C는 안내 없이 20초에 도착하지 못해 종료했다. D는 4초에 중립적 발화 요청을 받고 8초에 조용히 도착했다.

이 자체 집계의 도움은 목표 도착 전에 정답 위치나 경로를 제공한 경우다. 생각을 계속 말해 달라는 중립 요청은 그 집계의 정답 도움으로 세지 않지만 시각과 내용을 보존한다. 중립 요청도 실제 행동을 바꿀 가능성이 있으므로 무개입 평상시 속도의 증거로 쓰지 않는다. A의 도착 뒤 안내는 이 첫 도착 판정에 소급 적용하지 않는다. 같은 내용을 다음 과업 전에 알려 주면 다음 과업의 사전 노출은 따로 기록한다.

발화가 없던 D도 목표 도착이라는 행동 근거로 이 과제에서는 성공이다. 침묵만으로 실패나 이해 완료를 추측하지 않는다. 세션 길이 평균에는 C의 중단까지의 20초를 넣을 수 있지만 이를 모든 세션의 완료 시간 평균이라고 부르지 않는다. 완료하지 않은 C의 완료 시간은 관측되지 않았다. 실제 모집·녹음·타이머·학생 실험은 미수행이다.

과업을 하며 생각 말하기

think-aloud는 참가자가 실제 과업을 진행하면서 현재 생각을 말하는 방법이다. 무엇을 찾고 무엇을 기대했는지 발화를 행동과 연결하면 클릭 결과만으로 알기 어려운 망설임을 이해할 수 있다. 대표적인 사용자와 과업을 정하고 목표는 주되 정답 버튼 위치를 알려 주지 않는다.

진행자는 생각을 계속 말해 달라는 중립적 안내를 사용할 수 있다. 그러나 빨간 버튼을 누르라는 지시는 선택을 바꾼다. 도움이 들어간 시점을 기록해야 이후 성공을 스스로 발견한 성공과 구별할 수 있다.

관찰과 추론 나누기

목록을 세 번 오갔다는 행동 기록과 설명을 이해하지 못했다는 해석은 다르다. 발화가 해석을 뒷받침해도 모든 생각이 말로 나오지는 않는다. 조용히 있었다는 사실만으로 성공이나 실패를 판단하지 않는다.

자체 성공 기준을 도움 없이 목표 페이지 도착으로 정했다면 안내 뒤 도착은 별도 도움 성공이다. 말하는 과업의 시간은 침묵한 평상시 수행 시간과 조건이 다르다. 발화로 생기는 부담과 진행자 개입을 해석에 포함한다.

설계와 실제 수행 구별하기

실험 계획에는 참여 동의, 중단 방법, 필요한 최소 기록과 보관 범위를 넣는다. 사람의 능력을 평가하는 자리가 아니라 인터페이스를 점검하는 자리임을 설명한다. 어린 참여자가 있다면 해당 기관·보호자 관련 절차를 확인할 계획을 세운다. 이것은 특정 법률 요건을 단정하는 설명이 아니다.

한 사람의 반복 사건과 화면을 보지 않은 사람을 어떻게 셀까요?

앞 본문의 사람·사건·발생 기회 분모를 별도 가상 장부로 확장한다. A는 기회 세 번 중 두 번, B는 한 번 중 한 번, C는 기회가 전혀 없고 사건도 없다. D는 기회 두 번에 사건이 없고 E는 기회 네 번 중 한 번 사건이 있다. 각 기회에는 해당 문제가 최대 한 번 발생한다는 자체 계약이다. 전체는 다섯 사람이며 화면에 노출된 사람은 A/B/D/E 네 명이다.

같은 네 사건이라도 전체 사람의 경험 비율, 노출된 사람의 경험 비율, 기회당 발생 비율, 전체 사람당 평균 사건 수는 다른 양이다. 화면을 보지 않은 C를 모든 사람 분모에는 포함하되 노출된 사람 분모에는 넣지 않는다. 관측 사건이 적다는 이유만으로 확인된 큰 영향까지 없어졌다고 판단하지 않는다.

별도 통합 문제 P의 독립 심각도 평가는 1·1·4, Q는 2·2·2다. P의 가운데 등급은 1, Q는 2지만 P의 등급 4 근거가 실제로 무엇인지 검토해야 한다. 이 과제의 자체 공개 조건은 근거가 확인된 회복 불가 입력 손실 문제가 남으면 공개 보류다. 중간 등급이나 단순 평균만으로 그 조건을 통과시키지 않는다. 개선 코드·재현 검사·사용자 재시험은 다른 증거 단계이며 모두 아직 실제 수행하지 않았다.

먼저 확인할 개념
  • 빈도와 심각도 근거

  • 통합 문제의 출처

    평가자의 등급 차이에 연결된 문제 근거를 보존한다.

분모가 있는 빈도

발생 횟수와 겪은 사람 수는 다르다. 한 사람이 같은 문제를 세 번 겪어도 문제를 겪은 사람은 한 명이다. 사람·과업·발생 기회·관측 기간 중 어떤 분모를 쓰는지 먼저 적는다. 해당 화면을 전혀 방문하지 않은 사람을 분모에 넣으면 발생 기회당 비율과 다른 값을 얻는다.

다섯 명 중 세 명이 겪었다는 3/5와 열 번의 기회 중 네 번 발생했다는 4/10은 서로 다른 질문의 답이다. 분모가 없으면 비율을 만들지 않는다. 작은 사례에서 얻은 비율을 전체 사용자 집단의 확정적 발생률로 쓰지 않는다.

심각도는 이유가 있는 판단

Nielsen은 빈도뿐 아니라 영향과 지속성을 고려하는 심각도 판단을 설명한다. 제시된 0~4 범주는 문제로 보지 않음, 외관상 문제, 작은 문제, 큰 문제, 출시 전 해결이 필요한 치명적 문제의 순서다. 이 숫자는 순서 범주이며 4가 2보다 피해량 두 배라는 물리량이 아니다.

통합 문제 목록에 대해 각 평가자가 독립적으로 등급과 이유를 남기고 의견 차이를 논의한다. 쉽게 되돌릴 수 있는 혼동과 입력 자료가 사라지는 실패는 영향과 회복 가능성이 다르다. 드물다는 이유만으로 큰 손실을 뒤로 미루지 않는다.

수정과 다시 확인할 기준

문제 기록에는 재현 과업, 증거, 영향, 원인 가설, 개선안과 완료 기준을 연결한다. 저장 실패 후 입력이 사라지는 사례라면 입력 유지, 실패 이유 표시, 재시도 경로를 자체 개선안으로 제안할 수 있다. 이것이 실제 사용자의 손실을 줄이는지는 다시 확인해야 한다.

수정 코드가 반영되었다는 것과 사용자 과업이 개선되었다는 것은 다른 증거다. 같은 과업 조건의 재검증에서 원래 문제와 새로운 문제를 함께 살핀다. 아래 계산은 가상 사례이며 실제 장비·학생 실험을 수행하지 않았다.

사람을 세는 행과 기회를 세는 행을 나누어 읽는다. 순서 등급의 가운데 값은 요약이며 가장 큰 영향 근거를 삭제하는 정책이 아니다. 자체 공개 조건은 별도로 검사한다.

중간 과정을 따라가는 예제

자체 사례 P는 쉽게 회복하는 문구 혼동으로 10회 기회 중 4회 발생했다. Q는 회복 불가 입력 손실로 2회 기회 중 1회 발생했다. 발생률과 개선 판단을 구하라.

  1. P는 4/10=40%, Q는 1/2=50%다.

  2. Q의 관측 기회는 두 번뿐이라 전체 사용자 발생률을 확정할 수 없다.

  3. 회복 불가 손실이라는 영향 근거로 Q를 우선 검토할 수 있다. 비율만 심각도 점수로 변환하지 않는다.

가상 관측 비율 40%와 50%. 빈도 외에 영향·지속성·회복 가능성으로 우선순위를 설명한다.

조건을 바꾸어 비교하기

세 분모에서 달라지는 빈도

가상 장부의 전체 사람 경험 비율, 노출된 사람 경험 비율, 기회당 발생 비율을 구하라.

  1. 사건을 겪은 A/B/E는 세 사람이다. 전체 다섯 사람 기준은 3/5=60%다.

  2. 노출된 네 사람 기준은 3/4=75%다. 네 사건과 열 기회 기준은 4/10=40%다.

전체 사람 기준 60%, 노출된 사람 기준 75%, 기회 기준 40%다. 같은 빈도 이름으로 서로 바꾸지 않는다.

중간 등급이 낮아도 남아 있는 공개 조건

P/Q 등급을 비교하라. 추가 확인에서 P의 회복 불가 손실 근거가 확인됐고 수정은 아직 안 됐다. 자체 공개 조건은 통과하는가?

  1. P의 가운데 등급은 1이고 Q는 2다. 등급 4를 피해량 네 배로 읽지 않는다.

  2. 자체 조건의 확인된 회복 불가 손실 P가 남으므로 공개를 보류한다. 등급 차이와 근거도 함께 남긴다.

가운데 등급 순서는 P가 낮지만 자체 공개 조건은 미충족이다. 실제 공개 결정이나 사용자 시험은 수행하지 않았다.

다른 문제에 적용하기

문제 정체성·도움 시점·누락 관측의 세 감사

세 독립 사례를 감사하라. ① A는 P1·P2·Q, B는 P1·R, C는 Q·S를 독립적으로 기록했다. P1/P2는 같은 원칙이지만 다른 화면·원인·영향이며 두 P1과 두 Q만 동일 문제다. 원기록과 고유 문제 수를 구하라. ② 네 세션 중 A는 10초 도착 뒤 12초 회고에서 정답 안내, B는 5초 안내 뒤 9초 도착, C는 20초 미도착 종료, D는 안내 없이 8초 도착했다. 도움은 도착 전 정답 경로 제공이다. 도움 없는 성공과 도움 포함 도착 비율을 구하라. ③ 전체 열 기회 중 아홉 기회가 관측되어 네 사건을 기록했고 누락 기회에는 최대 한 사건이 가능하다. 전체 발생 비율 범위를 구하라. 별도 P의 확인된 회복 불가 입력 손실이 남으면 공개 보류라는 자체 조건에서 가운데 등급 1만으로 공개 가능한지도 설명하라.

힌트 1

① 원칙 범주와 문제 ID를 나눈다. ② 안내와 도착의 앞뒤를 본다.

힌트 2

③ 관측 누락을 자동 무사건으로 바꾸지 않으며 공개 조건은 등급 요약과 따로 본다.

풀이와 답 확인

  1. ① 원기록은 3+2+2=7건이고 고유 ID는 P1·P2·Q·R·S 다섯 개다.

  2. ② 도움 없는 성공은 A/D 두 세션이라 2/4=50%다. B까지 도착한 세션은 세 개라 3/4=75%다. A의 회고 안내는 첫 도착 뒤다.

  3. ③ 전체 사건은 네 번 또는 다섯 번이라 전체 비율은 40%에서 50% 사이다. 가운데 등급이 1이어도 확인된 회복 불가 손실이 남아 자체 공개 조건은 미충족이다.

  4. 이 가상 기록과 정책 계산은 실제 사용자 관찰·코드 수정·재시험·공개 수행을 입증하지 않는다.

원기록은 일곱 건, 고유 문제는 다섯 개다. 도움 없는 성공은 50%, 도움 포함 도착은 75%다. 누락을 포함한 전체 열 기회의 발생 비율은 [40%,50%] 범위다. 확인된 회복 불가 손실이 남아 자체 공개 조건은 미충족이며 실제 실험·수정·공개는 미수행이다.

해결한 뒤 점검할 것

  • 같은 원칙과 동일 문제를 구별하고 출처를 보존한다.

  • 정답 도움의 시점과 정의에 맞춰 성공 분자를 계산한다.

  • 관측 분모와 누락 범위를 명시한다.

  • 순서 등급과 자체 공개 조건 및 실제 수행 증거를 구별한다.

기본 세 설명과 모든 기본 예제·활동·퀴즈, 새 저장 내용의 모든 과제·힌트·답·오답·전이를 손대조했다. 새 원기록은 일곱 건이고 고유 문제는 다섯 개이며 P2 분할 뒤 고유 문제는 여섯 개지만 원기록은 일곱 건을 유지한다. 첫 세션 A의 회고는 도착 뒤라 도움 없는 성공은 A/D 두 개로 50%, 도착 세 개는 75%다. 종료까지 길이 합은 47초, 평균은 11.75초다. 도움 없는 성공의 평균 완료 시간은 9초다. A 안내를 6초로 옮긴 별도 경우는 도움 없는 성공 25%, 도착 75%다. 가상 다섯 사람 중 경험한 세 사람의 비율은 60%, 노출된 네 사람 기준은 75%이고 네 사건과 열 기회 기준은 40%다. 사건 평균은 전체 사람당 0.8회, 노출 사람당 1회다. P의 가운데 등급은 1이고 Q는 2지만 확인된 P 손실이 남으면 자체 공개 조건은 미충족이다. 별도 누락 한 기회의 전체 발생 비율은 [40%,50%]다. 같은 단원 세 고유 기본 설명과 여섯 HTML 의미 앵커를 확인했다.
