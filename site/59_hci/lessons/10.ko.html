소단원 10.1

heuristic evaluation

전문가가 발견한 문제를 실제 학생도 겪었다고 말해도 될까?

준비 개념과 학습 목표

준비 개념

  • 사용자 과업과 인터페이스

  • 관찰과 추론의 구별

학습 목표

  • 평가 원칙과 구체적인 화면 증거 연결하기

  • 독립 발견·문제 통합·실제 관찰 구별하기

원칙으로 질문 만들기

heuristic evaluation은 전문가가 사용성 원칙을 기준으로 인터페이스의 잠재적인 문제를 찾는 평가다. Nielsen의 원칙은 현재 상태를 알 수 있는지, 익숙한 표현인지, 실수를 취소할 수 있는지 등을 물을 출발점이 된다. 원칙 번호만 적으면 어떤 사용자가 어디서 막히는지 알 수 없으므로 과업·화면 위치·관찰 가능한 동작을 함께 기록한다.

예를 들어 저장 버튼을 눌렀는데 아무 안내도 없다는 화면 사실과, 사용자가 저장 여부를 몰라 다시 누를 것이라는 가설은 구별한다. 앞의 사실은 화면 점검으로 확인할 수 있지만 뒤의 행동은 실제 사용자 관찰이 필요하다. 전문가의 판단만으로 학생 실험을 완료했다고 하지 않는다.

독립 발견 뒤 통합하기

평가자들은 대상 사용자, 수행 과업, 화면과 기기 범위를 먼저 맞춘 뒤 서로의 발견 목록을 보지 않고 점검한다. 처음부터 동료의 목록을 보면 같은 문제만 찾는 방향으로 생각이 끌릴 수 있다. 각자의 기록을 남긴 뒤 함께 비교하는 순서가 중요하다.

같은 장소·원인·영향을 가리키는 중복은 하나의 문제 ID로 합치되 서로 다른 증거와 의견을 보존한다. 같은 원칙을 위반한다는 이유만으로 서로 다른 화면 문제를 합치지는 않는다. 문제 수는 평가자끼리의 경쟁 점수도, 실제 사용자 실패율도 아니다.

발견에서 검증으로 이어가기

원칙 위반이 반드시 같은 수정으로 해결되는 것은 아니다. 작은 화면에서 메뉴를 접는 선택에는 공간과 발견 가능성 사이의 절충이 있을 수 있다. 실제 과업의 중요도와 사용자 맥락을 보고 대안을 제안한다.

아래 P·Q·R은 자체 교육 사례 ID이며 실제 사이트 감사 기록이 아니다. 목록의 합집합은 중복을 제거한 잠재 문제 수만 알려 준다. 사용자에게 그 문제가 얼마나 자주 발생하는지 판단하려면 별도 관찰 기회와 분모가 필요하다.

중간 과정을 따라가는 예제

교육 사례에서 평가자 A는 {P: 저장 결과 안내 없음,Q: 취소 경로 없음}, B는 {P,R: 날짜 표현 불일치}를 기록했다. 두 P가 같은 문제임을 확인했다. 기록 수와 고유 문제 수는?

  1. A 2건과 B 2건을 더하면 원기록 4건이다.

  2. 합집합 {P,Q,R}은 3개, 교집합 {P}는 1개다.

  3. P의 두 기록을 같은 ID로 묶되 각 평가자의 화면 근거를 남긴다.

원기록 4건, 고유 문제 3개, 공통 발견 1개. 사용자 발생률은 계산할 수 없다.

종이와 본문으로 직접 해보기

C가 {Q,S: 키보드 초점 없음}을 추가하면 기록 수와 고유 문제 수는? P와 S가 같은 원칙에 연결된다는 이유로 합쳐도 될까?

힌트 보기

원기록의 덧셈과 ID 합집합을 따로 구하자.

풀이 보기

원기록은 6건, 합집합 {P,Q,R,S}은 4개다. P와 S는 장소·원인·영향이 다른 문제라면 그대로 구별한다.

오해와 반례

전문가 발견 4건은 학생 실패 4회를 뜻한다.

전문가 목록은 잠재 문제 기록이다. 실제 학생 수와 수행 기회도 없으므로 실패 횟수나 발생률로 바꿀 수 없다.

한 단계 더

P를 개선하는 저장 중·성공·실패 상태 문구와 실패 시 다음 행동을 종이에 설계하자. 문구를 만들었다는 사실과 실제 사용성 향상은 구별한다. 실제 효과는 검증하지 않았다.

think-aloud

어느 버튼을 누를지 묻는 질문이 행동을 바꾸지는 않을까?

준비 개념과 학습 목표

준비 개념

  • 사용자 과업과 인터페이스

  • 관찰과 추론의 구별

학습 목표

  • 발화·행동·해석 구별하기

  • 중립 과업과 도움 개입을 기록하기

과업을 하며 생각 말하기

think-aloud는 참가자가 실제 과업을 진행하면서 현재 생각을 말하는 방법이다. 무엇을 찾고 무엇을 기대했는지 발화를 행동과 연결하면 클릭 결과만으로 알기 어려운 망설임을 이해할 수 있다. 대표적인 사용자와 과업을 정하고 목표는 주되 정답 버튼 위치를 알려 주지 않는다.

진행자는 생각을 계속 말해 달라는 중립적 안내를 사용할 수 있다. 그러나 빨간 버튼을 누르라는 지시는 선택을 바꾼다. 도움이 들어간 시점을 기록해야 이후 성공을 스스로 발견한 성공과 구별할 수 있다.

관찰과 추론 나누기

목록을 세 번 오갔다는 행동 기록과 설명을 이해하지 못했다는 해석은 다르다. 발화가 해석을 뒷받침해도 모든 생각이 말로 나오지는 않는다. 조용히 있었다는 사실만으로 성공이나 실패를 판단하지 않는다.

자체 성공 기준을 도움 없이 목표 페이지 도착으로 정했다면 안내 뒤 도착은 별도 도움 성공이다. 말하는 과업의 시간은 침묵한 평상시 수행 시간과 조건이 다르다. 발화로 생기는 부담과 진행자 개입을 해석에 포함한다.

설계와 실제 수행 구별하기

실험 계획에는 참여 동의, 중단 방법, 필요한 최소 기록과 보관 범위를 넣는다. 사람의 능력을 평가하는 자리가 아니라 인터페이스를 점검하는 자리임을 설명한다. 어린 참여자가 있다면 해당 기관·보호자 관련 절차를 확인할 계획을 세운다. 이것은 특정 법률 요건을 단정하는 설명이 아니다.

아래 네 사례는 자체 가상 기록이다. 실제 학생 모집·녹음·관찰을 수행하지 않았다. 작은 정성 사례 비율을 전체 학생 집단의 통계로 일반화하지 않으며 learner_review는 not_performed로 유지한다.

중간 과정을 따라가는 예제

가상 네 사례 A·B는 도움 없이 목표에 도착하고, C는 진행자의 경로 안내 후 도착하며, D는 도착하지 못했다. 도움 없는 성공률과 도움 포함 도착 비율은?

  1. 도움 없는 도착은 A·B 두 사례이므로 2/4=50%다.

  2. 도움을 포함하면 A·B·C 세 사례이므로 3/4=75%다.

  3. 분모는 같은 네 가상 사례지만 분자의 성공 정의가 다르다.

도움 없는 성공 50%, 도움 포함 도착 75%. 실제 학생 비율이 아니다.

발화·행동과 원인 해석을 분리하자.

풀이 보기

발화와 두 번 이동은 기록할 수 있지만 색이 원인인지는 아직 가설이다. 어떤 생각을 하고 계신지 계속 말씀해 주세요라고 요청하고 요청 시점을 기록한다.

정답 버튼을 알려 준 뒤 성공했으므로 쉽게 찾는 화면이다.

안내가 발견을 대신했을 수 있다. 안내 전 행동과 안내 뒤 도착을 나누어 기록해야 스스로 찾는 정도를 판단할 수 있다.

문제빈도·심각도·개선

드문 데이터 손실과 흔한 문구 혼동 중 무엇을 먼저 고칠까?

준비 개념과 학습 목표

준비 개념

  • 사용자 과업과 인터페이스

  • 관찰과 추론의 구별

학습 목표

  • 빈도 분모와 심각도 근거 기록하기

  • 개선과 재검증 기준 연결하기

분모가 있는 빈도

발생 횟수와 겪은 사람 수는 다르다. 한 사람이 같은 문제를 세 번 겪어도 문제를 겪은 사람은 한 명이다. 사람·과업·발생 기회·관측 기간 중 어떤 분모를 쓰는지 먼저 적는다. 해당 화면을 전혀 방문하지 않은 사람을 분모에 넣으면 발생 기회당 비율과 다른 값을 얻는다.

다섯 명 중 세 명이 겪었다는 3/5와 열 번의 기회 중 네 번 발생했다는 4/10은 서로 다른 질문의 답이다. 분모가 없으면 비율을 만들지 않는다. 작은 사례에서 얻은 비율을 전체 사용자 집단의 확정적 발생률로 쓰지 않는다.

심각도는 이유가 있는 판단

Nielsen은 빈도뿐 아니라 영향과 지속성을 고려하는 심각도 판단을 설명한다. 제시된 0~4 범주는 문제로 보지 않음, 외관상 문제, 작은 문제, 큰 문제, 출시 전 해결이 필요한 치명적 문제의 순서다. 이 숫자는 순서 범주이며 4가 2보다 피해량 두 배라는 물리량이 아니다.

통합 문제 목록에 대해 각 평가자가 독립적으로 등급과 이유를 남기고 의견 차이를 논의한다. 쉽게 되돌릴 수 있는 혼동과 입력 자료가 사라지는 실패는 영향과 회복 가능성이 다르다. 드물다는 이유만으로 큰 손실을 뒤로 미루지 않는다.

수정과 다시 확인할 기준

문제 기록에는 재현 과업, 증거, 영향, 원인 가설, 개선안과 완료 기준을 연결한다. 저장 실패 후 입력이 사라지는 사례라면 입력 유지, 실패 이유 표시, 재시도 경로를 자체 개선안으로 제안할 수 있다. 이것이 실제 사용자의 손실을 줄이는지는 다시 확인해야 한다.

수정 코드가 반영되었다는 것과 사용자 과업이 개선되었다는 것은 다른 증거다. 같은 과업 조건의 재검증에서 원래 문제와 새로운 문제를 함께 살핀다. 아래 계산은 가상 사례이며 실제 장비·학생 실험을 수행하지 않았다.

중간 과정을 따라가는 예제

자체 사례 P는 쉽게 회복하는 문구 혼동으로 10회 기회 중 4회 발생했다. Q는 회복 불가 입력 손실로 2회 기회 중 1회 발생했다. 발생률과 개선 판단을 구하라.

  1. P는 4/10=40%, Q는 1/2=50%다.

  2. Q의 관측 기회는 두 번뿐이라 전체 사용자 발생률을 확정할 수 없다.

  3. 회복 불가 손실이라는 영향 근거로 Q를 우선 검토할 수 있다. 비율만 심각도 점수로 변환하지 않는다.

가상 관측 비율 40%와 50%. 빈도 외에 영향·지속성·회복 가능성으로 우선순위를 설명한다.

종이와 본문으로 직접 해보기

다섯 사람 중 세 사람이 P를 겪고, P 사건은 총 네 번이었다. 사람 비율과 전체 사람당 평균 사건 수는? 기회당 발생률도 구할 수 있나?

힌트 보기

사람 수와 사건 수의 분자를 나누자.

풀이 보기

겪은 사람 비율은 3/5=60%, 전체 사람당 사건 수는 4/5=.8회다. 사건 발생 기회 수가 없으므로 기회당 발생률은 구할 수 없다.

오해와 반례

심각도 4는 심각도 2보다 피해가 정확히 두 배다.

0~4는 순서 있는 판단 범주다. 크기 비율을 보장하지 않으므로 영향·회복·반복의 구체적 근거를 함께 적는다.
