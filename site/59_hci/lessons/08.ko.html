소단원 8.1

종이·디지털 prototype

버튼을 눌렀을 때 다음 화면을 아직 만들지 않았다면 무엇을 확인할 수 있을까?

준비 개념과 학습 목표

준비 개념

  • prototype 은 완제품 전에 질문을 시험하기 위한 시제품이다.

  • 화면 상태와 사용자의 행동을 구별한다.

학습 목표

  • 종이 화면의 상태 전이를 적는다.

  • 디지털 연결과 실제 기능 구현의 차이를 설명한다.

같은 소개 카드가 서로 다른 과목을 보여 줄 수 있을까요?

앞 본문은 카드 이름과 그 안의 과목 자료를 구별했다. 새 종이 모형의 전체 상태는 화면과 검색어 q, 선택한 과목 ID i, 저장 집합 S의 네 항목이다. 초기 상태는 화면 A, 빈 검색어, 선택 없음, 빈 저장 집합이다. 지원 검색어 선형은 결과 B에서 과목 ID 1과 2를 보여 주고, 미적분은 ID 3을 보여 준다. 이 두 검색어 이외의 입력은 결과 없음 D로 간다. 실제 검색이나 저장소는 없다.

A에서 제출하면 q가 해당 검색어로 바뀌고 i는 없음이 된다. B에서 ID를 선택하면 소개 화면 C와 그 ID를 함께 설정한다. C의 저장 행동은 i를 S에 추가하고 C에 머문다. C의 뒤로는 q와 i와 S를 보존해 같은 결과 B로 돌아간다. D의 수정은 A로 돌아가되 q를 보존한다. 각 행동에서 명시하지 않은 상태 항목은 그대로 둔다. C 한 장에 제목을 ID 1의 자료로 고정하면 ID 2 선택도 1처럼 보이는 잘못된 모형이 된다.

종이 컴퓨터 담당은 이 계약에 따라 카드와 자료를 바꾼다. 지원 밖 입력의 결과를 즉석에서 발명하거나 잘못된 카드를 보여 준 뒤 없었던 일로 지우면 시험 대상과 기록을 바꾼다. 판본과 실제 표시·복구 사건을 남긴다. 화면이 같아도 자료나 S가 바뀌는 사건을 놓치지 않으며 카드 교체 지연을 서버 응답 시간으로 부르지 않는다.

먼저 확인할 개념
  • 화면 이름과 자료 바인딩

    같은 C 카드와 여러 과목 ID를 구별하는 기본 활동을 전체 상태 계약으로 확장한다.

  • 시작 상태와 도움 규약

    저장 목록 초기화와 진행자의 경로 힌트를 별도 기록한다.

화면보다 행동의 연결을 만든다

과목 찾기 화면 한 장은 목록의 배치를 보여 준다. 하지만 검색어 입력 뒤 무엇을 보여 줄지, 결과를 고른 뒤 어디로 갈지 없으면 탐색 과업을 끝낼 수 없다. 먼저 시작 상태·행동·다음 상태를 세 칸 표로 적는다.

종이 prototype 에서는 사람이 정해 둔 전이표에 맞춰 화면 카드를 교체한다. 참가자의 선택을 대신하거나 정답 버튼을 가리키면 설계의 이해 가능성과 진행자의 도움 효과를 분리할 수 없다. 화면 교체 담당과 관찰 기록 역할을 준비한다.

디지털 화면도 계약을 정한다

같은 그림을 디지털 도구의 클릭 영역과 연결하면 자동으로 다음 화면을 보여 줄 수 있다. 그러나 화면 전환을 만들었다고 서버 검색이나 데이터 저장까지 구현된 것은 아니다. 실제 기능·고정 자료·사람이 대신하는 부분을 구분해 표시한다.

예제의 검색 결과는 미리 만든 단어 세 개만 처리하는 자체 모형이다. 다른 단어를 입력했을 때 진행자가 임의로 결과를 발명하면 원래 설계와 다른 모형을 시험하게 된다. 지원 밖 입력은 지원하지 않는 상태로 기록하고 필요한 경우 다음 판에 추가한다.

반복은 관찰에서 수정으로 간다

막힌 화면에서 문제를 메모하고 설계 가설을 적은 다음 새 판을 만든다. 예컨대 결과 없음에서 검색어를 바꾸는 길이 없다는 문제라면 수정안은 편집으로 돌아가는 연결이다. 색만 바꾸고 이 경로를 그대로 두면 그 문제를 해결한 것이 아니다.

아래 활동은 카드의 논리적 연결만 확인한다. 사람이 카드를 다루는 지연은 실제 앱 응답 성능 측정이 아니며, 만든 경로가 타당하다고 실제 학생이 쉽게 사용할 것이라 검증된 것도 아니다. 사용자 관찰은 별도 수행해야 한다.

같은 카드 이름과 다른 전체 상태

화면 카드의 이동 횟수와 전체 상태 변경 횟수를 따로 센다. 저장 집합에 같은 ID를 다시 추가하는 행동도 기록하지만 집합 내용은 변하지 않는다.

중간 과정을 따라가는 예제

자체 카드 A=검색 입력, B=결과 목록, C=과목 소개, D=결과 없음이다. A 에서 알려진 검색어를 제출하면 B, 모르는 검색어는 D, B 에서 과목 선택은 C, C 의 뒤로는 B 다. D 에는 나가는 연결이 없다. 미지 검색어에서 다시 검색하려면 무엇이 부족한가?

  1. A 에서 미지 검색어를 제출하여 D 에 도달한다.

  2. D 의 나가는 연결이 없으므로 검색어 수정이라는 다음 행동을 할 수 없다.

  3. D 의 검색어 수정 행동을 A 로 연결한다. 새 전이는 A→D→A 이며 다음에 알려진 단어를 넣으면 A→B→C 로 진행한다.

D→A 연결이 필요하다. 수정 뒤 두 제출과 선택을 포함한 경로 A,D,A,B,C 의 전이는 4 번이다.

조건을 바꾸어 비교하기

일곱 사건과 네 번의 화면 이동

처음부터 선형 제출, ID 2 선택, 저장, 뒤로, ID 1 선택, 저장, 저장을 차례로 수행한다. 마지막 상태와 화면 이동·전체 상태 변경 횟수를 구하라.

  1. 제출과 두 선택·뒤로는 각각 화면을 바꿔 총 네 번 이동한다. 두 최초 저장은 S에 2와 1을 추가하고 같은 C에 머문다.

  2. 마지막 반복 저장은 S={1,2}를 그대로 두므로 전체 상태는 변하지 않는다. 전체 상태 변경은 앞의 여섯 사건이다.

사건은 일곱 개, 화면 이동은 네 번, 전체 상태 변경은 여섯 번이다. 마지막은 C, q는 선형, i는 1, S는 {1,2}다.

비교할 점

저장 버튼을 눌렀다는 사건과 집합 내용의 변경은 다른 수다.

결과 없음에서 수정하고 새 자료 선택

초기 상태에서 지원 밖 검색어 벡터 제출, 수정, 미적분 제출, ID 3 선택을 한다. 마지막 q와 i, 화면 이동 수는?

  1. 화면 순서는 A,D,A,B,C다. D의 수정은 q를 보존하지만 새 제출은 q를 미적분으로 교체한다.

  2. 마지막 선택은 i를 3으로 설정하며 저장 행동은 없었다.

화면 이동은 네 번이다. 마지막 화면 C의 q는 미적분, i는 3, S는 빈 집합이다.

비교할 점

A로 돌아온 사실만으로 검색어가 빈 문자열이라고 추정하지 않는다.

종이와 본문으로 직접 해보기

A 에서 알려진 단어를 제출하고 과목을 선택한 뒤 뒤로 간다. 카드 순서를 적고 B 에서 다른 과목을 고를 때 C 가 고정된 한 과목이면 무엇이 빠졌는지 설명하라.

힌트 보기

한 화면 이름과 그 화면이 담는 과목 자료는 별개다.

풀이 보기

A,B,C,B 의 전이는 3 번이다. 다른 과목의 소개 상태나 자료 바인딩을 준비해야 한다. 같은 C 카드의 제목만 고정해 두면 여러 과목 선택을 검증하지 못한다.

오해와 반례

클릭 가능한 화면이면 검색 기능도 구현됐다.

A→B 의 연결이 고정 결과 카드만 보여 주어도 클릭은 가능하다. 실제 검색 알고리즘·저장소·없는 단어 처리는 각각 별도의 기능이다.

스스로 풀어보기

먼저 답과 이유를 적고, 필요한 만큼 힌트를 한 단계씩 열어 보세요.

연습 1 · 값과 상태 예측

앞 첫 예제에서 첫 저장 직후 뒤로 간 상태와 ID 1을 선택한 직후 상태를 비교하라.

힌트 1

뒤로는 q와 S를 보존한다.

힌트 2

선택한 i만 바뀌는지 화면도 바뀌는지 본다.

풀이와 답 확인

  1. 뒤로 직후는 B, q는 선형, i는 2, S는 {2}다.

  2. ID 1 선택 뒤는 C, q는 선형, i는 1, S는 {2}다.

뒤로는 저장 목록을 지우지 않고 새 선택은 저장 집합에 자동 추가하지 않는다.

흔한 오답에서 다시 생각하기

뒤로 가면 S가 비워지고 다음 선택은 자동 저장된다.

두 행동의 계약에는 그런 자료 변경이 없다.

연습 2 · 오류 찾아 고치기

ID 2 선택 뒤 C에 ID 1의 제목이 표시됐다. 진행자가 제목만 조용히 바꾸고 오류 사건을 기록하지 않았다. 무엇을 고쳐야 하는가?

힌트 1

선택 ID와 표시 자료의 대응을 본다.

힌트 2

이미 노출한 내용은 회수해도 관찰 이력에 남는다.

풀이와 답 확인

  1. 정상 계약은 ID 2 자료 표시다. 잘못된 표시와 정정 사건을 기록하고 판본의 자료 바인딩을 고친다.

  2. 정정 뒤 행동도 오염 가능성이 있는 기록으로 구별한다.

표시를 고친 사실이 앞서 본 ID 1 자료와 진행자 설명의 영향을 지우지 않는다.

흔한 오답에서 다시 생각하기

정정했으니 처음부터 정확한 카드만 본 기록으로 쓴다.

실제 표시 이력을 숨겨 이해 가능성과 진행자 오류를 구별하지 못한다.

연습 3 · 직접 만들어 보기

각 과업을 새 초기 상태에서 시작하도록 준비표를 쓰고 S={2}가 남은 상태에서 ID 2 저장 과업을 시작하는 오류를 설명하라.

힌트 1

화면만 A로 바꾸는 초기화로 충분한지 본다.

힌트 2

완료 조건이 이미 충족됐는지 확인한다.

풀이와 답 확인

  1. 화면 A, q는 빈 문자열, i는 없음, S는 빈 집합을 각각 준비한다.

  2. S={2}가 남으면 새 저장 효과 없이도 ID 2 목록 확인이 가능하여 과업의 시작 전제를 깨뜨린다.

화면과 자료를 함께 초기화하고 과업별 시작·판본·지원 범위를 기록한다.

흔한 오답에서 다시 생각하기

첫 카드 A만 보이면 모든 과업 조건이 같다.

보이지 않는 저장 집합과 검색어가 다음 결과에 영향을 준다.

연습 4 · 선택 심화

선택 심화는 기본 연습 뒤 더 탐구하고 싶을 때 풀어 보세요.

지원 밖 벡터 입력에 진행자가 새 결과 ID 4를 만들었다. 기존 판본과 같은 검색 계약의 증거로 합칠 수 있는가?

힌트 1

지원 범위와 결과 생성 규칙을 대조한다.

힌트 2

새 행동을 숨기지 않고 판본을 나눈다.

풀이와 답 확인

  1. 기존 계약은 D로 가는 것인데 새 결과를 발명하여 전이를 바꿨다.

  2. 새 판본의 지원 범위를 명시하고 원래 관찰과 별도로 기록한다.

기존 판본의 수행 결과로 합치지 않는다. 새 판본도 실제 검색 기능을 구현한 증거는 아니다.

흔한 오답에서 다시 생각하기

소단원 8.2

충실도와 검증목적

예쁜 화면과 실제로 작동하는 화면은 같은 수준의 prototype 일까?

준비 개념과 학습 목표

준비 개념

  • 충실도는 최종 제품과 닮은 정도이며 하나의 점수만으로 설명하기 어렵다.

  • 시험 질문을 먼저 정하면 필요한 자료와 반응을 선택할 수 있다.

학습 목표

  • 시각·상호작용·내용의 충실도를 분리한다.

  • 주장할 수 있는 결론의 범위를 정한다.

지원 요소가 많으면 모든 질문을 시험할 수 있을까요?

새 준비 행렬의 열은 실제 내용 C, 조작 경로 I, 실제 표시 크기와 색 V, 실제 저장 구현 D다. 값 1은 이 과제에서 정한 요소를 준비했다는 뜻이다. 사용자 성공 확률이나 충실도의 보편 점수가 아니다. 내용 이해 질문 X에는 C, 탐색 완료 질문 Y에는 I, 읽기 질문 Z에는 V, 재시작 뒤 저장 보존 질문 W에는 D가 필요하다.

두 후보 P=(1,0,1,0), Q=(0,1,0,0)를 둔다. 같은 한 시제품에서 설명을 읽고 과목을 선택해 돌아오기라는 결합 질문 J에는 C와 I를 함께 요구한다. P에서 읽고 Q에서 이동한 두 별도 기록만으로 같은 시제품의 결합 경험을 시험했다고 말하지 않는다. 두 화면의 내용과 버튼 맥락이 연결됐는지도 준비해야 한다.

자체 추가 비용은 P에 I를 붙이면 3단위, Q에 C를 붙이면 2단위, Q에 V를 붙이면 4단위다. 비용은 가상 준비 노력이며 실제 도구 가격이나 제작 시간은 아니다. J만 준비하는 최소 후보와 J와 Z를 함께 준비하는 최소 후보를 구별한다. 어느 준비안도 D를 제공하지 않아 W의 저장 지속성은 미지원이다.

먼저 확인할 개념

    기본 내용/경로 행렬을 네 요소와 결합 질문으로 확장한다.

  • 고정 자료와 실제 구현

    카드 연결이 실제 저장·재시작 복구를 대신하지 않는 이유를 확인한다.

어떤 면에서 닮았는지 묻는다

시각 충실도는 배치·색·글꼴 같은 모습, 상호작용 충실도는 입력에 대한 반응, 내용 충실도는 문장·자료의 현실성을 뜻한다. 세 가지를 각각 적으면 화려하지만 클릭이 안 되는 화면과 단순하지만 탐색이 되는 화면을 구별할 수 있다.

이 단원은 낮음/높음이라는 자체 두 수준 표를 쓴다. 실제 설계는 중간 수준도 있으며 모든 차원을 동시에 높여야 한다는 규칙은 아니다. 시험하려는 질문에 꼭 필요한 차원이 무엇인지 먼저 적는다.

질문에 필요한 표현을 남긴다

학습자가 과목 설명을 이해하는지 묻는데 모든 설명이 가짜 한 줄이면 내용 이해를 시험하지 못한다. 반대로 버튼 사이 이동을 확인하는 질문에는 서버 전체가 반드시 필요하지 않을 수 있다. 필요한 자료와 움직임을 골라 작은 시제품으로 시험한다.

색 대비·작은 글자 읽기 같은 질문은 실제 표시 크기와 관련 색이 충분히 표현되어야 한다. 흑백 큰 종이에서 읽힌 결과로 실제 작은 휴대전화의 읽기 쉬움을 확정할 수 없다. 매체와 지원 범위를 결론에 함께 붙인다.

충실도와 성능 증거를 구별한다

입력과 화면 반응이 잘 연결되어도 고정 자료로 만든 프로토타입은 많은 사용자가 접속하는 상황의 성능을 보여 주지 않는다. 실제 저장·통신을 생략한 부분은 해당 결론의 근거가 될 수 없다.

자체 요구표에서 기능이 제공되면 1, 없으면 0 으로 표시한다. 이것은 검증 가능성의 필요조건을 점검하는 도구이지 실제 참가자의 성공을 예측하는 확률은 아니다. 조건을 갖춘 뒤 실제 실험을 해야 효과를 관찰할 수 있다.

질문별 필요 열을 모두 만족하는지 같은 행 안에서 확인한다. 비용 비교는 선언한 추가 작업만의 가상 계산이며 실제 효과를 관찰한 결과가 아니다.

중간 과정을 따라가는 예제

시제품 P 는 실제 과목 설명·그림이 있지만 정적 화면이고, Q 는 클릭 경로가 있지만 설명은 모두 lorem ipsum 이다. 질문 X 는 설명을 읽고 선수과목을 고를 수 있는지, Y 는 검색→소개→돌아가기 경로를 끝낼 수 있는지다. 내용/경로 지원을 P=(1,0),Q=(0,1)로 두고 각 질문에 필요한 요소를 판정하라.

  1. X 는 실제 설명을 필요로 하므로 내용 지원이 1 인 P 가 해당 자료 조건을 갖춘다.

  2. Y 는 세 상태의 상호작용을 필요로 하므로 경로 지원이 1 인 Q 가 조건을 갖춘다.

  3. X 와 Y 를 모두 확인하려면 실제 내용을 Q 에 넣거나 P 의 상태 연결을 추가해야 한다. 원래 어느 하나도 두 요구를 모두 충족하지 않는다.

자체 요구표에서 P 는 X 자료, Q 는 Y 경로를 지원한다. 이것은 실험 준비 가능성 판정이며 실제 이해·사용 성공 결과는 아니다.

조건을 바꾸어 비교하기

결합 질문 하나의 최소 준비

J만 준비하려면 P에 I 또는 Q에 C를 추가할 수 있다. 가상 비용을 비교하라.

  1. P 경로 추가는 3단위다. Q 내용 추가는 2단위다.

  2. 원래 두 후보를 그대로 나눠 쓰면 같은 후보에서 C와 I의 결합 조건을 만족하지 않는다.

J만의 최소 추가 비용은 Q에 C를 붙이는 2단위다. 실제 완료 관찰은 아직 없다.

비교할 점

서로 다른 준비안의 효과나 실제 비용 순위를 증명하는 계산은 아니다.

질문을 추가하면 준비안 순위가 바뀐다

J와 Z를 같은 후보에서 준비한다. P에 I를 붙이는 안과 Q에 C 및 V를 붙이는 안을 비교하라.

  1. P는 이미 C와 V가 있으므로 I 추가 비용 3단위로 세 열을 채운다.

  2. Q는 C 추가 2단위와 V 추가 4단위가 필요해 합계 6단위다.

J와 Z에는 P의 추가 비용 3단위가 Q의 6단위보다 작다. W는 양쪽 모두 미지원이다.

비교할 점

J만의 최소안이 질문 추가 뒤에도 최소라고 가정하지 않는다.

소단원 8.3

참여자 과업 구성

“오른쪽 즐겨찾기 버튼을 누르세요”라고 안내하면 무엇을 알아낼 수 없을까?

준비 개념과 학습 목표

준비 개념

  • 과업은 화면 조작 명령보다 참여자가 달성할 목표로 표현할 수 있다.

  • 성공 기준과 도움 여부를 사전에 정한다.

학습 목표

  • 정답 경로를 유도하지 않는 과업을 쓴다.

  • 가상 사건표에서 독립 성공과 도움 뒤 완료를 구별한다.

과업 성공과 모든 과업을 끝낸 참여자의 비율은 같을까요?

새 합성 기록은 참여자 A/B/C 세 명이 과업 U와 V를 수행하는 여섯 기회다. 독립 성공은 I, 경로 힌트 뒤 완료는 H, 유효하지만 기준 미완료는 F다. 기록은 A=(I,I), B=(I,H), C=(F,I)다. 도구 오류 기회는 이 첫 표에 없고 모든 기회가 유효하다. 실제 참여자나 UI 시험은 수행하지 않았다.

과업 기회 기준 독립 성공은 네 건이고 도움 포함 완료는 다섯 건이다. 모든 과업을 독립적으로 끝낸 참여자는 A 한 명이다. 한 번이라도 독립 성공한 참여자는 세 명이다. 이 네 지표는 분자와 분모가 달라 서로 대체할 수 없다. 과업 U는 독립 성공 두 건, V도 두 건이지만 B의 도움과 C의 미완료가 서로 다른 과업에 있다.

별도 재시험 표에서 같은 세 사람의 V 결과가 모두 I가 되었다고 하자. 첫 V의 독립 성공은 두 건, 재시험은 세 건이지만 판본 변경·순서·앞 과업에서의 학습이 함께 달라졌다면 향상 한 건의 원인을 설계 변경 하나로 확정하지 못한다. 시작 상태와 도움 규약, 판본·순서·기회를 함께 기록하고 실제 모집단 효과로 발표하지 않는다.

먼저 확인할 개념
  • 독립 성공과 도움 뒤 완료

    기본 네 기회 산술을 참여자별 두 과업의 다른 분모로 확장한다.

  • 도구 오류와 유효 기회의 구별

    기본 과업 구성 설명의 도구 고장·지원 밖 행동과 유효 기회 정책을 대조한다.

맥락과 목표를 주고 경로는 남긴다

공개 강의에서 나중에 다시 볼 과목을 보관하려는 상황을 제시한다. 즐겨찾기라는 버튼명과 위치를 먼저 알려 주면 그 이름을 발견하고 이해하는지 관찰하기 어렵다. 필요한 과목과 목표는 구체적으로 주되 경로 자체를 지시하지 않는다.

애매하게 알아서 해 보라고만 하면 참여자가 목표를 물어야 할 수 있다. 어떤 과목을 찾는지, 어떤 결과가 필요한지를 분명히 적는다. 표준 용어를 억지로 피해서 더 혼란스러운 문장을 만드는 것도 목표가 아니다.

시작 상태와 성공 판정을 고정한다

각 과업에서 계정·저장 목록·검색 상태를 같은 조건으로 준비하고 완료 기준을 적는다. 이 예제의 성공은 특정 과목을 저장하고 나중에 볼 목록에서 확인하는 것이다. 좋아 보인다는 말만으로 완료 판정을 대신하지 않는다.

이 단원은 도움 없이 기준 충족이면 독립 성공, 진행자의 경로 힌트 뒤 충족이면 도움 뒤 완료로 분리하는 자체 기록 규약을 쓴다. 중단·도구 고장·지원 밖 행동도 별도 적어야 사용자의 실패와 시제품 한계를 구별할 수 있다.

기록은 과업과 참여자별로 나눈다

참여자별 시작·행동·막힘·도움·결과를 연결하면 수정할 근거가 남는다. 앞 과업에서 저장 기능을 배웠다면 다음 과업 결과에 학습 효과가 있을 수 있으므로 과업 순서도 기록한다.

아래의 인물과 사건은 모두 만들어 낸 교육용 표다. 실제 참여자를 모집하거나 실험하지 않았으므로 성공 비율을 사이트의 검증 수치로 공개하면 안 된다. 작은 가상 표의 산술과 모집단 추론은 별개다.

중간 과정을 따라가는 예제

자체 가상 로그에서 A 는 도움 없이 과목 저장과 목록 확인, B 는 저장했으나 목록 확인 전에 중단, C 는 위치 힌트 뒤 두 기준 충족, D 는 도움 없이 두 기준 충족했다. 네 과업 기회 모두 유효하며 독립 성공 기준은 두 결과를 도움 없이 충족하는 것이다.

  1. A 와 D 는 두 기준을 도움 없이 충족하여 독립 성공 2 명이다.

  2. C 는 도움 뒤 완료, B 는 이번 기준 미완료다. 저장 한 단계만 끝냈다고 전체 성공으로 바꾸지 않는다.

  3. 독립 성공 비율은 2/4=50%, 도움 포함 완료는 3/4=75%다. 두 수치의 분자 정의가 다르다.

가상 표의 독립 성공 50%, 도움 포함 완료 75%다. 실제 이용자의 성과나 모집단의 확률 추정은 아니다.

조건을 바꾸어 비교하기

같은 표의 네 비율

A=(I,I), B=(I,H), C=(F,I)의 독립 기회 성공·도움 포함 완료·모든 과업 독립 완료·한 번 이상 독립 완료 비율을 구하라.

  1. 기회 분모는 여섯 건이고 I 네 건, I 또는 H 다섯 건이다.

  2. 사람 분모는 세 명이다. 두 과업 모두 I는 A만이며 한 번 이상 I는 세 명 모두다.

독립 기회 성공은 4/6=2/3, 도움 포함 완료는 5/6, 모든 과업 독립 완료는 1/3, 한 번 이상 독립 완료는 3/3=100%다.

비교할 점

100%는 두 과업 전체 독립 완료를 뜻하지 않는다.

도구 오류를 따로 표시한 새 표

별도 기록에서 C의 V 기회만 시제품 고장 E로 바뀌었다. 규약은 E를 유효 기회 분모에서 제외하되 전체 시도 수에 남긴다. 독립 성공과 도움 포함 완료를 구하라.

  1. 전체 시도는 여전히 여섯 건이고 E 한 건을 빼 유효 기회는 다섯 건이다. I는 세 건, H는 한 건이다.

  2. 독립 성공은 3/5, 도움 포함 완료는 4/5다. 실패 F 한 건과 도구 오류 E 한 건을 별도로 보고한다.

유효 기회 독립 성공은 60%, 도움 포함 완료는 80%다. 전체 시도 여섯 건과 평가 불가 한 건을 함께 명시한다.

비교할 점

도구 오류를 성공으로 세거나 발생 자체를 숨기는 정책이 아니다.

유효 기회 분모와 전체 시도 분모를 이름 붙인다.

풀이와 답 확인

  1. 전체 시도 기준 독립 성공은 3/6=50%다. 유효 기회 기준은 3/5=60%다.

  2. 도구 오류 한 건을 제외한 사유와 두 분모를 공개한다.

두 비율을 서로 다른 이름으로 보고하며 E를 참여자의 기능 이해 실패 F로 자동 바꾸지 않는다.

상태와 준비 조건과 수행 분모를 함께 점검하기

① 첫 초기 상태에서 선형 제출, ID 2 선택, 저장, 뒤로, ID 1 선택, 저장, 저장의 일곱 사건을 손추적하고 화면 이동과 상태 변경을 구별하라. ② P=(C1,I0,V1,D0), Q=(C0,I1,V0,D0), P의 I 추가 비용 3단위, Q의 C 추가 2단위 및 V 추가 4단위다. 같은 후보에서 결합 질문 J와 표시 질문 Z를 준비할 최소 추가 비용과 저장 질문 W 지원을 판단하라. ③ 합성 A=(I,I), B=(I,H), C=(F,I)의 기회별 독립 성공과 모두 독립 성공한 참여자 비율을 구하라. 별도 C의 V만 오류 E인 표에서는 E를 유효 기회에서 제외하고 두 분모를 공개하라. 실제 UI·참여자 실험은 미수행이다.

힌트 1

① 카드 이름뿐 아니라 q/i/S를 함께 적는다. ② 질문의 필요 열을 같은 후보 행에서 확인한다.

힌트 2

③ 기회 여섯 건과 사람 세 명을 분리하고 별도 오류 표를 첫 표와 섞지 않는다.

풀이와 답 확인

  1. ① 마지막 화면은 C, q는 선형, i는 1, S는 {1,2}다. 화면 이동은 네 번, 전체 상태 변경은 여섯 번이며 마지막 저장은 내용 변화가 없다.

  2. ② P에 I를 추가하면 3단위로 J와 Z를 준비한다. Q는 C와 V에 총 6단위가 필요하다. 양쪽 D가 없어 W는 미지원이다.

  3. ③ 첫 표의 독립 기회 성공은 4/6=2/3, 두 과업 모두 독립 완료한 참여자는 A 한 명으로 1/3이다. 별도 오류 표는 독립 성공 세 건·전체 시도 여섯 건·유효 기회 다섯 건이다.

  4. ③ 오류 표의 전체 시도 기준 독립 성공은 3/6=50%, 유효 기회 기준은 3/5=60%다. 오류 한 건의 제외 사유를 명시하며 실제 사이트 성과로 발표하지 않는다.

마지막 S는 {1,2}이며 화면 이동은 네 번, 전체 상태 변경은 여섯 번이다. J와 Z의 최소 추가 비용은 P의 3단위이고 W는 미지원이다. 첫 표의 기회 독립 성공은 2/3, 모든 과업 독립 완료한 참여자 비율은 1/3이다. 별도 오류 표는 전체 시도 기준 50%, 유효 기회 기준 60%이며 도구 오류 한 건을 따로 공개한다.

해결한 뒤 점검할 것

  • 화면 이동·자료 상태 변경·반복 행동의 수를 각각 보고한다.

  • 동일 후보의 질문별 지원과 가상 추가 비용을 비교한다.

  • 기회·참여자·오류 제외의 분모를 명시한다.

  • 가상 상태·비율·준비를 실제 UI 성능·사용자 효과로 확대하지 않는다.
