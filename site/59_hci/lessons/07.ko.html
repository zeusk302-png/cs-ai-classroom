소단원 7.1

분류·label·navigation

같은 강의가 영상과 글로 있어도 학습자는 두 메뉴를 오가야 할까?

준비 개념과 학습 목표

준비 개념

  • 집합과 관계

  • 경로와 이름

  • IA는 자료의 조직·관계·명칭을 정하는 정보구조, UI는 사용자가 보고 조작하는 화면이다.

학습 목표

  • 콘텐츠 분류와 화면 탐색 장치를 구별한다.

  • 대상 학습자의 말로 label 과 연결을 설계한다.

자료의 부모가 둘이면 breadcrumbs는 어느 경로를 말하는가?

앞 본문은 고유 콘텐츠 ID 하나를 여러 탐색 링크가 참조할 수 있다고 설명했다. 새 종이 구조는 홈 H에서 주제 T와 형식 F로 이동하고, T에서 변수 V로, F에서 글 W로 이동한다. V와 W는 모두 같은 자료 ID A를 참조한다. 선언한 연결은 H→T→V→A와 H→F→W→A다. 두 세 단계 경로가 있으나 콘텐츠 A는 한 객체이며 본문을 두 번 복제하지 않는다.

경로가 둘이므로 A의 유일한 부모가 V라고 쓰는 것은 전체 관계를 빠뜨린다. 이 모형의 정책은 A의 기본 breadcrumbs를 H→T→V→A로 정하고 다른 형식 경로도 별도 링크로 표시하는 것이다. F와 W를 거쳐 왔어도 기본 breadcrumbs는 선언한 주제 계층을 보여 준다. 이것은 방금 방문한 이동 이력과 다르다. 방문 이력이 필요하면 실제 들어온 경로를 따로 기록해야 한다.

직접 링크로 A에 들어온 사람에게 이전 세 단계를 수행했다고 안내하지 않는다. 계층의 기본 경로, 자료의 속성, 사용자 이동 이력과 선수 학습 관계를 다른 정보로 다룬다. 최단 경로의 간선 수가 같아도 이름의 이해와 링크 발견이 같다는 결론은 없다. 실제 화면·사용자 경로는 실행하거나 수집하지 않은 자체 관계 모형이다.

먼저 확인할 개념
  • 여러 링크와 하나의 고유 ID

    앞 본문의 대상 ID와 링크 수 구별을 부모가 둘인 탐색 관계로 확장한다.

  • 구조와 화면의 별도 조사

    이름과 관계 검사만으로 실제 링크 발견이나 목표 완료를 보장하지 않는다.

정보구조는 콘텐츠 사이의 관계다

정보구조는 무엇을 제공하고 어떻게 묶고 이름 붙일지 정하는 바탕이다. navigation 은 그 관계를 사용자가 따라갈 메뉴·링크·필터 같은 화면 장치다. 보기 좋은 메뉴를 먼저 그려도 내용의 위치가 모호하면 필요한 강의를 찾기 어렵다.

우리 콘텐츠 목록은 변수 글 A, 변수 영상 B, 반복문 글 C, 반복문 영상 D 다. 형식 기준과 주제 기준은 각각 가능한 분류 축이다. 어느 축이 목표에 맞는지는 실제 학습자의 과제와 용어를 확인해야 하며 종이 설계만으로 편리함을 입증하지 않는다.

label 은 다음 내용의 약속이다

label 은 메뉴에 붙이는 이름이다. 재미있는 이름이라도 무엇을 담는지 예측할 수 있어야 한다. 학습자가 변수를 찾는데 메뉴가 보물상자·성장의 숲으로만 되어 있으면 설명이나 보조 이름을 검토한다. 한 용어를 서로 다른 의미로 쓰는지도 확인한다.

한 콘텐츠는 고유 ID 로 관리하며 주제와 형식 같은 여러 속성을 가질 수 있다. 여러 탐색 경로가 같은 ID 를 가리키는 것은 본문을 복제하는 것과 다르다. 제목이 같다는 이유만으로 두 자료를 하나라고 판단하지 않고 내용·버전·대상 관계를 기록한다.

현재 위치와 다음 길을 보여 준다

전체 메뉴는 큰 영역, 지역 메뉴는 현재 영역의 하위 내용, breadcrumbs 는 현재 페이지가 놓인 경로를 보여 줄 수 있다. 선수 개념과 관련 자료 링크는 다른 관계를 드러낸다. 모든 관계를 한 계층에 억지로 넣을 필요는 없다.

우리 주제 우선 경로는 홈→프로그래밍→변수→자료다. 직접 링크로 들어온 학습자도 변수 주제와 다른 형식의 자료를 볼 수 있게 설계한다. 경로 깊이만 최소화하려고 모든 항목을 한 메뉴에 넣으면 선택 항목 수가 커지므로 과제별 확인이 필요하다.

두 링크가 같은 내용을 참조

H/T/F/V/W/A는 고유 노드 이름이다. 탐색 링크의 방향과 클릭 수를 세며 자료 ID 수와 복제 본문 수는 따로 센다.

중간 과정을 따라가는 예제

A/B/C/D 네 자료를 형식 우선과 주제 우선으로 묶고 변수 공부에서 글과 영상에 접근할 경로를 적어라.

  1. 형식 우선은 글={A,C}, 영상={B,D}다.

  2. 주제 우선은 변수={A,B}, 반복문={C,D}다.

  3. 변수 페이지가 A/B 의 두 형식 링크를 제공하면 주제를 정한 뒤 형식을 고를 수 있다. 각각은 동일한 고유 ID 를 참조한다.

분류 축이 달라질 뿐 네 콘텐츠는 모두 보존한다. 주제 경로가 실제 더 쉬운지는 사용자 과제로 확인해야 한다.

조건을 바꾸어 비교하기

두 경로와 한 본문

H→T→V→A, H→F→W→A에 포함된 서로 다른 노드 수·간선 수·A 대상 수를 구하라.

  1. 서로 다른 노드는 H,T,V,F,W,A의 여섯 개다. 간선은 두 경로에 각각 세 개이며 서로 겹치는 간선이 없어 총 여섯 개다.

  2. A로 들어오는 간선은 V→A와 W→A 두 개지만 콘텐츠 A는 한 객체다.

노드 여섯 개·간선 여섯 개·A로 향하는 링크 두 개·대상 A 한 개다.

비교할 점

도착 노드의 공유는 본문 복제가 아니다.

방문 이력과 기본 계층

사용자가 H→F→W→A를 따라 왔지만 기본 breadcrumbs는 H→T→V→A다. 무엇이 서로 다른가?

  1. 실제 이동 이력은 형식 경로다. 기본 표시는 선언한 주제 계층이다.

  2. 두 정보는 다른 계약이므로 기본 계층을 방금 이동한 경로라고 부르면 잘못이다.

기본 계층과 방문 이력을 구별해 이름 붙이며 실제 이동을 추정하지 않는다.

비교할 점

정확한 계층 표기가 곧 방문 기록은 아니다.

변수 글 A 에 주제·형식 두 탐색 링크를 만들면 콘텐츠 ID 는 몇 개일까? breadcrumbs 홈→프로그래밍→변수의 관계는 무엇일까?

힌트 보기

링크 수와 대상 자료 수를 따로 센다.

풀이 보기

A 의 ID 는 1 개, A 로 향하는 링크는 2 개다. breadcrumbs 는 선언한 계층 경로이며 선수 과목 순서나 개인 학습 이력을 자동 표시하지 않는다.

오해와 반례

navigation 메뉴 디자인만 바꾸면 정보구조의 모든 문제가 해결된다.

눈에 안 띄는 링크는 UI 문제일 수 있지만, 변수 자료가 어느 범주인지 이해할 수 없는 이름과 분류 문제도 있다. 원인을 구별하여 검토한다.

연습 1 · 값과 상태 예측

W→A 링크를 제거하되 A 본문과 주제 경로는 유지한다. 남는 간선 수와 A의 대상 수는?

힌트 1

제거한 것은 한 링크다.

힌트 2

다른 경로의 동일 ID를 남긴다.

풀이와 답 확인

  1. 총 여섯 간선에서 하나가 빠져 다섯 개다.

  2. A는 주제 경로로 계속 연결되며 대상 한 개로 유지된다.

간선은 다섯 개이고 A는 한 객체로 남는다.

흔한 오답에서 다시 생각하기

링크를 지웠으므로 A 본문도 삭제됐다.

링크 제거와 대상 콘텐츠 삭제는 별도 사건이다.

연습 2 · 오류 찾아 고치기

직접 URL로 A에 들어온 사람에게 “당신은 H,T,V를 방문했습니다”라고 기본 breadcrumbs를 근거로 표시했다. 고쳐라.

힌트 1

직접 유입에는 이전 경로 정보가 없다.

힌트 2

선언한 관계와 실제 관찰을 구별한다.

풀이와 답 확인

  1. 문구를 A의 기본 주제 위치 안내로 고친다.

  2. 실제 이전 방문은 미확인으로 두고 방문 이력 기능에 별도 근거를 요구한다.

위치 관계를 방문 사실로 바꾸지 않는다.

흔한 오답에서 다시 생각하기

breadcrumbs가 있으니 이전 클릭도 자동으로 알려진다.

표시된 계층은 이용자가 실행한 사건 목록이 아니다.

연습 3 · 직접 만들어 보기

A의 제목은 변수 시작이며 새 자료 B의 제목도 변수 시작이다. B는 별도 ID와 다른 대상 수준을 가진다. 두 링크의 이름과 대상 정보를 계획하라.

힌트 1

제목 같음만으로 ID를 합치지 않는다.

힌트 2

대상 수준과 형식 같은 필요한 설명을 제공한다.

풀이와 답 확인

  1. A와 B의 ID를 각각 보존하고 대상 수준·형식·판본 중 실제 구별 조건을 함께 기록한다.

  2. 링크 표시는 제목과 구별 설명을 포함하도록 계획하며 실제 이해 가능성은 후속 과제로 확인한다.

서로 다른 ID와 구별 설명을 보존하고 같은 제목을 동일 자료로 처리하지 않는다.

흔한 오답에서 다시 생각하기

제목이 같으므로 B를 A로 바꿔도 정보 손실이 없다.

별도 ID이며 대상 수준이 다르다는 조건을 지워 버린다.

연습 4 · 선택 심화

선택 심화는 기본 연습 뒤 더 탐구하고 싶을 때 풀어 보세요.

모든 자료를 홈의 한 메뉴에 넣으면 경로는 한 단계다. 두 경로의 세 단계보다 실제 탐색이 항상 빠르다고 할 수 있는가?

힌트 1

선택 수와 용어 이해가 제공되지 않았다.

힌트 2

간선 수와 실제 시간은 다른 관찰이다.

풀이와 답 확인

  1. 단계 수는 줄지만 한 화면의 선택 수·이름·시각 발견 조건이 달라진다.

  2. 같은 목표·대상 사용자로 구조 조사와 화면 과제를 계획하며 실제 속도 우열은 미확인으로 남긴다.

깊이만으로 실제 시간의 우열을 인증할 수 없다.

흔한 오답에서 다시 생각하기

한 번 클릭이 세 번보다 언제나 빠르다.

각 선택의 비용과 목표 발견 시간이 주어지지 않았다.

한 단계 더

전체 메뉴 항목 수를 줄이는 깊은 계층과 선택 수가 많은 얕은 계층의 경로를 각각 그려라. 목표 과제를 정하고 실제 tree test 와 UI 관찰을 계획하되 수행 결과로 표시하지 않는다.

출처와 확인 범위
  • NN/g 원저자 IA 와 Navigation

    실제 본문에서 콘텐츠 목록/관계/명칭이라는 정보구조와 이를 드러내는 메뉴·breadcrumbs·필터·관련링크 등 UI 탐색의 구별을 읽었다.

준비 개념과 학습 목표

준비 개념

  • 비율

검색 슬롯·고유 ID·첫 결과의 성공은 같은 분모인가?

앞 본문의 관련 정답 집합 A,C,E를 유지하되 새 검색 목록의 순서는 F,A,A,E다. F는 무관하고 A가 두 슬롯에 중복된다. 고유 ID 집합으로 평가하면 반환은 F,A,E 세 개이고 관련은 A,E 두 개다. 따라서 고유 ID 정밀도는 2/3, 재현율은 2/3이다. 슬롯 기준으로 관련 출현을 세면 3/4지만 이는 다른 단위의 지표이며 고유 ID 정밀도로 보고하면 안 된다.

순서의 첫 두 슬롯에서 관련 비율은 1/2다. 같은 슬롯들을 A,E,F,A로 재배열하면 첫 두 슬롯은 모두 관련이라 2/2가 되지만 고유 ID 집합과 두 집합 비율은 변하지 않는다. 중복 제거 뒤의 순위도 따로 선언한다. 관련 결과가 있다는 사실과 사용자가 그 결과를 발견하고 과제를 완료하는 사실도 다르다.

별도 가상 tree 기록 여덟 건은 직접 성공 네 건, 간접 성공 두 건, 실패 두 건이다. 첫 선택이 맞은 다섯 건은 직접 성공 네 건과 이후 실패한 한 건으로 구성한다. 나머지 세 건은 첫 선택이 틀렸으며 그중 두 건은 돌아가 성공하고 한 건은 실패했다. 전체 성공은 6/8, 직접 성공은 4/8, 첫 선택 정답은 5/8이다. 실제 참가자를 조사하지 않은 합성 장부다.

먼저 확인할 개념
  • 정밀도·재현율의 단위와 분모

    앞 본문의 집합 지표에 중복 슬롯과 순서 조건을 추가한다.

  • 탐색 경로와 고유 대상

    같은 ID에 도달하는 여러 경로와 중복 결과의 대상 수를 구별한다.

찾는 목표가 있거나 아직 없거나

findability 는 있다고 예상하는 자료를 찾는 성질이고 discoverability 는 몰랐던 자료나 기능을 접하는 성질이다. 검색어를 아는 학습자는 검색을 쓰고 아직 용어를 모르는 학습자는 주제 소개·예제·관련 링크로 새 길을 발견할 수 있다.

검색과 메뉴는 서로 보완할 수 있다. 검색 결과가 있더라도 제목과 요약이 모호하면 어느 자료를 눌러야 할지 모른다. 우리 자체 예시는 반복문이라는 정해진 과제와 관련 자료 둘러보기라는 별도 과제를 나누며 실제 행동 자료는 수집하지 않았다.

검색 결과의 포함과 누락을 센다

자체 결과 집합의 정밀도는 반환한 항목 중 관련 항목의 비율, 재현율은 실제 관련 항목 중 반환한 비율로 정의한다. 관련성 정답 집합과 집계 단위를 미리 정한다. 반환 0 이나 관련 0 이면 분모 0 의 처리 정책도 별도로 필요하다.

이 비율은 결과 목록의 포함 여부를 본다. 첫 결과가 틀렸는지, 원하는 형식인지, 학습자가 이해했는지는 자동 평가하지 않는다. 검색 질의의 동의어·철자·필터·결과 요약과 순위는 별도의 설계 판단이며 모든 질의에 같은 정답이 있는 것도 아니다.

구조와 화면을 나누어 조사한다

tree test 는 꾸민 화면 없이 범주 이름과 구조를 따라 목표에 도달하는지 볼 수 있다. 성공했어도 되돌아갔는지에 따라 직접 성공과 간접 성공을 구별한다. UI 과제 관찰은 메뉴가 보이는지와 실제 조작도 확인한다.

좋은 구조 결과만으로 화면 성공을 보장하거나 검색 사용률 하나로 구조 실패를 확정하지 않는다. 검색을 선호할 수도 있기 때문이다. 과제·경로·첫 선택·오류·완료를 함께 기록하고 가상 표의 퍼센트를 실제 학생 성공률이라고 바꾸지 않는다.

  • open/closed 카드소팅을 구별한다.

  • 공동 묶임 빈도와 이유 및 후속 검증의 한계를 설명한다.

모르는 카드가 있으면 모든 쌍의 분모를 같게 두어도 되는가?

앞 본문의 네 가상 분할 P1={AB},{C},{D}, P2={AB},{CD}, P3={ABC},{D}, P4={A},{BC},{D}를 그대로 둔다. 새 P5는 {AC},{D}로 묶었으나 B를 이해하지 못해 미배치로 남겼다. 이 보강의 쌍별 정책은 두 카드를 모두 이해하여 배치한 기록만 해당 쌍의 유효 분모에 넣는다. 따라서 B를 포함한 AB/BC/BD의 분모는 네 개이고 다른 쌍의 분모는 다섯 개다.

AB의 공동 묶임은 P1/P2/P3의 세 번으로 3/4=75%다. AC는 P3/P5의 두 번으로 2/5=40%이며 BC는 P3/P4의 두 번으로 2/4=50%다. CD는 P2 한 번으로 1/5=20%다. B 미배치를 다른 모든 카드와 별도 그룹으로 읽어 AB/BC를 3/5와 2/5로 낮추면 모름을 분리 선호로 바꾸는 다른 정책이다.

자체 기준 50% 이상으로 연결하면 AB와 BC는 연결되지만 AC는 연결되지 않는다. 연결의 추이 폐쇄로 ABC를 하나의 메뉴에 합치면 모든 쌍이 50% 이상이라는 주장은 거짓이다. 합친 후보를 만들 수는 있어도 원래 쌍별 자료와 그 이유를 보존하고 후속 경로 과제로 확인해야 한다. 다섯 합성 기록에서 실제 모집단 선호나 메뉴 탐색 성공을 주장하지 않는다.

먼저 확인할 개념
  • 공동 묶임 빈도와 모르는 카드

    앞 본문의 미배치와 쌍별 유효 분모를 새 다섯 번째 기록으로 명시한다.

  • 구조 근거와 경로 완료 구별

    카드 묶임 결과를 실제 메뉴 탐색 성공으로 확대하지 않는다.

무엇을 어떻게 묶는지 묻는다

카드소팅은 콘텐츠 이름이나 설명을 카드로 주고 참여자가 묶는 방식과 이유를 알아보는 방법이다. open 방식은 참여자가 묶음과 이름을 만들고 closed 방식은 준비된 범주에 배치한다. 어떤 방식인지 먼저 선언해야 해석이 맞는다.

카드는 내용이 이해될 만큼 분명하되 원하는 범주를 답처럼 숨겨 넣지 않는다. 모르는 항목은 억지로 아무 곳에 넣기보다 따로 두고 이유를 묻는다. 카드 묶음은 메뉴를 클릭하여 자료에 도달한 행동과 다르다.

쌍별 빈도를 직접 센다

우리 계산에서는 네 장 A 변수/B 함수/C 배열/D 프로세스를 사용한다. 각 가상 참여자가 각 카드를 한 그룹에 정확히 한 번 배치했다고 가정한다. 쌍이 같은 그룹에 놓인 횟수/유효 참여자 4 로 유사도를 정의한다.

그룹 이름이 달라도 같은 카드쌍의 공동 묶임을 셀 수 있다. 반대로 같은 이름을 썼다고 구성 카드가 같다는 뜻은 아니다. 쌍별 높은 빈도가 항상 추이적인 큰 그룹을 만드는 것은 아니므로 임의 기준선으로 모든 연결을 합치기 전에 원 자료를 본다.

빈도와 설명을 함께 읽는다

가상 표의 숫자는 의견 분포를 드러내지만 왜 그렇게 묶었는지는 말해 주지 않는다. 단어를 모른 경우, 특정 활동 기준인 경우, 두 범주에 속한다고 생각한 경우를 이유 질문으로 구별할 수 있다. 참여자가 붙인 이름이 최종 메뉴 이름으로 적합한지도 별도 검토한다.

몇 명의 종이 예로 전 세계 학습자의 선호를 확정하지 않는다. 대상 언어와 준비개념을 고려한 실제 조사 및 이후 tree test·사용자 과제를 계획한다. 이 단원에는 실제 참여자도 동의 절차도 수행 결과도 없으며 가상 계산만 있다.

중간 과정을 따라가는 예제

P1={AB},{C},{D}; P2={AB},{CD}; P3={ABC},{D}; P4={A},{BC},{D}다. AB/AC/BC/CD 공동 묶임 비율을 구하라.

  1. AB 는 P1/P2/P3 으로 3/4=75%다.

  2. AC 는 P3 만으로 1/4=25%다. BC 는 P3/P4 로 2/4=50%다.

  3. CD 는 P2 만으로 1/4=25%다. 같은 그룹 표기를 쌍별로 전부 풀어 세었다.

AB75%, AC25%, BC50%, CD25%다. 50%이상 연결이라는 자체 규칙에서는 AB 와 BC 가 연결돼도 AC 는 기준 미만이다.

  1. AB와 BC는 P5를 분모에서 제외해 각각 3/4,2/4다.

  2. AC와 CD는 P5도 유효하며 각각 2/5,1/5다.

AB 75%, AC 40%, BC 50%, CD 20%다.

  1. AB와 BC만 기준을 통과한다. AC는 40%로 탈락한다.

  2. 두 간선의 연결 성분이 ABC라는 사실은 AC가 기준을 통과한다는 뜻이 아니다.

ABC는 연결되지만 모든 쌍이 50% 이상인 그룹은 아니다.

  2. ② 고유 반환은 F,A,E 세 개이고 관련은 A,E 둘이므로 정밀도와 재현율은 각각 2/3이다. 첫 두 슬롯 관련 비율은 1/2다. 전체 경로 성공은 6/8=75%, 직접 성공은 4/8=50%, 첫 선택 정답은 5/8=62.5%다.

  3. ③ AB는 3/4=75%, AC는 2/5=40%, BC는 2/4=50%, CD는 1/5=20%다. AB와 BC의 연결만으로 AC가 기준을 통과한다고 말할 수 없다. 원 자료와 제외 사유를 남기고 실제 메뉴 탐색은 별도 계획한다.

A는 한 객체이고 부모는 둘이며 기본 계층은 방문 이력이 아니다. 검색의 두 고유 ID 비율은 각각 2/3, 첫 두 슬롯 비율은 1/2다. 가상 경로 전체 성공은 75%, 직접 성공은 50%, 첫 선택 정답은 62.5%다. 카드쌍 비율은 AB 75%, AC 40%, BC 50%, CD 20%이고 ABC가 모든 쌍의 50% 기준을 만족하지 않는다. 실제 사용자 성공은 미측정이다.

F,A,A,E의 고유 반환은 세 개이고 관련 ID는 두 개이므로 고유 ID 정밀도와 재현율은 각각 2/3이다. 관련 슬롯 비율은 3/4이며 첫 두 슬롯 관련 비율은 1/2다. 재배열 A,E,F,A에서는 첫 두 슬롯 관련 비율만 100%가 되고 집합 비율은 같다. 여덟 가상 경로의 전체 성공은 75%, 직접 성공은 50%, 첫 선택 정답은 62.5%다. 실패 한 건을 간접 성공으로 변경하면 전체 성공만 87.5%로 바뀐다. 두 질의 정밀도의 단순 평균은 65%이고 반환 합계 기준 비율은 4/11이다. P5의 B 모름에서 쌍별 비율은 AB 75%, AC 40%, BC 50%, CD 20%다. P5가 ABC로 완성된 별도 자료는 AB 80%, AC 40%, BC 60%다.
