소단원 12.1

연구→설계 추적

버튼을 크게 만든 이유를 누구의 어떤 어려움과 연결할 수 있을까?

준비 개념과 학습 목표

준비 개념

  • 관찰은 실제로 보거나 들은 사실이다.

  • 가설은 아직 확인할 설명이다.

학습 목표

  • 관찰·해석·설계 결정을 연결한다.

  • 결정의 근거와 미확인 가정을 구별한다.

관찰 번호가 남아 있지만 그 관찰을 더는 사용할 수 없다면?

앞 본문의 관찰과 결정 사슬에 유효 상태를 추가한다. 자체 종이 장부의 결정은 D1부터 D5까지 다섯 개다. D1은 O1, D2는 O1과 O2, D3는 O3, D4는 가설 H1, D5는 O2에 연결한다. O1과 O2는 현재 사용 가능한 가상 관찰이고 O3는 잘못 옮긴 기록이라 무효 표시했다. H1은 관찰이 아니라 아직 확인할 가설이다.

여기서 관리 지표는 현재 사용 가능한 관찰에 하나 이상 연결된 결정 수를 전체 결정 수로 나눈다. D2의 링크가 둘이어도 결정 하나로 센다. 번호가 존재하거나 가설에 닿는 것만으로 분자에 넣지 않는다. 별도 링크 관리 비율은 현재 사용 가능한 관찰 링크 수를 모든 관찰 링크 수로 나눈다. 두 비율의 분모가 다르다.

같은 행동 O1이 안내 이해의 어려움인지 발견의 어려움인지 아직 결정되지 않았다. 무효 기록을 빼도 남은 연결의 해석과 효과가 자동 입증되지는 않는다. 실제 자료 사용 범위가 바뀌거나 철회되는 상황에서는 관련 원자료와 결과의 취급 절차를 별도로 확인해야 한다. 아래에서는 사람 자료 없이 링크 유효 상태만 바꾸는 자체 모형을 연습한다.

먼저 확인할 개념
  • 관찰과 해석의 사슬

    행동·가설·결정과 분모를 구별한 기본 설명에 유효 상태를 추가한다.

  • 사용 범위와 보고

    자료 번호 존재와 실제 사용 허용 범위가 다름을 유지한다.

관찰과 해석을 다른 칸에 쓴다

가상의 수업 선택 화면에서 한 사람이 작은 화살표를 세 번 눌렀다가 돌아갔다고 하자. 이것은 행동 기록이다. “버튼이 작아 못 찾았다”는 설명은 가능한 해석이며 화면 안내가 모호했거나 목표를 바꿨을 가능성도 있다. 행동과 원인 해석을 같은 문장으로 확정하지 않는다.

여기서는 O1처럼 관찰 번호를 붙이고 과제·화면 버전·입력 방법·도움 제공 여부를 함께 쓴다. 실제 연구를 하지 않은 종이 사례에는 가상이라는 표시를 한다. 참여자 번호는 연결용이며 이름이나 얼굴을 공개해도 된다는 허가가 아니다.

설계 결정까지 연결되는 사슬

관찰 O1→해석 I1→해결 후보 D1→확인 계획 T1을 종이에 연결한다. I1을 “다음 화면으로 가는 동작을 찾기 어렵다”, D1을 “다음 수업이라는 글자 버튼을 둔다”로 쓰면 의도와 확인할 목표가 보인다. 화면의 미적인 선호만으로 이 사슬이 완성되지는 않는다.

관찰 하나가 여러 해석을 낳고 결정 하나가 여러 관찰에 대응할 수 있다. 그래서 연결은 반드시 일대일이 아니다. 후보에는 반대 근거와 다른 해결안도 적는다. 글자를 늘리면 좁은 화면에서 줄바꿈이 생길 수 있다는 제약까지 적어야 결정의 비용을 설명할 수 있다.

추적 가능성과 증거 강도는 다르다

모든 결정에 관찰 링크를 붙였다고 효과가 검증된 것은 아니다. 연결 여부는 근거가 어디서 왔는지 찾게 해 주는 구조적 성질이다. 원인 해석의 타당성이나 실제 개선 효과는 별도 조사와 평가가 필요하다.

이 수업의 자체 관리 비율은 근거 링크가 있는 결정 수/전체 결정 수다. 이 비율을 연구 신뢰도나 사용자 만족도라고 부르지 않는다. 미연결 결정은 실험적 아이디어일 수도 있어 삭제보다 어떤 가정과 다음 검증이 필요한지 먼저 기록한다.

관찰 번호가 남아 있지만 그 관찰을 더는 사용할 수 없다면?
자체 장부 조건연결 또는 결과해석할 범위

D1

O1에 연결

현재 사용 가능한 관찰이 있음

D2

O1과 O2에 연결

결정은 한 개, 관찰 링크는 두 개

D3

무효 O3에 연결

현재 유효 결정 분자에서 제외

D4와 D5

D4는 H1, D5는 O2

가설과 관찰을 서로 바꾸어 세지 않음

결정마다 사용 가능한 관찰이 하나라도 있는지 먼저 판정한다. 다음에는 별도 링크 장부를 센다. 이 계산은 가상 추적 관리 지표이며 사용자 만족도나 설계 효과의 비율이 아니다.

중간 과정을 따라가는 예제

가상 결정 D1·D2·D3·D4 중 D1은 O1, D2는 O1과 O2, D3는 O3에 연결되고 D4는 아직 근거가 없다. 연결 비율과 효과가 검증된 결정 수를 구별하자.

  1. 연결된 결정은 D1,D2,D3로 3개다. D2에 링크가 두 개 있어도 결정 두 개로 세지 않는다.

  2. 전체 결정 4개이므로 연결 비율은 3/4=75%다.

  3. 실제 효과 검증 기록은 주어지지 않았다. 연결된 세 개를 검증 완료 세 개로 바꿔 적을 수 없다.

추적 비율은 75%다. 효과 검증은 미확인이다. D4의 근거 또는 가설과 다음 평가 계획을 추가한다.

조건을 바꾸어 비교하기

결정 비율과 링크 비율의 서로 다른 분모

초기 장부의 두 관리 비율을 구하라.

  1. 유효 관찰에 연결된 결정은 D1, D2, D5의 세 개다. 결정 비율은 3/5 = 60%다.

  2. 관찰 링크는 D1의 하나, D2의 둘, D3의 하나, D5의 하나로 다섯 개다. 그중 O3 링크를 제외한 네 개가 유효하여 링크 비율은 4/5 = 80%다.

결정 관리 비율은 60%, 관찰 링크 관리 비율은 80%다. 가설 H1은 관찰 링크 분모에 넣지 않는다.

비교할 점

같은 장부라도 관리 대상이 결정인지 링크인지에 따라 요약이 다르다.

한 관찰의 무효화가 여러 결정을 바꾸는 경우

초기 장부에서 O1만 추가로 무효 표시한다. O2는 계속 사용 가능하다. 결정 비율은?

  1. D1에는 유효 관찰이 남지 않는다. D2는 O2 링크가 남아 유효 결정을 유지한다.

  2. D5도 O2가 남는다. D3와 D4는 계속 분자 밖이므로 유효 결정은 두 개다.

유효 결정 비율은 2/5 = 40%다. O1 링크 두 개를 지웠다고 결정 두 개가 모두 무효가 되는 것은 아니다.

비교할 점

연결의 개수와 각 결정에 남는 대체 근거를 함께 확인한다.

종이와 본문으로 직접 해보기

D4를 가설 H1에만 연결하면 관찰 근거 비율은? 새 D5를 O2에 연결해 추가하면 관찰 링크가 있는 결정 비율은?

힌트 보기

가설 링크와 관찰 링크를 구별하고 결정 개수로 센다.

풀이 보기

H1만 추가한 상태는 여전히 3/4=75%다. D5 추가 후 관찰 링크 결정은 4개/전체 5개로 80%다. H1의 번호 존재는 실제 관찰로 변환되지 않는다.

오해와 반례

근거 번호가 붙은 화면 수정은 사용자가 좋아한다고 입증됐다.

번호는 출처를 찾게 해 준다. 가상 O1의 해석이 틀릴 수도 있고 D1이 다른 어려움을 만들 수도 있다. 사슬과 효과 검증을 따로 기록한다.

연습 1 · 값과 상태 예측

초기 장부에서 O2만 무효가 되고 O1은 유효하다. 남는 유효 결정과 두 관리 비율을 구하라.

힌트 1

D2는 O1 링크도 갖는다.

힌트 2

결정 다섯 개와 관찰 링크 다섯 개는 각자의 분모다.

풀이와 답 확인

  1. D1과 D2가 유효하여 결정 비율은 2/5 = 40%다.

  2. O1 링크 두 개만 유효하므로 링크 비율도 2/5 = 40%다.

D1과 D2가 남으며 두 비율은 이번에는 모두 40%다. 같은 분모 숫자는 두 지표의 정의가 같다는 뜻이 아니다.

흔한 오답에서 다시 생각하기

O2 링크가 둘이니 결정 비율은 처음 60%에서 40퍼센트포인트 줄어 20%다.

D2에는 O1이 남는다. 결정을 링크 개수만큼 차감했다.

연습 2 · 오류 찾아 고치기

보고 초안은 D3에 O3 번호가 있으므로 효과가 입증됐다고 썼다. 장부와 문장을 고쳐라.

힌트 1

O3의 현재 상태를 확인한다.

힌트 2

유효 관찰 연결과 효과 평가도 다른 단계다.

풀이와 답 확인

  1. D3의 O3 링크는 무효 상태로 표시하고 유효 결정 분자에서 제외한다.

  2. D3의 해석 가설과 다음 확인 계획을 별도로 적는다. 실제 개선 검증 기록은 주어지지 않았다.

번호만으로 유효성이나 효과 입증을 주장하지 않는다. 연결을 감사 가능하게 남기되 무효 기록을 근거로 재사용하지 않는다.

흔한 오답에서 다시 생각하기

가설 H1로 번호를 바꾸면 관찰 효과 입증이 복구된다.

가설의 이름을 바꾸어도 관찰이나 평가를 실제 수행한 것은 아니다.

연습 3 · 직접 만들어 보기

O1과 O2가 모두 유효한 초기 장부에 새 결정 D6을 O2에 연결한다. 새 비율을 구하고 추적 장부의 열을 설계하라.

힌트 1

유효 결정과 전체 결정이 각각 하나 늘어난다.

힌트 2

버전·상태·관찰/가설 종류를 남긴다.

풀이와 답 확인

  1. 유효 결정은 네 개, 전체 결정은 여섯 개로 4/6 = 약 66.67%다.

  2. 결정 ID, 화면 버전, 근거 종류/ID, 유효 상태, 대안 해석, 다음 확인 계획을 별도 열로 둔다.

새 결정 비율은 약 66.67%다. 표의 완성은 효과 검증 완료가 아니다.

흔한 오답에서 다시 생각하기

링크를 한 개 추가했으니 결정 비율도 정확히 20퍼센트포인트 늘어난다.

분자와 분모가 함께 변하여 단순 가산할 수 없다.

연습 4 · 선택 심화

선택 심화는 기본 연습 뒤 더 탐구하고 싶을 때 풀어 보세요.

초기 장부의 D2에 O2 링크를 실수로 한 번 더 복제했다. 결정 비율과 중복을 제거한 링크 비율은 어떻게 되는가?

힌트 1

같은 결정·관찰 쌍을 고유 링크로 센다.

힌트 2

새 관찰이 생긴 것은 아니다.

풀이와 답 확인

  1. D2는 여전히 결정 하나다. 유효 결정은 세 개라 60%를 유지한다.

  2. 복제된 같은 쌍을 제거하면 관찰 링크는 원래 다섯 개이고 유효 네 개라 80%다.

두 관리 지표는 60%와 80%를 유지한다. 중복 행을 새 독립 증거로 세지 않는다.

흔한 오답에서 다시 생각하기

복제 링크가 생겼으니 연구 신뢰도가 높아졌다.

복사는 독립적인 관찰이나 효과 평가를 추가하지 않는다.

소단원 12.2

전후 비교와 iteration

성공률이 올랐다는 숫자만 있으면 화면 수정 덕분이라고 말할 수 있을까?

준비 개념과 학습 목표

준비 개념

  • 성공률은 성공 수/시도 수다.

  • 버전은 비교하는 화면 상태를 식별한다.

학습 목표

  • 비교 조건과 실패 기록을 맞춘다.

  • 수치 차이와 인과적 개선을 구별해 반복 계획을 세운다.

완료한 사람만 남기면 전후 성공률은 어떻게 달라질까요?

별도 가상 반복 장부에서 화면 A의 전체 대상은 10회다. 도움 없는 성공 여섯 회, 도움을 받아 끝낸 두 회, 중단 두 회가 있다. 화면 B도 대상 10회이며 도움 없는 성공 일곱 회, 도움을 받아 끝낸 한 회, 중단 두 회가 있다. 이 자체 지표의 성공 조건은 도움 없이 끝내는 것이다. 중단은 이 사전 조건을 만족한 성공에 넣지 않고 전체 대상 분모에 남긴다.

A의 성공 시간은 여섯 회 모두 40초, B의 성공 시간은 일곱 회 모두 50초라고 제공한다. 성공자 평균은 실제로 관찰한 성공 집합을 대상으로 한다. 중단 시간을 0초로 채우거나 성공하지 않은 회차를 시간 평균의 분모에 섞지 않는다. 여기서 전체 대상 성공률과 성공자 평균은 서로 다른 결과다.

별도 판본에서 B의 두 중단은 완료 상태 자체가 미확인이라고 하자. 이때 확인 성공 일곱 회만으로 확정 전체 성공률을 70%라고 적을 수 없다. 미확인 둘을 모두 실패 또는 모두 성공으로 두어 가능한 전체 비율 범위를 적는다. 중단을 실패로 정의한 앞 장부와 상태가 알려지지 않은 별도 판본을 구별한다. 어느 표도 화면 변화의 인과 효과를 입증하지 않는다.

먼저 확인할 개념
  • 분모와 조건을 맞춘 비교

    성공자 시간과 전체 시도 성공률을 나누는 기본 설명을 확장한다.

  • 미평가 범위 표시

    확인하지 않은 회차를 성공으로 채우지 않고 보고 범위에 남긴다.

반복은 질문을 좁히는 과정

iteration은 후보를 만들고 확인 결과에 따라 수정하는 반복이다. 한 번의 화면 변경 뒤 “완성”을 선언하기보다 어떤 문제를 줄이려 했고 무엇을 관찰할지를 먼저 정한다. 예를 들어 다음 수업 선택을 도움 없이 끝내는 것을 성공으로 정의할 수 있다.

같은 화면에서도 성공 조건이 바뀌면 비율이 달라진다. 첫 회는 도움을 받아도 성공, 둘째는 혼자 끝내야 성공이면 두 비율을 같은 척도로 비교하지 않는다. 작업·안내·입력 환경·버전·도움·중단을 함께 기록한다.

분모와 시간을 함께 보여 준다

성공률과 완료 시간은 다른 결과다. 완료 시간 평균을 성공자에게만 계산하면 실패자는 빠지고, 실패가 많은 화면이 오히려 빠른 것처럼 보일 수도 있다. 실패를 임의로 0초로 넣는 것도 잘못이다. 여기서는 성공자 시간과 전체 시도 성공률을 나누어 표시한다.

전후 비율의 차이는 percentage point, 퍼센트포인트로 쓴다. 50%에서 75%는 25퍼센트포인트 증가이고 원래 비율 대비 상대 증가는 (75−50)/50=50%다. 서로 같은 수치가 아니며 원래 비율 0에서는 이 상대 증가식의 분모가 0이다.

차이가 왜 생겼는지 확인한다

같은 사람이 화면 A 뒤 B를 보면 연습 효과가 생길 수 있다. 다른 사람을 쓰면 숙련도·기기 차이가 섞일 수 있다. 따라서 작은 전후 표는 관찰된 차이를 보여 줄 수 있지만 모든 차이를 화면 수정의 인과 효과로 자동 해석하지 않는다.

반복 보고에는 성공한 변화와 새 실패를 모두 넣는다. 다음 회차는 남은 가장 중요한 질문을 확인하도록 정한다. 중립 과제와 일관된 안내는 비교에 도움이 되지만 종이 표 계산만으로 실제 실험의 조건 통제가 수행된 것은 아니다.

각 행의 자료 판본과 성공 정의를 먼저 읽는다. 도움 완료는 이 지표의 성공이 아니며 중단과 상태 미확인도 동일한 기록이 아니다. 숫자는 성공 수·대상 수·시간 대상별로 이름을 붙여 보고한다.

중간 과정을 따라가는 예제

자체 가상 표에서 A는 4회 중 2회 성공, 성공 시간 40·60초다. B는 4회 중 3회 성공, 성공 시간 30·40·50초다. 성공률·성공자 평균·비율 차이를 계산하자.

  1. A 성공률 2/4=50%, 성공자 평균 (40+60)/2=50초다.

  2. B 성공률 3/4=75%, 성공자 평균 (30+40+50)/3=40초다.

  3. 차이는 25퍼센트포인트, 상대 증가는 25/50=50%다. 성공자 평균은 10초 감소하지만 다른 사람 집합일 수 있다.

가상 표에서는 B의 성공률이 높고 성공자 평균이 짧다. 화면 효과의 인과 검증과 미래 사용자 성공 보장은 아직 없다.

조건을 바꾸어 비교하기

성공률과 완료자 시간의 서로 다른 방향

원래 두 장부의 성공률 변화와 성공자 평균 변화를 구하라.

  1. A는 6/10 = 60%, B는 7/10 = 70%로 10퍼센트포인트 증가한다. 상대 증가는 10/60 = 약 16.67%다.

  2. 성공자 평균은 A 40초에서 B 50초로 10초 늘어난다. 두 성공자 집합이 같다는 조건은 없다.

성공률은 10퍼센트포인트 증가하고 성공자 평균은 10초 길어진다. 개선을 단일 숫자로 확정하지 않는다.

비교할 점

성공률 방향을 시간 방향으로 자동 옮길 수 없다.

완료만 남긴 다른 분모

도움 완료까지 포함한 완료 여덟 회만 분모에 두면 어떤 별도 비율이 나오는가?

  1. A는 6/8 = 75%, B는 7/8 = 87.5%다.

  2. 차이는 12.5퍼센트포인트다. 전체 대상의 60%와 70%를 이 비율로 바꾸지 않는다.

완료 회차 안의 무도움 성공 비율은 A 75%, B 87.5%다. 전체 대상 성공률과 별도 지표로 표시한다.

중단 행을 없애고 같은 성공률 이름으로 보고하면 분모의 변경을 숨긴다.

사용자영향·윤리·보고

성공한 화면을 공개하면서 연구 참여자의 얼굴과 실패 장면까지 올려도 될까?

준비 개념과 학습 목표

준비 개념

  • 공개 보고와 내부 연구 기록은 공유 범위가 다르다.

  • 동의는 어떤 목적과 자료 사용에 관한 것인지 확인한다.

학습 목표

  • 연구 참여와 공개 공유의 범위를 구별한다.

  • 확인한 사용자 영향과 미검증 범위를 보고한다.

이름을 빼고도 공개 요약이 사람을 가리킬 수 있을까요?

자체 가상 공개 정책을 먼저 정한다. 내부 분석표의 다섯 행은 이름, 학급, 입력 방법, 결과를 갖는다. P1과 P2는 A학급에서 키보드를 쓰고, P3는 A학급에서 마우스를 쓴다. P4는 B학급에서 키보드를 쓰고, P5는 B학급에서 마우스를 쓴다. 여기서는 공개 집계 칸마다 기록이 최소 두 개 있어야 한다는 자체 규칙을 둔다. 이 문턱은 법률이나 익명성 보증이 아니다.

이름 열을 빼더라도 학급과 입력 방법을 함께 공개하면 세 칸이 한 행씩이다. 특히 다른 정보와 결합하면 개인을 추측할 수도 있다. 두 행 이상이라는 자체 규칙을 만족했다고 외부 정보에 대한 재식별 안전성이나 실제 자료 사용 동의가 입증되지는 않는다. 아래의 공개 허용 판정은 이 종이 규칙의 결과에 한정한다.

공개 보고의 대상도 판본과 페이지·언어·방법을 갖는다. 화면 v1의 한국어 두 페이지를 전문가가 수동 확인했다고 가정한 기록은 v2나 일본어 페이지의 결과가 아니다. 사용자 관찰·자동 검사·전문가 점검은 다른 방법이며 수행하지 않은 방법을 추가하지 않는다. 자료 공유 범위와 철회 기록은 별도 상태로 관리한다.

먼저 확인할 개념
  • 공개 범위와 자료 사용

    기본의 공개 요약·내부 기록·동의 범위 구분을 유지한다.

  • 출처의 상태와 추적

    관찰 번호가 결과를 찾아가게 하더라도 공개 허가나 효과 입증을 대신하지 않는다.

자료를 보여 줄 목적과 범위를 정한다

수업 사이트의 학습 경험을 설명하려고 참여자의 이름·얼굴·학교를 모두 공개할 필요는 없다. 숫자와 문제 유형은 자체 가상 자료로 설명할 수 있다. 실제 연구를 할 때는 어떤 자료를 수집하고 누가 보고 얼마나 보관하는지 이해 가능한 안내를 제공해야 한다.

참여자가 연구에 동의했다는 사실이 모든 녹화의 공개 재사용을 허락했다는 뜻은 아니다. 동의된 사용 범위와 철회 절차를 확인하고 연구 목적에 필요한 자료만 다룬다. 여기서는 법률 판정이나 실제 동의 취득을 수행하지 않고 공개 계획의 정보 흐름을 연습한다.

평균 뒤에 남는 사람을 살핀다

전체 성공률이 높아도 키보드만 쓰는 사람이 과제를 못 마칠 수 있다. 집단별 결과와 미평가 환경을 함께 표시하면 개선 대상이 보인다. 집단 크기 한두 명의 수치를 전체 집단 특성으로 단정하거나 개인 실패를 능력 탓으로 돌리지 않는다.

참여자를 평가하는 시험과 화면 문제를 찾는 사용성 연구는 목적이 다르다. 어려움의 원인을 듣고 서비스 조건을 점검한다. 아동 등 보호가 필요한 참여자에게 실제 연구를 계획한다면 적절한 보호·동의 절차를 갖추어야 하며, 이 종이 활동은 실제 사람 모집 없이 가능하다.

보고 범위가 결론의 범위다

보고에는 화면 버전과 날짜, 과제, 평가한 페이지·언어·입력 환경, 제외한 범위, 관찰과 권고를 넣는다. 점검한 한 페이지가 통과했다고 다른 언어의 모든 페이지가 통과한 것은 아니다. 사이트가 바뀌면 과거 보고의 적용 버전도 확인해야 한다.

자동 검사·전문가 수동 점검·사용자 관찰은 서로 다른 증거다. 실제 수행하지 않은 방법을 사용한 것처럼 적지 않는다. 공개 요약에는 문제와 개선 계획을 담고, 개인 식별 가능한 원자료는 공유 목적과 접근 범위를 별도로 검토한다.

중간 과정을 따라가는 예제

가상 평가 표에서 마우스 사용 8회는 모두 성공, 키보드 사용 2회는 모두 실패다. 공개 문서 초안은 “전체 성공 80%, 모든 입력 방법 검증 완료”라 썼고 이름·얼굴·성적·화면 버전의 네 항목을 붙였다. 계산과 주장 및 필요한 공개 항목을 점검하자.

  1. 전체 성공은 8/10=80%다. 마우스 8/8=100%, 키보드 0/2=0%다.

  2. 키보드 실패가 있어 “모든 입력 방법 검증 완료”를 성공 보장 의미로 쓸 수 없다. 관찰한 범위와 미해결 실패를 표시한다.

  3. 이 가상 요약의 목적에 이름·얼굴·성적은 필요하지 않다. 화면 버전은 결과 범위를 찾게 해 준다. 실제 자료 공개 허가는 별도이며 여기서는 수집하지 않았다.

80%라는 전체 비율을 유지하면서 집단 결과·키보드 문제·가상 평가임을 함께 보고한다. 개인 정보 세 항목 대신 버전과 평가 범위를 명시한다.

다른 문제에 적용하기

근거 상태·비교 분모·공개 범위가 다른 보고 감사

세 별도 가상 장부를 감사하라. ① 첫 소단원 초기 다섯 결정에서 O1만 추가로 무효 표시하고 O2는 유지한다. 유효 결정과 그 비율을 구하라. ② 둘째 소단원의 별도 B 미확인 판본은 전체 10회 중 성공 7회, 비성공 1회, 미확인 2회다. 전체 성공률 범위와 확인된 회차 비율을 구하라. ③ 셋째 소단원 초기 다섯 기록에서 P2 사용을 중지하고 집계에서도 제거한다. 학급별/입력별 및 교차 칸의 크기를 구하라. v1 한국어 두 페이지의 전문가 점검으로 v2 일본어 사용자 검증 완료를 주장할 수 있는지도 판정하라. 실제 연구·자료 이동·공개는 요구하지 않는다.

힌트 1

결정에 다른 유효 관찰이 남는지 확인하고 미확인 회차는 0부터 2 성공까지 바꾼다.

힌트 2

전체 대상 분모와 확인된 회차 분모, 단일 기준 표와 교차표를 구별한다.

풀이와 답 확인

  1. 유효 결정은 O2가 남는 D2와 D5다. 결정 비율은 2/5 = 40%다.

  2. B의 전체 성공은 7부터 9회까지로 범위 [70%,90%]다. 확인된 여덟 회 안의 비율은 7/8 = 87.5%다.

  3. P2 제거 뒤 A학급과 B학급의 기록은 각각 두 개다. 키보드와 마우스 기록도 각각 두 개다. 네 교차 칸은 각각 한 기록이라 자체 최소 두 기록 규칙을 만족하지 않는다.

  4. 제공 평가의 판본·언어·방법 밖인 v2 일본어 사용자 검증은 미확인이다. 집계 규칙 만족도 실제 공유 허가나 익명성 입증을 대신하지 않는다.

유효 결정은 D2와 D5이며 비율은 40%다. B의 전체 성공률 범위는 70%부터 90%, 확인된 회차 비율은 87.5%다. P2 제거 후 두 단일 기준 표는 각각 [2,2]지만 네 교차 칸은 각각 1이다. v2 일본어 사용자 검증 완료는 주어진 평가 범위로 주장할 수 없다.

해결한 뒤 점검할 것

  • 결정/링크와 관찰/가설/유효 상태를 분리한다.

  • 전체 대상과 확인된 회차의 다른 분모를 이름 붙인다.

  • 집계 개수 규칙과 실제 자료 사용 허가·재식별 위험을 구별한다.

  • 판본·언어·평가 방법과 모든 새 연구/학생 미수행 상태를 보존한다.

기본 전체와 모든 새 표·예제·연습/힌트/오답·전이를 손대조했다. 초기 유효 결정은 세 개, 전체 결정은 다섯 개로 결정 비율은 60%다. 유효 관찰 링크는 네 개, 전체 관찰 링크는 다섯 개로 링크 비율은 80%다. O1만 무효이면 D2와 D5가 남고, O2만 무효이면 D1과 D2가 남는다. 두 경우의 결정 비율은 각각 40%다. D6 추가 후 유효 결정은 네 개, 전체 결정은 여섯 개로 약 66.67%다. 같은 링크의 중복을 제거하면 기존 지표를 유지한다. A의 성공률은 60%, 성공자 평균은 40초다. B의 성공률은 70%, 성공자 평균은 50초다. 성공률 차이는 10퍼센트포인트이고 상대 증가는 약 16.67%다. 성공자 평균은 10초 늘어난다. 완료 회차 안의 성공 비율은 A 75%, B 87.5%다. 별도 B 미확인 판본의 전체 범위는 [70%,90%], 하나가 성공으로 확인된 뒤 범위는 [80%,90%]다. 성공 시간 합계 240초를 성공 여섯 회로 나눈 평균은 40초이지 24초가 아니다. 초기 공개 교차 칸은 [2,1,1,1]로 세 칸이 자체 문턱 미달이다. 학급별은 A 세 개/B 두 개이고 입력별은 키보드 세 개/마우스 두 개다. P2 제거 뒤 학급별과 입력별은 각각 [2,2]이며 교차 칸은 각각 한 기록이다. 같은 단원 기본 세 설명 전체와 여섯 실제 의미/HTML 앵커를 확인했다.
