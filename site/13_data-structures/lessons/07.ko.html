소단원 7.1

부모·자식과 높이

폴더의 깊이가 세 단계라는 말은 노드 세 개일까, 연결 세 개일까?

준비 개념과 학습 목표

준비 개념

  • 노드는 항목이며 간선은 부모와 자식을 연결한다.

  • 이진트리는 왼쪽/오른쪽 두 자식 위치를 구별하며 비어 있을 수 있다.

학습 목표

  • 부모·조상·자식·리프를 구별한다.

  • 간선을 세는 깊이/높이와 노드를 세는 높이 정의를 변환한다.

자식이 둘씩 있는 조건과 왼쪽부터 빈칸 없이 채운 조건은 같을까?

이 단원의 높이는 간선 수이며 빈 트리는 −1, 잎은 0이다. full은 모든 노드가 자식 0개 또는 2개라는 조건, complete는 마지막 레벨 전까지 가득 차고 마지막 레벨은 왼쪽부터 채운다는 조건이다. perfect는 모든 내부 노드에 두 자식이 있고 모든 잎 깊이가 같다는 조건으로 따로 부른다. 용어를 번역한 단어만 비교하지 말고 실제 조건을 적는다. 여기에 값 정렬 조건은 없다.

R의 왼쪽 L·오른쪽 M, L의 왼쪽 P·오른쪽 Q, P의 왼쪽 U·오른쪽 V이고 M/Q/U/V는 잎이라고 하자. 일곱 노드 모두 자식 수가 0 또는 2라 full이다. 그러나 깊이 2에서 M 아래가 비었는데 깊이 3의 U/V가 있으므로 complete가 아니다. 높이는 3, 내부 노드 수 I=3, 잎 수 F=4다. 각 내부 노드가 두 자식을 가지므로 간선 수는 2I이고, 유한 트리의 간선 수는 I+F−1이므로 F=I+1이다.

완전함만 있는 여섯 노드 트리는 A의 자식 B/C, B의 자식 D/E, C의 왼쪽 F로 만들 수 있다. 레벨별 1/2/3이 왼쪽부터 채워져 complete지만 C의 자식 수가 하나여서 full이 아니다. 일반 이진트리에서는 한 자식 노드도 있으므로 전체 잎 수에 I+1을 무조건 적용하면 안 된다. 높이 h인 비어 있지 않은 트리는 h+1≤n≤2^(h+1)−1이며 양끝은 사슬과 가득 찬 레벨로 달성한다.

먼저 확인할 개념
  • 간선 깊이와 빈 위치

    노드 수 높이와 간선 높이의 한 단계 차이를 고정한다.

  • 트리와 공유 구조의 조건

    서로 다른 자식 서브트리와 공유 DAG를 나눈다.

계층을 연결로 표현한다

루트는 시작점이고 비루트 노드는 부모가 하나다. 자식 없는 노드는 리프, 자식이 있는 노드는 내부 노드다. 같은 부모를 가진 두 노드는 형제다. 조상은 부모보다 넓은 관계로 루트에서 내려가는 경로에 있는 노드이며 아래에서는 자기 자신을 조상 수에 포함하지 않는다.

이진트리의 왼쪽 위치와 오른쪽 위치는 다르다. 루트의 자식이 하나여도 왼쪽인 트리와 오른쪽인 트리는 별개다. 자식 포인터가 null 인 것은 값 0 인 노드가 있다는 뜻이 아니라 해당 위치의 서브트리가 비었다는 뜻이다.

깊이와 높이의 단위를 정한다

깊이는 루트에서 그 노드까지 간선 수로 세어 루트 깊이 0 이다. 이 본문은 노드의 높이를 그 노드에서 리프까지 가장 긴 경로의 간선 수로 정의한다. 리프 높이 0, 빈 트리 높이−1 로 정하면 h(v)=1+max(h(left),h(right))로 통일된다.

높이를 노드 수/레벨 수로 정의하는 교재도 있다. 인용한 2018 OpenDSA 와 NIU 의 노드 수 높이는 비어 있지 않은 트리에서 여기 높이보다 1 크다. 혼용하면 단일 노드 높이를 0/1 로 다르게 답한다. 값을 비교할 때 먼저 정의를 적고 양쪽이 같은 모양을 말하는지 확인한다.

모양과 값의 조건을 분리한다

노드 수가 같아도 한 줄로 이어진 트리와 여러 방향으로 갈라진 트리는 높이가 다르다. 트리가 이진이라는 조건은 자식 위치가 최대 둘이라는 뜻이고 값의 정렬 조건은 아니다. 이진 탐색 트리의 순서 규칙은 따로 추가한다.

참조가 한 노드로 합쳐지거나 아래에서 조상으로 되돌아가는 순환이 있으면 단순 트리 모형이 아니다. 순회에서 같은 노드를 두 번 방문하거나 무한히 재귀할 수 있으므로 자료구조의 조건을 확인한다. 일반 그래프 탐색의 방문집합과 트리의 부모 관계를 구별한다.

  1. D/E/F 는 자식이 없어 리프다.

  2. A→C→F 의 간선 2 개로 F 깊이 2 다.

  3. B→D 또는 E 는 간선 1 개로 B 높이 1 이다.

  4. 전체의 최장경로는 간선 2 개, 6 노드의 연결은 5 개다.

리프 D/E/F, F 깊이 2, B 높이 1, 전체 높이 2, 간선 5 개다.

잎 공식을 잘못 일반화한다

세 노드 A→B→C 한 자식 사슬에서 내부 두 개이므로 잎이 세 개라고 했다.

  1. 실제 잎은 C 하나다.

  2. 2I 간선 식은 모든 내부 노드가 두 자식일 때만 성립한다.

  3. 이 사슬의 간선은 두 개이고 자식 수 1인 노드가 둘이다.

일반 이진트리의 잎은 내부 수만으로 I+1이 되지 않는다.

비교할 점

높이 계산과 자식 수 조건을 분리한다.

공유 잎을 합치면 트리가 아니다

A의 왼쪽 B/오른쪽 C, B와 C가 같은 D를 자식으로 참조한다.

  1. D에는 들어오는 부모 간선이 둘이다.

  2. 서브트리의 서로 다른 노드 조건을 위반한다.

  3. 같은 값인 두 별도 D 객체라면 이 공유 반례와 다르다.

내 말로 설명하기

두 조건이 모두 참이면 항상 perfect인가?

설명 기준 확인

아니다. complete이면서 full인 트리도 마지막 레벨이 일부만 찰 수 있다. 예를 들어 다섯 노드 A(B(D,E),C)는 두 조건이 참이지만 잎 깊이가 다르다.

동일 값 두 노드가 공유인가?

설명 기준 확인

노드 정체성이 다르면 값만 같은 두 노드다. 공유는 같은 객체를 참조하는 것이다.

한 단계 더

7 노드가 각 레벨 1/2/4 로 꽉 차면 간선 높이 2, 한 줄이면 6 이다. 높이 h 인 이진트리의 최대 노드 수 1+2+…+2^h=2^(h+1)−1 을 h2 의 7 로 검산하고 최소 노드 수 h+1 과 비교한다.

  • 레벨 순회의 큐를 손으로 추적한다.

출력 값 두 줄만 같으면 구조를 복원할 수 있을까?

같은 트리의 전위와 중위 순회에 서로 다른 노드 ID가 각각 한 번씩 있다면 그 트리는 유일하게 복원된다. 전위 첫 ID를 루트로 삼고 중위의 루트 위치로 좌우 ID 집합을 나눈 뒤 각 분할에 같은 규칙을 적용한다. 입력을 받을 때는 전체 길이와 ID 집합뿐 아니라 모든 재귀 분할의 구간과 ID 집합이 호환되는지도 검사해야 한다. 전위 [A,C,B]와 중위 [B,A,C]는 고유 ID와 전체 집합이 같지만, 루트 A의 왼쪽 중위 B에 대응하는 전위 첫 ID가 C이므로 거절한다. ID 중복이나 분할 불일치를 무시하고 연결을 추측하지 않는다.

값 7인 루트와 값 7인 한 자식이 있는 두 트리를 비교하자. 왼쪽 자식인 경우와 오른쪽 자식인 경우 모두 값 전위 [7,7], 값 중위 [7,7]이다. 값 목록만으로 위치를 구별할 수 없다. 서로 다른 ID A/B를 쓰면 전위 [A,B]는 같아도 중위 [B,A]는 왼쪽 자식, [A,B]는 오른쪽 자식이다. 값 중복을 노드 ID 중복으로 바꾸면 복원 조건을 잃는다.

전위에 빈 위치 토큰 #을 함께 남기면 ID 중복과 관계없이 모양을 복원할 수 있다. 비어 있지 않은 토큰은 정확히 두 자식 위치를 예약하고 #은 빈 위치 하나를 소비한다. 처음 미처리 위치를 한 개로 시작해 노드에서는 순증가 1, #에서는 감소 1을 한다. 토큰이 남아 있는 동안 처리 직전 위치 수가 양수여야 하며 마지막에 정확히 0이어야 한다. 이 문법은 #이 노드 값 토큰과 충돌하지 않는 별도 표기라는 조건이다.

방문하는 시점을 옮긴다

여기서는 모든 순회를 왼쪽부터 진행한다. 전위는 현재 노드→왼쪽 서브트리→오른쪽 서브트리, 중위는 왼쪽→현재→오른쪽, 후위는 왼쪽→오른쪽→현재다. 서브트리에도 같은 규칙을 재귀 적용하므로 단순히 직계 자식만 나열하는 규칙이 아니다.

visit 와 재귀호출을 구별하면 세 방법의 차이가 보인다. 전위는 visit 후 자식으로 가고, 중위는 왼쪽 호출이 돌아오면 visit, 후위는 두 호출이 돌아온 다음 visit 한다. 빈 위치는 방문하지 않는다. 좌우 순서를 바꾸면 다른 나열이므로 출력과 함께 convention 을 남긴다.

폭을 먼저 보는 레벨 순회

레벨 순회는 깊이 0,1,2 순서로 기록한다. 큐에 루트를 넣고 앞의 노드를 꺼내 방문한 뒤 존재하는 왼쪽/오른쪽 자식을 뒤에 넣는다. 같은 깊이 안에서 왼쪽부터 시작하는 약속이 이 큐 순서를 만든다.

큐 앞/뒤와 현재 출력은 다른 것이다. 자식은 enqueue 될 때 발견되지만 여기서는 dequeue 될 때 방문한다. 발견 출력과 방문 출력을 섞어 두 번 쓰지 않는다. 한 번 꺼낸 노드마다 자식 둘까지 검사하므로 n 노드를 한 번씩 처리하면 시간은 O(n)이다.

순서가 쓰임을 바꾼다

전위는 부모 정보를 먼저 전달하는 계층 출력에 어울리고 후위는 자식 결과가 필요한 크기 합산/해제에 어울린다. 중위가 값 오름차순이라는 성질은 이진 탐색 트리의 정렬 조건이 있을 때다. 임의 값 이진트리에는 보장되지 않는다.

순회 결과만으로 구조가 항상 복원되는 것도 아니다. A/B 라는 전위만으로 B 가 A 의 왼쪽인지 오른쪽인지 알 수 없다. 중복 없는 노드 ID 의 전위와 중위를 함께 쓰거나 비어 있는 위치 표시까지 보존하면 구조 정보가 더 풍부해진다.

소단원 7.3

재귀·반복 순회 비교

재귀를 반복문으로 바꾸면 돌아갈 위치를 어디에 저장해야 할까?

준비 개념과 학습 목표

준비 개념

  • 함수 호출 스택에는 호출이 끝난 뒤 돌아갈 작업이 저장된다.

  • 명시적 스택의 top 은 마지막으로 넣은 원소다.

학습 목표

  • 재귀의 대기 작업을 명시적 스택으로 표현한다.

  • 방문 순서·시간·보조공간의 차이를 분석한다.

트리 높이가 같아도 두 순회의 실제 대기 칸 수가 다를까?

반복 중위는 current가 가리키는 왼쪽 경로를 쌓고 pop한 노드를 방문한 뒤 오른쪽으로 이동한다. 보조 스택의 상계는 h+1이지만 항상 정확히 h+1인 것은 아니다. 다섯 노드 왼쪽 사슬은 첫 방문 전에 다섯 포인터가 쌓이고, 다섯 노드 오른쪽 사슬은 push 후 바로 pop하여 최대 한 포인터만 쌓인다. 두 사슬의 높이는 모두 4다. 시간은 두 경우 각 노드 한 번 push/pop으로 선형이다.

큐 레벨 순회는 서로 이웃한 두 깊이의 노드를 함께 저장할 수 있다. A의 자식 B/C, B의 자식 D/E, C는 잎인 다섯 노드 트리에서 깊이별 폭은 1/2/2다. 하지만 A를 꺼낸 큐 [B,C]에서 B를 꺼내 D/E를 넣으면 [C,D,E] 세 칸이다. 최대 레벨 폭이 2라고 큐가 정확히 두 칸 이하라는 결론을 내리면 실패한다. 큐는 현재 레벨의 남은 노드와 다음 레벨의 발견 노드를 함께 담는다.

후위의 phase 프레임은 자식 작업을 기다리는 부모의 다음 위치를 보존한다. phase 0에서는 부모를 phase 1로 바꾼 뒤 왼쪽 자식, phase 1에서는 phase 2로 바꾼 뒤 오른쪽 자식을 먼저 처리하고 phase 2에서 방문·제거한다. 여기서는 빈 자식에 새 프레임을 만들지 않는다. 재귀 호출의 원시 개수에는 빈 위치 호출도 포함할 수 있어 n개의 비어 있지 않은 노드에 대해 2n+1이다. 포인터 칸과 언어 호출 프레임의 실제 바이트 수는 같다고 가정하지 않는다.

먼저 확인할 개념
  • 대기 작업과 중위 스택

    재귀와 반복의 논리 대기 정보를 구별한다.

  • 큐의 논리 길이와 용량

    현재 발견했지만 처리하지 않은 노드 수를 예약 용량과 분리한다.

재귀는 돌아갈 일을 기억한다

중위 inorder(v)는 v 가 없으면 반환하고, inorder(left), visit(v), inorder(right)를 차례로 실행한다. 왼쪽 호출 동안 부모의 방문과 오른쪽 호출이 기다린다. 그 대기 정보를 함수 호출 스택이 보존하므로 재귀가 기억장치 없이 일하는 것은 아니다.

서브트리의 높이가 h 이면 살아 있는 재귀 프레임은 가장 긴 경로 길이에 비례한다. 출력 저장공간을 제외하고 O(h+1) 보조공간이다. h 는 간선 높이이고 한 노드는 h0 이라 +1 을 적었다. 균형이면 O(log n), 사슬이면 O(n)이며 실제 언어의 호출 한도를 넘을 수 있다.

반복 중위는 왼쪽 경로를 쌓는다

반복 중위는 current=root, 빈 스택으로 시작한다. current 가 있으면 push 후 left 로 계속 내려간다. 없으면 pop 한 노드를 방문하고 그 오른쪽으로 current 를 바꾼다. 바깥 반복 조건은 current 가 있거나 스택이 비지 않은 것이다. 둘 다 비어야 끝난다.

push 한 노드는 왼쪽 서브트리 작업 뒤 자기 방문/오른쪽 작업을 기다린다. 각 노드는 한 번 push/pop 되어 전체 시간 O(n), 이 방식의 스택은 O(h+1)이다. 반복이라는 이유만으로 상수공간이 되는 것은 아니며 저장 대상이 언어 호출 프레임에서 노드 포인터로 바뀐다.

후위에는 단계까지 필요하다

후위는 두 자식 작업 뒤 방문해야 하므로 노드만 보고 되돌아왔을 때 왼쪽에서 왔는지 오른쪽에서 왔는지 구별할 정보가 필요하다. last-visited 포인터나 (node,phase) 프레임으로 재귀의 프로그램 위치를 표현할 수 있다. 여기서는 phase0=왼쪽 대기,1=오른쪽 대기,2=방문이라고 정한다.

전위 반복에서는 노드를 꺼내 방문하고 오른쪽을 먼저 push 한 다음 왼쪽을 push 하면 왼쪽이 먼저 pop 된다. push 순서를 출력 순서와 혼동하면 반대로 돈다. 자료구조가 진짜 트리이며 순회 중 연결을 바꾸지 않는다는 조건 아래 결과를 재귀와 대조한다.

힌트 1

연결·ID·값을 다른 관찰 대상으로 다룬다. full은 자식 수, complete는 레벨 빈 위치, perfect는 같은 잎 깊이를 검사한다.

힌트 2

큐는 실제 상태를 기록하고 #은 빈 위치마다 하나씩 넣는다. 중위 스택은 왼쪽 경로를 기다린다.

풀이와 답 확인

  1. 원래 높이 2, 잎 D/E/C 세 개다. 모든 내부가 자식 두 개라 full이며 왼쪽부터 마지막 레벨을 채워 complete지만 C와 D/E의 깊이가 달라 perfect는 거짓이다.

  2. 전위 A B D E C, 중위 D B E A C, 후위 D E B C A, 레벨 A B C D E다. # 전위는 A B D # # E # # C # #로 11토큰이며 위치 수는 시작1 이후 2,3,4,3,2,3,2,1,2,1,0이다.

  3. 반복 중위는 처음 [A,B,D]로 최대 세 포인터다. 큐도 B 처리 직후 [C,D,E]로 최대 세 포인터지만 서로 다른 노드를 저장한다. 원시 재귀 전체 호출은11이고 실제 방문은5다.

  4. C를 제거하면 노드4/간선3/높이2/잎2다. A가 자식 하나라 full은 거짓이다. 깊이1의 오른쪽 빈 자리보다 아래 D/E가 존재해 complete도 거짓이다. ID 전위 A B D E와 중위 D B E A는 여전히 고유 ID로 복원할 수 있다. B/D/E 값7의 중복 때문에 값 목록만으로 같은 복원을 일반 보장하지 않는다.

full 반례는 노드 7개, 높이 3, 잎 4개이고 complete 반례는 노드 6개와 높이 2다. 내부 노드 수 I=5인 full 트리는 잎 6개, 전체 노드 11개, 간선 10개임을 대조했다. 다섯 노드의 네 방문열과 직렬화의 11개 토큰, 여섯 빈 위치 및 접두 위치 수를 손검산했다. 값 7인 좌우 자식의 모호성과 전위 [A,C,B]·중위 [B,A,C]의 재귀 분할 불일치를 확인했다. 좌우 사슬의 최대 중위 스택 수는 5와 1이며 push와 pop은 각각 5회다. 큐 길이 1, 2, 3, 2, 1, 0과 최대 레벨 폭 2를 구별했다. 반복 레벨 탐색의 접두 합 15와 빈 호출을 포함한 원시 호출 수 11을 대조했다. 전이 삭제 뒤 노드 4개, 간선 3개, 높이 2, 잎 2개도 손으로 확인했다.
