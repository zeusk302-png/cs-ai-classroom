소단원 7.1

부모·자식과 높이

폴더의 깊이가 세 단계라는 말은 노드 세 개일까, 연결 세 개일까?

준비 개념과 학습 목표

준비 개념

  • 노드는 항목이며 간선은 부모와 자식을 연결한다.
  • 이진트리는 왼쪽/오른쪽 두 자식 위치를 구별하며 비어 있을 수 있다.

학습 목표

  • 부모·조상·자식·리프를 구별한다.
  • 간선을 세는 깊이/높이와 노드를 세는 높이 정의를 변환한다.

계층을 연결로 표현한다

루트는 시작점이고 비루트 노드는 부모가 하나다. 자식 없는 노드는 리프, 자식이 있는 노드는 내부 노드다. 같은 부모를 가진 두 노드는 형제다. 조상은 부모보다 넓은 관계로 루트에서 내려가는 경로에 있는 노드이며 아래에서는 자기 자신을 조상 수에 포함하지 않는다.

이진트리의 왼쪽 위치와 오른쪽 위치는 다르다. 루트의 자식이 하나여도 왼쪽인 트리와 오른쪽인 트리는 별개다. 자식 포인터가 null 인 것은 값 0 인 노드가 있다는 뜻이 아니라 해당 위치의 서브트리가 비었다는 뜻이다.

깊이와 높이의 단위를 정한다

깊이는 루트에서 그 노드까지 간선 수로 세어 루트 깊이 0 이다. 이 본문은 노드의 높이를 그 노드에서 리프까지 가장 긴 경로의 간선 수로 정의한다. 리프 높이 0, 빈 트리 높이−1 로 정하면 h(v)=1+max(h(left),h(right))로 통일된다.

높이를 노드 수/레벨 수로 정의하는 교재도 있다. 인용한 2018 OpenDSA 와 NIU 의 노드 수 높이는 비어 있지 않은 트리에서 여기 높이보다 1 크다. 혼용하면 단일 노드 높이를 0/1 로 다르게 답한다. 값을 비교할 때 먼저 정의를 적고 양쪽이 같은 모양을 말하는지 확인한다.

모양과 값의 조건을 분리한다

노드 수가 같아도 한 줄로 이어진 트리와 여러 방향으로 갈라진 트리는 높이가 다르다. 트리가 이진이라는 조건은 자식 위치가 최대 둘이라는 뜻이고 값의 정렬 조건은 아니다. 이진 탐색 트리의 순서 규칙은 따로 추가한다.

참조가 한 노드로 합쳐지거나 아래에서 조상으로 되돌아가는 순환이 있으면 단순 트리 모형이 아니다. 순회에서 같은 노드를 두 번 방문하거나 무한히 재귀할 수 있으므로 자료구조의 조건을 확인한다. 일반 그래프 탐색의 방문집합과 트리의 부모 관계를 구별한다.

중간 과정을 따라가는 예제

루트 A 의 왼쪽 B/오른쪽 C, B 의 왼쪽 D/오른쪽 E, C 의 오른쪽 F 이며 나머지 위치는 비어 있다. 각 리프, F 깊이, B 높이, 전체 높이, 간선 수를 구하라. 간선 높이 정의를 사용한다.

  1. D/E/F 는 자식이 없어 리프다.
  2. A→C→F 의 간선 2 개로 F 깊이 2 다.
  3. B→D 또는 E 는 간선 1 개로 B 높이 1 이다.
  4. 전체의 최장경로는 간선 2 개, 6 노드의 연결은 5 개다.

리프 D/E/F, F 깊이 2, B 높이 1, 전체 높이 2, 간선 5 개다.

종이와 본문으로 직접 해보기

F 의 오른쪽에 G 를 붙인다. 전체 높이와 G 깊이, 리프 수, 노드 수/간선 수는? 노드 수 높이로는?

힌트 보기

F 가 더 이상 리프가 아니며 최장경로 A→C→F→G 를 센다.

풀이 보기

G 깊이 3, 전체 간선 높이 3, 노드 수 높이 4 다. 리프는 D/E/G 로 3 개, 노드 7 개/간선 6 개다.

오해와 반례

이진트리 6 노드면 항상 높이는 2 다.

A→B→C→D→E→F 한 자식 사슬도 이진트리이며 높이 5 다. 높이는 노드 수만으로 고정되지 않는다.

자식 하나가 왼쪽인지 오른쪽인지 중요하나?

답과 이유 보기

순서가 있는 서로 다른 위치다.

한 단계 더

7 노드가 각 레벨 1/2/4 로 꽉 차면 간선 높이 2, 한 줄이면 6 이다. 높이 h 인 이진트리의 최대 노드 수 1+2+…+2^h=2^(h+1)−1 을 h2 의 7 로 검산하고 최소 노드 수 h+1 과 비교한다.

소단원 7.2

전위·중위·후위·레벨 순회

같은 트리에서 왜 출력 순서가 네 가지로 바뀔까?

준비 개념과 학습 목표

준비 개념

  • 방문은 노드의 값을 읽거나 기록하는 동작이다.
  • 스택은 마지막 것을 먼저 꺼내고 큐는 먼저 들어온 것을 먼저 꺼낸다.

학습 목표

  • 세 깊이우선 순회에서 방문 시점을 구별한다.
  • 레벨 순회의 큐를 손으로 추적한다.

방문하는 시점을 옮긴다

여기서는 모든 순회를 왼쪽부터 진행한다. 전위는 현재 노드→왼쪽 서브트리→오른쪽 서브트리, 중위는 왼쪽→현재→오른쪽, 후위는 왼쪽→오른쪽→현재다. 서브트리에도 같은 규칙을 재귀 적용하므로 단순히 직계 자식만 나열하는 규칙이 아니다.

visit 와 재귀호출을 구별하면 세 방법의 차이가 보인다. 전위는 visit 후 자식으로 가고, 중위는 왼쪽 호출이 돌아오면 visit, 후위는 두 호출이 돌아온 다음 visit 한다. 빈 위치는 방문하지 않는다. 좌우 순서를 바꾸면 다른 나열이므로 출력과 함께 convention 을 남긴다.

폭을 먼저 보는 레벨 순회

레벨 순회는 깊이 0,1,2 순서로 기록한다. 큐에 루트를 넣고 앞의 노드를 꺼내 방문한 뒤 존재하는 왼쪽/오른쪽 자식을 뒤에 넣는다. 같은 깊이 안에서 왼쪽부터 시작하는 약속이 이 큐 순서를 만든다.

큐 앞/뒤와 현재 출력은 다른 것이다. 자식은 enqueue 될 때 발견되지만 여기서는 dequeue 될 때 방문한다. 발견 출력과 방문 출력을 섞어 두 번 쓰지 않는다. 한 번 꺼낸 노드마다 자식 둘까지 검사하므로 n 노드를 한 번씩 처리하면 시간은 O(n)이다.

순서가 쓰임을 바꾼다

전위는 부모 정보를 먼저 전달하는 계층 출력에 어울리고 후위는 자식 결과가 필요한 크기 합산/해제에 어울린다. 중위가 값 오름차순이라는 성질은 이진 탐색 트리의 정렬 조건이 있을 때다. 임의 값 이진트리에는 보장되지 않는다.

순회 결과만으로 구조가 항상 복원되는 것도 아니다. A/B 라는 전위만으로 B 가 A 의 왼쪽인지 오른쪽인지 알 수 없다. 중복 없는 노드 ID 의 전위와 중위를 함께 쓰거나 비어 있는 위치 표시까지 보존하면 구조 정보가 더 풍부해진다.

중간 과정을 따라가는 예제

A 의 왼쪽 B/오른쪽 C, B 의 왼쪽 D/오른쪽 E, C 의 오른쪽 F 다. 전위/중위/후위/레벨 순서를 구하고 레벨 큐를 추적하라.

  1. 전위는 A 다음 B 서브트리 B/D/E, 다음 C/F 라서 A B D E C F 다.
  2. 중위는 D B E 다음 A 다음 C F 라서 D B E A C F 다.
  3. 후위는 D E B 다음 F C 다음 A 라서 D E B F C A 다.
  4. 레벨 큐는[A]→[B,C]→[C,D,E]→[D,E,F]→[E,F]→[F]→[]다. 출력 A B C D E F 다.

전위 ABDECF, 중위 DBEACF, 후위 DEBFCA, 레벨 ABCDEF 다.

종이와 본문으로 직접 해보기

B 의 두 자식을 서로 바꾸면 네 출력은? 다른 연결은 유지한다.

힌트 보기

B 서브트리 내부의 D/E 순서만 바뀐다.

풀이 보기

전위 A B E D C F, 중위 E B D A C F, 후위 E D B F C A, 레벨 A B C E D F 다. 루트 방문 시점은 그대로다.

오해와 반례

중위 순회는 어떤 이진트리에서도 값을 정렬한다.

값이 A10/B20/C5 이고 B 왼쪽/C 오른쪽이면 중위 20,10,5 다. 모양만 이진이어서는 정렬되지 않는다.

한 단계 더

소단원 7.3

재귀·반복 순회 비교

재귀를 반복문으로 바꾸면 돌아갈 위치를 어디에 저장해야 할까?

준비 개념과 학습 목표

준비 개념

  • 함수 호출 스택에는 호출이 끝난 뒤 돌아갈 작업이 저장된다.
  • 명시적 스택의 top 은 마지막으로 넣은 원소다.

학습 목표

  • 재귀의 대기 작업을 명시적 스택으로 표현한다.
  • 방문 순서·시간·보조공간의 차이를 분석한다.

재귀는 돌아갈 일을 기억한다

중위 inorder(v)는 v 가 없으면 반환하고, inorder(left), visit(v), inorder(right)를 차례로 실행한다. 왼쪽 호출 동안 부모의 방문과 오른쪽 호출이 기다린다. 그 대기 정보를 함수 호출 스택이 보존하므로 재귀가 기억장치 없이 일하는 것은 아니다.

서브트리의 높이가 h 이면 살아 있는 재귀 프레임은 가장 긴 경로 길이에 비례한다. 출력 저장공간을 제외하고 O(h+1) 보조공간이다. h 는 간선 높이이고 한 노드는 h0 이라 +1 을 적었다. 균형이면 O(log n), 사슬이면 O(n)이며 실제 언어의 호출 한도를 넘을 수 있다.

반복 중위는 왼쪽 경로를 쌓는다

반복 중위는 current=root, 빈 스택으로 시작한다. current 가 있으면 push 후 left 로 계속 내려간다. 없으면 pop 한 노드를 방문하고 그 오른쪽으로 current 를 바꾼다. 바깥 반복 조건은 current 가 있거나 스택이 비지 않은 것이다. 둘 다 비어야 끝난다.

push 한 노드는 왼쪽 서브트리 작업 뒤 자기 방문/오른쪽 작업을 기다린다. 각 노드는 한 번 push/pop 되어 전체 시간 O(n), 이 방식의 스택은 O(h+1)이다. 반복이라는 이유만으로 상수공간이 되는 것은 아니며 저장 대상이 언어 호출 프레임에서 노드 포인터로 바뀐다.

후위에는 단계까지 필요하다

후위는 두 자식 작업 뒤 방문해야 하므로 노드만 보고 되돌아왔을 때 왼쪽에서 왔는지 오른쪽에서 왔는지 구별할 정보가 필요하다. last-visited 포인터나 (node,phase) 프레임으로 재귀의 프로그램 위치를 표현할 수 있다. 여기서는 phase0=왼쪽 대기,1=오른쪽 대기,2=방문이라고 정한다.

전위 반복에서는 노드를 꺼내 방문하고 오른쪽을 먼저 push 한 다음 왼쪽을 push 하면 왼쪽이 먼저 pop 된다. push 순서를 출력 순서와 혼동하면 반대로 돈다. 자료구조가 진짜 트리이며 순회 중 연결을 바꾸지 않는다는 조건 아래 결과를 재귀와 대조한다.

중간 과정을 따라가는 예제

앞 단원의 6 노드 트리 A(B(D,E),C(없음,F))를 반복 중위로 돈다. 스택은 바닥→top 으로 적고 각 pop 방문을 기록하라.

  1. A/B/D 를 차례로 push 해[A,B,D], current=null 이다.
  2. D 를 pop 방문, 스택[A,B]. D 오른쪽은 없다. B 를 pop 방문하고 E 로 간다.
  3. E 를 push/pop 방문 후 A 를 pop 방문한다. 스택은 비었다가 C 를 push 한다.
  4. C 를 pop 방문 후 F 를 push/pop 방문하여 current=null/stack=[]로 끝난다.

방문 D B E A C F 로 재귀 중위와 같다. 최대 스택 3 개, 총 6push/6pop 이다.

종이와 본문으로 직접 해보기

반복 전위에서 A 를 pop 한 뒤 B 를 먼저 push 하고 C 를 다음 push 하면 첫 3 방문은? 올바른 왼쪽 우선 push 순서로 고치면?

힌트 보기

스택은 마지막 push 를 먼저 꺼낸다. C 에는 오른쪽 F 가 있다.

풀이 보기

잘못된 순서는 A C F 로 시작한다. C 먼저/B 다음 push 면 A B D 로 시작한다. 두 경우 모두 push 시점과 방문시점을 구별한다.

오해와 반례

반복 순회는 메모리 없이 O(1)로 동작한다.

현재 반복 중위는 최장 왼쪽 경로[A,B,D]를 저장한다. 왼쪽 사슬 n 노드면 스택 n 개로 O(n)이며 별도 Morris 방식 같은 구조수정 기법을 도입하지 않았다.

한 단계 더

단일 B 의 후위 프레임은(B,0)에서 왼쪽 없음→(B,1), 오른쪽 없음→(B,2), 방문 B/제거다. 큰 트리에서는 자식 프레임이 끝나면 부모의 다음 phase 로 돌아가며 D E B F C A 를 얻는 사건표를 만든다. 코드/실제 재귀한도 실험은 하지 않았다.
