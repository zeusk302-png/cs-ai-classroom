소단원 5.1

Lagrange·Newton 보간

주어진 세 점을 모두 지나는 다항식을 두 방법으로 만들어도 같을까?

준비 개념과 학습 목표

준비 개념

  • 다항식 차수는 가장 높은 지수다.

  • 서로 다른 노드는 같은 x값이 중복되지 않는다는 뜻이다.

학습 목표

  • Lagrange 기본다항식을 만든다.

  • Newton 형식의 계수와 같은 다항식임을 확인한다.

지나가야 할 점과 유일성

서로 다른 n+1개 노드 x_i와 값 y_i에 대해 p(x_i)=y_i를 만족하는 차수 n 이하 다항식이 보간다항식이다. 관측 오차를 허용하고 전체 제곱오차를 최소화하는 회귀와 달리, 여기서는 주어진 값을 정확히 통과시킨다.

만약 그런 p와 q가 둘 존재한다면 p−q는 차수 n 이하이면서 서로 다른 n+1개 근을 갖는다. 0이 아닌 차수 n 이하 다항식은 그럴 수 없으므로 차이는 0이다. 같은 x에 서로 다른 값을 요구하면 존재 자체가 불가능하다.

각 점만 켜지는 Lagrange 기저

ℓ_i(x)=Π_{j≠i}(x−x_j)/(x_i−x_j)로 둔다. x=x_i에서는 각 분자와 분모가 같아 값 1이고, 다른 노드에서는 한 인수가 0이 되어 값 0이다. 따라서 Σ_i y_iℓ_i는 각 노드에서 해당 y_i만 남긴다.

노드가 달라 분모가 0이 아니어야 한다. 보간 조건을 눈으로 확인하기 좋은 형태지만 점을 하나 추가하면 기존 기본다항식도 바뀐다. 대규모 수치 평가의 효율과 안정성은 수학적 존재 증명과 별도의 문제다.

Newton의 누적 곱 기저

Newton 형식은 a₀+a₁(x−x₀)+a₂(x−x₀)(x−x₁)+…다. 각 새 항이 앞선 노드에서 0이므로 이미 맞춘 값을 유지하며 다음 값을 맞출 수 있다. 계수는 분할차분이며 다음 소단원에서 표로 계산한다.

노드 순서를 바꾸면 중간 계수와 기저가 달라져도 모든 보간 조건과 차수 제한을 만족하는 최종 다항식은 유일하므로 같다. 표현이 같지 않다는 사실을 서로 다른 함수라는 뜻으로 오해하지 않는다.

중간 과정을 따라가는 예제

노드 (0,1),(1,2),(3,10)을 지나는 차수 2 이하 p를 두 형식으로 구하라.

  1. Lagrange 기저는 ℓ₀=(x−1)(x−3)/3, ℓ₁=−x(x−3)/2, ℓ₂=x(x−1)/6이다. 각 노드에서 1,0,0 패턴을 확인한다.

  2. 값을 곱해 ℓ₀+2ℓ₁+10ℓ₂를 전개하면 (x²−4x+3)/3−x²+3x+(5/3)(x²−x)=x²+1이다.

  3. Newton의 첫 계수는 1, 두 번째는 (2−1)/(1−0)=1, 세 번째는 ((10−2)/(3−1)−1)/(3−0)=1이다.

  4. 따라서 1+x+x(x−1)=1+x²다. 0,1,3에서 1,2,10을 얻는다.

두 구성 모두 p=x²+1이다.

종이와 본문으로 직접 해보기

위 다항식에 노드 x=2,값 5를 추가하면 더 높은 차수가 반드시 필요한지 판단하라.

힌트 보기

이미 구한 p(2)를 계산한다.

풀이 보기

p(2)=5이므로 새 조건도 만족한다. 차수 3 이하 보간의 유일성으로 같은 p가 답이며 새 Newton 최고차 계수는 0이다. 조건 수 증가가 실제 차수 증가를 강제하지 않는다.

오해와 반례

n+1개 점의 보간은 반드시 정확히 n차다.

세 점 (0,1),(1,2),(2,3)은 p=x+1로 맞는다. 차수는 n 이하이며 최고 계수가 0이면 실제 차수가 더 낮다.

소단원 5.2

분할차분과 오차항

보간 점에서는 오차가 0인데 점 사이의 오차는 무엇에 달려 있을까?

준비 개념과 학습 목표

준비 개념

  • 도함수는 국소 변화율이다.

  • n!은 1부터 n까지의 곱이다.

학습 목표

  • 분할차분 표를 구성한다.

  • 매끄러움 조건을 붙여 오차항을 사용한다.

분할차분의 재귀 표

0차는 f[x_i]=f(x_i), 1차는 두 값의 차를 노드 간격으로 나눈 평균 변화율이다. 일반적으로 f[x₀,…,x_r]=(f[x₁,…,x_r]−f[x₀,…,x_{r−1}])/(x_r−x₀)다. 노드가 서로 다르면 분모가 0이 아니다.

Newton의 r차 누적 곱 앞 계수는 f[x₀,…,x_r]다. 높은 차분은 바로 아래 두 차분의 차를 전체 양끝 간격으로 나누므로 인접 간격만 반복 사용하면 틀린다. 표를 종이에 삼각형으로 배열해 어떤 두 칸을 참조했는지 표시한다.

오차항의 조건과 위치

f가 노드와 평가점 x를 포함하는 구간에서 n+1번 연속 미분 가능하면 f(x)−p_n(x)=f⁽ⁿ⁺¹⁾(ξ)/(n+1)!·Π_i(x−x_i)다. ξ는 이 점들 사이 구간의 어떤 점이며 보통 정확한 위치를 알 수 없다.

오차항은 노드에서 곱이 0인 이유와, 도함수 크기·노드 배치가 점 사이 오차에 함께 영향을 주는 이유를 표현한다. |f⁽ⁿ⁺¹⁾|≤M을 그 구간 전체에서 알면 절댓값 오차는 M/(n+1)!·|Π_i(x−x_i)| 이하이다. 매끄러움이나 상한을 확인하지 않고 식을 숫자 보증으로 쓰지 않는다.

근이 많은 함수로 증명하기

평가점 x가 노드와 다를 때 ω(t)=Π_i(t−x_i), K=(f(x)−p_n(x))/ω(x)로 두고 g(t)=f(t)−p_n(t)−Kω(t)를 만든다. g는 모든 노드와 평가점 x에서 0이므로 서로 다른 n+2개 근이 있다.

Rolle 정리를 n+1번 적용하면 어떤 ξ에서 g⁽ⁿ⁺¹⁾(ξ)=0이다. p_n의 이 도함수는 0, ω의 도함수는 (n+1)!이므로 K=f⁽ⁿ⁺¹⁾(ξ)/(n+1)!다. 노드에서는 이미 오차 0이므로 K를 나눠 정의할 필요가 없다.

중간 과정을 따라가는 예제

f(x)=x³를 노드 0,1,2에서 보간하고 x=1/2의 오차를 표와 오차항으로 구하라.

  1. 값은 0,1,8이고 1차 차분은 1,7이다. 2차는 (7−1)/(2−0)=3이다.

  2. p=0+1·x+3x(x−1)=3x²−2x다.

  3. x=1/2에서 f=1/8,p=3/4−1=−1/4이므로 f−p=3/8이다.

  4. f‴=6이고 3!=6이므로 오차항은 (1/2)(−1/2)(−3/2)=3/8로 정확히 일치한다.

p=3x²−2x, 점 사이 오차 3/8이다.

종이와 본문으로 직접 해보기

f=x²를 0,1,3에서 보간할 때 차분과 오차항으로 오차가 0인 이유를 적으라.

힌트 보기

세 값은 0,1,9이고 1차 차분은 1,4다.

풀이 보기

2차 차분은 (4−1)/3=1이며 p=x+x(x−1)=x²다. f‴=0이므로 2차 보간 오차항도 모든 평가점에서 0이다.

오해와 반례

오차항의 ξ는 평가점 x와 같다.

ξ는 Rolle 정리가 보장한 존재점이지 지정된 평가점이 아니다. 도함수가 일정한 x³ 예제에서는 어디서나 같아 차이가 안 보일 뿐, 일반 함수에서는 f⁽ⁿ⁺¹⁾(x)로 대체하면 보증이 사라진다.

소단원 5.3

Hermite 보간

두 점의 높이뿐 아니라 기울기까지 지정하면 어떤 곡선이 나올까?

준비 개념과 학습 목표

준비 개념

  • p′는 다항식의 도함수다.

  • 서로 다른 두 끝점의 값과 1차 도함수를 각각 주는 상황이다.

  • C⁴는 네 번째 도함수까지 존재하고 연속이라는 뜻이며, 중근은 같은 근에서 함수와 첫 도함수가 함께 0인 경우다.

학습 목표

  • 함수값·미분 조건을 동시에 만족시킨다.

  • 반복 노드와 오차 조건을 설명한다.

값과 접선 정보를 함께 맞추기

Hermite 보간은 같은 노드에서 함수값과 도함수 값을 함께 지정한다. 두 노드 x₀≠x₁에서 값 2개와 기울기 2개를 주면 네 조건에 맞는 차수 3 이하 다항식을 구한다. 조건을 맞추는 방정식이 네 개라는 점을 먼저 센다.

유일성은 차이 다항식이 각 노드에서 값과 미분 모두 0이라는 사실로 보인다. 두 노드는 각각 중근이므로 차이가 0이 아니면 최소 차수 4인데, 차수 3 이하라는 제한과 모순이다. 값 없이 도함수만 주면 상수 이동이 남는 등 정보 종류에 따라 유일성은 달라진다.

구간의 길이와 네 기본함수

t=(x−x₀)/h,h=x₁−x₀로 좌표를 바꾸고 h₀₀=2t³−3t²+1,h₁₀=t³−2t²+t,h₀₁=−2t³+3t²,h₁₁=t³−t²를 둔다. H=y₀h₀₀+h d₀h₁₀+y₁h₀₁+h d₁h₁₁이며 d_i는 x에 대한 도함수다.

도함수 항에 h가 필요한 이유는 d/dx=(1/h)d/dt이기 때문이다. 예를 들어 t=0에서 h₁₀의 t 미분은 1이므로 h d₀를 곱해야 x 미분이 d₀가 된다. 길이가 1인 예제만 보면 빠진 배율을 발견하기 어렵다.

반복 노드와 남는 오차

분할차분의 두 노드를 가까이 보내면 f[x₀,x₀]=f′(x₀)가 된다. 반복 노드는 0으로 나누라는 뜻이 아니라 도함수 정보로 채우는 극한 규칙이다. 같은 노드가 r+1번이면 적절한 매끄러움 아래 f⁽ʳ⁾(x₀)/r!가 대응한다.

두 노드에서 값·1차 미분을 맞춘 경우 f가 관련 구간에서 C⁴이면 f(x)−H(x)=f⁽⁴⁾(ξ)/4!·(x−x₀)²(x−x₁)²다. 조건을 더 맞췄어도 모든 함수에서 오차가 0인 것은 아니다. 3차 이하 함수면 네 번째 도함수가 0이어서 정확하다.

중간 과정을 따라가는 예제

노드 0과 1에서 H(0)=0,H′(0)=0,H(1)=1,H′(1)=0인 3차 이하 다항식을 구하라.

  1. H=a+bx+cx²+dx³라 두면 0의 두 조건에서 a=b=0이다.

  2. 1의 값 조건은 c+d=1, 미분 조건은 2c+3d=0이다.

  3. 두 식을 풀면 d=−2,c=3이므로 H=3x²−2x³다.

  4. H′=6x−6x²로 두 끝점 기울기는 0이다. H(1/2)=3/4−1/4=1/2도 확인한다.

두 끝에서 평평한 연결곡선 H=3x²−2x³다.

종이와 본문으로 직접 해보기

노드 0,1에서 값 1,4,도함수 2,2를 요구하는 3차 이하 p를 종이에 구하라.

힌트 보기

상수와 x 계수는 1,2다. 남은 계수 c,d에 c+d=1,2c+3d=0을 세운다.

풀이 보기

c=3,d=−2여서 p=1+2x+3x²−2x³다. p1=4이고 p′=2+6x−6x²의 양끝 값은 2다.

오해와 반례

Hermite 기본함수에서 도함수 값을 그대로 곱하면 모든 구간에 통한다.

구간 길이 h가 2이면 t 미분을 x 미분으로 바꿀 때 1/2가 생긴다. 도함수 계수에 h를 곱하지 않으면 요구 기울기의 절반을 만들므로 길이 보정이 필수다.

소단원 5.4

Runge 현상과 노드 선택

보간 점을 계속 늘리면 점 사이에서도 반드시 더 정확해질까?

준비 개념과 학습 목표

준비 개념

  • 노드는 다항식이 맞추는 입력 위치다.

  • 보간 오차는 노드 밖에서도 평가해야 한다.

학습 목표

  • 등간격 고차 보간의 위험을 설명한다.

  • 끝점에 모인 노드와 증거의 범위를 구별한다.

많은 조건이 정확도를 보장하지 않는 이유

Runge 현상은 등간격 노드의 전역 고차 다항식 보간에서 매끄러운 함수라도 특히 끝점 부근 오차가 커질 수 있는 현상이다. 모든 노드에서는 오차가 0이어도 그 사이의 진동이 커질 수 있으므로 점 일치만 검사해서는 전체 구간 근사를 판단할 수 없다.

이는 단지 부동소수점 반올림의 탓이 아니다. 정확한 산술로 정의한 보간다항식에서도 해당 노드열이 근사 오차를 잘 제어하지 못할 수 있다. 계산 알고리즘의 안정성과 보간 문제의 조건성, 차수를 늘릴 때의 수렴은 서로 관련되지만 같은 질문은 아니다.

오차곱과 끝점에 모인 노드

오차항에는 Π_i(x−x_i)가 들어가며 노드 선택이 그 크기를 바꾼다. [−1,1]에서 끝점 포함 Chebyshev 노드 x_k=−cos(kπ/n),k=0,…,n, n≥1은 가운데보다 끝점 근처에 조밀하다. 등간격 노드의 끝점 문제를 완화하는 대표 선택이다.

노드만 좋으면 매끄러움 조건 없이 모든 함수에서 같은 속도로 수렴한다는 보장은 없다. f의 성질과 오차를 측정하는 구간도 중요하다. 관측 위치를 마음대로 선택할 수 없는 실제 자료라면 노드 이동 대신 낮은 차수의 조각 근사 같은 대안도 고려한다.

작은 계산과 무한 차수 주장을 구별하기

f(x)=1/(1+25x²)를 세 노드에서 보간해 점 사이 큰 차이를 직접 볼 수 있다. 이 한 계산은 그 보간의 오차를 보여주지만 차수를 무한히 늘릴 때 발산한다는 증명이 아니다. Runge 현상의 일반적 설명은 공개 원문에 있는 노드열·고차 비교와 구분한다.

정확도를 확인할 때에는 노드 외의 점과 끝점 부근을 포함한 독립 평가 지점을 사용한다. 컴퓨터 그래프를 그리지 않았어도 표의 차이는 종이로 확인 가능하다. 이 본문은 손계산 사례를 제공하며 고차 실험이나 실제 수치 프로그램을 실행했다고 표시하지 않는다.

중간 과정을 따라가는 예제

f=1/(1+25x²)를 노드 −1,0,1에서 2차 이하로 보간하고 x=4/5의 오차를 구하라.

  1. 끝점 값은 1/26, 가운데는 1이다. 좌우 대칭인 유일 다항식은 p=1+ax² 형태다.

  2. p1=1/26에서 a=−25/26이므로 p=1−(25/26)x²다.

  3. x=4/5에서 p=1−(25/26)(16/25)=5/13이다. f=1/(1+16)=1/17이다.

  4. 차이는 5/13−1/17=(85−13)/221=72/221≈.326이다. 노드에서는 모두 오차 0이다.

점 사이에서 p가 f보다 약 .326 높다. 이 한 차수의 계산만으로 모든 고차 수렴을 판단하지 않는다.

종이와 본문으로 직접 해보기

n=4일 때 등간격 노드와 끝점 포함 Chebyshev 노드를 순서대로 적고 왼쪽 끝 첫 간격을 비교하라.

힌트 보기

cos(0),cos(π/4),cos(π/2),cos(3π/4),cos(π)를 쓴다.

풀이 보기

등간격은 −1,−.5,0,.5,1로 간격 .5다. Chebyshev는 −1,−√2/2,0,√2/2,1이고 첫 간격 1−√2/2≈.293으로 끝점에 더 가깝다. 이 간격 비교만으로 모든 함수의 오차 우열을 증명한 것은 아니다.

오해와 반례

Runge 현상은 컴퓨터 정밀도를 올리면 완전히 사라진다.

정확 산술에서도 등간격 전역 고차 보간 자체의 근사 문제가 남을 수 있다. 정밀도를 높여 계산 오차를 줄이는 것과 노드·근사 방식을 바꾸는 것은 다른 조치다.
