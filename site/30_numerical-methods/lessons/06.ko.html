소단원 6.1

구간별 다항식

표 전체를 높은 차수 한 개로 연결해야 할까?

준비 개념과 학습 목표

준비 개념

  • 선형 보간과 기울기

  • 매듭은 구간을 나누는 서로 다른 순서화된 x값이다.

학습 목표

  • 구간별 다항식을 접합한다.

  • 값 연속과 도함수 연속을 구별한다.

작은 구간마다 낮은 차수를 쓴다

매듭 t0<t1<…<tn 사이마다 별도의 다항식을 정한다. 구간 선형은 양 끝 자료를 잇는 직선이고 각 구간 기울기는(yi+1−yi)/(ti+1−ti)다. 순서와 양의 구간 길이가 있어야 분모가 0 이 아니다.

자체 자료(0,0),(1,2),(3,1)를 보면[0,1]의 p=2x,[1,3]의 p=2−(x−1)/2 다. 두 식은 x1 에서 모두 2 이므로 이어진다. 함수가 하나의 전역 직선이라는 뜻은 아니다.

연속과 매끄러움은 다른 조건이다

자료를 지나는 이 직선들은 값이 연결되지만 x1 의 왼쪽 기울기 2/오른쪽−1/2 가 달라 미분 불가다. C0 는 값 연속, C1 은 1 차 도함수도 연속, C2 는 2 차 도함수까지 연속이라는 표기다. 차수만 높여도 접합 조건이 자동 만족하지 않는다.

국소좌표 z=x−ti를 쓰면 구간식의 계수를 해당 매듭에서 설명하기 쉽다. 같은 x1 에서 양쪽 식이 다르게 나온다면 구간 끝 포함 정책으로 숨길 문제가 아니라 연결 조건 자체가 실패한 것이다.

hat 기저와 외삽 범위

매듭 i에서 1 이고 다른 매듭에서 0 인 모자 모양 H_i를 쓰면 p=ΣyiH_i다. 현재 구간에서는 두 이웃 H만 0 이 아니고 합 1 이라 값이 두 자료의 가중평균이다. 자체 x2 에서 H1=1/2,H2=1/2 로 p=3/2 다.

이 설명의 정의역은[0,3]이다. 밖에서 마지막 기울기로 연장하거나 0 으로 두는 것은 추가 외삽 정책이고 보간이 자동 정하지 않는다. 자료 변경은 이웃 두 구간 선형식에만 영향을 주며 전역 고차 보간과 달리 국소적이다.

중간 과정을 따라가는 예제

자체 자료의 p(1/2),p(2),접합값과 양쪽 기울기를 구하라.

  1. 첫 구간 p=2x이므로 p(.5)=1 이다.

  2. 둘째 구간 p=2−(x−1)/2 이므로 p(2)=1.5 다.

  3. x1 에서 양쪽 값 2 로 연속이다.

  4. 미분 기울기 2 와−.5 는 달라 x1 에서 미분 불가다.

값 1/1.5, 접합값 2, C0 지만 C1 이 아니다.

종이와 본문으로 직접 해보기

중간 y1 을 2 에서 4 로 바꾸면 새 두 기울기와 p(2)는? x4 값도 자동 정해지는가?

힌트 보기

각 구간의 새 자료 차이를 해당 길이로 나누어라.

풀이 보기

첫 기울기 4,둘째(1−4)/2=−1.5,p(2)=4−1.5=2.5 다. x4 는 정의역 밖이므로 외삽 정책 없이는 정하지 않는다.

오해와 반례

각 구간이 다항식이면 합친 함수는 반드시 미분 가능하다.

각 구간 직선은 매끄러워도 접합기울기 2 와−.5 가 다르면 전체 함수는 그 매듭에서 미분되지 않는다.

답과 이유 보기

구간 길이 0 이 분모에 생긴다.

x2 에서 두 hat 가중치는?

답과 이유 보기

1/2,1/2 다.

답과 이유 보기

한 단계 더

같은 자료의 전역 이차 q=ax²+bx+c를 풀어라. c=0, a+b=2, 9a+3b=1 에서 a=−5/6,b=17/6 이다. q(2)=7/3 이며 구간 선형의 3/2 와 다르다. 두 방법 모두 자료점은 지나지만 사이 모양은 다른 이유를 설명하라.

소단원 6.2

삼차 스플라인의 경계

값과 두 도함수를 연결해도 양 끝 조건이 더 필요할까?

준비 개념과 학습 목표

준비 개념

  • 삼차 다항식의 4 개 계수

  • C2 는 값·1 차·2 차 도함수가 연속이라는 뜻이다.

학습 목표

  • 삼차 스플라인의 경계 조건을 구별한다.

  • 작은 자연 스플라인을 계수로 직접 푼다.

구간 연결 뒤 남는 두 조건

n개 구간에 차수 3 이하 다항식의 계수 4n개를 둔다. 각 양 끝 보간 2n개와 내부 1 차/2 차 연결 각 n−1 개를 합하면 4n−2 개다. 경계 조건 두 개가 더 필요하다. 여기서는 서로 다른 증가 매듭과 실수 자료를 쓴다.

자연 경계는 바깥 두 끝의 S″=0,고정 기울기 경계는 S′를 두 끝에서 지정한다. not-a-knot은 첫/마지막 내부 매듭의 3 차까지 이어 같은 삼차 구간이 되도록 한다. 이 단원 예제는 자연 경계이며 원저자의 후속 not-a-knot 구현을 실행한 것이 아니다.

두 구간 자연 예제 직접 풀기

자체 자료(0,0),(1,1),(2,0)를 두 구간으로 잇는다. 왼쪽 S0=a+bx+cx²+dx³의 x0 값 0/자연 조건 S0″0=0 에서 a=c=0, x1 값 1 에서 b+d=1 이다. 대칭 자료와 자연 경계의 유일한 해는 오른쪽이 S0(2−x)인 모양이다.

이 대칭모형에서 x1 의 오른쪽 기울기는 왼쪽의 음수이므로 C1 조건은 S0′1=b+3d=0 이다. b+d=1 과 함께 d=−1/2,b=3/2 다. S0=(3x−x³)/2, S1=(3(2−x)−(2−x)³)/2 다. 두 식의 값을 넣어 모든 조건을 별도로 확인할 수 있다.

검산과 물리적 오해

x1 에서 양쪽 값 1,양쪽기울기 0,양쪽 2 차 도함수−3 이다. x0/x2 에서 2 차 도함수 0 으로 자연 경계를 만족한다. 하지만 3 차 도함수는 왼쪽−3/오른쪽 3 으로 달라 C3 은 아니다. 이름 삼차는 C3 연속이라는 의미가 아니다.

자연 경계가 실제 원함수의 끝 곡률 0 을 알아냈다는 뜻은 아니다. 자료 밖 외삽이나 물리적 경계 해석은 별도다. 같은 세 자료의 이차 x(2−x)는 끝 2 차 도함수−2 라 자연 조건을 만족하지 않고 다른 보간이다.

중간 과정을 따라가는 예제

자연 스플라인의 S(.5),S(1.5),접합도함수를 구하라.

  1. S0(.5)=(1.5−.125)/2=11/16 이다.

  2. 대칭 S1(1.5)=S0(.5)=11/16 이다.

  3. S0′=(3−3x²)/2,S0″=−3x라 x1 은 0/−3 이다.

  4. S1 에서 z=2−x로 미분하면 S1′=−(3−3z²)/2,S1″=−3z, x1 역시 0/−3 이다.

두 값 11/16, 접합 1 차 0/2 차−3, 끝 2 차 0.

종이와 본문으로 직접 해보기

자료 전체의 y를 2 배하면 자연 스플라인과 S(.5)는? S가 C3 인지 확인하라.

힌트 보기

풀이 보기

새 함수는 2S로 S(.5)=11/8 다. 원 S0‴=−3,S1‴=3 으로 다르므로 C3 이 아니다.

오해와 반례

삼차 스플라인은 3차 도함수까지 이어지고 자연 경계는 끝 기울기 0이다.

자연 경계는 2차 도함수 0이다. 이 예제의 끝 기울기는 ±3/2다. 내부는 C2이고, 양쪽 3차 도함수 −3과 3은 다르다.

한 단계 더

소단원 6.3

최소제곱 함수근사

자료를 모두 지나지 않아도 전체 오차가 더 작을 수 있을까?

준비 개념과 학습 목표

준비 개념

  • 벡터 내적과 잔차

  • 기저 함수는 고정하고 계수에 대해서만 선형인 모형을 쓴다.

학습 목표

  • 설계행렬과 잔차제곱합을 구성한다.

  • 최소제곱의 직교 조건과 보간의 차이를 확인한다.

기저의 계수에 대해 선형이다

q(x)=Σcjφj(x)에서 φ는 이미 정한 함수다. 자료점마다 행 Aij=φj(xi)를 만들면 예측 Ac,잔차 r=y−Ac다. 목적은 Σri²이며 모든 ri=0 을 강제하는 보간과 다르다. sin x 같은 비선형 함수도 계수만 선형이면 이 문제에 들어간다.

자체 자료 x=−1,0,1,y=1,0,2 와 모형 a+bx를 둔다. A의 행은(1,−1),(1,0),(1,1)이다. 미지수 2 개에 자료 3 개라 일반적으로 모든 값을 맞출 수 없다. 데이터 수가 많다는 사실만으로 열 독립이 자동 보장되지는 않는다.

직교 잔차로 최적점을 찾는다

목적 J=(y−Ac)ᵀ(y−Ac)를 계수로 미분하면 AᵀAc=Aᵀy다. 잔차 형태로 Aᵀr=0 이며 모든 계수방향에 더 움직여도 일차 오차 변화가 0 이라는 뜻이다. 열이 독립이면 AᵀA는 양의정부호라 해가 유일하다.

여기서 Σx=0,Σx²=2,Σy=3,Σxy=1 이다. 정상방정식은 3a=3,2b=1 로 a=1,b=1/2 다. 예측(.5,1,1.5),잔차(.5,−1,.5)이며합 0/x가중합 0 이다. 제곱합.25+1+.25=3/2 다.

목적함수 선택은 근사의 의미를 정한다

최적 잔차 r에 작은 계수변화 d를 주면 새제곱합||r−Ad||²=||r||²+||Ad||²이다. 교차항은 Aᵀr=0 으로 없어져 전역 최소를 확인한다. 서로 다른 계수라도 같은 Ac가 되면 계수유일성이 없어질 수 있다.

표본 최소제곱·구간 전체 적분제곱·최대절댓값오차는 다른 목적이다. 로그 y를 맞추면 원 y 오차제곱합과 같지 않다. 높은 차수를 쓰면 표본 잔차를 줄여도새 점의예측이나 잡음 억제를 보장하지 않는다. 이계산은정확한 분수 손풀이이며 실제 수치 알고리즘 안정성을 측정하지 않았다.

중간 과정을 따라가는 예제

위 자료의 직선 최소제곱 계수·잔차·J를 구하라.

  1. AᵀA=diag(3,2),Aᵀy=(3,1)다.

  2. a=1,b=1/2 로 q=(.5,1,1.5)다.

  3. r=(.5,−1,.5),Σr=0,Σxr=−.5+.5=0 다.

  4. J=3/2 이며 직교성이 모든 계수 변화에 대한 교차항을 없앤다.

q(x)=1+x/2, J=3/2. 모든 자료점을 지나지는 않는다.

종이와 본문으로 직접 해보기

상수만 쓰면 최적값과 제곱합은? 이차 보간과 비교하라.

힌트 보기

상수는 평균이다. 이차 q(x)=a x²+b x+c를 세 자료에 대입하라.

풀이 보기

상수 1 의 잔차 (0,−1,1), J=2다. 이차 q=3x²/2+x/2 는 세 점을 모두 맞춰 J=0이다. 이는 새 점 정확도나 잡음 제거의 우수함을 입증하지 않는다.

오해와 반례

최소제곱이면 잔차 하나하나가 0이고, 표본 오차 0인 함수는 항상 가장 좋은 함수다.

직선의 최적 잔차 (.5,−1,.5)는 0이 아니다. 높은 차수로 보간하여 J=0으로 만들 수 있지만, 원함수의 표본 밖 정확성과는 별개다.

소단원 6.4

Chebyshev 근사 입문

평균오차 대신 가장 큰 오차를 줄이려면 어떤 수를 고를까?

준비 개념과 학습 목표

준비 개념

  • cos 배각 공식

  • 최대절댓값오차는 구간의 가장 나쁜 오차 크기다.

학습 목표

  • Chebyshev 다항식의 삼각 표현·재귀·근을 설명한다.

  • 간단한 균등근사와 최소제곱 근사를 비교한다.

cos를 다항식으로 표현한다

Tn(cosθ)=cos(nθ)를 정의로 쓴다. T0=1,T1=x,T2=2x²−1 이다. cos 덧셈으로 Tn+1=2xTn−Tn−1 을 유도하면 삼각 표현이 실제 다항식임을 확인할 수 있다. 이 단원은 첫째종 T만 다룬다.

x∈[−1,1]은 cosθ로 표현되어 |Tn(x)|≤1이다. T2는 x=−1,0,1에서 1,−1,1로 교대한다. 범위 밖에서도 다항식은 정의되지만 |Tn|≤1을 확대하면 안 된다. T2(2)=7이다.

작은 최악 오차 근사 직접 증명

f(x)=x²를 [−1,1]에서 상수 c로 근사한다. f의 범위는 [0,1]이라 최대 오차는 max(|c|,|1−c|)다. 두 끝값에서 생기는 오차를 균형 있게 두면 c=1/2, 최대 오차1/2다. 어떤 c도 |c|+|1−c|≥1이라 이보다 작은 최대 오차를 얻지 못한다.

오차 x²−1/2=T2(x)/2는 끝1/2·가운데−1/2로 교대한다. 여기서는 특정 상수 근사 문제를 직접 증명했으며 모든 Chebyshev 계수 절단이 항상 정확한 최대 오차 최적해라는 주장은 하지 않는다. 함수와 차수와 구간이 달라지면 별도 문제다.

노드 선택과 목적 차이

Tn의 n개 근은 cos((2k−1)π/(2n)),k=1..n이다. n=2는 ±1/√2로 등간격 양 끝 노드와 다르다. Chebyshev 근 노드에서 보간하는 방법과 Chebyshev 기저로 근사하는 방법·최대 오차 최적화는 관련되지만 동일한 정의가 아니다.

같은 x²의 연속 무가중 최소제곱 상수는 평균 (1/2)∫−1¹x²dx=1/3이다. 최대 오차는2/3으로 최악 기준의 최적값1/2보다 크다. 반대로 적분 제곱 오차는 c=1/3이 작다. 무엇을 작게 하려는지 정하지 않으면 최고 근사를 비교할 수 없다.

중간 과정을 따라가는 예제

T2의 근과 x²의 최대 오차를 최소화하는 상수 근사 및 오차를 구하라.

  1. 2x²−1=0 에서 x=±1/√2 다.

  2. x²의 값 범위 [0,1]의 양 끝 오차 |c|, |1−c|를 동일하게 하려면 c=1/2다.

  3. 오차=T2/2이므로 [−1,1]에서 절댓값은 1/2 이하다.

  4. x=−1,0,1에서 오차는 1/2,−1/2,1/2로 최대 크기를 실제로 달성한다.

근±1/√2,상수 1/2,최대 오차 1/2.

종이와 본문으로 직접 해보기

상수 1/3과 1/2의 연속 적분 제곱 오차를 비교하라. T3을 재귀로 구하라.

힌트 보기

∫x⁴=2/5,∫x²=2/3,∫1=2 를 써서 J(c)=2/5−4c/3+2c²를 계산하라.

풀이 보기

J(1/3)=8/45,J(1/2)=7/30 이므로 최소제곱에서는 1/3이 좋다. T3=2x(2x²−1)−x=4x³−3x다.

오해와 반례

Chebyshev 노드 보간·기저 절단·최대 오차 근사는 같고 모든 목적의 최적 상수도 같다.

상수 1/2는 최대 오차를, 1/3은 무가중 적분 제곱 오차를 최소화한다. 노드와 기저는 구성 방식이며 최적성 주장은 따로 증명해야 한다.

한 단계 더

구간 [a,b], a<b를 ξ=(2x−a−b)/(b−a)로 [−1,1]에 옮겨 Tn(ξ)를 사용한다. [0,2]이면 ξ=x−1,T2의 근을 옮긴 노드는 1±1/√2 다. 양 끝 보장 범위와 원 좌표 노드를 검산하고 범위 밖 외삽 오차를 동일하게 보장하지 않는 이유를 써라.
