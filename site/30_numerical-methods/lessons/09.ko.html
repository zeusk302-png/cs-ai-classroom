소단원 9.1

피벗과 LU 분해

첫 번째 계수가 0이면 방정식을 풀 수 없다는 뜻일까?

준비 개념과 학습 목표

준비 개념

  • 행렬 곱과 연립방정식

  • 삼각행렬과 행 교환

학습 목표

  • 행 순열을 포함한 PA=LU를 확인한다.

  • 같은 순열을 오른쪽 항에 적용하여 두 삼각계를 푼다.

두 번째 열에서 행을 바꾸면 첫 열의 소거 기록도 바꿔야 할까?

소거를 장부라고 생각하자. U는 남은 방정식을, L은 이전 방정식을 얼마나 빼었는지 기록한다. 아직 처리하지 않은 방정식 두 개를 바꾸면 이미 기록한 배수도 해당 방정식을 따라 이동해야 한다.

자체 3×3 행렬에서 첫 피벗은 그대로지만 두 번째 피벗을 위해 행을 교환한다. 마지막에는 PA=LU와 원래 Ax=b를 둘 다 검산한다. 행을 교환하는 것은 미지수의 이름을 바꾸는 작업이 아니다.

먼저 확인할 개념
  • PA=LU의 순열 약속

    기본 본문에서 행 교환과 오른쪽 항의 이동을 먼저 확인한다.

  • 두 삼각계와 분해 재사용

    L·U가 해를 구하는 절차와 연결되는 이유를 확인한다.

소거 과정을 두 행렬에 보관하기

여러 방정식에서 같은 미지수를 제거하는 가우스 소거는 위쪽 삼각행렬 U를 만든다. 그때 사용한 배수를 아래쪽 삼각행렬 L에 저장하면 행렬의 곱으로 과정을 다시 확인할 수 있다. 여기서는 대각이 1인 L과 일반 대각의 U를 사용한다.

나눗셈의 분모인 피벗이 0이면 그 순서로 소거할 수 없다. 그렇다고 원래 행렬이 반드시 특이한 것은 아니다. [[0,2],[3,4]]는 행을 교환하면 첫 피벗 3을 사용해 풀 수 있다. 작은 피벗도 큰 소거 배수를 만들어 반올림 오차를 키울 수 있다.

부분 피벗과 순열의 의미

부분 피벗은 현재 처리하는 열에서 아직 처리하지 않은 행들의 계수 중 절댓값이 가장 큰 것을 피벗으로 선택한다. 원래 입력 열이 아니라 이전 소거가 반영된 현재 열을 본다. 동률이면 미리 정한 순서를 사용한다. 정확한 산술에서는 선택된 피벗에 대한 소거 배수의 절댓값이 1 이하이다.

행 교환을 나타내는 순열행렬을 P라고 하면 약속은 PA=LU이다. 따라서 Ax=b는 LUx=Pb로 바뀐다. 먼저 Ly=Pb를 앞에서 뒤로 풀고, 이어 Ux=y를 뒤에서 앞으로 푼다. P는 식의 순서를 바꾸므로 미지수 순서는 그대로 두고 b의 항을 같은 순서로 옮긴다.

분해와 검산을 구별하기

분해를 얻었다면 LU가 PA와 일치하는지, 구한 x가 원래 Ax=b를 만족하는지 각각 확인한다. 이 두 확인은 서로 다른 실수를 잡는다. b를 바꿀 때 A가 그대로이면 L·U·P를 재사용할 수 있다. A가 바뀌면 같은 분해를 무조건 재사용할 수 없다.

부분 피벗은 일반적으로 유용하지만 모든 입력에서 무조건 작은 오차를 보장하는 주문은 아니다. U의 원소가 크게 성장하는 예외와 문제 자체의 큰 조건수를 구별해야 한다. 정확한 산술의 0 피벗과 유한 정밀도에서 매우 작은 피벗을 판단하는 기준도 같지 않다.

중간 과정을 따라가는 예제

자체 행렬 A=[[1,2],[4,5]], b=(5,14)ᵀ에 부분 피벗 LU를 사용하라. 계산은 정확한 분수로 한다.

  1. 첫 열의 절댓값은 1과 4이다. 행을 교환해 PA=[[4,5],[1,2]], Pb=(14,5)ᵀ를 얻는다.

  2. 소거 배수는 1/4이다. L=[[1,0],[1/4,1]], U=[[4,5],[0,3/4]]이며 LU의 둘째 행은 (1,2)이다.

  3. Ly=Pb에서 y₁=14, y₂=5−14/4=3/2이다. Ux=y에서 x₂=(3/2)/(3/4)=2, x₁=(14−10)/4=1이다.

  4. 원래 식에 대입하면 Ax=(1+4,4+10)ᵀ=(5,14)ᵀ이므로 잔차가 0이다.

x=(1,2)ᵀ이다. 순열은 오른쪽 항에도 적용했다.

조건을 바꾸어 비교하기

늦은 행 교환까지 분해하기

위 A의 부분 피벗 PA=LU를 완성하라.

  1. 첫 소거 뒤 둘째 행은 (0,1/2,1), 셋째 행은 (0,11/4,1)이다.

  2. 둘째·셋째 행을 바꾼다. L의 첫 열 배수는 1/4,1/2 순서가 된다.

  3. L=[[1,0,0],[1/4,1,0],[1/2,2/11,1]], U=[[4,1,0],[0,11/4,1],[0,0,9/11]]이다.

  4. LU의 행은 (4,1,0),(1,3,1),(2,1,1)이라 PA와 같다.

P는 원래 행을 1,3,2 순서로 옮긴다.

비교할 점

원래 A의 둘째 열 최댓값만 미리 고르는 방식은 현재 소거 열의 선택과 다르다.

같은 인자로 오른쪽 항 풀기

b=(6,7,10)ᵀ를 위 인자로 풀어라.

  1. Pb=(6,10,7)ᵀ이다.

  2. 전진 대입에서 y₁ = 6, y₂ = 10 − 6/4 = 17/2, y₃ = 7 − 3 − (2/11)(17/2) = 27/11이다.

  3. 후진 대입에서 x₃ = 3, x₂ = 2, x₁ = 1이다.

  4. 원래 Ax=(6,7,10)ᵀ를 확인한다.

Pb를 만들 때 x의 성분을 교환하면 원래 열 순서를 훼손한다.

힌트 보기

첫 경우 Pb=(4,1)ᵀ이다. 잘못된 경우는 Ly=(5,14)ᵀ를 풀어 보라.

풀이 보기

오해와 반례

피벗이 0이면 항상 해가 없다.

해가 없는지, 여러 개인지, 유일한지는 전체 계와 오른쪽 항으로 판단한다. [[0,2],[3,4]]처럼 가역인 행렬도 첫 피벗은 0일 수 있다. 행 교환을 시도한 뒤 남은 열 전체가 0인 상황은 별도 rank 분석이 필요하다.

선택 심화는 기본 연습 뒤 더 탐구하고 싶을 때 풀어 보세요.

Cε=[[ε,1],[1,1]],0<ε<1에서 교환 전후 배수를 구하고 ε→1일 때의 문제를 설명하라.

힌트 1

교환 전 첫 피벗 ε이다.

힌트 2

교환 후 U22=1−ε이고 det(Cε)=ε−1이다.

풀이와 답 확인

  1. 교환 전 배수 1/ε, 교환 후 ε이다.

  2. 교환 후 U22=1−ε는 ε→1에서 작아진다.

  3. ε=1이면 두 행이 같아 특이하다. 작은 배수만으로 조건 문제가 사라지지 않는다.

부분 피벗은 큰 소거 배수를 피하지만 원래 문제의 특이성 접근을 없애지 않는다.

흔한 오답에서 다시 생각하기

배수가 1 이하이면 해 오차가 항상 작다.

성장과 조건수는 별도다. ε→1에서 가역성 자체가 한계에 접근한다.

A=[[ε,1],[1,1]], 0<ε<1을 비교하라. 행 교환이 없으면 배수 1/ε와 두 번째 피벗 1−1/ε가 생긴다. 교환하면 배수 ε와 피벗 1−ε가 된다. ε=1/100에서 100과 1/100의 차이를 손으로 확인하되, 실제 부동소수점 실행 결과로 기록하지 않는다.

준비 개념

  • 이차형식과 양수

학습 목표

  • A=CCᵀ로 분해하고 두 삼각 대입을 수행한다.

양의 대각만 보고 분해를 선택하면 어떤 행렬을 놓칠까?

자체 행렬 A=[[4,−2],[−2,10]]의 이차형식은 (2u−v)²+9v²다. 비영벡터에서 양수가 된다는 이유를 식의 구조로 읽어 보자. 대각의 부호만 보는 것보다 강한 조건이다.

Cholesky의 아래 인자 C는 대각이 2,3이다. LU의 대각 1 약속과 구분하고 전치된 두 번째 삼각계를 풀어야 한다. 조건을 바꾸면 양의 준정부호·부정부호·비대칭 입력이 서로 다른 이유로 제외된다.

대칭과 양의 정부호를 함께 요구하기

실수 정방행렬 A가 Aᵀ=A이면 대칭이다. 여기에 모든 비영벡터 z에 대해 zᵀAz>0이면 대칭 양의 정부호, 줄여서 SPD라고 한다. z=0에서는 이차형식도 0이므로 정의에서 제외한다. 대각 원소가 양수라는 사실만으로 SPD를 결론 낼 수는 없다.

Cholesky 분해는 SPD 행렬을 A=CCᵀ로 표현하며 C는 양의 대각을 가진 아래쪽 삼각행렬이다. 위쪽 삼각행렬 R=Cᵀ를 써서 A=RᵀR로 쓰는 자료도 있다. C의 대각을 모두 1로 정하는 LU 약속과 혼동하지 않는다.

행렬 곱에서 계산식을 얻기

2×2 대칭행렬 [[a,b],[b,d]]에 C=[[c₁₁,0],[c₂₁,c₂₂]]를 넣으면 c₁₁=√a, c₂₁=b/c₁₁, c₂₂=√(d−c₂₁²)이다. SPD 조건은 a>0이고 d−b²/a>0이라는 형태로 나타난다. 제곱근 안이 0이면 양의 대각의 이 분해는 완성되지 않는다.

큰 행렬도 이전 열의 곱을 빼고 대각에서는 양의 제곱근을 취한다. 대칭 구조 덕분에 일반 밀집 LU보다 분해의 대표 연산량이 작다. 분해 뒤에는 Cy=b를 전진 대입하고 Cᵀx=y를 후진 대입한다. 예제에서는 실제 라이브러리 호출 대신 이 식을 직접 계산한다.

구조를 쓰되 성공 범위를 확인하기

정확한 산술에서 SPD 행렬에는 이런 분해가 존재한다. 표준 Cholesky의 수치 안정성도 이 조건에 기대며 일반적인 행 교환이 필요하지 않다. 그러나 반올림된 입력이 거의 특이하거나 더 이상 SPD가 아니면 실패할 수 있다. 실패는 단순히 계산기를 다시 누를 문제라고 보지 않는다.

대칭이라는 이유만으로 SPD라고 간주하거나 한 삼각부분만 읽는 프로그램을 호출하고 대칭성까지 검증됐다고 말하지 않는다. 입력 구조 확인, 분해 재구성, 원래 계의 잔차는 따로 점검한다. 양의 준정부호와 부정부호에는 다른 처리가 필요하다.

자체 A=[[9,3],[3,5]], b=(15,13)ᵀ를 Cholesky로 풀고 SPD도 확인하라.

A와 b=(6,−12)ᵀ를 Cholesky로 풀어라.

  1. 인자의 성분은 c₁₁ = 2, c₂₁ = −1, c₂₂ = √(10 − 1) = 3이다.

  2. Cy = b를 풀면 y₁ = 3, y₂ = (−12 + 3)/3 = −3이다.

  3. Cᵀx = y를 풀면 x₂ = −1이다. 이어 2x₁ − x₂ = 3에서 x₁ = 1을 얻는다.

비대각이 음수라는 이유만으로 SPD를 배제하지 않는다.

행렬군의 정확한 경계

Aτ=[[4,−2],[−2,τ]]에서 SPD 조건을 구하라.

  1. 이차형식은 (2u−v)²+(τ−1)v²이다.

  2. τ>1이면 비영벡터에서 양수이고 c22=√(τ−1)>0이다.

  3. τ=1이면 (1,2)에서 0,τ<1이면 같은 벡터에서 4(τ−1)<0이다.

SPD는 τ>1이다.

정확한 조건과 반올림된 입력에서 수치 판정의 신뢰도는 구별한다.

힌트 보기

풀이 보기

Cy=b는 y=(2,4)ᵀ이고 Cᵀx=y는 x=(0,2)ᵀ이다. B는 두 번째 제곱근 안이 1−1=0이다. zᵀBz=0인 비영벡터가 있으므로 SPD가 아닌 양의 준정부호이다. 양의 대각을 요구하는 표준 Cholesky는 완료되지 않는다.

오해와 반례

대칭이고 대각이 양수이면 Cholesky가 반드시 성공한다.

[[1,2],[2,1]]은 대칭이고 대각이 양수지만 z=(1,−1)ᵀ에서 zᵀAz=−2이다. 두 번째 제곱근 안도 1−4=−3이다. 대칭과 양의 정부호는 별도의 조건이다.

같은 상대 잔차가 나오면 두 답의 정확도도 같을까?

가역 A=diag(2,1/50),b=(2,1/50)ᵀ의 정확한 해는 (1,1)ᵀ다. 두 번째 성분의 작은 계수 때문에 그 방향의 큰 해 오차가 작은 잔차로 보인다.

무한대 노름은 가장 큰 성분을 사용한다. 같은 노름에서 조건수 100을 계산하고 상계와 실제 오차를 구분한다. 또한 각 성분의 규모를 따로 보면 전체 최대값에 가려진 오차를 찾을 수 있다.

먼저 확인할 개념
  • 잔차 부호와 조건수 상계

    r=b−Ax̂와 x−x̂=A⁻¹r을 기본 본문에서 확인한다.

  • 구조에 맞는 안정성

    분해 안정성과 입력 조건의 역할을 구분하는 비교를 제공한다.

모르는 해 대신 식의 어긋남을 보기

Ax=b의 정확한 해 x를 모르는 경우에도 근삿값 x̂를 원래 식에 넣을 수 있다. 잔차는 r=b−Ax̂이다. 이 정의의 부호를 일관되게 사용하면 Ax̂=b−r이므로 x̂는 오른쪽 항을 −r만큼 바꾼 문제의 정확한 해다. 이것은 A를 고정한 후방오차 해석이다.

가역 A에서 x−x̂=A⁻¹r이다. 따라서 잔차와 해 오차는 일반적으로 같은 벡터가 아니다. 원래 입력 단위가 바뀌어 A와 b를 같은 상수로 곱하면 원래 해는 같아도 잔차의 절대 크기는 바뀐다. 절대 잔차만으로 다른 문제의 품질을 비교하면 곤란하다.

조건수가 잔차와 오차 사이를 연결하기

유도 행렬노름을 쓰고 b≠0이면 ||x−x̂||/||x||≤κ(A)||r||/||b||이며 κ(A)=||A||||A⁻¹||이다. 이 상계는 A 고정의 잔차에 적용한다. b=0이면 이 상대 잔차의 분모가 0이므로 같은 표현을 사용하지 않는다.

여기서는 벡터 무한대 노름, 즉 성분 절댓값의 최댓값을 쓴다. 대응하는 행렬 무한대 노름은 각 행의 절댓값 합 중 최댓값이다. 큰 조건수는 작은 잔차라도 해 오차가 커질 수 있다는 경고다. 상계가 크다는 사실만으로 실제 오차가 반드시 그 크기라는 뜻은 아니다.

알고리즘의 안정성과 한 결과의 잔차

후방안정성은 계산 결과를 입력에 아주 작은 상대 변화가 있는 문제의 정확한 해로 설명할 수 있다는 알고리즘의 성질이다. 한 답에서 잔차가 작았다고 해서 모든 입력에 대한 알고리즘 안정성을 증명한 것은 아니다. A도 바뀌는 모형과 A를 고정하는 잔차 해석은 구분한다.

부분 피벗 LU에서는 성장인자가 큰 예외를 살피고, SPD의 표준 Cholesky는 구조에 맞는 안정적인 방법이다. 이미 얻은 분해로 Ad=r을 풀어 x̂+d를 만드는 반복개선을 생각할 수 있다. 실제 성공과 정밀도는 잔차 계산, 조건수, 근사 풀이의 정확도에 달리며 여기서는 정확한 종이 계산만 한다.

준비 개념과 학습 목표

준비 개념

같은 행렬로 많은 질문을 풀 때 무엇을 저장해야 할까?

자체 A=[[3,1],[1,1]]를 한 번 분해한 뒤 여러 b에 적용해 보자. 식 x=A⁻¹b는 해를 표현하지만 실제 출력이 벡터이면 모든 역행렬 원소를 미리 만들 필요는 없다.

  • 원래 입력으로 잔차 검사

수학적 표현과 계산 절차

가역 A에 대해 x=A⁻¹b는 올바른 해의 표현이다. 그러나 실제 필요한 출력이 한 벡터 x라면 역행렬의 모든 원소를 먼저 구할 이유가 없다. PA=LU를 구하고 두 삼각 대입을 하면 필요한 답만 얻는다.

역행렬의 j번째 열은 Azⱼ=eⱼ의 해이다. 따라서 A⁻¹ 전체를 만드는 일은 n개의 특별한 오른쪽 항을 푸는 일이다. n×n개의 결과를 보관해야 하며, 곱해서 다시 한 벡터를 만드는 단계도 추가된다. 수식에 역기호가 있다는 사실은 구현에서 역행렬 배열을 요구하지 않는다.

여러 오른쪽 항도 분해로 처리하기

A가 그대로인 m개의 문제에서는 한 번 분해하고 오른쪽 항마다 삼각 대입을 한다. 일반 밀집 행렬의 대표 규모는 분해 O(n³), 한 쌍의 대입 O(n²)이므로 전체는 O(n³+mn²)이다. 이 설명은 희소 구조, 병렬 구현, 하드웨어 시간을 포함한 실측 결과가 아니다.

역행렬을 먼저 만드는 방법도 큰 차수로는 O(n³)일 수 있다. 그러므로 직접 풀면 차수가 무조건 한 단계 낮아진다는 주장도 틀리다. 한 번만 필요한 해를 위해 여러 열을 계산하는 추가 작업과 저장, 반올림 과정이 문제다. 실제 수치 정밀도는 입력과 구현으로 확인해야 한다.

결과의 필요성과 검산을 기준으로 선택하기

요청 자체가 역행렬의 원소를 분석하는 것이라면 역행렬이 출력일 수 있다. 그런 경우에도 필요성과 크기·정확도를 설명한다. 단순한 선형계 해결에는 검증된 풀이 함수나 구조에 맞는 분해를 우선 선택하고, 결과의 잔차를 원래 A,b로 검사한다.

가역성은 계속 전제이다. 특이행렬에 역행렬을 호출해서 없는 해를 만들어 낼 수는 없다. 최소제곱이나 일반화 역은 다른 목표와 조건을 가진 다음 주제다. 여기서는 모든 계산을 정확한 분수로 해서 두 방법이 같은 수학적 해를 주는지 비교한다.

항목계산 또는 조건점검 의미

b=(8,4)

정확 시간의 실측이 아님

삼각계 한 회와 앞뒤 한 쌍을 구별한다. 역행렬 두 열을 얻은 뒤에도 새 b마다 곱 단계가 추가된다.

중간 과정을 따라가는 예제

자체 A=[[2,1],[1,1]], b=(7,4)ᵀ을 LU로 풀고, 역행렬의 두 열도 별도로 구해 비교하라.

  1. A=LU에서 L=[[1,0],[1/2,1]], U=[[2,1],[0,1/2]]이다. Ly=b는 y=(7,1/2)ᵀ, Ux=y는 x=(3,1)ᵀ을 준다.

  2. 첫 열은 Az₁=(1,0)ᵀ를 푼다. y=(1,−1/2)ᵀ이므로 z₁=(1,−1)ᵀ이다. 둘째 열은 Az₂=(0,1)ᵀ를 풀어 y=(0,1)ᵀ, z₂=(−1,2)ᵀ를 얻는다.

  3. A⁻¹=[[1,−1],[−1,2]]이고 A A⁻¹=I이다. A⁻¹b=(7−4,−7+8)ᵀ=(3,1)ᵀ이다.

  4. 원래 A에 x를 넣으면 (6+1,3+1)ᵀ=(7,4)ᵀ이다. 첫 경로는 한 오른쪽 항, 역행렬 경로는 두 단위 오른쪽 항을 추가로 계산했다.

두 방법의 정확한 해는 같지만, 역행렬 경로는 필요하지 않았던 열도 만든다.

조건을 바꾸어 비교하기

필요한 한 답과 불필요한 두 열

A,b=(8,4)ᵀ의 직접 풀이와 역행렬 표현을 비교하라.

  1. Ly = b를 풀면 y₁ = 8, y₂ = 4 − 8/3 = 4/3이다.

  2. Ux = y를 풀면 x₂ = 2, x₁ = 2이다.

  3. 역행렬은 [[1/2,−1/2],[−1/2,3/2]]이며 곱은 (4−2,−4+6)=(2,2)다.

  4. 직접 경로는 필요한 오른쪽 항을, 역행렬 구성은 두 단위 오른쪽 항을 푼다.

정확한 해는 같지만 요구한 출력에 따라 필요한 중간 계산이 다르다.

종이와 본문으로 직접 해보기

같은 A에 새 오른쪽 항 b=(1,0)ᵀ가 왔다. 기존 L,U를 사용하여 풀고, A 대신 B=[[1,2],[2,4]]를 넣으면 무엇이 달라지는지 설명하라.

힌트 보기

풀이 보기

오해와 반례

오른쪽 항이 많으면 반드시 역행렬을 저장해야 한다.

같은 A의 LU 인자를 보관하고 각 오른쪽 항을 대입하면 된다. 역행렬의 필요성은 출력 목적과 구현 조건으로 판단한다. 이론의 A⁻¹b와 실제로 역행렬을 구성하는 비용은 다르며, 어느 방법이 항상 모든 입력에서 더 정확하다고 단정하지 않는다.

  2. m=n이면 O(n³+n³)=O(n³)이다.

다른 문제에 적용하기

서비스가 Aτ=[[4,−2],[−2,τ]]의 같은 행렬로 두 오른쪽 항 (6,−12),(−2,10)을 받는다. τ=10에서 분해 선택·재사용·두 답·검산을 설계하라. 다음 요청에서 τ=1 또는 τ=1/2로 바뀌면 같은 선택과 캐시를 쓸 수 있는가? 실제 시간이나 학생 성공을 추정하지 말고 계약과 실패 이유를 설명하라.

힌트 1

τ=10에서는 C=[[2,0],[−1,3]]이며 두 답을 본문의 계산과 연결한다.

힌트 2

τ = 1에서는 행렬이 양의 준정부호이면서 특이하다. τ = 1/2에서는 부정부호이지만 가역이다.

풀이와 답 확인

  1. τ=10은 SPD라 양의 대각 Cholesky를 선택할 수 있다. C를 한 번 구하고 각 b마다 두 삼각계를 푼다.

  2. 두 답은 (1,−1),(0,1)이며 각각 A10에 곱하면 요청 b다.

  3. τ = 1에서는 둘째 행이 첫째 행의 −1/2배이므로 오른쪽 항도 b₂ = −b₁/2를 만족해야 한다. 첫 요청 (6, −12)에는 둘째 성분 −3이 필요하지만 실제 값은 −12다. 둘째 요청 (−2, 10)에는 둘째 성분 1이 필요하지만 실제 값은 10이다. 따라서 두 요청 모두 해가 없다.

  4. τ=1/2는 det=−2라 가역이지만 SPD가 아니므로 표준 Cholesky 계약에서 제외한다. 일반 피벗 LU 같은 가역 계 풀이로 전환할 수 있다.

  5. 행렬이 바뀌었으므로 τ=10 인자를 재사용하지 않는다. 새 계의 구조·분해·잔차를 새로 검증한다.

τ = 10에서는 Cholesky 분해 1회와 두 오른쪽 항의 삼각 대입으로 처리한다. τ = 1에서는 두 지정 오른쪽 항 모두 일치 조건을 어긴다. τ = 1/2에서는 가역 일반 계 풀이가 필요하다. 변경된 계에 기존 인자를 무조건 재사용하면 실패한다.
