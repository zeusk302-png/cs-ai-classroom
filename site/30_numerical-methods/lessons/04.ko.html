소단원 4.1

Jacobian과 Newton 단계

두 식을 동시에 맞추려면 두 변수를 어느 방향으로 바꿀까?

준비 개념과 학습 목표

준비 개념

  • 벡터 (x,y)는 두 수를 순서대로 모은 것이다.

  • 편미분은 다른 변수를 고정하고 한 변수만 바꿀 때의 변화율이다.

  • 행렬과 벡터의 곱은 각 행과 벡터의 곱의 합으로 계산한다.

학습 목표

  • Jacobian 의 행과 열을 식·변수에 연결한다.

  • Newton 이동량을 선형 연립방정식으로 구하고 원래 식에 재대입한다.

두 잔차와 네 변화율

F(x,y)=(F₁(x,y),F₂(x,y))=0 은 두 식 모두 0 이라는 조건이다. 함수가 두 변수 근방에서 미분가능하면 작은 이동 s=(sₓ,sᵧ)에 대해 F(z+s)≈F(z)+J(z)s 를 쓸 수 있다. z 는 현재 (x,y)이고 J 는 국소 변화를 모은 Jacobian 이다. 충분히 연속인 이계미분을 가지면 생략 오차는 작은 s 에 대해 O(||s||²)로 제어할 수 있다.

J 의 첫 행은 F₁의 x,y 편미분, 둘째 행은 F₂의 x,y 편미분이다. 따라서 Jᵢⱼ=∂Fᵢ/∂zⱼ다. F₁=x²+y−3, F₂=x+y−2 이면 J=[[2x,1],[1,1]]이다. 행을 변수, 열을 식으로 뒤집으면 같은 이동을 계산하는 행렬이 아니다.

선형 모형만 먼저 0 으로 만든다

선형 모형 F(z)+J(z)s 를 0 으로 두면 J(z)s=−F(z)를 얻는다. 이 식을 소거법 등으로 풀고 새 후보 z+s 를 만든다. 역행렬 표기는 이론상 가능하지만 실제 계산에서는 역행렬 전체를 만드는 대신 선형계를 푸는 것이 기본이다. 여러 변수의 F 를 좌표별로 나누는 것은 행렬 결합을 없애므로 일반적인 Newton 방법이 아니다.

정방 Jacobian 이 가역이면 단계 s 는 유일하다. 특이하면 단계가 없거나 여러 개일 수 있다. 이것은 원래 비선형 방정식의 해가 없다는 증명이 아니다. 선형계의 해 존재와 원래 식의 해 존재는 서로 다른 질문이다.

이동 뒤 원래 식을 다시 읽는다

J 와 F 는 현재 위치에서 평가한다. 새 후보를 만든 뒤 다시 F 를 계산해야 한다. 선형 모형이 0 이어도 생략한 곡률 때문에 원래 잔차가 0 일 필요는 없다. 반복마다 달라지는 Jacobian 을 오래된 값으로 고정하면 다른 방법이 된다.

F 가 선형이면 곡률 생략항이 사라져 가역 행렬에서 한 단계가 정확한 해를 준다. 비선형에서 빠른 국소수렴은 충분한 매끄러움과 해 근방의 가역성, 충분히 가까운 초기값 같은 조건에 의존한다. 두 번 계산한 결과가 그럴듯하다는 사실만으로 전역수렴을 주장하지 않는다.

중간 과정을 따라가는 예제

F=(x²+y−3,x+y−2), z₀=(2,0)에서 한 Newton 단계와 새 잔차를 구하라. 모든 수는 무차원이다.

  1. F(2,0)=(1,0), J(2,0)=[[4,1],[1,1]]이다.

  2. 4sₓ+sᵧ=−1, sₓ+sᵧ=0 이다. 둘째 식을 첫째에서 빼면 3sₓ=−1 이다.

  3. sₓ=−1/3, sᵧ=1/3 이며 새 후보는 (5/3,1/3)이다.

  4. 원래 첫 식은 25/9+1/3−3=1/9, 둘째는 5/3+1/3−2=0 이다.

  5. 선형 모형은 정확히 0 이지만 원래 잔차 (1/9,0)는 남는다. det J=3 이라 이 단계는 유일하다.

s=(−1/3,1/3), z₁=(5/3,1/3), F(z₁)=(1/9,0)이다.

종이와 본문으로 직접 해보기

같은 F 에서 z=(0,2)의 J 와 F 를 구하고 한 단계를 계산하라. 후보의 원래 잔차도 확인하라.

힌트 보기

첫 행은 [0,1]이고 F=(−1,0)이다. 선형계의 둘째 식은 sₓ+sᵧ=0 이다.

풀이 보기

sᵧ=1, sₓ=−1 이므로 후보 (−1,3)이다. F=(1,0)으로 잔차 크기는 이전과 같다. det J=−1 이므로 가역인 단계가 반드시 잔차를 줄이는 것은 아니다.

오해와 반례

Jacobian 이 가역이면 한 단계 뒤 원래 잔차가 항상 0 이다.

(2,0)에서 선형계는 유일하게 풀려도 원래 잔차 1/9 가 남는 것이 반례다. 가역성은 선형 단계의 유일성이고 비선형 곡률은 별도로 남는다.

자기점검

J 의 두 번째 열은 무엇인가?

답과 이유 보기

각 식을 y 로 편미분한 값이다.

열은 변경 변수, 행은 출력 식이다.

J s=F 를 풀면 같은 Newton 단계인가?

답과 이유 보기

아니다.

선형 모형을 0 으로 만들려면 우변은 −F 다.

J 가 특이면 비선형 해도 없는가?

답과 이유 보기

그렇지 않다.

F=(x²,y)는 (0,0)에 해가 있지만 그곳 J 는 특이하다.

한 단계 더

일반 F=(x²+y−3,x+y−2)의 Newton 이동은 x≠1/2 일 때 정의된다. det J=2x−1 을 구하고 x=1/2 에서 y=3/2 를 넣어 보라. F₁=−5/4,F₂=0 이고 같은 두 행에 서로 다른 우변이 요구되어 단계가 없다. 원래 해는 다음 소단원에서 따로 구한다.

소단원 4.2

감쇠와 초기값

크게 한 번 움직이는 대신 조금만 움직이면 언제 도움이 될까?

준비 개념과 학습 목표

준비 개념

  • 이동 s 에 α를 곱하면 α=1 은 전부, α=1/2 는 절반이다.

  • ||F||₂는 각 잔차 제곱합의 제곱근이다.

  • 한 번 수락한 후보와 수락 전에 시험한 후보를 구분한다.

학습 목표

  • 감쇠 Newton 의 후보·수락·거절을 설명한다.

  • 잔차 감소를 확인해도 모든 문제의 해 발견은 보장되지 않음을 구별한다.

같은 방향의 다른 거리

감쇠 Newton 은 먼저 J s=−F 를 풀고 z+αs, 0<α≤1 을 후보로 시험한다. 방향과 거리를 나누는 방식이다. 큰 단계가 국소 선형 모형의 유효 범위를 벗어나면 절반 단계가 더 좋은 후보일 수 있다. 정의역 밖 후보는 원래 함수 평가가 불가능하므로 잔차 감소 비교 전에 제외해야 한다.

여기서는 자체 규칙으로 α=1 부터 시작해 잔차 제곱합이 엄밀히 감소하면 수락하고 아니면 α를 절반으로 줄인다. 실제 솔버는 충분감소율·최소 단계·반복제한 등을 더 정한다. 이 간단한 규칙을 특정 라이브러리의 구현과 동일하다고 주장하지 않는다.

잔차 목적의 내려가는 방향

Φ(z)=||F(z)||₂²/2 이면 미분가능한 곳에서 ∇Φ=JᵀF 다. 정확한 Newton 단계가 J s=−F 를 만족하면 ∇Φᵀs=FᵀJ s=−||F||₂²다. F≠0 이면 음수여서 정의역 내부에서 충분히 작은 양의 α는 Φ를 줄인다. 이는 현재 정확한 단계·미분가능성에 대한 국소 주장이다.

근사 Jacobian 과 부정확한 선형계 해는 위 등식을 깨뜨릴 수 있다. 또 F≠0 인데 JᵀF=0 이면 잔차 목적의 정지점일 수 있다. 잔차를 최소화하는 모든 점이 잔차 0 인 해라는 뜻은 아니다. 감쇠는 특이 Jacobian 을 자동으로 가역으로 만들지 않는다.

초기값과 다른 안정화 방법

초기값은 여러 해 중 어느 해로 가는지 또는 실패하는지를 바꿀 수 있다. 변수·식의 단위와 가능한 범위에 맞게 정하고, 서로 다른 합리적 시작값에서 원래 잔차와 조건을 확인한다. 유한한 몇 시작값 시험은 모든 초기값의 수렴 증명이 아니다.

Levenberg 는 (JᵀJ+λI)s=−JᵀF 처럼 단계 자체를 변경하며 λ>0 을 써서 조정한다. α 감쇠는 이미 구한 방향의 길이를 줄이므로 같은 연산이 아니다. FNC 원저자 자료의 제안 수락/거절 원리를 참고하지만 여기의 예는 별도 α 규칙이다. 두 방법 모두 실제 데이터에서 성공했다는 증거는 이 종이 계산에 없다.

중간 과정을 따라가는 예제

F=(x²−1,y), z=(1/4,0)에서 Newton 방향을 구하고 α=1,1/2 후보의 잔차 크기를 비교하라.

  1. F=(−15/16,0), J=diag(1/2,1)이다. 따라서 s=(15/8,0)이다.

  2. α=1 후보 x=1/4+15/8=17/8 이다. 잔차 첫 성분은 289/64−1=225/64 이다.

  3. 이전 잔차 절댓값은 15/16=60/64 다. 225/64 는 커서 이 규칙으로 거절한다.

  4. α=1/2 후보 x=1/4+15/16=19/16 이다. 잔차는 361/256−1=105/256 이다.

  5. 이전 15/16=240/256 보다 작아 절반 후보를 수락한다. 두 후보에서 y 는 0 이다.

전부 단계는 잔차 225/64 로 증가해 거절, 절반은 105/256 로 감소해 수락한다.

종이와 본문으로 직접 해보기

같은 시작점에서 α=1/4 후보의 x 와 잔차를 구하라. 절반보다 더 작은 α가 항상 더 큰 개선을 주는가?

힌트 보기

x=1/4+15/32=23/32 다. 잔차 절댓값에서 부호와 크기를 분리하라.

풀이 보기

잔차는 529/1024−1=−495/1024, 크기 495/1024 다. 이전보다 작지만 절반 후보의 105/256=420/1024 보다 크다. 더 작은 단계가 항상 더 좋은 잔차를 주지는 않는다.

오해와 반례

α를 아주 작게 잡으면 어떤 비선형 문제든 해로 수렴한다.

F=(x²+1,y)는 실수 해가 없다. z=(0,0)에서 J 는 특이하고 Φ의 기울기는 0 인데 F=(1,0)이다. 감쇠로 해 존재나 모든 초기값 성공을 만들 수 없다.

자기점검

거절한 후보로 현재점을 바꾸는가?

답과 이유 보기

여기의 규칙에서는 바꾸지 않는다.

수락할 α를 찾기 전 현재점과 방향을 유지한다.

Levenberg λ와 감쇠 α는 같은 변수인가?

답과 이유 보기

아니다.

λ는 선형계의 행렬, α는 구한 단계의 길이에 관여한다.

F≠0 이고 정확한 단계면 ∇Φᵀs 는?

답과 이유 보기

−||F||₂²<0 이다.

J s=−F 를 Φ의 방향미분에 대입한다.

한 단계 더

잔차 충분감소를 Φ(z+αs)≤Φ(z)+cα∇Φᵀs, 0<c<1 로 더 엄격하게 정할 수 있다. 위 국소 방향미분과 정의역 내부 조건을 이용해 작은 α에서 왜 성립하는지 설명하라. 이는 Armijo 형태의 수학 조건이며 이 원고에서는 실제 탐색 코드나 최적 c 를 시험하지 않는다.

소단원 4.3

비선형 잔차

화면의 오차 숫자가 작으면 입력도 실제 해에 가까운 것일까?

준비 개념과 학습 목표

준비 개념

  • 잔차 r=F(z)는 원래 식에 후보를 넣어 남는 출력이다.

  • 입력 오차 z−z*는 참해를 알아야 직접 계산할 수 있다.

  • 방정식의 한 행에 상수를 곱해도 영점은 같지만 잔차 수치는 달라진다.

학습 목표

  • 잔차와 해의 오차 및 단계의 크기를 구별한다.

  • 척도·원래 식·정의역을 포함하는 검산 기준을 만든다.

영점과 잔차의 의미

잔차 벡터는 모든 식을 동시에 조사한다. ||r||∞=maxᵢ|rᵢ|는 가장 큰 성분, ||r||₂=√Σrᵢ²는 제곱합 길이다. r 의 성분이 서로 다른 단위를 가지면 물리적으로 그대로 더하는 해석은 적절하지 않을 수 있다. 기준 척도 dᵢ>0 으로 rᵢ/dᵢ를 비교하는 등 기준을 먼저 명시한다.

F(z)=r 이면 후보 z 는 수정된 방정식 F(z)−r=0 의 정확한 해다. 이런 가산식 수정의 의미에서 잔차는 후방 오차로 읽을 수 있다. 원래 측정값이나 모든 계수의 상대 오차와 언제나 동일한 값이라는 뜻은 아니다. 어떤 데이터를 얼마나 수정했는지 모형을 적어야 한다.

작은 잔차에서 작은 입력오차로

해 z* 근방에서 F(z)≈J(z*)(z−z*)이므로 가역 Jacobian 이면 오차≈J(z*)⁻¹r 다. 역행렬의 크기가 크면 작은 잔차가 큰 입력 차이로 증폭될 수 있다. 비선형에서는 이 식도 근방의 일차 근사이고 전역 오차 보증으로 사용할 수 없다.

실제 정지를 판단할 때 각 잔차의 허용범위와 변수 이동량, 선형계 정확도, 반복제한과 정지 이유를 함께 남긴다. 움직임이 매우 작아서 멈춘 것은 잔차 통과와 다르다. 아주 작은 감쇠나 반올림 때문에 진행이 멈췄는데 원래 식은 크게 틀릴 수 있다.

원래 식과 척도로 돌아가기

방정식을 10⁻⁶배하면 해는 같고 잔차는 10⁻⁶배다. 더 작은 숫자만 보고 정확성이 좋아졌다고 결론 내릴 수 없다. 서로 다른 표현의 후보를 비교하려면 정한 원래 식과 같은 척도에서 평가한다. 함수 계산 자체에 반올림·상쇄가 있으면 계산된 잔차와 정확한 잔차도 나누어야 한다.

계산할 때 분모를 곱하거나 로그를 취했다면 원래 정의역과 제외점을 재검사한다. 변형식에서 0 이더라도 분모가 0 인 후보는 원래 해가 아니다. 수치 결과의 마지막 자리와 실제 측정 자료의 정확도도 같은 것이 아니다. 이 단원은 정확한 유리수와 합성 식으로 원리를 확인한다.

중간 과정을 따라가는 예제

F(x,y)=(10⁻⁶(x−1),y−2)의 참해와 후보 z=(2,2)의 잔차/입력오차를 구하라. 첫 잔차 척도 d₁=10⁻⁶,d₂=1 을 쓰면 어떻게 바뀌는가?

  1. 참해는 z*=(1,2)다. 각 성분을 0 으로 두어 확인한다.

  2. 후보 F(2,2)=(10⁻⁶,0)이므로 두 잔차 노름 모두 10⁻⁶이다.

  3. 입력 오차는 (1,0), 그 2 노름은 1 이다. 작은 잔차만으로 입력오차가 10⁻⁶이라고 말할 수 없다.

  4. J=diag(10⁻⁶,1), 역행렬은 diag(10⁶,1)이라 첫 오차 증폭이 정확히 보인다. 이 F 는 선형이어서 근사가 아닌 등식이다.

  5. 척도로 나눈 잔차는 (1,0)이다. 통과 기준을 잔차 노름≤10⁻³으로 정하면 원래 값 기준과 척도 기준은 다른 판정을 준다.

원래 잔차 10⁻⁶, 입력오차 1, 척도 잔차 1 이다. 척도 선택은 통과 판정의 일부다.

r=(3,4)에서 두 노름을 구하라. 기준 ||r||∞≤4 와 ||r||₂≤4 는 같은 판정인가? 또 x=1 에서 (x²−1)/(x−1)=0 을 판정하라.

오해와 반례

작은 이동량은 작은 잔차를 보장한다.

소단원 4.4

수렴 영역과 해의 검산

같은 식인데 시작 위치만 바꿔도 도착점이 달라질까?

준비 개념과 학습 목표

준비 개념

  • 수열의 수렴은 끝없이 반복했을 때 한 값에 가까워지는 성질이다.

  • 해 근방의 국소 조건과 모든 시작값의 전역 보장은 다르다.

  • 정확한 산술의 수학 수열과 유한 정밀도 프로그램의 반복은 구별한다.

학습 목표

  • 수렴 영역을 특정 반복법과 해에 연결한다.

  • 해 존재·단계 정의·수렴속도·후보 검산을 분리한다.

어느 해에 대한 영역인가

정한 반복법에서 특정 해 z*로 수렴하는 초기값들의 집합을 그 해의 수렴 영역이라고 부른다. 알고리즘과 감쇠 규칙이 달라지면 영역도 달라질 수 있다. 어떤 해에 가장 가까운 시작값이 언제나 그 해로 간다는 일반 법칙도 없다.

해 근방에서 F 가 충분히 매끄럽고 J(z*)가 가역이며 초기값이 충분히 가까우면 정확한 Newton 의 오차를 O(||e||²)로 제어할 수 있다. 이는 지역적 충분조건이다. FNC 의 수렴 분석도 매끄러움과 단순근·실제 근방 수렴의 조건을 둔다. 조건이 없으면 적용을 보류하고 별도 분석한다.

수렴속도와 멈춘 이유

이차 오차 경계 ||eₖ₊₁||≤C||eₖ||²는 작은 오차에서 매우 빠른 감소를 설명한다. 모든 단계에 반드시 정확한 자리 수가 두 배라는 보장은 아니다. 중근이나 특이 Jacobian 에서는 다른 속도가 나타나며, 유한 정밀도에서는 더 줄지 않는 한계가 생긴다.

이 단원의 F=(x²−1,y)는 해 (1,0),(−1,0)가 있다. x≠0 이면 x 새값=(x+1/x)/2 이고 y 는 한 단계 뒤 0 이다. x=0 에서는 첫 행이 0 인데 우변이 1 이라 Newton 단계가 없다. 원래 해 존재와 이 특정 시작점에서의 단계 정의를 분리한다.

결과를 여러 방식으로 확인하기

x>0 에서 다음값도 양수이고 첫 단계 이후 (x+1/x)/2≥1 이다. x≥1 이면 다음값≤x 여서 감소하고 1 아래로 가지 않는다. 따라서 극한 ℓ≥1 이 존재하며 연속인 갱신식에서 ℓ=(ℓ+1/ℓ)/2, ℓ=1 을 얻는다. 음수는 부호 대칭으로 −1 에 수렴한다. 이 간단한 식에서는 양수/음수 영역을 직접 증명할 수 있다.

실제 후보 검산은 원래 모든 식의 잔차, 정의역, 추가 범위와 단위 조건, 정지 이유를 포함한다. 예를 들어 x 가 길이여서 x≥0 이라는 추가 모형 조건이 있다면 대수적으로 정확한 −1 도 물리 후보로는 제외된다. 여러 초기값 결과가 같다는 관찰만으로 유일 해를 증명하지 않는다.

중간 과정을 따라가는 예제

F=(x²−1,y), z₀=(2,3)에서 두 단계를 계산하라. 첫 성분의 참해 1 기준 오차와 두 번째 잔차를 비교하라.

  1. 갱신 x=(x+1/x)/2 이고 y 는 0 이다. 첫 후보는 (5/4,0)이다.

  2. 첫 오차는 1/4, 잔차 첫 성분은 25/16−1=9/16 이다.

  3. 둘째 후보 x=(5/4+4/5)/2=41/40, y=0 이다.

  4. 둘째 오차는 1/40, 잔차는 1681/1600−1=81/1600 이다.

  5. 정확히 e 새값=e²/[2(1+e)]다. e=1/4 를 넣으면 (1/16)/(5/2)=1/40 으로 확인된다.

후보 (5/4,0)→(41/40,0), 오차 1/4→1/40, 잔차 9/16→81/1600 이다.

오해와 반례

다른 시작값에서 같은 결과가 두 번 나오면 해가 유일하고 모든 초기값도 성공한다.

양수 시작 2 와 3 은 +1 로 가지만 음수 시작은 −1 로 가며 0 은 단계가 정의되지 않는다. 유한 시험은 해의 유일성과 모든 시작값 성공의 증명이 아니다.

답과 이유 보기
