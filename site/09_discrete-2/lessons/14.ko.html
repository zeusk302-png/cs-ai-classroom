소단원 14.1

관계망의 모델 선택

문이 연결돼 있다는 그림만으로 어느 방향으로 이동할 수 있는지 알 수 있을까?

준비 개념과 학습 목표

준비 개념

  • 관계와 순서쌍

  • 그래프

  • 합

학습 목표

  • 정점과 간선의 의미를 정한다.

  • 방향·가중치·자기루프를 선택한다.

  • 모형 변경에 따라 답이 달라짐을 확인한다.

정점과 간선에 계약을 붙인다

그래프 G=(V,E)의 정점은 대상, 간선은 정한 관계를 나타낸다. 이동 가능성을 나타내는 간선과 비용을 나타내는 숫자는 서로 다른 정보다. 같은 대상도 질문에 따라 다른 그래프를 만들 수 있다.

여기서는 방향 있는 단순 그래프를 쓰며 (u,v)는 u에서 v로 가는 간선이다. 자기루프와 중복 간선을 허용하지 않는다. 양방향 이동이면 두 방향을 적거나 무방향 간선을 사용한다. 그림의 가까운 위치는 이동 비용을 뜻하지 않는다.

간선 수와 비용 합을 구별한다

방향을 따라 정점을 이어 가는 순서를 보행이라 부르며 이 원고의 단순 경로는 정점을 반복하지 않는다. 간선 수는 이동 횟수, 가중치 합은 정한 비용이다. 책마다 path라는 용어의 반복 허용 규약이 달라 정의를 먼저 확인한다.

비용이 다른 간선에서 최소 이동 횟수와 최소 비용은 다를 수 있다. BFS의 수준이 간선 수를 세는 것과 비용을 최소화하는 것은 구별한다. 도달 가능성만 묻는 모형에서 비용의 최적화까지 해결했다고 말하지 않는다.

현실의 제약을 빠뜨리지 않는다

한 방향 문, 통행 시간, 닫힌 구간이나 수용량이 질문에 중요하다면 간선의 조건으로 반영해야 한다. 단순 방향 그래프 하나로 시간에 따라 달라지는 모든 이동 문제를 해결할 수는 없다.

모형을 만든 뒤 실제 사례와 비교한다. 간선 하나를 뒤집거나 비용을 바꿔도 같은 답인지 확인하는 것은 모형 민감도 점검이다. 본문의 작은 그래프를 실제 지도나 장비의 측정값으로 부르지 않는다.

중간 과정을 따라가는 예제

V={s,a,t}, E={(s,a),(a,t),(s,t)}이고 비용은 각각2,2,9다. s→t의 최소 간선 수와 최소 비용을 비교하라.

  1. 직접 s→t는 간선1개, 비용9다.

  2. s→a→t는 간선2개, 비용4다.

  3. 최소 횟수 경로는 직접 경로, 최소 비용 경로는 a를 거친다. t에서 s로 가는 간선은 없다.

최소 간선 수1과 최소 비용4는 서로 다른 경로의 값이다.

종이와 본문으로 직접 해보기

힌트 보기

풀이 보기

좌표는 시각적 배치일 수 있다. 질문의 간선 비용과 방향을 따라 합해야 한다.

소단원 14.2

모듈러 검사와 해시 직관

같은 나머지에 들어간 두 수가 같은 값이라는 뜻일까?

준비 개념과 학습 목표

준비 개념

  • 정수 나눗셈

  • 합동

  • 비둘기집 원리

학습 목표

  • 양의 법과 나머지 규약을 정한다.

  • 해시 충돌을 계산한다.

  • 후보 좁히기와 같은 값 검증을 구별한다.

나머지는 분류표다

m>0일 때 a=qm+r, 0≤r<m인 유일한 r을 a mod m이라 둔다. a≡b (mod m)은 m이 a−b를 나눈다는 뜻이다. 같은 나머지를 갖는 많은 정수를 하나의 부류로 묶는다.

음수에도 이 비음수 나머지 규약을 적용하여 −1 mod 5=4다. 언어의 %가 음수에 같은 값을 주는지 별도로 확인한다. 수학적 규약을 실제 언어의 실행 결과라고 주장하지 않는다.

해시 인덱스는 동일성 증명이 아니다

자체 해시 h(a)=a mod 5는 정수를 다섯 버킷으로 보낸다. 다른 값이 같은 버킷으로 가면 충돌이다. 후보가 버킷보다 많으면 비둘기집 원리로 충돌을 피할 수 없다.

검색은 후보 안에서 실제 키의 동등성을 확인해야 한다. 체이닝은 같은 버킷의 값을 목록에 보관한다. 단순 나머지는 작은 정수 예제이며 암호학적 해시나 무결성 인증의 보장은 없다.

검사 통과와 성능 가정을 구별한다

같은 나머지만으로 정수 자체가 같다고 결론 낼 수 없다. 여러 법을 써도 가능한 값의 범위와 정리를 명시해야 유일성을 얻는다. 해시는 후보를 좁히는 역할이다.

기대 성능에는 분포·부하율·충돌 처리의 가정이 있다. 입력을 5로 나누면 언제나 균등하게 퍼진다는 보장은 없다. 표 크기를 늘려도 모든 특정 충돌이 사라지지는 않는다.

중간 과정을 따라가는 예제

h(a)=a mod 5에 키 7, 12, 18, −1을 넣는다. 체이닝으로 버킷과 12 검색을 추적하라.

  1. 나머지는 차례로 2, 2, 3, 4다. 버킷 2=[7,12], 3=[18], 4=[−1]이다.

  2. 12 검색은 버킷 2의 7과 실제 동등성을 비교해 거절하고 12를 찾는다.

  3. 17 검색도 버킷 2지만 두 키 모두 다르므로 없다. 나머지 일치만으로 키가 같지는 않다.

7과 12는 충돌하지만 다른 키다. 17은 같은 버킷이어도 없다.

종이와 본문으로 직접 해보기

법을 10으로 바꾸면 7과 12, 7과 17의 충돌은? −1의 나머지는?

힌트 보기

각 수를 0부터 9 사이의 나머지로 계산한다.

풀이 보기

7→7, 12→2라 기존 충돌은 사라진다. 7과 17은 둘 다 7로 충돌한다. −1→9다. 크기 증가가 모든 충돌 제거를 보장하지 않는다.

오해와 반례

해시 값이 같으니 두 키도 같다.

7과 12는 mod 5로 합동이지만 다른 정수다. 후보 안에서 키의 동등성을 비교한다.

소단원 14.3

증명·반례·계산의 교차검증

여러 수에서 맞아 보이는 규칙이 모든 정수에서 맞다는 뜻일까?

준비 개념과 학습 목표

준비 개념

  • 전칭 명제

  • 합동

  • 유한 열거

학습 목표

  • 명제의 정의역과 조건을 적는다.

  • 반례와 증명의 역할을 구별한다.

  • 계산을 별도 근거로 교차 검증한다.

주장부터 정확하게 적는다

명제의 대상과 조건, 결론을 명시한다. 모든 정수에서의 주장과 0부터 9까지의 주장은 범위가 다르다. 여러 예제를 통과했다고 무한 정의역의 명제가 증명되지는 않는다.

거짓 전칭 명제는 조건을 만족하고 결론이 틀리는 반례 하나로 부정한다. 반례가 조건 밖이면 원래 주장을 반박하지 못한다. 특정 예제의 참과 전체 명제의 참을 구별한다.

정리로 묶고 계산으로 점검한다

a≡b (mod m)이면 a−b=mq다. a²−b²=(a−b)(a+b)=mq(a+b)이므로 제곱도 합동이다. 이 식은 임의 정수에 적용되는 증명이다.

반대 방향은 자동으로 따라오지 않는다. 제곱의 나머지가 같아도 원래 수가 합동이 아닐 수 있다. 계산표는 반례를 찾는 도구다. 증명에는 정수 분해와 양의 법이라는 조건을 남긴다.

유한 계산의 완전성을 확인한다

유한 정의역을 빠짐없이 검사하면 그 정의역의 전칭 명제를 확인할 수 있다. 목록의 완전성, 계산 정확성과 비교 조건을 확인한다. 임의 표본 검사와 전수 검사는 다르다.

독립 검산은 다른 방법으로 같은 결론을 점검하는 일이다. 나머지를 구한 뒤 차이가 법의 배수인지 확인하거나 경로 목록과 탐색표를 비교한다. 같은 잘못된 식을 복사하는 것은 강한 독립 근거가 아니다.

중간 과정을 따라가는 예제

mod 5에서 a²≡b²이면 a≡b라는 주장을 a=1, b=4로 검사하라. 올바른 순방향도 증명하라.

  1. 제곱 1과 16의 나머지는 모두 1이라 가정은 참이다.

  2. 1−4=−3은 5의 배수가 아니라 결론은 거짓이다.

  3. 순방향은 a−b=5q에서 a²−b²=5q(a+b)라 제곱도 합동이다.

반대 방향은 1과 4의 반례로 거짓이다. 순방향은 인수분해로 증명된다.

종이와 본문으로 직접 해보기

a=2, b=3의 새 반례와 0부터 4까지의 제곱 나머지 표를 적어라.

힌트 보기

제곱은 0, 1, 4, 9, 16이다.

풀이 보기

나머지는 [0,1,4,4,1]이다. 2와 3은 다른 나머지지만 제곱 나머지가 4로 같다. 표를 임의 정수에 연결하려면 합동 보존 정리를 사용한다.

오해와 반례

처음 열 정수에서 맞았으니 모든 정수에서 증명됐다.

검사는 해당 범위의 증거다. 무한 범위에는 증명이나 빠짐없는 잔여류 환원의 근거가 필요하다.

답과 이유 보기

제곱 합동의 반대 방향은 항상 참인가?

답과 이유 보기

잔여류 표를 모든 정수로 확장하는 근거는?

소단원 14.4

알고리즘 과목으로의 연결

도달하는 경로가 있다는 사실을 반복 절차로 어떻게 찾아낼까?

준비 개념과 학습 목표

준비 개념

  • 도달 가능성

  • 큐

  • 불변식

학습 목표

  • 모형을 자료구조로 연결한다.

  • BFS의 발견 표시와 종료를 설명한다.

  • 표현에 따른 복잡도 조건을 확인한다.

수학적 대상과 저장 방식을 연결한다

인접목록은 정점의 나가는 이웃을 저장하고 인접행렬은 순서쌍의 간선 여부를 칸에 저장한다. 유한 단순 그래프에서 목록 공간은 O(|V|+|E|), 전체 행렬 공간은 O(|V|²)다.

정점 번호와 방향, 없는 정점 처리 같은 계약을 명시한다. 같은 그래프의 저장 방식이 달라도 이웃 열거 비용은 달라진다. 직접 간선의 존재와 여러 간선을 통한 도달 가능성을 구별한다.

발견한 정점은 한 번만 큐에 넣는다

BFS는 시작 s를 발견 표시하고 큐에 넣는다. 앞에서 u를 꺼내 나가는 이웃 중 미발견 v를 표시하고 뒤에 넣는다. 발견 시 표시하여 순환과 중복 삽입을 피한다.

발견 정점은 s에서 도달 가능하다는 불변식은 처음 s와 새 간선 u→v로 보존된다. 유한 그래프에서 각 정점은 최대 한 번 추가되어 종료한다. 빠짐없는 도달 가능성은 경로 길이의 귀납으로 확인한다.

복잡도와 최단 기준의 조건을 적는다

인접목록과 상수 시간 발견 표시·큐 연산을 가정하면 전체 정점 처리와 간선 검사는 O(|V|+|E|)다. 행렬의 행을 스캔하면 도달 정점마다 |V|칸을 봐서 최악 O(|V|²)다. 기본 연산 비용도 조건이다.

BFS 수준은 가중치 없는 간선 수 기준의 최단 거리다. 임의 가중치 비용의 최적화를 보장하지 않는다. 알고리즘 과목에서는 불변식·귀납·표현·비용 모형을 함께 배우며 실제 실행 시간은 따로 측정한다.

중간 과정을 따라가는 예제

V={s,a,b,t,z}, E={(s,a),(s,b),(a,b),(b,t),(t,a)}다. 이웃은 적힌 순서대로 처리하며 s에서 BFS 전체 탐색을 추적하라.

  1. 초기 발견 {s}, 큐 [s]. s 처리 뒤 발견 {s,a,b}, 큐 [a,b]다.

  2. a의 이웃 b는 이미 발견되어 추가하지 않는다. 큐 [b]. b 처리에서 t를 추가해 큐 [t]다.

  3. t의 이웃 a도 이미 발견되어 추가하지 않는다. 큐가 비고 도달 집합은 {s,a,b,t}다. z는 고립되어 남는다.

방문 순서는 s,a,b,t, 수준은 0,1,1,2다. z는 도달 불가다.

종이와 본문으로 직접 해보기

간선 (b,z)를 추가하고 b의 이웃 순서를 t,z로 정한다. 새 큐와 수준은?

힌트 보기

b 처리 때 두 미발견 이웃을 차례로 넣는다.

풀이 보기

b 처리 뒤 큐 [t,z]이고 둘 다 수준 2다. t 처리 뒤 [z], z 처리 뒤 빈다. 방문은 s,a,b,t,z다. 발견 표시가 순환 t→a의 중복을 막는다.

오해와 반례

발견 검사는 성능만을 위한 것이며 순환에서도 생략해도 된다.

같은 순환을 반복하면 종료하지 않을 수 있다. 발견 표시는 중복 작업과 종료의 핵심 조건이다.
