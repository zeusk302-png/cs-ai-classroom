소단원 7.1

ADC·샘플링·분해능

전압의 연속적인 변화를 컴퓨터의 숫자로 바꾸면 무엇이 빠질까?

준비 개념과 학습 목표

준비 개념

  • 전압

  • 비트와 이진수

  • 주파수

학습 목표

  • 시간 표본화와 진폭 양자화를 구분한다.

  • LSB와 앨리어스 주파수를 계산한다.

같은 ADC 코드가 나오면 실제 전압도 같다고 할 수 있을까요?

새 이상적 ADC는 4비트이며 실제 기준 전압 R에 대해 0≤V<R를 16개 구간으로 나눈다. 코드는 floor(16V/R)이고 구간 중심 복원값은 (k+1/2)R/16이다. 펌웨어가 사용하는 기준 전압을 4 V로 고정했는데 실제 R이 4.4 V이면, 실제 구간 폭은 0.275 V이나 펌웨어 복원 폭은 0.25 V다. 명목 비트 수와 코드 표가 같아도 전압 해석의 기준이 다르다.

V=2.64 V이면 실제 코드는 9다. 실제 구간 중심은 2.6125 V이고 펌웨어는 2.375 V로 표시한다. 전체 표시 오차 −0.265 V는 실제 중심의 양자화 오차 −0.0275 V와 기준을 잘못 쓴 복원 오차 −0.2375 V의 합이다. 실제 양자화 반 LSB인 0.1375 V만으로 전체 표시 오차를 제한하지 못한다.

별도 표본 모형에서 Fs=1000 Hz의 800 Hz 코사인과 200 Hz 코사인은 같다. 비트 수를 늘려도 동일한 시각에 얻은 동일한 높이를 구별하지 못한다. Fs=1200 Hz로 바꾸면 800 Hz는 400 Hz와 겹치므로 두 후보 800/200 Hz는 구별된다. 이것은 지정 후보 두 개의 구별이며 모든 미지 신호를 복원한다는 뜻은 아니다. Nyquist 경계의 500 Hz 사인은 Fs=1000 Hz에서 모두 0이어서 영 신호와도 같다.

  • 기울기와 단위의 복원

    원시 코드가 전압으로 바뀌는 비율에 기준 오차가 들어가는지 확인한다.

시간과 높이를 따로 잘라 본다

ADC는 아날로그 전압을 디지털 코드로 바꾸는 변환기다. 표본화는 어느 시각의 값을 잡을지 정하고 양자화는 그 높이를 어느 코드로 나타낼지 정한다. 표본을 더 자주 얻는 것과 한 표본을 더 많은 비트로 나타내는 것은 다른 개선이다.

여기서는 균일한 표본 간격을 가정한다. 실제 회로는 입력 범위, 기준 전압, 입력이 안정되는 시간, 표본 시점의 흔들림도 확인해야 한다. 명목 비트 수만으로 측정의 정확도를 결론내릴 수 없다.

분해능을 계산하는 모델을 먼저 정한다

이상적인 N비트 ADC에는 2^N개의 코드가 있다. 이 소단원은 입력 범위 [0,Vref)를 같은 폭 Δ=Vref/2^N으로 나누고 코드 k=floor(V/Δ), 복원값 (k+0.5)Δ를 쓰는 구간 중심 모델을 사용한다.

포화되지 않은 구간의 중심 복원 오차는 최대 반 LSB다. 실제 데이터시트의 코드 전이와 기준 범위를 따라야 하며 끝점에 코드를 대응시키는 Vref/(2^N−1) 계산과 이 모델을 섞으면 안 된다. 범위 밖 전압은 안전한 입력이라고 가정할 수 없다.

앨리어싱은 되돌릴 수 없는 겹침이다

표본화 주파수 Fs에서 한 주파수의 코사인과 Fs에서 그 주파수를 뺀 코사인은 같은 표본열이 될 수 있다. 대역 제한 신호를 이상적으로 복원하려면 Fs가 최고 주파수의 두 배보다 커야 한다. 현실에서는 필터 전이 대역을 위한 여유도 둔다.

높은 주파수가 낮은 주파수처럼 들어온 뒤 디지털 필터만으로 원래 신호를 알아낼 수는 없다. 아날로그 앤티앨리어싱 필터가 ADC 앞에서 대역 밖 성분을 줄여야 한다. 센서가 느리다는 추측만으로 잡음의 고주파 성분까지 없어지지는 않는다.

같은 ADC 코드가 나오면 실제 전압도 같다고 할 수 있을까요?
독립 모형과 조건계산 결과해석의 범위

실제 R=4.4 V, 입력 2.64 V

코드는 9, 실제 중심은 2.6125 V, 명목 표시값은 2.375 V다.

서로 다른 두 복원 눈금의 오차를 합한다.

별도 명목 4 V 포화 모형

V≥4 V이면 코드 15와 표시 3.875 V를 유지한다.

포화 이후에는 반 LSB 오차 한계가 적용되지 않는다.

Fs=1000 Hz, 두 코사인 후보

800 Hz와 200 Hz의 표본이 같다.

진폭 양자화와 시간 표본화 손실을 분리한다.

Fs=1000 Hz, 500 Hz 사인

모든 정수 표본 인덱스 n에서 값은 0이다.

최고 성분과 같은 Nyquist 경계를 안전한 복원 조건으로 쓰지 않는다.

각 행은 지정된 독립 모형이다. 실제 ADC의 안전 입력 범위나 장치 포화 동작을 인증한 값으로 읽지 않는다. 양자화 오차와 잘못된 기준을 사용한 복원 오차는 같은 전압 단위로 합한다.

중간 과정을 따라가는 예제

이상적 3비트 ADC의 Vref=8 V, 입력 V=2.6 V다. 위의 구간 중심 모델을 쓴다. 별도의 코사인 신호를 Fs=1000 Hz로 표본화하며 입력 주파수는 800 Hz다.

  1. 코드는 2^3=8개이고 Δ=8/8=1 V다.

  2. k=floor(2.6/1)=2이며 복원값은 (2+0.5)×1=2.5 V다. 복원값−입력은 −0.1 V로 반 LSB 이내다.

  3. cos(2π×800n/1000)=cos(2πn−2π×200n/1000)=cos(2π×200n/1000)이다. 따라서 800 Hz는 200 Hz와 같은 표본이 된다.

진폭 코드는 2, 중심 복원값은 2.5 V다. 800 Hz의 입력은 이 표본화에서 200 Hz와 구별되지 않는다.

조건을 바꾸어 비교하기

양자화 오차 밖에 남는 기준 오차

실제 R=4.4 V, V=2.64 V에서 코드와 두 중심 복원값, 전체 표시 오차를 구하라. 펌웨어는 R=4 V를 사용한다.

  1. 16×2.64/4.4=9.6이므로 코드는 9다. 실제 중심은 9.5×0.275=2.6125 V다.

  2. 펌웨어 중심은 9.5×0.25=2.375 V다. 실제 중심−입력은 −0.0275 V이고 표시−실제 중심은 −0.2375 V다.

표시−입력은 −0.265 V다. 실제 양자화 오차와 기준 해석 오차를 따로 기록한다.

비교할 점

반 LSB는 실제 중심 복원과 범위 내 입력의 차이에 적용하며 잘못된 펌웨어 눈금까지 포함하지 않는다.

표본화 경계의 보이지 않는 사인

Fs=1000 Hz에서 x(t)=sin(2π×500t)와 영 신호의 표본을 비교하라. t의 단위는 s다.

  1. t=n/1000을 대입하면 x[n]=sin(πn)=0이다.

  2. 모든 정수 n에서 영 신호와 같으므로 코드 비트 수를 늘려도 두 표본열은 같다.

두 입력은 이 시각들의 표본만으로 구별되지 않는다.

비교할 점

이상적인 대역 제한 복원의 엄격한 여유 조건과 특정 위상으로 표본이 사라지는 경계를 구별한다.

종이와 본문으로 직접 해보기

같은 8 V 범위를 4비트로 바꾸면 Δ와 2.6 V의 코드·중심 복원값을 계산하자.

힌트 보기

코드 수는 두 배가 되고 구간 폭은 반이 된다.

풀이 보기

Δ=8/16=0.5 V, k=floor(5.2)=5, 중심값=(5.5)×0.5=2.75 V다. 이 특정 입력의 오차가 앞의 −0.1 V보다 작지는 않지만 최악의 양자화 오차 한계는 0.25 V로 줄었다.

오해와 반례

비트를 늘리면 모든 입력의 실제 오차가 반드시 줄어든다.

최악의 양자화 한계가 작아지는 것과 특정 입력의 오차 크기가 단조롭게 줄어드는 것은 다르다. 활동의 2.6 V가 반례이며 기준 전압 오차와 잡음도 별도로 남는다.

연습 1 · 값과 상태 예측

실제 R=4.4 V와 명목 R=4 V에서 V=1.24 V를 읽는다. 코드와 명목 중심값을 계산하고 실제 R=4 V일 때의 코드와 비교하라.

힌트 1

실제 폭은 0.275 V다.

힌트 2

1.24를 각 폭으로 나누되 floor를 적용한다.

풀이와 답 확인

  1. 실제 R=4.4 V에서는 floor(1.24/0.275)=4다. 명목 표시는 4.5×0.25=1.125 V다.

  2. 실제 R=4 V에서도 floor(1.24/0.25)=4다. 같은 코드라도 물리 구간이 다르다.

두 경우 모두 코드 4지만 실제 구간은 다르며 명목 표시는 1.125 V다.

흔한 오답에서 다시 생각하기

코드가 같으므로 실제 기준 전압 오차가 없다.

한 입력에서 같은 구간 번호가 나와도 두 눈금이 일치한다는 증거는 아니다.

연습 2 · 오류 찾아 고치기

별도 모형은 명목 R=4 V이고 V≥4 V를 코드 15에 포화시킨다. 입력 4.8 V의 표시값과 오차를 계산하고 반 LSB 주장 오류를 고쳐라.

힌트 1

코드 15의 중심을 사용한다.

힌트 2

입력이 명시한 비포화 범위 밖임을 표시한다.

풀이와 답 확인

  1. 표시는 15.5×0.25=3.875 V다. 표시−입력은 −0.925 V다.

  2. 0.125 V의 반 LSB 한계는 [0,4) V의 입력에만 적용한다. 이 포화 규칙은 종이 모형이며 실제 과전압 안전을 보장하지 않는다.

오차는 −0.925 V이고 반 LSB 보장은 적용되지 않는다.

흔한 오답에서 다시 생각하기

4비트이면 어떤 입력에서도 오차는 0.125 V 이하다.

비포화 입력과 정확한 복원 기준이라는 조건이 빠졌다.

연습 3 · 직접 만들어 보기

주파수 후보가 정확히 800 Hz 또는 200 Hz인 단위 진폭·영 위상 코사인이다. Fs=1200 Hz의 n=1 표본으로 두 후보를 구별하라.

힌트 1

각도는 2πf/1200이다.

힌트 2

cos(4π/3)과 cos(π/3)을 비교한다.

풀이와 답 확인

  1. 800 Hz 후보의 표본은 −1/2이고 200 Hz 후보의 표본은 1/2다.

  2. 따라서 지정 두 후보는 이 한 표본에서 구별된다. 다른 주파수 후보나 잡음은 이 계약에 없다.

n=1에서 −1/2이면 800 Hz, 1/2이면 200 Hz 후보와 맞는다.

흔한 오답에서 다시 생각하기

표본 한 개로 모든 연속 신호를 유일하게 복원한다.

유한 후보·진폭·위상을 고정한 식별 문제에만 답했다.

연습 4 · 선택 심화

힌트 2

두 교정점이 맞으면 그 사이와 모든 단위에서도 식이 그대로 맞을까요?

새 교정 자료는 10 ℃에서 원시값 200 코드, 90 ℃에서 840 코드다. r=aT+b의 선형 모형에서는 a=8 코드/℃, b=120 코드이고 r=600의 추정 온도는 60 ℃다. 적용 온도와 원시값 범위, 기준점의 버전을 함께 보존한다.

불확실성 모형에서는 참 원시값이 [598,602] 코드, b가 [117,123] 코드, a가 [7.8,8.2] 코드/℃에서 서로 독립적으로 어느 값이든 가능하다고 지정한다. 분자가 항상 양수여서 T=(r−b)/a의 최소는 작은 분자·큰 분모에서, 최대는 큰 분자·작은 분모에서 나온다. 구간은 [2375/41,2425/39] ℃로 약 [57.927,62.179] ℃다. 기울기까지 불확실한데 분모 8만 고정하면 이 전체 범위를 놓친다.

반대로 같은 시점의 원시값과 영점에 동일한 오프셋 d가 들어가 r와 b가 함께 d만큼 증가하면 r−b는 같다. 임의 독립 오차로 푼 범위와 공동 변화로 지정한 범위는 다른 모형이다. 두 점을 맞추는 곡선 r=8T+120+0.01(T−10)(T−90)는 50 ℃에서 504 코드여서 선형 역식이 48 ℃를 준다. 두 점 교정만으로 비선형성이 없다고 결론낼 수 없다.

  • 공통 오차와 평균

    공통 오프셋은 평균으로 없어지지 않으며 오차 간의 관계도 기록한다.

기준을 비교해 눈금을 맞춘다

교정은 알려진 기준과 측정을 비교해 대응 관계와 그 불확실성을 확인하는 과정이다. 보정은 그 결과로 읽은 값에 수정을 적용하는 과정이다. 여기서는 온도 T와 센서 원시값 r 사이를 r=aT+b로 근사한다.

a는 온도 한 단위에 따른 눈금 변화이고 b는 영점의 이동이다. 두 점을 맞췄다고 모든 온도에서 선형이라는 사실이 증명되지는 않는다. 사용 범위와 기준점의 신뢰성을 함께 기록한다.

선형식에서 실제 단위로 돌아간다

두 기준점 (T1,r1),(T2,r2)가 서로 다른 온도이면 a=(r2−r1)/(T2−T1), b=r1−aT1로 구한다. 이후 T=(r−b)/a로 역변환한다. a가 0에 가깝거나 기준점이 너무 가까우면 오차에 민감해진다.

원시값이 ADC 코드인지 전압인지도 적어야 한다. ℃당 코드라는 기울기를 코드당 ℃와 바꾸어 쓰면 단위가 틀린다. 제조사 모델의 적용 범위 밖으로 식을 연장하는 것도 별도 가정이다.

남은 오차를 따로 기록한다

평균은 독립적이고 영평균인 흔들림을 줄일 수 있지만 영점이나 기울기의 체계적 오차를 없애지는 않는다. 온도 변화, 비선형성, 기준 전압과 기준 기구의 불확실성도 남을 수 있다.

최대 오차 한계를 보수적으로 합하려면 같은 출력 단위로 바꾼 뒤 절댓값 한계를 더한다. 표준편차를 제곱합으로 합치는 방법에는 독립성 같은 추가 조건이 있다. 단순 최대 범위를 근거 없이 확률적 표준편차로 읽으면 안 된다.

두 교정점이 맞으면 그 사이와 모든 단위에서도 식이 그대로 맞을까요?
독립 모형과 조건계산 결과해석의 범위

두 기준점의 선형 모형

기울기는 8 코드/℃이고 영점은 120 코드다.

새 원시값 600 코드는 60 ℃로 변환한다.

세 독립적인 구간 불확실성

최소 온도는 475/8.2 ℃, 최대는 485/7.8 ℃다.

가장 큰 절댓값만 기계적으로 더하지 않고 분모도 바꾼다.

같은 오프셋을 공유하는 r와 b

(r+d)−(b+d)=r−b다.

공동 변화 조건에서 정확히 상쇄되는 항이다.

두 끝점이 같은 곡선

50 ℃의 원시값은 504 코드이며 선형 추정은 48 ℃다.

같은 두 교정점과 다른 중간 오차가 가능하다.

단순 최대 구간은 확률 분포나 표준편차가 아니다. 독립적으로 가능한 구간 값이라는 가정과 동일한 d를 공유한다는 가정을 섞지 않는다.

중간 과정을 따라가는 예제

온도 0 ℃에서 r=100, 100 ℃에서 r=1100을 읽었다. 이 구간에서 정확한 선형 모델을 가정한다. 새 r=650이다. 원시값 최대 오차 ±2 코드와 영점 추정 오차 ±1 코드만 고려하고 기울기는 정확하다고 둔다.

  1. a=(1100−100)/(100−0)=10 코드/℃, b=100 코드다.

  2. T=(650−100)/10=55 ℃다.

  3. 두 오차의 최악 방향이 같으면 온도 오차 한계는 (2+1)/10=0.3 ℃다. 이것은 실제 센서의 전체 정확도 측정 결과가 아니다.

모델의 추정값은 55 ℃이고 명시한 두 오차만의 보수적 한계는 ±0.3 ℃다.

  1. 최소 분자는 598−123=475 코드, 최대는 602−117=485 코드다. 모두 양수다.

같은 용량과 처리 횟수인데 표본 하나가 빠질 수 있을까요?

새 FIFO의 사용 가능한 용량은 표본 세 개이며 처음 비어 있다. 번호 1부터 6의 표본은 각각 1 ms부터 6 ms까지 한 번씩 도착한다. 소비자는 4 ms와 6 ms에서 현재 저장된 가장 오래된 표본을 최대 두 개씩 제거한다. 버퍼가 가득 차면 새 표본을 버린다. 같은 시각에서 도착을 먼저 처리하면 4번이 버려지지만 소비를 먼저 처리하면 여섯 표본이 모두 받아들여진다.

도착 우선에서는 4 ms에 도착한 번호 4가 버려진 뒤 번호 1과 2를 제거해 [3]이 남는다. 5 ms에는 [3,5], 6 ms에는 [3,5,6]이 된 뒤 번호 3과 5를 제거해 [6]이 남는다. 소비 우선에서는 4 ms에 번호 1과 2를 제거한 뒤 번호 4를 받아 [3,4], 5 ms에는 [3,4,5]가 된다. 6 ms에는 번호 3과 4를 제거한 뒤 번호 6을 받아 [5,6]이 남는다. 평균 처리율만으로 각 순간의 안전을 인증하지 않는다.

별도 세 표본 평균은 실제 취득 인덱스가 n,n−1,n−2이고 동일 간격일 때의 필터다. 누락 뒤 남은 세 값을 연속한 세 시각으로 재번호하면 다른 시간 창을 만들 수 있다. 또 입력을 x[n]=b+c+ε[n]으로 두고 ε만 서로 독립·영평균·분산 9라면 세 평균의 오차는 c+평균 ε다. 공통 오프셋 c=2이면 평균의 분산은 3이지만 목표 b에 대한 MSE는 4+3=7이다. 잡음만 줄였다는 말과 전체 오차가 사라졌다는 말은 다르다.

표본 취득과 처리를 분리한다

센서는 일정한 시점에 값을 주지만 계산이나 전송은 오래 걸릴 수 있다. 버퍼는 두 속도의 차이를 잠시 흡수하는 대기 공간이다. 계속해서 입력 속도가 출력 속도보다 빠르면 어떤 유한 버퍼도 결국 찬다.

원형 버퍼는 인덱스를 끝에서 처음으로 돌려 공간을 재사용한다. 빈 상태와 꽉 찬 상태를 구별하는 구현에 따라 배열 한 칸을 비워 두기도 한다. 여기서는 사용할 수 있는 실제 용량이 8표본이라고 명시한다.

빠진 표본까지 측정 기록의 일부다

표본 번호, 취득 시각, 단위, 교정식 버전과 누락 수를 함께 기록하면 결과를 다시 해석할 수 있다. 처리 시각을 취득 시각으로 대신하면 지연을 물리 현상의 변화로 오해할 수 있다.

하드웨어나 DMA가 채우는 버퍼는 누가 언제 읽고 다시 써도 되는지 소유권을 정해야 한다. 이 소단원은 종이 모델만 다루며 인터럽트나 장치의 실제 동작을 확인한 자료로 읽으면 안 된다.

평균은 흔들림을 줄이고 변화를 늦춘다

최근 세 표본의 이동 평균은 y[n]=(x[n]+x[n−1]+x[n−2])/3이다. 일정 간격의 선형 필터로 볼 때 그룹 지연은 한 표본이며 급격한 계단 변화는 세 출력에 걸쳐 반영된다. 시작 전 표본의 처리도 명시해야 한다.

독립적 영평균 잡음의 분산은 세 개 평균에서 원래 분산의 1/3이지만 공통 오프셋은 그대로 남는다. 필터를 강하게 할수록 변화나 경보를 늦출 수 있어 지연 한계와 함께 선택한다.

현재 표본 수는 1이고 누락 수는 1이다.

소비 우선, 같은 용량과 시각

누락이 없고 6 ms의 도착 뒤 [5,6]이 남는다.

현재 표본 수는 2다.

별도 취득 번호 0,1,3

처리 기록이 세 개여도 취득 시각은 연속하지 않는다.

번호 2의 표본을 임의로 채워 넣지 않는다.

오프셋 2와 독립 분산 9

세 평균의 잡음 분산은 3이고 전체 MSE는 7이다.

편향과 분산을 목표값 기준으로 합한다.

대기열은 각 도착과 제거 뒤의 내용을 순서대로 읽는다. 평균 필터의 인덱스는 저장 배열의 칸 번호와 물리 취득 시각을 구별한다.

중간 과정을 따라가는 예제

사용 가능한 버퍼 용량은 8표본이고 처음 비어 있다. 소비가 중지된 동안 매 1 ms에 한 표본씩 도착하며 도착 시각은 1,2,… ms다. 필터의 별도 입력은 …,0,0,9,9,9다.

  1. 6 ms 시점의 도착까지 소비가 없으면 저장된 표본은 6개이고 여유는 2개다.

  2. 10 ms까지 소비하지 않고 꽉 차면 새 입력을 버리는 정책이면 8개 저장, 2개 누락이다. 경계 시점에도 소비는 없다고 명시했다.

  3. 영 초기 상태에서 세 표본 평균은 첫 9에 (0+0+9)/3=3, 다음에 (0+9+9)/3=6, 다음에 (9+9+9)/3=9다.

버퍼는 긴 정지를 무한히 숨길 수 없으며 필터의 출력은 3→6→9로 늦게 바뀐다.

조건을 바꾸어 비교하기

경계 시각의 순서가 만든 누락

지정 세 칸 FIFO에서 도착 우선과 소비 우선을 6 ms까지 추적하라.

  1. 1 ms 뒤에는 [1], 2 ms 뒤에는 [1,2], 3 ms 뒤에는 [1,2,3]으로 두 정책이 같다. 도착 우선의 4 ms에는 번호 4가 버려지고 번호 1과 2를 소비한 뒤 [3]이 남는다.

  2. 도착 우선은 5 ms에 [3,5], 6 ms 도착 뒤 [3,5,6], 소비 뒤 [6]이다. 소비 우선은 4 ms 뒤 [3,4], 5 ms 뒤 [3,4,5], 6 ms 뒤 [5,6]이다.

도착 우선의 누락은 1개, 소비 우선의 누락은 0개다. 최종 FIFO는 각각 [6]과 [5,6]이다.

비교할 점

같은 처리 시각과 횟수라도 경계 순서가 현재 자료와 누락을 바꾼다.

평균의 분산과 목표 오차 분리

x[n]=b+2+ε[n]이고 세 ε는 독립·영평균·분산 9다. 세 평균의 분산과 b를 목표로 한 MSE를 구하라.

  1. 평균 잡음의 분산은 (9+9+9)/9=3이다. 기대 평균은 b+2다.

  2. 목표 b에 대한 편향 제곱은 4이므로 MSE는 4+3=7이다.

분산은 3, 목표 MSE는 7이다. 평균 전 한 표본의 MSE 13보다 작지만 영은 아니다.

비교할 점

ε의 독립성은 잡음 분산 감소를 뒷받침하며 공통 오프셋을 제거하지 않는다.

종이와 본문으로 직접 해보기

세 입력 10,12,14의 평균을 계산하고 모든 입력에 공통 오프셋 +2가 더해졌을 때 평균을 비교하자.

힌트 보기

덧셈 후 3으로 나누고 오프셋이 합에 세 번 나타나는지 확인한다.

풀이 보기

원래 평균은 36/3=12다. 새 평균은 (12+14+16)/3=14다. 공통 +2는 제거되지 않는다.

오해와 반례

큰 버퍼와 필터가 있으면 측정은 항상 정확하다.

입력 속도가 더 빠르면 큰 버퍼도 찬다. 필터는 공통 오프셋이나 이미 발생한 앨리어싱을 없애지 못하며 지연도 만든다. 용량, 대역, 교정과 시각 기록을 함께 판단한다.

연습 1 · 값과 상태 예측

위 FIFO의 용량만 네 표본으로 늘린다. 도착 우선에서 6 ms의 소비 뒤 내용과 누락 수를 구하라.

힌트 1

4 ms에는 4번까지 저장한 뒤 두 개를 제거한다.

힌트 2

6 ms에도 도착 후 최대 두 개를 제거한다.

풀이와 답 확인

  1. 4 ms 도착 뒤 [1,2,3,4]이고 소비 뒤 [3,4]다. 5 ms 뒤 [3,4,5]다.

  2. 6 ms 도착 뒤 [3,4,5,6]이고 소비 뒤 [5,6]이다. 어느 도착도 버려지지 않는다.

최종 내용은 [5,6], 누락 수는 0개다.

흔한 오답에서 다시 생각하기

용량이 달라도 평균 입력률이 같으므로 반드시 한 개가 빠진다.

순간 최대 점유와 경계 순서에 따라 용량 증가는 이 유한 기록의 결과를 바꾼다.

연습 2 · 오류 찾아 고치기

취득 번호 0,1,3의 입력값이 0,0,9다. 번호 2는 누락됐다. 세 저장 값의 평균 3을 정규 세 표본 필터의 y[3]이라고 보고한 오류를 설명하라.

힌트 1

정규 y[3]은 번호 3,2,1을 사용한다.

힌트 2

번호 0은 현재 정규 창의 밖이다.

풀이와 답 확인

  1. 세 저장 값의 평균은 3이지만 정규 필터 y[3]=(9+x[2]+0)/3에는 미관측 x[2]가 있다.

  2. 예를 들어 x[2]=0이면 3, x[2]=9이면 6이다. 남은 기록만으로 정규 y[3]을 결정하지 못한다.

기록 세 개의 평균과 정규 취득 창의 평균은 다르다. 누락을 표시하고 y[3]을 미결로 기록한다.

저장 위치를 다시 붙이면 취득 시각 정보가 손실된다.

연습 3 · 직접 만들어 보기

도착 우선·용량 세 표본의 원고에서 재해석 가능한 누락 장부를 만들어라. 번호·취득 시각·폐기 이유·처리 시각을 구별하라.

힌트 1

버려진 번호를 먼저 찾는다.

힌트 2

소비 시각은 취득 시각을 대신하지 않는다.

풀이와 답 확인

  1. 누락 표본은 번호 4이고 취득 시각은 4 ms이며 당시 FIFO가 [1,2,3]으로 가득 찼다는 이유를 남긴다.

  2. 번호 1과 2의 처리 시각은 4 ms이고 번호 3과 5의 처리 시각은 6 ms다. 남은 번호 6의 취득 시각은 6 ms다.

번호 4의 취득·폐기 장부와 각 번호의 처리 시각을 별도로 보존한다. 실제 ISR나 DMA 기록을 생성한 것은 아니다.

다른 문제에 적용하기

ADC 코드·교정 판본·취득 장부의 조건 연결

세 독립 모형을 분석하라. ① 실제 R=4.4 V인 4비트 ADC에 2.64 V를 넣고 명목 R=4 V로 중심 복원한다. 코드와 표시 오차, 실제 양자화 오차를 구하라. ② 위 곡선 센서의 참 온도가 50 ℃다. 원시값과 선형 판본의 추정을 구하라. ③ 세 칸 FIFO의 도착 우선 정책에서 6 ms의 소비 뒤 내용·누락 번호를 적고, 취득 번호 0, 1, 3의 값이 각각 0, 0, 9로 남은 기록의 평균을 정규 y[3]으로 확정할 수 있는지 답하라. 실제 ADC나 센서·버퍼 프로그램을 실행하지 않는다.

힌트 1

원시 코드를 만드는 기준과 복원 기준을 분리하고 센서 곡선의 추가 항을 계산한다.

힌트 2

대기열 사건 순서를 적은 뒤 정규 필터의 필요한 취득 번호를 확인한다.

풀이와 답 확인

  1. ADC 코드는 floor(9.6)=9다. 명목 표시는 2.375 V로 전체 오차는 −0.265 V다. 실제 중심 2.6125 V의 양자화 오차는 −0.0275 V다.

  2. 곡선의 50 ℃ 원시값은 504 코드다. 선형 판본은 (504−120)/8=48 ℃로 표시하여 오차 −2 ℃가 남는다.

  3. 도착 우선 FIFO의 최종 내용은 [6]이고 번호 4가 누락됐다. 누락된 취득 시각은 4 ms다.

  4. 저장 세 값의 평균은 3이지만 정규 y[3]에는 x[2]가 필요하다. x[2]가 0이면 3이고 9이면 6이므로 미관측 값 없이 확정하지 않는다.

ADC 코드는 9이고 표시 오차는 −0.265 V, 실제 중심 양자화 오차는 −0.0275 V다. 센서의 원시값은 504 코드이고 선형 추정은 48 ℃다. FIFO는 [6]을 남기고 번호 4를 잃는다. 남은 세 값의 평균 3은 정규 y[3]을 인증하지 못한다.

해결한 뒤 점검할 것

  • 양자화 오차와 기준을 잘못 쓴 표시 오차를 서로 다른 항으로 기록한다.

  • 두 점의 일치와 중간 곡선의 오차를 구별하고 교정 판본을 보존한다.

  • 도착 우선·폐기 정책·누락 번호·필요한 취득 번호를 명시한다.

  • 자체 손모형과 실제 MCU·센서·수집·학습자 실행 미수행을 구별한다.

보강 자료의 출처와 확인 범위
  • TI Principles of Data Acquisition and Conversion Rev.A

    실제 PDF 74–91/178–262행을 읽었다. 표본화·앨리어싱, aperture 오차, 양자화와 gain/offset/linearity, FSR/2^n의 LSB·코드 수를 대조했다. 새 R=4/4.4 V와 포화 규칙·500 Hz 경계 반례는 자체 모형이며 실제 입력 안전 범위나 원문의 특정 부품 수치를 인증한 것이 아니다.

  • TI TMS570LS20x/10x Embedded ADC Rev.A

    실제 PDF 143–173/306–433행 전체를 읽었다. 기준 전압 잡음과 gain/offset, ADC 앞 앤티앨리어싱, trigger 시점의 지터, 내부 offset 교정·온도 의존성, oversampling/필터의 CPU 비용·지연을 확인했다. 원문의 장치별 재교정 수치와 실행 코드·시험 결과를 새 센서의 근거로 일반화하지 않았다. 새 역식 구간·곡선·FIFO와 잡음 통계는 자체 손유도이며 실제 ADC 코드를 실행하지 않았다.
