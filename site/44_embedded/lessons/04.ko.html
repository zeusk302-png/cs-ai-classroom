소단원 4.1

입출력·풀업·전압

전선의 전압과 프로그램의 0·1 은 같은 것일까?

준비 개념과 학습 목표

준비 개념

  • 전압은 두 점의 차이다

  • 옴의 법칙 I=V/R

학습 목표

  • GPIO 모드와 기준 전압을 구별한다

  • pullup 의 기본 상태와 전류를 계산한다

입력 핀이 전류를 거의 먹지 않으면 열린 스위치는 항상 HIGH일까요?

기본의 높은 입력 임피던스와 풀업을 새 저항망에 적용한다. 가상 입력의 전압은 수신기 GND를 기준으로 하고, 0.8 V 이하를 LOW, 2.0 V 이상을 HIGH, 그 사이를 미정으로 판정한다. 이상적인 3.3 V 전원에서 10 kΩ 저항으로 입력 노드를 끌어 올린다. 입력 자체의 전류는 0이고 스위치는 열려 있지만, 외부 회로에 노드와 GND를 잇는 저항 Rₚ가 추가되어 있다고 지정한다. 두 저항의 직렬 전류는 3.3/(10,000+Rₚ) A이고 입력 전압은 Vᵢₙ=3.3Rₚ/(10,000+Rₚ) V다. 입력 핀이 전류를 먹지 않아도 외부 저항에는 전류가 흐른다.

Rₚ가 10 kΩ이면 입력은 1.65 V로 미정이다. Rₚ가 20 kΩ이면 2.2 V로 HIGH이고, Rₚ가 2 kΩ이면 0.55 V로 LOW다. 따라서 스위치가 열렸다는 설명만으로 HIGH를 보장할 수 없다. 이 저항값과 임계값은 계산용 계약이며 실제 보드의 내부 풀업 범위·누설·입력 임계값을 대신하지 않는다. 기본의 이상적인 외부 10 kΩ 풀업에서도 다른 부하가 없다는 조건이 있어야 3.3 V를 얻는다.

전압의 기준도 따로 적는다. 송신기의 출력은 자기 GND보다 3.3 V 높지만, 송신기 GND가 수신기 GND보다 1.5 V 낮다고 지정하면 수신기가 보는 입력은 1.8 V다. 두 장치에 모두 3.3 V라고 쓰여 있어도 이 사례의 판정은 미정이다. 이는 일정한 두 기준 전위의 종이 모형이며 실제 비공통 접지의 안전한 연결법을 제공하지 않는다. 허용 입력 범위와 기준 전위, 외부 부하, 논리 임계값을 각각 확인한다.

먼저 확인할 개념
  • 입력 임피던스와 기준 전압

    핀 자체의 부하와 외부 전류 경로, HIGH의 기준을 구별한다.

  • 회로 조건과 논리 해석

    논리 선언을 실제 노드의 전압·연결 조건과 대응시킨다.

입력은 관찰하고 출력은 구동한다

GPIO는 설정에 따라 외부 전압을 읽는 입력 또는 외부 회로를 구동하는 출력으로 쓸 수 있다. 입력 모드는 보통 고임피던스여서 작은 전류로 전압을 감지한다. 출력은 HIGH/LOW로 전류를 공급하거나 흡수하는 동작과 이어진다. 두 모드를 단순한 변수 읽기/쓰기로만 보면 회로의 부하를 놓친다.

Digital LOW와 HIGH는 물리 전압 범위로 정의된다. 기준 ground와 허용 입력 전압, LOW 상한/HIGH 하한은 해당 chip과 전원 조건의 자료로 확인해야 한다. 모든 보드가 5V라는 가정이나 3.3V 장치가 5V 입력을 받아도 된다는 가정을 일반화하지 않는다. 이 원고는 실제 연결을 요구하지 않는 가상 회로다.

연결되지 않은 입력의 상태

Floating 입력은 외부에서 정해진 전압으로 묶이지 않은 입력이다. 잡음이나 주변 신호에 영향을 받을 수 있어서 열린 스위치가 반드시 0을 주지는 않는다. Pullup은 저항으로 입력을 전원 쪽에 약하게 연결하여 스위치가 열렸을 때 기본 HIGH를 정한다.

스위치를 입력과 ground 사이에 두면 닫힐 때 LOW가 된다. Pullup 저항은 전원과 ground가 직접 연결되지 않도록 전류를 제한한다. 내부 pullup 값은 마이크로컨트롤러마다 다르며 소프트웨어 옵션 이름이 같아도 정확한 저항값은 같지 않다.

논리 판정의 빈 구간

가상 입력은 V≤0.8V에서 LOW,V≥2.0V에서 HIGH를 보장하고 그 사이는 미정이라고 하자. 1.4V를 보고 가까운 쪽으로 반올림하는 것은 이 규격의 규칙이 아니다. 실제 장치에는 전원/온도 조건과 전기 특성이 있으므로 데이터시트를 읽는다.

Pullup은 기본값을 정하지만 접점 bounce·과전압·올바른 통신 타이밍을 모두 해결하지 않는다. 공통 ground가 없는 두 장치의 숫자 3.3V 표기만 비교해 같은 입력이라고 결론 내리지 않고 기준점과 회로 경로를 함께 확인한다.

중간 과정을 따라가는 예제

이상적 3.3V 전원,10kΩ pullup,입력 누설 0,입력-ground 스위치 저항 0 이다. 열림/닫힘의 입력 전압과 저항 전류를 구하라.

  1. 열림에서는 ground 로 가는 경로가 없고 입력 누설 0 이므로 저항 전류 0 이다.

  2. 저항 전압 강하 IR=0 으로 입력은 3.3V 다.

  3. 닫힘에서는 입력이 ground 와 직결되어 0V 다.

  4. Pullup 양끝 3.3V 를 10,000Ω로 나누면 I=0.00033A=0.33mA 다. 가상 threshold 에서는 열림 HIGH/닫힘 LOW 다.

열림 3.3V/0mA,닫힘 0V/.33mA. LOW 가 누름 상태인 active-low 입력이다.

조건을 바꾸어 비교하기

입력 전류는 0이지만 분압은 남는다

열린 스위치, 입력 전류 0, 위쪽 10 kΩ, 아래쪽 Rₚ=10 kΩ인 지정 회로의 전류와 논리 판정은?

  1. 두 저항의 합은 20 kΩ이므로 전류는 0.165 mA다.

  2. 아래쪽 저항의 전압은 0.165 mA×10 kΩ=1.65 V이며 두 임계값 사이에 있다.

노드 전압은 1.65 V이고 논리 판정은 미정이다.

비교할 점

높은 입력 임피던스는 입력 핀의 전류 조건이며 외부 아래쪽 저항을 없애지 않는다.

출력의 기준을 수신기로 옮기기

송신기 출력이 자기 GND보다 3.3 V 높고 송신기 GND는 수신기 GND보다 1.5 V 낮다. 수신기 입력을 판정하라.

  1. 수신기 GND를 0 V로 두면 송신기 GND는 −1.5 V다.

  2. 송신기 출력은 −1.5+3.3=1.8 V다.

수신기 기준 1.8 V이므로 이 가상 임계값에서 미정이다.

비교할 점

두 공급 전압 표기가 같아도 실제 기준 전위가 같다는 전제가 필요하다.

연습 1 · 값과 상태 예측

위쪽 10 kΩ과 외부 아래쪽 Rₚ=20 kΩ인 회로의 전류·입력 전압·논리 판정을 구하라.

힌트 1

직렬 저항의 합으로 전류를 구한다.

힌트 2

아래쪽 저항에 걸린 전압을 임계값과 비교한다.

풀이와 답 확인

  1. 전류는 3.3 V/30 kΩ=0.11 mA다.

  2. 입력 전압은 0.11 mA×20 kΩ=2.2 V다.

전류는 0.11 mA이고 입력은 2.2 V로 HIGH다.

흔한 오답에서 다시 생각하기

입력 전류가 0이므로 모든 저항의 전류도 0이다.

연습 2 · 오류 찾아 고치기

열린 스위치와 외부 Rₚ=10 kΩ에서 소프트웨어가 HIGH라고 가정했다. 필요한 보고 수정과 회로 확인을 적어라.

힌트 1

회로의 아래쪽 부하를 먼저 포함한다.

힌트 2

미정 전압을 디지털 입력의 확정값과 구별한다.

풀이와 답 확인

  1. 지정 계산에서 입력은 1.65 V로 미정임을 보고한다.

  2. 외부 부하의 존재와 실제 입력 임계값·누설·허용 전압을 확인한다.

열림만으로 HIGH를 확정하지 않는다. 이 모형의 중간 전압 판정과 실제 보드의 읽기 결과는 별개다.

연습 3 · 직접 만들어 보기

위쪽 10 kΩ을 유지한다. 양의 외부 저항 Rₚ에 대해 지정 회로가 HIGH인 필요충분 범위를 구하고 경계의 전압을 확인하라.

힌트 1

3.3Rₚ/(10,000+Rₚ)≥2.0을 푼다.

힌트 2

분모는 양수이므로 부등호 방향은 유지된다.

풀이와 답 확인

  1. 1.3Rₚ≥20,000이므로 Rₚ≥200,000/13 Ω다.

  2. 경계 저항에서는 입력이 정확히 2.0 V이며 HIGH 판정에 포함된다.

Rₚ≥200,000/13 Ω, 약 15.385 kΩ가 이 지정 회로의 HIGH 범위다.

흔한 오답에서 다시 생각하기

Rₚ는 10 kΩ보다 크기만 하면 항상 HIGH다.

같은 두 저항의 중간값은 1.65 V이며 HIGH 임계값 2.0 V보다 낮다.

연습 4 · 선택 심화

선택 심화는 기본 연습 뒤 더 탐구하고 싶을 때 풀어 보세요.

같은 양의 Rₚ 회로가 LOW인 필요충분 범위를 구하라. HIGH 범위 사이에 남는 미정 범위도 명시하라.

힌트 1

입력이 0.8 V 이하인 부등식을 푼다.

힌트 2

두 임계값의 등호는 각각 LOW와 HIGH에 포함된다.

풀이와 답 확인

  1. 3.3Rₚ≤0.8(10,000+Rₚ)이므로 2.5Rₚ≤8,000, 즉 0<Rₚ≤3,200 Ω다.

  2. 3,200 Ω<Rₚ<200,000/13 Ω에서는 미정이다.

LOW는 0<Rₚ≤3.2 kΩ이고 두 경계 사이의 열린 구간은 미정이다.

같은 세 표본이면 연속 횟수 규칙과 경과 시간 규칙도 같은 결과일까요?

기본의 연속 세 번 확인을 새 불균등 표본 시간과 비교한다. 원시 값 0은 누름이고 1은 놓임이며 확정 상태의 초기값은 1이다. 횟수 필터 C는 직전 표본이 없는 초기 연속 횟수 0에서 시작한다. 첫 표본의 횟수는 1이다. 그 뒤에는 원시 값이 직전 표본과 같으면 횟수를 하나 늘리며 다르면 1로 시작한다. 횟수가 3에 도달하면 그 원시 값을 확정 상태로 삼는다. 확정 1→0에서만 누름 사건을 한 번 센다. 시간 필터 D는 초기 후보값 1과 후보 시작 시각 0 ms를 둔다. 표본의 원시 값이 후보와 다르면 후보를 바꾸고 시작 시각을 현재 시각으로 갱신한다. 현재 시각에서 후보 시작 시각을 뺀 값이 50 ms보다 클 때만 후보를 확정한다. 실제 시간 필터 예제의 엄격한 > 조건을 사용하되 두 필터 모두 이 문단의 상태 계약으로 비교한다.

이력 A는 0, 1, 2 ms에 원시 값 0, 0, 0을 읽는다. C는 2 ms에 세 번째 0으로 눌림을 확정하지만 D는 2 ms의 경과로 아직 확정하지 않는다. 별도 이력 B는 0, 1, 100 ms에 같은 원시 값 0, 0, 0을 읽는다. C와 D 모두 100 ms에 확정한다. 세 표본이라는 개수는 두 기록의 시간 간격을 보존하지 않는다. 또한 D는 읽은 표본 사이에 후보가 물리적으로 계속 같았다고 증명하지 않는다. 사이에 짧은 놓임·재누름이 있었어도 표본이 그것을 놓칠 수 있다.

엄격한 경계를 따로 추적한다. 후보가 0 ms부터 0이고 50 ms에서도 원시 값 0이면 D는 경과가 정확히 50 ms여서 아직 확정하지 않는다. 51 ms의 같은 값에서 처음 확정한다. 다른 이력에서 50 ms에 원시 값 1을 읽고 51 ms에 다시 0을 읽으면 새 후보 0의 시작은 51 ms다. 102 ms에 같은 0을 읽을 때 경과가 51 ms이므로 확정한다. 처음 누름의 시각을 계속 사용하면 중간 후보 변경을 무시한 것이다. 사건은 원시 표본의 0 개수가 아니라 확정 상태의 전이로 센다.

LED에도 전류 경로가 필요하다

LED는 전류가 정한 방향으로 흐를 때 빛을 내는 소자다. 전원에서 저항과 LED를 거쳐 ground로 이어지는 직렬 경로에 전류 제한 저항을 둔다. 여기서는 LED 순방향 전압 2.0V라는 상수 모형을 쓴다. 실제 전압은 부품·전류·온도에 따라 달라진다.

GPIO 출력이 LED를 밝힌다는 코드의 뜻은 회로에 따라 달라진다. HIGH에서 전류를 공급하는 회로와 LOW에서 전류를 흡수하는 회로가 있다. 원하는 전류가 핀별·전체 전류 규격을 만족하는지도 따로 검사하며 빛이 난다는 관찰만으로 전기 안전성을 증명하지 않는다.

접점의 짧은 반복을 읽는다

기계 스위치 접점은 한 번 닫는 중에도 짧게 붙고 떨어질 수 있다. Raw 표본의 1→0 변화를 모두 누름으로 세면 한 동작을 여러 번 셀 수 있다. Debounce는 raw와 확정된 상태를 분리하여 짧은 변화를 곧바로 사건으로 바꾸지 않는 규칙이다.

이 단원의 종이 규칙은 같은 raw 값이 연속 3번 보이면 그 값을 확정한다. 새 값이 이전 raw와 다르면 count1로 다시 시작하고 같으면 count를 늘린다. Arduino 공식 예제는 시간 기준 대기를 사용하므로 이 연속 표본 규칙과 동일 구현이라고 말하지 않는다.

눌림 상태와 눌림 사건

확정 상태가 LOW로 유지되는 것과 HIGH→LOW로 바뀌는 누름 사건은 다르다. Active-low 입력에서 누름 횟수를 셀 때에는 확정 1→0 전환만 센다. 매 반복마다 LOW면 횟수를 늘리는 코드는 계속 누르는 한 동작을 반복 집계한다.

표본 간격이 달라지면 연속 3회의 시간 의미도 달라진다. 마지막 표본 3개만 보고 그 사이 전압이 계속 같았다는 물리 주장도 할 수 없다. 너무 긴 필터는 빠른 누름을 놓칠 수 있어 응답 지연·잡음 제거·실제 파형을 함께 평가해야 한다.

두 출력의 명령이 다르면 어느 쪽 논리값이 이길까요?

기본의 source와 sink를 새 두 드라이버의 저항 모형으로 비교한다. 한 노드에 드라이버 H와 L을 함께 연결한다. H는 이상적인 3.3 V 전원에 직렬 1 kΩ을 둔 HIGH 출력이고 L은 이상적인 0 V에 직렬 1 kΩ을 둔 LOW 출력이다. 입력 핀의 전류는 0이다. 실제 출력 회로의 특성이 아니라 자체 저항 모형이다. 노드는 1.65 V이고 H에서 L로 1.65 mA가 흐른다. 가상 입력의 LOW/HIGH 임계값을 적용하면 미정이다. 두 드라이버의 허용 전류를 각각 1 mA로 지정하면 둘 다 이 한도를 넘는다. 명령값 HIGH와 LOW를 논리 연산으로 합쳐 실제 노드를 정할 수 없다.

L의 직렬 저항만 2 kΩ으로 바꾸면 노드는 2.2 V로 HIGH이고 전류는 1.1 mA다. 이 경우에도 두 드라이버의 지정 한도 1 mA를 넘는다. 입력 논리 판정의 성공과 출력 전류 계약의 성공을 별도로 확인한다. 별도 이상적인 open-drain 모형에서는 각 드라이버가 0 V로 당기는 LOW 또는 전류를 흘리지 않는 high-Z 두 상태만 가진다. 외부 10 kΩ 풀업 하나를 3.3 V에 연결하면 둘 다 high-Z일 때만 노드가 HIGH이고 어느 하나라도 LOW면 노드는 LOW다. 두 LOW일 때의 전류 분담은 이 이상적 계약으로 정하지 않는다. 여기서는 전압과 풀업 총전류만 판정한다.

시작 순서도 별도 가상 레지스터 계약으로 추적한다. enable=0이면 출력은 high-Z이며 외부 풀업으로 노드가 HIGH다. enable=1이면 latch가 0일 때 LOW, latch가 1일 때 HIGH를 구동한다. 초기 enable과 latch는 모두 0이다. 연결된 active-low 표시기는 LOW에서 켜지고 HIGH에서 꺼진다고만 정의하며 표시기 입력 전류는 0이다. enable을 먼저 1로 만들면 잠깐 LOW가 되어 켜지고, 그 뒤 latch를 1로 쓰면 꺼진다. latch를 먼저 1로 쓴 뒤 enable을 1로 만들면 중간 상태와 최종 상태에서 모두 꺼져 있다. 이 두 필드의 추상 계약은 실제 Arduino pinMode나 특정 MCU 레지스터의 구현 보장이 아니다. 실제 부팅·주변 기능·래치 접근 규칙은 해당 기기의 문서를 별도로 확인한다.

전기 규격은 변수값이 아니다

소프트웨어는 핀의 모드와 출력 논리를 명령하지만 외부 회로의 전압 범위·전류·상승 시간·접지 경로가 그 명령의 물리 결과를 결정한다. 입력을 필터링해도 과전압 보호 회로가 생기는 것은 아니다. GPIO 출력에 큰 부하를 직접 연결해도 자료형 bool이 전류를 제한해 주지 않는다.

핀 번호와 기능도 보드별로 확인한다. 부팅/리셋 중 입력이나 기본 상태로 머무는 구간이 있을 수 있고, 주변장치 기능으로 배정된 핀은 일반 GPIO와 다른 동작을 할 수 있다. 실제 제품에서는 datasheet와 보드 회로도·초기화 순서를 함께 검증한다.

논리 극성을 회로에 연결한다

가상 회로 A는 GPIO→저항→LED→ground로 이어져 HIGH일 때 켜진다. 회로 B는 전원→저항→LED→GPIO로 이어져 LOW로 전류를 흡수할 때 켜진다. 따라서 같은 켜기 요구의 출력 비트가 반대일 수 있다. 이 설명은 전기 정격을 만족하는 이상적 출력 모형이다.

입력의 active-low와 출력의 active-low는 독립 설정이다. 눌림=입력 0을 뜻한다고 LED 켜기=출력 0이라고 자동 결정하지 않는다. 읽은 raw→확정 입력→논리 pressed→논리 led_on→핀 출력이라는 단계를 분리하면 회로 극성이 바뀌어도 업무 의미를 유지하기 쉽다.

시험을 어느 층에서 했는지

종이 상태표는 입력열에 대한 논리 동작을 검사한다. 실제 전압을 측정한 것도, 핀에 필요한 전류가 흐른 것도 아니다. 회로 시험에는 전압·전류·파형·시작 상태를, 소프트웨어 시험에는 상태 전환·시간 정책·오류 처리를 서로 맞추어 남긴다.

정한 목표가 빠른 전환을 모두 기록하는 것이면 필터의 지연과 누락도 오류가 될 수 있다. 긴 debounce가 보기에는 안정적이어도 요구사항을 만족하는지는 별개다. 이 원고에서는 장치 연결 없이 조건과 반례로 각 층의 책임을 배운다.

연습 1 · 값과 상태 예측

두 open-drain A와 B는 각각 LOW 또는 high-Z만 가능하다. 조합 (LOW,LOW), (LOW,high-Z), (high-Z,LOW), (high-Z,high-Z)의 노드 전압을 나열하라. 외부 풀업은 3.3 V와 10 kΩ이다.

힌트 1

한 드라이버라도 이상적인 0 V 경로를 만들면 노드는 0 V다.

힌트 2

모두 high-Z이면 외부 풀업이 노드를 올린다.

풀이와 답 확인

  1. latch를 먼저 1로 써 중간 상태 (0,1)을 만든다. 노드는 풀업 HIGH다.

  2. 그다음 enable을 1로 써 최종 (1,1)의 HIGH 출력을 만든다.

latch를 먼저 쓰고 enable을 나중에 켠다. 이것은 지정 두 필드 모형의 결과다.

입력 판정·확정 사건·시작 출력을 각각 기록하기

새 가상 장치는 3.3 V에서 위쪽 10 kΩ 풀업과 아래쪽 외부 20 kΩ 저항을 사용하며 입력 임계값은 LOW≤0.8 V, HIGH≥2.0 V다. 스위치가 닫히면 노드를 이상적으로 0 V로 만든다. 열린 때 전압과 판정을 구하라. 별도 기록에서 초기 확정 1인 필터 C와 D가 0, 1, 100 ms에 원시 [0,0,0]을 읽는다. C는 연속 세 번, D는 현재 후보 시작에서 경과 >50 ms일 때 확정한다. 두 확정 시각과 물리 연속 눌림의 확인 가능 여부를 설명하라. 마지막으로 active-low 표시기의 가상 enable/latch가 초기 (0,0)에서 최종 (1,1)로 가는 두 쓰기 순서를 비교하라. enable=0은 high-Z이며 외부 풀업으로 HIGH이고 enable=1은 latch 값대로 구동한다. 표시기 입력 전류는 0이며 LOW에서 켜지고 HIGH에서 꺼진다. 이 세 회로·기록은 각각 지정한 독립 모형이며 실제 보드 실행은 하지 않는다.

힌트 2

중간 enable/latch 상태와 최종 상태를 모두 기록한다.

풀이와 답 확인

  1. 열린 스위치에서 전류는 0.11 mA이고 노드 전압은 2.2 V이므로 HIGH다. 닫힌 스위치의 노드는 지정 이상적 경로로 0 V다.

  2. C의 연속 횟수는 1, 2, 3이므로 100 ms에 눌림을 확정한다. D의 후보 시작은 0 ms이고 100 ms의 경과는 50 ms보다 커 같은 시각에 확정한다. 각 필터의 누름 사건은 한 번이다.

  3. 표본 사이 20–30 ms에 잠깐 원시 상태 1이었던 물리 이력도 같은 세 표본을 만들 수 있다. 따라서 100 ms 동안 계속 눌렸다는 결론은 기록만으로 확정하지 않는다.

  4. enable 먼저는 중간 (1,0)의 LOW로 표시기가 켜지고 최종 (1,1)에서 꺼진다. latch 먼저는 중간 (0,1)에서 풀업 HIGH로 꺼져 있으며 최종에도 꺼져 있다.

열린 입력은 2.2 V로 HIGH다. 두 필터는 지정 기록에서 100 ms에 한 번 누름을 확정하지만 물리 연속 상태는 미확정이다. 표시기의 중간 켜짐을 피하려면 가상 계약에서 latch를 먼저 1로 쓰고 enable을 나중에 켠다.
