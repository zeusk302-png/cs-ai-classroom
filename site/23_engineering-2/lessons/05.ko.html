소단원 5.1

sine·cosine 급수

양수 구간만 주어진 그래프도 sine만 또는 cosine만으로 펼칠 수 있을까?

준비 개념과 학습 목표

준비 개념

  • 함수 내적은 구간에서 곱을 적분한다.
  • 직교 함수는 서로의 내적이 0이다.

학습 목표

  • 반구간 계수의 정규화 상수를 구한다.
  • 상수항과 끝점을 구별한다.

0~L에서의 두 가지 좌표계

L>0일 때 sine 반구간 전개는 Σ(n ≥1)b_n sin(n πx/L)다. cosine 전개는 A0 +Σ(n ≥1)A_n cos(n πx/L)다. 두 전개는 같은 원함수의 0<x<L 값을 표현할 수 있으나 음수 구간으로의 확장은 서로 다르다.

함수가 원래 홀수여야 sine 전개가 가능하다는 조건은 없다. 원자료가 양수 구간에만 있으면 이후 홀/ 짝 확장을 선택한다. 여기서는 조각별 매끄러운 함수의 계수와 내부점 수렴을 다루며 끝점은 별도로 읽는다.

직교성으로 계수 분리하기

0~L에서 sine의 같은 n 제곱 적분은 L/2이고 다른 n,m 곱 적분은 0이다. 따라서 함수에 sin(m πx/L)을 곱해 적분한 뒤 L/2로 나누면 b_m =(2/L)∫f(x)sin(m πx/L)dx다.

cosine도 n ≥1에서는 같은 L/2 규칙을 쓴다. 그러나 상수 함수 1의 제곱 적분은 L이므로 A0 =(1/L)∫f다. 이 단원은 상수항을 A0 그대로 쓰며 a0/2 관례와 혼합하지 않는다.

같은 내부와 다른 경계 해석

모든 sine 부분합은 x =0,L에서 0이다. 따라서 f가 끝점에서 1이라고 지정되어 있어도 sine 급수를 그 점에 대입하면 0이다. 이는 내부의 f를 표현할 수 있다는 사실과 모순되지 않는다. 끝점 하나의 값은 계수적분을 바꾸지 않는다.

cosine 전개에는 상수항이 있어 상수 함수도 그대로 표현한다. 유한 부분합을 미분하면 양 끝 기울기 0이나, 임의 무한 급수의 미분과 끝점 평가는 정당화 조건 없이 바꾸지 않는다. 경계 조건과 점별/ 적분적 표현을 구별한다.

중간 과정을 따라가는 예제

0<x<π에서 f(x)=1의 sine와 cosine 반구간 계수를 구하라.

  1. L =π이다. b_n =(2/ π)∫0 ^π sin(nx)dx =(2/ π)[−cos(nx)/n]0 ^π이다.
  2. 따라서 b_n =2(1 −(−1)^n)/(πn)이다. 짝수 n은 0, 홀수 n은 4/(πn)이다.
  3. cosine의 A0 =(1/ π)∫0 ^π1dx =1이며 A_n =(2/ π)[sin(nx)/n]0 ^π=0이다.
  4. sine 전개는 내부에서 1을, 양 끝에서 0을 나타낸다. cosine 전개는 상수 1 하나로 끝점까지 1이다.

sine 계수는 홀수 차 4/(πn), cosine은 A0 =1뿐이다.

종이와 본문으로 직접 해보기

힌트 보기

소단원 5.2

홀·짝 확장

양수 구간 그래프를 왼쪽에 거울처럼 붙일 때 높이의 부호도 바꿔야 할까?

준비 개념과 학습 목표

준비 개념

  • 홀 함수는 F(−x)=−F(x), 짝 함수는 F(−x)=F(x)를 만족한다.
  • 반구간은 0<x<L이다.

학습 목표

  • 홀· 짝 확장을 구간별로 쓴다.
  • 확장에서 생긴 점프를 발견한다.

확장은 없는 자료를 명시적으로 정하는 선택

주어진 f가 0<x<L에만 있다면 홀 확장은 음수 x에서 F_o(x)=−f(−x), 양수 x에서 f(x)로 정한다. 짝 확장은 음수 x에서 F_e(x)=f(−x)이며 양수 x에서는 같다. −x는 원자료의 양수 좌표를 가리킨다.

홀 확장에는 원점을 0으로 정해야 홀 성질이 성립한다. 원자료의 오른쪽 극한이 0이 아니면 원점에 점프가 생긴다. 짝 확장은 같은 높이를 반사하므로 원점 좌우 극한이 같지만 미분 가능성이 자동으로 보장되지는 않는다.

대칭이 계수를 없애는 과정

홀 함수에 짝 함수 cosine을 곱하면 홀 함수라 −L~L적분이 0이다. 따라서 홀 확장의 전체 Fourier 급수에는 sine만 남는다. 홀 함수와 sine의 곱은 짝수라 음수 구간 기여를 양수 구간의 2배로 바꾼다.

짝 확장은 sine과 곱하면 홀수가 되어 sine 계수가 0이다. cosine과 곱한 짝 함수 적분은 양수 구간의 2배가 된다. 이렇게 전체 급수의 1/L 계수가 반구간의 2/L 계수로 이어진다. 상수항은 별도 평균이다.

주기 붙이기와 끝점 확인

확장을 −L<x<L에 정한 뒤 2L 주기로 반복하면 왼 끝과 오른 끝에서도 접합이 생긴다. 홀 확장의 좌우 끝 극한은 −f(L −)와 f(L −)라 보통 다르고, 짝 확장은 끝 높이는 같지만 기울기가 접합에서 다를 수 있다.

따라서 원래 양수 구간에서 매끄러운 함수라도 주기 확장은 점프나 모서리를 가질 수 있다. 계수 계산은 가능하지만 점프 점의 급수는 통상 좌우 극한 평균으로 읽는다. 한 확장을 다른 확장의 값으로 해석해서는 안 된다.

중간 과정을 따라가는 예제

0<x<1에서 f(x)=2 +x다. 홀· 짝 확장의 −1/4값, 원점 좌우 극한, 주기 2 접합의 높이를 비교하라.

  1. x<0에서 홀 확장은 −(2 −x)=−2 +x, 짝 확장은 2 −x다.
  2. x =−1/4일 때 홀은 −9/4, 짝은9/4다. 원래 f(1/4)=9/4이다.
  3. 원점에서 홀의 좌 극한 −2/ 우극한 2 라 점프하며 홀 원점 값 0이다. 짝의 두 극한은 2다.
  4. 홀의 −1 오른쪽 극한 −3 과 1 왼쪽 극한 3은 주기 접합에서 점프한다. 짝의 양 끝 극한은 3으로 같다.

같은 양수 자료에서 홀· 짝 음수 값이 달라지고 매끄러움도 달라진다.

종이와 본문으로 직접 해보기

f(x)=x on(0,1)을 홀· 짝 확장하고 원점에서 미분 가능성을 검사하라.

힌트 보기

홀은 −f(−x), 짝은f(−x)를 대입해 단순화한다.

풀이 보기

홀 확장은 모든 내부 x에서 x 라 원점 기울기 1로 매끄럽다. 짝 확장은 |x|라 원점 좌기울기 −1/ 우기울기 1 이어서 미분 불가능하다.

오해와 반례

원함수가 양수 구간에서 홀 함수인지 알아야 홀 확장을 할 수 있다.

음수 값을 정하지 않은 반구간 자료에는 홀/ 짝 성질을 판정할 상대 점이 없다. 확장은 자료 밖을 만드는 선택이며 f =2 +x도 홀 확장 가능하다.

소단원 5.3

경계 조건과 기저 선택

막대 끝에서 온도를 고정하는 것과 열 흐름을 막는 것은 같은 sine을 쓰면 될까?

준비 개념과 학습 목표

준비 개념

  • u_x는 공간 방향 기울기다.
  • sin·cos의 미분과 끝점 값을 알고 있다.

학습 목표

  • 값 조건과 미분 조건을 구별한다.
  • 공간 고유 함수에 경계를 직접 대입한다.

값과 기울기가 서로 다른 경계를 나타낸다

Dirichlet 조건은 u(0,t)=u(L,t)=0처럼 끝의 값을 정한다. 온도라면 기준 온도 대비 편차 0으로 해석할 수 있다. Neumann 조건 u_x(0,t)=u_x(L,t)=0은 기울기가 0인 조건이다. 열 흐름이 기울기에 비례하는 모형에서는 절연을 뜻한다.

sin(n πx/L)은 양 끝 값 0이며 cos(n πx/L)의 미분 −(n π/L)sin(n πx/L)은 양 끝 0이다. 이 성질 때문에 해당 경계를 만족하는 함수들을 조합할 좌표계로 선택한다. 원함수의 겉모양보다 문제가 요구하는 경계가 먼저다.

고유값으로 허용 주파수를 고르기

분리 변수의 공간 문제 X ″+λX =0에서 λ=k²>0일 때 X =Acos(kx)+Bsin(kx)다. 양 끝 값 0이면 X(0)=A =0이고 X(L)=Bsin(kL)=0이다. 비영해는 kL =n π라 sine 기저가 나온다.

양 끝 기울기 0이면 X ′(0)=Bk =0이라 B =0이고 X ′(L)=−Aksin(kL)=0이다. 양의 λ에서는 같은 n π/L의 cosine이 남는다. λ=0의 X =A +Bx도 검사해야 하며 Neumann은 상수 A를 허용하지만 양 끝 Dirichlet은 0밖에 없다.

혼합 경계와 비동차 값의 처리

왼값 0/ 오른 기울기 0이면 X =Bsin(kx),X ′(L)=Bkcos(kL)=0이므로 kL =(n +1/2)π,n =0,1,…다. 같은 막대라도 경계가 바뀌면 주파수 목록도 바뀐다. 이는 삼각 함수에 직접 조건을 대입해서 얻은 결과다.

끝 값이 0 아닌 상수 a,b이면 먼저 ℓ(x)=a +(b −a)x/L를 빼 v =u −ℓ로 양 끝 값 0을 만들 수 있다. 원래 u 전체를 0 경계 sine 부분합으로 맞추려 하지 않는다. 시간 변화/ 외력에 따라 방정식의 추가 항도 함께 다시 계산해야 한다.

중간 과정을 따라가는 예제

L =π인 X ″+λX =0에서 양 끝 Dirichlet, 양끝 Neumann, 왼 Dirichlet/ 오른 Neumann의 첫 비영 공간 모드를 구하라.

  1. 양 끝 값 0에서 최소 양의 k =1이므로 X =sin x, λ=1이다.
  2. 양 끝 기울기 0에는 상수 X =1, λ=0 가 이미 비영해다. 첫 양의 λ는 cos x, λ=1이다.
  3. 혼합 조건에서는 k π=π/2이므로 X =sin(x/2), λ=1/4이다.
  4. 혼합 모드의 X(0)=0,X ′(π)=(1/2)cos(π/2)=0을 대입한다. 양 끝 Dirichlet과는 X(π)=1이라 호환되지 않는다.

기저를 경계별로 고른다. Neumann 상수 모드를 누락하지 않는다.

종이와 본문으로 직접 해보기

힌트 보기

풀이 보기

오해와 반례

cosine만 쓰면 항상 0 온도 경계도 만족한다.

cos(n π·0/L)=1이다. 예를 들어 cos x의 왼값 1은 0 값 조건을 어긴다. cosine이 기본적으로 맞추는 것은 미분 0 경계다.

소단원 5.4

초기분포의 계수 계산

처음 막대의 모양을 알면 각 공간 모드가 얼마나 들어 있는지 어떻게 계산할까?

준비 개념과 학습 목표

준비 개념

  • sine 반구간 계수는 2/L 내적이다.
  • 부분적분 ∫u dv =uv −∫v du를 쓴다.

학습 목표

  • 초기 조건을 공간 기저에 투영한다.
  • 계수와 시간 변화를 구별한다.

초기 조건은 모드의 크기를 정한다

경계에 맞는 공간 함수를 먼저 고른 뒤 초기 분포 f를 그들의 합으로 쓴다. 양 끝 0 값 조건에서는 b_n =(2/L)∫0 ^L f(x)sin(n πx/L)dx다. 계수는 f가 해당 모드 방향으로 얼마나 기여하는지 나타내며 부호도 가능하다.

f가 조각별 함수이면 적분을 각 구간으로 나눈다. 계수 정규화 2/L를 빠뜨리지 않고 길이 L과 좌표 단위를 먼저 고정한다. 초기 분포가 경계와 호환하는지도 별도로 확인하며 끝점 한 개 값으로 적분을 고칠 수 없다.

부분적분으로 다항식 계수를 계산하기

L =π,f =x(π−x)는 양 끝 0이다. I_n =∫0 ^π f sin(nx)dx에서 첫 부분적분의 경계 항은 f가 0이라 사라지고 I_n =(1/n)∫f ′cos(nx)dx다. 두 번째 부분적분에서 sin 끝 값 0을 사용하면 I_n =−(1/n²)∫f ″sin(nx)dx다.

f ″=−2이므로 I_n =(2/n²)∫sin(nx)dx =2(1 −(−1)^n)/n³다. b_n =(2/ π)I_n =4(1 −(−1)^n)/(πn³)이다. 짝수 차수는 0이고 홀수 차수는 8/(πn³)라 높은 차수의 계수가 빨리 작아진다.

계수는 초기 자료, 시간 인자는 방정식에서

열 방정식 u_t =κu_xx, κ>0,0 경계에서 각 모드는 sin(nx)e ^(−κn²t)로 변한다. L =π일 때 이 시간 인자는 미분해서 확인할 수 있다. t =0에서는 지수가 1이라 초기 계수 b_n가 남는다.

초기 계수가 같더라도 열· 파동 방정식의 시간 인자는 다르다. 공간 급수만으로 모든 미래 물리를 확정하지 않는다. 여기서 열 모형의 지수 감쇠는 제시한 PDE와 동차 경계의 결과이며 실제 막대 측정이나 학습자 실험을 수행한 것은 아니다.

중간 과정을 따라가는 예제

L =π,f =x(π−x)의 sine 계수 b1,b2,b3를 구하고 첫 모드만 남긴 초기 근사 S1(π/2)을 구하라.

  1. 부분적분 두 번으로 I_n =2(1 −(−1)^n)/n³ 를 얻는다.
  2. 2/ π를 곱하면 b1 =8/ π,b2 =0,b3 =8/(27 π)다.
  3. S1(x)=(8/ π)sin x이므로 S1(π/2)=8/ π다.
  4. 원래 f(π/2)=π²/4다. 단일 모드 값과 정확 값은 같지 않으므로 첫 항만으로 정확히 복원했다고 주장하지 않는다.

b1 =8/ π,b2 =0,b3 =8/(27 π). 첫 모드만은 근사이며 전체 급수와 구별한다.
