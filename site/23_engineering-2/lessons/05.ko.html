소단원 5.1

sine·cosine 급수

양수 구간만 주어진 그래프도 sine만 또는 cosine만으로 펼칠 수 있을까?

준비 개념과 학습 목표

준비 개념

  • 함수 내적은 구간에서 곱을 적분한다.

  • 직교 함수는 서로의 내적이 0이다.

학습 목표

  • 반구간 계수의 정규화 상수를 구한다.

  • 상수항과 끝점을 구별한다.

같은 직선 자료를 두 좌표계로 읽으면 계수와 끝점도 같을까?

새 자료는 0<x<2에서 f(x)=x다. 여기 길이는 L=2이고 sine의 각도는 nπx/2다. 앞 본문의 상수 예제와 달리 이 직선은 sine에서도 cosine에서도 여러 계수가 필요하다. sine 계수 b_n=∫₀² x sin(nπx/2)dx는 부분적분으로 4(−1)^(n+1)/(nπ)다. 길이 2를 각도와 적분의 양쪽에 반영해야 한다.

cosine의 상수항은 A₀=(1/2)∫₀² x dx=1이고 n≥1의 계수는 A_n=∫₀² x cos(nπx/2)dx=4[(−1)^n−1]/(n²π²)다. 홀수 계수는 −8/(n²π²), 짝수 계수는 0이다. 같은 직선 자료라도 확장 선택이 달라 계수의 감소율과 주파수 종류가 다르다. 상수항을 A₀ 그대로 더하는 관례를 유지한다.

sine의 모든 유한합은 양 끝에서 0이고, cosine 급수는 연속인 짝 주기 확장의 양 끝 값 0과 2로 수렴한다. 그러나 모든 유한 cosine 합의 끝점 도함수는 0인 반면 직선의 안쪽 기울기는 1이다. 함수의 급수 수렴만으로 도함수의 끝점 수렴을 보장하지 않는다. 직선 전체를 0 경계의 실제 정상 온도로 해석하는 것도 별도 문제다.

먼저 확인할 개념
  • 반구간 정규화와 끝점

    같은 L=2를 계수와 기저의 각도에 함께 사용한다.

  • 서로 다른 주기 확장

    양수 구간의 같은 자료가 음수 구간에서는 다른 자료가 됨을 확인한다.

0~L에서의 두 가지 좌표계

L>0일 때 sine 반구간 전개는 Σ(n ≥1)b_n sin(n πx/L)다. cosine 전개는 A0 +Σ(n ≥1)A_n cos(n πx/L)다. 두 전개는 같은 원함수의 0<x<L 값을 표현할 수 있으나 음수 구간으로의 확장은 서로 다르다.

함수가 원래 홀수여야 sine 전개가 가능하다는 조건은 없다. 원자료가 양수 구간에만 있으면 이후 홀/ 짝 확장을 선택한다. 여기서는 조각별 매끄러운 함수의 계수와 내부점 수렴을 다루며 끝점은 별도로 읽는다.

직교성으로 계수 분리하기

0~L에서 sine의 같은 n 제곱 적분은 L/2이고 다른 n,m 곱 적분은 0이다. 따라서 함수에 sin(m πx/L)을 곱해 적분한 뒤 L/2로 나누면 b_m =(2/L)∫f(x)sin(m πx/L)dx다.

cosine도 n ≥1에서는 같은 L/2 규칙을 쓴다. 그러나 상수 함수 1의 제곱 적분은 L이므로 A0 =(1/L)∫f다. 이 단원은 상수항을 A0 그대로 쓰며 a0/2 관례와 혼합하지 않는다.

같은 내부와 다른 경계 해석

모든 sine 부분합은 x =0,L에서 0이다. 따라서 f가 끝점에서 1이라고 지정되어 있어도 sine 급수를 그 점에 대입하면 0이다. 이는 내부의 f를 표현할 수 있다는 사실과 모순되지 않는다. 끝점 하나의 값은 계수적분을 바꾸지 않는다.

cosine 전개에는 상수항이 있어 상수 함수도 그대로 표현한다. 유한 부분합을 미분하면 양 끝 기울기 0이나, 임의 무한 급수의 미분과 끝점 평가는 정당화 조건 없이 바꾸지 않는다. 경계 조건과 점별/ 적분적 표현을 구별한다.

소단원 5.2

홀·짝 확장

양수 구간 그래프를 왼쪽에 거울처럼 붙일 때 높이의 부호도 바꿔야 할까?

준비 개념과 학습 목표

준비 개념

  • 홀 함수는 F(−x)=−F(x), 짝 함수는 F(−x)=F(x)를 만족한다.

  • 반구간은 0<x<L이다.

학습 목표

  • 홀· 짝 확장을 구간별로 쓴다.

  • 확장에서 생긴 점프를 발견한다.

끝 높이는 같은데 반사 방향에 따라 모서리는 어디에 생길까?

새 자료 f(x)=x(2−x)는 0<x<2에서 양 끝 한쪽 값이 0이다. 홀 확장의 음수 부분은 −f(−x)=2x+x²이고 짝 확장은 f(−x)=−2x−x²다. x=−1/2에서 홀 확장은 −3/4, 짝 확장은 3/4다. 같은 양수 자료의 음수 부분은 관측으로 주어진 것이 아니라 확장 계약으로 만든 것이다.

홀 확장은 0의 양쪽 기울기가 모두 2라 C1이며 원점에서 둘째 도함수는 왼쪽 2, 오른쪽 −2로 다르다. 짝 확장은 0에서 왼쪽 기울기 −2, 오른쪽 2라 연속이지만 미분 불가능하다. 높이가 0이라는 조건은 홀 확장의 연속성을 돕지만 모든 차수의 매끄러움을 보장하지 않는다.

주기 4로 붙이는 양 끝에서도 값을 넘어 도함수를 확인한다. 홀 확장의 −2 오른쪽 기울기와 2 왼쪽 기울기는 모두 −2라 C1 접합이고 둘째 미분은 다르다. 짝 확장은 같은 접합에서 기울기가 −2에서 2로 바뀌어 모서리가 생긴다. 짝 확장이 항상 끝점 기울기 0을 갖는다는 결론은 확장 함수 자체와 각 유한 cosine 합을 혼동한 것이다.

먼저 확인할 개념
  • 홀·짝 반사와 주기 접합

    음수 공식과 원점/주기 양끝을 각각 계산한다.

  • 유한합과 미분 극한 구별

    유한 cosine 합의 기울기와 원자료의 한쪽 기울기를 혼동하지 않는다.

확장은 없는 자료를 명시적으로 정하는 선택

주어진 f가 0<x<L에만 있다면 홀 확장은 음수 x에서 F_o(x)=−f(−x), 양수 x에서 f(x)로 정한다. 짝 확장은 음수 x에서 F_e(x)=f(−x)이며 양수 x에서는 같다. −x는 원자료의 양수 좌표를 가리킨다.

홀 확장에는 원점을 0으로 정해야 홀 성질이 성립한다. 원자료의 오른쪽 극한이 0이 아니면 원점에 점프가 생긴다. 짝 확장은 같은 높이를 반사하므로 원점 좌우 극한이 같지만 미분 가능성이 자동으로 보장되지는 않는다.

대칭이 계수를 없애는 과정

홀 함수에 짝 함수 cosine을 곱하면 홀 함수라 −L~L적분이 0이다. 따라서 홀 확장의 전체 Fourier 급수에는 sine만 남는다. 홀 함수와 sine의 곱은 짝수라 음수 구간 기여를 양수 구간의 2배로 바꾼다.

짝 확장은 sine과 곱하면 홀수가 되어 sine 계수가 0이다. cosine과 곱한 짝 함수 적분은 양수 구간의 2배가 된다. 이렇게 전체 급수의 1/L 계수가 반구간의 2/L 계수로 이어진다. 상수항은 별도 평균이다.

주기 붙이기와 끝점 확인

확장을 −L<x<L에 정한 뒤 2L 주기로 반복하면 왼 끝과 오른 끝에서도 접합이 생긴다. 홀 확장의 좌우 끝 극한은 −f(L −)와 f(L −)라 보통 다르고, 짝 확장은 끝 높이는 같지만 기울기가 접합에서 다를 수 있다.

따라서 원래 양수 구간에서 매끄러운 함수라도 주기 확장은 점프나 모서리를 가질 수 있다. 계수 계산은 가능하지만 점프 점의 급수는 통상 좌우 극한 평균으로 읽는다. 한 확장을 다른 확장의 값으로 해석해서는 안 된다.

초기 조건은 모드의 크기를 정한다

경계에 맞는 공간 함수를 먼저 고른 뒤 초기 분포 f를 그들의 합으로 쓴다. 양 끝 0 값 조건에서는 b_n =(2/L)∫0 ^L f(x)sin(n πx/L)dx다. 계수는 f가 해당 모드 방향으로 얼마나 기여하는지 나타내며 부호도 가능하다.

f가 조각별 함수이면 적분을 각 구간으로 나눈다. 계수 정규화 2/L를 빠뜨리지 않고 길이 L과 좌표 단위를 먼저 고정한다. 초기 분포가 경계와 호환하는지도 별도로 확인하며 끝점 한 개 값으로 적분을 고칠 수 없다.

먼저 답과 이유를 적고, 필요한 만큼 힌트를 한 단계씩 열어 보세요.

연습 1 · 값과 상태 예측

κ=1일 때 sine n=2와 cosine n=3 항의 시간 인자와 부호를 적어라.

힌트 1

고유값은 (nπ/2)²이다.

힌트 2

계수 부호는 적분 결과다.

풀이와 답 확인

  1. sine n=2 항은 (2/π)e^(−π²t)sin(πx)다.

  2. cosine n=3 항은 −[2/(3π)]e^(−9π²t/4)cos(3πx/2)다.

시간 감쇠와 공간 계수 부호를 각각 기록한다.

흔한 오답에서 다시 생각하기

n=3의 음수 계수는 지수 증가를 뜻한다.

계수 부호와 지수의 음의 감쇠율은 다른 정보다.

연습 2 · 오류 찾아 고치기

초기 x=1의 저장 값 9를 재현하려고 cosine 평균을 9로 바꿨다. 고쳐라.

힌트 1

한 점은 초기 적분에 영향을 주지 않는다.

힌트 2

원래 평균은 1/2다.

풀이와 답 확인

  1. 계수와 전체 초기 적분은 그대로다.

  2. 점프의 평균 1/2와 저장 값 9를 구별한다.

상수항 9는 전체 내부 자료의 평균을 바꾸는 오류다.

흔한 오답에서 다시 생각하기

한 점의 지정값이 모든 공간 평균을 결정한다.

평균은 구간 적분과 길이로 계산한다.

연습 3 · 직접 만들어 보기

같은 초기 자료에 절연 경계를 선택한 해의 첫 cosine 진동항 근사와 전체 적분을 구성하라.

힌트 1

상수 1/2를 남긴다.

힌트 2

cos(πx/2)의 구간 적분은 0이다.

풀이와 답 확인

  1. U₁=1/2+(2/π)e^(−κπ²t/4)cos(πx/2)다.

  2. 모든 시간의 ∫₀²U₁ dx=1이지만 초기 계단을 모든 점에서 정확히 복원하지 않는다.

보존 성질과 절단 근사의 정확성은 별도 검사다.

흔한 오답에서 다시 생각하기

전체 적분이 같으므로 두 초기 함수는 동일하다.

많은 서로 다른 함수가 같은 적분을 가질 수 있다.

연습 4 · 선택 심화

선택 심화는 기본 연습 뒤 더 탐구하고 싶을 때 풀어 보세요.

0 값 경계의 첫 sine 항 근사는 같은 초기 전체 적분 1을 보존하나? 초기 끝점 호환성까지 설명하라.

힌트 1

첫 항은 (2/π)e^(−κπ²t/4)sin(πx/2)다.

힌트 2

이 sine의 구간 적분은 4/π다.

풀이와 답 확인

  1. 근사의 전체 적분은 (8/π²)e^(−κπ²t/4)로 감소한다. 초기 값도 1이 아닌 절단 근사다.

  2. 초기 오른쪽 극한 f(0+)=1과 경계 0이 충돌하여 (0,0)에서 연속 고전적 초기해를 주장하지 않는다.

절연의 보존 증명을 이 경계에 그대로 붙이지 않는다.

끝의 기울기/열 유출 조건과 초기 호환성이 달라진다.

다른 문제에 적용하기

네 부분은 각각 독립 모형이다. ① 길이 2의 직선 f=x에 대해 b₂,A₀,A₁과 sine/cosine의 x=2 극한을 적어라. ② f=x(2−x)의 홀/짝 주기 확장이 원점에서 C1인지 검사하라. ③ u_t=u_xx, 끝 값 2와 2+t에서 ℓ를 빼 새 강제항과 초기 c₁(0)=0인 첫 모드 계수를 구하라. ④ 0<x<1에서 1,1<x<2에서 0인 초기 자료의 절연 열 모형과 0 값 경계 모형을 평균 보존·점프 값·초기 호환성으로 비교하라.

힌트 1

계수의 각도에 L=2를 넣고 상수항과 진동항의 노름을 따로 사용한다.

힌트 2

주기 접합의 좌우를 계산하고, 경계 함수를 뺄 때 시간 미분까지 남긴 뒤 전체 적분의 경계 항을 검사한다.

풀이와 답 확인

  1. 직선은 b₂=−2/π,A₀=1,A₁=−8/π²다. x=2의 sine 극한은 0, cosine 극한은 2다.

  2. 포물선 홀 확장은 원점 기울기가 양쪽 2라 C1이고 짝 확장은 −2 대 2라 C1이 아니다. 홀의 둘째 미분은 양쪽에서 달라 C2도 아니다.

  3. ℓ=2+tx/2를 빼면 v_t=v_xx−x/2다. 첫 강제 계수는 −2/π, 고유값은 π²/4라 c₁(t)=−(8/π³)(1−e^(−π²t/4))다.

  4. 초기 적분은 1이고 절연의 상수항 1/2는 감쇠하지 않는다. 0 값 경계에는 상수 모드가 없으며 유출을 0이라고 가정하지 않는다. x=1의 초기 급수 극한은 두 경우 모두 1/2이고 저장 점값 9를 복원하지 않는다. 0 값 경계에서는 f(0+)=1과 경계 0이 충돌한다.

기저·확장·경계 변환·초기 투영과 보존성의 계약을 차례로 분리한다. 모든 계산은 이상 모형의 손유도이며 실제 막대·PDE 솔버·학습자 실험의 결과가 아니다.
