소단원 4.1

조각별 매끄러운 함수

모서리나 점프가 있는 파형도 삼각함수로 분석할 수 있을까?

준비 개념과 학습 목표

준비 개념

  • 실수 함수의 2π 주기 전개는 a0/2+Σ(an cos nx+bn sin nx)이며 an=(1/π)∫f cos nx, bn=(1/π)∫f sin nx 다.
  • S_N 은 n=1 부터 N 까지의 유한 부분합이다. 무한합과 유한합을 구별한다.
  • 끝점은 주기확장으로 이어 붙인 뒤 한쪽 극한을 판단한다.

학습 목표

  • 수렴 정리에 사용할 조각별 C1 조건을 검사한다.
  • 충분조건과 필요조건, 한 점의 값과 적분 계수를 구별한다.

유한 개의 구간으로 나누기

여기서 조각별 매끄러움은 한 주기를 유한한 분할로 나누어 각 열린 조각에서 f 가 C1 이고 조각 양끝에서 f 와 f′의 유한 한쪽 극한이 존재하는 조건으로 정한다. C1 은 도함수가 존재하고 그 도함수가 연속이라는 뜻이다. 점프에서는 좌우 극한이 서로 달라도 되지만 각 극한은 유한해야 한다.

원래 함수가 모서리점에서 미분되지 않아도 양옆 조각에서는 조건이 성립할 수 있다. |x|는 0 에서 도함수가 없지만 왼쪽−1·오른쪽 1 의 유한 도함수 극한을 갖는다. 서로 다른 조각을 한 식으로 매끄럽게 이어야 한다는 조건은 아니다. 이 정의는 간단한 수렴 정리에 쓸 충분조건이며 Fourier 수렴의 모든 가능성을 설명하는 필요조건은 아니다.

한 점의 변경이 지워지는 이유

적분에서 유한 개 점의 값만 바꾸면 함수와 삼각함수 곱의 적분은 바뀌지 않는다. 따라서 같은 조각의 함수라도 점프점에 어떤 값을 지정했는지는 Fourier 계수에서 드러나지 않는다. 부분합과 그 극한은 지정한 점값보다 주변의 한쪽 극한을 반영한다.

유한 한쪽 극한 조건은 조각 내 C1 만 확인해 끝내지 말라는 뜻이다. √|x|는 0 에서 연속이고 양쪽 열린 조각 C1 이지만 도함수가 0 가까이에서 발산한다. 여기 정한 충분조건으로는 승인할 수 없다. 이것만으로 그 함수의 Fourier 급수가 발산한다고 결론 내리지 않는다.

규칙적인 조각이 주는 수렴 범위

이 조건이면 연속점에서는 부분합이 f(x)에, 점프에서는 좌우 극한 평균에 수렴한다. 주기 끝에서는 마지막 조각 끝과 첫 조각 시작을 연결한다. 고정된 한 점에서의 수렴은 모든 점에서 같은 오차를 보장하는 균등 수렴과 다르다.

점프에서 떨어진 닫힌 구간에서는 이 조건 아래 균등 수렴을 논할 수 있지만 점프를 포함하는 전체 주기에서 불연속 함수를 연속 부분합으로 균등 근사할 수는 없다. 연속 함수들의 균등 극한은 연속이라는 사실이 장애다. 반면 제곱 오차 적분은 작아질 수 있으므로 수렴 방식의 이름과 범위를 반드시 함께 쓴다.

중간 과정을 따라가는 예제

f(x)=|x|를[−π,π]에서 2π 주기확장한다. 필요한 분할·한쪽 극한·주기 경계의 연속성을 검사하라.

  1. 분할점은−π,0,π다. 열린 왼쪽은 f=−x, 오른쪽은 f=x 로 C1 이다.
  2. 0 에서 f 의 좌우 극한은 0, 도함수는−1 과 1 로 모두 유한하다.
  3. 끝 함수 극한은 f(−π+)=π, f(π−)=π여서 주기확장 함수는 끝에서 연속이다.
  4. 끝 도함수는−1 과 1 로 달라 모서리가 생기지만 각 한쪽 극한은 유한하므로 조건을 만족한다.

0 과 주기 경계에 모서리는 있지만 조각별 C1 조건은 만족한다.

종이와 본문으로 직접 해보기

g(x)=−1(−π<x<0), +1(0<x<π), g(0)=50 이라 하자. 조각 조건과 0 의 급수 극한을 구하라. g(0)을 0 으로 바꾸면 계수가 변하는지도 판단하라.

힌트 보기

각 조각의 도함수는 0 이다. 한 점의 지정값과 좌우−1/+1 을 분리한다.

풀이 보기

오해와 반례

조각별 C1 조건을 만족하지 않으면 급수는 반드시 발산한다.

이 조건은 충분조건이다. √|x|의 도함수 극한이 무한하므로 여기 정리를 적용하지 못하지만 이 사실 하나로 발산을 판정할 수 없다.

소단원 4.2

끝점·점프에서의 수렴

원래 파형의 끝값과 급수의 끝값이 다르면 계수를 잘못 계산한 것일까?

준비 개념과 학습 목표

준비 개념

  • 실수 함수의 2π 주기 전개는 a0/2+Σ(an cos nx+bn sin nx)이며 an=(1/π)∫f cos nx, bn=(1/π)∫f sin nx 다.
  • S_N 은 n=1 부터 N 까지의 유한 부분합이다. 무한합과 유한합을 구별한다.
  • 끝점은 주기확장으로 이어 붙인 뒤 한쪽 극한을 판단한다.

학습 목표

  • 주기 경계와 내부 점프의 한쪽 평균을 계산한다.
  • 부분합의 대칭성과 계수에서 점프 극한을 검산한다.

고정된 점에서 무엇으로 수렴하는가

앞의 조각별 C1 조건에서 연속인 내부점에서는 S_N(x)→f(x)다. 점프점 c 에서는 S_N(c)→[f(c−)+f(c+)]/2 다. f(c)의 지정값이 이 평균과 다르면 급수는 원래 지정값을 재현하지 않는다. 전개를 등호로 쓸 때 이런 예외나 적절한 대표값을 함께 밝힌다.

이는 좌우를 대칭으로 다루는 삼각 부분합의 수렴 정리다. 한쪽 값만 택하는 규칙이나 데이터 저장값을 보고 정하는 규칙이 아니다. 모든 적분 가능한 함수에 가정 없이 이 평균 공식이 적용된다고 확대하지 않는다.

끝을 이어서 두 방향 보기

[−π,π]의 오른쪽 끝π에 오른쪽에서 접근하면 주기확장으로−π 바로 오른쪽 값을 만나게 된다. 따라서 양끝 급수 극한은[f(π−)+f(−π+)]/2 다. 입력 구간 안에서만 왼쪽을 보거나 양끝의 임의 지정값을 평균 내는 방식은 잘못이다.

f=x 를[−π,π]에서 확장하면 내부는 매끄럽지만 경계에서는π에서−π로 점프한다. 양끝에서 급수는 0 으로 수렴하며 내부에서는 x 로 수렴한다. 직선 조각이 부드럽다는 사실은 이어 붙인 주기 함수도 매끄럽다는 뜻이 아니다.

유한합으로 먼저 검산하기

이 sawtooth 의 짝 대칭 계수 a0 와 an 은 0 이고 bn=2(−1)^(n+1)/n 이다. ∫x sin nx 의 부분적분을 통해 이 부호를 얻는다. 모든 S_N 은 사인함수 합이므로 0 과±π에서 정확히 0 이다. 끝 평균 0 과 일치한다.

내부 고정점에서는 해당 점의 목표값으로 수렴하더라도 적은 N 의 값은 다를 수 있다. N 을 늘리는 극한과 점을 경계로 가까이 보내는 극한도 서로 바꿀 수 있다고 가정하지 않는다. 이 차이가 다음 Gibbs 설명의 핵심이다.

중간 과정을 따라가는 예제

f=x 의 S1(x)=2 sin x, S2(x)=2 sin x−sin2x 를 계산한다. x=π/2 와π에서 두 합 및 무한급수의 목표 극한을 구하라.

  1. π/2 에서는 sin x=1,sin2x=0 이므로 S1=S2=2 다.
  2. 연속인 내부점π/2 의 무한급수 극한은π/2 다. 두 항이 같다고 벌써 극한에 도달한 것은 아니다.
  3. π에서는 sin nπ=0 이므로 모든 부분합이 0 이다.
  4. 주기 좌우 극한π와−π의 평균 0 이므로 끝 극한도 0 이며 f(π)=π로 지정해도 바뀌지 않는다.

π/2 에서 두 부분합 2·극한π/2, π에서 모든 부분합 및 극한 0.

오해와 반례

주기 끝점에서는 입력 구간 내부에서 접근하는 한쪽 값으로만 수렴한다.

Gibbs 현상

항을 더 넣어도 점프 옆의 삐죽한 진동이 남는 이유는 무엇일까?

준비 개념과 학습 목표

준비 개념

  • 실수 함수의 2π 주기 전개는 a0/2+Σ(an cos nx+bn sin nx)이며 an=(1/π)∫f cos nx, bn=(1/π)∫f sin nx 다.
  • S_N 은 n=1 부터 N 까지의 유한 부분합이다. 무한합과 유한합을 구별한다.
  • 끝점은 주기확장으로 이어 붙인 뒤 한쪽 극한을 판단한다.

학습 목표

  • 점프에서의 평균 수렴과 점프 주변의 overshoot 를 구별한다.
  • 고정점 수렴과 움직이는 점에서 남는 높이를 계산한다.

점프 자체와 주변을 나누기

Gibbs 현상은 불연속 파형을 Fourier 부분합으로 근사할 때 점프 가까이에서 양쪽 값 범위를 넘는 진동이 생기는 현상이다. 항을 늘리면 그 구역은 좁아지지만 대표적인 점프 파형에서 최대 초과 높이가 0 으로 사라지지는 않는다. 점프점 자체가 좌우 평균으로 수렴한다는 말과 같은 정의는 아니다.

정사각파 q=−1(−π<x<0),1(0<x<π)를 주기확장하자. a 계수는 0 이고 홀수 bn=4/(πn), 짝수 bn=0 이다. 첫 홀수 항 m 개를 Q_m(x)=(4/π)Σk=1..m sin((2k−1)x)/(2k−1)로 쓴다. 이는 최고 주파수 2m−1 까지의 삼각 부분합이다.

작은 부분합의 범위 넘기

m=2 이면 Q2=(4/π)(sin x+sin3x/3)다. x=π/4 에서 sin x=sin3x=√2/2 이므로 Q2=8√2/(3π)≈1.2004 다. 오른쪽 원래 값 1 보다 약 .2004 높다. 이 유한합의 초과 비율을 곧바로 무한항 Gibbs 상수라고 부르지 않는다.

Q2′=(4/π)(cos x+cos3x)=(8/π)cos2x cosx 다.0<x<π/2 에서 π/4 앞은 양수, 뒤는 음수이므로 이 점은 국소 최대다.0 에서는 모든 항이 0 여서 Q2(0)=0 이다. 평균값 0 과 근처의 범위 초과가 동시에 성립한다.

더 많은 항과 두 극한의 차이

일반 m 에서는 Q_m′=(4/π)Σcos((2k−1)x)=(2/π)sin(2mx)/sin x 다.0<x<π/(2m)에서 양수이고 바로 뒤에서 음수이므로 첫 봉우리 x_m=π/(2m)이 점프 0 으로 가까워진다. 그러나 높이의 Riemann 합 극한은 (2/π)∫0π(sin t/t)dt 로 1 보다 큰 값이다. 적분 0 의 값은 연속확장 1 로 해석한다.

이 봉우리 점은 m 에 따라 바뀐다. 고정된 0<x<π의 내부점에서는 Q_m(x)→1 이라는 수렴과 x_m→0 에서 봉우리 높이가 남는 사실이 모순되지 않는다. 모든 점에 같은 오차 경계를 요구하는 균등 수렴이 없기 때문이다. 이 결과의 적분 극한을 이해해도 다른 불연속·필터의 실제 출력 높이를 모두 동일하게 단정하지 않는다.

중간 과정을 따라가는 예제

Q2=(4/π)(sin x+sin3x/3)에서 0,π/4,π/2 의 값을 비교하라. q 의 점프 크기는 2 다.

  1. 0 에서는 0 이다. 점프 평균(−1+1)/2 와 일치한다.
  2. π/4 에서는 8√2/(3π)≈1.2004 다. 원래 오른쪽 값 1 을 약 .2004 넘는다.
  3. π/2 에서는(4/π)(1−1/3)=8/(3π)≈.8488 이다.
  4. π/4 초과를 점프 크기 2 로 나누면 약 .1002, 즉 약 10.02%다. 이것은 m2 의 유한 부분합 값이다.

0·약 1.2004·약.8488 이며 m2 초과는 점프의 약 10.02%다.

힌트 보기

풀이 보기

오해와 반례

점프점 평균이 0 이므로 점프 주변 부분합도 항상−1 과 1 사이에 있다.

Q2(0)=0 이어도 Q2(π/4)≈1.2004 다. 한 점의 극한과 주변의 값 범위는 다른 질문이다.

소단원 4.4

Parseval 관계와 에너지

시간 파형의 제곱을 더한 양을 주파수 계수로도 계산할 수 있을까?

준비 개념과 학습 목표

준비 개념

  • 실수 함수의 2π 주기 전개는 a0/2+Σ(an cos nx+bn sin nx)이며 an=(1/π)∫f cos nx, bn=(1/π)∫f sin nx 다.
  • S_N 은 n=1 부터 N 까지의 유한 부분합이다. 무한합과 유한합을 구별한다.
  • 끝점은 주기확장으로 이어 붙인 뒤 한쪽 극한을 판단한다.

학습 목표

  • 실수 계수 정규화에 맞는 Parseval 식을 사용한다.
  • 유한 투영 에너지와 남은 제곱 오차를 계산한다.

제곱 적분으로 크기 재기

한 주기 제곱 적분 E=∫−ππ|f(x)|²dx 를 여기서 에너지라고 부른다. 평균 제곱은 E/(2π)다. 실제 전력이나 줄 단위 에너지가 되려면 신호 단위·시간 축·물리 계수가 추가로 필요하다. 수학적 에너지를 모든 물리량과 바로 동일시하지 않는다.

f 가 L2, 즉 제곱 적분이 유한한 실수 함수이면 E=πa0²/2+πΣn≥1(an²+bn²)다. 상수항은 a0/2 이므로 그 제곱 적분은 2π(a0/2)²=πa0²/2 다. 이 계수를 일반 사인·코사인 계수와 같은 가중치로 쓰면 상수 에너지를 두 배로 계산하게 된다.

유한합은 직교성으로 직접 확인하기

S_N 을 제곱해 적분하면 다른 주파수 곱·사인과 코사인 곱·상수와 진동항 곱이 0 으로 사라진다. 같은 주파수 사인/코사인 제곱 적분은π이고 상수 1 의 제곱 적분은 2π다. 따라서 E_N=πa0²/2+πΣn≤N(an²+bn²)를 얻는다. 이 단계는 유한합이라 적분과 무한합 교환이 없다.

잔차 r_N=f−S_N 은 보관한 기저와 직교한다. ∫f²=∫S_N²+∫r_N²라는 Pythagoras 식에서 제곱 오차 E−E_N 을 계산할 수 있다. 일반 직교계에서는 E_N≤E 인 Bessel 부등식까지 얻는다. 전체 삼각기저의 완비성과 L2 수렴이 있어야 무한 N 에서 남은 오차 0 과 Parseval 등식을 결론 낼 수 있다.

점값의 수렴과 분리하기

L2 수렴은 ∫|f−S_N|²→0 이라는 뜻이다. 한 점 또는 작은 점프 구역의 오차가 커도 적분은 작아질 수 있다. 따라서 Gibbs 의 남는 봉우리와 Parseval 은 모순되지 않는다. L2 라는 이유만으로 모든 점의 수렴이나 균등 수렴을 주장하지 않는다.

유한 점의 값을 바꾸어도 L2 에너지와 계수는 같다. 통계나 공학에서 평균 제곱 오차를 쓸 때 어떤 구간·정규화·대표값을 쓰는지 적는 습관이 필요하다. 계수 에너지 합을 비교할 때 기본주기와 좌표 스케일이 다른 식을 그대로 섞지 않는다.

중간 과정을 따라가는 예제

f=2+3 cos x−sin2x 다. 전체 E 와 평균 제곱, S1 까지 남긴 에너지 및 잔차 에너지를 계산하라.

  1. 상수항 2 이므로 a0=4, a1=3, b2=−1 이며 나머지는 0 이다.
  2. E=π·16/2+π·9+π·1=18π다. 평균 제곱 18π/(2π)=9 다.
  3. S1=2+3 cos x 라 에너지는 8π+9π=17π다.
  4. 잔차는−sin2x 로 제곱 적분π다. 18π−17π=π와 일치한다.

전체 18π, 평균 9, S1 의 17π, 남은π다.

종이와 본문으로 직접 해보기

g=1+2 sin x+2 cos3x 의 평균 제곱과 S1 잔차 에너지를 구하라. 상수만 보관했을 때 잔차도 구하라.

힌트 보기

a0=2, b1=2, a3=2 다. 각 진동항 제곱 평균은 계수 제곱의 1/2 다.

풀이 보기

평균 제곱 1+4/2+4/2=5, 전체 E=10π다. S1 은 상수+2sin x 로 에너지 6π, 잔차 4π다. 상수만 보관하면 에너지 2π이고 잔차 8π다.

오해와 반례

평균 제곱이 작아지면 모든 점에서 오차도 작고 Gibbs 봉우리도 사라진다.

제곱 적분은 구간 전체의 합이다. 점프에 가까운 폭이 좁아지면 봉우리 높이가 남아도 그 구역의 적분 기여는 줄 수 있다. 균등 오차와 L2 오차는 서로 다른 기준이다.
