  • Java 선수 후 Kotlin 상호운용 연결을 짧게 다루고 Android 중심으로 편성한다. 2019 대학 자료는 플랫폼 개념만, 현대 API는 공식 자료로 보완한다.
  • 단원은 주차와 같지 않다. 12개 학습 단원은 시험·휴강을 제외한 내용 체계이며 과목별 분량·실습시간에 맞춰 주차를 나눈다.
  • 여러 공개 자료의 범위·학습구조를 참고해 자체 구성한 목차이며 대학의 공식 한국어 번역본이나 전체 강의 복제본이 아니다.
  • Compose·coroutine·Room·WorkManager는 대학 2019 강의에서 확인한 항목이 아니라 Android 공식 공개 과정으로 보완했다.
