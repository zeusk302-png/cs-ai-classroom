소단원 9.1

지연·오류·분포 지표

서버가 빠르게 응답해도 모델은 엉뚱한 추천을 하고 있을 수 있을까?

준비 개념과 학습 목표

준비 개념

  • 모델은 입력으로 예측을 만들고 정답 라벨로 품질을 평가한다.

  • 비율은 분자와 분모 및 관측 기간을 함께 정한다.

학습 목표

  • 응답 성능·요청 실패·예측 품질을 분리한다.

  • 평균과 백분위수 및 분포를 계산한다.

무엇을 관측한 숫자인가

응답 지연은 요청을 받아 결과를 돌려주기까지의 시간이다. 실패율은 정한 기간의 실패 요청 수를 전체 요청 수로 나눈다. 모델 정확도는 라벨이 확인된 예측에서 맞힌 비율이므로 HTTP 성공률과 같은 숫자가 아니다. 빠르고 오류 없이 반환한 잘못된 예측도 가능하다.

측정 시작과 종료 위치를 명시해야 한다. 모델 연산 시간만 잰 값과 큐 대기·전처리·네트워크를 포함한 전체 응답 시간을 섞으면 개선 위치를 잘못 판단한다. 버전과 기간, 표본 크기를 숫자 옆에 함께 적는다.

평균이 가리는 긴 꼬리

평균은 합을 관측 수로 나눈다. 대부분이 빨라도 소수의 긴 지연이 사용자 경험에 영향을 줄 수 있어 백분위수를 함께 본다. 아래는 정렬된 원시 표본에 nearest-rank 방식 ceil(p×n)을 사용하는 자체 계산이고 histogram에서 보간한 추정치와 다르다.

여러 서버의 p95를 그냥 평균하면 전체 요청의 p95가 되지 않는다. 서버별 요청 수와 실제 분포가 필요하다. Prometheus는 count와 sum의 합산 및 histogram bucket의 집계와 quantile의 차이를 설명하므로 자료 종류를 먼저 확인한다.

입력 분포도 품질과 따로 보기

결측 비율, 범주별 입력 빈도와 예측 분포는 모델이 어떤 환경에서 동작하는지 보여 준다. 새 국가의 요청이 늘거나 특정 센서 값이 사라지면 과거 평가 집합과 운영 환경이 달라질 수 있다. 하지만 입력 변화만으로 정확도 하락의 크기를 알아내지는 못한다.

전체 평균에 가려진 소집단도 확인한다. 시간 구간과 집단별 지표를 나누면 어느 요청에 문제가 생겼는지 조사할 수 있다. 모든 작은 집단의 차이를 즉시 장애로 단정하기보다 표본 수와 지속 여부를 함께 읽는다.

중간 과정을 따라가는 예제

가상 완료 요청10개의 지연(ms)이10,10,10,10,10,10,10,10,10,110이다. 이10개 중 실패 요청은1개이며 실패에도 완료 지연을 기록했다. nearest-rank p90,p95와 평균·실패율을 구하자.

  1. 총 지연은9×10+110=200ms이고 평균200/10=20ms다.

  2. p90 위치는ceil(.9×10)=9라10ms, p95 위치는ceil(.95×10)=10이라110ms다.

  3. 실패율은1/10=10%다. 실패한 요청을 지연 표본에서 뺀 계산을 이 정의의 평균과 섞지 않는다.

평균 20ms·p90 10ms·p95 110ms·실패율 10%다. 모델 정확도는 라벨 정보가 없어 계산하지 않는다.

종이와 본문으로 직접 해보기

별도 서버A는2개 요청 지연10·10ms, B는8개 요청 모두100ms라고 하자. 서버 평균의 단순 평균과 전체 요청 평균을 비교하자.

힌트 보기

전체 평균은 서버별 합을 모두 더한 뒤 총 요청 수로 나누자.

풀이 보기

서버 평균의 단순 평균은(10+100)/2=55ms다. 전체는(20+800)/10=82ms다. 요청 수가 달라 단순 평균이 전체 요청 평균이 되지 않는다.

오해와 반례

HTTP 성공률이100%면 모델 정확도도100%다.

요청을 정상 처리한 것과 예측이 정답인 것은 다르다. 정답 라벨 없이 성공 응답만 보고 정확도를 계산하면 다른 사건의 비율을 혼동한다.

자기점검

예제 지연 합은?

답과 이유 보기

200ms다.

짧은 요청 9개의 지연 합 90ms와 긴 요청 1개의 110ms를 더한다.

nearest-rank p95 위치는?

답과 이유 보기

10번째다.

ceil(9.5)=10이다.

서버 p95 둘의 평균이 항상 전체p95인가?

답과 이유 보기

아니다.

quantile은 요청 분포를 합친 뒤 다시 계산해야 한다.

한 단계 더

종이에 기간·모델 버전·전체 요청·실패 요청·지연 합·라벨 확보 수를 열로 나누자. 계산할 근거가 없는 정확도 칸은 미상으로 남기고 관측 없는 값에0을 넣지 말자.

소단원 9.2

data·concept drift

입력의 모양이 그대로인데 정답을 만드는 규칙만 바뀔 수 있을까?

준비 개념과 학습 목표

준비 개념

  • 모델은 입력으로 예측을 만들고 정답 라벨로 품질을 평가한다.

  • 비율은 분자와 분모 및 관측 기간을 함께 정한다.

학습 목표

  • 입력분포 P(X)와 조건부 P(Y|X)의 변화를 구별한다.

  • 분포 경보를 성능 저하의 증명으로 오해하지 않는다.

이 교재에서 사용하는 구분

이 소단원에서는 data drift를 입력분포 P(X)의 시간 변화, concept drift를 같은 입력에서 정답이 나오는 조건부 분포 P(Y|X)의 변화로 구분한다. 문헌에서는 joint distribution 변화 전체를 concept drift라 부르고 virtual/real로 다시 나누기도 하므로 용어가 등장한 자료의 정의를 확인한다.

정답 규칙이 같아도 입력 집단 비중이 바뀌면 전체 정확도는 바뀔 수 있다. 반대로 입력 비중이 그대로라도 규칙이 바뀌면 입력 통계만 감시하는 시스템은 이를 알아채지 못할 수 있다. 두 변화는 따로 또는 함께 생길 수 있다.

기준 집합과 비교 기간

운영 입력을 학습 입력과 비교하는 skew와 운영의 이전 기간과 이후 기간을 비교하는 drift는 기준 집합이 다르다. 비교 범주, 결측 처리, 관측 창을 같게 정의해야 의미 있는 차이가 나온다. 다른 기준을 사용한 점수들을 이름이 같다고 바로 비교하지 않는다.

범주형 분포의 간단한 자체 지표로 가장 큰 비율 차이를 사용할 수 있다. 경보 문턱을 넘으면 조사할 신호이지 정답 규칙 변화나 정확도 하락이 확정되는 것은 아니다. 작은 표본 변동과 정상적인 계절 변화도 함께 검토한다.

경보 뒤에는 원인을 조사

입력 수집 오류·새 사용자 비중·특성 계산 코드 변화가 분포를 바꿀 수 있다. 재학습만 하면 잘못된 입력을 해결하지 못하고 문제가 숨겨질 수도 있다. 동일 모델의 품질을 가능한 라벨과 집단별로 대조하고 데이터 경로를 확인한다.

아래 모형은 두 범주의 비중과 결정적 라벨 규칙을 완전히 정해 논리적으로 비교한다. 실제 서비스에서 모든 분포나 진짜 규칙을 알고 있다는 주장이 아니다. 실제 관측에는 표본 오차와 라벨 지연이 남는다.

중간 과정을 따라가는 예제

입력X는A/B다. 기준 비중은.8/.2, 새 비중은.5/.5다. 최대 절댓값 차이를 D로 정의하자. 정답 규칙은 항상 A→0,B→1이고 모델도 이 규칙을 정확히 사용한다. 그다음 별도 상황에서 비중은.8/.2 그대로지만 정답 규칙을 A→1,B→0으로 뒤집는다.

  1. 첫 상황 D=max(|.8−.5|,|.2−.5|)=.3이다. 입력분포가 변했지만 모델과 정답 규칙이 같아 두 기간 정확도는100%다.

  2. 둘째 상황은 입력비중 차이D=0이다. 그러나 같은 A/B의 정답이 뒤집혀 조건부 규칙이 변했다.

  3. 원래 모델은 A를0,B를1로 계속 예측해 둘째 상황의 모든 예측이 틀리므로 정확도는0%다.

첫 상황은 입력 변화 D.3와 정확도 유지, 둘째는 입력 변화0과 정확도100→0의 규칙 변화다. 입력 지표만으로 품질을 확정할 수 없다.

종이와 본문으로 직접 해보기

모델이 항상0을 예측하고 정답 규칙 A→0,B→1은 유지된다고 하자. 비중이.8/.2에서.5/.5로 바뀌면 정확도는? 문턱을 D>.3으로 정했다면 D=.3은 경보인가?

힌트 보기

맞는 범주는A뿐이며 경보의 엄격한 부등호를 확인하자.

풀이 보기

정확도는A비중에 따라80%에서50%로30퍼센트포인트 낮아진다. P(Y|X)는 유지되지만 입력 비중 변화가 이 부정확한 모델의 전체 정확도에 영향을 준다. D=.3은 D>.3을 만족하지 않아 경보가 아니다.

오해와 반례

입력분포가 같으면 모델 정답률도 같고, 다르면 반드시 떨어진다.

두 예제가 각각 반례다. 입력분포만 보는 감시는 정답 규칙 변화를 놓칠 수 있고 올바른 모델은 입력 비중이 바뀌어도 정확도를 유지할 수 있다.

두 범주 모두 절댓값 차이가.3이다.

입력 통계가 변하지 않은 규칙 반전에서 모델 정확도는?

원래 결정적 예측의 정답이 두 범주 모두 뒤집힌다.

80%→50%의 차이를 무엇으로 적는가?

답과 이유 보기

비율 값의 뺄셈이며 상대 감소율과 다르다.

입력 비중 변화와 조건부 규칙 변화를 두 축으로 두고 네 칸을 만들자. 각 칸에서 분포만 관측해 확정할 수 있는 것과 라벨이 있어야 평가할 것을 나누어 적자.

소단원 9.3

라벨지연과 경보

아직 결과를 모르는 예측을 틀렸다고 세어도 될까?

준비 개념과 학습 목표

준비 개념

  • 모델은 입력으로 예측을 만들고 정답 라벨로 품질을 평가한다.

  • 비율은 분자와 분모 및 관측 기간을 함께 정한다.

학습 목표

  • 라벨 미도착과 음성 정답을 구별한다.

  • 관측 분모·시간창·경보 지속 조건을 계산한다.

예측 시점과 정답 시점

숙제 제출 여부를 예측하면 제출 마감이 지난 뒤에야 정답을 확정할 수 있다. 라벨은 즉시 또는 고정·변동 지연 후 올 수 있고 끝내 확인되지 않을 수도 있다. 아직 모르는 라벨을 0이나 오답으로 넣으면 품질 측정이 왜곡된다.

예측ID와 모델 버전, 예측 시각, 라벨 시각을 연결해야 한다. 늦게 도착한 정답을 오늘의 예측처럼 섞으면 어느 모델·기간의 품질인지 모호해진다. 관측이 끝난 cohort를 비교하되 최종 미확보 대상도 따로 기록한다.

확보한 라벨 집합의 편향

확보한 라벨 수를 전체 예측 수로 나누면 coverage가 된다. 그 확보 집합에서 맞힌 비율은 라벨이 온 집합의 정확도이며 미확보 집합의 정확도를 자동으로 대표하지 않는다. 빨리 결과가 나오는 쉬운 사례만 먼저 라벨이 올 수 있기 때문이다.

미확보의 실제 정답을 모르면 전체 정확도의 가능한 범위를 구할 수 있다. 미확보 전부 오답/전부정답의 두 극단을 계산하면 확정 가능한 경계를 보인다. 이 경계는 신뢰구간이나 무작위 표본 추정과는 다른 논리적 범위다.

신호를 대응으로 연결하기

경보에는 기준·비교창·최소표본·문턱·지속조건과 담당 대응을 명시한다. 여기서는 충분한 라벨 수가 있는 창에서 오류율이20%를 엄격히 넘는 상태가 두 창 연속이면 조사하는 자체 규칙을 사용한다. 실제 통계 검정이나 보편적 최적 문턱이라는 주장은 아니다.

라벨 없는 즉시 지표로 입력 이상과 시스템 실패를 먼저 살피고 나중에 라벨 기반 품질을 대조할 수 있다. 경보만으로 모델을 자동 재학습하거나 교체하기보다 데이터 수집·버전·집단 변화를 확인하고 대응 근거를 남긴다.

중간 과정을 따라가는 예제

한 예측 cohort 100개 중 40개의 라벨이 왔고 그중 32개가 맞았다. 나머지 60개는 정답 미상이다. coverage·확보 집합 정확도·전체 정확도 가능한 범위를 구하자. 별도로 각 100라벨이 확보된 연속 창의 오류 수가 18,25,24라고 하자.

  1. coverage는 40/100=40%, 확보 집합 정확도는 32/40=80%다. 확보된 오답은 8개다.

  2. 미확보 60개가 전부 오답이면 전체 32/100=32%, 전부 맞으면 (32+60)/100=92%다. 전체의 논리적 범위는 32–92%다.

  3. 창별 오류율은 18%,25%,24%다. 둘째부터 문턱 20% 초과가 시작하고 셋째에 두 창 연속이므로 셋째에서 자체 규칙 경보가 발생한다.

라벨 확보 40%·확보 집합 정확 80%이지만 전체는 32–92% 범위로만 알 수 있다. 주어진 지속 조건 경보는 셋째 창이다.

종이와 본문으로 직접 해보기

나머지60개의 라벨이 모두 도착했고 추가로36개가 맞았다고 하자. 최종 정확도는? 오류율20%,21%,19%,22%,23%의 다섯 창에서 동일한 두 창 연속 규칙이 처음 충족되는 창은?

힌트 보기

정답 수는 원래32개와 추가36개를 더한다. 문턱은20%이상 아닌20%초과다.

풀이 보기

총 68/100=68%다. 경보 규칙은 1창 20%에서 불충족, 2창 21%에서 첫 초과, 3창 19%에서 연속 끊김, 4창 22%에서 다시 첫 초과, 5창 23%에서 연속 충족하므로 5창이다.

오해와 반례

라벨이 안 왔으면 음성이라 세고, 확보집합80%를 전체정확도라 적어도 된다.

미관측은 음성정답과 다르다. 확보집합에서80%라는 사실만으로 미확보60개를 추론하지 않는다. 원래 예제의 가능한32–92%가 전체값을 아직 확정하지 못함을 보여 준다.
