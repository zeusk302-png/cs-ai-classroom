소단원 6.1

baseline과 slice 평가

전체 정답률이 올랐는데 특정 학생에게는 더 많이 틀리면 새 모델을 통과시켜도 될까?

준비 개념과 학습 목표

준비 개념

  • 정확도는 평가 대상 중 맞힌 수를 전체 수로 나눈 값이다.

  • slice 는 관심 조건으로 고른 부분집합이며 서로 겹칠 수도 있다.

학습 목표

  • 같은 평가 자료에서 baseline 과 후보를 비교한다.

  • 전체 지표와 중요 부분집합의 회귀를 함께 계산한다.

겹치는 두 slice의 정답 수를 더하면 전체 성적이 될까?

각 사례는 실제 평가 자료가 아닌 자체 유한 모형이다. 전체 ID는 1부터 12까지이며 A는 1부터 8, B는 5부터 12다. 두 집단의 교집합은 ID 5부터 8까지 네 개이고 합집합은 전체다. A의 정답 수는 6개, B의 정답 수는 5개라고만 알려져 있다. 교집합 정답 수를 t라고 두면 전체 정답 수는 6+5−t다.

A에서 교집합 밖의 ID는 네 개이므로 정답 6개를 채우려면 교집합에서 적어도 두 개가 맞아야 한다. B에서는 적어도 한 개가 필요하며 교집합은 최대 네 개다. 따라서 가능한 t는 정수 2, 3, 4이고 전체 정답 수는 각각 9, 8, 7개다. 두 slice의 개수 합 16은 고유 평가 ID 수 12가 아니다. t가 3이라고 추가로 확인한 경우 전체 정확도는 8/12 = 2/3이다.

별도 같은 12개 ID에 대한 이진 분류의 짝 표를 둔다. 각 ID의 정답은 고정된 두 클래스 중 하나이며 두 모델도 그중 하나만 예측한다. 둘 다 정답은 7개, 기존만 정답은 2개, 새 모델만 정답은 1개, 둘 다 오답은 2개다. 기존은 9개, 새 모델은 8개가 맞아 정확도 차이는 −1/12다. 이 이진 조건에서 예측이 바뀐 ID는 세 개이고 그중 개선은 한 개, 회귀는 두 개다. 정확도 변화량 하나가 변경된 ID를 전부 나타내지는 않는다.

다른 별도 평가에서는 전체 12개 중 8개만 판정되어 그중 7개가 정답이다. 미판정 네 개의 정오를 모르면 전체 정확도 범위는 [7/12,11/12]다. 전체 최소 3/4라는 정책에 대해 통과도 실패도 아직 확정하지 못한다. 판정된 사례의 7/8을 전체 성적으로 대신 보고하지 않는다. 이 범위는 유한 장부의 가능한 완성 범위이며 모집단 신뢰구간이 아니다.

비교의 출발선

baseline 은 개선 여부를 판단할 기준이다. 직전 운영 모델, 항상 다수 클래스를 고르는 규칙, 간단한 선형 모델처럼 목적에 맞게 정한다. 복잡한 모델이라는 이유만으로 간단한 규칙보다 낫다고 할 수 없으므로 같은 평가 자료와 지표를 적용한다.

비교 시 라벨·예측 시점·전처리·임계값 정책을 고정하고 모델 버전을 기록한다. 정확도 차이가 작아도 시간이나 메모리 비용이 커질 수 있다. 이 단원은 정답률 표만 종이로 분석하며 운영 성공이나 실제 학습 결과를 주장하지 않는다.

전체에서 가려지는 부분집합

중요 slice 는 언어, 입력 길이, 촬영 조건 등 목표에 관련된 조건으로 미리 정한다. 전체 정확도가 다수 집단의 개선에 크게 좌우되면 소수 집단의 악화가 가려질 수 있다. slice 별 표본 수와 정답 수를 함께 보여 분모가 다른 퍼센트를 비교한다.

두 slice 가 겹치면 정답 수를 합쳐 전체 정답 수로 삼을 수 없다. 아래 A/B 는 겹치지 않고 전체를 나누는 특별한 경우다. 미리 중요하다고 정한 집단을 통과 기준에 넣되 평가 후 나쁜 집단을 숨기거나 여러 탐색 중 좋은 결과만 선택하지 않는다.

차이와 불확실성을 읽는다

평가 회귀는 기존보다 품질이 악화되는 변화다. 전체 최소 기준과 slice 별 최소 기준, 허용 변화량을 정할 수 있다. 여러 조건 중 하나라도 실패하면 왜 실패했는지 먼저 분석하며 전체 평균 하나로 다른 실패를 덮지 않는다.

90%와 92%의 차이는 2 퍼센트포인트다. 상대 증가율은 2/90 이므로 약 2.22%로 다른 양이다. 한정된 표본의 값은 모집단 성능의 정확한 증명이 아니며 특히 적은 slice 의 한 건 차이는 크게 보인다. 실제 신뢰 구간 추정은 별도 자료/가정이 필요하다.

표의 마지막 행은 앞의 slice 자료와 독립이다. 분모는 고유 ID, 교집합의 정답도 한 번만 센다.

중간 과정을 따라가는 예제

같은 100 건을 A 80 건/B 20 건으로 나눈다. baseline 정답은 A72/B16, 후보는 A76/B14 다. 전체 개선, 각 slice 변화, 통과 여부를 구하라. 규칙은 전체≥90%, B≥75%이고 두 조건 모두 필요하다.

  1. baseline 전체(72+16)/100=.88 이다.

  2. 후보 전체(76+14)/100=.90 으로 +2 퍼센트포인트다.

  3. A 는 90%→95%로 +5 퍼센트포인트, B 는 80%→70%로 −10 퍼센트포인트다.

  4. 후보의 전체 조건은 통과하지만 B70%<75%로 탈락이다.

전체가 개선되어도 중요 B 조건 때문에 후보는 통과하지 못한다.

조건을 바꾸어 비교하기

교집합 정답을 뺀 전체

t=3일 때 전체 정확도와 잘못된 slice 집계를 비교하라.

  1. 정답 합 11에서 중복 정답 3을 빼면 전체 정답은 8개다.

  2. 고유 분모는 12개이므로 전체 정확도는 2/3다.

  3. 6/8과 5/8의 단순 평균은 11/16이며 서로 다른 가중 목표다.

전체 정확도는 2/3이며 11/16과 다르다.

비교할 점

겹치는 slice를 서로 배타적인 분할로 취급하지 않는다.

짝 표가 보여 주는 회귀

별도 짝 표에서 두 성적과 변경된 ID 수를 구하라.

  1. 기존 정답은 7+2=9개, 새 정답은 7+1=8개다.

  2. 변경된 ID는 2+1=3개다.

  3. 정답 차이는 1−2=−1개이며 정확도 차이는 −1/12다.

회귀는 두 개, 개선은 한 개이며 변경은 세 개다.

비교할 점

주어진 장부의 산술이지 새 모델의 모집단 열등성 검정이 아니다.

연습 1 · 값과 상태 예측

t를 모를 때 가능한 전체 정답 수와 각 값의 실현 가능성을 설명하라.

힌트 1

A에만 속한 네 개의 최대 정답 수를 센다.

힌트 2

교집합과 두 나머지 집단 각각의 정답 수를 구성한다.

풀이와 답 확인

  1. t가 2이면 A에만 속한 정답은 4개, B에만 속한 정답은 3개다. t가 3이면 각각 3개와 2개이며, t가 4이면 각각 2개와 1개다.

  2. 두 나머지 집단은 각각 용량이 4개다. 모든 배정이 가능하므로 전체 정답 수 9개, 8개, 7개가 각각 실현된다.

전체 정확도는 7/12, 2/3, 3/4 중 하나다.

흔한 오답에서 다시 생각하기

slice 정확도만 알면 전체 값은 유일하다.

교집합 정답 수가 빠져 서로 다른 완성이 가능하다.

연습 2 · 오류 찾아 고치기

A와 B의 정답 수 합인 11개를 평가 ID 개수 합인 16개로 나눠 전체 정확도라고 했다. 고쳐라.

힌트 1

합집합과 중복을 구별한다.

힌트 2

정답 중복도 분모 중복과 별도로 뺀다.

풀이와 답 확인

  1. 고유 ID는 8+8−4=12개다.

  2. 고유 정답은 11−t개이며 t 정보가 없으면 유일한 값이 없다.

11/16은 현재 고유 전체 성적이 아니다.

흔한 오답에서 다시 생각하기

분모만 12로 바꿔 11/12를 보고한다.

분자의 중복 정답도 제거해야 한다.

연습 3 · 직접 만들어 보기

두 클래스 중 하나만 예측하는 별도 이진 분류에서 기존과 새 모델이 각각 9개 정답이지만 예측이 바뀐 ID가 네 개인 짝 표를 구성하라. 전체 ID는 12개다.

힌트 1

개선 수와 회귀 수를 같게 둔다.

힌트 2

전체 ID 12개를 유지한다.

풀이와 답 확인

  1. 둘 다 정답은 7개, 기존만 정답은 2개, 새 모델만 정답은 2개, 둘 다 오답은 1개로 둔다.

  2. 전체는 12개이고 각 모델의 정답은 9개다. 이진 분류 조건에서 예측이 바뀐 ID는 기존만 또는 새 모델만 정답인 네 개다.

성적이 같아도 정답 ID가 바뀔 수 있다.

흔한 오답에서 다시 생각하기

정확도가 같으면 어느 사례도 회귀하지 않았다.

두 기존만 정답 ID는 새 모델에서 회귀했다.

연습 4 · 선택 심화

선택 심화는 기본 연습 뒤 더 탐구하고 싶을 때 풀어 보세요.

별도 미판정 장부에서 전체 기준 3/4를 확정 통과하려면 네 미판정 ID 중 최소 몇 개가 정답임을 확인해야 하는가?

힌트 1

전체 최소 정답은 9개다.

힌트 2

확인된 정답 7개에서 추가 확인 수를 센다.

풀이와 답 확인

  1. 미판정 중 두 개를 정답으로 확인하면 확인된 정답은 9개가 된다.

  2. 남은 둘이 모두 오답이어도 전체 정확도는 9/12여서 통과한다. 한 개만 정답으로 확인하면 최악의 전체 정확도가 8/12라 확정 통과에는 부족하다.

최소 두 개의 추가 정답 확인이 필요하다.

흔한 오답에서 다시 생각하기

두 개를 임의로 고르면 반드시 두 개가 맞는다.

질문은 확인된 정답 개수 조건이며 실제 정오를 가정하지 않는다.

소단원 6.2

데이터·모델 테스트

숫자 타입과 범위가 맞으면 모델이 문제를 올바르게 푼다고 할 수 있을까?

준비 개념과 학습 목표

준비 개념

  • schema 는 자료의 타입·필수 여부·허용 범위를 표현하는 약속이다.

  • 단위 테스트는 작은 동작, 통합 테스트는 연결된 경로를 확인한다.

학습 목표

  • 자료 검사와 모델 동작 검사의 책임을 구별한다.

  • 스키마 위반과 예측 정답률을 독립 계산한다.

모양과 불변식이 맞으면 의미도 맞았다고 할 수 있을까?

자체 자료 계약은 TRAIN에서 label을 필수로 요구하고 SERVE에서는 label 열을 금지한다. 두 환경 모두 id가 양의 정수이고 age가 0부터 120까지의 숫자여야 한다. 예측 시각이 10이고 feature_available_at이 12인 행은 숫자 타입과 범위 검사를 통과할 수 있어도 예측 당시 이용할 수 없는 자료다. 환경별 열 계약, 값 계약, 시각 의미를 따로 검사한다. SERVE의 label 금지는 이 수업의 자체 정책이며 모든 도구의 기본 동작이라고 주장하지 않는다.

별도 sparse 입력은 index와 value를 같은 위치끼리 묶는 정책이다. index=[2,5], value=[7]은 길이 불일치다. index=[5,2], value=[7,11]은 두 길이가 같지만 기준 사전의 2→7, 5→11과 다르게 5→7, 2→11을 뜻한다. valency 검사 통과와 index/value 의미 대응은 다른 검사다. 두 배열을 독립적으로 정렬하지 않고 쌍을 함께 이동해야 한다.

별도 회귀 규칙의 정답 함수는 f(x)=2x이며 정의역은 모든 실수다. API 약속은 유한 실수 입력에 유한 실수 한 개를 반환하는 것이다. metamorphic 관계는 f(−x)=−f(x), f(x+1)=f(x)+2로 둔다. 잘못된 g(x)=0은 API 약속과 첫 관계를 통과하지만 둘째 관계를 실패한다. h(x)=3x도 첫 관계를 통과하지만 정답 사례 x=1에서 출력 3으로 기준 2와 다르다.

검사는 명시된 목적에 한정한다. 두 번째 이동 관계를 만족하는 k(x)=2x+1은 기준 f와 다르고 첫 홀수 관계도 실패한다. API·홀수 관계·이동 관계·작은 정답 사례는 서로 다른 오류를 찾는다. 현재 표의 유한 몇 사례를 통과했다는 사실과 모든 실수 입력의 보장은 구별한다. 자동 schema 추론이나 seed 기록만으로 업무 의미와 전체 재현성을 인증하지 않는다.

먼저 확인할 개념
  • 데이터·모델 테스트

    기본 설명의 평가 조건과 자료 계약을 읽고 새 종이 사례에 적용한다.

  • 누수와 비교가능성

    검사 통과와 정보 가용성·평가 목적의 차이를 다른 기본 설명과 연결한다.

자료 약속을 검사한다

입력 자료에는 이름·타입·범위·결측률·고유성 등의 약속이 있다. 나이가 숫자인지, 필수 값이 빠졌는지, 라벨이 예상 클래스에 속하는지 검사하면 의미 있는 오류를 학습 전에 발견할 수 있다. 자동 schema 추론은 관측 자료의 기본 특성을 추정할 뿐 업무의 올바른 규칙을 모두 알지는 못한다.

학습에는 정답 라벨이 필요해도 실제 예측 입력에는 없어야 할 수 있다. 환경별 schema 로 이 차이를 명시한다. 단순히 같은 열 수를 강요하면 정상적인 serving 입력을 잘못 거절하거나 정답 누출 열을 그대로 허용하는 실수를 한다.

모델의 작은 동작도 확인한다

모델 테스트에는 입력 모양/출력 모양, 유한한 값, 범위·확률합 같은 API 약속 검사가 있다. 이와 별도로 알고리즘이 의미에 맞는 답을 내는지 작은 정답 사례를 검사한다. 출력이 [0,1] 안이라는 사실만으로 분류 정답을 증명하지 못한다.

예를 들어 확률 두 개의 합은 허용 오차 안에서 1 이어야 한다. 같은 입력에 항상 .5/.5 를 반환하는 모델도 이 검사는 통과하지만 유용한 구분은 못 한다. dtype·shape·NaN 검사, 학습/전처리 연결 확인, 품질 평가가 각각 필요한 이유다.

검사 결과를 버전과 묶는다

회귀검사에서는 데이터 버전·schema·모델·변환 코드·평가 설정을 함께 남긴다. seed 를 기록해도 병렬 실행이나 라이브러리 차이로 완전히 동일한 학습이 보장되는 것은 아니다. 가능한 재현 범위와 허용 차이를 구체적으로 정의한다.

통과 기준은 오류 유형에 맞게 정한다. 필수 열이 없으면 즉시 중단할 수 있지만 새 범주나 분포 이동은 조사 대상으로 분류할 수 있다. 검사 목록을 갖춘 것과 실제 검사를 실행해 통과한 것은 다르므로 이 종이 활동은 도구 실행 증거가 아니다.

소단원 6.3

누수와 비교가능성

미래 시험 문제를 보고 평균을 정한 뒤 평가하면 공정한 비교일까?

준비 개념과 학습 목표

준비 개념

  • 학습 자료는 모델/전처리를 맞추는 자료이며 평가 자료는 그 밖의 자료다.

  • 날짜와 사용자 ID 는 같은 출처와 미래 정보를 판단하는 단서다.

학습 목표

  • 전처리·출처·시간 누출을 구분한다.

  • 고정 평가셋과 바뀐 평가셋의 비교 한계를 설명한다.

시험 파일이 읽기 전용이어도 선택과 누출은 생길까?

자체 교차검증 자료는 숫자 0, 2, 8, 10이다. 첫 fold는 0과 2를 훈련에 쓰고 8과 10을 검증한다. 훈련 평균은 1이므로 검증 중심화 결과는 7과 9다. 둘째 fold는 8과 10을 훈련에 쓰므로 평균 9를 쓰고 검증 0과 2의 결과는 −9와 −7이다. 전체 평균 5를 먼저 쓰면 첫 검증 결과는 3과 5, 둘째 검증 결과는 −5와 −3으로 달라진다. 각 fold의 fit 범위가 다르다는 조건을 보존해야 한다.

새 사용자와 새 내용에 대한 평가라는 자체 목표를 둔다. 기록 a의 사용자와 내용은 U와 X, b는 V와 X, c는 V와 Y, d는 W와 Z다. 같은 사용자 또는 같은 내용이면 연결하는 규칙에서 a와 b는 내용 X로, b와 c는 사용자 V로 연결된다. a와 c가 직접 같지 않아도 셋을 같은 연결 성분으로 묶는다. 성분은 {a,b,c}와 {d} 두 개다. 모든 연결 간선이 train/test를 가르지 않도록 성분 단위로 배정한다. 더 큰 일반 그래프의 분할 도구 실행은 하지 않았다.

별도 예측 시각 10의 두 기록에서 R의 특징 사건 시각은 8, 특징 공개 시각은 11, 목표 결과 시각은 12, 라벨 공개 시각은 15다. S의 특징 사건 시각은 7, 특징 공개 시각은 9, 목표 결과 시각은 11, 라벨 공개 시각은 13이다. 훈련 자료 작성 마감 14에서는 R의 특징이 예측 당시 없었고 라벨도 마감 뒤라 두 조건을 실패한다. S의 특징은 예측 당시 있었고 미래 목표의 라벨은 마감 전에 도착했다. 미래 결과를 정답으로 학습하는 것과 미래 결과를 예측 입력으로 쓰는 것은 다르다.

별도 후보 A와 B의 validation 정답 수는 각각 네 개 중 3개와 2개다. 미리 정한 validation 기준은 A를 선택한다. 잠근 test에서 A는 네 개 중 1개, B는 네 개 중 4개라는 결과를 나중에 알았다고 A를 B로 바꾸면 test가 선택에 쓰였다. 파일이 읽기 전용이어도 이 선택 정보는 새어나간다. B의 현재 test 성적 4/4가 거짓 산술이라는 뜻은 아니며, 처음 약속한 독립 최종평가 절차를 인증하지 못한다는 뜻이다.

전처리에도 학습이 있다

평균·표준편차·단어 사전·feature 선택은 데이터에서 정보를 학습하는 과정이다. train/test 를 나눈 뒤 train 에서 이 값을 구하고 test 에는 같은 변환을 적용한다. test 를 포함해 평균을 맞추면 시험 자료가 학습 결정에 관여한다.

pipeline 은 교차검증에서 fold 별 전처리 fit 을 올바르게 묶는 데 도움을 준다. 그러나 동일 사용자가 양쪽에 섞였는지, 결과 뒤에 생성된 feature 를 사용했는지까지 모든 업무 의미를 자동 판단하지는 않는다. 그룹과 시간 기준은 자료 수집/예측 목적에 맞게 설계한다.

예측 당시 존재한 정보만 쓴다

시간 누출은 예측 당시 없던 정보를 사용하면서 좋은 결과를 얻는 상황이다. 오늘의 지출 예측에 내일 확정된 월말 합계를 넣으면 미래를 본 셈이다. 값이 실제 자료에 존재해도 예측 시점에 이용 가능한지 별도 검사가 필요하다.

같은 사용자의 비슷한 기록이 train/test 에 섞이면 새로운 사용자 성능을 알고 싶을 때 과도하게 낙관적일 수 있다. 목적이 기존 사용자의 미래 기록이면 시간 분할과 사용자별 역사 조건이 중요해진다. 하나의 분할 방식을 모든 목적의 정답으로 외우지 않는다.

같은 잣대에서 비교한다

두 모델을 비교할 때 평가 사례·라벨·기간·지표·threshold 정책을 일치시킨다. 서로 다른 평가 자료의 정확도 90/95%만으로 새 모델이 좋아졌다고 결론 내릴 수 없다. 표본의 어려움이나 구성 자체가 달라졌을 수 있다.

최종 test 를 여러 후보 선택에 반복 사용하면 선택 정보가 누적된다. validation 으로 선택하고 잠근 test 로 마지막 평가하며 재평가가 필요하면 절차와 범위를 명시한다. 여기서 잠근다는 말은 파일을 읽기 전용으로 만들기만 하는 것이 아니라 모델 선택에 답을 사용하지 않는 규약이다.

중간 과정을 따라가는 예제

train 값 2,4 와 test 값 10 이 있다. 중심화 x−μ에서 train 평균만 쓴 test 결과와 전체 평균을 쓴 결과를 비교하라. 이어 동일 사용자 A 의 원본이 train, 변형 A′가 test 일 때 새 사용자 평가의 문제를 설명하라.

  1. train 평균(2+4)/2=3 이다.

  2. test 변환 10−3=7 이다.

  3. 전체 평균(2+4+10)/3=16/3, test 는 10−16/3=14/3 이다.

  4. A 와 A′는 같은 출처여서 새로운 사용자에 대한 독립 평가라는 목표에 어긋난다.

적절한 train 평균 변환은 7 이며 전체평균 14/3 에는 test 정보가 섞였다. 출처 분리도 별도 필요하다.

fold마다 다른 평균

전체 평균 5와 각 훈련 fold의 평균을 비교하라.

  1. 전체 평균은 20/4 = 5다.

  2. 첫 훈련 평균 1을 쓰면 검증값 8과 10은 7과 9로 바뀐다. 전체 평균 5를 쓰면 3과 5로 바뀐다.

  3. 둘째 훈련 평균 9를 쓰면 검증값 0과 2는 −9와 −7로 바뀐다. 전체 평균 5를 쓰면 −5와 −3으로 바뀐다.

연결의 전이성을 지키는 분할

a/b/c/d의 성분과 한 유효 train/test 배정을 구성하라.

  1. a–b와 b–c가 연결되어 a/b/c는 같은 성분이다.

  2. d는 공유 사용자나 내용이 없어 별도 성분이다.

  3. train={a,b,c}, test={d}는 모든 명시 간선을 같은 쪽에 둔다.

다른 문제에 적용하기

세 부분은 각각 독립된 자체 모형이다. ① 전체 ID는 12개다. 겹치는 A와 B의 정답 수는 각각 6개와 5개, 교집합 정답은 3개다. 고유 정확도를 구한다. 별도 미판정 장부의 확인 정답 7개, 미판정 4개와 기준 3/4를 판정한다. ② 기준 sparse 쌍 (2,7),(5,11)을 역순으로 보존하고 g(x)=0의 API·홀수·이동 관계·x=1 정답을 검사한다. ③ 두 fold의 fit 평균과 검증값, a/b/c/d 연결 성분, 기록 R과 S의 두 시각 조건, validation 선택 A와 test 재선택 B의 평가 절차를 보고한다.

힌트 1

각 분모·교집합·미판정과 sparse 같은 위치 쌍을 이름 붙여 센다.

힌트 2

fit 범위·공개 시각·라벨 마감·후보 선택에 사용한 자료를 각각 확인한다.

풀이와 답 확인

  1. 교집합 정답 3개를 빼면 고유 정답은 8개이고 정확도는 2/3다. 별도 미판정 장부의 전체 범위는 [7/12,11/12]이며 기준 3/4를 아직 확정하지 못한다.

  2. 정상 역순 sparse는 index=[5,2], value=[11,7]이다. g는 유한 스칼라와 홀수 관계를 통과하지만 g(1)=0과 g(0)+2=2가 달라 이동 관계를 실패한다. x=1의 기준 정답2에도 실패한다.

  3. 첫 fold의 평균은 1이고 검증 변환값은 7과 9다. 둘째 fold의 평균은 9이고 검증 변환값은 −9와 −7이다. 연결 성분은 {a,b,c}와 {d}이며 공유 간선을 가르지 않게 배정한다.

  4. 훈련 마감 14에서 R은 특징 공개 시각 11이 예측 시각 10 이후이고 라벨 공개 시각 15가 마감 이후라 실패한다. S는 특징 공개 시각 9가 예측 이전이고 라벨 공개 시각 13이 마감 이전이라 적격이다. 처음 절차의 최종 성적은 선택한 A의 1/4다. B의 4/4를 보고할 때는 test 재선택 사실을 명시한다.

고유 평가 장부·구조/의미 테스트·fit/연결/시각/선택 범위를 따로 확인한다.

해결한 뒤 점검할 것

  • 겹침과 미판정으로 전체 값 또는 범위가 달라지는 이유를 설명한다.

  • 자료 모양·metamorphic 관계·정답 사례가 검사하는 서로 다른 오류를 드러낸다.

  • 각 fold와 두 공개 시각, 연결 성분 및 test 결과 이용 범위를 정확히 추적한다.

  • 자체 유한 장부와 손논증을 실제 TFDV/Pipeline/모델/학생 실행이나 모집단 인증으로 확대하지 않는다.
