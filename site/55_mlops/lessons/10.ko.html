소단원 10.1

trigger와 재평가

모델이 오래되거나 입력 분포가 달라졌다는 알림이 오면 새 모델을 바로 공개해야 할까?

준비 개념과 학습 목표

준비 개념

  • 훈련 자료와 평가 자료의 역할은 다르다.

  • 배포한 모델의 입력·출력·정답은 서로 다른 시점에 도착할 수 있다.

학습 목표

  • 재학습 신호와 배포 승인을 구별한다.

  • 동일한 평가 조건에서 기존 모델과 새 모델을 비교한다.

오류가 한 개 줄었다면 새 후보를 배포해도 될까?

자체 고정 평가 집합은 A 집단 12개와 B 집단 8개를 합친 고유 사례 20개다. 모든 사례의 정답과 전처리는 고정한다. 기존 모델 O의 오류는 A에서 3개, B에서 2개다. 후보 N의 오류는 A에서 1개, B에서 3개다. 기존 전체 오류율은 5/20=25%, 후보는 4/20=20%다. 자체 승인 조건은 전체 오류율이 20% 이하이고 각 집단 오류율이 25% 이하이며 전체 정답이 확인되는 것이다. 후보의 B 오류율은 3/8=37.5%이므로 전체 조건만 통과한다. 경보·재학습 완료·전체 개선은 승인과 동일하지 않다.

같은 사례의 짝 장부는 두 모델 모두 틀린 사례 2개, O만 틀린 사례 3개, N만 틀린 사례 2개, 두 모델 모두 맞힌 사례 13개다. O의 오류 5개와 N의 오류 4개를 복원할 수 있다. 별도 비용 계약에서 O만 틀린 세 사례는 각각 오류 비용 1 U이고 N만 틀린 두 사례는 각각 오류 비용 2 U다. 두 모델 모두 틀린 사례의 비용은 모델 간 동일하다. N은 비용 3 U를 없애지만 4 U를 새로 발생시키므로 총 오류 비용은 1 U 증가한다. 오류 개수 감소와 비용 감소는 다른 판정이다. 이는 관측 장부의 산술이며 모집단 개선의 유의성 검정이 아니다.

라벨 마감의 별도 변형에서는 A 12개와 B 4개만 확인됐다. 후보의 확인 오류는 A에서 1개, 확인 B에서 1개다. 확인 집합 오류율은 2/16=12.5%지만 미확인 B 네 개 때문에 전체 오류율의 가능한 범위는 [2/20,6/20], B 오류율 범위는 [1/8,5/8]이다. 이 범위는 신뢰구간이 아니다. 후보 N의 완전 장부와 이 미완전 장부는 서로 다른 평가 조건이다. Google Rules of ML의 fresh data·held-out 평가·피드백 범위를 읽고, 승인 조건과 짝 장부는 자체로 정했다.

trigger는 조사와 새 후보 만들기의 신호

trigger, 시작 신호는 주기 경과·새로운 정답 자료 축적·오류율 변화·입력 분포 변화 등으로 정할 수 있다. 그러나 입력 분포가 변했다고 정답 예측이 나빠졌다고 확정할 수는 없다. 사용자 지역 비율이 달라져도 그 지역에서의 예측 관계가 같다면 성능이 유지될 수 있다.

반대로 데이터 파이프라인이 멈추거나 특징 값이 누락되는 장애는 모델을 다시 학습하는 일로 해결되지 않을 수 있다. 신호를 받으면 자료 최신성·결측률·정답 지연·수집 코드 변경을 먼저 조사한다. 재학습은 새 후보를 만드는 과정이며 사용자가 받는 모델을 바꾸는 결정과는 별도다.

같은 시점과 같은 자료에서 후보를 비교한다

평가할 때 기존 모델과 후보 모델에 동일한 입력·정답과 같은 전처리 규칙을 적용한다. 미래의 정답이나 사후에만 생기는 특징이 훈련에 들어가지 않게 시점 경계를 둔다. 학습에 사용한 자료의 높은 정확도를 독립 평가 성능으로 보고하지 않는다.

전체 평균과 함께 주요 집단·최근 기간·실패 유형을 확인한다. 전체 오류가 줄어도 새로 유입된 학습자 집단의 오류가 늘 수 있다. 평가 자료를 반복해서 보고 후보를 고르면 그 자료에 맞춰 선택하는 과적합도 생길 수 있어 최종 판단용 별도 자료와 평가 이력을 보존할 이유가 있다.

통과 조건과 되돌릴 경로를 함께 기록한다

배포 기준에는 정확도뿐 아니라 응답 시간·자원 비용·집단별 하한 등을 목적에 맞게 미리 정한다. 아래 기준은 수업을 위한 임의 기준이며 모든 서비스에 공통인 정책이 아니다. 재학습 실행 기록, 자료 버전, 모델 버전, 평가 결과를 연결해야 개선의 원인을 추적할 수 있다.

오프라인 평가 통과는 실제 사용자 환경의 성공을 증명하지 않는다. 운영 영향 평가가 아직 없으면 그 상태를 명시한다. 배포 뒤 문제가 생기면 기존 모델로 되돌릴 수 있는 버전과 입력 호환성을 마련한다. 후보 만들기·평가·운영 반영을 구별하면 알림이 곧 자동 공개로 이어지는 실수를 줄일 수 있다.

대상과 조건확인한 결과

완전 장부의 O

전체 오류는 5개이며 A 오류율은 25%, B 오류율은 25%다.

완전 장부의 N

전체 오류는 4개지만 B 오류율은 37.5%로 집단 조건에 실패한다.

짝 비교의 별도 비용

고친 사례 비용은 3 U이고 새 오류 비용은 4 U다. 순비용은 1 U 증가한다.

정답 마감 변형

확인 오류율은 12.5%지만 전체 범위는 [10%,30%]다.

완전 장부와 라벨 마감 변형을 합쳐 집계하지 않는다. 두 모델 모두 틀린 사례는 두 오류 수에 각각 포함되지만 모델 간 비용 차이에서는 상쇄된다.

중간 과정을 따라가는 예제

자체 평가 자료 100개는 집단 A 80개와 B 20개로 나뉜다. 기존 모델 오류는 A에서 8개·B에서 2개, 후보는 A에서 4개·B에서 6개다. 기준은 전체 오류율 12% 이하이며 각 집단 오류율도 20% 이하라고 미리 정했다. 후보를 통과시킬까?

  1. 기존 전체 오류는 10/100=10%, A는 8/80=10%, B는 2/20=10%다. 모든 기준을 통과한다.

  2. 후보 전체 오류도 (4+6)/100=10%이고 A는 4/80=5%다. 평균만 보면 유지되고 A는 개선된다.

  3. 후보 B는 6/20=30%로 집단 기준 20%를 넘는다. 전체 12% 기준을 통과했다는 이유만으로 후보를 배포 통과로 판정할 수 없다.

후보는 주어진 집단 기준 때문에 불통과다. 새 학습을 실행했다는 사실과 배포 적합성을 구별한다. 이 100개 표의 계산은 통계적 확신이나 실제 서비스 검증을 제공하지 않는다.

조건을 바꾸어 비교하기

전체 합격과 집단 불합격

완전 장부에서 O와 N의 전체·집단 오류율 및 N 승인 여부를 구하라.

  1. O는 전체 25%, A는 3/12=25%, B는 2/8=25%다.

  2. N은 전체 20%, A는 1/12, B는 3/8=37.5%다.

  3. 전체 오류율 등호는 허용되지만 B가 집단 상한을 넘는다.

N은 승인되지 않는다. O도 새 승인 조건의 전체 상한에는 실패하므로 어느 모델도 조건을 만족한다는 결론은 아니다.

비교할 점

기본의 집단 조건에 기존·후보의 실패 조건을 모두 기록한다.

같은 순개선에도 새 오류 비용이 크다

짝 장부에서 오류 개수와 비용 차이를 구하라.

  1. O의 오류는 공통 2개와 O만의 3개를 합친 5개다. N은 공통 2개와 N만의 2개를 합친 4개다.

  2. O만의 오류 3개를 고쳐 비용 3 U를 줄인다. N만의 새 오류 2개가 비용 4 U를 만든다.

  3. N 비용에서 O 비용을 뺀 값은 4−3=1 U다.

오류는 1개 줄고 비용은 1 U 늘어난다.

연습 1 · 값과 상태 예측

A 오류가 2개, B 오류가 2개인 별도 후보 C를 같은 완전 평가 집합에서 심사하라.

힌트 1

전체 오류는 4개다.

힌트 2

각 집단 상한은 25% 이하로 등호를 포함한다.

풀이와 답 확인

  1. 전체 오류율은 4/20=20%다. A는 2/12=1/6이고 B는 2/8=25%다.

  2. 모든 정답이 확인되고 세 비율 조건을 만족한다.

C는 이 종이 승인 조건을 통과한다. 실제 배포·서비스 검증을 했다는 뜻은 아니다.

전체 합은 집단별 오류 배치를 정하지 않는다.

연습 2 · 오류 찾아 고치기

분석자가 미완전 장부의 후보 오류율 2/16을 전체 20개의 오류율로 보고 승인했다. 고쳐라.

힌트 1

미확인 네 사례는 모두 B에 속한다.

힌트 2

최소 오류는 확인 오류 2개이고 최대는 6개다.

풀이와 답 확인

  1. 전체 가능한 오류율은 [1/10,3/10]이다. B는 [1/8,5/8]이다.

  2. 상한 통과를 보장하지 못하며 전체 정답 확인 조건도 실패한다.

확인 집합 오류율만 12.5%다. 현재 계약에서는 승인을 보류한다.

미확인은 성공을 입증한 사례가 아니다.

연습 3 · 직접 만들어 보기

완전 장부에서 O와 N을 연결한 짝 평가 기록과 배포 전 판정 필드를 설계하라.

힌트 1

같은 고유 ID·정답·전처리에서 두 예측을 비교한다.

힌트 2

집단·오류 비용·정답 마감과 승인 조건도 보존한다.

풀이와 답 확인

  1. 각 사례에 ID, 집단, 입력/정답 판본, 전처리 판본, O/N 모델 판본과 원래 예측, 비용 계약을 기록한다.

  2. 공통 오류 2개, O만 오류 3개, N만 오류 2개, 공통 정답 13개를 따로 보고한다. 전체·집단 오류와 라벨 확인 여부를 함께 판정한다.

짝 연결과 승인 조건을 기록하고 N의 B 실패를 숨기지 않는다. rollback 준비와 운영 검증은 별도 미수행 항목이다.

active learning 입문

정답을 붙이는 시간이 제한되어 있다면 어떤 자료부터 사람에게 질문할까?

준비 개념과 학습 목표

준비 개념

  • 라벨은 예측 결과와 구별되는 학습용 정답 정보다.

  • 이진 분류 확률 p와 1−p는 두 클래스에 대한 모델 추정이다.

학습 목표

  • 불확실성 기반 선택을 작은 후보 표에 적용한다.

  • 선택한 학습 자료와 대표성 있는 평가 자료의 목적을 구별한다.

불확실성 순위의 상위 두 개가 예산 안의 최선일까?

자체 미라벨 pool은 A1·A2·B·C 네 항목이다. 양성 확률 점수는 A1과 A2가 각각 0.5, B가 0.6, C가 0.9다. 선택용 불확실성은 u=1−2|p−0.5|로 정의해 A1과 A2는 1, B는 4/5, C는 1/5다. 이 점수는 새 라벨을 얻었을 때 실제 정확도가 얼마나 오르는지를 보장하지 않는다. A1과 A2는 정보 범위 계산용으로 같은 가족 A에 속한다. 가족 이름이 같다는 조건만으로 두 실제 정답이 같다고 가정하지 않는다.

종이 선택 계약의 각 질의 비용은 A1과 A2가 각각 3 U, B가 2 U, C가 1 U이고 총예산은 4 U다. 목적은 예산 안에서 집합 점수를 최대화하는 것이다. 집합 점수는 선택한 가족별 u를 한 번씩 더한다. 같은 A 가족 두 개를 고르면 두 번째 A의 추가 점수는 0이다. 가능한 비어 있지 않은 가족 조합 중 A 단독은 점수 1, B 단독은 4/5, C 단독은 1/5, A와 C는 6/5, B와 C는 1이다. A와 B는 비용 5 U로 불가능하며 A 두 개도 비용 6 U로 불가능하다. 최선은 A 하나와 C이며 A1/A2 동률은 ID 사전순으로 A1을 고른다.

u/비용을 큰 순서로 채우는 별도 탐욕은 B의 2/5, A의 1/3, C의 1/5 순이다. B를 고른 뒤 남은 2 U로 A를 못 고르고 C를 골라 점수 1을 얻는다. 최적 점수 6/5보다 작다. Settles의 pool-based·불확실성·대표성·batch 중복·가변 비용 관련 본문을 읽었다. 위 선형 u와 가족별 한 번 집계 및 예산은 해당 문헌의 알고리즘을 실행한 결과가 아니라 자체 유한 모형이다.

먼저 확인할 개념
  • active learning 입문

  • trigger와 재평가

    평가 자료의 선택·출처와 운영 장부의 분모를 연결해 확인한다.

라벨을 요청할 대상을 학습기가 고른다

active learning, 능동 학습은 라벨이 없는 자료 중 학습에 도움이 될 후보를 골라 사람 등 라벨 제공자에게 정답을 요청하는 방식이다. 작은 라벨 자료로 모델을 만들고, 후보를 선택하고, 받은 라벨을 추가해 다시 학습하는 사이클을 생각하자. 라벨이 저절로 생기는 방법은 아니다.

pool-based 방식에서는 미리 모인 후보 목록에서 선택한다. 선택 비용뿐 아니라 질문 비용·라벨 품질·주어진 예산을 고려한다. 현재 모델의 예측을 정답이라고 그대로 붙이는 self-training과는 다르다. 능동 학습에서 모델은 어디를 물을지 고를 수 있어도 문의한 정답이 무엇인지 미리 확정하지 않는다.

이진 분류에서 0.5에 가까운 후보

확률을 출력하는 이진 분류기에서는 p가 0.5에 가까울수록 두 클래스 사이에서 불확실하다고 보는 간단한 규칙을 쓸 수 있다. 후보마다 |p−0.5|를 계산하고 작은 순서로 고르면 된다. 이 점수는 모델의 현재 믿음에 대한 척도이며 실제 정답률을 직접 측정한 값이 아니다.

세 클래스 이상에서는 가장 큰 클래스 확률 하나만 보는 least-confidence나 상위 두 확률의 차이를 보는 margin 등 규칙이 서로 다른 후보를 고를 수 있다. 예를 들어 (0.45,0.44,0.11)은 margin 0.01, (0.40,0.30,0.30)은 0.10이다. margin은 첫 후보를 더 불확실하게 보지만 최대 확률만 보면 둘째가 0.40으로 더 낮다.

불확실하지만 쓸모가 적은 표본도 있다

불확실성만 따라가면 외딴 이상치나 반복해서 비슷한 질문을 고를 수 있다. 후보가 전체 자료를 얼마나 대표하는지, 같은 유형이 너무 많이 선택되지는 않는지 살펴보자. 현재 모델이 확신하지만 틀리는 영역을 이 규칙이 충분히 발견하지 못할 수도 있다.

라벨 요청으로 고른 어려운 자료의 오류율을 전체 사용자 오류율이라고 보고하지 않는다. 평가 목적의 자료는 목표 모집단을 대표하도록 별도로 설계한다. 요청 예산을 모두 소모해도 학습 이득이 보장되지 않으므로 동일 예산의 무작위 선택과 별도 평가에서 비교하는 것이 도움이 된다.

비율 탐욕의 결과

개별 점수의 합과 가족별 한 번의 점수를 구별한다. 남은 예산을 모두 쓰는 것 자체가 목적은 아니며 사람에게 얻은 정답과 모델 점수는 서로 다르다.

중간 과정을 따라가는 예제

후보 A·B·C·D의 양성 확률은 각각 0.10,0.48,0.90,0.55다. 중복 없는 두 후보에 라벨을 요청한다. |p−0.5|가 작은 순서를 쓰고 라벨 요청 비용은 모두 같다고 가정하자.

  1. A의 거리 0.40, B의 거리 0.02, C의 거리 0.40, D의 거리 0.05다.

  2. 가장 작은 B 0.02와 다음 D 0.05를 고른다. A와 C의 동률은 이번 두 개 선택에 영향을 주지 않는다.

  3. 사람이 B는 음성·D는 양성이라고 답했다면 그 관찰 라벨을 학습 자료에 추가한다. p가 0.48·0.55였다는 이유로 관찰 라벨을 수정하지 않는다.

B와 D에 요청한다. 모델 불확실성을 계산했을 뿐 재학습 후 정확도 개선 수치는 아직 알 수 없다.

노출 후 클릭 비율이 높으면 내용 자체도 더 좋을까?

자체 고정 비율 모형에서 내용 A의 잠재 클릭 계수는 θ_A=2/5, 내용 B는 θ_B=3/5다. 위쪽 위치의 배율은 1, 아래쪽은 1/2이며 클릭 비율은 θ×위치 배율로 정확히 정한다. 실제 클릭 실험이나 확률 표본을 실행하지 않았다. 정책이 A를 위쪽에 900번, B를 아래쪽에 100번 노출한 종이 장부는 A 클릭 360번과 B 클릭 30번이다. 관측 비율 A 40%가 B 30%보다 높지만 내용 계수는 A 40%가 B 60%보다 낮다. 관측 위치가 다르면 클릭 비율의 순위를 내용 계수의 순위로 옮기지 못한다.

별도 균등 위치 장부는 A와 B 각각 위쪽 100번·아래쪽 100번을 노출한다. A 클릭은 위쪽 40번·아래쪽 20번으로 합계 60/200=30%이고 B는 위쪽 60번·아래쪽 30번으로 합계 90/200=45%다. 이미 알려진 곱셈 모형에서 아래쪽 클릭을 2배 보정하면 A는 (40+2×20)/200=40%, B는 (60+2×30)/200=60%다. 이는 알려진 위치 배율을 사용하는 모형 계산이다. 실제 관측만으로 위치 배율을 알아내거나 인과 효과를 검증한 것은 아니다. 원래 장부에서 B를 더 이상 노출하지 않으면 B 클릭 0번/노출 0번은 비율을 정의하지 못한다.

정답 출처의 별도 장부는 서로 다른 고유 ID 200개다. 이 종이 모형에서 사람 라벨 100개는 참 정답으로 두며, 나머지는 모델 자신의 예측을 복사한 pseudo-label 100개다. 같은 고정 모델이 사람 라벨과 일치한 수는 90개이며 pseudo-label과는 구성상 100개 모두 일치한다. 섞은 일치율은 190/200=95%지만 pseudo-label의 실제 정답은 미확인이다. 사람 라벨을 참 정답으로 사용하는 별도 가정에서 전체 실제 정확도의 논리 범위는 [90/200,190/200]=[45%,95%]다. 사람 라벨과 다른 10개까지 예측으로 덮어쓰면 저장 라벨 일치율은 100%가 되지만 평가 정답을 바꾼 것이다. 모델이 만든 노출도 자료 수집 조건이다

추천 모델이 A 자료를 많이 보여 주면 A의 반응을 많이 관찰하고 B의 반응은 적게 관찰한다. 그 클릭 수를 선호도의 순수한 증거로 쓰면 처음의 선택이 다음 학습에도 영향을 준다. 이것이 자기 선택을 통해 미래 자료를 바꾸는 피드백 루프의 한 형태다.

위치·시간·대상 집단도 반응에 영향을 준다. 화면 맨 위의 클릭 수가 많다는 사실만으로 내용의 가치가 더 높다고 확정할 수 없다. 노출되지 않은 자료에 클릭이 없다고 부정 라벨을 붙이는 것도 관찰 기회 없음과 싫어함을 혼동한다. 노출·위치·선택 정책 등 자료 수집 맥락을 기록할 이유다.

비율을 계산해도 인과 관계는 남는다

클릭률은 클릭 수/노출 수로 분모를 맞춘 기술 통계다. 단순 클릭 개수 비교보다 수집 기회 차이를 드러내지만, 다른 위치나 다른 사용자를 비교하면 클릭률 차이도 내용 자체의 인과 효과로 단정할 수 없다. 같은 숫자를 기록하면서 해석의 한계를 함께 적자.

수집 정책의 영향을 줄이는 방법에는 목적에 맞게 설계한 무작위 노출이나 기존 모델 영향 밖의 별도 자료 확보가 있다. 이는 모든 상황에서 바로 시행해야 하는 명령이나 완전한 해결책이 아니다. 탐색 비용과 사용자 영향, 정답 품질을 고려하며 기존 자료만으로 무엇을 추정할 수 없는지 명시한다.

라벨과 평가 경계를 오염시키지 않는다

피드백 선택 편향과 라벨 오염은 다르다. 사람 정답을 모델 예측으로 덮어 쓰면 라벨의 출처가 바뀌고 이전 오류를 정답처럼 강화할 수 있다. 자동 생성 라벨을 쓰는 방법이 모두 금지되는 것은 아니지만 사람 라벨·약한 라벨·예측 라벨을 구별하고 불확실성과 별도 검증을 기록해야 한다.

평가 오염은 평가용 자료가 학습에 섞이거나 미래 정보가 과거 예측 특징으로 들어가는 등의 문제다. 동일 문서의 복사본이 양쪽에 있으면 파일명만 다르다고 독립 표본이 되지 않는다. 자료 식별자·중복 관계·시점·라벨 출처를 추적하여 원인을 구별해야 단순 재학습으로 같은 실패를 반복하지 않는다.
