공개 참고자료

  • Stanford University — Computer and Network Security — Syllabus

    본문 열람 확인: 시스템·웹·네트워크·privacy·AI security
    공격 실습은 허가된 격리 환경에서 작성할 예정이다. 원과제 실행·전 취약성 검증을 완료한 것은 아니다.

  • University of Wisconsin–Madison — OSTEP 공개 교재·장별 자료·프로젝트

    본문 열람 확인: 가상화·동시성·영속성·보안·프로젝트 링크
    무료 열람이 임의 재배포 허가를 뜻하지 않는다. 저자는 장별 원링크 연결을 요청한다. 주제 개념의 보완 근거로 사용.

  • Stanford University — Introduction to Cryptography — Syllabus

    본문 열람 확인: PRG·PRF·CPA·MAC·hash·AE·DH·RSA·signatures·TLS·PQC·ZK
    고학년 학부/대학원 수준을 고려해 PQC·ZK는 개요로 제한. 독자 구현 암호를 실제 보안에 배포하는 경로로 설계하지 않는다.
