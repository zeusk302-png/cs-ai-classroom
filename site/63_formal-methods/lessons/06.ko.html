소단원 6.1

loop invariant

반복 중 i와 합계가 계속 바뀌는데 무엇이 불변일까?

준비 개념과 학습 목표

준비 개념

  • 수학 정수의 정확한 연산을 쓴다. 기계 정수 overflow는 별도다.

  • N은 바뀌지 않는 비음수 정수이고 대입은 순서대로 수행한다.

학습 목표

  • 초기화·보존·종료 시 함의를 구별한다.

  • 합계 반복문의 불변식을 유도한다.

두 칸씩 이동하며 홀수를 더하면 어느 지점에서 제곱합 관계가 유지되나요?

새 명령 O는 i:=0; s:=0; while i<2×N do s:=s+i+1; i:=i+2입니다. N은 고정 비음수 정수이고 i,s는 별개 저장 칸입니다. 모든 연산은 무한정밀 수학적 정수이며 예외·별칭·동시 갱신은 없습니다. 조건 검사 지점의 불변식 I는 0≤i≤2×N, i는 짝수, s=(i/2)²입니다. 여기 i/2는 짝수 조건에서 정확한 정수입니다.

검사 지점에서 i=2×k라고 쓰면 s=k²입니다. 본문 첫 대입 뒤 s=k²+2×k+1=(k+1)²이지만 i는 아직 2×k입니다. 따라서 I의 합 관계는 이 중간 지점에서 보통 거짓입니다. 둘째 대입 뒤 i=2×(k+1)이 되어 I가 복구됩니다. i<2×N과 짝수 조건으로 k<N, 따라서 k+1≤N도 보입니다. 초기화·한 바퀴 보존·종료 함의는 서로 다른 검사입니다.

종료하면 I와 i≥2×N을 합쳐 i=2×N, s=N²을 얻습니다. 대입 순서를 바꾼 O′는 i:=i+2; s:=s+i+1로 새 i를 읽어 매번 2×k+3을 더합니다. O′의 검사 지점 관계는 s=k(k+2)이며 마지막 합은 N(N+2)입니다. 순서 변경은 단순 표기 변경이 아닙니다. 아래 상태표는 실제 명령 실행 결과가 아닌 자체 종이 유도입니다.

  • 순차 대입의 중간 상태

    둘째 식은 첫 대입 뒤 상태를 읽으므로 순서를 보존합니다.

바뀌지 않는 값과 참인 관계를 구별한다

loop invariant는 루프 조건 검사 지점마다 참으로 유지하는 관계다. 변수 값이 안 바뀐다는 말이 아니다. i가 늘고 s가 늘어도 s=i(i+1)/2 같은 관계는 유지될 수 있다.

자체 프로그램은 i=0;s=0; while i<N: i=i+1; s=s+i다. 불변식 I는0≤i≤N ∧ s=i(i+1)/2다. 루프 안 모든 중간 줄에서 I가 참이라는 요구는 아니다. i를 먼저 올린 직후 s는 아직 옛 합이다.

초기화와 한 바퀴 보존

초기 i=s=0이면 범위0≤0≤N과 합0을 만족한다. I와 i<N을 가정하고 옛 i=k라 쓰면 첫 대입 뒤 i=k+1, 둘째 뒤 s=k(k+1)/2+(k+1)=(k+1)(k+2)/2다.

k<N과 정수 조건에서 k+1≤N이므로 범위도 보존된다. 몇 사례의 표 확인은 모든 k의 대수 증명을 대신하지 않는다. N이 본문에서 바뀌지 않는다는 조건도 증명의 일부다.

종료 시 조건을 결합한다

종료하면 I와 ¬(i<N)을 함께 안다. i≤N과 i≥N에서 i=N이고 s=N(N+1)/2다. I만으로는 i가 아직0일 때도 참이므로 최종 합을 바로 결론낼 수 없다.

이 논증은 종료한 경우의 후조건을 보장한다. 유한 시간 종료는 별도의 감소량으로 증명한다. 아래 표는 자체 종이 상태 카드이며 프로그램이나 증명 도구를 실제 실행하지 않았다.

힌트 보기

풀이 보기

연습 1 · 값과 상태 예측

독립 초기화한 O에서 N=4의 검사 상태와 끝 합을 쓰세요.

힌트 1

짝수 i를 2씩 늘립니다.

힌트 2

옛 i에 1을 더한 홀수를 s에 더합니다.

풀이와 답 확인

  1. 검사 상태는 (0,0),(2,1),(4,4),(6,9),(8,16)입니다.

  2. 마지막 i=8에서 i<8은 거짓입니다.

끝 상태는 (8,16)입니다.

흔한 오답에서 다시 생각하기

매 바퀴 2를 더하니 합도 8이다.

2는 i의 증가량이며 s의 증가량은 1,3,5,7입니다.

연습 2 · 오류 찾아 고치기

O의 불변식을 범위 J:0≤i≤2×N만으로 약화했습니다. N=2에서 J와 guard를 만족하지만 한 바퀴 뒤 J를 깨는 정수 상태를 만드세요.

힌트 1

실제 도달 상태뿐 아니라 J가 허용한 모든 guard 참 상태가 보존 대상입니다.

힌트 2

i=3은 범위와 guard를 만족하지만 짝수는 아닙니다.

풀이와 답 확인

  1. 초기 검사 상태 i=3,s=0,N=2를 택합니다.

  2. 첫 대입 뒤 s=4이고 둘째 대입 뒤 i=5입니다.

  3. i=5는 상한 4를 넘어 J의 보존을 깹니다.

J의 반례는 (i,s)=(3,0)→(5,4)입니다. 원래 I의 짝수 조건이 이 상태를 배제합니다.

흔한 오답에서 다시 생각하기

이 상태는 원래 초기화에서 도달하지 않으니 J의 보존 증명에 상관없다.

J 자체로 보존을 증명하려면 J와 guard가 허용한 모든 상태를 다뤄야 합니다. 도달성을 쓰려면 그 추가 관계를 명시해야 합니다.

연습 3 · 직접 만들어 보기

O′의 검사 불변식 s=k(k+2), i=2×k를 초기화·보존·종료로 손증명하세요.

힌트 1

새 i는 2×(k+1)입니다.

힌트 2

s에는 새 i+1=2×k+3을 더합니다.

풀이와 답 확인

  1. 초기 k=0,s=0으로 관계가 참입니다.

  2. k(k+2)+2×k+3=(k+1)(k+3)이므로 새 k의 관계를 보존합니다.

  3. 짝수 범위와 guard 거짓에서 k=N입니다.

O′의 끝 합은 N(N+2)입니다.

흔한 오답에서 다시 생각하기

순서가 바뀌어도 같은 N개의 항이라 합은 N²이다.

항의 개수는 같아도 각 항이 2만큼 커져 총 2×N이 더해집니다.

연습 4 · 선택 심화

선택 심화는 기본 연습 뒤 더 탐구하고 싶을 때 풀어 보세요.

O에서 N=0일 때의 종료와, N을 본문에서 N:=N+1로 늘리도록 바꾸었을 때 기존 종료 논증의 실패를 설명하세요.

힌트 1

N=0이면 첫 guard가 거짓입니다.

힌트 2

N과 i가 함께 커지면 남은 차이가 줄지 않을 수 있습니다.

풀이와 답 확인

  1. N=0인 O는 (0,0)으로 0바퀴 종료합니다.

  2. 변경 명령을 N=1에서 시작하면 한 바퀴마다 N은 1만큼, i는 2만큼 증가합니다.

  3. 2×N−i는 초기 값 2에서 계속 2여서 guard가 계속 참입니다.

원래 N=0은 즉시 종료합니다. 변경 명령의 초기 N=1에서는 종료하지 않으며 고정 N이라는 전제를 잃었습니다.

흔한 오답에서 다시 생각하기

불변식 비슷한 식이 있으니 N의 변경도 종료에 영향을 주지 않는다.

범위 보존과 종료 측정의 감소는 별도입니다. 이동하는 목표는 남은 차이를 유지할 수 있습니다.

소단원 6.2

부분정확성

후조건이 맞다는 증명은 프로그램이 끝난다는 증명일까?

준비 개념과 학습 목표

준비 개념

  • Hoare triple {P} C {Q}는 전조건/명령/후조건이다.

  • while의 guard는 반복을 계속할 조건이며 skip은 상태를 바꾸지 않는다.

학습 목표

  • 부분 정확성의 종료 조건부 의미를 설명한다.

  • 약한 불변식과 잘못된 후조건을 반례로 구별한다.

홀수에서 멈추지 않는 루프도 끝난 모든 결과가 0이라는 약속을 지키나요?

고정 비음수 정수 n에서 x:=n 뒤 새 루프 L은 while x>0 do if x=1 then skip else x:=x−2입니다. 수학적 정수·순수 식·순차 명령이며 기계 정수와 구별합니다. 검사 불변식은 0≤x≤n이고 x와 n의 짝홀이 같습니다. x≥2인 가지는 2를 빼고, x=1인 가지는 상태를 유지합니다.

짝수 n에서는 x가 0으로 끝납니다. 홀수 n에서는 x가 1에 도달한 뒤 계속 같은 루프를 반복합니다. 따라서 n≥0에서 종료하면 x=0이라는 부분 정확성은 유효하지만 모든 입력 종료는 실패합니다. 가장 넓은 전체 정확성 입력은 비음수 짝수 n입니다. x=1의 상태가 계속 존재한다는 말은 최종 상태 x=1을 반환했다는 말이 아닙니다.

비교 루프 D는 while x>0 do x:=x−2입니다. 같은 초기화에서 D는 짝수 n이면 0, 홀수 n이면 −1로 종료합니다. D의 관계 −1≤x≤n과 짝홀 보존은 종료 후 {0,−1} 중 정확한 값을 결정합니다. L과 D가 n=4에서 모두 0이라고 모든 입력에서 동등하지는 않습니다. 부분 정확성의 유효성과 종료한 반례, 유한 예산의 미완료 관찰을 구별합니다.

먼저 확인할 개념
  • 종료 조건부 후조건

    무한 반복은 종료 상태의 반례가 아니며 전체 정확성에는 종료가 추가됩니다.

  • 완료와 유한 예산

    Timeout과 순환에 의한 발산 근거를 구별합니다.

끝난 실행의 상태에 대한 약속

부분 정확성은 P에서 시작하여 C가 종료하면 최종 Q가 참이라는 뜻이다. 종료 여부를 함께 주장하지 않는다. 어떤 실행도 종료하지 않는 명령이면 부분 정확성의 조건부 약속은 공허하게 참일 수 있다.

예를 들어 while true: skip의 종료한 최종 상태는 없다. 따라서 부분 정확성 {True} C {False}도 논리적으로 가능하다. False가 실제 실행 끝에서 관측되었다는 뜻이 아니며 프로그램이 유용하다는 판정도 아니다.

while 규칙이 주는 정보

{I∧b} body {I}를 보이면 {I} while b body {I∧¬b}를 얻는다. 전조건 P가 초기화 후 I를 보장하고 I∧¬b가 목표 Q를 함의하는지 각각 확인한다. 이 규칙 자체는 종료를 추가하지 않는다.

자체 x=N; while x>0: x=x−1은 N≥0에서 I:0≤x≤N을 보존한다. 종료하면 x≤0이므로 x=0이다. 정확한 정수와 본문 대입만 있는 조건으로 읽는다.

참인 불변식도 충분히 강해야 한다

I=True도 이 감소 루프에서 보존되지만 종료 뒤 True∧x≤0만 얻어 x=0을 보일 수 없다. x가 음수인 상태도 이 논리식에 포함되기 때문이다. 참인 식을 찾는 것과 목표를 이끄는 식을 찾는 것은 다르다.

x=N을 불변식으로 삼으면 첫 감소 후 깨진다. 초기 참/보존/종료 함의 세 검사를 따로 두면 어떤 부분이 잘못됐는지 설명할 수 있다. 이 단원은 종이 증명이며 실제 검증기 PASS가 아니다.

소단원 6.3

variant와 전체정확성

남은 작업이 매번 줄면 어떤 추가 조건으로 종료를 보일 수 있을까?

준비 개념과 학습 목표

준비 개념

  • 전체 정확성은 부분 정확성에 종료 보장을 더한다.

  • 자연수는0,1,2,…이며 무한 엄격 감소열이 없다.

학습 목표

  • 감소량의 아래 경계와 엄격 감소를 확인한다.

  • 실수 감소 반례와 사전식 튜플을 설명한다.

둘째 수가 다시 커지는 루프의 정확한 바퀴 수를 어떤 자연수로 셀까요?

새 루프 R은 자연수 상태 (a,b)에서 a>0 또는 b>0 동안 반복합니다. b>0이면 b:=b−1입니다. b=0이면 a:=a−1; b:=2×a를 순서대로 수행하며 둘째 식은 감소한 새 a를 읽습니다. 이 가지에 들어올 때 guard에 의해 a>0이므로 자연수 범위를 보존합니다. 각 본문은 유한 대입으로 종료합니다.

사전식 쌍 (a,b)는 두 가지에서 모두 감소합니다. b를 줄이는 가지는 첫 성분이 같고 둘째가 작아집니다. 재설정 가지는 a가 작아져 b의 증가를 허용합니다. 단일 자연수 W=a²+b도 매 바퀴 정확히 1만큼 줄어듭니다. 옛 (a,0)에서 새 값은 (a−1,2×(a−1))이므로 새 W=(a−1)²+2×(a−1)=a²−1입니다. guard 거짓인 자연수 상태는 (0,0)뿐이므로 정확한 바퀴 수는 초기 a²+b입니다.

측정량이 본문을 마친 뒤 감소한다는 부분 약속만으로 본문 자체의 종료를 빠뜨리지 않습니다. 새 루프 H는 while x>0 do (x:=x−1; while true do skip)입니다. 초기 x=1이면 첫 감소 뒤 내부 반복에 갇혀 다음 외부 검사 지점에 도달하지 않습니다. 외부 본문은 종료 결과가 없어 부분 triple을 공허하게 만족할 수 있지만 전체 종료 증명은 실패합니다. Dafny의 실제 decreases는 guard 거짓 뒤 음수 허용·여러 종류의 순서를 포함하며 이 자체 자연수 충분 조건과 도구 전체 규칙을 동일시하지 않습니다.

먼저 확인할 개념
  • 자연수 감소와 사전식 순서

    엄격 감소·잘 정초된 순서·본문 종료의 필요성을 사용합니다.

  • 부분 약속과 종료

    종료 결과가 없는 본문의 부분 triple과 전체 종료를 구별합니다.

남은 작업을 자연수로 센다

variant는 반복을 계속할 때 엄격히 작아지는 종료 측정량이다. 초입에서는 조건 검사 지점의 V가 자연수이고 본문이 끝날 때 V′<V인 충분 조건을 사용한다. 값이 그대로인 비증가만으로는 충분하지 않다.

합계 루프의 V=N−i는 I에서 자연수다. i<N일 때 V≥1이며 한 바퀴 뒤 V′=V−1≥0이다. 본문 자체가 종료하는 유한 정수 대입이므로 이 감소는 전체 루프가 끝남을 보인다.

작아짐과 아래 경계가 함께 필요하다

정수 x에서 while true:x=x−1은 값이 엄격히 줄어도 음수로 끝없이 내려갈 수 있다. 아래 경계가 없으므로 이 측정으로 종료를 보일 수 없다.

양의 실수 x에서 while x>0:x=x/2는 x가 작아지고0이 아래 경계여도 정확 실수 모형에서는1,1/2,1/4,…가 무한하다. 자연수 또는 잘 정초된 순서라는 조건이 중요하다. 부동소수점 underflow는 다른 모형이다.

여러 단계는 사전식 순서를 쓴다

자연수 쌍 (a,b)는 첫 a가 줄면 b가 커져도 감소로 판정한다. a가 같으면 b가 엄격히 줄어야 한다. 모든 성분이 매번 줄어야 하는 것은 아니다. 이 사전식 순서도 자연수 쌍에서는 무한 감소를 허용하지 않는다.

Dafny의 실제 decreases는 guard 거짓 뒤 음수 값을 허용하는 등 더 넓은 규칙이 있다. 여기 충분 조건과 도구 전체 규칙을 동일시하지 않는다. 주석을 썼다는 사실은 실제 검증 성공 증거가 아니다.

R의 5바퀴 및 H의 발산을 손대조했다. 기본과 저장 보강 전체 및 수동 변경 필드를 실제 재독했다. 여섯 실제 선수 설명/HTML 앵커와 두 실제 primary를 확인했다.

not_executed: 모든 새 계산/증명은 손유도다. Rocq/Dafny·명령 해석기·실수/정수/난수 구현·실제 장치·서비스·학생 수행을 실행하지 않았다. Python은 JSON/SHA/구조/원자 저장에만 사용한다. 기본/v1/외국어를 보존한다.
