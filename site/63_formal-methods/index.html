같은 단원 안에서 쉬운 진입 → 본 이론 → 심화로 이어집니다. 처음에는 작은 예시를 보고, 다음에는 정의·기호·계산·유도를 공부합니다. 심화에서는 증명과 더 복잡한 문제를 다룹니다.

기본 활동은 종이와 본문으로 읽고 해볼 수 있게 설계합니다. 프로그램 설치와 실행은 선택 활동입니다.

본 이론의 권장 선수: 오토마타와 계산이론 · 프로그래밍언어론 · 이산수학 II

선수과목 전체를 먼저 마쳐야 이 페이지를 읽을 수 있는 것은 아닙니다. 필요한 개념은 단원 시작에서 확인하고 짧은 보충 설명으로 연결합니다.

  • 명세·프로그램논리·타입·모델검사의 입문을 통합한다. 검증된 명세 범위와 도구 가정을 분리하며 대형 시스템 완전검증은 주장하지 않는다.
  • 단원은 주차와 같지 않다. 12개 학습 단원은 시험·휴강을 제외한 내용 체계이며 과목별 분량·실습시간에 맞춰 주차를 나눈다.
  • 여러 공개 자료의 범위·학습구조를 참고해 자체 구성한 목차이며 대학의 공식 한국어 번역본이나 전체 강의 복제본이 아니다.
  • SAT·SMT·bounded model checking·추상해석은 프로그램논리와 공개 분석 강좌를 연결하는 자체 입문 구성이다. UPenn 교재가 모델검사 전체를 제공한다고 주장하지 않는다.
