전이모델과 planning

상상한 다음 상태가 틀리면 가장 좋은 계획도 틀릴 수 있을까?

학습 목표

계획한 세 단계 정책을 다른 전이확률로 평가하면 무엇이 남을까?

앞 본문의 유한 지평 규칙을 새 종이 모형에 적용한다. 상태 A에서 안전은 보상 3을 받고 종료 E로 간다. 도전은 항상 보상 1을 받고 확률 p로 A에 남으며 확률 1−p로 E에 간다. 할인은 γ=1이고 남은 행동 수는 최대 세 번이다. 종료 뒤 보상과 가치는 0이다.

추정 모델은 p̂=4/5이고 실제 전이확률은 p=2/5라고 별도로 가정한다. 모델 안에서 V₁(A)=3, V₂(A)=17/5, V₃(A)=93/25다. 모델 정책은 세 번 또는 두 번 남았을 때 도전하고 한 번 남으면 안전을 고른다. 이 정책을 고정한 뒤 실제 p로 평가하면 47/25다. 실제에서 새로 최적화한 값과 모델 계획값도 각각 별개다.

각 Vk는 모든 상태에서 이전 Vk−1을 사용한다. 갱신 순서에 따라 같은 sweep에서 방금 만든 값을 읽는 계산은 허용될 수 있는 별도 알고리즘이지만 그 sweep 번호를 곧 남은 행동 수로 해석할 수 없다. 아래 모든 연습은 명시한 초기값으로 독립 시작한다.

다음 상태의 분포가 모델이다

전이모델 T(s,a,s′)는 상태 s에서 행동 a를 할 때 다음 상태 s′가 될 확률이다. 가능한 다음 상태들의 확률은 음수가 아니고 합이 1이어야 한다. 결정적인 다음 상태 하나만 적는 모델도 확률 1의 특수한 경우로 볼 수 있다.

모델은 처음부터 주어질 수도 있고 자료에서 추정할 수도 있다. 상태 전이와 보상 규칙을 함께 알아야 계획의 기대 이익을 계산한다. 관측 횟수로 만든 경험 비율은 추정이며 실제 확률을 완전히 알아냈다는 증명이 아니다.

모델 안에서 여러 미래를 비교한다

Planning은 주어진 모델로 미래를 계산하여 행동을 고르는 과정이다. 남은 행동 수가 k일 때의 최적 기대 합을 Vk(s)라고 하고 V0=0으로 둔다. 다음 행동을 정한 뒤 가능한 결과별 즉시 보상과 할인된 남은 가치를 더하고 확률로 평균한다.

유한 단계 규칙은 Vk+1(s)=max_a Σs′ T(s,a,s′)[R(s,a,s′)+γVk(s′)]다. 합 안은 확률에 따른 평균이고 max는 행동 선택이다. 끝난 상태는 남은 가치 0으로 둔다. 모든 상태를 같은 이전 Vk로 갱신하는 계산과 갱신 도중 새 값을 쓰는 계산을 섞지 않는다.

모델의 성공은 실제 시험과 다르다

추정 모델에 최적이라는 결과는 그 모델과 목적에 대한 결과다. 전이가 틀리거나 탐색한 행동의 자료가 부족하면 실제 결과가 달라진다. 길게 모델을 따라가면 작은 오류가 누적될 수도 있어 계획의 범위와 실제 평가를 따로 기록한다.

아래는 상태 A와 종료 E만 있는 자체 두 단계 모형이다. γ=1은 유한 두 단계라 허용한다. 이 계산을 무한 지평 γ=1의 수렴 증명이라고 하지 않는다. 실제 환경·RL 학습·학생 실험은 수행하지 않았다.

중간 과정을 따라가는 예제

자체 모형에서 A의 안전 행동은 보상 2를 받고 E로 간다. 도전은 보상 1을 받으며 확률 1/2로 A, 1/2로 E로 간다. E에서는 추가 보상 0이다. γ=1, V0(A)=V0(E)=0으로 V1(A), V2(A)를 구하라.

  1. 한 단계 안전 값은 2, 도전 값은 (1/2)×1+(1/2)×1=1이라 V1(A)=2다. E의 가치는 0이다.

  2. 두 단계 안전 값은 2+V1(E)=2다. 도전 값은 (1/2)×(1+2)+(1/2)×(1+0)=2다.

  3. V2(A)=max(2,2)=2이며 두 행동이 동점이다. A로 돌아갔을 때 마지막 행동은 안전을 고른다.

V1(A)=2, V2(A)=2다. 두 단계 첫 행동에는 동점이 있으며 미래 가치를 단순히 두 번 더하지 않는다.

조건을 바꾸어 비교하기

모델의 미래 가치와 실제 정책의 미래 가치

세 단계 모델 계획값과 그 모델 정책의 실제 기대값을 각각 구하라.

  1. V₁=3이다. 모델 두 단계 도전 값은 1+(4/5)×3=17/5라 안전 3보다 높다.

  2. 모델 세 단계 도전 값은 1+(4/5)×(17/5)=93/25다.

  3. 실제에서 같은 정책의 두 단계 값은 1+(2/5)×3=11/5다. 세 단계 값은 1+(2/5)×(11/5)=47/25다.

모델 값은 93/25이고 고정 정책의 실제 기대값은 47/25다. 실제 최적 정책은 이 모형에서 즉시 안전이며 값은 3이다.

비교할 점

실제 첫 전이에 모델 V₂=17/5를 계속 넣으면 서로 다른 두 환경의 미래를 섞는다.

같은 sweep 안의 새 값을 쓰면 지평이 바뀐다

별도 결정적 모형에서 A는 보상 0으로 B로 가고 B는 보상 5로 종료한다. 각 상태의 행동은 하나다. V₀=0, γ=1에서 동시 V₁/V₂와 B부터 갱신하는 첫 in-place sweep을 구하라.

  1. 동시 V₁(A)=0이고 V₁(B)=5다.

  2. 동시 V₂(A)=5이고 V₂(B)=5다.

  3. 첫 in-place sweep에서 B를 5로 갱신한 뒤 A가 새 B를 읽으면 A도 5가 된다.

동시 한 단계 값은 A에서 0이다. 첫 in-place sweep의 A=5는 이미 두 전이의 보상을 담는다.

비교할 점

in-place 값이 틀렸다는 일반 결론이 아니라 sweep 횟수와 유한 지평 k를 같은 뜻으로 쓰는 오류다.

종이와 본문으로 직접 해보기

도전의 A 복귀 확률 추정이 3/4로 바뀌었다. 다른 조건은 같을 때 두 단계 도전의 계획 값과 첫 선택을 구하라. 실제 복귀 확률이 여전히 1/2면 어떻게 되는가?

힌트 보기

도전 값은 1+p×V1(A)다. 종료 확률은 1−p다.

풀이 보기

모델 계획 값은 1+(3/4)×2=5/2로 안전 2보다 높아 도전을 고른다. 실제 p=1/2이면 그 정책의 두 단계 기대값은 2다. 모델의 5/2를 실제 측정 성능이라고 적지 않는다.

오해와 반례

모델에서 가장 높은 보상을 찾았으므로 실제 환경에서도 그 값이 보장된다.

모델과 보상 및 조건이 맞아야 해석할 수 있다. 추정 오류와 자료 범위 및 실제 평가가 남는다.

연습 1 · 값과 상태 예측

첫 모형의 추정 p̂를 1/2로 독립 변경한다. 두 단계 첫 선택과 모델 가치 및 실제 p=2/5에서 같은 정책의 값을 구하라.

힌트 1

한 단계에서는 안전 3을 고른다.

힌트 2

두 단계 도전 값 1+3p̂를 안전 값과 비교한다.

풀이와 답 확인

  1. 도전 값은 5/2로 안전 3보다 작다.

  2. 모델 정책은 즉시 안전을 고르므로 실제 전이 p를 사용하기 전에 종료한다.

모델과 실제에서 모두 안전 값 3이다.

흔한 오답에서 다시 생각하기

추정 도전 값 5/2가 정책의 값이다.

도전 후보를 계산한 뒤 max와 실제 선택을 따로 확인해야 한다.

연습 2 · 오류 찾아 고치기

모델 정책을 고정한 실제 세 단계 값을 1+(2/5)×(17/5)=59/25라고 보고했다. 어떤 값을 잘못 가져왔는지 고쳐라.

힌트 1

17/5는 추정 모델에서의 두 단계 값이다.

힌트 2

실제에서 도전 후 안전을 택하는 두 단계 값을 먼저 평가한다.

풀이와 답 확인

  1. 실제 두 단계 고정 정책 값은 11/5다.

  2. 이를 실제 첫 도전의 미래 값에 넣으면 47/25다.

59/25는 모델의 미래를 섞었다. 올바른 실제 값은 47/25다.

흔한 오답에서 다시 생각하기

첫 확률만 실제값으로 바꾸면 충분하다.

정책은 유지하되 모든 남은 전이의 확률도 실제 환경으로 평가해야 한다.

연습 3 · 직접 만들어 보기

두 단계에서 안전 보상 3과 도전 보상 1을 그대로 둔다. p∈[0,1]의 최적 행동 구간과 p가 [2/5,4/5] 중 어디인지 모르는 경우 두 고정 첫 행동의 최악값을 비교하라.

힌트 1

도전과 안전의 동점 조건은 1+3p=3이다.

힌트 2

도전 값은 p에 대해 증가하므로 구간 왼쪽에서 최소다.

풀이와 답 확인

  1. p=2/3에서 동점이며 그보다 크면 도전, 작으면 안전이다.

  2. 안전 최악값은 3이고 도전 후 마지막 안전의 최악값은 11/5다.

두 단계 선택 경계는 2/3다. 지정 불확실성 구간의 maximin 첫 선택은 안전이다.

흔한 오답에서 다시 생각하기

구간의 오른쪽 끝이 더 유망하므로 최악값도 그 끝에서 구한다.

최악값은 후보 행동별로 최소를 먼저 구하고 그 최소들 중 큰 것을 고른다.

연습 4 · 선택 심화

선택 심화는 기본 연습 뒤 더 탐구하고 싶을 때 풀어 보세요.

두 모델에서 도전의 A 복귀확률이 p와 p′이고 남은 한 단계 가치가 A에서 3, E에서 0이다. 두 단계 도전 후보 값의 차이를 구하고 모든 p에서 첫 행동이 안정적인지 설명하라.

힌트 1

두 후보는 1+3p와 1+3p′다.

힌트 2

2/3 양쪽의 가까운 두 확률을 생각한다.

풀이와 답 확인

  1. 후보 값 차이는 3|p−p′|다.

  2. p=2/3 부근에서는 작은 확률 교란이 동점의 양쪽으로 넘어가 행동을 바꿀 수 있다.

후보 값의 연속적인 변화와 argmax 행동의 안정성은 다르다.

흔한 오답에서 다시 생각하기

후보 값 오차가 작으면 행동도 항상 같다.

안전과 도전 사이 여유가 0인 선택 경계에서는 작은 교란도 선택을 바꾼다.

내 말로 설명하기

실제 평가에서 모델 정책을 다시 고르는가?

설명 기준 확인

고정 정책 평가라면 행동 규칙은 유지하고 전이확률만 실제 가정으로 평가한다.

유한 세 단계 γ=1이 무한 지평 수렴을 보장하는가?

설명 기준 확인

아니다. 종료 지평을 둔 계산과 무한 반복 수렴 조건을 분리한다.

한 단계 더

일반 복귀 확률 p∈[0,1]의 두 단계 도전 값은 1+2p다. 안전 2와 비교하면 p>1/2에서 도전, p<1/2에서 안전, p=1/2에서 동점이다. p 추정의 작은 오차가 경계 근처 행동 선택을 바꿀 수 있음을 확인하자. 이 식은 자체 유한 모형의 결과다.

오프라인·부분관측 입문

기록에 없는 행동과 직접 보이지 않는 상태를 어떻게 다루어야 할까?

준비 개념과 학습 목표

준비 개념

  • 자료의 상태·행동·보상 기록

  • Bayes 규칙

  • 관측과 실제 상태

학습 목표

  • 오프라인 학습과 off-policy를 구별한다.

  • 미관측 행동을 자료만으로 확정할 수 없음을 설명한다.

  • 간단한 belief와 기대 보상을 계산한다.

관측 전에 상태가 움직였다면 어떤 prior를 보정해야 할까?

앞 본문의 정적 Bayes 모형을 동적으로 바꾼다. 이전 H 확률은 4/5이고 상태는 관측 전에 확률 1/4로 H와 L 사이를 뒤집는다. 행동에 의한 이 전이는 두 상태에서 같은 뒤집기 확률이다. 새 밝음 관측 가능도는 현재 H에서 4/5, 현재 L에서 1/5다.

현재 H의 예측 확률은 (4/5)(3/4)+(1/5)(1/4)=13/20이다. 밝음과 현재 H의 결합확률은 13/25이며 현재 L의 결합확률은 7/100이다. 밝음 확률은 59/100이고 사후 H는 52/59다. 이전 belief를 그대로 가능도에 곱한 16/17은 상태가 움직이지 않는 다른 모형의 답이다.

밝음 뒤 한 단계 행동 X는 현재 H에서 6, 현재 L에서 −8을 받고 Y는 항상 4를 받는다. MAP 상태를 확정하는 대신 X의 기대 보상 256/59를 Y의 4와 비교한다. 다른 보상표에서는 같은 MAP 상태라도 다른 선택이 가능하다. 오프라인 자료의 미관측 행동도 0으로 메우지 않는다.

  • 전이분포의 평균

    이전 belief를 상태 전이로 예측한 뒤 새 관측으로 보정한다.

추가 탐험 없이 기존 기록으로 배운다

오프라인 RL은 고정된 과거 전이 자료로 정책을 배우며 학습 중 새 환경 상호작용을 수집하지 않는 설정이다. 자료를 만든 행동 정책과 배울 정책이 다를 수 있다. 다른 정책의 자료를 쓰는 off-policy라는 말만으로 추가 수집이 없다는 뜻이 되지는 않는다.

새 정책이 기록에 적게 나온 상태·행동을 고르면 예측이 자료 범위를 벗어날 수 있다. 값이 높다고 추정된 미관측 행동을 반복 선택하면 오류를 이용하는 선택이 될 수 있다. 자료 제한·불확실성·분포 이동을 고려하며 단순히 평균 보상이 높은 행동을 고르는 것과 구별한다.

오프라인과 부분관측은 서로 다른 축이다

부분관측에서는 환경 상태를 직접 완전히 보지 못하고 관측 o를 받는다. 같은 관측도 여러 상태에서 나올 수 있다. 현재 관측 하나만으로 상태가 모두 결정된다고 가정하면 과거 관측과 행동의 유용한 정보를 버릴 수 있다.

Belief b(s)는 지금까지의 증거와 모델 아래 각 상태일 확률이다. 동적인 문제에서는 이전 belief를 행동 전이로 예측한 뒤 새 관측 가능도로 보정한다. 본문 예제는 상태가 변하지 않는 한 번 관측 사례라 Bayes 보정만 한다. 오프라인 여부와 상태 가시성은 독립적으로 정할 수 있다.

없는 정보의 빈칸을 확신으로 채우지 않는다

기록에 행동 오른쪽이 한 번도 없다면 왼쪽 보상만으로 오른쪽의 결과를 확정할 수 없다. 같은 기록을 설명하지만 오른쪽 보상이 다른 두 환경을 생각하면 한계를 볼 수 있다. 추가 구조 가정이나 외부 정보가 있다면 그것도 근거로 따로 적는다.

Belief 역시 모델과 관측 규칙에 조건부인 분포다. 가장 확률 높은 상태를 참이라고 고정하는 것과 기대 보상을 최대화하는 것은 다를 수 있다. 아래 표와 관측은 모두 직접 만든 가상 자료이며 실제 센서·로봇·학생 자료를 사용하지 않았다.

중간 과정을 따라가는 예제

정적인 숨은 상태 H/L의 사전확률은 각 1/2다. 신호 밝음의 가능도는 H에서3/4, L에서1/4다. 밝음을 관측한 뒤 H의 belief와 행동 X의 기대 보상을 구하라. X 보상은 H에서4, L에서−4이고 Y는 항상1이다.

  1. P(밝음)=(1/2)×(3/4)+(1/2)×(1/4)=1/2다.

  2. P(H|밝음)=[(1/2)×(3/4)]/(1/2)=3/4, L은1/4다.

  3. X 기대 보상은 (3/4)×4+(1/4)×(−4)=2다. Y는1이라 이 한 단계 모형에서는 X를 고른다.

belief는 H3/4·L1/4이며 X 기대 보상2로 Y의1보다 크다. H 확정이라는 뜻은 아니다.

조건을 바꾸어 비교하기

전이 예측 뒤 Bayes 보정

지정 모형의 사후 H와 X/Y 선택을 구하라.

  1. H 예측은 13/20이며 밝음 결합은 52/100이다. L의 밝음 결합은 7/100이다.

  2. 사후 H=52/59, L=7/59다.

  3. X 기대값은 (6×52−8×7)/59=256/59이며 4=236/59보다 크다.

사후 H는 52/59이고 이 한 단계 보상표에서는 X를 고른다.

비교할 점

사후를 최대화하는 상태와 기대 보상을 최대화하는 행동은 다른 계산이다.

기록이 같은 두 환경은 미관측 행동에서 달라진다

별도 한 단계 완전관측 모형에서 기록은 같은 상태의 L 행동 보상 2만 포함한다. 환경 U의 R 보상은 6이고 환경 W의 R 보상은 −6이다. 자료만으로 최적 행동을 정하고 μ(R)=0인 중요도 비율을 계산할 수 있는가?

  1. 관측된 L 보상은 U/W에서 동일하므로 기록은 둘 다 설명한다.

  2. U는 R이 최적이고 W는 L이 최적이다.

  3. R을 고르는 목표 정책에 대해 자료 정책 μ의 R 확률이 0이면 π(R)/μ(R)는 정의되지 않는다.

이 기록만으로 두 환경을 구별하거나 R 목표 정책의 값을 중요도 재가중만으로 식별할 수 없다.

비교할 점

없는 행동을 보상 0 또는 비율 0으로 정의하면 관측되지 않은 사실을 추가한다.

종이와 본문으로 직접 해보기

기록에는 같은 상태에서 왼쪽 행동3회와 보상1/1/1만 있다. 오른쪽 보상은 모두5인 환경과 모두−5인 환경이 이 기록과 양립 가능한지 설명하라.

힌트 보기

관측된 왼쪽 결과는 두 환경에서 같고 오른쪽은 관측하지 않았다.

풀이 보기

두 환경 모두 기록과 양립한다. 왼쪽 경험 평균은1이나 오른쪽 보상이나 최적 선택을 이 기록만으로 확정할 수 없다. 오른쪽을 안 봤다는 이유로 오른쪽 보상을0이라고 정의하지 않는다.

오해와 반례

오프라인 RL에서는 상태가 언제나 보이지 않는다.

오프라인은 추가 자료 수집 조건이고 부분관측은 상태와 관측의 관계다. 완전관측 오프라인이나 부분관측 온라인도 가능하다.

연습 1 · 값과 상태 예측

뒤집기 확률만 1/2로 독립 변경한다. 밝음 뒤 H 사후와 원래 X/Y 보상표의 선택을 구하라.

힌트 1

전이 뒤 H 확률은 이전 확률에 상관없이 1/2다.

연습 3 · 직접 만들어 보기

별도 정적 모형에서 H/L prior는 각 1/2다. 밝음 가능도는 4/5와 1/5다. 조건부로 독립인 두 번의 밝음 관측과 하나의 밝음 사건을 기록만 두 번 복사한 경우를 구별해 사후를 구성하라.

힌트 1

독립 새 증거 두 번은 각 상태 가능도를 제곱한다.

힌트 2

연습 4 · 선택 심화

선택 심화는 기본 연습 뒤 더 탐구하고 싶을 때 풀어 보세요.

현재 H prior가 q일 때 원래 X 보상 6/−8와 Y 보상 4의 선택 경계를 구하라. 이어 새 관측 O의 가능도가 H와 L에서 모두 0이면 사후를 1/2로 둘 수 있는가?

힌트 1

X 기대값은 14q−8이다.

힌트 2

관측 분모는 q×0+(1−q)×0이다.

풀이와 답 확인

  1. 14q−8=4에서 q=6/7이다. 이보다 크면 X, 작으면 Y, 같으면 동점이다.

  2. O의 분모가 0이라 Bayes 나눗셈은 정의되지 않는다.

X/Y 경계는 6/7이며 불가능 관측의 사후는 해당 모형에서 정해지지 않는다. 오류 처리나 모형 변경은 별도 규약이다.

흔한 오답에서 다시 생각하기

분모가 0이면 균등 사후가 자동으로 정답이다.

균등 대입은 추가 정책이며 주어진 확률모형의 조건부 계산이 아니다.

기록 수가 많으면 미관측 행동도 식별되는가?

설명 기준 확인

같은 행동의 반복만으로 다른 행동의 결과를 정할 수 없다. 추가 구조나 자료가 필요하다.

새 belief의 첫 단계는 무엇인가?

설명 기준 확인

이전 belief에 상태 전이를 적용한 예측을 먼저 만들고 현재 관측 가능도로 보정한다.

한 단계 더

어두움의 가능도가 H1/4·L3/4면 사후 H1/4·L3/4다. X 기대 보상은−2여서 Y1을 고른다. 사전 H 확률을 q로 바꾸면 밝음 뒤 H는3q/(1+2q)다. q=0 또는1의 경계도 확인하고, 관측 확률이0인 사건을 조건부로 나눌 때는 별도 처리가 필요함을 기억하자.

다중 seed·평가정책·보상해킹

최고 점수 한 번과 여러 번의 평균은 무엇이 다르며 보상은 진짜 목표와 같은가?

준비 개념과 학습 목표

준비 개념

  • 평균·중앙값·범위

  • 훈련 정책과 평가 정책

  • 보상과 원하는 결과

학습 목표

  • 독립 훈련 run과 평가 episode를 구별한다.

  • 좋은 seed만 보고하는 선택의 문제를 설명한다.

  • 자체 반복 보상의 허점을 계산한다.

같은 평가 episode 표를 어떤 단위로 평균할까?

새 가상 장부에는 독립 훈련 run 두 개가 있고 각 모델의 평가 episode 수가 다르다. run R1의 점수는 (0,10)이고 run R2의 점수는 (6,6,6,6,6,6)이다. run별 평균은 5와 6이다. 훈련 run을 같은 무게로 요약하면 11/2이고 모든 episode를 같은 무게로 합치면 23/4다.

둘은 다른 질문의 답이다. episode 개수가 많은 모델에 더 큰 무게를 주는 합계를 독립 훈련 반복의 평균으로 바꿔 부르면 안 된다. 별도 비교값 28/5와 비교할 때 11/2는 작고 23/4는 커서 보고 선택만으로 순위가 달라진다. 두 run만으로 모집단 우위를 확정하지 않는다.

평가 행동 규칙과 checkpoint 선택 자료도 고정한다. 별도 한 상태 정책은 A 확률 3/5, B 확률 2/5이고 보상은 10과 0이다. 확률적 평가의 기대 보상은 6이지만 최대확률 행동 평가의 값은 10이다. 보상 규칙을 고친 뒤에도 늦게 끝내는 경로가 남는지 전체 경로를 다시 비교한다.

훈련 반복과 평가 반복의 단위를 적는다

Seed는 난수 초기 상태를 지정하는 값이다. 초기 파라미터·자료 순서·탐험·환경이 달라지면 학습 결과가 달라질 수 있다. run은 한 번의 독립 훈련 실행, episode는 시작부터 종료까지의 한 환경 진행이다. 여러 seed로 훈련 run을 수행하고 각 run에 고정한 평가 규약으로 여러 episode를 평가하여 run별 값을 구분한다.

한 모델을100번 평가하는 것과100개의 모델을 각각 훈련하는 것은 같은 실험이 아니다. 가장 좋은 seed만 남기면 선택 편향이 생긴다. 모든 run과 요약·변동을 보고하고 seed 고정만으로 다른 조건의 일반 성능이나 모든 장치의 결정성을 보장하지 않는다.

평가할 때 어떤 정책을 썼는지 기록한다

훈련의 탐험 행동과 평가의 결정적 최대 점수 행동 또는 확률적 정책은 서로 다를 수 있다. 평가 환경·지평·종료·보상 규칙·모델 버전과 checkpoint 선택 방법을 맞춘다. 평가 자료로 가장 좋은 checkpoint를 골랐다면 그 자료가 최종 독립 평가에 쓰인 셈이 아님을 표시한다.

적은 run의 평균 하나는 불확실성을 감춘다. 평균·중앙값·범위는 서로 다른 요약이며 범위 자체가 신뢰구간은 아니다. 충분한 반복과 올바른 분석이 필요하다. 아래는 실제 훈련이 없는 자체 가상 표이므로 유의성이나 우월성 확정 주장을 하지 않는다.

명시 보상과 원하는 일이 어긋날 수 있다

보상해킹은 높은 명시 점수를 얻지만 사람이 의도한 과제를 달성하지 않는 행동을 가리킨다. 보조 보상이 같은 동작을 반복할 때마다 생기면 과제를 끝내기보다 반복 점수를 모으는 정책이 유리해질 수 있다. 이는 최적화 실패보다 목적 명세의 허점일 수 있다.

실제 완료율·제약 위반·오류 종류 같은 별도 결과를 확인한다. 보상을 고쳐도 모든 새로운 환경에서 의도가 완전히 일치한다고 인증하지 않는다. 본문 버튼 모형은 점수 규칙의 허점을 종이로 확인하는 사례이며 실제 시스템을 조작하거나 게임을 실행하지 않는다.

중간 과정을 따라가는 예제

같은 평가 규칙의 가상 run별 점수는 A=(0,6,12), B=(5,6,7)이다. 평균·중앙값·범위·최댓값을 비교하라.

  1. A 합18/3=6, B 합18/3=6으로 평균이 같다. 두 중앙값도6이다.

  2. A 범위는0–12, B는5–7이며 폭은12와2다.

  3. 최댓값만 고르면 A12가 B7보다 커 보이지만 전체 평균 우위의 증거가 아니다. 세 run만으로 진짜 분산이나 미래 우위를 확정하지 않는다.

평균과 중앙값 모두6, 범위 폭은 A12·B2다. 모든 run과 같은 평가 규칙을 함께 보고한다.

조건을 바꾸어 비교하기

같은 장부에서 순위가 바뀌는 평균

두 평균을 계산하고 별도 기준 28/5와 비교하라.

  1. R1 평균은 10/2=5이고 R2 평균은 36/6=6이다.

  2. 동일 run 평균은 (5+6)/2=11/2다. episode 합계는 46이고 전체 평균은 46/8=23/4다.

  3. 11/2<28/5<23/4다.

평균의 표본 단위만 바꾸어도 기준에 대한 순위가 달라진다.

비교할 점

숫자 계산은 둘 다 맞을 수 있으나 같은 평가 목적이라고 이름 붙이면 의미가 달라진다.

한 번만 보조 보상을 줘도 완료는 늦어진다

새 최대 네 행동 모형에서 완료하면 8점을 받고 종료한다. 미완료 상태에서 기다리기를 처음 할 때만 2점을 주고 이후 기다리기는 0점이다. γ=1에서 즉시 완료와 한 번/세 번 기다린 뒤 완료를 비교하라.

  1. 즉시 완료는 8점이며 한 번 기다린 뒤 완료는 10점이다.

  2. 세 번 기다린 뒤 네 번째에 완료해도 10점이다.

  3. 보조 보상 2를 제거하고 각 행동에 비용 1/2를 부과하면 즉시 완료는 15/2, 세 번 기다린 뒤 완료는 6이다.

일회 보조 보상도 즉시 완료보다 대기를 선호한다. 별도 수정 모형에서는 비용 때문에 즉시 완료가 더 크다.

비교할 점

일회 지급이 반복 점수 누적을 막아도 신속 완료라는 의도와 자동으로 일치하지 않는다.

종이와 본문으로 직접 해보기

자체 과제는 5단계 안에 완료하되 가능하면 빨리 완료하는 것이다. 완료 행동은 즉시 10점을 받고 종료한다. 완료하지 않고 반복 버튼을 누를 때마다 3점을 받으며 5회 뒤 종료된다. γ=1일 때 즉시 완료와 반복 5회, 반복 4회 뒤 완료의 점수와 완료 여부를 비교하라.

힌트 보기

반복 버튼의 점수는 횟수×3이다. 완료 뒤에는 추가 행동이 없고5단계 한도 안에서 반복 후 완료도 가능하다.

풀이 보기

즉시 완료는10점·완료, 반복5회는15점·미완료, 반복4회 뒤 완료는12+10=22점·완료다. 이 전체 행동 집합에서는22점 정책이 최적이지만 빠른 완료라는 의도와 달리 완료를 마지막까지 미룬다. 또15점 미완료가10점 즉시 완료보다 높아 점수만으로 완료를 판정할 수 없다.

오해와 반례

가장 높은 seed 점수와 가장 높은 보상은 각각 알고리즘 실력과 과제 성공을 보장한다.

연습 1 · 값과 상태 예측

별도 정책 A 확률 3/5, B 확률 2/5와 보상 10/0에서 확률적 평가와 최대확률 행동 평가의 기대 보상을 구하라. 두 값을 같은 평가규약의 개선이라고 할 수 있는가?

힌트 1

확률적 평가에는 두 행동의 확률을 곱한다.

힌트 2

최대확률 행동은 A만 고른다.

풀이와 답 확인

  1. 확률적 기대 보상은 6이다.

  2. 최대확률 행동 평가의 값은 10이다.

값은 6과 10이다. 평가 행동 규칙이 바뀌었으므로 같은 규약 아래 학습 개선이라고 부르지 않는다.

흔한 오답에서 다시 생각하기

모델 파라미터가 같으니 두 값은 같은 정책 평가다.

파라미터뿐 아니라 실제 행동을 선택하는 규칙도 평가 대상의 일부다.

연습 2 · 오류 찾아 고치기

같은 선택 자료에서 checkpoint C1/C2/C3의 점수는 4/8/6이고 최고값으로 C2를 택했다. 이 8을 독립 최종 평가라고 보고했다. 별도로 보지 않았던 최종 자료에서 C2 점수가 4라면 무엇을 보고해야 하는가?

힌트 1

선택에 사용한 자료와 최종 자료의 역할을 나눈다.

힌트 2

C2를 최종 자료 점수를 본 뒤 다시 선택하지 않는다고 가정한다.

풀이와 답 확인

  1. 8은 선택 자료에서 C2를 고른 근거다.

  2. 선택된 C2의 별도 최종 자료 점수는 4다.

선택 점수 8과 독립 최종 점수 4를 역할별로 기록한다.

흔한 오답에서 다시 생각하기

최고 checkpoint 점수 8이 더 대표적이라 최종값으로 남긴다.

선택에 사용한 최고값은 독립 최종 평가로 이름을 바꿀 수 없다.

연습 3 · 직접 만들어 보기

run R1/R2의 평가 장부는 위 표 그대로다. 두 run에 같은 무게를 주되 각 run 안에서는 episode를 같은 무게로 평균하는 각 episode의 최종 무게를 구성하라.

힌트 1

R1의 두 episode 무게 합은 1/2이어야 한다.

힌트 2

R2의 여섯 episode 무게 합도 1/2이어야 한다.

풀이와 답 확인

  1. R1의 각 episode에 1/4를 준다.

  2. R2의 각 episode에 1/12를 주면 합은 1이고 가중 점수는 10/4+36/12=11/2다.

R1은 각 1/4, R2는 각 1/12이며 run 동일 무게 평균을 복원한다.

흔한 오답에서 다시 생각하기

모든 episode에 1/8을 주면 독립 run에도 같은 무게다.

그 경우 R1의 무게는 1/4이고 R2는 3/4다.

연습 4 · 선택 심화

선택 심화는 기본 연습 뒤 더 탐구하고 싶을 때 풀어 보세요.

보조 보상이 없는 네 행동 모형에서 완료 보상은 8이고 각 행동 비용은 1/2다. k번 기다린 뒤 완료하는 모든 k=0,1,2,3의 점수와 네 번 기다려 미완료로 종료한 점수를 비교하라.

힌트 1

완료 경로의 행동 수는 k+1이다.

힌트 2

미완료 네 번의 경로는 완료 보상 없이 비용만 낸다.

풀이와 답 확인

  1. 완료 경로는 8−(k+1)/2로 15/2,7,13/2,6이다.

  2. 미완료 경로의 점수는 −2다.

이 한정 행동 집합에서는 즉시 완료가 유일 최적이다. 다른 환경이나 새로운 행동의 목적 일치를 인증한 것은 아니다.

흔한 오답에서 다시 생각하기

한 경로만 확인하면 보상 수정이 일반적으로 안전하다.

여기서는 명시한 모든 경로를 비교했으며 다른 전이·보상·행동은 별도 검토가 필요하다.

run별 episode 수가 다르면 무게가 다르다. 같은 수이거나 특별히 평균이 같을 때 우연히 일치할 수 있다.

보조 보상을 일회로 바꾸면 의도를 보장하는가?

설명 기준 확인

반복 점수는 줄여도 완료 지연이 여전히 유리할 수 있다. 전체 경로와 실제 목표를 함께 비교한다.

한 단계 더

반복 버튼 보상을 첫1회에만3점으로 제한한다고 바꾸면 완료 없이 반복한 점수는3이다. 반복1회 뒤 완료하면13점이라 즉시 완료10보다 커진다. 끝내는 것을 우선하고 빠르게 끝내는 것도 원한다면 이 수정만으로 충분한지 다시 검토해야 한다. 종료·시간 비용·보조 보상의 전체 경로를 함께 비교하자.

다른 문제에 적용하기

세 보고서의 조건을 복원한다

세 사례는 서로 독립이다. ① 첫 모형의 p̂=4/5, 실제 p=2/5에서 세 단계 모델 정책의 계획값과 실제 기대값을 구하라. ② 이전 H 확률 4/5, 뒤집기 1/4, 밝음 가능도 4/5·1/5에서 사후 H와 새 Z 보상 1/−10 대 Y′=0 선택을 구하라. ③ run R1 점수 (0,10), R2 점수 (6,6,6,6,6,6)의 동일 run 요약과 episode 합계를 비교하고 일회 보조 보상 2/완료 8의 네 행동 모형에서 즉시 완료와 대기 후 완료를 비교하라.

힌트 1

① 모델 미래와 실제 미래의 재귀를 별도로 쓴다. ② 전이 예측 뒤 결합 무게를 합으로 나눈다.

힌트 2

③ 평균의 최종 무게를 명시하고 완료까지 행동 수와 일회 보상을 따로 기록한다.

풀이와 답 확인

  1. ① 모델 V₁=3, V₂=17/5, V₃=93/25다. 고정 정책의 실제 값은 한 단계 3, 두 단계 11/5, 세 단계 47/25다. 즉시 안전의 실제 값 3이 더 크다.

  2. ② H 예측 확률은 13/20이고 밝음 결합 무게는 H에서 52/100, L에서 7/100이다. 사후 H는 52/59다. Z 기대 보상은 −18/59여서 Y′의 0을 고른다.

  3. ③ R1의 평균은 5이고 R2의 평균은 6이다. 두 run에 같은 무게를 주면 11/2다. 모든 episode 합계 46을 8로 나누면 23/4다. 일회 보조 보상 모형에서 즉시 완료는 8점이고 한 번 또는 세 번 대기 후 완료는 10점이다. 따라서 일회 지급만으로 신속 완료를 유도하지 못한다.

계획 93/25와 실제 47/25를 구별한다. 사후 H=52/59라도 새 보상표에서는 Y′를 고른다. 동일 run 평균 11/2와 episode 평균 23/4는 다른 집계이며 일회 보조 보상은 완료 지연을 남긴다.

해결한 뒤 점검할 것

  • 정책을 고정한 평가와 실제 환경에서 새로 고른 최적 정책을 구별한다.

  • 전이·관측·보상표 및 미관측 자료의 지지 조건을 빠뜨리지 않는다.

  • 훈련 run과 평가 episode의 최종 무게 및 보상/완료/속도 목적을 따로 설명한다.
