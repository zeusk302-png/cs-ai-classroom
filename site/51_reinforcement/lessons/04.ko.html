소단원 4.1

return과 표본평균

한 번의 모험에서 받은 점수와 그 출발점의 기대 가치는 왜 다를까?

준비 개념과 학습 목표

준비 개념

  • 보상 R_(t+1)은 시각 t 의 행동 다음에 받은 값이고 상태 S_t 는 그 행동 직전의 상태다.
  • 기댓값은 가능한 결과에 확률을 곱해 더한 값이며 한 번의 관측값과 다르다.
  • 종료 시각 T 가 있는 에피소드와 끝나지 않는 과정은 같은 조건을 갖지 않는다.

학습 목표

  • 할인 return 을 시간 인덱스와 함께 계산한다.
  • 같은 고정 정책의 return 표본으로 상태 가치를 추정하고 표본평균의 한계를 말한다.

보상의 장부를 미래 방향으로 합치기

종료 에피소드에서 G_t=Σ_(k=t+1)^T γ^(k−t−1)R_k 로 정의한다. 할인 γ는 여기서 0≤γ≤1 이다. 바로 다음 보상은 γ^0=1, 그다음은 γ, 다음은 γ²를 곱한다. 종료 후 추가 보상이 없으면 G_T=0 이며 G_t=R_(t+1)+γG_(t+1)로 뒤에서 앞을 계산할 수 있다.

γ는 미래를 얼마나 할인하는가의 모형 선택이다. 작은 할인은 먼 보상의 영향을 줄이지 보상 자체를 삭제하거나 과거를 재평가하는 연산이 아니다. 계속되는 과정에서 γ=1 을 쓰면 합이 존재하지 않을 수 있다. 여기서는 유한 종료 에피소드의 관측 보상만 사용한다.

가치는 정책에 따른 기대값

정책 π를 고정하고 상태 s 에서 시작할 때 v_π(s)=E_π[G_t|S_t=s]가 목표다. 정책이나 보상·전이 규칙이 바뀌면 같은 상태 이름이어도 평가 대상이 달라질 수 있다. Monte Carlo 방식은 실제 종료까지 얻은 return 을 모아 평균한다. 환경의 전이 확률 표를 알아야만 평균을 낼 수 있는 것은 아니다.

n 개 표본 g_1,…,g_n 의 추정은 V_n=(g_1+…+g_n)/n 이다. 이 단원은 같은 고정 정책·환경에서 독립적인 에피소드를 반복하고, 상태가 충분히 방문되며 기대 return 이 존재하는 설정을 다룬다. 표본 하나가 반드시 진짜 가치와 같거나 n 이 늘 때 오차가 매번 감소한다는 보장은 없다.

평균을 저장하고 불확실성 구별하기

합과 개수로 평균을 계산할 수 있고 V_n=V_(n−1)+(g_n−V_(n−1))/n 으로 갱신해도 같다. 현재 추정과 새 표본의 차이를 1/n 만큼 반영한다. 개수와 상태별 평균을 따로 관리해야 하며 다른 상태의 방문 횟수를 분모에 섞지 않는다.

이 return 계산은 다른 상태의 현재 가치 추정으로 끝부분을 대신하는 bootstrap 을 사용하지 않는다. 중간에 로그가 끊긴 것을 진짜 종료로 처리하면 return 을 바꾸게 된다. 독립·동일 분포 표본과 유한 분산 σ²가 있으면 평균의 표준편차는 σ/√n 이지만, 상관된 표본이나 정책이 변한 자료에 이 식을 그대로 붙이지 않는다.

중간 과정을 따라가는 예제

T=3, 보상 R_1=2,R_2=−1,R_3=4, γ=1/2 인 한 에피소드의 모든 return 을 구하라. 같은 상태의 세 독립 에피소드 첫 방문 return 이 2.5,1.5,5 였다고 가정하고 표본평균을 갱신하라.

  1. 종료 G_3=0 이고 G_2=4+(1/2)·0=4 다.
  2. G_1=−1+(1/2)·4=1, G_0=2+(1/2)·1=2.5 다. 직접 합 2−0.5+1=2.5 와 같다.
  3. 첫 표본 후 V_1=2.5 다. 두 번째 후 V_2=2.5+(1.5−2.5)/2=2 다.
  4. 세 번째 후 V_3=2+(5−2)/3=3 이다. 직접 합 (2.5+1.5+5)/3=3 과 일치한다.
  5. 이 세 표본 평균은 추정값이다. 상태의 모든 가능한 결과와 확률을 주지 않았으므로 진짜 기대 가치가 3 이라고 단정하지 않는다.

G_0=2.5,G_1=1,G_2=4,G_3=0; 상태별 표본평균은 2.5→2→3 이다.

종이와 본문으로 직접 해보기

종이에 보상 (−2,3,6), γ=1/2 의 return 을 계산하라. 같은 상태의 관측 return 1,3 다음에 8 이 들어오면 세 표본 평균이 이전 평균에 가까워지는지 확인하라.

힌트 보기

뒤에서 G_2 부터 구한다. 평균 업데이트에서는 세 번째 분모를 3 으로 둔다.

풀이 보기

G_2=6,G_1=3+3=6,G_0=−2+3=1 이다. 첫 두 평균은 2, 새 평균은 2+(8−2)/3=4 다. 진짜 가치가 예를 들어 2 인 다른 모형이라면 이번 표본은 오차를 늘린다. 표본 수 증가가 각 경로의 단조 오차 감소를 보장하지 않는다.

오해와 반례

Monte Carlo 의 매 에피소드 return 은 기대 가치이며 평균을 내면 언제나 더 정확해진다.

return 은 무작위 결과 한 개다. 보상 0 또는 4 를 각각 반반 받는 모형의 기대는 2 이지만 첫 관측 0 이나 4 는 2 가 아니다. 다음 표본도 같은 끝값이면 평균의 오차가 그대로일 수 있다.

한 단계 더

평균 갱신식의 근거: nV_n=(n−1)V_(n−1)+g_n 이므로 양변을 n 으로 나누면 V_n=V_(n−1)+(g_n−V_(n−1))/n 이다. 일정 학습률 α로 V←V+α(g−V)를 쓰면 일반적으로 동일 가중 표본평균이 아니다. 예를 들어 V_0=0, α=1/2, 표본 2,4 이면 V_1=1,V_2=2.5 지만 두 표본 평균은 3 이다. 변하는 환경에서 최근 표본을 강조할 선택일 수 있지만 그 목표를 따로 밝혀야 한다.

소단원 4.2

first·every visit

같은 에피소드에서 한 상태를 두 번 만나면 둘 다 평균에 넣어야 할까?

준비 개념과 학습 목표

준비 개념

  • 방문은 에피소드에서 특정 상태가 나타난 한 시각이다. 상태 이름과 시각 번호를 따로 적는다.
  • return 은 그 방문 직후부터 종료까지의 보상을 포함한다.
  • 같은 에피소드의 두 return 은 뒤 보상을 공유하므로 일반적으로 독립 표본이 아니다.

학습 목표

  • 첫 방문과 모든 방문의 표본 선택·분모를 구별한다.
  • 뒤로 return 을 계산해도 첫 방문을 바르게 선택한다.

무엇을 한 표본으로 셀까

first-visit MC 는 각 에피소드에서 상태 s 가 처음 나온 시각의 return 만 선택한다. every-visit MC 는 같은 에피소드에서 s 가 나타난 모든 시각의 return 을 넣는다. 처음이라는 범위는 전체 기록의 최초 한 번이 아니라 각 에피소드별이다. s 가 없는 에피소드는 둘 다 그 상태에 표본을 추가하지 않는다.

두 방법의 평균은 유한 자료에서 다를 수 있다. 모든 방문에서는 같은 에피소드가 s 를 자주 거칠수록 더 많은 표본을 준다. 에피소드별 모든 방문 평균을 먼저 만들고 그 평균들을 다시 동일 가중 평균하는 방식은 일반 every-visit 평균과 다르다. 분모가 방문 수인지 에피소드 수인지 적는다.

return 계산 방향과 방문 선택 방향

G_t=R_(t+1)+γG_(t+1)라서 뒤에서 계산하면 효율적이다. 그러나 뒤에서 처음 마주친 s 는 시간 순서상 마지막 방문일 수 있다. first-visit 을 선택하려면 앞부분 S_0,…,S_(t−1)에 s 가 없는지 확인하거나 앞에서 첫 시각을 먼저 표시해야 한다.

동일한 정책·환경을 충분히 탐색하는 적절한 종료 MDP 설정에서는 두 방식으로 같은 상태 기대 가치에 접근할 수 있다. 모든 방문 표본들은 같은 에피소드 안에서 상관될 수 있으므로 표본 개수만 보고 독립 표본의 표준오차 식을 붙이지 않는다. 충분한 탐색·적분가능성 같은 조건 없이 모든 문제의 수렴을 주장하지 않는다.

표본 장부를 공개하기

에피소드 번호, 방문 시각, 상태, return, 선택 여부를 한 행씩 기록하면 오류가 드러난다. first-visit 표에는 에피소드마다 한 상태의 선택이 최대 하나다. every-visit 표에는 같은 에피소드 번호가 여러 번 나온다. 종료 상태는 미래 보상이 없다는 이 단원의 설정에서 값 0 으로 별도 취급한다.

자료를 모으던 중 정책이 바뀌면 하나의 고정 정책 가치를 추정한다는 설명을 다시 검토해야 한다. 다음 표는 두 가상 에피소드의 계산을 비교할 뿐 실제 MDP 의 확률 모형이나 수렴 실험을 제공하지 않는다. 상관 구조와 방문별 가중을 이해하는 종이 활동이다.

중간 과정을 따라가는 예제

γ=1. E1 의 상태는 s,a,s,종료이고 전이 보상은 1,2,3 이다. E2 는 s,종료에 보상 4 다. s 의 first-visit/every-visit 추정과 에피소드별 평균의 평균을 비교하라.

  1. E1 의 뒤 return 은 G_2=3,G_1=2+3=5,G_0=1+5=6 이다. s 의 방문 시각 0 과 2 에는 각각 6 과 3 을 적는다.
  2. E2 의 s return 은 4 다. first-visit 표본은 E1 의 6 과 E2 의 4 이므로 평균 10/2=5 다.
  3. every-visit 표본은 6,3,4 이므로 평균 13/3≈4.333 이다. 분모는 세 방문이다.
  4. E1 내부 s 방문 평균은 (6+3)/2=4.5, E2 는 4 다. 두 에피소드 평균의 평균은 (4.5+4)/2=4.25 다.
  5. 4.25 는 13/3 과 다르다. E1/E2 를 1:1 로 가중한 방식과 방문 개수 2:1 로 가중한 방식이 다르기 때문이다.

첫 방문 5, 모든 방문 13/3, 에피소드 평균의 평균 4.25. 각 방법의 선택과 분모가 다르다.

종이와 본문으로 직접 해보기

E3 를 s,s,종료와 보상 −2,5 로 추가하라. 기존 표에서 first-visit/every-visit 평균을 갱신하고, E3 를 뒤로 읽다가 처음 발견한 s 만 택하면 무엇이 잘못되는지 설명하라.

힌트 보기

E3 의 시각 1 return 은 5, 시각 0 은 −2+5 다. first 는 시간상 먼저다.

풀이 보기

E3 의 return 은 3 과 5 다. first 표본은 6,4,3 이어서 13/3, every 는 6,3,4,3,5 이어서 21/5=4.2 다. 뒤에서 첫 발견만 쓰면 E3 에서 5 를 골라 첫 방문 3 을 놓치며 last-visit 이 된다.

오해와 반례

every-visit 은 표본을 더 많이 쓰니 같은 에피소드의 모든 return 도 서로 독립이다.

E1 의 6 과 3 은 마지막 보상 3 을 공유한다. 뒤 보상이 무작위이면 두 return 이 같이 움직일 수 있다. 더 많은 방문 수는 더 많은 독립 에피소드 수와 같지 않다.

자기점검

상태 s 가 없는 에피소드는 s 의 분모를 늘리는가?

아니다.

소단원 4.3

on-policy·off-policy

다른 행동 규칙으로 모은 기록을 이용해 내가 원하는 정책을 평가할 수 있을까?

준비 개념과 학습 목표

준비 개념

  • 정책 π(a|s)는 상태에서 행동을 고를 확률이다. 같은 상태의 행동 확률 합은 1 이다.
  • 표본을 만든 행동 정책 b 와 평가하려는 목표 정책 π를 구별한다.
  • 확률비는 분모가 양수여야 계산된다. 관측하지 않은 가능성을 자료만으로 복원하지 못할 수 있다.

학습 목표

  • on/off-policy 와 coverage 를 정의한다.
  • ordinary/weighted importance sampling 을 같은 자료로 비교하고 편향·분산·분모 한계를 설명한다.

자료 정책과 목표 정책 나누기

on-policy 는 평가 대상 정책으로 자료를 만들고 off-policy 는 다른 행동 정책 b 의 자료로 목표 π를 평가한다. 행동 자료의 단순 평균은 기본적으로 b 의 return 기대를 겨냥한다. π와 b 가 다르면 그 평균이 π의 가치라고 보장할 수 없다. 두 정책 모두 여기서는 고정한다.

coverage 는 π(a|s)>0 인 행동에 b(a|s)>0 도 요구하는 조건이다. 목표가 가능한 행동을 자료 정책이 절대로 하지 않으면 그 행동의 결과를 해당 자료로 추정할 근거가 없다. 초기 상태·전이·보상 규칙은 같은 환경이라고 가정한다. 다른 환경을 단지 정책 확률비만 곱해 보정하는 주장은 아니다.

경로의 확률비로 보정하기

관측 시각 t 부터 종료 T 까지의 경로 가중치는 ρ=∏_(k=t)^(T−1)π(A_k|S_k)/b(A_k|S_k)다. 같은 환경의 경로 확률을 나누면 전이 부분이 약분되어 행동 확률비의 곱이 남는다. 독립 단계의 비를 평균하는 것이 아니라 연속한 경로 사건의 비를 곱한다. 목표가 하지 않는 관측 행동이 포함되면 ρ=0 이다.

n 개의 return 과 가중치에서 ordinary 추정은 Σ_i ρ_iG_i/n, weighted 추정은 Σ_i ρ_iG_i/Σ_i ρ_i 다. 같은 분자를 쓰지만 분모가 다르다. weighted 분모가 0 이면 이 원고에서는 유효한 추정 없음으로 표시한다. 출처의 구현상 0 초기화는 정보가 없다는 수학적 상황에서 가치가 진짜 0 이라는 결론이 아니다.

표본마다 맞는 값은 아니다

독립적인 첫 방문 에피소드, coverage, 유한 기대 return 등 적절한 조건에서 ordinary 추정은 기대상 올바른 값을 겨냥한다. 그러나 한 표본의 확률비가 크면 값이 크게 흔들리고 분산이 무한할 수도 있다. 불편향은 각 자료의 추정이 정답이라는 뜻이 아니다.

weighted 방식은 분모가 무작위여서 일반적으로 유한 표본에서 편향이 있다. 적절한 조건에서는 일관성을 갖고, 분모가 양수이면 비음수 정규화 가중 평균이므로 관측 return 의 최소·최대 사이에 있다. 이 성질만으로 데이터 부족·coverage 실패를 해결할 수는 없다. 아래 계산은 가상 자료이며 정책 실행·성능 실험은 하지 않았다.

중간 과정을 따라가는 예제

한 상태에서 행동 A 는 보상 4, B 는 0 후 즉시 종료한다. b(A)=1/4,b(B)=3/4, π(A)=π(B)=1/2 다. 자료 A,B 두 에피소드의 단순·ordinary·weighted 평균과 실제 목표 가치를 비교하라.

  1. 목표 기대는 v_π=(1/2)4+(1/2)0=2, 행동 정책 기대는 v_b=(1/4)4+(3/4)0=1 이다.
  2. A 의 가중치는 (1/2)/(1/4)=2, B 는 (1/2)/(3/4)=2/3 이다.
  3. 단순 자료 평균은 (4+0)/2=2 다. 우연히 목표 기대와 같지만 일반적인 정책 보정 근거는 아니다.
  4. 가중 합은 2·4+(2/3)·0=8 이다. ordinary 는 8/2=4 다.
  5. weighted 는 8/(2+2/3)=8/(8/3)=3 이다. 둘 다 이 작은 자료에서 목표 2 와 다르다.

단순 2, ordinary 4, weighted 3; 목표 기대 2. 한 자료가 정답과 같다는 사실과 추정 원리를 구별했다.

종이와 본문으로 직접 해보기

자료를 A,B,B,B 로 바꾸어 세 추정을 구하라. 이어 두 단계 관측 행동이 모두 A 이고 각 단계의 목표 확률 1/2·행동 확률 1/4 일 때 경로 가중치를 구하라.

힌트 보기

새 자료의 분자는 그대로 8 이고 가중치 합은 2+3·(2/3)이다. 두 단계는 비를 곱한다.

풀이 보기

단순 평균 4/4=1, ordinary 8/4=2, weighted 8/4=2 다. 두 단계 경로 비는 2·2=4 다. 두 추정이 이번 표에서 같아도 늘 같다는 뜻은 아니며 경로 비 4 는 보상값 또는 추정값 자체가 아니다.

오해와 반례

importance sampling 을 쓰면 전혀 하지 않은 목표 행동의 가치도 알아내고 모든 유한 표본에서 정확하다.

b(A)=0 인데 π(A)>0 이면 A 결과가 자료에 없고 비를 계산할 수 없다. coverage 가 있더라도 예제의 ordinary 4 와 weighted 3 은 목표 2 와 달라 유한 표본 정확성도 보장되지 않는다.

자기점검

π=b 이면 관측 경로의 ρ는?

답과 이유 보기

1 이다.

양의 관측 행동 확률마다 같은 수를 나누므로 곱도 1 이다.

weighted 분모가 0 이면 참 가치가 0 인가?

답과 이유 보기

알 수 없다.

목표에 기여하는 관측 경로 가중치가 없는 상태다.

ordinary 값이 관측 최대 return 보다 클 수 있는가?

답과 이유 보기

있다.

분모가 가중치 합이 아니라 표본 수여서 정규화 가중 평균이 아니다.

한 단계 더

목표를 A 만 고르는 결정 정책으로 바꾸고 A 한 표본만 관측하자. ρ=1/(1/4)=4, return=4 이므로 ordinary 는 16, weighted 는 4 다. 목표의 참 가치는 4 다. B 만 한 번 관측하면 가중치 0 이고 ordinary 의 그 표본 값은 0, weighted 는 추정 없음이다. 이러한 자료의 발생 확률까지 평균하면 ordinary 의 기대는 (1/4)16+(3/4)0=4 가 된다. 기대상 불편향과 단일 자료의 큰 오차를 동시에 확인하는 예다.
