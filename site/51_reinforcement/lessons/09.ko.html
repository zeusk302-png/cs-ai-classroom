소단원 9.1

DQN 학습흐름

게임 화면을 보고 움직이는 신경망은 무엇을 정답으로 삼아 배울까?

준비 개념과 학습 목표

준비 개념

  • 행동가치 Q와 할인율

  • 신경망 출력과 손실

  • 경험재생과 목표 네트워크

학습 목표

  • 하나의 경험에서 DQN 목표와 손실을 계산한다.

  • 환경 상호작용과 파라미터 업데이트를 구별한다.

상태 하나에서 행동별 숫자를 낸다

DQN은 상태를 받아 각 이산 행동의 Q 추정값을 출력한다. 값은 그 행동 뒤 얻을 할인된 보상의 예측이지 행동의 확률이 아니다. 행동 두 개의 출력이 4와 6이면 탐욕 선택은 두 번째다. 탐험 정책은 다른 행동도 선택할 수 있으므로 실제 행동과 최대값의 행동이 항상 같지는 않다.

상태 표현, 허용 행동, 보상, 종료 조건을 먼저 적자. 화면만으로 과거가 충분히 표현되지 않는 경우 입력 구성도 중요하다. 여기서는 두 행동의 작은 표를 사용하며 이미지 처리와 실제 게임 학습을 필수로 하지 않는다.

경험과 학습 목표를 연결한다

경험은 (s,a,r,s′,종료 여부)로 기록한다. 종료가 아니면 목표 y=r+γ max_b Q_target(s′,b), 진짜 종료면 y=r다. 다음 상태의 추정값으로 현재 예측을 가르치는 bootstrap이다. 환경이 정답 Q를 직접 알려 주는 지도학습과는 차이가 있다.

선택했던 a의 현재 온라인 출력 Q_online(s,a)와 y의 차이를 손실로 만든다. 목표 네트워크는 이 업데이트에서 고정하며 목표 쪽으로 역전파하지 않는 계약을 사용한다. 이 절의 제곱오차와 수치 활동은 계산 구조를 설명하는 선택이다. 실제 구현의 Huber 손실·평균 방식·optimizer를 확인해야 한다.

한 환경 걸음과 한 업데이트는 다른 기록이다

환경에서 행동하고 경험을 저장한 뒤 버퍼에서 학습 표본을 뽑는다. 하나의 경험이 여러 업데이트에 쓰일 수 있다. 환경 걸음 수, optimizer 업데이트 수, 목표 복사 주기를 서로 다른 열에 적으면 순서를 확인하기 쉽다.

종료 표시는 문제의 정의에 따라야 한다. 시간 제한으로 기록을 잘랐다는 이유만으로 과제 자체가 끝난 상태라고 판단하지 않는다. 참 종료와 수집 중단을 구분하고 후속 상태 및 bootstrap 정책을 명시한다. 경험재생과 고정 목표를 넣었다는 사실만으로 모든 환경에서 수렴이 보장되지는 않는다.

중간 과정을 따라가는 예제

자체 경험에서 r=2, γ=1/2, 다음 상태의 목표 출력은 [4,6], 선택 행동의 현재 온라인 출력은 1이다. 참 종료가 아닌 경우 y와 제곱오차를 구하라.

  1. 다음 상태 최대 출력은 6이므로 y=2+(1/2)·6=5다.

  2. TD 오차를 y−Q로 정의하면 5−1=4다. 제곱오차는 4²=16이다.

  3. 현재 상태의 다른 행동 출력과 다음 상태의 두 출력을 혼동하지 않는다. 5는 이 경험의 학습 목표이며 참 최적값이라는 증거는 아니다.

목표 5, TD 오차 4, 제곱오차 16이다.

종이와 본문으로 직접 해보기

동일 숫자의 경험이 참 종료라면 목표와 제곱오차는 무엇인가? 비종료·종료 경험 하나씩의 제곱오차를 단순 평균하라. 별도로 표의 값 하나만 q←q+0.1(y−q)로 바꿀 때 비종료 경험의 q를 구하라.

힌트 보기

종료에서는 다음 상태 값을 더하지 않는다. 표의 q 직접 갱신은 일반 신경망의 모든 가중치 갱신과 같지 않다.

풀이 보기

종료 목표는 2, 오차는 1, 제곱오차는 1이다. 두 손실 평균은 (16+1)/2=8.5다. 표의 직접 갱신은 1+0.1·4=1.4다. 실제 신경망에서는 출력의 가중치 미분과 optimizer를 함께 사용한다.

오해와 반례

Q 출력의 합이 1이 아니면 학습이 잘못됐다.

Q는 행동 확률이 아니라 할인 보상 추정값이다. 출력 4와 6의 합 10은 확률 정규화 실패가 아니다. 정책의 탐험 확률과 행동가치를 구분한다.

소단원 9.2

과대추정과 Double DQN

가장 큰 추정값을 고르는 과정 자체가 값의 평균을 높일 수 있을까?

준비 개념과 학습 목표

준비 개념

  • 최대값과 argmax

  • 추정 오차

  • DQN 목표식

학습 목표

  • 선택과 평가를 다른 네트워크에 맡긴 목표를 계산한다.

  • 작은 확률 표에서 max 편향과 적용 조건을 설명한다.

큰 오차도 선택될 수 있다

진짜 행동값을 모르므로 큰 추정값이 큰 참값인지 양의 오차인지 구별하기 어렵다. 여러 행동 중 최대값을 택하면 우연히 높게 틀린 행동이 선택될 수 있다. 각 행동 추정이 평균적으로 맞더라도 최대 추정의 평균까지 맞아야 하는 것은 아니다.

이 현상은 환경의 보상이 랜덤일 때만 생기는 문제가 아니다. 함수 근사의 오차도 원인이 될 수 있다. 다음 자체 표에서는 행동별 참값을 일부러 같게 정하여 선택 오차를 분리한다. 모든 경험의 추정이 반드시 참값보다 크다는 주장을 하지는 않는다.

선택하는 표와 평가하는 표를 나눈다

Double DQN은 온라인 네트워크로 b*=argmax_b Q_online(s′,b)를 고른 뒤 목표 네트워크의 그 행동값으로 y=r+γ Q_target(s′,b*)를 만든다. DQN은 목표 네트워크에서 최대값을 고르고 그 값을 사용한다.

두 방식 모두 온라인·목표 네트워크를 사용한다. Double이라는 이름을 이유로 기존 두 개에 네트워크 두 개를 더한다고 해석하지 않는다. 주기적인 목표 복사도 유지한다. 두 네트워크는 복사로 연결되므로 독립 오차라는 이상화가 실제 학습에서 자동으로 성립하지는 않는다.

작은 편향 표의 조건을 읽는다

참값이 두 행동 모두 5이고 각 추정이 독립적으로 4 또는 6을 같은 확률로 낸다고 가정하자. 네 가지 표 [6,6], [6,4], [4,6], [4,4]가 동확률이면 최대값은 6,6,6,4다. 평균은 5.5지만 각 행동 추정 평균은 5다.

별도의 평가 추정이 선택 오차와 독립이고 각 행동에서 평균 5라면 선택된 행동을 평가한 값의 기대값도 5다. 이것은 조건부 기대의 작은 모형 설명이다. 실제 Double DQN의 상관된 추정, 서로 다른 참값, 유한 학습에서 항상 편향 0이나 더 높은 보상을 보장하는 정리는 아니다.

중간 과정을 따라가는 예제

자체 다음 상태에서 온라인 출력 [7,6], 목표 출력 [4,8], r=2, γ=1/2, 현재 선택 행동 값 1이다. DQN과 Double DQN 목표 및 제곱오차를 비교하라.

  1. DQN은 목표 출력 최대 8을 쓰므로 목표 2+4=6, 오차 5, 손실 25다.

  2. Double DQN은 온라인에서 첫 행동을 고르고 목표 네트워크의 첫 값 4를 평가하므로 목표 2+2=4, 오차 3, 손실 9다.

  3. 두 목표가 다르다는 계산이다. 다음 상태의 참값을 주지 않았으므로 더 작은 손실만으로 더 정확한 참값 추정이라고 결론내리지 않는다.

DQN 목표 6·손실 25, Double DQN 목표 4·손실 9다.

종이와 본문으로 직접 해보기

온라인만 [3,9]로 바꾸고 다른 숫자를 유지하라. 두 목표를 다시 구하라. 이어 네 동확률 표의 최대값 평균과 각 행동 평균을 구하라.

힌트 보기

온라인의 최대 위치가 두 번째로 바뀐다. 네 표의 각 열을 따로 평균한다.

풀이 보기

Double DQN도 두 번째 목표값 8을 평가하므로 두 목표는 6으로 같아진다. 네 최대값 평균은 (6+6+6+4)/4=5.5, 각 행동 평균은 (6+6+4+4)/4=5다. 온라인 [7,7] 동률에서는 미리 정한 tie-break 규칙이 필요하다.

오해와 반례

Double DQN에는 이미 목표 네트워크가 있으니 DQN에는 목표 네트워크가 없다.

둘 다 목표 네트워크를 사용한다. 차이는 다음 행동을 선택하는 argmax가 온라인에 있는지 목표에 있는지다. 목표 네트워크 존재 여부만으로 두 알고리즘을 구분하지 않는다.

작은 편향 표에서 각 행동이 평균 5면 최대값도 평균 5인가?

아니다. 이 표에서는 5.5다.

현재 손실 9가 25보다 작으면 최종 정책 보상도 반드시 큰가?

답과 이유 보기

그런 보장은 없다.

학습 목표의 변화와 실제 정책 평가는 별개다.

한 단계 더

앞 편향 표에서 평가 네트워크가 두 행동 모두 항상 4를 낸다면 어떤 행동을 선택해도 평가값은 4다. 참값 5보다 낮아진다. 독립적이고 평균이 맞는 평가라는 전제가 빠졌으므로 앞 기대값 5의 설명을 적용할 수 없다. 이 반례는 선택·평가 분리가 모든 오차를 없애는 마법이 아님을 보여 준다.

안정화 실험

한 번 얻은 높은 점수만으로 안정적인 학습이라고 말할 수 있을까?

준비 개념과 학습 목표

준비 개념

  • 평균·분산·중앙값

  • 통제 비교

  • 환경 걸음과 학습 업데이트

학습 목표

  • 재생·목표 복사 일정의 자체 장부를 추적한다.

  • 여러 실행과 평가 조건을 분리하는 실험 계획을 만든다.

상태 장부로 구현 순서를 점검한다

용량 3의 선입선출 재생 버퍼에 경험 T1,T2,T3,T4를 차례로 넣으면 마지막에는 T2,T3,T4가 남는다. 뽑기는 저장 순서와 별개다. 임의 재생은 연속 표본의 의존을 줄이는 목적이 있지만 버퍼 밖의 상태를 만들어 주지는 않는다.

자체 목표 복사 장부에서는 업데이트가 끝난 뒤 매 두 번마다 온라인을 목표로 복사한다고 정하자. 시작 두 값 1, 첫 업데이트 후 온라인 2·목표 1, 둘째 업데이트 후 온라인 3을 복사하여 목표 3이다. 어떤 순간의 출력을 목표로 썼는지 함께 기록해야 재현할 수 있다.

한 요소를 바꾸고 나머지 계약을 고정한다

재생 제거, 목표 복사 주기 변경, DQN 목표를 Double DQN 목표로 변경하는 비교를 각각 계획한다. 환경 정의·관측·할인율·상호작용 예산·평가 횟수·seed 목록을 먼저 고정하자. 여러 요소를 한 번에 바꾸면 점수 차이가 어느 변화에서 왔는지 분리하기 어렵다.

학습 중 탐험 보상, 평가 정책의 보상, Q 추정값, 손실을 서로 다른 지표로 기록한다. 보상이 커졌는데 Q가 과도하게 커지는 경우도 생각할 수 있다. 평가에 사용한 데이터를 보고 계속 설정을 고르면 별도 최종 평가의 의미도 약해진다.

흩어짐과 실패를 함께 보고한다

아래 세 숫자는 학습을 실행한 결과가 아니라 비교 방법을 연습하는 가상 점수다. 평균·중앙값·최솟값·모든 값을 보이면 한 성공만 골라 보여 주는 문제를 줄인다. 동일 평균이어도 흩어짐이 다를 수 있다.

세 실행만으로 전체 환경에서 우월함을 증명할 수 없다. seed가 같아도 정책에 따라 수집 경험이 달라질 수 있으며 통계 단위도 정해야 한다. 실제 수행 전에는 계획, 수행 후에는 관측과 실패·중단 원인을 구분한다. 여기서는 학생·게임·장비 실험을 미수행으로 남긴다.

중간 과정을 따라가는 예제

자체 가상 평가 A=[10,12,8], B=[16,2,12]의 평균과 분산을 비교하라. 분산은 표본 추정이 아니라 세 값의 모집단형 요약으로 3으로 나눈다.

  1. A의 합은 30, B의 합도 30이므로 평균은 둘 다 10이다.

  2. A의 제곱편차 합은 0²+2²+(−2)²=8로 분산 8/3이다.

  3. B는 6²+(−8)²+2²=104로 분산 104/3이다. 동일 평균이 모든 실행의 유사함을 뜻하지 않는다.

평균은 둘 다 10, 가상 세 값의 요약 분산은 A 8/3, B 104/3이다.

종이와 본문으로 직접 해보기

힌트 보기

정렬한 가운데 값과 가장 작은 값을 읽는다. 목표 복사는 짝수 업데이트가 끝난 뒤만 한다.

풀이 보기

A 중앙값 10·최소 8, B 중앙값 12·최소 2다. T5 추가 후 버퍼는 T3,T4,T5다. 셋째 후 목표는 3으로 유지된다. 온라인 4를 바로 목표 4로 바꾸면 정한 복사 계약과 다르다.

오해와 반례

평균이 같으니 안정성도 같고 더 볼 필요가 없다.

가상 B에는 2와 16처럼 더 넓게 흩어진 값이 있다. 평균·분산·중앙값은 다른 요약이며 실제 안정성 결론에는 여러 실행과 학습 곡선·실패 기록·환경 범위가 필요하다.
