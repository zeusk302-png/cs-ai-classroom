소단원 12.1

해상도·지연·메모리

사진의 가로와 세로를 절반으로 만들면 모델 속도와 정확도도 정확히 같은 비율로 바뀔까?

준비 개념과 학습 목표

준비 개념

  • 픽셀과 채널

  • 바이트와 시간 단위

  • 크기 변경과 비율

학습 목표

  • 입력 크기와 저장량을 계산한다.

  • 전처리 좌표와 작은 물체의 변화를 추적한다.

  • 시간 측정 범위와 실제 최대 메모리를 구별한다.

해상도는 정보와 계산 조건을 바꾼다

가로 W·세로 H 영상에는 W×H개의 픽셀이 있다. 채널 C와 값당 바이트 b를 정하면 연속 데이터 자리만 WHCb다. 두 축을 절반으로 만들면 픽셀 수는 1/4이다. 이는 데이터 자리 산술이며 모든 모델의 실행 시간이 1/4이 된다는 정리는 아니다.

축소는 세부와 작은 물체의 표현을 바꾼다. 크기와 보간 방법, 종횡비 유지·잘라내기·여백 정책을 기록한다. OpenCV의 축소 보간 안내는 시각 품질에 관한 것으로 검출 정확도나 원래 정보를 완전히 보존한다는 보증이 아니다.

같은 좌표 규칙으로 정답과 예측을 비교한다

x좌표와 폭에는 가로 비율, y좌표와 높이에는 세로 비율을 적용한다. 여백을 넣거나 잘라내면 추가 이동과 영역 변화가 생긴다. 영상만 바꾸고 정답 상자의 좌표를 그대로 두면 평가 자체가 틀릴 수 있다.

작은 물체는 축소 뒤 몇 픽셀 안에 들어갈 수 있고 손실된 세부를 확대만 해서 되찾지 못한다. 입력 크기별 성능은 같은 분할과 평가 규약에서 실제 측정해야 한다. 아래는 좌표 변환의 수학적 사각형이며 특정 라이브러리의 픽셀 중심 규약까지 구현한 예는 아니다.

전체 요청과 모델 구간을 나눈다

전처리·전송·순전파·후처리·대기 중 어느 범위를 측정했는지 적는다. 비동기 장치에서는 작업 완료를 확인하며 준비 실행인 warmup과 본 반복을 나눈다. 배치 처리량이 높아도 개별 요청 지연이나 긴 꼬리 지연은 별도로 남을 수 있다.

입력 배열 저장량에는 모델 파라미터·중간 활성값·작업 버퍼·할당 오버헤드가 빠져 있다. 같은 입력이라도 타입과 배치, 모델 구조에 따라 최대 메모리가 다르다. 다음 시간과 데이터 크기는 가상 값으로 실제 GPU·카메라 계측을 하지 않았다.

중간 과정을 따라가는 예제

RGB uint8 영상 640×480을 320×240으로 비율 축소한다. 입력 데이터 자리와 x=100,y=80,w=40,h=20인 수학적 상자를 계산하라. 가상 요청 구간이 전처리2ms·모델8ms·후처리3ms일 때 모델만 4ms가 되면 전체는?

  1. 원래 데이터 자리는 640×480×3×1=921600바이트다. 축소 뒤는 320×240×3=230400바이트로 1/4이다.

  2. 가로·세로 비율 모두 1/2이므로 상자는 (50,40,20,10)이다. 따로 여백이나 잘라내기가 없다는 조건이다.

  3. 가상 전체는 2+8+3=13ms에서 2+4+3=9ms다. 모델 구간이 두 배 빨라도 전체 속도 배수는 13/9이며 대기·전송 비용은 이 가정에서 제외됐다.

입력 데이터 자리는 921600→230400바이트, 상자는 (50,40,20,10), 가상 전체는 13→9ms다. 실제 최대 메모리나 실행 가속으로 보고하지 않는다.

종이와 본문으로 직접 해보기

축소 뒤 320×240×3을 값당4바이트 float로 보관하고 배치2를 만들면 입력 배열만 얼마인가? 원래 폭4·높이4의 작은 물체는 같은 축소에서 얼마인가?

힌트 보기

픽셀×채널×값당 바이트×배치를 계산한다. 두 공간 축은 각각 절반이다.

풀이 보기

320×240×3×4×2=1843200바이트다. 작은 물체의 수학적 크기는 2×2다. 이 숫자는 실제 픽셀 반올림·보간·검출 성공이나 모델 최대 메모리를 보증하지 않는다.

오해와 반례

입력 픽셀이 1/4이면 모든 지연과 메모리도 1/4이다.

고정 구간과 모델 내부 구조·버퍼가 남고 입력 데이터 자리는 전체 메모리의 일부다. 같은 조건에서 실제 범위를 나누어 측정한다.

자기점검

영상을 가로만 절반으로 바꾸면 상자의 y도 절반인가?

답과 이유 보기

아니다.

세로 비율이 1이면 y와 높이는 그 축에서 그대로다.

모델 구간이 8→4 ms로 줄면 가상 전체 시간도 13→6.5 ms로 줄어드는가?

답과 이유 보기

아니다. 전체 시간은 9 ms다.

다른 구간의 2+3 ms가 남으므로 전체는 2+4+3=9 ms다.

입력1843200바이트가 최대 GPU 메모리인가?

답과 이유 보기

아니다.

모델·활성값·버퍼 등 다른 상태가 빠져 있다.

한 단계 더

가상 반복 지연9,10,10,11,60ms를 모두 기록하면 평균20ms, 중앙값10ms, 관측 최대60ms다. 60ms를 이유 없이 삭제하지 않는다. 표본5개의 최대는 미래의 모든 지연 상한이 아니며 원시 기록·동시 요청·측정 환경을 추가한다.

출처와 확인 범위
  • OpenCV 4.13 — Geometric Image Transformations

    실제 14–24행 보간/좌표 문제, 105–111행 보간 종류, 414–459행 resize 크기·축 비율·축소/확대 설명을 읽었다. 시각 품질 설명을 검출 정확도 보증으로 확대하지 않는다.

  • PyTorch 2.14 — Benchmark Utils

    실제 3734–3795행 warmup·반복·동기화·환경/입력/스레드 조건과 3833–3852행 타이머 오버헤드를 읽었다. 자체 가상 시간표와 저장량 산술이며 실제 비전 모델 계측은 미수행이다.

소단원 12.2

절제실험

성능이 좋아졌을 때 해상도와 증강 중 어느 변경이 도움이 됐는지 어떻게 구별할까?

준비 개념과 학습 목표

준비 개념

  • 기준선과 분할

  • 정확도 분모

  • 변수와 조건

학습 목표

  • 하나씩 바꾸는 비교와 결합 효과를 구별한다.

  • 자료·지표·계산 예산을 맞춘다.

  • 반복 변동과 최종 평가 자료의 독립성을 유지한다.

같은 기준선에서 구성 요소를 바꾼다

절제실험은 구성 요소를 제거하거나 조건을 바꾸어 결과 차이를 살피는 비교다. 기준 모델과 변경 모델의 자료 분할·평가 규약·학습 예산 등을 기록한다. 해상도와 증강을 동시에 바꾼 두 결과만으로 각 요소의 기여를 분리할 수는 없다.

요소를 빼면 모델을 다시 학습해야 하는지, 추론 때만 바꾸는지 정한다. 학습한 고해상도 모델에 작은 이미지만 넣는 시험과 작은 입력으로 다시 학습한 모델은 다른 질문이다. 비교 표에 학습·추론 조건을 함께 남긴다.

결합 효과는 단순 합과 다를 수 있다

두 요소 A와 B에 대해 기준·A만·B만·A와B를 함께 쓰는 네 조건을 비교하면 단일 변화와 결합 변화를 구별할 수 있다. 차이의 차이를 계산하되 이는 정한 지표와 조건에서의 기술적 비교다. 모든 자료와 모델에서 영구적인 인과 효과로 확정하지 않는다.

분할과 임계값을 고정하고 반복 난수·훈련량·모델 선택 규칙을 보존한다. 한 요소가 계산량도 늘렸다면 효과와 예산 변화가 섞인다. 같은 예산 비교와 실제 사용 예산 비교를 필요한 질문에 맞게 나누어 보고한다.

반복과 최종 평가를 분리한다

훈련 반복에서 결과가 달라질 수 있으므로 여러 실행의 값과 요약을 남긴다. 가까운 점수 차이 하나를 확실한 우월성이라고 해석하지 않는다. 가상 반복표로 표본의 평균을 계산해도 통계적 유의성이나 미래 개선을 증명한 것은 아니다.

조정과 구성 선택은 개발용 검증 자료에서 하고, 최종 평가 자료의 반복 관찰로 실험을 계속 선택하지 않는다. 최종 평가 후 발견한 실패를 개선에 사용한다면 이후 평가는 새 독립 자료 등 계획이 필요하다. 아래는 실제 모델 실행 없이 만든 비교표다.

중간 과정을 따라가는 예제

같은 가상 검증 자료20장에서 맞힌 수가 기준14, 고해상도 A만16, 증강 B만15, A+B18이다. 정확도, 단일 개선과 결합의 차이의 차이를 구하라.

  1. 정확도는 기준70%, A80%, B75%, A+B90%다. A만의 개선은10%p, B만은5%p다.

  2. 두 단일 개선을 더한 예상은70+10+5=85%지만 실제 가상 결합표는90%다. 차이는5%p다.

  3. 차이의 차이도90−80−75+70=5%p다. 이는 이 표의 지표·분할·예산 조건에서의 결합 비교이며 반복이나 유의성 검사를 대신하지 않는다.

단일 변화10%p와5%p, 결합 개선20%p, 차이의 차이5%p다. 각 요소의 효과가 항상 더해진다고 가정하지 않는다.

종이와 본문으로 직접 해보기

같은 훈련 조건의 가상 세 반복 정확도가 기준70,72,71%, 변경71,70,72%다. 평균과 반복별 차이를 구하고 항상 개선이라고 말할 수 있는지 판단하라.

힌트 보기

각 합을3으로 나누고 같은 반복 번호끼리 뺀다.

풀이 보기

두 평균은 모두71%다. 변경−기준 차이는1,−2,1%p라 매번 개선이 아니다. 반복 번호 대응의 난수/자료 조건도 설명해야 하며 이 작은 표로 동일 성능을 증명한 것은 아니다.

오해와 반례

결합 결과18/20이므로 A와 B가 각각2장씩 기여했다.

기준14에서 결합18까지4장 증가한 사실만으로 개별 기여를 나눌 수 없다. A만·B만 및 실패 표본의 겹침을 함께 보며 조건별 결합을 구별한다.

자기점검

A의 정확도 80%와 기준선 70%의 차이는 10%인가, 10 퍼센트포인트(%p)인가?

답과 이유 보기

10 퍼센트포인트(%p)다.

두 비율을 직접 뺀 차이다. 상대 개선 비율은 기준선 70%를 분모로 삼아 10/70≈14.29%로 계산한다.

A+B만 비교해 B의 단독 효과를 분리했는가?

답과 이유 보기

아니다.

B만 조건 등 추가 비교가 필요하다.

최종 평가에서 가장 좋은 조합을 계속 고르면 평가의 독립성이 유지되는가?

답과 이유 보기

유지되지 않는다.

최종 평가 결과가 선택 과정에 들어간다.

한 단계 더

A+B에서 A를 뺀 결과 B만75%라 차이는15%p이고, 기준에 A를 더한 차이10%p와 다르다. 상대 요소의 존재에 따른 조건부 비교다. 제거 비교를 A의 유일한 고정 기여로 표현하지 말고 두 조건을 나란히 기록한다.

조건별 오검출과 한계보고

밝은 사진에서 잘 맞힌 모델이 어두운 새 카메라에서도 충분하다고 말할 수 있을까?

준비 개념과 학습 목표

준비 개념

  • 참양성·거짓양성·거짓음성

  • 정밀도와 재현율

  • 표본과 조건

학습 목표

  • 검출의 정답 매칭 규칙을 먼저 정한다.

  • 조건별 분모와 오류 양상을 비교한다.

  • 관찰·원인 가설·미검사 한계를 분리한다.

무엇을 검출했다고 세는지 정한다

객체 검출은 상자의 위치와 클래스, 점수 임계값 및 정답과의 일대일 매칭 규칙이 필요하다. IoU 기준은 상자 교집합 면적을 합집합 면적으로 나눈 값에 대한 기준이다. 한 정답에 겹친 여러 예측을 모두 참양성으로 세지 않는다.

고정한 규칙에서 TP는 매칭된 올바른 예측, FP는 매칭되지 않거나 틀린 예측, FN은 찾지 못한 정답이다. 정밀도는 TP/(TP+FP), 재현율은 TP/(TP+FN)다. 객체가 없는 배경의 가능한 위치가 많으므로 보통 영상 전체의 거짓양성 수를 임의 TN 개수와 혼동하지 않는다. 여기서는 군중 객체(crowd)나 평가 제외(ignore)가 없는 일반 객체의 고정 임계값 예제를 쓴다. 공개 평가기는 이러한 예외와 여러 IoU·점수 규약을 별도로 처리하므로 이 단순 계산을 COCO AP 전체라고 부르지 않는다.

조건과 분모를 함께 나눈다

빛·가림·물체 크기·카메라·지역·시간 등 사용 조건별로 지표와 표본 수를 적는다. 작은 집단의 낮은 성능이 큰 집단의 평균에 가려질 수 있다. 조건별 지표의 단순 평균과 전체 카운트를 합쳐 계산한 지표는 다르다.

새 조건은 훈련 조건과 다른 분포일 수 있다. 공개 자료의 특정 이동에 견고한 모델이 다른 이동에도 견고하다고 보증하지 않는다. 조건이 중복되면 같은 표본이 여러 표에 들어갈 수 있으므로 집단 합을 전체라고 부를 때는 서로 겹치지 않는 분할인지 확인한다.

관찰과 설명, 미검사를 나누어 적는다

실패 보고에는 원본과 정답·예측, 모델/입력/매칭/임계값 버전, 조건과 가능한 라벨 문제를 남긴다. 어두운 사진에서 오류가 많았다는 관찰과 노출 부족이 원인이라는 가설은 구별한다. 원인을 확인하려면 별도의 통제 비교가 필요하다.

미검사 카메라·장면·물체와 표본이 적은 조건, 응답 지연·자원 미측정 등을 명시한다. 정답이 맞는지 사람이 검토하지 않았다면 검토했다고 적지 않는다. 아래 오류 수는 지정한 가상 매칭 결과이며 실제 영상이나 주석을 평가하지 않았다.

중간 과정을 따라가는 예제

서로 겹치지 않는 밝은 조건의 정답 객체100개에서 TP90·FN10·FP10, 어두운 조건의 정답20개에서 TP8·FN12·FP12다. 각 정밀도·재현율과 전체 카운트를 합친 두 지표를 계산하라.

  1. 밝은 조건 정밀도90/(90+10)=90%, 재현율90/100=90%다. 어두운 조건 정밀도8/(8+12)=40%, 재현율8/20=40%다.

  2. 합은 TP98,FN22,FP22다. 전체 정밀도와 재현율은 모두98/120=49/60으로 약81.67%다.

  3. 두 조건 지표의 단순 평균은(90%+40%)/2=65%다. 전체 약81.67%만 쓰면 어두운 조건40%의 실패를 충분히 보여 주지 못한다.

밝음90%·어두움40%, 전체 약81.67%, 조건 단순 평균65%다. 동일 값인 정밀도와 재현율도 서로 다른 분모 정의를 먼저 적는다.

종이와 본문으로 직접 해보기

정답 객체2개에 대해 정답1을 맞히는 동일 클래스 예측3개가 모두 매칭 기준을 만족하고 정답2 예측은 없다. 일대일 매칭이면 TP·FP·FN과 정밀도·재현율은?

힌트 보기

하나의 정답에는 예측 하나만 매칭한다. 나머지 중복 예측과 놓친 정답을 나눈다.

풀이 보기

TP1, 중복 FP2, FN1이다. 정밀도1/3, 재현율1/2다. 예측3개를 TP3으로 세면 정답 수와 일대일 규칙을 위반한다.

오해와 반례

전체 지표81.67%면 모든 빛과 모든 카메라에서 같은 성능이다.

이 표에서도 어두운 조건은40%이며 새 카메라는 아예 시험하지 않았다. 조건·분모·검사하지 않은 범위를 보고한다.

한 단계 더

임계값을 바꾸면 FP와 FN이 함께 바뀔 수 있다. 가상 새 어두운 결과TP12,FN8,FP28이면 재현율60%지만 정밀도12/40=30%다. 이를 모든 지표 개선이라고 부르지 않는다. 임계값은 개발용 검증 자료에서 선택하고 이후 독립 조건을 평가한다.
