소단원 9.1

pixel-wise 예측

사진 속 두 고양이를 같은 색으로 칠하면 두 마리를 구별한 걸까?

준비 개념과 학습 목표

준비 개념

  • 이미지 높이·폭·채널

  • 분류와 확률

  • argmax

학습 목표

  • 픽셀마다 클래스 점수를 읽는다.

  • 의미 분할과 인스턴스 분할을 구별한다.

  • 배경 비율과 픽셀 정확도의 한계를 계산한다.

무시할 픽셀을 배경으로 바꾸면 같은 평가가 될까?

여섯 위치의 정답은 [1,1,0,0,255,255], 예측은 [1,0,1,0,1,1]이다. 자체 규약에서 255는 클래스가 아니라 평가 제외 표지다. 위치 5와 6을 정답과 예측 비교 모두에서 제외한다. 남은 네 위치에서 물체 TP는 1개, FN은 1개, FP는 1개이고 TN은 1개다. 정확도는 1/2, 물체 IoU는 1/3, Dice는 1/2다. 가상 지도 손계산이며 영상·모델 출력 관측이 아니다.

255를 배경 0으로 바꾸어 여섯 위치 모두 평가하는 것은 다른 규약이다. 기존 두 제외 위치의 예측 1이 FP 두 개를 추가한다. TP는 1개, FN은 1개, FP는 3개, TN은 1개가 되어 정확도는 1/3, 물체 IoU는 1/5, Dice는 1/3이다. 제외 표지를 배경 클래스로 치환하는 작업은 중립적인 전처리가 아니다.

두 클래스 logits가 같은 위치의 argmax는 동점 규약이 필요하다. 자체 규약은 작은 클래스 ID인 0을 고른다. 두 logits가 같으면 softmax 값은 각각 1/2지만 이는 실제 신뢰도 보정 검증이 아니다. 제외 위치의 예측을 바꾸어도 지정 평가 결과는 같지만 그 영역을 포함하는 배포 요구까지 검증했다는 뜻은 아니다.

클래스 지도 [1,1,1,1]은 신원 지도 [A,A,B,B]와 [A,A,A,A]를 모두 같은 클래스로 투영할 수 있다. 연결 성분이나 높은 픽셀 정확도만으로 신원이 자동 복원되지 않는다. 입력과 정답의 공간 변환·평가 제외 범위·클래스와 인스턴스의 목적을 함께 기록한다.

먼저 확인할 개념
  • 픽셀 지도와 신원

    앞 본문의 클래스/인스턴스 구별과 무시 레이블 정책을 자체 여섯 위치에 적용한다.

  • 집합 점수의 분모

    앞 본문의 TP·FP·FN 식으로 제외 뒤 분모를 계산한다.

출력이 사진 한 장의 이름에서 지도로 바뀐다

의미 분할은 H×W 위치마다 클래스 레이블을 예측한다. C개 클래스의 점수 텐서는 배치 하나를 제외하면 H×W×C 또는 C×H×W로 저장할 수 있다. 저장 순서와 실제 위치의 의미를 먼저 확인한다.

서로 배타적인 C개 클래스 모형은 각 위치의 logits에 softmax를 적용하고 argmax로 하나를 고른다. 확률처럼 보이는 수치가 실제 신뢰도를 정확히 보정했다는 뜻은 아니다. 학습한 모델과 평가 조건을 별도로 확인한다.

의미와 객체의 신원을 구분하기

의미 분할에서 두 고양이의 픽셀은 모두 고양이라는 클래스다. 인스턴스 분할은 고양이1과 고양이2처럼 객체 신원을 추가로 나눈다. 객체 상자만 맞추는 검출과 픽셀 영역의 예측도 서로 다른 문제다.

두 객체가 붙어 있으면 동일 클래스 지도에서 연결된 영역 하나로 보일 수 있다. 연결 성분을 나눴다고 모든 실제 객체 신원이 자동 복원되지는 않는다. 겹침·가림과 레이블 정책을 확인해야 한다.

레이블과 평가 조건을 함께 정하기

작은 두 클래스 문제는 물체 1과 배경 0으로 표현한다. 레이블은 색 자체가 아니라 약속한 클래스 번호다. 감독 학습에는 입력과 같은 위치의 정답 지도가 필요하며 자르기·회전 같은 공간 변환은 두 지도에 맞춰 적용한다.

배경이 대부분이면 모두 배경으로 예측해도 픽셀 정확도가 높아질 수 있다. 무시할 레이블이 있으면 손실과 평가에서 같은 정책으로 제외한다. 픽셀 수가 많다는 이유만으로 서로 독립적인 새 이미지 표본이 많다고 해석하지 않는다.

중간 과정을 따라가는 예제

네 픽셀의 물체 확률이 [0.8,0.4,0.6,0.1]이고 배경 확률은 각각 1에서 뺀 값이다. argmax의 예측과 정답 [1,1,0,0]에 대한 정확도를 구하라.

  1. 각 픽셀에서 1 확률이 0 확률보다 큰지 비교하면 예측은 [1,0,1,0]이다. 동률은 없는 예다.

  2. 첫째와 넷째만 정답이라 맞은 수는 2/4다. 둘째는 물체 누락, 셋째는 배경을 물체로 오인했다.

  3. 전체 픽셀 정확도는 50%이며 물체의 TP=1, FN=1, FP=1이다. 이 예측만으로 인스턴스 수는 알 수 없다.

예측 [1,0,1,0], 정확도 50%다. 수치는 가상 확률표이며 실제 모델 관측이 아니다.

조건을 바꾸어 비교하기

분모에서 제외한 위치를 복원하지 않는다

255 제외 규약의 네 유효 위치를 추적하라.

  1. 위치 1은 TP, 위치 2는 FN, 위치 3은 FP, 위치 4는 TN이다.

  2. 맞은 두 위치를 유효 네 위치로 나누면 1/2다. IoU는 1/(1+1+1)=1/3, Dice는 2/(2+1+1)=1/2다.

유효 위치와 물체 분모를 각각 기록한다.

비교할 점

전체 여섯 위치를 정확도 분모에 넣지 않는다.

제외 표지를 배경으로 바꾸는 별도 정책

255를 0으로 바꾸어 모두 평가할 때 결과를 구하라.

  1. 기존 네 위치의 결과에 FP 두 개만 추가된다.

  2. 정확도는 2/6=1/3, IoU는 1/5, Dice는 2/6=1/3이다.

새 점수는 정책 변경의 결과다.

비교할 점

같은 예측 배열이므로 점수가 같아야 한다고 주장하지 않는다.

종이와 본문으로 직접 해보기

100픽셀 중 물체가 5개일 때 전부 배경으로 예측하면 전체 정확도와 물체 재현율은?

힌트 보기

배경은 95개이며 물체 중 맞춘 수는 0이다.

풀이 보기

정확도 95/100=95%, 물체 재현율 0/5=0%다. 높은 전체 정확도가 물체를 잘 찾았다는 뜻은 아니다.

오해와 반례

픽셀마다 클래스를 맞히면 같은 클래스의 여러 객체도 구별한 것이다.

클래스 지도에는 객체 신원이 없을 수 있다. 두 고양이의 픽셀을 같은 클래스 1로 표시하면 인스턴스의 구분은 별도 문제다.

encoder-decoder와 skip

  • 텐서 공간 크기·채널

  • encoder와 decoder의 공간 역할을 구별한다.

  • skip 결합의 크기와 채널을 추적한다.

  • 업샘플링과 정확한 역연산을 구별한다.

같은 텐서 크기라면 같은 위치끼리 skip을 결합한 것일까?

자체 특징 모형에서 encoder skip은 9×9×3이고 좌표 원점은 (0,0), 격자 간격은 1이다. decoder 특징은 7×7×5이며 원점은 (1,1), 격자 간격은 1이다. skip의 네 변에서 한 칸씩 crop하면 7×7×3이고 원점 (1,1)이 맞는다. 채널 concatenation은 7×7×8이다. 두 클래스로 바꾸는 편향 포함 1×1 층의 계수는 8×2+2=18개다. 이 작은 텐서 모형은 원 U-Net 전체 구조가 아니다.

skip의 왼쪽 위 7×7 영역만 자르면 크기는 같아도 원점은 (0,0)이다. 같은 배열 인덱스끼리 결합하면 서로 한 칸 다른 실제 위치를 잇는다. 크기 검사는 필요하지만 좌표 정렬의 충분 조건이 아니다. 격자 간격·crop 시작·축 방향·보간 좌표 정책도 대조한다.

addition을 선택하려면 채널 수도 맞아야 한다. 3채널 skip을 5채널로 투영하는 편향 포함 1×1 층은 3×5+5=20개다. 정렬된 두 5채널 특징을 더한 뒤 두 클래스로 바꾸는 층은 5×2+2=12개다. 지정 두 투영층의 총계는 32개로 concatenation의 지정 출력층 18개와 다르다. encoder·decoder의 다른 계수는 이 비교에 포함하지 않는다.

max pooling이 [1,4]와 [3,4]를 모두 4로 만들면 그 결과만으로 원 입력을 고를 수 없다. skip은 추가 정보 경로이고 업샘플링은 일반적인 역함수의 보장이 아니다. 원 U-Net의 unpadded convolution·crop/concatenation·픽셀 softmax를 실제 읽었으며 새 tensor나 학습을 실행하지 않았다.

먼저 확인할 개념
  • skip 크기와 채널 결합

    앞 본문의 crop·concat/add 구별과 공유 1×1 계수를 좌표 원점까지 확장한다.

  • 정답과 입력의 위치 대응

    앞 본문의 공간 변환 일치를 특징 격자의 원점과 간격 비교에 연결한다.

문맥을 얻으며 위치 해상도가 줄어든다

encoder는 convolution과 다운샘플링으로 넓은 문맥을 요약한다. pooling이 두 값의 최대만 남기면 작은 값을 잃을 수 있으므로 축소가 일반적인 일대일 변환은 아니다. 문맥을 얻는 것과 세밀한 위치를 유지하는 것 사이의 설계 문제가 있다.

decoder는 공간 격자를 키우며 픽셀 예측을 만든다. 보간이나 학습 가능한 전치 convolution 같은 선택지가 있다. 해상도를 늘리는 연산만으로 사라진 정보를 정확하게 되찾는다는 보장은 없다.

skip으로 높은 해상도의 특징을 연결한다

U-Net 계열의 skip은 encoder의 해당 단계 특징을 decoder의 특징과 결합한다. 원 U-Net은 자른 encoder 특징과 채널 방향 concatenation을 사용한다. 이 방식은 좌표 정렬과 공간 크기를 맞춘 뒤 채널을 이어 붙인다.

이 단원의 작은 모형은 입력 8×8에서 same padding으로 공간 크기를 유지한 특징 8×8×4를 저장하고, 축소 특징 4×4×8을 만든다고 가정한다. decoder가 8×8×4로 키우면 skip 8×8×4와 이어 붙여 8×8×8이 된다. 이는 원 논문의 unpadded 전체 숫자를 재현한 구조가 아니다.

출력과 학습의 역할은 별도다

1×1 convolution은 위치마다 채널을 C개 클래스 점수로 바꿀 수 있다. 두 클래스 예에서 결합 특징 8채널을 2채널로 바꾸면 8×8×2 점수가 나온다. 위치별 softmax와 레이블 비교로 학습 목표를 정할 수 있다.

concatenation은 채널 수를 더하고 원소별 addition은 같은 채널 수가 필요하다. skip이 있어도 데이터·학습·좌표 정렬이 잘못되면 경계가 정확해지지 않는다. 실제 학습 효과와 구조상 가능한 정보 경로를 분리한다.

준비 개념과 학습 목표

준비 개념

  • 집합 교집합·합집합

  • TP·FP·FN

  • 분수와 평균

  • 면적 겹침과 경계 위치 오류를 구별한다.

평균 IoU에 변환식을 적용하면 평균 Dice가 될까?

독립 이미지 A는 교집합 1, 합집합 1이고 이미지 B는 교집합 1, 합집합 9다. 두 집합 크기의 합은 각각 2와 10이므로 IoU는 1과 1/9, Dice는 1과 1/5다. 이미지별 IoU 평균은 5/9, Dice 평균은 3/5다. 전체 합산 IoU는 2/10=1/5, 전체 Dice는 4/12=1/3이다. 이미지별 동일 가중과 합산 분모 가중은 다른 평가 목적이다.

같은 한 쌍의 양의 분모에서는 Dice=2J/(1+J)이지만 평균을 넣으면 2×(5/9)/(1+5/9)=5/7이다. 이것은 이미지별 Dice 평균 3/5와 다르다. 비선형 변환과 평균은 일반적으로 교환되지 않는다. 반면 합산 IoU 1/5를 같은 합산 계약의 식에 넣으면 전체 Dice 1/3을 얻는다.

경계 폭의 효과는 자체 일차원 연속 구간으로 손추적한다. G=[0,10], P=[1,9]이고 길이를 면적 대신 쓰므로 Mask IoU는 4/5, Dice는 8/9다. 각 구간 안에서 양 끝점으로부터 거리 d 이내인 띠의 합집합을 경계 집합으로 정한다. d=1이면 G의 띠는 [0,1]∪[9,10], P의 띠는 [1,2]∪[8,9]다. 교집합의 길이는 0이고 띠 IoU는 0이다. 끝점 한 점의 공유는 양의 길이가 아니다.

d=2이면 G의 띠는 [0,2]∪[8,10], P의 띠는 [1,3]∪[7,9]다. 교집합 길이 2, 합집합 길이 6으로 띠 IoU는 1/3이다. d≥5면 양쪽 띠가 각 구간 전체를 덮어 Mask IoU 4/5와 같아진다. 이 연속 구간 모형은 실제 픽셀 구현 실행이 아니다. Boundary IoU 논문의 내부 경계 집합 정의·폭에 따른 Mask IoU 환원·내부 오류 한계를 읽고 구별한다. 둘 다 빈 마스크의 정책도 자동 값 대신 명시한다.

먼저 확인할 개념
  • 집합 점수와 평균 정책

    앞 본문의 Dice/IoU 관계·표본 평균과 합산·경계 단위를 새 두 이미지와 구간에 적용한다.

  • 평가 위치와 제외 조건

    앞 본문의 정답 지도 및 무시 레이블 조건을 점수 대상 장부에 연결한다.

영역을 집합으로 세기

같은 해상도의 정답 물체 픽셀 집합 G와 예측 집합 P를 둔다. IoU=|G∩P|/|G∪P|이고 Dice=2|G∩P|/(|G|+|P|)다. 이 절은 확률을 넣은 soft 손실이 아니라 이진 집합의 평가를 다룬다.

TP=|G∩P|, FP=|P−G|, FN=|G−P|라면 IoU=TP/(TP+FP+FN), Dice=2TP/(2TP+FP+FN)다. 배경 TN은 이 물체 점수의 분모에 넣지 않는다. 서로 다른 물체·클래스의 평균에는 별도 집계 약속이 필요하다.

점수의 관계와 빈 분모

분모가 양수인 같은 두 집합에서는 Dice=2IoU/(1+IoU)다. Dice 수치가 더 크다고 더 좋은 모델로 바뀌었다는 뜻은 아니다. 같은 오류를 다른 척도로 표현한 것이다.

G와 P가 모두 비면 두 식이 0/0이므로 점수가 저절로 정해지지 않는다. 제외·별도 보고·약속한 값 같은 정책을 사전에 정한다. 한쪽만 비고 다른 쪽은 비지 않으면 두 점수는 0이다. smoothing을 넣은 손실과 원 집합 점수를 혼동하지 않는다.

경계는 전체 면적 점수만으로 충분하지 않다

큰 물체는 내부 면적이 커서 경계의 한 줄 오류가 전체 IoU에 작은 변화만 줄 수 있다. 경계 주변 띠나 거리를 평가하는 방법에는 허용 폭과 좌표·해상도 정책이 필요하다. Boundary IoU 같은 별도 척도는 원 정의를 따라 계산해야 한다.

같은 TP/FP/FN이라도 누락이 경계에 있는지 내부에 구멍처럼 있는지는 다를 수 있다. 겹침 점수와 함께 오류 지도를 읽고 목적에 맞는 경계 평가를 추가한다. 경계 평가만으로 내부 오류까지 모두 보장하지 않으며 주석의 모호함도 고려한다.

IoU 분모와 Dice 분모는 같지 않다. 단순 평균·전체 합산·변환한 평균을 세 가지 다른 계산으로 읽는다.

중간 과정을 따라가는 예제

G={1,2,3,4}, P={2,3,4,5,6}인 가상 여섯 픽셀에서 IoU와 Dice를 구하라.

  1. 교집합은 {2,3,4}로 TP=3이다. FP는 {5,6}의 2개, FN은 {1}의 1개다.

  2. 합집합은 여섯 픽셀이므로 IoU=3/6=1/2다.

  3. Dice=2×3/(4+5)=6/9=2/3이며 2×(1/2)/(1+1/2)=2/3로도 확인된다.

IoU=1/2, Dice=2/3다. 같은 두 마스크를 다른 식으로 요약했다.

조건을 바꾸어 비교하기

비선형 변환과 평균의 순서

두 이미지의 평균 Dice와 평균 IoU를 변환한 값을 비교하라.

  1. Dice 평균은 (1+1/5)/2=3/5다.

  2. IoU 평균 5/9를 변환하면 5/7이며 두 값은 다르다.

한 쌍의 항등식을 모든 평균으로 확대하지 않는다.

비교할 점

같은 집계 목적이라고 가정하지 않는다.

같은 마스크와 다른 경계 폭

연속 구간 G/P에서 d=1과 d=2의 띠 IoU를 구하라.

  1. d=1은 교집합 길이 0, 합집합 길이 4라 점수 0이다.

  2. d=2는 교집합 길이 2, 합집합 길이 6이라 점수 1/3이다.

Mask IoU는 4/5로 그대로이며 경계 규약만 바뀌었다.

비교할 점

폭 변경을 모델의 실제 개선으로 부르지 않는다.

오해와 반례

IoU가 같으면 경계 오류의 위치도 같다.

정답 G={1,2,3,4,5}인 일차원 연속 물체에서 P₁={2,3,4,5}는 끝을, P₂={1,2,4,5}는 내부를 놓친다. 둘 다 IoU=4/5와 Dice=8/9지만 오류 위치가 다르다.

평가 영역·정렬·집계를 따로 승인한다

세 부분은 독립된 가상 문제다. ① 정답 [1,1,0,0,255,255]와 예측 [1,0,1,0,1,1]에서 255 제외 규약의 정확도·물체 IoU/Dice를 계산한다. 255를 배경으로 바꾸어 모두 평가한 대안도 비교한다. ② 원점 (0,0)·간격 1의 9×9×3 skip과 원점 (1,1)·간격 1의 7×7×5 decoder를 같은 축으로 정렬해 concat 및 편향 포함 두 클래스 1×1 출력층을 설계한다. ③ 이미지 A/B의 교집합은 각각 1, 합집합은 1과 9, 두 집합 크기 합은 2와 10이다. 이미지별 평균과 전체 합산 IoU/Dice를 구하고 실제 실행 범위를 밝힌다.

힌트 1

제외 표지와 배경을 구별하고 crop 뒤 원점과 격자 간격을 대조한다.

힌트 2

같은 한 쌍의 Dice/IoU 관계를 이미지 평균에 그대로 넣지 않는다.

풀이와 답 확인

  1. 255 제외 뒤 TP·FP·FN·TN은 각 1개다. 정확도는 1/2, IoU는 1/3, Dice는 1/2다. 배경 치환 대안은 FP가 3개가 되어 정확도 1/3, IoU 1/5, Dice 1/3이다.

  2. skip의 네 변에서 한 칸씩 crop하면 원점 (1,1)의 7×7×3이다. concat은 7×7×8이고 출력은 7×7×2다. 출력층 계수는 8×2+2=18개다.

  3. 이미지별 평균 IoU는 5/9, Dice는 3/5다. 전체 합산 IoU는 1/5, Dice는 1/3이다. 평균 IoU의 변환 5/7은 이미지별 Dice 평균이 아니다.

  4. 모든 값은 지정 지도·텐서 크기·집합의 손계산이다. 실제 segmentation 모델·영상·라이브러리·GPU·학습자 시험은 실행하지 않았다.

제외 규약은 정확도 1/2·IoU 1/3·Dice 1/2이고 배경 치환은 1/3·1/5·1/3이다. 정렬된 concat의 출력층은 18개 계수다. 이미지별 IoU/Dice 평균은 5/9·3/5, 전체 합산은 1/5·1/3이다.
