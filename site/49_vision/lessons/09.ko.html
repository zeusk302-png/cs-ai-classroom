소단원 9.1

pixel-wise 예측

사진 속 두 고양이를 같은 색으로 칠하면 두 마리를 구별한 걸까?

준비 개념과 학습 목표

준비 개념

  • 이미지 높이·폭·채널
  • 분류와 확률
  • argmax

학습 목표

  • 픽셀마다 클래스 점수를 읽는다.
  • 의미 분할과 인스턴스 분할을 구별한다.
  • 배경 비율과 픽셀 정확도의 한계를 계산한다.

출력이 사진 한 장의 이름에서 지도로 바뀐다

의미 분할은 H×W 위치마다 클래스 레이블을 예측한다. C개 클래스의 점수 텐서는 배치 하나를 제외하면 H×W×C 또는 C×H×W로 저장할 수 있다. 저장 순서와 실제 위치의 의미를 먼저 확인한다.

서로 배타적인 C개 클래스 모형은 각 위치의 logits에 softmax를 적용하고 argmax로 하나를 고른다. 확률처럼 보이는 수치가 실제 신뢰도를 정확히 보정했다는 뜻은 아니다. 학습한 모델과 평가 조건을 별도로 확인한다.

의미와 객체의 신원을 구분하기

의미 분할에서 두 고양이의 픽셀은 모두 고양이라는 클래스다. 인스턴스 분할은 고양이1과 고양이2처럼 객체 신원을 추가로 나눈다. 객체 상자만 맞추는 검출과 픽셀 영역의 예측도 서로 다른 문제다.

두 객체가 붙어 있으면 동일 클래스 지도에서 연결된 영역 하나로 보일 수 있다. 연결 성분을 나눴다고 모든 실제 객체 신원이 자동 복원되지는 않는다. 겹침·가림과 레이블 정책을 확인해야 한다.

레이블과 평가 조건을 함께 정하기

작은 두 클래스 문제는 물체 1과 배경 0으로 표현한다. 레이블은 색 자체가 아니라 약속한 클래스 번호다. 감독 학습에는 입력과 같은 위치의 정답 지도가 필요하며 자르기·회전 같은 공간 변환은 두 지도에 맞춰 적용한다.

배경이 대부분이면 모두 배경으로 예측해도 픽셀 정확도가 높아질 수 있다. 무시할 레이블이 있으면 손실과 평가에서 같은 정책으로 제외한다. 픽셀 수가 많다는 이유만으로 서로 독립적인 새 이미지 표본이 많다고 해석하지 않는다.

중간 과정을 따라가는 예제

네 픽셀의 물체 확률이 [0.8,0.4,0.6,0.1]이고 배경 확률은 각각 1에서 뺀 값이다. argmax의 예측과 정답 [1,1,0,0]에 대한 정확도를 구하라.

  1. 각 픽셀에서 1 확률이 0 확률보다 큰지 비교하면 예측은 [1,0,1,0]이다. 동률은 없는 예다.
  2. 첫째와 넷째만 정답이라 맞은 수는 2/4다. 둘째는 물체 누락, 셋째는 배경을 물체로 오인했다.
  3. 전체 픽셀 정확도는 50%이며 물체의 TP=1, FN=1, FP=1이다. 이 예측만으로 인스턴스 수는 알 수 없다.

예측 [1,0,1,0], 정확도 50%다. 수치는 가상 확률표이며 실제 모델 관측이 아니다.

종이와 본문으로 직접 해보기

100픽셀 중 물체가 5개일 때 전부 배경으로 예측하면 전체 정확도와 물체 재현율은?

힌트 보기

배경은 95개이며 물체 중 맞춘 수는 0이다.

풀이 보기

정확도 95/100=95%, 물체 재현율 0/5=0%다. 높은 전체 정확도가 물체를 잘 찾았다는 뜻은 아니다.

오해와 반례

픽셀마다 클래스를 맞히면 같은 클래스의 여러 객체도 구별한 것이다.

클래스 지도에는 객체 신원이 없을 수 있다. 두 고양이의 픽셀을 같은 클래스 1로 표시하면 인스턴스의 구분은 별도 문제다.

자기점검

네 픽셀에 두 클래스 점수를 저장하면 몇 개의 수인가?

답과 이유 보기

8개다.

4 위치×2 클래스다. 배치 차원은 이 계산에서 제외했다.

확률 0.8을 관측했다고 실제 오류 확률이 0.2라고 보장되는가?

답과 이유 보기

그 사실만으로 보장되지 않는다.

모델 수치의 보정과 적용 환경을 별도 검증해야 한다.

배경만 예측한 활동의 물체 TP는?

답과 이유 보기

0이다.

물체를 하나도 예측하지 않아 다섯 물체가 FN이다.

한 단계 더

가상 클래스 지도 [1,1,1,1]에서 앞 두 픽셀과 뒤 두 픽셀이 다른 고양이라면 클래스 지도와 신원 지도 [A,A,B,B]의 정보 차이를 적어 보라. 실제 사진·주석·학습 실험은 수행하지 않았다.

소단원 9.2

encoder-decoder와 skip

줄여서 본 그림을 다시 키우면 없어진 가느다란 선도 돌아올까?

준비 개념과 학습 목표

준비 개념

  • convolution과 pooling
  • 텐서 공간 크기·채널
  • 리스트 이어 붙이기와 합

학습 목표

  • encoder와 decoder의 공간 역할을 구별한다.
  • skip 결합의 크기와 채널을 추적한다.
  • 업샘플링과 정확한 역연산을 구별한다.

문맥을 얻으며 위치 해상도가 줄어든다

encoder는 convolution과 다운샘플링으로 넓은 문맥을 요약한다. pooling이 두 값의 최대만 남기면 작은 값을 잃을 수 있으므로 축소가 일반적인 일대일 변환은 아니다. 문맥을 얻는 것과 세밀한 위치를 유지하는 것 사이의 설계 문제가 있다.

decoder는 공간 격자를 키우며 픽셀 예측을 만든다. 보간이나 학습 가능한 전치 convolution 같은 선택지가 있다. 해상도를 늘리는 연산만으로 사라진 정보를 정확하게 되찾는다는 보장은 없다.

skip으로 높은 해상도의 특징을 연결한다

U-Net 계열의 skip은 encoder의 해당 단계 특징을 decoder의 특징과 결합한다. 원 U-Net은 자른 encoder 특징과 채널 방향 concatenation을 사용한다. 이 방식은 좌표 정렬과 공간 크기를 맞춘 뒤 채널을 이어 붙인다.

이 단원의 작은 모형은 입력 8×8에서 same padding으로 공간 크기를 유지한 특징 8×8×4를 저장하고, 축소 특징 4×4×8을 만든다고 가정한다. decoder가 8×8×4로 키우면 skip 8×8×4와 이어 붙여 8×8×8이 된다. 이는 원 논문의 unpadded 전체 숫자를 재현한 구조가 아니다.

출력과 학습의 역할은 별도다

1×1 convolution은 위치마다 채널을 C개 클래스 점수로 바꿀 수 있다. 두 클래스 예에서 결합 특징 8채널을 2채널로 바꾸면 8×8×2 점수가 나온다. 위치별 softmax와 레이블 비교로 학습 목표를 정할 수 있다.

concatenation은 채널 수를 더하고 원소별 addition은 같은 채널 수가 필요하다. skip이 있어도 데이터·학습·좌표 정렬이 잘못되면 경계가 정확해지지 않는다. 실제 학습 효과와 구조상 가능한 정보 경로를 분리한다.

중간 과정을 따라가는 예제

작은 same-padding 모형에서 skip=8×8×4, 업샘플 특징=8×8×6이다. 채널 concatenation 후 1×1 convolution으로 두 클래스 점수를 만든다. 텐서 크기와 1×1 층의 가중치·편향 수를 구하라.

  1. 공간 크기가 같아 이어 붙일 수 있고 채널은 4+6=10이다. 결합 크기는 8×8×10이다.
  2. 출력은 8×8×2다. 1×1 층은 입력 채널 10에서 출력 2로 연결하여 가중치 1×1×10×2=20개다.
  3. 출력 채널마다 편향 하나를 쓰는 모형이면 2개를 더해 22개다. 공간 위치 64개마다 별도 가중치를 만들지는 않는다.

결합 8×8×10, 출력 8×8×2, 공유 가중치 20개와 편향 2개다.

종이와 본문으로 직접 해보기

skip이 10×10×4인데 decoder가 8×8×6이면 바로 concatenation할 수 있나? 두 특징을 정렬해 8×8로 맞춘 뒤 addition할 수 있나?

힌트 보기

공간 정렬과 채널 동등성을 별도로 검사한다.

풀이 보기

바로 결합할 수 없다. 예를 들어 좌표가 맞는 중앙 crop으로 8×8을 만든 뒤 concatenation은 가능하다. addition은 4와 6채널이 달라 별도 채널 투영 없이 불가능하다.

오해와 반례

업샘플링은 pooling의 정확한 역함수다.

두 값 [1,3]과 [2,3]의 max pooling 결과는 둘 다 3이다. 결과 3만으로 어느 입력이었는지 고를 수 없다. skip과 학습은 추가 정보를 이용하는 경로다.

자기점검

8×8×10을 두 클래스로 바꾸면 공간 크기는?

답과 이유 보기

8×8이다.

stride1의 1×1 convolution 모형은 위치 수를 유지한다.

예제의 22개 매개변수는 각 위치마다 다른가?

답과 이유 보기

공유한다.

convolution의 동일 계수가 모든 공간 위치에 적용된다.

skip이 있다는 사실만으로 경계 검증은 완료됐나?

답과 이유 보기

아니다.

정렬·학습·평가 조건과 실제 결과가 필요하다.

한 단계 더

편향을 쓰지 않으면 예제 매개변수는 20개다. 원 U-Net은 unpadded convolution 때문에 공간 크기가 줄어 skip crop이 필요함을 원문과 비교하라. 학습 가능한 전치 convolution도 일반적인 pooling 역함수는 아니다.

소단원 9.3

IoU·Dice와 경계오류

같은 겹침 점수면 잘못 칠한 위치도 같은가?

준비 개념과 학습 목표

준비 개념

  • 집합 교집합·합집합
  • TP·FP·FN
  • 분수와 평균

학습 목표

  • 이진 마스크 IoU와 Dice를 계산한다.
  • 빈 집합·평균 방식의 정책을 밝힌다.
  • 면적 겹침과 경계 위치 오류를 구별한다.

영역을 집합으로 세기

같은 해상도의 정답 물체 픽셀 집합 G와 예측 집합 P를 둔다. IoU=|G∩P|/|G∪P|이고 Dice=2|G∩P|/(|G|+|P|)다. 이 절은 확률을 넣은 soft 손실이 아니라 이진 집합의 평가를 다룬다.

TP=|G∩P|, FP=|P−G|, FN=|G−P|라면 IoU=TP/(TP+FP+FN), Dice=2TP/(2TP+FP+FN)다. 배경 TN은 이 물체 점수의 분모에 넣지 않는다. 서로 다른 물체·클래스의 평균에는 별도 집계 약속이 필요하다.

점수의 관계와 빈 분모

분모가 양수인 같은 두 집합에서는 Dice=2IoU/(1+IoU)다. Dice 수치가 더 크다고 더 좋은 모델로 바뀌었다는 뜻은 아니다. 같은 오류를 다른 척도로 표현한 것이다.

G와 P가 모두 비면 두 식이 0/0이므로 점수가 저절로 정해지지 않는다. 제외·별도 보고·약속한 값 같은 정책을 사전에 정한다. 한쪽만 비고 다른 쪽은 비지 않으면 두 점수는 0이다. smoothing을 넣은 손실과 원 집합 점수를 혼동하지 않는다.

경계는 전체 면적 점수만으로 충분하지 않다

큰 물체는 내부 면적이 커서 경계의 한 줄 오류가 전체 IoU에 작은 변화만 줄 수 있다. 경계 주변 띠나 거리를 평가하는 방법에는 허용 폭과 좌표·해상도 정책이 필요하다. Boundary IoU 같은 별도 척도는 원 정의를 따라 계산해야 한다.

같은 TP/FP/FN이라도 누락이 경계에 있는지 내부에 구멍처럼 있는지는 다를 수 있다. 겹침 점수와 함께 오류 지도를 읽고 목적에 맞는 경계 평가를 추가한다. 경계 평가만으로 내부 오류까지 모두 보장하지 않으며 주석의 모호함도 고려한다.

중간 과정을 따라가는 예제

G={1,2,3,4}, P={2,3,4,5,6}인 가상 여섯 픽셀에서 IoU와 Dice를 구하라.

  1. 교집합은 {2,3,4}로 TP=3이다. FP는 {5,6}의 2개, FN은 {1}의 1개다.
  2. 합집합은 여섯 픽셀이므로 IoU=3/6=1/2다.
  3. Dice=2×3/(4+5)=6/9=2/3이며 2×(1/2)/(1+1/2)=2/3로도 확인된다.

IoU=1/2, Dice=2/3다. 같은 두 마스크를 다른 식으로 요약했다.

종이와 본문으로 직접 해보기

P에서 잘못 들어간 6만 삭제하면 두 점수는? G와 P가 모두 빈 별도 사례는?

힌트 보기

TP=3을 유지한 채 FP를 하나 줄이고 분모를 다시 센다.

풀이 보기

새 P={2,3,4,5}라 IoU=3/5, Dice=6/8=3/4다. 둘 다 빈 사례는 0/0이라 약속 없이 점수를 쓰지 않는다.

오해와 반례

IoU가 같으면 경계 오류의 위치도 같다.

정답 G={1,2,3,4,5}인 일차원 연속 물체에서 P₁={2,3,4,5}는 끝을, P₂={1,2,4,5}는 내부를 놓친다. 둘 다 IoU=4/5와 Dice=8/9지만 오류 위치가 다르다.

자기점검

한쪽 집합만 비면 IoU와 Dice는?

둘 다 0이다.

두 이미지의 IoU가 1과 0이고 각각 합집합 크기가 1과 9이면 단순 평균과 합산 점수는?

답과 이유 보기

단순 평균 1/2, 합산 교집합/합집합은 1/10이다.

교집합 수는 1과 0이다. 표본별 평균과 전체 집계가 다르다.

많은 배경 픽셀을 더하면 이 물체 집합 점수가 자동으로 높아지나?

G와 P의 물체 집합이 같다면 교집합과 합집합도 같다.

한 단계 더

정답·예측이 겹침 없이 각각 2픽셀이면 IoU=0, Dice=0이다. 경계 척도를 추가할 때 허용 거리 단위, 해상도, 빈 마스크 및 배경 포함 정책을 적어 보라. 실제 segmentation 라이브러리나 영상 평가를 실행한 결과는 없다.
