소단원 7.1

CNN과 vision transformer

영상의 가까운 무늬와 멀리 떨어진 부분을 어떤 구조로 함께 읽을까?

준비 개념과 학습 목표

준비 개념

  • 영상은 높이·너비·채널이 있는 배열이다.

  • 분류 모델은 클래스별 점수에서 하나의 범주를 고른다.

학습 목표

  • 국소 합성곱과 패치 attention의 경로를 구별한다.

  • 패치·임베딩·분류 출력 크기를 계산한다.

  • 구조 이름만으로 성능을 단정하지 않는다.

패치 순서와 위치를 서로 바꾸면 같은 분류 문제일까?

아래는 실제 모델을 실행하지 않은 자체 계산이다. RGB 영상의 높이는 8, 폭은 12다. 겹치지 않는 정사각 패치의 한 변을 4로 잡으면 패치는 6개이고 각 패치는 48개 수로 펼쳐진다. 차원 D=4로 투영하고 클래스 토큰 하나를 추가하면 토큰은 7개다. 한 attention head의 점수표는 7×7이다. 경계의 남는 패치나 padding은 이 예에 없다.

패치 투영의 가중치는 48×4개, bias는 4개다. 학습 가능한 위치 표를 7×4, 클래스 토큰을 4개 수, 두 클래스의 선형 head를 4×2 가중치와 2개 bias로 정하면 이 네 부분의 파라미터 합은 196+28+4+10=238이다. encoder 내부의 파라미터는 이 합에 포함하지 않는다. 토큰 수와 파라미터 수, 실제 메모리와 실행 시간은 서로 다른 관찰이다.

위치가 없는 작은 attention 계산을 별도로 정의한다. 클래스 질의는 1이고 첫 패치의 key와 value는 1, 둘째 패치의 key와 value는 3이다. 클래스 자신은 읽지 않는 mask를 지정한다. e는 자연로그의 밑이며 exp(1)을 뜻한다. 출력은 (e+3e³)/(e+e³)다. 두 패치를 함께 교환하면 합의 항 순서만 바뀌므로 값은 같다. 이 예는 전체 ViT 구현이 아니라 위치 없는 content attention의 손모형이다.

첫 위치의 고정 위치값은 0, 둘째 위치의 값은 2다. 이를 각각 내용에 더해 key와 value를 만들면 원래 배열은 첫 값 1, 둘째 값 5가 된다. 내용을 교환한 배열은 두 값 모두 3이다. 원래 출력은 (e+5e⁵)/(e+e⁵)이고 교환 출력은 3이다. 원래 값에서 3을 빼면 2(e⁵−e)/(e+e⁵)>0이다. 내용을 교환하면서 위치 표까지 함께 교환하는 연산과, 고정 위치에서 내용을 옮기는 연산을 구별한다.

먼저 확인할 개념
  • 패치·클래스 토큰과 위치 정보

    앞 본문의 패치 수·위치 정보·분류 head를 자체 크기와 순서 교환에 적용한다.

  • 분류 출력과 평가 단위

    앞 본문의 예측 클래스와 평가 분모를 토큰·파라미터 수와 구별한다.

CNN이 무늬를 쌓는 방식

CNN은 같은 커널을 여러 위치에 적용해 국소 특징을 만든다. 층을 쌓으면 더 넓은 영역의 정보를 결합할 수 있고 분류층은 특징을 클래스 점수로 바꾼다.

평행 이동에 대한 구조적 성질은 stride·padding·pooling·경계 조건에 따라 달라진다. 영상 전체가 얼마나 움직여도 같은 분류가 보장된다고 말하지 않는다. 위치마다 커널을 새로 만드는 전결합 구조와 가중치 공유를 구분한다.

ViT가 영상을 토큰으로 바꾸는 방식

기본 ViT는 겹치지 않는 p×p 패치를 펴서 임베딩 벡터로 투영한다. 위치 임베딩과 class token을 넣고 Transformer encoder의 attention으로 패치 사이 정보를 결합한다.

높이와 너비가 p로 나누어떨어지면 패치 수는 (H/p)(W/p), 펼친 패치 길이는 p²C다. 기본 전역 attention에서 class token을 포함한 L개 토큰의 쌍별 점수는 한 head당 L×L이다. 변형 구조는 다른 규칙을 쓸 수 있다.

출력과 평가를 같은 기준에 맞추기

class token의 표현을 K개 점수로 투영하는 기본 설계에서는 출력이 배치 크기×K다. attention을 쓰는 구조에도 패치 투영을 합성곱으로 구현할 수 있으므로 코드의 Conv 한 줄만 보고 전체를 CNN이라고 분류하지 않는다.

어느 구조가 낫다는 결론은 같은 데이터 분할·전처리·학습 예산·측정 조건의 비교가 필요하다. 아래 크기 계산은 실제 성능·속도·장비 메모리 측정이 아니다.

중간 과정을 따라가는 예제

배치 2개의 8×8 RGB 영상, p=4, 임베딩 폭 D=6, class token 1개, 클래스 K=3의 기본 ViT 크기를 구하라.

  1. 패치 수는 (8/4)²=4이며 각 패치의 펼친 길이는 4²×3=48이다. 패치 투영은 각 48차원을 6차원으로 바꾼다.

  2. class token을 더하면 encoder 입력은 (2,5,6)이다. 한 head의 영상당 점수 행렬은 5×5=25개 원소다.

  3. encoder가 폭과 토큰 수를 보존하면 class 표현은 (2,6), 분류 점수는 (2,3)이다.

패치 4개, 토큰 5개, 마지막 출력 (2,3)이다. 점수 행렬 원소 수는 학습 파라미터 수와 다르다.

비교할 점

위치를 고정한 내용 교환

두 내용 1,3에 위치값 0,2를 더한 attention 출력과 내용 교환 출력을 비교하라.

  1. 원래 key/value는 1,5라 출력은 (e+5e⁵)/(e+e⁵)다.

  2. 교환 뒤 두 key/value가 3이므로 출력은 3이다. 원래 출력은 3보다 크다.

위치 표를 고정하면 내용 교환이 이 손모형의 출력을 바꾼다.

위치 없는 계산의 순열 불변성을 위치가 있는 경우에 그대로 옮기지 않는다.

오해와 반례

ViT라는 이름이면 모든 작은 데이터에서 CNN보다 잘된다.

구조 차이만으로 학습 데이터·사전학습·규제·예산을 대신할 수 없다. 같은 조건의 검증 없이 성능 우열을 완료로 표시하지 않는다.

소단원 7.2

사전학습과 미세조정

다른 사진으로 배운 표현을 새 분류 문제에 어떻게 이어 쓸까?

준비 개념과 학습 목표

준비 개념

  • 파라미터는 학습으로 바뀌는 가중치다.

  • 학습·검증·최종 평가 데이터의 역할이 다르다.

학습 목표

  • 특징 추출과 미세조정을 나눈다.

  • 출력층 교체와 파라미터 갱신을 추적한다.

  • 전이 실패·누수·평가 조건을 설명한다.

가중치를 고정하면 특징과 통계도 고정될까?

PyTorch의 requires_grad=False는 해당 파라미터의 gradient 기록을 막는 설정이다. 공식 전이학습 예제는 새 head만 optimizer에 넣고 특징 추출기의 forward는 계속 수행한다. BatchNorm은 기본 설정에서 train forward 중 평균·분산의 running 통계를 갱신하고 eval에서 이를 사용한다. 파라미터 고정과 모드·통계 상태를 따로 확인한다.

자체 running 평균 r은 초기값 0, momentum 1/2로 r새=(r옛+b)/2라 정한다. batch 평균 2 다음 6을 읽으면 r은 1 다음 7/2가 된다. 반대로 6 다음 2면 r은 3 다음 5/2다. 아래 출력 비교는 전체 BatchNorm이 아니라 중심화 성분 x−r만이다. x=4에서 두 값은 1/2와 3/2다. 실제 정규화에는 분산·epsilon·affine 항도 필요하다.

학습 가능한 가중치가 바뀌지 않아도 이 통계 장부는 바뀔 수 있다. 특징 cache는 입력·전처리·가중치뿐 아니라 사용한 모드와 관련 상태도 식별해야 한다. track_running_stats=False인 BatchNorm은 eval에서도 batch 통계를 사용하므로 eval이라는 말만으로 batch 구성 독립성을 보장하지 않는다.

별도 스칼라 미세조정의 손모형은 목표 0, 출력 wa, 손실 (wa)²/2다. 시작 a=2, w=1/2에서 두 gradient는 각각 ∂L/∂w=2, ∂L/∂a=1/2다. 같은 시작 상태에서 w의 보폭은 1/10, a의 보폭은 1/100으로 정해 동시 갱신하면 w는 3/10, a는 399/200이 된다. 실제 모델·optimizer·통계 API는 실행하지 않았다.

기존 표현과 새 라벨 연결하기

사전학습은 원천 데이터에서 표현을 학습한 상태로 시작하는 방법이다. 목표 범주가 바뀌면 기존 분류 head 대신 새 출력층을 둔다. 원천 표현이 목표 데이터에도 도움이 된다는 것은 검증할 가정이다.

배경·색·질감만 배운 표현은 목표에서 방해가 될 수도 있다. 사용하는 가중치의 출처·학습 데이터 정보·허용 사용 조건을 확인하고 목표 성능은 별도 데이터로 평가한다.

고정 특징 추출과 미세조정 나누기

고정 특징 추출은 표현 파라미터를 고정하고 새 head만 학습한다. 미세조정은 표현의 일부 또는 전체도 갱신한다. optimizer가 실제 갱신할 집합을 명시해야 설정과 설명이 맞는다.

gradient를 막는 설정과 train/eval 모드는 서로 다르다. BatchNorm의 이동 통계 같은 비파라미터 상태도 따로 관리해야 완전히 고정된 표현이라는 주장이 맞는다. head만 학습해도 특징의 forward 계산은 필요하다.

작은 변경과 공정한 선택

사전학습 층과 새 층에 서로 다른 학습률을 쓰기도 한다. 이 선택은 보편적으로 최적인 상수가 아니라 validation으로 고를 설계다. 작은 목표 데이터에서는 과적합과 원래 표현 손실도 확인한다.

같은 대상의 비슷한 사진이 학습과 평가로 갈라지면 쉬운 중복 단서가 생길 수 있다. 대상별 분할과 평가셋 보존을 먼저 정하고 실제 학습하지 않았다면 아래 계산을 모델 성능으로 제시하지 않는다.

분류지표와 혼동분석

정확도 하나로 드문 범주를 놓치는 문제까지 알 수 있을까?

준비 개념과 학습 목표

준비 개념

  • 실제 라벨과 예측 라벨을 같은 샘플끼리 비교한다.

  • 분수의 분모가 0인지 확인한다.

학습 목표

  • 혼동행렬 축과 TP·FP·FN·TN을 고정한다.

  • 정확도·precision·recall·F1을 계산한다.

  • 불균형과 오류 유형을 수치와 사례로 분석한다.

같은 F1이라는 이름이면 표를 합치는 순서도 무관할까?

각 표는 독립된 가상 단일 라벨 이진 분류 10건이다. A의 TN은 8, FP는 0, FN은 1, TP는 1이다. B의 TN은 0, FP는 8, FN은 0, TP는 2다. 양성 F1은 2TP/(2TP+FP+FN)이므로 A는 2/3, B는 1/3이다. 두 F1의 단순 평균은 1/2다. 실제 분류기를 실행하지 않았다.

두 표를 합치면 TN은 8, FP는 8, FN은 1, TP는 3이다. 합친 양성 F1은 6/15=2/5다. F1은 비율이므로 사례 수가 같은 두 표라도 F1 평균이 합친 F1과 같지 않을 수 있다. 어떤 집계 단위를 평가하는지 명세에 먼저 정한다.

합친 표에서 음성을 양성처럼 취급한 F1은 16/(16+1+8)=16/25다. 두 클래스 macro F1은 (2/5+16/25)/2=13/25다. 전체 두 클래스를 포함한 단일 라벨 micro F1은 정확도와 같은 11/20이다. 양성 F1·macro·micro를 하나의 지표로 섞어 보고하지 않는다.

별도 네 사례가 모두 클래스 0이고 모두 0으로 맞힌 표에서 클래스 0의 F1은 1이다. 클래스 집합을 {0,1}로 고정하면 클래스 1의 F1 분모는 0이라 정의되지 않는다. sklearn의 zero_division=0으로 채운 macro는 1/2, zero_division=nan으로 제외한 macro는 1이다. 이 차이는 클래스 1의 실제 성능을 새로 알아낸 결과가 아니라 보고 규약의 차이다.

  • 학습과 평가의 분리

    앞 본문의 평가 대상 구별을 실제 모델 없는 가상 혼동표 보고에 연결한다.

축부터 정해 혼동을 세기

여기서는 행이 실제 클래스, 열이 예측 클래스다. 이진 문제의 양성을 명시하면 실제 양성/예측 양성이 TP, 실제 음성/예측 양성이 FP, 실제 양성/예측 음성이 FN이다. 나머지는 TN이다.

같은 표라도 양성 범주나 축 규약을 바꾸면 읽는 방식이 바뀐다. 데이터 누락·중복과 라벨 순서를 먼저 확인하고 예측 점수의 threshold 선택은 보존한 평가셋 결과를 보며 반복 조정하지 않는다.

서로 다른 분모가 다른 질문이다

정확도는 (TP+TN)/전체다. precision=TP/(TP+FP)는 양성이라고 예측한 것 중 맞은 비율, recall=TP/(TP+FN)는 실제 양성 중 찾은 비율이다. F1=2TP/(2TP+FP+FN)이다.

분모가 0이면 정의되지 않는 경우를 따로 표시하거나 도구의 zero_division 정책을 명시한다. 0을 대입한 표시와 관측상 precision이 0이라는 주장을 구분한다. F1은 TN을 직접 쓰지 않으므로 전체 정확도를 대신하는 모든 정보는 아니다.

오류를 돌아보되 평가를 학습에 쓰지 않기

불균형 자료는 흔한 범주만 찍어도 높은 정확도가 나올 수 있다. 범주별 recall, 혼동표와 어떤 오류가 발생했는지를 같이 읽는다. 다중 클래스의 macro 평균은 범주별 지표를 같은 가중치로 평균한다.

비슷한 형태·촬영 환경·라벨 오류를 사례로 조사하되 오류 사례를 보고 모델을 바꿨다면 별도의 최종 평가가 필요하다. 아래 표는 가상 분류 결과이며 학습·추론 실행을 하지 않았다.

중간 과정을 따라가는 예제

실제행/예측열 순서가 [음성,양성]인 가상 표 [[8,2],[3,7]]이다. 양성을 찾는 분류의 지표를 계산하라.

  1. TN=8, FP=2, FN=3, TP=7이며 전체는 20이다.

  2. 정확도=(8+7)/20=0.75, precision=7/9≈0.7778, recall=7/10=0.7이다.

  3. F1=14/(14+2+3)=14/19≈0.7368이다. 실제 양성 10개 중 3개를 놓친다.

정확도 75%와 양성 recall 70%는 다른 질문이다. 오류 유형을 표의 축과 함께 기록한다.

비교할 점

관측되지 않은 클래스의 규약

네 건 모두 0으로 정답인 표에서 {0,1} 고정 macro의 두 정책을 비교하라.

  1. 클래스 0은 F1=1이고 클래스 1의 분모는 0이다.

  2. 0으로 채우면 macro=1/2, nan으로 제외하면 macro=1이다.

클래스 집합과 미정의 처리 규약을 함께 보고한다.

비교할 점

높은 macro를 얻기 위해 결과를 본 뒤 조용히 클래스 집합을 바꾸지 않는다.

힌트 보기

풀이 보기

정확도는 95%, recall은 0/5=0이다. precision은 0/0이므로 수학적으로 정의되지 않는다. 표시값을 0으로 정한다면 정책을 명시한다. F1은 0/(0+0+5)=0이다.

오해와 반례

높은 정확도면 모든 범주를 잘 찾는다.

95/5 예제는 정확도 95%여도 드문 양성을 하나도 찾지 못한다. 분포와 범주별 지표를 함께 본다.
