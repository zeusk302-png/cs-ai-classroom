소단원 6.1

라벨링과 클래스분포

사진에 붙인 이름은 원래부터 정답으로 존재했을까?

준비 개념과 학습 목표

준비 개념

  • 분류는 영상의 범주, 검출은 대상 위치, 분할은 픽셀별 범주를 예측한다.

  • 라벨은 과제 기준에 따라 붙인 목표이며 클래스분포는 범주별 건수/비율이다.

학습 목표

  • 과제별 라벨 단위와 모호한 경우의 정책을 정한다.

  • 다수 클래스 예측의 전체/클래스별 차이를 계산한다.

평가표의 전체 1등이 목표 환경에서도 1등일까?

모든 자료는 가상으로 그린 도형 분류표다. 확정 라벨은 삼각형 T가 90장, 원 C가 10장이다. 예측기 P는 T를 81장, C를 2장 맞힌다. Q는 T를 63장, C를 9장 맞힌다. 실제 학습이나 사진 수집은 하지 않는다. 전체 정확도는 P가 83%, Q가 72%다. T와 C의 재현율은 P에서 각각 0.9와 0.2이고 Q에서는 각각 0.7과 0.9다.

두 클래스 재현율의 단순 평균은 P가 0.55, Q가 0.8이다. 별도 목표 환경의 비중 T=0.3, C=0.7을 지정하고 클래스별 재현율이 그대로라는 조건을 추가하면 목표 가중 정확도는 P가 0.41, Q가 0.84다. 이는 가정 아래 표를 다시 가중한 값이며 실제 배포 성능이나 분포 이동 후 재현율 유지의 증거는 아니다.

미검토 사례는 정확도 분모에서 사라졌다고 숨기지 않는다. 별도 100장 중 확정 80장에 정답 72장이면 확정 부분 정확도는 0.9, 라벨 검토 비율은 0.8이다. 나머지 20장의 정답 여부에 아무 정보가 없으면 전체 100장의 정확도는 0.72부터 0.92 사이일 수 있다. 미검토를 모두 틀림 또는 모두 맞음으로 단정하지 않는다.

검토자 일치는 라벨 타당성과 다른 관찰이다. 별도 20장에서 두 검토자가 각각 T를 18번, C를 2번 선택하고, 둘 다 T인 경우 16장, 서로 다른 경우가 각 2장, 둘 다 C인 경우 0장이라고 하자. 관측 일치율은 0.8이다. 두 검토자의 주변 선택 비중을 고정하고 독립 선택을 가정한 기준 일치율은 0.9²+0.1²=0.82다. 높은 다수 선택이 일치를 쉽게 만들 수 있으며 이 계산은 실제 검토자 독립성이나 정답을 증명하지 않는다.

먼저 확인할 개념
  • 클래스별 재현율과 라벨 기준

    앞 본문의 전체/클래스별 평가·미검토·검토자 일치의 한계를 두 예측기와 목표 비중에 적용한다.

  • 평가 대상과 분할 목적

    앞 본문의 분할 목적·대상수와 실제 평가 범위를 목표 환경 가중치의 가정에 연결한다.

무엇을 예측하는 자료인가

같은 영상도 한 장의 문서 종류를 고르는 분류, 글자 영역 상자를 찾는 검출, 글자 픽셀을 구분하는 분할의 라벨은 다르다. 먼저 예측 대상·라벨 단위·허용 범주를 정하고 기준 버전을 기록한다.

자체 분류 자료는 스스로 그린 삼각형/원이다. 겹친 그림은 하나의 주된 도형만 고를지 복수 라벨을 허용할지 합의가 필요하다. 모호함을 억지로 정답 하나로 숨기지 않고 검토 상태로 남기는 자체 정책을 둔다.

수집 비중이 평가를 바꾼다

가상 100 장의 삼각형 90/원 10 에서 항상 삼각형이면 전체 정확도 90%다. 그러나 원의 재현율은 0/10=0,삼각형은 90/90=1 이다. 두 클래스 재현율 단순 평균은.5 로 전체.9 와 다르다.

비율을 늘리는 표본추출이나 가중 손실은 서로 다른 개입이다. 평가 자료를 실제 목표 분포와 다르게 균형화하면 그 평가가 무엇을 대표하는지 보고한다. 표가 균형이라고 실제 라벨 오류·촬영 환경 차이가 없어지는 것은 아니다.

라벨 품질을 확인할 경로

원저자 datasheet 는 라벨·단위·수집/검증·분포·오류를 기록하도록 질문한다. 자체 정책은 기준 예시/모호 사례/독립 검토와 변경 이력을 남긴다. 두 사람이 일치한 것만으로 진실이나 공정성을 확정하지 않는다.

실제 사람의 사진·민감정보를 모으는 활동은 이 단원에 없다. 자료를 사용한다면 출처·제공 조건·목적과 처리 범위를 따로 확인해야 한다. 여기서는 직접 그린 가상 도형 표로 이론만 계산한다.

중간 과정을 따라가는 예제

항상 삼각형인 예측기를 100 장(삼각형 90/원 10)과 별도 균형 20 장(각 10)에 평가하라.

  1. 첫 표는 90 정답/100=.9 다. 클래스 재현율 삼각형 1/원 0 이다.

  2. 균형 표는 10 정답/20=.5 다. 같은 예측기라도 평가 비중이 달라 전체가 바뀐다.

  3. 양쪽 클래스 재현율 평균은(1+0)/2=.5 로 같고 실제 원 분류 능력은 개선되지 않았다.

전체 90%/50%,클래스 재현율 1/0,평균 50%.

조건을 바꾸어 비교하기

평가 비중이 바꾸는 순위

P/Q를 90:10 표와 별도 30:70 목표 비중에서 비교하라.

  1. 기존 P는 81+2=83장, Q는 63+9=72장을 맞혀 P가 앞선다.

  2. 고정 재현율 조건에서 P는 0.3×0.9+0.7×0.2=0.41, Q는 0.3×0.7+0.7×0.9=0.84라 Q가 앞선다.

동일한 클래스별 성능이어도 집계 목적과 비중에 따라 순위가 달라진다.

비교할 점

새 환경에서 클래스별 성능 유지까지 시험한 것으로 보고하지 않는다.

확정 부분과 전체의 가능한 범위

별도 100장 중 확정 80장에 72정답, 미검토 20장이면 보고할 값과 범위를 쓰라.

  1. 확정 정확도는 72/80=0.9이고 검토 비율은 80/100=0.8이다.

  2. 미검토 정답 수 k는 0부터 20이라 전체 정확도는 (72+k)/100, 즉 [0.72,0.92]다.

부분 지표와 검토 비율·불확정 전체 범위를 함께 보고한다.

비교할 점

미검토 제외 뒤의 90%를 전체 100장 평가값으로 덮지 않는다.

종이와 본문으로 직접 해보기

원 10 장 중 2 장은 겹친 도형으로 미검토다. 확정된 원 8 장만으로 재현율을 보고할 때 분모와 제외 기록은?

힌트 보기

미검토를 자동 오답/정답으로 두지 않는다.

풀이 보기

확정 원에 대한 0/8=0 이며 2 장은 미검토로 따로 적는다. 전체 10 장을 모두 확정 평가했다고 보고하지 않는다.

오해와 반례

전체 정확도 90%면 모든 클래스에 좋은 모형이며 라벨 일치는 진실의 증명이다.

항상 삼각형은 원을 하나도 찾지 못한다. 같은 잘못된 기준을 공유하면 사람 둘이 일치해도 라벨 타당성 검토가 필요하다.

연습 1 · 값과 상태 예측

목표 T 비중을 p, C 비중을 1−p로 둘 때 고정 재현율의 P와 Q가 동률인 p를 구하라.

힌트 1

P는 0.2+0.7p다.

힌트 2

Q는 0.9−0.2p다.

풀이와 답 확인

  1. 0.2+0.7p=0.9−0.2p에서 p=7/9다.

  2. p가 7/9보다 크면 P, 작으면 Q가 앞선다. 이 범위는 클래스별 재현율 고정 조건 아래다.

목표 비중의 경계는 7/9다.

흔한 오답에서 다시 생각하기

표에서 P가 전체 1등이므로 모든 p에서 P가 앞선다.

집계 가중치는 목표를 바꾸며 이 예에는 명시적인 순위 교차가 있다.

연습 2 · 오류 찾아 고치기

미검토 20장을 모두 오답으로 적어 정확도 72%를 확정 결과라고 보고했다. 수정을 쓰라.

힌트 1

72%는 가능한 최솟값이다.

힌트 2

검토 비율과 부분 정확도를 별도로 남긴다.

풀이와 답 확인

  1. 확정 80장의 정확도 90%, 검토 비율 80%라고 기록한다.

  2. 전체는 72%부터 92%의 가능한 범위이며 현재는 정확한 값 미확정이다.

최악 가정의 하한과 실제 확정 평가를 구별한다.

흔한 오답에서 다시 생각하기

안전하게 낮은 값을 쓰면 그것이 측정 정확도다.

보수적인 가정도 가정으로 표시해야 측정과 구별된다.

연습 3 · 직접 만들어 보기

20장 검토자 표에서 관측 일치율과 주변 비중 독립 기준을 계산하고 라벨 타당성 보고를 설계하라.

힌트 1

일치는 대각선 16+0이다.

힌트 2

각 검토자의 T 비중은 18/20이다.

풀이와 답 확인

  1. 관측 일치는 16/20=0.8이다. 주변 선택을 독립으로 합성한 기준은 0.82다.

  2. 기준 버전·불일치 4장의 재검토 경로·외부 근거를 남긴다. 관측 일치율을 정답 비율로 변환하지 않는다.

독립 기준 0.82와 관측 0.8은 다른 계산이며 진실 검증이 아니다.

흔한 오답에서 다시 생각하기

80% 일치했으니 라벨 80%가 참이다.

같은 잘못된 기준이나 다수 선택은 일치를 만들 수 있고 실제 정답은 이 표에 없다.

연습 4 · 선택 심화

선택 심화는 기본 연습 뒤 더 탐구하고 싶을 때 풀어 보세요.

두 검토자가 별도 20장 모두 T로 일치했고 독립 외부 기준에서는 그중 4장이 C라고 알려졌다. 일치율·각 검토자의 외부 정확도·두 클래스 재현율을 구하라.

힌트 1

외부 기준은 T 16장, C 4장이다.

힌트 2

일치와 외부 기준 정답의 분모를 나눈다.

풀이와 답 확인

  1. 검토자끼리 일치는 20/20=1이다. 각 외부 정확도는 16/20=0.8이다.

  2. T 재현율은 1, C 재현율은 0이다. 완전 일치해도 기준 타당성은 실패할 수 있다.

일치 100%가 정확도 100%를 보장하지 않는다.

흔한 오답에서 다시 생각하기

둘이 완전히 일치하면 외부 C 기준이 틀렸다.

일치는 두 출력의 관계이며 외부 기준을 반박하는 독립 근거가 아니다.

소단원 6.2

증강과 전처리

사진을 뒤집으면 상자와 이름도 같이 바꿔야 할까?

준비 개념과 학습 목표

준비 개념

  • 전처리는 모형 입력 표현을 만드는 변환, 증강은 학습 예의 변형이다.

  • 상자 XYXY 는 좌상단/우하단의 연속 좌표이며 픽셀 인덱스와 다른 규약이다.

학습 목표

  • 변환과 목표 라벨의 일관성을 확인한다.

  • 학습 전처리 통계와 평가 규약을 구별한다.

crop과 반전 순서를 바꾸어도 같은 대상이 남을까?

연속 XYXY 상자와 경계를 쓰며 픽셀 인덱스는 사용하지 않는다. 원본 canvas는 폭 12, 높이 8이고 상자 A=[1,1,9,7]의 면적은 48이다. 자체 crop는 원래 또는 현재 canvas의 x=7에서 폭 4, y=0에서 높이 8인 창을 남긴다. crop는 원점 이동과 경계 clipping을 함께 수행한다.

crop 후 새 폭 4에서 반전하면 A의 crop 상자는 [0,1,2,7], 면적 12이고 반전 뒤 [2,1,4,7]이다. 원래 면적 대비 유지 비율은 1/4이다. 반대로 원본 폭 12에서 먼저 반전하면 [3,1,11,7]이고 같은 숫자의 crop 창을 쓰면 [0,1,4,7], 면적 24가 남아 비율 1/2다. 두 순서는 서로 다른 물리 부분을 선택한다.

자체 라벨 정책은 유지 면적 비율이 1/2 이상인 상자만 유지한다. 따라서 첫 순서는 A를 버리고 둘째는 A를 유지한다. 이 문턱은 출처 API의 기본 정책이 아니라 직접 정한 교육 규약이다. clipping 뒤 양의 폭·높이와 라벨 배열 정렬도 별도로 검사한다. 숫자 분류에서 crop나 반전이 클래스 뜻을 바꾸면 이름 유지 가정부터 재검토한다.

Torchvision v2는 입력 타입에 따라 공동 변환하며 일반 문자열·정수는 그대로 전달할 수 있다. 파일 경로가 그대로 남는 것과 상자/라벨이 의미상 맞는 것은 다르다. 삭제한 상자의 라벨도 같은 mask로 제외해야 한다. 실제 TVTensor·이미지 변환·모형은 실행하지 않았으며 아래 표는 연속 좌표 손계산이다.

먼저 확인할 개념
  • 연속 좌표 반전과 crop

    앞 본문의 W−x·원점 이동·clipping·라벨 공동 변환을 순서와 삭제 정책에 적용한다.

  • 과제별 라벨 단위

    앞 본문의 분류/검출/분할 목표 구별과 모호 사례 정책을 상자 삭제와 클래스 뜻에 연결한다.

유효한 변형인지 과제에서 판단한다

분류 증강은 이름이 유지되는 변형이라는 가정을 확인한다. 회전한 삼각형은 같은 도형일 수 있지만 글자 6 을 180 도 돌려 9 처럼 만들면 기존 숫자 라벨 유지가 틀릴 수 있다. 모든 과제에 같은 변환을 적용하지 않는다.

검출/분할의 기하 변환은 영상과 상자·마스크를 함께 바꿔야 한다. Torchvision 공식 v2 는 이 공동 변환을 지원하지만 입력 타입과 좌표 규약을 알아야 한다. 문서 기능이 모든 자기 자료의 라벨 일관성을 자동 증명하지 않는다.

좌표를 종이에서 바꾼다

폭 W 의 연속 좌표를 수평 반전하면 x′=W−x 다. 상자[x1,y1,x2,y2]는[W−x2,y1,W−x1,y2]가 된다. 좌/우 순서를 뒤집어 다시 정렬하며 픽셀 인덱스의 W−1−i 와 구별한다.

원점 기준 크기 두 배 변환은 x/y 와 상자 모든 좌표를 2 배 한다. 잘라내기는 새 원점 빼기·경계 clipping 과 사라진 대상 처리 정책이 필요하다. 단순 클래스 이름 유지와 위치 라벨 갱신은 별개다.

학습과 평가에서 같은 표현을 쓴다

자체 한 채널 정규화 z=(x−μ)/σ,σ>0 에서 μ/σ를 자료로 추정하면 학습 부분만 사용한다. 검증/최종평가에도 같은 추정값을 적용하며 평가에서 새 평균을 다시 fit 하지 않는다.

학습의 무작위 증강은 목적과 난수 규약을 기록한다. 평가의 결정적 크기/스케일 규약을 고정하고 실제 성능은 별도 실행으로 확인한다. 지금은 실제 영상을 변환하거나 모형을 학습하지 않았다.

연습 4 · 선택 심화

선택 심화는 기본 연습 뒤 더 탐구하고 싶을 때 풀어 보세요.

정규화 z=(x−μ)/σ에서 x와 학습 μ,σ에 동일한 양의 a와 offset b를 적용하면 z가 유지됨을 증명하라. σ=0과 a<0도 구별하라.

힌트 1

x′=ax+b, μ′=aμ+b, σ′=aσ는 a>0에서 성립한다.

힌트 2

표준편차는 비음수다.

풀이와 답 확인

  1. a>0,σ>0이면 (x′−μ′)/σ′=a(x−μ)/(aσ)=z다.

  2. σ=0이면 나눗셈 정책이 별도로 필요하다. a<0에서 실제 표준편차는 |a|σ라 z′=−z이며 같은 결론을 쓸 수 없다.

좌표/단위 변환의 조건과 상수 채널을 명시한다.

흔한 오답에서 다시 생각하기

모든 비영 a에 σ′=aσ를 써도 된다.

음의 a는 음의 표준편차를 만들므로 정의에 맞지 않는다.

준비 개념과 학습 목표

준비 개념

  • 학습은 모수 추정, 검증은 설정 선택, 최종 test 는 선택 뒤 평가다.

  • 누수는 예측 때 없을 정보를 학습/선택에 사용하는 것이다.

학습 목표

  • 원본·변형·촬영 그룹으로 누수 경로를 추적한다.

  • 출처와 분할·전처리 기록을 작성한다.

직접 같은 파일이 아니어도 연결 경로로 누수할까?

자체 관계표의 파일은 A1, B1, B2, C1, D1, D2, E1의 7개다. 출처 관계 A↔B, B↔C와 D 내부 관계를 지정한다. 새 대상 독립 평가를 위한 자체 정책은 이 관계의 연결 성분을 한 분할에 둔다. A와 C의 바이트가 다르고 직접 관계가 없어도 B를 통해 이어져 같은 성분이다. 이는 모든 실제 자료에서 무조건 같은 grouping을 쓰라는 규칙이 아니라 지정 평가 목적의 정책이다.

성분은 {A,B,C}, {D}, {E}의 3개다. 파일은 각 성분에 4개, 2개, 1개가 있다. 학습에 A1, B1, B2를 두고 최종평가에 C1을 두면 직접 A–C 관계만 보는 검사는 놓치지만 B–C 관계가 분할을 건너간다. 예로 학습 {A1,B1,B2,C1}, 검증 {D1,D2}, 최종평가 {E1}은 각 분할의 파일 수가 4개, 2개, 1개이고 연결 성분은 각각 1개다. 파일 수의 균형·클래스 균형·독립 대상 수는 다르다.

그룹별 fold를 만들어도 전처리는 각 학습 fold에서 따로 fit해야 한다. 별도 숫자 자료의 학습 fold는 [0,2], 보류 값은 10이다. 학습 평균 1로 중심화하면 보류 값은 9다. 전체 평균 4를 먼저 추정해 모든 fold에 쓰면 6이 되어 보류 값이 변환에 들어간다. 그룹 분리만으로 이 누수는 막히지 않는다.

성분 3개를 3개의 nonempty test fold에 한 번씩 넣을 수 있지만 4개 fold에 모두 넣을 수는 없다. 공식 GroupKFold도 고유 그룹 수가 fold 수 이상이어야 한다고 명시한다. 파일명이나 hash가 다른 것을 그룹 독립성으로 쓰지 않고 출처·관계·시간·라벨 기준·분할 버전을 기록한다. 실제 수집·분할 API·학습·법적 판단은 수행하지 않는다.

먼저 확인할 개념
  • 원본·변형 그룹과 fit 범위

    앞 본문의 서로 다른 파일과 같은 그룹·학습만 fit을 연결 성분 및 fold별 전처리에 적용한다.

  • 추정 통계와 평가 변환

    앞 본문의 학습 μ/σ와 평가에서 같은 표현을 사용한다는 조건을 각 fold의 학습 범위에 연결한다.

비슷한 자료의 연결을 먼저 적는다

복사본/압축본/같은 영상의 프레임은 서로 다른 파일이어도 강하게 연결된다. 배포 목표가 새 촬영 대상이면 동일 대상 그룹을 여러 분할에 나누는 평가가 목표와 어긋날 수 있다. 분할 단위를 파일/대상/시간 중 목적에 맞게 정한다.

자체 표는 원본 A,변형 A′,원본 B,같은 촬영 B′,원본 C,원본 D 의 6 파일이다. A/A′와 B/B′를 그룹으로 묶는 자체 규약을 사용한다. 정확 hash 만 같음과 눈으로 비슷함은 다른 검사라 hash 다름을 독립성 증거로 쓰지 않는다.

분할 전에 준비한 통계도 누수다

학습 값 2/4 에서 평균 3 을 추정해 최종 값 10 을 변환하면 중심화 결과 7 이다. 전체 2/4/10 평균 16/3 을 사용하면 최종값 14/3 으로 달라져 평가값이 변환 기준에 영향을 줬다. 라벨을 쓰지 않은 평균도 누수 가능성을 확인한다.

먼저 분할하고 학습만 fit 한 변환을 평가에 transform 한다. pipeline 은 이런 절차를 묶지만 동일 인물/프레임의 그룹 누출까지 자동으로 고치지는 않는다. 설정 선택에 test 를 반복 읽는 문제도 따로 막는다.

출처와 변형 이력을 보존한다

원본 ID·생성 방식·촬영 그룹·자료 버전·라벨 기준·분할 목적을 기록한다. datasheet 의 출처/이용조건/중복·권장분할 질문은 누락 정보를 드러내는 틀이지 모든 자료 사용 허용의 증명은 아니다.

공개 다운로드 가능성과 재배포/학습 허용은 같은 뜻으로 단정하지 않는다. 실제 외부 사진을 수집하거나 법적 적합성을 판정한 활동은 없다. 가상 관계표로 설계를 검토하고 미확인은 미확인으로 남긴다.

P는 T를 81장, C를 2장 맞히고, Q는 T를 63장, C를 9장 맞힌다. 전체 정확도와 클래스별 재현율의 평균을 비교하라. 클래스별 재현율을 고정하고 T의 비중이 0.3인 목표 정확도로 재가중하라. 별도 100장에서는 확정된 80장 중 정답이 72장이고 나머지 20장은 미검토다. 전체 정확도의 가능한 범위를 적어라. ② 폭이 12, 높이가 8인 영상의 상자 A=[1,1,9,7]에 crop와 반전을 두 순서로 적용한다. crop 창은 연산 당시 x=7부터 폭 4, y=0부터 높이 8이다. 원래 면적의 1/2 이상이 남아야 유지하는 자체 정책의 결과를 구하라. ③ 파일 A1, B1, B2, C1, D1, D2, E1에서 관계 A↔B↔C와 D 내부 관계의 연결 성분을 함께 묶는다. 학습 파일을 4개, 검증 파일을 2개, 최종평가 파일을 1개 배정하는 예와 각 성분 수를 보고하라. 비어 있지 않은 4개 그룹 fold를 만들 수 있는지도 판단하라. 별도 학습 값 [0,2]에서 추정한 평균으로 보류 값 10을 중심화하라.

힌트 1

클래스별 재현율을 먼저 구하고 평가 비중을 곱한다. 미검토 정답 수는 0부터 20까지다.

힌트 2

crop와 반전은 연산 당시 canvas를 쓰며 연결 성분은 경로까지 포함한다. 각 학습 fold에서만 fit한다.

풀이와 답 확인

  1. P 전체는 0.83, Q는 0.72다. 클래스 평균은 P가 0.55, Q가 0.8이고 목표 재가중은 P가 0.41, Q가 0.84다. 목표 값은 재현율 고정 가정의 계산이다. 별도 확정 부분은 0.9, 검토 비율은 0.8이고 전체 가능한 정확도는 [0.72,0.92]다.

  2. A의 원래 면적은 48이다. crop 후 반전한 상자는 [2,1,4,7]이며 면적은 12다. 원래 면적의 1/4만 남아 제외한다. 반전 후 crop한 상자는 [0,1,4,7]이며 면적은 24다. 원래 면적의 1/2이 남아 유지한다. 라벨에도 동일한 유지 mask를 적용한다. x=4는 상자의 경계이며 픽셀 인덱스가 아니다.

  3. 학습에는 {A1,B1,B2,C1}, 검증에는 {D1,D2}, 최종평가에는 {E1}을 둔다. 파일 수는 각각 4개, 2개, 1개이고 연결 성분 수는 각 분할에 1개씩이다. 전체 성분이 3개이므로 비어 있지 않은 4개 그룹 fold의 조건을 충족하지 못한다.

  4. 별도 학습 값 [0,2]의 평균은 1이고 보류 값 10의 중심화 결과는 9다. 전체 평균 4를 사용한 결과 6에는 보류 정보가 들어간다. 실제 영상·라벨 검토·분할 API·학습·학생 수행은 없다.

기존 전체 정확도에서는 P가 앞서지만 클래스별 재현율의 평균과 지정 목표 재가중에서는 Q가 앞선다. 미검토를 포함한 전체 정확도는 72%부터 92% 사이이며 정확한 값은 미확정이다. crop 후 반전은 A를 제외하고 반전 후 crop는 유지 비율 1/2의 경계에서 A를 유지한다. 학습·검증·최종평가 파일은 각각 4개, 2개, 1개지만 성분은 각각 1개다. 비어 있지 않은 4개 그룹 fold는 불가능하다. 학습 평균 1을 사용한 보류 값의 중심화 결과는 9다.
