픽셀의 겉보기 이동을 연결한다

Optical flow는 두 영상 사이의 겉보기 이동 벡터다. 물체의 움직임뿐 아니라 카메라 회전·이동도 영향을 준다. 각 벡터는 영상 평면의 이동이며 깊이와 카메라 보정 정보 없이 그 값을 바로 m/s의 실제 3D 속도로 읽지 않는다.

이 소단원에서 u,v는 프레임 간 시간 간격을 1로 정했을 때의 가로·세로 픽셀 변위다. 실제 시간 간격 Δt를 쓰면 변위를 Δt로 나눠 픽셀/초를 얻는다. 영상 좌표 y가 아래로 증가하는지 등 좌표 규약도 함께 기록한다.

밝기 일정과 작은 이동을 가정한다

대응점 밝기가 같다는 I(x,y,t)=I(x+u,y+v,t+1)을 작은 이동의 일차 Taylor 근사로 선형화하면 Ix u+Iy v+It≈0이다. 밝기 일정은 조명 변화·가림·반사에서 깨질 수 있다. 근사식 하나에는 u,v 두 미지수가 있어서 픽셀 하나만으로 일반적으로 결정되지 않는다.

이웃 패치의 이동이 같다는 가정 아래 여러 픽셀의 식을 모아 최소제곱으로 푼다. A의 각 행이 [Ix,Iy], b의 각 원소가 −It이면 A[u,v]ᵀ≈b다. AᵀA가 가역이어야 두 방향을 유일하게 구할 수 있고, 작게 변화하는 방향에서는 잡음에 민감하다.

모서리와 경계는 서로 다르게 보인다

한 방향의 직선 경계만 보이면 그 경계에 평행한 이동을 구분하기 어렵다. 이것이 aperture problem, 즉 창 문제다. 서로 다른 방향의 기울기가 있는 모서리는 두 성분을 구하는 데 도움이 된다. 아무 무늬가 없는 패치도 정보가 부족하다.

큰 이동을 낮은 해상도에서 작게 만든 뒤 세밀하게 보정하는 피라미드 방법이 있다. 그래도 가림이나 잘못된 밝기 가정을 자동 해결하는 것은 아니다. OpenCV의 점 상태가 1이어도 실제 같은 물리 점이라는 완전한 증명은 아니다. 희소 특징점 이동과 모든 픽셀의 밀집 이동도 구별한다.

중간 과정을 따라가는 예제

한 패치의 두 기울기 행은 [2,0], [0,3]이고 It는 각각 −2,−6이다. 같은 이동을 가정해 u,v를 구하고, 행이 [2,0],[4,0]으로 바뀌면 무엇이 달라지는가?

  1. 처음 식은 2u−2=0, 3v−6=0이다. 따라서 u=1, v=2 픽셀/프레임이다.

  2. AᵀA=diag(4,9)는 rank 2여서 두 방향을 구분한다. 두 식에 1,2를 대입하면 잔차가 모두 0이다.

  3. 대체 패치의 It를 −2,−4로 주면 두 식 모두 u=1만 요구한다.

  4. AᵀA=diag(20,0)는 rank 1이고 v는 어떤 값이어도 식을 만족한다. v=0을 답으로 출력해도 참 이동이라고 입증할 수 없다.

  5. 처음 프레임 간 시간이 .1초면 변위 (1,2)는 (10,20)픽셀/초다. 실제 m/s는 아직 알 수 없다.

정보가 두 방향이면 (u,v)=(1,2), 기울기가 한 방향뿐이면 u만 결정되고 v는 미정이다.

탐지는 현재 박스이고 추적은 시간의 연결이다

탐지기는 한 프레임의 박스·종류·신뢰도를 준다. 추적기는 이전 상태를 예측하고 현재 탐지와 연결해 ID를 유지한다. 같은 프레임에 박스가 두 개 있다는 사실만으로 다음 프레임의 두 박스가 누구인지 결정되지는 않는다.

기본 tracking-by-detection 흐름은 탐지, 기존 상태의 다음 시각 예측, 대응 비용 계산, 일대일 할당, 대응한 상태 보정, 미대응 탐지의 새 트랙과 오래 미대응한 트랙의 삭제다. 미대응 트랙의 예측값은 관측된 사실과 구별해 표시한다.

예측에는 시간과 불확실성을 넣는다

단순한 일정 속도 모델은 p예측=p이전+vΔt다. 관측이 들어오면 오차와 불확실성으로 상태를 보정할 수 있다. 아래 스칼라 위치 계산은 Kalman 보정의 한 요소를 단순화한 예이며 완전한 박스 추적 구현이 아니다.

SORT 원문은 박스의 위치·크기와 Kalman 예측, IoU 기반 연관을 결합한다. 관측을 놓친 동안 예측만 계속하면 오차가 커질 수 있으므로 트랙 생성·확인·삭제 정책이 필요하다. 원문이 사용한 특정 수명 숫자를 모든 영상의 정답으로 고정하지 않는다.

일대일 연관은 각 행의 최솟값 선택과 다르다

IoU=교집합 면적/합집합 면적이다. 대응 비용은 예를 들어 1−IoU로 만들 수 있지만 공간 거리나 외형 특징을 조합할 수도 있다. 같은 탐지를 두 트랙에 중복 연결하지 않는 전체 할당 문제로 풀어야 한다.

아무리 전체 비용이 낮아도 기하적으로 불가능한 대응은 gate로 배제한다. 대응 없는 선택도 허용해야 한다. 단순 greedy가 처음 좋은 쌍을 고르면 다음 쌍이 매우 나빠질 수 있다. 아래 2×2 비교는 전체 할당의 의미를 보여주며 실제 Hungarian 프로그램을 실행한 결과가 아니다.

중간 과정을 따라가는 예제

트랙 중심 p=10픽셀, 속도 v=2픽셀/초, Δt=2초다. 예측 위치에 관측 z=16을 스칼라 이득 K=.25로 보정하라. 별도 대응 비용 C=[[.10,.20],[.11,.90]]에서 두 일대일 할당의 총 비용을 비교하라.

  1. 위치 예측은 10+2·2=14다. 보정은 14+.25(16−14)=14.5다. 관측에 무조건 맞추지 않고 예측과 관측을 섞는다.

  2. K=.25는 예측 위치 분산 P=4, 관측 잡음 분산 R=12인 스칼라 모델에서 P/(P+R)=4/16으로 얻을 수 있다. 이 경우 보정 분산은 (1−K)P=3이다.

  3. 행은 트랙 T1,T2, 열은 탐지 D1,D2다. 주어진 C는 자체 가상 비용이며 IoU로부터 계산했다고 가정하지 않는다.

  4. T1→D1, T2→D2는 .10+.90=1.00이다. T1→D2, T2→D1은 .20+.11=.31이다.

  5. 가장 작은 .10을 먼저 고르는 greedy보다 교차 할당의 전체 비용이 작다. 비용이 모두 허용된다는 조건에서 교차 할당을 선택한다.

예측 14, 보정 14.5이며 두 할당 중 교차 비용 .31이 작다. 스칼라 불확실성 모델과 할당 허용 조건을 기록한다.

가림은 사라짐과 같지 않다

한 개체가 가려져 탐지가 없어도 장면을 떠났다고 단정할 수 없다. 상태를 잠시 예측하며 외형 특징과 움직임으로 재연결할 수 있다. 반대로 오래 남겨둔 잘못된 트랙은 새 개체를 과거 ID로 연결할 수 있어 수명 정책의 절충이 생긴다.

Deep SORT 원문은 외형 특징과 움직임 gate를 사용해 연관하고 최근 관측 트랙을 먼저 처리하는 cascade를 제안한다. 비슷한 외형·카메라 이동·긴 가림에서 완벽한 재식별을 보장하지 않는다. 특징 유사도는 특정 사람의 신원 확정과 동일한 주장도 아니다.

누락·오탐·번호 전환을 각각 기록한다

정답에 있는데 대응 출력이 없으면 FN, 정답과 대응되지 않은 출력이면 FP다. 같은 정답 궤적이 이전에 대응한 추적 ID와 다른 ID에 대응하면 ID switch를 센다. 추적기가 쓰는 연관과 평가기가 정답에 연결하는 대응은 서로 다른 과정이다.

정답 박스 수 GT>0에서 MOTA=1−(FN+FP+IDSW)/GT다. 프레임마다 정답이 여러 개면 GT는 프레임 수가 아닌 정답 개체 관측 수의 합이다. 오탐이나 ID 오류가 많으면 MOTA가 음수일 수도 있다. 평가 gate·제외 영역·가림 정답 규약을 일관되게 적용한다.

IDF1은 전체 궤적의 ID 대응을 본다

IDF1=2IDTP/(2IDTP+IDFN+IDFP)다. IDTP 등은 전체 정답 궤적과 예측 궤적을 전역 일대일로 연결해 계산하므로 매 프레임의 일반 TP·FN·FP를 그대로 넣지 않는다. 한 정답의 시간 앞부분과 뒷부분이 다른 예측 ID로 나뉘면 이 차이가 드러난다.

아래 가상 표는 모든 올바른 위치의 박스가 평가 gate를 통과하고 다른 개체/오탐과의 교차 대응은 불가라고 가정한다. 실제 벤치마크·TrackEval 실행 결과가 아니다. 점수 하나만 보지 말고 오류 수와 궤적 표를 함께 읽는다.

중간 과정을 따라가는 예제

정답 A,B가 3프레임 모두 있어 GT=6이다. 출력 대응은 f1:A→1,B→2; f2:A→1,B 누락, 오탐 9 하나; f3:A→3,B→2다. FN·FP·IDSW·MOTA와 전역 IDF1을 계산하라.

  1. 위치 대응 TP는 2+1+2=5다. FN=1, FP=1이며 예측 박스 총수도 6이다.

  2. A가 마지막에 1에서 3으로 바뀌어 IDSW=1이다. B는 놓침 뒤 같은 ID 2로 돌아와 이 표에서 IDSW를 추가하지 않는다.

  3. MOTA=1−(1+1+1)/6=1/2다. 위치 recall=5/6, precision=5/6이다.

  4. 전역 ID 대응에서 A는 ID 1의 두 관측과 연결하는 것이 ID 3의 한 관측보다 유리하다. B는 ID 2의 두 관측과 연결한다. 다른 ID 쌍은 대응할 수 없다는 가정이다.

  5. IDTP=2+2=4, IDFN=6−4=2, IDFP=6−4=2다. IDF1=8/(8+2+2)=2/3다.

  6. 위치 TP=5와 IDTP=4가 다르다. 같은 개체의 ID가 갈라졌기 때문이다.

FN=1, FP=1, IDSW=1, MOTA=1/2, IDF1=2/3다. 각 점수는 위치 gate와 전역 대응 규약 아래 계산한다.

오해와 반례

MOTA의 분모는 프레임 수이며 IDF1에는 프레임별 TP만 넣으면 된다.

MOTA의 분모는 정답 관측 수 합이고 IDF1은 전체 궤적의 전역 ID 대응 통계다. 같은 영상이라도 서로 다른 오류를 드러낸다.
