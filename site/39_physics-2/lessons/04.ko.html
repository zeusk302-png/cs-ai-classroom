소단원 4.1

전위차와 선적분

길게 돌아가면 전위차도 더 커질까?

준비 개념과 학습 목표

준비 개념

  • 전기장은 공간의 각 점에 붙인 힘/전하 벡터다.

  • 선적분은 경로의 짧은 이동과 장의 내적을 더한다.

  • 이 단원은 시간에 따라 변하지 않는 정전기장과 고정된 원천 전하를 가정한다.

학습 목표

  • 전위차의 부호·기준점·단위를 설명한다.

  • 경로의 내적을 구간별로 계산한다.

  • 전기장 일과 외부 일의 조건을 구별한다.

각 구간이 큰 일을 해도 합은 작을 수 있을까요?

여러 지출과 환불을 합칠 때 총액은 이동 횟수와 다르다. 장의 선적분도 구간의 방향을 포함한 부호 장부다. 정전기장·고정 원천·영향이 작은 시험 전하를 가정하고 실제 전하를 이동시키지 않는다.

비균일 가상 장 E=(2x,−3)에서 x,y는 m이며 x성분 계수는 2 V/m², y성분은 −3 V/m다. ΔV=−∫E·dl, ΔU=qΔV, W_E=−ΔU를 차례로 사용한다. 외부 일은 운동에너지까지 함께 기록한다.

  • 전기장의 전위 관계

    V=−x²+3y에 계수 단위를 붙여 gradient를 대조한다.

전하 한 개당 에너지

전위 V 는 기준에 상대적인 스칼라다. 같은 환경에서 시험 전하 q 를 A 에서 B 로 옮길 때 ΔU=q(V_B−V_A)이다. 전위차의 단위는 J/C 인 volt 다. q 는 부호를 포함하며 양전하와 음전하의 에너지 변화가 서로 반대일 수 있다. 시험 전하는 원천의 배치를 바꾸지 않을 만큼 작다고 가정한다.

기준점의 전위를 0 으로 정하는 것은 숫자 표의 원점을 고르는 일이다. 모든 점에 같은 상수 C 를 더해도 V_B−V_A 는 바뀌지 않는다. 반면 서로 다른 기준으로 작성된 두 표의 수를 바로 빼면 의미 없는 결과를 얻을 수 있다. 높은 전위는 큰 전기장이나 큰 총 에너지를 뜻하지 않는다.

경로 방향을 포함한 적분

정전기장에서 V_B−V_A=−∫_A^B E·dl 이다. 짧은 이동 dl 과 장이 같은 방향이면 내적이 양수여서 전위는 내려간다. 수직 이동에서는 내적이 0 이다. 단순히 경로 길이를 곱하는 것은 균일장이며 이동 방향을 고려한 특수 경우일 뿐이다.

보존장에서는 동일한 두 끝점의 적분이 경로와 무관하다. 정전기장이라는 가정은 이 보장을 준다. 시간에 따라 변하는 자기장이 만드는 유도 전기장 등에는 일반적으로 단일 스칼라 전위 차만으로 전체 전기장 선적분을 설명할 수 없다. 여기서는 그러한 시간 의존 상황을 계산하지 않는다.

일과 에너지의 부호 장부

전기장이 한 일 W_E=q∫E·dl=−ΔU 이다. 외력이 전하를 아주 천천히 옮겨 운동에너지 변화가 0 이고 다른 비보존 일이 없다면 W_ext=ΔU 다. 실제 가속하는 상황에서 외부 일을 무조건 ΔU 라고 적으면 운동에너지 항을 빠뜨린다.

전위차가 0 인 이동에서도 전기력이 각 순간 존재할 수 있다. 장에 수직인 경로에서는 일을 하지 않을 뿐이다. 되돌아오는 폐곡선의 순일이 0 이라는 것과 어느 점에도 장이 없다는 것은 다른 주장이다. 이동 방향·시험 전하 부호·준정적 조건을 계산 옆에 함께 적자.

중간 과정을 따라가는 예제

균일장 E=(4,−2) V/m 이다. A=(0,0)m, B=(3,1)m 을 직선 또는 (3,0)을 거치는 꺾인 길로 이동한다. q=−2 μC 의 ΔU 와 전기장 일을 구하라.

  1. 직선에서 전체 변위는 (3,1)m 이고 균일장 내적은 4×3−2×1=10 V 다.

  2. 따라서 V_B−V_A=−10 V 다. 기준을 V_A=7 V 로 택하면 V_B=−3 V 지만 차는 같다.

  3. 꺾인 길의 첫 수평 구간 적분은 12 V, 다음 수직 구간 적분은−2 V 이다. 합 10 V 로 직선과 같다.

  4. 음전하 q=−2×10^−6 C 를 곱하면 ΔU=20×10^−6 J=20 μJ 다.

  5. 전기장 일은−20 μJ 다. 준정적으로 외력이 옮겼다는 추가 조건이 있으면 외부 일은+20 μJ 다.

두 경로의 ΔV 는−10 V, ΔU 는+20 μJ, W_E 는−20 μJ 다. 총 경로 길이 차이는 결과를 바꾸지 않는다.

전기장의 전위 관계

전위 지도만으로 전기장의 화살표를 그릴 수 있을까?

준비 개념과 학습 목표

준비 개념

  • 편미분은 다른 좌표를 고정하고 한 좌표 방향의 변화율을 구한다.

  • gradient ∇V 는 각 편미분을 모은 벡터다.

  • 미분가능한 정전기 전위를 Cartesian 좌표에서 다룬다.

학습 목표

  • E=−∇V 의 방향과 성분 단위를 구한다.

  • 전위의 상수와 변화율을 구별한다.

  • 국소 영 전기장과 주변 전기장을 분리한다.

같은 고도를 가진 지도에서 경사도 같을까요?

지도 높이 하나와 주변 경사는 다른 정보다. 가상 다항식 V=5 V+(2 V/m²)xy−(1 V/m²)y²를 사용하여 좌표별 변화율을 구한다. 실제 원천 배치나 장비 지도가 아닌 미분 연습이다.

E=−∇V에서 E_x=−(2 V/m²)y, E_y=−(2 V/m²)x+(2 V/m²)y다. 장 벡터와 등전위 접선을 내적으로 대조하며 영 장점에서는 방향을 정하지 않는다.

    좌표별 편미분·계수 단위와 전위 기준을 사용한다.

  • 전위 분포 측정

    국소 미분값과 유한 간격의 근사를 비교한다.

차이를 좁히면 기울기가 된다

x 방향의 짧은 이동에서는 ΔV≈−E_x Δx 이다. 간격을 0 으로 줄인 극한에서 E_x=−∂V/∂x 를 얻고 y,z 성분도 같은 방식이다. 전기장 벡터는−∇V 이며 변화율을 뒤집는 음수가 핵심이다. V 가 미분가능한 점에서만 이 미분 표현을 바로 적용한다.

전위는 하나의 숫자지만 그 숫자의 주변 변화는 여러 방향을 갖는다. 높이가 같은 두 지도라도 더 촘촘히 변하는 지도는 더 큰 장을 만들 수 있다. 한 점의 V 값만으로 세 성분을 알아낼 수 없고 이웃의 변화 정보가 필요하다.

등전위와 수직 방향

매끄러운 등전위 곡선 또는 면을 따라 V 가 일정하면 접선방향 미분은 0 이다. ∇V 와 접선의 내적도 0 이므로 ∇V≠0 인 곳에서 장은 등전위면의 법선이다. 장의 방향은 그 두 법선 중 낮은 V 쪽이다. 장이 0 이면 방향 자체가 없어 수직 화살표를 유일하게 정할 수 없다.

이 관계는 음전하의 힘 방향과 구별한다. 전기장 방향은 양의 시험 전하 기준이고 실제 힘은 qE 다. 같은 지도에서 양전하와 음전하는 서로 반대 힘을 받는다. 전위가 높은 쪽을 향하는 음전하의 힘도 E=−∇V 와 모순되지 않는다.

상수 이동과 임계점

V 에 상수 C 를 더하면 모든 편미분이 같아서 E 는 바뀌지 않는다. V=0 인 점이라도 기울기는 0 이 아닐 수 있다. 반대로 V 가 10 V 인 일정한 영역이면 E 는 0 이다. 값과 기울기를 별개로 검사하면 잘못된 직관을 피한다.

∇V=0 인 한 점은 국소 전기장 0 을 의미하지만 주변 전체의 장 0 이나 안정평형을 보장하지 않는다. 평형의 안정성에는 전하 부호와 여러 방향의 에너지 변화를 봐야 한다. 이 단원은 가상 다항식 전위의 미분만 계산하며 물리적 원천 전하를 실제 구성하거나 평형 실험을 하지 않는다.

소단원 4.3

전하계의 위치에너지

세 전하의 에너지를 세 전위에 곱해 더하면 될까?

준비 개념과 학습 목표

준비 개념

  • 점전하 사이 거리는 양수이며 서로 겹치지 않는다.

  • 여기서는 진공의 정전기 Coulomb 모형과 k≈9.0×10^9 N m²/C²를 사용한다.

  • 무한히 분리된 배치의 상호작용 에너지를 0 으로 택하며 점전하 자기 에너지는 포함하지 않는다.

학습 목표

  • 서로 다른 쌍을 한 번씩 합한다.

  • 외부 원천 속 시험 전하와 전체 전하계의 에너지를 구별한다.

  • 전하 부호·거리·단위를 포함해 조립 일을 구한다.

한 쌍의 관계를 양쪽 장부에 적으면 몇 번 센 것일까요?

두 사람 사이 거래를 두 사람의 장부에서 모두 합하면 같은 거래가 중복될 수 있다. 점전하 쌍의 상호작용도 서로 다른 쌍을 한 번씩 세는 것이 핵심이다. 진공 k=9×10⁹ N·m²/C², 무한 분리 기준 U=0, 서로 겹치지 않는 점전하를 가정한다.

q₁=+2 nC는 x=0 m, q₂=−1 nC는 x=2 m, q₃=+3 nC는 x=5 m다. 자기 에너지는 포함하지 않으며 준정적 조립의 외부 일과 전체 쌍합을 대조한다. 실제 조립 장치는 사용하지 않는다.

먼저 확인할 개념
  • 전하계의 위치에너지

    서로 다른 쌍 한 번·외부 시험 전하 추가·자기 전위 제외를 사용한다.

  • 전위차와 선적분

    보존 힘과 외부 일·준정적 조건을 에너지 장부에 연결한다.

한 쌍부터 조립하기

고정한 q₁ 근처 r 거리에 q₂를 아주 천천히 가져오면 상호작용 에너지는 kq₁q₂/r 이다. 같은 부호면 양수, 다른 부호면 음수다. 이것은 두 전하의 관계에 속하는 에너지이지 한쪽에만 독점적으로 붙는 숫자가 아니다. 기준은 두 전하를 무한히 멀리 분리했을 때 0 이다.

r 은 두 위치의 직선거리이며 0 일 때 점전하 모형의 식이 특이해진다. 에너지가 음수라고 에너지 보존이 깨지는 것은 아니다. 기준보다 낮은 배치라는 뜻이고 분리하려면 외부 일을 가해야 할 수 있다. 실제 전하의 유한 크기/내부 에너지는 이 상호작용 모형 밖이다.

세 번째를 가져오면 두 쌍이 늘어난다

q₁,q₂가 이미 놓여 있으면 q₃가 보는 원천 전위는 V₃=kq₁/r₁₃+kq₂/r₂₃이다. q₃를 가져오는 에너지 증가는 q₃V₃이다. 처음 q₂를 가져온 kq₁q₂/r₁₂와 더하면 세 쌍 12/13/23 이 정확히 한 번 나타난다.

따라서 N 전하의 에너지는 U=Σ_{i<j} kq_iq_j/r_ij 이다. 원천들이 배치 과정 내내 지정된 자리에 고정되고 외부가 준정적으로 일을 한다는 조건 아래 최종값은 조립 순서와 무관하다. 움직이는 전하의 운동에너지까지 자동 포함한 식은 아니다.

전위 합에서 이중 계산 찾기

각 i 에서 자기 전하를 제외한 전위 V_other(i)를 계산해 Σq_iV_other(i)를 만들면 쌍 ij 가 i 항과 j 항에 두 번 나타난다. 전체 에너지는 그 합의 절반이다. 자기 전위를 넣으면 점전하 위치의 발산을 함께 넣는 잘못을 범한다.

전위 분포 측정

측정표의 작은 흔들림을 미분하면 어떤 일이 생길까?

준비 개념과 학습 목표

준비 개념

  • 모든 전위 읽기는 같은 기준점에 대한 차로 기록한다.

  • 이 소단원의 숫자는 가상 자료이며 실제 전압계·회로·장비 측정을 하지 않는다.

  • 표의 차분은 국소 기울기의 근사이지 연속 함수 전체를 결정하지 않는다.

학습 목표

  • 가상 측정 위치·기준·단위를 기록한다.

  • 중앙차분으로 장을 추정하고 부호를 해석한다.

  • 측정 오차 증폭과 공간 간격의 균형을 설명한다.

표의 두 끝값이 같으면 가운데 기울기도 0일까요?

두 위치의 높이만 알고 그 사이의 경사를 유일하게 정할 수는 없다. 같은 기준·정확한 좌표의 가상 전위표에서 차분을 만들고 읽기 오차·절단 오차·기준 드리프트를 따로 기록한다. 실제 전압계 연결이나 측정은 수행하지 않는다.

중앙차분 E≈−[V(x+h)−V(x−h)]/(2h)를 쓴다. 각 끝 읽기 오차가 절댓값 ε 이하면 기여 상한 ε/h다. |V‴|≤M인 매끄러운 구간의 절단 상한 Mh²/6을 더할 때만 이 가정 안의 총 경계를 말할 수 있다.

먼저 확인할 개념
  • 전위 분포 측정

    기준·위치 정확·차분 오차와 매끄러움 가정을 구별한다.

  • 전기장의 전위 관계

    유한 간격의 평균 변화율과 참 국소 미분값을 비교한다.

숫자에는 좌표와 기준이 붙는다

전위 분포 표에는 위치좌표, 길이 단위, 기준 위치/전위, 읽기 부호를 함께 기록한다. 같은 점도 기준을 바꾸면 읽는 숫자가 달라지므로 날짜가 다른 표를 비교할 때 기준부터 맞춘다. 실제 전압계는 두 단자의 차를 표시하며 순서를 뒤집으면 부호가 뒤집힌다.

종이에서는 이상적으로 장을 교란하지 않는 측정을 가정한다. 실제 장비의 입력저항, 접촉, 기준 드리프트, 위치 오차는 별도로 확인해야 한다. 본문 가상 표는 장비의 정확도나 안전한 실험 구성을 검증한 자료가 아니다. 설치나 실제 전기 연결 없이 좌표와 수를 분석한다.

차분과 등전위 지도

한 축의 x−h,x+h 에서 전위 값을 알고 있으면 E_x(x)≈−[V(x+h)−V(x−h)]/(2h)로 중앙차분을 만든다. 매끄러운 함수에서 h 가 충분히 작으면 국소 기울기에 접근하지만 유한 간격의 평균 변화율이다. 다른 축도 별도 측정값으로 계산해야 완전한 벡터를 얻는다.

여러 점에서 같은 전위를 연결하면 가상의 등전위선을 그릴 수 있다. 같은 ΔV 간격의 선들이 가까우면 보통 그 방향의 변화율이 크지만 선 간격을 비교하려면 같은 전위 간격과 실제 좌표축척이 필요하다. 각 점의 화살표는 낮은 전위쪽이며 장 0 의 임계점에서는 수직 방향을 하나로 확정하지 않는다.

작은 간격은 오차도 나눈다

각 전위 읽기의 오차가 절댓값≤ε이고 위치는 정확하다고 가정하면 두 값 차의 오차는≤2ε다. 분모 2h 로 나누므로 장 추정의 측정 오차 기여는≤ε/h 다. 더 작은 h 가 측정 오차를 무조건 줄이지 않는 이유다.

매끄러운 전위의 차분 절단 오차와 측정 잡음은 다른 원인이다. 세 번 미분가능하고 주변 |V‴|≤M 이면 중앙차분 기울기의 절단 오차는≤Mh²/6 이라는 Taylor 경계를 사용할 수 있다. 이를 ε/h 와 더하면 한쪽을 줄일 때 다른 쪽이 커지는 균형을 볼 수 있다. 위치오차·상관구조를 실제 조사하지 않았으므로 이 장부를 측정 불확실성 인증으로 표시하지 않는다.
