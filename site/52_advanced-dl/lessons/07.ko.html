소단원 7.1

가역변환

자료를 휘어 놓은 뒤 원래 위치를 하나로 되찾을 수 있을까?

준비 개념과 학습 목표

준비 개념

  • 역함수와 합성

  • 벡터의 좌표

학습 목표

  • 일대일 대응과 역변환을 확인한다.

  • coupling 전체와 내부 함수의 가역성을 구별한다.

미분이 모든 점에서 가역이면 전체 좌표도 하나로 복원되는가?

앞 본문의 단일 coupling에 두 번째 층을 붙인다. 모든 좌표는 실수이며 데이터에서 기본 좌표로 가는 A(u,v)=(u,3v+u²), B(a,b)=(2a+b,b)를 정의한다. F=B∘A는 A를 먼저, B를 나중에 적용한다. (1,2)는 A 뒤 (1,7), B 뒤 (9,7)이 된다. 두 층을 바꾼 A∘B에서는 같은 입력이 (4,22)가 되어 일반적으로 합성 순서를 바꾸지 못한다.

복원은 B부터 되돌린다. z=(z₁,z₂)에서 b=z₂, a=(z₁−z₂)/2를 구한 뒤 u=a, v=(b−a²)/3을 계산한다. 내부 shift u²의 역은 구하지 않는다. A의 scale 3과 B의 scale 2가 0이 아니며 모든 실수 출력에서 이 역을 정의할 수 있으므로 F는 전역 가역이다.

별도 반례 H(u,v)=(exp(u)cos(v),exp(u)sin(v))의 Jacobian determinant는 exp(2u)로 모든 실수 입력에서 양수다. 하지만 (0,0)과 (0,2π)는 모두 (1,0)으로 간다. 원점은 어느 입력에서도 출력되지 않는다. 점별 미분의 가역성은 국소 역을 뒷받침하지만 지정한 전체 영역의 일대일 대응과 전사성을 대신하지 않는다.

새 일반 coupling A_c(u,v)=(u,cv+u²)는 c가 음수여도 c≠0이면 전역 역을 가진다. exp(s)를 쓰는 원래 affine coupling 계열은 양의 scale만 만들므로 c=−3은 이 계열 밖의 별도 반전 예다. c=0에서는 v 정보가 사라진다. 모든 과제는 명시한 새 입력에서 독립 시작하며 실제 구현 복원 오차는 미측정이다.

방향과 영역을 먼저 정하기

이 단원은 데이터 x에서 기본 분포 좌표 z로 가는 f를 사용한다. 밀도평가는 z=f(x), 생성은 z를 뽑아 x=f^−1(z)다. 다른 책이 생성 방향을 T로 정의하면 식의 부호와 determinant 방향도 맞춰 바꾸어야 한다.

보통의 같은 차원 연속 흐름에서는 f와 역함수가 미분 가능한 일대일 대응을 요구한다. 좌표를 지우는 투영이나 부호를 잃는 제곱은 전체 실수 영역에서 그대로 가역 흐름이 아니다.

일부 좌표를 기준으로 변환하기

affine coupling은 z_1=x_1을 유지하고 z_2=exp(s(x_1))x_2+t(x_1)로 다른 부분을 바꾼다. 유지한 x_1을 역변환에서도 알고 scale이 0이 아니므로 x_2를 복원할 수 있다.

s와 t가 각각 가역이어야 하는 것은 아니다. 역변환은 이 함수의 역을 찾지 않고 알려진 x_1에서 다시 계산한다. 전체 coupling이 가역이라는 사실과 일반 임의 신경망 층의 가역성은 다르다.

합성과 표현의 제한 보기

가역 층을 합성하면 마지막 적용 층부터 거꾸로 되돌린다. 한 층이 유지한 좌표도 다른 층에서는 바꾸도록 분할이나 순서를 바꿀 수 있다.

0이 아닌 scale은 수학적 역을 주지만 아주 크거나 작은 scale은 수치 오차를 키울 수 있다. 이 예제의 정확 종이 복원과 실제 부동소수점 구현의 안정성은 별도로 검사해야 한다.

소단원 7.2

변수변환과 Jacobian

공간을 두 배로 늘렸는데 같은 밀도를 쓰면 전체 확률은 어떻게 될까?

준비 개념과 학습 목표

준비 개념

  • 밀도와 구간 확률

  • 미분과 determinant

학습 목표

  • 밀도와 확률 질량을 구별한다.

  • 방향에 맞는 절댓값 determinant를 계산한다.

두 번째 층의 부피 배율은 원래 좌표에서 계산해도 될까?

새 데이터→기본 변환 C(u,v)=(u,exp(u)v), D(a,b)=(exp(b)a,b), F=D∘C를 정의한다. 두 층은 R²에서 전역 가역이며 C⁻¹(a,b)=(a,exp(−a)b), D⁻¹(z)=(exp(−z₂)z₁,z₂)다. C의 determinant는 exp(u), D의 determinant는 exp(b)다. D의 b는 원래 v가 아니라 C가 만든 exp(u)v이다.

새 x=(ln 2,1)에서 C의 중간 좌표는 (ln 2,2)이고 최종 z는 (exp(2)ln 2,2)다. 첫 log-determinant는 ln 2, 둘째 값은 2이므로 총합은 ln 2+2이다. D를 원래 v=1에서 평가해 ln 2+1로 기록하면 중간 좌표를 잃는다.

기본 분포를 2차원 표준정규로 고정하면 log p_X(x)=−ln(2π)−[exp(4)(ln 2)²+4]/2+ln 2+2=−ln π−exp(4)(ln 2)²/2다. 이는 밀도 값이며 점 하나의 확률은 0이다. 생성 방향 F⁻¹의 log-determinant는 대응한 z에서 −ln 2−2다.

별도 1차원 생성 모형 Z~Uniform[0,1], X=1−Z/2는 지지집합 [1/2,1], 내부 밀도 2를 갖는다. [3/4,1]의 질량은 1/2이며 한 점의 확률과 다르다. 지지집합 밖 밀도 0을 생략하면 정규화된 분포를 쓰지 못한다.

    앞 본문의 곱/나눗셈과 지지집합을 비선형 두 층에 적용한다.

  • 합성의 중간 좌표

    유지 좌표를 다음 층의 실제 입력으로 전달한다.

질량 보존으로 밀도 바꾸기

연속 변수에서 점의 밀도 p(x)는 그 점을 정확히 뽑을 확률이 아니다. 작은 구간의 확률은 밀도×구간 길이로 근사하며 전체 적분은 1이다. 변환이 구간을 늘리면 같은 질량을 더 넓게 나누어야 한다.

생성 방향 x=g(z)일 때 p_X(x)=p_Z(z)/|det J_g(z)|, z=g^−1(x)다. 데이터→기본 f=g^−1이면 p_X(x)=p_Z(f(x))|det J_f(x)|로 쓴다. 방향을 확인하고 곱/나눗셈을 결정한다.

Jacobian은 작은 부피의 배율

D차원 Jacobian은 각 출력 좌표를 각 입력 좌표로 미분한 D×D 행렬이다. determinant 절댓값은 작은 부피 배율이며 음의 determinant는 방향 반전을 뜻할 뿐 음의 밀도를 만들지 않는다.

가역이고 양방향 미분 가능한 조건에서 이 식을 사용한다. 전체 일대일 대응이 아닌 x=z² 같은 변환은 여러 원상에 대한 별도 합산이 필요하므로 이 단원의 단일 역 식을 그대로 적용하지 않는다.

로그에서 변화량을 합치기

데이터→기본 방향은 ln p_X=ln p_Z(f(x))+ln|det J_f|다. 합성 층의 determinant는 곱이고 log-absolute-determinant는 각 층의 합이 된다. 각 Jacobian은 그 층에 실제 들어가는 중간 좌표에서 평가한다.

밀도를 정확히 쓸 수 있다는 말은 계산이 언제나 싸다는 뜻일까?

준비 개념과 학습 목표

준비 개념

학습 목표

전체 determinant가 1이면 복원 오차도 커지지 않을까?

부피 배율과 방향별 민감도를 별도 확인한다. 새 선형 데이터→기본 변환 L(x)=(2x₁,x₂/2)는 determinant 1이다. 역은 (z₁/2,2z₂)이며 유클리드 유도 2노름에서 L과 L⁻¹의 노름은 모두 2, 조건수는 4다. 부피를 보존해도 어떤 방향은 늘리고 다른 방향은 줄인다.

같은 크기 ε>0인 기본 좌표 교란을 비교한다. z 교란 (ε,0)은 복원 x에 (ε/2,0), 교란 (0,ε)은 (0,2ε)를 만든다. 두 복원 오차 노름은 네 배 차이다. 이는 정확 식의 민감도 분석이며 부동소수점 실험 결과가 아니다.

전체 log 배율이 0이어도 기본 밀도는 변환한 점에서 평가한다. Z~N(0,I₂), 새 x=(1,0)은 z=(2,0)이므로 log p_X=−ln(2π)−2다. 변환을 무시한 표준정규 x의 log 값은 −ln(2π)−1/2여서 다르다. determinant 항이 사라지는 것과 기본 분포 평가점이 그대로인 것은 다르다.

별도 비용 모형은 D=8, 층 수 K=3이다. 각 층의 조건 함수 평가를 100 U, 이미 얻은 네 scale의 log 집계를 4 U로 정의한다. 기본 밀도 평가는 8 U이고 층별 log 세 값을 합치는 비용은 2 U다. 한 점의 평가 비용은 3×(100+4)+8+2=322 U다. 여기 U는 자체 작업 단위이며 GPU 시간은 아니다. 역 함수의 존재만으로 일반 수치 역해법이나 전체 계산 비용을 이 값으로 정하지 않는다.

먼저 확인할 개념
  • determinant 집계와 전체 비용

    앞 본문의 O(D) 집계 대상에 조건 함수와 기본 밀도 비용을 추가한다.

  • 밀도 평가점과 부피 배율

    determinant 1이어도 변환된 좌표의 밀도를 사용한다.

밀도평가의 세 작업

데이터 x를 f로 기본 좌표 z에 보내고 p_Z(z)를 계산한 뒤 log|det J_f(x)|를 더한다. 이는 정의한 흐름 모델 안의 밀도평가다. 모델이 실제 자료 분포를 정확히 맞췄다는 뜻은 아니다.

샘플링은 기본 분포에서 z를 뽑고 f의 역을 적용한다. 평가 방향과 생성 방향의 비용이 구조에 따라 다를 수 있으므로 가역이라는 이유만으로 두 방향이 항상 같은 비용이라고 일반화하지 않는다.

삼각 구조로 determinant 줄이기

일반 조밀 D×D determinant의 표준 분해 비용은 O(D³) 수준이며 Jacobian 자체 생성 비용도 별도다. 삼각 구조라면 determinant는 대각 원소의 곱, log-absolute-determinant는 로그 절댓값의 합이라 O(D)로 계산할 수 있다.

affine coupling에서는 유지 좌표와 다른 좌표의 조건부 scale로 삼각 구조를 만든다. determinant를 싸게 구해도 s/t 신경망 평가·메모리·층 수·데이터 차원의 전체 비용은 남는다. O(D)라는 말의 대상은 이 determinant 집계다.

로그와 수치 안정성 읽기

많은 scale을 직접 곱하면 매우 크거나 작은 수가 되어 overflow/underflow가 생길 수 있다. 로그 합은 이를 완화하지만 신경망 출력·역계산의 다른 수치 문제까지 자동으로 없애지는 않는다.

정확 log-likelihood라는 표현은 수학적으로 다루기 쉬운 모델 밀도와 근사 적분 없이 계산 가능한 목적을 가리킨다. 실제 부동소수점의 무오차나 실제 데이터 생성의 완전한 진실성을 뜻하지 않는다.

determinant 곱과 로그 합을 계산하되 전체 비용과 구별한다.

풀이 보기

총 determinant는 1/2, 로그는 ln 2−ln 4=−ln 2≈−0.693147이다. 두 숫자만으로 신경망 평가 비용·메모리·역변환 비용은 알 수 없다.

오해와 반례

밀도평가가 exact이면 현실 자료에도 완벽하게 맞고 실행 오차도 없다.

정확 계산 가능한 것은 모델이 정의한 식이다. 분포 추정 오류와 부동소수점 오차는 별도로 남는다. 예제의 수학적 계산은 실제 학습·속도 측정 결과가 아니다.

힌트 1

합성은 마지막 층부터 복원하며 둘째 Jacobian은 중간 좌표에서 평가한다.

힌트 2

밀도는 변환한 z에서 평가하고 조건수는 두 유도 노름의 곱이다.

풀이와 답 확인

  1. ① A(2,−1)=(2,1), B(2,1)=(5,1)이다. B⁻¹은 (2,1), A⁻¹은 (2,−1)을 복원한다.

  2. ② C의 중간 좌표는 (ln 2,−2), 최종 z는 (exp(−2)ln 2,−2)다. 총 log 배율은 ln 2−2다. log p_X=−ln(2π)−[exp(−4)(ln 2)²+4]/2+ln 2−2=−ln π−4−exp(−4)(ln 2)²/2다.

  3. ③ determinant는 1이고 두 유도 노름은 3이므로 조건수는 9다. 역 좌표 교란은 (ε/3,0)과 (0,3ε)이며 오차 노름 비는 9다.

  4. 비용은 네 층의 416 U, 기본 밀도 8 U, 로그 합산 3 U를 더한 427 U다. 이 합은 앞의 수학적 조건수와 별도 모형이다.

F 출력은 (5,1)이다. 비선형 합성의 총 log 배율은 ln 2−2이며 밀도는 실제 z에서 평가한다. L₃의 부피 배율 1은 조건수 9와 양립한다. 네 층 자체 평가 비용은 427 U다.
