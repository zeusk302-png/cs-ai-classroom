소단원 6.1

generator·discriminator

새 표본을 만드는 모델과 그 출처를 구별하는 모델은 어떤 신호를 주고받을까?

준비 개념과 학습 목표

준비 개념

  • 확률 분포는 가능한 값에 비음수 확률을 부여하며 합은1이다.

  • G는 generator/생성자, D는 discriminator/판별자다. 서로 다른 매개변수를 갖는다.

학습 목표

  • 잠재 입력·생성 표본·출처 판별을 구별한다.

  • 한 모델 수정 때 다른 모델을 고정한다는 뜻을 설명한다.

두 모델의 입력과 출력

잠재 입력 z를 단순한 사전 분포에서 뽑아 G(z)를 데이터 공간으로 보낸다. D(x)는 x가 실제 데이터 쪽에서 왔다는 출처 점수다. 이 표준 GAN의 판별은 사물 종류나 진위에 대한 법적 인증이 아니다.

자체 z가1/2/3/4에 균등하고 데이터 공간이 L/R 두 기호라 하자. G가 세 z를L, 하나를R로 보내면 생성 분포(.75,.25)다. z의 종류가 많아도 G가 모두L로 보내면 출력은 하나뿐이다.

번갈아 수정하는 책임

D를 수정할 때는 실제 표본과 G가 만든 표본의 출처를 알려 주고 G 매개변수는 고정한다. G를 수정할 때는 D 매개변수를 고정하지만 D의 입력에 대한 미분을 통해 생성 결과를 바꾸는 신호를 전달한다. 고정은 미분 경로 전체를 끊는다는 뜻이 아니다.

G가 출력 x를 만들고 D가 x를 점수화하므로 연쇄법칙의 경로는 G→x→D다. G/D의 매개변수 집합을 같은 공유 가중치로 혼동하지 않는다. 실제 딥러닝 구현은 연속 미분 가능한 모형이 흔하고 아래 이산 표는 분포 이해용 종이 모델이다.

출처 점수의 해석 조건

실제와 생성 표본을 같은 비율로 공급하는 표준 목적에서 이상적 최적 D는 두 분포의 상대 비율을 반영한다. .5는 그 지점에서 출처를 구별할 근거가 같다는 뜻이며 실제 이미지가 항상 좋아졌다는 관측이 아니다.

학습이 부족한 D가 모든 입력에 .5를 내도 균형처럼 보인다. 데이터 권리·개인정보·원본 암기·새 표본 다양성은 별도 확인해야 하며 여기서는 자체 L/R 기호만 사용한다. 실제 데이터 수집과 생성은 없다.

중간 과정을 따라가는 예제

자체 실제 분포 L/R=(.75,.25), 균등 z1~4의 G가1/2/3→L,4→R이다. 생성 비율과 최적 D를 구하라.

  1. G의 L확률3/4=.75,R확률1/4=.25다.

  2. 두 분포가 같아 L에서 .75/(.75+.75)=.5다.

  3. R에서도 .25/(.25+.25)=.5다. 합이0인 지점은 이 계산의 대상이 아니다.

생성(.75,.25), 두 기호의 최적 D=.5다.

종이와 본문으로 직접 해보기

G가 z1~4를 전부L로 바꾸면 생성 분포와 최적 D(L/R)는?

힌트 보기

D*(x)=p_real(x)/(p_real(x)+p_G(x))를 양의 분모에서 쓴다.

풀이 보기

생성(1,0), D*(L)=.75/1.75=3/7, D*(R)=.25/.25=1이다. D가L에.5를 안 주는 것은 공급 분포가 다른 결과다.

오해와 반례

입력 noise가 다양하면 출력도 반드시 다양하고 D=.5면 학습 성공이다.

모든 z를L에 매핑하는 반례가 있다. 학습 안 된 상수 D=.5도 가능하므로 분포/조건/독립 평가를 함께 확인한다.

한 단계 더

소단원 6.2

minimax 목적

판별자는 키우고 생성자는 줄이는 목적을 하나의 식으로 쓸 수 있을까?

준비 개념과 학습 목표

준비 개념

  • ln은 자연로그이고 확률0의 로그는 유한 값이 아니다.

  • 기댓값은 표본 확률로 가중한 평균이다.

학습 목표

  • min_G max_D의 방향과 최적 D를 유도한다.

  • 비매개변수 이상적 결과와 실제 신경망 수렴을 구별한다.

부호와 방향을 먼저 쓴다

V(D,G)=E_real[ln D(x)]+E_z[ln(1−D(G(z)))]다. D는 실제에는 높은 점수, 생성에는 낮은 점수를 주어 V를 키운다. G는 두 번째 항을 줄여 D가 생성 표본에 높은 점수를 주게 한다. 첫 항은 G가 고정된 실제 데이터를 직접 바꾸는 항이 아니다.

D의 최소화 loss를 쓰면 L_D=−V로 부호를 바꾼다. 표준 minimax G의 loss는 E_z ln(1−D(G(z)))다. 두 모델에 똑같은 부호로 V 최소화를 시키면 다른 게임이다.

한 점의 최적 판별을 유도한다

한 기호에서 실제확률 p,생성확률 q이면 f(d)=p ln d+q ln(1−d)다. p,q>0에서 f′(d)=p/d−q/(1−d)=0을 풀어 d=p/(p+q)다. f″=−p/d²−q/(1−d)²<0이라 최댓값이다.

p=0,q>0이면 경계d=0,q=0,p>0이면d=1이 최적이며0확률 항은 극한으로 다룬다. p=q=0이면 목적에 영향을 안 주어 이 비율이 정의되지 않는다. 이 설명은 점별 자유로운 D를 허용한 이상적 경우다.

균형 값과 학습 보장을 나눈다

두 분포가 같고 양의 지지점이면 D*=.5다. V=ln.5+ln.5=−ln4다. 최적 D를 가정한 목적의 전역 최소라는 이론 결과는 충분한 분포 표현력 등 조건 아래다.

실제 제한된 신경망·유한 표본·번갈아 작은 수정은 항상 최적 D나 전역 균형을 만들지 않는다. 초기에 D가 생성에 매우 낮은 점수를 주면 minimax의 logit 경사 신호가 약할 수 있어 비포화 −ln D(G(z))를 최소화하는 대안을 구별한다.

중간 과정을 따라가는 예제

자체 실제p=(.75,.25),생성q=(.25,.75)의 최적 D와 V를 식으로 계산하라.

  1. D*(L)=.75/(.75+.25)=.75,R=.25다.

  2. 실제 기대항=.75ln.75+.25ln.25, 생성 기대항=.25ln.25+.75ln.75다.

  3. V=1.5ln.75+.5ln.25≈−1.12467이다. 일치 분포의−ln4≈−1.38629보다 크다.

D(.75,.25), V≈−1.12467이며 G는 최적 D 목적을 더 작게 만들 여지가 있다.

종이와 본문으로 직접 해보기

L의 d=.5에서 f′와 d=.75에서 f′를 계산하고 일치 분포 V를 확인하라.

힌트 보기

p=.75,q=.25를 각각 대입한다. 로그값을 평균하는 것과 확률을 평균하고 로그를 취하는 것은 다르다.

풀이 보기

d=.5면1.5−.5=1, d=.75면1−1=0이다. 일치 때 양쪽 기대항ln.5,합−ln4다.

오해와 반례

D의 분류 정확도가 높을수록 G도 성공하며 이론 정리가 모든 신경망의 수렴을 보장한다.

D가 생성 표본을 쉽게 가리면 현재 생성 분포와 차이가 클 수 있다. 전역 분포 이론의 조건을 실제 매개변수 최적화에 그대로 옮기지 않는다.

한 단계 더

소단원 6.3

mode collapse와 안정화

그럴듯한 한 종류만 계속 만들면 생성 분포를 배웠다고 할 수 있을까?

준비 개념과 학습 목표

준비 개념

  • mode는 분포에서 표본이 집중되는 영역이다. collapse는 여러 잠재 입력이 일부 출력으로 몰리는 현상이다.

  • 평균과 분산, 쌍 사이 절댓값 거리를 계산할 수 있다.

학습 목표

  • mode collapse를 품질·다양성과 구별한다.

  • 안정화 기법의 목적과 보장 한계를 손계산한다.

분포의 한 부분만 남는 실패

자체 실제 데이터가−2/+2에 각각.5다. G가 모든 입력을−2로 보내면 보기에는 실제 가능한 값이지만 +2영역을 하나도 만들지 않는다. 이 카드에서는 두 지지점 중 하나만 덮었다는1/2를 쓰며 실제 이미지 평가 지표라고 부르지 않는다.

실제 평균0/분산4, collapse 평균−2/분산0이다. 생성 다양성을 입력 noise의 종류 수나 D loss 하나로 대체하지 않는다. 표본의 질과 분포 범위는 함께 살펴야 한다.

한 통계량만 맞추는 반례

feature matching은 판별자의 중간 특징 통계가 실제/생성에서 비슷해지도록 생성 목표를 바꾸는 방법이다. 자체 특징 f(x)=x일 때 G가 항상0을 내면 실제 평균0과 같아 제곱차0이지만 실제 지지점−2/+2를 둘 다 놓친다.

특징을 f(x)=(x,x²)로 바꾸면 실제 기대(0,4), 항상0 생성은(0,0)이라 제곱거리16이다. 특징이 더 정보를 담으면 이 반례를 볼 수 있지만 유한 특징 매칭이 모든 분포 차이를 항상 잡는다는 보장은 없다.

배치 정보와 게임의 움직임

minibatch discrimination은 표본을 따로만 보지 않고 다른 생성 표본과의 유사성도 판별에 활용하려는 방법이다. 자체 두 표본 −2/+2의 쌍 거리는4,−2/−2는0이다. 실제 표본도 우연히 같은 모드를 두 번 뽑으면0이므로 한 배치를 증거 전부로 쓰지 않는다.

두 모델의 상호 수정은 한 고정 함수 최소화와 다르다. 작은 게임 min_x max_y xy의 동시 수정 x′=x−ηy,y′=y+ηx는 원점에서 멀어질 수 있다. 학습률·목적·표본·여러 seed 기록을 검토하되 어떤 기법도 여기서 실제 GAN 성공으로 검증하지 않았다.

중간 과정을 따라가는 예제

자체 실제{−2,+2}반반과 G가항상0일 때 f=x 및 f=(x,x²)의 평균 특징 loss를 계산하라.

  1. 실제 E[x]=0,E[x²]=4다. 생성은0/0이다.

  2. f=x만이면(0−0)²=0인데 지지점 겹침은 없다.

  3. 두 특징 제곱거리=(0−0)²+(4−0)²=16이다.

평균 하나의loss0은 분포 일치 증거가 아니며 두 특징loss16은 차이를 드러낸다.

종이와 본문으로 직접 해보기

같은 실제 분포에 G가항상−2이면 평균/분산/두 특징loss와 쌍 거리는?

힌트 보기

분산은E[x²]−E[x]², 특징 loss는 두 좌표 차이 제곱합이다.

풀이 보기
