소단원 6.1

generator·discriminator

새 표본을 만드는 모델과 그 출처를 구별하는 모델은 어떤 신호를 주고받을까?

준비 개념과 학습 목표

준비 개념

  • 확률 분포는 가능한 값에 비음수 확률을 부여하며 합은1이다.

  • G는 generator/생성자, D는 discriminator/판별자다. 서로 다른 매개변수를 갖는다.

학습 목표

  • 잠재 입력·생성 표본·출처 판별을 구별한다.

  • 한 모델 수정 때 다른 모델을 고정한다는 뜻을 설명한다.

판별 점수 0.5를 균형 기준으로 쓰려면 공급 비율도 같은가?

앞 본문은 실제와 생성 표본을 같은 비율로 공급하는 목적을 사용했다. 새 종이 모형은 먼저 출처 Y를 고른다. 0<α<1에서 실제 출처의 확률은 α이고 생성 출처의 확률은 1−α이다. 출처 안에서 기호 x를 뽑는 분포를 각각 p와 q라 한다. 이번 판별 목적은 αE_p[lnD]+(1−α)E_q[ln(1−D)]의 최대화다. 점별 가중치를 포함해 유도한 최적 D는 이 혼합 실험의 출처 사후확률 αp(x)/[αp(x)+(1−α)q(x)]이며 양의 분모에서만 정의한다. α가 달라지면 같은 두 분포라도 출처 점수는 달라진다.

새 입력은 α=4/5, 실제 L/R 확률 p=(1/2,1/2), 생성 확률 q=(3/4,1/4)이다. L의 실제 결합확률은 2/5, 생성 결합확률은 3/20이므로 최적 출처 점수는 8/11이다. R의 두 결합확률은 2/5와 1/20이므로 점수는 8/9다. 이 값들은 사물의 품질 등급이 아니라 지정한 출처 실험의 조건부 확률이다.

같은 α=4/5에서 두 분포가 같아지면 모든 양의 지지점의 최적 점수는 4/5다. 점수 1/2만 보고 분포 일치 여부를 판단하면 공급 비율을 놓친다. 반대로 최적화되지 않은 판별자가 상수 4/5를 내는 것만으로 분포 일치도 인증할 수 없다.

잠재 기호를 세는 비율도 입력 분포를 먼저 확인해야 한다. 별도 새 입력에서 z=1,2,3,4의 확률은 (1/10,2/10,3/10,4/10)이다. G가 1과 4를 L로, 2와 3을 R로 보낸다. L과 R의 생성 확률은 각각 1/2이지만 두 입력을 L로 보낸다는 개수 정보만으로는 이 값을 유도하지 않는다. 모든 예제와 과제는 명시한 새 상태에서 독립 시작한다.

먼저 확인할 개념
  • 출처 점수와 생성 분포

    같은 비율이라는 앞 본문의 조건을 바꾸고 잠재 입력의 확률 질량을 합한다.

  • 양의 분모의 최적 판별

    표준 점별 유도를 출처 혼합 비율을 포함한 목적에 적용한다.

두 모델의 입력과 출력

잠재 입력 z를 단순한 사전 분포에서 뽑아 G(z)를 데이터 공간으로 보낸다. D(x)는 x가 실제 데이터 쪽에서 왔다는 출처 점수다. 이 표준 GAN의 판별은 사물 종류나 진위에 대한 법적 인증이 아니다.

자체 z가1/2/3/4에 균등하고 데이터 공간이 L/R 두 기호라 하자. G가 세 z를L, 하나를R로 보내면 생성 분포(.75,.25)다. z의 종류가 많아도 G가 모두L로 보내면 출력은 하나뿐이다.

번갈아 수정하는 책임

D를 수정할 때는 실제 표본과 G가 만든 표본의 출처를 알려 주고 G 매개변수는 고정한다. G를 수정할 때는 D 매개변수를 고정하지만 D의 입력에 대한 미분을 통해 생성 결과를 바꾸는 신호를 전달한다. 고정은 미분 경로 전체를 끊는다는 뜻이 아니다.

G가 출력 x를 만들고 D가 x를 점수화하므로 연쇄법칙의 경로는 G→x→D다. G/D의 매개변수 집합을 같은 공유 가중치로 혼동하지 않는다. 실제 딥러닝 구현은 연속 미분 가능한 모형이 흔하고 아래 이산 표는 분포 이해용 종이 모델이다.

출처 점수의 해석 조건

실제와 생성 표본을 같은 비율로 공급하는 표준 목적에서 이상적 최적 D는 두 분포의 상대 비율을 반영한다. .5는 그 지점에서 출처를 구별할 근거가 같다는 뜻이며 실제 이미지가 항상 좋아졌다는 관측이 아니다.

학습이 부족한 D가 모든 입력에 .5를 내도 균형처럼 보인다. 데이터 권리·개인정보·원본 암기·새 표본 다양성은 별도 확인해야 하며 여기서는 자체 L/R 기호만 사용한다. 실제 데이터 수집과 생성은 없다.

중간 과정을 따라가는 예제

자체 실제 분포 L/R=(.75,.25), 균등 z1~4의 G가1/2/3→L,4→R이다. 생성 비율과 최적 D를 구하라.

  1. G의 L확률3/4=.75,R확률1/4=.25다.

  2. 두 분포가 같아 L에서 .75/(.75+.75)=.5다.

  3. R에서도 .25/(.25+.25)=.5다. 합이0인 지점은 이 계산의 대상이 아니다.

생성(.75,.25), 두 기호의 최적 D=.5다.

소단원 6.2

minimax 목적

판별자는 키우고 생성자는 줄이는 목적을 하나의 식으로 쓸 수 있을까?

준비 개념과 학습 목표

준비 개념

  • ln은 자연로그이고 확률0의 로그는 유한 값이 아니다.

  • 기댓값은 표본 확률로 가중한 평균이다.

학습 목표

  • min_G max_D의 방향과 최적 D를 유도한다.

  • 비매개변수 이상적 결과와 실제 신경망 수렴을 구별한다.

판별자 매개변수를 고정하면 생성자의 경사도 없어지는가?

앞 본문은 G 갱신 때 D의 매개변수를 고정하면서 입력 미분은 전달한다고 설명했다. 새 미분 가능한 종이 모형은 한 잠재 입력의 생성값 x=Gθ(z)=θ²와 D_w(x)=σ(wx)이다. σ(u)=1/(1+exp(−u))이며 G를 갱신하는 동안 w=−2를 고정한다. θ=1에서 x=1, u=−2이고 판별 점수를 δ=σ(−2)라 쓴다.

최소화하는 minimax 생성 항 ln(1−σ(u))의 u 미분은 −δ다. x에 대한 u 미분은 w=−2, θ에 대한 x 미분은 2θ=2다. 따라서 θ 미분은 4δ이다. 비포화 생성 항 −lnσ(u)의 u 미분은 δ−1이므로 같은 연쇄 경로의 θ 미분은 4(1−δ)다. 두 값의 부호는 모두 양수여서 작은 하강 갱신은 θ를 줄인다.

D 매개변수를 고정한다는 것은 w를 갱신하지 않는다는 뜻이다. x를 단순 상수로 취급해 G에서 D로 이어지는 경로를 끊으면 위 θ 미분을 0으로 잘못 바꾼다. 반대로 w까지 함께 갱신하면 고정 판별자를 통한 G 단계라는 이번 문제와 다른 계산이다.

별도 θ=0에서는 dx/dθ=0이라 두 목적의 θ 경사가 모두 0이다. 이 새 상태의 판별 점수는 σ(0)=1/2이고 비포화 logit 미분은 −1/2로 0이 아니어도 전체 경사는 0일 수 있다. 앞의 θ=±1에서 정의한 δ=σ(−2)와 이 새 점수를 구별한다. 강한 logit 신호가 모든 생성 매개변수에서 강한 경사를 보장한다는 주장을 피한다. 이 계산은 실제 autograd나 GAN 훈련을 실행한 결과가 아니다.

먼저 확인할 개념
  • 고정 매개변수와 입력 미분 경로

    G와 D의 별도 책임을 연쇄법칙 경로로 구체화한다.

  • minimax와 비포화 logit 신호

    목적의 부호와 전체 생성 경사를 분리한다.

부호와 방향을 먼저 쓴다

V(D,G)=E_real[ln D(x)]+E_z[ln(1−D(G(z)))]다. D는 실제에는 높은 점수, 생성에는 낮은 점수를 주어 V를 키운다. G는 두 번째 항을 줄여 D가 생성 표본에 높은 점수를 주게 한다. 첫 항은 G가 고정된 실제 데이터를 직접 바꾸는 항이 아니다.

D의 최소화 loss를 쓰면 L_D=−V로 부호를 바꾼다. 표준 minimax G의 loss는 E_z ln(1−D(G(z)))다. 두 모델에 똑같은 부호로 V 최소화를 시키면 다른 게임이다.

한 점의 최적 판별을 유도한다

한 기호에서 실제확률 p,생성확률 q이면 f(d)=p ln d+q ln(1−d)다. p,q>0에서 f′(d)=p/d−q/(1−d)=0을 풀어 d=p/(p+q)다. f″=−p/d²−q/(1−d)²<0이라 최댓값이다.

p=0,q>0이면 경계d=0,q=0,p>0이면d=1이 최적이며0확률 항은 극한으로 다룬다. p=q=0이면 목적에 영향을 안 주어 이 비율이 정의되지 않는다. 이 설명은 점별 자유로운 D를 허용한 이상적 경우다.

균형 값과 학습 보장을 나눈다

두 분포가 같고 양의 지지점이면 D*=.5다. V=ln.5+ln.5=−ln4다. 최적 D를 가정한 목적의 전역 최소라는 이론 결과는 충분한 분포 표현력 등 조건 아래다.

실제 제한된 신경망·유한 표본·번갈아 작은 수정은 항상 최적 D나 전역 균형을 만들지 않는다. 초기에 D가 생성에 매우 낮은 점수를 주면 minimax의 logit 경사 신호가 약할 수 있어 비포화 −ln D(G(z))를 최소화하는 대안을 구별한다.

소단원 6.3

mode collapse와 안정화

그럴듯한 한 종류만 계속 만들면 생성 분포를 배웠다고 할 수 있을까?

준비 개념과 학습 목표

준비 개념

  • mode는 분포에서 표본이 집중되는 영역이다. collapse는 여러 잠재 입력이 일부 출력으로 몰리는 현상이다.

  • 평균과 분산, 쌍 사이 절댓값 거리를 계산할 수 있다.

학습 목표

  • mode collapse를 품질·다양성과 구별한다.

  • 안정화 기법의 목적과 보장 한계를 손계산한다.

평균과 분산을 모두 맞추면 분포와 게임의 수렴도 같아지는가?

앞 본문은 평균 하나가 같아도 분포가 다를 수 있다고 설명했다. 새 실제 분포 P는 −1과 +1을 각각 1/2로 만든다. 새 생성 분포 Q는 −√2, 0, +√2를 각각 1/4, 1/2, 1/4로 만든다. 두 분포의 평균은 0이고 두 번째 모멘트와 분산은 1이다. 특징 f(x)=(x,x²)의 기대값도 (0,1)로 같지만 지지점은 하나도 겹치지 않는다.

네 번째 모멘트는 차이를 드러낸다. P에서는 x⁴=1이라 기대값이 1이고 Q에서는 양끝의 x⁴=4에 총확률 1/2가 붙어 기대값이 2다. 특징을 하나 더 쓰면 이 반례는 보이지만 유한 특징 집합이 모든 분포를 식별한다는 일반 보장은 따로 필요하다.

배치 판별도 표본 모형을 고정해야 한다. 각 분포에서 독립으로 두 번 뽑은 값이 같은 확률은 P에서 1/2이고 Q에서 (1/4)²+(1/2)²+(1/4)²=3/8이다. 따라서 서로 다른 확률은 각각 1/2와 5/8이다. 표본 두 개의 같음/다름은 확률적 관찰이며 한 번 같았다는 사실만으로 collapse를 확정하지 않는다.

게임 갱신의 계산 시점도 중요하다. 별도 min_x max_y xy 게임에서 η=1, 초기 (x,y)=(1,0)을 고정한다. 동시 갱신은 x′=x−y와 y′=y+x를 옛 값에서 함께 계산하여 (1,1), (0,2)를 얻는다. 순차 갱신은 먼저 x′=x−y, 뒤 y′=y+x′로 계산하여 (1,1), (0,1)를 얻는다. 순차 경우는 이어 (−1,0),(−1,−1),(0,−1),(1,0)으로 되돌아오므로 발산을 피했다고 원점 수렴을 인증하지 않는다. 이 작은 게임은 모든 GAN의 훈련 이력을 대신하는 정리가 아니다.

먼저 확인할 개념
  • 특징 통계와 작은 게임 반례

    평균 반례를 두 모멘트로 강화하고 갱신의 계산 시점을 바꾼다.

  • 이상적 목적과 실제 갱신의 조건

    최적 판별의 분포 정리와 유한 게임 궤적을 구별한다.

분포의 한 부분만 남는 실패

자체 실제 데이터가−2/+2에 각각.5다. G가 모든 입력을−2로 보내면 보기에는 실제 가능한 값이지만 +2영역을 하나도 만들지 않는다. 이 카드에서는 두 지지점 중 하나만 덮었다는1/2를 쓰며 실제 이미지 평가 지표라고 부르지 않는다.

실제 평균0/분산4, collapse 평균−2/분산0이다. 생성 다양성을 입력 noise의 종류 수나 D loss 하나로 대체하지 않는다. 표본의 질과 분포 범위는 함께 살펴야 한다.

한 통계량만 맞추는 반례

feature matching은 판별자의 중간 특징 통계가 실제/생성에서 비슷해지도록 생성 목표를 바꾸는 방법이다. 자체 특징 f(x)=x일 때 G가 항상0을 내면 실제 평균0과 같아 제곱차0이지만 실제 지지점−2/+2를 둘 다 놓친다.

특징을 f(x)=(x,x²)로 바꾸면 실제 기대(0,4), 항상0 생성은(0,0)이라 제곱거리16이다. 특징이 더 정보를 담으면 이 반례를 볼 수 있지만 유한 특징 매칭이 모든 분포 차이를 항상 잡는다는 보장은 없다.

배치 정보와 게임의 움직임

minibatch discrimination은 표본을 따로만 보지 않고 다른 생성 표본과의 유사성도 판별에 활용하려는 방법이다. 자체 두 표본 −2/+2의 쌍 거리는4,−2/−2는0이다. 실제 표본도 우연히 같은 모드를 두 번 뽑으면0이므로 한 배치를 증거 전부로 쓰지 않는다.

두 모델의 상호 수정은 한 고정 함수 최소화와 다르다. 작은 게임 min_x max_y xy의 동시 수정 x′=x−ηy,y′=y+ηx는 원점에서 멀어질 수 있다. 학습률·목적·표본·여러 seed 기록을 검토하되 어떤 기법도 여기서 실제 GAN 성공으로 검증하지 않았다.
