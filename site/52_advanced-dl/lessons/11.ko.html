소단원 11.1

데이터·모델병렬 개념

같은 모델을 두 장치에 복사하는 것과 하나의 모델을 두 장치로 나누는 것은 어떻게 다를까?

준비 개념과 학습 목표

준비 개념

  • 기울기와 SGD
  • 평균과 가중 평균
  • 계산 그래프

학습 목표

  • 데이터 병렬과 모델 병렬을 구별한다.
  • 조건에 맞는 전체 기울기를 계산한다.
  • 통신과 의존성이 속도를 제한함을 설명한다.

복제본에서 자료를 나누어 계산한다

데이터 병렬은 같은 모델의 복제본에 서로 다른 자료 부분을 보내 계산한다. 동기 방식에서는 기울기를 모아 공통 갱신을 만든다. 시작 파라미터와 optimizer 상태·규칙의 일치 같은 조건을 확인해야 같은 갱신 뒤 복제본이 맞는다.

각 장치가 같은 수의 표본에 대한 평균 손실 기울기를 구했다면 장치 기울기의 평균은 전체 표본 평균 기울기와 같다. 배치 크기나 손실 정규화가 다르면 단순 장치 평균이 원하는 목적의 기울기가 아닐 수 있다. 표본 수와 합/평균 규약을 먼저 적는다.

모델의 계산을 나눈다

모델 병렬은 모델의 파라미터나 연산을 나누는 방식이다. 층을 단계로 나누는 pipeline 병렬에서는 앞 단계의 출력이 다음 단계의 입력이 된다. 서로 다른 작은 배치가 여러 단계를 이용하도록 배치할 수 있다.

연산 하나의 텐서를 나누는 tensor 병렬과 층 단계를 나누는 방식은 다르며 데이터 병렬과 결합할 수도 있다. 단계 사이 활성값과 역전파 정보의 통신, 자료 의존성과 대기 시간이 생긴다. 모델이 한 장치에 안 들어간다는 이유와 계산 속도를 높이려는 이유를 구별한다.

장치 수만으로 가속을 약속하지 않는다

장치가 늘면 계산 일부가 나뉘어도 통신·자료 공급·부하 불균형이 남는다. 통신을 계산과 겹치는 방식도 있지만 항상 완전히 숨길 수 있는 것은 아니다. 메모리 비용, 처리량과 지연 시간을 별도로 관찰한다.

아래는 한 번의 종이 SGD와 가상 시간표다. 실제 GPU·네트워크·분산 프로세스를 실행하지 않았다. 최신 API의 세부 동작은 사용하는 버전의 문서를 확인해야 하며 파이프라인 공식 문서의 alpha 상태를 안정성 보증으로 바꾸지 않는다.

소단원 11.2

분포이동과 적대오류

새 병원의 영상에서 틀리는 것과 작은 입력 변화를 골라 틀리게 하는 것은 같은 평가일까?

준비 개념과 학습 목표

준비 개념

  • 훈련·평가 분리
  • 선형 분류 점수
  • 벡터 노름과 미분

학습 목표

  • 자연 분포 이동과 적대 교란을 구별한다.
  • 위협 조건과 선형 점수 변화를 계산한다.
  • 한 공격 실패와 강건성 인증을 구별한다.

어떤 자료에서 평가하는지 정한다

훈련과 다른 병원·카메라·시간·지역의 자료는 분포 이동을 만들 수 있다. 같은 무작위 분할에서 높은 정확도를 얻어도 이런 조건에 그대로 일반화한다는 보장은 없다. 평가 자료의 출처와 사용 가능한 정보를 먼저 적는다.

전체 평균 외에 조건별 성능과 최저 성능을 볼 수 있다. 집단 크기 가중 평균과 같은 가중 집단 평균은 다른 질문이다. 평가를 보고 모델을 계속 골랐다면 그 자료는 최종 독립 평가의 역할을 잃을 수 있다.

적대 교란에는 허용 범위가 있다

적대 예제는 정해진 목표와 제약 아래 입력 변화를 찾아 모델 오류를 유도하는 사례다. 최대 성분 크기 ||η||∞≤ε, Euclidean 크기 ||η||₂ 같은 노름과 입력 범위·접근 권한을 밝혀야 한다. 같은 숫자 ε라도 다른 노름이면 허용 집합이 다르다.

선형 점수 f(x)=wᵀx+b의 변화는 wᵀη다. 최대 성분 제약에서는 |wᵀη|≤εΣ|wᵢ|=ε||w||₁이다. 이는 모든 허용 교란에 대한 이 선형 모델의 식이며 임의 신경망에 그대로 적용하는 인증이 아니다.

공격과 보장을 구별한다

FGSM은 입력 손실을 국소적으로 선형화하여 η=ε sign(∇xJ) 방향을 쓰는 방법이다. 실제 입력 범위로 투영해야 하는 경우도 있고 목표형 공격의 방향은 목적 정의를 확인한다. 한 번의 계산이 비선형 손실의 전역 최악 교란을 찾는다고 보장하지 않는다.

공격을 찾아 예측이 바뀌면 그 위협 조건의 실패 증거다. 어떤 공격이 실패했다고 모든 허용 교란에서 안전한 것은 아니다. 자연 이동 평가, 공격 기반 평가와 수학적 인증의 조건을 나누어 기록한다. 실제 영상·모델 공격·방어 학습은 여기서 수행하지 않았다.

중간 과정을 따라가는 예제

양수 또는 0의 점수를 +, 음수를 −로 분류한다. x=(1/5,1/5), w=(1,−1), b=1/10이고 η=(−1/10,1/10)이다. 교란 전후 점수와 노름을 구하라.

  1. 원점수는 1/5−1/5+1/10=1/10이므로 +다.
  2. 점수 변화는 1×(−1/10)+(−1)×(1/10)=−1/5다. 새 점수는 −1/10이므로 −다.
  3. ||η||∞=1/10, ||η||₂=√2/10이다. 같은 교란이 두 노름에서 같은 숫자를 갖지는 않는다.

점수 1/10에서 −1/10으로 바뀌며 최대 성분 노름 1/10, Euclidean 노름 √2/10이다.

종이와 본문으로 직접 해보기

같은 선형 모델과 x에서 ||η||∞≤1/25이면 모든 허용 교란 뒤 점수의 하한은? 부호가 유지되는가?

힌트 보기

||w||₁=2다. 원점수에서 ε||w||₁을 뺀다.

풀이 보기

하한은 1/10−2/25=1/50>0이다. 이 선형 모델과 이 점 및 이 위협 집합에서는 모든 허용 교란의 + 분류가 유지된다. 자연 분포 이동이나 다른 모델의 인증은 아니다.

오해와 반례

FGSM 한 번이 실패했으므로 모든 작은 교란에서 강건하다.

한 탐색의 실패는 보편 명제가 아니다. 공격 방법과 제약을 밝히고 인증은 별도 수학적 근거를 요구한다.

소단원 11.3

일반화와 calibration

90%라고 말한 예측들 가운데 실제 정답이 절반이면 무엇을 점검해야 할까?

준비 개념과 학습 목표

준비 개념

  • 정확도와 확률
  • softmax와 로그
  • 가중 평균과 검증 자료

학습 목표

  • 정확도와 confidence calibration을 구별한다.
  • 구간별 ECE를 계산하고 한계를 설명한다.
  • temperature scaling의 순위 보존과 평가 조건을 확인한다.

맞힌 수와 말한 확신을 구별한다

정확도는 선택한 라벨을 맞힌 비율이다. Calibration은 예측이 말한 확률과 실제 정답 빈도의 대응을 묻는다. 최고 라벨의 confidence가 0.9인 사례들을 충분히 모았을 때 정답 비율도 약 0.9인지 살피는 질문은 전체 정확도와 다르다.

유한 표본의 빈도는 추정치다. 조건이나 집단이 바뀌면 대응도 달라질 수 있다. 전체가 잘 맞는 것처럼 보여도 특정 집단에서 어긋날 수 있으므로 표본 크기와 조건을 적는다. 높은 confidence를 사실의 출처나 안전 보증으로 바꾸지 않는다.

구간 차이를 가중 합한다

ECE는 confidence를 구간으로 묶고 구간의 평균 confidence와 정확도의 절댓값 차이에 그 구간 비중을 곱해 더하는 한 요약값이다. 같은 자료도 구간 수와 경계가 바뀌면 값이 달라질 수 있다. 빈 구간의 기여는 0으로 두며 평균을 0/0으로 계산하지 않는다.

작은 ECE 하나가 모든 개별 확률이나 모든 조건의 calibration을 인증하지 않는다. 절댓값 이전에 차이를 합하면 과신과 저신이 상쇄될 수 있어 같은 요약이 아니다. 정확도·분포 이동 성능·확률 평가를 각 목적에 맞게 구별한다.

temperature는 라벨 순위를 보존한다

Temperature scaling은 logits z를 양의 T로 나눈 뒤 softmax를 계산한다. T를 별도 검증 자료에서 NLL 같은 기준으로 맞추고 독립 자료에서 평가한다. T>0이면 logit 순위가 같아 동일한 동점 처리 아래 최고 라벨과 정확도는 유지된다.

확률은 바뀌므로 calibration을 개선할 수 있지만 항상 개선된다는 보장은 없다. 잘못된 라벨을 올바른 라벨로 순위 교환하는 방법도 아니다. 평가 자료로 T를 맞추고 그 자료 성능을 독립 결과라고 적지 않으며 아래 T 값은 사람이 정한 종이 사례다.

중간 과정을 따라가는 예제

고정한 두 구간의 자체 표에서 4개 예측은 모두 confidence 9/10이고 2개가 정답이다. 나머지 6개는 모두 confidence 3/5이고 3개가 정답이다. 정확도와 ECE를 구하라.

  1. 전체 정확도는 (2+3)/10=1/2다. 두 구간 정확도도 각각 2/4=1/2, 3/6=1/2다.
  2. 첫 차이는 9/10−1/2=2/5, 둘째 차이는 3/5−1/2=1/10이다.
  3. ECE=(4/10)×(2/5)+(6/10)×(1/10)=4/25+3/50=11/50=0.22다.

정확도 50%, 정한 구간의 ECE 0.22다. 표는 실제 모델 관측이 아니다.

종이와 본문으로 직접 해보기

두 logit이 (log 9,0)이다. T=1과 T=2의 첫 라벨 확률과 최고 라벨을 구하라.

힌트 보기

exp(log 9)=9이고 exp((log 9)/2)=3이다.

풀이 보기

T=1의 첫 확률은 9/(9+1)=9/10, T=2에서는 3/(3+1)=3/4다. 둘 다 첫 라벨이 최고다. 실제 정답 빈도를 모르므로 이 두 숫자만으로 개선을 선언하지 않는다.

오해와 반례

Calibration을 고치면 틀린 최고 라벨도 반드시 맞게 바뀐다.

양의 temperature scaling은 순위를 보존한다. 확률 대응과 라벨 정답은 다른 질문이며 모든 자료의 calibration 개선도 보장하지 않는다.

한 단계 더

평균 confidence는 (4×0.9+6×0.6)/10=0.72라서 전체 정확도와 차이는 0.22다. 이 표는 두 구간 모두 과신이라 ECE와 우연히 같다. 같은 크기 두 구간의 차이가 +0.2와 −0.2이면 전체 부호 있는 차이는 0이지만 ECE는 0.2다. 전체 차이만으로 구간 어긋남을 없다고 하지 않는다.
