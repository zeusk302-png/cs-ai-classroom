Python 프로그래밍
모든 학년의 관심 있는 학습자에게 열려 있는 과목이다.
현재: 전체 목차와 첫 단원 집필 설계. 강의 본문은 미작성.
단원별 쉬운 진입 → 본 이론 → 심화. 수학 정의와 증명을 유지한다.
설치 없이 읽고 계산·추적하는 활동을 기본으로 설계한다.
한국어 자료를 기준으로 작성하고 검토된 번역의 상태를 따로 표시한다.

- 비전공·대학 입문자의 첫 언어로 설계한다. 데이터분석 전문 라이브러리는 후속과목이며 여기서는 표준 라이브러리·파일·테스트 기반을 확보한다.

파일과 폴더:
index.html: 과목 안내와 전체 단원 목차
course.json: 과목·선수·언어·상태 메타데이터
01_outline.txt: 전체 단원과 세부 항목
02_content-plan.json: 첫 단원 구체적 집필 설계
units/01.json ...: 단원별 구조와 상태
lessons/: 집필할 강의 본문
examples/: 풀이 예제와 선택 코드
exercises/: 자기점검·힌트·해설
assets/: 자체 도표와 대체 설명
references/sources.json: 공개 참고자료와 확인 상태
