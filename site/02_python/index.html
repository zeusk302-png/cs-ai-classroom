준비개념

  • 문장 순서를 따라 읽기
  • 기본 사칙연산

시작 질문

x=x+3은 수학의 등식일까?

종이로 따라갈 예제

x=2; x=x+3; print(x)를 실행 없이 추적하고 출력 예측

입력과 중간 과정

x=2; x=x+3; print(x); 상태 2→5, 출력 5

대표적인 오해

대입의 =는 수학의 항등식이다
