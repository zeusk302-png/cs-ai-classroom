완료라는 단어의 경계를 독자가 직접 판정할 수 있나요?

이 연습에서는 문서 검토의 확인 완료를 자체 조작적 정의로 정합니다. 확인 완료는 지정한 원본 버전과 대상 버전이 같고, 필수 네 항목을 모두 대조해 일치하며, 그 결과와 확인 위치가 기록된 검토 상태입니다. 실제 제품이나 모든 기관의 표준 정의가 아니라 아래 카드의 분류 기준입니다.

상위 범주는 검토 상태이며 구별 기준은 버전 일치·필수 네 항목 일치·결과 기록입니다. 파일 이름이 보인다나 확인 버튼을 눌렀다는 예시만으로 이 세 조건을 대신할 수 없습니다. 정의를 어려운 동의어로 반복하지 말고 새 사례와 반례에 적용할 수 있게 씁니다.

범주와 경계를 먼저 정하기

정의는 어떤 대상을 같은 이름으로 부를지 정하는 기준이다. 상위 범주는 대상의 큰 종류이고 구별 기준은 그 안에서 해당 개념을 골라내는 특징이다. 이 글에서 캐시는 이후 접근 비용을 줄이려고 데이터나 계산 결과를 저장해 재사용하는 장치 또는 기법이라고 정한다.

그 정의만으로 모든 구현 세부사항을 알 수는 없다. 임시 저장과 캐시가 겹칠 수 있지만 단순히 잠깐 보관한다는 설명만으로 재사용 목적을 판별할 수 없다. 독자가 실제 사례에 기준을 적용할 수 있도록 목적과 경계를 드러낸다.

예시와 반례로 경계 점검하기

이미 계산한 값을 다시 쓰는 표는 캐시의 사례가 될 수 있다. 아직 처리하지 않은 작업을 순서대로 기다리게 하는 대기열은 저장이 있어도 그것만으로 캐시가 되지 않는다. 기능이 겹치는 시스템은 저장 내용이 어떤 목적으로 쓰이는지 따져야 한다.

예시 하나를 정의로 바꾸면 범위가 지나치게 좁아진다. 캐시가 반드시 웹 브라우저의 파일이라는 정의는 CPU의 데이터 캐시를 설명하지 못한다. 반대로 모든 저장 공간이라는 정의는 원본 보관용 저장소까지 무조건 포함한다.

독자의 언어로 일관되게 쓰기

새 용어를 처음 쓸 때 쉬운 정의를 붙이고 문서 내내 같은 이름을 유지한다. 여기서 비용은 돈에 한정되지 않고 시간·통신량 등 접근에 필요한 자원을 말한다. 원본과 복사본의 차이를 먼저 알면 캐시를 설명하기 쉽다.

정의의 범위가 문서별로 달라지면 이 글에서 어떤 뜻으로 쓰는지 밝힌다. 설계 문서의 조작적 정의는 측정과 분류를 위해 범위를 정한 것이며 세상 모든 사전의 유일한 정의라고 주장하지 않는다.

확인 완료 정의를 적용한 가상 카드
카드주어진 조건정의에 따른 판정

A

지정 버전이 아닌 구판 원본과 네 항목 일치, 결과와 위치 기록 있음

지정 버전이 아니므로 확인 완료가 아니다.

B

C

지정 버전 같음, 네 항목 일치, 결과·위치 기록 있음

확인 완료다.

D

버전 미확인, 네 항목 일치, 기록 있음

버전 조건을 판정할 자료가 부족하다. 확인 완료로 표시하지 않는다.

세 조건을 각각 확인하세요. D의 버전 미확인은 A의 구판 확인과 다른 상태이며 두 카드 모두 확인 완료로 표시할 수 없습니다.

중간 과정을 따라가는 예제

후보 A는 이전 계산값을 다음 요청에서 재사용한다. B는 처리 전 작업만 보관한다. 위 정의를 적용하라.

  1. A의 목적은 다음 접근에서 계산 반복을 줄이는 것이다.

  2. B의 목적은 처리 순서를 유지하는 것이며 결과 재사용은 제시되지 않았다.

A는 캐시 사례이고 B는 제공된 정보만으로 캐시라고 할 수 없다.

조건을 바꾸어 비교하기

과도하게 넓은 정의 수정

확인 완료는 검토 화면을 연 상태라는 정의를 위의 목적에 맞게 고치세요.

  1. 검토 화면 열기는 작업 시작 행동입니다.

  2. 버전·필수 항목·기록이 충족되는지는 아직 알 수 없습니다.

  3. 상위 범주와 세 기준을 포함해 다시 정의합니다.

이 연습의 확인 완료는 지정 원본 버전과 대상 버전이 같고 필수 네 항목이 모두 일치하며 결과와 확인 위치가 기록된 검토 상태다.

비교할 점

작업을 시작했다는 관측과 정의의 완료 조건은 다릅니다.

정의가 바뀌면 분류도 다시 하기

원래 C에서 결과 기록만 없다고 가정하면 완료인가요? 이후 정의를 기록 불필요로 바꾸면 무엇을 밝혀야 할까요?

  1. 원래 정의는 기록을 필수로 요구합니다.

  2. 따라서 기록 없는 C는 원래 기준에서 완료가 아닙니다.

  3. 기준을 바꾸면 새 정의와 적용 시점을 공개하고 다시 분류합니다.

원래 정의에서는 완료가 아니다. 기록 불필요라는 새 정의를 사용할 때는 기준 변경을 밝히고 새 기준의 분류로 구별한다.

비교할 점

같은 완료라는 이름을 쓰더라도 기준이 달라졌으면 같은 판정처럼 비교하면 안 됩니다.

연습 1 · 값과 상태 예측

A와 D가 모두 완료 표시 불가라면 상태도 같은가요?

힌트 1

A의 버전은 구판으로 확인되었습니다.

힌트 2

D의 버전은 알 수 없습니다.

풀이와 답 확인

  1. A는 지정 버전 불일치라고 적습니다.

  2. D는 버전 정보 부족이라고 적습니다.

같지 않습니다. A는 지정 버전 조건 위반이고 D는 그 조건이 미확인입니다. 원인과 후속 확인이 다릅니다.

흔한 오답에서 다시 생각하기

최종 표시가 같으면 이유도 같다.

표시 결과와 판정 이유를 함께 설명해야 후속 행동을 정할 수 있습니다.

연습 2 · 오류 찾아 고치기

확인 완료란 확인이 완료된 것이다라는 순환 정의를 고치세요.

힌트 1

정의할 용어를 다시 쓰기만 했는지 봅니다.

힌트 2

실제로 판정할 조건을 넣습니다.

풀이와 답 확인

  1. 검토 상태라는 범주를 씁니다.

  2. 지정 버전·필수 항목·기록이라는 기준을 적습니다.

확인 완료는 지정 버전의 필수 네 항목이 모두 일치하고 그 결과와 위치가 기록된 검토 상태다.

흔한 오답에서 다시 생각하기

문법적으로 자연스러우면 정의도 충분하다.

독자가 새 사례를 분류할 기준이 있어야 합니다.

연습 3 · 직접 만들어 보기

확인 완료가 아닌 새 반례 하나를 세 조건으로 설명하세요.

힌트 1

한 조건만 어기는 사례도 가능합니다.

힌트 2

실제로 수행한 기록이라고 쓰지 않습니다.

풀이와 답 확인

  1. 가상 E의 버전과 네 항목은 일치한다고 정합니다.

  2. 기록이 없다는 조건을 넣습니다.

  3. 원래 정의의 기록 조건을 위반했다고 설명합니다.

예: 가상 E는 지정 버전과 네 항목이 모두 일치하지만 결과 기록이 없다. 따라서 이 연습의 확인 완료가 아니다.

사례를 하나 만들면 모든 현실 문서에도 같은 정의가 적용된다.

연습 4 · 선택 심화

선택 심화는 기본 연습 뒤 더 탐구하고 싶을 때 풀어 보세요.

필수 항목을 네 개에서 다섯 개로 바꾸면 기존 C의 상태는 어떻게 되나요?

힌트 1

기존 C는 네 항목만 대조했습니다.

힌트 2

새 다섯째 항목의 자료가 있는지 묻습니다.

풀이와 답 확인

  1. 기준 변경을 기록합니다.

  2. 다섯째 항목 확인이 없으면 새 기준의 완료를 표시하지 않습니다.

  3. 새 확인 후에만 새 기준의 판정을 갱신합니다.

기존 기준의 완료 기록은 남기되 새 다섯 항목 기준에서는 추가 항목이 미확인입니다. 새 기준 완료라고 자동 표시하지 않습니다.

같은 안내에서 실패와 미확인의 다음 행동도 찾을 수 있나요?

여기서는 실제 파일을 복사하거나 제출하지 않고 종이 카드로 검토 안내를 작성합니다. 준비물은 지정 원본 버전 ID, 대상 버전 ID, 필수 네 항목의 값과 확인 위치, 기록할 카드입니다. 목표는 앞 소단원의 정의로 판정한 결과를 남기는 것입니다.

안내에는 시작 조건·행동·관찰·분기·완료 조건을 적습니다. 버전이 같지 않으면 지정 버전을 확보하는 경로로 돌아갑니다. 버전을 모르면 미확인으로 적고 정보를 확인합니다. 항목이 불일치하면 수정 후 다시 대조하며 완료 조건 확인은 필수입니다. 선택적인 제목 꾸미기는 확인을 대신하지 않습니다.

시작 조건과 목표

절차는 독자가 수행할 행동을 순서대로 안내하는 글이다. 목표와 준비물을 먼저 밝히면 독자가 중간에 멈추지 않고 따라갈 수 있다. 파일 복사라면 원본 위치, 대상 공간과 읽기 권한을 확인한다.

설치가 필요한 행동과 종이 활동을 섞지 않는다. 실제 컴퓨터를 쓰는 안내에서는 메뉴 이름과 적용 제품·버전을 밝히고, 이 소단원의 활동에서는 종이로 행동 순서만 점검한다.

한 단계의 행동과 관찰

번호는 시간 순서를 나타내고 각 단계는 구체적 동사로 시작한다. 파일을 선택하고 복사한 뒤 대상 폴더에 붙여넣는 순서를 설명한다. 대상에 같은 이름이 있다면 덮어쓰기 전에 원본 보존 여부를 확인하는 분기를 둔다.

행동 뒤에는 필요한 관찰을 붙인다. 대상에 파일 이름이 보인다는 것과 내용이 올바르다는 것은 다르므로 크기 또는 내용 확인 등 목적에 맞는 완료 기준을 쓴다. 중요한 실패 분기는 정상 순서 가까이에 제시한다.

완료와 복구를 분리

완료 기준은 독자가 목표 달성을 판단하는 조건이다. 복사 절차라면 원본을 지우지 않은 채 대상 파일을 열어 내용 확인을 할 수 있다. 오류 메시지가 나면 이를 성공으로 해석하지 않고 원인과 재시도 조건을 확인한다.

선택 단계는 선택이라고 표시한다. 필수 확인을 선택처럼 쓰면 독자가 생략할 수 있다. 여러 대체 방법이 있다면 처음부터 모두 섞기보다 독자에게 적절한 경로 하나를 제공하고 별도 절에 대안을 둔다.

질문이 기준을 정한다

비교하는 글은 둘 이상의 대상을 공통 기준으로 살펴본다. 먼저 누구의 어떤 선택을 돕는지 정한다. 이동 수업용 컴퓨터를 고른다면 가격뿐 아니라 무게·배터리 등 목적에 관련된 기준을 사용한다.

대상마다 좋은 기준 하나씩만 골라 서로 다른 기준으로 평가하면 비교가 불공정해진다. 같은 기준 목록을 각 대상에 적용하고 정보가 없으면 추측값을 넣지 않고 미확인으로 기록한다.

같은 조건의 값

가격에는 통화와 포함 항목, 무게에는 단위, 속도에는 작업과 환경을 밝힌다. 다른 해에 측정한 서로 다른 작업 시간을 단순히 나란히 놓으면 제품 차이인지 조건 차이인지 알기 어렵다.

표는 공통 기준을 한눈에 보여 주지만 설명을 대신하지는 않는다. 숫자의 방향이 무엇을 의미하는지 써야 한다. 무게는 낮을수록 이동 부담이 작아질 수 있지만 사용 목적에 따라 화면 크기도 고려해야 한다.

근거와 판단 연결

가상의 A는 60만 원·1.2kg, B는 50만 원·1.8kg이다. A가 가볍고 B가 저렴하다는 사실에서 어느 쪽이 무조건 우수하다는 결론은 나오지 않는다. 예산이 55만 원이라는 조건을 추가하면 A는 예산을 넘는다.

가중 점수를 쓰면 가중치와 계산 방법을 공개한다. 수치로 합쳤다고 취향이나 가치 선택이 사라지지 않는다. 본문 결론에는 선택 조건과 다른 경우에 바뀔 수 있는 이유를 함께 적는다.

다른 문제에 적용하기

새 기준으로 정의·안내·비교 다시 쓰기

새 가상 문서는 지정 버전 일치·필수 다섯 항목 일치·결과와 위치 기록을 확인 완료로 정의합니다. S는 14분에 다섯 항목을 확인하고 되돌리기가 없으며 T는 19분에 다섯 항목을 확인하고 되돌리기가 있습니다. 시간 제한 18분과 되돌리기 필수 조건을 모두 적용할 때 후보를 판단하고, 조건 불충족을 숨기지 않는 결론과 버전 미확인 분기를 쓰세요. 두 방법 모두 지정 버전 확인과 결과·위치 기록은 충족하고, 확인한 다섯 항목은 원본과 일치한다고 가정합니다.

힌트 1

S는 되돌리기가 없고 T는 제한 시간을 넘습니다.

힌트 2

후보가 없다는 결론도 자료에 맞는 결과입니다.

풀이와 답 확인

  1. 확인 완료의 범주와 세 기준을 새 다섯 항목 정의로 적습니다.

  2. 버전 미확인일 때 ID 확인 후 진행하도록 안내합니다.

  3. S는 되돌리기 조건 위반이고 T는 19분으로 시간 조건 위반임을 적습니다.

  4. 현재 후보가 없으며 요구 변경이나 다른 방법 확인이 필요하다고 설명합니다.

확인 완료는 지정 버전의 필수 다섯 항목이 모두 일치하고 결과와 위치가 기록된 검토 상태다. 버전 ID가 미확인이면 먼저 ID를 확인하며 완료로 표시하지 않는다. S는 되돌리기가 없고 T는 18분 제한을 넘으므로 현재 두 조건을 모두 충족하는 후보는 없다. 조건 변경이나 다른 방법의 확인은 후속 계획이며 수행 결과가 아니다.

해결한 뒤 점검할 것

  • 새 다섯 항목 정의와 이전 네 항목 정의를 섞지 않았습니다.

  • 버전 미확인 분기와 완료 조건을 명시했습니다.

  • S와 T에 같은 시간·되돌리기 기준을 적용했습니다.

  • 후보가 없는데 임의 수치를 만들어 선택하지 않았습니다.

P는 13분과 네 항목 및 되돌리기 없음, Q는 18분과 네 항목 및 되돌리기 있음, R은 9분과 세 항목 및 되돌리기 있음입니다. 20분 제한과 네 항목 필수이면 P·Q가 후보이고 되돌리기도 필수이면 Q만 남습니다. 15분 제한에서는 P만 남습니다. 전이의 S는 14분이지만 되돌리기가 없고 T는 19분이어서 18분 제한을 넘으므로 두 필수 조건을 만족하는 후보가 없습니다. 이 수치와 절차는 자체 종이 카드로 손대조했습니다.
