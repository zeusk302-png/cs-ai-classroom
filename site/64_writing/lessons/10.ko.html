소단원 10.1

캡션과 본문 연결

그림 아래에 “결과”라고 쓰면 독자는 무엇을 알아야 할까?

준비 개념과 학습 목표

준비 개념

  • 표의 행·열

  • 문장의 주장과 근거

학습 목표

  • 대상·조건·단위를 포함한 캡션을 쓴다

  • 본문의 주장을 그림의 구체적 값과 연결한다

  • 비교 결과와 원인 주장을 구분한다

평균 시간이 짧은 쪽을 곧바로 더 좋은 방법이라고 소개해도 될까요?

표는 수치를 모아 놓는 공간이면서 독자가 비교 조건을 되찾는 경로입니다. 이 단원에서는 같은 가상 요청 20개를 방법 A와 B에 각각 넣었다고 가정합니다. A는 18개를 완료했고, 완료한 요청만의 평균 시간은 300 ms입니다. B는 20개를 완료했고 그 평균은 340 ms입니다. 이는 직접 만든 교육용 수치이며 실제 서비스를 시험한 결과가 아닙니다.

완료한 요청의 평균과 모든 요청의 완료율은 서로 다른 질문에 답합니다. A의 평균이 짧다는 관찰은 완료된 부분에 한정됩니다. A가 실패한 두 요청은 B의 평균에는 포함되어 있어 평균을 계산한 요청 집합도 같지 않습니다. 캡션에는 표의 대상과 단위, 집계 조건을 적고 본문은 이 제한이 결론에 미치는 영향을 설명합니다.

먼저 확인할 개념
  • 근거의 적용 범위

    완료한 요청의 평균을 모든 입력이나 모든 서비스로 확대할 수 있는지 판단합니다.

  • 비교 기준과 사례

    시간과 완료율 중 어떤 기준을 필수로 삼는지 먼저 정합니다.

번호가 독자의 길잡이가 된다

표와 그림을 넣기 전에 독자가 답해야 하는 질문을 정한다. 숫자를 정확히 조회하는 일이면 표가 유용하고, 변화나 관계를 빠르게 보는 일이면 그림이 도움이 된다. 표1·그림1처럼 번호를 붙여 본문에서 무엇을 가리키는지 명확하게 만든다.

캡션은 대상, 비교 조건, 단위와 필요한 해석 조건을 제공한다. “그림1. 같은 100개 가상 요청에 대한 방식 A·B의 처리 시간(ms), 자체 계산 자료”처럼 쓰면 독자가 실제 서버 측정으로 오인하지 않는다. 캡션과 본문에 증거 상태가 일치해야 한다.

본문은 중요한 관계를 해석한다

본문에서 모든 칸을 그대로 반복할 필요는 없다. 비교하려는 값과 차이를 짚고 그 차이가 질문에 왜 관련되는지 설명한다. 그림의 핵심 정보를 글로도 이해할 수 있게 만들면 이미지가 보이지 않는 상황에서도 논리를 따라갈 수 있다.

A가 120ms, B가 90ms인 자체 예시라면 차이는 30ms, A를 기준으로 감소율은 30/120=25%이다. “B가 더 빠르다”를 쓰더라도 비교 대상과 시간의 정의를 밝혀야 한다. 처리 시간이 작다는 사실과 전체 처리량이 크다는 사실은 같은 주장이 아니다.

그림을 벗어나는 주장은 멈춘다

둘의 값이 다르다고 원인이 특정된 것은 아니다. 실제 실험이라면 입력·장비·반복·측정 방법과 변동도 조사해야 한다. 가상의 표는 계산과 글쓰기 연습에는 쓸 수 있지만 실제 서비스 성능 개선 증거가 아니다.

표와 본문의 단위, 반올림, 대상 수와 기준 방향을 대조한다. 표에는 90ms인데 본문에는 90초라고 쓰거나, 25% 감소를 25%포인트 감소라고 쓰면 같은 숫자라도 의미가 달라진다. 캡션에 모든 한계를 넣기 어렵다면 필요한 설명 위치를 안내한다.

표 1. 같은 가상 요청 20개를 입력한 두 방법의 완료 수와 완료된 요청만의 평균 시간

완료율의 분모는 각 방법에 넣은 요청 20개입니다. 시간 평균의 분모는 A에서 18개, B에서 20개이며 실패 요청의 시간은 제공되지 않았습니다. 서로 다른 집계 조건을 캡션과 열 이름에 남겨 읽습니다.

중간 과정을 따라가는 예제

가상 표1의 A=120ms, B=90ms이다. 캡션과 비교 본문을 작성하라. 다른 장비나 실제 실행 정보는 제공되지 않았다.

  1. 표1 캡션에 가상 자료·A/B·처리 시간·ms를 적는다.

  2. 120−90=30ms, 30/120=25%를 계산한다.

  3. 원인이 검증된 것처럼 쓰지 않는다.

예: “표1. A·B의 가상 처리 시간(ms), 자체 예시.” 본문: “표1에서 B는 A보다 30ms 작으며 A 기준 25% 감소한다. 실제 측정이나 원인 검증 결과는 아니다.”

조건을 바꾸어 비교하기

수치와 비교 조건을 함께 회수하기

표 1을 소개하는 문장 “위의 표는 A가 모든 면에서 우수함을 증명한다”를 고치세요. 완료율과 시간의 차이도 계산하세요.

  1. A의 완료율은 18 ÷ 20 = 90%이고 B는 100%입니다.

  2. 완료율 차이는 10%포인트입니다. 완료된 요청만의 평균 시간은 A가 40 ms 짧습니다.

  3. 시간이 40 ms 짧다는 사실을 전체 요청의 성능이나 원인으로 바꾸지 않습니다. 표 번호로 연결합니다.

예: “표 1에서 A는 완료된 요청의 평균 시간이 40 ms 짧지만 완료율은 B보다 10%포인트 낮다. 두 시간 평균은 완료한 요청 집합이 달라 전체 요청의 처리 성능을 이 표만으로 단정할 수 없다.”

비교할 점

표 번호와 제한을 적으면 그림 위치가 바뀌어도 주장의 근거를 찾을 수 있습니다.

실패한 요청의 시간까지 제공되면

추가 가상 카드에서 A의 실패 요청 두 개는 각각 1,000 ms 후 종료했고 B는 모든 요청을 완료했다고 가정합니다. 종료까지 걸린 시간의 전체 요청 평균을 계산하세요.

  1. A의 완료 요청 시간 합계는 18 × 300 = 5,400 ms입니다.

  2. 실패 요청의 시간 합계 2,000 ms를 더하면 7,400 ms입니다. 전체 요청 평균은 7,400 ÷ 20 = 370 ms입니다.

  3. B는 모든 요청이 완료되어 전체 요청 평균도 340 ms입니다.

이 추가 카드의 종료 시간 평균은 A가 370 ms, B가 340 ms입니다. 최초 표의 완료 요청 평균 300 ms를 전체 평균으로 읽었을 때와 순서가 바뀝니다.

비교할 점

추가 정보가 없을 때 370 ms를 추정한 것은 아닙니다. 실패한 요청을 완료한 요청으로 바꾸거나, 종료 시간을 성공 처리 시간으로 부르지도 않습니다.

종이와 본문으로 직접 해보기

가상 값이 A=80ms, B=60ms로 바뀌었다. 차이와 A 기준 감소율을 구하고 캡션에서 무엇을 유지할지 적어라.

힌트 보기

기준은 여전히 A이고 자료 상태도 가상이다.

풀이 보기

차이20ms, 감소율20/80=25%이다. 대상 A/B·처리 시간·ms·가상 자료 표시는 유지하며 본문 값만 정확히 갱신한다.

오해와 반례

숫자가 실린 그림은 원인까지 증명한다.

A/B 차이는 관찰 또는 모형 결과다. 원인 분리 조건이 없으면 B의 특정 기능 때문이라고 결론내리지 않는다. 가상 값은 실제 성능 자체도 입증하지 않는다.

스스로 풀어보기

먼저 답과 이유를 적고, 필요한 만큼 힌트를 한 단계씩 열어 보세요.

연습 1 · 값과 상태 예측

최초 표 1만 있을 때 “A의 전체 요청 종료 시간 평균은 300 ms이다”를 판정하고 계산에 필요한 미확인 정보를 적으세요.

힌트 1

300 ms의 분모를 봅니다.

힌트 2

실패한 두 요청의 종료 시간을 확인했는지 묻습니다.

풀이와 답 확인

  1. 300 ms는 완료 요청 18개의 평균입니다.

  2. 실패 요청의 시간이 없어 전체 요청 시간 합계를 계산할 수 없습니다.

현재 정보로는 판정할 수 없습니다. 실패 요청 두 개의 종료 시간이 추가로 필요합니다.

흔한 오답에서 다시 생각하기

완료 평균을 모든 요청 평균으로 복사한다.

같은 표 안에서도 각 열이 사용하는 대상이 다릅니다. 전체 평균을 만들기 전에 누락된 값을 확인하세요.

연습 2 · 오류 찾아 고치기

표 제목 “실제 사이트 속도 비교”와 캡션 “A가 더 빠르다”를 최초 가상 자료에 맞게 고치세요.

힌트 1

교육용 가정과 실제 측정 상태를 구분합니다.

힌트 2

대상 수와 평균의 집계 대상을 넣습니다.

풀이와 답 확인

  1. 실제 사이트를 시험했다는 표현을 지웁니다.

  2. 같은 가상 요청 20개, 완료 수, 완료된 요청만의 평균 시간이라고 명시합니다.

예: “표 1. 가상 요청 20개에 대한 완료 수와 완료된 요청만의 평균 시간.” 본문에는 완료율과 평균 대상의 차이를 설명합니다.

흔한 오답에서 다시 생각하기

제목에 실제라는 말을 붙여 신뢰도를 높인다.

수치의 제작 목적은 바뀌지 않습니다. 실제라는 표현은 실제 관찰 근거가 있을 때만 사용할 수 있습니다.

연습 3 · 직접 만들어 보기

완료율이 95% 이상이어야 하는 조건에서 방법을 선택하는 본문 두 문장을 쓰세요. 최초 표를 사용합니다.

힌트 1

필수 조건을 먼저 적용합니다.

힌트 2

통과한 방법과 아직 확인하지 않은 범위를 적습니다.

풀이와 답 확인

  1. A의 90%는 문턱을 넘지 못하고 B의 100%는 넘습니다.

  2. 이 가상 요청 집합과 조건에 한정하여 B를 선택합니다.

예: “표 1의 완료율 95% 이상이라는 조건에서는 B만 통과한다. 이는 가상 요청 20개에 대한 판단이며 다른 입력이나 실제 서비스에서의 우수성을 확인한 결과는 아니다.”

흔한 오답에서 다시 생각하기

A의 평균이 짧으므로 필수 완료율을 무시한다.

필수 조건은 선택 순서를 제한합니다. 시간의 장점이 완료율 미달을 자동으로 보상하지 않습니다.

연습 4 · 선택 심화

선택 심화는 기본 연습 뒤 더 탐구하고 싶을 때 풀어 보세요.

완료율 95% 이상과 완료 요청 평균 시간 320 ms 이하를 모두 요구하면 최초 표에서 무엇을 선택할 수 있나요?

힌트 1

두 조건을 각각 체크합니다.

힌트 2

선택 가능한 방법이 없다는 답도 허용합니다.

풀이와 답 확인

  1. A는 시간 조건만 통과합니다.

  2. B는 완료율 조건만 통과합니다.

두 조건을 함께 만족하는 방법이 없습니다. 조건을 바꾸거나 새 방법을 검토하는 단계가 필요하며 기존 두 방법 중 하나가 통과했다고 적을 수 없습니다.

흔한 오답에서 다시 생각하기

적어도 하나는 골라야 하므로 B의 시간을 반올림한다.

조건은 실제 값과 대조합니다. 340 ms는 320 ms 이하가 아니며 선택을 강요해 수치를 바꿀 수 없습니다.

내 말로 설명하기

캡션과 본문은 무엇을 나누어 설명하나요?

설명 기준 확인

캡션은 표의 대상·단위·집계 조건을 회수하게 하고 본문은 그 수치가 주장에 주는 의미와 제한을 설명합니다.

완료된 요청 평균이 같아도 전체 평균은 같나요?

설명 기준 확인

숫자는 그대로인데 그림의 차이가 두 배처럼 보이는 이유는 무엇일까요?

가상 지표 A가 100, B가 104라고 합시다. 실제 차이는 4이며 A를 기준으로 4% 높습니다. 막대의 시작점을 96으로 잡으면 보이는 길이는 4와 8이 되어 B가 두 배처럼 보입니다. 수치를 그대로 적었다고 해도 눈이 비교하는 길이와 실제 값의 비례 관계를 바꿀 수 있습니다.

그래프를 읽을 때에는 값, 단위, 집계 방식과 함께 길이·넓이가 무엇을 표현하는지 확인합니다. 막대는 길이가 값을 나타내므로 0에서 시작하는 축이 그 비례 관계를 보존합니다. 선그래프에서 좁은 범위의 변화를 보여 주는 경우에는 다른 판단이 가능하지만 축의 생략을 명확히 드러내고 같은 축을 쓰는지 확인해야 합니다. 모든 그래프에 같은 규칙을 기계적으로 적용하지 않습니다.

그려진 길이와 실제 값

막대는 기준선에서의 길이가 값을 나타낸다. 같은 척도에서 값80과90을 0부터 그리면 길이 비는90/80=1.125다. 기준선을70으로 옮겨 막대를 그리면 보이는 길이는10과20이 되어 비가2가 된다. 값 자체가 두 배가 된 것이 아니라 표시가 비를 바꾼 것이다.

막대에서는 0 기준선을 사용하고 단위를 밝히는 것이 중요하다. 세밀한 작은 차이를 보여야 한다면 값을 직접 쓰거나 다른 표시법을 고려한다. 선그래프에서 제한된 축 범위를 쓰는 선택은 있을 수 있으나 범위·생략을 명확히 표시하고 차이가 과장되어 읽힐 위험을 살핀다.

퍼센트의 분모를 되묻기

실패율이10%에서8%가 되면 차이는2%포인트다. 초기 실패율을 기준으로 한 상대 감소는(10−8)/10=20%다. “2% 감소”라고만 쓰면 독자가 둘 중 어떤 계산인지 알아내야 한다. 총 요청 수나 측정 조건이 달라졌는지도 같이 읽는다.

가상 집단 A의 성공90/100과 B의 성공18/20은 모두90%다. 성공 건수90과18만 비교해 A가 성공률이5배 높다고 적으면 잘못이다. 건수와 비율의 질문을 분리하고 각각의 분모를 남긴다.

빠진 값과 불확실성을 숨기지 않기

자료가 없는 시점은 값0이 아니다. 관측하지 않은 2월을 0으로 채우면 급락이라는 이야기가 만들어진다. 누락과 추정값을 구분하고 추정한다면 방법을 밝힌다. 단위가 다른 두 값을 같은 축에 올릴 때도 관계를 쉽게 오해할 수 있다.

하나의 평균만으로 모든 대상이 비슷하다고 결론내리지 않는다. 자체 가상 시간10·10·100의 평균은40이지만 두 값은10이고 하나는100이다. 질문이 긴 대기 경험이라면 분포나 개별 값 정보가 더 필요하다. 이 계산은 실제 이용자 자료를 분석한 결과가 아니다.

  1. 원자료의 비율은 104 ÷ 100 = 1.04입니다.

  2. 시작점 96에서는 길이만 8 ÷ 4 = 2가 됩니다.

B는 A보다 4% 높으며 두 배라는 표현은 생략한 축에서의 길이를 실제 값으로 착각한 것입니다.

비교할 점

같은 평균이 다른 분포를 숨기기

  1. P의 합계는 36이고 Q의 합계도 36입니다. 각 집합은 여섯 값이므로 평균은 6입니다.

  2. P의 최댓값은 31이며 Q의 최댓값은 6입니다.

  3. 평균 막대만으로는 P의 큰 값 한 개와 작은 값 다섯 개를 회수할 수 없습니다.

평균은 같지만 분포는 다릅니다. 평균 비교를 모든 개별 값이 같다는 주장으로 확대할 수 없습니다.

소단원 10.3

그림 출처와 접근성

출처 링크와 그림 설명은 서로 무엇을 해결할까?

준비 개념과 학습 목표

준비 개념

  • 링크의 목적

  • 본문과 이미지 구분

학습 목표

  • 원자료·그림 제작·변형 정보를 구분한다

  • 라이선스 조건 확인과 출처 표시를 연결한다

  • 이미지 없이도 값·관계·기능을 전달한다

그림이 보이지 않아도 독자가 값과 결론을 되찾을 수 있나요?

출처는 누가 만든 어떤 자료를 사용했는지 찾아가는 경로이고 정보 설명은 지금 보고 있는 글의 내용을 되찾는 경로입니다. 자체 가상 자료를 직접 그린 그림에도 정보 설명은 필요할 수 있습니다. 반대로 원자료 링크 하나가 그래프의 값·단위·관계를 모두 설명하지는 않습니다.

이 소단원의 복잡한 그래프 설명 초안은 짧은 식별 문장과 가까운 본문·표를 연결하는 방식입니다. 독자가 개별 값을 읽어야 한다면 구조를 가진 값 표를 제공하고, 결론도 알아야 한다면 관계와 제한을 함께 적습니다. 이미 주변 글에 같은 정보가 있는 경우 중복을 줄이는 선택은 문맥에 따라 판단하며, 정보가 사라지는 방식으로 생략하지 않습니다.

먼저 확인할 개념
  • 인용과 참고문헌

    원자료와 제작자의 기록을 구분하고 독자가 실제 자료를 찾게 합니다.

  • 수치 왜곡 피하기

    대체 설명에서도 원값·집계 조건·미측정 상태를 유지합니다.

누가 만든 무엇을 사용했는가

다른 사람의 그림을 그대로 쓰거나 바꾸는 경우 원본, 저자와 이용 조건을 실제 확인한다. CC BY4.0 요약은 적절한 저작자 표시·라이선스 링크·변경 표시 등을 안내한다. 다른 CC 조건이나 제공된 고지도 달라질 수 있으므로 이미지별 원래 조건을 읽는다. 인터넷에서 볼 수 있다는 사실만으로 재사용 조건이 정해지지는 않는다.

원자료와 그림 저자는 다를 수 있다. 외부 데이터로 직접 그림을 그렸다면 데이터의 정확한 자료 페이지와 버전·필요한 이용 조건, 자신의 제작·가공 내용을 분리해 적는다. 저장소의 자체 라이선스가 외부 그림의 조건을 자동으로 바꾸었다고 적지 않는다.

설명은 독자가 필요한 정보를 되찾게 한다

출처는 원본을 찾아가게 하고 대체 설명은 그림이 보이지 않아도 현재 글의 내용을 이해하게 한다. 복잡한 그래프에는 짧은 식별 설명과 값·축·관계·추세를 설명하는 본문 또는 표가 도움이 된다. 정보 그림에 파일명이나 “그림”만 적으면 주장을 복원하기 어렵다.

“가상 실패율 비교, 상세 값은 아래 표”라는 짧은 설명과 “A10%, B8%, A 기준20% 상대 감소·2%포인트 차이”라는 정보 설명을 연결해 볼 수 있다. 색만으로 A/B를 구별하지 않고 이름과 값도 적는다. 이것은 설명 초안이며 실제 보조기기 시험 완료 주장이 아니다.

문맥과 기능을 먼저 판단하기

이미지가 링크나 버튼의 유일한 단서라면 대체 텍스트는 이동 목적이나 동작을 전달해야 한다. 같은 모양도 본문에서 순수 장식일 때와 다운로드 버튼일 때 역할이 다르다. 의미 없는 장식에는 빈 alt를 쓸 수 있지만 중요한 정보를 숨기는 목적으로 사용하지 않는다.

원본을 확대하는 링크라면 “그림1 확대 보기” 같은 기능 설명을 준다. 긴 정보가 이미 주변 글에 완전하게 있는 경우 중복 읽기를 줄이는 방식도 고려한다. 그림을 제거했을 때 필요한 정보와 행동이 남는지 읽어 보고, 실제 접근성 판정은 화면·키보드·보조기기에서 별도 확인한다.

현재 주장이 무엇을 말하지 않는지도 남는가?

각 요소가 맡는 질문을 읽습니다. 출처가 있다고 값 설명을 빼거나 대체 설명이 있다고 원자료 기록을 지우지 않습니다. 이 표는 설명 설계 연습이며 실제 보조기기 평가의 통과 기록이 아닙니다.

중간 과정을 따라가는 예제

자체 가상 데이터 A10%, B8%를 직접 그린 그림1에 출처·짧은 설명·긴 설명을 작성하라. 외부 그림은 사용하지 않았다.

  1. 출처는 자체 가상 데이터·직접 제작이라고 적는다.

  2. 짧은 설명은 그림의 질문과 상세 설명 위치를 식별한다.

  3. 긴 설명에 두 값·단위·차이를 넣는다.

예: “그림1. A·B 실패율, 자체 가상 데이터·직접 제작.” 짧은 설명: “A·B 가상 실패율, 상세 비교는 아래 설명.” 긴 설명: “A10%, B8%이다. B는 A보다2%포인트 낮고 A 기준20% 감소한다. 실제 서비스 측정은 아니다.”

조건을 바꾸어 비교하기

보이지 않는 그래프의 핵심 회수하기

최초 표 1을 그린 자체 가상 그래프의 설명은 “초록색이 더 좋다”입니다. 그림을 보지 않아도 판단할 수 있도록 고치세요.

  1. 초록색이 어느 방법인지 모르므로 방법 이름을 먼저 적습니다.

  2. 각 방법의 입력 수, 완료 수와 완료 평균 시간을 남깁니다.

  3. 시간의 대상이 완료한 요청이라는 점과 전체 시간 비교의 한계를 적습니다.

예: “같은 가상 요청 20개를 사용했다. A는 18개를 완료했고 완료한 요청의 평균은 300 ms, B는 20개를 완료했고 평균은 340 ms이다. A의 완료 평균은 40 ms 짧지만 완료율은 10%포인트 낮다. 전체 요청 시간은 미확인이다.”

비교할 점

색은 부가 단서로 쓸 수 있지만 이름과 값, 비교 조건을 대신하지 않습니다.

그림의 역할이 바뀌면 설명도 달라지기

같은 화살표 그림을 문단 옆 장식으로만 쓰는 경우와 이미지 하나만 있는 “표 1의 상세 설명으로 이동” 링크로 쓰는 경우를 비교하세요.

  1. 장식은 없어도 내용과 행동이 유지되는지 확인합니다.

  2. 링크의 유일한 단서라면 독자가 이동 목적을 알도록 설명합니다.

순수 장식에서는 빈 대체 텍스트가 후보가 될 수 있습니다. 유일한 링크 단서에서는 “표 1 상세 설명으로 이동”처럼 목적을 전달해야 합니다.

연습 1 · 값과 상태 예측

원자료 링크만 붙이고 A와 B의 수치를 어디에도 적지 않은 그래프에서, 그림 없이 원값 비교가 가능한가요?

  2. 긴 설명에 ms, A의 18개와 B의 20개, 전체 시간 미확인이라는 제한을 넣습니다.

힌트 2

실제 자료나 외부 그림을 사용했다고 쓰지 않습니다.

풀이와 답 확인

  2. 짧은 설명은 가상 두 집합의 평균과 최댓값 비교, 상세 값 표의 위치를 식별합니다.

  3. 표는 집합·개수·평균·최댓값으로 구성하고 여섯 원값도 가까이 남깁니다.

예: “가상 집합 P·Q의 평균과 최댓값 비교. 값은 가까운 표 2에 있습니다.” 표 2에는 P: 6개, 평균 6, 최댓값 31과 Q: 6개, 평균 6, 최댓값 6을 적습니다.

설명 원칙의 출처와 수치의 출처는 다릅니다. 지침을 읽었다는 사실이 자체 가상 수치를 공식 관찰로 만들지 않습니다.

연습 4 · 선택 심화

선택 심화는 기본 연습 뒤 더 탐구하고 싶을 때 풀어 보세요.

긴 정보 표에 열 제목과 행 이름이 있습니다. 그 내용을 한 줄 문자열로만 연결한 설명이 구조를 가진 표와 완전히 같다고 할 수 있나요?

힌트 1

값이 들어 있는지와 구조를 탐색할 수 있는지는 별개입니다.

힌트 2

독자가 행과 열의 관계를 어떻게 찾는지 생각합니다.

풀이와 답 확인

  1. 긴 문자열에는 값이 들어 있어도 행·열 제목을 따라 탐색하는 구조가 사라질 수 있습니다.

  2. 구조를 가진 가까운 표나 별도 상세 설명을 연결하고 실제 환경에서 확인할 항목을 남깁니다.

정보를 많이 넣는 것만으로 표 구조의 사용성을 확인한 것은 아닙니다. 구조를 가진 설명을 회수하는 경로를 마련하고 키보드·보조기기에서 실제 확인하는 단계는 미수행으로 남깁니다.

흔한 오답에서 다시 생각하기

모든 값을 한 문자열로 넣으면 보조기기 검증도 통과한 셈이다.

값 포함 여부는 초안 점검이고 실제 환경의 탐색·이해는 별도 확인입니다. 이 종이 연습으로 검증 통과를 주장하지 않습니다.

내 말로 설명하기

자료 기록과 그림 설명은 왜 둘 다 필요한가요?

설명 기준 확인

하나는 자료와 제작 정보를 찾게 하고 다른 하나는 현재 그림의 값·관계·목적을 전달합니다. 서로를 대신하지 않습니다.

설명 초안을 썼다면 접근성 평가를 수행한 것인가요?

설명 기준 확인

아닙니다. 현재 초안의 정보와 조건을 점검했을 뿐 실제 화면·키보드·보조기기·학습자 관찰은 별도 수행 여부를 남겨야 합니다.

다른 문제에 적용하기

빠진 달을 포함한 가상 완료율 그림의 설명 만들기

자체 가상 자료에서 1월은 시도 50개 중 완료 40개, 2월은 미측정, 3월은 시도 20개 중 완료 18개입니다. “3월 완료량이 증가했고 2월에는 0으로 떨어졌다”라는 그림 설명을 바로잡으세요. 월·시도 수·완료 수·완료율 표의 초안, 표 번호를 참조하는 본문, 짧은 그림 설명과 자료 기록을 만들고 실제 확인하지 않은 항목을 남기세요.

힌트 1

완료 수와 완료율을 각각 비교하고 미측정 달은 수치로 바꾸지 않습니다.

힌트 2

현재 자료는 가상 수치입니다. 그림 설명의 원칙 출처와 자료 출처를 구별합니다.

풀이와 답 확인

  1. 1월 완료율은 40 ÷ 50 = 80%이며 3월은 18 ÷ 20 = 90%입니다. 완료 수는 40개에서 18개로 줄었습니다.

  2. 완료율은 10%포인트 높지만 완료 수는 22개 적습니다. 서로 다른 시도 수를 밝혀 비교합니다.

  3. 2월의 시도·완료·완료율은 모두 미측정으로 남깁니다. 0이나 관찰한 중간 추세를 만들지 않습니다.

  4. 표 3에 월·시도 수·완료 수·완료율과 집계 조건을 적고 본문에서 표 3을 참조합니다.

  5. 짧은 설명은 가상 월별 완료 수·완료율과 표 3 위치를 식별합니다. 자료 기록은 자체 가상 자료·직접 제작이라고 적습니다.

예: “표 3에서 1월은 시도 50개 중 40개 완료로 80%, 3월은 시도 20개 중 18개 완료로 90%이다. 완료율은 10%포인트 높지만 완료 수는 22개 적다. 2월은 미측정이며 중간 변화는 알 수 없다.” 짧은 설명은 “가상 월별 완료 수와 완료율. 상세 값과 미측정 상태는 표 3에 있습니다.”로 만들 수 있습니다. 실제 서비스 측정, HTML 구성과 보조기기·학생 관찰은 수행하지 않았습니다.

해결한 뒤 점검할 것

  • 완료 수 감소와 완료율 증가를 각각 계산하고 서로 바꾸지 않았습니다.

  • 2월을 미측정으로 유지하고 존재하지 않는 추세를 만들지 않았습니다.

  • 표 번호·단위·집계 조건과 가까운 정보 설명을 연결했습니다.

  • 가상 자료 기록과 실제 미수행 확인 단계를 구별했습니다.
