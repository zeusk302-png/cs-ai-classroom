논리적 글쓰기와 발표

관심 있는 누구나 시작할 수 있습니다. 학년·나이로 내용을 잠그지 않습니다.

현재 제공: 전체 목차·집필 설계·일부 단원 본문 초안. 나머지 본문은 준비 중입니다.

어떻게 공부하게 될까요?

같은 단원 안에서 쉬운 진입 → 본 이론 → 심화로 이어집니다. 처음에는 작은 예시를 보고, 다음에는 정의·기호·계산·유도를 공부합니다. 심화에서는 증명과 더 복잡한 문제를 다룹니다.

기본 활동은 종이와 본문으로 읽고 해볼 수 있게 설계합니다. 프로그램 설치와 실행은 선택 활동입니다.

본 이론의 권장 선수: 목록상 선수과목 없음

선수과목 전체를 먼저 마쳐야 이 페이지를 읽을 수 있는 것은 아닙니다. 필요한 개념은 단원 시작에서 확인하고 짧은 보충 설명으로 연결합니다.

첫 단원 집필 설계

아래는 강의 본문이 아니라 설명할 내용·예제·준비개념을 정한 제작 계획입니다.

학습 목표

  • 독자·질문·주장·근거를 구분하고 글의 목적을 정한다
  • 예시의 가정과 적용 한계를 자기 말로 설명한다

준비개념

  • 문장 읽기
  • 이유 제시

종이로 따라갈 예제

학교의 전자책 도입 주장에 자료·반론·조건을 붙여 한 문단 구성

대표적인 오해

자료를 많이 나열하면 자동으로 논증이 된다

자기점검과 해설

개념 구분 1문항·예제 변형 1문항·오해 반례 1문항, 각각 답과 이유 제공

단원 공통 구성과 과목 경계
  • 궁금증과 학습 목표
  • 준비개념·자가진단·미니복습
  • 쉬운 진입: 작은 예시와 예상
  • 본 이론: 정의·기호·조건·유도
  • 중간 과정을 보여주는 예제
  • 종이와 본문으로 직접 해보기
  • 오해·반례·비유의 한계
  • 자기점검·힌트·해설
  • 심화: 증명·추가 문제·선택 구현
  • 다음 연결·원문 출처·검토 상태
  • 개발 문서 작성 이전에 필요한 한국어 학술 읽기·쓰기의 기본을 다룬다.
  • 단원 번호는 주차가 아니다. 시험·복습·프로젝트 시간을 포함한 실제 차시 배분은 후속 설계한다.
