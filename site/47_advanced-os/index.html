운영체제 심화

관심 있는 누구나 시작할 수 있습니다. 학년·나이로 내용을 잠그지 않습니다.

현재 제공: 전체 목차·집필 설계·일부 단원 본문 초안. 나머지 본문은 준비 중입니다.

어떻게 공부하게 될까요?

같은 단원 안에서 쉬운 진입 → 본 이론 → 심화로 이어집니다. 처음에는 작은 예시를 보고, 다음에는 정의·기호·계산·유도를 공부합니다. 심화에서는 증명과 더 복잡한 문제를 다룹니다.

기본 활동은 종이와 본문으로 읽고 해볼 수 있게 설계합니다. 프로그램 설치와 실행은 선택 활동입니다.

본 이론의 권장 선수: 운영체제 및 실습

공개 참고자료

  • Stanford University — Advanced Topics in Operating Systems — Schedule

    본문 열람 확인
    논문 중심 대학원 성격의 범위를 학부 심화로 축소·재편성. 전체 연구 논문 재현을 한 학기 필수로 만들지 않는다.

  • MIT — Operating System Engineering — Schedule

    본문 열람 확인: 커널·트랩·페이지·락·스케줄·파일시스템 강의와 labs
    교육용 xv6·RISC-V 설계를 참고한다. Linux 전체 구현 강의와 동일한 범위로 주장하지 않는다.

  • Carnegie Mellon University — Parallel Computer Architecture and Programming — Schedule

    본문 열람 확인: 분해·스케줄·지역성·CUDA·일관성·메시지·동기화·병렬DL
    강의 영상은 Andrew 계정 로그인 조건이 있다. 공개 슬라이드 링크와 일정 중심 근거.
