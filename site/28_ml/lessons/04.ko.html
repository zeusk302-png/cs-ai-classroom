소단원 4.1

편향·분산

같은 학습법에 다른 예제 묶음을 주면 예측은 얼마나 달라질까?

준비 개념과 학습 목표

준비 개념

  • 평균은 확률 가중합이고 분산은 평균에서 벗어난 제곱의 평균이다.

  • 이 단원은 회귀 제곱 손실과 고정 입력 x 에서의 예측을 다룬다.

  • 통계적 편향과 사회적 공정성의 편향은 서로 다른 질문이다.

학습 목표

  • 학습표본에 따른 예측 편향·분산과 새 관측 잡음을 구별한다.

  • 필요한 독립·평균 0 조건으로 제곱 오차 분해를 유도한다.

예측 두 개를 평균하면 분산은 언제 줄어드는가?

새 모형에서는 입력 x를 고정하고 참 회귀값을 f=2로 정한다. 훈련 자료의 무작위성은 Z가 −1과 1을 같은 확률로 갖는 것으로 표현한다. 새 정답은 Y=2+ε이며 ε도 −1과 1을 같은 확률로 갖고 Z와 독립이다. 예측 h₁=2+Z와 h₂=2−Z는 각각 평균 2, 분산 1이다. 하지만 같은 Z를 반대로 사용하므로 둘의 공분산은 −1이다. 평균 예측은 항상 2이고 분산은 0이다.

반대로 h₂도 2+Z라면 두 예측은 같은 변동을 복사한다. 공분산은 1이고 평균 예측의 분산도 1이다. 각각 분산이 1이라는 정보만으로 평균 분산이 1/2이라고 결론 낼 수 없다. 일반적으로 두 예측 평균의 분산은 (Var(h₁)+Var(h₂)+2Cov(h₁,h₂))/4다. 공분산이 0인 경우에만 이 사례의 값이 1/2이 된다.

새 ε가 훈련과 독립이고 평균이 0이며 모든 이차 모멘트가 유한하면 제곱 예측 위험은 편향의 제곱, 훈련 변동 분산, 새 잡음 분산의 합이다. 반대 변동 평균은 위험 1, 복사 변동 평균은 위험 2다. 예측을 3+Z와 3−Z로 바꾸면 평균은 3이다. 분산은 0이어도 편향의 제곱이 1이므로 위험은 2다. 평균으로 없앤 변동과 남은 체계적 오차를 따로 기록한다.

먼저 확인할 개념
  • 훈련 자료에 대한 평균과 새 잡음

    기대값의 대상 및 독립 새 정답 조건을 고정한 뒤 분해를 적용한다.

  • 검증 점수와 반복 훈련 분산

    한 검증 점수와 여러 훈련 자료에서의 변동을 서로 다른 대상으로 읽는다.

여러 학습표본을 떠올리기

알고리즘을 하나 고정해도 어떤 훈련표본 D 를 받느냐에 따라 예측 h_D(x)가 달라질 수 있다. 입력 x 를 고정하고 m=E_D[h_D(x)]라 두면 편향은 m−f(x), 예측 분산은 E_D[(h_D(x)−m)²]다. 예측 한 번의 오차나 훈련 잔차 분산과 동일한 값이 아니다.

f(x)는 새 목표 Y 의 조건부 평균으로 생각한다. Y=f(x)+ε에서 잡음의 평균은 0, 분산은σ²(x)이며 새ε는 훈련 과정과 독립이라고 가정하자. 같은 훈련 정답을 재사용해 평가하면 이 독립 조건이 깨질 수 있다. 실제로 반복 학습을 하지 않고도 정의를 이용한 작은 확률 모형은 종이로 계산할 수 있다. 이 분해에서는 E_D[h_D(x)²]와 E[ε²]가 유한하다고 가정한다. 제곱 평균이 무한하면 유한한 항들의 교차항 소거 계산을 그대로 사용할 수 없다.

제곱을 펴서 오차를 분리하기

h_D−Y=(h_D−m)+(m−f)−ε를 제곱한다. h_D−m 의 평균 0, ε의 평균 0 과 독립성 때문에 세 교차항의 기대값은 0 이다. 남은 항에서 E[(h_D−Y)²]=분산+(m−f)²+σ²를 얻는다. 부호가 있을 수 있는 편향 자체가 아니라 편향의 제곱이 더해진다.

이 식은 현재 가정의 고정 x 에서 제곱 손실에 대한 것이다. 입력 분포에도 평균 내면 각 항을 입력에 대해 다시 평균한다. 분류의 0/1 손실이나 다른 손실에 똑같은 식을 무조건 적용하지 않는다. 잡음과 훈련 예측이 의존하면 교차항이 남아 위 단순 분해를 다시 검토해야 한다.

복잡도와 진단을 조심해서 읽기

아주 단순한 모델은 중요한 곡선을 놓쳐 편향이 클 수 있고, 표본의 작은 흔들림을 크게 따라가는 모델은 분산이 클 수 있다. 하지만 복잡도라는 말만으로 모든 알고리즘의 편향·분산이 단조롭게 바뀐다고 보장하지 않는다. 훈련오차가 0 이라는 한 수치로 새 예측오차나 분산을 알 수도 없다.

정규화·더 많은 같은 분포의 자료·평균화 같은 방법은 특정 상황의 불안정성을 줄일 수 있다. 어떤 개입이 효과가 있는지는 분할 평가와 자료 조건을 확인해야 한다. σ²는 현재 입력에서 목표 자체가 흔들리는 모형 항이며 관측 정보를 추가하면 달라질 수도 있다. 모든 현실 오류가 영원히 제거 불가능하다는 뜻은 아니다.

중간 과정을 따라가는 예제

고정 x 에서 f=2, 독립 새 잡음 ε=−1/+1 이 각각 1/2 다. 알고리즘 A 는 훈련표본에 따라 예측 1/3 을 각각 1/2 로 내고, B 는 항상 1 을 낸다. 두 기대 제곱 오차를 구하라.

  1. 잡음 평균 0, 분산 1 이다. A 예측 평균(1+3)/2=2 라 편향 0 이다.

  2. A 분산=((1−2)²+(3−2)²)/2=1 이다. 따라서 기대오차 0+1+1=2 다.

  3. B 평균 1 이므로 편향−1, 제곱 1 이다. 예측분산 0 이어서 기대오차 1+0+1=2 다.

  4. A 와 새 Y=1/3 의 네 독립 조합에서 제곱오차 0,4,4,0 평균 2 로 직접 확인한다.

  5. 두 알고리즘의 총오차는 같아도 편향·분산 구성은 다르다. 실제 반복학습 통계가 아니다.

A 와 B 의 기대 제곱 오차는 둘 다 2 다. A 분산 1·편향 0, B 분산 0·편향제곱 1 이다.

조건을 바꾸어 비교하기

같은 개별 분산의 다른 평균

h₁=2+Z일 때 h₂=2−Z와 h₂=2+Z의 평균 분산을 비교하라.

  1. 첫 경우 평균은 2여서 분산이 0이다.

  2. 둘째 경우 평균은 2+Z여서 분산이 1이다.

분산 1인 두 예측을 평균한 결과가 항상 분산 1/2인 것은 아니다.

비교할 점

앞 본문의 단일 예측 분해에 두 예측의 공분산을 추가한다.

잡음을 예측에 재사용한 관찰

예측을 h=Y로 정하고 같은 Y에 대한 제곱 오차를 측정했다. 분산 1과 새 잡음 1을 더해 위험 2라고 보고할 수 있는가?

  1. 같은 정답과 예측은 항상 같아 관찰 오차가 0이다.

  2. h−f와 ε의 공분산은 1이며 교차항 −2가 두 분산의 합을 상쇄한다.

재사용한 정답의 오차 0은 독립 새 정답 위험의 분해가 아니다.

비교할 점

개별 숫자만 맞추지 않고 훈련·평가 독립 조건의 실패를 확인한다.

종이와 본문으로 직접 해보기

같은 잡음에서 C 예측이 0/4 각각 1/2 이면 평균·편향·분산·총오차를 구하라. 항상 2 를 내는 D 와 비교하라.

힌트 보기

C 는 평균 2 지만 두 예측이 평균에서 2 씩 떨어져 있다.

풀이 보기

C 평균 2·편향 0·분산 4·총오차 5 다. D 평균 2·편향 0·분산 0·총오차 1 이다. 평균 예측이 같다고 분산이나 총오차가 같은 것은 아니다.

오해와 반례

편향이 0 이면 모든 예측도 정확하고 총오차도 0 이다.

C 는 평균이 2 여서 편향 0 이지만 예측 0/4 로 흔들려 분산 4 가 있고 새 목표 잡음 1 도 있다. 총오차 5 다.

스스로 풀어보기

먼저 답과 이유를 적고, 필요한 만큼 힌트를 한 단계씩 열어 보세요.

연습 1 · 값과 상태 예측

예측 3+Z와 3−Z를 평균하고 독립 새 Y=2+ε에 대한 편향·분산·위험을 구하라.

힌트 1

평균 예측을 먼저 약분한다.

힌트 2

평균 예측과 f=2의 차이를 제곱하고 새 잡음 분산을 더한다.

풀이와 답 확인

  1. 평균은 3이고 편향은 1이다.

  2. 평균 예측 분산은 0이며 위험은 1+0+1=2다.

변동은 없어도 체계적 오차는 남는다.

흔한 오답에서 다시 생각하기

분산이 0이니 위험도 0이다.

편향의 제곱과 독립 새 잡음 항을 생략했다.

연습 2 · 오류 찾아 고치기

분산 1인 h₁과 h₂ 두 개를 평균하므로 분산은 항상 1/2이라고 썼다. 수정하라.

힌트 1

두 예측의 공분산을 표시한다.

힌트 2

공분산이 1인 복사 예측을 대입한다.

풀이와 답 확인

  1. 평균 분산은 1/2+Cov(h₁,h₂)/2다.

  2. 복사 예측이면 공분산이 1이므로 평균 분산은 1이다.

공분산을 확인한 뒤 감소량을 판단한다.

흔한 오답에서 다시 생각하기

모델을 두 번 호출하면 두 결과는 독립이다.

호출 횟수와 훈련 자료·난수·예측의 독립성은 다른 조건이다.

연습 3 · 직접 만들어 보기

분산이 각각 1이고 공분산이 0인 두 예측을 직접 구성하고 평균 위험을 구하라.

힌트 1

Z와 독립인 새 훈련 변수 W를 ±1 같은 확률로 정한다.

힌트 2

예측을 2+Z와 2+W로 구성한다.

풀이와 답 확인

  1. 네 훈련 상태 (Z,W)가 각각 확률 1/4이면 공분산은 0이다.

  2. 평균의 편향은 0, 분산은 1/2다. ε와 둘 다 독립이면 새 위험은 3/2다.

네 상태의 공동 분포와 새 잡음 독립까지 명시한다.

흔한 오답에서 다시 생각하기

Z와 W의 주변 확률만 같으면 공분산이 0이다.

같은 주변 분포라도 W=Z 또는 W=−Z일 수 있다.

연습 4 · 선택 심화

선택 심화는 기본 연습 뒤 더 탐구하고 싶을 때 풀어 보세요.

Var(h₁)=Var(h₂)=1일 때 평균 분산의 가능한 범위와 양 끝의 예를 설명하라.

힌트 1

Cauchy–Schwarz로 공분산의 절댓값을 제한한다.

힌트 2

평균 분산 식에 −1과 1을 각각 넣는다.

풀이와 답 확인

  1. 공분산은 −1 이상 1 이하이므로 평균 분산은 0 이상 1 이하다.

  2. 같은 평균에 반대 변동을 주면 0, 같은 변동을 복사하면 1을 달성한다.

가능한 공분산 계약이 분산 감소의 경계를 정한다.

흔한 오답에서 다시 생각하기

공분산은 음수가 될 수 없다.

분산은 비음수지만 서로 다른 변수의 공분산은 음수일 수 있다.

내 말로 설명하기

평균이 제거하지 못한 것은?

설명 기준 확인

모든 예측에 공통인 편향과 독립 새 잡음은 평균을 취했다는 이유만으로 없어지지 않는다.

분해 전에 정할 대상은?

설명 기준 확인

소단원 4.2

L1·L2 패널티

계수의 크기에 비용을 붙이면 답은 어떻게 바뀔까?

준비 개념과 학습 목표

준비 개념

  • 계수 벡터 w 의 L1 은Σ|wj|, 제곱 L2 는Σwj²다.

  • 정규화 패널티와 입력 표준화는 다른 개념이다.

  • 계수·손실의 단위와 1/2,n 가중치를 명시해야 λ를 비교할 수 있다.

학습 목표

  • 같은 잔차항에 L1/L2 를 붙인 1 차원 최적해를 유도한다.

  • 희소성·계수 축소의 차이와 평가 필요성을 설명한다.

동일한 두 특성에 L1을 쓰면 어느 특성을 선택하는가?

새 두 특성은 모든 관측에서 같은 값이어서 예측에 계수의 합 θ=u+v만 나타난다. 자체 목적은 J₁=½(u+v−4)²+λ(|u|+|v|)이고 λ=1이다. θ를 고정하면 삼각부등식에 의해 |u|+|v|≥|θ|다. θ가 양수이고 u와 v가 모두 비음수이면 등호다. 따라서 먼저 ½(θ−4)²+|θ|를 최소화하여 θ=3을 얻는다.

θ=3을 만드는 (u,v)=(3,0), (0,3), (3/2,3/2)는 모두 같은 최소 목적 7/2를 갖는다. 희소한 해가 존재해도 모든 최소해가 하나의 특성을 선택하는 것은 아니다. 이 목적만으로 선택된 특성의 인과적 중요성이나 유일한 계수를 인증하지 않는다. 같은 예측과 다른 계수 배분을 구별한다.

비교 목적 J₂=½(u+v−4)²+(λ/2)(u²+v²)에서는 θ를 고정할 때 u=v=θ/2가 제곱 패널티를 최소화한다. λ=1이면 줄어든 목적은 ½(θ−4)²+θ²/4다. 미분으로 θ=8/3, u=v=4/3을 얻는다. 자료 손실은 8/9이고 패널티는 16/9여서 전체는 8/3이다. L1과 L2의 목적값은 서로 다른 함수를 평가한 값이므로 작은 숫자만으로 일반화 우열을 정하지 않는다.

먼저 확인할 개념
  • 목적의 패널티 계수와 임계값

    λ와 자료 손실의 정규화가 고정된 일차원 공식을 합 계수에 적용한다.

  • 패널티 선택과 독립 평가

    목적의 최소값을 서로 다른 모델의 새 자료 성능으로 혼동하지 않는다.

자료 적합과 계수 비용의 합

선형 예측에서 자료 잔차를 줄이는 손실에 λ≥0 인 계수 패널티를 붙인다. 일반 L1 은절댓값 합, L2 정규화는 흔히 제곱합을 쓴다. 여기서는 1 차원 자료항½(w−3)², 절편은 없고 L1 목적 J1=½(w−3)²+λ|w|, L2 목적 J2=½(w−3)²+(λ/2)w²로 정확히 정한다.

다른 교재·라이브러리는 잔차합 또는 평균,1/2 유무를 다르게 정의한다. 그러므로 동일한 λ 숫자가 같은 정규화 강도를 뜻하지 않는다. 패널티를 넣어 학습 자료와의 차이가 조금 커져도 새 자료의 오차가 줄 수 있지만 그것은 별도 평가 문제이며 패널티 목적값만 보고 판단하지 않는다.

매끄러운 L2 와 꺾이는 L1

J2 의 도함수는(w−3)+λw 다.0 으로 놓으면 w=3/(1+λ), 이계미분 1+λ>0 이라 유일 최소다. λ가 커지면 양의 계수가 0 쪽으로 줄지만 유한 λ에서는 이 예의 계수가 정확히 0 은 아니다. 일반 다변수에서 일부 계수가 0 일 수 없다는 보편 주장은 아니다.

J1 은 w>0 에서 도함수 w−3+λ, w<0 에서 w−3−λ다. λ<3 이면 양의 해 3−λ가 있고, λ≥3 이면 0 의 왼쪽 기울기는음수·오른쪽은비음수가 되어 최소 0 이다. 따라서 이 예의 해는 max(3−λ,0)다. L1 의 꺾임은 일정 범위의 입력 계수를 정확히 0 으로 만들 수 있다.

단위와 적용 범위 남기기

같은 예측을 x 의 100 배 스케일로 표현하면 새 계수 v=w/100 이다. 이 v 에 같은 λ를 붙이면 원래 예측의 패널티가 L1 에서 1/100, L2 에서 1/10000 로 달라진다. 특성 간 단위 차이가 벌점의 의미를 바꾸므로 표준화 등의 정책을 훈련 자료에서만 정해야 한다.

L1 은 모든 계수를 반드시 0 으로 만들지 않고 선택한 특징이 원인이라고 증명하지도 않는다. 상관된 특징의 선택은 불안정하거나 여러 최적해가 있을 수 있다. L2 의 유일성도 여기처럼 양의λ와 제곱 목적 조건을 확인해서 말한다. 절편을 패널티에 포함할지는 모델 계약에 따로 적는다.

위 자체 J1/J2 에서 λ=1 일 때 최소 계수와 자료 적합항½(w−3)²를 각각 계산하라.

소단원 4.3

교차검증과 학습곡선

정규화 강도를 고르는 점수와 최종 성적은 같은 자료에서 확인해도 될까?

준비 개념과 학습 목표

준비 개념

  • 훈련 자료는 계수 학습, 검증 자료는 설정 선택, 최종 test 는 선택 후 평가 역할이다.

  • 여기서는 평균 제곱 오차 MSE 를 쓰며 작을수록 좋다.

  • 아래 오차 표는 직접 만든 종이 입력이고 실제 모델 fit 결과가 아니다.

학습 목표

  • 분할 내부 학습과 최종 미사용 평가를 구별한다.

  • 동일 크기 fold 평균과 학습곡선의 조건부 해석을 계산한다.

fold 평균과 전체 사례 평균은 같은 모델을 고르는가?

새 가상 검증 기록은 fold 두 개이고 사례 수는 각각 1개와 9개다. 모델 A의 각 fold MSE는 0과 4, 모델 B는 3과 3이다. fold 하나에 같은 무게를 주면 A의 평균은 2, B는 3이다. 그러나 사례 하나에 같은 무게를 주면 A는 (1×0+9×4)/10=18/5, B는 3이다. 집계 목적에 따라 선택이 뒤집힌다.

어떤 평균이 맞는지는 평가 목표가 정한다. 각 사례를 대표하려면 사례 수로 가중한다. 각 집단을 동등하게 대표하려면 fold가 목표 집단이라는 근거와 동등 가중 정책을 명시해야 한다. 사례 수가 다른 fold에서 단순 평균을 계산했다는 사실만으로 오류라고 하거나 자동으로 전체 사례 평균이라고 부르면 안 된다.

가중 정책도 선택 전에 고정한다. A와 B의 점수를 본 뒤 A가 이기는 평균을 선택하면 집계 정책까지 검증 자료에 맞춘 것이다. 최종 모델과 평가 정책을 독립 test로 평가하고, 모든 전처리 fit은 각 훈련 fold 안에서 한다. 학습곡선의 간격이 작아지는 현상도 반복 훈련 예측의 분산을 직접 측정한 값이 아니다. 훈련·검증 오차가 둘 다 큰 채 가까워질 수 있으므로 간격과 오차 수준을 함께 읽는다.

먼저 확인할 개념
  • fold 평균의 분모와 최종 test

    동일한 fold 무게와 동일한 사례 무게를 명시하고 선택 점수와 새 평가를 구별한다.

  • 분산의 반복 훈련 대상

    학습곡선의 오차 차이를 고정 입력의 훈련 변동 분산과 구별한다.

선택용 자료와 평가용 자료를 나누기

최종 test 를 보고 λ나 특징을 반복 바꾸면 test 의 정보가 선택 과정에 들어간다. 이제 그 자료는 미사용 평가 역할이 아니다. 훈련 부분 안에서 설정 선택을 하고 마지막에 보관한 test 로 평가해야 한다. 검증 점수로 고른 최고 점수 자체도 선택에 의한 낙관이 있어 그대로 최종 일반화 성적이라 부르지 않는다.

기본 k-fold 에서는 선택용 훈련 묶음을 k 개의 겹치지 않는 fold 로 나누고 매번 k−1 개로 학습한 뒤 남은 1 개에서 평가한다. 각 반복마다 모델을 새로 학습한다. 동일 크기 fold 라면 fold MSE 평균은 모든 검증 관측의 제곱 오차 평균과 같다. 크기가 다르면 두 집계 방식이 다르므로 지표를 명시한다.

전처리도 훈련 과정 안에 넣기

평균·표준편차를 구하는 표준화나 특징 선택도 자료에서 정보를 얻는 학습 단계다. 먼저 전체 자료로 fit 한 뒤 CV 를 나누면 검증 fold 정보가 새어 들어간다. 각 fold 의 훈련 부분에서만 fit 하고 검증은 그 변환으로 transform 한다. 마지막 선택 후에는 전체 선택용 훈련 묶음에 다시 fit 해 보관 test 를 transform 한다.

같은 학생의 반복 관측이나 같은 기기의 연속 기록이 섞이면 행을 무작위로 나눠도 독립 평가가 아닐 수 있다. 새로운 사람을 예측할 목표면 사람 단위 그룹 분할, 미래를 예측할 목표면 과거로 학습하고 뒤 시간에 평가하는 분할이 필요할 수 있다. CV 라는 이름만으로 누출이나 분포 변화가 없어지지는 않는다.

학습곡선은 표본 수를 바꾸는 비교

학습곡선은 설정을 고정하고 훈련표본 수에 따른 train·validation 손실을 비교한다. λ처럼 설정 값을 바꾸는 validation curve 와 다르다. 표본이 작을 때 훈련오차가 낮고 검증오차가 높다가 표본 증가로 간격이 줄면 표본 민감성을 줄일 여지가 있다는 단서다.

둘 다 높은 오류에서 가까워지면 표현 부족이나 강한 정규화 등을 의심할 수 있다. 다만 누출·다른 분포·잘못된 목표·최적화 실패도 확인해야 하므로 곡선만으로 정확한 편향과 분산을 계산했다고 주장하지 않는다. 더 많은 자료가 반드시 더 좋은 검증값을 주거나 모든 과소적합을 해결한다고 보장하지 않는다.

작은 간격이 숨긴 큰 오차

훈련 사례 수가 20개, 40개, 80개일 때 훈련 MSE는 각각 0.70, 0.75, 0.78이고 검증 MSE는 각각 0.90, 0.85, 0.82다. 모든 성능이 좋아진다고 할 수 있나?

  1. 훈련과 검증의 MSE 간격은 각각 0.20, 0.10, 0.04로 줄어든다.

  2. 훈련 MSE는 오히려 커지고 검증 MSE는 줄지만 마지막 검증 MSE도 0.82다.

간격 감소는 관찰된다. 허용 오차와 새 평가 없이 충분한 성능이나 분산 제거를 인증하지 못한다.

오해와 반례

CV 를 쓰면 전체 자료로 미리 표준화해도 되고 최종 test 를 계속 보고 λ를 바꿔도 된다.

전처리 fit 은 각 훈련 fold 에만 해야 한다. 최종 test 를 설정 선택에 쓰면 미사용 평가가 아니라 선택용 자료가 된다. CV 는 정보 흐름 규칙을 자동 면제하지 않는다.

두 fold의 사례 수가 n₁,n₂이고 MSE가 a,b일 때 단순 평균과 사례 가중 평균이 같을 조건을 유도하라.

힌트 2

(n₁−n₂)(a−b)를 확인한다.

풀이와 답 확인

  1. 가중 평균에서 단순 평균을 빼면 (n₁−n₂)(a−b)/(2(n₁+n₂))다.

  2. 양의 사례 수에서는 n₁=n₂ 또는 a=b일 때 두 평균이 같다.

서로 다른 사례 수만으로 항상 값이 다르다고 단정하지 않는다.

흔한 오답에서 다시 생각하기

사례 수가 다르면 두 평균은 반드시 다르다.

다른 문제에 적용하기

같은 평가 계획의 세 오류를 고쳐라. ① 고정 입력 f=2, Z와 ε가 독립인 ±1 균등 변수다. h₁=3+Z와 h₂=3−Z의 평균을 독립 Y=2+ε와 비교하라. 편향·분산·위험을 구하라. ② 중복 특성 목적 J₁=½(u+v−4)²+|u|+|v|에서 (1,2)와 (4,−1)의 값을 비교하고 모든 최소해를 적어라. ③ 사례 수 1개와 9개인 두 fold에서 A의 MSE는 0과 4, B는 3과 3이다. 사례 동등 정책과 fold 동등 정책의 선택을 각각 구하고 어느 정책을 채택할지 결정하는 근거와 새 test의 역할을 적어라.

힌트 1

첫 계산은 평균 예측과 f의 차이 및 독립 새 잡음을 분리한다. 둘째 계산은 합 계수와 절댓값 합을 따로 구한다.

힌트 2

마지막 계산은 fold 손실 합을 복원한 뒤 분모를 정한다. 점수를 본 뒤 유리한 정책을 고르는 과정을 최종 평가와 구별한다.

풀이와 답 확인

  1. 평균 예측은 3이므로 편향은 1, 분산은 0이다. 독립 새 잡음 분산은 1이어서 위험은 2다.

  2. (1,2)는 합 3, 절댓값 합 3으로 전체 목적 7/2다. (4,−1)은 같은 합이지만 절댓값 합 5여서 목적 11/2다. 모든 최소해는 비음수 u와 v의 합이 3인 집합이다.

  3. 사례 동등 정책은 A의 손실 합 36과 B의 손실 합 30을 각각 10으로 나누어 B를 선택한다. fold 동등 정책은 A의 평균 2와 B의 평균 3으로 A를 선택한다.

  4. 목표가 사례인지 동등 집단인지와 fold 구성의 의미에 따라 정책을 사전 정한다. 모델과 정책을 고정한 뒤 선택에 쓰지 않은 test로 새 성능을 평가한다.

① 편향 1, 분산 0, 위험 2다. ② 목적은 7/2와 11/2이며 모든 최소 배분은 u≥0, v≥0, u+v=3이다. ③ 사례 동등 선택은 B, fold 동등 선택은 A다. 평가 목표 없이 어느 정책이 맞는지 단정하지 않고 독립 test를 별도로 유지한다.

해결한 뒤 점검할 것

  • 평균으로 변동을 없애도 편향과 새 잡음이 남는 이유를 설명한다.

  • 예측 합이 같아도 패널티가 다를 수 있고 최소 배분이 유일하지 않음을 보인다.

  • 각 집계의 분모와 선택 정책의 사전 결정 근거를 쓰며 선택 점수를 실제 test 결과로 보고하지 않는다.
