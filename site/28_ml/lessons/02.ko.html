소단원 2.1

벡터미분과 gradient

손실이 숫자 하나인데 조절할 매개변수가 두 개라면 어느 방향으로 움직여야 할까?

준비 개념과 학습 목표

준비 개념

  • 미니복습: 열벡터 w=(w₁,w₂)ᵀ는 두 수를 순서대로 모은 것이다. 내적 uᵀv=Σuᵢvᵢ, 길이 ||v||₂=√Σvᵢ²이다. 행렬 A가 m×n이고 w가 n×1이면 Aw는 m×1이다.
  • 한 변수 미분은 작은 변화에 대한 선형 근사다. 편미분 ∂J/∂wᵢ는 다른 좌표를 고정하고 그 좌표만 바꾼다. 이번 정의는 실수 좌표와 보통의 Euclidean 내적에 대한 스칼라 손실이며 복소 미분이나 임의 내적의 gradient는 별도다.

학습 목표

  • 스칼라 손실의 gradient와 미분 변수를 명시한다.
  • 잔차 전개로 최소제곱 gradient와 Hessian을 유도한다.
  • 감소 방향·유한 갱신·최적성의 서로 다른 조건을 설명한다.

1. 편미분을 모아 선형 근사를 만든다

열벡터 관례로 ∇J(w)=(∂J/∂w₁,…,∂J/∂wₙ)ᵀ를 쓴다. 열린 영역에서 J가 w에 대해 미분가능하면 J(w+h)=J(w)+∇J(w)ᵀh+o(||h||₂)이다. 모든 편미분이 존재한다는 사실만으로 이 전체 선형 근사가 보장되지는 않는다. 이웃에서 편미분이 연속인 C¹ 함수는 미분가능하다는 충분조건을 사용할 수 있다.

방향 v로의 변화율은 ∇J(w)ᵀv이다. ||v||₂=1에서 Cauchy–Schwarz에 의해 이 값은 −||∇J||₂ 이상이고 gradient가 0이 아니면 v=−∇J/||∇J||₂에서 최소다. 이는 그 점 근처의 1차 방향 선택이다. 합성함수에서는 미분 변수를 구별한다. A가 m×n, w가 n×1이고 F:ℝᵐ→ℝ이면 ∇F(Aw)는 F의 입력에 대한 m×1 벡터이고 ∇w F(Aw)=Aᵀ∇F(Aw)는 w에 대한 n×1 벡터다. m=n이라 두 크기가 같아도 미분 대상과 계수는 구별해야 한다. 벡터 출력 Aw의 미분은 Jacobian A라고 부르고 스칼라 손실 gradient와 구별한다.

2. 잔차를 전개하면 전치가 필요한 이유가 보인다

A∈ℝ^{m×n}, y∈ℝᵐ는 고정 자료, J(w)=½||Aw−y||₂²로 놓자. r=Aw−y이고 변화 h를 넣으면 J(w+h)−J(w)=rᵀAh+½||Ah||₂²이다. 첫 항이 (Aᵀr)ᵀh이므로 ∇J=Aᵀr, Hessian H=AᵀA다. 잔차 m개를 매개변수 n개의 변화율로 모으기 때문에 Aᵀ를 곱한다. 이 미분 공식에는 A의 열 독립이나 역행렬이 필요하지 않다.

H는 대칭이고 vᵀHv=||Av||₂²≥0이다. ∇J(w*)=0이면 같은 전개에서 J(w*+h)−J(w*)=½||Ah||₂²≥0이므로 w*는 전역 최소점이다. A의 영공간에 비영 벡터가 있으면 여러 최소점이 가능하다. 일반 C² 함수의 Hessian은 혼합 편미분 연속성 아래 대칭이지만 모든 목적함수의 stationary point가 최소점이라는 결론은 아니다.

3. 감소 방향은 무조건 큰 걸음을 허용하지 않는다

gradient가 0이 아니고 미분가능한 점에서 h=−η∇J를 넣으면 η→0⁺일 때 손실 변화는 −η||∇J||₂²+o(η)이다. 따라서 충분히 작은 양의 η는 감소하지만 임의의 큰 η는 보장되지 않는다. 값이 0인 gradient는 1차 판단이 멈췄다는 뜻이며 안장점·최대점일 수 있다. J(u,v)=u²−v²의 원점은 gradient가 0이지만 v축으로 감소한다.

실제 학습에서는 손실의 합/평균, 매개변수 순서와 shape, 정규화 항, 부동소수점 자료형까지 명시해야 한다. 평균 손실은 합 손실 gradient를 m으로 나누므로 같은 η도 다른 갱신이다. 자동미분을 실행했다고 수식·데이터 분리·최적성까지 확인된 것은 아니다. 다음 소단원의 수치 오차와 마지막 소단원의 갱신 조건을 함께 확인한다.

중간 과정을 따라가는 예제

정확한 실수 산술에서 A=[[1,0],[1,2]], y=(1,3)ᵀ, w=(0,1)ᵀ의 J와 gradient를 구하고 η=0.1로 한 번 갱신한 손실을 확인하라.

  1. Aw=(0,2)ᵀ이므로 r=(−1,−1)ᵀ이고 J=½(1+1)=1이다. A의 크기는 2×2이고 잔차도 2×1이다.
  2. Aᵀr=[[1,1],[0,2]](−1,−1)ᵀ=(−2,−2)ᵀ이다. 전치 없이 계산하는 일반 규칙은 차원과 계수가 맞지 않는다.
  3. w_new=w−0.1∇J=(0.2,1.2)ᵀ이다. 새 예측은 (0.2,2.6)ᵀ, 새 잔차는 (−0.8,−0.4)ᵀ이다.
  4. J_new=½(0.64+0.16)=0.4로 감소했다. H=[[2,2],[2,4]]이며 이 한 번의 감소만으로 모든 η의 감소나 학습 일반화를 증명하지 않는다.

J=1, gradient=(−2,−2)ᵀ, 새 손실 0.4다. 정확 산술의 자체 종이 계산이며 실제 학습 실행은 아니다.

소단원 2.2

부동소수점과 조건수

컴퓨터가 작은 차이를 잃는 문제와 입력의 작은 오차가 답을 크게 바꾸는 문제는 어떻게 다를까?

준비 개념과 학습 목표

준비 개념

  • 미니복습: 과학적 표기는 m×10ᵉ처럼 유효숫자와 지수를 나눈다. 절대 오차는 |ŷ−y|, y≠0일 때 상대 오차는 |ŷ−y|/|y|다. 출력이 0이면 이 상대식은 정의되지 않아 절대 또는 기준 규모를 더한 오차를 쓴다.
  • 함수 y=f(x)는 계산할 문제이고 어떤 순서로 연산하는가는 알고리즘이다. 입력 측정·모형·학습 표본 오차와 반올림 오차는 다른 원인이다. 아래 계산은 제한된 십진 숫자 종이 모형이며 실제 binary64나 Python float 실행 결과가 아니다.

학습 목표

  • 반올림과 연산 순서가 결과에 미치는 영향을 모형으로 추적한다.
  • 조건수를 미분으로 유도하고 근사 적용 범위를 밝힌다.
  • 전방/후방 오차와 알고리즘 안정성·문제 민감도를 구별한다.

1. 유한한 유효숫자는 실수 산술과 다르다

부동소수점은 부호·유효숫자·지수의 유한 표현이다. 정상 범위의 round-to-nearest 연산은 자주 fl(a op b)=(a op b)(1+δ),|δ|≤u라는 상대 오차 모형으로 분석한다. 이는 overflow·underflow와 0 주변의 모든 경우를 자동 포괄하지 않는다. 비정규 수·무한대·NaN과 런타임 예외 처리도 실제 형식과 환경 계약을 확인해야 한다.

여기서는 지수 범위가 충분하고 유효숫자 세 자리, 0을 정확히 표현하며 매 연산 후 가장 가까운 값으로 반올림하고 동률이면 마지막 유효숫자가 짝수인 값을 택하는 자체 십진 모형을 고정한다. 아래 숫자는 동률이 아니다. 1000+1은 1001을 세 자리로 반올림해 1000이 된다. 따라서 (1000+1)−1000은 0이지만(1000−1000)+1은 1이다. 같은 실수식에 결합법칙을 적용해도 이 모형의 실행 순서는 달라진다. 이 차이를 모든 실제 자료형의 출력으로 일반화하지 않는다.

2. 조건수는 문제의 국소 민감도를 나타낸다

스칼라 f가 x의 이웃에서 미분가능하고 x≠0,f(x)≠0이면 f(x+Δx)−f(x)=f′(x)Δx+o(|Δx|)다. 상대식으로 나누면 작은 변화에 대해 |Δy|/|y|≈κ_f(x)|Δx|/|x|, κ_f(x)=|xf′(x)/f(x)|를 얻는다. 이 값은 그 점과 상대 오차 선택에 의존한다. 유한한 큰 섭동에서 그대로 성립하는 등식이나 전역 보증은 아니다.

f(x)=1/(x−1)은 x≠1에서 정의되고 κ=|x/(x−1)|다. x=1.001에서는 1001로 크다. 극점 가까이의 입력 오차가 출력 상대 오차로 크게 나타날 수 있다는 뜻이다. f(x)=2x는 x≠0에서 κ=1이다. 조건수가 크다는 말만으로 계산이 틀렸다는 뜻은 아니며 정확한 입력과 정확 산술에서는 그 정의된 답을 얻는다.

3. 계산 방법의 안정성과 자료의 민감도를 따로 진단한다

전방 오차는 계산값과 원래 문제의 정답 차이다. 후방 오차는 계산값이 정확한 답이 되는 가까운 입력 문제까지의 변화다. 작은 후방 오차를 만드는 방법도 민감한 문제에서는 큰 전방 오차를 낼 수 있다. 후방 안정성은 허용 입력 섭동·오차 척도와 문제 크기를 명시한 성질이며 몇 개 예제 성공만으로 판정하지 않는다.

가까운 큰 수의 뺄셈은 이미 입력에 들어 있는 작은 오차를 작은 차이의 큰 상대 오차로 드러낼 수 있다. 뺄셈 연산 자체가 정확히 표현되더라도 입력 정확도가 손실될 수 있다. 정밀도 증가·알고리즘 재구성·입력 재측정은 해결하는 원인이 다르다. 모델에 잘못 정한 표적이나 모집단 이동은 부동소수점 정밀도만 높여 해결되지 않는다.

중간 과정을 따라가는 예제

정확한 유리수로 f(x)=1/(x−1), x=1.001을 계산한다. 입력을 Δx=0.000001만큼 늘린 경우 실제 상대 출력 변화와 조건수 1차 예측을 비교하라.

  1. x=1001/1000이고 f(x)=1000이다. f′(x)=−1/(x−1)²이므로 κ=1001이다. 두 입력 모두 1을 넘는다.
  2. 새 입력은 1.001001이고 새 답은 1/0.001001=1000000/1001이다. 이는 1000보다 작은 값이다.
  3. 상대 입력 변화는 (1/1000000)/(1001/1000)=1/1001000이다. 실제 상대 출력 변화는|1000000/1001−1000|/1000=1/1001이다.
  4. 1차 예측은 1001/1001000=1/1000이다. 실제 1/1001과 가까우나 동일하지 않다. Δx→0에서의 미분 근사와 정확한 유한 변화식을 구별한다.

한 단계 더

심화: 두 실수 입력 x,y의 차이 s=x−y를 생각하라. 성분별 상대 입력 변화 |Δx|≤ε|x|,|Δy|≤ε|y| 아래 |Δs|/|s|≤ε(|x|+|y|)/|x−y|다 (s≠0). x=1.0001,y=1에서는 이 상계 계수 20001이다. 두 섭동의 부호를 반대로 고르면 상계가 달성된다. 이는 앞의 단일 변수 κ와 입력 섭동 계약이 다르다. 다변수 조건수에서는 노름과 어떤 변수를 바꾸는지 먼저 명시해야 한다.

소단원 2.3

표준화와 경사하강

같은 크기의 걸음을 두 매개변수에 적용할 때 한쪽만 계속 튀는 이유는 무엇일까?

준비 개념과 학습 목표

준비 개념

  • 미니복습: 평균 μ=Σxᵢ/N이고 이번 열별 표준편차는 s=√(Σ(xᵢ−μ)²/N)다. N≥1, 유한한 훈련값을 가정하며 표본분산의 분모 N−1과 구별한다. 표준화 z=(x−μ)/s에는 s>0이 필요하다.
  • 경사하강은 w_new=w−η∇J(w)로 값을 갱신한다. η는 양의 걸음 크기다. 이번 이론 예제는 정확 실수 산술의 전자료 gradient이며 확률적 minibatch·장치 실행·실제 모델 학습은 하지 않는다.

학습 목표

  • 훈련 자료에서만 통계를 만들고 같은 변환을 다른 분할에 적용한다.
  • 이차 손실의 고유방향 갱신과 안정 걸음 구간을 증명한다.
  • 스케일·상관·조건수·일반화와 정규화의 차이를 설명한다.

1. 통계의 계산 대상과 영분산 처리를 먼저 정한다

각 열의 μ,s는 훈련 분할에서만 산정하고 검증·시험에는 보존한 값을 사용한다. 자료 [2,4]의 μ=3,s=1이므로 훈련 표준값은 −1,1이고 시험값 10은 7이다. 시험값을 포함해 μ를 다시 맞추면 훈련 변환이 시험 분포에 의존하는 누수가 생긴다. 그룹/시계열 분리는 앞 단원의 평가 계약을 먼저 따른다.

s=0이면 나누기 식을 그대로 쓸 수 없다. 이 원고는 그런 열의 scale을 1로 정하고 훈련 평균만 빼는 관례를 명시한다. 훈련값 [4,4]는 [0,0], 새 값 6은 2다. 영분산이었던 훈련 열은 이 관례로도 단위 분산이 되지 않는다. 이는 읽은 StandardScaler의 기본 관례와 맞지만 실제 호출하지 않았으며 문서 버전과 실행환경을 혼용하지 않는다.

2. 곡률이 다른 방향에서는 같은 η도 다르게 작용한다

J(w)=½(w₁²+100w₂²)는 Hessian diag(1,100)의 양의 정부호 이차식이다. gradient=(w₁,100w₂)ᵀ이고 갱신은 w₁_new=(1−η)w₁,w₂_new=(1−100η)w₂다. 모든 시작점의 두 성분이 0으로 수축하려면 |1−η|<1,|1−100η|<1, 즉 0<η<0.02면 충분하고 이 모형에서는 필요하다. η=0.02의 두 번째 성분은 부호만 바뀌어 일반적으로 수렴하지 않는다.

일반 J(w)=½wᵀHw, H가 실수 대칭 양의 정부호일 때 직교 고유기저에서 각 좌표는 (1−ηλᵢ)배가 된다. 0<η<2/λ_max이면 모든 좌표 수축과 최소점 0으로 수렴이 따른다. 이 고유기저 증명은 고정 H의 이차식에 대한 것이다. 비선형 J에서는 gradient의 L-Lipschitz 조건 아래 선분 적분으로 J(w−ηg)≤J(w)−η(1−Lη/2)||g||₂²를 얻는다. 영역은 전체 ℝⁿ 또는 해당 선분을 포함해야 하고 감소만으로 비볼록 전역 최소를 보장하지 않는다.

3. 표준화는 좌표와 거리·패널티도 바꾼다

이 이차식에 q₁=w₁,q₂=10w₂라는 좌표를 쓰면 J=½(q₁²+q₂²)가 되어 곡률비가 1이다. q에서의 같은 η는 w에서의 같은 η와 다른 갱신이며 예측 목적함수가 같아도 경로는 달라진다. 특징 열의 표준화 역시 단위 차이를 줄일 수 있지만 모든 목적함수를 이처럼 구형으로 만들지는 않는다. 열들이 완전히 같은 표준값이면 상관과 열 종속성은 남는다.

선형 예측에서 zⱼ=(xⱼ−μⱼ)/sⱼ와 β+Σvⱼzⱼ는 원좌표 wⱼ=vⱼ/sⱼ,b=β−Σvⱼμⱼ/sⱼ로 같은 예측을 나타낸다(sⱼ>0 또는 명시한 양의 scale). 그러나 v의 L2 패널티를 원좌표 w의 같은 계수 L2로 그대로 바꾸면 일반적으로 다른 목적이다. 표준화는 이상값에 민감할 수 있으며 더 빠른 최적화가 더 좋은 시험 일반화나 인과 효과를 뜻하지 않는다.

중간 과정을 따라가는 예제

정확 산술에서 J=½(w₁²+100w₂²),w=(1,1)ᵀ로 시작한다. η=0.01과 0.03을 각각 한 번 적용하고 손실을 비교하라.

  1. 초기 gradient=(1,100)ᵀ, 손실=½(1+100)=50.5다. 두 실험은 같은 초기값에서 각각 시작한다.
  2. η=0.01이면 w_new=(0.99,0)ᵀ이다. 손실은 ½·0.99²=0.49005로 작아진다.
  3. η=0.03이면 w_new=(0.97,−2)ᵀ이다. 손실은 ½(0.9409+400)=200.47045로 커진다.
  4. 고유방향 배율은 첫 경우 0.99/0, 둘째 0.97/−2다. 0.03은 안정 구간(0,0.02) 밖이다. 단지 양의 η라는 조건은 충분하지 않다.

η=0.01의 새 손실 0.49005, η=0.03의 새 손실 200.47045다. 둘째가 튀는 이유는 큰 곡률 방향의 배율 −2다.

종이와 본문으로 직접 해보기

오해와 반례

표준화하면 자료가 정규분포가 되고 모든 gradient 갱신이 빨라지며 시험 성능도 좋아진다.

두 점 [2,4]를 표준화하면 두 점 [−1,1]일 뿐 정규분포가 아니다. 위 활동은 상관/종속성도 남긴다. 큰 η는 표준화 뒤에도 발산할 수 있고 시험 성능은 별도 분리 평가가 필요하다.

한 단계 더

심화: L-Lipschitz gradient의 감소 상계를 직접 유도하라. J(w+h)−J(w)=∫₀¹∇J(w+th)ᵀh dt이고 gradient 차이의 내적은 Lt||h||₂² 이하이므로 J(w+h)≤J(w)+gᵀh+(L/2)||h||₂²다. h=−ηg를 대입하면 본문식이다. 이는 C¹과 gradient Lipschitz, 허용 선분 조건의 정리이며 L을 모르는 실제 학습에서 임의 숫자 η가 이를 만족한다고 주장할 수 없다. 정해진 목적/자료 분할에서 baseline과 동일한 예산으로 비교하는 후속 실험이 필요하고 이번에는 수행하지 않았다.
