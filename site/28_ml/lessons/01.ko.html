소단원 1.1

지도·비지도학습

집값 정답이 있는 표와 면적만 있는 표에서 배울 수 있는 것은 같을까?

준비 개념과 학습 목표

준비 개념

  • 표의 한 행은 관측 하나, 열은 면적·방 수 같은 특징이다. x는 입력 특징, y는 예측하려는 표적이다. 특징이 둘이면 x=(면적, 방 수)처럼 순서 있는 묶음이다.

  • 함수 미니복습: f(x)=2x는 입력 3을 출력 6으로 보낸다. 모델은 이런 예측 규칙의 후보이고 학습은 자료로 후보의 값을 정하는 과정이다.

  • 평균은 합÷개수, 절댓값 |a|는 부호를 뺀 크기이다. |15−18|=3. 첫 단원은 미분·적분 없이 손으로 손실을 계산하며 최적화는 후속 단원에서 다룬다.

같은 세 정답에서 제곱오차가 작은 예측이 절대오차도 작을까?

새 가상 표적은 0, 0, 9이며 단위는 자체 수치 단위다. 언제나 0을 예측하는 후보 A는 절대오차가 0, 0, 9이고 제곱오차가 0, 0, 81이다. MAE는 3, MSE는 27이다. 언제나 3을 예측하는 후보 B는 절대오차가 3, 3, 6이고 제곱오차가 9, 9, 36이다. MAE는 4, MSE는 18이다. B의 MSE는 작지만 A의 MAE가 작으므로 목적 손실을 쓰기 전에 우수 후보를 하나로 정할 수 없다.

상수 c의 제곱손실은 [2c²+(c−9)²]/3=(c−3)²+18이다. 따라서 c=3에서 최소다. 절대손실은 0≤c≤9에서 [2c+(9−c)]/3=3+c/3이므로 이 구간에서는 c=0이 최소다. c<0이면 3−c, c>9이면 c−3이어서 전 범위에서도 c=0이 최소다. 앞 본문의 두 표적에서는 절대손실 최소가 구간 전체였지만 여기서는 중복된 0이 중앙 위치를 정해 유일한 최소를 만든다.

같은 숫자 0과 9를 두 범주의 이름으로 쓰는 별도 문제라면 그 차이 9는 가격 오차가 아니다. 항상 범주 0을 고르면 오분류율은 1/3이다. 범주 이름을 100과 101로 바꾸어도 오분류율은 같다. 또 정답 없이 특징을 묶는 군집은 거리를 정해야 한다. 특징 점 P=(0,0), Q=(2,0), R=(0,1)에서 P와 가장 가까운 다른 점은 R이다. 두 번째 좌표만 세 배로 바꾸고 같은 유클리드 거리를 쓰면 Q가 더 가까워진다. 비지도라는 이름이 단위 선택의 영향을 지우지 않는다.

정답과 어떤 함수를 배울지부터 정한다

지도학습에서는 관측 (xᵢ, yᵢ)의 모음으로 입력에서 표적을 예측하는 fθ를 정한다. θ는 조절할 수 있는 매개변수이다. 집의 면적으로 거래 가격을 예측하는 것은 수치 표적의 회귀, 사진으로 품종 이름을 예측하는 것은 범주 표적의 분류다. 같은 숫자 0·1도 가격 단위인지 클래스 이름인지에 따라 문제와 손실이 달라진다.

특징은 실제 예측 시점에 사용할 수 있는 정보로 정해야 한다. 거래 전 가격을 예측하는데 거래 완료 후 실제 결제금액을 특징으로 넣으면 정답을 입력에 옮긴 것일 뿐이다. 기록에는 집 ID·날짜처럼 분리를 위한 정보가 있을 수 있고 그 정보가 항상 모델 입력이어야 하는 것은 아니다. 관측 단위와 표적이 무엇인지를 먼저 문장으로 적는다.

손실은 틀린 정도를 수로 재는 계약이다

회귀 절대손실은 ℓ(ŷ, y)=|ŷ−y|, 제곱손실은 (ŷ−y)²이다. 분류의 0−1손실은 클래스가 같으면 0, 다르면 1이다. n≥1인 정수 개수의 훈련 자료에서 경험위험은 R̂(θ)=(1/n)Σℓ(fθ(xᵢ), yᵢ). 경험위험 최소화는 후보 집합에서 이 값을 작게 하는 θ를 찾는 문제다. 손실·단위·후보를 정하지 않으면 잘 학습했다는 말을 계산할 수 없다.

항상 같은 c를 예측하는 모델에 표적 10,20을 주면 제곱손실 평균은 [(c−10)²+(c−20)²]/2=(c−15)²+25이다. 그래서 c=15가 최소이며 미분 없이 완전제곱으로 증명한다. 절대손실은 10≤c≤20에서 모두 평균 5로 최소라 해가 유일하지 않다. 손실을 바꾸면 같은 자료에서도 학습 결과의 의미가 달라질 수 있다.

비지도학습도 목적과 검증 조건이 있다

비지도학습은 정답 y가 주어지지 않은 x들의 구조를 찾는다. 비슷한 집을 묶는 군집, 적은 축으로 표현하는 차원축소, 자료의 분포를 추정하는 작업이 예이다. 정답이 없다는 말은 목적함수나 가정이 없다는 뜻이 아니다. 군집의 거리·군집 수·특징의 단위가 달라지면 묶음이 달라진다.

훈련 점을 전부 외워 경험위험 0을 만들 수 있어도 보지 않은 새 집의 가격을 보장하지 못한다. 관심은 자료를 생성하는 대상 분포의 평균 손실 R(θ)=E[ℓ(fθ(X), Y)]이고 유한 훈련 손실은 그 대용값이다. 경험위험의 정의 자체는 독립 표본이 아니어도 쓸 수 있지만 새 표본 성능을 해석할 때는 표본과 미래 자료의 관계·분포·분리 가정을 추가해야 한다. 비지도 표현을 새 표본에 적용하는 귀납적 평가에서도 시험 자료로 표현 변환을 학습하면 분리 목적에 어긋난다.

중간 과정을 따라가는 예제

가격 단위를 가상의 가격 단위로 고정한다. 훈련 표적 10,20에 상수 제곱손실 모델을 맞춘 뒤 새 두 집의 실제 표적 18,22를 예측한다. 훈련 MSE와 새 자료 MAE를 구하라.

  1. 훈련 제곱손실을 (c−15)²+25로 정리해 학습된 상수 15를 얻는다.

  2. 훈련 제곱오차는 25와 25이므로 MSE 25이다.

  3. 새 예측은 두 집 모두 15, 절대오차는 3과 7이다.

  4. 새 자료 MAE=(3+7)/2=5이며 훈련 MSE 25와는 단위도 다르다.

c=15, 훈련 MSE 25, 새 자료 MAE 5이다. MSE는 가격 단위², MAE는 가격 단위이므로 숫자 크기만 비교하지 않는다.

조건을 바꾸어 비교하기

두 손실이 뒤집는 후보 순위

표적 0, 0, 9에서 상수 0과 3의 두 평균 손실을 구하라.

  1. 상수 0의 MAE는 9/3=3이며 MSE는 81/3=27이다.

  2. 상수 3의 MAE는 12/3=4이며 MSE는 54/3=18이다.

MAE는 상수 0, MSE는 상수 3을 선호한다.

비교할 점

앞 본문의 훈련 MSE와 새 MAE 비교를 넘어 같은 평가 사례에서도 손실별 순위가 바뀐다.

특징 단위가 바꾸는 이웃

P=(0,0), Q=(2,0), R=(0,1)에서 P의 가까운 점을 구하고 두 번째 좌표를 세 배로 바꾼 뒤 비교하라.

  1. 처음 거리는 PQ=2, PR=1이다.

  2. 변환 뒤 Q=(2,0), R=(0,3)이므로 거리는 각각 2와 3이다.

가까운 점이 R에서 Q로 바뀐다.

비교할 점

오해와 반례

비지도학습에는 정답이 없으니 목적함수와 데이터 평가가 필요 없다.

군집도 어떤 거리에서 얼마나 가까운 묶음을 만들지 목적을 정한다. 면적을 m²에서 다른 단위로 바꿀 때 거리 가중치가 달라지면 결과가 달라질 수 있다. 새 집에 적용할 평가를 하려면 비지도 전처리도 시험 자료와 분리해야 한다.

연습 1 · 값과 상태 예측

표적 0, 0, 9에 상수 2를 예측한다. MAE와 MSE를 구하고 A/B와 각 손실별로 비교하라.

힌트 1

절대오차는 2, 2, 7이다.

힌트 2

제곱오차 합은 4+4+49다.

풀이와 답 확인

  1. MAE는 11/3이고 MSE는 57/3=19다.

  2. MAE 순서는 A의 3 < 11/3 < B의 4이며 MSE 순서는 B의 18 < 19 < A의 27이다.

상수 2는 두 손실에서 모두 두 후보 사이에 있다.

흔한 오답에서 다시 생각하기

MSE 19가 MAE 11/3보다 크니 제곱손실 모델은 무조건 나쁘다.

서로 다른 단위의 열을 비교했다. 같은 손실 안에서 후보를 비교한다.

두 클래스 이름을 0과 9로 쓰면서 오분류율 대신 이름의 제곱 차이를 평균했다. 어떤 조건을 먼저 고쳐야 하나?

힌트 1

표적의 숫자가 수량인지 이름인지 묻는다.

힌트 2

이름 재부호화가 오류 판정을 바꾸면 안 된다.

풀이와 답 확인

  2. 이름을 100과 101로 바꾸어도 같은 분류 오류에 같은 손실을 준다.

숫자 저장 형식과 표적의 의미를 분리한다.

연습 3 · 직접 만들어 보기

표적 0, 0, 9에서 상수 제곱손실의 최소를 미분 없이 증명하라.

힌트 1

2c²+(c−9)²를 전개한다.

힌트 2

(c−3)²를 만들고 남는 상수를 찾는다.

풀이와 답 확인

  1. 평균은 c²−6c+27=(c−3)²+18이다.

  2. 제곱항은 0 이상이고 c=3에서만 0이다.

유일한 최소 상수는 3이며 최소 MSE는 18이다.

흔한 오답에서 다시 생각하기

훈련 손실을 최소화했으므로 모든 새 표적에도 MSE 18이다.

이 증명은 주어진 세 표적의 경험 손실에 대한 것이다. 미래 분포는 정하지 않았다.

연습 4 · 선택 심화

선택 심화는 기본 연습 뒤 더 탐구하고 싶을 때 풀어 보세요.

두 번째 좌표를 세 배로 바꾸어도 원래 거리 순서를 보존하려면 새 좌표의 거리식을 어떻게 정할까?

힌트 1

변환된 두 번째 차이를 3으로 다시 나눈다.

힌트 2

거리 제곱에서 두 번째 항의 가중치를 찾는다.

풀이와 답 확인

  1. 새 좌표의 거리를 sqrt((Δx)²+(Δy′/3)²)로 정한다.

  2. P와 R의 거리는 1로 돌아오고 P와 Q의 거리는 2로 유지된다.

표본과 모집단

표에 1000행이 있어도 1000개의 독립된 집을 관측했다고 말할 수 있을까?

준비 개념과 학습 목표

준비 개념

  • 모집단은 관심 대상의 전체, 표본은 실제 수집한 관측들이다. 같은 집의 두 날짜 기록은 두 행이지만 같은 집 정보가 공유될 수 있다.

  • 독립은 하나의 관측이 다른 관측의 분포에 정보를 주지 않는다는 조건이다. 동일분포는 관측마다 같은 분포를 따른다는 조건이며 둘은 별개다.

  • 미니복습: 성공 지시값 0/1의 평균은 성공 비율이다. 시간 순서가 있는 관측은 무작위 순서를 가정하기 전에 다음 시점에 무엇을 알 수 있었는지 묻는다.

학습 목표

  • 관심 모집단·표본 틀·관측 단위·목표 분포를 구분한다.

  • i.i.d.를 사용하는 이유와 시계열/그룹 데이터의 한계를 설명한다.

  • 평균 오차의 해석을 표본 설계와 연결한다.

기록이 많은 장치를 더 세면 새 장치의 평균 손실을 바꿀까?

새 가상 평가에서 장치 L의 네 기록 손실은 모두 0이고 장치 M의 한 기록 손실은 6이다. 다섯 행의 평균은 6/5다. 장치를 똑같은 비중으로 평가하면 장치별 평균 0과 6의 평균은 3이다. 두 수치 중 하나를 오산이라고 부르지 않는다. 새 기록을 표의 빈도대로 만날 질문과 새 장치를 같은 비중으로 만날 질문이 다른 것이다.

목표 환경에서 장치 L의 비중이 1/4, M의 비중이 3/4라고 따로 정하면 손실은 (1/4)×0+(3/4)×6=9/2다. 이는 두 장치 내부 손실이 목표 환경에서도 그대로라는 가정에 따른 값이다. 기록을 더 복제해 행 수를 늘려도 그 목표 비중이 바뀌지 않는다. 관측 단위·수집 비중·목표 비중을 세 칸으로 적으면 어떤 평균을 계산했는지 보인다.

독립성도 행 개수로 판정하지 않는다. 성공 지시값 Z가 0과 1을 각각 확률 1/2로 가지면 평균은 1/2, 분산은 1/4다. 똑같은 Z를 네 행으로 복사한 평균은 여전히 Z여서 분산도 1/4다. 독립인 네 지시값의 평균은 같은 평균 1/2이지만 분산은 1/16이다. 분산 계산의 모집단 모형을 따로 고정한 것이며 실제 장치 오차가 이 Bernoulli 모형이라는 주장은 아니다.

일반화는 어느 새 대상에 대한 주장인가

한 도시의 다음 달 거래 가격을 예측하는 문제와 같은 도시의 현재 미관측 집 가격을 예측하는 문제는 모집단이 다를 수 있다. 자료가 고가 아파트 거래 사이트에만 올라왔다면 이 표본 틀은 모든 주택을 포함하지 않는다. 관측행 수가 많아도 빠진 집단이나 비응답 구조를 자동으로 해결하지 못한다.

데이터의 모집단은 실제 유한 대상 목록일 수도 있고 미래 관측을 생성하는 확률분포 P일 수도 있다. 평균 손실 R=E_Pℓ는 어느 P에 대해 평균낼지 명시한다. 지역·시점·센서·고객군이 달라져 P가 바뀌는 분포 이동에서는 과거의 시험 점수를 새 환경 보장으로 그대로 쓰지 않는다. 수집 범위와 배포 대상의 차이를 기록하는 것이 첫 검토다.

독립 표본은 평균의 불확실성을 제어한다

표본 수 n은 양의 정수이다. 시험 자료와 독립적으로 정한 고정 모델의 손실 Lᵢ가 독립·동일분포이고 평균 μ, 유한 분산 σ²이면 표본 평균 L̄의 평균은 μ, 분산은 σ²/n이다. 분산은 평균에서의 제곱 거리의 기대값이고 독립일 때 서로 다른 손실의 공분산이 0이 되어 이 식을 얻는다. 표준편차가 1/√n으로 감소한다는 해석에는 독립 조건이 들어 있다.

일반적으로 Var(L̄)=[ΣVar(Lᵢ)+2Σ_{i<j}Cov(Lᵢ, Lⱼ)]/n²이다. 같은 집 복제본이 같은 손실을 갖고 함께 움직이면 공분산 항이 남는다. 집 10개를 각각 100번 복제하여 1000행으로 만들어도 독립 집 1000개와 같지 않다. 고정 모델의 독립 시험 손실 평균과, 같은 표본으로 모델을 선택하고 보고한 점수의 선택 편향도 구분해야 한다.

그룹·시간 구조에 맞춰 새 대상을 만든다

새로운 집의 성능을 보려면 같은 집 ID의 기록을 같은 분할에 묶는다. 새 환자 문제는 환자별, 새 기계 문제는 기계별 분리가 자연스럽다. 같은 대상의 미래를 예측하려는 문제에서는 그 대상의 과거를 훈련에 사용할 수 있지만 미래 표적·겹치는 결과 창을 과거 특징에 포함시키면 안 된다. 그룹 분리는 목적에 따른 도구이지 모든 문제에 무조건 동일한 정책은 아니다.

시계열에서는 과거 훈련→나중 검증→더 나중 시험처럼 예측 순서를 모사한다. 앞뒤 창이 겹치거나 표적을 만드는 기간이 길면 분할 경계의 간격도 고려한다. 시간 분리가 미래 분포 변화까지 제거하는 것은 아니며 그룹 분리와 시간 분리가 동시에 필요한 경우도 있다. 무작위 행 분리, 클래스 비율을 맞추는 층화, 그룹 독립성은 서로 다른 조건이다.

힌트 1

목표 평균은 q×0+(1−q)×6이다.

힌트 2

이를 원래 행 평균 6/5와 같게 놓는다.

풀이와 답 확인

  1. 목표 평균은 6(1−q)다.

  2. 6(1−q)=6/5에서 q=4/5다.

시험 답을 조금씩 보고 모델을 바꾼 뒤 높은 시험 점수를 얻으면 공정한 평가일까?

준비 개념과 학습 목표

준비 개념

  • 훈련은 매개변수를 맞추는 자료, 검증은 후보·설정을 고르는 자료, 테스트는 선택을 끝낸 뒤 최종 평가하는 자료이다. 이름표보다 실제 사용 목적이 기준이다.

  • 미니복습: 평균 중심화 x−μ에서 μ는 자료에서 배운 수치이다. 고정된 단위변환은 원래 정한 상수지만 중심화·결측 대치·PCA·특징 선택은 fit 자료에 의존한다.

  • 집 ID·시간은 분할 조건을 정한다. 동일 집 중복을 나누지 말아야 하는지, 미래 예측 순서를 유지해야 하는지 먼저 명세한다.

학습 목표

  • 각 분할의 역할과 테스트를 통한 선택 편향을 설명한다.

  • 전처리 fit/transform과 목표 누수를 구체적 사례로 검사한다.

  • 그룹·시계열 분리 및 교차검증에서의 전처리 학습 범위를 명시한다.

자료 이름이 validation이면 모델 선택 후 그 점수를 독립 시험으로 보고해도 될까?

새 종이 후보 두 개의 검증 평균 손실은 A가 0, B가 2이고, 별도 시험 손실은 A가 4, B가 1이라고 주어진다. 검증만으로 고정한 선택은 A이며 이후 시험에서 보고할 값은 4다. 시험값 1을 보고 B로 바꾼 뒤 그 1을 독립 최종 성능으로 쓰면 시험 자료가 후보 선택에 사용된 것이다. 수치 표는 자체 가상 기록이며 실제 모델을 두 번 학습한 결과가 아니다.

전처리의 사용 이력도 따라간다. 새 훈련 특징은 1과 5이며 평균은 3이다. 평가 특징 9를 transform하면 6이다. 전체 세 값을 먼저 fit한 평균은 5여서 평가 변환은 4가 된다. 라벨이 없어도 평가 입력이 학습 기준을 바꾼다. 고정 길이 단위 변환과 자료에서 학습한 평균을 같은 과정으로 취급하지 않는다.

두 fold를 생각해 보자. fold F의 훈련은 [1,5], 검증은 [9]라 평균 3을 사용한다. fold G의 훈련은 [9], 검증은 [1,5]라 평균 9를 사용하여 검증값은 −8과 −4다. 처음 전체 평균 5를 만들어 공유하면 각 검증 행이 자기 fold의 학습에 들어간다. Pipeline은 fold 안의 fit 순서를 돕지만 잘못된 그룹 분리나 미래 특징을 자동으로 적법하게 바꾸지 않는다.

먼저 확인할 개념

    같은 단원의 평균 중심화와 선택 이력을 fold마다 확인한다.

  • 새 대상과 시간 순서

    전처리 도구와 별개로 장치 ID·미래 정보 접근을 검사한다.

선택에 사용한 자료는 최종 독립 시험이 아니다

훈련에서 모델의 θ를 정하고 검증에서 복잡도·정규화·특징·분류 임계값 등을 고른다. 테스트는 정한 절차를 고정한 뒤 새 자료에서 손실을 측정한다. 테스트 점수가 낮을 때마다 설정을 바꿔 다시 보고하면 테스트를 선택용 검증으로 사용한 것이다. 파일명이 test라고 적혀 있어도 독립 평가의 역할은 사라진다.

검증자료에 반복 적응하면 검증점수도 낙관적이 될 수 있으므로 후보 수와 선택 절차를 기록한다. 마지막 모델을 훈련+검증에 다시 fit하는 방법은 가능하지만 모든 선택을 끝낸 뒤 테스트를 별도로 유지해야 한다. 교차검증에서는 각 fold의 훈련 부분만으로 학습·전처리를 정하고 남은 부분에 적용한다. 데이터가 작을 때 선택과 평가를 분리하는 중첩 교차검증은 후속 단원의 주제다.

정답을 보지 않은 전처리도 누수일 수 있다

train 특징 [2,4]의 평균은 3이다. 중심화한 훈련값은 [−1,1]이고 시험값 12에는 같은 μ=3을 적용해 9로 변환한다. 전체 [2,4,12]의 평균 6으로 먼저 fit하면 훈련 [−4,−2], 시험 6이 되어 테스트 분포가 훈련 좌표계를 바꾼다. 라벨을 보지 않았어도 귀납적 새 표본 평가에서 시험 정보가 학습에 들어간 것이다.

표준화·대치·PCA·특징 선택도 훈련 fit과 검증/시험 transform을 나눠야 한다. Pipeline은 이런 순서를 관리하는 도구지만 데이터 분할 자체의 그룹·시간 오류나 부적절한 특징까지 자동 고치지는 않는다. 이미 정해진 m²→cm² 변환처럼 데이터에서 값을 학습하지 않는 고정 규칙과 구분한다. 시험 입력 전체를 미리 이용하는 transductive 설정을 연구할 수는 있으나 그 다른 배포 조건을 명세하고 새 표본 귀납 성능과 혼동하지 않는다.

누수는 분할 경계와 예측 시점을 함께 본다

훈련 여섯 기록 H1, H2, H3, H4, H5, H6, 테스트 두 기록 H1′, H7을 놓자. H1′이 같은 집 H1의 복제이면 새 집 시험 목적에서 중복 정보가 양쪽에 들어간다. 전체 여덟 기록을 그룹으로 묶어 train=H1, H1′, H2, H3, H4, validation=H5, test=H6, H7 같은 5/1/2 분할을 할 수 있다. 아주 작은 분할이 안정적 성능 증거라는 뜻은 아니다.

목표 누수는 예측할 답 또는 답 이후에만 알 수 있는 정보를 입력에 쓰는 문제다. 거래 전 가격 예측에 결제 완료액, 질병 진단 전 예측에 확진 후 처방 정보를 쓰면 행을 완전히 분리해도 문제가 남는다. 시계열의 이동 평균은 그 시점까지의 과거로만 계산하고, 그룹 반복 기록·겹친 시간 창은 목적에 맞게 경계를 나눈다. 누수 검사는 단순 중복 행 제거 한 번으로 끝나지 않는다.

시험 특징을 포함하여 PCA나 평균을 fit하는 전처리 누수, 같은 집 복제의 그룹 누수, 예측 시점 이후 정보를 쓰는 목표 누수는 테스트 라벨을 직접 보지 않아도 발생한다. 입력이 언제 어떻게 이용 가능했는지 검사한다.

자기점검

검증 점수로 모델을 고른 뒤 같은 값을 최종 독립 테스트 점수라고 보고해도 되는가?

  3. 시험 ID·그룹·시간·fit 범위·선택 이력과 독립 시험값을 기록한다.

훈련+검증 재학습은 가능하지만 시험을 섞는 재학습은 별도 최종 평가를 잃는다.

검증 후보의 오차가 우연히 흔들릴 때 많은 후보 중 최소 관측 오차를 고르면 실제 평균보다 낮은 값을 선택할 수 있다. 독립 최종 시험은 이 선택 과정을 포함한 절차의 성능을 평가한다. 최종 시험으로 또 선택했다면 새 평가 자료나 미리 정한 중첩 평가 설계가 필요하다. 보고서에는 후보, 분할 ID, 시간 경계, 전처리 fit 범위와 선택 횟수를 적는다.

다른 문제에 적용하기

가상 장치 평가 계획을 수정하라. L의 네 행 손실은 모두 0, M의 한 행 손실은 6이다. 새 장치를 동일가중 평가한다고 쓰면서 행 평균을 보고했다. 별도 상수 예측 문제의 표적은 0, 0, 9인데 제곱손실 최소 상수와 절대손실 최소 상수가 같다고 했다. 훈련 특징 [1,5]와 평가 특징 [9]를 전체 평균 5로 중심화했고, 예측 시각 8에 시각 9 공개 특징을 사용했다. 각 평균·목적·정보 경계를 고쳐라.

힌트 1

행의 비중과 장치의 비중을 분리하고 두 손실을 같은 표적에서 직접 계산한다.

힌트 2

fit 자료를 훈련으로 제한하고 특징 공개 시각을 실제 예측 시각과 비교한다.

풀이와 답 확인

  1. 행 평균은 6/5지만 동일가중 장치 평균은 (0+6)/2=3이다. 두 장치 내부 평균 유지와 목표 비중을 명시한다.

  2. 제곱손실은 (c−3)²+18이므로 최소 상수는 3이며 MSE는 18이다. 절대손실 최소 상수는 0이며 MAE는 3이다. 상수 3의 MAE는 4다.

  3. 훈련 평균 3을 fit하여 평가값 9를 6으로 transform한다. 전체 평균 5로 만든 4는 현재 귀납적 평가의 계산이 아니다.

  4. 시각 9 공개 특징은 시각 8의 예측에 쓰지 않는다. 도구와 행 분리가 맞아도 시간상 가용성은 따로 검사한다.

동일가중 장치 손실은 3, 제곱손실 최소 상수는 3, 절대손실 최소 상수는 0, 적법한 평가 중심화 값은 6이다. 미래 공개 특징을 제외한다.

해결한 뒤 점검할 것

  • 행 평균 6/5와 장치 평균 3의 다른 가중치를 설명한다.

  • 상수 0/3의 MAE 3/4와 MSE 27/18을 계산하고 손실·단위를 구별한다.

  • 훈련 fit/평가 transform과 선택 후 독립 시험의 역할을 설명한다.

  • 시각 가용성과 실제 모델·장치·학생 실행 미수행을 분리한다.
