불균형 지표와 비용

천 개 중 스무 개만 중요한 사건이라면 모두 아니라고 답해도 좋은 모델일까?

준비 개념과 학습 목표

준비 개념

  • 혼동행렬

  • 분수와 비율

  • 분류 임계값

학습 목표

  • 양성 클래스를 정하고 혼동행렬을 계산한다.

  • 정확도·재현율·정밀도·F1의 분모를 구별한다.

  • 오류 비용과 검증 자료로 선택 조건을 정한다.

클래스별 탐지율이 같아도 새 모집단의 양성 예측은 같은 비율로 맞을까?

새 자체 모집단 U는 100명 중 실제 양성 20명, 음성 80명이다. 고정 판정 규칙의 양성 재현율은 1/2이고 음성 중 양성으로 오인하는 비율은 1/4라고 가정한다. 따라서 TP는 10, FN은 10, FP는 20, TN은 60이다. 다른 모집단 V는 100명 중 양성 80명이며 같은 두 조건부 비율을 유지한다고 가정하여 TP 40, FN 40, FP 5, TN 15를 얻는다. 실제 장치의 분포 이동 실험이 아니라 명시한 비율을 표에 적용하는 손모형이다.

U의 정밀도는 10/30=1/3이지만 V에서는 40/45=8/9다. 양성 재현율은 둘 다 1/2, 음성 재현율은 둘 다 3/4이므로 균형 정확도는 둘 다 5/8이다. 정밀도는 양성 예측 중 맞은 비율이어서 클래스 구성에 영향을 받는다. 양성 비중 π에서 같은 조건부 비율을 유지한다면 정밀도는 (π/2)/(π/2+(1−π)/4)=2π/(1+π)다. 같은 균형 정확도를 새 모집단의 같은 정밀도나 비용으로 번역하지 않는다.

FN 한 건 비용을 4, FP 한 건 비용을 1로 둔 자체 모형에서는 U의 총 비용이 60, V는 165다. 표본 크기가 둘 다 100이므로 평균 비용은 각각 3/5와 33/20이다. 이 수치는 비용이 사례별 일정하고 정답 비용이 0이라는 전제를 쓴다. 같은 비용 규약이라도 구성 변화가 총 비용을 바꾼다. 비율의 평균을 보고할 때도 각 표의 비율 평균인지 합친 혼동행렬에서 계산한 비율인지 먼저 정한다.

먼저 확인할 개념
  • 혼동행렬의 분모와 비용

    클래스별 재현율·정밀도의 서로 다른 분모를 그대로 사용한다.

  • 같은 평가 계약과 보고 조건

    모집단과 비용 규약이 바뀐 비교를 같은 실험으로 부르지 않는다.

무엇을 양성으로 볼지 먼저 정한다

이진 분류에서 찾으려는 사건을 양성으로 정한다. 실제 양성이면서 양성 예측이면 TP, 실제 양성인데 음성 예측이면 FN이다. 실제 음성의 양성 예측은 FP, 올바른 음성 예측은 TN이다. 실제 라벨의 신뢰성과 평가 모집단도 확인한다.

정확도는 (TP+TN)/N이다. 음성이 압도적으로 많으면 양성을 전혀 찾지 못해도 정확도가 높다. 클래스별 표본 수를 같이 보고 단순한 다수 클래스 기준모델과 비교해야 한다. 평가 자료의 다수 클래스를 보고 기준모델의 예측 클래스를 바꾸면 평가 정답을 선택에 사용한 셈이다.

각 지표의 질문과 분모가 다르다

정밀도는 TP/(TP+FP)로 양성이라고 부른 것 중 맞은 비율이고, 재현율은 TP/(TP+FN)로 실제 양성 중 찾은 비율이다. 이진 F1은 2TP/(2TP+FP+FN)이다. 균형 정확도는 양성 재현율과 음성 재현율 TN/(TN+FP)의 산술평균이다. 여기서는 두 실제 클래스가 모두 존재한다.

분모가 0이면 원래 비율이 정의되지 않는다. 보고서에는 미정의 표시 또는 사용하는 도구의 처리 규약을 적는다. 양성 예측이 하나도 없을 때 정밀도를 임의로 100%라고 보고하지 않는다. F1은 TN이나 구체적인 오류 비용을 직접 반영하지 않아 모든 목적의 단일 정답 지표가 아니다.

손실과 선택은 사용 목적에 맞춘다

가상의 단순 비용 모형에서 FN 한 건의 비용 cFN, FP 한 건의 비용 cFP를 정하면 총 비용은 cFN×FN+cFP×FP다. 이 식은 정답 비용을 0으로 두고 오류마다 비용이 일정하다는 가정이다. 안전·권리·필수 조건이나 사례별 다른 영향을 하나의 숫자로 자동 대체하지 않는다.

같은 점수 모델이라도 임계값에 따라 혼동행렬이 바뀐다. 임계값과 비용에 따른 선택은 학습·검증 단계에서 정하고, 최종 평가 정답을 반복해서 들여다보며 유리한 값으로 바꾸지 않는다. 아래 행렬은 계산 연습용 가정이며 실제 모델의 임계값 실험 결과가 아니다.

각 행의 네 칸 합과 실제 클래스 합을 먼저 확인한다. 마지막 행의 정밀도는 TP 합을 양성 예측 합으로 나눈 값이며 앞 두 정밀도의 산술평균이 아니다. 조건부 비율 유지도 본 모형의 가정이다.

중간 과정을 따라가는 예제

평가 표본 1000개 중 양성은 20개다. A는 모두 음성, B는 TP=15, FN=5, FP=45, TN=935다. 정확도와 B의 정밀도·재현율·F1, cFN=20와 cFP=1의 비용을 비교하라.

  1. A는 TN=980, FN=20이라 정확도 980/1000=98%지만 재현율 0이다. 정밀도의 분모는 0이라 미정의다.

  2. B의 정확도는 950/1000=95%, 정밀도 15/60=1/4, 재현율 15/20=3/4, F1=30/80=3/8이다.

  3. A 비용은 20×20=400, B 비용은 20×5+45=145다. 이 가상 비용에서는 정확도가 낮은 B가 더 낮은 비용이다.

B는 정확도 95%, 정밀도 25%, 재현율 75%, F1 37.5%다. 비용 145는 A의 400보다 작다. 선택은 정해진 비용 조건에 따른다.

U와 V의 정밀도·균형 정확도를 비교하라.

  1. U는 양성 예측 30명 중 10명, V는 45명 중 40명이 맞았다.

정밀도는 1/3과 8/9, 균형 정확도는 둘 다 5/8이다.

비교할 점

같은 균형 정확도에서 정밀도 동일을 결론내리지 않는다.

합치기와 비율 평균

U와 V를 합친 정밀도와 두 정밀도의 단순 평균을 구하라.

  1. 합친 TP는 50, FP는 25이므로 정밀도는 50/75=2/3이다.

  2. 단순 평균은 (1/3+8/9)/2=11/18이다. 원래 분모 30과 45가 다르다.

합친 2/3과 단순 평균 11/18은 다른 보고량이다.

비교할 점

합친 비율은 분모인 양성 예측 수로 가중하면 재구성할 수 있다.

스스로 풀어보기

먼저 답과 이유를 적고, 필요한 만큼 힌트를 한 단계씩 열어 보세요.

연습 1 · 값과 상태 예측

π=1/2인 100명 모집단에 같은 조건부 비율을 적용한다. 기대 혼동행렬과 정밀도·평균 비용을 구하라. 분수 인원은 확률 모형의 기대 수다.

힌트 1

양성 50명과 음성 50명을 각각 나눈다.

힌트 2

정밀도는 기대 TP와 FP 합을 분모로 쓴다.

풀이와 답 확인

  1. 기대 TP와 FN은 각각 25, FP는 25/2, TN은 75/2다.

  2. 정밀도는 25/(75/2)=2/3, 비용은 100+25/2=225/2이고 100명당 평균은 9/8이다.

기대 정밀도 모형 값은 2/3, 평균 비용은 9/8이다. 이 비율은 확률 질량으로 계산했으며 무작위 표본 정밀도의 기대값과 자동 동일하다고 주장하지 않는다.

흔한 오답에서 다시 생각하기

분수 인원이 나왔으므로 공식이 잘못됐다.

표본 실측이 아니라 확률 질량의 기대 수로 정한 모형이다.

연습 2 · 오류 찾아 고치기

U와 V의 정밀도를 평균한 11/18을 합친 200명의 정밀도로 보고했다. 고쳐라.

힌트 1

양성 예측 수는 U에서 30, V에서 45다.

힌트 2

TP와 FP를 합친 뒤 비율을 계산한다.

풀이와 답 확인

  1. 합친 양성 예측은 75이고 TP는 50이다.

  2. 정밀도는 2/3이며 가중식은 (30×1/3+45×8/9)/75다.

단순 평균 11/18은 두 모집단 지표의 같은 가중 평균이며 합친 지표와 구별한다.

흔한 오답에서 다시 생각하기

두 표본 크기가 100으로 같으면 모든 비율도 단순 평균이다.

정밀도의 분모는 전체 크기가 아니라 양성 예측 수다.

연습 3 · 직접 만들어 보기

양성 비중 π가 달라지는 보고서를 설계하라. 같은 조건부 비율과 FN 비용 4/FP 비용 1 가정에서 정밀도·평균 비용식을 쓰고 확인할 가정을 적어라.

힌트 1

TP 질량은 π/2, FP 질량은 (1−π)/4다.

힌트 2

FN 질량도 π/2다.

풀이와 답 확인

  1. 정밀도는 2π/(1+π), 평균 비용은 2π+(1−π)/4=(1+7π)/4다.

  2. 새 모집단에서 조건부 오류율·라벨·비용 규약 유지 여부와 표본 불확실성을 별도로 보고한다.

구성비·조건부 오류·비용·실측 여부를 구분한 보고 계약을 만든다.

흔한 오답에서 다시 생각하기

옛 임계값이면 새 조건부 오류율은 언제나 유지된다.

고정 임계값만으로 분포 이동 후 조건부 오류 유지가 증명되지 않는다.

힌트 2

학습 마감 전에 라벨을 알았어도 예측 당시 없던 특성을 써도 될까?

새 기록은 장치와 사건 시각 t, 특성 공개 시각 rX, 라벨 공개 시각 rY를 갖는다. 예측 계약은 사건 시각 t에 예측하고, 학습 자료는 시각 c=6까지 확보한 것을 사용한다. 과거 기록도 그 사건을 실제로 예측했을 상황을 재현하려면 특성이 rX≤t여야 한다. 학습 라벨에는 rY≤6이 필요하다. 라벨을 마감까지 알았다는 조건과 예측 당시 특성을 알았다는 조건은 서로 다른 시계다.

학습 후보 A1은 장치 A/t=1/rX=1/rY=3, A4는 A/t=4/rX=5/rY=6, B3은 B/t=3/rX=3/rY=7이다. A1만 두 가용 조건을 만족한다. A4는 뒤에 나온 특성을 과거 예측에 사용하므로 실패하고 B3은 학습 마감 뒤 공개된 라벨이므로 실패한다. 새 장치의 미래 평가 후보 C7은 C/t=7/rX=7/rY=9이며, 학습 장치 A와 겹치지 않는다. C7의 예측은 7에 가능하지만 정답 기반 지표 계산은 9 이후다.

하나의 gap 행 개수를 정한다고 모든 공개 지연 문제가 해결되지는 않는다. 행 번호 간격과 실제 공개 시각은 같지 않을 수 있다. 전처리도 각 분할의 적격 학습 행만 사용한다. 별도 단순 중심화 예에서 학습 값은 2와 4, 평가 값은 100이다. 학습 평균 3을 빼면 평가 변환값은 97이다. 전체 평균 106/3을 먼저 사용하면 평가 값 자체가 기준에 들어가 194/3이라는 다른 결과를 만든다. 분할·가용성·fit 범위를 각각 검사한다.

새 행과 새 그룹은 다른 질문이다

한 사람·장치·문서에서 나온 여러 행은 공통 특성을 가져 서로 의존할 수 있다. 새 장치에 대한 성능을 알고 싶으면 같은 장치가 학습과 평가 양쪽에 나타나지 않도록 분리한다. 행 번호만 달라졌다고 독립된 새 그룹은 아니다.

목표가 이미 관측한 장치의 미래 기록이라면 새 장치 평가와는 다른 설계가 필요하다. 어떤 대상을 예측하는지 먼저 적는다. 그룹 분할도 그룹 수가 적거나 클래스가 특정 그룹에 몰리면 결과가 불안정할 수 있어 각 분할의 그룹과 클래스 수를 확인한다.

미래 예측은 정보가 존재한 시점을 따른다

시간 자료는 가까운 기록끼리 의존하거나 분포가 변할 수 있다. 미래 예측을 평가하려면 이전 자료로 학습하고 이후 구간에서 평가한다. 과거와 미래를 임의로 섞은 결과가 실제 미래 예측을 입증하지는 않는다. 같은 기간을 비교할지 같은 행 수를 비교할지도 정한다.

행의 날짜와 그 라벨이 확인된 날짜는 다를 수 있다. 시점 t의 결과가 t+2에야 공개된다면 학습 마감 시점까지 공개된 라벨만 사용할 수 있다. 이동 창 특성이 미래 값을 참조하거나 라벨 기간이 평가 구간과 겹치는지 확인하고, 필요하면 경계에 간격을 둔다. 간격 길이는 자료의 의미에 따라 정한다.

분할 뒤에 학습할 수 있는 변환을 적용한다

정규화 평균, 결측값 대체값, 특성 선택과 같은 학습 가능한 전처리는 학습 부분에서만 fit, 즉 변환의 기준을 학습하고 검증·평가에는 transform, 즉 정해진 변환을 적용한다. 전체 자료를 먼저 fit하면 평가 정보가 학습 과정에 들어갈 수 있다. 교차 검증에서는 각 fold, 즉 나누어 평가하는 한 묶음의 학습 부분에 맞춰 다시 학습한다.

그룹 조건과 시간 조건이 동시에 필요하면 두 조건을 모두 확인해야 한다. 시간 분할만 했다고 새 그룹이 분리되거나, 그룹만 나눴다고 미래 특성 누출이 사라지지 않는다. 아래는 종이 인덱스 점검이며 실제 분할 API나 모델을 실행한 결과가 아니다.

A를 뺀 차이는 A만 넣었을 때의 효과와 같을까?

새 자체 실험 표는 같은 평가 20건, 같은 재학습·탐색 예산 계약에서 정답 수를 기록했다고 가정한다. 둘 다 없는 구성 00은 12건, A만 있는 10은 13건, B만 있는 01은 13건, 둘 다 있는 11은 18건을 맞힌다. 실제 모델 실행 결과가 아니라 상호작용을 읽는 가상 표다. A의 추가 차이는 B가 없을 때 1건이지만 B가 있을 때 5건이다. 어떤 배경 구성에서 비교했는지 없이 A의 기여라는 숫자 하나로 요약하지 않는다.

정답 수의 차이 중 차이는 (18−13)−(13−12)=4건, 즉 정확도 20퍼센트포인트다. 단독 개선 1건씩을 더하면 2건이지만 전체 개선은 6건이다. 반대로 전체에서 A 제거 차이 5건과 B 제거 차이 5건을 합하면 10건이어서 6건과 맞지 않는다. 이 가상 비교 계약 안의 상호작용 표지이며 임의 모집단의 인과 효과나 통계적 유의성으로 단정하지 않는다.

오류 분류의 중복도 합산을 바꾼다. 자체 오류 ID 집합의 형식 문제 F={e1,e2,e3}, 희귀 그룹 G={e3,e4}라면 범주별 개수는 3과 2지만 서로 다른 오류는 4건이다. 모두 고친다고 가정해도 독립 절약 5건으로 더할 수 없다. 또한 반복을 짝지을 때 같은 split과 반복 ID를 써야 한다. 별도 A의 r1/r2/r3 정답 수는 16/18/14이고 B는 17/17/17이면 차이는 1/−1/3건이고 평균은 1건이다. r3의 B가 누락되면 남은 두 쌍 평균은 0건이지 빠진 값을 임의 보충한 1건이 아니다.

기준모델은 비교의 출발점이다

항상 같은 클래스를 예측하는 모델이나 간단한 선형 모델도 비교 기준이 된다. 다수 클래스 기준은 학습 자료에서 정하며 새 모델과 같은 평가 표본·지표·비용 조건으로 비교한다. 복잡한 모델이 조금 좋아져도 계산 시간이나 사용 조건에 맞는지 별도로 확인한다.

기준모델과 새 모델에 서로 다른 분할을 주거나 한쪽만 유리하게 조정하면 모델 차이와 실험 차이가 섞인다. 탐색 예산과 선택 절차를 적고 검증에서 선택한 뒤 독립 평가한다. 평가를 자주 확인해 선택하면 평가 자료가 사실상 추가 검증 자료가 된다.

하나를 빼고 다시 비교한다

절제실험은 완성된 방법의 구성요소 하나를 제거한 변형을 비교해 어떤 요소가 기여하는지 살피는 방법이다. 다른 조건을 고정하고 필요한 재학습을 수행한다. 제거 뒤 재조정을 허용할지, 같은 예산을 쓸지 규약을 먼저 정한다.

전체 방법에서 요소 A를 뺀 차이는 A 단독의 보편 효과가 아니다. 다른 요소와의 상호작용이 포함될 수 있어 A·B를 각각 뺀 차이를 더하면 둘의 총 기여라고 일반화하지 않는다. 오류 사례도 라벨 오류·드문 집단·형식 차이처럼 원인 가설을 나누되 같은 오류가 여러 범주에 속하는지 표시한다.

재현 가능한 기록과 견고한 결과는 다르다

자료 버전과 분할 인덱스, 전처리 fit 범위, 코드와 설정, 환경 버전, 난수 조건, 지표와 선택 절차를 기록한다. seed는 난수 생성의 초기 조건을 지정하는 값이다. seed 하나를 적었다고 장치·라이브러리·자료 변경까지 결과가 같다고 보장하지 않는다. 가능한 반복 결과를 빠뜨리지 않고 보여 준다.

같은 조건의 여러 초기값에서 차이가 얼마나 변하는지 보면 한 번의 좋은 결과를 과장할 위험을 줄일 수 있다. 표본 수와 반복 수가 작은 평균 차이를 일반적인 우월성이나 통계적 유의성으로 단정하지 않는다. 아래 표는 보고 연습용 가정이며 실제 모델을 학습하거나 반복 실행하지 않았다.
