소단원 12.1

불균형 지표와 비용

천 개 중 스무 개만 중요한 사건이라면 모두 아니라고 답해도 좋은 모델일까?

준비 개념과 학습 목표

준비 개념

  • 혼동행렬

  • 분수와 비율

  • 분류 임계값

학습 목표

  • 양성 클래스를 정하고 혼동행렬을 계산한다.

  • 정확도·재현율·정밀도·F1의 분모를 구별한다.

  • 오류 비용과 검증 자료로 선택 조건을 정한다.

무엇을 양성으로 볼지 먼저 정한다

이진 분류에서 찾으려는 사건을 양성으로 정한다. 실제 양성이면서 양성 예측이면 TP, 실제 양성인데 음성 예측이면 FN이다. 실제 음성의 양성 예측은 FP, 올바른 음성 예측은 TN이다. 실제 라벨의 신뢰성과 평가 모집단도 확인한다.

정확도는 (TP+TN)/N이다. 음성이 압도적으로 많으면 양성을 전혀 찾지 못해도 정확도가 높다. 클래스별 표본 수를 같이 보고 단순한 다수 클래스 기준모델과 비교해야 한다. 평가 자료의 다수 클래스를 보고 기준모델의 예측 클래스를 바꾸면 평가 정답을 선택에 사용한 셈이다.

각 지표의 질문과 분모가 다르다

정밀도는 TP/(TP+FP)로 양성이라고 부른 것 중 맞은 비율이고, 재현율은 TP/(TP+FN)로 실제 양성 중 찾은 비율이다. 이진 F1은 2TP/(2TP+FP+FN)이다. 균형 정확도는 양성 재현율과 음성 재현율 TN/(TN+FP)의 산술평균이다. 여기서는 두 실제 클래스가 모두 존재한다.

분모가 0이면 원래 비율이 정의되지 않는다. 보고서에는 미정의 표시 또는 사용하는 도구의 처리 규약을 적는다. 양성 예측이 하나도 없을 때 정밀도를 임의로 100%라고 보고하지 않는다. F1은 TN이나 구체적인 오류 비용을 직접 반영하지 않아 모든 목적의 단일 정답 지표가 아니다.

손실과 선택은 사용 목적에 맞춘다

가상의 단순 비용 모형에서 FN 한 건의 비용 cFN, FP 한 건의 비용 cFP를 정하면 총 비용은 cFN×FN+cFP×FP다. 이 식은 정답 비용을 0으로 두고 오류마다 비용이 일정하다는 가정이다. 안전·권리·필수 조건이나 사례별 다른 영향을 하나의 숫자로 자동 대체하지 않는다.

같은 점수 모델이라도 임계값에 따라 혼동행렬이 바뀐다. 임계값과 비용에 따른 선택은 학습·검증 단계에서 정하고, 최종 평가 정답을 반복해서 들여다보며 유리한 값으로 바꾸지 않는다. 아래 행렬은 계산 연습용 가정이며 실제 모델의 임계값 실험 결과가 아니다.

중간 과정을 따라가는 예제

평가 표본 1000개 중 양성은 20개다. A는 모두 음성, B는 TP=15, FN=5, FP=45, TN=935다. 정확도와 B의 정밀도·재현율·F1, cFN=20와 cFP=1의 비용을 비교하라.

  1. A는 TN=980, FN=20이라 정확도 980/1000=98%지만 재현율 0이다. 정밀도의 분모는 0이라 미정의다.

  2. B의 정확도는 950/1000=95%, 정밀도 15/60=1/4, 재현율 15/20=3/4, F1=30/80=3/8이다.

  3. A 비용은 20×20=400, B 비용은 20×5+45=145다. 이 가상 비용에서는 정확도가 낮은 B가 더 낮은 비용이다.

B는 정확도 95%, 정밀도 25%, 재현율 75%, F1 37.5%다. 비용 145는 A의 400보다 작다. 선택은 정해진 비용 조건에 따른다.

종이와 본문으로 직접 해보기

C가 TP=19, FN=1, FP=100, TN=880이라면 같은 비용에서 B와 C 중 무엇이 유리한가? FN 비용을 1로 바꾸면 A·B·C 중 무엇이 최소인가?

힌트 보기

네 칸의 합과 실제 클래스 합을 확인한 뒤 비용을 다시 계산한다.

풀이 보기

각 행렬 합은 1000이고 양성 20·음성 980이다. C 비용은 20+100=120이라 B의 145보다 작다. FN 비용이 1이면 A=20, B=50, C=101이라 A가 최소다. 비용을 바꾼 뒤에도 원래 순위를 고정하면 안 된다.

오해와 반례

정확도가 더 높은 모델은 어떤 사용 목적에서도 더 좋다.

A의 98%는 양성을 하나도 찾지 않은 결과다. 오류 비용과 양성 재현율 조건을 포함하면 B나 C가 더 적합할 수 있다.

자기점검

답과 이유 보기

아니다. 실제 양성 20이다.

60은 양성 예측 수로 정밀도의 분모다.

A의 정밀도를 100%로 선언해도 되는가?

답과 이유 보기

안 된다. 분모 0의 처리 규약을 밝혀야 한다.

양성 예측이 없어서 비율식 자체는 정의되지 않는다.

최종 평가에서 가장 좋아 보이는 임계값으로 바꿔도 같은 독립 평가인가?

답과 이유 보기

아니다.

평가 정답이 선택에 쓰였으므로 새로운 독립 평가가 필요하다.

한 단계 더

A의 균형 정확도는 (0+1)/2=1/2다. B는 (3/4+935/980)/2=167/196이다. C의 정밀도는 19/119로 B보다 낮지만 위 비용에서는 C가 유리하다. 비율 하나와 총 비용의 순위가 같지 않은 이유를 설명하고, 모집단 비율이 바뀔 때 비용 추정이 유지되는지 별도로 검토한다.

소단원 12.2

그룹·시간분할

같은 장치의 다른 날 기록을 평가에 넣으면 새 장치에서도 잘 작동한다는 증거일까?

준비 개념과 학습 목표

준비 개념

  • 학습·검증·평가 구분

  • 자료 의존성

  • 전처리 fit/transform

학습 목표

  • 목표 일반화 대상에 맞춰 분할 단위를 정한다.

  • 그룹 교집합과 시간 순서를 점검한다.

  • 특성·라벨 공개 시점과 전처리 누출을 확인한다.

새 행과 새 그룹은 다른 질문이다

한 사람·장치·문서에서 나온 여러 행은 공통 특성을 가져 서로 의존할 수 있다. 새 장치에 대한 성능을 알고 싶으면 같은 장치가 학습과 평가 양쪽에 나타나지 않도록 분리한다. 행 번호만 달라졌다고 독립된 새 그룹은 아니다.

목표가 이미 관측한 장치의 미래 기록이라면 새 장치 평가와는 다른 설계가 필요하다. 어떤 대상을 예측하는지 먼저 적는다. 그룹 분할도 그룹 수가 적거나 클래스가 특정 그룹에 몰리면 결과가 불안정할 수 있어 각 분할의 그룹과 클래스 수를 확인한다.

미래 예측은 정보가 존재한 시점을 따른다

시간 자료는 가까운 기록끼리 의존하거나 분포가 변할 수 있다. 미래 예측을 평가하려면 이전 자료로 학습하고 이후 구간에서 평가한다. 과거와 미래를 임의로 섞은 결과가 실제 미래 예측을 입증하지는 않는다. 같은 기간을 비교할지 같은 행 수를 비교할지도 정한다.

행의 날짜와 그 라벨이 확인된 날짜는 다를 수 있다. 시점 t의 결과가 t+2에야 공개된다면 학습 마감 시점까지 공개된 라벨만 사용할 수 있다. 이동 창 특성이 미래 값을 참조하거나 라벨 기간이 평가 구간과 겹치는지 확인하고, 필요하면 경계에 간격을 둔다. 간격 길이는 자료의 의미에 따라 정한다.

분할 뒤에 학습할 수 있는 변환을 적용한다

정규화 평균, 결측값 대체값, 특성 선택과 같은 학습 가능한 전처리는 학습 부분에서만 fit하고 검증·평가에는 그 변환을 적용한다. 전체 자료를 먼저 fit하면 평가 정보가 학습 과정에 들어갈 수 있다. 교차 검증에서는 각 fold의 학습 부분에 맞춰 다시 학습한다.

그룹 조건과 시간 조건이 동시에 필요하면 두 조건을 모두 확인해야 한다. 시간 분할만 했다고 새 그룹이 분리되거나, 그룹만 나눴다고 미래 특성 누출이 사라지지 않는다. 아래는 종이 인덱스 점검이며 실제 분할 API나 모델을 실행한 결과가 아니다.

중간 과정을 따라가는 예제

장치 A·B·C·D마다 기록 1과 2가 있다. 학습 A1,B1,C1,D1과 평가 A2,B2,C2,D2를 새 장치 평가라고 할 수 있는가? 학습 A1,A2,B1,B2와 평가 C1,C2,D1,D2는?

  1. 첫 학습 그룹은 {A,B,C,D}, 평가 그룹도 {A,B,C,D}라 교집합이 네 그룹 모두다. 행은 달라도 새 장치 평가가 아니다.

  2. 두 번째 학습 그룹 {A,B}와 평가 그룹 {C,D}의 교집합은 공집합이다. 새 그룹 분리 조건을 만족한다.

  3. 두 번째 분할의 실제 예측 성능이나 클래스 균형은 이 인덱스 표만으로 알 수 없다. 전처리와 라벨 품질도 따로 점검한다.

첫 분할은 새 그룹 평가 조건에 실패한다. 두 번째는 그룹 분리 조건을 만족하지만 모델 성능 검증 자체는 아직 수행하지 않았다.

종이와 본문으로 직접 해보기

등간격 시점 1–8에서 학습 1–4, 검증 5–6, 평가 7–8을 정했다. 라벨은 각 행 시점+2에 공개되고 학습 마감은 4다. 학습 1–4 중 실제 사용 가능한 라벨은? 마감 전까지 공개되지 않은 라벨을 쓰면?

힌트 보기

행 시점 t가 아니라 공개 시점 t+2≤4를 적용한다.

풀이 보기

사용 가능한 행은 1·2다. 행 3의 라벨은 5, 행 4의 라벨은 6에 공개되어 마감 4에서는 알 수 없다. 이를 학습에 쓰면 미래 정보가 누출된다. 검증·평가 결과도 각 라벨이 공개된 뒤에 계산해야 한다.

오해와 반례

시간 순서대로 행을 나누면 전처리와 라벨 누출도 자동으로 없어졌다.

전체 자료의 평균으로 정규화하거나 마감 뒤 공개된 라벨을 사용하면 순서 분할에도 누출이 남는다. 정보 이용 가능 시점을 따로 확인한다.

그룹 분할만으로 시간 누출도 제거되는가?

답과 이유 보기

새 그룹의 미래 특성이나 뒤늦게 공개된 라벨을 포함할 수 있다.

한 단계 더

새 장치의 미래를 동시에 평가하는 계획을 종이에 설계한다. 그룹 목록, 특성과 라벨의 공개 시점, 학습 마감, 검증/평가 기간을 별도 열로 적는다. 모든 조건을 만족하는 표본이 너무 적으면 조건을 몰래 완화하지 말고 평가 질문을 바꾸거나 자료 수집 계획을 명시한다.

기준모델은 비교의 출발점이다

항상 같은 클래스를 예측하는 모델이나 간단한 선형 모델도 비교 기준이 된다. 다수 클래스 기준은 학습 자료에서 정하며 새 모델과 같은 평가 표본·지표·비용 조건으로 비교한다. 복잡한 모델이 조금 좋아져도 계산 시간이나 사용 조건에 맞는지 별도로 확인한다.

기준모델과 새 모델에 서로 다른 분할을 주거나 한쪽만 유리하게 조정하면 모델 차이와 실험 차이가 섞인다. 탐색 예산과 선택 절차를 적고 검증에서 선택한 뒤 독립 평가한다. 평가를 자주 확인해 선택하면 평가 자료가 사실상 추가 검증 자료가 된다.

하나를 빼고 다시 비교한다

절제실험은 완성된 방법의 구성요소 하나를 제거한 변형을 비교해 어떤 요소가 기여하는지 살피는 방법이다. 다른 조건을 고정하고 필요한 재학습을 수행한다. 제거 뒤 재조정을 허용할지, 같은 예산을 쓸지 규약을 먼저 정한다.

전체 방법에서 요소 A를 뺀 차이는 A 단독의 보편 효과가 아니다. 다른 요소와의 상호작용이 포함될 수 있어 A·B를 각각 뺀 차이를 더하면 둘의 총 기여라고 일반화하지 않는다. 오류 사례도 라벨 오류·드문 집단·형식 차이처럼 원인 가설을 나누되 같은 오류가 여러 범주에 속하는지 표시한다.

재현 가능한 기록과 견고한 결과는 다르다

자료 버전과 분할 인덱스, 전처리 fit 범위, 코드와 설정, 환경 버전, 난수 조건, 지표와 선택 절차를 기록한다. seed 하나를 적었다고 장치·라이브러리·자료 변경까지 결과가 같다고 보장하지 않는다. 가능한 반복 결과를 빠뜨리지 않고 보여 준다.

같은 조건의 여러 초기값에서 차이가 얼마나 변하는지 보면 한 번의 좋은 결과를 과장할 위험을 줄일 수 있다. 표본 수와 반복 수가 작은 평균 차이를 일반적인 우월성이나 통계적 유의성으로 단정하지 않는다. 아래 표는 보고 연습용 가정이며 실제 모델을 학습하거나 반복 실행하지 않았다.

중간 과정을 따라가는 예제

같은 고정 평가 20개에서 학습 다수 클래스 기준모델은 16개, 전체 모델은 18개, 특성 A를 제거한 재학습 모델은 17개, 전처리 B를 제거한 재학습 모델은 14개를 맞혔다. 정확도와 전체 모델 대비 변화량을 구하라.

  1. 기준 16/20=80%, 전체 18/20=90%, A 제거 17/20=85%, B 제거 14/20=70%다.

  2. 전체 대비 A 제거는 5퍼센트포인트 감소, B 제거는 20퍼센트포인트 감소다. 제거 규약과 다른 조건이 같다는 가정 아래 표에서의 차이다.

  3. 기준에서 전체로 정확도는 10퍼센트포인트 증가하고 오류 수는 4에서 2로 절반이다. 두 제거 차이를 더해 구성요소의 독립적인 총 효과라고 단정하지 않는다.

기준/전체/A 제거/B 제거는 80/90/85/70%다. 정확도 차이의 퍼센트포인트와 오류 수의 상대 감소율은 다른 양이다.

종이와 본문으로 직접 해보기

같은 분할에서 계획한 세 초기값의 A 결과가 80,82,81%, B가 79,84,80%다. 평균과 각 쌍의 B−A를 계산하라. B 최고 84%만으로 일관된 우월성을 주장할 수 있는가?

힌트 보기

각 방법 평균과 같은 초기값 쌍의 차이를 따로 적고 최고값만 고르지 않는다.

풀이 보기

A와 B 평균은 모두 81%다. 쌍별 차이는 −1,2,−1퍼센트포인트로 평균 0이다. 세 결과에서 B가 일관되게 우위라고 할 수 없다. 분할과 초기값이 같은 것만으로 모든 난수 경로나 통계적 독립성이 보장되지는 않는다.

오해와 반례

최고 한 번의 점수가 높은 모델을 고르면 재현성과 일반적인 우월성도 입증됐다.

B의 최고 84%만 고르면 나머지 79/80%와 같은 평균 81%를 숨긴다. 전체 반복과 선택 절차를 보고하고 별도 불확실성 평가가 필요하다.

자기점검

90%에서 85%의 정확도 감소는 5%라는 상대 감소율인가?

답과 이유 보기

5퍼센트포인트다. 상대 감소율은 5/90이다.

비율의 차이와 원래 값으로 나눈 변화율을 구별한다.

A 제거와 B 제거의 차이를 더하면 독립적 기여의 합인가?

답과 이유 보기

일반적으로 아니다.

구성요소가 겹치거나 상호작용할 수 있다.

분할 인덱스가 다른 fold의 두 점수 차이를 그대로 짝지어도 되는가?

답과 이유 보기

안 된다.

자료 난도 차이와 모델 차이가 섞이므로 비교 조건을 맞춘다.

한 단계 더

전체·A 제거·B 제거·둘 다 제거의 네 칸 실험 계획을 만든다. 같은 평가 계약과 재학습/탐색 예산을 기록하고 아직 없는 둘 다 제거 점수를 임의로 계산하지 않는다. 성능·시간·실패 범주의 원시 결과와 모르는 사항, 실제 실행/종이 예제를 나누어 보고서를 작성한다.
