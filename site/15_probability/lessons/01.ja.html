小節 1.1

標本空間と事象

コインを2回投げた結果を表が出た回数 0・1・2 として記録すると、3種類とも確率は 1/3 だろうか？

準備する概念と学習目標

準備する概念

  • 集合は要素を集めたものである。{H, T} において H∈Ω は、H が Ω の要素であることを表す。部分集合は、一部またはすべての要素を選んだ集合である。
  • ミニ復習：分数 3/4 は、重みが等しい4区画のうち3区画を表す。区画の重みが異なるなら、個数ではなく重みを足す必要がある。
  • 関数は、各入力に1つの出力を定める規則である。表が出た回数を数える関数 X は、HT と TH のどちらにも 1 を与える。この単元には微分・積分は必要ない。

学習目標

  • 実験の記録規則を先に定め、標本空間を書く。
  • 事象を部分集合、和集合、共通部分、補集合で表す。
  • 結果をまとめることと等確率の仮定を区別する。

結果を先に区別し、その後に確率を与える

確率実験は、結果がまだ分からない状況をモデルとして表したものである。目の前の物体が本当にランダムかを哲学的に判定する前に、何を1回の試行とし、何を記録するかを定める。2回投げるときに1回目と2回目を区別すれば、HT と TH は異なる記録になる。標本空間 Ω は、その記録規則で可能なすべての結果の集合であり、各結果 ω を標本点という。

ここではコインが縁で立つ結果を除き、毎回 H または T が出ると仮定して Ω={HH, HT, TH, TT} とする。実際の装置でほかの結果が意味をもって発生するなら、標本空間と記録規則を修正する必要がある。標本空間を列挙しただけでは、各結果の確率は等しくならない。

事象は条件が真になる結果を集めた集合

事象 A は、ある問いに「はい」と答える標本点の集まりである。少なくとも1回表が出る事象は A={HH, HT, TH}、1回目が表は B={HH, HT}、ちょうど1回表は C={HT, TH} である。A∩B は両方が真の結果、A∪B は少なくとも一方が真の結果、Aᶜ=Ω∖A は A が偽の結果を表す。確率での「または」は、特に断らない限り両方が真の場合も含む。

有限の Ω では、すべての部分集合を事象として使える。一般の確率モデルは (Ω,ℱ, P) と書き、ℱ は事象として認める集合の族である。Ω を含み、補集合と可算和集合について閉じている集合族を σ-代数という。連続モデルで、すべての部分集合に無条件に確率を与えようとする問題を避ける仕組みである。この単元の有限問題では、ℱ が Ω のすべての部分集合からなることだけを使う。

記録を圧縮しても元の重みは消えない

公平なコインを独立に2回投げるという追加の仮定があれば、各順序対に確率 1/4 を与える。したがって A の確率は 1/4+1/4+1/4=3/4 である。表が出た回数 X に記録を変えると Ω′={0,1,2} だが、元の点がそれぞれ1個・2個・1個ずつまとまるため、確率は 1/4・1/2・1/4 になる。

一般に新しい事象 D の確率は P(X∈D)=P({ω:X(ω)∈D}) で計算する。元の空間に戻って対応する事象を探すと読めばよい。独立で各回の表の確率が 3/4 なら、HH、HT、TH、TT の重みは 9/16、3/16、3/16、1/16 になる。事象の集合表示が同じでも確率は変わる。

途中の過程をたどる例題

公平なコインを順序を区別して独立に2回投げる。A=少なくとも1回表、B=1回目が表として、A∩B と Aᶜ、およびそれぞれの確率を求めよ。

  1. Ω の4点を HH、HT、TH、TT と書き、それぞれに 1/4 と記す。
  2. A={HH, HT, TH}、B={HH, HT} なので A∩B={HH, HT}。
  3. Aᶜ={TT} は、全4点から A の3点を除いたものである。
  4. 重みを足して P(A∩B)=2/4=1/2、P(Aᶜ)=1/4、P(A)=3/4。

両事象がともに真になる確率は 1/2、表が1回も出ない確率は 1/4 である。

紙と本文で試してみよう

紙に4点を書き、C=ちょうど1回表、D=2回目が表を色で示せ。C∪D と C∩D を求め、公平・独立の仮定で確率を計算せよ。

ヒントを見る

C={HT, TH}、D={TH, HH}。2文字目を確認し、同じ点を2回数えない。

解答を見る

D={HH, TH}。C∪D={HH, HT, TH} なので 3/4、C∩D={TH} なので 1/4。文字の順序を保たないと HT と TH を混同する。

よくある誤解と反例

標本空間の結果が3種類なら、それぞれの確率は 1/3 である。

表が出た回数 0・1・2 は、元の4つの順序対を1個・2個・1個ずつまとめたものだ。公平・独立の条件でも確率は 1/4・1/2・1/4 になる。結果の名前の数と、その結果を生む重みは別である。

理解を確かめる

事象と標本点の違いは？

答えと理由を見る

標本点は1つの完全な記録、事象は条件を満たす記録の集合である。

例えば HT は点、{HT, TH} は事象である。1点だけを含む集合も事象になる。

各回の表の確率が 3/4 の独立な2回の試行で、少なくとも1回表が出る確率は？

答えと理由を見る

15/16。

余事象 TT の確率は (1/4)²=1/16 なので、残りを取る。

P(HT)=P(TH) だけが分かれば、4点は等確率か？

答えと理由を見る

いいえ。

9/16、3/16、3/16、1/16 は HT=TH を満たすが、4点すべては等しくない。

もう一歩先へ

小さな Ω={a, b, c} で σ-代数の閉性を確かめよ。ℱ={∅,{a},{b, c},Ω} は補集合と可算和集合に関して閉じているが、{b} を観測可能な事象として含まない。これは b と c を区別できない記録装置に対応する。より精密なセンサーを付けると、事象の集合族も変わりうる。

小節 1.2

確率の公理と計数

和集合の確率を単純に足すと、なぜ 1 を超える値が出るのだろう？

準備する概念と学習目標

準備する概念

  • ミニ復習：A∩B は共通の要素、A∪B は少なくとも一方の要素、Aᶜ は全体から A を除いた要素である。互いに素とは、共通の要素がないことをいう。
  • 階乗は n!=n(n−1)…1 で、0!=1 である。順序を区別すれば AB と BA は異なり、2人を1チームとして選ぶなら同じ選択と数える。
  • Σ は複数の項を足す記号である。この節の有限和には微分・積分は必要ない。可算とは 1,2,3,… と列挙できることをいう。

学習目標

  • 確率の公理から余事象、単調性、和集合の公式を導く。
  • 乗法原理と、順列・組合せにおける重複計数の根拠を説明する。
  • 等確率の場合にだけ場合の数の比を使う。

確率の最小限の規則とその直接の帰結

確率 P は各事象に数を与え、次を満たす。すべての事象 A について P(A)≥0、P(Ω)=1、互いに素な事象 A₁、A₂、… について P(∪Aₖ)=ΣP(Aₖ) である。最後は可算加法性であり、有限個の事象にも適用される。重なる事象をそのまま足すという意味ではない。確率が現実に対する確信の程度を表す場合でも、これらの規則を一貫して満たさなければならない。

互いに素な Ω と ∅ を足して P(∅)=0 を得る。A と Aᶜ が Ω を分割するので P(Aᶜ)=1−P(A)、したがって P(A)≤1 である。A⊆B なら B=A∪(B∖A) を互いに素な部分に分けられ、P(B)≥P(A) となる。これらの導出は空事象、余事象、小さな事象の確率がそれを含む大きな事象より高くなれない理由を説明する。

重なる部分は1回だけ数える

A∪B を A∖B、B∖A、A∩B の3つの互いに素な部分に分ける。P(A)+P(B) は共通部分を2回足すので、P(A∪B)=P(A)+P(B)−P(A∩B) となる。P(A∩B) を P(A)P(B) に置き換えてよいのは、独立であると分かっている場合だけである。互いに素であることと独立であることは異なる条件だ。

互いに素で両方の確率が正なら、共通部分の確率は 0 だが積は正なので、独立ではありえない。例えばサイコロ1回の結果が 1 と 2 である事象は同時に起きない。表の確率が 1/2 のコインの1回目が表と2回目が表は独立になりうるが、HH という共通の結果があるので互いに素ではない。

場合の数は何を同じ選択とみなすかで決まる

最初の段階の m 個の選択それぞれで次の n 個の選択が可能なら、順序対の総数は mn 個である。n 個から重複なしで k 個を順序付きで選ぶと n(n−1)…(n−k+1)=n!/(n−k)! 通り。順序を無視した k 個の組1つは k! 通りの順序で表されるので、割り算により C(n, k)=n!/[k!(n−k)!] となる。この割り算の重要な条件は、すべての組がちょうど k! 回ずつ重複して数えられることである。

有限の Ω の全点が同じ確率をもつ場合、正規化によって各点の重みは 1/|Ω| となる。その場合だけ P(A)=|A|/|Ω| である。3人から2人を選ぶ際に特定の人を選びやすくする手順なら、C(3,2)=3 という計数は同じでも3チームの確率は等しくない。計数と抽出手順の両方を確認する必要がある。

途中の過程をたどる例題

公平な6面サイコロを1回振る。A=偶数、B=4以上として P(A∪B) を求めよ。

  1. Ω={1,2,3,4,5,6}。各点は 1/6。
  2. A={2,4,6}、B={4,5,6}、A∩B={4,6}。
  3. P(A)+P(B)−P(A∩B)=3/6+3/6−2/6=4/6。
  4. 和集合 {2,4,5,6} を直接数え、2/3 と一致することを確認する。

P(A∪B)=2/3。単純な和 1 は、共通の結果 4・6 を2回数えた値である。

紙と本文で試してみよう

異なる4人の学生 a、b、c、d から2人を等確率で選ぶ。順序なしのチームを列挙し、a が含まれる確率を求めよ。会長・副会長を選ぶ場合と比較せよ。

ヒントを見る

チーム ab と ba は同じである。役割がある場合、同じ2人でも役割を交換した2つの選択になる。

解答を見る

チームは ab、ac、ad、bc、bd、cd の6つで、a を含むのは3つなので 1/2。役割の選択は 4×3=12 通りで、a がどちらかの役割を担う選択は6通りなので 1/2 である。計数は異なるが、この事象の確率は同じだ。

よくある誤解と反例

2つの事象が独立なら重ならない。

独立な公平コインの2回の試行で、A=1回目が表、B=2回目が表は P(A∩B)=1/4=P(A)P(B) だが HH で重なる。互いに素で正の確率をもつ事象は、むしろ独立ではない。

理解を確かめる

P(A)=0.7、P(B)=0.6、P(A∩B)=0.4 のとき和集合の確率は？

答えと理由を見る

0.9。

0.7+0.6−0.4 であり、1以下という条件も満たす。

5人から順序なしで3人を選ぶ場合の数は？

答えと理由を見る

10。

5×4×3 通りの順序付きの選択を 3!=6 で割る。

サイコロの目の確率が異なる場合、偶数の確率は常に 3/6 か？

答えと理由を見る

いいえ。

偶数の3点の実際の重みを足す必要がある。公平性は別の仮定である。

もう一歩先へ

和集合の公式と P(A∪B)≤1 から P(A∩B)≥P(A)+P(B)−1 を得る。共通部分は両方の部分集合なので P(A∩B)≤min(P(A), P(B)) も得る。0.7 と 0.6 の場合、重なりの確率は 0.3 から 0.6 の範囲になる。計算前に公理への違反を点検するための範囲である。

小節 1.3

標本抽出の仮定

同じ袋から2回取り出すのに、戻すかどうかによってなぜ確率が変わるのだろう？

準備する概念と学習目標

準備する概念

  • 分数 2/3 は、現在選べる3つの物体のうち2つが求める性質をもつときの重みである。1回抽出した後に残る物体が変わるか、先に記録する。
  • ミニ復習：観測の順序を区別すると (r₁, r₂) と (r₂, r₁) は異なる。同じ色でも、r₁・r₂ のような個体名を付けて数える。
  • P(B|A) は A が起きたという情報のもとでの B の確率である。P(A)>0 のとき P(A∩B)/P(A) と定義し、次の単元で体系的に学ぶ。

学習目標

  • 復元／非復元、等確率、独立、同分布という仮定を区別する。
  • 小さな母集団で順序対を列挙し、確率を照合する。
  • 無作為抽出と代表性、選択バイアスを区別する。

実験の操作規則が確率モデルを作る

母集団は抽出対象の全体、標本は実際に抽出した対象である。母集団に赤い r₁、r₂ と青い b が1つあるとしよう。各抽出時点で残っている個体を等確率で選ぶと明記して初めて、色の確率を計算できる。赤と青の2種類をまず各 1/2 で選ぶ手順は、3個体を等確率で選ぶ手順とは異なる。

復元抽出では、取り出した個体を戻してから次の抽出を行う。よく混ぜ、各回を独立に等確率抽出するという仮定もあれば、毎回赤の確率は 2/3、2回とも赤の確率は 4/9 になる。戻すという動作だけで物理的な独立性が自動的に保証されるわけではない。同じ乱数の使用や不十分な混合が結果を連動させることがある。

残る対象が変わるなら条件付き確率を使う

非復元抽出では同じ個体を再び抽出できない。1回目が赤の後には残る2つのうち赤は1つなので、2回目が赤の確率は 1/2。1回目が青の後には残る2つとも赤なので、2回目が赤の確率は 1 である。最初の結果が次の結果について情報を与えることが従属の意味である。

2回とも赤の事象は、1回目が赤と2回目が赤の共通部分である。条件付き確率の定義を整理すると P(A∩B)=P(A)P(B|A) なので、ここでは (2/3)(1/2)=1/3。3×2=6 個の順序対から (r₁, r₂)、(r₂, r₁) の2つを数えても同じ値になる。個体の順序対は等確率だが、色の順序 RR、RB、BR の3つの名前を等確率とみなす根拠は別途確認しなければならない。

独立・同分布・代表性は異なる言葉

同分布は各抽出の個別の確率分布が同じこと、独立は同時確率が各確率の積に分解できることをいう。上の非復元実験で2回目が赤の確率は (2/3)(1/2)+(1/3)(1)=2/3 となり、1回目と同じである。しかし2回とも赤の確率 1/3 は (2/3)² と異なるので独立ではない。i.i.d. は独立かつ同分布という2つの条件をまとめて表す。

オンライン調査の回答者1000人を無作為に選んでも、全住民の意見を自動的に代表するわけではない。回答しない住民は抽出枠から外れ、包含確率が異なることもある。現実を解釈するには、対象母集団、標本抽出枠、包含確率、無回答を記録する必要がある。互いに独立な観測を多く集めることと、誤った抽出枠を直すことは別の作業である。

r₁、r₂、b から、毎回選べる個体を等確率で抽出する。2回とも赤という事象を復元・非復元で比較せよ。

  1. 復元かつ独立：3²=9 個の順序対のうち2回とも赤は 2²=4 個なので 4/9。
  2. 非復元：3×2=6 個の順序対のうち2回とも赤は r₁r₂、r₂r₁ の2個なので 1/3。
  3. 差は 4/9−1/3=1/9。最初に抽出した赤い物体を戻さないと、次に赤を引く機会が減る。
  4. 非復元で各位置が赤の確率はともに 2/3 だが、同時確率は 1/3 なので独立ではない。

小節 1.4

シミュレーションと確率モデル

10回の実験で8回表が出たら、コインの本当の表の確率は 0.8 と確定できるだろうか？

準備する概念と学習目標

準備する概念

  • 比率 k/n は、観測された成功回数 k を試行回数 n で割った値である。モデルの P(A) と異なり、実験ごとに変わりうる。
  • ミニ復習：指示変数 I は事象が起きれば 1、そうでなければ 0 である。平均 (I₁+…+Iₙ)/n が事象の相対度数である。
  • 平方根 √n は、2乗すると n になる正の数である。この節の誤差の規模は、微分・積分なしで分散と確率の定義から理解できる。

学習目標

  • モデルから標本を生成する手順と現実のデータの違いを説明する。
  • 短い乱数入力リストを事象に対応させ、相対度数を計算する。
  • 独立な試行での誤差の規模と seed による再現性の限界を説明する。

先に分布を定め、その規則どおりに実験する

シミュレーションは、仕様を定めた確率モデルを繰り返し実装して結果を観察する方法である。U が [0,1) 上で一様なら、U<p のとき成功と定めることで成功確率 p の試行を作れる。p=1/4 では区間 [0,1/4) の長さが全体の 1/4 なので、この規則が正しい。現実の p を知るための実験と、p を既に入力したモデルの結果を確かめる実験は目的が異なる。

コンピュータの擬似乱数は、初期値 seed とアルゴリズムで生成される。同じアルゴリズム・環境・呼び出し順序・seed なら再現しやすく、同じ seed を2回使って同じ実験を繰り返した結果は新しい独立な証拠ではない。文書の random() は 0以上1未満の数を返すが、有限精度のアルゴリズムである。一様・独立という数学的理想化と、実際の生成器の性質を区別して記録する。

相対度数は確率の近似であり、変動する

独立で成功確率が同じ p の n 試行の Iⱼ について、E(Iⱼ)=p、Var(Iⱼ)=p(1−p) である。E は分布の重みによる平均、Var は平均からの距離の2乗の重み付き平均である。I²=I なので Var(I)=E(I²)−E(I)²=p−p² を得る。相対度数 p̂=(ΣIⱼ)/n は E(p̂)=p を満たし、独立により共分散項が 0 となって Var(p̂)=p(1−p)/n である。

標準偏差は √Var であり、p=1/4 なら √(3/(16n)) となる。n=100 で約 0.0433、n=400 で約 0.0217。典型的な誤差の規模を半分にするには4倍の試行が必要である。この数は特定の実行の最大誤差や信頼区間ではない。n を増やしても各段階の誤差が単調に減るわけではなく、従属する試行ではこの分散公式がそのまま成立するとは限らない。

結果の確認では実装と現実を分ける

小さな空間では、理論計算とシミュレーションを比較する。公平・独立なコイン2回で少なくとも1回表が出る確率は 3/4 だが、実装が1回目の結果を2回目へコピーすると HH・TT しか生じず 1/2 になる。反復回数を増やしても、誤って実装した別のモデルにより精密に近づくだけである。まず結果の対応、復元の有無、独立な乱数の使用を確認する必要がある。

現実のデータが理論と異なるなら、偶然の標本変動、実装の誤り、モデルの仮定の不適合を別々の候補として考える。10回とも表でも、公平・独立なモデルでの確率は (1/2)¹⁰=1/1024 で 0 ではない。まれな結果1つで論理的反証が完成するわけではなく、比較手順・標本数・仮説をあらかじめ定めなければならない。この単元は実際の統計的検定まで行ったとは主張しない。

もう一歩先へ

n が正の整数、ε>0 である独立同分布の試行では、Chebyshev（チェビシェフ）の不等式により P(|p̂−p|≥ε)≤p(1−p)/(nε²)≤1/(4nε²) を得る。その理由は、(p̂−p)² が ε² 以上の事象で、2乗偏差の平均が少なくとも ε²×その事象の確率になるためである。n=10000、ε=0.05 なら最後の上界は 0.01。保守的だが、有限の n で条件を明記した上界であり、後の極限定理の単元の大数の法則につながる。
