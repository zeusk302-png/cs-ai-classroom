小節 4.1

密度と累積分布

密度グラフの高さが2なら、確率が200%という意味だろうか？

準備する概念と学習目標

準備する概念

  • 確率変数 X は各結果に実数値を対応させる関数である。事象 {a<X≤b} は、その値が区間内に入る結果の集まりである。
  • CDF は F(x)=P(X≤x) である。任意の実数値確率変数に定義され、非減少で右連続である。右連続とは h↓0 のとき F(x+h)→F(x) となることをいう。
  • 積分 ∫ₐᵇ f(t)dt は、小区間ごとの高さ×幅の和の極限と理解できる。無限端点の積分は有限端点を無限へ送る極限である。非負関数の積分は面積であり、原始関数があればその差で計算する。

学習目標

  • 密度の値ではなく区間の積分から確率を求める。
  • CDF の連続性・絶対連続性・各点での微分可能性を区別する。

高さと面積の役割

この単元で最初に扱うのは密度を持つ絶対連続分布である。非負の可積分関数 f が ∫ℝ f(x)dx=1 を満たし、各 Borel 集合 A に P(X∈A)=∫_A f(x)dx を与えるモデルである（∫_A は集合 A 上の積分）。Borel 集合には区間やその可算和集合など、通常の実数値の事象が含まれる。密度 f の一点での高さは、その点の確率ではない。

X を秒で表すと f の単位は1/秒であり、f(x)dx は無次元の確率になる。幅1/2秒の区間で密度が2/秒の一様モデルは、総面積が1なので適切である。一点の積分は0なので P(X=x)=0 となる。非可算個の点確率をすべて足す操作は、確率の可算加法性の規則ではない。

累積確率として読み直す

密度モデルでは F(x)=∫₋∞ˣ f(t)dt であり、a<b に対して P(a<X≤b)=F(b)−F(a) である。一点の確率が0なので、区間端点の < と ≤ を替えても値は変わらない。互いに重ならない区間の和集合の確率は各面積の和だが、重なる区間では重複部分を一度だけ数える。

密度の積分で得た F は絶対連続であり、特に連続である。絶対連続とは、任意の ε>0 に対してある δ>0 が存在し、互いに重ならない有限個の区間の総延長が δ 未満なら、それらに対応する F の増分の総和も ε 未満になることをいう。単なる連続性からこの条件や密度表現が自動的に得られるわけではない。連続だが密度を持たない特異分布もあるため、すべての連続 CDF を密度の公式で扱えるとは主張しない。

どこで微分できるか

f がある点 x で連続なら、積分の微分に関する定理により F′(x)=f(x) である。一般の可積分密度では、この関係はほとんどすべての点、すなわち長さ0の例外集合を除いて成り立つ。確率を求める際には、先にすべての点で微分値を作る必要はなく、元の積分を使える。

一様分布 U(0,1) の F は、x≤0 で0、0<x<1 で x、x≥1 で1である。F は連続だが、0と1では左右の傾きが異なり微分できない。密度の有限個の点の値を変更しても、積分と分布は変わらない。その点の密度値を定める慣例と、F の導関数の存在を混同しない。

途中の過程をたどる例題

f(x)=c x（0<x<2）、それ以外で0とする仮定された密度を正規化し、CDF と P(1<X≤3/2) を求めよ。

  1. 非負の密度のため c≥0 とする。全体の積分 ∫₀² c x dx=2c=1 より c=1/2 である。
  2. x≤0 では F=0、0<x<2 では F=∫₀ˣ t/2 dt=x²/4、x≥2 では F=1 である。端点でも3つの部分は連続につながる。
  3. F(3/2)=9/16、F(1)=1/4=4/16 を求める。区間確率は2つの累積確率の差である。
  4. P(1<X≤3/2)=5/16 であり P(X=1)=0 である。f(1)=1/2 は密度の高さで、点確率とは異なる。

c=1/2、F(x)=0（x≤0）、x²/4（0<x<2）、1（x≥2）。区間確率は5/16。

紙と本文で試してみよう

f(x)=2（0<x<1/2）、それ以外で0のモデルについて、総面積、P(1/8<X<3/8)、F(1/4)、P(X=1/4) を紙上で求めよ。

ヒントを見る

区間内では高さ×幅を計算する。CDF は左端0から累積する。

解答を見る

全体は2·(1/2)=1である。区間確率は2·(3/8−1/8)=1/2、F(1/4)=2·1/4=1/2、一点の確率は0である。高さ2は1を超えるが、この4つの計算に現れる確率値はすべて [0,1] に入る。

よくある誤解と反例

CDF が連続ならすべての点で微分でき、その導関数が確率である。

U(0,1) の連続 CDF は0と1で微分できない。内部の導関数1は密度であり、P(X=1/2) は0である。連続性・微分可能性・密度・点確率はそれぞれ別の主張である。

理解を確かめる

密度を区間 (0,1) で f=3、それ以外で0とすると有効か？

答えと理由を見る

有効ではない。

総面積が3で、正規化条件1に反する。

密度モデルで P(a≤X≤b) と P(a<X<b) は同じか？

答えと理由を見る

a<b なら同じである。

両端点の確率はそれぞれ0なので、除いても差がない。

秒単位の X を Y=1000X ミリ秒へ変換したとき、密度の高さをそのまま使えるか？

答えと理由を見る

使えない。fᵧ(y)=fₓ(y/1000)/1000 である。

dx=dy/1000 であり、確率の面積を保つには高さの単位も変換する。

もう一歩先へ

一点の確率0と CDF の連続性の直接証明：密度モデルでは {x} の長さは0なので ∫_{ {x} }f=0 である。一般の CDF の左極限は P(X<x) である。実際、事象 {X≤x−1/n} は増加して {X<x} となり、確率の下からの連続性によって極限を得る。したがって F(x)−F(x−)=P(X=x) である。密度モデルではこの差が0で、右連続でもあるので F は連続である。有限個の点で f を変更しても影響がないのは、差の積分が0だからである。この証明は、逆に連続な F が必ず密度を持つとは述べていない。次の小単元では具体的な2種類の密度を計算する。

小節 4.2

一様分布・指数分布

同じ長さの時間区間が同じ確率を持つのはいつか。また、長く待つと残りの待ち時間は変わるだろうか？

準備する概念と学習目標

準備する概念

  • 一様とは密度の高さが一定という意味である。同じ長さの区間の確率が等しいかを判断するには、その区間が全支持区間の内側にあるかを先に確認する。
  • exp(−λt) は t が大きくなると減少する。λt は無次元なので、t が分なら λ の単位は1/分である。
  • P(A|B)=P(A∩B)/P(B) は P(B)>0 のときに定義する。平均 E[X] は ∫x f(x)dx であり、絶対値の積分が有限なら有限の実数として定義される。

学習目標

  • a<b と λ>0 のもとで一様分布・指数分布を正規化する。
  • rate と scale、無記憶性と実際の待ち時間データの検証を区別する。

有限区間の一様モデル

実数 a<b に対し U(a,b) は (a,b) で f=1/(b−a)、それ以外で0の密度を持つ。端点の密度値は積分に影響しないため0にしてよい。CDF は x≤a で0、a<x<b で (x−a)/(b−a)、x≥b で1である。任意の区間の確率は、その区間と (a,b) の共通部分の長さを b−a で割った値である。

平均は ∫ₐᵇ x/(b−a)dx=(a+b)/2 である。X−(a+b)/2 の二乗を対称な区間で積分すると、分散 (b−a)²/12 を得る。a=b の場合はこの密度では定義しない。値 a に集中する定数確率変数は別の退化分布であり、正の幅がないという問題を隠さない。

正の時間の指数モデル

rate λ>0 の Exp(λ) は、t≥0 で f(t)=λe^(−λt)、t<0 で0とする。∫₀∞ λe^(−λt)dt=1 であり、CDF は t<0 で0、t≥0 で1−e^(−λt) である。裾の確率 P(T>t)=e^(−λt) は t≥0 で使う。λ=0 では、積分が1になるこの密度を得られない。

scale θ=1/λ>0 を使って同じ分布を表すと、密度は (1/θ)e^(−t/θ) である。θ は時間、λ は時間の逆数の単位を持ち、平均 E[T]=θ=1/λ である。モデル名だけを見てパラメータ2が rate か scale かを推測すると、平均が1/2か2かで変わってしまう。記号と単位を両方明示する。

条件付き待ち時間とモデルの仮定

s,t≥0 では P(T>s)>0 なので P(T>s+t|T>s)=e^(−λ(s+t))/e^(−λs)=e^(−λt) である。これを無記憶性という。すでに s だけ待ったという条件のもとで、残りの待ち時間の裾が最初の待ち時間と同じになる分布の性質であり、過ぎた時間が消えたという主張ではない。

指数分布を一定強度の Poisson 過程における最初の事象までの待ち時間と解釈するには、その過程の定常かつ独立な増分、一定強度などの仮定が必要である。あらゆる実際の待ち時間がこのモデルに従うとはいえない。U(0,4) は P(T>3|T>2)=1/2 だが P(T>1)=3/4 なので無記憶性を持たない。データへの適合は別の観測・検討課題である。

途中の過程をたどる例題

仮想的な出発待ち時間 U~U(2,8) 分と、別の仮想待ち時間 T~Exp(rate 1/4 分⁻¹) について、P(3<U<5)、E[U]、P(T>8)、P(T>12|T>8) を求めよ。2変数の結合分布や独立性は仮定しない。

  1. U の全幅は6分で (3,5) の幅は2分なので、確率は2/6=1/3である。
  2. 一様分布の平均は (2+8)/2=5分である。T の rate 1/4 分⁻¹ は scale 4分と同じである。
  3. T の裾で λ·8=2 なので P(T>8)=e⁻² である。T の平均は4分である。
  4. {T>12}⊂{T>8} なので条件付き確率は e⁻³/e⁻²=e⁻¹ である。これは追加4分の裾と同じである。

1/3、平均5分、e⁻²、e⁻¹。それぞれ仮定された周辺分布だけを使った。

紙と本文で試してみよう

W~U(−1,3) の P(2<W<5) と平均を紙上で求めよ。H~Exp(scale 2秒) の P(H>2)、P(H>5|H>3)、平均も求めよ。

ヒントを見る

一様分布の区間は3で切り、共通部分の長さだけを数える。scale 2秒を rate 1/2 秒⁻¹ に変換する。

解答を見る

W の共通区間は (2,3) なので確率は1/4、平均は1である。H の裾は e^(−t/2) なので、2つの確率はともに e⁻¹、平均は2秒である。追加待ち時間は5−3=2秒で、条件事象の確率 e^(−3/2) は正である。

よくある誤解と反例

指数分布のパラメータ λ は平均待ち時間で、どの待ち時間データも指数分布である。

この原稿の λ は rate であり、平均は1/λである。U(0,4) の条件付き確率の反例は、待ち時間のモデルが指数分布である必要はないことを示す。指定モデルの計算と現実データの検証は別である。

理解を確かめる

U(4,4) を上の密度公式で定義できるか？

答えと理由を見る

できない。

a<b の条件が成立せず1/(b−a)を作れない。定数変数は別の分布である。

rate 3秒⁻¹ の平均と scale は？

答えと理由を見る

平均1/3秒、scale 1/3秒。

rate の逆数が時間単位の scale になる。

Exp(λ) の P(T>−1) を e^λ と計算してよいか？

答えと理由を見る

よくない。実際の値は1である。

T≥0 がほぼ確実であり、指数の裾の公式の t≥0 という条件に反している。

もう一歩先へ

平均の積分と無記憶性の適用範囲：λ>0 の指数分布で、有限の R に対して部分積分すると ∫₀ᴿ tλe^(−λt)dt=−R e^(−λR)+(1−e^(−λR))/λ となる。R→∞ では指数関数の増加が一次式より速いので R e^(−λR)→0 となり、平均1/λを得る。例えば e^(λR)≥(λR)²/2 を用いれば R e^(−λR)≤2/(λ²R)→0 と確認できる。無記憶性は s,t≥0 で上の条件付きの裾の比から証明され、分母は常に正である。この計算は仮想的な指数モデル内の定理であり、観測された事象の独立性を新たに証明するものではない。

小節 4.3

正規分布と標準化

平均と広がりが異なる2つの釣鐘形の分布を、どう同じ目盛りで読めるだろうか？

準備する概念と学習目標

準備する概念

  • 平均 μ は分布の中心を表す。分散は Var(X)=E[(X−μ)²] で、標準偏差 σ はその正の平方根である。分散の単位は元の単位の二乗、σ の単位は元の単位である。
  • 標準化 Z=(X−μ)/σ は、中心を引いて正の大きさ σ で割る変換である。σ>0 なら不等号の向きは保たれる。
  • Φ はこの単元で定義する標準正規 CDF の名前である。関数名を使った正確な答えと数値近似した答えは異なる表現である。正規分布の仮定がデータから自動的に確認されるわけではない。

学習目標

  • 正規密度とパラメータの条件を書く。
  • 確率を標準化して正確な Φ の式で求め、標準化が正規性を作るわけではないと説明する。

正規モデルの定義

μ∈ℝ、σ>0 のとき N(μ,σ²) はすべての実数 x で f(x)=exp(−(x−μ)²/(2σ²))/(σ√(2π)) という密度を持つ。ここで第2パラメータは分散である。密度は正で総積分は1である。σ=0 ではこの密度公式はなく、μ に集中する定数分布を別に扱う。

μ は位置を移動し、σ は横の幅を変える。σ が小さいほど同じ総面積を狭い範囲に収めるため、高さは大きくなりうる。釣鐘形という視覚的な印象だけではデータの正規分布を証明しない。また正規モデルは負の値も許すので、常に正でなければならない測定量に用いるならモデルの裾と現実の制約を別に検討する必要がある。

標準化が保存する事象

Z~N(0,1) の密度を φ(z)=e^(−z²/2)/√(2π)、CDF を Φ(z)=∫₋∞ᶻ φ(t)dt と定義する。X=μ+σZ なら X~N(μ,σ²) である。逆に X がその正規分布なら (X−μ)/σ は標準正規分布に従う。置換 dx=σ dz は密度の正規化と確率の面積をともに保存する。

σ>0 なので P(X≤x)=Φ((x−μ)/σ) であり、a<b に対し P(a<X≤b)=Φ((b−μ)/σ)−Φ((a−μ)/σ) である。裾は1−Φ((x−μ)/σ)である。標準化後の値 z は無次元で、μ・x・σ は同じ単位でなければならない。分散 σ² で割ることは標準化ではない。

対称性は正確な計算の根拠

φ は偶関数なので Φ(−z)=1−Φ(z)、Φ(0)=1/2 である。c≥0 に対して P(|Z|≤c)=2Φ(c)−1 となる。この対称性で左右の裾を同じ式で表せる。有限の z で φ>0 なので Φ は狭義単調増加であり、0<Φ(z)<1 である。

標準化自体は分布の形を正規分布に変えない。例えば U~U(−1,1) は平均0、分散1/3なので、√3U の平均・分散は0・1だが、依然として有限区間の一様分布である。標準正規分布はすべての実数で正の密度を持つので、この分布と異なる。この単元の正規例題は指定モデル内でのみ計算する。

途中の過程をたどる例題

仮定された X~N(10,4) cm について P(8<X≤12)、P(X>14)、P(X≤10) を正確な式で求めよ。正規分布表や数値プログラムは使用しない。

  1. 第2パラメータ4は cm² 単位の分散なので、σ=2 cm、μ=10 cm である。
  2. Z=(X−10)/2 によって2つの端点を−1と1に変換し、P(8<X≤12)=Φ(1)−Φ(−1) を得る。
  3. 対称性によって最初の答えを2Φ(1)−1にまとめる。X>14 は Z>2 と同じなので1−Φ(2)である。
  4. 中心以下の確率は Φ(0)=1/2 である。最初の2つの答えは正確な関数式であり、確認していない小数近似や実測比率を付け加えない。

2Φ(1)−1、1−Φ(2)、1/2。σ は4ではなく2 cmである。

紙と本文で試してみよう

Y~N(−2,9) 秒の P(Y≤1)、P(−5<Y<1)、P(Y>−2) を Φ の式で求めよ。密度の単位と標準化後の値の単位も書け。

ヒントを見る

解答を見る

3つの答えは Φ(1)、Φ(1)−Φ(−1)=2Φ(1)−1、1/2である。密度の単位は1/秒で、z=(y+2)/3 は無次元である。負の時間を許す仮想的な正規モデルであり、必ず非負の実際の待ち時間に適合するとは主張しない。

よくある誤解と反例

平均を引き標準偏差で割ると、すべてのデータが正規分布になる。

一様な U(−1,1) を √3 倍しても、(−√3,√3) の外で密度が0の一様分布である。平均0・分散1という2つの数値は、分布全体を決定しない。

理解を確かめる

答えと理由を見る

1。

σ=√9=3 なので (8−5)/3=1 である。

正規分布で P(X=μ) は1/2か？

答えと理由を見る

違う。0である。

1/2は P(X≤μ) である。一点では密度積分の面積が0になる。

標準正規分布の Φ(−2) を Φ(2) で表すと？

答えと理由を見る

1−Φ(2)。

偶密度において左右の裾が等しいという対称関係を使う。

小節 4.4

分位点と裾の確率

上側の裾の確率を定めるとどの境界値を選ぶべきか。また、平坦な CDF ではどうするだろうか？

準備する概念と学習目標

準備する概念

  • 0<p<1 の p は下側の累積確率水準である。モデルの90パーセンタイル値は p=9/10 の分位点を意味し、標本の90パーセンタイルを計算する規約とは区別する。
  • inf S は S の下界のうち最大の値、すなわち下限である。その値が S に属するかどうかは別問題だが、CDF の右連続性が分位点の境界の包含を保証する。
  • 裾 P(X>x) は境界を超える事象である。一般の分布では P(X≥x)=1−F(x−) と区別し、密度モデルでは一点の確率が0なので両者は等しい。

学習目標

  • inf の規約で分位点を計算し、平坦な区間を扱う。
  • 分位点水準と超過確率の関係を証明し、正規分布の裾の正確な式と境界を区別する。

一般化逆関数の規約

CDF F に対し、この単元の分位点を Q(p)=inf{x∈ℝ:F(x)≥p}、0<p<1 と定義する。CDF の両端での極限は0と1なので、該当集合は空でなく下に有界であり、Q(p) は有限実数である。0と1の端点分位点はこの規約の定義域に入れず、無限の境界や別の慣例が必要になることがある。

F が連続かつ狭義単調増加で、0と1の間のすべての値を取るなら、Q は通常の逆関数で F(Q(p))=p である。F が平坦なら F(x)=p の解が複数存在することがあり、inf の規約は累積確率 p に初めて到達する左の境界を選ぶ。分布の特定の分位点を述べるときは、どの規約かを示す。

平坦な区間と超過確率

密度 f=1/2 を (0,1) と (2,3) に置き、それ以外で0とすると、総面積は1である。CDF は [1,2] で1/2に平坦になる。方程式 F(x)=1/2 はこの区間全体を解に持つが、Q(1/2)=1 である。Q(3/4)=5/2 は第2区間の内部にある。連続 CDF だからといって通常の逆関数が常にあるわけではない。

一般の CDF では F(Q(p))≥p なので P(X>Q(p))≤1−p である。跳躍があると厳密な不等号も起こりうる。連続 CDF では F(Q(p))=p なので正確に1−pとなる。例えば定数 X=0 の Q(p)=0 だが P(X>0)=0 なので、すべての分布で超過確率が正確に1−pだとしてはいけない。

分布ごとの境界と正規分布の裾

U(a,b) では Q(p)=a+(b−a)p、rate λ の指数分布では Q(p)=−ln(1−p)/λ である。λ>0 と0<p<1によって正の待ち時間の境界を得る。正規分布では Q(p)=μ+σΦ⁻¹(p) である。Φ は狭義単調増加なので逆関数が存在し、σ>0なので順序を保つ。

標準正規分布の右裾 T(z)=1−Φ(z)=∫ᶻ∞ φ(t)dt は正確な式のまま保てる。z>0 では [z/(1+z²)]φ(z)≤T(z)≤φ(z)/z という上下界もある。これは近似等式でも実測確率でもない。z=0 では上界の分母0を使わず、対称性による正確値 T(0)=1/2 を使う。

途中の過程をたどる例題

上の2区間の密度 f=1/2 のモデルについて、Q(1/2)、Q(3/4) と各分位点の超過確率を求めよ。

  1. F は x≤0 で0、0<x<1 で x/2、1≤x≤2 で1/2、2<x<3 で1/2+(x−2)/2=(x−1)/2、x≥3 で1である。
  2. F(x)≥1/2 の集合は [1,∞) なので、その下限 Q(1/2)=1 である。平坦区間の中間値を任意に選ばない。
  3. 3/4 は第2の増加区間で得られる。(x−1)/2=3/4 を解くと x=5/2 であり、それより小さい x では累積確率が3/4未満である。
  4. 密度を持つ分布なので F は連続である。P(X>1)=1/2、P(X>5/2)=1/4 で、それぞれ1−pに等しい。

Q(1/2)=1、Q(3/4)=5/2。超過確率は1/2と1/4である。

紙と本文で試してみよう

T~Exp(rate 1/2 分⁻¹) の Q(3/4) とその超過確率を求めよ。X~N(10,4) cm の Q(3/4) を正確な Φ⁻¹ の式で書き、標準正規分布の T(2) の上下界を φ(2) の式で書け。

ヒントを見る

1−p=1/4 であり ln 4 を正確に保つ。正規分布の σ=2 と裾の境界 z=2 を使う。

解答を見る

指数分布の分位点は −ln(1/4)/(1/2)=2 ln 4 分で、超過確率は e^(−ln 4)=1/4 である。正規分布の分位点は10+2Φ⁻¹(3/4) cmである。標準正規の裾は (2/5)φ(2)≤T(2)≤(1/2)φ(2) で、φ(2)=e⁻²/√(2π) である。どの式にも、実行していない小数近似を付け加えない。

よくある誤解と反例

分位点はいつも方程式 F(x)=p の一意の解で、その境界を超える確率は常に1−pである。

2区間密度の p=1/2 では [1,2] 全体が方程式の解だが、inf 規約は1を選ぶ。定数 X=0 ではどの0<p<1にも Q=0だが、超過確率0は1−pより小さい。一意性と裾の等式には、それぞれ別の条件がある。

理解を確かめる

U(2,8) の Q(1/4) は？

答えと理由を見る

7/2。

2+(8−2)/4=2+3/2=7/2 である。

正規分布の Q(1/2) は？

答えと理由を見る

μ。

Φ(0)=1/2 で狭義単調増加なので Φ⁻¹(1/2)=0 である。

p=1 を指数分布の分位点公式に代入すると有限値を得るか？

答えと理由を見る

得ない。この単元の規約は p<1 である。

ln(1−p) が ln 0 となり実数として定義されない。p↑1 で境界は+∞へ向かう。

もう一歩先へ

分位点の性質と裾の境界の証明：A={x:F(x)≥p} の下限を q とする。各 n に対して q≤aₙ<q+1/n を満たす aₙ∈A を選べる。単調性と右連続性によって F(q)≥p となる。したがって Q(p)≤x と p≤F(x) は同値である。F が連続なら、すべての y<q で F(y)<p であり、y↑q とすると F(q)≤p も得られ、等号になる。よって連続モデルの超過確率は1−pである。また p₁≤p₂ なら {x:F(x)≥p₂}⊂{x:F(x)≥p₁} なので Q(p₁)≤Q(p₂) である。事象の同値性から Q の各半直線の逆像は (0,1) 内の区間で、Borel 可測である。そのため Q(U) を確率変数として扱える。U~U(0,1) にこの事象の同値性を適用すると P(Q(U)≤x)=P(U≤F(x))=F(x) となり、逆変換による分布構成も証明される（実際の乱数生成はしていない）。正規分布の裾は z>0 で φ′(t)=−tφ(t) を用いると、部分積分から T(z)=φ(z)/z−∫ᶻ∞ φ(t)/t² dt となる。最後の積分は非負なので上界を得る。t≥z ではその積分≤T(z)/z² なので T(z)(1+1/z²)≥φ(z)/z となり、下界を得る。無限端点の項 φ(t)/t→0 で、上記の指数減衰により積分は収束する。この2つの結果は明示した実数モデルの証明であり、数値表や観測実験の代わりにはならない。
