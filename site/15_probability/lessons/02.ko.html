소단원 2.1

조건부확률의 정의

어떤 일이 일어났다는 정보를 알게 되면, 무엇을 분모로 삼아야 할까?

준비 개념과 학습 목표

준비 개념

  • 사건은 표본공간 Ω의 부분집합이다. A∩B는 둘 다 일어나는 사건이고 Aᶜ는 A가 일어나지 않는 사건이다.

  • 확률은 0 이상이고 P(Ω)=1이다. 서로소 사건의 확률은 더한다. 유한 표본공간이어도 각 결과가 같은 확률일 필요는 없다.

  • 미니복습: 0.2/0.5=2/5는 전체 0.5 중 0.2가 차지하는 비율이다. 조건 뒤의 세로선은 나눗셈 기호가 아니라 주어진 정보를 표시한다.

학습 목표

  • P(B)>0일 때 조건부확률을 정의하고 계산한다.

  • 조건부확률의 순서를 바꾸면 의미와 분모가 바뀜을 설명한다.

  • 확률이 0인 조건 사건과 단순 경우의 수를 쓸 수 있는 조건을 구분한다.

서로 겹치는 두 정보를 받으면 조건부확률 두 개를 곱하면 될까?

본문의 네 결과 a, b, c, d와 확률 0.1, 0.2, 0.3, 0.4를 쓰되, 새 질문의 사건은 A = {a,c}, B = {b,c}, C = {c,d}로 정한다. 두 정보 B와 C가 모두 주어지면 남는 사건은 B∩C = {c}다. P(B∩C) = 0.3 > 0이고 c는 A에도 속하므로 P(A|B∩C) = 1이다. 본문과 A의 정의가 다르므로 새 사건 정의를 먼저 적는다.

B만 주면 P(A|B) = 0.3/0.5 = 3/5이고 C만 주면 P(A|C) = 0.3/0.7 = 3/7이다. 이 둘의 곱 9/35는 두 정보를 함께 준 확률 1과 다르다. 서로 다른 기준 집단에서 계산한 확률을 그냥 곱할 근거가 없다. B로 제한한 공간에서 다시 C로 제한하면 분자와 분모의 P(B)가 약분되어 원래 공간의 교집합 조건으로 돌아간다.

확률이 0인 조건과, 양의 확률을 가진 조건 안에서 불가능한 사건을 구별한다. B의 확률이 양수이고 A∩B가 비어 있으면 분자가 0이므로 조건부확률은 0이다. 반면 조건 사건 자체의 확률이 0이면 이 비율을 정의하지 못한다. 분모를 먼저 확인하면 관측 조건이 모형에서 가능한지도 점검할 수 있다.

먼저 확인할 개념
  • 조건의 양수 분모와 중첩 제한

    새 정보를 교집합으로 기록한 뒤 같은 기준에서 정규화한다.

  • 같은 조건에서 쓰는 전확률

    여러 기준 집단의 비율을 혼합할 때 조건을 통일한다.

조건 정보를 새로운 기준으로 삼는다

P(B)>0이면 P(A|B)=P(A∩B)/P(B)로 정의한다. B가 일어났다는 조건에서 A가 일어날 확률이다. B 밖의 결과는 제외하고, B 안에 남은 확률을 합이 1이 되도록 다시 나눈다. B 안의 결과들이 원래 서로 다른 확률이었다면 조건을 주어도 그 비율은 유지된다.

B가 비어 있지 않다는 것만으로 충분하지 않다. 연속 균등 분포에서는 한 점의 사건이 비어 있지 않아도 확률은 0이다. P(B)=0이면 이 비율은 정의하지 않는다. 조건부 밀도·정규 조건부 분포 등의 추가 이론을 쓰는 경우를 이 정의에 몰래 넣어 0으로 계산하지 않는다.

조건부확률도 확률 법칙을 따른다

B를 고정하고 Q(E)=P(E∩B)/P(B)라 두면 Q(E)≥0, Q(Ω)=1이다. 서로소 Eᵢ의 교집합 Eᵢ∩B도 서로소이므로 가산 가법성을 P에 적용하고 양수 P(B)로 나누면 Q의 가산 가법성이 나온다. 따라서 P(Aᶜ|B)=1−P(A|B)이고 모든 조건부확률은 0과 1 사이에 있다.

유한 균등 결과에서는 P(A∩B)/P(B)=|A∩B|/|B|가 된다. 결과의 개수로 계산할 수 있는 것은 이 균등 가정 덕분이다. 결과가 두 개 남았다는 이유만으로 각각 1/2이라고 하는 것은 일반적으로 틀리다.

조건의 방향과 곱셈법칙

P(A|B)와 P(B|A)는 교집합은 같아도 분모와 질문이 다르다. 각각 P(B)>0와 P(A)>0이 필요하다. 정의를 곱하면 P(A∩B)=P(A|B)P(B)다. 이 항등식은 독립을 가정하지 않는다. 독립일 때에만 조건부확률을 무조건부확률로 바꿀 수 있다.

세 사건의 곱셈 전개 P(A∩B∩C)=P(A)P(B|A)P(C|A∩B)는 P(A)>0, P(A∩B)>0인 경우 정의를 두 번 적용한 결과다. 중간 조건이 확률 0이면 그 조건부 항을 사용하지 않고 교집합 자체의 확률이 0임을 먼저 판정한다. 0×정의되지 않은 값을 정당한 계산으로 쓰지 않는다.

중간 과정을 따라가는 예제

Ω={a,b,c,d}이고 확률은 각각 0.1, 0.2, 0.3, 0.4다. A={a,b}, B={b,c}일 때 P(A|B)와 P(B|A)를 구하라.

  1. 네 확률의 합은 1이다. P(A)=0.1+0.2=0.3이고 P(B)=0.2+0.3=0.5로 두 분모 모두 양수다.

  2. A∩B={b}이므로 교집합 확률은 0.2다. 원소 개수 1을 원소 개수 2로 바로 나누지 않는다.

  3. P(A|B)=0.2/0.5=2/5이고 P(B|A)=0.2/0.3=2/3이다. 조건을 뒤집으면 답이 달라진다.

  4. B 안의 b,c 확률은 각각 2/5, 3/5이며 합은 1이다. (2/5)×0.5=0.2로 원 교집합을 복원한다.

P(A|B)=2/5, P(B|A)=2/3. B 안의 두 결과는 균등하지 않다.

조건을 바꾸어 비교하기

중첩 조건을 교집합으로

B를 안 뒤 C도 알았다. B 안에서 다시 계산한 P(A|C)는 원래 어떤 확률인가?

  1. B 안에서 C의 확률은 0.3/0.5 = 3/5다.

  2. B 안에서 A∩C의 확률도 0.3/0.5 = 3/5다.

  3. 두 조건부확률의 비는 1이다.

원래 P(A|B∩C)=1과 같다. 두 정보를 함께 조건으로 사용했다.

비교할 점

원래 P(A|C)=3/7과는 기준 집단이 다르다.

0과 정의 불가

별도 표본공간 Ω = {a,b,z}에서 각 확률은 0.4, 0.6, 0이다. P({a}|{b})와 P({a}|{z})를 비교하라.

  1. 첫 조건의 분모 0.6은 양수이고 교집합은 비어 있어 분자가 0이다.

  2. 둘째 조건의 분모는 0이므로 비율을 정의하지 못한다.

첫째는 0이고, 둘째는 이 정의에서 정의되지 않는다.

비교할 점

{z}는 비공집합이어도 양의 확률 조건을 만족하지 않는다.

종이와 본문으로 직접 해보기

공정한 육면체 주사위를 한 번 던진다. B=짝수, A={6}일 때 P(A|B), P(B|A), P(Aᶜ|B)를 구하라. 조건 사건을 ∅로 바꾸면 어떻게 되는가?

힌트 보기

B={2,4,6}의 세 결과는 같은 확률이다. A에 속하면 반드시 짝수지만, 짝수라고 반드시 6은 아니다.

풀이 보기

P(A|B)=1/3, P(B|A)=1, P(Aᶜ|B)=2/3이다. ∅는 확률 0이므로 P(A|∅)는 이 정의에서 정의되지 않는다. 0이라고 답하지 않는다.

오해와 반례

조건 뒤에 결과가 두 개 남으면 각각의 확률은 1/2이다.

예제의 B 안에 b,c 두 개가 남아도 각각 2/5, 3/5다. 경우의 수 비율은 같은 확률인 결과를 세는 모형에서만 쓴다.

자기점검

P(B)=0인 비공집합 B에도 교집합 비율을 쓸 수 있나?

답과 이유 보기

쓸 수 없다.

분모의 양수 조건이 필요하며 비공집합과 양의 확률은 같은 조건이 아니다.

P(A)=0.3,P(B)=0.5,P(A∩B)=0.2일 때 A와 B는 독립인가?

답과 이유 보기

아니다.

0.3×0.5=0.15가 교집합 0.2와 다르다. 곱셈법칙 자체는 여전히 성립한다.

P(A|B)=0.4이면 P(Aᶜ|B)는?

답과 이유 보기

0.6이다.

P(B)>0로 정의된 같은 조건부 확률공간에서 여사건 법칙을 쓴다.

스스로 풀어보기

먼저 답과 이유를 적고, 필요한 만큼 힌트를 한 단계씩 열어 보세요.

연습 1 · 값과 상태 예측

첫 표에서 P(A|B∩Cᶜ)와 그 조건에서 A의 여사건 확률은?

힌트 1

B∩Cᶜ={b}다.

힌트 2

b는 A={a,c} 밖에 있다.

풀이와 답 확인

  1. 분모는 0.2이고 A와의 교집합은 비어 있어 분자가 0이다.

  2. 같은 조건에서 여사건의 확률은 1 − 0 = 1이다.

양의 분모에서 A의 확률은 0, A의 여사건 확률은 1로 정상 정의된다.

흔한 오답에서 다시 생각하기

교집합이 비었으니 조건부확률도 정의되지 않는다.

정의 여부는 조건 사건의 분모로 판단한다.

연습 2 · 오류 찾아 고치기

P(A|B)P(A|C)=9/35를 두 정보 아래 A의 확률로 보고했다. 고쳐라.

힌트 1

조건 둘은 B∩C로 함께 묶는다.

힌트 2

그 교집합의 확률은 0.3이다.

풀이와 답 확인

  1. A∩B∩C = {c}의 확률은 0.3이다.

  2. 0.3/0.3=1로 계산한다.

다른 조건에서 계산한 두 확률의 곱을 근거 없이 사용하지 않는다.

두 정보를 더 알면 확률을 반드시 곱해 작게 만든다.

추가 정보는 확률을 높이거나 낮출 수 있고 여기서는 A를 확정한다.

연습 3 · 직접 만들어 보기

B를 조건으로 둔 새 확률 Q에서 C를 조건화하는 식을 원 확률 P로 전개하라.

힌트 1

Q(A∩C)=P(A∩B∩C)/P(B)다.

힌트 2

Q(C)=P(B∩C)/P(B)이며 양수인지 확인한다.

풀이와 답 확인

  1. 두 식의 비를 쓰고 P(B)를 약분한다.

  2. P(A∩B∩C)/P(B∩C)=P(A|B∩C)를 얻는다.

P(B)>0와 P(B∩C)>0에서 성립한다.

흔한 오답에서 다시 생각하기

첫 번째 조건을 반영한 뒤 두 번째에는 원래 분모 P(C)를 넣는다.

두 번째 정규화의 기준도 Q다. 원 분모 P(C)로 섞지 않는다.

연습 4 · 선택 심화

선택 심화는 기본 연습 뒤 더 탐구하고 싶을 때 풀어 보세요.

B∩C의 확률이 0인 다른 모형에서는 같은 약분식으로 조건부확률을 구할 수 없는 이유를 설명하라.

힌트 1

Q(C)=0이다.

힌트 2

조건부 비율은 양의 분모가 필요하다.

풀이와 답 확인

  1. 교집합을 조건으로 둔 비율의 분모가 0이다.

  2. 현재 유한 사건의 정의로 두 정보 아래 확률을 계산하지 않고 모형과 관측 정의를 점검한다.

연속 모형의 정규 조건부 분포 같은 다른 이론을 이 비율에 몰래 넣지 않는다.

흔한 오답에서 다시 생각하기

0/0은 정보를 전혀 못 받았으므로 원 확률과 같다.

이 정의에서 0/0에 그런 값을 배정할 근거가 없다.

내 말로 설명하기

조건을 두 개 받으면 무엇을 분모로 쓰나?

설명 기준 확인

두 정보의 교집합 확률이 양수일 때 그 교집합을 기준으로 정규화한다.

분자가 0인 경우와 분모가 0인 경우는 같은가?

설명 기준 확인

분모가 양수이고 분자가 0이면 확률은 0이다. 분모가 0이면 이 정의를 적용하지 못한다.

한 단계 더

심화: 조건 사건 C⊆B이고 P(C)>0이면 먼저 B로 제한한 확률 Q에서 다시 C로 조건화해도 Q(A|C)=P(A∩C)/P(C)다. Q의 분자와 분모에 있는 P(B)가 약분되기 때문이다. 중첩된 정보가 집합의 포함관계로 표현되는 경우의 항등식이며, 임의의 관측을 순서대로 곱해도 된다는 독립 가정은 아니다.

독립과 조건부독립

서로 독립인 두 결과도, 어떤 정보를 골라 보면 서로 연결될까?

준비 개념과 학습 목표

준비 개념

  • 곱 형태의 독립 정의는 P(A∩B)=P(A)P(B)다. P(B)>0일 때에만 P(A|B)=P(A)라는 동치식을 사용한다.

  • 유한 확률변수 X는 각 결과에 수나 범주를 붙인 함수다. X=1은 이 값을 가진 결과들의 사건이다.

  • 미니복습: 0과 1 두 값을 갖는 X,Y의 결합표는 00, 01, 10, 11 네 칸이다. 같은 확률이라고 명시하면 각 칸의 확률은 1/4다.

학습 목표

  • 독립과 특정 양의 확률 사건 아래의 조건부독립을 구분한다.

  • 조건화가 독립성을 만들거나 깨뜨리는 반례를 계산한다.

  • 쌍별 독립과 여러 사건의 상호 독립을 구분한다.

숨은 범주와 선별은 독립성을 어느 방향으로 바꿀까?

본문의 숨은 범주 S = 0, 1은 각각 확률 1/2로 유지한다. 새 비교에서는 S = 0일 때 P(X=1|S=0) = 0.2, P(Y=1|S=0) = 0.8이고, S = 1일 때는 각각 0.8과 0.2다. 각 범주 안에서 X와 Y가 독립이라고 정한다. 범주를 합치면 X와 Y가 1일 확률은 각각 0.5지만 둘 다 1일 확률은 (0.16 + 0.16)/2 = 0.16이다. 주변확률의 곱 0.25와 다르므로 주변에서는 독립이 아니다.

본문의 세 이진 변수 모형은 결과 000, 011, 101, 110에 각각 확률 1/4를 준다. 새로 X₃ = 1이라는 조건을 붙이면 011과 101만 남는다. X₁과 X₂가 1일 조건부확률은 각각 1/2지만 둘 다 1인 결과는 불가능하므로 결합확률은 0이다. 원래 각 쌍이 독립이라는 사실과 선별한 표에서의 독립을 따로 확인한다. 이 유한 표의 관계는 실제 센서의 인과 효과를 측정한 결과가 아니다.

큰 결합표에서는 한 칸이 주변확률의 곱과 같아도 전체 독립을 증명하지 못한다. X의 값은 0, 1이고 Y의 값은 0, 1, 2인 새 표를 생각하자. 두 행의 확률은 (2,3,1)/12와 (2,1,3)/12다. 행합은 각각 1/2, 열합은 각각 1/3이다. (X=0,Y=0)의 확률 1/6은 주변확률의 곱과 같지만 (X=0,Y=1)의 확률 1/4는 1/6과 다르다. 본문의 이진 2×2 표에서 성립하는 특수 성질을 다른 크기의 표에 적용하지 않는다.

독립은 교집합과 곱의 일치다

사건 A,B의 독립은 확률표의 등식이다. 이 정의는 한 사건의 확률이 0인 경우에도 의미가 있고 A,B에 대칭이다. 사건이 서로소인 것과는 다르다. 두 사건의 확률이 모두 양수인데 서로소라면 교집합은 0, 곱은 양수이므로 오히려 독립이 아니다.

유한 X,Y의 독립은 모든 값 x,y에 대해 P(X=x,Y=y)=P(X=x)P(Y=y)로 정의한다. 일반 크기의 결합표에서는 한 칸의 일치만 확인해서 전체 독립을 판정할 수 없다. 다만 X,Y가 각각 0과 1만 갖고 주변 확률 p=P(X=1), q=P(Y=1)가 주어졌다면 P(X=1,Y=1)=pq 하나가 나머지 칸 p−pq, q−pq, 1−p−q+pq를 강제하므로 네 칸 모두 곱으로 분해된다. 이 특수한 2×2 표의 성질을 더 큰 표에 일반화하지 않는다. 자료가 서로 다른 파일에 있거나 서로 다른 장치에서 나온다는 설명도 이 등식의 증명이 아니다.

같은 조건부 확률공간에서 독립을 다시 묻는다

P(C)>0일 때 A,B가 C 아래 조건부독립이라는 말은 P(A∩B|C)=P(A|C)P(B|C)라는 뜻이다. 세 항 모두 같은 C로 조건화한다. 유한 범주 변수 S가 주어졌을 때 X,Y의 조건부독립은 P(S=s)>0인 모든 s와 모든 x,y에서 해당 결합표가 곱으로 분해된다는 조건이다.

조건부독립에서 주변 독립이 자동으로 나오지 않는다. S=0,1이 각각 확률 1/2이고, S별로 X,Y를 독립 생성하되 각각의 1 확률이 0.2와 0.8이라 하자. P(X=1)=P(Y=1)=0.5지만 P(X=1,Y=1)=(0.04+0.64)/2=0.34라 주변 독립이 아니다. 같은 숨은 범주의 혼합이 연결을 만든다.

정보로 결과를 골라내면 독립이 깨질 수 있다

원 결합표 네 칸이 각각 1/4이면 X,Y는 독립이다. 하지만 X=Y라는 C를 알게 되면 00,11만 남고 각각 조건 확률 1/2다. 하나가 1임을 알면 다른 하나도 1이다. 이것은 기존 표와 새로운 조건부 표를 서로 다른 기준에서 계산한 결과이지 확률 법칙의 모순이 아니다.

상호 독립은 여러 사건 중 모든 비어 있지 않은 부분집합의 교집합 확률이 각 확률의 곱이어야 한다. 세 사건 전체 교집합 하나만 확인하거나 모든 두 사건 쌍만 확인하는 것으로는 일반적으로 충분하지 않다. 분할·선별·반복 관측을 포함하는 자료 분석에서 필요한 독립 조건을 정확히 지정한다.

전확률 공식

여러 경로의 오류율을 합칠 때, 왜 단순 평균이 아닌 가중 평균일까?

준비 개념과 학습 목표

준비 개념

  • 분할 B₁,…,Bₙ은 서로소이며 합집합이 Ω인 사건들이다. 각 결과는 정확히 한 조각에 속한다.

  • 가중 평균은 값에 그 값이 적용되는 비중을 곱한 뒤 더한다. 비중은 0 이상이고 합이 1이다.

  • 미니복습: 경로 1을 전체의 20%만 쓰면 그 경로 오류율을 전체 100%에 적용해서는 안 된다. 경로와 오류가 독립일 필요는 없다.

학습 목표

  • 서로소·전체 포함 조건으로 전확률 공식을 증명한다.

  • 분할의 확률을 가중치로 전체 확률을 계산한다.

  • 중복 범주·누락 범주·영확률 범주의 처리를 설명한다.

선별한 자료에도 원래 경로 비중을 그대로 쓰면 될까?

새 모형의 경로 G와 H는 전체를 나누는 서로소 사건이며 확률은 0.4와 0.6이다. 경로별 오류 사건 E의 확률은 0.2와 0.05이므로 전체 오류 확률은 0.4×0.2 + 0.6×0.05 = 0.11이다. 선별 사건 C의 확률은 G에서 0.5, H에서 0.25다. 각 경로 안에서 C와 E가 독립이라고 추가로 가정한다. 이 가정이 있어야 선별한 뒤에도 경로별 오류율을 그대로 쓸 수 있다.

P(C) = 0.4×0.5 + 0.6×0.25 = 0.35다. 선별 자료의 경로 비중은 G가 0.2/0.35 = 4/7, H가 0.15/0.35 = 3/7이다. 따라서 P(E|C) = (4/7)×0.2 + (3/7)×0.05 = 19/140이다. 원래 비중 0.4와 0.6을 사용한 값 0.11과 다르다. 조건부확률과 가중치에 같은 조건을 붙여야 하는 이유다.

구성 차이는 전체 성적의 비교에도 작용한다. 별도의 계산표에서 방법 A는 쉬운 문제 100개 중 90개, 어려운 문제 20개 중 10개를 맞힌다. 방법 B는 쉬운 문제 20개 중 19개, 어려운 문제 100개 중 60개를 맞힌다. B가 두 범주에서 모두 높은 정답률을 보이지만 전체 정답률은 A의 100/120이 B의 79/120보다 높다. 두 범주를 같은 반반 비중으로 가중하면 A는 0.7, B는 0.775가 된다. 문제 구성이 다른 비율을 곧바로 방법의 인과 효과로 읽지 않는다.

먼저 확인할 개념
  • 조건부 전확률과 가중치

    선별 후 분할 비중과 범주 내부 확률의 조건을 통일한다.

  • 조건부독립 가정의 역할

    선별이 범주 내부 오류율을 유지하는지 별도 조건을 확인한다.

사건을 중복 없이 쪼개면 확률을 더할 수 있다

분할에 대해 A=⋃ᵢ(A∩Bᵢ)이며 각 교집합은 서로소다. 가법성으로 P(A)=ΣᵢP(A∩Bᵢ)다. P(Bᵢ)>0인 조각에는 곱셈법칙을 적용해 P(A)=ΣᵢP(A|Bᵢ)P(Bᵢ)를 얻는다. 유한 또는 가산 분할에서는 같은 논증이 가능하지만 임의의 비가산 합을 이 공식처럼 쓰지 않는다.

확률 0인 조각이 있으면 그 교집합도 확률 0이다. 먼저 이 항을 제외하고 양의 확률 조각에만 조건부 공식을 쓴다. 정의되지 않은 P(A|Bᵢ)에 0을 곱했다고 설명하지 않는다. 서로 겹치는 범주를 그대로 합치면 중복 계수이고, Ω를 덮지 않으면 빠진 조각이 있다.

전체를 대표하는 가중치는 자료량과 연결된다

경로별 오류율이 같지 않아도 전확률은 성립한다. 여기서는 각 항의 가중치가 경로 선택 확률이고, 조건부 값이 그 경로 안의 오류 확률이다. 단순 산술평균은 경로 선택 확률이 모두 같거나 우연히 같은 합을 낼 때에만 일치한다.

예제의 10000개 환산은 확률을 보기 위한 기대 빈도 표다. 실제 표본에서 반드시 그 개수가 나오거나 실제 조사로 얻은 비율이라는 뜻은 아니다. 경로 비중이 바뀌어 전체 오류율이 달라져도 경로 자체의 품질이 바뀌었다는 인과 결론은 나오지 않는다.

추가 조건이 있으면 가중치도 같은 조건으로 바꾼다

P(C)>0이면 C 아래에서 다시 분할을 적용한다. P(A|C)=Σᵢ P(A|Bᵢ∩C)P(Bᵢ|C)이며 P(Bᵢ∩C)>0인 조각만 포함한다. C로 선별된 모집단에서 원래의 P(Bᵢ)를 그대로 쓰면 일반적으로 틀린다. 조건부 값과 가중치는 같은 기준 집단에 속해야 한다.

전체 확률에서 역방향 비중도 계산할 수 있다. P(A)>0이면 P(Bⱼ|A)=P(A|Bⱼ)P(Bⱼ)/P(A)다. 이는 오류가 나온 경로의 비중이고, 경로 안의 오류율과 질문이 반대다. 다음 소단원에서 이 등식을 Bayes 갱신으로 정리한다.

가상 처리 경로 B₁,B₂,B₃가 분할이고 선택 확률은 0.2, 0.3, 0.5다. 오류 사건 A의 경로별 확률은 0.1, 0.04, 0.02다. 전체 오류 확률을 구하라.

  1. 세 경로는 겹치지 않고 전부를 덮으며 비중의 합은 0.2+0.3+0.5=1이다. 모두 양수라 조건부 값을 사용한다.

  2. 오류와 각 경로의 교집합 확률은 0.2×0.1=0.02, 0.3×0.04=0.012, 0.5×0.02=0.01이다.

  3. 서로소인 세 교집합을 더해 P(A)=0.02+0.012+0.01=0.042=21/500이다.

  4. 10000개 기대 빈도로는 경로별 2000, 3000, 5000개 중 오류 기대 개수가 200, 120, 100으로 합 420이다. 420/10000=0.042로 일치한다.

전체 오류 확률은 4.2%다. 기대 빈도 환산이며 실제 처리 로그가 아니다.

쉬운 문제와 어려운 문제의 표에서 A와 B를 원래 전체 비중과 같은 반반 비중으로 비교하라.

  3. 반반 비중이면 A는 (0.9 + 0.5)/2 = 0.7, B는 (0.95 + 0.6)/2 = 0.775다.

소단원 2.4

Bayes 갱신과 기저율

결함을 잘 감지하는 경보라도, 경보가 울린 물건이 결함일 확률은 왜 낮을 수 있을까?

준비 개념과 학습 목표

준비 개념

  • 사전확률은 관측 정보를 주기 전의 P(D)이고 사후확률은 정보를 조건으로 준 P(D|T)다. 둘은 같은 모집단과 확률모형 안에서 비교한다.

  • P(T|D)는 결함 물건에서 경보가 울릴 확률이다. P(T|Dᶜ)는 정상 물건의 거짓 경보 확률이며 P(D|T)와 구분한다.

  • 미니복습: 전체 경보는 결함의 경보와 정상의 경보 두 서로소 조각이다. 분모에는 두 조각을 모두 넣어야 한다.

학습 목표

  • 양의 증거 확률 아래 Bayes 공식을 유도한다.

  • 기저율과 거짓 경보가 사후확률에 미치는 영향을 계산한다.

  • 반복 증거의 조건부독립 및 확률 갱신과 의사결정의 경계를 설명한다.

반대 결과로 갱신하는 일과 그 뒤 행동을 정하는 일은 같을까?

본문의 가상 결함률 0.01, 경보의 감지 확률 0.9와 거짓 경보 확률 0.05를 유지한다. 이번에는 경보가 없다는 사건 Tᶜ를 관측한다. 결함이면서 무경보일 확률은 0.01×0.1 = 0.001, 정상이면서 무경보일 확률은 0.99×0.95 = 0.9405다. P(D|Tᶜ) = 0.001/0.9415 = 2/1883이다. 정상일 때 무경보일 확률 0.95를 무경보일 때 결함의 사후확률로 읽지 않는다.

두 번의 새 관측이 각 가설 D와 Dᶜ 아래에서 조건부독립이고 같은 경보율을 가진다고 명시하자. 첫째는 경보, 둘째는 무경보인 경우의 결함 교집합 확률은 0.01×0.9×0.1 = 0.0009이고 정상 교집합 확률은 0.99×0.05×0.95 = 0.047025다. 결함의 사후확률은 4/213이다. 같은 기록을 복사한 두 관측이라면 경보와 무경보를 동시에 보는 사건 자체가 비어 있으므로 이 분모를 사용하지 못한다.

사후확률은 행동을 정할 때 사용하는 입력 중 하나다. 별도의 의사결정 모형에서 그대로 두면 결함일 때 손실 20, 정상일 때 손실 0이고, 수리는 확실히 결함을 없애며 비용 2가 든다고 정한다. 그대로 둘 때의 기대손실 20p와 수리 비용 2를 비교해 p > 0.1이면 수리를 고른다. 비용이 5라면 기준은 0.25다. 첫 경보 뒤 같은 사후확률 2/13에서도 비용 2에서는 수리, 비용 5에서는 그대로 두기를 고른다. 이는 실제 수리 효과나 비용을 측정한 결과가 아니라 직접 정한 손실표의 계산이다.

교집합을 두 방향으로 쓰면 갱신 공식이 나온다

P(D)>0, P(T)>0이면 P(D∩T)=P(T|D)P(D)=P(D|T)P(T)다. 마지막 식을 P(T)로 나누면 P(D|T)=P(T|D)P(D)/P(T)다. D, Dᶜ가 양의 확률이면 전확률로 P(T)=P(T|D)P(D)+P(T|Dᶜ)P(Dᶜ)를 구한다. 이것은 교집합의 대칭성과 조건부 정의에서 나온 항등식이다.

가설 Hᵢ들이 양의 확률 분할을 이루고 P(T)>0이면 사후 비중은 P(T|Hᵢ)P(Hᵢ)를 전체 합으로 나눈 값이다. 확률 0인 가설은 교집합도 0으로 별도 처리한다. 모형상 P(T)=0인 증거를 관측했다면 이 비율은 정의되지 않는다. 임의로 사후확률 0을 반환하기보다 모형·측정·사건 정의를 점검해야 한다.

기저율은 분모 안의 정상 물건 수에도 작용한다

예제의 결함률 1%, 감지 확률 90%, 거짓 경보 확률 5%는 실제 장치 측정값이 아니라 가정이다. 같은 대상 모집단에 이 값들이 적용되고 물건 하나를 그 분포에서 선택하는 모형이다. 결함이 드물면 정상 물건은 많아서, 정상의 작은 거짓 경보율이 많은 경보를 만들 수 있다.

10000개 기대 빈도에서 90과 495라는 값은 모형 확률에 곱한 기대 개수다. 무작위 표본이 반드시 이 표가 된다는 뜻도, 무작위 비율의 기대값이 항상 기대 개수 비율과 같다는 뜻도 아니다. 선별된 모집단이나 기간에서 조건부 경보율이 달라지면 원 표를 그대로 옮기지 않는다.

증거를 반복 사용하려면 새로운 가정을 확인한다

두 경보 T₁,T₂의 결합 우도는 P(T₁∩T₂|D)다. 이를 각 우도의 곱으로 바꾸려면 D 아래 조건부독립이 필요하고, 정상 가설 쪽에서도 Dᶜ 아래 조건부독립이 필요하다. 두 결과가 주변에서 독립이라는 가정과는 다르다. 같은 기록을 복사해 두 번 읽는 경우는 새로운 독립 증거가 아니다.

Bayes 갱신은 확률을 주며 원인이나 행동을 자동 결정하지 않는다. 결함 발생의 인과 관계나 실제 성능은 추가 설계와 자료가 필요하다. 물건을 폐기할지 재검사할지에는 비용·위험·효용과 목표가 필요하다. 여기서는 가상 확률 계산만 하고 실제 장치·사용자 실험을 수행하지 않는다.

중간 과정을 따라가는 예제

가상 결함 사건 D의 확률은 0.01이다. 경보 T에 대해 P(T|D)=0.9, P(T|Dᶜ)=0.05다. 경보가 울렸을 때 결함일 확률을 구하라.

  1. 사전 비중은 결함 0.01, 정상 0.99다. 교집합 P(D∩T)=0.01×0.9=0.009다.

  2. 정상 경보의 교집합은 0.99×0.05=0.0495다. 전체 경보 확률은 0.009+0.0495=0.0585>0이다.

  3. P(D|T)=0.009/0.0585=2/13≈0.153846이다. 감지 확률 0.9를 사후확률로 바꾸어 읽지 않는다.

  4. 10000개 기대 빈도로는 결함 100개 중 경보 90, 정상 9900개 중 경보 495다. 전체 585개 기대 경보 중 결함 경보 비중은 90/585=2/13이다.

사후확률은 2/13, 약 15.38%다. 90%는 결함 조건에서의 경보 확률이다.
