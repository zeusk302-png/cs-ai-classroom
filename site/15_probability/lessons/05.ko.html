소단원 5.1

기댓값의 선형성

서로 영향을 주는 두 점수도 평균을 따로 계산해 더할 수 있을까?

준비 개념과 학습 목표

준비 개념

  • 확률 p는0이상이며 가능한 경우의 합은1이다.

  • 유한 확률변수는 각 경우에 수를 붙인 표다.

학습 목표

  • 가중평균을 계산한다.

  • 선형성에 독립성이 필요 없음을 설명한다.

평균 알림 개수가 1을 넘으면 확률 규칙을 어긴 걸까?

가상 상태 U는 1, 2, 3, 4를 각각 확률 1/4로 갖는다. 알림 A는 U가 1 또는 2일 때, B는 2 또는 3일 때, C는 2일 때 켜진다. 알림 개수 N = I_A + I_B + I_C의 평균은 1/2 + 1/2 + 1/4 = 5/4다. 하나라도 켜질 확률은 U가 1, 2, 3인 확률 3/4다. 개수의 평균과 합집합의 확률은 서로 다른 양이므로 평균 5/4를 확률 125%로 해석하지 않는다.

각 상태의 알림 개수는 차례로 1, 3, 1, 0이다. 직접 가중합으로도 E[N] = (1 + 3 + 1 + 0)/4 = 5/4다. 알림들은 같은 U에서 만들어져 독립이 아니지만 선형성에는 문제가 없다. 처리 비용을 L = 5 + 2I_A + 3I_B + 4I_C로 정하면 평균 비용은 5 + 1 + 3/2 + 1 = 17/2다. 기본 비용 5와 각 알림의 고정 비용을 명시한 자체 모형이다.

비용 계수가 무작위로 달라지면 고정 상수처럼 평균 밖으로 빼지 않는다. 별도 두 상태에서 요청 수 X와 요청당 비용 R이 각각 (0,4), (2,1)이며 각 확률은 1/2라고 하자. 실제 총비용 XR은 0 또는 2여서 평균 1이다. E[X]E[R]은 1 × 5/2 = 5/2로 다르다. R이 상수이거나 적절한 독립 조건을 갖는 경우와 달리, 여기서는 요청 수와 단가의 관계를 전체 표로 계산해야 한다.

먼저 확인할 개념
  • 기댓값의 선형성과 지시변수

    종속된 알림도 각 개수의 평균을 더할 수 있다.

  • 변수변환의 가중합

    무작위 비용 계수의 곱은 상태별 값을 먼저 구한다.

확률을 무게로 사용하는 평균

값 x_i가 확률 p_i로 나온다면 E[X]=Σx_i p_i이다. 같은 값이 여러 경우에 나오면 확률을 합쳐도 결과는 같다. 관측한 자료의 평균과 달리 이 값은 모형의 모든 경우를 이용한다. 한 번 시행하면 기댓값 자체가 나오리라는 뜻은 아니다.

예를 들어0과1이 각각 절반 확률이면 평균은0.5다. 가능한 결과에는0.5가 없지만 평균이 잘못된 것은 아니다. 유한 표에서는 계산이 항상 유한하며, 무한 표에서는 E|X|<∞ 같은 존재 조건을 먼저 확인한다.

왜 더하기와 상수배가 통하는가

같은 표본 경우 ω마다 X(ω),Y(ω)를 적고 확률 p(ω)를 붙인다. Σ[aX(ω)+bY(ω)+c]p(ω)를 분배하면 aΣXp+bΣYp+cΣp가 된다. 마지막 합이1이므로 E[aX+bY+c]=aE[X]+bE[Y]+c이다.

이 증명은 p를 X의 확률과Y의 확률의 곱으로 바꾸지 않는다. X,Y가 같은 시행에서 완전히 함께 움직여도 성립한다. 독립성은 두 변수의 관계에 대한 추가 조건이며 선형성의 전제가 아니다.

지시변수로 세기와 사용 경계

사건 i가 일어나면 I_i=1, 아니면0인 지시변수를 둔다. E[I_i]=P(사건 i)이므로 사건 발생 개수 N=ΣI_i의 평균은 ΣP(사건 i)다. 사건끼리 겹쳐도 개수의 평균 계산에는 선형성을 그대로 쓴다.

곱이나 제곱까지 분배해서는 안 된다. X가±1을 절반씩 취하면 E[X]=0이지만 E[X²]=1이다. 무한 개 변수를 더할 때도 유한합 증명을 그대로 늘리지 말고 수렴과 기댓값 교환 조건을 따로 확인한다.

각 행의 확률은 1/4다. N 열의 평균 5/4와 N > 0인 행의 확률 3/4를 따로 계산한다.

중간 과정을 따라가는 예제

X=-1,1,3의 확률이1/4,1/2,1/4다. Y=2X로 정하고 Z=3X−Y+4의 기댓값을 구하라.

  1. E[X]=(−1)/4+1/2+3/4=1이다.

  2. Y는X로 결정되어 독립이 아니지만 E[Y]=2E[X]=2다.

  3. 선형성으로 E[Z]=3·1−2+4=5다.

  4. 직접 Z=X+4의 값3,5,7에 같은 확률을 붙이면3/4+5/2+7/4=5로 일치한다.

평균5이며, 종속성은 선형 계산을 방해하지 않는다.

조건을 바꾸어 비교하기

개수의 분포를 먼저 만들기

N의 PMF와 평균을 구하고 합집합 확률과 비교하라.

  1. N = 0은 U = 4, N = 1은 U = 1 또는 3, N = 3은 U = 2다.

  2. 질량은 각각 1/4, 1/2, 1/4이며 가중합은 0 + 1/2 + 3/4다.

E[N] = 5/4, P(N > 0) = 3/4다.

비교할 점

최대 세 개를 세는 개수 변수와 한 번만 세는 발생 여부는 다르다.

고정 비용과 무작위 단가

알림 비용 L의 평균과 별도 XR의 평균을 구하라.

  1. L의 직접 평균은 (7 + 14 + 8 + 5)/4 = 17/2다.

  2. 별도 XR의 직접 평균은 (0 × 4 + 2 × 1)/2 = 1이다.

고정 비용의 선형 계산은 일치하지만 무작위 단가의 평균 곱은 일치하지 않는다.

비교할 점

두 모형을 같은 비용 정책으로 취급하지 않는다.

종이와 본문으로 직접 해보기

힌트 보기

풀이 보기

N표로0·1/2+2·1/2=1이다. 각각 E[I]=1/2이므로 합도1이다. N=1인 경우가 없어도 평균1은 가능하다.

오해와 반례

기댓값을 더하려면 두 변수가 독립이어야 한다.

같이 켜지는 알림은 완전히 종속이지만 합의 평균은1이다. 반대로 곱의 평균을 평균의 곱으로 쓰려면 별도 조건이 필요하다.

분산과 표준편차

평균 점수가 같아도 매번 흔들리는 정도를 어떻게 수로 나타낼까?

준비 개념과 학습 목표

준비 개념

  • 기댓값은 확률을 가중치로 한 평균이다.

  • 제곱은 부호를 없애지만 단위를 제곱한다.

학습 목표

  • 중심 제곱편차를 계산한다.

  • 이동·배율에 따른 분산 변화를 구별한다.

센서를 두 개로 늘렸다는 이유만으로 평균의 분산이 줄어들까?

가상 오차 U는 −2와 2를 각각 확률 1/2로 취해 평균 0, 분산 4를 갖는다. 첫 값 X = U와 둘째 값 Y = U를 같은 기록에서 복사하면 두 값의 평균 M은 여전히 U여서 분산 4다. Y = −U로 만들면 M = 0이므로 분산은 0이다. 독립인 두 값을 각각 같은 주변분포로 만들 때는 평균 M의 값 −2, 0, 2에 확률 1/4, 1/2, 1/4가 붙어 분산 2다. 두 값의 개수와 각 주변분포가 같아도 결합 방식이 평균의 흔들림을 바꾼다.

독립 예에서 중심 제곱합은 4 × 1/4 + 0 + 4 × 1/4 = 2다. 복사 예는 4이고 반대 부호 예는 0이다. 합 X + Y의 분산은 각 평균의 분산에 4를 곱한 16, 0, 8이다. 개별 분산 두 개를 무조건 더한 8은 세 경우 중 독립 예에만 맞는다. 이 표는 실제 센서 두 개를 측정해 독립성을 확인한 결과가 아니다.

정확 수학식 Var(X) = E[X²] − (E[X])²와 근사 저장값의 뺄셈도 구별한다. 별도 X₀가 100과 102를 반씩 갖으면 평균 101, E[X₀²] = 10202, 분산 1이다. 자체 저장 규칙이 둘째 모멘트만 가장 가까운 10의 배수로 반올림하고 평균은 정확히 보존한다면 저장된 둘째 모멘트는 10200이다. 두 저장값으로 계산한 10200 − 101² = −1은 실제 음수 분산이 아니라 서로 다른 정확도의 요약을 뺀 오류다. 중심 편차 −1과 1을 정확히 제곱하면 1을 얻는다. 이 규칙은 특정 언어의 부동소수점 구현을 시험한 결과가 아니다.

평균에서의 거리와 단위

μ=E[X]일 때 Var(X)=E[(X−μ)²]를 분산이라고 한다. 양쪽 편차를 그냥 평균하면0이 되어 퍼짐을 놓치므로 제곱한 거리를 평균한다. 제곱은 비음수이므로 분산도0이상이다.

표준편차 σ=√Var(X)는 원래 측정 단위를 돌려준다. 시간이 초 단위이면 분산은초², 표준편차는초다. 모형 확률변수의 표준편차와 n개 자료로 모집단을 추정하는 표본분산의 n−1 보정은 다른 정의다.

계산 공식과 존재 조건

제곱을 전개하면 E[X²−2μX+μ²]=E[X²]−2μ²+μ²이므로 Var(X)=E[X²]−μ²다. 이 식은 E[X²]가 유한할 때 일반적인 유한 수 계산으로 쓴다. 평균이 존재해도 분산이 무한할 수 있다.

첫 정의는 거리의 의미가 명확하고, 두 번째 식은 계산이 빠르다. 다만 컴퓨터에서 큰 두 수의 차를 빼면 반올림 문제가 생길 수 있어 실제 수치 계산에서는 중심 편차 합을 활용하는 방법도 필요하다. 이론상 두 식은 같다.

이동과 배율, 합의 함정

Y=aX+b이면 E[Y]=aμ+b이므로 Y−E[Y]=a(X−μ)다. 이를 제곱하고 평균하면 Var(Y)=a²Var(X), 표준편차는 |a|σ다. 모든 값에5를 더해도 퍼짐은 그대로이며2배 확대하면 분산은4배다.

분산은 일반적으로 선형이 아니다. X+X=2X의 분산은4Var(X)다. Var(X)+Var(X)=2Var(X)라고 합치면 틀린다. 독립인 두 유한분산 변수의 합에 대해서는 공분산 항이 사라져 분산을 더할 수 있다.

변수변환의 기댓값

점수를 제곱한 뒤 평균내는 것과 평균을 제곱하는 것은 같을까?

준비 개념과 학습 목표

준비 개념

  • PMF(probability mass function, 확률질량함수)는 이산 값마다 확률을 붙이는 함수다.

  • 연속 밀도는 적분으로 확률을 계산한다.

학습 목표

  • 원래 분포로 E[g(X)]를 계산한다.

  • 비일대일 변환에서 확률을 합친다.

상한을 적용한 평균과 평균에 상한을 적용한 값은 같을까?

가상 사용량 X는 0, 2, 8을 각각 확률 1/2, 1/4, 1/4로 갖는다. 과금 기록을 g(X) = min(X,3)으로 정하면 값은 0, 2, 3으로 바뀌고 원래 확률은 유지된다. 원래 평균은 5/2지만 과금 평균은 0 + 2/4 + 3/4 = 5/4다. 원래 평균을 먼저 구해 상한을 적용한 min(5/2,3) = 5/2와 다르다. 고정 장부나 실제 요금제의 측정 결과가 아니라 명시한 가상 과금 모형이다.

기록의 둘째 모멘트는 0 + 4/4 + 9/4 = 13/4이고 분산은 13/4 − (5/4)² = 27/16이다. 원래 X의 둘째 모멘트는 17이고 분산은 43/4다. 상한으로 큰 값을 합친 것은 단순한 상수 이동이나 선형 배율이 아니므로 a² 분산 공식을 바로 적용하지 않는다. 임계값 3 이상이라는 지시변수의 평균도 1/4지만, 원래 평균 5/2에 지시함수를 적용한 값은 0이다.

연속 비교 모형 V ~ U(−2,2)에서는 E[|V|] = 1이고 E[V] = 0이라 |E[V]|와 다르다. Y = V²의 CDF는 0 < y < 4에서 P(−√y ≤ V ≤ √y) = √y/2다. 미분하면 해당 구간의 밀도는 1/(4√y)다. 원래 v로 적분한 E[V²]와 새 y로 적분한 E[Y]는 각각 4/3으로 같다. 원래 변수의 밀도를 쓰는 적분과 새 변수의 밀도를 쓰는 적분을 혼합하지 않는다. y = 0에서 미분값이 유한하지 않다는 이유로 점 질량을 추가하지 않는다.

값만 바꾸고 확률은 보존하기

유한 이산 X의 값이x_i, 확률이p_i라면 E[g(X)]=Σg(x_i)p_i다. 어떤 결과가 일어나는 확률은 그대로이고 그 결과에 붙이는 숫자를 g로 바꾼다. 변환된 확률변수 Y의 분포를 먼저 구하지 않아도 이 방식으로 평균을 구할 수 있다.

g가 일대일이 아니면 여러x가 같은y로 가므로 Y의 확률은 해당x들의 확률을 모두 합친다. 각각의 기여를 원래 표에서 더하는 방법과 묶인 Y표에서 더하는 방법은 같은 합을 재배열한 것이다.

연속 변수의 경우와 적분 조건

밀도 f_X가 있을 때 E[g(X)]=∫g(x)f_X(x)dx다. 적분 구간은 X가 값을 갖는 영역이며 확률밀도와 변환값을 곱한다. 유한한 일반 기댓값을 쓰려면 ∫|g(x)|f_X(x)dx<∞을 확인한다.

이 공식에는 Y의 밀도를 구할 때 사용하는 Jacobian이 따로 붙지 않는다. 원래x변수로 이미 적분하기 때문이다. Y의 밀도를 구하는 방법을 선택하면 그때는 변수변환 규칙을 적용하며 두 방식을 혼합하면 확률을 이중 보정한다.

같은 분산이면 모든 오류 경계에서 위험도 같을까?

비교 모형 A는 −1과 1을 각각 확률 1/2로 취한다. B는 −3과 3을 각각 확률 1/18로 취하고 나머지 확률 8/9로 0을 취한다. 둘 다 평균 0이고 분산 1이다. 그러나 |오차| ≥ 1/2의 확률은 A가 1, B가 1/9이고, |오차| ≥ 2의 확률은 A가 0, B가 1/9다. 어느 모형이 더 위험한지는 먼저 정한 임계값에 따라 달라진다.

제4중심모멘트는 A가 1, B가 9다. 평균이 0이라 이번에는 제4원점모멘트와도 같지만, 모든 모형에서 같은 것은 아니다. A에 10을 더한 모형은 분산과 제4중심모멘트가 그대로 1인 반면, 제4원점모멘트는 (9⁴ + 11⁴)/2 = 10601이다. 위치를 옮긴 것과 퍼짐을 늘린 것을 원점모멘트 하나로 혼동하지 않는다.

k차 원점모멘트는 E[X^k], 중심모멘트는 E[(X−μ)^k]다. 첫 원점모멘트가 평균이고 첫 중심모멘트는0이다. 두 번째 중심모멘트가 분산이다. k는 양의 정수이며 필요한 기댓값의 존재를 확인한다.

같은 두 요약값과 다른 전체 분포

평균은 중심, 분산은 평균 제곱거리라는 두 수만 제공한다. 그 둘만으로 각 값의 확률을 전부 결정하지 못한다. 드물게 큰 값이 나오는 모형과 항상 작은 값이 나오는 모형이 같은 평균·분산을 가질 수 있다.

따라서 불확실성 비교에는 사용 목적이 필요하다. ±2 이상의 오류가 문제인지 평균 오차가 문제인지 먼저 정하고 관련 꼬리확률 또는 모멘트를 계산한다. 분산이 더 작다는 말은 모든 임계값에서 꼬리확률이 더 작다는 보장이 아니다.

제곱거리로 꼬리의 상한을 얻기
