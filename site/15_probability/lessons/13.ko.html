소단원 13.1

귀무·대립가설

동전이 공정하다는 말을 검토하려면 먼저 무엇을 가정해야 할까?

준비 개념과 학습 목표

준비 개념

  • 모집단 모수와 표본

  • 베르누이 시행

  • 독립성과 이항분포

학습 목표

  • 모수에 관한 두 가설을 쓴다.

  • 방향과 검정 규칙을 자료 전에 정한다.

  • 비기각과 동등성 증명을 구별한다.

가설은 관측 횟수보다 모수를 다룬다

여기서는 독립이고 성공확률 p가 일정한 동전 모형을 정한다. 성공은 앞면이다. H0: p = 0.5는 모수에 대한 귀무가설이고 H1: p > 0.5는 앞면 쪽 변화를 묻는 대립가설이다. 관측 비율이 정확히 0.5여야 H0가 참이라는 뜻은 아니다.

연속 던지기가 독립인지, 던지는 조건이 같은지, 무엇을 성공으로 세는지까지 모형의 일부다. 자료가 모형과 맞지 않으면 작은 p값의 원인이 귀무 모수만의 문제라고 단정할 수 없다. 아래는 실제 동전 실험 없이 정한 확률 모형이다.

한쪽과 양쪽은 다른 질문이다

H1: p > 0.5는 큰 성공횟수가 극단이다. H1: p ≠ 0.5는 작은 횟수와 큰 횟수를 모두 본다. 방향을 관측 후 유리한 쪽으로 고르면 사전에 정한 절차와 달라진다. n과 통계량, 극단의 기준과 유의수준 α를 먼저 기록한다.

검정은 귀무 아래 드물게 나타나는 통계량의 영역을 기각역으로 정하는 방식이다. 기각은 선택한 모형에서 H0와 자료의 불일치를 판단하는 것이며 특정 대립 모수의 참을 논리적으로 증명하는 것과 다르다.

비기각에도 여러 이유가 있다

비기각은 그 규칙에서 충분한 불일치를 찾지 못했다는 결과다. 작은 표본이나 작은 효과 때문에 검정력이 부족할 수도 있다. 공정함을 확정하거나 모든 차이가 없다고 증명하는 문장으로 바꾸지 않는다.

실용적으로 허용할 차이 안에 있는지 묻는 동등성 검정은 허용 범위와 다른 가설이 필요하다. 단순 차이 검정의 비기각을 동등성 성공으로 표시하지 않는다. 이 단원에서는 차이 검정의 질문을 먼저 명확히 한다.

중간 과정을 따라가는 예제

iid는 각 시행이 독립이고 같은 분포를 가진다는 뜻이다. 동전을 n = 4회 던지는 모형에서 H0: p = 0.5, H1: p > 0.5다. 가능한 성공 횟수와 H0의 확률을 구하고 큰 쪽 극단을 확인하라.

  1. 순서 있는 앞면·뒷면 결과 16개는 각각 확률 1/16이다.

  2. K = 0, 1, 2, 3, 4의 순서열 수는 1, 4, 6, 4, 1이다. 각각의 수를 16으로 나누면 확률이 된다.

  3. 큰 쪽 끝 K = 4의 확률은 1/16이다. K = 2가 흔하더라도 다른 횟수도 귀무 아래 가능하다.

횟수는 0–4이며 확률은 1/16, 4/16, 6/16, 4/16, 1/16이다. H0는 성공 횟수를 하나로 고정하지 않는다.

소단원 13.2

검정통계량과 p값

관측 결과 하나의 확률과 그보다 극단적인 결과까지의 확률은 같을까?

준비 개념과 학습 목표

준비 개념

  • 귀무 모형

  • 이항 꼬리 합

  • 유의수준과 극단 방향

학습 목표

  • p값의 조건부 꼬리 정의를 계산한다.

  • 관측 한 점과 꼬리 합을 구별한다.

  • p값을 가설 확률이나 효과로 오해하지 않는다.

귀무를 가정하고 통계량의 꼬리를 센다

한쪽 이항 검정에서 통계량은 성공횟수 K다. 관측 k에 대한 p값은 H0의 모형 아래 P(K≥k)로 정한다. 자료를 보지 않은 다른 결과도 정한 극단 규칙으로 합한다. 이는 H0가 참일 확률 P(H0|자료)를 계산한 것이 아니다.

양측에서는 무엇을 더 극단적으로 셀지 정의해야 한다. 여기서는 p0=0.5인 대칭 이항분포에서 |K−n/2|가 관측보다 크거나 같은 사건을 쓴다. 모든 비대칭 이산 모형의 양측 p값이 단순히 단측의 두 배라는 규칙은 아니다.

같은 자료라도 질문이 바뀌면 값이 바뀐다

n=4에서 K=3의 단측 p값은 P(K=3)+P(K=4)=5/16이다. 한 점 K = 3만의 4/16과 다르다. K=4의 단측은 1/16이고 위 양측 규칙에서는 K = 0과 K = 4를 합해 2/16이다.

미리 정한 α=0.05에서 p값≤α일 때 기각한다는 규칙을 쓸 수 있다. 0.05는 자연의 보편적인 선이나 진실 경계가 아니다. 검정 모형과 사전 규칙을 기록하고 값 자체도 함께 보고한다.

작은 p값에서 읽을 수 없는 것

작은 p값은 특정 귀무 모형과 관측 통계량의 불일치를 나타낸다. 효과의 크기·원인의 중요성·자료 오류·선택 편향·모형의 타당성을 따로 평가한다. p값 하나로 실제 의사결정을 끝내지 않는다.

반복해서 던지며 처음 작은 p값만 보고하면 고정 n의 원래 꼬리 계산과 다른 절차다. 여기서는 고정한 n만 분석한다. 중간 확인이나 선택적 보고를 했다면 전체 절차를 반영한 분석이 필요하다.

중간 과정을 따라가는 예제

n = 4, H0: p = 0.5에서 k = 3과 4의 한쪽 p값을 구하라. k = 4의 대칭 양쪽 p값도 구하고 α = 0.05 규칙과 비교하라.

  1. k = 3의 한쪽 값은 (4 + 1)/16 = 5/16 = 0.3125다.

  2. k = 4의 한쪽 값은 1/16 = 0.0625다. 양쪽 값은 (1 + 1)/16 = 0.125다.

  3. 세 값 모두 0.05보다 크므로 각 사전 규칙에서는 비기각이다. 관측 비율이 1이라고 참 모수 p = 1을 확정하지 않는다.

p값은 0.3125, 0.0625, 0.125이며 이 고정 표의 세 규칙에서는 비기각이다.

종이와 본문으로 직접 해보기

처음부터 n=5인 별도 계획에서 k=5를 얻었다고 가정하라. 한쪽 p값과 α=0.05 결론은? 이 값이 H0의 확률인지도 답하라.

힌트 보기

풀이 보기

p값 0.03125이므로 H0가 참일 확률이3.125%이고 실제 효과도 3.125%다.

p값은 귀무 모형 아래 정한 극단 사건의 확률이다. 가설의 사후확률도 효과 크기도 아니며 다른 계산과 정보가 필요하다.

제1·2종 오류·검정력

진짜 차이가 있어도 작은 표의 규칙이 자주 놓칠 수 있을까?

준비 개념과 학습 목표

준비 개념

  • 기각역

  • 반복 확률

  • 이항 모형

학습 목표

  • 두 오류를 서로 다른 모형에 조건화한다.

  • 구체적 대립 모수의 검정력을 계산한다.

  • 명목 수준과 실제 이산 크기를 구별한다.

판정과 실제 상태의 두 축

제1종 오류는 귀무가 참인데 기각하는 사건이다. 제2종 오류는 정한 대립 모수가 참인데 비기각하는 사건이다. 검정력은 그 대립에서 기각할 확률 1 − β다. 하나의 관측 뒤 참 모수를 모르면 지금 어떤 오류를 범했는지 자동으로 확정할 수 없다.

α는 보통 귀무 아래 제1종 오류를 제한하는 설계 수준이다. 이산 검정에서는 실제 기각 확률이 α보다 작을 수 있다. β와 검정력은 표본 수·규칙·구체적인 대립 모수에 따라 바뀌며 모든 대립에 같은 숫자가 아니다.

작은 기각역을 두 모형에서 계산한다

n=5에서 K=5일 때만 기각하는 규칙을 미리 정한다. H0: p = 0.5에서는 실제 기각 확률 1/32≈0.03125로 명목 0.05 이하이다. p=0.8에서는 같은 사건 확률0.8^5다. 검정 규칙은 같고 확률을 계산하는 모형만 달라진다.

큰 차이 p=0.8도 다섯 번 모두 성공해야 하므로 자주 비기각할 수 있다. 비기각 사례가 실제 효과 없음의 증명이 아닌 이유다. 더 큰 표본이나 다른 사전 규칙을 계획하되 결과 뒤에 규칙을 고른 효과와 구별한다.

표본 계획은 질문하는 효과와 연결한다

검정력을 높이려면 탐지할 효과와 모집단 변동·표본 설계·유의수준을 함께 정한다. 독립성을 어긴 복제 자료로 n만 늘리면 원래 이항 계산이 맞지 않는다. 더 엄격한 기준과 더 큰 표본의 역할을 분리한다.

검정력은 특정 모형의 사전 성질이며 관측 p값을 보고 효과가 있었을 확률을 계산한 것이 아니다. 아래 비교는 자체 모형에서 정확한 이항 합으로 계산한 값이며 실제 동전의 성능 측정이 아니다.

중간 과정을 따라가는 예제

n = 5에서 K = 5일 때 기각하는 규칙이다. H0: p = 0.5의 실제 제1종 오류 확률과 대립 p = 0.8의 검정력·제2종 오류 확률을 구하라.

  1. 귀무 아래 기각 확률은 (0.5)^5 = 1/32 = 0.03125다.

  2. 대립 아래 검정력은 (0.8)^5 = 1024/3125 = 0.32768다.

  3. β = 1 − 0.32768 = 0.67232다. 실제 크기가 α = 0.05보다 작아도 검정력이 높다는 뜻은 아니다.

실제 크기는 3.125%다. p = 0.8에서 검정력은 32.768%, 제2종 오류 확률은 67.232%다.

종이와 본문으로 직접 해보기

별도 사전 계획 n = 8에서 K ≥ 7일 때만 기각한다. p = 0.5의 실제 크기와 p = 0.8의 검정력을 구하고 앞 계획과 비교하라.

힌트 보기

K = 7과 K = 8의 확률을 더한다. K = 7의 순서열 수는 8이다.

풀이 보기

귀무 크기는 (8 + 1)/256 = 9/256 = 0.03515625다. 대립 검정력은 8 × (0.8)^7 × 0.2 + (0.8)^8 = 0.50331648다. 두 계획 모두 크기가 0.05 이하이고, 이 대립에서 n = 8 계획의 검정력이 더 높다.

오해와 반례

제1종 오류가 작으면 제2종 오류도 자동으로 작고, 비기각은 오류가 없다는 뜻이다.

두 오류는 서로 다른 실제 모형에 조건화한다. 엄격한 기각역은 대립을 놓칠 수 있으며 비기각에도 제2종 오류 가능성이 있다.

소단원 13.4

다중비교와 효과크기

여러 질문 중 가장 작은 p값 하나만 고르면 원래 오류 기준이 유지될까?

준비 개념과 학습 목표

준비 개념

  • 유효 p값과 유의수준

  • 합집합 확률

  • 효과와 표본 추정

학습 목표

  • 검정 하나와 가족 오류를 구별한다.

  • Bonferroni 기준을 계산한다.

  • 유의성과 효과 크기·선택 보고를 구별한다.

여러 번 기각할 기회를 센다

m개의 사전 검정 가족에서 제1종 오류가 적어도 한 번 날 확률을 가족 오류율(FWER)이라 한다. 각 검정이 0.05라 해도 전체가 0.05인 것은 아니다. 서로 독립이고 모두 귀무이며 각 실제 크기가 정확히 0.05인 모형이면 m = 10의 확률은 1 − 0.95^10이다.

의존이면 이 곱식을 그대로 쓸 수 없다. 대신 오류 사건의 합집합 확률은 각 확률의 합 이하라는 부등식을 쓸 수 있다. 모든 귀무 아래 유효한 개별 p값은 P(p_i≤t)≤t를 만족한다는 조건이 필요하다. 잘못된 모형의 p값을 조정하는 것만으로 타당성이 생기지는 않는다.

전체 기준을 나누는 보수적 방법

가족 목표 α에 대해 각 p_i≤α/m이면 기각하는 Bonferroni 방법을 쓴다. 참인 귀무들의 오류 사건을 합하면 전체 오류 확률은 최대 m×α/m=α다. 이 합집합 논증에는 검정 간 독립성이 필요하지 않다. 모든 기각이 틀릴 확률을 관측 후 산출한 것은 아니다.

m은 실제로 탐색한 가족과 분석 절차에 맞게 정한다. 여러 분석을 수행하고 선택한 한 개만 보고 m = 1이라고 적으면 원래 선택 문제를 숨긴다. 더 적합한 다중검정법도 있지만 목표 FWER와 다른 오류율을 같은 이름으로 바꾸지 않는다.

얼마나 달랐는지도 함께 적는다

효과 크기는 성공비율 차이·평균 차이처럼 과제에 맞는 양이다. p값의 단위와 대상이 다르다. 표본 크기와 변동이 다르면 비슷한 효과도 다른 p값을 가질 수 있으므로 유의성만으로 크거나 유용한 효과를 확정하지 않는다.

추정 효과와 불확실성, 자료 수집·분석 선택·실제 탐색 수를 함께 보고한다. 관측 차이를 모집단의 정확한 차이 또는 인과 효과로 바꾸지 않는다. 아래 p값들은 가상 유효 입력이며 실제 검정 자료를 실행해 얻은 것이 아니다.

중간 과정을 따라가는 예제

미리 정한 검정 4개의 가족에서 가상 p값은 0.01, 0.02, 0.04, 0.20이다. 가족 목표 α = 0.05에서 Bonferroni 기각과 각자 0.05만 쓴 기각을 비교하라.

  1. 조정 기준은 0.05/4 = 0.0125다.

  2. Bonferroni에서는 0.01 하나만 기준 이하이다.

  3. 각자 0.05만 쓰면 0.01, 0.02, 0.04 세 개를 기각한다. 같은 가족 오류 보장을 제공하는 규칙은 아니다.

Bonferroni 기각은 1개, 개별 0.05 규칙의 기각은 3개다. 실제 연구의 검정 결과가 아닌 자체 입력이다.

힌트 보기

독립이면 아무 오류도 없는 확률이 0.95^10이다. 가족 기준은 검정 수로 나눈다.

풀이 보기

오류 확률은 1 − 0.95^10 ≈ 0.40126306이다. Bonferroni 기준은 0.005다. 독립이 없으면 앞 곱식 대신 합집합 상한을 사용하며 유효 p값 조건도 확인한다.

오해와 반례

p값이 더 작으면 실제 효과도 반드시 더 크고 선택된 한 결과만 보고해도 된다.

p값은 효과 크기가 아니다. 표본 크기와 변동·분석 선택을 함께 보고하고 검정 가족을 숨기지 않는다.
