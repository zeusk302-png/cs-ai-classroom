소단원 12.1

누락되는 사용자

사이트가 열리는데도 어떤 사람은 수업을 시작할 수 없는 이유가 무엇일까?

준비 개념과 학습 목표

준비 개념

  • 사용자의 목표

  • 입력과 출력

  • 부분집단과 전체 비율

학습 목표

  • 접속 가능과 실제 이용 가능을 구별한다.

  • 다양한 사용 조건에서 생기는 장벽을 찾는다.

  • 미관찰 집단을 성공으로 처리하지 않는다.

겹치는 조건의 실패를 더하면 몇 요청이 빠질까요?

앞 본문은 전체와 경로별 성공률을 구별합니다. 새 가상 장부의 대상은 서로 다른 요청 ID 12개입니다. 키보드 조건에서 과제를 끝내지 못한 ID 집합 K는 {1,2,3,4}, 저속 연결 조건의 실패 집합 L은 {3,4,5}입니다. 두 조건을 함께 가진 요청도 있으므로 K와 L을 겹치지 않는 사람 집단으로 취급하지 않습니다. 이 모형의 완료 조건은 두 종류 장벽 모두에서 실패하지 않는 것이며 다른 장벽은 없다고 추가 가정합니다.

겹친 실패는 ID 3과 4의 두 개입니다. 하나 이상의 장벽이 있는 요청은 K∪L = {1,2,3,4,5}로 다섯 개이고 완료는 일곱 개입니다. 실패 횟수 4+3 = 7은 고유 실패 ID 수가 아닙니다. 두 집합의 크기만 알고 교집합을 모르면 고유 실패는 4개부터 7개까지, 완료는 5개부터 8개까지 가능합니다.

수정 X는 K의 모든 실패를 제거하지만 L은 그대로 둡니다. 그러면 ID 3과 4는 키보드 장벽을 벗어나도 저속 연결 장벽 때문에 완료하지 못합니다. 완료는 아홉 개가 되어 기존보다 두 개 늘어납니다. 수정 Y만 적용하면 L이 비어도 K의 네 실패가 남아 완료는 여덟 개입니다. X와 Y를 모두 적용하면 이 명시 모형에서는 열두 개가 완료됩니다. 실제 페이지·도구·사람 시험 결과가 아닙니다.

대체 텍스트가 있다는 표시와 그 내용이 과제의 핵심 관계를 전달하는지는 별도로 검사합니다. 예를 들어 목표가 표의 두 값을 비교하는 것인데 대체 문구가 단지 그림이라고만 쓰여 있으면 그 표시만으로 관계가 전달됐다고 결론 내릴 수 없습니다. 실제 접근성 평가는 기술 점검과 사람의 구체적 경험을 함께 다루며 이 작은 장부는 전체 적합성 판정을 대신하지 않습니다.

먼저 확인할 개념
  • 누락되는 사용자

    기본의 겹치지 않는 두 조건 집단과 미관찰 조건을 새 겹침 장부의 고유 ID 계산에 연결합니다.

  • 참여와 포용적 설계

    기본의 참여와 기술 검증 병행을 수정 뒤 완료 확인의 구별로 연결합니다.

평균 사용자 밖의 조건을 살핀다

공개 주소를 알고 페이지를 열었다는 사실만으로 내용을 이해하고 과제를 할 수 있는 것은 아니다. 마우스로만 조작하는 버튼은 키보드 사용자에게 막힐 수 있고 소리만 있는 설명은 듣기 어려운 사람에게 전달되지 않을 수 있다. 접근성은 사용자가 내용을 인지하고 이해하며 이동·상호작용하는 조건과 관련된다.

장애의 종류와 사용 도구는 다양하며 한 사람의 방식이 같은 장애를 가진 모든 사람의 방식은 아니다. 작은 화면, 느린 연결, 소리를 켤 수 없는 장소와 같은 조건도 이용을 바꾼다. 이 단원은 실제 사용자 경험을 대신 추측해 확정하지 않고 장벽을 찾아볼 질문을 제공한다.

설계 선택과 실패 경로를 연결한다

강의의 핵심 그림을 색깔만으로 구별하면 색을 구별하기 어려운 사용자에게 정보가 누락될 수 있다. 글자와 패턴 또는 직접적인 설명을 함께 두는 대안을 검토한다. 영상 대본이나 설명 텍스트는 소리를 듣기 어렵거나 연결이 느린 상황의 대안이 될 수 있으나 실제 내용 대응과 조작 가능성은 따로 확인해야 한다.

같은 자료를 다른 경로로 제공한다는 것은 학습 목표를 없애는 일이 아니다. 예를 들어 그래프의 증가를 읽는 목표라면 그래프의 핵심 관계를 말이나 표로도 접근할 수 있게 하는 방법을 검토한다. 모든 그림에 똑같은 짧은 단어를 붙이는 것만으로 충분하다고 보지 않는다.

전체 성공률과 누락 범위를 나눈다

자체 가상 이용 기록에서 마우스 조건의 8명이 모두 성공하고 키보드 조건의 2명이 모두 실패했다면 전체 성공률은 8/10 = 80%다. 마우스 조건의 8/8 = 100%와 키보드 조건의 0/2 = 0%를 함께 보면 전체 수치가 가린 경로를 알 수 있다. 이 두 집단은 예제 계산을 위해 겹치지 않게 정했으며 실제 사람의 능력 집단을 단정하지 않는다.

저속 연결 조건을 관찰하지 않았다면 그 조건의 성공률은 미확인이다. 실패가 없다는 말도 할 수 없다. 접근성 검사 도구와 사람의 평가를 함께 계획하고 실제 수행 여부를 남긴다. 이 자료는 실제 사이트나 보조 기술, 사용자 시험을 수행하지 않았다.

대상명시된 조건결과와 한계

원래 장벽

K의 실패는 4개, L의 실패는 3개이며 공통 ID는 2개다.

고유 실패는 5개, 완료는 7개다.

X만 적용

K가 비고 L의 실패 3개는 남는다.

완료는 9개이며 순증은 2개다.

Y만 적용

L이 비고 K의 실패 4개는 남는다.

완료는 8개이며 순증은 1개다.

둘 다 적용

두 실패 집합이 모두 빈 집합이다.

다른 장벽이 없다는 모형에서만 완료는 12개다.

조건별 실패 횟수와 고유 ID 수를 먼저 나눕니다. 한 조건의 수정이 모든 조건의 완료로 이어지는지 남은 장벽을 확인합니다.

중간 과정을 따라가는 예제

겹치지 않는 가상 조건 집단에서 마우스 조건의 8명 중 8명이 성공하고 키보드 조건의 2명 중 0명이 성공했다. 전체와 집단별 성공률을 구한다.

  1. 전체 성공은 8명이며 전체 관찰 인원은 10명이므로 8/10 = 80%다.

  2. 마우스 조건은 8/8 = 100%, 키보드 조건은 0/2 = 0%다.

  3. 전체 성공률 80%는 키보드 조건의 장벽을 해결했다는 증거가 아니다.

전체 성공률 80%와 집단별 성공률 100%·0%를 함께 기록한다. 특정 경로의 실패를 평균으로 숨기지 않는다.

조건을 바꾸어 비교하기

교집합을 뺀 고유 실패

K와 L의 합집합과 완료 수를 구하세요.

  1. K∩L = {3,4}이므로 공통 실패는 두 개입니다.

  2. 고유 실패는 4+3−2 = 5개입니다.

  3. 전체 12개에서 다섯 개를 빼면 완료는 일곱 개입니다.

완료율은 7/12입니다. 실패 횟수의 합인 일곱 개를 고유 실패로 쓰지 않습니다.

비교할 점

같은 ID의 두 실패는 두 사람을 뜻하지 않습니다.

완료의 순증과 수정 항목 수

X만 적용했을 때 완료 수가 네 개 늘지 않는 이유를 설명하세요.

  1. 키보드 실패 네 개를 제거해도 ID 3과 4는 L에 남습니다.

  2. 새 고유 실패는 L의 세 개이고 완료는 12−3 = 9개입니다.

  3. 완료의 순증은 9−7 = 2개입니다.

수정한 키보드 실패 네 개와 새로 완료한 두 요청을 구별합니다.

비교할 점

작업 수정량과 사용자 목표 완료량의 분모가 다릅니다.

종이와 본문으로 직접 해보기

가상 수정 뒤 마우스 조건에서는 8/8명, 키보드 조건에서는 1/2명이 성공했다. 전체 성공률과 키보드 성공률을 구하고, 시험하지 않은 저속 연결 조건을 어떻게 적을지 쓰라.

힌트 보기

성공 인원은 8 + 1명이며 저속 연결의 관찰 분모는 없다.

풀이 보기

전체 성공률은 9/10 = 90%, 키보드 조건의 성공률은 1/2 = 50%다. 저속 연결은 미확인으로 적고 분모 0으로 성공률을 계산하지 않는다. 전체 개선에도 키보드 조건에서 실패한 1명은 남는다.

오해와 반례

무료로 공개한 페이지는 누구에게나 이용 장벽이 없다.

무료 접속은 비용 조건 하나를 줄인다. 조작·감각·언어·연결·이해의 장벽이 남을 수 있어 실제 이용 조건을 별도로 확인한다.

자기점검

전체 성공률이 80%이면 키보드 조건의 성공률도 80%인가?

답과 이유 보기

아니다.

자체 표의 키보드 조건에서 성공한 인원은 0/2명이다.

저속 연결의 관찰 인원이 0명이면 성공률은 0%인가?

답과 이유 보기

미확인이다.

실패 인원 0명과 관찰 분모 0은 다른 상태이며 0/0은 정의되지 않는다.

검사 도구 통과만으로 모든 이용 가능성을 보장하는가?

답과 이유 보기

보장하지 않는다.

사람의 평가와 구체적 사용 조건도 필요하다.

연습 1 · 값과 상태 예측

원래 K와 L에서 ID 5의 저속 연결 실패만 제거하면 완료 수와 완료율은?

힌트 1

L에서 5를 지웁니다.

힌트 2

K에 남은 ID 3과 4는 여전히 실패입니다.

풀이와 답 확인

  1. 새 L은 {3,4}이고 합집합은 K의 {1,2,3,4}입니다.

  2. 완료는 12−4 = 8개입니다.

완료는 8개이며 완료율은 2/3입니다.

흔한 오답에서 다시 생각하기

L의 실패가 두 개 줄었다.

제거된 ID는 5 하나뿐이고 3과 4는 그대로입니다.

연습 2 · 오류 찾아 고치기

실패 4+3 = 7개이므로 완료 5개라고 보고했습니다. 고치세요.

힌트 1

공통 ID를 센 뒤 한 번만 셉니다.

힌트 2

실패 횟수와 고유 ID 이름을 분리합니다.

풀이와 답 확인

  1. 공통 ID 3과 4가 두 번 셈에 들어갔습니다.

  2. 고유 실패는 다섯 개이므로 완료는 일곱 개입니다.

고유 실패 5개와 완료 7개로 고칩니다.

모든 조건 집합은 서로 배타적이다.

여기서는 같은 ID가 두 조건에 속한다고 명시했습니다.

연습 3 · 직접 만들어 보기

|K| = 4와 |L| = 3만 알고 교집합을 모릅니다. 완료 수의 가능한 양끝을 만드는 집합을 구성하세요.

힌트 1

L을 K 안에 두면 합집합이 가장 작습니다.

힌트 2

두 집합을 겹치지 않게 두면 합집합이 가장 큽니다.

풀이와 답 확인

  1. K = {1,2,3,4}, L = {1,2,3}이면 고유 실패는 4개, 완료는 8개입니다.

  2. 같은 K에서 L = {5,6,7}이면 고유 실패는 7개, 완료는 5개입니다.

완료 수의 가능한 범위는 5개부터 8개까지이며 양끝은 실제 명시 집합으로 구성할 수 있습니다.

흔한 오답에서 다시 생각하기

교집합 정보가 없어도 완료는 항상 일곱 개다.

일곱 개는 교집합이 두 개인 원래 사례의 값입니다.

연습 4 · 선택 심화

선택 심화는 기본 연습 뒤 더 탐구하고 싶을 때 풀어 보세요.

X와 Y를 모두 적용했다고 기록했지만 내용 이해 조건은 시험하지 않았습니다. 완료 12개를 모든 접근성 요구 통과라고 쓸 수 있나요?

힌트 1

열두 개는 두 집합만 있는 모형의 결과입니다.

힌트 2

미관찰 요구를 통과로 채우지 않습니다.

풀이와 답 확인

  1. K와 L의 장벽 제거는 명시 모형에서 완료 12개를 뜻합니다.

  2. 이해 조건과 다른 도구·상황의 실제 확인은 별도로 미수행입니다.

두 장벽 모형의 완료와 실제 전체 접근성 확인을 분리해 보고합니다.

불평등의 재생산

과거 기록을 그대로 따라 추천하면 이미 기회를 놓친 사람은 어떻게 될까?

준비 개념과 학습 목표

준비 개념

  • 자료 수집

  • 비율과 분모

  • 추천과 관찰

학습 목표

  • 과거 결과와 능력의 차이를 구별한다.

  • 선택·관찰·기록이 만드는 누락을 설명한다.

  • 전체 지표와 기회 배분을 함께 검토한다.

클릭이 적다는 사실은 관심이 적다는 뜻일까요?

새 별도 가상 기록에서 수업 A는 노출 100회 중 클릭 20회, 수업 B는 노출 20회 중 클릭 6회입니다. 한 노출에서 클릭은 최대 한 번이며 두 수업의 노출 집합은 이 계산에서 분리합니다. 클릭 수는 A가 크지만 노출당 클릭 비율은 A가 20%, B가 30%입니다. 실제 흥미·능력·학습 효과나 인과 실험의 자료가 아닙니다.

자체 추천 규칙이 클릭 수가 큰 수업에 다음 창의 노출 80회를, 다른 수업에 20회를 준다고 정합니다. 각 수업의 클릭 비율이 다음 창에서도 정확히 유지된다는 가상 조건을 추가하면 A는 클릭 16회, B는 6회입니다. 클릭 수 규칙은 다시 A를 택합니다. 노출 기회가 다른 상태에서 같은 수업이 계속 선택되는 모형이며 실제 이용자의 미래 행동을 예측했다고 쓰지 않습니다.

별도 설문 장부의 대상은 12명인데 응답 가능한 경로를 통과해 실제로 응답했다고 가정한 사람이 8명이고 그중 만족 응답은 6명입니다. 나머지 네 명은 응답하지 않았고 이유·만족 여부는 미확인입니다. 응답자 만족률 6/8 = 75%에서 전체 만족률을 확정할 수 없습니다. 미응답자가 모두 불만이면 전체는 6/12, 모두 만족이면 10/12입니다. 이 장부는 가상 기록이며 실제 사람에게 설문을 수행한 것이 아닙니다.

노출당 클릭도 순수 관심 지표가 아닙니다. 배치 위치, 설명, 조작 가능성, 연결과 선택 과정이 달라질 수 있습니다. 새로운 기회 규칙을 검토할 때 분모와 적합성·접근·오류·피해를 함께 다루어야 하며 비율 하나를 같게 만드는 것은 모든 공정성 기준의 증명이 아닙니다.

먼저 확인할 개념
  • 불평등의 재생산

    기본의 노출·클릭 순환과 설문 참여 경로 누락을 별도 분모와 가능한 완성으로 확장합니다.

  • 누락되는 사용자

    기본의 미관찰 조건을 설문에 들어오지 못한 사람의 미확인 상태에 연결합니다.

과거 결과에는 기회의 차이가 섞일 수 있다

기록에 과제 완수가 적다는 이유만으로 관심이나 능력이 낮다고 판단하면 컴퓨터를 쓸 시간이나 연결 상태가 부족했던 조건을 놓칠 수 있다. 과거 자료가 당시의 기회 차이를 포함하면 그 결과를 학습한 규칙도 차이를 반복할 수 있다. 모든 차이가 같은 원인이라는 뜻은 아니며 어떤 조건을 관찰했는지 검토해야 한다.

이 단원의 A·B 집단은 자체 가상 접속 조건으로 나눈 두 집단이며 실제 국가·장애·학생 집단의 능력을 뜻하지 않는다. 민감한 특성을 수집하지 않는다고 모든 불평등이 사라지는 것도 아니다. 연결 시간 같은 다른 값이 기회 차이를 반영할 수 있다.

기록에 들어오는 사람부터 달라진다

설문 링크를 빠른 영상 시청 뒤에만 두면 영상을 끝내지 못한 사람은 의견을 남길 기회가 없다. 기록에는 응답자의 목소리만 커지고 서비스를 떠난 이유는 보이지 않을 수 있다. 자료에 들어오지 않은 사람을 불만이 없는 사람으로 처리하지 않는다.

이전 추천이 많이 노출한 수업은 클릭도 많이 받을 가능성이 있다. 클릭 수만으로 수업의 가치가 높다고 정해 더 노출하면 처음 적게 보인 수업과 사용자에게 기회가 더 줄어들 수 있다. 클릭에는 노출·관심·조작·연결 조건이 섞이므로 관심 하나의 순수 측정값이라고 단정하지 않는다.

분모와 판단 기준을 함께 공개한다

자체 가상 표에서 A는 후보 40명 중 20명이 추천을 받고 B는 후보 10명 중 2명이 추천을 받았다고 하자. 추천 비율은 A 집단에서 50%, B 집단에서 20%, 전체에서 22/50 = 44%다. 전체 비율 44%만으로 두 집단의 기회가 같다고 말할 수 없다. 차이는 30퍼센트포인트지만 이 수치만으로 특정한 법 위반이나 모든 원인을 확정하지 않는다.

후보 조건과 추천 목적, 실제로 적합했던 사람의 누락, 피해 가능성과 대안 경로를 함께 살펴야 한다. 공정성은 여러 기준으로 평가할 수 있으며 하나의 비율을 맞추는 일만으로 모든 요구가 충족되는 것은 아니다. 집단별 작은 표는 문제를 찾을 단서이고 전체 윤리 판단의 자동 점수가 아니다.

중간 과정을 따라가는 예제

가상 후보 A 집단의 40명 중 20명, B 집단의 10명 중 2명이 추천을 받았다. 전체와 집단별 추천 비율을 구한다.

  1. A 집단은 20/40 = 50%, B 집단은 2/10 = 20%다.

  2. 전체 비율은 (20 + 2)/(40 + 10) = 22/50 = 44%다.

  3. 집단 간 차이는 50 − 20 = 30퍼센트포인트다.

전체 비율 44%와 집단별 비율 50%·20%를 함께 보며 원인·적합성·피해 판단은 별도로 검토한다.

표준 점검과 사용자 확인을 더하면 완료 항목 수일까요?

새 가상 수정 장부의 필수 항목은 a,b,c,d 네 개입니다. 현재 판본 v2에서 기술 점검을 완료한 집합 T는 {a,b,c}, 지정된 사용자 과제의 재확인을 완료한 집합 U는 {b,c,d}입니다. 이 활동의 자체 완료 정책은 두 확인을 모두 가진 항목만 완료로 표시합니다. 실제 표준의 전 항목 또는 전체 사용자를 대표하는 인증 정책은 아닙니다.

두 집합의 공통 항목은 b와 c여서 완료는 2/4 = 50%입니다. 어느 한 확인이라도 있는 합집합은 네 개이지만 이를 모두 완료로 세면 정책을 바꾼 것입니다. a에는 사용자 확인이, d에는 기술 점검이 남아 있습니다. 같은 판본·과제·도구 조건을 연결하고 다른 판본의 기록을 섞지 않습니다.

같은 사람이 같은 항목을 다시 언급한 기록을 새 완료 항목으로 더하지 않습니다. d의 기술 점검이 v1에서 성공했어도 현재 v2의 확인이라는 추가 근거가 없으면 현재 T에 넣지 않는다고 자체 정책을 선언합니다. 이것은 모든 변경에 동일한 실제 시험 절차를 강제하는 규정이 아니라 어떤 증거가 현재 결정을 지지하는지 추적하는 종이 사례입니다.

별도 계획에서 키보드·화면 읽기·저속 연결·작은 화면 네 경로 중 앞의 두 경로에서 의견을 받았다고 정합니다. 계획 경로의 수집 비율은 2/4지만 전체 사람의 대표성이 50%라는 뜻은 아닙니다. 한 사람의 의견을 모든 경험으로 일반화하지 않고 참여자의 중단·시간·자료 범위를 존중하는 실제 절차는 별도로 준비해야 합니다. 이 단원에서는 모집과 시험을 수행하지 않습니다.

먼저 확인할 개념
  • 참여와 포용적 설계

    기본의 채택·구현·재확인 분모와 사용자 참여·표준 평가 병행을 두 확인의 교집합 정책으로 확장합니다.

  • 누락되는 사용자

    기본의 도구만으로 충분하지 않다는 설명을 기술 확인과 사용자 과제 확인의 별도 상태로 연결합니다.

문제를 정할 때부터 의견 경로를 만든다

완성된 화면에서 좋아요만 묻는 대신 목표와 사용 상황을 정할 때 어려운 경로를 알아볼 계획을 세운다. 의견은 말하기뿐 아니라 글·대본·그림 설명 등 참여자의 방식으로 받을 수 있다. 원고를 이해하기 어려운 사람에게 장시간 영상 면담만 요구하면 참여 단계부터 누락이 생길 수 있다.

실제 참여를 계획할 때 목적과 기록 범위, 중단할 수 있다는 점을 알리고 시간과 요구를 존중한다. 개인 정보를 필요 이상으로 모으지 않는다. 이 자료는 일반적인 설계 원칙을 다루며 특정 국가의 아동 연구 법률이나 실제 동의 절차를 완료했다고 주장하지 않는다.

경험을 설계 근거로 연결하되 일반화하지 않는다

한 사용자가 확대해서 읽는 방식에 익숙하다고 해도 모든 저시력 사용자가 같은 방식인 것은 아니다. 어떤 도구와 경험에서 어떤 과제를 했는지 남기고 다른 경로의 의견도 살핀다. 참여자의 말을 사실 관찰·해석·제안으로 나누면 특정 제안을 그대로 구현해야 하는지 검토하기 쉽다.

참여자 검토는 표준 평가를 대신하지 않고 표준 점검도 실제 경험을 모두 대신하지 않는다. 기술 조건과 다양한 이용 방식을 함께 다루어야 한다. 종이 활동에서는 가상 의견만 사용하며 실제 사용자 대신 장애 경험을 완전히 재현했다고 주장하지 않는다.

의견 수보다 결정과 확인을 추적한다

자체 가상 장부에서 제안 4개 중 2개를 채택하고 1개를 수정 구현했으며 실제 사용자 재확인은 0개라고 정한다. 채택 비율은 2/4 = 50%, 채택 항목을 기준으로 한 구현 비율은 1/2 = 50%, 재확인 비율은 0/2 = 0%다. 의견을 들었다거나 구현했다는 사실을 이용 가능 확인과 섞지 않는다.

계획한 사용 경로를 키보드·화면 읽기·느린 연결·작은 화면 네 가지로 정하고 처음 두 가지 경로의 의견만 받았다는 가상 조건에서는 의견 수집 경로의 비율이 2/4 = 50%다. 이 비율은 모든 장애와 사람을 대표하는 확률이 아니며 아직 들을 수 없었던 경로를 찾는 자체 점검 표다.

  1. 제안을 기준으로 한 채택 비율은 2/4 = 50%다.

  3. 계획 경로의 의견 수집 비율은 2/4 = 50%이며 전체 인구의 대표성을 나타내는 수치가 아니다.

다른 문제에 적용하기

별도 가상 대상 요청은 10개입니다. 키보드 실패 K = {1,2,3}, 저속 연결 실패 L = {3,4}이며 다른 실패는 없다고 가정합니다. K만 모두 수정했을 때 완료 수와 원래 대비 순증을 구하세요. 별도 설문 대상 10명 중 응답자 6명, 만족 응답 4명이고 나머지 네 명은 미확인입니다. 전체 만족률 범위를 구하세요. 별도 현재 판본의 필수 항목 p,q,r에서 기술 확인 T = {p,q}, 사용자 확인 U = {q,r}입니다. 두 확인 모두 필요한 자체 정책의 완료율과 최소 추가 확인을 쓰세요. 실제 사용자나 서비스 시험이 아닌 손장부 활동입니다.

힌트 1

겹친 실패 ID 3을 두 번 세지 않고 남은 L을 확인합니다.

힌트 2

설문의 미확인 네 명과 확인 장부의 두 빈 칸을 각각 계산합니다.

풀이와 답 확인

  1. 원래 고유 실패는 {1,2,3,4}로 네 개이고 완료는 여섯 개입니다. K만 수정하면 L의 두 실패가 남아 완료는 여덟 개이며 순증은 두 개입니다.

  2. 설문 전체 만족은 최소 네 명부터 최대 여덟 명까지 가능하므로 전체 만족률은 40%부터 80%까지입니다. 응답자 4/6과 같은 값으로 확정하지 않습니다.

  3. 현재 두 확인 모두 있는 항목은 q 하나이므로 완료는 1/3입니다. p의 사용자 확인과 r의 기술 확인을 추가해야 하며 한 건당 한 칸 조건에서 최소 두 건입니다.

장벽 수정 뒤 완료는 8/10 = 80%이고 원래 대비 두 요청 증가입니다. 전체 설문 만족률은 40%부터 80%까지 미확인 범위로 보고합니다. 현재 필수 항목 완료는 1/3이며 필요한 추가 확인은 두 건입니다.

  • 조건별 실패 횟수와 고유 ID 및 완료 순증을 구별합니다.

  • 설문의 응답자 분모와 전체 대상 분모 및 미확인 상태를 보존합니다.

  • 현재 판본의 교집합과 항목별 빈 칸을 명시합니다.

  • 가상 장부 산술과 실제 접근성·공정성·참여·표준 인증 미수행을 구별합니다.
