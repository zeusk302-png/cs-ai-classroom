  • 자기점검·힌트·해설
  • 심화: 증명·추가 문제·선택 구현
  • 다음 연결·원문 출처·검토 상태
  • ML 모델 유도를 반복하지 않고 패턴발견·추천·스트림·대규모 처리의 자료 구조와 평가를 다룬다.
  • 단원은 주차와 같지 않다. 12개 학습 단원은 시험·휴강을 제외한 내용 체계이며 과목별 분량·실습시간에 맞춰 주차를 나눈다.
  • 여러 공개 자료의 범위·학습구조를 참고해 자체 구성한 목차이며 대학의 공식 한국어 번역본이나 전체 강의 복제본이 아니다.
  • 이상탐지·시계열·다중검정은 자료의 대규모 패턴·군집 범위를 연결해 추가한 자체 통합 단원이다. 시계열 전체 예측이론을 독립 과목만큼 다루지 않는다.
