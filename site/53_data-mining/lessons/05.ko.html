소단원 5.1

계층·밀도 기반 군집

이웃을 이어 붙이는 것과 중심 가까이 모으는 것은 같은 기준일까?

준비 개념과 학습 목표

준비 개념

  • 군집은 정답 라벨 없이 정한 거리/ 구조로 묶는 과정이다.

  • single linkage는 두 군집의 가장 가까운 점쌍 거리다.

  • DBSCAN의 eps는 이웃 반경, min_samples는 여기서 자기점 포함 개수다.

학습 목표

  • 병합과 밀도 연결을 추적한다.

  • core/ border/ noise와 매개변수 조건을 구별한다.

양쪽 핵심점에 가까운 한 점이 두 군집을 반드시 합치는가?

앞 본문의 지역 반경과 전체 지름 구별을 새로운 점 배치로 확인한다. 아래는 절댓값 거리, 닫힌 이웃 |x−y|≤eps, 자기점 포함 min_samples, 가중치 없는 서로 다른 객체의 종이 모형이다. 실수는 정확한 수로 취급하며 부동소수점 경계 시험을 수행하지 않는다.

왼쪽 네 좌표는 −1.3, −1.2, −1.1, −1이고 오른쪽 네 좌표는 1, 1.1, 1.2, 1.3이다. 별도 객체 z의 좌표는 0이다. eps=1, min_samples=4로 정한다. 양쪽 네 점은 각각 자기 묶음의 네 점을 보므로 모두 core다. −1과 1은 추가로 z를 보아 이웃이 5개다. z의 이웃은 −1, z, 1의 3개라 core가 아니다.

z는 양쪽 core에 가까운 border 후보지만 비core를 통해 확장을 이어 가지 않는다. 자체 결정 규칙은 먼저 확장한 core 성분에 z를 배정하고 이후 다시 배정하지 않는 것이다. 왼쪽부터 시작하면 z는 왼쪽, 오른쪽부터 시작하면 오른쪽에 속한다. core 성분 두 개는 그대로지만 실제 객체의 소속 차이는 단순 군집 번호 바꾸기와 다르다. 이 규칙은 문서의 순서 민감성을 보여 주는 자체 추적이며 API를 실행한 결과가 아니다.

별도 계층 사례는 좌표 0, 2, 3, 7이다. 가장 가까운 2와 3을 높이 1에서 합친 뒤 single/complete/average의 정의를 각각 적용한다. 군집 수만 같아도 병합 높이와 잘라 얻은 분할의 근거가 달라질 수 있다.

먼저 확인할 개념
  • core·border와 지역 반경

    앞 본문의 core에서만 확장하는 규칙과 자기점 포함 조건을 새 경계 사례에 적용한다.

  • 번호와 객체 관계

    군집 번호 재명명과 실제 border 객체의 소속 변경을 구별한다.

작은 묶음에서 큰 묶음으로

계층 병합은 각 점을 한 군집으로 두고 정한 linkage의 가까운 쌍을 합친다. 병합 높이를 나무 그림 dendrogram에 남기며 어디서 자를지에 따라 군집 수가 달라진다. 거리와 동률 처리 규칙을 먼저 정한다.

single은 최소 점 거리, complete는 최대 점 거리, average는 쌍 거리 평균이다. 같은 자료라도 병합 순서가 바뀐다. single의 점 사슬은 양 끝이 멀어도 이어질 수 있어 모든 군집 지름이 병합 높이 이하라고 오해하지 않는다.

밀도 연결은 core에서 확장한다

DBSCAN은 반경 eps 내 자기점 포함 개수가 min_samples 이상인 점을 core로 정한다. 가까운 core를 이어 군집을 확장하고 core 근처 비core 점은 border가 될 수 있다. 어떤 core에도 연결되지 않은 점은 noise다.

단순히 가까운 모든 점을 무조건 이어 붙이지 않는다. 비core 점이 사슬을 계속 확장하지 않는 조건이 있다. eps는 군집 전체의 최대 거리도 아니다. 거리 단위· 특징 스케일과 서로 다른 밀도는 결과에 영향을 준다.

자료 정의와 실패 상태

상자 번호나 군집 ID는 의미 라벨이 아니다. 번호가 바뀌어도 같은 묶음일 수 있고 noise는 기계가 정한 밀도 조건에서의 분류다. 사람의 가치나 정상/ 악성이라는 판정으로 바꾸지 않는다.

실제 자료에는 측정 단위와 거리· 결측값· 매개변수 선택을 기록한다. 본 단원은 1 차원 자체 점의 종이 군집이며 라이브러리 실행· 실제 사회 집단 발견을 수행하지 않았다.

조건을 바꾸어 비교하기

방문 순서가 바꾸는 border 소속

위 아홉 객체에서 왼쪽 성분을 먼저 처리한 L과 오른쪽 성분을 먼저 처리한 R의 z 소속과 core 성분 수를 구하라.

  1. z는 이웃 3개여서 확장을 이어 가지 않는다.

  2. L은 z를 왼쪽에, R은 z를 오른쪽에 배정한다.

  3. 서로 직접 연결된 양쪽 core가 없으므로 두 실행의 core 성분은 각각 2개다.

z의 소속은 다르지만 core 성분 수는 2개로 같다.

비교할 점

군집 이름만 다른 사례와 실제 객체 소속이 다른 사례를 분리한다.

같은 네 점에서 세 linkage

별도 좌표 0,2,3,7의 세 linkage에 대해 병합 높이 세 개를 구하라. 동률은 없다.

  1. 첫 높이는 공통으로 2와 3 사이의 1이다.

  2. {2,3}과 0은 single 2, complete 3, average (2+3)/2=5/2로 합친다. 각각 7과 합치는 대안보다 작다.

  3. 마지막 {0,2,3}과 7은 single 4, complete 7, average (7+5+4)/3=16/3이다.

single은 1,2,4; complete는 1,3,7; average는 1,5/2,16/3이다.

비교할 점

최소/최대/평균의 대상은 군집 간 모든 점쌍이다.

연습 1 · 값과 상태 예측

아홉 객체의 eps=1을 유지하고 min_samples만 3으로 바꾼다. z의 종류와 군집 수는?

힌트 1

z는 자기 포함 이웃 3개다.

힌트 2

core 경로 왼쪽→z→오른쪽을 본다.

풀이와 답 확인

  1. z가 core로 바뀐다.

  2. z의 core 연결이 양쪽 성분을 이어 군집은 1개가 된다.

z는 core이며 모든 아홉 객체가 한 군집이다.

흔한 오답에서 다시 생각하기

z의 좌표가 같으니 결과도 두 군집이다.

이웃 개수가 같아도 core의 문턱을 바꾸면 연결 규칙이 바뀐다.

연습 2 · 오류 찾아 고치기

min_samples=4인 원래 아홉 점에서 모든 eps 이웃 간선을 이어 하나의 군집으로 보고했다. 잘못된 확장 지점과 정상 결과를 적어라.

힌트 1

z가 core인지 먼저 본다.

힌트 2

border는 core 성분을 이어 주는 통로가 아니다.

풀이와 답 확인

  1. z의 이웃은 3개로 문턱 4에 못 미친다.

  2. z에서 다른 성분으로 확장하지 않아 core 성분 2개를 유지한다.

z를 통한 확장을 막고 border 배정 규칙을 기록한다.

흔한 오답에서 다시 생각하기

연결 그래프는 언제나 DBSCAN과 같다.

core 조건 없는 전체 이웃 연결은 다른 알고리즘이다.

연습 3 · 직접 만들어 보기

위 계층 네 점을 높이 5/2 이하의 병합까지 허용해 자른다. single, complete, average의 분할을 각각 구성하라.

힌트 1

높이와 자르기 경계를 정확히 비교한다.

힌트 2

average의 두 번째 높이는 경계와 같다.

풀이와 답 확인

  1. single은 높이 1과 2를 허용해 {0,2,3}/{7}이다.

  2. complete는 높이 3을 허용하지 않아 {0}/{2,3}/{7}이다.

  3. average는 높이 5/2를 포함해 {0,2,3}/{7}이다.

군집 수는 single 2개, complete 3개, average 2개다.

흔한 오답에서 다시 생각하기

세 방식 모두 첫 병합이 같으니 분할도 같다.

첫 병합 이후 linkage별 높이가 다르다.

연습 4 · 선택 심화

선택 심화는 기본 연습 뒤 더 탐구하고 싶을 때 풀어 보세요.

원래 아홉 점의 좌표를 모두 10배 한다. min_samples=4를 유지할 때 eps를 1로 둔 경우와 10으로 바꾼 경우를 비교하라.

힌트 1

같은 좌표 변환에 거리는 10배 된다.

힌트 2

eps 1에서 끝점 사이 3도 이웃이 아니다.

풀이와 답 확인

  1. eps 1에서 각 측면의 이웃 개수는 끝점 2개, 내부점 3개이며 z는 1개다. core가 없어 모두 noise다.

  2. eps 10이면 원래 이웃 관계를 복원하여 core 성분 2개와 순서 의존 border z를 얻는다.

eps 1은 core 0개·noise 9개, eps 10은 원래 관계를 보존한다.

단위를 바꾸어도 eps 숫자는 고정해야 한다.

좌표와 거리 반경의 단위를 함께 변환한다.

대규모군집 근사

점 백만 개를 요약하면 무엇을 빨리 계산하고 무엇을 잃을까?

준비 개념과 학습 목표

준비 개념

  • 미니배치는 전체 대신 일부 자료로 한 번 갱신하는 묶음이다.

  • CF 통계는 N 개수,LS 벡터 합, SS 제곱 길이 합이다.

  • 대표 중심과 원래 점 전체는 다른 정보를 갖는다.

학습 목표

  • 요약 통계로 평균과 제곱 편차를 계산한다.

  • 근사 비용 감소와 품질 손실을 구별한다.

평균과 제곱 편차가 같으면 반경 안의 점 개수도 알 수 있을까?

앞 본문의 CF 합 통계를 유지하면서 잃는 정보를 새로운 두 다중집합으로 분리한다. 서로 다른 객체가 같은 좌표를 가질 수 있다. P의 좌표는 −2,0,0,2이고 Q의 좌표는 −√2,−√2,√2,√2다. 두 묶음 모두 N=4, LS=0, SS=8이며 평균은 0, SSE는 8이다.

그러나 |x|≤1인 객체는 P에서 2개이고 Q에서 0개다. 평균 주위 최대 거리는 P에서 2, Q에서 √2다. CF 세 값만으로 이 두 질의를 동시에 복원하는 함수는 두 입력에 같은 값을 반환해야 하므로 적어도 한쪽에서 틀린다. 이것은 모든 요약이 무용하다는 뜻이 아니라 보존한 질의와 잃은 질의가 다르다는 반례다.

별도 한 중심 누적 모형은 이미 처리한 좌표 0 두 객체의 N=2, LS=0을 유지하고 새 객체 6을 한 번 추가한다. 새 평균은 (0+6)/(2+1)=2다. 이전 장부를 잊고 마지막 배치만 쓰면 6이 되고, 새 객체를 두 번 처리하면 누적 평균은 3이다. 이 모형은 BIRCH 전체나 라이브러리의 재할당/학습률 규칙을 구현하지 않는다.

각 묶음의 개수와 좌표 단위, 정확한 합을 함께 보존해야 합친 SSE를 계산할 수 있다. 새 자료를 기다리는 동안의 메모리·시간 비용과 전체 군집 품질은 여기서 측정하지 않는다.

먼저 확인할 개념
  • CF의 합과 제곱 합

    앞 본문의 N, LS, SS와 SSE 공식을 다른 자료의 정보 손실에 적용한다.

  • 밀도 판단에 필요한 이웃

    평균 요약으로 이웃 개수와 core 판정을 복원한다고 추측하지 않는다.

일부 자료로 중심을 갱신하기

MiniBatchKMeans는 샘플 일부를 중심에 배정해 이전 배정과 합친 평균으로 중심을 수정한다. 전체 최적화 목적을 추구하지만 매번 전체 자료를 배정하는 Lloyd 단계와 같은 궤적은 아니다. 순서· 초기화· 샘플링과 예산을 기록한다.

일부만 보니 희귀한 작은 군집이 배치에 없을 수 있다. 빠르다는 알고리즘 설명은 내 자료의 측정 시간 증거가 아니다. 샘플 누락과 전체 자료 검증 비용을 고려하고 작은 정확 기준과 비교한다.

합으로 보관하는 군집 특징

BIRCH는 CF 묶음과 나무로 자료를 요약한다. N,LS,SS를 합치면 두 묶음의 요약을 갱신할 수 있다. 평균 c =LS/N이며 SSE =SS −||LS ||²/N으로 평균 주위 제곱 편차 합을 구한다.

이 식은 같은 좌표계의 원래 합 통계에 대해 성립한다. 개별 점의 순서· 꼬리· 모든 쌍 거리를 요약 세 개에서 복원하지 못한다. 실제 BIRCH의 threshold/ 분기/ 병합 규칙은 이 한 번 요약 계산보다 많다.

대표 점을 같은 개수로 세지 않기

원래 100점을 대표한 중심과 1점을 대표한 중심에 같은 가중치를 주면 전체 평균이 달라진다. 어떤 목적을 근사하는지와 대표의 개수/ 가중치를 함께 기록한다. 원래 군집 간 거리에 대한 정확 보장도 자동 생기지 않는다.

자료 압축은 메모리를 줄이는 대신 국소 정보를 잃을 수 있다. 입력 순서/ 스케일/ 차원· 요약 크기· 보류자료에서 품질을 비교한다. 실제 대규모 자료 처리· 실행 시간· 메모리 측정은 미수행이다.

소단원 5.3

안정성과 해석

군집 번호가 바뀌었다는 이유만으로 결과가 불안정하다고 할까?

준비 개념과 학습 목표

준비 개념

  • 안정성은 자료/ 초기 조건을 바꿨을 때 묶음 관계가 유지되는지 보는 성질이다.

  • 같은 군집 쌍 관계는 군집 번호 재명명에 불변이다.

  • 안정적인 묶음도 목적에 맞는 정답이라는 보장은 없다.

학습 목표

  • 쌍 일치로 분할을 비교한다.

  • 스케일· 누락· 해석 근거의 책임을 구별한다.

쌍의 대부분이 서로 다른 군집이면 높은 RI가 무엇을 가릴까?

객체 ID를 먼저 맞추고 같은/다른 군집의 순서 없는 쌍을 비교한다. 새 여덟 객체 A부터 H에서 P는 {A,B}만 묶고 나머지 여섯 객체는 각각 한 군집이다. Q는 여덟 객체 모두 각각 한 군집이다. 28쌍 중 AB 하나만 판정이 다르고 나머지 27쌍은 둘 다 분리라 RI=27/28이다.

동시에 P가 함께 묶은 쌍을 Q가 유지했는지를 묻는 자체 지표는 0/1=0이다. 이 지표는 RI나 ARI의 다른 이름이 아니다. 전체 쌍 일치와 특정 함께 묶음의 보존은 다른 질문이므로 두 분모를 표시한다. 군집의 목적 적합성이나 실제 집단의 원인을 이 수치로 추가하지 않는다.

별도 네 객체 비교에서 P={AB}/{CD}, Q={AB}/{C}/{D}다. 공통 A/B만 관찰하면 한 쌍이 일치해 RI=1이지만 전체 네 객체는 CD가 달라 5/6이다. 관찰 범위 2/4와 평가된 쌍 1/6을 함께 보고한다. 빠진 객체를 임의로 독립 군집에 넣거나 일치로 채우지 않는다.

noise 처리도 평가 규칙이다. 별도 출력 N은 AB 한 군집, C/D는 noise이고 비교 R은 {AB}/{CD}다. noise 둘을 한 평가 군집으로 보느냐, 각자 분리하느냐, 둘 다 제외하느냐에 따라 동일 출력의 평가값과 범위가 달라진다. 실제 군집 라이브러리가 noise를 하나의 의미 집단으로 확인했다는 주장은 아니다.

먼저 확인할 개념
  • 쌍 일치와 평가 범위

    앞 본문의 RI 정의·공통 ID·noise 정책을 새 높은 일치율 사례에 적용한다.

  • 요약과 해석의 한계

    통계 요약을 원래 자료나 목적 적합성 전체로 확대하지 않는다.

이름표 대신 관계를 비교하기

한 결과의 군집0/1을 다른 결과에서7/4로 바꿔도 같은 점들이 함께 묶였다면 동일한 분할이다. 번호의 일치율로 안정성을 재면 가짜 변동이 생긴다. 같은 객체 ID와 같은 자료 집합을 먼저 맞춘다.

Rand 지수는 모든 순서 없는 점쌍에 대해 두 결과가 함께/ 분리 판정에서 동의하는 비율이다. ARI는 우연 일치를 보정한 별도 지표다. 아래는 RI이며 ARI라고 이름 붙이지 않는다.

작은 변화와 평가 정책

초기화 seed· 자료 부분 추출· 잡음· 거리 스케일을 변경하며 결과를 비교한다. 빠진 객체의 쌍은 직접 비교할 수 없어 공통 ID 기준 또는 예측 매핑 정책을 정해야 한다. 안정성을 위해 동일 입력을 반복한 것과 자료 변화를 시험한 것도 다르다.

noise를 한 군집으로 취급할지 제외할지 명시한다. 서로 분리된 쌍이 많은 자료에서 RI가 높아도 군집 전체가 비슷하다고 단정하기 어려울 수 있다. 여러 지표와 분포· 조건을 함께 보고한다.

해석은 증거와 범위를 붙이기

군집의 중심 특징과 대표 사례를 보고 왜 묶였는지 설명할 수 있다. 그러나 측정되지 않은 성격· 능력· 질병 같은 속성을 이름표로 추가하지 않는다. 정답 라벨 없이 만든 군집은 인과적 집단의 발견과 다르다.

한 특징의 스케일이 거리를 지배하면 그 특징으로 안정적으로 나뉘어도 원래 목적을 놓칠 수 있다. 안정성· 내부 응집· 외부 타당성은 각각 다른 검사다. 실제 학습자 자료를 수집하거나 검증하지 않은 자체 분할만 비교한다.

풀이와 답 확인

  1. min_samples 4에서는 양쪽 core 성분 2개, z는 비core이며 왼쪽 우선이면 왼쪽·오른쪽 우선이면 오른쪽에 배정한다. min_samples 3에서는 z도 core라 전체 군집 1개다.

  2. P와 Q는 각각 CF (4,0,8), 평균 0, SSE 8이다. |x|≤1인 객체는 P에서 2개이고 Q에서 0개다. 독립 초기 P에 좌표 1을 하나 추가하면 CF는 (5,1,9), 평균은 1/5, SSE는 44/5다.

  3. 여덟 객체의 RI는 27/28이고 자체 함께 쌍 보존은 0/1이다.

  4. 별도 네 객체의 noise 개별 처리는 RI 5/6·객체 4개, 제외는 RI 1·객체 2개·평가 쌍 1개다. 제외 범위는 전체 객체의 2/4와 전체 쌍의 1/6이다.

핵심점 문턱은 2개 대 1개 군집을 만들며, border 소속은 방문 정책에 달린다. 같은 CF가 범위 개수를 보존하지 않고, 높은 RI나 제외 범위의 완전 일치가 함께 관계와 전체 범위의 성공을 보장하지 않는다.
