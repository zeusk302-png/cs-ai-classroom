소단원 5.1

계층·밀도 기반 군집

이웃을 이어 붙이는 것과 중심 가까이 모으는 것은 같은 기준일까?

준비 개념과 학습 목표

준비 개념

  • 군집은 정답 라벨 없이 정한 거리/ 구조로 묶는 과정이다.
  • single linkage는 두 군집의 가장 가까운 점쌍 거리다.
  • DBSCAN의 eps는 이웃 반경, min_samples는 여기서 자기점 포함 개수다.

학습 목표

  • 병합과 밀도 연결을 추적한다.
  • core/ border/ noise와 매개변수 조건을 구별한다.

작은 묶음에서 큰 묶음으로

계층 병합은 각 점을 한 군집으로 두고 정한 linkage의 가까운 쌍을 합친다. 병합 높이를 나무 그림 dendrogram에 남기며 어디서 자를지에 따라 군집 수가 달라진다. 거리와 동률 처리 규칙을 먼저 정한다.

single은 최소 점 거리, complete는 최대 점 거리, average는 쌍 거리 평균이다. 같은 자료라도 병합 순서가 바뀐다. single의 점 사슬은 양 끝이 멀어도 이어질 수 있어 모든 군집 지름이 병합 높이 이하라고 오해하지 않는다.

밀도 연결은 core에서 확장한다

DBSCAN은 반경 eps 내 자기점 포함 개수가 min_samples 이상인 점을 core로 정한다. 가까운 core를 이어 군집을 확장하고 core 근처 비core 점은 border가 될 수 있다. 어떤 core에도 연결되지 않은 점은 noise다.

단순히 가까운 모든 점을 무조건 이어 붙이지 않는다. 비core 점이 사슬을 계속 확장하지 않는 조건이 있다. eps는 군집 전체의 최대 거리도 아니다. 거리 단위· 특징 스케일과 서로 다른 밀도는 결과에 영향을 준다.

자료 정의와 실패 상태

상자 번호나 군집 ID는 의미 라벨이 아니다. 번호가 바뀌어도 같은 묶음일 수 있고 noise는 기계가 정한 밀도 조건에서의 분류다. 사람의 가치나 정상/ 악성이라는 판정으로 바꾸지 않는다.

실제 자료에는 측정 단위와 거리· 결측값· 매개변수 선택을 기록한다. 본 단원은 1 차원 자체 점의 종이 군집이며 라이브러리 실행· 실제 사회 집단 발견을 수행하지 않았다.

중간 과정을 따라가는 예제

점 0,.1,.2,3,3.1,8에서 절댓값 거리,eps =.15,min_samples =2(자기 포함) DBSCAN을 추적하라.

  1. 0의 이웃{0,.1},.1은{0,.1,.2},.2는{.1,.2}라 세 점 모두 core다.
  2. 3과 3.1은 서로와 자기를 포함해 2개라 core다.
  3. 8은 자기만 1개라 core 아니고 다른 core 반경 밖이라 noise다.
  4. core 연결 군집{0,.1,.2}/{3,3.1},noise{8}이다. 첫 군집 지름.2는 eps.15보다 크다.

군집 2개, noise 8이며 core 연결은 쌍 반경이지 군집 지름 제한이 아니다.

소단원 5.2

대규모군집 근사

점 백만 개를 요약하면 무엇을 빨리 계산하고 무엇을 잃을까?

준비 개념과 학습 목표

준비 개념

  • 미니배치는 전체 대신 일부 자료로 한 번 갱신하는 묶음이다.
  • CF 통계는 N 개수,LS 벡터 합, SS 제곱 길이 합이다.
  • 대표 중심과 원래 점 전체는 다른 정보를 갖는다.

학습 목표

  • 요약 통계로 평균과 제곱 편차를 계산한다.
  • 근사 비용 감소와 품질 손실을 구별한다.

일부 자료로 중심을 갱신하기

MiniBatchKMeans는 샘플 일부를 중심에 배정해 이전 배정과 합친 평균으로 중심을 수정한다. 전체 최적화 목적을 추구하지만 매번 전체 자료를 배정하는 Lloyd 단계와 같은 궤적은 아니다. 순서· 초기화· 샘플링과 예산을 기록한다.

일부만 보니 희귀한 작은 군집이 배치에 없을 수 있다. 빠르다는 알고리즘 설명은 내 자료의 측정 시간 증거가 아니다. 샘플 누락과 전체 자료 검증 비용을 고려하고 작은 정확 기준과 비교한다.

합으로 보관하는 군집 특징

BIRCH는 CF 묶음과 나무로 자료를 요약한다. N,LS,SS를 합치면 두 묶음의 요약을 갱신할 수 있다. 평균 c =LS/N이며 SSE =SS −||LS ||²/N으로 평균 주위 제곱 편차 합을 구한다.

이 식은 같은 좌표계의 원래 합 통계에 대해 성립한다. 개별 점의 순서· 꼬리· 모든 쌍 거리를 요약 세 개에서 복원하지 못한다. 실제 BIRCH의 threshold/ 분기/ 병합 규칙은 이 한 번 요약 계산보다 많다.

대표 점을 같은 개수로 세지 않기

원래 100점을 대표한 중심과 1점을 대표한 중심에 같은 가중치를 주면 전체 평균이 달라진다. 어떤 목적을 근사하는지와 대표의 개수/ 가중치를 함께 기록한다. 원래 군집 간 거리에 대한 정확 보장도 자동 생기지 않는다.

자료 압축은 메모리를 줄이는 대신 국소 정보를 잃을 수 있다. 입력 순서/ 스케일/ 차원· 요약 크기· 보류자료에서 품질을 비교한다. 실제 대규모 자료 처리· 실행 시간· 메모리 측정은 미수행이다.

중간 과정을 따라가는 예제

자체 1 차원 묶음 A ={0,2},B ={4}의 CF를 합쳐 평균과 SSE를 구하라.

  1. A는 N2,LS2,SS4,B는 N1,LS4,SS16이다.
  2. 합친 N3,LS6,SS20이므로 평균 2다.
  3. SSE =20 −6²/3 =8이다. 직접(0 −2)² +(2 −2)² +(4 −2)² =8로 검산한다.
  4. A 중심 1/B 중심 4를 무가중 평균하면 2.5로 틀린다. 개수2/1을 반영하면(2·1 +1·4)/3 =2다.

합 CF(3,6,20), 평균 2,SSE8이며 대표 중심에는 개수가 필요하다.

종이와 본문으로 직접 해보기

이 묶음에 점 6을 하나 더 넣으면?

힌트 보기

N에 1, LS에 6,SS에 36을 더한다.

풀이 보기

N4,LS12,SS56, 평균 3,SSE =56 −144/4=20이다. 직접 편차 제곱 9 +1 +1 +9 =20이다.

오해와 반례

평균과 SSE를 저장했으면 원래 자료 모두를 복원했다.

동일 통계를 갖는 다른 배치가 가능하며 점 순서부터 복원되지 않는다. 대표 중심을 원래 모든 점인 것처럼 같은 가중치로 세는 것도 틀린다.

소단원 5.3

안정성과 해석

군집 번호가 바뀌었다는 이유만으로 결과가 불안정하다고 할까?

준비 개념과 학습 목표

준비 개념

  • 안정성은 자료/ 초기 조건을 바꿨을 때 묶음 관계가 유지되는지 보는 성질이다.
  • 같은 군집 쌍 관계는 군집 번호 재명명에 불변이다.
  • 안정적인 묶음도 목적에 맞는 정답이라는 보장은 없다.

학습 목표

  • 쌍 일치로 분할을 비교한다.
  • 스케일· 누락· 해석 근거의 책임을 구별한다.

이름표 대신 관계를 비교하기

한 결과의 군집0/1을 다른 결과에서7/4로 바꿔도 같은 점들이 함께 묶였다면 동일한 분할이다. 번호의 일치율로 안정성을 재면 가짜 변동이 생긴다. 같은 객체 ID와 같은 자료 집합을 먼저 맞춘다.

Rand 지수는 모든 순서 없는 점쌍에 대해 두 결과가 함께/ 분리 판정에서 동의하는 비율이다. ARI는 우연 일치를 보정한 별도 지표다. 아래는 RI이며 ARI라고 이름 붙이지 않는다.

작은 변화와 평가 정책

초기화 seed· 자료 부분 추출· 잡음· 거리 스케일을 변경하며 결과를 비교한다. 빠진 객체의 쌍은 직접 비교할 수 없어 공통 ID 기준 또는 예측 매핑 정책을 정해야 한다. 안정성을 위해 동일 입력을 반복한 것과 자료 변화를 시험한 것도 다르다.

noise를 한 군집으로 취급할지 제외할지 명시한다. 서로 분리된 쌍이 많은 자료에서 RI가 높아도 군집 전체가 비슷하다고 단정하기 어려울 수 있다. 여러 지표와 분포· 조건을 함께 보고한다.

해석은 증거와 범위를 붙이기

군집의 중심 특징과 대표 사례를 보고 왜 묶였는지 설명할 수 있다. 그러나 측정되지 않은 성격· 능력· 질병 같은 속성을 이름표로 추가하지 않는다. 정답 라벨 없이 만든 군집은 인과적 집단의 발견과 다르다.

한 특징의 스케일이 거리를 지배하면 그 특징으로 안정적으로 나뉘어도 원래 목적을 놓칠 수 있다. 안정성· 내부 응집· 외부 타당성은 각각 다른 검사다. 실제 학습자 자료를 수집하거나 검증하지 않은 자체 분할만 비교한다.

중간 과정을 따라가는 예제

객체 A/B/C/D의 분할 P ={AB}/{CD},Q ={AC}/{BD}다. 여섯 쌍의 RI를 구하라.

  1. AB는 P 함께/Q 분리,AC는 P 분리/Q 함께다.
  2. AD와 BC는 두 분할 모두 분리로 동의한다.
  3. BD는 P 분리/Q 함께,CD는 P 함께/Q 분리다.
  4. 동의 2/ 전체 6 =1/3이다. 군집 ID 번호를 비교한 값이 아니다.

RI1/3이며 동의 쌍은 AD/BC다.

힌트 보기

쌍별 함께/ 분리를 기존 P와 비교한다.

풀이 보기

여섯 쌍 모두 같으므로 RI1이다. 라벨 문자열이 다른 것은 분할 변경이 아니다.

오해와 반례

안정적인 군집은 실제 사람의 본질적인 능력 집단이다.

한 측정 단위가 거리를 지배해 안정적인 묶음이 생겨도 능력을 측정한 증거는 없다. 주어진 특징 관계와 해석의 추가 주장을 구별한다.
