소단원 6.1

통계·거리·밀도 해법

다른 점에서 멀다는 것과 주변에서 드물다는 것은 같은 뜻일까?

준비 개념과 학습 목표

준비 개념

  • 거리·평균·표준편차는 자료의 좌표와 단위에 따라 달라진다.

  • 이상탐지는 평소 분포와 다른 관측을 찾는 문제다. 드묾이 곧 해로움이나 오류는 아니다.

학습 목표

  • 통계·거리·국소 밀도 점수를 비교한다.

  • 모형의 가정과 새로운 관측 평가를 구별한다.

새로운 이상 묶음을 정상 참조에 넣으면 희귀성 점수가 어떻게 바뀔까?

앞 본문의 정상 참조와 새 관측을 구별하는 조건을 확장한다. 자체 참조 R의 네 객체 좌표는 0, 1, 4, 5다. 새 q에 대해 닫힌 반경 |q−r|≤1에 들어오는 R 객체 수를 N(q)라 하고 자체 희귀성 점수를 s(q)=1/(N(q)+1)로 정한다. 모든 수는 정확한 실수이며 높은 점수 쪽이 더 드물다는 규약이다. 실제 LOF 공식이나 API 출력이 아니다.

q=1은 참조 0과 1을 보므로 N=2이고 s=1/3이다. q=2.5는 어느 참조도 보지 못해 s=1이다. 새 세 객체 B의 좌표는 10, 10.2, 10.4이며 고정 R에서는 모두 N=0이라 s=1이다. 이 세 객체를 정상이라고 확인하지 않고 R에 추가하면 평가 질문이 바뀐다.

비교용 잘못된 정책은 R과 B를 합친 일곱 객체를 참조로 삼고 자기 객체도 포함하여 B를 다시 평가한다. 이때 각 B 객체는 가까운 B 세 개를 보아 N=3, s=1/4이다. 새 객체가 서로 가깝다는 사실을 정상 학습의 증거로 바꾼 것이다. 정상 여부·원인·해로움은 이 점수만으로 확정하지 않는다.

독립 통계 비교에서 R의 평균은 5/2, 모집단 분산은 17/4, 표준편차는 √17/2다. 통계 점수 z(q)=|q−5/2|/(√17/2)는 q=2.5에서 0, q=5에서 5/√17이다. 한 중심에서 가까움과 정상 무리 주변에 가까움은 다른 조건이다.

먼저 확인할 개념
  • 정상 참조와 자체 점수

    앞 본문의 다중 정상 무리와 자체 이웃 점수를 새 참조 오염 사례로 확장한다.

  • 고정 점수와 행동 경계

    참조 변경으로 점수를 바꾸는 일과 고정 점수의 경보 문턱 변경을 구별한다.

통계적 기준은 가정과 함께 쓴다

참조 평균 μ와 양의 표준편차 σ가 있으면 자체 점수 |x−μ|/σ를 쓸 수 있다. 큰 값은 그 기준에서 먼 관측이다. μ0/σ1 의 자체 정상 모델에서 x3 은 점수 3,x−4 는 4 다. σ0 이면 이 나눗셈을 쓰지 않는다.

한 개의 중심/퍼짐으로 정상 영역을 표현하면 실제 정상 자료가 여러 무리를 이룰 때 각 무리를 놓칠 수 있다. Gaussian shape 와 강건한 추정도 전제를 확인한다. 점수 3 초과를 이상이라 정하는 규칙은 이 카드의 선택이며 모든 데이터의 보편 법칙이 아니다.

거리는 단위와 비교 대상을 필요로 한다

자체 참조점 (0,0),(0,2),(2,0)의 Euclidean 거리는 √((x−u)²+(y−v)²)다. 새 (1,1)은 모두√2,새(10,10)은√200/√164/√164 라 가장 가까운 점까지√164 다.

시간 초와 길이 미터를 섞는 좌표는 축 크기가 거리를 지배할 수 있어 정상 학습 자료에서 변환 규칙을 정한다. 시험 자료로 변환을 다시 fit 하면 평가 조건이 달라진다. 가장 가까운 거리 한 개가 실제 오류 원인을 설명하는 것은 아니다.

주변 밀도는 다른 정상 무리를 허용한다

자체 정상 참조−.1/0/.1/4/4.1/4.2 에서 새 관측 q 의 .2 이내 참조 수를 N(q),점수를 1/(N+1)로 정한다. q4.15 는 세 이웃으로 1/4,q2 는 0 개로 1 이다. 높은 점수가 드문 쪽이라는 자체 규약이다.

이 점수는 실제 LOF 공식이 아니다. LOF 는 이웃 대비 국소 밀도를 비교하며 라이브러리는 점수 부호/학습 표본 평가 규칙을 별도로 둔다. 정상 학습만으로 새 관측을 찾는 novelty 와 이상이 섞인 학습 자료의 outlier 탐지를 구별한다.

새 객체를 정상으로 추가하는 정책 차이

B의 세 점수는 서로 다른 세 객체를 각각 평가한 값이다. 오른쪽 재평가는 API의 LOF 학습 표본 평가 방법이 아니라 자기 포함을 명시한 자체 점수다. 다른 참조를 사용한 점수를 같은 고정 모형의 개선 성과로 비교하지 않는다.

중간 과정을 따라가는 예제

위 자체 참조에서 q=.05/4.15/2 의 반경.2 이웃 수와 자체 점수를 구하라.

  1. .05 에는−.1/0/.1 세 점이 들어 N3 이다.

  2. 4.15 에는 4/4.1/4.2 세 점이 들어 N3 이다.

  3. 2 에는 아무 참조도 없어 N0 이다. 점수는 각각 1/4,1/4,1 이다.

두 정상 무리의 새 점은.25,무리 사이 빈 구간은 1 이다.

조건을 바꾸어 비교하기

가까운 새 묶음이 스스로 기준을 만드는 오류

B 세 객체를 고정 R과 R+B에서 평가하고 score≥1/2라는 자체 경보 규칙을 적용하라.

  1. 고정 R에서는 세 점수가 모두 1이므로 경보 3개다.

  2. R+B에서는 세 점수가 모두 1/4이므로 경보 0개다.

  3. 변한 것은 정상 참조 집합이다. 실제 새 객체가 정상으로 확인된 것이 아니다.

경보 3개 대 0개지만 참조를 변경한 두 평가다.

비교할 점

novelty 탐지의 정상 학습 조건과 새 묶음의 내부 밀도를 구별한다.

한 중심 점수가 놓치는 빈 구간

R의 통계 점수와 자체 희귀성 점수로 q=2.5와 q=5를 비교하라.

  1. 평균은 (0+1+4+5)/4=5/2이고 분산은 (42/4)−(5/2)²=17/4이다.

  2. q=2.5의 z는 0이고 q=5의 z는 5/√17이다.

  3. q=2.5의 s는 1이고 q=5는 참조 4와 5를 보아 s=1/3이다.

통계적 먼 순서는 q=5가 앞서고 자체 희귀성 순서는 q=2.5가 앞선다.

비교할 점

둘 중 어느 것이 현실 이상인지 증명한 비교는 아니다.

연습 1 · 값과 상태 예측

고정 R에서 새 q=−1과 q=6의 N과 s를 구하라. 닫힌 반경 1을 유지한다.

힌트 1

끝의 거리가 정확히 1인 참조도 포함한다.

힌트 2

두 문제 모두 같은 고정 R을 사용한다.

풀이와 답 확인

  1. q=−1은 참조 0만 보며 q=6은 참조 5만 본다.

  2. 둘 다 N=1이고 s=1/2이다.

두 점 모두 경계 이웃 1개와 점수 1/2이다.

흔한 오답에서 다시 생각하기

거리가 1인 참조를 빼면 두 점수는 1이다.

이 카드의 ≤ 경계를 <로 바꾼 계산이다.

연습 2 · 오류 찾아 고치기

모든 좌표를 10배한 뒤 q=1의 대응 좌표 10을 평가한다. 반경은 실수로 1에 고정했다. 원래 이웃 관계를 보존하도록 고쳐라.

힌트 1

변환한 R은 0, 10, 40, 50이다.

힌트 2

좌표 거리와 반경을 함께 변환한다.

풀이와 답 확인

  1. 반경 1이면 참조 10만 있어 N=1, s=1/2이다.

  2. 반경을 10으로 바꾸면 참조 0과 10이 들어 N=2, s=1/3이 복원된다.

반경 10을 써야 원래 q=1의 이웃 관계를 보존한다.

흔한 오답에서 다시 생각하기

단위만 바꾸었으니 어떤 반경을 써도 점수가 같다.

수치 반경도 같은 물리 길이에 맞춰 변환해야 한다.

연습 3 · 직접 만들어 보기

정상 참조 R을 고정한 novelty 평가 계획과, 이상이 섞인 학습 자료에서 outlier를 찾는 계획의 입력/평가 대상을 따로 작성하라.

힌트 1

학습 자료가 정상이라는 전제를 먼저 적는다.

힌트 2

실제 LOF를 사용할 계획에서는 기본 모드와 novelty 모드를 구별한다.

풀이와 답 확인

  1. novelty 계획은 확인된 정상 참조로 규칙을 정하고 새 미관측 객체를 평가한다.

  2. outlier 계획은 이상이 섞일 수 있는 학습 객체 자체에서 비정상 후보를 찾는다. LOF 기본 모드의 fit_predict와 novelty 모드의 새 객체 평가를 혼동하지 않는다.

두 계획은 학습 전제와 평가 객체가 다르며 아직 실제 학습/API를 실행하지 않았다.

흔한 오답에서 다시 생각하기

novelty=True이면 학습 객체에 predict를 다시 써도 같은 평가다.

공식 문서는 novelty 모드의 predict/decision_function/score_samples를 새 미관측 자료에만 쓰도록 경고한다.

연습 4 · 선택 심화

선택 심화는 기본 연습 뒤 더 탐구하고 싶을 때 풀어 보세요.

정상 참조가 한 객체 2뿐일 때 표준편차 0이다. q=2와 q=3의 자체 N/s 및 z 점수의 상태를 구별하라. 반경 1은 유지한다.

힌트 1

이웃 계산은 표준편차를 필요로 하지 않는다.

힌트 2

0으로 나누는 표준화는 별도 정책이 필요하다.

풀이와 답 확인

  1. 두 q 모두 참조 2와의 거리가 1 이하라 N=1, s=1/2이다.

  2. z의 분모는 0이므로 두 관측 모두 이 식으로는 정의되지 않는다.

자체 이웃 점수는 각각 1/2지만 표준화 점수는 미정의다.

흔한 오답에서 다시 생각하기

q=2는 0/0이므로 표준화 0으로 자동 통과한다.

0/0을 임의 숫자로 채우는 것은 추가 정책이며 원래 식의 결과가 아니다.

소단원 6.2

불균형과 threshold

이상이 아주 적으면 정확도 99%가 좋은 탐지를 뜻할까?

준비 개념과 학습 목표

준비 개념

  • TP 는 실제 이상을 경보, FP 는 정상을 경보, FN 은 이상을 놓침, TN 은 정상을 통과한 건수다.

  • precision=TP/(TP+FP), recall=TP/(TP+FN)이며 분모 0 이면 별도 미정의 표시다.

학습 목표

  • 불균형의 정확도 함정을 계산한다.

  • threshold 와 경계 규칙을 바꾸며 혼동표를 만든다.

경보 두 개라는 용량을 문턱 하나로 항상 정확히 맞출 수 있을까?

고정된 여덟 가상 객체 A부터 H의 점수는 순서대로 0.9, 0.8, 0.8, 0.7, 0.6, 0.4, 0.3, 0.1이다. 실제 이상 라벨은 A, C, E, G이고 정상 라벨은 B, D, F, H다. 모든 라벨은 이 카드에서만 주어진 정답이며 실무 사건을 조사한 기록이 아니다. 높은 점수일수록 이상이고 score≥t를 경보하는 자체 규칙을 쓴다.

t=0.8이면 A/B/C 경보 3개이고 TP=2, FP=1, FN=2, TN=3이다. t=0.6이면 A부터 E까지 5개를 경보하며 TP=3, FP=2, FN=1, TN=2다. 정확도는 두 경우 모두 5/8이지만 recall은 1/2과 3/4로 다르다.

B와 C의 점수가 같아 ≥ 문턱은 이 둘을 함께 넣거나 함께 뺀다. 0.8<t≤0.9이면 A만 남고 t>0.9이면 경보가 없다. t≤0.8이면 적어도 세 개다. 따라서 경보를 정확히 두 개 만들 수 없다. 용량 2의 top-2 정책을 쓴다면 별도 동점 규칙을 명시해야 한다.

자체 top-2 정책은 동점에서 문자 ID가 앞선 객체를 먼저 둔다. 그러면 A/B가 뽑혀 TP=1, FP=1이다. C가 이상이라는 정답 라벨을 보고 동점 선택을 바꾸면 평가 때 정답을 행동 정책에 누출한 것이다. 독립 조정 자료와 최종 평가 자료를 구별한다.

먼저 확인할 개념
  • 고정 점수와 혼동표

    앞 본문의 문턱·경계와 분모 계산을 동점 및 용량 사례로 확장한다.

  • 비용과 검토 용량

    최저 비용과 용량 충족이 다른 조건임을 동점 경보 집합에서 확인한다.

큰 정상 집단이 평균을 가린다

정상 100/이상 5 의 카드에서 전부 정상이라 예측하면 100/105=20/21≈95.24% 정확도다. 그러나 이상 5 개를 모두 놓쳐 recall0 이다. 경보가 0 개라 precision 분모 0 을 성공 100%로 채우지 않는다.

평가에 실제 이상을 판정한 라벨과 분모가 필요하다. 미확인 사건을 정상으로 자동 채우거나 train 에서 threshold 를 최적화한 결과만 보고하면 범위가 달라진다. 학습용/조정용/최종 평가 자료의 역할을 구별한다.

점수와 경보는 다른 층이다

자체 높은 점수일수록 이상이라는 규약과 score≥t 경계 규칙을 쓴다. A.9/B.8/C.7/D.6/E.4/F.2 이며 실제 이상은 A/C/E,정상은 B/D/F 다. threshold 만 바꿔도 점수 순서는 그대로다.

t 를 낮추면 경보 집합이 커지고 이 고정 표에서 recall 은 줄지 않지만 precision 은 항상 좋아지거나 나빠지는 단조량이 아니다. 동점과 ≥/>의 선택도 경보 수를 바꾸므로 기록한다. 라이브러리 기본 경계와 이 카드의 ≥를 혼동하지 않는다.

최종 평가에서 고르지 않는다

t=.8 은 A/B 만 경보라 TP1/FP1/FN2/TN2 다. t=.6 은 A/B/C/D 라 TP2/FP2/FN1/TN1 이다. 각 경보 precision 은.5,recall 은 1/3→2/3 다.

이 표는 threshold 이해용 가상 카드다. 조정용 자료에서 목적 지표와 threshold 를 정한 뒤 독립 최종 자료에서 평가해야 하며 이 표에서 고른 값이 다른 분포/미래에서 보편 최적이라는 결론은 없다.

중간 과정을 따라가는 예제

  3. .6:TP2/FP2/FN1/TN1,precision2/4=.5,recall2/3,정확도 3/6=.5 다.

조건을 바꾸어 비교하기

같은 0.8을 포함하는가

≥0.8과 >0.8의 경보·precision·recall을 비교하라.

  1. ≥이면 A/B/C를 경보하여 TP 2, FP 1이고 precision 2/3, recall 1/2이다.

  2. >이면 A만 경보하여 TP 1, FP 0이고 precision 1, recall 1/4이다.

  3. 점수 순서를 다시 학습하지 않았으며 경계 규칙만 다르다.

경보 3개 대 1개이며 성과 분모도 달라진다.

비교할 점

라이브러리의 기본 경계가 이 자체 ≥ 규칙과 같다고 가정하지 않는다.

용량 두 개와 정답을 본 동점 선택

top-2의 ID 규칙과, 평가 라벨을 보고 C를 B 대신 고른 선택을 비교하라.

  1. 사전에 정한 ID 규칙은 A/B를 골라 TP 1, FP 1이다.

  2. 라벨을 보고 A/C를 고르면 TP 2, FP 0이지만 같은 사전 정책의 성과가 아니다.

  3. 실무에서 쓸 동점 규칙을 조정 단계에 고정하고 최종 평가에서는 바꾸지 않는다.

표의 정식 top-2 precision은 1/2이고 recall은 1/4다.

비교할 점

정답을 본 사후 선택을 독립 성능으로 보고하지 않는다.

종이와 본문으로 직접 해보기

정확도만 같으면 탐지 성과도 같고 threshold 를 낮추면 모든 지표가 좋아진다.

두 표의 정확도.5 는 같지만 놓친 이상/경보수가 다르다. .9 에서.4 로 precision1→.6 이면서 recall1/3→1 이라 목적에 따른 교환을 확인한다.

연습 2 · 오류 찾아 고치기

검토 용량 2인데 score≥0.8 정책을 용량 충족이라고 기록했다. 한 문턱 정책을 유지하면서 가능한 경보 수를 고쳐라.

힌트 1

경보는 A/B/C 세 개다.

힌트 2

0.8의 두 객체를 문턱만으로 나눌 수 없다.

풀이와 답 확인

  1. ≥0.8은 용량을 넘는다.

  2. 예를 들어 ≥0.9이면 A 하나만 경보되어 용량을 지키지만 정확히 두 개를 쓰지 않는다.

한 문턱으로 정확히 두 개는 불가능하며 한 개 경보 후보를 따로 기록한다.

흔한 오답에서 다시 생각하기

경보 집합·정책을 바꾸지 않고 숫자만 고치면 관측 계약을 어긴다.

힌트 1

힌트 2

G는 경보 밖에 있고 이상일 수도 정상일 수도 있다.

풀이와 답 확인

힌트 1

전체 분자는 TP 합계다.

힌트 2

묶음 평균은 각 묶음에 같은 무게를 준다.

풀이와 답 확인

  2. 단순 묶음 평균은 (1+1/9)/2=5/9이다.

흔한 오답에서 다시 생각하기

평균 recall 5/9가 전체 열 건 중 탐지 비율이다.

오탐 비용

경보를 많이 보내는 비용과 놓치는 비용을 어떻게 함께 판단할까?

준비 개념과 학습 목표

준비 개념

  • FP/FN 의 분모와 비용 단위를 구별한다. 비용은 예시의 가상 손실 점수다.

  • 확률 추정의 보정은 점수가 실제 조건부 비율을 잘 반영하는지에 관한 성질이다.

  • 비용표와 검토 용량으로 threshold 후보를 비교한다.

  • 빈도·확률·점수 및 실제 운영 검증의 범위를 구별한다.

순위가 같은 두 점수에 같은 숫자 문턱을 쓰면 같은 행동일까?

독립 확률 모형에서 이상확률 p는 해당 객체의 정확한 조건부 확률이라고 가정한다. 정상 객체를 경보하는 FP 비용은 3, 이상을 경보하지 않는 FN 비용은 9이며 맞는 결정 비용은 0이다. 경보 기대 비용은 3(1−p), 무경보 기대 비용은 9p다. 경보가 엄격히 유리한 조건은 p>1/4이고 같으면 무경보를 택하는 자체 동률 정책이다. 실제 금액이나 피해를 측정한 모형이 아니다.

변형 점수 q=p²는 [0,1]에서 순서를 보존하지만 일반적으로 같은 확률을 뜻하지 않는다. p 문턱 1/4의 동등한 q 문턱은 1/16이다. 같은 수치 1/4를 q에 적용하면 p>1/2인 객체만 남아 다른 행동이 된다.

또 다른 독립 경험 기록은 점수 0.2인 열 객체다. X 맥락 다섯 개 중 이상 2개, Y 맥락 다섯 개 중 이상 0개다. 전체 빈도는 2/10=0.2여도 X의 경험 비율은 2/5=0.4이고 Y는 0이다. 이 유한 기록은 정확한 미래 확률의 증명이 아니며 전체 점수 묶음의 일치가 모든 하위 맥락의 보정을 보장하지 않는다.

별도 용량 사례의 세 객체 J/K/L은 정확한 p가 각각 0.6, 0.4, 0.3이다. 이때 기대 비용을 더할 수 있도록 총비용을 각 객체 비용 합으로 정의한다. 사건 독립성은 기대 합계에 필요하지 않다. 경보 용량은 2개이며 행동은 결과를 보기 전에 정한다.

먼저 확인할 개념
  • 확률·비용과 별도 용량

    앞 본문의 보정된 확률 전제와 기대 비용 경계를 다른 가상 비용으로 유도한다.

  • 고정 순위와 행동 정책

    순위 보존 변환과 같은 숫자 문턱을 혼동하지 않는 이유를 연결한다.

가상 비용으로 후보를 비교한다

앞 카드의 정상 오경보 하나에 2,이상 누락 하나에 10 의 가상 비용을 둔다. 맞는 결정 비용 0 이면 합계 2FP+10FN 이다. t=.9 는 0FP/2FN 으로 20,.8 은 1FP/2FN 으로 22,.6 은 2FP/1FN 으로 14,.4 는 2FP/0FN 으로 4 다.

.4 가 이 후보표에서 최저일 뿐 모든 자료/후보/실제 운영의 보편 최적은 아니다. 사람 검토 시간·정상 차단의 영향·누락 손실은 문맥에 따라 다르고 여기서는 실제 돈이나 위험을 측정하지 않았다.

검토 용량은 별도 제약이다

한 번에 경보 2 개까지만 처리할 수 있다면 .6 의 4 개와.4 의 5 개는 용량 밖이다. 가능한 .9 의 1 개/.8 의 2 개 중 비용 20 인.9 가 22 인.8 보다 작다. 최저 비용 계산과 용량 충족을 별도 표시한다.

경보를 추가로 확인해서 실제 이상인지 알아야 하는 검토 절차는 자동 점수와 구별한다. 순위 앞 2 개를 고르는 정책과 고정 threshold 정책은 동점/시간별 빈도에서 다른 행동을 만들 수 있다. 실제 검토자·서버·사건은 없다.

보정된 확률일 때 기대 비용

정확한 조건부 이상확률 p 를 안다는 자체 가정이면 경보의 기대 비용 2(1−p),무경보의 기대 비용 10p 다. 2(1−p)<10p 를 풀면 p>1/6 에서 경보가 더 작고 같을 때 동률 정책을 정한다. 점수가 확률이 아니면 이 경계를 그대로 쓰지 않는다.

이상 빈도가 달라지면 같은 TPR/FPR 가정에서도 경보 중 이상 비율이 달라진다. 정상 1000/이상 10 에서 TPR.8/FPR.02 의 가상 기대표는 TP8/FP20/FN2/TN980 이다. 실제 건수 관측이 아니라 이 수를 만족하도록 둔 모형이다.

조건을 바꾸어 비교하기

제곱 점수에도 확률 문턱을 그대로 쓰는 오류

p=0.2,0.3,0.5에서 q>1/4와 올바른 변환 문턱을 비교하라.

  1. q는 각각 0.04, 0.09, 0.25다.

  2. q>1/4는 세 객체 모두 무경보다.

  3. q>1/16이면 0.09와 0.25가 경보되어 원래 p>1/4와 같다.

풀이와 답 확인

  1. ① 고정 R에서 B 세 객체는 각각 N=0, s=1이라 경보 3개다. R+B에서 각각 N=3, s=1/4이라 경보 0개지만 정상 참조를 바꾼 평가다.

  2. ② ≥0.8은 A/B/C로 TP 2, FP 1, FN 2, TN 3이고 용량을 넘는다. ID top-2는 A/B로 TP 1, FP 1, FN 3, TN 3이며 경보 2개다.

  3. ③ 모두 무경보의 기대 비용은 11.7이다. J의 이득 4.2가 가장 커서 J만 경보하면 1.2+3.6+2.7=7.5다.

  4. 동일 비용의 개별 유리한 경계 p>1/4는 q=p²에서 q>1/16으로 변환된다. 그러나 용량 1은 그 경계만으로 자동 충족되지 않으므로 후보 이득을 따로 비교한다.

참조 변경의 경보 수는 3개 대 0개다. ≥0.8 경보 3개와 top-2 경보 2개는 다른 정책이다. 용량 1의 J만 경보는 기대 비용 7.5이며 제곱 점수의 개별 행동 경계는 1/16이다.

해결한 뒤 점검할 것

  • 자체 N/s와 실제 LOF를 구별하고 새 객체를 정상으로 추가한 전제 변경을 설명한다.

  • 동점 B/C·ID 선택·전체 분모를 유지해 두 혼동표와 용량을 계산한다.

  • 확률/점수·개별 유리한 문턱/용량 제약을 나누어 기대 비용을 계산한다.

  • 모든 가상 사건과 손계산 범위를 보존하고 실제 탐지·조정·학생 성과를 주장하지 않는다.
